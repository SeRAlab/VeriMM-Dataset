Develop a basic calculator module that performs arithmetic operations based on the CONTROL input. It takes two 8-bit inputs, A and B, and outputs the result of the selected operation—addition, subtraction, multiplication, or division—on an 8-bit output C. The module operates synchronously on the rising edge of the CLK signal, with the ability to reset its output and internal temporary storage to zero when the CLEAR signal is activated.
module top_module(input CLK, input [1:0] CONTROL, input CLEAR, input [7:0] A, input [7:0] B, output reg [7:0] C);
