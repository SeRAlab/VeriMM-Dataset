Implement a First-In-First-Out (FIFO) buffer that operates on a positive clock edge. The module allows writing 8-bit data inputs into a memory buffer and reading from the buffer based on the specified address. It maintains internal pointers for head and tail to track data entries while measuring the buffer's current length. The FIFO signals when it is empty and checks if the specified amount of data has been sent. On a read request, it increments the tail pointer and outputs the data from the buffer; on data writing, it stores incoming data at the head pointer location. Additionally, it includes a mechanism to reset the length and tail pointers once data transmission is complete.
