

You are tasked with designing a module that implements a 4-bit binary up counter with synchronous clear functionality. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock input
- `clr`: a synchronous clear input

Outputs:
- `Q`: a 4-bit output representing the count value

The counter should increment by 1 on each rising edge of the clock input. When the clear input is asserted, the counter should be reset to 0.

Write a Verilog module that implements the above counter with synchronous clear functionality.
