Design a Verilog module that implements a 4-bit binary up-counter with synchronous set. The counter should increment on the rising edge of the clock. The counter should set to a given value when the synchronous set (sset) is high. The counter value should be output to the "count" signal.

module top_module
(
    input clk,
    input sset,
    input [3:0] set_value,
    output reg [3:0] count
);
