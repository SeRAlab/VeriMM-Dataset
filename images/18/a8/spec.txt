
Implement a UART transmitter that sends an 8-bit data byte serially at a specified baud rate. The module should include the following inputs: 
1. `data_in` (8 bits): The data byte to be transmitted.
2. `start_tx`: A signal to initiate the transmission.
3. `clk`: The clock signal for synchronization.
4. `baud_rate`: A parameter defining the baud rate for transmission.

The output should be a serial `tx_line` which transmits the data in the following format: start bit (0), followed by the 8 data bits, and then the stop bit (1).
