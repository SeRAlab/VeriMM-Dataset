Design a simple PCIe endpoint controller that can accept requests for reading and writing data. The controller should have an input for a request signal, a 32-bit address, a 32-bit data input for writes, and a 32-bit data output for reads. When a read request is received, the controller should output data from the specified address. For write requests, the controller should store the data at the specified address. The controller should also have a ready signal to indicate when it is ready to accept new requests.
