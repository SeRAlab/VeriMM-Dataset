Design a Verilog module that implements a 5-bit binary down-counter with enable and asynchronous reset. The counter should decrement on the rising edge of the clock if the "enable" signal is high. The counter should reset to the maximum value (5'b11111) when the asynchronous reset (areset) is high. The counter value should be output to the "count" signal.

module top_module
(
    input clk,
    input areset,
    input enable,
    output reg [4:0] count
);
