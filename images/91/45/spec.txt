Design a synchronous 2-to-1 multiplexer with an active-low reset feature. The output 'out' is determined by the selection input 'sel': when 'sel' is 0, output A is passed through, and when 'sel' is 1, output B is selected. The output is updated on the rising edge of the clock signal 'clk', and if the 'reset' signal is asserted (active low), the output is reset to 0.
module top_module(
    input A, B, sel, reset, clk,
    output reg out
);
