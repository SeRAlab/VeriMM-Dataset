Design a simple calculator circuit that performs basic arithmetic operations—addition, subtraction, multiplication, and division—on two signed 8-bit input values, a and b. The operation to be performed is selected by a 2-bit operation code (op). For each operation, the module outputs the result to the respective output ports while ensuring that unused outputs for other operations are set to zero.
module top_module(input signed [7:0] a, b, output reg signed [7:0] add_out, sub_out, mul_out, div_out, output reg [1:0] op);
