Design a 4-bit wide, synchronous flip-flop module with additional reset functionality. The module captures an 8-bit input data when the enable signal is active and the clock rises, and it will reset to zero upon receiving a reset signal or an external reset command. The current value of the flip-flop is continuously outputted for further usage.
module top_module(
  input        clock,
  input        reset,
  input  [7:0] io_input_0_data,
  input        io_input_0_enable,
  input        io_input_0_reset,
  output [7:0] io_output_data
);
