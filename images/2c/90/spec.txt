
Design a Verilog module that implements a data integrity checker using a simple checksum. The module will take a 8-bit input data, and a 3-bit checksum input. The module will compute the checksum of the input data by summing the bits and will compare it to the provided checksum. If they match, the output should indicate that the data is valid; otherwise, it should indicate that the data is invalid. The output should be a single bit, where '1' indicates valid data and '0' indicates invalid data. The module should have a clock input to synchronize the operations.
