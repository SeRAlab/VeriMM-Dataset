Design a 4-bit barrel shifter capable of performing both left and right shifts based on a 2-bit shift control input. The output reflects the input value A shifted by the number of positions specified in SHIFT, which can take values from 0 to 3. The design intends to provide a simple mechanism for shifting bits within a 4-bit width, facilitating operations such as multiplication (left shifts) and division (right shifts).
module top_module(
    input [3:0] A,
    input [1:0] SHIFT,
    output reg [3:0] OUT
);
