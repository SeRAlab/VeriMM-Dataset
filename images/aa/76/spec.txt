Design a 1-to-4 demultiplexer. The module takes a single input signal `x` and a 2-bit select signal `S`, directing the input to one of the four output channels `Y`. Based on the value of `S`, one of the outputs will emit the value of `x`, while all other outputs will be set to LOW. Specifically, when `S` is 00, `x` appears at `Y[0]`; when `S` is 01, it goes to `Y[1]`; when `S` is 10, it is routed to `Y[2]`; and all other select values default to placing `x` at `Y[3]`.
module top_module(
    x,
    S,
    Y
);
