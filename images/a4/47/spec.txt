Develop a D flip-flop with asynchronous reset functionality. The output Q reflects the input D's value on the rising edge of a clock signal while RESET_B allows asynchronous resetting of the output to a LOW state when activated. This design also incorporates power management features with VPWR, VGND, and biasing inputs VPB and VNB, demonstrating a robust implementation using standard cell techniques.

    input D,

    input VNB,
    output reg Q,
    output reg Q_N,
    input GATE_N
