Design a 4-input Logistic Regression module that outputs a binary classification based on weighted sums and a threshold. The module should take 4 input signals (x1, x2, x3, x4), each representing a feature. The weights (w1, w2, w3, w4) for these inputs are fixed as 2, -1, 1, and 1 respectively. The output should be 1 if the weighted sum exceeds a threshold (which is set to 1.0), otherwise 0.
