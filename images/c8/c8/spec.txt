

You are tasked with designing a Verilog module for a 2:1 multiplexer. The module should have two inputs, A and B, and one output, Y. The output should be equal to A when the select input, S, is 0, and equal to B when S is 1. 

Your module should have the following interface:

```
module mux_2to1 (
    input A,
    input B,
    input S,
    output Y
);
```

You are required to implement the module using only combinational logic, without using any built-in Verilog constructs such as `if-else` or `case` statements. You may use any other combinational logic construct, such as `and`, `or`, `not`, `xor`, or `nand`.

Your module must be able to handle the following test cases:

1. When S = 0, A = 1 and B = 0, Y should be 1.
2. When S = 1, A = 0 and B = 1, Y should be 1.
3. When S = 0, A = 0 and B = 1, Y should be 0.
4. When S = 1, A = 1 and B = 0, Y should be 0.

Note: You may assume that the input signals A, B, and S are always valid (i.e., either 0 or 1).
