Design a 4x Phase-Locked Loop (PLL) that takes an input clock signal and generates an output clock signal that is four times the frequency of the input clock. The PLL should include a phase detector, a low-pass filter, and a voltage-controlled oscillator (VCO). The phase detector outputs a pulse when the input clock is higher or lower than the VCO output clock. The output clock should toggle every time there is a pulse from the phase detector.
