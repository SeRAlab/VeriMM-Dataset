Design a state-space controller that takes a 4-bit input representing the current state and a 1-bit signal representing a control input. The controller should output the next state based on the following state transition table:

| Current State | Control Input | Next State |
|---------------|---------------|------------|
| 0000          | 0             | 0001       |
| 0000          | 1             | 0010       |
| 0001          | 0             | 0011       |
| 0001          | 1             | 0100       |
| 0010          | 0             | 0101       |
| 0010          | 1             | 0000       |
| 0011          | 0             | 0110       |
| 0011          | 1             | 0000       |
| 0100          | 0             | 0101       |
| 0100          | 1             | 0111       |
| 0101          | 0             | 0000       |
| 0101          | 1             | 0001       |
| 0110          | 0             | 0111       |
| 0110          | 1             | 0011       |
| 0111          | 0             | 0000       |
| 0111          | 1             | 0100       |
