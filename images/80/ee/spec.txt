Design a clock gating circuit that enables or disables the clock signal based on control inputs. The module toggles the output `ENCLK` on the rising edge of the `CLK` signal whenever both the `EN` (enable) and `TE` (toggle enable) inputs are asserted. If the `reset` input is active, the output is set to LOW. This functionality helps in power management by controlling when the clock is active, thereby reducing unnecessary power consumption in digital circuits.
module top_module(
  input CLK,
  input EN,
  input TE,
  input reset,
  output ENCLK
);
