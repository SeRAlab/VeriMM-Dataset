Design a 16-bit DRAM cell that can store, read, and write data. The DRAM cell should have the following inputs: a 16-bit data input (data_in), a control signal for write (write_enable), a control signal for read (read_enable), and a clock signal (clk). The output should be a 16-bit data output (data_out). The DRAM cell should hold the data written to it until it is overwritten, and when read, it should output the currently stored data. Ensure proper timing with the clock signal.
