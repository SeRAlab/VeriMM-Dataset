Develop a digit state machine that sequentially selects and outputs four decimal digits (units, tens, hundreds, thousands) based on a clock signal. Upon each clock cycle, the state machine transitions through four states (S0 to S3) that correspond to each digit. While the decimal point is active (logic high) for the first three digits, it is turned off (logic low) for the thousands place. The output signals include a digit selector to indicate the currently active digit and the corresponding data value for display purposes. This module can be used in applications such as a digital display where multiple digits need to be shown one at a time.
module top_module(input clk,input reset_n,input [3:0] units,input [3:0] tens,input [3:0] hundreds,input [3:0] thousands,output reg [2:0] digit_select,output reg [3:0] data,output reg decimal_point);
