Design an 8-bit DRAM cell that can store a single bit of data. The DRAM cell should have a data input (D), a read/write control signal (RW), and a clock signal (CLK). When RW is high, the data from D should be written to the cell on the rising edge of CLK. When RW is low, the stored data should be output on a data output signal (Q) on the rising edge of CLK.
