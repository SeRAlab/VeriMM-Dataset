
Design a Model Predictive Control (MPC) unit in Verilog that controls a simple first-order system. The system has an input `u` and an output `y`. The MPC will use a simple proportional control strategy where the control action is computed based on the error between the desired setpoint `setpoint` and the current output `y`. The control action will be constrained within specific limits. Implement an update mechanism such that the control action is applied every clock cycle based on the current error and the previous action.
