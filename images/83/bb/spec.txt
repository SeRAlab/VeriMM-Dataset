Design a one-bit wide D flip-flop with asynchronous enable control. When the enable signal (en) is high and on the rising edge of the clock (clk), the input data (din) is latched into the output (q). If the enable signal is low, the output retains its previous value regardless of the input. This module effectively captures and holds input data under specified conditions, making it suitable for synchronous storage applications.
