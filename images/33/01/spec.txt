
Design a simple Automatic Repeat reQuest (ARQ) error correction system that takes a 5-bit input data word and a single bit for an acknowledgment (ACK). If the ACK is '1', the system will accept the data and store it. If the ACK is '0', the system will output a request for retransmission (RETRANSMIT signal) and keep the previous valid data until a valid ACK is received.
