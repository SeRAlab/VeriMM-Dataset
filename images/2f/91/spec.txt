
Design a 16-bit DRAM cell that has the following functionalities:
1. It should have a data input (data_in), a data output (data_out), a read enable (read_en), a write enable (write_en), and a clock (clk).
2. When write_en is high, the data_in should be stored in the 16-bit memory cell on the rising edge of clk.
3. When read_en is high, the data stored in the memory cell should be available at data_out on the next clock cycle.
