Design a Verilog module that implements a 9-bit binary up-counter with both synchronous and asynchronous resets and a load functionality. The counter should increment on the rising edge of the clock. The counter should load a given value (load_val) when the load (ld) signal is high. The counter should reset to zero when the synchronous reset (sreset) is high or the asynchronous reset (areset) is high. The counter value should be output to the "count" signal.

module flexible_up_counter
(
    input clk,
    input ld,
    input sreset,
    input areset,
    input [8:0] load_val,
    output reg [8:0] count
);
