Design a sequential circuit that implements a three-stage shift register for each of the three input signals (x0, y0, and z0). On each rising edge of the clock (clk), the input signal x0 is shifted through three stages producing the output x3, while inputs y0 and z0 are similarly processed to yield outputs y3 and z3 respectively. The first stage for each signal is implemented using non-blocking assignments for x and blocking assignments for y and z, resulting in different timing behaviors for how the outputs reflect the inputs over time.
module top_module(
    input wire clk,
    input wire x0, y0, z0,
    output reg x3, y3, z3
   );
