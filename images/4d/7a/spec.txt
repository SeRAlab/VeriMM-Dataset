Design a 4-to-16 decoder. The module takes a 2-bit select input and an enable signal. When the enable signal is LOW, the output is set to zero. When the enable signal is HIGH, the output corresponds to one of the 16 output lines, activated based on the value of the select input, which asserts one of the four bits in the output to HIGH while the rest remain LOW.
module top_module(
    input [1:0] select,
    input enable,
    output reg [15:0] out
);
