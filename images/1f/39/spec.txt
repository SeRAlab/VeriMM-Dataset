
Design a 4-bit SRAM cell with read and write functionality. The SRAM cell should have the following inputs: 
- `write_enable`: a control signal to enable writing
- `address`: a 2-bit address to select one of four 4-bit data lines
- `data_in`: a 4-bit input data to be written
- `read_enable`: a control signal to enable reading

The outputs should be:
- `data_out`: a 4-bit output data that is read from the selected address.
