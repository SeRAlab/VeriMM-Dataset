
Design an 8-bit SRAM cell with the following specifications:
1. It should have an 8-bit data input (D_IN) and an 8-bit data output (D_OUT).
2. It should have a write enable signal (WE) that controls whether the data is written to the memory.
3. It should have an active low chip select signal (CS) that enables the SRAM cell.
4. The SRAM cell should retain the last written data when not writing, provided it is selected.
5. The SRAM cell should have a clock signal (CLK) to synchronize the writing process.
