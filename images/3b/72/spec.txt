
Design a fan speed controller that has a speed control input, a temperature input, and a clock signal. The fan should operate at different speeds based on the temperature input and the control signal. The speed can be set to off (00), low (01), medium (10), or high (11) based on the following conditions:
- If the temperature is below 20 degrees, the fan speed should be off.
- If the temperature is between 20 and 30 degrees, the fan speed should be low.
- If the temperature is between 30 and 40 degrees, the fan speed should be medium.
- If the temperature is over 40 degrees, the fan speed should be high.
If the control signal is 00, the fan should remain off regardless of temperature.
