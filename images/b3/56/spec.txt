Design a gated D flip-flop with asynchronous clear functionality. The flip-flop captures the input data (d) on the rising edge of the clock (clk) only when the enable signal (en) is asserted; otherwise, it retains its previous state. If the clear signal (clr) is active low, it resets the output (q) to LOW and the inverted output (qn) to HIGH. This design effectively combines memory storage with control signals for synchronization and state management.
