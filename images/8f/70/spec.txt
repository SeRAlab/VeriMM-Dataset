Module name:  
    shift_register

    clk: Clock signal used for synchronous operation.
    rst_n: Active-low reset signal to initialize the register.
    load: Signal to load a specific value into the shift register.

Output port:
    Q: 16-bit register representing the current value of the shift register.

Implementation:

If the load signal is high, the shift register value (Q) is set to the load_value.
Otherwise, the shift register shifts left by 1 bit.
