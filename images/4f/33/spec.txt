Design a flip-flop register that stores instruction and program counter information in a pipelined architecture. On the rising edge of the clock, it captures and latches the input instruction (instrIn) and the value of pcplus4, which represents the address of the next instruction. The output will provide the stored instruction as instrOut and the program counter incremented by 4 as pcplus_4 for use in the subsequent pipeline stage.
module top_module(

	input clk,
	input [31:0] instrIn,
	input [31:0] pcplus4,
	output reg [31:0] instrOut,
	output reg [31:0] pcplus_4
    );
