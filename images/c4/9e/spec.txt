

You are tasked with designing a Verilog module for a computer system's video in subsystem edge detection. The module should be able to detect the edges in the input video signal and output the detected edges.

The module should have the following inputs:
- `in_data`: a 10-bit input signal representing the video data
- `clk`: the clock signal
- `rst`: the reset signal

The module should have the following outputs:
- `out_data`: a 10-bit output signal representing the detected edges in the input video

The edge detection algorithm should work as follows:
- The module should compare the current input value with the previous input value
- If the difference between the current and previous input value is greater than a certain threshold, the module should output a 1 to indicate an edge has been detected. Otherwise, the module should output a 0.

The threshold value should be configurable and should be set by a 4-bit input signal `threshold`. The threshold value should be in the range of 0 to 1023.

Design a Verilog module that implements the above edge detection algorithm.
