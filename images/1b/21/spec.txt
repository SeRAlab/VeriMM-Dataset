Design a JK latch using Verilog. The JK latch should have two inputs (J and K), one clock input (CLK), and two outputs (Q and not Q). The latch should toggle its state based on the values of J and K at the rising edge of the clock. If J and K are both low, the output Q retains its state. If J is high and K is low, Q should be set to high. If J is low and K is high, Q should be set to low. If both J and K are high, Q should toggle its current state.
