

You are tasked with designing a Verilog module that implements a 4-to-1 multiplexer (MUX4_1) using the following inputs and outputs:

Inputs:
- x0: 1-bit input
- x1: 1-bit input
- x2: 1-bit input
- x3: 1-bit input
- s0: 1-bit select input
- s1: 1-bit select input

Output:
- y: 1-bit output

The MUX4_1 should select one of the four inputs (x0, x1, x2, or x3) based on the values of s0 and s1, and output the selected input to y. The selection should follow the following truth table:

s1 | s0 | y
---|---|---
0 | 0 | x0
0 | 1 | x1
1 | 0 | x2
1 | 1 | x3

You should implement the MUX4_1 module within 200 lines of Verilog code.
