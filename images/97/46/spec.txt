Design a one-bit edge detector that outputs a signal indicating a rising edge on the input. The module uses a clock signal to synchronize operations; on each rising edge of the clock, it captures the current input value and stores it in a buffer. The output is generated by performing a bitwise AND operation between the current input and the negation of the stored buffer, effectively detecting transitions from LOW to HIGH in the input signal.
