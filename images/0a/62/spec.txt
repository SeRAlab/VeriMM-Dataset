Design a simple virtual memory management unit (VMU) that translates a virtual address to a physical address using a page table. The page table is stored in memory and consists of 4 entries. Each entry maps a virtual page number to a physical frame number. The input is a virtual address and a valid bit indicating if the entry is valid. The output is the corresponding physical address, or an error signal if the entry is invalid. The unit should also include a clock to trigger the updates.
