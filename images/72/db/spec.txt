Design a four-bit adder that computes the sum of two 4-bit inputs, A and B, along with an additional carry-in bit, Cin. The summation is triggered on the rising edge of the clock signal, and the resulting sum is output as a 4-bit value, C. Additionally, the module outputs a carry-out signal, Cout, indicating whether there is an overflow from the addition.
module top_module(
  input clk,
  input [3:0] A,
  input [3:0] B,
  input Cin,
  output [3:0] C,
  output Cout
);
