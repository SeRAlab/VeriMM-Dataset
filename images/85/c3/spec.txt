Design a synchronous data memory module capable of performing read and write operations. The module has a 32-bit address and write data input, and a 32-bit read data output. On the rising edge of the clock, if the MemWrite signal is asserted, it writes the Write_data to the specified memory location, indexed by the Address (divided by four). On the falling edge of the clock, if the MemRead signal is asserted, it retrieves the data from the specified memory location into Read_data. This effectively creates a simple dual-port memory system that separates read and write operations by clock edge.
module top_module(Address, Write_data, Read_data, MemRead, MemWrite, clk);
