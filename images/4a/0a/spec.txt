Design a circuit that decodes a 13-bit address input to generate selection signals for ROM and RAM. The module activates the ROM selection signal (`rom_sel`) when the address starts with `11`, while the RAM selection signal (`ram_sel`) is activated for addresses starting with `10` or `01`. For any other address pattern, both selection signals are set to LOW. This design ensures proper routing of the address to the correct memory subsystem based on the specified address ranges.
