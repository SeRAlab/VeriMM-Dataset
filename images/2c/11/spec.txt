Design a simple I2C controller that can perform the start condition, stop condition, and send a byte of data. The controller should have inputs for the I2C clock (SCL), the I2C data line (SDA), a start signal, and a stop signal. The outputs should indicate when a start condition has occurred, a stop condition has occurred, and when a byte of data has been sent. The data byte should be shifted out on the SDA line on the rising edge of SCL.
