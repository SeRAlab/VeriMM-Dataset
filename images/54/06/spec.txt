Design a pixel overlay module for a graphical display system. This module takes pixel clock, pixel coordinates, and RGB input values to determine if a pixel should be displayed as an overlay, specifically when the pixel's coordinates are on the edges of the display (where either x or y coordinate is at its limits). When in an overlay position, the pixel color is set to black for red and green channels while keeping the blue channel fully on, creating a distinct overlay effect. Otherwise, the module outputs the original input pixel colors, allowing for dynamic visual effects based on the display position.
