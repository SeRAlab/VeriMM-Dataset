Design a 2-channel DMA controller that allows for data transfer between memory and two peripheral devices. The controller should have the following inputs: `request1`, `request2` (indicating peripheral device requests), `clk` (clock), and `reset`. The output should be `grant` (indicating which device is granted access to the bus). The controller should grant access in a round-robin fashion: if `request1` is active first, it gets granted, then `request2` gets granted on the next request, and so forth. The reset signal should clear the state.
