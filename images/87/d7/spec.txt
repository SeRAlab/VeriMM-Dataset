Design a 16-bit Arithmetic and Logic Unit (ALU) that performs basic operations based on a 2-bit operation select signal (`op`). When `op` is `00`, the ALU computes the sum of inputs `A` and `B`. When `op` is `01`, it calculates the difference of `A` minus `B`. For `op` equal to `10`, it performs a bitwise AND operation between `A` and `B`, and for `op` equal to `11`, it executes a bitwise OR operation on `A` and `B`. The result of these operations is stored in the output `Z`.
module top_module(output reg [15:0] Z, input [1:0] op, input [15:0] A, B, C);
