Design a WiFi module control unit that manages the state transitions between four different states: IDLE, SCANNING, CONNECTING, and CONNECTED. The module should accept a clock signal and a reset signal. The state transitions are controlled by two inputs: scan_request (to initiate scanning) and connect_request (to initiate connecting). The state should transition from IDLE to SCANNING when scan_request is high, from SCANNING to CONNECTING when connect_request is high, and from CONNECTING to CONNECTED. It should return to IDLE state if reset is triggered at any state.
