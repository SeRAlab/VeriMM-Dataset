Design a simple 1-bit EEPROM cell in Verilog that can store a binary value. The EEPROM cell should have inputs for write enable (we), data input (d), and a clock (clk). The stored value can be read on the output (q). When write enable is high, upon a rising edge of the clock, the value of 'd' should be stored in the cell. If write enable is low, the cell should retain its previous value. The output 'q' should reflect the stored value at all times.
