Design a 8-to-3 priority encoder that outputs a 3-bit binary code (EN) corresponding to the highest-priority active input from an 8-bit input (D). The highest active bit has the priority and is encoded such that if multiple bits are high, the output represents the highest-order bit that is set. If no bits are set, the output defaults to 000.
