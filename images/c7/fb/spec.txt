
You are tasked with designing a module that takes in a 4-bit input and outputs a 3-bit value. The output value should be the same as the input value, except when the input value is equal to 0b101 (decimal 5) or 0b110 (decimal 6). In these cases, the output value should be 0b111 (decimal 7). 

Write a Verilog module that implements this functionality. The module should be named "value_converter" and should have the following ports:

- `input_val` (input, 4 bits): the input value to be converted
- `output_val` (output, 3 bits): the converted output value

Your solution should use the `always` block to implement the desired functionality.
