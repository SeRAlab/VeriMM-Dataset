
Design a fan speed controller that adjusts the speed of a fan based on temperature input. The controller has a clock input and a reset input. The fan speed is determined by a 2-bit binary value representing the temperature range:
- 00: Temperature < 20°C -> Fan Speed = 0 (OFF)
- 01: 20°C ≤ Temperature < 25°C -> Fan Speed = 1 (Low)
- 10: 25°C ≤ Temperature < 30°C -> Fan Speed = 2 (Medium)
- 11: Temperature ≥ 30°C -> Fan Speed = 3 (High)

The fan speed should only change on the rising edge of the clock, and the reset signal should set the fan speed to OFF.
