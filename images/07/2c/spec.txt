Design a 2-bit shift register with parallel load functionality. The shift register should have an input for loading parallel data, a clock signal, a reset signal, and an output for the current state of the register. When the reset signal is high, the register should clear to 00. When the load signal is high, the data should be loaded into the register on the next clock edge. When the load signal is low, the register should shift left by one bit on the next clock edge.
