
Create a Verilog module that implements a part of the SHA-256 hash function. The module should take a 512-bit input block and a 256-bit hash output. The output should be the first round of preprocessing, which includes a simple message schedule generation. The message schedule consists of 64 words where the first 16 words are directly derived from the input block, and the next 48 words are generated using specific bitwise operations on the previous words.
