
Design an SR flip-flop with asynchronous set and reset inputs. The flip-flop should have two outputs Q and Qbar. The SR flip-flop should update its state based on the inputs S (Set) and R (Reset) on the rising edge of the clock. The outputs should be defined as follows:
- If S=1 and R=0, then Q=1.
- If S=0 and R=1, then Q=0.
- If S=0 and R=0, then Q retains its previous state.
- If S=1 and R=1, this is an invalid state, and Q will be set to 0.
