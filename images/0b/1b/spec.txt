Design a 1-bit SRAM cell in Verilog. The SRAM cell should have the following inputs: `data_in` (the data to be stored), `write_enable` (a control signal that enables writing), and `read_enable` (a control signal that enables reading). The output should be `data_out`, which will provide the stored value when reading is enabled. The SRAM cell should hold its value as long as the `write_enable` signal is low and update the stored value when `write_enable` is high.
