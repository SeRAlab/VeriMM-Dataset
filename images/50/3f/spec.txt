Design a synchronous RAM module with a configurable data width of 8 bits and an address space of up to 2**22 locations. This module allows read and write operations based on the enable_RW signal; when enable_RW is high, it performs a read operation if the read signal is asserted, outputting the data stored at the specified address, or a write operation when the read signal is not asserted, storing the input data at the given address. The address is provided as a 24-bit input, but the lower two bits are ignored for addressing the memory array.
