Design a clock divider that generates an inverted output clock signal, UP_CLK, from the input clock signal CLK. When the RESET signal is asserted (high), UP_CLK is set to 0. On each rising edge of CLK, if RESET is not active, the output UP_CLK toggles its state, effectively creating a divide-by-two clock functionality with reset capability.

 input CLK,
 input RESET,
 output reg UP_CLK);
