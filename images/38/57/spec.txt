Design a 4-bit DRAM cell that can store a 4-bit value and provide read and write operations. The DRAM cell should have the following inputs: `write_enable` (1 bit), `data_in` (4 bits), `row_select` (2 bits), and outputs `data_out` (4 bits). When `write_enable` is high, the data should be written to the selected row. When `write_enable` is low, the data should be read from the selected row.
