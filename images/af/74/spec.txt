Implement an n-bit wide synchronous shift register with reset and shift functionality. When the reset signal is activated, the shift register clears to zero. On each positive edge of the clock, if the shift enable (shift_en) signal is high, the register shifts its contents to the left by one bit, filling the least significant bit with zero. The current contents of the shift register are continuously made available at the output (data_out).
module top_module(
  input [n-1:0] data_in,
  input clk,
  input reset,
  input shift_en,
  output [n-1:0] data_out
);
