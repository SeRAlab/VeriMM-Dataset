Design a 16-bit SRAM cell with read and write functionality. The SRAM cell should have a data input (16 bits), a data output (16 bits), a write enable signal (we), a read enable signal (re), and an address input (4 bits) to select one of 16 cells. The SRAM cell should store data when the write enable signal is high and provide the stored data on the output when the read enable signal is high.
