
Design a 24-bit ADC (Analog-to-Digital Converter) interface in Verilog that takes a 24-bit input representing the analog value and outputs a 12-bit digital value. The conversion should scale the 24-bit input value down to a 12-bit digital output. Specifically, the output should be the upper 12 bits of the input value when the input is less than or equal to the maximum representable value of 24-bits, otherwise, the output should be set to 4095 (the maximum for 12 bits).
