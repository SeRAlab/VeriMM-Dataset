Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs: 
1. state M (output 0).
2. state N (output 1).
3. state O (output 1).

State transitions:
1. From state M: If v = 0, then transition to state N. If v = 1, then transition to state O.
2. From state N: If v = 0, then transition to state M. If v = 1, then transition to state O.
3. From state O: If v = 0, then transition to state N. If v = 1, then transition to state M.

Resets into state M. For this part, assume that a one-hot code is used with the state assignment d[3:1] = 001, 010, 100 for states M, N, O, respectively.

Write Verilog for the next-state signals D2 and D3 corresponding to signal d[2] and d[3]. Derive the logic equations by inspection assuming a one-hot encoding.
