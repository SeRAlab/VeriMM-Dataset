Design a basic arithmetic calculator that performs four operations: addition, subtraction, multiplication, and division, on two 8-bit inputs (op1 and op2). The operation is selected using a 2-bit control signal (op_sel). Depending on the value of op_sel, the module computes the corresponding result and provides the output for the selected operation, storing the results in individual registers for sum, diff, product, and quotient, while setting unused outputs to zero.
module top_module(
    input [7:0] op1,
    input [7:0] op2,
    input [1:0] op_sel,
    output reg [7:0] sum,
    output reg [7:0] diff,
    output reg [7:0] product,
    output reg [7:0] quotient
);
