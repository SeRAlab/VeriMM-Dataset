

You are tasked with designing a 2:1 multiplexer using Verilog. A 2:1 multiplexer has two input signals, A and B, and a select signal, S. If S is 0, the output is A, and if S is 1, the output is B. You should implement this multiplexer in a single Verilog module called `mux_2to1`.

The module should have the following input and output ports:

- `input A`: the first input signal
- `input B`: the second input signal
- `input S`: the select signal
- `output M`: the output signal

You should use the following code as a starting point for your implementation:

```
module mux_2to1 (M, A, B, S);
   input A, B, S;
   output M;

   // your code here

endmodule
```

Your implementation should be contained within the `mux_2to1` module and should not exceed 200 lines of Verilog code.
