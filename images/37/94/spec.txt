Design a simple Verilog module that takes an 8-bit input representing a pixel value and outputs the grayscale equivalent. The grayscale value is computed by averaging the red, green, and blue components of the pixel value, assuming the input is an RGB format where the first 3 bits are red, the next 3 bits are green, and the last 2 bits are blue. The output should be a 4-bit grayscale value.
