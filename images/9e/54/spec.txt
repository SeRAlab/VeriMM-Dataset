Design a 4-bit comparator that determines the relational status of two 4-bit inputs, A and B. The module outputs a signal indicating if the two inputs are equal (EQ) and another signal indicating if A is greater than B (GT). The EQ output is asserted when all bits of the difference between A and B are zero, while the GT output is asserted when the sign bit of the difference indicates A is greater.
module top_module(
  input [3:0] A,
  input [3:0] B,
  output EQ,
  output GT
);
