
Design a hazard detection and resolution circuit for a 2-input combinational logic circuit. The circuit should detect any hazards caused by changes in the inputs, and it should implement a simple hazard resolution mechanism. The inputs are A and B, which can each be 0 or 1, and the output is Z. The output Z should be 1 when both A and B are 1, and should be 0 otherwise. However, if a hazard is detected (i.e., if A changes from 0 to 1 while B is 1), the output Z should be held at its previous value for one clock cycle.
