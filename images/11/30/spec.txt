Design a simple Support Vector Machine (SVM) classifier in Verilog that can classify 2D points based on a linear decision boundary. The SVM will take two input features (x1, x2) and output a binary classification (0 or 1). The decision boundary will be defined by weights (w1, w2) and a bias (b). The classifier will output 1 if w1*x1 + w2*x2 + b > 0, otherwise it will output 0. Provide parameters for weights and bias as inputs.
