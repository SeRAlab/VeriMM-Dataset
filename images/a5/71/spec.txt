Design an up-down counter that increments or decrements a 4-bit output Q based on the state of the U_D input signal. When U_D is high (1), the counter increments on each positive clock edge; when U_D is low (0), the counter decrements. This module can be utilized in applications requiring counting in both directions, such as in frequency synthesis or position tracking.
module top_module(
    input clk,
    input U_D,
    output reg [3:0] Q
);
