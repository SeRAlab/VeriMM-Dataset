Design a combinational circuit that implements the A* search algorithm heuristic function, which calculates the estimated cost to reach the goal from a given node based on the cost from the start node to the current node (g(n)) and the estimated cost from the current node to the goal (h(n)). The circuit will take `g` and `h` as 8-bit inputs and produce a 9-bit output representing `f(n) = g(n) + h(n)`.
