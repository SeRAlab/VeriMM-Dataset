
Design a simple Automatic Repeat Request (ARQ) system that uses a single-bit acknowledgement (ACK) to determine if a transmitted data packet was received correctly. The sender transmits a data bit and waits for an ACK signal. If the ACK signal is received, the sender will proceed to the next data bit. If the ACK signal is not received within a timeout period, the sender will retransmit the same data bit. The system should be able to handle up to 5 data packets.
