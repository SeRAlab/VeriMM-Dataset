
Design an EEPROM cell that can store a single bit of data. The cell should have the following functionalities:
1. A `write` operation that sets the stored bit to `1` or `0` based on an input signal and a `write_enable` control signal.
2. A `read` operation that outputs the stored bit when a `read_enable` control signal is high.
3. The stored bit should retain its value when not being written to (i.e., the state must be stable unless a write operation occurs).
