
Design a 5-stage pipelined processor that can perform the following instructions:
1. Load (LD)
2. Store (ST)
3. Add (ADD)
4. Subtract (SUB)
5. AND

The pipeline should have the following stages:
1. Instruction Fetch (IF)
2. Instruction Decode (ID)
3. Execute (EX)
4. Memory Access (MEM)
5. Write Back (WB)

The processor should handle data hazards using a simple stall mechanism, where the pipeline will insert bubbles in case of data dependencies.
