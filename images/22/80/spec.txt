Implement a combinational logic circuit that performs LU decomposition on a 2x2 matrix. The circuit should take as input four values (a, b, c, d) representing the matrix:
```
| a  b |
| c  d |
```
The output should be the L and U matrices:
```
L = | 1   0 |
    | l21  1 |

U = | u11  u12 |
    | 0    u22 |
```
where l21 and u11, u12, u22 are calculated based on the input values.
