
Design a Verilog module that implements a Kalman filter for sensor fusion. The module should take as inputs the current sensor measurement, previous state estimate, and previous error covariance. It should output the updated state estimate and updated error covariance. The Kalman filter equations you need to implement are as follows:

1. Compute the Kalman Gain: K = P * H' / (H * P * H' + R)
2. Update the state estimate: x' = x + K * (z - H * x)
3. Update the error covariance: P' = (I - K * H) * P

Where:
- K is the Kalman Gain
- P is the error covariance matrix
- H is the measurement matrix
- z is the measurement vector
- x is the state estimate vector
- I is the identity matrix
- R is the measurement noise covariance
