Implement a simple Direct Memory Access (DMA) controller that transfers data from a source address to a destination address on the rising edge of a clock signal. The controller should have the following inputs: `clk` (clock), `start` (start the transfer), `src_addr` (source address), `dest_addr` (destination address), and `data_in` (input data). It should have one output: `data_out` (output data). When `start` is high, it should begin the transfer of `data_in` from `src_addr` to `dest_addr` and output the data to `data_out`.
