Design a circuit that converts a 4-bit Binary-Coded Decimal (BCD) input into an 8-bit display output suitable for a 7-segment display. The module features a reset functionality and a clock-triggered operation; upon reset, the display is set to all segments off and briefly turns to all segments illuminated. The output corresponds to specific segments being activated based on the BCD input values (0-9), with each case defining the segment patterns for the respective digits. If the BCD input is out of range (greater than 9), the display outputs zero.
module top_module(input clk,input rst,input [3:0] BCD,output reg[7:0] DISPLAY);
