Design a 2x2 matrix inversion module in Verilog. The module should take a 2x2 matrix as input and output its inverse. The inverse of a matrix A = [[a, b], [c, d]] is given by A^(-1) = (1/det(A)) * [[d, -b], [-c, a]], where det(A) = ad - bc. Ensure to handle cases where the determinant is zero by outputting a predefined value (e.g., all zeros) indicating that the matrix is not invertible.
