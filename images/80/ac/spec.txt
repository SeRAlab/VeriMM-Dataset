Design a module that implements a Hash-based Message Authentication Code (HMAC) system. The module receives a 256-bit wide message and a 256-bit key as inputs, computes the HMAC using a defined cryptographic hash function, and compares the computed HMAC to a provided HMAC value. The output indicates the validity of the HMAC, returning HIGH if the computed HMAC matches the input HMAC and LOW otherwise.
module top_module(
  input [n-1:0] message,
  input [k-1:0] key,
  input [s-1:0] hmac,
  output out
);
