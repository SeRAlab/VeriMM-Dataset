Design a 32-bit linear feedback shift register (LFSR) based random number generator. Upon a clock edge, it updates its state based on a set of tapped outputs from its current state, producing a new pseudo-random value. The generator can be reset asynchronously to a zero state when the reset signal is activated. The current value of the LFSR is assigned to the output, providing a stream of random numbers for applications requiring stochastic behavior.
module top_module(
    input clk,
    input reset,
    output reg [31:0] rand_num
);
