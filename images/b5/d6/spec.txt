Design a 32-bit D flip-flop with asynchronous preset and clear functionality. When the clock signal raises, if the preset (PREbar) is low, the output (q) is set to all ones. If the clear (CLRbar) is low, the output is reset to zero. If both preset and clear are high, the flip-flop will store the input data when write enable (Wen) is high. The module also generates an output (qbar) that is the inverse of q, and Wen indicates when writing to the flip-flop is permitted.
module top_module(q, qbar, clock, data, PREbar, CLRbar, Wen);
