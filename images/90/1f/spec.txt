Design a 4-to-2 multiplexer that selects between four input signals (A0, A1, A2, A3) based on two select lines (S0 and S1). The module outputs a signal (X) which is the combination of inputs determined by the select lines. Specifically, if (S0, S1) = (0, 0), then X outputs A0; if (S0, S1) = (0, 1), then X outputs A1; if (S0, S1) = (1, 0), then X outputs A2; and if (S0, S1) = (1, 1), then X outputs A3. The design employs basic logic gates such as inverters, AND, and OR gates to implement the selection logic.
module top_module(
    input  A0,
    input  A1,
    input  A2,
    input  A3,
    input  S0,
    input  S1,
    output X 
);
