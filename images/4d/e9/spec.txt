Design a 4-bit wide adder-subtractor circuit that conditionally outputs either the sum or the difference of two 4-bit inputs A and B based on a control signal C. When C is low (0), the module outputs the sum (A + B); when C is high (1), it outputs the difference (A - B). The operations are triggered on the positive edge of the control signal, ensuring synchronized computation.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input C,
    output reg [3:0] out
);
