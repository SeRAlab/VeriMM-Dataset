Design a 4-to-1 multiplexer with 8-bit wide data inputs. The module selects one of the four 8-bit inputs (D0, D1, D2, D3) based on a 2-bit control signal (`ctrl`). The output (`S`) reflects the value of the selected data input according to the control signal: when `ctrl` is 00, output D0; when 01, output D1; when 10, output D2; and when 11, output D3. If an invalid control signal is detected, it defaults to outputting zero.
module top_module(ctrl, D0, D1, D2, D3, S);
