Design a power-on reset (POR) circuit that initializes a system reset signal. Upon rising edge of the power supply (vdd), the reset signal is set to LOW after a short delay (t) to allow the system to stabilize. Following this delay, the reset signal goes back to HIGH to indicate that the system is now ready to operate. This ensures that all components in the system start in a known state when power is applied.
