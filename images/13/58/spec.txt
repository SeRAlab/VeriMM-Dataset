Design an NVMe controller that accepts a command and processes it with a simple state machine. The controller has the following states: IDLE, READ, WRITE, and DONE. The controller should transition between these states based on an input command and a clock signal. Upon receiving a READ command, it should move to the READ state, and upon receiving a WRITE command, it should move to the WRITE state. The controller should go to the DONE state after processing the command and return to IDLE when a reset is applied.
