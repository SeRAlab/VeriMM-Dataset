

You are tasked with designing a Verilog module for a circuit that takes in four inputs, A1, A2, B1, and B2, and outputs a single bit X. The circuit will also have four additional inputs, VPWR, VGND, VPB, and VNB, which will be used to power the circuit and provide reference voltages. 

Your module should be named "four_to_one_circuit" and should be no longer than 200 lines of Verilog code. The circuit should operate as follows:

- If A1 and A2 are both 0, and B1 and B2 are both 0, then X should be 0.
- If A1 and A2 are both 0, and B1 and B2 are both 1, then X should be 1.
- If A1 and A2 are both 1, and B1 and B2 are both 0, then X should be 1.
- If A1 and A2 are both 1, and B1 and B2 are both 1, then X should be 0.

Your module should be properly instantiated and connected to the inputs and outputs as follows:

- The output X should be of type output.
- The inputs A1, A2, B1, B2, VPWR, VGND, VPB, and VNB should be of type input.
- The inputs A1, A2, B1, and B2 should be connected to wires of the same name within the module.
- The inputs VPWR, VGND, VPB, and VNB should be connected to wires of the same name within the module.

Your module should be designed to be synthesizable and should be able to be implemented on an FPGA.
