
You are tasked with designing a verilog module for a 4-bit adder. The module should have two input ports, `a` and `b`, and one output port, `sum`. The module should also have a control input, `enable`, which is active-high. When `enable` is low, the output should be `0000`. When `enable` is high, the output should be the sum of `a` and `b`.
