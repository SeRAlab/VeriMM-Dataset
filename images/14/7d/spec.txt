
Design a 24-bit ADC output decoder that takes a 24-bit binary input representing the ADC value and produces a 4-bit output corresponding to the ADC's voltage range. The output should be:
- 0000 for 0V
- 0001 for 1V
- 0010 for 2V
- 0011 for 3V
- ...
- 1111 for 15V
Any input greater than the maximum ADC value should output 1111 (15V).
