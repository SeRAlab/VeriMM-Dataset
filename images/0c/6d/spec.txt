Design a Verilog module that implements a simple JPEG compression component. The module should take an 8-bit pixel value as input and apply a basic quantization process. The quantization step consists of dividing the pixel value by a quantization factor (which is hard-coded to 32 for this problem) and rounding down to the nearest integer. The output should be the quantized pixel value. The module should also include an enable signal to control whether the quantization is performed or not.
