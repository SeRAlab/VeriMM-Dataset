Design a 4-bit ripple carry adder that computes the sum of two 4-bit inputs, A and B. The module evaluates the sum based on the binary addition of A, B, and a carry chain, which tracks the carry-out from each bit addition to handle the propagation of carry bits through the adder. It produces a 4-bit SUM output and a CARRY output that indicates whether there is an overflow from the most significant bit. The carry chain is generated using a sequential initialization and loop to support the carry propagation required in a ripple carry structure.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output reg [3:0] SUM,
    output reg CARRY
);
