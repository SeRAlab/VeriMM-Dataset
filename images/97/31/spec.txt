Design a 32-bit shift register with a load capability. When the LOAD input is high, the register captures the parallel input value (PAR_IN) and stores it. When LOAD is low, the shift register shifts its contents to the left and inserts the serial input (SER_IN) into the least significant bit (LSB). The most significant bit (MSB) of the shift register is output through the SER_OUT signal.
module top_module(
  input CLK,
  input LOAD,
  input SER_IN,
  input [31:0] PAR_IN,
  output SER_OUT
);
