Design a Verilog module for a 5-bit EEPROM cell that can store a single bit of data (0 or 1) for each bit position. The module should have a write enable input signal, a data input for writing, and a 5-bit output to read the stored values. If the write enable is high, the data input should be written to the corresponding bit position. If the write enable is low, the output should retain its previous value.
