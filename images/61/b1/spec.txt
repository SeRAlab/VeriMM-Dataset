Implement a 4-bit shift register with load and shift capabilities. When the load signal is high, the register is loaded with the 4-bit input data. If load is low, the register shifts its contents to the right, inserting the specified shift input bit at the most significant position and discarding the least significant bit. The module continuously outputs the current contents of the register and provides the most significant bit as the shift output.
module top_module(
    input clk,
    input load,
    input [3:0] data_in,
    input shift_in,
    output [3:0] data_out,
    output shift_out
);
