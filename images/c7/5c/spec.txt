

You are tasked with designing a circuit that counts the number of times a button has been pressed. The button is connected to a single input port `button`. The circuit should have an output `count` that displays the number of times the button has been pressed. The count should reset to zero when it reaches the maximum value of 5. The circuit should be synchronous and operate on the rising edge of the clock signal `clk`. 

Design the circuit using Verilog.
