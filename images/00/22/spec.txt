Create a 16-bit digital-to-analog converter (DAC) that takes a 4-bit control signal (representing a gain) and a 16-bit input data signal, and outputs a 20-bit analog signal where the output is calculated by the formula: Output = Input_Data * Gain. The gain values are represented as: 0000 = 1, 0001 = 2, 0010 = 4, 0011 = 8, 0100 = 16, and 0101 = 32. Any gain above 32 should be considered as 0.
