Design a Verilog module for a simple WiFi signal strength indicator that takes a 4-bit input signal representing the received signal strength (RSSI) and outputs a 3-bit value indicating the strength level. The output levels should be defined as follows: 000 for RSSI < 4, 001 for 4 <= RSSI < 8, 010 for 8 <= RSSI < 12, 011 for 12 <= RSSI < 16, and 100 for RSSI >= 16.
