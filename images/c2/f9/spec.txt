
You have been tasked with designing a module in Verilog that takes in three input signals and outputs a single signal. The module should be named "tkg_c3" and it should have the following ports:
- output port "o" which should be a single bit signal
- input port "i0" which should be a single bit signal
- input port "i1" which should be a single bit signal
- input port "i2" which should be a single bit signal

The module should use a sub-module called "C3" to compute the output signal. The C3 sub-module should take in three input signals and output a single signal. The C3 sub-module should implement the following Boolean equation:
o = i0 & i1 | i0 & i2 | i1 & i2

You should write the Verilog code for the tkg_c3 module. Your code should be contained within a single module and should be no more than 200 lines of code.
