Implement a Verilog module for a 4-bit binary counter with an enable signal. The counter should have a clock input `clk`, an asynchronous reset input `reset`, an enable input `en`, and a 4-bit output `count`. The counter should increment on the rising edge of `clk` when `en` is high, and reset to 0 when `reset` is high.

module binary_counter(
	input wire clk,
	input wire reset,
	input wire en,
	output reg [3:0] count
);
