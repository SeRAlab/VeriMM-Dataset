Design a circuit that serves as an 8-bit wide RAM with read and write capabilities. The module responds to a clock signal and a reset signal to manage the memory contents, initializing all memory cells to zero upon reset. When the MEM_READ signal is asserted, it outputs the data stored at the specified DataAddress. If the MEM_WRITE signal is active, it updates the memory at the specified address with the WriteData value. When not reading, the ReadData output is high-impedance, effectively disconnecting it from any output value.
module top_module(Clk, Reset, MEM_READ, MEM_WRITE, DataAddress, WriteData, ReadData);
