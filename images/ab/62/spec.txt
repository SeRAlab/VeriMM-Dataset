Implement a 3-stage pipeline using D flip-flops. The module captures an input bit 'd' on each rising edge of the clock and shifts it through three flip-flops. Upon a low clear signal (clr), all flip-flops are reset to a high state (1). The output 'q' reflects the state of the last flip-flop in the pipeline, providing a delayed version of the input signal after three clock cycles.
module top_module(
    input clk,
    input clr,
    input d,
    output reg q
);
