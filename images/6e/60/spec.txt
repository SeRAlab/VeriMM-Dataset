Implement the Verilog module based on the following description.
Design a Verilog module that implements a 7-bit binary up-counter with enable and synchronous load. The counter should increment on the rising edge of the clock if the "enable" signal is high. If the "load" signal is high, the counter should load the "data" input value. The counter should reset to zero when the asynchronous reset (areset) is high. The counter value should be output to the "count" signal.

module top_module
(
    input clk,
    input areset,
    input enable,
    input load,
    input [6:0] data,
    output reg [6:0] count
);
