When the Reset (R) signal is low, the output RF is forced to LOW. When the Set (S) signal is low, the output RF is set to the value of D. If both R and S are high, RF retains its previous state. The output RI is always the logical negation of RF, effectively providing an inverted version of the flip-flop output.
