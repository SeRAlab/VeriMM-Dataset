Design a simple 4-register accumulator module that stores 8-bit wide input data. The module has a clock and reset signal for synchronous operation; upon reset, it initializes all registers to zero. When the write enable signal is asserted, the module writes the input data to the register specified by a 2-bit address. The data at the specified address can be accessed through the output, providing the current value stored in that register.
