Design a 2-state Viterbi decoder that outputs the most likely path of a given input sequence of bits. The Viterbi decoder should have a clock input, a reset input, an input bit stream, and should output the decoded bits. You are to implement the state transition and output logic based on a simple convolutional code with the generator polynomials G1 = 111, G2 = 101. The decoder should work on a 5-bit input sequence and output the corresponding decoded bits.
