Develop a Verilog module that controls a signal based on these rules:
- When t = 1 and u = 1, output_signal = 1.
- When t = 1 and u = 0, output_signal = 0.
- When t = 0 and u = 1, output_signal = 0.
- When t = 0 and u = 0, output_signal = 0.

module signal_manager(
	input t,
	input u,
	output reg output_signal);
