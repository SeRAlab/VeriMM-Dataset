Design a synchronous data memory module that supports read and write operations for a 32-word address space. The module takes a clock input for synchronizing write operations, where data from `WriteData` is stored in the memory at an address specified by `Address` whenever `MemWrite` is asserted. The memory is organized as an array of 32-bit words, and when `MemRead` is asserted, it outputs the value stored at the specified address through `ReadData`. Each address is byte-addressable, and the effective memory location is determined by right-shifting the address input by 2 bits.
module top_module(clk, Address, WriteData, MemWrite, MemRead, ReadData);
