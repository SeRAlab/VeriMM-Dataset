
You are tasked with designing a Verilog module that takes in a 4-bit input and outputs a 2-bit output. The output should be the sum of the input and a constant value, where the constant value is represented as a 2-bit binary number. If the sum exceeds 3, the output should be set to 3. The module should be named "adder_4_2".

You are only allowed to use one module within 200 lines of Verilog code. Additionally, the module should have the following ports:
- input [3:0] A
- output [1:0] Y

The module should be synthesizable and should have a single clock input. Assume that the input A will only take on values between 0 and 3.
