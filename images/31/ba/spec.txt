
Design a fan speed control system that takes in a 3-bit input representing the desired speed (0 to 7) and a 1-bit input to indicate whether the fan should be turned on (1) or off (0). The fan should maintain the desired speed when turned on and remain off when turned off. The current speed of the fan should be output as a 3-bit value. Include a clock input to allow for simulation of changes over time.
