

You are tasked with designing a module that takes in two pairs of inputs (A1_N, A2_N, B1, B2) and outputs a single value (Y). The module should be named "mux2to1" and should be written in Verilog.

The module should have the following behavior:
- If A1_N and A2_N are both 0, Y should be equal to B1.
- If A1_N is 0 and A2_N is 1, Y should be equal to B2.
- If A1_N is 1 and A2_N is 0, Y should be equal to B1.
- If A1_N and A2_N are both 1, Y should be equal to B2.

You can assume that all inputs and outputs are single-bit signals.
