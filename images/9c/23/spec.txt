Design a 4-bit adder/subtractor circuit. The module takes two 4-bit inputs, A and B, along with a control signal S to determine the operation. When S is LOW, the circuit performs addition (A + B), and when S is HIGH, it computes the subtraction (A - B). The result of the operation is output as a 4-bit value C, while Cout indicates any carry out from the most significant bit, allowing detection of overflow during addition.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input S,
  input clk,
  output [3:0] C,
  output Cout
);
