

You are tasked with designing a module that takes in 4 inputs (S0, S1, S2, S3) and 2 select signals (Sel[1], Sel[0]). The module should output one of the four inputs based on the select signals. 

The select signals work as follows:
- If Sel[1] is 0, the output will be either S0 or S1, depending on the value of Sel[0]. 
- If Sel[1] is 1, the output will be either S2 or S3, depending on the value of Sel[0].

Your task is to design a Verilog module that implements this functionality. The module should be named "MUX4_1_SL" and should take in the following inputs and outputs:

Inputs:
- Sel[1:0] (2-bit input)
- S0, S1, S2, S3 (4-bit inputs)

Outputs:
- out (4-bit output)

You should ensure that the module is completely self-contained, meaning that it should not rely on any other modules to function.
