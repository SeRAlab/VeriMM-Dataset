Design a circuit to control a RGB LED with a blinking effect. The module uses an input clock signal (CLK_IN) and an active-low reset signal (RST_N) to toggle the LED state every 1 second, based on a 12 MHz clock frequency. Upon reset, the LED is turned off. When the LED is active, the RGB output is set to a bright white (3'b111), and when inactive, it is set to a yellow color (3'b110), creating a clear visual indication of the LED state.
module top_module(
input wire CLK_IN,
input wire RST_N,
output wire [2:0] RGB_LED
);
