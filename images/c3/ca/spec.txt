
You are tasked with designing a module that takes in four input signals and outputs one signal. The input signals are A1_N, A2_N, B1, and B2, while the output signal is Y. The module also takes in four power signals: VPB, VPWR, VGND, and VNB. 

The module should perform the following operation: 

- If A1_N and A2_N are both 0, Y should be 0.
- If A1_N is 1 and A2_N is 0, Y should be B1.
- If A1_N is 0 and A2_N is 1, Y should be B2.
- If A1_N and A2_N are both 1, Y should be the logical OR of B1 and B2.

Design the module and provide the Verilog code for it.
