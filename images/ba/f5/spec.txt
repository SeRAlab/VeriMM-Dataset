Design a dual-edge sensitive flip-flop that captures the input data on both the rising and falling edges of the clock. When the clock transitions from low to high, the flip-flop samples and stores the input 'd' in a register. On the subsequent falling edge of the clock, it passes the stored value to the output 'q'. This design allows the flip-flop to effectively operate at double the sample rate relative to the clock frequency.
module top_module(
    input clk,
    input d,
    output q
);
