On the rising edge of the clock, if the reset signal is asserted, the register outputs are cleared to zero, and the complementary output (qbar) is updated accordingly. If reset is not asserted, the register captures the 8-bit input data on the rising edge of the clock, while the complementary output (qbar) is simultaneously updated to reflect the inverted state of q.

    input [7:0] d,
    output reg [7:0] q,
    output reg [7:0] qbar
    );
