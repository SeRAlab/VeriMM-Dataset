Design a finite state machine (FSM) that implements a multiplier for two 8-bit input values. The module takes two 8-bit inputs, `a` and `b`, and upon receiving an enable signal (`in_en`), it performs multiplication in a stepwise manner, managing the multiplication process over multiple clock cycles. The FSM transitions through four states: initialization, execution of shifts and additions based on the least significant bit of the multiplier, and completion. The result of the multiplication is stored in a 16-bit output register (`prdct`), and an output enable signal (`out_en`) indicates when the multiplication is complete and the result is ready to be used.
module top_module(input clk,rst,in_en,input[7:0] a,b,output [15:0] prdct ,output reg out_en);
