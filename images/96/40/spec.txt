Design an 8-bit wide, 2-to-1 multiplexer. The module outputs either `in_0` or `in_1` based on the value of the `select` signal. When `select` is low (0), the output will mirror `in_0`; when `select` is high (1), the output will take the value of `in_1`. In case of an unexpected value, the default behavior is to output `in_0`.
module top_module(
    output reg [7:0] out,
    input wire [7:0] in_0,
    input wire [7:0] in_1,
    input select
);
