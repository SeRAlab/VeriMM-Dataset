
Create a simple instruction pipeline that performs a sequence of arithmetic operations. The pipeline should have three stages: Instruction Fetch (IF), Instruction Decode (ID), and Execute (EX). The pipeline should take in a 32-bit instruction that specifies the operation and the operands. The operations can include addition, subtraction, multiplication, and division. Each stage of the pipeline should be clocked, and the output should be the result of the arithmetic operation after passing through the pipeline.
