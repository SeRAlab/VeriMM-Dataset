Design a synchronous 128-word data memory module with 32-bit address and data buses. The module supports both read and write operations: on the rising edge of an input clock signal, if the `memWrite` signal is asserted, it stores `writeData` at the specified `address`. When `memRead` is asserted, it retrieves the data from the specified address and outputs it as `readData`. The memory is initialized to zero for the first 32 words. This design is suitable for use in a CPU's data memory interface.
module top_module( clock_in,address,writeData,memWrite,memRead,readData);
