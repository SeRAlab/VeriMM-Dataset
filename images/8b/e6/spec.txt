Design a four-input, one-output 4-to-1 multiplexer. The module takes a 2-bit select signal to choose one of the four 4-bit wide input signals (in0, in1, in2, in3). Depending on the value of the select signal, the corresponding input is routed to the output, which holds the selected 4-bit value. If the select signal does not match any of the defined cases, the output will default to zero.
module top_module(
  input [1:0] sel,
  input [3:0] in0,
  input [3:0] in1,
  input [3:0] in2,
  input [3:0] in3,
  output [3:0] out
);
