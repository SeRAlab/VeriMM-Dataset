Design a D latch with active-low reset functionality. The latch outputs a stored value Q and its complement Q_N, which is set to LOW when RESET_B is asserted. The state of the latch is updated on the rising edge of the GATE signal; if D is HIGH, Q is set to HIGH. The module includes power and ground connections (VPWR, VGND, VPB, VNB) to support proper operation within a digital circuit.
module top_module(
    input wire RESET_B,
    input wire D,
    input wire VPWR,
    input wire VGND,
    input wire VPB,
    input wire VNB,
    input wire GATE,
    output reg Q,
    output reg Q_N
);
