

You are tasked with designing a module in Verilog that implements a 4-bit counter. The module should have the following inputs and outputs:

- `clk`: a clock input
- `reset`: an asynchronous reset input
- `enable`: an enable input that allows the counter to count when high
- `out`: a 4-bit output that represents the current count value

The counter should start at 0 and increment by 1 on the rising edge of `clk` when `enable` is high. When `reset` is asserted, the counter should be reset to 0.

Design a Verilog module that implements this counter within 200 lines of code. Your module should be named `counter` and should have the inputs and outputs described above.
