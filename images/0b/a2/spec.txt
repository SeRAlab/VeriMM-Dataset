Design a dynamic range compressor circuit that takes a 5-bit input signal and outputs a compressed 5-bit signal based on the following criteria: 
1. If the input signal is less than 8 (00000 to 00111), it should remain unchanged.
2. If the input signal is between 8 and 15 (01000 to 01111), it should be halved.
3. If the input signal is greater than 15 (10000 to 11111), it should be reduced to 15 (11111).
