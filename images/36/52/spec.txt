Design a simple 2-bit branch predictor that uses a saturating counter to predict whether a branch will be taken or not. The counter increments for a taken branch and decrements for a not-taken branch. The prediction is based on the current value of the counter. The counter has four states: strongly taken, weakly taken, weakly not taken, and strongly not taken. The state transitions are as follows:  
- If the current state is strongly taken and a taken branch occurs, remain in strongly taken.  
- If the current state is strongly taken and a not-taken branch occurs, change to weakly taken.  
- If the current state is weakly taken and a taken branch occurs, change to strongly taken.  
- If the current state is weakly taken and a not-taken branch occurs, change to weakly not taken.  
- If the current state is weakly not taken and a taken branch occurs, change to weakly taken.  
- If the current state is weakly not taken and a not-taken branch occurs, change to strongly not taken.  
- If the current state is strongly not taken and a taken branch occurs, change to weakly not taken.  
- If the current state is strongly not taken and a not-taken branch occurs, remain in strongly not taken.
