Design a 4-bit ring counter with synchronous reset. The module should have a clock input, a synchronous reset input, and a 4-bit output. The counter should generate the ring sequence (1000, 0100, 0010, 0001).

Module name:
    ring_counter
Input ports:
    clk: a 1-bit clock input
    reset: a 1-bit synchronous reset input
Output ports:
    count: a 4-bit output representing the current count value

Implementation:
The module uses an always block triggered by the rising edge of the clock signal. Inside the always block, there is an if-else statement to check the reset signal. If the reset signal is asserted, the counter is set to the initial state (1000). Otherwise, the counter generates the next state in the ring sequence.
