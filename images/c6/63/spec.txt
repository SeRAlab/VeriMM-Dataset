

You are tasked with designing a module that implements a 2:1 multiplexer using Verilog. The module should have two input ports, `in0` and `in1`, and one select port, `sel`. The output port should be `out`. When `sel` is 0, `in0` should be the output, and when `sel` is 1, `in1` should be the output.

Your module should be named `mux_2to1` and should be defined as follows:

```verilog
module mux_2to1 (
    input in0,
    input in1,
    input sel,
    output out
);
```

You should use the code snippet provided as a reference to define your module.
