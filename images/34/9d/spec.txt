Design a 1-bit SRAM cell with read and write capabilities. The SRAM cell should have one data input (D), one data output (Q), a write enable signal (WE), and a read enable signal (RE). When WE is high, the input data (D) should be written to the SRAM cell. When RE is high, the data from the SRAM cell should be output to Q. The SRAM cell should retain its value when both WE and RE are low.
