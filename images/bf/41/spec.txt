Design a 8-register file with the capability to read and write 4-bit data. This module allows for asynchronous write operations on the falling edge of the clock when the RW signal is high, storing data into one of eight 4-bit registers (AR to HR) based on a 3-bit address input. When RW is low, the module outputs the contents of the selected register to the Data_out signal, using the same 3-bit address for selection. If writing occurs, the Data_out is driven to a high-impedance state.
