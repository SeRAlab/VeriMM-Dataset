Design a Verilog module for a Run-Length Encoding (RLE) encoder. The encoder should take an 8-bit input data stream and output the run-length encoded data. The output should consist of the value and its run-length, and the module should handle inputs up to a maximum run-length of 15. The encoding should be resettable, and the data should be clocked in on the rising edge of a clock signal. You should also include a valid output signal to indicate when the output data is valid.
