

You are tasked with designing a module that takes in four inputs and produces one output. The module should be named `four_to_one` and should have the following input and output ports:

- `input [3:0] in`: a 4-bit input
- `output out`: a single bit output

The module should implement the following logic:

- If the input is equal to 0b0000 or 0b1111, the output should be 1.
- If the input is equal to 0b0101 or 0b1010, the output should be 1.
- Otherwise, the output should be 0.

You may use any verilog operators, modules, or constructs necessary to implement this logic.
