Develop a traffic light controller that sequences through green, yellow, and red states based on a clock input and a start signal. The green light is active for a predefined duration (5 clock cycles), followed by the yellow light for 2 cycles, and then the red light for 3 cycles, before the cycle repeats. The module also includes a reset input to initialize the state and output signals to a known state when activated. The outputs represent the status of the traffic lights, ensuring efficient traffic management at road intersections.
module top_module(
    input clk,
    input rst,
    input start,
    output reg green,
    output reg yellow,
    output reg red
);
