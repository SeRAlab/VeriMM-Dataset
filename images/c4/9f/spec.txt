
You are given a verilog module `counter` that counts from 0 to a given value `N` and then resets back to 0. The module has the following inputs and outputs:
- `clk`: a clock signal
- `rst`: a synchronous reset signal
- `N`: the maximum count value
- `enable`: an enable signal that starts the counter when high
- `count`: the current count value, represented as an output

Implement the `counter` module using the following guidelines:
- Use a synchronous reset that sets the count value to 0 when `rst` is high
- When `enable` is high, increment the count value on every rising edge of `clk`
- When the count value reaches `N`, reset it back to 0 on the next rising edge of `clk`
- The count value should be represented using the minimum number of bits required to represent all values from 0 to `N`
