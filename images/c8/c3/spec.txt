

You are tasked with designing a Verilog module that implements a simple 2-bit counter. The module should have the following inputs and outputs:

- `clk`: a clock signal
- `reset`: a reset signal
- `enable`: an enable signal
- `count`: a 2-bit output representing the current count value

The counter should count up on each rising edge of the clock signal, but only if the `enable` signal is high. If the `reset` signal is high, the counter should be reset to 0.

Write a Verilog module that implements this counter.
