Write a Verilog module for a 10-bit up counter with enable, clear, and roll-over detection. Assume positive clock/clk edge triggered. When enable is low, the counter holds its value. When clear is high, the counter resets to 0. The counter should also have an output that goes high when the counter reaches its maximum value (1023).

module up_counter (
  input clk,
  input enable,
  input clear,
  output reg [9:0] count,
  output reg rollover
);
