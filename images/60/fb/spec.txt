Design a synchronous 8-bit register with an active-low reset and active-low write enable. When the reset signal (rst_) is low, the output (dout) is cleared to 0. When the write enable (we_) is low, the register takes the input data (din) and updates dout with this value. If both controls (rst_ and we_) are inactive, the register maintains its current output state.
