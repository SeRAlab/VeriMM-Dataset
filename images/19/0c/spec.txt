
Design a Verilog module that implements a simple linear regression model to calculate the predicted output given a set of weights and an input vector. The module should take in an input vector of size 5 and a weight vector of size 5, and output the predicted value as a 32-bit integer. The linear regression formula is given by:

output = w1*x1 + w2*x2 + w3*x3 + w4*x4 + w5*x5

where wi are the weights and xi are the input values.
