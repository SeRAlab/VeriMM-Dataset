Design a 16-bit to 32-bit sign and zero extension module. If the Op signal is high and the most significant bit of the input (cin[15]) is set, it produces a sign-extended 32-bit output by combining the input with the upper 16 bits filled with ones. Otherwise, it performs a zero extension by setting the upper 16 bits to zero while retaining the lower 16 bits from the input.

	input [15:0] cin,  
	input Op,          
	output reg [31:0] result
