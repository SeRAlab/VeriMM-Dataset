
Implement a simple Discrete Wavelet Transform (DWT) module that takes 4 input samples and produces 2 approximation coefficients (low-pass) and 2 detail coefficients (high-pass). The DWT can be implemented using the following equations:
- Approximation coefficients: A0 = (X0 + X1 + X2 + X3) / 2
- Detail coefficients: D0 = (X0 - X1 + X2 - X3) / 2
Where X0, X1, X2, and X3 are the input samples. You must ensure that the module handles clock and reset appropriately, providing output only when the valid signal is high.
