
Design a Verilog module that implements a Gaussian blur filter on a 3x3 pixel matrix. The module should take a 3x3 matrix of pixel values as input and output a single pixel value, which is the result of applying the Gaussian blur. The Gaussian blur can be approximated using the following kernel:
```
1  2  1
2  4  2
1  2  1
```
Given the input pixel values as a 3x3 matrix, the output pixel value should be calculated using the formula:
```
Output = (1*I1 + 2*I2 + 1*I3 + 2*I4 + 4*I5 + 2*I6 + 1*I7 + 2*I8 + 1*I9) / 16
```
where I1 to I9 are the pixel values of the input matrix.
