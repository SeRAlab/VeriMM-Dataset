
Design an 8-bit SRAM cell that allows for read and write operations. The SRAM cell should have inputs for data (8 bits), a write enable signal (we), and an output for the data read (8 bits). If the write enable signal is high, the data should be written to the SRAM cell; if low, the data should be read from the SRAM cell. The cell should maintain data until a new write occurs.
