Create a 5-bit Linear Feedback Shift Register (LFSR) with the polynomial x^5 + x^2 + 1. The LFSR should have a clock input and a reset input. The output should be the current state of the LFSR, and it should shift left on each clock cycle. When reset is high, the LFSR should return to its initial state of 1. The LFSR's feedback taps are taken from bit positions 5 and 2.
