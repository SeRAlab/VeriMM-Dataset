Design a Verilog module that implements a simple Flash memory cell type with the following characteristics:
- The memory cell can store a single bit (0 or 1).
- It has two inputs: a 'write' signal and a 'data' signal.
- If 'write' is high, the value of 'data' is stored in the memory cell.
- If 'write' is low, the memory cell retains its previous value.
- The output should reflect the current state of the memory cell.
