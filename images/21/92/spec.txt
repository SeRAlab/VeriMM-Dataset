Design a simple audio compression controller that takes a 16-bit input audio sample, processes it to reduce the dynamic range by applying a simple compression algorithm, and outputs a 16-bit compressed audio sample. The controller should use a state machine to switch between idle and processing states. When in the processing state, if the input sample exceeds a predefined threshold, it should scale it down. The threshold can be defined as 10000 (in decimal). If the sample is below the threshold, it should remain unchanged.
