
Design a convolutional encoder that takes a 1-bit input data stream and produces a 2-bit output for every input bit. The encoder uses the following connections:
- The first output bit is the XOR of the input bit and the previous input bit (stored in a register).
- The second output bit is the XOR of the input bit and the previous two input bits (stored in another register).
The encoder should operate on a clock edge and reset the registers when a reset signal is asserted.
