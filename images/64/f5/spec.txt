Design a circuit that functions as a 2-bit register controlled by two enable signals. The output, `foo`, is initialized to a default value of 00. When `en0` is high, the least significant bit of `foo` is set to the value of `in0`, and when `en1` is high, the most significant bit of `foo` is set to the value of `in1`. This allows for selective updating of the output bits based on the enable signals.
module top_module(output reg [1:0] foo,
   input wire in0, en0,
   input wire in1, en1
   );
