Design a 128x8 bit random-access memory (RAM) module that allows for writing and reading operations. The module has an input for data (din) and a 7-bit address (addr) to select the memory location. When the write enable signal (we) is high on a rising clock edge (clk), the input data is stored in the specified address. The output (dout) continuously reflects the data stored at the specified address, regardless of whether a write operation occurs.
module top_module(
    dout,
    din,
    addr,
    we,
    clk
);
