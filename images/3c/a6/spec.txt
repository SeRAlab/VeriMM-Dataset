Design a 16-bit DRAM cell with read and write operations. The DRAM cell should have the following inputs and outputs:
- Inputs:
  - clk: Clock signal
  - wr_en: Write enable signal
  - addr: 4-bit address to select one of the 16 cells
  - data_in: 16-bit data input for writing to the cell
- Outputs:
  - data_out: 16-bit data output for reading from the cell
The DRAM cell should store the data when wr_en is high and output the stored data when wr_en is low.
