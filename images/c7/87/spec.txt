

You are working on a project that requires you to create a module that converts a 4-bit binary input to a 16-bit decimal output. You decide to write a Verilog module called "bin_to_dec" that takes a 4-bit binary input called "bin_in" and outputs a 16-bit decimal value called "dec_out". 

Your task is to complete the "bin_to_dec" module by writing the Verilog code that will perform the binary-to-decimal conversion. You must use the following formula to calculate the decimal value:

```
dec_out = bin_in[0] * 2^0 + bin_in[1] * 2^1 + bin_in[2] * 2^2 + bin_in[3] * 2^3
```

You should ensure that the module has the following ports:

- "bin_in": a 4-bit binary input
- "dec_out": a 16-bit decimal output

You should also ensure that the module uses the "assign" statement to perform the binary-to-decimal conversion.

Write a Verilog module called "bin_to_dec" that performs the binary-to-decimal conversion as described above.
