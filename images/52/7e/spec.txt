Design a synchronous 8-bit up counter with an asynchronous active-low reset. On each rising edge of the clock, if the reset signal (aclr) is low, the counter output (q) is set to zero. If the reset is not active and the counter reaches its maximum value of 255 (8'hFF), it resets to zero. Otherwise, it increments the counter by one on each clock cycle.
