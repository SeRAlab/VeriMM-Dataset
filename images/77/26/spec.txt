Design a 64-bit wide arithmetic right shifter that conditionally shifts the input based on the enable signal. When enable is high, the input is shifted right by one bit, preserving the sign bit (the most significant bit). If enable is low, the output retains the original bit value for all bits except for the most significant bit, which remains unchanged. Additionally, it outputs the least significant bit that is shifted off, providing information about the bit that was removed during the shift operation.
