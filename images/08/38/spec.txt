Design a 4-bit shift register with synchronous load and shift operations. The shift register should have an input data line, a load control signal, and a shift control signal. If the load control signal is high, the input data should be loaded into the shift register. If the shift control signal is high, the bits in the register should shift right, with the least significant bit being shifted out and a zero being shifted in on the most significant bit. The output should be the current value of the shift register.
