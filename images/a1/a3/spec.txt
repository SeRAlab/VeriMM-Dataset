Design a D-type flip-flop with asynchronous set and reset functionality, along with an enable signal. When the enable (EN) is active, the flip-flop will capture the input data (D) on the rising edge of the clock (CLK). The flip-flop can be asynchronously set to logic HIGH or reset to logic LOW based on the SET and RESET inputs, respectively. The output (Q) reflects the stored state, with the complementary output (QN) representing the negation of Q.
