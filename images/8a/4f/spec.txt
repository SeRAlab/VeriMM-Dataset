Design a UART state machine that processes command and data transfers based on the UART protocol. The module has an active clock and reset input to manage transitions through three states: RX_SYNC, RX_CMD, and RX_DATA. Upon receiving a burst transfer signal, it enables the transition from the command state to the data state. The output, cmd_valid, indicates the validity of command signals when in the RX_CMD state and a transfer is complete, as determined by the xfer_done signal that is asserted whenever the state is not RX_SYNC. This module effectively handles UART communication protocol for command validation and synchronization.
