Design a simple memory allocator with a fixed-size memory block. The memory allocator should have the following functionalities: allocate a block of memory of a given size, free a previously allocated block, and check the status of memory (allocated or free). The memory block size should be defined as a parameter, and the allocator should maintain a list of allocated and free blocks. The module should have inputs for allocation requests, free requests, and a status request. The output should indicate the success of allocation or freeing operations and provide the status of a specific block.
