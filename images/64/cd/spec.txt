Design a Verilog module that implements an 11-bit binary counter with count enable and a terminal count output. The module should have a clock input, a reset input, an enable input, and an 11-bit output with a terminal count signal. The counter should increment on every clock cycle when the enable signal is high, reset to 0 when the reset signal is high, and assert the terminal count signal when the counter reaches its maximum value.

module counter11bit_term (
    input clk,
    input rst,
    input en,
    output reg [10:0] count,
    output reg term_count
);
