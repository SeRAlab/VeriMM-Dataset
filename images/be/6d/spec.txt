Design a parallel-in serial-out (PISO) shift register that facilitates data transmission. The module captures an 11-bit input when the load (ld) signal is active and then serially shifts out the least significant bit (LSB) through the ser_out output when the shift enable (sh_en) signal is asserted. The register is synchronous to the clock (Clk) and can be reset asynchronously with the reset (Rst) signal, initializing the stored data to zero. Additionally, it incorporates a serial input (ser_in) to shift new data into the register during the shift operation.
