
Design a JK latch using Verilog. The JK latch should have inputs J, K, and a clock signal. The latch will toggle its output Q based on the values of J and K at the rising edge of the clock. If J and K are both low, the output Q should remain unchanged. If J is high and K is low, Q should be set to high. If J is low and K is high, Q should be reset to low. If both J and K are high, Q should toggle its current state.
