Design a Parallel-in Parallel-out (PIPO) shift register that can load data in parallel and output data in parallel. The shift register should have the following parameters: a 5-bit input data bus, a 5-bit output data bus, a clock signal, a load signal, and a reset signal. On the rising edge of the clock, if the load signal is asserted, the input data should be loaded into the register. If the reset signal is asserted, the register should be cleared to zero. Otherwise, the output data should reflect the current state of the register.
