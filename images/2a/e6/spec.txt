Design an 8-bit Digital-to-Analog Converter (DAC) that takes an 8-bit input and outputs a corresponding analog voltage level. The output voltage is determined by the formula: V_out = (V_ref / 255) * digital_input, where V_ref is the reference voltage (let's assume V_ref = 5V). The output should be represented as a 10-bit binary number to allow for a greater resolution in the output. The design should include a combinational logic that converts the 8-bit input to the corresponding 10-bit output.
