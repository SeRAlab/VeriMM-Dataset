
Design a FIFO (First-In, First-Out) queue in Verilog. The FIFO should support the following operations:
1. Enqueue: Add an item to the end of the queue.
2. Dequeue: Remove an item from the front of the queue.
3. Check if the queue is empty.
4. Check the current size of the queue.
The FIFO should have a fixed size of 4 elements. Use a parameter to define the size. The data width is 8 bits.
