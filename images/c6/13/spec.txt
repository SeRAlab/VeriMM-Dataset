

You have been tasked with designing a verilog module for a 4-bit adder that can perform both addition and subtraction. The module should have two 4-bit inputs, A and B, and a 1-bit input, subtract. If subtract is 0, the module should output the sum of A and B. If subtract is 1, the module should output the result of A minus B. The output should be a 4-bit representation of the result.

Design the verilog module for the 4-bit adder that meets the above specifications.
