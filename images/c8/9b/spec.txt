Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a clock gating cell. 
A clock gating cell is a digital circuit that is used to control the clock signal to a set of flip-flops. 
By controlling the clock signal, the clock gating cell can reduce power consumption and improve performance.

Your module should have the following inputs and outputs:

Inputs: a clock signal (CLK)
         a control signal (EN)
Outputs: a gated clock signal (CLK_G)

Your module should implement the following functionality:

When the control signal is high, the clock gating cell should pass the clock signal through to the gated clock signal.
When the control signal is low, the clock gating cell should hold the gated clock signal low, regardless of the state of the clock signal.
The module should be implemented using Verilog code. You should use a simple gate-level implementation to create the clock gating cell. 
You should also ensure that the module produces a synchronous output by using the clock signal as a reference for the control signal.
