
Design a combinational logic circuit that implements a simple decision tree for classifying a binary input based on two features. The features are `feature1` and `feature2`, both 1-bit values, and the output `class` is also a 1-bit value indicating the class of the input. The decision logic is as follows:
- If feature1 is 0 and feature2 is 0, output class is 0.
- If feature1 is 0 and feature2 is 1, output class is 1.
- If feature1 is 1 and feature2 is 0, output class is 1.
- If feature1 is 1 and feature2 is 1, output class is 0.
