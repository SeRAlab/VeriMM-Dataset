
Design a simple ARQ (Automatic Repeat reQuest) system for error correction in communication. The system should include a sender and a receiver. The sender will send a data signal and a control signal (ACK/NACK) indicating whether the data was received correctly. The receiver will check the data and send back an ACK if it is correct, or a NACK if there is an error. The sender should resend the data upon receiving a NACK.
