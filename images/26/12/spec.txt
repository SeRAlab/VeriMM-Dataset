
Design a virtual memory management unit (MMU) that maps a virtual address to a physical address using a simple page table. The page table will contain 4 entries, where each entry maps a 4-bit virtual page number to a 4-bit physical frame number. The MMU should output the corresponding physical address when a 4-bit virtual address is input. If the virtual page number is invalid (not in the page table), the MMU should output a specific invalid address (for instance, 4'b1111).
