Design a Verilog module that implements a simple 8-point Fast Fourier Transform (FFT) using a radix-2 algorithm. The module should take a 16-bit input for each of the 8 points (a total of 128 bits). It should output the 16-bit result for each of the 8 transformed points sequentially. The input and output should be clocked, and the module should have a start signal to initiate the transformation and a done signal to indicate completion.
