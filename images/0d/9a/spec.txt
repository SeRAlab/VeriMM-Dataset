Design a simple depth-first search (DFS) state machine that explores a binary tree. The inputs to the circuit are a clock signal (`clk`), a reset signal (`reset`), and a new node signal (`new_node`). The output is the current node being explored (`current_node`). The DFS should start from the root node (0) and explore left first, then right. The tree structure is defined as a binary tree with values from 0 to 7.
