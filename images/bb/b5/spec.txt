2. state Processing (ready=0, done=0).

1. From state Idle: If start = 1, then transition to state Processing. If start = 0, then remain in state Idle.
2. From state Processing: If start = 0, then transition to state Done. If start = 1, then remain in state Processing.
3. From state Done: If start = 1, then transition to state Idle. If start = 0, then remain in state Done.

At reset, the state machine starts in state "Idle". Derive next-state logic equations and output logic equations by inspection assuming the following one-hot encoding is used: (Idle, Processing, Done) = (3'b001, 3'b010, 3'b100)

- Idle_next -- next-state logic for state Idle

- Done_next
- ready -- output logic
- done -- output logic
