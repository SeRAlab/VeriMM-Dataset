Design an I2C controller that can initiate a start condition, send data, and generate a stop condition. The controller must be able to handle 8 bits of data and send an acknowledgment signal after each byte. The controller should have the following inputs: `start`, `stop`, `clk`, and `data_in[7:0]`, and outputs: `sda`, `scl`, `ack`, and `data_out[7:0]`.
