Design a simple interrupt controller that receives multiple interrupt requests (IRQs) and provides a single output indicating which IRQ is currently being serviced. The controller should have a register to store the current IRQ being serviced, and it should prioritize the IRQs based on their input order. The controller should also have an acknowledge (ACK) signal to indicate that the interrupt has been serviced, and a reset (RST) signal to clear the current service. The design should include a clock signal (CLK) for timing.
