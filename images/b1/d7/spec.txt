Design a color decoder that maps a 3-bit input code to a corresponding 12-bit RGB hex representation of various colors. The module takes a 3-bit input called "code" and uses a combinational logic block to output the appropriate hex value for BLACK, GREY, ORANGE, GREEN, YELLOW, RED, or WHITE based on the input code. When the code matches a specific value, the corresponding color's hex value is assigned to the output "hex".
module top_module(
    input [2:0] code,
    output reg [11:0] hex
    );
