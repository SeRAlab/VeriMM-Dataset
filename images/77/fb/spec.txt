Implement the Verilog module based on the following description.
Design a Verilog module that implements a 16-bit binary down-counter with enable. The counter should decrement on the rising edge of the clock if the "enable" signal is high. The counter should reset to its maximum value (65535) when the asynchronous reset (areset) is high. The counter value should be output to the "count" signal.

module top_module
(
    input clk,
    input areset,
    input enable,
    output reg [15:0] count
);
