Design a D flip-flop with an asynchronous reset and enable functionality. The flip-flop captures the input data (D) on the positive edge of the clock (Ck) when the reset (Rn) is not asserted and the enable (Ckn) signal is not active. If the reset is low, the output (Q) is set to LOW, and its complement (Qn) is set to HIGH. If the enable signal is low, the flip-flop maintains its current state. When enable is active, the output follows the input data, toggling the output (Q) to the value of D and setting (Qn) to its inverse.
