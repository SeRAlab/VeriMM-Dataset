Implement a Verilog module that converts RGB color values to YUV color space. The input will be 8-bit values for Red, Green, and Blue, and the output will be 8-bit values for Y, U, and V. Use the following formulas for conversion:
Y = 0.299 * R + 0.587 * G + 0.114 * B
U = -0.14713 * R - 0.28886 * G + 0.436 * B + 128
V = 0.615 * R - 0.51499 * G - 0.10001 * B + 128
Ensure to handle rounding appropriately and convert the fixed-point results to integers.
