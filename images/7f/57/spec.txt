Design a 4-bit adder-subtractor circuit. The module takes two 4-bit inputs (in0 and in1) and an input signal (SUB) to determine the operation. When SUB is LOW, the circuit performs addition on in0 and in1, while when SUB is HIGH, it performs subtraction (in0 - in1), producing a 4-bit output (out).
module top_module(
    input [3:0] in0,
    input [3:0] in1,
    input SUB,
    output reg [3:0] out
);
