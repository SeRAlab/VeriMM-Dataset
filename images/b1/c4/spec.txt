Design a resettable register that operates on a clock signal. When the reset signal is high, the output data_out is set to low. If the set signal is high, data_out is set to high. The clear signal also sets data_out to low when activated. In the absence of reset, set, or clear signals, the output maintains its previous state. This module is useful for managing a register with programmable control for initializing, setting, and clearing its value.
module top_module(
    input clk, reset, set, clear,
    input data_in,
    output reg data_out
);
