Implement a module of a 4-bit comparator. The comparator should output a high signal if the first 4-bit input is greater than the second 4-bit input. Otherwise, it should output a low signal.

Module name:  
    comparator

Input ports:
    A: First 4-bit input
    B: Second 4-bit input

Output ports:
    GT: Output signal indicating if A is greater than B

Implementation:
The comparator module uses continuous assignment to compare the two 4-bit inputs (A and B). If A is greater than B, the output signal (GT) is set to high. Otherwise, the output signal is set to low.

Give me the complete code.

module comparator(A, B, GT);
input [3:0] A, B;
output GT;
