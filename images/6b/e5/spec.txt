Implement a 5-to-1 multiplexer with a 3-bit select input. The multiplexer should output one of the five 10-bit input data signals based on the value of the select input.

Module name:
    mux_5to1

Input ports:
	sel: 3-bit select input.
	in0: 10-bit input data 0.
	in1: 10-bit input data 1.
	in2: 10-bit input data 2.
	in3: 10-bit input data 3.
	in4: 10-bit input data 4.

Output ports:
	out: 10-bit output data based on the select input.
