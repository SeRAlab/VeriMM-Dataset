Design a combinational logic unit that performs various bitwise operations on two 32-bit input operands, opA and opB. The operation to be executed is controlled by a 2-bit input signal, op. When op is set to '00', the module computes the bitwise AND of opA and opB; when '01', it computes the bitwise OR; when '10', it performs the bitwise XOR; and with '11', it outputs the bitwise NOR of opA and opB. The resulting output, result, reflects the selected operation based on the op input.
module top_module(
            opA, opB,
            op,
            result);
