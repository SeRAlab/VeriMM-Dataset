Design a 2-to-1 multiplexer utilizing active-low inputs. The circuit uses the inverted inputs A1_N and A2_N to select between two data inputs B1 and B2, producing an output Y. When A1_N and A2_N are both LOW, B2 is selected; when A1_N is LOW and A2_N is HIGH, B1 is chosen; if A1_N is HIGH and A2_N is LOW, B2 is also selected; and when both are HIGH, B1 is outputted.
module top_module(
    input A1_N,
    input A2_N,
    input B1,
    input B2,
    output Y
);
