Design a 4-to-1 multiplexer with data forwarding capability. The multiplexer should select one of the four 8-bit input data lines based on a 2-bit select signal. Additionally, it should have a data forwarding feature such that if the select signal is equal to a specific value (for example, 00), the output should forward the last output value to the output line instead of selecting from the inputs. In this case, the multiplexer should maintain the last output when it is supposed to select input 0.
