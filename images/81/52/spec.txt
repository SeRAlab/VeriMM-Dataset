Design a circuit that functions as a delayed signal inverter. It uses a D flip-flop to store the state of the input_signal on the rising edge of the clk. If the reset signal is activated, the output is set to LOW; otherwise, the output_signal produces the inverse of the value stored in the flip-flop, effectively inverting input_signal with a one-clock cycle delay.
module top_module(
  input clk,
  input reset,
  input input_signal,
  output output_signal
);
