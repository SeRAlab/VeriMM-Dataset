
Design a combinational logic circuit to perform the LU decomposition of a 2x2 matrix. Given a 2x2 matrix:
```
A = | a11 a12 |
    | a21 a22 |
```
The output should be the matrices L and U such that:
```
L = | 1    0   |
    | l21  1   |

U = | u11  u12 |
    | 0    u22 |
```
where:
```
u11 = a11
u12 = a12
l21 = a21 / u11
u22 = a22 - l21 * u12
```
Ensure that all outputs are computed correctly based on the input matrix A.
