

You are tasked with designing a Verilog module that implements a simple 4-bit adder. The module should have two 4-bit input ports, `a` and `b`, and a 4-bit output port, `sum`. The module should also have a single input port, `carry_in`, which is a single bit.

The module should implement the following logic:

- The 4-bit output `sum` should be the sum of the two 4-bit inputs `a` and `b`, plus the value of `carry_in`.
- If the sum of any two corresponding bits in `a`, `b`, and `carry_in` is greater than or equal to 2, then the corresponding bit in `sum` should be 1. Otherwise, it should be 0.
- The module should also have a single output port, `carry_out`, which is a single bit. `carry_out` should be 1 if the sum of the most significant bits of `a`, `b`, and `carry_in` is greater than or equal to 2. Otherwise, it should be 0.

Your module should be named `adder_4bit` and should be implemented in a single Verilog module no longer than 200 lines.
