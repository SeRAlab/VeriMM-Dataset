Implement a 64-bit vector addition module that sums two 64-bit input vectors (vector1 and vector2) on the rising edge of a clock signal. The output, result_vector, is initialized to zero when the reset signal (resetn) is low. When resetn is high, each clock cycle computes the sum of vector1 and vector2, updating result_vector accordingly.
module top_module(
   input logic clock,
   input logic resetn,
   input logic [63:0] vector1,
   input logic [63:0] vector2,
   output logic [63:0] result_vector
);
