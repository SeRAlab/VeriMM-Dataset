
Design a 1-bit DRAM cell in Verilog that can store a single bit of data. The cell should have an input for data (D), a write enable signal (WE), a read enable signal (RE), and an output for the stored data (Q). The write enable signal should determine when data can be written to the cell, and the read enable signal should determine when data can be output from the cell. The cell should maintain its state when not being written to or read from.
