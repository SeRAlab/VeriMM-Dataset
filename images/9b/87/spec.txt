Design a 4-to-1 multiplexer that selects one of four 4-bit wide input signals (in1, in2, in3, in4) based on a 2-bit selection input. The selected input is output as a 4-bit signal (out). When select=00, in1 is chosen; when select=01, in2 is chosen; when select=10, in3 is selected; and when select=11, in4 is used as the output. In case of an invalid selection, the output is set to an unknown state.
module top_module(
    input wire [3 : 0] in1, in2, in3, in4,
    input wire [1 : 0] select,
    output reg [3 : 0] out
);
