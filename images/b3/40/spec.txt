Design a Verilog module that implements a 6-bit binary up-counter with enable, synchronous reset, and carry out. The counter should increment on the rising edge of the clock if the "enable" signal is high. The counter should reset to zero when the synchronous reset (sreset) is high. When the counter overflows, the "carry_out" signal should go high. The counter value should be output to the "count" signal.

module top_module
(
    input clk,
    input sreset,
    input enable,
    output reg [5:0] count,
    output reg carry_out
);
