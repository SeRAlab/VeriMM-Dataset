Design a synchronous 8-bit register with an asynchronous reset. On the rising edge of the clock, the register captures the 8-bit input `d` and stores it in the output `q`. When the asynchronous reset signal `areset` is asserted, the output `q` is immediately cleared to zero, regardless of the clock edge.
module top_module(
	input clk,
	input [7:0] d,
	input areset,
	output reg [7:0] q);
