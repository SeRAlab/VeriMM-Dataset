Design a four-bit binary adder with carry-in functionality. The module takes two 4-bit inputs, A and B, along with a carry-in input, cin. It computes the sum, S, of the two inputs along with the carry-in and produces a carry-out output, cout, to indicate if the sum exceeds the 4-bit maximum value (15).
module top_module(
    input [3:0] A,
    input [3:0] B,
    input cin,
    output reg [3:0] S,
    output reg cout
);
