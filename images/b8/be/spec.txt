Design a 4-bit comparator that outputs a 2-bit code indicating the relational status of two input values A and B. The output EQ_LT_GT signals whether A is equal to B (01), A is less than B (10), or A is greater than B (00). This functionality allows for easy comparison and can be utilized in various digital applications requiring relational evaluation.
module top_module(
  input [3:0] A,
  input [3:0] B,
  output reg [1:0] EQ_LT_GT
);
