Design a synchronous 8-bit counter with an optional load input. On the rising edge of the clock, the current output value is latched into a temporary register. The counter sums the current output and a carry-in (cin), producing a carry-out (cout) while also allowing new data to be loaded into the counter when the load signal is asserted. If the load signal is active, the counter loads the value from the data input, overriding the current count.
