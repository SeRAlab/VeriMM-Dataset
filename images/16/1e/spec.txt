Design a packet filtering module that checks incoming packets against a predefined set of rules. Each packet is represented by a 16-bit value where the first 8 bits are the source IP address and the last 8 bits are the destination IP address. The module should allow packets through if they match a stored rule or block them if they do not. The rules are stored in a 4-entry memory. The module should have inputs for the packet, a clock, and a reset signal, and an output indicating whether the packet is allowed (1) or blocked (0).
