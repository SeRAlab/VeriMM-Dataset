    gray_code_counter

Implementation:
Binary Counter:
Use a binary counter to track the current count.
Gray Code Conversion:
Convert the binary count to gray code using the formula gray_code = binary ^ (binary >> 1).

Output Assignments:
The gray_code output is assigned the value of the gray code generated from the binary count.
