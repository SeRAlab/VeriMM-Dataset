
Design a simple SPI (Serial Peripheral Interface) controller in Verilog. The SPI controller should support the following operations: 
1. Begin communication by pulling the Chip Select (CS) low.
2. Shift out data on the MOSI line while receiving data on the MISO line. 
3. End communication by pulling the Chip Select (CS) high.
The controller should operate based on a clock signal (SCK) and have an input for data to send, an output for received data, and a control signal for starting communication.
