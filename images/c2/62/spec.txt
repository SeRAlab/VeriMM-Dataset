

You are tasked with designing a module that implements a 4-bit adder-subtractor in Verilog. The module should have the following inputs and outputs:

Inputs:
- `a` (4-bit input): the first operand of the operation
- `b` (4-bit input): the second operand of the operation
- `sub` (1-bit input): a control signal that determines whether the operation is addition or subtraction. If `sub` is 1, the operation is subtraction. If `sub` is 0, the operation is addition.

Outputs:
- `result` (4-bit output): the result of the operation
- `carry_out` (1-bit output): the carry-out bit of the operation. For addition, `carry_out` is the carry-out bit of the most significant bit. For subtraction, `carry_out` is the borrow-out bit of the most significant bit.

Your module should be named `adder_subtractor` and should have the following interface:

```
module adder_subtractor(a, b, sub, result, carry_out);
	input [3:0] a, b;
	input sub;
	output [3:0] result;
	output carry_out;
	
	// your code here
	
endmodule
```

You should assume that the inputs `a` and `b` are valid 4-bit binary numbers.
