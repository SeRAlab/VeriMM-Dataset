Design a 2-to-4 line decoder that activates one of four outputs (out0 to out3) based on the 2-bit address input (addr0 and addr1) when the enable signal is high. If enable is low, all outputs will be turned off. The specific output activated corresponds to the binary value represented by the address inputs, effectively translating the 2-bit address into a single high output among the four.
module top_module(
    output out0, out1, out2, out3,
    input addr0, addr1,
    input enable
);
