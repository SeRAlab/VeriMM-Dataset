
Design a JK flip-flop with the following specifications:
1. The flip-flop should have inputs J and K, a clock input CLK, and an output Q.
2. The outputs should follow the standard JK flip-flop behavior.
3. If J and K are both 0, Q retains its value.
4. If J is 1 and K is 0, Q is set to 1.
5. If J is 0 and K is 1, Q is reset to 0.
6. If J and K are both 1, Q toggles its value on the rising edge of the clock.
