Design a module for performing various bitwise and shift operations based on a specified operation code. The module accepts a 3-bit operation code (op) and two 16-bit inputs (a and b). It computes the results of AND, OR, XOR, NOT (applied to a), left shift, and right shift operations on the inputs. The output is determined by the operation code: op=0 for AND, op=1 for OR, op=2 for XOR, op=3 for NOT, op=4 for left shift, and op=5 for right shift of `a` by the number of bits indicated by the lower 4 bits of `b`.
module top_module(
    input [2:0] op,
    input [15:0] a,
    input [15:0] b,
    output [15:0] out
);
