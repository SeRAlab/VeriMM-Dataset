
Design a simple SATA controller state machine that transitions between three states: IDLE, ACTIVE, and ERROR. The state machine should respond to two inputs: a signal to start the operation (start_signal) and a signal to indicate an error (error_signal). The state machine should transition as follows:
- From IDLE to ACTIVE on start_signal.
- From ACTIVE to ERROR on error_signal.
- From ACTIVE to IDLE on a reset signal (reset).
- From ERROR to IDLE on a reset signal (reset).
