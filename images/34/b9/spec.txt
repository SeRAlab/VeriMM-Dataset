Design a Verilog module that implements a simple HMAC (Hash-based Message Authentication Code) algorithm using a fixed key. The module should take an input message and output the HMAC value. The HMAC will be generated using a simple XOR operation with the key and a simple hash function (for simplicity, we will use a parity check as the hash function). The module should have an input for the message and an output for the HMAC, as well as a clock and reset signal.
