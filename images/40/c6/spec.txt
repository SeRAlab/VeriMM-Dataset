Design a GPIO controller that can read and write to a 5-bit GPIO port. It should have a mode selection input that decides whether the port is in input mode or output mode. If the mode is set to input mode (mode = 1), the controller should read the value from the GPIO pins and store it in a register. If the mode is set to output mode (mode = 0), the controller should take the value from the register and write it to the GPIO pins. The controller should also have a clock input for synchronization and a reset input to initialize the register to zero.
