Design a circuit that functions as a barrel shifter with an integrated arithmetic logic unit (ALU). The module takes two 4-bit inputs, A and B, a direction control signal (dir), and a 3-bit operation selection (op). Depending on the value of dir, it shifts input A left or right and then performs various operations (addition, subtraction, logical AND, OR, XOR, and left shift) between A and the shifted value, outputting the result as a 4-bit output S. This design enables bit-level manipulation and arithmetic processing in a single module.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input dir,
    input [2:0] op,
    output [3:0] S
);
