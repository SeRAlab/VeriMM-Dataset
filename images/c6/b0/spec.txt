
You are tasked with designing a Verilog module for a 2:1 multiplexer. The module should have two input ports, a select port, and an output port. The output port should output the value of the first input port when the select port is 0, and the value of the second input port when the select port is 1.

Design a Verilog module that implements the 2:1 multiplexer described above. Your module should be named "mux_2to1" and should have the following inputs and outputs:

Inputs:
- in0: a 1-bit input signal
- in1: a 1-bit input signal
- sel: a 1-bit select signal

Outputs:
- out: a 1-bit output signal

Your module should be implemented within 200 lines of Verilog code.
