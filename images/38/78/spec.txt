Design a virtual memory page table manager in Verilog that uses a finite state machine (FSM). The FSM should have the following states: IDLE, READ, WRITE, and INVALIDATE. The module should take inputs for a virtual address and a control signal to read or write data. The output should indicate whether the operation was successful or if an error occurred (e.g., trying to write to an invalid page). It should also handle page faults by asserting a page fault signal.
