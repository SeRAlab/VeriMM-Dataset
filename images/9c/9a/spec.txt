Design a 4-to-1 multiplexer that selects one of four 4-bit inputs (in0, in1, in2, in3) based on a 2-bit selection signal (sel). The output (out) will reflect the selected input based on the value of sel: if sel is 00, output in0; if sel is 01, output in1; if sel is 10, output in2; if sel is 11, output in3. In the case of an invalid selection, the output is set to zero.
module top_module(
  input [3:0] in0,
  input [3:0] in1,
  input [3:0] in2,
  input [3:0] in3,
  input [1:0] sel,
  output reg [3:0] out
);
