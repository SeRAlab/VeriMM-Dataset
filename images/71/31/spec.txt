Design a 3-bit binary counter using Verilog. The counter increments on each clock cycle.

Module name:  
    binary_counter  

Input ports:
    clk: Clock signal.
    rst: Reset signal.

Output ports:
    count: 3-bit Output count.

Implementation:
Counter operation:
