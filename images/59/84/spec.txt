Design a multi-bit comparator that can compare two n-bit input numbers, a and b. It provides three output signals: 'greater' indicates if a is greater than b, 'less' signifies if a is less than b, and 'equal' shows if both numbers are equal. The comparator supports both unsigned and signed comparisons based on the most significant bit. This functionality is essential for arithmetic and logical operations in digital design, enabling decision-making processes based on the relative sizes of the input values.
module top_module(
  input [n-1:0] a,
  input [n-1:0] b,
  output greater,
  output less,
  output equal
);
