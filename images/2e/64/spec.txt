Design a fan speed controller that takes an input temperature (in degrees Celsius) and controls the fan speed based on the following rules: If the temperature is less than 20°C, the fan speed should be 0 (off). If the temperature is between 20°C and 30°C, the fan speed should be 1 (low). If the temperature is between 30°C and 40°C, the fan speed should be 2 (medium). If the temperature is 40°C or more, the fan speed should be 3 (high). The fan speed should change only on the rising edge of a clock signal.
