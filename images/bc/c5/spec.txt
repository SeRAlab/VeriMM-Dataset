Design a general-purpose register file (GRF) that supports reading and writing to 32 registers, each 32 bits wide. The module allows two simultaneous read operations based on provided addresses, reading data from the specified registers to output ports. A write operation can be performed on the rising edge of the clock if the write_enable signal is active, allowing new data to be stored in the target register specified by write_addr, provided it is not the reserved zero register. Additionally, the module includes a reset functionality that initializes all registers to zero when activated, ensuring a clean starting state.
