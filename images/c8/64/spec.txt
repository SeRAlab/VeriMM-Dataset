

You are asked to design a verilog module that implements a 4-bit synchronous up-counter with a synchronous clear (CLR) input. The counter should increment on every rising edge of the clock signal (CLK) and reset to 0 when the CLR input is asserted. The module should have the following interface:

Inputs:
- CLK: clock input
- CLR: synchronous clear input

Outputs:
- Q: 4-bit output representing the current count value

You can assume that the inputs will be valid and that the clock signal has a 50% duty cycle.
