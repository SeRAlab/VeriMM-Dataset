Design a 3-to-8 line decoder with an enable signal. When the enable input is high, the output will represent the inverse of the most significant bit followed by the inverse of the middle bit and the least significant bit, followed by the direct values of the three input bits, with the last two output bits set to zero. If the enable input is low, all output lines will be low, effectively disabling the decoder.

    input [2:0] in,
    input enable,
