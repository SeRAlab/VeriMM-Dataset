Design a 4-bit Serial-in Serial-out (SISO) shift register. The shift register should have a serial input (SI), a clock input (CLK), and a reset input (RST). On each rising edge of the clock, if the reset is not active, the shift register should shift in the serial input from SI and shift out the most significant bit (MSB) to a serial output (SO). The shift register should be initialized to zero on reset.
