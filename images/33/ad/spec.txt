Design a UART transmitter module in Verilog that takes a parallel 8-bit data input, a transmit enable signal, and outputs a serial data stream. The module should implement a baud rate of 9600, with a 1 stop bit, no parity, and support data transmission when enabled. The data should be transmitted starting with a start bit (0), followed by the 8 data bits, and ending with a stop bit (1). Additionally, implement a clock divider for the 9600 baud rate from a 50 MHz input clock.
