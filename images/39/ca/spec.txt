
Design a 2nd-order IIR filter using Verilog. The filter will have two input taps and two output taps, and it will process a stream of input data to produce an output based on the specified coefficients. The filter's behavior should be defined by the transfer function:
H(z) = (b0 + b1*z^-1 + b2*z^-2) / (1 + a1*z^-1 + a2*z^-2)
Where b0, b1, b2 are the feedforward coefficients and a1, a2 are the feedback coefficients. The filter should have a clock signal and a reset signal.
