Design a 4-bit arithmetic calculator that takes two 4-bit inputs (reg_a and reg_b) and performs one of four arithmetic operations based on a 2-bit operation code (op). The calculator can execute addition, subtraction, multiplication, or division when the computation is triggered by a start signal, producing a 4-bit result. The module handles different operations in a combinational manner, responding to changes in the operation code and inputs.
module top_module(
    input [3:0] reg_a,
    input [3:0] reg_b,
    input [1:0] op,
    input start,
    output reg [3:0] result
);
