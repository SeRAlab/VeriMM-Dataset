
You are required to design a simple GPIO (General Purpose Input/Output) controller that can read a 5-bit input and generate a 5-bit output based on a configuration register. The controller should have the following features:
1. A 5-bit input port that represents the GPIO data.
2. A 5-bit output port that reflects the GPIO data if the configuration register allows it.
3. A 5-bit configuration register where each bit enables or disables the corresponding GPIO input bit.
4. The output should update on the rising edge of a clock signal.
5. An asynchronous reset should initialize the output to all zeros and reset the configuration register.

Implement the GPIO controller in Verilog.
