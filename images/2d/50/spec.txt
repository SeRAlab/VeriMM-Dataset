Design a simple OFDM modulator that takes a stream of binary data (input) and produces an OFDM symbol (output) consisting of multiple subcarriers. The data is to be processed in blocks of 4 bits, and each block will modulate a subcarrier using BPSK (Binary Phase Shift Keying). The output OFDM symbol will be a 8-bit value, where the first 4 bits represent the phase of the first subcarrier and the last 4 bits represent the phase of the second subcarrier (0 for 0 phase, 1 for 180 phase). The design should include a clock and reset signal, and it should handle the input data stream sequentially, generating an output symbol for every 4 bits processed.
