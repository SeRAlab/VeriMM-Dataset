Design a 1-to-4 octal demultiplexer. This module takes an 8-bit input and routes it to one of four 8-bit outputs based on a 2-bit selection signal. When select is 00, the input is directed to out0; when select is 01, the input goes to out1; when select is 10, it is sent to out2; and when select is 11, the input is output on out3. All other outputs remain LOW (zeroed) when not selected.
