Design a fan speed control system that adjusts the speed of a fan based on temperature readings. The system should have an input for temperature (in degrees Celsius) and output control signals for three levels of fan speeds: Low, Medium, and High. The fan speed should be determined as follows:
- If the temperature is below 20°C, the fan should be OFF.
- If the temperature is between 20°C and 30°C, the fan should run at Low speed.
- If the temperature is between 30°C and 40°C, the fan should run at Medium speed.
- If the temperature is above 40°C, the fan should run at High speed.
