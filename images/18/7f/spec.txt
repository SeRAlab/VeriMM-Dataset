Design a simple WiFi module controller that manages the power state of the WiFi based on the input signals. The module should have an input signal `power_enable` that, when high, powers on the WiFi module after a delay of 2 clock cycles. If `power_enable` goes low, the WiFi module should turn off immediately. The output signal `wifi_power` should indicate the current power state of the WiFi module, which should be high when powered on and low when powered off.
