
Design a 2-bit branch predictor using a 2-bit saturating counter. The predictor has two states: '00' (Strongly not taken), '01' (Weakly not taken), '10' (Weakly taken), '11' (Strongly taken). The input is the last outcome of a branch instruction (1 for taken, 0 for not taken). The output should be the prediction for the next branch instruction (1 for taken, 0 for not taken).
