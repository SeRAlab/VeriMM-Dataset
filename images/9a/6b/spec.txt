Implement a Verilog module for a 4-bit binary up-counter with enable and load. The counter should load a specific value when the load signal is high. The counter should have an asynchronous active-high reset that sets the counter to zero.

module up_counter_with_load (
    input clk,
    input reset,
    input enable,
    input load,
    input [3:0] load_value,
    output reg [3:0] count
);
