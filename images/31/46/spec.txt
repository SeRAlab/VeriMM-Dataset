
Design an 8-bit DRAM cell that allows for reading and writing operations. The cell should have a single data input (D), a data output (Q), a write enable signal (WE), a read enable signal (RE), and a clock signal (CLK). When WE is high, the input data should be written to the cell on the rising edge of CLK. When RE is high, the current data in the cell should be output to Q on the rising edge of CLK. Ensure that both read and write operations cannot occur simultaneously.
