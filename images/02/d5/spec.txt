
Design a Run-length encoding (RLE) encoder in Verilog. The encoder should take an 8-bit input data stream and produce a run-length encoded output. The output should consist of pairs of values representing the number of consecutive identical bits (the run length) and the value itself (0 or 1). The encoder should also indicate when the output is valid by asserting an output valid signal. The encoder should handle the end of the input stream gracefully and should be resettable.
