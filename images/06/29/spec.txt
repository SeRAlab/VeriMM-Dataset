
Design a simple 4-bit DRAM cell that can store a data value and has a control signal to read or write data. The DRAM cell should have the following inputs: a 4-bit data input (data_in), a control signal (we) for write enable (1 for writing data and 0 for reading data), and a clock signal (clk). The output should be the 4-bit data stored in the DRAM cell (data_out).
