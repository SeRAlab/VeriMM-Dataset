
Create a Verilog module that implements a simple PID controller. The module should take three inputs: the current process variable (PV), the setpoint (SP), and a clock signal. It should output the control signal (CV) which is a result of PID calculations. The PID constants (Kp, Ki, Kd) should be configurable via parameters. The module should also have reset functionality to initialize the integrator and previous error values.
