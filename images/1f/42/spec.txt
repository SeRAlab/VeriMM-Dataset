Implement a simple version of the ChaCha20 stream cipher's quarter round function. The function takes four 32-bit inputs and produces four 32-bit outputs. The quarter round function operates on the inputs as follows:  
1. a += b  
2. d ^= a  
3. d <<<= 16  
4. c += d  
5. b ^= c  
6. b <<<= 12  
7. a += b  
8. d ^= a  
9. d <<<= 8  
10. c += d  
11. b ^= c  
12. b <<<= 7  
The function should output the modified values of a, b, c, and d after processing.
