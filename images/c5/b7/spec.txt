

You are tasked with designing a verilog module for a 2-to-1 multiplexer. The module should have two inputs, `A` and `B`, and one output, `Y`. Additionally, there should be a select input, `S`, which determines which input is selected. If `S` is 0, then `A` is selected and `B` is ignored. If `S` is 1, then `B` is selected and `A` is ignored. 

Your module should be named `two_to_one_mux` and should have the following ports:
- `A` (input): a 1-bit input signal
- `B` (input): a 1-bit input signal
- `S` (input): a 1-bit select signal
- `Y` (output): a 1-bit output signal
