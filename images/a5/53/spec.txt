Design a 2-to-1 multiplexer that selects between two 32-bit inputs, `a` and `b`, based on the control signal `MemtoRegSel`. When `MemtoRegSel` is 0, the output `Result` will be assigned the value of `a`; when `MemtoRegSel` is 1, the output will take the value of `b`. The implementation ensures that `Result` reflects the selection promptly through continuous monitoring of the control signal.
module top_module( input [31:0] a,
							 input [31:0] b,
							 input MemtoRegSel,
							 output [31:0] Result
							 );
