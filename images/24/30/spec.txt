Design a packet filtering module that checks the validity of a packet based on predefined rules. The module should have the following inputs: `src_ip` (source IP address), `dst_ip` (destination IP address), and `protocol` (protocol type, e.g., TCP, UDP). The output should be `permit` (1 if the packet is allowed, 0 otherwise). The rules are as follows:
1. Permit packets from source IP "192.168.1.1" to any destination IP if the protocol is TCP.
2. Permit packets to destination IP "10.0.0.5" from any source IP if the protocol is UDP.
3. Deny all other packets.
