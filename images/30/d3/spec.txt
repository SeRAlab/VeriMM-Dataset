
Design a SATA controller state machine that implements a simple command processing flow. The state machine should have the following states: IDLE, COMMAND_RECEIVE, DATA_TRANSFER, and COMMAND_COMPLETE. The input to the state machine should be a command signal (`cmd`), and it should advance to the next state based on the current state and the command received. The output should indicate the current state and whether the command is complete (`cmd_done`).
