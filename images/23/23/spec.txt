Design a current sensor circuit that takes a 3-bit binary input representing a current level and produces a 2-bit output indicating the current state. The output should be as follows:  
- Output '00' for a current level of 0 to 2.  
- Output '01' for a current level of 3 to 5.  
- Output '10' for a current level of 6 to 7.  
- Output '11' for a current level of 8 to 10.  
If the input exceeds this range, the output should be '11' (indicating an overflow condition).
