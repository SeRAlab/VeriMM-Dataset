A state machine that controls a simple elevator system with three states: Moving Up, Moving Down, and Idle. The elevator receives two inputs: a request to move up and a request to move down. The elevator should transition between states based on these inputs. If moving up is requested, it should go to the Moving Up state; if moving down is requested, it should go to the Moving Down state. If neither is requested, it should remain in the Idle state. The state of the elevator should be indicated by a 2-bit output.
