Develop a serial data transmitter module that operates under a clock signal and resets upon a reset input. The module utilizes enable signals for both baud timing and data transfer. It manages a 10-bit shift register to serially send an 8-bit input data along with a start and stop bit, where `txd` outputs the least significant bit of the shift register for transmission. The transmitter also includes a busy flag, `t_busy`, to indicate when data is being transmitted and a transmit buffer ready signal, `tbr`, which indicates when the module is not busy. The design incorporates state handling for timing and data loading during transmission.
module top_module(input clk, input rst,input baud_t_enable, input data_t_enable, input [7:0]data, output txd, output tbr);
