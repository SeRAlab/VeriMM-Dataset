Design a current sensor that takes a 5-bit binary input representing the current level and outputs a 3-bit binary value indicating the status. The status output will be defined as follows: 
- If the input current level is between 0 and 10 (inclusive), the output should be '000'.
- If the input current level is between 11 and 20 (inclusive), the output should be '001'.
- If the input current level is between 21 and 30 (inclusive), the output should be '010'.
- If the input current level is greater than 30, the output should be '011'.
The input current is represented as a 5-bit number (0-31).
