
Create a CRC (Cyclic Redundancy Check) module that takes an input data stream of 8 bits and computes a 4-bit CRC value based on a given polynomial (for example, x^4 + x^3 + x^2 + 1). The module should have an enable signal to start the CRC computation and a reset signal to initialize the circuit. The CRC value should be ready after all input bits are processed.
