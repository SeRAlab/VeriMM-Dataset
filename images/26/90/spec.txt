
Design a simple PCIe endpoint state machine that transitions between three states: IDLE, TRANSMIT, and RECEIVE. The machine should transition to TRANSMIT when a 'start_tx' signal is high, move to IDLE when 'reset' is high, and switch to RECEIVE when 'start_rx' is high. The outputs should indicate the current state as 2-bit binary values (00 for IDLE, 01 for TRANSMIT, 10 for RECEIVE).
