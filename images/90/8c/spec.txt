Design a circuit that computes the parity bit for an 8-bit input data stream. The module captures incoming data on each clock cycle, shifts the previous data into a register, and accumulates the sum of the shifted data. It then evaluates the sum to determine the parity; if the total number of set bits is odd, the parity output is set to HIGH, otherwise, it remains LOW.
module top_module(
  input clk,
  input [7:0] data_in,
  output reg parity
);
