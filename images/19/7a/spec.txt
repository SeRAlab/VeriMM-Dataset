Design a Verilog module for a flash memory cell that can be programmed (set to 1), erased (set to 0), and read (output current state). The memory cell should have three inputs: `program`, `erase`, and `read`, alongside a clock input `clk` that triggers state changes. The output should be a single bit representing the stored value of the memory cell. The cell should only allow programming and erasing on the rising edge of the clock, while reading the value should be combinationally available whenever the `read` signal is high.
