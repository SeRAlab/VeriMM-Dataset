Design a 3-bit up/down counter with asynchronous reset functionality. The counter increments when the UP_DOWN input is high and decrements when it is low, while the output Q holds the current count value. Upon receiving a reset signal (RST), the counter resets to zero. The internal registers maintain the previous states of the counter to facilitate the counting operation based on the clock signal.
module top_module(
    input RST,
    input UP_DOWN,
    input clk,              // Added clk input
    output reg [2:0] Q
);
