
Design a LIFO (Last In First Out) stack using Verilog. The stack should support the following operations:
1. Push: Add an item to the top of the stack.
2. Pop: Remove the top item from the stack.
3. Peek: Retrieve the top item without removing it.
4. IsEmpty: Check if the stack is empty.
The stack should have a fixed size defined as a parameter and should include necessary signals for control and data.
