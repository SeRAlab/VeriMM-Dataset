Design a Verilog module that implements a simple Recurrent Neural Network (RNN) cell for inference. The RNN cell should accept an input vector and a hidden state from the previous time step, and output the new hidden state. Assume the input and hidden state are fixed-size 4-bit vectors, and use a simple activation function (e.g., a basic threshold function) for the output. Provide the necessary state update equations and ensure the state is updated on each clock cycle.
