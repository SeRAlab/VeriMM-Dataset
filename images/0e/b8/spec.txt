Design a digital phase shifter that takes a 4-bit input phase control signal and generates a 4-bit output phase shifted signal. The phase shifting should occur based on a clock signal, with the output updating its value on the rising edge of the clock. The phase control signal will determine how much the output signal is shifted. The output should cycle between the inputs based on the phase control value. Implement a simple phase shifter that shifts the input signal by the phase control value.
