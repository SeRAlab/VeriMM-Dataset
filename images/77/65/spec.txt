Write a Verilog module that outputs the 8-bit AND result of two 8-bit inputs a and b when the enable signal is high. The output and_result should be reset to 0 when the reset signal is high.

module and_module (
    input [7:0] a,
    input [7:0] b,
    input enable,
    input reset,
    output reg [7:0] and_result);
