Design a 3-bit up/down counter that increments or decrements its count based on a control signal. When the reset signal is activated, the counter resets to zero. On the rising edge of the clock, if the control signal is high, the counter increments; if the control signal is low, the counter decrements.
module top_module(
    input clk,
    input reset,
    input control,
    output reg [2:0] count
);
