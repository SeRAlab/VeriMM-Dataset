
Design a 1-bit DRAM cell in Verilog that can store a single bit of data. The DRAM cell should have the following inputs and outputs:
- `data_in`: Input data to store (1 bit)
- `write_enable`: When high, the data is written to the cell
- `read_enable`: When high, the data is output to `data_out`
- `data_out`: The output data (1 bit)
