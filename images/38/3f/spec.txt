
Design a simple EEPROM cell that can store one bit of data. The EEPROM cell should have the following inputs:
- `data_in`: The input data to be written to the cell (1 bit).
- `write_enable`: A control signal that enables writing to the cell (1 bit).
- `read_enable`: A control signal that enables reading from the cell (1 bit).
The output should be `data_out`, which reflects the stored data when `read_enable` is high. If `write_enable` is high, `data_in` should be written to the cell.
