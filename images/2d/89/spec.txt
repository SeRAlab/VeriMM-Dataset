Design a Verilog module that implements a simple Bluetooth state machine with the following states: IDLE, CONNECTING, CONNECTED, and DISCONNECTED. The state transitions are as follows:  
- From IDLE to CONNECTING on input signal `start`.  
- From CONNECTING to CONNECTED on input signal `connected`.  
- From CONNECTED to DISCONNECTED on input signal `disconnect`.  
- From DISCONNECTED to IDLE on input signal `reset`.  
The module should output the current state as a 2-bit binary value (00 for IDLE, 01 for CONNECTING, 10 for CONNECTED, 11 for DISCONNECTED).  
The clock is positive edge triggered and an active-high reset signal initializes the state machine to IDLE.
