Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a constant voltage driver. 
A constant voltage driver is a type of digital circuit that generates a constant voltage output signal. The input to the circuit is a control signal, and the output is a voltage signal that remains constant regardless of changes in the control signal.
Your module should have the following inputs and outputs:

Inputs: a control signal (ctrl)
Outputs: a constant voltage signal (vout)

Your module should implement the following functionality:

The output signal should be a constant voltage signal that remains constant regardless of changes in the control signal.
The output signal voltage level should be programmable using a parameter (voltage_level)
To implement the constant voltage driver, you should use Verilog code to define the output as a constant voltage signal that depends on the voltage level parameter. 
You should then use the control signal as an enable signal to enable or disable the output signal.
