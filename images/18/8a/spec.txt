Design an interrupt controller that manages multiple interrupt requests. The controller should have inputs for multiple interrupt signals (irq[3:0]) and a clock signal. It should output a single interrupt request (interrupt) and a 2-bit interrupt vector (irq_vector) that indicates which interrupt is being serviced. The controller should prioritize interrupts based on their order (irq[0] has the highest priority). When an interrupt occurs, the controller should acknowledge it and clear the interrupt signal after being serviced.
