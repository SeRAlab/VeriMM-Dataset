Design a parameterized edge-triggered register (known as an enabled flip-flop) that captures and outputs a multi-bit signal. The module allows for a control signal (`oe_e1`) to enable or disable the output of the stored data (`q`). Each bit of the input (`a`) is latched on a rising clock edge, and the corresponding output (`q`) reflects either the captured value or an unknown state (1'bx) based on the output enable signal. The design can be scaled to any specified width, facilitating the implementation of registers of varying sizes.
