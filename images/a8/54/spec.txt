Design a digit display controller for a 7-segment display. The module utilizes a clock signal at 400Hz to cycle through four digits, controlling which digit is currently active via a 4-bit select signal (sm_wei). For each active digit, a corresponding 4-bit value from the 16-bit data input is taken and converted into an 8-bit output (sm_duan) that represents the segment encoding needed to light up the desired segments of the 7-segment display. This design effectively multiplexes the display of up to four hexadecimal values, ensuring that only one digit is illuminated at any time, while the rest remain off.
