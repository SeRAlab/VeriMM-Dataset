Design an SD card interface controller that takes a 4-bit command input and produces a 4-bit response output. The controller should respond to specific commands: 
- Command 0001: Response 0001 (Card ready)
- Command 0010: Response 0010 (Card busy)
- Command 0011: Response 0011 (Data read)
- Command 0100: Response 0100 (Data write)
For any other command, the response should be 0000 (Invalid command).
