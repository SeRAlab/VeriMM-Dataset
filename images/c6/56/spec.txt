

You have been tasked with designing a module that takes a 4-bit input and outputs the binary equivalent of the input in reverse order. For example, if the input is 0101, the output should be 1010.

Design a verilog module that takes a 4-bit input (in binary) and outputs the reverse order of the input (in binary). You should use a combinational logic approach to solve this problem.

You should name your module "reverse_binary" and it should have the following ports:
- input [3:0] in: a 4-bit binary input
- output [3:0] out: a 4-bit binary output
