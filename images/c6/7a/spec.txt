

You are tasked with designing a module in Verilog that implements a simple logic gate. The module should have three inputs and one output. The three inputs are A1, A2, and B1, and the output is X. Your module should be named `logic_gate`.

The logic gate should operate as follows: if either A1 or A2 is high and B1 is low, then X should be high. Otherwise, X should be low.

You should use the following template for your module:

```
module logic_gate (
    // inputs
    input A1,
    input A2,
    input B1,

    // output
    output X
);

    // your code here

endmodule
```

Your task is to fill in the `// your code here` section with Verilog code that implements the logic gate described above. Your code should be no longer than 200 lines.
