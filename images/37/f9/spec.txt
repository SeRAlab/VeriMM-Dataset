Design a simple interrupt controller. The controller has 3 interrupt request (IRQ) inputs and a single interrupt acknowledge (ACK) output. The logic should prioritize the IRQ signals such that the highest priority interrupt request is acknowledged first. The priority order is IRQ0 > IRQ1 > IRQ2. The controller should respond to the IRQ signals on the rising edge of a clock signal. If multiple IRQs are asserted at the same time, the one with the highest priority should be acknowledged.
