

You are tasked with designing a verilog module that takes in a 4-bit input, and outputs a 2-bit output. The output bits should be the result of the following operation: 

- If the most significant bit of the input is 1, output 01
- If the most significant bit of the input is 0, output 10

You should use the following template as a starting point:

```
module bit_manipulation (
    input  wire [3:0] I,
    output wire [1:0] O
);

    // Your code here

endmodule
```
