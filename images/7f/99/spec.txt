Design a 64-bit shifter module that performs left shifting based on a 2-bit selector input called "factor." The module takes a 64-bit input A and generates a 64-bit output B. Depending on the value of the "factor," the output B will be either a direct copy of A (when factor is 00), or A will be shifted left by 4, 8, or 12 bits with zero-padding added to the lower-order bits for factor values 01, 10, and 11, respectively. This functionality allows for variable left shifting with different shift amounts controlled by the factor input.
