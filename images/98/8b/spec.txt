Design a four-bit adder that computes the sum of two four-bit binary numbers, A and B. The output, S, represents the sum, while Cout indicates a carry-out condition from the most significant bit. The module includes a reset input, Rst; when Rst is high, both the sum S and carry-out Cout are set to zero, otherwise, the sum is calculated, and the carry-out is derived from the bit-wise addition of the input bits.
module top_module(
    input [3:0] A, B,
    input Rst,
    output reg [3:0] S,
    output reg Cout
);
