Design a Verilog module for a 4-bit priority encoder. The module should have 4 input lines and produce a 2-bit binary output along with a valid signal indicating whether any input is active.

Module name:
    priority_encoder_4bit

Input ports:
    in: 4-bit input lines.

Output ports:
    out: 2-bit binary output.
    valid: Valid signal indicating whether any input is active.

Implementation:
The encoder should give priority to the highest-order bit that is set to 1. If any input line is active (1), the valid signal is set to 1, otherwise it is set to 0.
