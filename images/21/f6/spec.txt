
Design a simple Automatic Repeat reQuest (ARQ) error correction protocol in Verilog that includes a sender and receiver. The sender will send a data bit and a corresponding parity bit to the receiver. The receiver will check the parity and send an acknowledgment (ACK) back to the sender. If the parity is incorrect, the receiver will send a negative acknowledgment (NACK), prompting the sender to resend the data.
