Design a Verilog module that implements a divide-by-8 circuit. The module should take a clock signal and a reset signal as inputs, and an 8-bit input value. The output should be the input value divided by 8, using a state machine approach. The division should be performed on the rising edge of the clock, and the output should be valid on the next clock cycle after the division is performed. The module should also handle the reset condition to initialize the output.
