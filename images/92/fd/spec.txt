Design a D flip-flop with asynchronous set and reset inputs. The module captures the value of the input D on the rising edge of the clock (CLK). If the reset (R) is asserted, the output Q is set to LOW. If the set (S) is asserted, the output Q is set to HIGH. If neither set nor reset is active, the output Q follows the value of D, effectively storing it on the clock edge.
