Design a Parallel-in Parallel-out (PIPO) shift register that allows for 5-bit parallel input and 5-bit parallel output. The register should have a clock input, a load input to control when data is loaded, and an output to provide the stored data. When the load signal is high, the register should load the input data on the rising edge of the clock. When the load signal is low, the register should hold the data. The output is always available as long as the clock is functioning.
