Write a Verilog module to implement a 16-bit up/down counter with synchronous reset, enable, and direction control. The counter should increment or decrement based on the direction signal (1 for up, 0 for down). The reset signal should set the counter to 16'b0000000000000000.

module up_down_counter
(
    input clk,
    input reset,
    input enable,
    input direction,
    output reg [15:0] count
);
