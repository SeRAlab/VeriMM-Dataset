Design a countdown counter that begins counting from a preset value of 6 (binary 110) when the start signal is asserted. The counter decrements its value on each rising edge of the clock signal. Once the counter reaches zero, it sets the done output high to indicate the completion of the countdown. The done signal remains low while the counter is still counting down.
module top_module(
    input start,
	input clk,
    output reg done,
    output reg [2:0] cnt
    );
