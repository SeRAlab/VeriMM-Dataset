Design a GPIO controller that allows users to read and write to a set of GPIO pins. The controller should have the following features:
1. A data register (GPIO_DATA) that holds the current state of the GPIO pins. 
2. A direction register (GPIO_DIR) that determines the direction of each pin (input or output).
3. A clock input (clk) and reset input (rst).
4. A read function that outputs the state of the GPIO pins when they are configured as inputs.
5. A write function that updates the GPIO_DATA when the GPIO pins are configured as outputs.
