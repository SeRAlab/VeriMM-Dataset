

You are tasked with designing a Verilog module that takes in a 32-bit input signal, `in`, and outputs a 16-bit signal, `out`, that is the result of truncating the input signal to its least significant 16 bits.

Design a Verilog module that performs this operation, and name it `trunc`.

Your module should have the following ports:
- `input [31:0] in`: the 32-bit input signal
- `output [15:0] out`: the 16-bit output signal
