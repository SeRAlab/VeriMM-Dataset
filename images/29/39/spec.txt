Design a reset controller that manages a synchronous reset for a finite state machine (FSM). The reset controller should have a reset signal (reset_n) and a clock signal (clk). When reset_n is low, the output should be set to a predefined state (e.g., 0). When reset_n is high, the output should follow the clock signal and maintain its state unless a transition occurs. The controller should also have a state output that indicates the current state of the FSM.
