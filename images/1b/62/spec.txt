A Parallel-in Serial-out (PISO) shift register allows data to be loaded in parallel and then shifted out serially. Create a PISO shift register with a 5-bit data input, a clock input, a load signal, and a serial output. The load signal should control when to load the data into the register. On the rising edge of the clock, if the load signal is active, the data should be loaded; otherwise, the data should shift out serially.
