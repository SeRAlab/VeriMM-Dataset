Design a D flip-flop with clock enable (ce) and synchronous reset functionality. On the rising edge of the clock (Clk), if the reset signal is asserted, the output (Q) is set to LOW. If reset is not active and the clock enable (ce) is HIGH, the output (Q) captures the value of input D. Otherwise, Q retains its current value, effectively allowing controlled data storage based on the clock and enable signals.
module top_module(
    input D,
    input Clk,
    input reset,
    input ce,
    output reg Q
    );
