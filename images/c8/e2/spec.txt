

You have been tasked with designing a module that takes in a 4-bit input, and outputs the binary equivalent of the input in reverse order. For example, if the input is 0101, the output should be 1010. You are provided with a template module that contains an empty `reverse` module, and your task is to complete the `reverse` module using Verilog.

The module has the following inputs and outputs:

- `input [3:0] in`: the 4-bit input
- `output [3:0] out`: the 4-bit output

You may use any Verilog constructs to complete the `reverse` module.
