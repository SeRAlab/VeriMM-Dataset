Design a circuit that performs the addition of two 4-bit unsigned values and generates a 5-bit output. The module takes two 4-bit inputs, x and y, adds them using a function, and outputs the result in a 5-bit register, z. The output z can accommodate the carry bit that may result from the addition of the two inputs. This effectively allows for addition of values ranging from 0 to 15 for each input, producing a maximum output range of 0 to 30.
module top_module(
    input [3:0] x,y,
    output reg [4:0] z
    );
