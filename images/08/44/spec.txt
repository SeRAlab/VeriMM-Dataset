
Design a 2nd-order Infinite Impulse Response (IIR) filter that takes a 16-bit signed input sample and outputs a 16-bit signed output sample. The filter coefficients are defined as follows:
- a[0] = 1
- a[1] = -0.5
- a[2] = 0.25
- b[0] = 1
- b[1] = 0.5
- b[2] = 0.25

The filter should maintain an internal state for two previous output samples and two previous input samples.
