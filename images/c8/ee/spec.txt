

You have been tasked with designing a verilog module for a 2-to-1 multiplexer (MUX) that takes two inputs and selects one of them based on a select signal. The module should have the following inputs and outputs:
- Input A (1-bit)
- Input B (1-bit)
- Select (1-bit)
- Output X (1-bit)

Use the following code snippet as a base for your module:

```
module mux_2to1 (
    A,
    B,
    Select,
    X
);

    input A;
    input B;
    input Select;
    output X;

    // Your code here

endmodule
```

Your task is to complete the module by implementing the logic for the MUX. When the select signal is 0, the output X should be equal to input A. When the select signal is 1, the output X should be equal to input B.
