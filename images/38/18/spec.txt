Design a CRC (Cyclic Redundancy Check) generator using a linear feedback shift register (LFSR). Your CRC generator should take an input data stream of 8 bits and produce a 4-bit CRC based on the polynomial x^4 + x + 1 (binary 10011). The generator should shift the input data into the LFSR and perform the necessary XOR operations to update the CRC each time a new bit is input. The final CRC value should be output after all bits have been processed.
