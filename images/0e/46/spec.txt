
Design a hardware module in Verilog that implements a simple gradient descent optimizer. The module should take an input value representing the current position (x) and a learning rate (lr). It should calculate the new position using the formula: 
new_x = x - lr * gradient. 
For simplicity, use a fixed gradient value (e.g., gradient = 1). The module should store the current position and update it on each clock cycle when a valid input signal is asserted.
