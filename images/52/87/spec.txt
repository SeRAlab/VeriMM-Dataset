Design a one-bit wide, edge-triggered 2-to-1 multiplexer controlled by a clock signal. When the select signal (sel) is LOW, the output (out) forwards the value of input signal in1; when sel is HIGH, out takes the value of input signal in2. This design allows for synchronous control of the output based on the clock and the select signal.
module top_module(
    input wire clk,   // clock signal
    input wire sel,   // select signal
    input wire in1,   // input signal 1
    input wire in2,   // input signal 2
    output reg out    // output signal changed to reg
);
