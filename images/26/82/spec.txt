
Design a simple branch predictor using a 2-bit saturating counter. The predictor should take a 2-bit input representing the previous state (00, 01, 10, 11) and output the next predicted state based on the input. The states represent:
00 - Strongly Not Taken
01 - Weakly Not Taken
10 - Weakly Taken
11 - Strongly Taken

The transition rules are as follows:
- From 00: Next state is 00 if 'Not Taken', 01 if 'Taken'
- From 01: Next state is 00 if 'Not Taken', 10 if 'Taken'
- From 10: Next state is 01 if 'Not Taken', 11 if 'Taken'
- From 11: Next state is 10 if 'Not Taken', 11 if 'Taken'
