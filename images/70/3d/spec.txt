Design a priority encoder that takes four single-bit inputs (A, B, C, D) and produces a two-bit output (Y) representing the index of the highest priority input that is high, along with a valid output signal (V). The priority is given in the order A > B > C > D, such that when A is high, Y is set to 00, when B is high, Y is set to 01, when C is high, Y is set to 10, and when D is high, Y is set to 11. If none of the inputs are high, Y defaults to 00 and the valid output V is set to 0, indicating no valid input was detected.
module top_module(
    input A,
    input B,
    input C,
    input D,
    output reg [1:0] Y,
    output reg V
);
