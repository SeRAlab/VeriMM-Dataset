Design a JK flip-flop using Verilog. The JK flip-flop has two inputs (J and K), one clock input (clk), and two outputs (Q and Q_not). The flip-flop should behave according to the following truth table:
- If J = 0 and K = 0, Q remains unchanged.
- If J = 0 and K = 1, Q resets to 0.
- If J = 1 and K = 0, Q sets to 1.
- If J = 1 and K = 1, Q toggles its state.
The flip-flop should be edge-triggered on the rising edge of the clock.
