Design a one-bit wide, 4-to-1 multiplexer that selects one of four input signals (A, B, C, D) based on a 2-bit selection input (S). The output (Z) will correspond to the input signal indicated by the value of S, with S=00 yielding A, S=01 yielding B, S=10 yielding C, and S=11 yielding D.
module top_module(
    input [3:0] A, B, C, D,
    input [1:0] S,
    output reg Z
);
