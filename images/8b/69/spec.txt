Design a synchronous 8-bit up-counter with load capability. The counter can be reset to zero, load a specified value from the input data when the load signal is asserted, and increment its value on each positive clock edge when the enable signal is high. The reset signal takes precedence, initializing the counter to zero regardless of the other inputs.
