Design a simple FIFO (First-In-First-Out) queue with a depth of 8. The FIFO should support enqueue and dequeue operations. The enqueue operation will add an item to the queue if it is not full, and the dequeue operation will remove an item from the queue if it is not empty. The design should have inputs for data to be enqueued, a clock signal, and control signals for enqueue and dequeue. The output should be the current data at the front of the queue and a flag indicating if the queue is empty.
