Design a SPI master controller in Verilog that handles the transmission of 8 bits of data to a slave device. The SPI master should have a clock output, a data output, and a chip select output. It must also include a state machine to manage the transmission process. The SPI master should assert the chip select signal when a transmission begins and deassert it when the transmission is complete. The master should be able to send data on the rising edge of the clock and should transmit data serially.
