

You are tasked with designing a Verilog module for a simple 4-bit adder. The module should have two 4-bit inputs, A and B, and a 4-bit output, C. The module should also have a control input, S, which determines whether the output should be the sum (S=0) or the difference (S=1) of the inputs. 

Write a Verilog module that implements this 4-bit adder with the following specifications:

- The module should be named "adder_4bit".
- The module should have the following ports:
  - A: a 4-bit input
  - B: a 4-bit input
  - S: a control input that determines whether the output should be the sum (S=0) or the difference (S=1) of the inputs
  - C: a 4-bit output
- The module should use only combinational logic (no flip-flops or other sequential elements).
- The module should synthesize to a circuit with a minimum number of logic gates.
