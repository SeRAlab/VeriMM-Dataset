Design a simple SD card interface controller that takes a 4-bit command input and produces a 4-bit response output. The controller should respond to specific commands: 
- Command 0b0001 should respond with 0b0010
- Command 0b0010 should respond with 0b0011
- Command 0b0011 should respond with 0b0100
- For any other command, the response should be 0b0000.
