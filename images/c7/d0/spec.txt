

You are tasked to design a module that will take in an 8-bit input signal and perform a specific operation on it. The operation is as follows: the first 4 bits of the input signal are to be inverted, and the last 4 bits are to be shifted to the left by 2 bits. The resulting 8-bit signal is then to be outputted.

Design a module named `signal_process` that will perform this operation. The input signal should be named `input_signal` and the output signal should be named `output_signal`.

You should assume that the input signal is a valid 8-bit signal, and that the output signal should also be an 8-bit signal.

Your module should be self-contained and should not require any external modules or libraries. Your module should be written in Verilog, and should be no more than 200 lines of code.
