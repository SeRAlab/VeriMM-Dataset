Design a 2-channel DMA (Direct Memory Access) controller that allows data transfer between memory and two peripherals without CPU intervention. The DMA controller should be able to manage two transfer requests, providing priority to one channel over another. The controller should include the following inputs: `request1`, `request2` (indicating if each channel has a data transfer request), `clk` (clock signal), `reset` (to reset the controller). The outputs should be `grant` (indicating which channel is granted access), `busy` (indicating if the DMA controller is currently busy), and a `data` output that represents the current data being transferred. The priority should be given to channel 1 over channel 2.
