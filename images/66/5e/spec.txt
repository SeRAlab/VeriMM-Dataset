Design a one-bit wide, 2-to-1 multiplexer that selects between two 8-bit input data lines, `data0` and `data1`. The selection is controlled by the `sel` input signal; when `sel` is 0, the output `bus1` will reflect `data0`, and when `sel` is 1, the output will reflect `data1`.
module top_module(
    input wire sel,
    input wire [7:0] data0,
    input wire [7:0] data1,
    output wire [7:0] bus1
    );
