It features asynchronous clear (`clrn`) and preset (`prn`) inputs: when `clrn` is low, the output `q` is reset to 0, and when `prn` is low, the output `q` is set to 1, regardless of the clock or enable state. This allows for flexible control of the register's output, making it suitable for various synchronous logic applications.
module top_module(
    input d,
    input clk,
    input ena,
    input clrn,
    input prn,
    output reg q
);
