Design a module for an asynchronous transmitter that serially transmits an 8-bit data frame at a specified baud rate. The transmitter uses a state machine to control the transmission process, which includes a start bit, 8 data bits, and two stop bits. The module takes as inputs the clock signal, a start signal for transmission, a baud ticking signal to synchronize the sending of bits, and the 8-bit data to be transmitted. It outputs the TxD line that carries the transmitted bits and a TxD_busy signal indicating when the transmitter is busy sending data. The design accommodates the reception of new data while transmission is ongoing, ensuring robust data handling and communication.
module top_module(clk, Baud1Tick, TxD_start, TxD_data, TxD, TxD_busy);
