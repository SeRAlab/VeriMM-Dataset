Design a circular shift register that is initialized with a predefined 32-bit constant value (plu). On each rising edge of the clock, it shifts the bits of the register left by one position, while the most significant bit circulates to the least significant bit position. The output provides the most significant bit of the current register value, effectively producing a pulse based on the shifted values. The register is reset asynchronously to the initial constant value when the reset signal is inactive (low).
module top_module(
	input i_clk,    
	input i_rst_n,
	output o_pluse
);
