Design a 16-bit SRAM cell with read and write functionality. The SRAM cell should have the following inputs: a 16-bit data input (data_in), a 16-bit data output (data_out), a write enable signal (we), an address signal (addr) (4 bits for addressing 16 cells), and a clock signal (clk). The data should be written to the addressed cell when we is high on the rising edge of the clock. The data from the addressed cell should be output on data_out when we is low.
