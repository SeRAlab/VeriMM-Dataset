Design a logic circuit that outputs a HIGH signal (1) based on specific combinations of three input signals (A1, A2, A3) and a two-bit input (B). The output Y is HIGH if A1 is HIGH, or if A2 is HIGH while A1 is LOW, or if A3 is HIGH while both A1 and A2 are LOW. If none of these conditions are met, Y will instead output the logical OR of the two bits in B; hence, Y will also be HIGH if at least one of the bits in B is 1.
module top_module(
    input  A1,
    input  A2,
    input  A3,
    input  [1:0] B,
    output Y
);
