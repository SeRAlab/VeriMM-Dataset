Design a synchronous D flip-flop with asynchronous reset and set functionality. The flip-flop captures the value of the input 'd' on the rising edge of the clock 'clk' and outputs this value through 'q'. It will reset 'q' to LOW when the active-low reset 'rst_n' is asserted, or set 'q' to HIGH when the set signal is active. The internal state of the flip-flop is managed by a specific base cell, with additional provisions for controlling set and clear signals. This module can be used in sequential logic circuits requiring controlled data storage and state management.

    input clk,
    input d,
