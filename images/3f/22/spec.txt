Design a simple Ethernet MAC controller state machine that manages the state transitions for sending and receiving frames. The state machine should have three states: IDLE, SENDING, and RECEIVING. The transitions are as follows: from IDLE, it can go to SENDING or RECEIVING based on control signals. In SENDING state, it stays there until the send operation is complete, transitioning back to IDLE. In RECEIVING state, it stays there until the receive operation is complete, transitioning back to IDLE.
