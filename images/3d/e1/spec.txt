Design a Run-Length Encoding (RLE) circuit that takes in a stream of binary data (1-bit wide) for a defined length (e.g., 8 bits) and outputs the run-length encoded data. The RLE should encode runs of consecutive bits and output the length of the run followed by the bit value. The output format should be a pair of values: [length, bit]. The state machine should handle the transitions between counting runs of '0's and '1's.
