
Design a GPIO controller with the following functionality: 
1. It has 8 GPIO pins (GPIO[7:0]) that can be configured as input or output.
2. It has a control signal (ctrl) for configuring the pins.
3. If ctrl is high, the pins are configured as output and can be driven by an output data signal (data_out). 
4. If ctrl is low, the pins are configured as input and their status can be read through a data input signal (data_in).
5. The controller should have a reset signal (rst) that initializes the GPIO pins to low.
