Design a basic calculator module that performs four arithmetic operations: addition, subtraction, multiplication, and division, based on a two-bit operation code (op) input. The module takes two 8-bit inputs (a and b) and outputs an 8-bit result along with a validity signal to indicate when a new result is available, synchronizing with the clock (clk) and active low reset (rst_n). When reset is deactivated, the module processes the selected operation and stores the output, asserting the valid signal to inform that the result can be read.
module top_module(clk, rst_n, op, a, b, result, valid);
