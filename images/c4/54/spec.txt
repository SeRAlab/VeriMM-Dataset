

You are tasked with designing a verilog module that implements a binary to gray code converter. The module should have the following ports:

- `input wire [7:0] bin`: 8-bit binary input
- `output wire [7:0] gray`: 8-bit gray code output

The module should convert the binary input to its corresponding gray code and output it through the `gray` port. The module should be synchronous and operate on the positive edge of the clock signal `clk`.
