
Design a simple PCIe endpoint controller that has a 2-bit state machine. The states will be IDLE, REQUEST, and ACK. The state transitions are as follows:
- From IDLE to REQUEST on input signal `start` being high.
- From REQUEST to ACK on input signal `ack` being high.
- From ACK back to IDLE after a delay of one clock cycle.
The output will indicate the current state of the state machine.
