Design a circular FIFO (First In, First Out) buffer capable of storing data with a width of 32 bits and a capacity of 16 entries. The module has clock and reset inputs, along with push and pull control signals to manage data insertion and removal. When the push signal is activated and the buffer is not full, incoming data is written to the current "head" position, which updates to the next position. Conversely, when the pull signal is active and the buffer is not empty, data is read from the current "tail" position, which then advances to the next position. The module also outputs flags indicating if the buffer is full or empty.
module top_module(
    input clk_i,
    input rst_i,
    input [g_width-1:0] data_i,
    input push_i,
    input pull_i,
    output [g_width-1:0] data_o,
    output full_o,
    output empty_o
);
