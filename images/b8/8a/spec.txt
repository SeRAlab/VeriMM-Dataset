Develop a 4-bit binary counter that increments its count on each positive clock edge when enabled, and resets to zero when the reset signal is high. The counter holds its current value when not enabled. This design allows for controlled counting based on the `enable` signal, making it suitable for applications requiring adjustable counting sequences.
module top_module(
    input            clk,
    input            reset,
    input            enable,
    output reg [3:0] count
  );
