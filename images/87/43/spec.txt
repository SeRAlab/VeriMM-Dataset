Implement a 3-stage shift register that operates on the rising edge of the clock. When the reset signal is asserted, all output stages are cleared to LOW. When the enable signal is active, the current input data (d) is shifted through three stages of storage, with the output (q) reflecting the value held by the last stage (q2). This design allows for serial input data to be shifted through the register, enabling applications in data buffering and timing adjustments.
module top_module(
  input clk,
  input reset,
  input enable,
  input d,
  output reg q
);
