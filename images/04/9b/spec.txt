Design a 4-bit CRC (Cyclic Redundancy Check) generator. The generator should take a 4-bit data input and produce a 2-bit CRC output. The CRC polynomial used for this example is x^2 + x + 1 (which corresponds to the binary 111). The circuit should have a clock and reset signal. On the rising edge of the clock, if reset is high, the CRC output should be cleared. Otherwise, compute the CRC for the input data.
