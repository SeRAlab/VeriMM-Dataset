Design a 4-bit barrel shifter that allows for variable shifting of input data based on a 2-bit shift amount. The module accepts a 4-bit input and can shift the bits left or right, with the shifting controlled by the `shift_amount` signal. Specifically, `shift_amount` values determine how many positions the bits are shifted, with `00` performing no shift, `01` shifting by one position, `10` shifting by two positions, and `11` shifting by three positions. The output `result` reflects the properly shifted version of the input data after processing through two stages of shifting logic.
module top_module(
    input [3:0] data,
    input [1:0] shift_amount,
    output reg [3:0] result
);
