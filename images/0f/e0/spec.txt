Design an 8-bit DRAM cell that can store a single bit of data for each of the 8 cells. The DRAM cell should have a write enable signal (WE), a read enable signal (RE), and an address input to select which cell to read from or write to. When WE is high, the data should be written to the specified address. When RE is high, the data should be read from the specified address. If both signals are low, the cell should retain its current state. The output should be the data stored in the selected cell.
