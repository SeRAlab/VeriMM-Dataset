Design a synchronous 4-bit up counter that increments on the rising edge of the input clock signal (div_clk) when the 'contando' signal is high. The counter resets to zero when the 'rst' signal is asserted. It compares its value to the specified 'time_value'; when the counter reaches this value, it resets to zero and asserts the 'terminado' output signal to indicate completion. If 'contando' is low, the 'terminado' output remains deasserted, regardless of the counter's value. This module is useful for timing applications where an event needs to be triggered after a set number of clock cycles.
