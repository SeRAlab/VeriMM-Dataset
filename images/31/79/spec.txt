Design an 8-bit DRAM cell with read and write capabilities. The DRAM cell should have a data input (D), data output (Q), a write enable (WE), and a clock (CLK). When WE is high, the data on D should be written to the cell at the rising edge of CLK. When WE is low, the current stored value should be output to Q. The DRAM cell should be designed to hold one byte of data.
