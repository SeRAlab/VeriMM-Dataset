
Create a Verilog module for a thermal sensor calibration system. The system should utilize a 4-bit input representing the raw temperature data from a thermal sensor. The module should have a calibration register that stores the calibrated temperature value. The calibration process involves shifting the raw data left by one position (for scaling purposes) and adding a constant offset (which can be parameterized). The module should have a clock input, a reset input, and an enable signal to start the calibration process. When enabled, the calibrated value should be updated on the next clock edge.
