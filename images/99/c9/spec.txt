Design a four-input, one-bit wide multiplexer. The module selects one of the four input lines (in[0] to in[3]) based on the two-bit selector signal (sel). The output reflects the value of the selected input, with each combination of sel determining which input is routed to the output. If an invalid sel value is provided, the output will be undefined.
module top_module(
    input [3:0] in,
    input [1:0] sel,
    output out
);
