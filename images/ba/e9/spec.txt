Design a synchronous memory module that outputs a 16-bit value based on the 5-bit address input. On each positive edge of the clock, the module updates its output by capturing the previous output value and fetching a new value from a predefined set of constants, indexed by the address. The constants are defined for addresses ranging from 0 to 31, with a default output of 0 for any address outside this range. This module acts like a simple lookup table (LUT) that can be used for applications where specific fixed values are required based on an index.
