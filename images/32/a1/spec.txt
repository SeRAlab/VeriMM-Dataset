
Design a 4-bit SRAM cell in Verilog. The SRAM cell should have inputs for data (4 bits), a write enable (we), and a read enable (re). When write enable is high, the data should be written to the SRAM cell. When read enable is high, the stored data should be available at the output. If both write and read are enabled simultaneously, prioritize write over read. Initialize the SRAM cell to 4'b0000 at reset.
