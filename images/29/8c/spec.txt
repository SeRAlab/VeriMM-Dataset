
Design a LIFO stack in Verilog with the following specifications:
- The stack should have a fixed depth of 4.
- It should support push and pop operations.
- The stack should have a `clk` and `reset` signal to operate.
- The stack should have an output that shows the current top element.
- When the stack is empty and a pop operation is attempted, it should provide an output indicating an underflow condition.
