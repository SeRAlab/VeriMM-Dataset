Design a 4-to-1 multiplexer that selects one of four input signals (i0, i1, i2, i3) based on two select lines (s0 and s1). module top_module(
    input s0,
    input s1,
    input i0,
    input i1,
    input i2,
    input i3,
    output reg d
    );
