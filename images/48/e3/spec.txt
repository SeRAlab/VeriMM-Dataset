Design a 3-to-1 multiplexer with an enable control signal. When the enable signal is asserted, the module selects one of the three inputs based on the binary value of the 3-bit input 'in'. The output corresponds to one of the inputs based on the case conditions, where inputs are mapped in a specific manner: for input values 0 to 2, the output is directly the corresponding input, while for input values from 3 to 5, the output cycles through inputs 0 to 2. If the enable signal is not active, the output is set to LOW.
module top_module(
    input [2:0] in,
    input enable,
    output reg out
);
