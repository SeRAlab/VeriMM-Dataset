Design a synchronous 64x32-bit Random Access Memory (RAM) module. It has a write enable input (wea) and address input (addra) to write data (dina) into the memory on the rising edge of the clock (clka). If the write enable is inactive, the module outputs the stored value at the specified address (addra) to douta, allowing for reading from the memory.
module top_module(
    input clka,
    input wea,
    input [6:0] addra,
    input [31:0] dina,
    output reg [31:0] douta
);
