Design a 5-to-32 decoder. The decoder takes a 5-bit binary input and activates one of the 32 output lines corresponding to the binary value of the input. The outputs are active high. For example, if the input is 00000, output line 0 should be activated (high), and for an input of 00001, output line 1 should be activated (high), and so forth up to an input of 11111, which should activate output line 31. All other outputs should be low.
