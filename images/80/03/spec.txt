Design a module to perform both addition and subtraction operations on 32-bit input operands. The module accepts two inputs, Data_X_i and Data_Y_i, which can be loaded into internal registers based on the control signals load_a_i and load_b_i. The operation to perform—either addition or subtraction—is determined by the input add_subt_i. It calculates the result using two's complement arithmetic for the subtraction case. The module outputs a 30-bit result (DMP_o and DmP_o), a zero flag to indicate if the result is zero, a real operation flag to signify if the operation was addition or subtraction, and a sign flag to indicate the sign of the final result. If reset is triggered, the internal registers are cleared.
