
Design a temperature monitoring system that uses a 4-bit binary input to represent temperature readings in degrees Celsius. The system should include a 3-bit output that represents an alarm signal. The alarm should trigger when the temperature exceeds a certain threshold (e.g., 10 degrees Celsius). When the alarm is triggered, the output should be set to '111'. Otherwise, it should be '000'. The system should also have a reset signal to set the output back to '000'.
