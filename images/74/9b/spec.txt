Implement a Serial-In Parallel-Out (SIPO) shift register that captures serial input data on each clock cycle and outputs the data in parallel format once the specified number of bits (N) has been collected. The design uses a clock and reset signal to manage the data shift and reset behavior; when reset, it clears the output. The internal register is shifted to the right with new bits coming in from the `in` input, and the output `outP` becomes valid when the entire N bits have been received, providing a parallel output of the captured data.
