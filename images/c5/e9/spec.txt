

You are tasked with designing a verilog module for a 4-bit binary to Gray code converter. The module should have a 4-bit binary input (B) and a 4-bit Gray code output (G). The Gray code output should be generated based on the following rules:
- The most significant bit (MSB) of the Gray code output should be the same as the MSB of the binary input.
- Each subsequent bit of the Gray code output should be the XOR of the corresponding bit of the binary input and the previous bit of the Gray code output.

Design the module and write the verilog code for it.
