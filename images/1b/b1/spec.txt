Design a 32-bit Linear Feedback Shift Register (LFSR) with a primitive polynomial to generate pseudo-random sequences. The LFSR should take a clock signal and a reset signal. When the reset signal is high, the LFSR should load an initial value. On each clock cycle, the LFSR should shift and generate a new bit based on the feedback from specific taps. The output should be the current state of the LFSR.
