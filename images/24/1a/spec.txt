
Design a 16-bit Digital-to-Analog Converter (DAC) controller that takes a 4-bit input representing a select line (from 0 to 15) and outputs a 16-bit analog value based on a predefined lookup table. The lookup table is defined as follows: for each selected input from 0 to 15, the output should be a specific 16-bit value. The output should be updated immediately whenever the input changes.
