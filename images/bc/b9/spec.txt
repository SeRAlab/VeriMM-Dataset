Design a 2-to-4 decoder that outputs a one-hot encoded signal based on the 2-bit select input when enabled. Additionally, it includes an invert feature that allows for inverted outputs of the active high signals. When the enable input is low, all outputs are set to low. When the enable input is high, the decoder activates one specific output line corresponding to the select input, while the extra functionality allows for inversion of this output pattern.
module top_module(
    input enable,
    input [1:0] select,
    input invert,
    output reg [7:0] out
);
