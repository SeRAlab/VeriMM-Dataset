Design a register file module for a digital system that allows reading and writing data to a set of registers. It features two read address inputs to fetch data from two different registers, a write address for updating a specified register, and a write data input to supply the data to be written. The module includes a control signal to enable writing (reg_write) and a reset signal (rst) to initialize or clear the registers. The outputs provide the data from the specified read addresses, enabling two simultaneous read operations.
module top_module(
	read_address_1, 
	read_address_2, 
	write_address, 
	write_data, 
	reg_write, 
	rst, 
	data_reg_1, 
	data_reg_2);
