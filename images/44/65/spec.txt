Implement the Verilog module based on the following description.
Design a Verilog module that implements a 10-bit binary down-counter with enable and synchronous reset. The counter should decrement on the rising edge of the clock if the "enable" signal is high. The counter should reset to its maximum value (1023) when the synchronous reset (sreset) is high. The counter value should be output to the "count" signal.

module top_module
(
    input clk,
    input sreset,
    input enable,
    output reg [9:0] count
);
