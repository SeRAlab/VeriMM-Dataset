
Design a Verilog module that implements a simplified JPEG-like block compression method. The module should take an 8x8 block of pixel values (8 bits each) as input and produce a compressed output signal. It should also have a control signal to start the compression process and a ready signal to indicate when the output is valid. You need to simulate the compression process using a simple reduction algorithm that sums the values in the block. The input and output should be valid only during the clock's positive edge.
