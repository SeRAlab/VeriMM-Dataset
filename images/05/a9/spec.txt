Design a data forwarding unit for a simple 5-stage pipeline. The unit should be able to forward data based on source and destination registers. It should accept two source register addresses (src1, src2) and one destination register address (dest) along with a valid signal. If the destination register address matches either source register address, the forwarding unit should output a forward signal indicating which source register should be forwarded to the destination. If there is no match, the output should indicate no forwarding.
