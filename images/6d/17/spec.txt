Design a 2-to-1 multiplexer for 2-bit wide inputs. The module takes two 2-bit inputs, inA and inB, and a selector signal. When the selector is 0, the output result will be equal to inA; when the selector is 1, the output will be inB. This allows for the selection of one of the two 2-bit inputs based on the value of the selector.
module top_module(
		input [1:0] inA, 
		input [1:0] inB,
		input selector,

		output reg [1:0] result
	);
