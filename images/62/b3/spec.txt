Design a set-reset (SR) flip-flop circuit with asynchronous reset functionality. When the reset (RST) signal is asserted, the output Q is set to LOW. On each rising edge of the clock (CLK), the flip-flop updates its output based on the state of the set (S) and reset (R) inputs. If both S and R are LOW, the output Q retains its current value. If R is HIGH and S is LOW, the output is set to LOW, and if S is HIGH and R is LOW, the output is set to HIGH. If both S and R are HIGH, the output remains unchanged, effectively making that condition invalid in typical use.
