Design a 16-register bank capable of reading and writing 16-bit data. The module outputs data from two specified registers based on a 4-bit address derived from an 8-bit input called `output_AB`. The `write` signal controls the write operation, allowing a 16-bit input (`data_in`) to be stored in a register designated by the `address` input, provided that the address is not zero. Initially, only register 0 is set to zero, while the other registers are uninitialized. The outputs are two 16-bit data buses, `data_out_A` and `data_out_B`, representing the contents of the registers accessed by higher and lower bits of `output_AB`, respectively.
