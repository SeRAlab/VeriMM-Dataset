Design a 4-to-1 multiplexer that selects one of four input lines (D0, D1, D2, D3) based on the values of the two select lines (S0 and S1). The output (Y) will reflect the value of the selected input; when S1 and S0 are both 0, Y will output D0, with subsequent combinations of the select lines choosing D1, D2, or D3 accordingly.
module top_module(
    input D0, D1, D2, D3,
    input S0, S1,
    output reg Y
);
