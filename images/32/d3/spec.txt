
Design a D flip-flop in Verilog that has the following features:
1. A positive edge-triggered clock input.
2. An asynchronous reset input that resets the output to 0 when activated.
3. An enable input that allows the flip-flop to store the input value (D) when high and hold the previous value when low.
4. The output (Q) should follow the input (D) only when the enable signal is high and the clock edge is detected.
