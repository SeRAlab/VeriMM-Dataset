Design a 16-bit SRAM cell that can store data. The SRAM cell should have two inputs: a 16-bit data input (data_in) and a write enable signal (we). When the write enable signal is high, the data input should be stored in the SRAM cell; when the write enable signal is low, the stored data should remain unchanged. The SRAM cell should have one output: a 16-bit data output (data_out) that reflects the stored data.
