Design a module that directly transfers a 3-bit input vector to a 3-bit output and also provides individual outputs for each bit of the input. The module outputs `outv` as a copy of the input `vec`, while `o0`, `o1`, and `o2` represent the least significant, middle, and most significant bits of `outv`, respectively.
module top_module( 
                    input wire [2:0]  vec,
                    output wire [2:0] outv,
                    output wire       o2,
                    output wire       o1,
                    output wire       o0  );
