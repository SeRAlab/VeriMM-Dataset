Design a circuit that functions as an 8-bit adder with overflow detection. When the enable signal (EN) is set to high, the module computes the sum of two 8-bit inputs, A and B, and checks for overflow conditions, signifying whether the addition resulted in an incorrect value. If EN is low, it holds the previous inputs for further processing. The output consists of an 8-bit sum and a single-bit overflow signal indicating any overflow in the addition operation.
module top_module(
  input [7:0] A,
  input [7:0] B,
  input EN,
  output reg [7:0] SUM,
  output reg OVF
);
