Design a 16-bit wide barrel shifter that performs either left or right logical shifting based on the control signal C. When C is 0, it shifts the input A left by the number of bits specified in the 4-bit input S. Conversely, when C is 1, it shifts A right by the same specified number of bits, producing the output B.
module top_module(
    input [15:0] A,
    input [3:0] S,
    input C,
    output reg [15:0] B
);
