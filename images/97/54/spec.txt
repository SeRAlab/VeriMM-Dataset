Design a 4-to-1 multiplexer that selects one of four 1-bit input signals (a, b, c, d) based on a 2-bit selection input (sel). The output reflects the value of the selected input according to the sel signal: when sel is 00, output a; when sel is 01, output b; when sel is 10, output c; and when sel is 11, output d.
module top_module(
  input wire a,
  input wire b,
  input wire c,
  input wire d,
  input wire sel,
  output reg out
);
