Module name:  
    Shift_register_16               
Input ports:
    clk: Clock signal used for synchronous operation.
    rst_n: Active-low reset signal to initialize the shift register.
    load: Control signal to load parallel data into the register.
    parallel_in: 16-bit input data to be loaded into the register.
Output port:
    serial_out: Serial output bit from the register.

Implementation:
On every rising edge of the clock signal (clk) or the falling edge of the reset signal (rst_n), the shift register value is updated.
If the reset signal (rst_n) is low, indicating a reset condition, the shift register value is set to 0.
If the load signal is high, the parallel data is loaded into the register.
Otherwise, the register shifts the current value to the right, and the least significant bit becomes the serial output.
