
Design a combinational logic circuit that implements a simple Huffman encoding for a set of characters with fixed frequency. The circuit should take a 4-bit input representing characters (0-15) and output a corresponding 3-bit Huffman code based on predefined encoding. The encoding is as follows:
- Character 0: 000
- Character 1: 001
- Character 2: 010
- Character 3: 011
- Character 4: 100
- Character 5: 101
- Character 6: 110
- Character 7: 111
- Characters 8-15 are not encoded and should output 'xxx'.
