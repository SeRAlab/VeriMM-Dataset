Design a priority encoder that takes an 8-bit input and generates a 3-bit output based on the highest priority active input. The module outputs an enable signal (EN) to indicate that at least one input is active, and a valid signal (V) to confirm that the output corresponds to a valid input. The output Q provides the binary encoding of the highest active input. If no inputs are active, all outputs are set to zero.

    input [7:0] I,
    output reg EN,

);
