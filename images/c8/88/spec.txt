

You are tasked with designing a module that takes in two input signals, `a` and `b`, and outputs a single signal `o`. The output signal should be the result of applying a custom logic function to the input signals.

The custom logic function is defined as follows:
- If both `a` and `b` are 0, `o` should be 0.
- If both `a` and `b` are 1, `o` should be 0.
- If `a` is 1 and `b` is 0, `o` should be 1.
- If `a` is 0 and `b` is 1, `o` should be 1.

You should implement this custom logic function as a module in Verilog. Your module should be named `custom_logic` and should have three ports:
- `a` (input): a single-bit input signal
- `b` (input): a single-bit input signal
- `o` (output): a single-bit output signal

Your module should be completely self-contained and should not rely on any external modules or variables. Your module should be solvable within 200 lines of Verilog code.
