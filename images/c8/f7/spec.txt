

You are tasked with designing a module that implements a D flip-flop with asynchronous reset functionality. The module should have the following inputs and outputs:

- `clk` (1-bit input): the clock signal
- `d` (1-bit input): the data input
- `r` (1-bit input): the asynchronous reset signal
- `q` (1-bit output): the output of the D flip-flop

Implement the module using Verilog and ensure that the output `q` is updated on the rising edge of the clock signal.
