Design a 4-channel DMA controller that can transfer data from source to destination addresses. The DMA controller should have the following inputs: `start` (to initiate the transfer), `channel_select` (to select which channel to use), `source_address` (where to read data from), `dest_address` (where to write data to), and a `data_in` signal (which carries the data to be transferred). It should have an output `data_out` (the data read from the source) and a `done` signal (indicating that the transfer is complete). The controller should switch channels for each transfer and keep track of the state of each channel. Implement the necessary state logic to ensure that the correct channel is activated and deactivated, and that transfers occur without interference.
