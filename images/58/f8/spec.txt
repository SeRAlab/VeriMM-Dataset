Design a module that performs an 8-bit barrel shift operation, allowing for either a right or left shift based on the value of the shift_direction input. The number of bit positions to shift is specified by the shift_amount input, facilitating both logical right shifting and left shifting of the input data. The result of the shifting operation is output through data_out.
module top_module(
    input [7:0] data_in,
    input [2:0] shift_amount,
    input shift_direction,
    output [7:0] data_out
);
