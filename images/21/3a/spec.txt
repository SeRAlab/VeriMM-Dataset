Design a temperature sensor controller that monitors a temperature input and controls an output based on predefined thresholds. The controller should have the following specifications: It has a 10-bit temperature input (temp_in), an enable signal (enable), and a reset signal (reset). When enabled, if the temperature exceeds 75 degrees (represented by a binary value of 75), the output (alert) should be set to high (1). If the temperature is below 60 degrees (binary value of 60), the output (alert) should be set to low (0). The output should remain unchanged if the temperature is between these thresholds. The controller should reset the alert output to low (0) when the reset signal is asserted.
