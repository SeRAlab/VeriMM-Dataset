Design a 32-entry RAM module that allows for both reading and writing operations based on control signals. The module takes a 16-bit input for writing data into the RAM and has a 32-bit output for reading data from the RAM. It uses a clock input to synchronize operations and includes a reset signal to initialize the index used to access the RAM entries. When the switchRead signal is activated, the module writes the input data into the RAM at the current index and increments the index. Conversely, when the switchWrite signal is activated, it retrieves data from the RAM at the current index and decrements the index. The output haveData indicates whether any data has been written to the RAM based on the index value.
