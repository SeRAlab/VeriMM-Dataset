Design a simple cache memory module that implements the Least Recently Used (LRU) cache replacement policy. The cache will have a fixed size of 4 blocks and will store 4-bit data. The module will have inputs for data to be stored, a request signal to specify whether to read or write, and an address input to specify the cache line. The output will indicate whether the data was a hit or a miss, and it should also output the data stored in the cache. The module should handle updating the LRU status of the cache lines upon each access.
