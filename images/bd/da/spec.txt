Design a sequential circuit that produces an output based on the states of three input signals, A, B, and C, with control provided by a clock and reset signal. When the reset is activated, the output is set to LOW. On each positive edge of the clock, if both B and C are HIGH, the output follows the state of A; otherwise, the output takes the value of B. This design functions as a controlled signal selector based on a combination of inputs, effectively acting like a state-dependent output logic unit.
module top_module(
    clk,
    reset,
    A,
    B,
    C,
    out
);
