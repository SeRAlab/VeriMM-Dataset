Design a digital phase shifter that takes a 3-bit input and generates a 5-bit output. The output should represent the phase shifted version of the input signal. The phase shift is defined as follows:  
- When the input is `000`, the output should be `00000`  
- When the input is `001`, the output should be `00001`  
- When the input is `010`, the output should be `00010`  
- When the input is `011`, the output should be `00011`  
- When the input is `100`, the output should be `00100`  
- When the input is `101`, the output should be `00101`  
- When the input is `110`, the output should be `00110`  
- When the input is `111`, the output should be `00111`
