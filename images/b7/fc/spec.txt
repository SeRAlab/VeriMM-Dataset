Design a synchronous full adder with an enable signal. When the enable signal (En) is high, the module computes the sum and carry-out outputs using standard full adder logic; specifically, it calculates the sum by XORing inputs A, B, and Cin, and generates the carry-out using a combination of AND and OR operations. When the enable signal is low, both the sum and carry-out outputs are set to zero, effectively disabling the adder functionality.
module top_module(
    input A,
    input B,
    input Cin,
    input En,
    output reg Sum,
    output reg Cout
);
