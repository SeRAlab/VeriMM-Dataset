Design a JK flip-flop with asynchronous reset and preset inputs. The flip-flop should toggle its output based on the J and K inputs while taking into account the clock signal and the asynchronous reset and preset signals. The output should be Q, and the flip-flop should have the following behavior:
- When RESET is high, Q should be 0.
- When PRESET is high, Q should be 1.
- On the rising edge of the clock:
  - If J=1 and K=0, then Q should be set to 1.
  - If J=0 and K=1, then Q should be set to 0.
  - If J=1 and K=1, then Q should toggle its current state.
  - If J=0 and K=0, then Q should remain in its current state.
