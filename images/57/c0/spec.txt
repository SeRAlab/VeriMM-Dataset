Design a D flip-flop with an asynchronous clear function. On every rising edge of the clock input (C), if the clear input (CLR) is asserted, the output (Q) is reset to LOW. Otherwise, the output takes the value of the data input (D) after a specified delay. The module includes a parameter to set an initial value for Q and a local parameter to define the flop's propagation delay.
