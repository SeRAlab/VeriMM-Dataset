Design a register file with support for read and write operations. This module includes 32 registers, each capable of storing a specified data width. It accepts clock and reset signals, provides read addresses for two registers, a write address, and the data to be written. On the rising edge of the clock, if reset is asserted, all registers are initialized to zero. If reset is not asserted and the write address is non-zero, writing to the specified register occurs if the write control signal is active. The outputs provide the data from the two specified read addresses.
