Design a 4-bit binary adder with a control signal to select between two operations. When CTRL is 0, the module performs a standard addition of inputs A and B, producing a 4-bit sum output C. When CTRL is 1, it adds the upper three bits of both A and B, effectively discarding the least significant bit from each before the addition. This design purposefully enables different addition modes based on the control input, thus enhancing flexibility in arithmetic operations.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input CTRL,
    output reg [3:0] C
);
