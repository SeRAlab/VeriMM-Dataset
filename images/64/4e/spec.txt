Design a circuit that functions as a simple ALU capable of performing either addition or subtraction based on the control signal. The module takes two 8-bit input numbers and, depending on the value of the control input, it adds or subtracts these numbers. The result is provided as an 8-bit output, and a carry output is also generated to indicate overflow for both operations.
module top_module(input [7:0] num1, num2, input control, output reg [7:0] result, output reg carry);
