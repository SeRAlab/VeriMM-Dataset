
Design a 4-bit DRAM cell which can store a 4-bit value. The DRAM cell should have inputs for a write enable signal (we), a 4-bit data input (data_in), a read enable signal (re), and a 4-bit data output (data_out). The cell should hold the value written to it when the write enable signal is high and provide the stored value when the read enable signal is high. Ensure that the stored value is not lost between writes and reads unless explicitly overwritten.
