Design a module that computes the sum of four one-bit inputs and provides a selectable output based on a control signal. The circuit includes an adder that sums inputs A1, A2, A3, and A4, producing a 4-bit output called 'sum'. The module features a multiplexer functionality, where the output X is determined by the selection signal: if sel=1, X outputs the value of input B1; if sel=0, X outputs the calculated sum. This design allows for conditional output selection based on the input conditions.
module top_module(
    input  A1,
    input  A2,
    input  A3,
    input  A4,
    input  B1,
    input  sel,
    output reg X
);
