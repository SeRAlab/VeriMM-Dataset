Design a circuit that performs variable left-bit shifting on a 32-bit input signal B based on control signals. The shift amount is determined by the 2-bit input A, and the specific shift operation is selected using the 2-bit control signal ctrl. Depending on the value of ctrl, the input B is shifted left by A, A+1, A+2, or A+3 positions, and the resultant shifted value is output as dout.
module top_module(
    output [31:0] dout,
    input [31:0] B,
    input [1:0] ctrl,
    input [1:0] A
);
