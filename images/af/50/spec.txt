Implement the Verilog module based on the following description.
Build a 32-bit shift register with synchronous active high load and shift enable signals. The register shifts right on each clock edge when shift is enabled.
(1) load: Loads data into the register.
(2) shift_enable: Enables the shift operation.
(3) data: The data to be loaded into the register.
(4) q: The contents of the register.

module shift_register(
    input clk,
    input load,
    input shift_enable,
    input [31:0] data,
    output reg [31:0] q);
