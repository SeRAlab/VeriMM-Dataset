
Design a fan speed controller that uses a 3-bit binary input to set the speed of the fan. The fan can have 8 different speed levels (from 0 to 7). The fan speed should increase with the input value. If the input value is 3 or higher, the fan should be set to high speed. If the input value is less than 3, the fan should be set to low speed. The system should hold the last speed level until a new input is received.
