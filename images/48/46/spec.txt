Design a signed gain multiplier circuit that processes a 16-bit input signal (mixerIn) by multiplying it with a signed 7-bit gain value. The module includes an overflow detection mechanism and manages overflow behavior based on the oflowMode input signal. During each clock cycle, it registers the input values and performs the multiplication, storing the result in a 24-bit intermediate signal, gainMult. If an overflow condition is detected, it selects the output based on the specified oflowMode: either a portion of the gainMult result, zero, or saturation values. The output (dout) is a 16-bit signed value, and the overflow flag is asserted if the multiplication exceeds the representational limits.
module top_module(
    input clk,
	 input [1:0] oflowMode,
    input signed [15:0] mixerIn,
    input signed [6:0] gain,
    output reg signed [15:0] dout = 16'sd0,
    output reg overflow = 1'b0
    );
