Design a Verilog module for an SR latch using D flip-flops. The latch should have two inputs, Set (S) and Reset (R), and one output Q. The behavior should be such that when S is high, Q should be set to 1, and when R is high, Q should be reset to 0. If both inputs are low, Q should maintain its previous state. If both inputs are high, it should be considered an invalid state.
