Design a rising edge detector that outputs a pulse signal for one clock cycle whenever the input signal transitions from LOW to HIGH. The module uses a registered version of the input signal to capture its state on the positive edge of the clock, while a logical AND operation is employed to generate the output only when there is a rising edge detected (the current input is HIGH and the registered input was LOW). A reset input is incorporated to initialize the registered signal.

    input clk,
    input rst,
