Implement a D-type flip-flop with asynchronous inputs and outputs. The flip-flop captures the value of the input D on the rising edge of the clock signal (CLK) and produces a stable output (Q) that reflects the last captured value. Additionally, the outputs are initialized to an undefined state (X) at the start. The module also provides complementary output (Q_N). This design can be used in sequential circuits for data storage and synchronization.
