Design a FIFO queue with a fixed size of 4 entries. It should have the following inputs and outputs:  
Inputs:  
- clk: clock signal  
- rst: reset signal  
- enq: enqueue signal  
- deq: dequeue signal  
- data_in: data input (5 bits)  
Outputs:  
- data_out: data output (5 bits)  
- full: flag indicating if the FIFO is full  
- empty: flag indicating if the FIFO is empty
