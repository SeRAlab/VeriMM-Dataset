

You are tasked with designing a Verilog module that takes in four input signals, A1, A2, A3, and A4, and produces a single output signal, O. Your module must use only an OR gate to perform this operation.

Assume that each input signal is a single bit (0 or 1), and that the output signal should also be a single bit. Your module should be able to handle any combination of input signals.

Your task is to write a Verilog module that satisfies these requirements and is no longer than 200 lines of code. Your module should be named JOR4B, and should include the inputs and output as specified in the code snippet below:

```
module JOR4B(A1, A2, A3, A4, O);
input   A1;
input   A2;
input   A3;
input   A4;
output  O;
or g0(O, A1, A2, A3, A4);
endmodule
```
