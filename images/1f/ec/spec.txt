Design a Parallel-in Serial-out (PISO) shift register that can take an 8-bit input in parallel and shift it out serially on each clock pulse. The shift register should have a load enable signal to allow loading the parallel input. When the load enable is high, the input data should be loaded into the register; when load enable is low, the data should shift out serially on the output pin. Include a reset signal to initialize the register to zero.
