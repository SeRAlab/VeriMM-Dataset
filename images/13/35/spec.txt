Design a 4-channel DMA (Direct Memory Access) controller that allows data transfer between memory and I/O devices. The controller should have the following inputs: `request` (4 bits), `grant` (4 bits), and `clk` (clock). The outputs should be `active_channel` (2 bits) indicating which channel is currently active and `transfer` (1 bit) indicating if a transfer is occurring. The DMA controller should prioritize channel requests based on their order of appearance.
