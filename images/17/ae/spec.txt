Design a 16-bit SRAM cell that can perform read and write operations. The SRAM cell should have the following features: 
1. It should take a 16-bit input data (`data_in`).
2. It should have a 4-bit address input (`addr`) to select which of the 16 cells to read from or write to.
3. It should have a `write_enable` signal to control write operations (active high).
4. It should have a `read` signal (active high) to control read operations.
5. The output should be a 16-bit data output (`data_out`) that reflects the contents of the SRAM cell when a read operation is performed. 
6. Ensure that the write operation occurs on the rising edge of the clock.
