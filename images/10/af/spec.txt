Design a 7-stage pipeline processor that can process a sequence of 8-bit instructions. Each stage of the pipeline performs a specific operation, and the output of one stage is the input to the next stage. The main operations include fetching an instruction, decoding it, executing it, memory access, and writing back the result. The processor should have a clock signal for synchronization and a reset signal to initialize the pipeline. The pipeline should handle data hazards by stalling if necessary.
