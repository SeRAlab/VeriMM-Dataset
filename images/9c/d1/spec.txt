Design a synchronous counter with a parameterizable data width. It has inputs for clock, reset, enable, and load, along with a parallel input data signal. Upon a positive clock edge or negative reset, the counter will reset to zero when reset is low. If reset is high and enable is asserted, the counter can either load a value from data_in (if load is asserted) or increment its current value by one. The output data_out reflects the current counter value.
module top_module(clock, reset, enable, load, data_in, data_out);
