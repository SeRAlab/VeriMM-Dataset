Design a Verilog module that computes a simple checksum for a 5-bit input data. The checksum will be calculated as the sum of the bits in the input data, modulo 2. The module should output the checksum along with the original data. The input is a 5-bit wide signal, and the output should be a 6-bit wide signal, where the first 5 bits are the original data and the last bit is the checksum.
