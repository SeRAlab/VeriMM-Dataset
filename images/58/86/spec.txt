Design a simple arithmetic calculator that performs basic operations on two signed 32-bit inputs based on a 2-bit operation selector. The module can execute addition, subtraction, multiplication, and division, producing corresponding outputs for each operation. When the operation is invalid, all output values reset to zero.
module top_module(
  input signed [31:0] a, b,
  input [1:0] op,
  output reg signed [31:0] sum,
  output reg signed [31:0] difference,
  output reg signed [31:0] product,
  output reg signed [31:0] quotient
);
