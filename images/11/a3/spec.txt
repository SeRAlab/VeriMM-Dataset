Design a 2-bit shift register with parallel load capability. The shift register should have a clock input (clk), a reset input (rst), a load input (load), a 2-bit input data (data_in), and a 2-bit output (data_out). When the load signal is high, the contents of data_in should be loaded into the shift register. On each rising edge of the clock, if the load signal is low, the contents of the shift register should shift left by one position, and the least significant bit (LSB) should be filled with 0. If the reset signal is high, the shift register should be reset to 0.
