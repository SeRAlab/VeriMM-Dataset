Implement a 16-bit barrel shifter that can perform both logical left and right shifts based on a 4-bit shift_amount input. If the shift_amount is positive, the input is shifted left by that many positions; if it is negative, it is shifted right by the absolute value of shift_amount. This module enables efficient data manipulation for operations like multiplication and division by powers of two.
