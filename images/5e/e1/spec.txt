Design a forwarding unit for a pipelined processor to resolve data hazards. This module determines whether to forward data from previous stages of the pipeline (EXMEM, MEMWB) to the current execution stage based on the register write signals and the valid destination registers. The outputs forwardA and forwardB indicate the source of data for operands from registers specified in the instruction during the ID stage, while forward1 and forward2 provide similar functionality for operands used in the IF stage. The various output values (00, 01, 10, 11) specify the forwarding paths, ensuring that the most up-to-date data is used without stalling the pipeline.
