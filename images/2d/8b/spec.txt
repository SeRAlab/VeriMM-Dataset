Design a Verilog module that implements a simple hash table using an array of registers. The hash table should support two operations: inserting a key-value pair and retrieving a value by key. The hash function can be a simple modulo operation on the key to determine the index in the array. The module should include the following inputs: a clock signal, a reset signal, an operation signal (0 for insert, 1 for retrieve), a key input, and a value input for insert operations. The output should be the retrieved value for retrieve operations.
