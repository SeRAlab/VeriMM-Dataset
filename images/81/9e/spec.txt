Design an integer square root calculator that operates on a 32-bit input. This module iteratively refines its guess for the square root by squaring the current guess and comparing it to the input value. If the squared guess exceeds the input, it reduces the guess by shifting it right; otherwise, it adds the guess to an estimate, which is also reduced. The final output is the upper 16 bits of the estimate, providing the integer part of the square root of the input.
module top_module(
  input [31:0] in,
  output reg [15:0] out
);
