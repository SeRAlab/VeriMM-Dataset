
Create a Verilog module that implements a simple PCIe interface signal checker. The module should have two inputs: `signal_in` (a 5-bit input) and `control` (a 1-bit input). The output `signal_out` should be 1 if the `signal_in` is equal to `control` extended to 5 bits (i.e., if `control` is 1, then `signal_out` should be 1 for `signal_in` equal to 5'b11111; if `control` is 0, then `signal_out` should be 1 for `signal_in` equal to 5'b00000). Otherwise, `signal_out` should be 0.
