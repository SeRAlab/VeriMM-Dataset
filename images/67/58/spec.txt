Design an n-bit wide accumulator circuit that captures and sums a data input signal on each positive clock edge. The circuit features a parameterized bit width, allowing for configurations ranging from 1 to any desired number of bits (default set to 8). The accumulator continuously adds the input data to its internal register, and the current accumulated value is outputted as the sum signal.
module top_module(
  input clk, // clock signal
  input [n-1:0] d, // data signal
  output reg [n-1:0] s // sum signal
);
