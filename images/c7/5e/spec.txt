

You have been tasked with designing a verilog module for a 2-input NOR gate. The module should take two input signals, `a` and `b`, and output the logical NOR of the two inputs as `z`. Use the following template to create your module:

```
module ctu_nor2 (z, a, b);

output z;
input  a;
input  b;

// your code here

endmodule
```

Your goal is to fill in the module with the appropriate verilog code to implement a 2-input NOR gate. Your solution should use behavioral modeling and not structural modeling.
