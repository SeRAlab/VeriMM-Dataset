
Design a Verilog module for a simple Bluetooth state machine that manages three states: IDLE, CONNECTING, and CONNECTED. The module should transition between these states based on input signals. The state transitions should be as follows:
- From IDLE to CONNECTING on input signal `start_connect`.
- From CONNECTING to CONNECTED on input signal `connection_success`.
- From CONNECTING to IDLE on input signal `connection_fail`.
- Remain in CONNECTED until a reset signal is activated, which should return the state to IDLE.
The module should also output the current state as a 2-bit binary value.
