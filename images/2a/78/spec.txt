
Create an 8-bit DRAM cell that can be read from and written to. The DRAM cell has the following interfaces:
- An 8-bit data input (D)
- An 8-bit data output (Q)
- A write enable (WE) signal: when WE is high, the data on the D input is written to the cell
- A read enable (RE) signal: when RE is high, the data from the cell is output to Q
- A clock signal (CLK) to synchronize the operation
The DRAM cell should store the last written value until overwritten.
