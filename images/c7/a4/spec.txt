

You are tasked with designing a verilog module for a simple 4-bit adder that takes in two 4-bit inputs and outputs a 5-bit sum. The module should have the following inputs and outputs:

Inputs:
- `a` (4-bit): the first input
- `b` (4-bit): the second input

Outputs:
- `sum` (5-bit): the sum of the two inputs

The module should be called `simple_adder` and should have the following interface:

```
module simple_adder (
  input [3:0] a,
  input [3:0] b,
  output [4:0] sum
);
```

You should make use of the following verilog operators:
- `+` for addition
- `<<` for left shift
