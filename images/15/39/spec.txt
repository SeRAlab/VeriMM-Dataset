Design a 24-bit ADC controller that converts a given 24-bit digital input to its corresponding analog voltage. The controller should have a clock input, a reset input, and a 24-bit data input. Upon receiving a valid clock edge, the controller should output the analog equivalent voltage in a 16-bit format. The voltage conversion formula is: Voltage = (Digital Input / 2^24) * V_ref, where V_ref is a reference voltage set to 5V.
