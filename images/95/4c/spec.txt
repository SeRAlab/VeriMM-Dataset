Design a 2-bit binary counter with a clock input (CLK) and a reset input (RESET). On each rising edge of the clock, the counter increments its value, cycling through the states 00, 01, 10, and 11, before wrapping back to 00. If the RESET signal is asserted, the counter outputs will reset to 00. The outputs, Q1 and Q0, represent the two bits of the counter state.
module top_module(
    input CLK,
    input RESET,
    output reg Q1,
    output reg Q0
);
