Design a 4-bit adder/subtractor circuit controlled by a clock and a reset signal. The module takes two 4-bit inputs, A and B, and a control signal, ctrl. When ctrl is low, the circuit performs addition (A + B), and when ctrl is high, it performs subtraction (A - B). The result of the operation is stored in a temporary register and outputted as a 4-bit result. The system is initialized to zero on a reset signal.
module top_module(
  input clk,
  input reset,
  input [3:0] A,
  input [3:0] B,
  input ctrl,
  output [3:0] result
);
