

You have been asked to design a 4-bit comparator module that takes two 4-bit inputs, A and B, and outputs a 2-bit signal that indicates whether A is greater than, less than, or equal to B. You are to implement this using a combination of logical and arithmetic operations in Verilog.

The module should have the following interface:

```
module comparator_4bit(
    input [3:0] A,
    input [3:0] B,
    output reg [1:0] result
);
```

The `result` output should be 2 bits wide and should take the following values:

- `2'b00` if A is equal to B
- `2'b01` if A is greater than B
- `2'b10` if A is less than B

You may not use any built-in Verilog comparison operators (e.g. `>`, `<`, `==`) in your solution. You may use any other Verilog operators and constructs.
