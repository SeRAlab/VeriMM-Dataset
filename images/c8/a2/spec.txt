

In this problem, you need to design a Verilog module for a 4-bit synchronous up-counter with a reset input. The counter should increment on the rising edge of the clock signal and reset to zero when the reset input is asserted. The module should have the following inputs and outputs:

Inputs:
- `clk` (1-bit): the clock signal
- `reset` (1-bit): the reset signal

Outputs:
- `count` (4-bit): the current count value

You should use a single always block to implement the counter logic. You can assume that the clock signal has a 50% duty cycle and a frequency of 10 MHz.
