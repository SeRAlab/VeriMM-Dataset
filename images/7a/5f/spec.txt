Design a 4-to-2 priority encoder that converts four 1-bit inputs (a, b, c, d) into a 2-bit binary output (x, y). The circuit prioritizes the inputs such that if multiple inputs are high, the encoder generates an output corresponding to the highest priority input, with 'a' having the highest priority, followed by 'b', 'c', and 'd'. The outputs x and y represent the binary encoding of the highest active input. If none of the inputs are asserted, the outputs default to a known state.
module top_module(
    input a,
    input b,
    input c,
    input d,
    output x,
    output y
);
