Design a 32-bit register with asynchronous reset and load capabilities. The module captures the input value when the load signal is asserted on the rising edge of the clock, storing the input data in the output register. When the reset signal is active, it initializes the output to zero. If neither the load nor reset signals are active, the register holds its current value, facilitating both data retention and controlled data updating.
