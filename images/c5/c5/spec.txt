

You are tasked to design a verilog module that implements a 4-bit binary to gray code converter. The module should have 2 inputs and 1 output. The inputs are the 4-bit binary input (B) and a clock signal (Clk). The output should be the corresponding 4-bit gray code (G). 

The module should have the following constraints:
- The module should use a synchronous design.
- The output should only change on the rising edge of the clock signal.
- The module should be implemented using only combinational logic.

Write the verilog code for the module.
