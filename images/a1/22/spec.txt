Design a four-bit shift register with serial input and output capabilities. On each rising edge of the clock, if the serial input (SI) is high, the module shifts the current data in the register to the left and introduces SI into the least significant bit. If SI is low, the register loads a new 4-bit parallel input (D) directly into the register. The output (SO) provides the value of the least significant bit of the shift register, enabling serial output of shifted data.
module top_module(
    input clk,
    input [3:0] D,
    input SI,
    output reg SO
);
