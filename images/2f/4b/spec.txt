Design an 8-bit Digital-to-Analog Converter (DAC) that takes a 3-bit control signal to select one of the 8 possible voltage levels. The DAC output should be a 10-bit value representing the selected voltage level, where each level corresponds to a specific value based on a reference voltage of 5V. The output should be calculated as (input_value * 5V) / 255. Implement this in Verilog.
