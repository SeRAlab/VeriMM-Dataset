Design a circuit that functions as a multi-input control logic gate. The output, X, is determined based on a specific set of conditions: it outputs a LOW signal when all inputs (A1, A2, B1, C1, D1, along with power and ground signals) are LOW, and it outputs a HIGH when all the inputs are HIGH. If the inputs are in any other state, the output is defined as unknown (X). This module could be used for power management or logic initialization in digital circuits.
module top_module(
    input A1,
    input A2,
    input B1,
    input C1,
    input D1,
    input VPWR,
    input VGND,
    input VPB,
    input VNB,
    output X
);
