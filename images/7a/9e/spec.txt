Design a circuit that performs a signed bitwise shift operation on a 4-bit input. The module accepts a 2-bit shift amount and a directional control signal; if the direction is 0, it shifts the input data left by the specified amount, and if 1, it shifts right. The output, GTE, indicates whether the resulting shifted value is greater than or equal to zero, effectively providing a flag for non-negativity of the shifted result.
module top_module(
    input [1:0] shift_amount,
    input direction,
    input signed [3:0] signed_data,
    output reg GTE
);
