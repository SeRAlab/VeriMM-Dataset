
Design a fixed-priority arbiter in Verilog that takes multiple request signals and generates a single grant signal based on the fixed priority of the requests. The arbiter should have 4 request inputs (req0, req1, req2, req3), and a single grant output (grant) that indicates which request is granted based on priority (req0 has the highest priority and req3 has the lowest). The arbiter should also have a clock input for synchronization and a reset input to clear the state.
