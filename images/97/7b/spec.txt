Design a 4-bit shift register with serial input and parallel output functionality. The shift register captures the serial input on the rising edge of the clock, shifting the existing bits towards the least significant bit (LSB) while inserting the new serial bit at the most significant bit (MSB). Upon the falling edge of the clock, it outputs the current state of the shift register in parallel form. The shift register can be reset to zero when the reset signal is asserted.
module top_module(
    input clk,
    input serial_in,
    input reset,
    output reg [3:0] parallel_out
);
