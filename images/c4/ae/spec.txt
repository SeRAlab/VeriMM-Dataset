

You are tasked with designing a module that takes in two 8-bit inputs and produces their sum. The module should also output a carry bit. The design should be optimized for minimum hardware usage.

Write a Verilog module that implements the following circuit:

```
         +--------+
  A[7:0] |        |
  B[7:0] |  ADDER |
  C[7:0] |        |
  CARRY  |        |
         +--------+
```

The module should have the following inputs and outputs:
- `A`: an 8-bit input
- `B`: an 8-bit input
- `C`: an 8-bit output representing the sum of `A` and `B`
- `CARRY`: a single bit output representing the carry bit

Assume that the inputs are valid and that overflow will not occur.
