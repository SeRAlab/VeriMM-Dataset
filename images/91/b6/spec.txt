Design a 16-bit linear feedback shift register (LFSR) that generates pseudorandom bit sequences based on a given seed. The module operates on the rising edge of a clock signal, with an asynchronous reset and an enable input. When reset, it initializes the LFSR with the provided seed and outputs zero. When enabled, it shifts the LFSR to produce the next bit in the sequence and updates the output Data with the current LFSR value, signaling completion with the Done output. If not enabled, the Done signal indicates that no new data is generated.
