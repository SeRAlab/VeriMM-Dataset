

You are tasked with designing a Verilog module that takes in 5 inputs and produces 1 output. The module should have the following interface:

```
module my_module(
    input A,
    input B,
    input C,
    input D,
    input E,
    output reg X
);
```

The module should perform the following operation:

1. If A is 0, X should be set to 0.
2. If A is 1, B should be added to C and the result should be stored in a temporary variable T.
3. If T is greater than or equal to D, X should be set to 1.
4. If T is less than D, E should be added to T and the result should be stored in a temporary variable T2.
5. If T2 is greater than or equal to D, X should be set to 1.
6. If T2 is less than D, X should be set to 0.

Write a Verilog module that implements the above operation. Your solution should be contained within a single module that is no more than 200 lines of code.
