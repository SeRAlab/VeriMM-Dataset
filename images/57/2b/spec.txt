Design a pixel reader module that interfaces with an image data source. This module reads pixel data in a 24-bit RGB format, outputting the individual red, green, and blue channels as 8-bit values. It operates synchronously with a clock and supports asynchronous reset. The module controls read operations based on readiness signals, managing a reading state with an internal count to track how many pixels have been read. It signals the readiness of pixel data and indicates when the last pixel has been processed. The design includes mechanisms for handling the start and completion of read actions while providing a status output for pixel availability.
