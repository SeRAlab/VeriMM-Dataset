Create a Verilog module that implements a 4-bit binary subtractor with borrow-in and borrow-out. The module should have the following specifications:
- `a`: The 4-bit input operand A.
- `b`: The 4-bit input operand B.
- `borrow_in`: The borrow-in input.
- `diff`: The 4-bit output representing the difference.
- `borrow_out`: The borrow-out output.
