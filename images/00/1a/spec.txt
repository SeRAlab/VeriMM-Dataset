Design a simple voltage output control circuit for a switching regulator. The circuit accepts a 3-bit binary input representing the desired voltage level (000 for 0V, 001 for 1V, 010 for 2V, 011 for 3V, 100 for 4V) and produces a 5-bit binary output that represents the actual voltage output from the regulator. The output should be proportional to the input in a predefined manner: each increment in the input results in an increment of 1V in the output.
