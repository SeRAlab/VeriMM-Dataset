
Design a JK latch using Verilog. The JK latch should have two inputs (J and K), a clock input (CLK), and two outputs (Q and Qn). The latch should hold its state stable until the clock edge, where it will toggle based on the J and K inputs according to the following conditions:
- If J = 1 and K = 0, then Q should be set to 1.
- If J = 0 and K = 1, then Q should be set to 0.
- If J = 1 and K = 1, then Q should toggle (if Q was 1, it should become 0, and vice versa).
- If J = 0 and K = 0, then Q should remain unchanged.
