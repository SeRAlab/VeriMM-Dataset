Design a 4-bit shift register with four parallel data inputs (D0, D1, D2, D3) and four corresponding output registers (Q0, Q1, Q2, Q3). The shift register is controlled by a LOAD signal that, when asserted, loads the inputs into the outputs. On each positive edge of the clock, if RESET is activated, all outputs are set to zero. If RESET is not active and LOAD is not asserted, the outputs shift their previous values, with Q0 taking the value of Q1, Q1 taking the value of Q2, Q2 taking the value of Q3, and Q3 getting the value from D0, effectively creating a circular shift operation.
module top_module(
    input [3:0] D0,
    input [3:0] D1,
    input [3:0] D2,
    input [3:0] D3,
    input LOAD,
    input RESET,
    input CLK,             // Added the CLK input
    output reg [3:0] Q0,
    output reg [3:0] Q1,
    output reg [3:0] Q2,
    output reg [3:0] Q3
);
