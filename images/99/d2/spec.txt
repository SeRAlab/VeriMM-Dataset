Design a synchronous 4-bit counter with load functionality. The counter increments its value on each positive clock edge unless it has been reset, in which case it outputs zero. If the LOAD signal is activated, it loads a specified 4-bit input value instead of incrementing. The counter wraps around to zero upon reaching the value nine (4'b1001).
module top_module(
    input CLK,
    input RESET,
    input LOAD,
    input [3:0] DATA,
    output reg [3:0] Q
);
