
Create a 4-channel DMA controller that manages data transfers from memory to multiple peripherals. The controller should be able to select one of the four channels based on a 2-bit channel select input (`channel_sel`). It should support starting a transfer with a `start` signal and indicate when the transfer is complete with a `done` signal. The `data_in` input is to be transferred to `data_out` when the selected channel is active.
