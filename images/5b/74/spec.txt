Design a 4-to-1 multiplexer that selects one of four 8-bit input signals (A, B, C, or D) based on a 2-bit selector input (sel). The output (S) will reflect the value of the selected input according to the combination of the selector bits, with the default output being the value of A when sel is an invalid state.
module top_module(
 input[1:0] sel,
 input[7:0] A, 
 input[7:0] B, 
 input[7:0] C, 
 input[7:0] D, 
 output reg[7:0] S
 );
