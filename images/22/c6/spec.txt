Design a 4-bit EEPROM cell controller that allows writing and reading of data. The controller should have the following inputs: a 4-bit data input (D), a write enable signal (WE), a read enable signal (RE), and a clock signal (CLK). When WE is high, the data D should be written to the EEPROM cell on the rising edge of CLK. When RE is high, the stored data should be output to a 4-bit data output (Q) on the next rising edge of CLK. The initial state of the EEPROM cell should be all zeros.
