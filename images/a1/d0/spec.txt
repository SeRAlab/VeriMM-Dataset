Design a 16-bit wide, 4-to-1 multiplexer. The output will select one of four 16-bit inputs (a, b, c, d) based on the 2-bit select input. When select is '00', output 'a' is chosen; when '01', output 'b' is selected; when '10', output 'c' is used; and when '11', output 'd' is routed to the output.
module top_module(
    input [1:0] select,
    input [15:0] a,
    input [15:0] b,
    input [15:0] c,
    input [15:0] d,
    output [15:0] out
);
