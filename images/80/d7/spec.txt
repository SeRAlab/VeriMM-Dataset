Design a synchronous flip-flop with set functionality. The module holds a registered output `Q` that is updated on the rising edge of the clock (`clk`). If the clock enable (`CE`) is high, the output is set to high when the set input (`S`) is activated; otherwise, it takes the value of the data input (`D`). If `CE` is low, the output remains unchanged. This design allows for conditional loading of data or setting the output high based on the control signals.
module top_module(input clk, input D, input S, input CE, output reg Q);
