Create an SPI master controller that can initiate communication with a slave device. The SPI protocol involves a clock signal (SCK), a data input (MISO), a data output (MOSI), and a chip select (CS). The master should send 8 bits of data to the slave on every rising edge of SCK while the CS is low. The master should also read the 8 bits of data sent back by the slave on the MISO line.
