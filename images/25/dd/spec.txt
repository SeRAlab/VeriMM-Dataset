
Design a simple SR flip-flop in Verilog. The flip-flop has two inputs (S and R) and one output (Q). The flip-flop should follow these rules:
1. If S = 1 and R = 0, Q = 1 (Set)
2. If S = 0 and R = 1, Q = 0 (Reset)
3. If S = 0 and R = 0, Q retains its previous state (No Change)
4. If S = 1 and R = 1, Q is considered an invalid state.
