Create a Verilog module for a 16-bit register that holds its value unless a load signal is high, in which case it loads the input data on the positive edge of the clock. The reset is synchronous and sets the register to 0.
module register (
	input clk,
	input reset,
	input load,
	input [15:0] data_in,
	output reg [15:0] data_out);
