Design a 4-bit binary counter that increments its value on each positive edge of the clock signal, clk. It has an active-low reset input, where asserting reset (reset = 0) clears the counter to zero (0000). When reset is not asserted, the counter continues to increment its value with each clock cycle.
module top_module(
    input clk,
    input reset,
    output reg [3:0] count
);
