
Design a digital phase shifter that takes a 3-bit input representing a phase angle (0 to 7), and produces an output that represents the phase shifted value. The phase shifter should shift the input phase by a specified amount based on a secondary 2-bit control input (00 = 0 degrees, 01 = 90 degrees, 10 = 180 degrees, 11 = 270 degrees). The output should wrap around if it goes beyond the maximum phase of 7.
