Design a 4-bit comparator that outputs a signal indicating whether the input A is greater than input B. The module includes a reset feature; when the reset signal is asserted, the output is set to LOW. If reset is not active, the output 'match' becomes HIGH if A is greater than B, and LOW otherwise.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input reset,
  output reg match
);
