Design a Verilog module for a 4-bit binary counter with synchronous reset and maximum value detection. The counter should increment on each clock cycle. If reset is high, the counter should reset to 0. The module should also have an output signal 'max' that goes high when the counter reaches its maximum value.
module binary_counter(
	input clk,
	input reset,
	output reg [3:0] count,
	output max);
