Design a 4-to-1 multiplexer that selects one of four 4-bit wide inputs (A, B, C, D) based on a 2-bit select signal (S). The output (OUT) reflects the value of the selected input, with S='00' choosing A, S='01' choosing B, S='10' choosing C, and S='11' choosing D.
module top_module(
    input [3:0] A, B, C, D,
    input [1:0] S,
    output reg [3:0] OUT
);
