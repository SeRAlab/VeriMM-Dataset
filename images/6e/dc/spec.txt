Design a 16-to-4 priority encoder that outputs a 4-bit representation of the highest-priority active input when enabled. If no inputs are active and the enable signal is high, the output will be undefined. If the enable signal is low, the output will be forcibly driven to zero. The active inputs are expected to be provided on a 16-bit input bus, with the priority determined by the lowest index of the active bit.
