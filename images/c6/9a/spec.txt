

You are working on a project that requires you to design a module that can perform a bitwise XOR operation on two 8-bit inputs. Write a Verilog module that takes two 8-bit inputs A and B and produces an 8-bit output Z that is the result of performing a bitwise XOR operation on A and B.

Your module should be named "xor_8bit" and should have the following ports:
- input [7:0] A
- input [7:0] B
- output [7:0] Z

You should assume that both A and B are valid 8-bit binary numbers. Your module should output the result of performing a bitwise XOR operation on A and B, which should also be an 8-bit binary number.

Your module should be designed to be synthesizable and should be implemented in less than 200 lines of Verilog code.
