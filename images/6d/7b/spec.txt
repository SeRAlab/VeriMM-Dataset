Design a Verilog module that implements a 3-bit gray code counter. The counter outputs a 3-bit gray code value on every rising edge of the clock.

Initial state: gray_counter = 3'b000
Time 0ns: clock = 0, gray_counter = 3'b000.
Time 10ns: clock = 1, gray_counter = 3'b001.
Time 20ns: clock = 0, gray_counter = 3'b001.
Time 30ns: clock = 1, gray_counter = 3'b011.
Time 40ns: clock = 0, gray_counter = 3'b011.
Time 50ns: clock = 1, gray_counter = 3'b010.

module gray_counter (
	input clock,
	output reg [2:0] gray_counter);
