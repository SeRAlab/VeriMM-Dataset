Design a Set-Reset (SR) Flip-Flop that stores a single bit of information. The flip-flop uses two inputs, S (set) and R (reset), along with a clock signal (clk) to control its operation. When S is high and R is low, the output Q is set to high; when S is low and R is high, Q is reset to low. If both S and R are low, the flip-flop retains its current state, while the inverse output Qb is generated as the complement of Q. If both S and R are high, outputs Q and Qb are both set to low, representing an invalid state. The circuit therefore provides basic memory functionality with asynchronous reset capability.
