Design a circuit that performs various 2-input logic operations on a 2-bit input. The module outputs the results of an AND, NAND, OR, NOR, XOR, and XNOR operation based on the provided input signals. Each output reflects the corresponding logical function applied to the bits of the input, allowing for a comprehensive analysis of the input states.
module top_module(
   input [1:0] in,
   output      out_and,
   output      out_nand,
   output      out_or,
   output      out_nor,
   output      out_xor,
   output      out_xnor
   );
