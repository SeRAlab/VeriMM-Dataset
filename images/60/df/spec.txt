Design a 32-bit counter with reset and load functionality. On the positive edge of the clock, if the reset signal is active, the count is set to zero. If the load signal is active, the counter is loaded with a specified 32-bit value. If neither reset nor load is asserted but the enable signal is active, the counter increments its value by one.
module top_module(input clk, reset, enable, load,
   input [31:0] load_value,
   output reg [31:0] count);
