

You have been tasked with designing a verilog module for a simple calculator that can perform addition and subtraction operations. The calculator should have two inputs (`a` and `b`) and one output (`result`). Additionally, the calculator should have a control input (`op`) that determines whether the calculator should perform an addition or subtraction operation. The control input should be a single bit, where a value of 0 indicates addition and a value of 1 indicates subtraction.

Design a verilog module that implements the above requirements. The module should have the following inputs and outputs:

Inputs:
- `a` (32-bit signed integer)
- `b` (32-bit signed integer)
- `op` (1-bit)

Outputs:
- `result` (32-bit signed integer)

Assume that the input values `a` and `b` are valid and within the range of a signed 32-bit integer.
