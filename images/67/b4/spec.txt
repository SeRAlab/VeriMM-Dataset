Design an arithmetic logic unit (ALU) that performs three operations on two 32-bit input operands (ALUA and ALUB) based on a 3-bit control signal (ALUOp). The operations include addition, subtraction, and bitwise OR, which are selected by the values of ALUOp: '001' for addition, '010' for subtraction, and '011' for OR. If none of these operations are selected, the ALU outputs zero. The ALU's output is a 32-bit result reflecting the operation defined by the ALUOp selection.
module top_module(
    input [31:0] ALUA,
    input [31:0] ALUB,
    input [2:0] ALUOp,
    output [31:0] ALU
    );
