Write a Verilog module for a 2-bit binary counter with enable, clear, and load. The counter should have an input value to load, and an output count. It should be positive clock/clk edge triggered. When enable is low, the counter holds its value. When clear is high, the counter resets to 0. When load is high, the counter loads the input value.

module counter (
  input clk,
  input clear,
  input enable,
  input load,
  input [1:0] value,
  output reg [1:0] count
);
