
Design an SR latch using D flip-flops. The SR latch should have two inputs, S (set) and R (reset), and two outputs, Q and Q'. The behavior should be as follows:
- If S = 1 and R = 0, then Q should be 1.
- If S = 0 and R = 1, then Q should be 0.
- If S = 0 and R = 0, Q should retain its previous state.
- If S = 1 and R = 1, it should be considered an invalid state, and we will set Q to 0 in this implementation.
