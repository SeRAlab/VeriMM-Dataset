Design a read-only memory (ROM) module that outputs 8-bit data based on a 4-bit address input when a read control signal is asserted. The ROM is initialized with predefined hexadecimal values from 01 to 10, and on each positive clock edge, if the read signal is high and the address is within the valid range, the corresponding data from the ROM array is made available at the output.
module top_module(
    input [3:0] address,
    input read,
    input clk,
    output reg [7:0] data_out
);
