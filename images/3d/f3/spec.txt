
Design a simple Bluetooth state machine that handles three states: IDLE, CONNECTING, and CONNECTED. The state transitions occur based on the following inputs:
- `start`: When high, transitions from IDLE to CONNECTING.
- `connect`: When high in the CONNECTING state, transitions to CONNECTED.
- `reset`: Resets the state machine back to IDLE.

The output of the state machine should be the current state encoded in a 2-bit signal: 00 for IDLE, 01 for CONNECTING, and 10 for CONNECTED.
