Design a 12-bit subtractor module that computes the difference between two 12-bit input values, `lhs` (left-hand side) and `rhs` (right-hand side). The output, `result`, represents the subtraction of `rhs` from `lhs`. Additionally, the module generates an `overflow` signal, which indicates if an overflow occurs during the subtraction, specifically when `lhs` is less than `rhs`.
module top_module(
    input [11:0] lhs,
    input [11:0] rhs,
    output [11:0] result,
    output overflow
    );
