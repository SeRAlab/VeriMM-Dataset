Design a 2-input Support Vector Machine (SVM) decision function that classifies input data based on a linear decision boundary. The inputs are two 4-bit binary values representing two features of the input data. The output should be a single bit indicating class 0 or class 1, based on a predefined weight vector and bias. The weight vector is fixed as [2, 3] and the bias is -5. The decision function can be expressed as: output = 1 if (2*feature1 + 3*feature2 + bias) >= 0, else output = 0.
