Implement a clock phase shifter that adjusts the output clock phase based on a signed 32-bit input value, `phase_shift`. When `phase_shift` is positive, the output clock (`clk_out`) is delayed by the specified amount, resulting in a phase advancement. Conversely, if `phase_shift` is negative, the output clock exhibits a phase retardation. If `phase_shift` is zero, the output clock follows the input clock directly. This design is useful for applications requiring precise clock synchronization or timing adjustments in digital circuits.
module top_module(
  input clk_in,
  input signed [31:0] phase_shift,
  output clk_out
);
