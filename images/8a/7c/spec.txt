Design a 4-to-1 multiplexer that selects one of four input signals (in0, in1, in2, in3) based on a 2-bit selection input (sel0 and sel1). The output will be the value of the selected input: when sel = 00, output in0; when sel = 01, output in1; when sel = 10, output in2; and when sel = 11, output in3.
module top_module(
  input in0,
  input in1,
  input in2,
  input in3,
  input sel0,
  input sel1,
  output out
);
