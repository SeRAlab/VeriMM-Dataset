Design a 3-bit up/down counter with load capability. The counter increments its value on the rising edge of the clock when the UP signal is active, decrements when the DOWN signal is active, and loads a new value from the DIN input when the LD signal is asserted. The output Q reflects the current count value.
module top_module(
    input CLK, UP, DOWN, LD,
    input [2:0] DIN,
    output reg [2:0] Q
);
