Design a circuit that functions as a four-input OR gate, where inputs A, B, and C are direct logical inputs, and input D_N represents the logical negation of input D (an active low signal). The output X will be high if any of the inputs A, B, C are high or if D is low, making this a combinational logic block suitable for digital signal processing. Additionally, the module includes power supply and ground connections, enhancing its integration in mixed-signal circuits.
module top_module(
    input A,
    input B,
    input C,
    input D_N,
    input VPWR,
    input VGND,
    input VPB,
    input VNB,
    output reg X
);
