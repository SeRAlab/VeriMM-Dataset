Design a 4-to-1 multiplexer using NAND gates. The module takes a 4-bit data input and a 2-bit select input. The output `out` will reflect one of the four data inputs based on the value of the select lines, effectively allowing the selection of one of the four data inputs to pass through to the output. This design leverages NAND gates for both negating the inputs and implementing the selection logic, providing a compact implementation using a fundamental logic gate.
module top_module(
    input [3:0] data,
    input [1:0] sel,
    output reg out
);
