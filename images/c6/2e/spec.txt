
You are tasked with creating a module that calculates the area of a rectangle. The module should take two inputs, the length and width of the rectangle, and output the area. The module should be named "rectangle_area".

Your module should have the following ports:
- input [7:0] length
- input [7:0] width
- output reg [15:0] area

The length and width inputs are 8-bit unsigned integers, and the area output is a 16-bit unsigned integer. The area output should be calculated as length times width.

You should write the module code to implement this functionality. Your code should be synthesizable and should not use any non-synthesizable constructs.
