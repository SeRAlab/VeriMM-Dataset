Design a Verilog module that implements a 2-bit binary up-counter with enable and carry-out. The counter should increment on the rising edge of the clock if the "enable" signal is high. The counter should reset to zero when the synchronous reset (sreset) is high. The counter value should be output to the "count" signal, and the carry-out should be output to the "carry" signal.

module top_module
(
    input clk,
    input sreset,
    input enable,
    output reg [1:0] count,
    output reg carry
);
