Design a Verilog module that implements an audio mixer. The module should take two audio signals as 8-bit inputs (audio_in1 and audio_in2) and a 1-bit control signal (mix_select). If mix_select is 0, the output (audio_out) should be the first audio input (audio_in1). If mix_select is 1, the output should be the second audio input (audio_in2). The module should also have a reset signal (rst) that resets the output to zero when asserted.
