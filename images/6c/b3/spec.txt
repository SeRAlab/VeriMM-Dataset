Please act as a professional verilog designer.

Design a Verilog module for a 2-to-1 multiplexer. The multiplexer selects one of the two 4-bit input signals based on a select signal.

Module name:  
    mux_2to1_4bit  

Input ports:
    sel: Select signal for the multiplexer.
    in0: First 4-bit input signal.
    in1: Second 4-bit input signal.

Output ports:
    out: Multiplexer output signal with a data width of 4 bits.

Implementation:
Multiplexer operation:
If the select signal (sel) is 0, the output (out) is in0.
If the select signal (sel) is 1, the output (out) is in1.
