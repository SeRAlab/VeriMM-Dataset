Design an 8-bit DRAM cell that can read and write data. The cell should have the following inputs: a data input (8 bits), a write enable signal (1 bit), a read enable signal (1 bit), and a clock signal. The output should be the 8-bit data stored in the cell. When the write enable signal is high, the cell should store the input data on the rising edge of the clock. When the read enable signal is high, the stored data should be output. If both signals are high, prioritize the read operation. Ensure that no data is lost during simultaneous read and write operations.
