Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a half adder and a full adder. 
In digital electronics, an adder is a circuit that performs the arithmetic addition of two binary numbers. A half adder adds two single binary digits and returns a sum and carry bit. A full adder adds three binary digits and returns a sum and carry bit. 

Your module should have the following inputs and outputs for the half adder:

Inputs: two single binary digits (a, b)
Outputs: a sum bit (s) and a carry bit (c)

Your module should have the following inputs and outputs for the full adder:

Inputs: three single binary digits (a, b, cin)
Outputs: a sum bit (s) and a carry bit (cout)

To implement the half adder, you should use Verilog code to define the sum and carry bits as Boolean functions of the input signals. 

To implement the full adder, you should use Verilog code to define the sum and carry bits as Boolean functions of the input signals and the carry bit from the previous stage. You should use the half adder module to implement the first stage of the full adder, which adds the first two digits and generates a carry bit. You should then use the Verilog code to add the generated carry bit to the third input digit to produce the final sum and carry bits.
