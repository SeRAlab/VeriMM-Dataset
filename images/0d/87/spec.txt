
Create a 16-bit ADC (Analog to Digital Converter) output encoding module. The module should take a 16-bit input representing the ADC value and produce an 8-bit output representing the encoded value. The encoding follows the specification that if the ADC value is in the range of 0 to 255, the output should be the ADC value itself. If the ADC value is in the range of 256 to 511, the output should be the ADC value minus 256. If the ADC value is greater than 511, the output should be capped at 255.
