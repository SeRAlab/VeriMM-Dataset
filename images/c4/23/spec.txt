

You are tasked with designing a verilog module that implements a 4-stage delay gate with synchronous reset functionality. The module should have the following ports:

- `input A`: the input signal to be delayed
- `input reset`: a synchronous reset signal that resets the output to 0 when high
- `output X`: the delayed output signal
- `input clk`: the clock signal for the synchronous reset

The module should be named `delay_gate` and should be written in behavioral verilog.
