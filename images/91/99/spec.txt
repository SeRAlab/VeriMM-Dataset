Design a circuit that interfaces with an I2C (Inter-Integrated Circuit) module. It takes three inputs: in1 is connected to the clock signal (sclk) of the I2C, in2 serves as the interrupt signal, and in3 is unused. The output, out1, is driven by the interrupt input, effectively relaying the interrupt status from the I2C module to the output.
module top_module(
    input wire in1,
    input wire in2,
    input wire in3,
    output wire out1
);
