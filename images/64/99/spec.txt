Design a circuit that performs arithmetic operations based on the inputs. The module takes two single-bit inputs (A1 and A2) and determines the operation to perform based on the values of two control signals (B1 and C1). If B1 is high and C1 is low, it outputs the difference (A1 - A2). If both B1 and C1 are high, it outputs the product (A1 * A2). In all other cases, it outputs the sum (A1 + A2). The output is a 2-bit register (Y) to accommodate the result of the operations.
module top_module(
    input A1,
    input A2,
    input B1,
    input C1,
    output reg [1:0] Y
);
