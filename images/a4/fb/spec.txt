Implement a 16-bit register with synchronous reset and enable signals. The module should load new data when the enable signal is high.

Module name:
    register
Input ports:
    clk: clock signal
    rst: reset signal
    en: enable signal
    data_in: 16-bit input data
Output ports:
    data_out: 16-bit register output

Implementation:
The module uses an always block that triggers on the rising edge of the clock. It resets the register if the reset signal is high; otherwise, it loads new data if the enable signal is high.
