Design a 1-bit SRAM cell that can store a single bit of data. The cell should have inputs for data (D), a write signal (WE), and a clock signal (CLK). When WE is high, the data input (D) should be written to the cell on the rising edge of the clock. When WE is low, the cell should hold its previous value and not change. The output (Q) should reflect the stored value of the SRAM cell.
