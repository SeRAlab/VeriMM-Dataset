Design a 64-bit Arithmetic Logic Unit (ALU) capable of performing various operations based on a 3-bit operation code (op). The ALU can perform addition, subtraction, and bitwise operations (AND, OR, XOR) on two 64-bit inputs (lhs and rhs). It outputs the result of the selected operation, a zero flag that indicates if the result is zero, and a sign flag that denotes the sign of the result (positive or negative). The module supports multiple ALU instructions and efficiently provides the required outputs based on the operation specified by the input code.
module top_module(
	input [2:0] op,
	input [63:0] lhs,
	input [63:0] rhs,
	output [63:0] result,

			
	output zero,	
	output sign	
);
