
Create a 16-bit timer that counts up from 0 to a maximum value of 65535 (16-bit unsigned). The timer should have the following inputs:
- `clk`: Clock input
- `reset`: Asynchronous reset (active high)
- `enable`: Timer enable (active high)

The output should be a 16-bit value representing the current timer value. When enabled, the timer should increment every clock cycle until it reaches the maximum value, then it should roll over to 0.
