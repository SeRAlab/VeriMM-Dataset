
Design a simple Ethernet MAC controller that receives data and maintains a frame counter. The MAC controller should have the following features:
- An input signal `data_in` to receive incoming data (8 bits).
- A clock input `clk` to synchronize the operations.
- A reset signal `rst` to reset the frame counter.
- An output signal `frame_count` that counts the number of frames received.
- The `frame_count` increments whenever `data_in` is received.
