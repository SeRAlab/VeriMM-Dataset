Design a 4-to-1 multiplexer that selects one of four 8-bit input channels (ch_0 to ch_3) based on the 2-bit select signal. The output, data_out, corresponds to the selected input channel according to the binary value of the select signal, with the mapping being reversed such that select = 00 returns ch_3, 01 returns ch_2, 10 returns ch_1, and 11 returns ch_0.
module top_module(

input wire [1:0] select,
input wire [7:0] ch_0,
input wire [7:0] ch_1,
input wire [7:0] ch_2,
input wire [7:0] ch_3,


output reg [7:0] data_out
);
