Design a 4-bit up/down counter. On each rising edge of the clock, if the load signal is asserted, the counter resets to zero. If load is not active and the up_down signal is high, the counter increments its value; if up_down is low, it decrements its value. This module is capable of counting both upwards and downwards based on the control input, providing flexibility for various counting applications.
module top_module(
    input clk,
    input load,
    input up_down,
    output reg [3:0] count
);
