Design a PRBS (Pseudorandom Binary Sequence) checker module for a 23-bit sequence. The module accepts a clock signal and a reset signal, and it processes an incoming PRBS input signal. On reset, it initializes an internal 23-bit shift register to a predefined state. During each clock cycle, it shifts the incoming PRBS input into the register while maintaining the previous values. The feedback for the PRBS is generated by XORing specific bits of the shift register, and an error output is generated by comparing this feedback with the input PRBS signal. If they differ, an error signal is asserted, indicating a mismatch in the expected PRBS pattern.
