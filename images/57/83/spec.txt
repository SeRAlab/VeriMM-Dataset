Design a control unit for an Arithmetic Logic Unit (ALU) that interprets instructions based on a 32-bit input and a single ALU operation control signal. The module decodes the function code specified in the least significant six bits of the input, generating a four-bit output that represents various ALU operations: ALUOp=0 sets the output to a fixed operation (4'b0011), while specific function codes correspond to different ALU functions (e.g., addition, subtraction, AND, OR). This design allows the ALU to perform the correct computation based on the provided control signals and input instruction.
