

You are tasked with designing a module that takes in two input signals, `signal_d` and `signal_e`, and outputs a signal `signal_f`. The `signal_d` input is a 2-bit signal, while the `signal_e` input is a 3-bit signal. The `signal_f` output is a single bit.

Your task is to design a combinational logic circuit that takes in the two input signals and outputs a single bit signal `signal_f`. The output signal should be high if the value of `signal_d` is greater than the value of `signal_e`, and low otherwise.

You are required to implement this logic using a single module, without any submodules. Your module should be named `comparator` and should have the following inputs and outputs:

Inputs:
- `signal_d`: a 2-bit input signal
- `signal_e`: a 3-bit input signal

Outputs:
- `signal_f`: a single-bit output signal

Your module should be defined using the following code snippet:

```
module comparator(
    input [1:0] signal_d,
    input [2:0] signal_e,
    output signal_f
);

// Your code here

endmodule
```
