Design a 24-bit Digital-to-Analog Converter (DAC) module in Verilog. The module should take a 24-bit input and output a corresponding analog voltage level represented as a 12-bit integer value. The output should be calculated using a simple scaled formula where the maximum input (2^24 - 1) maps to the maximum output (4095). The module should also include a reset input to initialize the output to zero.
