Design an 8-bit ADC (Analog to Digital Converter) that takes an 8-bit binary input representing a voltage level and outputs a 3-bit binary representation of a scaled value. The scaling factor is defined as follows: the maximum 8-bit value (255) corresponds to the maximum 3-bit value (7). The output should be the scaled value of the input divided by 32 (i.e., input_value = 0 corresponds to output 0 and input_value = 255 corresponds to output 7).
