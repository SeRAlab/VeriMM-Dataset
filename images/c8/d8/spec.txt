
You are tasked with designing a verilog module for a 2:1 MUX. The module should have two input signals, one select signal, and one output signal. The select signal determines which input signal is passed to the output signal. The module should be named "mux_2_1". 

The module should be defined with the following ports:
- "in_0": a 1-bit input signal 
- "in_1": a 1-bit input signal 
- "sel": a 1-bit select signal 
- "out": a 1-bit output signal 

The module should implement the following logic:
- If "sel" is 0, then "in_0" should be passed to "out"
- If "sel" is 1, then "in_1" should be passed to "out"
