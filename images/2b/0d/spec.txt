Design a simple packet filtering firewall in Verilog that checks incoming packets based on a set of rules. The firewall should allow packets if they match a specific source IP address and a specific destination port. The design will include a clock input and a reset signal. The firewall will accept a packet with a source IP and destination port as inputs and output whether the packet is allowed (1) or blocked (0). The rules for the allowed packets are as follows: only packets from source IP '192.168.1.100' to destination port '8080' are allowed.
