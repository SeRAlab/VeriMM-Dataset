Design a parity checker that computes the parity of an 8-bit input data signal. When the control signal is low, the output parity is set to zero. When the control signal is high, the module calculates the even parity by performing an XOR operation across all bits of the input data. The resulting parity bit will be high if the number of ones in the input is odd and low if it is even, thus enabling error detection in data transmission.

  input [7:0] data_in,
  input control,
  output reg parity
