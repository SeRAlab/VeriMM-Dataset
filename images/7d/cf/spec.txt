1. state Door_Closed (door_open = 0).
2. state Door_Open (door_open = 1).

State transitions:
1. From state Door_Closed: If open_door = 1, then transition to state Door_Open. If open_door = 0, then transition to state Door_Closed.
2. From state Door_Open: If close_door = 1, then transition to state Door_Closed. If close_door = 0, then transition to state Door_Open.
