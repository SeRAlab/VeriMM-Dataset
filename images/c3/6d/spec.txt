

You have been tasked with designing a module that performs a 4-bit binary to Gray code conversion. The module should have the following inputs and outputs:

Inputs:
- `in`: a 4-bit binary input
- `clk`: a clock input

Outputs:
- `out`: a 4-bit Gray code output

Implement the module using Verilog code. Assume that the clock input is a 50MHz clock signal. You can assume that the initial binary input is 0000.
