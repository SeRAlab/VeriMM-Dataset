Design an IIR filter in Verilog that implements a simple second-order recursive filter with the following equation:  
y[n] = a1 * y[n-1] + a2 * y[n-2] + b0 * x[n] + b1 * x[n-1] + b2 * x[n-2]  
where `x[n]` is the current input, `y[n]` is the current output, and `a1`, `a2`, `b0`, `b1`, and `b2` are filter coefficients. Use fixed-point representation for the inputs and outputs. The filter should have a clock input and should update its output on the rising edge of the clock.
