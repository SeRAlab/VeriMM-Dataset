Design a Verilog module that implements a simple 3x3 Gaussian blur filter for a grayscale image. The module should take a 3x3 matrix of pixel values as input and output a single blurred pixel value. The Gaussian blur kernel used for this problem is as follows:
```
| 1 | 2 | 1 |
| 2 | 4 | 2 |
| 1 | 2 | 1 |
```
The output pixel value is computed as the weighted sum of the input pixel values divided by 16 (the sum of the weights).
