Implement an 8-bit subtractor. The module should subtract an 8-bit number b from another 8-bit number a and produce an 8-bit difference and a borrow-out bit.

Module name:
    subtractor_8bit
Input ports:
    a: 8-bit input
    b: 8-bit input
    bin: borrow-in bit
Output ports:
    diff: 8-bit difference output
    bout: borrow-out bit

Implementation:
The module uses an always block that triggers on the input change. It calculates the 8-bit difference and borrow-out using bitwise operations.
