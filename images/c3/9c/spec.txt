Please act as a professional verilog designer. Design a module that implements a 4-bit up/down counter with a synchronous reset and enable. The module should have one 1-bit input (up), one 1-bit input (en), one 1-bit input (rst), and one 4-bit output (out). When up is high, the counter should count up. When up is low, the counter should count down. When en is low, the counter should hold its current value. When rst is high, the counter should reset to zero.
