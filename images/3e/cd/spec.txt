Design a simple SATA controller state machine which has three states: IDLE, TRANSFER, and ERROR. The state transitions are based on the input signals: start (to initiate transfer) and error (to indicate an error). The controller should remain in the IDLE state until 'start' is asserted, then transition to the TRANSFER state. If 'error' is asserted during the TRANSFER state, it should transition to the ERROR state. The controller should return to IDLE state after resolving the ERROR condition.
