

You are tasked with designing a 4-bit comparator in Verilog. The module should have two 4-bit inputs, A and B, and two 1-bit outputs, EQ and GT. EQ should be high if A is equal to B, and GT should be high if A is greater than B. Otherwise, both outputs should be low.

You should use the following module declaration as a starting point:

```
module comparator (
  input [3:0] A,
  input [3:0] B,
  output EQ,
  output GT
);
  // your code here
endmodule
```
