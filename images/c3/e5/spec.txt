Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a watchdog timer.
A watchdog timer is a timer that is used to detect and recover from software malfunctions.
Your module should have the following inputs and outputs:

Inputs: a clock signal (clk) and a reset signal (rst)
Outputs: a signal (wdt) that is used to reset the system if the timer expires
The module should also have the following parameters:

timeout: the length of the timer in clock cycles
Your module should implement the following functionality:

The timer should start counting when the reset signal is set to 0 and should continue to count as long as the reset signal is 0 and the clock signal is toggling.
If the timer reaches the timeout value, the wdt signal should be set to 1, which can be used to reset the system.
If the reset signal is set to 1, the timer should be reset to 0 and the wdt signal should be set to 0.
To implement the watchdog timer, you should use Verilog code to define a counter that counts the clock cycles and compares it to the timeout value.
You should also use an if statement to check if the reset signal is 1 and reset the counter and the wdt signal accordingly.
Finally, you should use a combinational logic to set the wdt signal to 1 if the counter reaches the timeout value.
