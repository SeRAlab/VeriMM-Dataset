

You are tasked with designing a module that implements a simple 8-bit adder with a carry-in and carry-out bit. The module should have the following inputs and outputs:

Inputs:
- `a` (8-bit signed integer)
- `b` (8-bit signed integer)
- `cin` (1-bit carry-in)

Outputs:
- `sum` (8-bit signed integer)
- `cout` (1-bit carry-out)

The module should perform the following operation: `sum = a + b + cin`. If the result overflows the 8-bit signed integer range, the output should be saturated to the maximum or minimum value.

Design the module and write its Verilog code.
