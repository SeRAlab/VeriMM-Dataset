
Design a Verilog module for a flash memory cell type that can store a single bit of data. The module should have inputs for a clock signal, a data input (`din`), and a control signal (`wen` for write enable). If `wen` is high, the module should store the value of `din` in an internal register on the rising edge of the clock. If `wen` is low, the stored value should remain unchanged. The module should also have an output (`dout`) that reflects the stored value.
