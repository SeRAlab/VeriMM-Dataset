
Design a Verilog module for a Flash memory cell that can perform the following operations:
1. Write a value to the memory cell.
2. Read the value from the memory cell.
3. Erase the memory cell to reset it to a default state.

The memory cell should have an input for the data to be written, a write enable signal, a read enable signal, and an erase signal. The output will be the current value stored in the memory cell.
