Design a cryptographic random number generator (RNG) using a Linear Feedback Shift Register (LFSR). The LFSR should take a 5-bit seed input and produce a 5-bit random output. The LFSR should be clocked, and the feedback polynomial for the 5-bit LFSR should be x^5 + x^3 + 1. The output should be provided on the rising edge of the clock.
