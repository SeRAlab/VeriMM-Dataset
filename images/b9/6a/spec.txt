Design a digital vending machine controller that manages the insertion of coins and product dispensing. It accepts a 2-bit coin input corresponding to different coin values (5 cents, 10 cents, 25 cents, and 1 dollar), accumulates the total inserted amount, and allows the user to select a product for dispensing via a 2-bit control signal. If the total inserted amount meets or exceeds the predefined product price (50 cents), the selected product's corresponding dispenser output is activated, and any remaining change is calculated and output. The module also features a reset function to clear the inserted amount and dispenser states, ensuring proper initialization of the system.
module top_module(
    input clk,
    input reset,
    input [1:0] coin,
    input [1:0] dispense,
    output reg dispenser1,
    output reg dispenser2,
    output reg dispenser3,
    output reg dispenser4,
    output reg [1:0] change
);
