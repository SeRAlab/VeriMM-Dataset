Design a memory module with a 32-bit wide data interface and a 10-bit address space, supporting 8KB of addressable memory. The module operates in response to a clock signal; on a rising edge, if the write enable signal (D_WE) is asserted, it stores the input data (D_IN) at the specified address (ADDR). The output (D_OUT) provides the value stored at the address calculated from the upper bits of ADDR, effectively implementing synchronous write and asynchronous read operations for a simple SRAM-like behavior.
