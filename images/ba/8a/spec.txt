Design a one-bit wide, 2-to-1 multiplexer. The module selects between two input signals, A and B, based on the SEL signal. When SEL is 0, the output X is equal to A; when SEL is 1, the output X is equal to B. The design uses AND gates to combine the inputs with the selection signal and an OR gate to produce the final output.
module top_module(
    input A,
    input B,
    input SEL,
    output X
);
