
Create a Verilog module that implements a simple 3x3 convolution operation. The module should take a 3x3 input image (flattened into a 9-bit input), a 3x3 kernel (also flattened into a 9-bit input), and produce a single output pixel. You need to implement the convolution operation as a state machine, where the module goes through states to read the inputs and compute the output. The output should be a 10-bit result to accommodate potential overflow from the convolution.
