Design a Hamming (7,4) encoder that takes 4 data bits as input and produces 7 encoded bits as output. The Hamming code should be able to detect single-bit errors and correct them. The input data bits will be denoted as D3, D2, D1, D0 (from the most significant to the least significant). The output encoded bits will be denoted as C6, C5, C4, C3, C2, C1, C0. The parity bits are calculated based on the input data bits.
