Design an 8-bit CRC generator that accepts an 8-bit data input and generates an 8-bit CRC output based on a predefined polynomial. The CRC polynomial to be used is x^8 + x^2 + x + 1. The generator should include a 3-bit state machine to manage the CRC calculation process. The design must handle the data input in a pipelined manner, meaning that it should allow new data to be input while processing the previous input.
