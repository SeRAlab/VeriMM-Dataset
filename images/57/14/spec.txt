The sum is computed by performing bit-wise XOR operations for each bit of A and B, accounting for the carry-in and any necessary propagation of carries between bits. The carry-out signal indicates whether there is an overflow from the most significant bit, enabling further cascading of this adder in larger arithmetic operations.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input carry_in,
    output reg [3:0] sum,
    output reg carry_out
);
