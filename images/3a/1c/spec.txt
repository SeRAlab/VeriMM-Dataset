
Create an 8-bit DRAM cell that can perform read and write operations. The DRAM cell should have the following inputs: 
- `data_in`: 8-bit input data to write to the cell.
- `addr`: 3-bit address to select one of 8 cells.
- `we`: write enable signal (1 for write, 0 for read).
- `clk`: clock signal for synchronization.
The output should be `data_out`: 8-bit data read from the selected cell.
