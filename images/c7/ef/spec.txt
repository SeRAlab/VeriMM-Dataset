

Write a verilog module for a 2-to-1 multiplexer. The module should have two input bits and one select bit. If the select bit is 0, the output should be equal to the first input bit, and if the select bit is 1, the output should be equal to the second input bit. The module should also have power and ground inputs.

The module should be named `mux2to1` and should have the following ports:
- `in1`: input bit 1
- `in2`: input bit 2
- `sel`: select bit
- `out`: output bit
- `vpwr`: power input
- `vgnd`: ground input

Use the provided code snippet as a reference for the input and output port format.
