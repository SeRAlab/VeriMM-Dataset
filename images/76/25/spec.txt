Design a module that combines an 8-input priority encoder and a 2-input AND gate. The priority encoder takes an 8-bit input and outputs a 3-bit position indicating the highest-order bit that is set to 1. Additionally, the module includes an AND gate that outputs HIGH only when both of its two inputs are HIGH. This dual functionality allows the circuit to prioritize input signals while also performing logical operations based on the AND gate's conditions.
module top_module(
    input [7:0] in, // 8-bit input for priority encoder
    input a, // First input for AND gate
    input b, // Second input for AND gate
    output reg out, // Output of the functional module
    output reg [2:0] pos // Output of the priority encoder
);
