
Design a 4-bit SRAM cell with read and write functionalities. The SRAM cell should have the following interface:
- Inputs: 
  - `data_in`: 4-bit input data to be written to the SRAM.
  - `addr`: 2-bit address to select the SRAM cell (for 4 bits, 0 to 3).
  - `we`: Write enable signal (1 for write, 0 for read).
  - `clk`: Clock signal for synchronous operation.
- Output: 
  - `data_out`: 4-bit output data read from the SRAM.
