Design a binary-coded decimal (BCD) to seven-segment display decoder. This module takes a 4-bit input representing a BCD digit and outputs a 7-bit signal that corresponds to the segments required to display the digit on a seven-segment display. Each BCD value from 0 to 9, as well as the values A to E, is mapped to the appropriate segment configuration, effectively allowing for visual representation of BCD inputs on the display.
module top_module(
	input [3:0] bcd_in,
	output [6:0] out
);
