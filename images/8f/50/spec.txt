Design a circuit that serially transmits a 256-bit data frame using a clock signal with 8 times the base frequency. The module outputs a single data bit (sdo) and a frame synchronization signal (frame_sync). Upon enabling the shift, the data is loaded at the first clock cycle, signaling the start of transmission. The output bit is derived from the most significant bit of the data frame, which is then shifted to the right with each clock cycle, effectively serializing the data for transmission. The frame_sync signal briefly indicates the start of data transmission when the first bit is being shifted out.
