Design a synchronous arithmetic unit that performs either addition or subtraction on two 4-bit inputs, A and B, based on the operation control signal. When the reset signal is low, the result is cleared to zero. On the rising edge of the clock, if the reset is high, the module computes the sum of A and B when the operation signal is low, or the difference (A - B) when the operation signal is high, outputting the result as a 4-bit value.
module top_module(
  input clk,
  input reset,
  input operation,
  input [3:0] A,
  input [3:0] B,
  output reg [3:0] result
);
