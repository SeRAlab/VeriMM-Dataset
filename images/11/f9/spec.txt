A 4th-order IIR filter is to be designed where the input is a 16-bit signed sample, and the output is also a 16-bit signed sample. The filter is characterized by 5 coefficients: b0, b1, b2, b3, b4 for the feedforward part, and a1, a2, a3, a4 for the feedback part. The output is computed using the formula: 
output[n] = b0 * input[n] + b1 * input[n-1] + b2 * input[n-2] + b3 * input[n-3] + b4 * input[n-4] - a1 * output[n-1] - a2 * output[n-2] - a3 * output[n-3] - a4 * output[n-4].
Design the Verilog module for the IIR filter and create a testbench with 5 test cases.
