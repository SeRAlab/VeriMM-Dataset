Design a 2-to-4 decoder in Verilog. The decoder should have 2 input signals (A1, A0) and 4 output signals (Y0, Y1, Y2, Y3). The output signals should be high (1) for the corresponding binary value of the input signals, and low (0) otherwise. The priority should be given such that when the input is 00, Y0 is high, when the input is 01, Y1 is high, when the input is 10, Y2 is high, and when the input is 11, Y3 is high.
