Design a 4-to-1 multiplexer that selects one of four 4-bit wide input signals (a, b, c, d) based on a 2-bit select line (sel). The selected input is output on a 4-bit wide output (out). If an invalid select signal is provided, the output defaults to 0000.
module top_module(
  input [3:0] a,
  input [3:0] b,
  input [3:0] c,
  input [3:0] d,
  input [1:0] sel,
  output reg [3:0] out
);
