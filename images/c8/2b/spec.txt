

You have been tasked with designing a Verilog module for a 4-bit synchronous up-counter that counts from 0 to 15. The counter should have a synchronous reset input that clears the counter to 0 when asserted. The module should have the following inputs and outputs:

Inputs:
- `clk`: the clock signal
- `rst`: the synchronous reset signal

Outputs:
- `count`: a 4-bit output representing the current count value

Design a Verilog module that meets these requirements. You may use any Verilog constructs and primitives that you see fit.
