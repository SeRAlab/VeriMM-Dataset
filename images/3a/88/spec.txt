Design a simple EEPROM cell with read and write capabilities. The cell should have the following inputs: a `clk` for the clock signal, a `we` (write enable) signal, a `addr` for the address (3 bits), and a `data_in` (5 bits) for the data to be written. The outputs should include `data_out` (5 bits) for the read data. On a rising edge of the clock, if `we` is high, the data at the given address should be written; if `we` is low, the data from the address should be outputted on `data_out`.
