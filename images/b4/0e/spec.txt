Develop a 4-bit adder/subtractor circuit that operates in two modes, controlled by the mode input M. When M is low (0), the module performs addition of the 4-bit inputs A and B, outputting the result as S. When M is high (1), the module performs subtraction by inverting input B and adding it to A, effectively calculating A - B, and outputting the result as S.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input M,
    output [3:0] S
);
