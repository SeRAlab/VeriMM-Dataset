Design a sequential logic circuit that increments a three-bit input value by one and outputs the result on a four-bit LED display. The circuit is clock-driven and also features an asynchronous reset; when reset is activated, both the stored input value and the output are set to zero. On each rising edge of the clock, if reset is not asserted, the circuit captures the current value of the input switches and increments this value by one, driving the output accordingly.
module top_module(
    input clk, reset, 
    input [2:0] SW, 
    output reg [3:0] LED
);
