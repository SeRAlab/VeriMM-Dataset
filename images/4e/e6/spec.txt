Please act as a professional verilog designer.

Design a 2-to-1 multiplexer using Verilog. The multiplexer has a selection signal to choose between two 4-bit input signals and also has an enable signal.

Module name:  
    mux_2to1_en  

Input ports:
    a: Input signal a with a data width of 4 bits.
    b: Input signal b with a data width of 4 bits.
    sel: Selection signal.
    en: Enable signal.

Output ports:
    y: Output signal with a data width of 4 bits.

Implementation:
Multiplexer operation:
If the enable signal (en) is 0, the output (y) is assigned 4'b0000.
If the enable signal (en) is 1 and the selection signal (sel) is 0, the output (y) is assigned the value of input a.
If the enable signal (en) is 1 and the selection signal (sel) is 1, the output (y) is assigned the value of input b.
