Implement a simple decision tree inference where the input is a 3-bit binary value representing a feature set. The output should be a 2-bit binary value that represents the class inferred from the decision tree. The decision tree works as follows:
- If the input is less than 4 (binary 100), output class '00'.
- If the input is between 4 and 6 (inclusive), output class '01'.
- If the input is greater than 6, output class '10'.
