Implement a 3-to-2 binary decoder with an enable signal for selecting a city. When the enable signal is active and the read_city signal is high, the module decodes the 3-bit `select` input to generate a 2-bit output representing one of three possible cities (00, 01, or 10) while asserting a `city_done` indicator output. If the `select` input does not match any of the specified cases, it defaults to city 00. The `city_done` output confirms the completion of the city selection process.
module top_module(input read_city, input enable, input [2:0]select, output reg [1:0]city, output city_done_out);
