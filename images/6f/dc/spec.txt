Implement the Verilog module based on the following description.
Build a 16-bit register with asynchronous positive edge triggered reset, synchronous load signal, and synchronous active high clear signal.
(1) reset: Resets register to zero.
(2) load: Loads the register with data[15:0].
(3) clear: Clears the register to zero.
(4) data: The data to be loaded into the register.
(5) q: The contents of the register.

module top_module(
    input clk,
    input reset,
    input load,
    input clear,
    input [15:0] data,
    output reg [15:0] q);
