
Design a 16-bit Linear Feedback Shift Register (LFSR) that generates a pseudo-random sequence based on an initial seed value. The LFSR should use the polynomial x^16 + x^14 + x^13 + x^11 + 1, and it should have an enable signal to start/stop the shifting process. The output should be the current state of the LFSR after each shift.
