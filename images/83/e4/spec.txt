Design a 4-bit binary counter that increments its count value on each clock cycle when enabled, and resets to zero when a reset signal is activated. The counter uses two always blocks: one to update the current count on the rising edge of the clock and another to compute the next count value. When the reset signal is high, the counter holds the value at zero regardless of the enable signal.
module top_module(
  input clk,
  input reset,
  input enable,
  output reg [3:0] count
);
