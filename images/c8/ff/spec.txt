

You are tasked with designing a verilog module that takes in two 4-bit inputs, A and B, and outputs a 4-bit result, Z. The output Z should be the bitwise AND of A and B. 

Design a module named "AND4" that implements the above functionality. The module should have the following ports:

- A: a 4-bit input
- B: a 4-bit input
- Z: a 4-bit output

You are not allowed to use the "&" operator directly in your implementation. Instead, you must use the bitwise AND operator "|" and the negation operator "~" to implement the functionality.
