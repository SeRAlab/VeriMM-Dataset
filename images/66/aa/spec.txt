Design a shift register that supports both loading data and shifting operations. The module has a configurable width (defaulting to 8 bits) and operates on the rising edge of a clock signal. When a reset signal is activated, the register clears to zero. If the load signal is asserted, it captures the input data. If the shift signal is asserted, it performs a left shift on the current data, filling the least significant bit with zero while preserving the most significant bit when shifting. The output consistently reflects the current state of the register data.
