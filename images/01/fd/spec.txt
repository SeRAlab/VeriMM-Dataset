Design a 5-tap Finite Impulse Response (FIR) filter that takes a 5-bit input data and outputs a 5-bit filtered data. The filter coefficients are fixed as follows: {1, 2, 3, 2, 1}. The output is calculated by multiplying each input sample with the corresponding coefficient and summing up the results. The FIR filter should be designed to accept an input stream of data and produce an output stream after processing the last sample.
