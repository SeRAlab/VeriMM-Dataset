Design a Verilog module that implements a basic ChaCha20 stream cipher core. The module should have inputs for a 32-bit key, a 32-bit nonce, and a 32-bit counter. The output should be a 32-bit stream of pseudo-random bytes generated from the ChaCha20 algorithm. The module should perform the encryption operation on a 32-bit plaintext input using these parameters and produce a 32-bit ciphertext output.
