Design a D flip-flop with asynchronous set and reset functionality. The circuit captures the input D on the rising edge of the clock signal C. If the reset signal R is asserted, the output Q is set to LOW regardless of other inputs. If the set signal S is asserted, Q is set to HIGH. When neither R nor S is active, Q follows the value of D. This design is commonly used in memory elements and sequential logic circuits.
