

You are tasked with designing a verilog module that implements a 4-bit shift register with serial input and parallel output. The module should have the following ports:

- `clk`: clock input
- `reset`: active-high asynchronous reset input
- `serial_in`: serial input
- `parallel_out`: 4-bit parallel output

The shift register should shift the data in `serial_in` into the register on every rising edge of the clock, and output the current contents of the register on `parallel_out` on every falling edge of the clock. The shift register should be reset to all zeros when `reset` is asserted.

Write the verilog code for the shift register module.
