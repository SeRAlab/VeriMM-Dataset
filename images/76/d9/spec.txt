Implement a 2-bit binary counter with enable and synchronous reset. At each clock cycle:
- If reset = 1, the counter should reset to 0.
- If enable = 1 and reset = 0, the counter should increment by 1.
- If enable = 0 and reset = 0, the counter should hold its value.

	input clk,
	input enable,
	input reset,
	output [1:0] count);
