
Create a Verilog module that implements a simple decision tree for binary classification. The decision tree should have three inputs (A, B, C) and one output (Y). The decision rules are as follows:
1. If A > 5, then Y = 1.
2. If A <= 5 and B > 3, then Y = 1.
3. If A <= 5 and B <= 3 and C > 2, then Y = 1.
4. Otherwise, Y = 0.
