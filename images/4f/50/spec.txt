Implement a 2-to-1 multiplexer with 8-bit inputs. The module has a select signal that chooses which of the two 8-bit input values to pass to the output.

Module name:
    mux_2to1_8bit

Input ports:
    sel: Select signal to choose between the two input values.
    data_in0: First 8-bit input data.
    data_in1: Second 8-bit input data.

Output ports:
    data_out: 8-bit output data selected by the sel signal.

Implementation:
The output data_out is selected based on the value of the sel signal. If sel is 0, data_in0 is selected. If sel is 1, data_in1 is selected.
