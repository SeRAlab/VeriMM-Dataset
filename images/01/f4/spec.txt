Design a SATA controller state machine that handles three states: IDLE, TRANSMIT, and RECEIVE. The controller should transition between these states based on input signals. The state should change to TRANSMIT when the 'start_tx' signal is asserted, and return to IDLE when 'tx_complete' is asserted. The state should change to RECEIVE when 'start_rx' is asserted, and return to IDLE when 'rx_complete' is asserted. The controller should also have a reset signal that initializes the state to IDLE.
