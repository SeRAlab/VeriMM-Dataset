Design a simple Huffman encoding circuit that takes a 4-bit input (representing a character) and outputs a 3-bit Huffman code. Use the following encoding scheme:  
- '0000' -> '00'  
- '0001' -> '01'  
- '0010' -> '10'  
- '0011' -> '11'  
- All other 4-bit inputs should output 'XXX' (invalid encoding).
