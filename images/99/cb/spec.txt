Implement a Verilog module that models a 16-bit register file with 4 registers. The module should have synchronous read and write operations. The 'wr_en' signal should enable writing to the register specified by 'wr_addr'. 'rd_addr' should be used to read data from the specified register.
module reg_file (
    input clk,
    input reset,
    input wr_en,
    input [1:0] wr_addr,
    input [1:0] rd_addr,
    input [15:0] wr_data,
    output [15:0] rd_data);
