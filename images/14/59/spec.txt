Design a temperature sensor controller that takes a 4-bit binary input representing the temperature in degrees Celsius (0-15) and outputs a 3-bit binary value indicating a warning level. If the temperature is below 5°C, the output should be 3'b000. If the temperature is between 5°C and 10°C, the output should be 3'b001. If the temperature is between 10°C and 15°C, the output should be 3'b010. For temperatures above 15°C, the output should be 3'b011.
