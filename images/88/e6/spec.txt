Implement a simple 4-bit binary counter with enable and synchronous reset signals. The counter should increment on each positive clock edge when the enable signal is high. When the reset signal is active, the counter should be reset to zero.

Module name:
    binary_counter

Input ports:
	clk: Clock signal used for synchronous operations.
	rst: Synchronous reset signal.
	en: Enable signal. When high, the counter increments on each positive clock edge.

Output ports:
	count: 4-bit output representing the current counter value.
