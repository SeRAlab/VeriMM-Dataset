

You are tasked with designing a verilog module that implements a 4-bit adder-subtractor circuit. The module should have two 4-bit inputs, "A" and "B", and a 1-bit input "sub". If "sub" is set to 0, the module should add the two inputs, and if "sub" is set to 1, the module should subtract "B" from "A". The module should have a 4-bit output "result" that represents the result of the addition or subtraction.

Design the verilog module "adder_subtractor" that implements the above functionality.
