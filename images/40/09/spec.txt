Design a 2-channel Direct Memory Access (DMA) controller in Verilog. The DMA controller should be able to transfer data from one memory location to another without CPU intervention. It should support two channels, allowing one channel to be active while the other waits. Each channel should have its own configuration register for the source address, destination address, and data length. The DMA controller should also provide control signals indicating when a transfer is in progress and when a transfer is complete.
