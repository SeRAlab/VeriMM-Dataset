Design a LIFO (Last In First Out) stack with push and pop operations. The stack should have a fixed size of 4. Implement the following functionalities: 
1. Push an 8-bit data onto the stack if there is space.
2. Pop an 8-bit data from the stack if it is not empty.
3. An output signal should indicate if the stack is full or empty. 
The stack should also keep track of its depth.
