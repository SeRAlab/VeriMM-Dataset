Design a circuit that functions as a program counter selector. It takes two 5-bit program counter values (pc_plus_4 and pc_const) and a 32-bit input (rd1) and outputs a 5-bit selected program counter (pc_from_pcsel) based on a 2-bit selection signal (pcsel). When pcsel is 00, the output is set to pc_plus_4; when pcsel is 01, it outputs pc_const; and when pcsel is 10, it selects the least significant 5 bits of rd1.
