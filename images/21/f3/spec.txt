
Design a 32-bit Linear Feedback Shift Register (LFSR) in Verilog. The LFSR should take a 32-bit seed value as input and produce a new 32-bit output every clock cycle. The feedback polynomial should be defined as x^32 + x^22 + x^21 + x^20 + x^17 + x^16 + x^15 + x^14 + x^13 + x^11 + x^10 + x^7 + x^6 + x^5 + x^4 + x^3 + x^2 + 1.
