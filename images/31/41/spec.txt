Design a SR-latch using D flip-flops. The latch should set (S=1, R=0) and reset (S=0, R=1) based on the inputs. If both S and R are 0, the latch should maintain its state. If both S and R are 1, the output should be undefined (this should not occur in the simulation). Create an enable input that allows the latch to only change state when enabled.
