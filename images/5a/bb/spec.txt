Design a programmable I/O (PIO) interface module with a 4-bit bidirectional data port. This module allows for data direction control and data transfer through a bi-directional port, which can either send or receive data based on the control signals. It features a chip select signal to enable operations, a clock for synchronization, and a reset mechanism to initialize the state. The data direction for each of the 4 bits can be set dynamically, allowing for read and write operations to occur based on specified addresses. When the device is in read mode, it outputs data corresponding to the selected operation on the readdata line. The design ensures that data is correctly manipulated in accordance with the control signals during each clock cycle while providing the necessary bidirectional capabilities.
