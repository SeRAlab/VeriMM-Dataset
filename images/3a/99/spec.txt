Design a Parallel-In Parallel-Out (PIPO) shift register. The register should have a width of 8 bits and allow data to be loaded in parallel and shifted out in parallel. It should include the following inputs:
1. `clk`: Clock signal.
2. `rst`: Asynchronous reset signal (active high).
3. `load`: Load signal (active high) to load data into the register.
4. `data_in`: 8-bit input data to be loaded.
5. `shift`: Shift signal (active high) to output the current register content.
The register should have the following output:
1. `data_out`: 8-bit output data representing the current state of the register.
