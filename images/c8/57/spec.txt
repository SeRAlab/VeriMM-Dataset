

You are tasked with designing a module that performs a full adder operation on three input bits: A, B, and CIN. The module should have two output bits: COUT and SUM. 

The module should be named "my_full_adder" and should be written in Verilog within 200 lines of code. 

The full adder operation is defined as follows: 
- The SUM output bit should be the result of adding A, B, and CIN together. 
- The COUT output bit should be the carry bit resulting from the addition operation. 

You may assume that the input bits A, B, and CIN will only have binary values (0 or 1). 

Your module should include the following inputs and outputs: 
- input A: a single bit representing the first input value 
- input B: a single bit representing the second input value 
- input CIN: a single bit representing the carry-in value 
- output SUM: a single bit representing the sum of the three input bits 
- output COUT: a single bit representing the carry-out value 

You may use any Verilog syntax or operators to complete this task.
