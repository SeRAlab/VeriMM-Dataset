Design a circular shift register with 8 bits of storage. On each rising edge of the clock, if the reset signal is asserted, the shift register is initialized to zero. Otherwise, it shifts the existing data to the left and inserts the new input data bit at the least significant bit position. The current state of the shift register is continuously output as an 8-bit wide signal.
module top_module(
  input clk,
  input reset,
  input data_in,
  output reg [7:0] data_out
);
