Design a circuit that processes a 16-bit input by splitting it into two 8-bit bytes and implements a multiplexer and decoder for data selection. Depending on the state of the select signal, the circuit either outputs the high byte or low byte from the input to the high output (out_hi), while the opposite byte is sent to the low output (out_lo). This setup allows for dynamic selection between the high and low bytes based on the select signal, effectively functioning as a dual-purpose signal selector.
module top_module( 
    input wire [15:0] in,
    input wire select,
    output wire [7:0] out_hi,
    output wire [7:0] out_lo );
