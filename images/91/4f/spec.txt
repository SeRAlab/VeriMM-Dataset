Implement a Verilog module for an 8-bit shift register with parallel load, enable, and synchronous reset. The register should shift left on each positive clock edge if enable is high. If load is high, the register should load parallel_in value. If reset is high, the register should reset to 8'b00000000.
module shift_register (
    input clk,
    input reset,
    input enable,
    input load,
    input [7:0] parallel_in,
    output reg [7:0] q
);
