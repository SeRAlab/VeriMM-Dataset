Create a Verilog module for a 5-bit Fibonacci LFSR with synchronous reset and enable. The module should have an input clock signal (clk), an input enable signal (en), an input synchronous reset signal (rst), and a 5-bit output signal (lfsr). On the rising edge of the clock, if reset is high, lfsr should be set to 5'b00001. If enable is high, the LFSR should shift left and the new bit should be the XOR of the current bits 4 and 2.
