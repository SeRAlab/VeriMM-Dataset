Design a Verilog module that implements a 3x3 Gaussian blur filter for a grayscale image. The input is a 3x3 matrix of pixel values, and the output is a single blurred pixel value. The Gaussian blur operation can be represented by the following formula for a pixel value at position (i,j):

output = (1/16) * (1*p(i,j) + 2*p(i-1,j) + 2*p(i+1,j) + 2*p(i,j-1) + 2*p(i,j+1) + 4*p(i-1,j-1) + 4*p(i-1,j+1) + 4*p(i+1,j-1) + 4*p(i+1,j+1))

where p(i,j) is the pixel value at the position (i,j). The resultant output should be rounded to the nearest integer.
