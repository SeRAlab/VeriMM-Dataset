
Design an 8-bit serializer that converts an 8-bit parallel input into a serial output. The module should have a clock input, a reset input, an 8-bit input data line, and a serial output line. On each clock cycle, the serializer should output one bit of the input data starting from the least significant bit (LSB) to the most significant bit (MSB). The serialization should occur on the rising edge of the clock, and the serialization process should be initiated by a high reset signal.
