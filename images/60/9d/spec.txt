Design a 4-bit register with synchronous reset, set, and load functionalities. Upon the rising edge of the clock, the register clears to zero if the reset signal is high, sets all bits to one if the set signal is high, or loads the data input D into the register if the load signal is high. If none of the control signals are active, the output Q remains unchanged.
module top_module(
    input [3:0] D,
    input Clk,
    input reset,
    input set,
    input load,
    output reg [3:0] Q
    );
