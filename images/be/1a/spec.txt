Design a synchronous 4-bit down counter with load, enable, and clear functionalities. The counter decrements its value on each clock cycle when enabled, while allowing for a synchronous reset to zero when the clear signal is asserted. Additionally, when the load signal is active or when the counter reaches zero, it can load a preset value of 10 (binary 1010). The current count is output on a 4-bit output \( Q \).
module top_module(
    input Clock,
    input Clear,
    input Enable,
    input Load,
    output [3:0] Q
    );
