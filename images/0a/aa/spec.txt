
Design an Infinite Impulse Response (IIR) filter in Verilog. The filter should have a single input and a single output. The IIR filter will implement the following difference equation:

y[n] = a1 * y[n-1] + b0 * x[n] + b1 * x[n-1]

Where:
- y[n] is the current output
- x[n] is the current input
- y[n-1] is the previous output
- x[n-1] is the previous input
- a1, b0, and b1 are filter coefficients (fixed-point numbers)

You need to parameterize the coefficients and ensure the filter operates at a clock edge.
