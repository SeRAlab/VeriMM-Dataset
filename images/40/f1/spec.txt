Design a simple NVMe controller status indicator. Create a Verilog module that takes the status of an NVMe command (input: cmd_status) and outputs a corresponding LED signal (output: led_status). The cmd_status input is a 3-bit status that indicates whether the command is idle, in progress, or completed. The LED should light up depending on the command status: 0 (idle) - off, 1 (in progress) - yellow, 2 (completed) - green.
