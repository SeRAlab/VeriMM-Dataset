Create an SR latch using D flip-flops. The SR latch should have two inputs (S and R) and one output (Q). When S is high and R is low, Q should be set to 1. When S is low and R is high, Q should be reset to 0. When both S and R are low, Q should retain its previous value. When both S and R are high, the state is invalid. Implement this functionality in Verilog.
