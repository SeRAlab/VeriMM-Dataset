Design an 8-bit ADC (Analog to Digital Converter) that takes a 3-bit binary input representing an analog value and converts it to an 8-bit digital output. The conversion should follow the following mapping: 
- 000 -> 00000000
- 001 -> 00111111
- 010 -> 01111111
- 011 -> 01111111
- 100 -> 11111111
- 101 -> 11111111
- 110 -> 11111111
- 111 -> 11111111
The ADC output will be a direct mapping based on the input value, where the output increases with the input value.
