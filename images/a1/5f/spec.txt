Design a 4-bit up/down counter that increments or decrements its value based on the state of the `up_down` input. When `up_down` is high (1), the counter increases by one on each rising edge of the `clk` signal, and when `up_down` is low (0), it decreases by one. The counter can be reset to zero whenever the `reset` input is asserted high (1).
module top_module(
    input clk,
    input up_down,
    input reset,
    output reg [3:0] q
);
