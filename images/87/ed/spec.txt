Design a two-bit comparator circuit that compares two 2-bit inputs, A and B. The output, Z, indicates the result of the comparison: if A is greater than B, Z is set to 01; if A is less than B, Z is set to 10; and if A is equal to B, Z is set to 11.
module top_module(
  input [1:0] A,
  input [1:0] B,
  output reg [1:0] Z
);
