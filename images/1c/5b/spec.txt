
Design a current sensor system in Verilog that measures the current flowing through a load. The system should have the following specifications:
- The input to the system will be a 4-bit value representing the current in milliamps (mA).
- The output of the system will be a 3-bit value, which indicates whether the current is low (000), normal (001), or high (010) based on the input.
- The thresholds for current ranges are as follows:
  - Low: 0 - 4 mA
  - Normal: 5 - 9 mA
  - High: 10 mA and above
- The system should have a clock input for synchronization and a reset input to clear the output.
