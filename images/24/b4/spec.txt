
Design a Verilog module that implements a simple gradient descent optimizer for a single-variable function. The module should take a current value (representing a parameter), a learning rate, and a gradient (the derivative at the current value) as inputs. It should output the updated value after applying the gradient descent update rule: 
\[ \text{new\_value} = \text{current\_value} - \text{learning\_rate} \times \text{gradient} \]
The module should have a clock input to synchronize the updates.
