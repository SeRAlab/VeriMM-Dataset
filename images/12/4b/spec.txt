
Design an ARQ (Automatic Repeat reQuest) protocol-based error correction system that uses a simple acknowledgment mechanism. The system should accept a data input and a signal indicating whether the data was received correctly. If the data is received incorrectly, the system should request a retransmission. The system should output the current state (either "ACK" for acknowledgment or "NACK" for negative acknowledgment) based on the received input.
