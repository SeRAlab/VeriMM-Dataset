Design a fan speed control system that adjusts the speed of the fan based on the temperature input. The system should have two inputs: a 4-bit temperature reading and a 2-bit control signal. The fan speed output should be a 3-bit value that represents the fan speed. Based on the temperature, the fan speed should be determined as follows: if temperature < 50, speed = 3'b000 (off); if 50 <= temperature < 70, speed = 3'b001 (low); if 70 <= temperature < 90, speed = 3'b010 (medium); if temperature >= 90, speed = 3'b011 (high). The control signal can be used to enable or disable the fan. If control signal is '00', the fan is off regardless of temperature. If control signal is '01', the fan operates according to the temperature. If control signal is '10' or '11', the fan operates continuously at medium speed regardless of temperature.
