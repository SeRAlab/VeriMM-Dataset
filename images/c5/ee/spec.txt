
You are tasked with designing a Verilog module that implements a 2-bit binary comparator. The module should have two 2-bit inputs, A and B, and a 1-bit output, X. If A is greater than or equal to B, X should be set to 1; otherwise, X should be set to 0. You should use the following Verilog code snippet as a starting point:

```
module binary_comparator(
    input [1:0] A,
    input [1:0] B,
    output X
);

//your code here

endmodule
```

Your module should contain only combinational logic and should have no more than 200 lines of code. You may use any Verilog operators or constructs that you find useful, but you may not use any built-in comparison operators (such as >, <, ==, etc.). Your module should be named "binary_comparator" and should be synthesizable.
