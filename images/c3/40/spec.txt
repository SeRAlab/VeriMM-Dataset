

You are tasked to design a verilog module that takes in two 8-bit vectors and outputs their product. The module should be named "vec_multiplier". The inputs are named "vector1" and "vector2" and the output is named "product". The module should have a reset input "rst" which resets the output to 0. The module should have a clock input "clk" which is used to synchronize the computation of the product. Assume that both input vectors are signed numbers in 2's complement format. 

Write the verilog code for the "vec_multiplier" module.
