Design a 4-to-1 multiplexer with 4-bit wide inputs and a 4-bit wide output. The multiplexer selects one of the four input lines (in0, in1, in2, in3) based on a 2-bit selection signal (sel). The output is valid only when the enable signal is asserted; otherwise, the output is set to zero. If enable is low, any selected input is ignored, resulting in an output of zero.
module top_module(
    input [3:0] in0,
    input [3:0] in1,
    input [3:0] in2,
    input [3:0] in3,
    input [1:0] sel,
    input enable,
    output reg [3:0] out
);
