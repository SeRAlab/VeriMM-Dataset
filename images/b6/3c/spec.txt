Design a 4-bit up/down counter with load capability. The counter increments or decrements its value based on the 'up_down' input: when 'up_down' is high, the counter increments, and when low, it decrements. It can be reset to zero asynchronously using the 'reset' input or loaded with a specific value through the 'load' input, which allows direct loading of the current count value. The output 'count' reflects the current value of the counter.
module top_module(
    input up_down,
    input load,
    input clock,
    input reset,
    output reg [3:0] count
);
