Design a simple SPI master controller that can send data to an SPI slave device. The master should be able to send a byte of data (8 bits) over the SPI bus, and the controller should include a clock signal for synchronization. The master will have a start signal input and will generate a clock signal for data transfer. Implement the functionality to send one byte of data when the start signal is asserted. Include a mechanism to indicate the completion of the data transfer.
