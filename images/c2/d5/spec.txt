

You have been tasked with designing a module for a processor. The module should take in two 8-bit inputs, A and B, and output a 9-bit result, C. The output should be the sum of A and B, with an additional carry bit if the sum exceeds 255 (the maximum value for an 8-bit number).

Your module should be named "adder" and should be written in Verilog. The module should include the following ports:

- A (input, 8 bits)
- B (input, 8 bits)
- C (output, 9 bits)

Your module should be able to handle all possible combinations of A and B inputs, and should output the correct sum and carry bit for each case.

Write a Verilog module named "adder" that takes in two 8-bit inputs, A and B, and outputs a 9-bit result, C, as described above.
