Design a LED controller module that manages a 10-bit wide data output based on specific address and chip select signals. The controller supports write operations to a data register when chip select is active, reset is inactive, and the address is zero. The read operation outputs the current data held in the data register, while also ensuring that the output port reflects the latest written data. Additionally, the module is designed to handle reset functionality on a negative edge, initializing the stored data to zero.
module top_module(
  input [1:0] address,
  input chipselect,
  input clk,
  input reset_n,
  input write_n,
  input [9:0] writedata,
  output reg [9:0] out_port,
  output reg [31:0] readdata
);
