Design a Verilog module that simulates a TCP segmenter. The module should take in a data stream of 8-bit packets and output 32-bit TCP segments. The segmentation should work as follows: each 4 packets (32 bits in total, as each packet is 8 bits) should be combined into a single TCP segment. If there are less than 4 packets at the end of the stream, the remaining packets should still be combined into a segment and padded with zeros to fill the remaining bits.
