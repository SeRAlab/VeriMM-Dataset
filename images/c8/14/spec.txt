

You are tasked with designing a module in Verilog that implements a flip-flop with synchronous reset and enable. The module should have the following inputs and outputs:

Inputs:
- `CLK`: clock signal
- `D`: data input
- `RST`: synchronous reset signal (active high)
- `EN`: enable signal (active high)

Outputs:
- `Q`: output data

The module should implement the following behavior:
- If `EN` is low, the output `Q` should hold its previous value.
- If `EN` is high, the output `Q` should follow the input `D`.
- If `RST` is high, the output `Q` should be reset to 0.

You should implement the module within 200 lines of Verilog code.
