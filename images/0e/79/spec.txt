Design a 1-bit SRAM cell that can perform read and write operations. The cell should have inputs for data (D), write enable (WE), and a read enable (RE) signal. The output should be the stored value (Q). When WE is high, the input data should be stored in the cell. When RE is high, the stored value should be outputted. If both WE and RE are low, the cell should hold its previous state.
