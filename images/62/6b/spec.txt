1. From state X: If in = 0, then transition to state Y. If in = 1, then transition to state Z.
2. From state Y: If in = 0, then transition to state Z. If in = 1, then transition to state X.
3. From state Z: If in = 0, then transition to state X. If in = 1, then transition to state Y.

Output logic:
1. From state X: out = in.
2. From state Y: out = ~in.
3. From state Z: out = 1'b0.

  input in,

  output reg out);
