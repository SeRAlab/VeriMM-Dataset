Implement a LIFO stack using Verilog. The stack should have the following features:
- A push operation to add an item to the top of the stack.
- A pop operation to remove the item from the top of the stack.
- An output to show the current top item of the stack.
- A full signal to indicate if the stack is full.
- An empty signal to indicate if the stack is empty.
The stack size will be defined as 4 items.
