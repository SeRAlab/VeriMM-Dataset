
Design a 4-bit Serial-In Serial-Out (SISO) shift register using Verilog. The shift register should have a serial input (SI), a clock input (CLK), a reset input (RST), and a serial output (SO). When the reset signal is asserted, the register should clear to zero. On each clock edge, if the SI is high, the bit is shifted into the register, and the oldest bit in the register is shifted out to the SO.
