Design a monostable multivibrator that generates a high pulse for a specified duration (t clock cycles) upon receiving a trigger signal. When the trigger is activated, the output pulse is set high, and a counter starts counting clock cycles. The pulse remains high as long as the counter is less than the specified duration; once the counter reaches the duration, the pulse is set low. This module effectively produces a single output pulse triggered by a signal, with the width of the pulse determined by the parameter t.
module top_module(
  input trigger,
  input clk,
  output reg pulse
);
