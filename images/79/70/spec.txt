Design a single-bit register that can either load a new value or perform an addition operation with an input value upon the rising edge of the clock signal. The module features an asynchronous reset (rst) to clear the stored value, a load signal (load) to determine whether to load the input data (D) or perform addition with the previously stored value. The output (Q) reflects the current state of the register. When load is high, the register takes on the value of D; otherwise, it adds D to its current stored value.
module top_module(
    input clk,
    input rst,
    input load,
    input [0:0] D,
    output [0:0] Q
);
