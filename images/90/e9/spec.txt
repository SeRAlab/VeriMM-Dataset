Design a synchronous one-bit full adder circuit that computes the sum of three input bits: A, B, and a carry-in bit (CarryIn). The sum output (S) and carry-out (CarryOut) are updated on the rising edge of the clock signal (clk). The logic used combines bitwise XOR for the sum and determines the carry-out using bitwise AND and OR operations.
module top_module(
		input A,
		input B,
		input CarryIn,
		input clk,
		output reg S,
		output reg CarryOut
		);
