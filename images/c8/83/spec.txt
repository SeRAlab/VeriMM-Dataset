

You are tasked with designing a module that takes in 4 inputs and produces 1 output. The module should be named `four_to_one` and should be written in Verilog.

The inputs to the module are:
- `in1` (1-bit)
- `in2` (1-bit)
- `in3` (1-bit)
- `in4` (1-bit)

The output from the module is:
- `out` (1-bit)

The output should be the result of the following logic:
- If `in1` is 1, `out` should be 1
- If `in1` is 0 and `in2` is 1, `out` should be 1
- If `in1` and `in2` are 0 and `in3` is 1, `out` should be 1
- If all inputs are 0, `out` should be 0

You may use any Verilog operators and constructs to implement this module.
