Design a 4-to-1 multiplexer that selects one of four 7-bit wide input signals (A, B, C, or D) based on a 2-bit select signal (sel). When sel is 00, the output Y is equal to input A; when sel is 01, Y reflects input B; when sel is 10, Y corresponds to input C; and when sel is 11, Y outputs input D.
module top_module(input [6:0] A,  
		input [6:0] B,  
		input [6:0] C,
		input [6:0] D,  
		input [1:0] sel,  
		output [6:0] Y);
