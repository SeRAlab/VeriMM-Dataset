Develop a D flip-flop with a synchronous reset. On the rising edge of the clock, if the reset signal is asserted, the output q is set to LOW; otherwise, the output q adopts the value of input d from a registered intermediate signal q1. This design effectively captures and stores a single-bit data input (d) in synchronization with a clock signal while providing the capability to reset the output to zero.

    input clk,
    input reset,
    input d,
    output reg q
