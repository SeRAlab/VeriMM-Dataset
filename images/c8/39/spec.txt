

Create a Verilog module that takes 3 inputs, `a`, `b`, and `c`, and produces a single output `x`. The output `x` should be equal to 1 if and only if at least two of the inputs `a`, `b`, and `c` are equal to 1. Otherwise, the output `x` should be 0. 

Use the following module declaration to implement your design:
```
module logic_unit (
    input a,
    input b,
    input c,
    output x
);
```
