Design a circuit that performs a bitwise left shift operation on an 8-bit input. The circuit takes an 8-bit input `data_in` and a 3-bit `shift_amount` to determine how many positions to shift the input to the left. If the `shift_amount` exceeds 7, the output will be set to zero; otherwise, the output `data_out` will be the result of the left shift operation on `data_in`.
module top_module(
    input [7:0] data_in,
    input [2:0] shift_amount,
    output reg [7:0] data_out
    );
