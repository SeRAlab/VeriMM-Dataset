Design a finite state machine (FSM) that manages two distinct states: an initialization state and a write state. The FSM transitions from the initialization state to the write state when the `init_done` signal is asserted, and remains in the write state indefinitely. The state transitions are synchronized with the clock signal, and the FSM resets to the initialization state when the reset signal is activated. This design is suitable for controlling processes that require initialization followed by a sustained operation.
