
Design a simple Ethernet MAC controller state machine that handles the transmission of data frames over Ethernet. The MAC controller should have the following states:
1. IDLE: Waits for a frame to be ready for transmission.
2. TRANSMIT: Sends the frame over the network.
3. WAIT: Waits for the transmission to complete.
4. ERROR: Indicates an error during transmission.

The controller should take a start signal to begin transmission and a frame valid signal to indicate that a frame is ready for transmission. The output should indicate the current state of the machine.
