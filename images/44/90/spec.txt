Design a 4-bit adder-subtractor module. The module takes two 4-bit inputs, A and B, and a control signal SUB. When SUB is low, the module outputs the sum of A and B. When SUB is high, it outputs the difference of A and B. The output Q is therefore the result of either the addition or subtraction based on the state of the SUB signal.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input SUB,
    output [3:0] Q
);
