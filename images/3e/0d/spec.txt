
Design a 16-bit timer that counts up from 0 to 65535. The timer should have the following inputs:
- `clk`: Clock input
- `reset`: Asynchronous reset input (active high)
- `enable`: Enable input (active high)

The timer should increment its value on each rising edge of the clock when the enable signal is high. When the reset signal is asserted, the timer value should reset to 0. The output should be a 16-bit value representing the current timer count.
