
Design a simple Ethernet MAC controller that can receive and transmit frames. The MAC controller should have the following functionalities:
1. Receive Frame: When a frame is received, it should be stored in a register.
2. Transmit Frame: When a frame is to be transmitted, it should be taken from a register and output on the data line.
3. Control signals: There should be a valid signal for indicating the presence of data to be transmitted or received.
