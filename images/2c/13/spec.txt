Design a 256-bit AES encryption module in Verilog. The module should take a 256-bit plaintext input and a 256-bit key input, and output a 256-bit ciphertext after a fixed number of rounds. You need to implement the core components of the AES algorithm, including key expansion, substitution, permutation, and mixing during the encryption process. The module should also include a clock signal and a reset signal to control the operation.
