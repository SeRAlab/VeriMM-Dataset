Design a low-power buffer that selectively drives its output based on a clock signal and an enable signal. When enabled, it captures the input value on the rising edge of the clock and holds this value in a register. The output is driven high only when the buffer is active and enabled; otherwise, it outputs a LOW. Additionally, the module includes a sleep transistor controlled by a sleep enable signal, allowing the buffer to enter a low-power state when not in use. This design effectively reduces power consumption while maintaining the functionality of a standard buffer.
