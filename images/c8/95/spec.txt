

You are tasked with designing a module that takes in 5 inputs and produces 1 output. The module should be named `five_to_one` and should have the following inputs and outputs:

- `input A1`: a 1-bit input
- `input A2`: a 1-bit input
- `input B1`: a 1-bit input
- `input C1`: a 1-bit input
- `input D1`: a 1-bit input
- `output Y`: a 1-bit output

The module should contain the following internal signals:

- `wire temp1`: a 1-bit wire
- `wire temp2`: a 1-bit wire

The module should perform the following operations:

- If `A1` and `A2` are both 1, `temp1` should be set to 1. Otherwise, `temp1` should be set to 0.
- If `B1` and `C1` are both 1, `temp2` should be set to 1. Otherwise, `temp2` should be set to 0.
- If `temp1` and `temp2` are both 1, `Y` should be set to 1. Otherwise, `Y` should be set to 0.

Design the `five_to_one` module to meet these specifications.
