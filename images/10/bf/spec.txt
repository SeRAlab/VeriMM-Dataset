Design a simple Ethernet MAC controller state machine that manages the transmit process. The state machine should have the following states: IDLE, TRANSMIT, and WAIT_FOR_ACK. The state transitions should be controlled by a clock signal and a transmit request signal (tx_req). When tx_req is asserted, the state machine should move from IDLE to TRANSMIT. Upon completion of the transmit process, it should wait for an acknowledgment signal (ack) before returning to IDLE.
