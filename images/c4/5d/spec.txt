Please act as a professional Verilog designer. Your task is to design a Verilog module that implements a clock gating cell. 
A clock gating cell is a circuit that is used to control the flow of clock signals to a particular section of a digital circuit in order to reduce power consumption. 
Your module should have the following inputs and outputs:

Inputs: 
- clock: the input clock signal
- enable: the enable signal that controls the clock gating cell
Outputs: 
- gated_clock: the output clock signal after gating

Your module should implement the following functionality:
- When the enable signal is high, the output clock signal should be the same as the input clock signal.
- When the enable signal is low, the output clock signal should be held at a logical 0 value.

To implement the clock gating cell, you should use Verilog code to design a circuit that controls the flow of the clock signal based on the value of the enable signal. 
You should then use this circuit to create the output clock signal that is either the same as the input clock signal or held at a logical 0 value.
You should also make sure that the module takes into account any potential clock skew or delay that may occur due to the clock gating.
