Design a clock gating circuit that controls the output clock based on enable and test signals. The module outputs the gated clock `output_clk`, which is derived from the input clock `input_clk` only when the `input_en` (enable) signal is high and the `input_te` (test enable) signal permits. This design is commonly used for power management in digital circuits to reduce dynamic power consumption by allowing the clock signal to be disabled under certain conditions.
module top_module(
    input input_clk,
    input input_en,
    input input_te,
    output output_clk
);
