Design a 32-bit Arithmetic Logic Unit (ALU) that performs a variety of operations based on a 4-bit control signal. The ALU supports addition, subtraction, bitwise AND, bitwise OR, bitwise XOR, NOR, and a less-than comparison between two inputs (alu_a and alu_b). The output value (alu_out) is assigned based on the specified operation, while a zero output signal indicates whether the result of the operation is zero. The module is also equipped with a reset input, allowing for initialization.
module top_module(
	input rst,
	input [3:0]ALUcontrol,
	input [31:0]alu_a,
	input [31:0]alu_b,
	output zero,
	output reg[31:0]alu_out
);
