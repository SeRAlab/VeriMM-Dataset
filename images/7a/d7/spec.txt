Design a 2-to-4 line decoder with an enable input. The module takes a 2-bit input (A) and produces four outputs (D[0] to D[3]). When the enable (E) is active, the output corresponding to the binary value represented by A will be set high, while all other outputs will remain low. If E is inactive, all outputs will remain low regardless of the input values of A.
module top_module(
	output	[0:3] D,
	input		E,
	input		[1:0] A
    );
