Design an interrupt controller that manages multiple interrupts from different sources. The interrupt controller should have the following features: it should accept 4 interrupt signals (irq[3:0]), a reset signal (rst), and a clock signal (clk). When an interrupt signal is asserted, it should be acknowledged and a corresponding interrupt number should be stored. The controller should maintain the priority of interrupts, with irq[3] having the highest priority and irq[0] having the lowest. The output of the controller should be the current acknowledged interrupt (ack_irq). The controller should also have a clear functionality that resets the acknowledged interrupt.
