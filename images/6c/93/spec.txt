Design a 4-to-1 multiplexer that selects one of four input data lines (A, B, C, or D) based on a 2-bit select signal (sel). The output (Y) corresponds to the chosen input based on the value of sel, where sel=00 results in Y=A, sel=01 results in Y=B, sel=10 results in Y=C, and sel=11 results in Y=D.
module top_module(
    input A, B, C, D,
    input [1:0] sel,
    output reg Y
);
