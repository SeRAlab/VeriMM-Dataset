Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a D latch. 
A D latch is a type of sequential circuit that can store one bit of data. It has two inputs: D (data) and C (clock), and one output: Q (output). 
When the clock signal is high, the D input is stored in the latch and appears at the output Q. When the clock signal is low, the latch holds its previous output value.

Your module should have the following inputs and outputs:

Inputs: D (data), C (clock)
Outputs: Q (output)

To implement the D latch, you should use Verilog code to describe the behavior of the latch. 
You should use a single always block to define the behavior of the latch. 
This always block should trigger on the positive edge of the clock signal and update the output Q with the value of the input D. 
When the clock signal is low, the latch should hold its previous output value.

You should use the following Verilog code to define the module and its IO:

module d_latch(
  input D,

  output Q
