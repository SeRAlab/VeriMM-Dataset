Design a 16-bit shift register that can shift either left or right based on a control signal. The shift register should have an input data line, a control signal for determining the direction of the shift (left or right), a clock signal, and an output data line that holds the current value of the shift register. When the control signal is high, the shift should occur to the left; when low, the shift should occur to the right. The shift register should also include a reset signal that clears the register.
