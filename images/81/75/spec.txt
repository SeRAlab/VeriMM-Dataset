Design a 4-to-1 multiplexer that accepts four 8-bit input data lines (A, B, C, D) and uses two select lines (S0 and S1) to determine which input to pass to the 8-bit output (Y). The module outputs A when both selects are low (00), outputs B when S0 is high and S1 is low (01), outputs C when S1 is low and S0 is high (10), and outputs D when both selects are high (11).
module top_module(
    input [7:0] A,
    input [7:0] B,
    input [7:0] C,
    input [7:0] D,
    input S0,
    input S1,
    output reg [7:0] Y
);
