Design a D flip-flop with asynchronous active-low reset functionality. The flip-flop captures the input data (D) on the rising edge of the inverted clock signal (CLK_P) and outputs the stored value (Q). When the active-low reset signal (RESET_B) is asserted, the output Q is asynchronously set to LOW regardless of the clock state. Additionally, the circuit is designed to operate with power supply inputs (VPWR and VGND) indicating its power requirements.
module top_module(
    input  wire RESET_B,
    input  wire CLK_N,
    input  wire D,
    output reg  Q,
    input  wire VPWR,
    input  wire VGND
);
