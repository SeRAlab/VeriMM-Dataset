
Design a 5-stage pipelined processor architecture that performs a simple arithmetic operation (e.g., addition) on two 8-bit inputs. The pipeline should consist of the following stages:
1. Instruction Fetch (IF)
2. Instruction Decode (ID)
3. Execute (EX)
4. Memory Access (MEM)
5. Write Back (WB)

The processor should take two 8-bit inputs A and B, perform the addition A + B in the EX stage, and output the result after the WB stage. The pipeline should also handle stalling when necessary (for simplicity, assume a stall signal is provided).
