Design a 3-to-1 multiplexer that selects one of three 64-bit input data signals (a0, a1, a2) based on a 3-bit select input. If select corresponds to binary '001', the output a will be set to a0; if it corresponds to '010', a will be set to a1; if it corresponds to '100', a will be set to a2. For any other select value, the output will default to zero.
module top_module(
					select,
					a0,
					a1,
					a2,
					a
				);
