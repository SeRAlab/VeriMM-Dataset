
Create a simple memory manager in Verilog that can allocate and free a memory block of a fixed size. The memory manager will have the following operations:
1. Allocate a block: Set a signal to indicate a request to allocate a block.
2. Free a block: Set a signal to indicate a request to free a previously allocated block.
3. Output the status of the memory (allocated/free).
The memory size is fixed at 4 blocks.
