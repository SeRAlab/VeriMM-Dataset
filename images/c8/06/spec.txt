

You have been tasked with designing a module that will implement a 4-bit up-counter in Verilog. The module should have the following inputs and outputs:

Inputs:
- `clk` (1-bit): the clock signal
- `rst` (1-bit): the reset signal

Outputs:
- `count` (4-bit): the current count value

The counter should increment on each rising edge of the clock signal, unless the reset signal is asserted. If the reset signal is asserted, the counter should be reset to 0.

Write the Verilog code for this module.
