Design a 8-to-1 multiplexer that selects one of eight input signals (I0 to I7) based on a 3-bit selection input (SEL) and an enable signal (EN). When EN is asserted (high), the output Y will reflect the selected input based on the current value of SEL; if EN is low, the output Y will remain unaffected by the inputs.
module top_module(
    input I0, I1, I2, I3, I4, I5, I6, I7, EN,
    input [2:0] SEL,
    output Y
    );
