Design a fan speed control system that takes a 3-bit input representing temperature levels (from 0 to 7) and produces a 2-bit output representing the fan speed (from 0 to 3). The fan speed should be determined based on the temperature level:  
- 0-1: Fan Speed 0  
- 2-4: Fan Speed 1  
- 5-6: Fan Speed 2  
- 7: Fan Speed 3  
The system should also have a reset signal that sets the output to 0 when activated.
