Design a 3-to-8 line decoder that takes a 3-bit binary input and activates one of the eight output lines corresponding to the input value. When the input, represented by `abc`, is between 0 and 7, the respective output bit in the 8-bit output `d` is set high, while all other outputs remain low, effectively enabling a unique output for each input combination.
module top_module(
    input wire [2:0] abc,
    output reg [7:0] d
);
