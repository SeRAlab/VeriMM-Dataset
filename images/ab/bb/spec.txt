Design a 4-bit Arithmetic Logic Unit (ALU) that performs addition or subtraction based on a control input and supports various arithmetic and logical operations. The ALU takes two 4-bit inputs, A and B, along with a control signal C to determine whether to add or subtract A and B. Additionally, the ALU can perform operations such as addition, subtraction, bitwise AND, bitwise OR, bitwise XOR, and bit shifts on a separate 4-bit input, ALU_in, utilizing a 3-bit operation selector (OP). The module outputs the result of the combined operations, effectively allowing for complex arithmetic and logical computations.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input C,
    input [3:0] ALU_in,
    input [2:0] OP,
    output reg [3:0] out
);
