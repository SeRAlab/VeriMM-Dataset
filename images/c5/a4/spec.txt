

You are tasked with designing a module for a signal repeater that takes in a 136-bit signal and outputs the same signal. The module should be named `signal_repeater` and have two ports: `input_signal` and `output_signal`. The input port should be named `in` and the output port should be named `out`. 

The module should have the following functionality:
- The module should have an `always` block that assigns the value of the input signal to the output signal.
- The module should be able to handle any 136-bit input signal.

Write the code for the `signal_repeater` module that meets the above requirements.
