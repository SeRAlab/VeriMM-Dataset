
Design a 32-bit ChaCha20 quarter round function in Verilog. The quarter round function takes four 32-bit inputs (a, b, c, d) and produces four 32-bit outputs. The function is defined as follows:
1. a += b; d ^= a; d <<<= 16;
2. c += d; b ^= c; b <<<= 12;
3. a += b; d ^= a; d <<<= 8;
4. c += d; b ^= c; b <<<= 7;

Your task is to implement this quarter round function in Verilog and create a testbench to verify its functionality with 5 test cases.
