

You are tasked with designing a verilog module for a 4-bit adder that performs addition of two 4-bit numbers. The module should have the following inputs and outputs:

- `input [3:0] A`: 4-bit input for the first number
- `input [3:0] B`: 4-bit input for the second number
- `input CLK`: clock input
- `input RST`: reset input
- `output reg [4:0] SUM`: 5-bit output for the sum of the two numbers

The module should operate as follows:
- On the rising edge of the clock (`posedge CLK`), if `RST` is high, the `SUM` output should be set to 0.
- If `RST` is low, the `SUM` output should be set to the sum of `A` and `B` inputs, with the least significant bit of the sum being stored in the least significant bit of the `SUM` output.
