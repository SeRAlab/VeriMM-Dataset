Create a Verilog module that implements an 8-bit linear feedback shift register (LFSR) with a tap sequence for polynomial x^8 + x^6 + x^5 + x^4 + 1. The module should have an input clock signal (clk), an input reset signal (rst), and an 8-bit output signal (q). On the rising edge of the clock, if reset is high, q should be set to 8'b1. Otherwise, q should shift left by one bit with the new bit being the XOR of q[7], q[5], q[4], and q[3].
