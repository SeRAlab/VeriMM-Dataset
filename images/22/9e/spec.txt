Design a simple Stop-and-Wait protocol controller in Verilog. The controller should manage the transmission of bits over a single channel, allowing for acknowledgments from the receiver after each bit is sent. The controller should have a `send_bit` input signal to trigger sending a bit and an `ack` input signal to acknowledge receipt of the bit. It should have an output signal `sent_bit` indicating the bit that has been sent. The system should reset when the `reset` signal is high.
