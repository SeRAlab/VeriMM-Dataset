
Design an Infinite Impulse Response (IIR) filter using Verilog. The filter should take a 16-bit input sample and produce a 16-bit output sample. The filter will have two coefficients, a0 and a1, and will implement the following difference equation:
y[n] = a0 * x[n] + a1 * y[n-1]
where 'x' is the input and 'y' is the output.
