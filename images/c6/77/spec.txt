

You are tasked with designing a verilog module for a simple 2-input AND gate. The module should have two input ports, A and B, and one output port, Y. The output should be the result of the logical AND operation between A and B. The module should have a positive-edge triggered clock input, CLK, and an asynchronous reset input, RST. When RST is asserted, the output should be set to 0. When CLK rises, the output should be updated with the result of the AND operation between A and B.

Design the module and provide the verilog code for it.
