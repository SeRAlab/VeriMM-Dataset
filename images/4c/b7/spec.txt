Design a 4-to-1 multiplexer that selects one of four 1-bit input signals based on a 2-bit selection input. The output will reflect the value of the selected input: when sel=00, the output will be in[0]; when sel=01, the output will be in[1]; when sel=10, the output will be in[2]; and when sel=11, the output will be in[3].
module top_module(
    input wire [3:0] in,
    input wire [1:0] sel,
    output reg out
);
