
Design an interrupt controller that can handle up to 4 different types of interrupts. The controller should have the following functionality:
1. An interrupt request (irq) input signal that indicates whether an interrupt has occurred.
2. A priority input (prty) that determines the priority of the interrupt (0-3, where 0 is the highest priority).
3. An acknowledge output (ack) that indicates when the interrupt is acknowledged by the CPU.
4. The controller should also have a reset signal (rst) to initialize the state.
5. The interrupt must be serviced based on its priority, and only one interrupt can be acknowledged at a time.

Assume that the controller can only service interrupts when the ack signal is low (inactive).
