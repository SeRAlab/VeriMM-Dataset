Design a Verilog module for a Flash memory cell that can store a single bit of data. The memory cell should have the following inputs and outputs: a `data_in` input for writing data, a `write_enable` control signal to determine when to write the input data, a `read_enable` control signal to determine when to output the stored data, and a `data_out` output for reading the stored data. The cell should behave as follows: when `write_enable` is high, the `data_in` should be stored in the cell. When `read_enable` is high, the `data_out` should reflect the stored data.
