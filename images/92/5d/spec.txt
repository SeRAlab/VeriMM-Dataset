Implement the Verilog module based on the following description. Create a finite state machine that controls a vending machine with three states: IDLE, DISPENSE, and OUT_OF_STOCK. The vending machine has two inputs: `coin` and `stock`. The machine transitions from IDLE to DISPENSE when a coin is inserted (coin = 1) and stock is available (stock = 1). It transitions to OUT_OF_STOCK when there is no stock (stock = 0). Use an asynchronous reset to set the initial state to IDLE.
