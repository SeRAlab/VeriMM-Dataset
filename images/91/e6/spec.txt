Develop a circuit that performs a bitwise XOR operation on two 4-bit input vectors, vec1 and vec2, resulting in a 4-bit output (out_xor). Additionally, generate a single output for each bit of the first input vector ANDed with the second input vector, providing the most significant bit (o4) directly and the individual bits of the XOR result (o3, o2, o1, and o0) as separate outputs. This design integrates essential logical operations for composable digital signal processing.
module top_module(
    input wire [3:0] vec1,
    input wire [3:0] vec2,
    output wire [3:0] out_xor,
    output wire o4,
    output wire o3,
    output wire o2,
    output wire o1,
    output wire o0
);
