

You are tasked with designing a Verilog module that implements a 4-bit adder. The module should have two 4-bit inputs, A and B, and a 4-bit output, S, where S = A + B. The module should also have a carry output, COUT, which should be high if the addition operation results in a carry.

Your module should be named "adder4" and should be self-contained, meaning it should not rely on any external modules. Your module should be implemented within 200 lines of Verilog code.

Please write a Verilog module that satisfies the above requirements and provide the code for it.
