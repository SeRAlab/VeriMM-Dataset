
Create a Verilog module that performs nearest neighbor interpolation for a 2x2 pixel image. The input will be two 2-bit pixel values (A and B) and the output will be a 4-bit interpolated pixel value based on the nearest neighbor approach. The outputs should be:
- If A is selected, output should be 00 (A's intensity).
- If B is selected, output should be 11 (B's intensity).
- If neither is selected, output 10 (default intensity).
