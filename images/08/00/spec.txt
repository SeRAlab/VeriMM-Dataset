
Create a module that computes the inverse of a 2x2 matrix. The input will be a 2x2 matrix represented as four 8-bit values. The output will be the inverse of the matrix, also as four 8-bit values. The formula for the inverse of a 2x2 matrix [[a, b], [c, d]] is given by (1/det) * [[d, -b], [-c, a]], where det = ad - bc. If the determinant is zero, the output should be set to zero.
