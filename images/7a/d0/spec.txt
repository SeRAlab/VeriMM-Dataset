Design a memory buffer module capable of reading and writing 8-bit data to a 10-entry memory array. The module employs a 4-bit address bus to access specific memory entries based on the provided `read_address`. Writing occurs when the `wr_en` signal is active, storing `data_in` at the specified `address`, while an edge-detection mechanism ensures proper handling of the write enable signal. A reset function, controlled by `mem_rst`, initializes the memory entries to zero and sets the address back to zero. The output `data_out` reflects the contents of the memory at the `read_address` at all times.
module top_module(data_out, data_in, address, read_address, wr_en, clk, mem_rst);
