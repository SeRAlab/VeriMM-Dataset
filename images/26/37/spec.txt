Design a simple UART receiver module that receives 8-bit data with start and stop bits. The module should have inputs for the received serial data bit (`rx`), a clock signal (`clk`), and a reset signal (`reset`). The output should be an 8-bit data (`data_out`) and a signal indicating that the data is ready (`data_ready`). The receiver will sample the `rx` line at the rising edge of the clock and should be able to process incoming bits correctly based on UART protocol.
