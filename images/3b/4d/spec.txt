Design a 4-bit DRAM cell that can store a 4-bit value and can perform the following operations: write, read, and reset. The cell should have inputs for write enable (we), read enable (re), reset (rst), and a 4-bit data input (d_in), and a 4-bit data output (d_out). The output should reflect the stored value when read, and should allow writing of a new value when write enable is active.
