Design a 16-bit Digital-to-Analog Converter (DAC) module in Verilog. The DAC takes a 16-bit binary input and produces an analog output represented as a floating-point value in the range from 0.0 to 5.0 V. The conversion formula for the output voltage (Vout) is given by Vout = (Vin / 65535) * 5.0, where Vin is the 16-bit input value.
