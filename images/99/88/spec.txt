Design a 4-to-1 multiplexer that selects one of four 8-bit input data lines (in_1, in_2, in_3, in_4) based on a 2-bit selection input. The chosen input is output as an 8-bit result. When select is 00, in_1 is passed to the output; for 01, in_2 is selected; for 10, in_3 is routed; and for 11, in_4 is output.
module top_module(
    input [1:0] select,
    input [7:0] in_1,
    input [7:0] in_2,
    input [7:0] in_3,
    input [7:0] in_4,
    output reg [7:0] out
);
