Design a 4-bit arithmetic unit that can perform either addition or subtraction based on a control signal. When the control signal `sub` is set to 1, the module computes the difference between `num1` and `num2`. When `sub` is 0, it computes the sum of `num1` and `num2`. The result of the arithmetic operation is output as a 4-bit value.
module top_module(
  input [3:0] num1,
  input [3:0] num2,
  input sub,
  output reg [3:0] result
);
