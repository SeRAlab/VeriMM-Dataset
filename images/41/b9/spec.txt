Design a state machine that detects the pressing and releasing of a key based on an input signal. The module tracks three states: "KEY_FREE," "KEY_PRESSED," and "KEY_RELEASED." Upon a clock pulse, if the reset signal is low, it transitions to the "KEY_FREE" state. When in the "KEY_FREE" state, if the input signal is low, it transitions to "KEY_PRESSED." If the input goes high while in the "KEY_PRESSED" state, it transitions to "KEY_RELEASED." When in "KEY_RELEASED," it sets the output to high for one cycle and then returns to "KEY_FREE." The purpose of this design is to provide a single pulse output (enable_out) upon the release of a key, which can be used to trigger other processes.
