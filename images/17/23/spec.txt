Design a Verilog module that implements a simple portfolio optimization logic where given a set of investment opportunities represented as 5 bits (representing weights for 5 different assets), the output will be a 5-bit value representing the selected optimal portfolio based on the highest total weight (sum of weights) that does not exceed a specified maximum weight. If the total weight exceeds the maximum, the output should be zero. The module should have inputs: `weights` (5 bits), and `max_weight` (5 bits), and output `optimal_portfolio` (5 bits).
