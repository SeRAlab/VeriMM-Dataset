Design a D flip-flop (DFF) with an asynchronous preset feature. The flip-flop captures the value of the D input on the rising edge of the clock signal (C) and holds this value until the next clock edge. If the PRE input is asserted high, the output Q is set to logic high (1) regardless of the clock or D input, enabling the flip-flop to be preset asynchronously.
module top_module(
  input wire D,
  input wire C,
  input wire PRE,
  output reg Q
);
