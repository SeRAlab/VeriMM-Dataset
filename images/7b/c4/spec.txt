Design a circuit that functions as a 4-to-1 multiplexer with asynchronous reset. The module selects one of four input signals based on a 2-bit selection input. When the clock signal has a rising edge and the reset is not activated, the output reflects the value of the selected input signal. If the reset is activated, the output is set to LOW.
module top_module(input clk,input reset,input [1:0]select,input [3:0]sig_in,output reg sig_out);
