
Design a finite state machine (FSM) for a simplified SD card interface where the card can be in one of three states: IDLE, READ, or WRITE. The FSM should change states based on a "start" input signal. The FSM should output the current state as a 2-bit binary value, where 00 = IDLE, 01 = READ, and 10 = WRITE. The state should remain unchanged if the "start" signal is not asserted.
