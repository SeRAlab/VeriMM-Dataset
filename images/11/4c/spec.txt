Design a dynamic range compressor in Verilog that takes a 5-bit input signal `in_signal` and outputs a 5-bit compressed signal `out_signal`. The compression should be such that if the input signal is below a certain threshold, it remains unchanged, but if it exceeds the threshold, the output should be scaled down according to a compression factor. For instance, if the threshold is 15 and the compression factor is 2, values greater than 15 should be halved. The values should be clamped to the maximum value of 31 for the output.
