

You have been tasked with designing a verilog module that implements a 4-bit counter with synchronous reset and enable inputs. The module should have the following inputs and outputs:

Inputs:
- clk: the clock signal
- reset: the synchronous reset signal (active low)
- enable: the synchronous enable signal (active high)

Outputs:
- count: the 4-bit counter output

The counter should increment on every rising edge of the clock signal, unless the reset signal is active low, in which case it should reset the counter to 0. The counter should only increment when the enable signal is active high.

Write a verilog module that implements this counter.
