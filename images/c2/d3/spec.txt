
You are tasked with designing a Verilog module that implements a 4-to-2 multiplexer with an active-low enable signal. The module should have 4 input ports (A0, A1, A2, A3), 2 select ports (S0, S1), and 1 output port (X). When the enable signal (EN) is high, the output should be set to 0. When the enable signal is low, the output should be selected based on the select inputs (S0, S1). If S0 and S1 are both low, the output should be A0. If S0 is low and S1 is high, the output should be A1. If S0 is high and S1 is low, the output should be A2. If S0 and S1 are both high, the output should be A3.

Your module should be named "mux_4to2" and should be contained within 200 lines of Verilog code.
