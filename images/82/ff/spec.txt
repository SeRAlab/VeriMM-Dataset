Design a keyboard input decoder that processes 7-bit keyboard inputs to determine the output based on the type of key pressed (alphabetic or numeric) and the state of the shift and control signals. For numeric keys, the output indicates the presence of a decimal point when shift is active; otherwise, it directly passes the input. If neither condition is met, the input is output unchanged.
