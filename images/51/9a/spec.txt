Design a circuit that implements a ready signal for a slow AXI interface with a delay mechanism. The module outputs a ready signal based on the delay input and the valid signal. When the delay is zero, it immediately asserts ready. Otherwise, it checks a shift register (rdy_reg) which tracks the previous valid signals and determines if the ready signal can be asserted after the specified delay. The register is reset on a reset signal and updated on each clock cycle, allowing it to maintain the state of valid inputs while accommodating the specified delay.
module top_module(input clk,input reset,input [3:0] delay,input valid,output ready);
