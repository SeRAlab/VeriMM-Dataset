
Design a PCIe (Peripheral Component Interconnect Express) interface controller that handles the framing of data packets. The controller should accept a 64-bit data input (`data_in`), a signal (`wr_en`) to indicate when to write data, and a clock signal (`clk`). When `wr_en` is asserted, the controller should frame the data by adding a start-of-frame (SOF) and end-of-frame (EOF) marker. The framing should be as follows: the SOF marker is `8’hA5`, the data follows, and the EOF marker is `8’h5A`. The output should be a 80-bit wide signal (`data_out`) that includes the SOF, data, and EOF.
