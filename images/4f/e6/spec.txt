Design a 2-bit synchronous counter with asynchronous reset and enable functionality. When the reset (RST) signal is high, the counter output (Q) is set to zero. If RST is low and the enable (EN) signal is high, the counter increments its value on each positive edge of the clock (CLK). If EN is low, the counter retains its current value.
module top_module(
  input CLK,
  input EN,
  input RST,
  output reg [1:0] Q
);
