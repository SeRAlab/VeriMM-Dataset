
Design a 1-bit SRAM cell in Verilog that allows writing and reading data to/from a cell based on control signals. The cell should have the following signals:
- `data_in`: Input data to be written to the SRAM cell.
- `write_enable`: Control signal to enable writing to the SRAM cell when high.
- `read_enable`: Control signal to enable reading from the SRAM cell when high.
- `data_out`: Output data read from the SRAM cell.
The SRAM cell should retain its state until a write operation is performed.
