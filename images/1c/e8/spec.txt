
Design a 7-stage pipelined processor in Verilog that takes a 5-bit input and performs the following operations in the pipeline stages:
1. Fetch: Pass the input directly to the next stage.
2. Decode: Increment the input value by 1.
3. Execute: Multiply the value by 2.
4. Memory: Add 3 to the value.
5. WriteBack: Subtract 4 from the value.
6. Output: Pass the value to the output.
7. Final: Pass the final output to a register.
The final output should be stored in a register and available for read after the pipeline completes.
