Design a Verilog module for a simple FSM with three states (M, N, O) and one input signal (E). Use one-hot state encoding where M=3'b001, N=3'b010, O=3'b100. The FSM has an output signal (out) which is dependent only on the current state.

The FSM has the following states and their corresponding outputs:
1. state M (out = 0).
2. state N (out = 1).
3. state O (out = 1).

State transitions:
1. From state M: If E = 1, then transition to state N. If E = 0, stay in state M.
2. From state N: If E = 0, then transition to state O. If E = 1, stay in state N.
3. From state O: If E = 1, then transition to state M. If E = 0, stay in state O.

module fsm_3 (
  input E,
  input [2:0] state,
  output reg [2:0] next_state,
  output reg out);
