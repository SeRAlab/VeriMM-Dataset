Design a synchronous block RAM module with a width of 8 bits and a depth of 4096 words. The module has an enable input (ena) and a clock input (clka). When ena is high, on the rising edge of the clock, it can either write a value (dina) to the memory at the specified address (addra) if the write enable (wea) is asserted, or read from that address to output douta. This module is suited for use as a ROM in a BIOS configuration, allowing both read and write operations based on the control signals.
module top_module(douta,
   ena,
   clka,
   addra,
   dina,
   wea);
