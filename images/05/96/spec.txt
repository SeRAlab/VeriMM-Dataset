
Design an 8-bit serializer that converts an 8-bit input into a serial output. The serializer should shift out the bits one by one on each clock pulse. The input will be an 8-bit value and the output will be a single serial bit. The output should be valid for 8 clock cycles, after which the output should remain at the last value until a new input is provided. There should also be a reset signal to initialize the state of the serializer.
