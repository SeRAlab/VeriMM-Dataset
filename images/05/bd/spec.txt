Design an SR-latch using D flip-flops. The SR-latch should have two inputs, S (Set) and R (Reset), and two outputs Q and Q_bar. When S is high and R is low, Q should be set to high. When R is high and S is low, Q should be reset to low. If both S and R are low, the latch should maintain its previous state. If both S and R are high, it should be considered an invalid state.
