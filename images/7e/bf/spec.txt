Design a circuit that performs a maximum value selection from four groups of two 3-bit inputs each. The module takes eight 3-bit inputs (A1, A2, B1, B2, C1, C2, D1, D2) and outputs a single 3-bit value (Y) that represents the highest value among all provided inputs. The maximum is determined by comparing pairs within each group and then further comparing those results across all groups.
module top_module(
    input [2:0] A1,
    input [2:0] A2,
    input [2:0] B1,
    input [2:0] B2,
    input [2:0] C1,
    input [2:0] C2,
    input [2:0] D1,
    input [2:0] D2,
    output reg [2:0] Y
);
