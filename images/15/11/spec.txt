
Design a 4-bit EEPROM cell type that allows writing, reading, and erasing operations. The EEPROM cell should have the following inputs: `data_in` (4-bit input data), `write_enable` (1-bit), `read_enable` (1-bit), and `erase_enable` (1-bit). It should output `data_out` (4-bit) and have a `busy` signal that indicates when an operation is in progress. When `write_enable` is high, the `data_in` is written to the memory cell. When `read_enable` is high, the stored data should be output on `data_out`. When `erase_enable` is high, the stored data should be erased (set to 0000). The `busy` signal should be high during any operation.
