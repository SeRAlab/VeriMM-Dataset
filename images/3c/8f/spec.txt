
Design a simple SD card interface controller in Verilog that manages the read and write operations. The controller should have the following inputs: `clk` (clock), `reset` (active high reset), `cmd` (command signal), and `data_in` (data to write). The outputs should include `data_out` (data read from the SD card), `ready` (signal indicating the controller is ready for the next command), and `error` (signal indicating an error in operation). The controller should process a command to either read data from or write data to the SD card.
