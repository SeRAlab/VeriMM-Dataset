

You are tasked to design a verilog module that takes in a 4-bit input `data_in` and outputs a 2-bit output `data_out`. The output should be the 2 most significant bits of the input data in little-endian format. In other words, the output should be the 2 most significant bits of the input data but reversed in order. The module should be named `little_endian` and should have the following ports:

- `data_in` : a 4-bit input
- `data_out`: a 2-bit output

You can assume that the input `data_in` will always have a value between 0 and 15.
