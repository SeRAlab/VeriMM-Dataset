Design an SR latch using Verilog. The latch should have two inputs, S (Set) and R (Reset), and two outputs, Q and Qn (not Q). The latch should maintain its state until the inputs change, with the following behavior:  
- If S = 1 and R = 0, then Q = 1 and Qn = 0 (Set condition)  
- If S = 0 and R = 1, then Q = 0 and Qn = 1 (Reset condition)  
- If S = 0 and R = 0, then Q retains its previous state  
- If S = 1 and R = 1, the output is indeterminate (but for the purpose of this problem, you can handle it as a no-change condition)
