Implement a Verilog module for a 5-bit binary up/down counter with an up/down control signal and a synchronous load signal. The counter increments when the control signal is high and decrements when the control signal is low. When the load signal is high, the counter loads a given value. The reset input is active low asynchronous and should reset the counter to 0.
module top_module(
    input clk,
    input reset_n,
    input up_down,
    input load,
    input [4:0] load_value,
    output reg [4:0] q);
