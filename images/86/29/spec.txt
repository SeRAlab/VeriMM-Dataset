Implement an 8-bit unsigned division circuit. The module takes two 8-bit inputs, `a` (dividend) and `b` (divisor), and outputs the 8-bit quotient after performing division in a sequential manner triggered by a clock signal. The design uses a control mechanism to initiate division and shifts the dividend left while calculating the quotient bit by bit. The process continues until all bits have been processed, at which point the quotient is outputted, and division is disabled.
module top_module(
    input clk,
    input [7:0] a,
    input [7:0] b,
    output reg [7:0] out
);
