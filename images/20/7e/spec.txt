Design a 2-channel DMA controller that allows data transfer from a source to a destination on request. The DMA controller should have the following features: two request lines (REQ0 and REQ1), two grant lines (GNT0 and GNT1), a data line (DATA), and a control line (START). When a request is made, the controller grants access to the channel by asserting the corresponding grant line. The data should be transferred when the START signal is high. The controller should manage the priority of requests, with REQ0 having higher priority than REQ1. Ensure that only one grant line can be active at a time. If both requests occur at the same time, GNT0 should be asserted. If no requests are made, both grant lines should be de-asserted.
