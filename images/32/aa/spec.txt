Design a simple Bluetooth module state machine that has three states: IDLE, CONNECTING, and CONNECTED. The state machine transitions as follows: 
1. From IDLE to CONNECTING when the input signal `start_connect` is asserted.
2. From CONNECTING to CONNECTED when the input signal `connection_success` is asserted.
3. The state returns to IDLE when the input signal `reset` is asserted.
The output should indicate the current state of the Bluetooth module.
