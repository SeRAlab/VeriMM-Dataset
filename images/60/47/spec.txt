Design a Verilog module that models a 5-bit binary counter with enable and asynchronous reset signals. The module should have an input clock signal (clk), an input enable signal (en), an input asynchronous reset signal (rst), and a 5-bit output signal (count). On the rising edge of the clock, if enable is high, count should increment by 1. If reset is high, count should be set to 5'b11111.
