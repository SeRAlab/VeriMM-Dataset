Design an Arithmetic Logic Unit (ALU) that performs a variety of arithmetic and logical operations based on a 5-bit control signal. This ALU can execute addition, subtraction, multiplication, division, and bitwise operations (AND, OR, XOR) on two 16-bit input data signals. Additionally, it supports unary operations like bitwise complement and can perform both logical and arithmetic shifts (left and right) on the first input data signal, controlled by another input that specifies the number of positions to shift. The result of the selected operation is output as a 16-bit value.
module top_module(
    input [4:0] ctrl,
    input [15:0] data_in_A,
    input [15:0] data_in_B,
    output reg [15:0] data_out
);
