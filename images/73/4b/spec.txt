Design a circuit that converts a 4-bit binary-coded decimal (BCD) input into its corresponding 7-segment display representation, with an additional bit for the decimal point. The module maps each valid BCD input (0 to 9) to a specific 8-bit output that encodes the segments to be lit on the display. If the BCD input is outside the range of 0-9, the output will be set to all segments off.
module top_module(
    input [3:0] bcd_data,
    output reg [7:0] seg_data
);
