Design a state-space controller in Verilog that takes a 4-bit input representing the current state and a control signal to determine the next state. The controller should implement a simple state transition based on the following state diagram:  
- State 0 transitions to State 1 if control is 1, else remains in State 0.  
- State 1 transitions to State 2 if control is 1, else transitions back to State 0.  
- State 2 transitions to State 0 if control is 1, else transitions to State 1.  
The state should be represented as a 2-bit output.
