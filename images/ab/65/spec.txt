Design a small register bank with two registers controlled by a clock signal. The module features a reset input to initialize the registers to zero and supports writing data to the registers based on a 3-bit address. Specifically, it includes a 2-bit wide register (reg0) and a 1-bit wide register (reg1). The WRITE signal enables data input, directing either 2 bits to reg0 or 1 bit to reg1, while the READ signal allows the output of data from the specified register depending on the ADDR input. The READ_DATA output consolidates the data read from the registers, with reg1's output extended to match the width of the output bus.
module top_module(CLK, RST, WRITE, READ, ADDR, WRITE_DATA, READ_DATA);
