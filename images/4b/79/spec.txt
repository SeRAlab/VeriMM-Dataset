Design a Verilog module for a 4-to-1 multiplexer. The module takes four 1-bit inputs (`in0`, `in1`, `in2`, `in3`) and a 2-bit select input (`sel`). The output `out` should be equal to one of the inputs based on the value of `sel`: `00` selects `in0`, `01` selects `in1`, `10` selects `in2`, `11` selects `in3`.
