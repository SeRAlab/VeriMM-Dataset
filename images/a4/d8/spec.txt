Design a versatile 8-bit counter with load and increment functionalities. The counter resets to zero when the reset signal is activated. It can load a value from the input data (data_in) when the load signal is high. Additionally, when both the enable and increment signals are active, the counter increments its current value by one on each positive edge of the clock.
module top_module(
    input clk,
    input rst,
    input enable,
    input load,
    input increment,
    input [7:0] data_in,
    output reg [7:0] count
);
