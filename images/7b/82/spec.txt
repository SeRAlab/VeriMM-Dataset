Design a circuit that functions as a 3-bit up/down counter combined with a parity bit generator. The counter increments or decrements based on the `up_down` input signal when triggered by a clock edge, and the current value of the counter, along with the inverted parity state, is output as a 4-bit wide signal. The circuit resets to zero both the counter and the parity state when a reset signal is asserted.
module top_module(
    input clk,
    input reset,
    input up_down,
    output reg [3:0] out
);
