Design a Verilog module that takes a 5-bit input representing a color value in the RGBA format and outputs the corresponding grayscale value. The grayscale value is computed as the average of the red, green, and blue components. The input color value will be provided as a concatenated 5-bit representation of the RGB values (e.g., 11100 represents red, green, and blue components) where the two least significant bits are ignored for the grayscale computation.
