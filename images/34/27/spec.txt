Design a 16-bit SRAM cell that allows reading and writing data. The SRAM cell should have inputs for a 16-bit data bus, a write enable signal, and a clock signal. When the write enable signal is high, the data on the data bus should be written to the SRAM cell on the rising edge of the clock. When write enable is low, the data from the SRAM cell should be output on a 16-bit output bus. The initial contents of the SRAM cell should be zero.
