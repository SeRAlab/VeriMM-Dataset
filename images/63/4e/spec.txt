Design a circuit that functions as an 8-bit adder/subtractor with carry handling. The module has two 8-bit inputs, A and B, and can perform addition or subtraction based on control signals `add_en` and `sub_en`. When `add_en` is asserted, it computes the sum of A, B, and the carry-in; when `sub_en` is asserted, it calculates A minus B using two's complement. An output enable signal (`out_en`) indicates when valid output is available based on the operation selected. The result, along with the carry-out, is provided as output.
module top_module(A, B, sub_en, add_en, carry_in, out_en, data_out, carry_out);
