Design a synchronous Static Random-Access Memory (SRAM) module with parameterized data width and address size. This module accepts a clock input and has data input and output ports, allowing for reading and writing operations. When the write enable signal is asserted, it stores the input data at the specified address on the rising edge of the clock. The module also continuously outputs the data stored at the last accessed address, effectively allowing simultaneous read and write operations, with the ability to configure the width and size of the memory through parameters.
