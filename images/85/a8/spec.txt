Design a 4-bit comparator module that evaluates two 4-bit inputs, A and B, based on a 2-bit operation code, op. Depending on the value of op, the module will output a signal eq indicating whether A and B are equal, A is greater than B, A is less than B, or A is not equal to B. The module provides functionality for comparison operations, making it suitable for applications in digital systems where relational evaluations are required.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input [1:0] op,
  output reg eq
);
