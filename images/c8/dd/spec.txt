

You are tasked with designing a module that takes in a 4-bit input and outputs a 4-bit number that is the complement of the input. You are to use the following module template:

```
module complement (
    input  [3:0] A,
    output [3:0] Y
);

    // Insert your code here

endmodule
```

Your design should use the minimum number of gates possible and should not use any behavioral constructs (e.g. if-else, case statements). You may use any of the following gates: NOT, AND, OR, XOR, NAND, NOR, XNOR. You may also use any of the following operators: &, |, ^, ~.
