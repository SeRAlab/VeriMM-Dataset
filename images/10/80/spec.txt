Design a LIFO (Last In First Out) stack using Verilog. The stack should support the following operations: push, pop, and check if the stack is empty. The stack has a fixed size defined by a parameter (e.g., 8 entries). When the stack is full, a push operation should be ignored. When the stack is empty, a pop operation should return a default value (e.g., 0) and should not alter the stack. The stack should also have an output to indicate if it is empty.
