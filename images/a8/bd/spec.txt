Design a simple Arithmetic Logic Unit (ALU) that performs basic arithmetic and logic operations based on the input address. The module takes a 2-bit address signal to select among addition, subtraction, bitwise AND, and bitwise OR operations, while the `write_n` signal determines when to write new data. It outputs a 32-bit `out_port` reflecting the result of the calculations and provides a read data output `readdata`. The system features asynchronous reset capability, initializing the `data_out` register on reset, and the clock is used to synchronize the operations.
module top_module(
  // inputs:
  input [1:0] address,
  input chipselect,
  input clk,
  input reset_n,
  input write_n,
  input [31:0] writedata,

  // outputs:
  output reg [31:0] out_port,
  output reg [31:0] readdata
);
