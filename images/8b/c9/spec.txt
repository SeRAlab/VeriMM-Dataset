Design a 4-to-16 line NAND decoder. This module takes four binary input signals (A, B, C, D) and generates a single active output line from 16 possible outputs (Y[0] to Y[15]), based on the combination of inputs, where each output line is activated when its corresponding binary input matches the selected input and all NAND gates are used for logic operations. The design includes one stage for initial NAND processing followed by a second stage to further refine the output signals, ensuring that only one output line is high while the others remain low in accordance with the classic decoder behavior.
module top_module(
    input A,
    input B,
    input C,
    input D,
    output [15:0] Y
);
