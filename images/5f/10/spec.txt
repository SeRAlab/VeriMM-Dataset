Design a 4-bit binary counter with enable and reset functionality. On each rising edge of the clock, if the reset signal is high, the counter will reset to zero. If the reset is not active and the enable signal is high, the counter will increment its value by one. The current count value is available on the 4-bit output port.
module top_module(
    input clk,
    input rst,
    input en,
    output [3:0] count
);
