Design a circuit that performs addition or subtraction based on a control signal. This 4-bit wide module takes two 4-bit inputs, A and B, and produces a 4-bit output, Y. When the control signal (ctrl) is high (1), the module calculates the sum of A and B; when ctrl is low (0), it computes the difference (A minus B). The results are registered and updated on the positive edge of a clock signal.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input ctrl,
    input clk,        // Added clk input
    output reg [3:0] Y
);
