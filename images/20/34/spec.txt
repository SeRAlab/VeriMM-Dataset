Design a simple Ethernet MAC controller that handles the transmission of data frames. It should have inputs for the data to be sent (`data_in`), a signal to initiate transmission (`start_tx`), and an output for the transmitted data (`data_out`). The controller should also provide a signal indicating when the transmission is complete (`tx_done`). When `start_tx` is asserted, the controller should latch the input data and send it out on `data_out` during the next clock cycle. After the data is transmitted, `tx_done` should be asserted for one clock cycle.
