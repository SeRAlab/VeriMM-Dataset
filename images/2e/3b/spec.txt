Implement an SR latch using D flip-flops. The SR latch should have two inputs, S (Set) and R (Reset), and two outputs, Q and Qn (not Q). The latch should store the state based on the values of S and R. If S is high and R is low, Q should be set to high. If S is low and R is high, Q should be reset to low. If both S and R are low, Q should hold its previous state. If both S and R are high, it should be considered an invalid state.
