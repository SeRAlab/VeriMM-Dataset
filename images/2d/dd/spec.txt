
Design an 8-bit timer with a countdown functionality. The timer should start counting down from a given value and decrement by 1 every clock cycle until it reaches zero. Once it reaches zero, it should remain at zero. The timer should have the following inputs: a clock signal (clk), a reset signal (rst), and an 8-bit input value (start_val) to load the timer. The output should be an 8-bit value (current_val) that represents the current value of the timer.
