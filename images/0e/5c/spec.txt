Design a DWT filter bank that performs a single level Discrete Wavelet Transform on an 8-bit input sample. The filter bank should generate approximation and detail coefficients based on the input. Assume the low-pass and high-pass filter coefficients are predefined and symmetrical. The system should have a clock input, reset input, and a valid input signal to indicate when new data is ready. The design must shift and store values for computation in the next clock cycle.
