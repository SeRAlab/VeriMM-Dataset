
Create an SPI master controller that sends a byte of data to a SPI slave. The controller should have the following inputs and outputs:
- Input: clk (clock), rst (reset), start (signal to start transmission), mosi (data to be sent), 
- Output: miso (data received from the slave), sclk (serial clock), cs (chip select).
The controller should send a byte of data over MOSI, generate a clock signal on SCLK, and receive data on MISO when the transmission is complete.
