
Design a 4-bit SRAM cell that allows for reading and writing data. The cell should have a data input (D), a data output (Q), a write enable (WE) signal, and an address input (A) that selects which cell to read from or write to. When WE is high, the data at input D should be written to the memory cell at the address specified by A. When WE is low, the content of the memory cell at address A should be output to Q.
