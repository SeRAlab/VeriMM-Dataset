

You are tasked with designing a verilog module that implements a 4-bit ripple carry adder with a carry-in input and a carry-out output. The module should have the following inputs and outputs:

Inputs:
- `a`: a 4-bit input signal
- `b`: a 4-bit input signal
- `cin`: a single-bit input signal representing the carry-in

Outputs:
- `sum`: a 4-bit output signal representing the sum of `a` and `b`
- `cout`: a single-bit output signal representing the carry-out

You should use only combinational logic to implement the ripple carry adder.
