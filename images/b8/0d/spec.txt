Design a combinational circuit that processes a 50-bit wide input based on a selection signal. When the selection signal is high, the circuit computes the AND, OR, and XNOR of the input bits; if the selection signal is low, it effectively ignores the input by treating it as zero. The outputs consist of three signals: `out_and`, which produces the logical AND of the input bits, `out_or`, which provides the logical OR, and `out_xnor`, which computes the XNOR of the input bits with their inverted values.
module top_module(
    input [49:0] in,
    input sel,
    output out_and,
    output out_or,
    output out_xnor
);
