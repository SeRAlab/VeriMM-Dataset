Design a simple memory module that simulates a RAM with 24001 16-bit wide storage locations. On the rising edge of the clock, if the load signal is high, the module writes the 16-bit input data to the specified address in RAM. If load is low, it reads the data from the specified address and outputs it. The output reflects the last value retrieved from the memory.
module top_module(
    clk,
    in,
    load,
    address,
    out
 );
