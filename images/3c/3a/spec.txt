
Design a Verilog module that implements a Gaussian blur filter on a 3x3 pixel grayscale image. The input to the module should be a 3x3 array of pixel values (8-bit each) and the output should be the blurred pixel value, also 8 bits. The Gaussian kernel to be used is:
```
1/16 * [1 2 1]
         [2 4 2]
         [1 2 1]
```
This means that each pixel's value in the output will be a weighted sum of itself and its neighbors, scaled by the Gaussian kernel.
