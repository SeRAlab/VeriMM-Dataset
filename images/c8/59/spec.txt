

You are tasked with designing a verilog module that implements a 2-input AND gate using behavioral modeling. The module should have the following inputs and outputs:

Inputs:
- A (1-bit)
- B (1-bit)

Outputs:
- Y (1-bit)

The module should have the following behavior:
- When both A and B are high (1), Y should be high (1).
- Otherwise, Y should be low (0).

Write the verilog code for the AND gate module using behavioral modeling.
