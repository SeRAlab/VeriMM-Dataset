Design an SR flip-flop using Verilog. The flip-flop should have two inputs: S (Set) and R (Reset), and two outputs: Q (output) and Qn (not Q). The flip-flop should behave such that when S is high, Q is set to 1 (Set state), when R is high, Q is reset to 0 (Reset state), and if both inputs are low, Q retains its previous state. If both S and R are high, the behavior should be indeterminate.
