

You are tasked with designing a verilog module that implements a 4-bit binary counter with a synchronous reset and an enable input. The counter should increment on the rising edge of the clock input if the enable input is high. If the reset input is high, the counter should be reset to 0.

The module should have the following inputs and outputs:
- `clk`: a 1-bit clock input
- `reset`: a 1-bit synchronous reset input
- `enable`: a 1-bit enable input
- `count`: a 4-bit output representing the current count value

Design the verilog module for the binary counter with synchronous reset and enable input.
