
Create a Verilog module for a dynamic range compressor (DRC) that takes a 4-bit signed input and produces a 4-bit signed output. The compression should be done as follows:
- If the input is less than or equal to -8, the output should be -8.
- If the input is between -7 and 0, the output should be half of the input.
- If the input is greater than 0 and less than or equal to 7, the output should be the same as the input.
- If the input is greater than 7, the output should be 7.
