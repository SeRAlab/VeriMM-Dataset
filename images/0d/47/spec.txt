Implement a 4-point FFT (Fast Fourier Transform) module in Verilog. The module should take 4 complex input samples and produce 4 complex output samples. Each complex number will be represented as a 16-bit signed integer for both real and imaginary parts (total 32 bits for each complex number). The module should be clocked and should handle the input and output via a valid signal, indicating that the data is ready to be processed. The operation should be done in a pipelined manner where the output is valid one clock cycle after the input is valid.
