Implement a module that computes a simplified version of the MD5 hash function. This module should take a 512-bit message as input and produce a 128-bit hash value as output. The hash function will perform basic operations including bitwise operations, additions, and rotations but will not implement the full MD5 specification. You are required to define the process, the data registers, and the output generation based on the input message. The module should also include a clock and reset signal to control the operation.
