Design a 4-to-1 multiplexer with two select lines (S) and four data inputs (A, B, C, D). The output (Y) will be determined based on the value of the select lines: when S=00, output C; when S=01, output D; when S=10, output A; and when S=11, output B. This circuit efficiently routes one of four input signals to the output based on the select inputs.
module top_module(
    input [1:0] S,
    input A,
    input B,
    input C,
    input D,
    output reg Y
);
