Design a digital phase shifter that takes a clock input and a control signal to shift an input signal's phase by a specified amount. The phase shifter will use a 2-bit control signal to determine the phase shift: 00 for 0 degrees, 01 for 90 degrees, 10 for 180 degrees, and 11 for 270 degrees. The input signal is a 1-bit signal, and the output of the phase shifter will be the phase-shifted version of the input signal.
