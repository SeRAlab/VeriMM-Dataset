

You have been tasked with designing a verilog module for a 16-bit adder that takes two inputs (A and B) and produces a sum output (S). The module should also have an output (C) that indicates if there is a carry out of the most significant bit. 

The module should have the following inputs and outputs:
- input [15:0] A, B;
- output [15:0] S;
- output C;

Your module should be named "adder_16bit" and should use only combinational logic. 

Write the verilog code for the adder_16bit module.
