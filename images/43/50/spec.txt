Create a 4-bit shift register with configurable operations. This module allows parallel loading of input data, resets the register to zero, and supports shifting in both left and right directions based on the value of the shift direction control signal. The output reflects the current state of the shift register, continuously updating on the rising edge of the clock signal.
module top_module(
  input clk,
  input reset,
  input [3:0] data_in,
  input shift_dir,
  input parallel_load,
  output reg [3:0] data_out
);
