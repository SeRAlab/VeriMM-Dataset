Design a 32-bit counter with load capability. On the rising edge of the clock, if the clear (cl) signal is active, reset the output (q) to zero. If the write (w) signal is active, load the output with the value from the input data (d). If neither of these conditions are met and the up signal is active, increment the output (q) by one.
module top_module(
 	input clk,
 	input cl,
  input up,
  input w,
  input [31:0] d,
 	output reg [31:0] q
     );
