

You are tasked with designing a verilog module for a 2-input AND gate that operates on a clocked input. The module should have the following inputs and outputs:

Inputs:
- `clk`: clock input
- `a`: first input
- `b`: second input

Outputs:
- `out`: output of the AND gate

The output of the AND gate should only update on the rising edge of the clock input. The module should also have a reset input `rst` that asynchronously resets the output to 0.

Write a verilog module that meets these specifications and is no more than 200 lines of code.
