

You are tasked with designing a module that implements a 2-to-1 multiplexer using Verilog. The module should take two input signals, A and B, and a select signal, S, and output the selected signal to O. The output signal should be the value of A if S is 0, and the value of B if S is 1.

Your module should be named "my_mux" and should be written in Verilog. It should be completely self-contained and should not rely on any other modules or external libraries.

Your module should include the following inputs and outputs:

- A (1-bit input)
- B (1-bit input)
- S (1-bit input)
- O (1-bit output)

Your module should be designed such that it can be tested using a simple testbench. Your testbench should include the following signals:

- A (1-bit signal)
- B (1-bit signal)
- S (1-bit signal)
- O (1-bit signal)

You should provide a Verilog file that includes your "my_mux" module and a testbench that tests the functionality of your module.
