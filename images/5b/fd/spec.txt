Implement a retiming block that delays an 8-bit input data signal by a specified number of clock cycles, defined by the `delay` parameter (set to 4 cycles). The module uses a shift register to store intermediate values of the input data, shifting them through the register on each rising edge of the clock. The output provides the data that has been delayed by the specified amount, effectively creating a data pipeline for synchronization purposes in digital systems.
