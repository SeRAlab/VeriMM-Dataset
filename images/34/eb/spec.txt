
Design a simple EEPROM cell in Verilog. The EEPROM cell should be able to store a single bit of data. It should have the following inputs:
- `write_enable`: Signal to enable writing to the cell.
- `data_in`: The data bit to be written.
- `read_enable`: Signal to enable reading from the cell.
The output should be `data_out`, which represents the stored bit when reading is enabled. The cell should retain its data until a new write operation is performed.
