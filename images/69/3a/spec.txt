Implement the Verilog module based on the following description.
You are given a ten-bit input vector in[9:0]. We want to compute some relationships between the bits and their neighbours: 
// (1) out_and: Each bit of this output vector should indicate whether both the corresponding input bit and its neighbour to the right are '1'. For example, out_and[1] should indicate if in[1] and in[0] are both 1. Since in[0] has no neighbour to the right, the answer is obvious so we don't need to know out_and[0]. 
// (2) out_or: Each bit of this output vector should indicate whether either the corresponding input bit or its neighbour to the left are '1'. For example, out_or[6] should indicate if either in[6] or in[7] are 1. Since in[9] has no neighbour to the left, the answer is obvious so we don't need to know out_or[9]. 
// (3) out_xor: Each bit of this output vector should indicate whether the corresponding input bit is different from its neighbour to the right. For example, out_xor[8] should indicate if in[8] is different from in[7]. For this part, treat the vector as wrapping around, so in[0]'s neighbour to the right is in[9].
