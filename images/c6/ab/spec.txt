

You are tasked with designing a verilog module that takes in a 4-bit input signal `in` and outputs a 4-bit signal `out` based on the following rules:
- If the input is less than or equal to 7, the output should be the input value plus 3.
- If the input is greater than 7, the output should be the input value minus 3.

You should use an `always` block with a sensitivity list that includes the `in` input signal. You should also use an `if-else` statement to implement the above rules.

Write the verilog code for this module.
