Design an 8-bit shift register that supports both left and right shifting. The shift direction is controlled by a 1-bit input signal, 'shift_dir'. If 'shift_dir' is 0, the register should shift left, and if it is 1, it should shift right. The register should also have an input 'data_in' to load new data when 'load' signal is high. The register should maintain its state when neither 'load' nor 'shift_dir' is activated.
