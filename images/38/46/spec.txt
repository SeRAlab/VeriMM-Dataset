
Design a simple memory allocator that can allocate and free memory blocks of a fixed size. The allocator should manage up to 8 blocks of memory, each of 4 bits. The module should have the following inputs and outputs:
- `alloc`: a signal to allocate memory (1 bit).
- `free`: a signal to free memory (1 bit).
- `addr`: a 3-bit address to specify which block to allocate or free.
- `data_out`: a 4-bit output that shows the allocated memory block.
- `allocated`: a 1-bit output indicating whether the allocation was successful or not.
