Design a 1-bit DRAM cell in Verilog. The DRAM cell should consist of a single bit of storage that can be written to and read from. The cell should include control signals for reading (READ), writing (WRITE), and a data input (DIN) and output (DOUT). The WRITE signal should store the DIN value into the cell when asserted, and the READ signal should output the stored value when asserted.
