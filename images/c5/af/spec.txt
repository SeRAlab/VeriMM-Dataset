

You are tasked with designing a verilog module for a simple calculator that can perform addition and subtraction operations on two 4-bit numbers. The calculator should have two input ports, `a` and `b`, each a 4-bit binary number, and a control input `op` that determines the operation to be performed. If `op` is 0, the calculator should output the result of adding `a` and `b`. If `op` is 1, the calculator should output the result of subtracting `b` from `a`. The output should be a 4-bit binary number `out`.

Design the verilog module for this calculator, ensuring that it meets the following specifications:

- The module should be named `calculator`.
- The module should have inputs `a`, `b`, and `op`, each a 4-bit binary number, and an output `out`, also a 4-bit binary number.
- The module should use only combinational logic to perform the addition and subtraction operations.
- The module should use a single always block to implement the combinational logic.
- The module should have no other outputs or internal signals besides `out`.
