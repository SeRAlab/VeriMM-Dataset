Design a 2-bit barrel shifter that can shift a 2-bit input either left or right based on a control signal. The barrel shifter should take a 2-bit input and a 1-bit control signal. If the control signal is 0, the output should be the input shifted to the left by 1. If the control signal is 1, the output should be the input shifted to the right by 1. The output should also wrap around for shifts.
