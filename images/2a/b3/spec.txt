Design a Watchdog Timer in Verilog. The Watchdog Timer should have an input signal `reset` and a clock signal `clk`. The timer should count from a preset value (in this case, 10) down to 0. If the timer hits 0, it should output a signal `timeout` that indicates a timeout condition. The timer should be reset to the preset value whenever the `reset` signal is asserted (1). The timer should also have an output `count` to show the current count value.
