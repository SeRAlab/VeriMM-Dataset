Design a 4-bit wide combinational logic circuit that performs various bitwise operations on two 4-bit inputs, A and B, based on a 2-bit selection signal, sel. When sel is 00, the output is the bitwise AND of A and B; when sel is 01, the output is the bitwise OR; when sel is 10, it outputs the bitwise XOR; and when sel is 11, the output is the bitwise NOR of A and B. The circuit also includes a default case that outputs zero if sel does not match any specified operation.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input [1:0] sel,
    output reg [3:0] out
    );
