
Design a 2x2 matrix multiplication unit in Verilog that takes two 2x2 matrices as input and produces a 2x2 matrix as output. Each matrix element is a 4-bit number. The inputs are provided as two 4-bit wide signals for each element of the matrices, and the output should also be a 4-bit wide signal for each element of the resulting matrix. Ensure that all operations are combinational.
