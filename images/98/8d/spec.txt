Design a one-bit wide, 4-to-1 multiplexer. It accepts a 4-bit input (DIN) and a 2-bit select signal (SEL). Depending on the value of the select signal, the output (DOUT) will reflect one of the four input bits (DIN[0] through DIN[3]). When SEL is 00, DOUT corresponds to DIN[0]; when SEL is 01, DOUT corresponds to DIN[1]; when SEL is 10, DOUT corresponds to DIN[2]; and when SEL is 11, DOUT corresponds to DIN[3].
module top_module(
  input [3:0] DIN,
  input [1:0] SEL,
  output DOUT
);
