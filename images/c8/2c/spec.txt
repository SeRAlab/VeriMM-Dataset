

You are tasked with designing a module in verilog that takes in three 9-bit inputs, `a`, `b`, and `c`, and outputs a 9-bit signal `out`. The output should be the bitwise OR of the three inputs, but with a twist: each input should be shifted left by a number of bits equal to its position in the input list. Specifically, `a` should be shifted left by 0 bits, `b` should be shifted left by 9 bits, and `c` should be shifted left by 18 bits.

You should use the following module signature:
```
module ShiftOr(
    input [8:0] a,
    input [8:0] b,
    input [8:0] c,
    output reg [8:0] out
);
```
