
Design a simple SATA controller state machine in Verilog that handles three states: IDLE, ACTIVE, and ERROR. The controller should transition between these states based on the input signals. The state transition should be as follows:
- From IDLE, it goes to ACTIVE on receiving an 'activate' signal.
- From ACTIVE, it can go to ERROR on receiving an 'error' signal, or return to IDLE on receiving a 'reset' signal.
- From ERROR, it can only return to IDLE on receiving a 'reset' signal.
