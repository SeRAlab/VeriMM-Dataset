Design a 24-bit Digital-to-Analog Converter (DAC) module in Verilog. The DAC should accept a 24-bit input binary value and produce a corresponding analog output in a simplistic model. The output should be represented as a 32-bit fixed-point number where the upper 24 bits represent the DAC value and the lower 8 bits are set to 0. The module should also include an enable signal that, when low, sets the output to 0.
