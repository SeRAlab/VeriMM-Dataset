Design a Verilog module that implements a 3x3 Gaussian blur filter for a grayscale image. The module should take a 3x3 pixel input and output the blurred pixel value. The Gaussian blur can be approximated using weights of 1/16 for the center pixel and 1/8 for the adjacent pixels. The input will be a 9-bit grayscale value for each pixel, and the output will be a 9-bit grayscale value for the blurred pixel.
