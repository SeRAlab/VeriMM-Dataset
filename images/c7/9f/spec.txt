

You are tasked with designing a verilog module that implements a 2:1 multiplexer. The module should have two input ports, one output port, and a select input that chooses which input port should be routed to the output port. The select input should be a single bit.

Using the provided code snippet as inspiration, design a verilog module named `mux_2to1` that implements the 2:1 multiplexer. The module should have the following ports:

- `in0`: a 1-bit input port
- `in1`: a 1-bit input port
- `sel`: a 1-bit input port
- `out`: a 1-bit output port

The module should route the selected input port to the output port, according to the value of the `sel` input. If `sel` is 0, the `in0` input should be routed to the `out` output. If `sel` is 1, the `in1` input should be routed to the `out` output.
