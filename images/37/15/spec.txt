Implement a 4-bit DRAM cell that can store a 4-bit data input. The cell should have a write enable signal (we) to allow writing data to the cell, and a read signal (re) to read the stored data. When writing, if we is high, the data should be stored. When reading, if re is high, the stored data should be output. The cell should have an asynchronous reset signal (rst) that clears the stored data.
