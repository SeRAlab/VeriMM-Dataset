Implement a simple RNN cell that takes a 4-bit input and a 4-bit hidden state, and produces a new hidden state based on the RNN update rule. The new hidden state is calculated as: new_state = activation_function(W * input + U * hidden_state), where W and U are weight matrices (for simplicity, we can consider them fixed values). The activation function can be a simple XOR operation for the sake of this example.
