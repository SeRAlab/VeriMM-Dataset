Design a module that performs zero or sign extension on a 16-bit input value based on a selection signal. When the Extsel input is 0, it zero-extends the 16-bit immediate (Imme) value to a 32-bit output by padding with zeros. When Extsel is 1, it sign-extends the 16-bit immediate value, replicating the sign bit (the most significant bit) to fill the upper 16 bits of the 32-bit output.
module top_module(
    input Extsel,
    input [15:0]Imme,
    output reg[31:0] ExtendOut
    );
