Design a 16-bit wide parallel-in serial-out (PISO) shift register. On each positive clock edge, if the reset signal is asserted, the shift register initializes to zero. If the reset is not asserted and the shift-in signal is active, the module shifts the input data into the most significant bit of the shift register, pushing the existing bits towards the least significant bit. The output data_out provides the most significant bit of the shift register for serial output.
module top_module(
    input clk,
    input data_in,
    input shift_in,
    input reset,
    output reg data_out
);
