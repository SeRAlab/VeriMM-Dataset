Design a 16-bit DRAM cell that can store and retrieve a single 16-bit data input. The DRAM cell should have the following signals: 
- `data_in`: 16-bit input data to be written to the cell.
- `data_out`: 16-bit output data read from the cell.
- `wr_en`: Write enable signal, when high, allows data to be written to the cell.
- `clk`: Clock signal for synchronization.
- `reset`: Asynchronous reset signal, when high, resets the cell to zero.
