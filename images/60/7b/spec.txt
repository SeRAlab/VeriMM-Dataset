Design a module that performs a specific bitwise shifting operation on two input vectors of width defined by the 'bits' parameter, defaulting to 32 bits. The output for the first input, `a_shift`, is generated by shifting bits of `a` to the left while replicating the highest bit. For the second output, `b_shift`, the lowest bit of `a` is shifted into the highest position while the remaining bits of `b` are shifted to the right. This design effectively creates a custom shifting mechanism that modifies both inputs based on their current bit configurations.
module top_module(
            input [bits:0] a,
            input [bits:0] b,
            output [bits:0] a_shift,
            output [bits:0] b_shift
    );
