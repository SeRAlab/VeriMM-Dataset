Design a frequency divider that produces an output clock signal with half the frequency of the input clock. The module takes a clock input and an asynchronous reset signal; when the reset is activated, it sets the internal state to zero. On each rising edge of the clock, two flip-flops toggle their states. The output clock is generated by performing a logical AND operation on the states of these two flip-flops, resulting in a square wave signal that is at half the frequency of the original clock.
module top_module(
    input clk, // Clock input
    input reset, // Asynchronous reset input
    output reg out_clk // Output clock signal with half the frequency of the input clock
);
