Develop a display driver module for a 7-segment display with four digits, which takes input values for each digit and outputs the appropriate segment activation signals. The module utilizes a clock and asynchronous reset to refresh the display at regular intervals. It cycles through the four digits based on a counter, enabling one digit at a time while ensuring the others remain inactive. The segment outputs are active-low signals, thereby controlling which segments of the selected digit light up, and it manages digit enable signals to indicate which digit is currently being displayed.
