Design a 4-bit adder module that computes the sum of two 4-bit inputs, A and B. The output S represents the 4-bit result of the addition. The module also includes a carry output C, which indicates whether there is a carry from the most significant bit during the addition process. When the sum exceeds the representable range of a 4-bit number, C is set high.
module top_module(
  input [3:0] A,
  input [3:0] B,
  output reg [3:0] S,
  output reg C
);
