Design a 2-channel DMA controller that allows data transfer between two peripheral devices and main memory. The controller should have the following inputs: a clock signal (clk), a reset signal (rst), a request signal for channel 1 (req1), a request signal for channel 2 (req2), and a grant signal for channel 1 (grant1) and channel 2 (grant2). The output should indicate which channel is currently active (active_channel) and whether the transfer is complete (transfer_complete). The DMA controller should grant access to one channel at a time based on the request signals and should be able to handle transfers independently for each channel.
