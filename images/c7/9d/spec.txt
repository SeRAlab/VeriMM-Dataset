

Write a Verilog module for a 2-to-1 multiplexer (MUX) with the following specifications:

- The module should be named "MUX2to1".
- The module should have three inputs: "a", "b", and "sel".
- The module should have one output: "out".
- When "sel" is 0, "out" should be equal to "a".
- When "sel" is 1, "out" should be equal to "b".

Use behavioral modeling to implement the MUX2to1 module.
