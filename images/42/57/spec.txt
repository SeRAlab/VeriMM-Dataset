Design a 4-bit binary counter that increments its count on each rising edge of the clock signal when enabled. The counter can be reset to zero when the reset signal is active. When the enable signal is deactivated, the counter holds its current value. Thus, it provides a controlled counting mechanism suitable for various digital applications requiring a simple sequential counting function.
module top_module(
  input clk,
  input reset,
  input en,
  output reg [3:0] count
);
