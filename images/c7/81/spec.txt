

You are tasked with designing a shift register using Verilog. The shift register should take in a single bit input (`in`) and output a 6-bit value (`q`). The shift register should have a synchronous reset (`rst_n`) and should shift the input bit into the least significant bit (LSB) of the output value. The shift register should operate on every rising edge of the clock signal (`clk`).

Design a Verilog module that implements the shift register described above. Your module should be self-contained and should not reference any external modules or libraries. Your module should be no more than 200 lines of Verilog code.
