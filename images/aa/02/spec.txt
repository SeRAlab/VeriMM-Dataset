Design a timer module that increments a 4-bit time counter based on a clock signal. The timer resets and initializes itself upon receiving a reset signal or when enabled, it starts counting clock cycles. After reaching 100,000,000 clock cycles, the timer increments the current time value. The current time is output as a 4-bit value, allowing for simple time tracking functionality.
module top_module(
    input clk,
    input reset,
    input enable,
    output [3:0] newTime
    );
