Design a 3-bit binary counter that increments its value on each rising edge of the clock signal. The counter resets to zero when the reset signal is asserted or when it reaches its maximum value of 7 (3'b111). This module effectively implements a simple finite state machine (FSM) capable of counting in binary from 0 to 7 and wrapping back to 0, suitable for applications requiring a controlled counting mechanism.

  input clk,
  input reset,
  output reg [2:0] counter
