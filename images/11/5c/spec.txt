
Design a 3x3 image convolution module in Verilog, where the module takes an 8-bit pixel value and a 3x3 kernel as inputs, and produces a single 8-bit output pixel after applying the convolution operation. The kernel should be represented as a 9-bit input, where each bit corresponds to a weight for the convolution operation. The output pixel value should be clamped to an 8-bit range (0-255).
