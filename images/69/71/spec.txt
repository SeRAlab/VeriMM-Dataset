Design a circuit that computes the two's complement of a 4-bit binary input. If the most significant bit (MSB) is set (indicating a negative number in signed representation), the module inverts all bits and adds one to produce the two's complement. If the MSB is clear (indicating a positive number), the output simply replicates the input.
module top_module(
    input [3:0] binary_input,
    output reg [3:0] twos_complement_output
);
