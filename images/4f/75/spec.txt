It supports hexadecimal digits (0-F), where each digit lights up specific segments to form the number or character on the display. Additionally, if the 'dp' (decimal point) input is active, it will turn off the decimal point segment on the display. If the input value is outside the valid range of 0 to F, all segments are turned off.
