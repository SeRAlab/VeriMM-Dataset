

You are tasked with designing a module for a 2:1 multiplexer using only NAND gates. The module should have three inputs: A, B, and S, where A and B are the two inputs to be selected from and S is the selection signal. The output of the module should be Y, which is equal to A when S is 0 and B when S is 1.

You should write a Verilog module that implements the 2:1 multiplexer using only NAND gates. Your module should be named `nand_mux` and should have the following ports:
- `A`: input, 1-bit
- `B`: input, 1-bit
- `S`: input, 1-bit
- `Y`: output, 1-bit

Assume that the inputs A and B are valid and stable before the selection signal S changes.

You may only use NAND gates in your implementation and may not use any other gates or modules. Your implementation should be within 200 lines of Verilog code.
