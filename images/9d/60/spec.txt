Design an Arithmetic Logic Unit (ALU) that performs basic arithmetic operations and bitwise logic operations on 32-bit inputs. The module takes two 32-bit inputs, `data0_i` and `data1_i`, and a 3-bit control signal `ALUCtrl_i` to select the operation. It supports addition, subtraction, multiplication, bitwise AND, and bitwise OR. The output, `data_o`, reflects the result of the selected operation, while the `zero_o` output indicates if the result is zero. If an invalid operation is specified, the ALU defaults to zero.
module top_module(
  input [31:0] data0_i,
  input [31:0] data1_i,
  input [2:0] ALUCtrl_i,
  output [31:0] data_o,
  output zero_o
);
