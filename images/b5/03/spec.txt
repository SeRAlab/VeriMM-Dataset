Design a shift register with configurable loading and shifting capabilities. It features an 8-bit wide data path, allowing it to load a parallel input or perform left or right shifts based on the shift direction control signal. A reset input initializes the register to a defined state, while a load signal enables loading of data from the serial input. The module outputs the current state of the register in parallel form and provides the least significant bit as a serial output.
module top_module(
  input clk,
  input rst,
  input load,
  input shift_dir,
  input [data_width-1:0] serial_in,
  output [data_width-1:0] parallel_out,
  output serial_out
);
