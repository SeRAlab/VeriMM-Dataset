Design a Verilog module that implements a simple PNG filter type selection logic. The filter types used in PNG compression are: 0 (None), 1 (Sub), 2 (Up), 3 (Average), and 4 (Paeth). Your module should take a 3-bit input representing a filter type and output a corresponding 3-bit binary code for the filter type, while also indicating whether the filter type is valid (1 for valid, 0 for invalid).
