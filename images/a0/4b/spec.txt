Implement a 32-bit register file with 32 registers that supports reading and writing operations. The module takes a clock signal (CLK) and a reset signal (RESET) to control operations. Upon a positive edge of the clock, if RegW is high, it writes the input data (Reg_in) to the register specified by the destination register address (DR). If RESET is asserted, all registers are initialized to zero. The outputs ReadReg1 and ReadReg2 provide access to the values stored in the registers indexed by SR1 and SR2, respectively, allowing for simultaneous read operations. This design is useful in CPU architectures for managing register storage and data flow.
