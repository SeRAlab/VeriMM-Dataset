Implement the Verilog module based on the following description.
Create a 1-bit JK flip-flop. On each positive edge of clk, if j and k are both low, the output q holds its previous value. If j is high and k is low, q is set to 1. If j is low and k is high, q is reset to 0. If both j and k are high, q toggles.
module jk_flip_flop(
	input clk,
	input j,
	input k,
	output reg q);
