
Design a 1-bit DRAM cell with read and write capabilities. The cell should be able to store one bit of data and can be written to or read from using control signals. The DRAM cell should have the following inputs: `data_in` (1-bit input data), `write_enable` (control signal to enable writing), and `read_enable` (control signal to enable reading). The output of the DRAM cell should be `data_out` (1-bit output data). The cell should store data when `write_enable` is high and should output the stored data when `read_enable` is high.
