Design a Verilog module that implements a simple NAT type classification system. The system will classify the NAT type based on two input signals: `isPublicIP` (1-bit) and `isPortMapped` (1-bit). The output will be a 2-bit signal `natType` which indicates the following:
00: Open NAT
01: Moderate NAT
10: Strict NAT
11: Unclassified NAT
The classification rules are as follows:
- If `isPublicIP` is 1 and `isPortMapped` is 1, then `natType` should be 00 (Open NAT).
- If `isPublicIP` is 1 and `isPortMapped` is 0, then `natType` should be 01 (Moderate NAT).
- If `isPublicIP` is 0 and `isPortMapped` is 1, then `natType` should be 10 (Strict NAT).
- If `isPublicIP` is 0 and `isPortMapped` is 0, then `natType` should be 11 (Unclassified NAT).
