Design a simple 8-bit calculator that performs basic arithmetic operations. It takes two 8-bit inputs, A and B, and uses a 2-bit operation code (op) to determine the operation: addition (op=00), subtraction (op=01), multiplication (op=10), and division (op=11). The output, Y, is generated based on the selected operation, producing either the sum, difference, high byte of the product, or high byte of the quotient. If division by zero occurs, the output is set to zero.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input [1:0] op,
    input oe,
    output reg [7:0] Y
);
