Design a D flip-flop with an asynchronous, active-low reset functionality. The flip-flop samples the input D on the rising edge of the clock (CLK) and outputs the stored value as Q. If the active-low reset signal (RESET_B) is asserted, the output Q will be immediately set to LOW, regardless of the clock state. The complementary output Q_B is generated by inverting Q.
module top_module(
    input D,
    input RESET_B,
    input CLK,
    output reg Q,
    output Q_B
);
