

You are tasked with designing a verilog module for a 4x4 matrix of push buttons that outputs a 4-bit binary value corresponding to the button being pressed. The module should have the following inputs and outputs:

Inputs:
- `clk`: clock signal
- `rst`: reset signal
- `btn`: a 4-bit input representing the state of the push buttons (1 for pressed, 0 for not pressed)

Outputs:
- `out`: a 4-bit binary value representing the button being pressed (1 for button 1, 2 for button 2, etc.)

You can assume that only one button will be pressed at any given time. The module should output a value of 0 if no button is pressed.
