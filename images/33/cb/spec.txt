
Design an 8-bit DRAM cell. The cell should have a single-bit input (D), a single-bit output (Q), a row address (A), a column address (B), a read/write control signal (RW), and a clock (CLK). When RW is high, the cell should store the input D at the specified address on the rising edge of CLK. When RW is low, the cell should output the stored value at the specified address.
