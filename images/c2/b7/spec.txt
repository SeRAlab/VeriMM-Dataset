

You have been tasked with designing a module for a simple calculator that can perform basic arithmetic operations. The calculator should be able to add, subtract, multiply, and divide two input values. The inputs and outputs should be 8-bit unsigned integers. The calculator should also have a clear input that resets the calculator to 0.

Design a Verilog module for this calculator that can perform all of the required operations. Your module should have the following inputs and outputs:

- `clk`: The clock signal
- `reset`: A synchronous reset signal that resets the calculator to 0
- `op`: A 2-bit input that specifies the operation to perform (00 for addition, 01 for subtraction, 10 for multiplication, 11 for division)
- `a`: An 8-bit input that represents the first operand
- `b`: An 8-bit input that represents the second operand
- `result`: An 8-bit output that represents the result of the operation

Your module should be able to perform the operations in a single clock cycle and should be implemented within 200 lines of Verilog code.
