
Design a simple Fractional-N PLL with the following specifications: The PLL should take a 10-bit input frequency divider value (`N`) and a 10-bit input fractional value (`F`). The output should be a 10-bit clock signal that toggles based on the fractional division. The output clock should have a frequency based on the relationship of the given `N` and `F`. The implementation can assume that `N` and `F` are valid inputs.
