Design a single-port RAM module that allows for reading and writing operations using a specified address. The module accepts an n-bit wide input for data storage and an address input to access memory locations within a depth defined by the parameter. A write enable signal controls whether to store data at the given address or to output data from that address on read operations. This configuration supports memory operations in digital systems, enabling storage and retrieval of data efficiently.
module top_module(
  input [n-1:0] data_in,
  input [addr_width-1:0] address,
  input write_en,
  input clk,
  output reg [n-1:0] data_out
);
