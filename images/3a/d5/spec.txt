Design a simple EEPROM cell with a write and read function. The EEPROM should have an input for data (D), a write enable signal (WE), an output for data (Q), and a clock signal (CLK). When WE is high, the data from D should be written to the EEPROM cell on the rising edge of CLK. When WE is low, the data stored in the EEPROM should be output on Q.
