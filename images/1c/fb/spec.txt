Design a 4-bit Ripple-Carry Adder that takes in two 4-bit binary numbers and produces a 5-bit sum. The inputs are A3 A2 A1 A0 and B3 B2 B1 B0. The output should be S4 S3 S2 S1 S0 where S4 is the carry out. Make sure to verify the functionality using a testbench that reads inputs from a file and checks outputs against expected results.
