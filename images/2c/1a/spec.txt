Design an Ethernet MAC controller that receives data and provides a simple frame check sequence (FCS) validation. The controller should accept a 64-bit data input and a valid signal. When the valid signal is high, it should compute the FCS for the incoming data and store it in an output register. If the computed FCS matches the received FCS, an output signal should indicate a valid frame. The FCS can be simplified to a basic XOR operation over the data bits.
