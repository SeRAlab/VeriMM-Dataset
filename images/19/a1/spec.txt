
Design a packet filtering firewall in Verilog that checks incoming packets based on the source IP address and the destination port. The firewall will allow packets from specific source IPs (e.g., 192.168.1.1 and 192.168.1.2) destined for a specific port (e.g., port 80). If the packet matches these criteria, it will be allowed; otherwise, it will be blocked. The inputs to the module will be the source IP, destination port, and an output signal indicating whether the packet is allowed (1) or blocked (0).
