Design a JK flip-flop with asynchronous set functionality. The module captures input signals on the rising edge of the clock, with the ability to reset the output Q to HIGH when the set (S) signal is asserted. When both J and K inputs are asserted, it toggles the output Q. If only J is asserted, Q is set to HIGH, while asserting only K sets Q to LOW. If neither J nor K is active, Q takes on the value from input D. The module also generates the complementary output Q_bar.
