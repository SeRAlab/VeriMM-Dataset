

You are tasked with designing a verilog module for a 4-to-1 multiplexer. Your module should have four input bits, two select bits, and one output bit. The two select bits should be used to select one of the four input bits to be passed through to the output bit. The truth table for the 4-to-1 multiplexer is as follows:

```
S1 | S0 | Y
---|----|---
 0 |  0 | A
 0 |  1 | B
 1 |  0 | C
 1 |  1 | D
```

Your module should be named `mux4to1` and should have the following inputs and outputs:

```
module mux4to1 (
  input [3:0] in,
  input [1:0] sel,
  output reg out
);
```

You should use `case` statements to implement the functionality of the multiplexer. Your solution should be within 200 lines of verilog code.
