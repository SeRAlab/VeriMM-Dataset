

You have been tasked with designing a module that takes in a 4-bit input and outputs the square of that input. The output should be a 8-bit value. Write a Verilog module that implements this functionality.

Your module should have the following inputs and outputs:
- Input: `input [3:0] num`
- Output: `output [7:0] square`

Assume that the inputs will always be valid and that overflow will not occur.
