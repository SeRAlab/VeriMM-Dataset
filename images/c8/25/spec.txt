

You are given a module named `REG32` which has four inputs and one output. The inputs are `in` (a 32-bit register), `clk` (a clock signal), `R` (a reset signal), and an unnamed input. The output is `out` (a 32-bit wire). You have to write the Verilog code for the `REG32` module that will perform the following operations:

- On the rising edge of the clock signal, the input value `in` will be transferred to the output `out`.
- When the reset signal `R` is high, the output `out` will be set to 0.
- When the reset signal `R` is low, the output `out` will be the same as the input `in`.
- The module should be able to handle multiple clock cycles and reset signals.

Write a Verilog code for the `REG32` module that satisfies the above requirements. Your code should be within 200 lines of Verilog code.
