Design a 16-bit SRAM cell in Verilog that allows for read and write operations. The SRAM should have the following inputs: a 16-bit data input (data_in), a 16-bit data output (data_out), a write enable signal (we), an address input (addr), and a clock signal (clk). The SRAM should store data at the specified address when the write enable signal is high, and output the stored data when the write enable signal is low.
