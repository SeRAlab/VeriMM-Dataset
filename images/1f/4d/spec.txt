Design a Verilog module that implements a simple decision tree for binary classification based on two features. The module should take two 1-bit inputs (feature1 and feature2) and produce one 1-bit output (classification). The classification output should be determined by the following rules:
1. If feature1 is 0 and feature2 is 0, output 0 (class A).
2. If feature1 is 0 and feature2 is 1, output 0 (class A).
3. If feature1 is 1 and feature2 is 0, output 1 (class B).
4. If feature1 is 1 and feature2 is 1, output 1 (class B).
