
Design a Verilog module that simulates a simple Flash memory cell. The Flash memory cell should have the following characteristics:
1. It should be able to store a 1-bit value (0 or 1).
2. It should have a write enable signal (WE) to allow writing data to the memory cell.
3. It should have a read signal (RE) to read the stored value.
4. When WE is high, the input data should be written to the cell.
5. When RE is high, the output should reflect the stored value.
6. The module should maintain its state even when WE and RE are not active.
