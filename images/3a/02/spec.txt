Design a Verilog module for a simple Flash memory cell type. The cell should be able to store a single bit of data (0 or 1) and allow for operations such as 'write' (to change the stored value) and 'read' (to output the current stored value). The module should have inputs for the write enable signal, the data input, and a clock signal. On the rising edge of the clock, if the write enable is active, the cell should store the data input. If the write enable is not active, the cell should output the stored value on the data output.
