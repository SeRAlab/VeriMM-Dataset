Design a dual-port RAM module that allows simultaneous read and write operations. The module features a clock input for synchronization and enables data writing to memory when both `port_en_0` and `wr_en` are asserted. It supports two independent ports: `data_out_0` reads data from the memory location specified by `addr_in_0` when `port_en_0` is active, while `data_out_1` reads from `addr_in_1` if `port_en_1` is enabled. Memory contents are represented as 8-bit wide data stored in a 16-location addressable space.
module top_module(   input clk,
        input wr_en,
        input [7:0] data_in,
        input [3:0] addr_in_0,
        input [3:0] addr_in_1,
        input port_en_0,
        input port_en_1,
        output [7:0] data_out_0,
        output [7:0] data_out_1
    );
