

You are tasked with designing a Verilog module for a 2-input AND gate that satisfies the following requirements:

- The module should be named `two_input_and`.
- The module should have two input ports named `a` and `b`, and one output port named `y`.
- The module should be synthesizable and should not include any delays.
- The module should be able to handle both rising and falling edge clocks.
- The module should have the following behavior:
  - When both `a` and `b` are high, `y` should be high.
  - Otherwise, `y` should be low.

Write the Verilog code for the `two_input_and` module that satisfies the above requirements.
