Design a 4-bit shift register with load and shift functionality. The circuit can load new data from the input `data_in` into the output `data_out` when `load_en` is asserted. Alternatively, if `shift_en` is activated, the contents of `data_out` are shifted to the right, with the most significant bit wrapping around to become the least significant bit. This allows for both loading and shifting operations based on the control signals.
module top_module(
    input [3:0] data_in,
    input shift_en,
    input load_en,
    output reg [3:0] data_out
);
