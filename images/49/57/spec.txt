Design a 4-bit binary up counter that increments on each positive edge of the clock when enabled. When the reset signal is active (reset=0), the counter resets to zero. Once the counter reaches its maximum value of 15, it wraps around back to zero. The enable signal controls the counting operation, allowing the counter to be paused or halted when not enabled.
module top_module(
    input clk,
    input reset,
    input enable,
    output reg [3:0] count
);
