Design a D flip-flop with asynchronous reset and set control features. The flip-flop captures the value of input D on the rising edge of the clock (CLK) when the set control (SCE) is active, and its complementary output Q_B is provided. If the reset (RESET_B) is asserted low, the flip-flop initializes Q to LOW and Q_B to HIGH. Additionally, when the set control (SCD) is activated, the output Q is forced HIGH and Q_B to LOW, regardless of the clock or other controls. This module effectively implements an edge-triggered memory element with additional set and reset capabilities.

    input D,

    input RESET_B,

    output reg Q_B    // Changed to output reg
);
