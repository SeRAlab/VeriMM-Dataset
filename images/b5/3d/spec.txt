Design a 4-input priority encoder that compares four 4-bit inputs (A, B, C, D) and outputs a 2-bit code indicating the highest value among them. The output will be `00` if A is the greatest, `01` if B is the greatest, `10` if C is the greatest, and `11` if all inputs are equal or if D is the greatest. This design effectively selects the input with the highest numerical priority.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input [3:0] C,
    input [3:0] D,
    output reg [1:0] out
);
