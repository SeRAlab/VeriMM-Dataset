

You are tasked with designing a verilog module that implements a simple counter with the following specifications:

- The module should be named "counter".
- The module should have 3 inputs: "clk", "rst", and "enable".
- The module should have 1 output: "count".
- The counter should start at 0 and increment by 1 on each rising edge of "clk" if "enable" is high.
- If "rst" is high, the counter should reset to 0.
- The counter should be 8 bits wide.

Write the verilog code for the "counter" module that meets the specifications above.
