Design a simple SATA controller state machine that handles three states: IDLE, READ, and WRITE. The controller should transition between these states based on input signals. The state transitions should be as follows:
- From IDLE, if 'start' is high, transition to READ.
- From READ, if 'done' is high, transition to WRITE.
- From WRITE, if 'finish' is high, transition back to IDLE.
