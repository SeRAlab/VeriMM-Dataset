Design a Verilog module that simulates a simple Flash memory cell type. The Flash memory cell has an input for the data to be written (`data_in`), a control signal for writing (`write_en`), and a control signal for reading (`read_en`). The memory cell should retain the value after writing until a new value is written. The output (`data_out`) represents the value currently stored in the memory cell. Implement the module with the appropriate sequential logic using a flip-flop to store the value.
