Implement the Verilog module based on the following description.
Build a 13-bit shift register (right shift), with asynchronous positive edge triggered reset, synchronous active high signals load, and enable.
(1) reset: Resets shift register to zero.
(2) load: Loads shift register with data[12:0] instead of shifting.
(3) ena: Enables the right shift.
(4) data: The data to be loaded into the shift register.
(5) q: The contents of the shift register.

module top_module(
    input clk,
    input reset,
    input load,
    input ena,
    input [12:0] data,
    output reg [12:0] q);
