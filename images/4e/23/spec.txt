Design a D flip-flop with asynchronous set and reset functionality. On the rising edge of the clock signal, if the reset input is LOW, the output q is cleared to LOW and q_bar is set to HIGH. If the set input is LOW, the output q is set to HIGH and q_bar is cleared to LOW. Otherwise, the flip-flop captures the input d, where q reflects the value of d and q_bar provides the inverted output. This module allows for precise control of the flip-flop state with direct asynchronous handling of set and reset signals.
module top_module(
    input clk,
    input reset,
    input set,
    input d,
    output reg q,
    output reg q_bar
);
