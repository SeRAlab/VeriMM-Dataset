Design an 8-bit shift register with the following specifications: The shift register should have an input `data_in` (8 bits), a clock input `clk`, a reset input `reset`, and a serial output `serial_out`. On each rising edge of the clock, if `reset` is low, the data in the shift register should shift to the right, and the least significant bit (LSB) should be assigned the value of `data_in`. If `reset` is high, the shift register should be cleared to 0. The `serial_out` should reflect the current value of the LSB of the shift register.
