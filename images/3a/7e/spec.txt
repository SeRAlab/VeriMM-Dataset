Design a 4-channel DMA controller that is capable of transferring data from one memory region to another. The controller should have the following inputs: a clock signal, a start signal to initiate the transfer, and four channel select signals (ch0, ch1, ch2, ch3). The controller should have output signals indicating which channel is currently active (active_channel) and a transfer complete signal (transfer_done). The data transfer should be simulated by incrementing an address register for each clock cycle while the start signal is asserted and a channel is selected. The transfer is considered complete when the address register reaches a predefined limit.
