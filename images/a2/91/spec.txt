When RegSrc is 00 or 01, output data from readFromMem; when RegSrc is 10, output the ALUResult; and for RegSrc equal to 11, output op2Val. This module is typically used in a CPU to route register data based on control signals during instruction execution.

	input [15:0] op2Val,
	output reg [15:0] outRegSrc
);
