Create a Verilog module for a 2-bit binary counter with enable and overflow indicator. The counter should increment by 1 on the rising edge of the clock if the enable signal is high. The overflow indicator should be high when the counter wraps around from 11 to 00.
module binary_counter_with_overflow(
    input clk,
    input enable,
    output reg [1:0] count,
    output reg overflow);
