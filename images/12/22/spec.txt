
Design a Verilog module that performs LU decomposition of a 2x2 matrix. The input will be a 2x2 matrix represented as four separate inputs (a, b, c, d). The outputs will be the matrices L and U, also represented as four separate outputs (l11, l21, u11, u12, u22). 
Assume that the input matrix is non-singular. The LU decomposition should be defined as:
Matrix A = LU, where:
L = | l11  0  |
    | l21  1  |
U = | u11  u12 |
    | 0    u22 |
