Design a circuit that performs various shift operations on a 4-bit input based on a 2-bit control signal. The module takes a 4-bit input (A) and uses the control signals to select one of four different transformations: output A directly, rotate the bits left by one position, rotate the bits right by one position, or rotate the bits left by one position with the most significant bit wrapping around to the least significant position. The output (X) reflects the selected transformation accordingly.
module top_module(
    input [3:0] A,
    input [1:0] control,
    output reg [3:0] X
);
