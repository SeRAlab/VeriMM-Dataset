Design a 4-bit SRAM cell that can read and write data. The SRAM should have a 4-bit data input (Din), a 4-bit data output (Dout), a write enable signal (WE), and a clock signal (clk). When WE is high, the data on Din should be written to the SRAM cell on the rising edge of clk. When WE is low, the data on Dout should reflect the current stored value in the SRAM cell.
