Design a packet filtering module for a firewall that checks incoming packets against a set of predefined rules. Each packet consists of a 16-bit source IP address and a 16-bit destination IP address. The module should output a signal indicating whether the packet is allowed (1) or blocked (0) based on a rule set defined by the user. The user can define up to 4 rules, each containing a source and destination IP address. If any rule matches the packet's source and destination IP, the packet should be allowed. If no rules match, the packet is blocked.
