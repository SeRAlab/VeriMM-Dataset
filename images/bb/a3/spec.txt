Implement the Verilog module based on the following description.
Design a 3-bit up/down counter with asynchronous reset. The counter counts up when the 'up' signal is high and counts down when 'down' signal is high. The counter should wrap around upon reaching the maximum or minimum value.

module counter (
  input clk,
  input reset_n,
  input up,
  input down,
  output reg [2:0] count
);
