Design a synchronous RAM module with a 16-bit address space and 24-bit data width. The module uses a clock input (CK) to control read and write operations. When the write enable (WE) signal is high, data from input D is written to the memory at the address specified by A. When the output enable (OE) is active, the module provides the data stored at the latched address A on the output Q; otherwise, it outputs zero. The design supports simultaneous read/write operations and maintains state across clock cycles.
