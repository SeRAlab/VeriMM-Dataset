Design a simple EEPROM cell model in Verilog. The EEPROM cell should be able to store a single bit of data. It should have the following inputs: `write_enable`, `data_in`, and `read_enable`. The output should be `data_out`. When `write_enable` is high, the cell stores the value from `data_in`. When `read_enable` is high, the cell outputs the stored value to `data_out`. If both `write_enable` and `read_enable` are low, the output should retain its previous state.
