Implement a 4-bit shift register with parallel load and serial output. The shift register should shift its content to the right on each positive edge of the clock. If the load signal is asserted, the register should load the input data in parallel.

Module name:
    shift_register
Input ports:
    clk: a 1-bit clock signal
    load: a 1-bit load signal
    data_in: a 4-bit input data signal
Output ports:
    data_out: a 1-bit serial output signal

Implementation:
The module uses an always block that is triggered on the positive edge of the clock. Inside the always block, if the load signal is asserted, the register is loaded with the input data. Otherwise, the register shifts its content to the right.
