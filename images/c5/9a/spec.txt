
You are tasked with designing a module in Verilog that takes a single input and outputs the same value. Your module should be named `Passthrough` and should be implemented within 200 lines of Verilog code. The input and output should be of type `logic` and should be named `in` and `out`, respectively.

Your module should have the following ports:
- `in`: a single bit input
- `out`: a single bit output

Your module should also have the following behavior:
- When a value is applied to the input, the same value should be immediately available on the output.
