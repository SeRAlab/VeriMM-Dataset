

You are tasked with designing a module that generates a clock and uses a case statement to set specific bits in a 8-bit register based on the value of a 4-bit signal. The module should have the following inputs and outputs:

Inputs:
- `clk`: a 1-bit clock signal
- `sig`: a 4-bit input signal

Outputs:
- `thing`: an 8-bit register with specific bits set based on the value of `sig`

The behavior of the module should be as follows:
- The clock signal should toggle every 10 time units.
- When `sig` is equal to 4'b0000, set the least significant bit (`thing[0]`) to 1.
- When `sig` is equal to 4'b0010, set the third bit (`thing[2]`) to 1.
- When `sig` is equal to 4'b0011, set the ninth bit (`thing[9]`) to 1.
- The module should finish execution after the initial block.

Write a verilog module that implements this behavior.
