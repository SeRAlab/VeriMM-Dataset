Design a synchronous N-bit register with reset functionality. When the reset signal (rst) is low, the output (dout) is initialized to a specified value (INI). On the rising edge of the clock (clk), if reset is high, the register captures the input data (din) and stores it in dout. This design effectively allows for data storage while providing a method to reset the stored value to its initial state.
