Please act as a professional verilog designer. Create a module that implements a 4-bit shift register with parallel load and serial output. The module should have two inputs, a 4-bit data input and a shift input. If the shift input is high, the module should shift the contents of the shift register right by one position, with the least significant bit being shifted out as the serial output. If the shift input is low, the module should load the contents of the shift register with the data input.
