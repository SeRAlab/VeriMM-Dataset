
Design a JK flip-flop in Verilog. The JK flip-flop should have inputs J, K, a clock signal (clk), and a reset signal (rst). The output Q should represent the current state of the flip-flop. The flip-flop should reset to 0 when rst is high. When clk transitions from low to high, the next state of Q should be determined by the values of J and K according to the following rules:
- If J = 0 and K = 0, Q remains unchanged.
- If J = 0 and K = 1, Q is reset to 0.
- If J = 1 and K = 0, Q is set to 1.
- If J = 1 and K = 1, Q toggles to the opposite state.
