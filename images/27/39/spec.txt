Design a 4-bit SRAM cell in Verilog that can store a 4-bit input data. The module should have the following ports: `input [3:0] data_in`, `input write_enable`, `input read_enable`, `output [3:0] data_out`. The read operation should output the stored data when `read_enable` is high, and the write operation should store `data_in` when `write_enable` is high.
