
Design a simple 5-bit Flash memory cell controller that can read, write, and erase data. The controller should have the following inputs and outputs:
- Inputs: `write_enable`, `erase_enable`, `data_in[4:0]`
- Outputs: `data_out[4:0]`

When `write_enable` is high, the `data_in` is written to the memory and should be reflected on `data_out`. When `erase_enable` is high, the memory should be erased (set to 5'b00000). If neither is enabled, `data_out` should hold its previous value.
