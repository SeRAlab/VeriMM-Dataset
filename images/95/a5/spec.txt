Design a stack pointer register that manages a 16-bit stack pointer based on clock cycles and a reset signal. The module responds to a reset by initializing the stack pointer to zero. Depending on the 2-bit operation code (`op`), it can increment the stack pointer, decrement it, load a new value from `writeData`, or retain its current value. The current value of the stack pointer is continually provided as output.
module top_module(input clock, reset,input [1:0] op,input [15:0] writeData,output [15:0] data);
