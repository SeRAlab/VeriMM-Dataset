Design a circuit for edge detection that identifies rising and falling edges of a digital input signal. The module takes a clock signal, a reset signal, and an input signal. On each rising clock edge, it captures the current state of the input signal, and the outputs indicate whether there was a rising edge (rise_out) or a falling edge (fall_out) in the input signal compared to its previous state. Specifically, rise_out asserts when the input transitions from LOW to HIGH, and fall_out asserts when the input transitions from HIGH to LOW.
module top_module(
    input clk,
    input rst,
    input in,
    output rise_out,  
    output fall_out);
