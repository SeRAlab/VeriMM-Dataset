Create a Verilog description for an EEPROM cell that can store a single bit of data. The cell should have inputs for data (D), a write enable (WE), and a read enable (RE). When WE is high, the value of D should be stored in the cell. When RE is high, the value of the stored bit should be outputted. The design should also have a reset input (RESET) that clears the stored value.
