Design a module that performs bitwise operations on a 100-bit input vector. The module computes the NOR of the input bits, then generates three output signals: the AND of all bits in the NOR result, the OR of all bits in the NOR result, and the XOR of all bits in the NOR result. Specifically, the AND output will be high only if all input bits are low, the OR output will be high if any input bit is low, and the XOR output will indicate whether there is an odd number of low inputs.
module top_module(
  input [99:0] data_in,
  output reg out_and,
  output reg out_or,
  output reg out_xor
);
