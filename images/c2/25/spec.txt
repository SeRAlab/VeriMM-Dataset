
You are tasked with designing a module for a simple calculator that can perform basic arithmetic operations (addition, subtraction, multiplication, and division) on two 8-bit numbers. The module should have the following inputs and outputs:
- Inputs: 
    - `op`: a 2-bit signal that specifies the operation to be performed (00 for addition, 01 for subtraction, 10 for multiplication, and 11 for division)
    - `num1`: an 8-bit signal that represents the first number in the operation
    - `num2`: an 8-bit signal that represents the second number in the operation
- Outputs:
    - `result`: an 8-bit signal that represents the result of the operation

Your module should be named `simple_calculator` and should be written in Verilog. The module should only use combinational logic (no registers or state machines). You can assume that the inputs will always be valid (i.e. no divide by zero).
