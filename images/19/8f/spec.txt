
Design a thermal sensor calibration system that takes a raw temperature input from a sensor and calibrates it based on predefined calibration coefficients. The system should have the following functionality:
- Accept a raw temperature value and the calibration coefficient.
- Adjust the raw temperature using the calibration coefficient.
- Output the calibrated temperature.
The calibrated value should be retained between clock cycles, so the system's output should be updated based on the clock signal.
