Design a synchronous circuit that computes the half-sum of a 32-bit input signal. On each rising edge of the clock, if the reset signal is active, the output will be set to zero. Otherwise, the module adds together the upper 16 bits (bits 31 to 16) and the lower 16 bits (bits 15 to 0) of the input signal, providing a 16-bit output corresponding to this half-sum computation.
module top_module(
    input clk,
    input reset,
    input [31:0] input_signal,
    output reg [15:0] output_signal
);
