Design a 4-bit ring counter with a directional toggle feature. The counter operates on the positive edge of the clock signal and resets to zero when the RESET input is active. It shifts in a circular manner, with the shifting direction determined by the state of the third bit of the counter; when this bit is high, the direction switches, effectively reversing the counting order. The output constantly reflects the current state of the counter in the OUT signal.
module top_module(
    input CLK,
    input RESET,
    output reg [3:0] OUT
);
