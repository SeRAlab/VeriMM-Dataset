

Write a Verilog module that takes in two 8-bit inputs, `a` and `b`, and outputs a 1-bit signal `y` that is high if `a` is greater than or equal to `b`, and low otherwise. 

Your module should be named `greater_than_or_equal` and should have the following ports:
- `a`: an 8-bit input
- `b`: an 8-bit input
- `y`: a 1-bit output

You should implement this module using only behavioral Verilog (no structural Verilog allowed).
