

You have been tasked with designing a module that takes in three input signals, A1, A2, and B1, and outputs a single signal Y. The module should be named "three_input_gate" and should be written in Verilog.

The module should perform the following logic:

- If A1 and A2 are both 1, Y should be 1
- If A1 and A2 are both 0, Y should be 0
- If B1 is 1, Y should always be 1, regardless of the values of A1 and A2

Write a Verilog module that implements this logic. Your module should only use the signals provided in the code snippet above.
