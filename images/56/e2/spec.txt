Design a simple dual-port RAM module with one clock cycle and separate enable signals for read and write operations. The module allows writing data to a specified address when the write enable signal (wea) is active and read data from another address when the read enable signal (enb) is active. The address inputs (addra and addrb) are 10 bits wide, while the data inputs and outputs (dia and dob) are 16 bits wide, supporting a memory capacity of 1024 x 16 bits.
