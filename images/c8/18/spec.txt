

You are tasked with designing a module that takes in a 16-bit input signal and outputs a 32-bit signal that is the sign extension of the input signal. Sign extension is the process of extending the most significant bit of a number to fill in the additional bits when the number is extended. For example, if the input signal is a negative number, the most significant bit will be 1, and when extended to 32 bits, the additional bits should also be 1. If the input signal is positive, the most significant bit is 0, and the additional bits should also be 0. 

Design a Verilog module that takes the input signal and outputs the sign-extended 32-bit signal. The module should be named `SignExt` and should have the following ports:
- `in` : a 16-bit input signal
- `out` : a 32-bit output signal that is the sign extension of the input signal

You should test your module using the provided testbench. The testbench instantiates your module and provides inputs to the `in` port. The inputs are changed every 100 ns.
