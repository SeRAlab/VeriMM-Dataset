

You are tasked with designing a Verilog module for a 2:1 multiplexer with 3-bit inputs and 1-bit output. The module should have the following ports:

- `input [2:0] A`
- `input [2:0] B`
- `input S`
- `output Y`

The output `Y` should be equal to `A` if `S` is 0, and equal to `B` if `S` is 1. You are allowed to use any additional wires or registers as needed.

Write the Verilog code for the multiplexer module.
