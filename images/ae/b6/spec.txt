Design a serial-to-parallel converter that captures a serial input signal and stores it in a parallel output register. The module accepts a 40-bit command input used to determine the width of the response (either 40 or 136 bits). When enabled and clocked, the module shifts in the serial data bit-by-bit into the output register until the specified width is reached, at which point it signals completion. The system can be reset to clear the output and internal counters. When not enabled, the output is set to zero. The functionality supports dynamic response widths based on the command input.
