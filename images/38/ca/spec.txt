
Design a simple elliptic curve point doubling circuit in Verilog. The circuit should take as input an x-coordinate and a y-coordinate of a point on the elliptic curve and output the x-coordinate and y-coordinate of the doubled point, using the formula:
- If P = (x1, y1), then 2P = (x3, y3) where:
  - λ = (3*x1^2 + a) / (2*y1) (assuming the elliptic curve equation y^2 = x^3 + ax + b)
  - x3 = λ^2 - 2*x1
  - y3 = λ*(x1 - x3) - y1
Assume that 'a' and 'b' are constants for the curve.
