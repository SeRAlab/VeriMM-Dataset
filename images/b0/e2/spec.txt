Design an 8-bit absolute value calculator that takes a signed input number and outputs its absolute value. If the most significant bit (sign bit) of the input is 1 (indicating a negative number), it computes the absolute value by negating the input and adding one, effectively performing two's complement. If the sign bit is 0 (indicating a non-negative number), it passes the input through unchanged. The parameter n can be adjusted for different bit-widths, but defaults to 8 bits.
module top_module(
  input signed [n-1:0] num,
  output [n-1:0] abs_num
);
