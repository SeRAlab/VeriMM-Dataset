

You are tasked to design a module that takes in 3 inputs (A, B, and C) and outputs a single bit (Y) according to the following logic:

- If A is 0, Y is always 0.
- If A is 1 and B is 0, Y is always 1.
- If A is 1 and B is 1, Y is equal to C.

Design a Verilog module that implements this logic. The module should be named `logic_gate` and should have the following interface:

```
module logic_gate (
    input A,
    input B,
    input C,
    output Y
);
```

Assume that A, B, and C are all single-bit inputs and Y is a single-bit output. Your module should be synthesizable and not use any procedural blocks or delays.
