Your module should consist of a single `always` block that uses Verilog's `+` operator to add the input values and generate the output values. The `always` block should also handle the carry-in and carry-out logic. You may assume that the inputs and outputs are always valid.

Write a Verilog module that implements this 16-bit adder with a carry-in and a carry-out.
