Design a synchronous D flip-flop with an asynchronous reset and a data enable signal. On the rising edge of the clock, if the reset signal is low, the output Q is set to 0. If the reset is high and the data enable (DE) signal is active, the output Q is updated to the value of input D. This design ensures that Q maintains its previous state unless explicitly reset or enabled to change by the data input.
