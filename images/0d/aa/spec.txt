Design a 24-bit ADC (Analog to Digital Converter) output processing module. The module takes a 24-bit input from the ADC and generates an 8-bit output based on the following criteria:
- If the input value is less than 8, the output should be 0.
- If the input value is between 8 and 16777215 (inclusive), the output should be the top 8 bits of the input.
- If the input value is greater than 16777215, the output should be 255 (maximum value for an 8-bit number).
