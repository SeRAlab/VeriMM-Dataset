Please act as a professional verilog designer.

Implement a priority encoder for an 8-bit input. The encoder should output the position of the highest-order bit that is set to '1'. If none of the input bits are set, the output should be zero. The module should also have a valid signal to indicate if any input bit is set.

Module name:
    priority_encoder

Input ports:
	in: 8-bit input data.

Output ports:
	pos: 3-bit output representing the position of the highest-order bit set to '1'.
	valid: Output signal indicating if any input bit is set.
