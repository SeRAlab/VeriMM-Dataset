Design a circuit for next program counter (NextPC) logic in a processor pipeline. The module computes the next instruction address based on the current program counter (CurrentPC), a sign-extended immediate value (SignExtImm64), and control signals for branching. If an unconditional branch is indicated or if the branch signal is active along with a zero result from the ALU (ALUZero), the next program counter is computed by adding the sign-extended immediate (shifted left by two bits) to the current program counter. Otherwise, it simply increments the CurrentPC by 4 to point to the next sequential instruction. This functionality is essential for managing control flow during program execution.
