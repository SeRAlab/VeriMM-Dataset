Design a circuit that controls an LED based on the state of a 3-bit switch input (SW). The output LED is intended to reflect the value of the switches; however, the current implementation is incorrect as it tries to assign the LED from both SW[0] and SW[1] simultaneously, which leads to conflicts. Properly, it should be designed to choose one of the switch inputs to determine the LED state, potentially based on an additional selection mechanism or by combining the switch states logically.
module top_module(
    input [2:0] SW,
    output LED
    );
