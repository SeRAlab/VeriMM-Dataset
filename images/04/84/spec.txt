Design a 16-bit DRAM cell with the following characteristics: The cell should support read and write operations. The cell should have a clock input, a write enable signal, an address input (4 bits for addressing 16 bits), data input (16 bits), and data output (16 bits). If the write enable signal is high, the data input should be written to the specified address; if the write enable signal is low, the data output should reflect the data stored at the specified address.
