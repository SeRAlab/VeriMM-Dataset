Design a simple SD card interface controller that handles read and write operations. The controller has a clock input, a reset input, a read enable (read_en), a write enable (write_en), a data input (data_in), and a data output (data_out). The controller should store the data that is written to it and provide the stored data when read is enabled. The behavior should be as follows: on the rising edge of the clock, if reset is high, the internal data should be cleared. If write_en is high, the data_in should be stored. If read_en is high, the stored data should be available at data_out.
