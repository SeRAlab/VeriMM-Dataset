Implement a Verilog module that performs LU decomposition of a 2x2 matrix. The module should take a 2x2 matrix as input and output the lower triangular matrix L and the upper triangular matrix U. The input matrix is represented by four individual inputs a, b, c, and d corresponding to the matrix [[a, b], [c, d]]. The output should be two 2x2 matrices represented by four outputs l11, l12, l21, l22 for L and u11, u12, u21, u22 for U.
