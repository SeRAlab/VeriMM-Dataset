Design a serial-in parallel-out (SIPO) shift register. The module captures a single-bit serial input on each clock cycle when the shift signal is asserted, while also allowing for the entire register to be reset to zero using the reset signal. After receiving eight bits, the contents of the shift register can be accessed as an 8-bit parallel output.
module top_module(
    input serial_in,
    input shift,
    input reset,
    input clk,
    output [7:0] parallel_out
);
