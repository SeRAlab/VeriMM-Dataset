Design a 32-entry register file that supports read and write operations. The module has three input address ports for reading data from two registers specified by RSaddr_i and RTaddr_i, and one address port for writing data to a specified register identified by RDaddr_i. The data to be written is provided via RDdata_i, and a control signal RegWrite_i determines whether a write operation should occur on the rising edge of the clock signal clk_i. The outputs RSdata_o and RTdata_o provide the data read from the specified registers.
module top_module(
    clk_i,
    RSaddr_i,
    RTaddr_i,
    RDaddr_i, 
    RDdata_i,
    RegWrite_i, 
    RSdata_o, 
    RTdata_o 
);
