Design a linear voltage regulator that takes a 5-bit binary input representing the desired output voltage level and outputs a 5-bit binary value representing the actual output voltage. The output voltage should be limited to a maximum of 31 (binary 11111) and must adjust to the input appropriately. The relationship between the input and output is defined such that if the input is less than or equal to 31, the output equals the input; otherwise, the output is clamped to 31.
