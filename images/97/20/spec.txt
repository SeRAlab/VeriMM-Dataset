Design a 4-bit up/down counter with synchronous reset and enable functionality. The counter increments its value when the direction signal is high and decrements when the direction signal is low. If the counter reaches its maximum value of 15 while counting up, it wraps around to 0. Conversely, if it reaches 0 while counting down, it wraps around to 15. The counter resets to 0 when the reset input is activated, and its counting operation is contingent on the enable signal.
module top_module(
  input clk,
  input reset,
  input enable,
  input direction,
  output reg [3:0] count
);
