Implement the Verilog module based on the following description.
Create a module that implements an 8-bit down-counter with enable. When the enable input is high, the counter decrements by 1 on each rising edge of the clock. The reset input is active high synchronous, and should reset the counter to 8'b11111111.
module down_counter(
	input clk,
	input reset,
	input enable,
	output reg [7:0] count);
