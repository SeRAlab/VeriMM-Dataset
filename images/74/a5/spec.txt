Design a 32-bit wide, 2-to-1 multiplexer. The module takes two 32-bit inputs, In0 and In1, and a single select input, Sel. Based on the value of Sel, the output, Out, will reflect either In0 when Sel is 0 or In1 when Sel is 1.
module top_module(
    input [31:0] In0, In1,
    input 		  Sel,
    output reg [31:0] Out
    );
