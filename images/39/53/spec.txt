
Create a Verilog module that implements a simple Huffman encoding circuit. The circuit should take a 4-bit input representing a character and output the corresponding 3-bit Huffman code based on the following predefined mapping:
- 0000 -> 000
- 0001 -> 001
- 0010 -> 010
- 0011 -> 011
- 0100 -> 100
- 0101 -> 101
- 0110 -> 110
- 0111 -> 111
Any input not in this range should output 111 (invalid code).
