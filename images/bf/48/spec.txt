Design a 4-bit up/down counter that increments or decrements its count based on the state of the up_down control signal. The counter resets to zero when the reset input is activated. On each rising edge of the clock, if the up_down signal is high, the counter increments; if low, it decrements. The current count value is stored and updated in a register, maintaining its state according to the clock cycles and control signals.
module top_module(
    input clk,
    input reset,
    input up_down,
    output reg [3:0] count
);
