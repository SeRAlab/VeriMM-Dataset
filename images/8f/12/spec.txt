Design a circuit that transforms a 4-bit input into a 3-bit output based on a specific condition. If the 4-bit input `in_value` is less than or equal to 7, the output `out_value` captures the lower 3 bits of `in_value` with the most significant bit set to 0. Conversely, if `in_value` exceeds 7, `out_value` is set to a fixed value of 3'b111, indicating an overflow condition.
module top_module(
    input [3:0] in_value,
    output [2:0] out_value
);
