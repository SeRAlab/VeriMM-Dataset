
Design a combinational logic circuit for a Flash memory cell that takes a 2-bit input control signal and a 5-bit data input. The control signal will determine whether to write the data to the memory cell or read the data from it. The output will be a 5-bit data output which will reflect the written data when the write control signal is active.
Control Signal:
00 - No operation
01 - Write operation (data is written to memory)
10 - Read operation (data is output from memory)
11 - Invalid operation (output should be zeroed)
