
You are tasked with designing a module that implements a 2-input inverter using Verilog. The module should have one output port and two input ports. Your task is to create a Verilog module that implements this functionality. Your module should be named `two_input_inv` and should have the following input and output ports:

- `input a`: a single bit input port
- `input b`: a single bit input port
- `output y`: a single bit output port

You should use the following Verilog primitives to implement this module:

- `not`: a logical NOT gate
- `and`: a logical AND gate
- `or`: a logical OR gate
- `xor`: a logical XOR gate

Your module should take the inputs `a` and `b` and produce the output `y` as described above. Your implementation should use no more than 200 lines of Verilog code.
