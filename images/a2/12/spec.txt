Design a four-bit wide 4-to-1 multiplexer. The multiplexer selects one of the four input bits based on the 2-bit select signal 's'. When 's' is 00, it outputs the least significant bit in[0]; when 's' is 01, it outputs in[1]; when 's' is 10, it outputs in[2]; and when 's' is 11, it outputs the most significant bit in[3]. If 's' is any value outside of these, the output defaults to 0.
module top_module(input wire [3:0] in, input wire [1:0] s, output wire out);
