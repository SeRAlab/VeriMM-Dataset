Design an IIR filter in Verilog that processes a single input sample and outputs a single sample based on the following equation:  
Y[n] = 0.5 * X[n] + 0.25 * Y[n-1]  
Where X[n] is the current input sample, Y[n] is the current output sample, and Y[n-1] is the previous output sample. The design should include a clock and reset signal.
