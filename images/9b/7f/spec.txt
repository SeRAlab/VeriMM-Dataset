Design a one-bit wide, 2-to-1 multiplexer. The module takes two data inputs, D0 and D1, and a control signal, ctrl. When ctrl is low (0), the output S is assigned the value of D0. When ctrl is high (1), the output S is assigned the value of D1. The design incorporates a lookup table to facilitate the selection based on the control signal, ensuring efficient signal routing based on the input states.
module top_module(
  input ctrl,
  input D0,
  input D1,
  output reg S
);
