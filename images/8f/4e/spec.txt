Design a 4-bit wide calculator module that performs basic arithmetic operations on two 4-bit inputs, A and B, based on a 2-bit operation selector (OP). The module supports four operations: addition, subtraction, multiplication, and division, corresponding to the values of OP (00 for addition, 01 for subtraction, 10 for multiplication, and 11 for division). The calculated result is output as a 4-bit value, RESULT.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input [1:0] OP,
    output [3:0] RESULT
);
