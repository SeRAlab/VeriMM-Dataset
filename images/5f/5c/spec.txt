Design a synchronous circuit that performs arithmetic operations based on a clock signal and a reset. When reset is activated, the outputs c and d are set to zero. On each rising edge of the clock, the module calculates the sum of 2-bit input a and 3-bit input b, storing the result in a 4-bit output c, while also calculating the product of the same inputs and storing it in a 5-bit output d.
module top_module(
  input clock,
  input reset,
  input [1:0] a,
  input [2:0] b,
  output reg [3:0] c,
  output reg [4:0] d
);
