
Design a simple SD card interface controller that handles read and write operations. The controller should have an input signal `cmd` which determines the operation (0 for read, 1 for write), a `data_in` input for incoming data, a `data_out` output for outgoing data, a `clk` signal for clocking, and a `reset` signal to reset the controller. The controller should store data written to it and output the data on read commands.
