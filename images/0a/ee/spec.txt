Design a 4-bit synchronous FIFO (First In First Out) queue with a depth of 4. The FIFO should have the following ports: 
- `clk`: Clock input
- `reset`: Active high reset signal
- `wr_en`: Write enable signal
- `rd_en`: Read enable signal 
- `data_in`: 4-bit input data
- `data_out`: 4-bit output data
- `full`: Flag indicating if the FIFO is full
- `empty`: Flag indicating if the FIFO is empty

The FIFO should store data in a circular manner and should correctly handle read and write operations, as well as the full and empty conditions.
