Implement the Verilog module based on the following description.
Given the following state machine with 1 input and 4 outputs (the outputs are given as "(out1, out2, out3, out4)"):

The state machine has the following states and their corresponding outputs:
1. state M (out1 = 1, out2 = 0, out3 = 0, out4 = 0).
2. state N (out1 = 0, out2 = 1, out3 = 0, out4 = 0).
3. state O (out1 = 0, out2 = 0, out3 = 1, out4 = 0).
4. state P (out1 = 0, out2 = 0, out3 = 0, out4 = 1).

State transitions:
1. From state M: If in = 0, then transition to state N. If in = 1, then transition to state O.
2. From state N: If in = 0, then transition to state O. If in = 1, then transition to state P.
3. From state O: If in = 0, then transition to state P. If in = 1, then transition to state M.
4. From state P: If in = 0, then transition to state M. If in = 1, then transition to state N.

Suppose this state machine uses one-hot encoding, where state[0] through state[3] correspond to the states M through P, respectively. The outputs are zero unless otherwise specified.

Write Verilog implementing the state transition logic and output logic portions of the state machine (but not the state flip-flops). You are given the current state in state[3:0] and must produce next_state[3:0] and the four outputs. Derive the logic equations by inspection assuming a one-hot encoding.
