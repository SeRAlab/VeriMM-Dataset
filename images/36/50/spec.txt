Design a Verilog module that implements the Canny edge detection algorithm's non-maximum suppression step. The module should take a 3x3 pixel intensity matrix as input, where each intensity value is an 8-bit number. It should output a single 8-bit value that represents the suppressed edge intensity. The non-maximum suppression should compare the center pixel with its neighbors in the direction of the gradient and retain the max value if it's the local maximum.
