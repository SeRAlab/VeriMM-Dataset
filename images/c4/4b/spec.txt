

You have been tasked with designing a verilog module for a 4:1 multiplexer. The module should have four inputs (A, B, C, D) and two select lines (S0, S1). The output of the module should be the selected input based on the select lines. The truth table for the module is as follows:

| S1 | S0 | Output |
|----|----|--------|
| 0  | 0  | A      |
| 0  | 1  | B      |
| 1  | 0  | C      |
| 1  | 1  | D      |

Design the verilog module for the 4:1 multiplexer.
