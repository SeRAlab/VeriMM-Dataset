
Design a 16-bit SRAM cell. The SRAM cell should have the following inputs: 
- `address`: a 4-bit address to select one of the 16 memory locations. 
- `data_in`: a 16-bit input data to write to the selected memory location. 
- `write_enable`: a signal to enable writing data to the memory. 
- `clk`: a clock signal. 

The output should be `data_out`, which is the 16-bit data read from the selected memory location.
