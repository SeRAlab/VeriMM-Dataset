Design a 4-bit EEPROM cell controller that allows the following operations: Read, Write, and Erase. The controller should have a clock input, a reset input, a Read/Write control signal, data input for writing, and data output for reading. When writing, the data should be stored in the internal register; when reading, the data should be output from the internal register. The erase operation should clear the stored data. The controller must ensure that Read and Write operations cannot occur simultaneously.
