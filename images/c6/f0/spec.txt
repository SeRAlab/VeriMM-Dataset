

You are tasked with designing a module that generates a constant output of 1'b0. The module should have four inputs: clk, ce, clr, and an output op. The output should be a single bit, and the inputs should be active-high.

The clk input is a clock signal that should be used to synchronize the module's operations. The ce input is an enable signal that should be used to enable the module's operations. When ce is low, the output should remain constant. The clr input is a reset signal that should be used to reset the module's operations. When clr is high, the output should be set to 1'b0 regardless of the state of the ce input.

Your task is to design a module that meets the above requirements. Your module should be named sysgen_constant and should be written in Verilog.
