Design a 16-bit DRAM cell with the following functionality: it should have a 16-bit input data bus (data_in), a 16-bit output data bus (data_out), a write enable signal (we), and a clock signal (clk). When we is high, data_in should be written to the DRAM cell on the rising edge of clk. When we is low, data_out should reflect the stored data in the DRAM cell on the falling edge of clk.
