Design an 8-bit DRAM cell that allows for basic read and write operations. The DRAM cell should include a data input, data output, a write enable signal, a read enable signal, and a clock signal. When the write enable signal is asserted, the data input should be stored in the cell on the rising edge of the clock. When the read enable signal is asserted, the data output should reflect the stored data in the cell at the next clock edge.
