Design a Verilog module that simulates a simple SLAM system with a state machine. The system will utilize a state register to represent different modes of operation: IDLE, MAPPING, and LOCALIZING. The system should transition between these states based on input signals. The module should have an input signal to trigger state changes, and it should output the current state. The state encoding will be as follows: IDLE (2'b00), MAPPING (2'b01), LOCALIZING (2'b10). When the input signal is high, the system should transition to the next state in the order: IDLE -> MAPPING -> LOCALIZING -> IDLE.
