
Design a UART controller that can transmit data serially. The UART controller should take a parallel data input of 8 bits, a transmission enable signal, and a clock. Upon receiving the transmission enable, it should start sending the data bit by bit, with a start bit ('0') followed by the 8 data bits, and end with a stop bit ('1'). The controller should also have a ready signal that indicates when the UART is ready to take a new byte of data for transmission.
