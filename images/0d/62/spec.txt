Design a 2-channel DMA controller that can read data from two separate memory locations and transfer it to two different output buffers. The DMA controller should have the following inputs: a clock signal, a reset signal, two memory addresses (addr1, addr2), and a start signal. The outputs will be two data outputs (data_out1, data_out2) corresponding to the data read from the two memory addresses. The controller should operate in a way that when the start signal is asserted, it reads data from the specified addresses on the next clock edge and then de-asserts the start signal after one cycle.
