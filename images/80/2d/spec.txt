Design a 4-bit up counter that counts from 0 to a specified maximum value (max_val) and resets to 0 when it reaches the maximum. The counter increments on each positive edge of the clock (clk) and can be reset asynchronously to 0 using the reset signal. The current count value is outputted as count_val.
module top_module(
  input wire [3:0] max_val,
  input wire reset,
  input wire clk,
  output wire [3:0] count_val
);
