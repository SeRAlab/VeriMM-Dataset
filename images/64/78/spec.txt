Design a 2-to-1 multiplexer that selects between two 96-bit wide input vectors, I1 and I2. When the select input (Sel) is low (0), the output O1 will be assigned the value of I1; when Sel is high (1), O1 will take the value of I2. The output is updated based on the value of Sel, making it suitable for applications that require switching between two data sources.
module top_module(input wire Sel,input wire [95:0]I1, I2,output reg [95:0] O1);
