Design a simple PCIe endpoint state machine in Verilog that handles the basic operations of a PCIe transaction. The state machine should have the following states: IDLE, REQUEST, RESPONSE, and ERROR. The FSM transitions based on a `start` signal to move from IDLE to REQUEST. If the transaction is successful, it should move to RESPONSE; if there is an error, it transitions to ERROR. The state machine should stay in the respective state until the transaction completes or an error occurs.
