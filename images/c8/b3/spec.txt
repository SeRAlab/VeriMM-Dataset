

You are tasked with creating a verilog module that takes in two inputs, A and B, and outputs their product, C. However, the product should only be calculated if a control input, enable, is high. If enable is low, C should output 0.

Implement a verilog module that satisfies the above requirements. Use the following interface:

```
module multiplier (
  input A,
  input B,
  input enable,
  output reg C
);
```
