Design a simple Automatic Repeat reQuest (ARQ) protocol for error correction. The system will transmit a 5-bit data frame, and if an error is detected in the received frame using a simple parity bit, the receiver will request the sender to retransmit the data. The sender will maintain a resend counter for how many times it has sent data. The system should include a sender and a receiver module where the sender transmits the data and the receiver checks for errors. The sender should have a maximum of 3 transmissions. If the receiver receives data correctly, it sends an acknowledgment. If the data is corrupted, it sends a negative acknowledgment for retransmission.
