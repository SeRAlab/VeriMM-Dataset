

You are tasked with designing a module in Verilog that takes in a 16-bit input `Din` and outputs the 5-bit slice of bits 12 to 8 of the input as `Dout`. You are to implement this module in no more than 200 lines of Verilog code.

Your module should be named `slice_module` and should have the following inputs and outputs:
- `Din` : a 16-bit input
- `Dout` : a 5-bit output

You should ensure that your module has the following characteristics:
- It should have a single always block.
- The always block should have a sensitivity list that includes only the input `Din`.
- The output `Dout` should be assigned within the always block.

You should assume that the input `Din` is a valid 16-bit binary number.
