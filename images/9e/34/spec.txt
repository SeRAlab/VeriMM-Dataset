Design a data reception module that captures a 1-bit input signal and outputs a 32-bit read data value based on a given address. The module utilizes a clock signal for synchronization and includes a reset feature for initializing the output. Specifically, when the address is 0, the received input signal from in_port is assigned to the output; otherwise, the output remains unaffected. The functionality is similar to that of a basic memory read operation, where the data is selectively captured based on address decoding in a specified clock cycle.
module top_module(
  input [1:0] address,
  input clk,
  input in_port,
  input reset_n,
  output reg [31:0] readdata
);
