Design a D flip-flop with an asynchronous active-low reset. When the reset signal is asserted (reset_n=0), the output q is set to 0 regardless of the clock or data inputs. On the rising edge of the clock, if reset is not active, the output q is updated to the value of the input d, thereby allowing for synchronous data storage and retrieval.
module top_module(
    input clk,
    input reset_n,
    input d,
    output reg q
);
