Design a 16-bit SRAM cell with read and write capabilities. The SRAM should have a write enable (we), read enable (re), a 16-bit data input (data_in), a 16-bit data output (data_out), and a 4-bit address input (addr) to select which cell to read from or write to. The SRAM should be designed to allow multiple writes and reads in a single simulation cycle, meaning the cell should retain its previous state until it is written to again.
