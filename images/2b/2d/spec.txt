
Design a 2-channel DMA controller that allows for data transfer from two different sources to a shared destination. The controller should have the following specifications:
- Two channels (Channel 0 and Channel 1).
- Each channel has a valid signal indicating when data is ready to be transferred.
- A request signal for each channel that indicates a request for DMA service.
- A grant signal that allows a channel to transfer data based on priority (Channel 0 has higher priority over Channel 1).
- A transfer complete signal that indicates the data transfer is finished.
- The state of the controller should be resettable.
