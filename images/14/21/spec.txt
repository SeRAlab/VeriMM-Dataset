
Design a simple OFDM modulator in Verilog. The modulator should take a stream of binary input data and perform the following operations:
1. Group the input bits into blocks of size 4 (i.e., 4 bits).
2. Map each block to a corresponding frequency subcarrier using a simple predefined mapping.
3. Generate a clock signal and sample the output at each clock edge, producing a serial output of the modulated data.
4. The modulator should also have a reset signal to initialize the system.
