Design a 2-to-1 multiplexer with hazard detection and resolution. The multiplexer should select between two 4-bit data inputs (`data0` and `data1`) based on a 1-bit select signal (`sel`). If both inputs are the same, the output should reflect that value, but if they differ, the output should be stable to avoid glitches (hazards). The output should be a 4-bit value (`out`). Implement logic to handle potential hazards when the select signal changes.
