

You have been tasked with designing a verilog module for a clock delay buffer that takes an input clock signal and outputs a delayed version of the same clock signal. The module should have the following specifications:

- The input clock signal is named `clk_in` and has a frequency of 50 MHz.
- The output clock signal is named `clk_out` and should be delayed by 5 ns with respect to the input clock signal.
- The module should have the following inputs:
  - `clk_in`: the input clock signal
  - `reset`: a synchronous reset signal that resets the output clock signal to low when high
- The module should have the following outputs:
  - `clk_out`: the delayed output clock signal

You can use any verilog primitives or gates, but you are not allowed to use any built-in delay functions or delay primitives.

Implement the verilog module for the clock delay buffer that meets the specifications above.
