Design a 2-to-1 multiplexer that processes 32-bit input signals. It selects between two 32-bit inputs, `input_0` and `input_1`, based on the value of the `selector` signal. When the `selector` is 0, the output `write_data` will equal `input_0`; when the `selector` is 1, the output will equal `input_1`. If the selector is neither 0 nor 1, which is not explicitly handled, the output defaults to 0.
module top_module(input wire[31:0] input_0,input wire[31:0] input_1,input wire selector,output wire[31:0] write_data);
