Design a 4-bit SRAM cell that can store a 4-bit data input and has read and write functionalities. The SRAM cell should have a write enable signal (we), a chip enable signal (ce), an output enable signal (oe), a 4-bit data input (data_in), a 4-bit data output (data_out), and a 2-bit address input (addr) to select which of the 4 SRAM cells to access. The design should support writing to and reading from the memory based on the control signals.
