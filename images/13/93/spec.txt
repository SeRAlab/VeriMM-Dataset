Design a simple Automatic Repeat reQuest (ARQ) system that uses a simple Stop-and-Wait protocol. The system should keep track of sent packets and acknowledge received packets. The sender will send packets and wait for an acknowledgment (ACK) from the receiver. If the acknowledgment is not received within a certain time frame, the sender will retransmit the packet. Create a Verilog module that implements this ARQ system with the following inputs: a clock signal, a reset signal, a data input signal representing the packet to be sent, and an acknowledgment signal from the receiver. The outputs should be the sent packet and a retransmit signal indicating whether the packet needs to be resent.
