Design a 8-stage shift register that captures two 8-bit input data signals (data_in1 and data_in2) on the rising edge of the clock. The first input data_in1 is shifted through the first six stages of the register while data_in2 is loaded into the last stage. The output q_out provides the value stored in the last stage of the shift register, allowing for the sequential processing of input data.
module top_module(
    input clk,
    input [7:0] data_in1,
    input [7:0] data_in2,
    output reg [7:0] q_out
);
