Design a 64-depth FIFO (First In, First Out) memory buffer that handles 94-bit wide data inputs. It provides outputs to indicate whether the buffer is empty or full. The module incorporates clocked read and write operations controlled by input signals, with the ability to reset the buffer state. When the write enable is asserted and the buffer is not full, it stores incoming data; when the read enable is asserted and the buffer is not empty, it outputs the oldest data.
