Design a 16-bit barrel shifter capable of performing both left and right shifts based on a 4-bit control input. If the shift amount is greater than 15 or negative, the output is set to zero. For non-negative shifts, the module rearranges the bits of the input signal A according to the specified number of positions in B, effectively facilitating circular shifts left or right. The output Y reflects the shifted value of A after processing through three stages of shifting logic.
module top_module(
    input [15:0] A,
    input [3:0] B,
    output reg [15:0] Y
);
