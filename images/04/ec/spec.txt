
Design a GPIO controller that can be configured for input or output modes. The controller should have the following functionality:
1. A mode select signal (`mode`) that determines whether the GPIO is configured as an input (`0`) or output (`1`).
2. An input data signal (`data_in`) that is only relevant when in input mode.
3. An output data signal (`data_out`) that reflects the state of the GPIO when in output mode.
4. A clock signal (`clk`) that allows for synchronous operation.
5. A reset signal (`reset`) that initializes the controller.
The GPIO controller should store the input data when in input mode and drive the output data when in output mode.
