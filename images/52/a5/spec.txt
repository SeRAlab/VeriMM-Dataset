Design a Set-Reset Flip-Flop (SRFF) that operates on the rising edge of a clock signal. This SRFF has synchronous and asynchronous reset capabilities, allowing it to be controlled via four inputs: a clock, a synchronous reset, a set signal, and an asynchronous reset. When the set input is activated, the output is set to HIGH; when the reset input is triggered, whether synchronously or asynchronously, the output is set to LOW. If the asynchronous reset is asserted, it takes precedence, immediately resetting the output regardless of the clock edge or other inputs. Additionally, the flip-flop has an initial state that can be randomized at simulation startup.
