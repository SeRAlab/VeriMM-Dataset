Please act as a professional verilog designer.

Design a Verilog module for a 16-bit register with an enable signal. The register holds its value until the enable signal is active, at which point it loads a new value from the input.

Module name:  
    register_16bit

Input ports:
    clk: Chip clock signal.
    enable: Enable signal for loading new data.
    data_in: Input data with a data width of 16 bits.

Output ports:
    data_out: Register output signal with a data width of 16 bits.

Implementation:
Register operation:
On every positive edge of the clock signal (clk), the register (data_out) holds its value if the enable signal (enable) is not active. If the enable signal is active, the register loads the input value (data_in).
