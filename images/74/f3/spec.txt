Design a 2-to-4 decoder that generates a specific 4-bit output based on the input selection signal, SEL, while being enabled by the EN signal. When EN is high, if SEL is 0, the output Y is set to 0001; if SEL is 1, the output Y becomes 0010. If EN is low, the output Y defaults to 0000, effectively disabling the decoder.
module top_module(
    input EN,
    input SEL,
    output reg [3:0] Y
);
