Design a 24-bit ADC that converts a 24-bit binary input into a voltage representation. The ADC has a reference voltage of 3.3V. The output should be a fixed-point representation of the voltage, which can be calculated using the formula: Voltage = (Input_Value / 2^24) * Reference_Voltage. The output should be 32 bits, where the first 24 bits represent the integer part and the last 8 bits represent the fractional part of the voltage.
