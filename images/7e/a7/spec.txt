Upon detection, it sets the `detected` output high and updates the `index` output to reflect which state matched the sequence. The FSM resets its state and outputs on a reset signal and cycles through states to continually search for the next occurrence of the sequence in the incoming data stream.

  input clk,
  input reset,
  input [7:0] data,

  output reg [1:0] index
