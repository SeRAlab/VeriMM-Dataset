
Design a state-space controller that takes a 3-bit input representing the state and a control signal. The output should be a 3-bit value representing the next state based on the current state and the control signal. The controller should have the following state transitions:
- From state 0: If control = 0, stay in state 0, if control = 1, go to state 1.
- From state 1: If control = 0, go to state 2, if control = 1, stay in state 1.
- From state 2: If control = 0, go to state 0, if control = 1, go to state 2.
