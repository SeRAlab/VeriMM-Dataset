Design a simple Verilog module that simulates a 4-to-1 multiplexer. The multiplexer should have four 1-bit inputs (`in0`, `in1`, `in2`, `in3`), a 2-bit select input (`sel`), and a 1-bit output (`out`). The output should be determined by the value of the select lines, such that if `sel` is `00`, `in0` is selected, `01` selects `in1`, `10` selects `in2`, and `11` selects `in3`.
