Design a 4-bit binary counter that increments its value on each clock pulse when enabled. The counter resets to zero when the reset input is asserted. If it reaches its maximum value (15), it wraps around to zero upon the next increment. The current count value is output through the `count` signal.
module top_module(
  input clk,
  input reset,
  input enable,
  output [3:0] count
);
