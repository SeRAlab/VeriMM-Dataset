Design a 2-to-1 multiplexer (mux) that selects between two 1-bit inputs, in_0 and in_1, based on the value of the select signal, sel. When sel is 0, the output out will mirror in_0; when sel is 1, the output will reflect in_1. The output is updated automatically whenever there is a change in the inputs or the select signal.
module top_module(
    input in_0,
    input in_1,
    input sel,
    output reg out
);
