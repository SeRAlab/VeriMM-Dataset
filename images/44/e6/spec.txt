Design a 4-to-1 multiplexer that selects one of four 4-bit data inputs (D0, D1, D2, D3) based on a 2-bit select signal (S). The output (Y) reflects the chosen 4-bit input according to the value of S: if S is 00, output D0; if S is 01, output D1; if S is 10, output D2; and if S is 11, output D3. In case of an invalid state, the output is set to an unknown value (4'hX).
module top_module(
    input [3:0] D0,
    input [3:0] D1,
    input [3:0] D2,
    input [3:0] D3,
    input [1:0] S,
    output reg [3:0] Y  // Change output to reg type
);
