

You are tasked with designing a verilog module that takes in a 4-bit input and outputs the 2's complement of the input. The module should be named "twos_complement" and should have the following ports:

- input [3:0] num: the 4-bit input number
- output [3:0] twos_comp: the 2's complement of the input number

Use the following equation to calculate the 2's complement of a binary number:

twos_comp = ~num + 1

You are not allowed to use any arithmetic operators (+, -, *, /) in your verilog code.
