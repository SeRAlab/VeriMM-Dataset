Design a rising and falling edge detector for a digital signal. The module outputs two signals: `rise` indicates a transition from LOW to HIGH on input `a`, while `down` signifies a transition from HIGH to LOW. The detection operates synchronously with a clock signal and includes an active-low reset for initialization.
module top_module(
  input               clk,
  input               rst_n,
  input               a,
  output reg          rise,
  output reg          down
);
