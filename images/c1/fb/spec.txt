Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a clock divider. 
A clock divider is a digital circuit that takes in an input clock signal and outputs a lower frequency clock signal by dividing the input clock frequency. 
Your module should have the following inputs and outputs:

Inputs: 
- clk_in: the input clock signal
- rst: a synchronous reset signal

Outputs: 
- clk_out: the output clock signal which has a lower frequency than clk_in

The module should also have the following parameters:

- div_factor: the factor by which the input clock frequency is to be divided. This is an integer value.

Your module should implement the following functionality:

- The module should output a clock signal that has a frequency equal to the input clock signal divided by the div_factor.
- The module should be synchronous with the input clock signal, i.e., the output clock signal should change state only when the input clock signal changes state.
- The module should have a synchronous reset input, rst, which when asserted should reset the output clock signal to its initial state.

To implement the clock divider, you should use Verilog code to define the output clock signal as a function of the input clock signal and the div_factor. 
You should then use this function to generate the output clock signal. 
You should also use the rst signal to reset the output clock signal when it is asserted.
