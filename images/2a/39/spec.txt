Design a Verilog module that implements a simple linear regression model to predict an output `y` based on two inputs `x1` and `x2`. The linear regression equation is defined as: 
y = a*x1 + b*x2 + c, 
where `a`, `b`, and `c` are fixed parameters. For this problem, let `a = 2`, `b = 3`, and `c = 5`. The module should take `x1` and `x2` as input and output `y`.
