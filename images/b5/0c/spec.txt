Design a module for data compression and decompression that processes an n-bit input into an m-bit output. When valid input data is detected, it performs a simple compression by shifting the input data right by (n-m) bits, generating the compressed output. Conversely, for decompression, it concatenates the compressed data with a series of zeros and combines it with the input data. The module asserts an output valid signal to indicate the presence of valid output data after each operation. The specified parameters allow customization of input and output data widths, making the module adaptable for various applications in data handling scenarios.
module top_module(
  input [n-1:0] in_data,
  input in_valid,
  output reg [m-1:0] out_data, // Changed to reg
  output reg out_valid         // Changed to reg
);
