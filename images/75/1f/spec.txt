Design a video output controller for VGA interfacing. This module takes in a pixel clock signal and reset input, along with RGB color data and synchronization signals for horizontal and vertical timing. Upon receiving a reset, it initializes the output signals to a known state. During operation, if the blank signal is asserted, the output will remain low for the color data while maintaining the sync signals; otherwise, it will output the RGB data corresponding to the current pixel, synchronizing with the provided h_synch and v_synch signals for VGA compatibility.
module top_module(
pixel_clock,
reset,
vga_red_data,
vga_green_data,
vga_blue_data,
h_synch,
v_synch,
blank,

VGA_HSYNCH,
VGA_VSYNCH,
VGA_OUT_RED,
VGA_OUT_GREEN,
VGA_OUT_BLUE
);
