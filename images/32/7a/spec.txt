Design a fixed-priority arbiter that has three request inputs (req0, req1, req2) and one grant output (grant). The arbiter should grant access to the highest priority request among the inputs, with req0 having the highest priority, followed by req1, and then req2. If multiple requests are asserted, only the highest priority request should be granted. The arbiter should also have a clock and reset signal. On reset, no grants should be active.
