Design a D flip-flop with asynchronous preset and clear functionalities. The flip-flop captures the value of the input D on the rising edge of the clock (CLK). If any of the power supply inputs (VPWR or VGND) or bias inputs (VPB or VNB) are low, it overrides the clocked operation to set Q or clear it, ensuring correct initialization and state maintenance under varying power conditions. Q is the output and Q_N is its inverted state.
module top_module(
    input wire D,
    input wire VPWR,
    input wire VGND,
    input wire VPB,
    input wire VNB,
    output reg Q,
    output reg Q_N,
    input wire CLK
);
