Design a synchronous memory module capable of storing 32-bit data at 16-bit addressable locations. The module supports chip selection (cs), read (re), and write (we) operations, controlled by a clock signal (clk) and a reset signal (reset). Upon reset, the specified address in memory is cleared to zero. When cs is enabled, writing data occurs when we is asserted, and reading data takes place when re is asserted, outputting the data stored at the given address.
module top_module(addr, cs, re, we, clk, reset, data_in, data_out);
