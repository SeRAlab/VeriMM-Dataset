Design a 3-bit up-counter that increments its output on each positive clock edge. When reset is active, the counter resets to zero, and the carry_out signal is set to low. When the counter reaches its maximum value (7, or binary 111), it wraps around to zero and sets the carry_out signal high, indicating a count overflow.
module top_module(
    input clk,
    input rst,
    output reg [2:0] out,
    output reg carry_out
);
