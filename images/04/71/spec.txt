
Design a Verilog module that performs matrix inversion for a 2x2 matrix. The inputs of the module will be the elements of the matrix (a, b, c, d) and the outputs will be the elements of the inverted matrix (a_inv, b_inv, c_inv, d_inv). The matrix inversion formula for a 2x2 matrix is given by:

\[
\begin{bmatrix}
a & b \\
c & d 
\end{bmatrix}^{-1} = \frac{1}{ad - bc} \begin{bmatrix}
d & -b \\
-c & a 
\end{bmatrix}
\]

If the determinant (ad - bc) is zero, the inversion is not possible, and the output should be set to a specific error value (e.g., all zeroes).
