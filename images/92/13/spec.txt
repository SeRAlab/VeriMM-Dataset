Design a programmable counter module that updates its output based on clock cycles. The counter resets to zero upon receiving a reset signal and can be enabled to either increment its current value by 2 or load a new value from an input when the write signal is active. The module features a 16-bit wide output, allowing it to store and manipulate a range of values efficiently.
module top_module(input wire I_clk,
    input wire I_reset,
    input wire I_enable,
    input wire[15:0] I_in,
    input wire I_write,
    output reg[15:0] O_out);
