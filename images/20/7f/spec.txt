Design a simple virtual memory management unit (MMU) that translates a virtual address to a physical address. The MMU should handle a single page table entry with a page size of 4KB. The input will be a 32-bit virtual address, and the output will be a 32-bit physical address. The page table contains a single entry that maps the virtual page 0 to physical page 1. The MMU should also have a valid bit indicating whether the translation is valid.
