Design a 16-bit SRAM cell that supports write and read operations. The SRAM cell should have a write enable signal (WE), a chip select signal (CS), a read enable signal (RE), a 16-bit data input (D), a 16-bit data output (Q), and a 4-bit address (addr). When WE is high and CS is low, the input data D should be written to the address specified by addr. When RE is high and CS is low, the data stored at the address specified by addr should be output to Q. If both WE and RE are high at the same time, the SRAM cell should prioritize the read operation.
