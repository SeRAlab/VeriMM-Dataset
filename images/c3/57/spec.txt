

You have been tasked with designing a module that performs binary addition of two 1-bit inputs xi and yi, and generates a 1-bit sum output Si and a 1-bit carry output Co. The module should be named "one_bit_adder" and should be written in Verilog.

The module should have the following ports:
- xi: a 1-bit input
- yi: a 1-bit input
- Si: a 1-bit output representing the sum of the inputs
- Co: a 1-bit output representing the carry generated by the addition

You should use the following truth table to implement the module:
- xi = 0, yi = 0: Si = 0, Co = 0
- xi = 0, yi = 1: Si = 1, Co = 0
- xi = 1, yi = 0: Si = 1, Co = 0
- xi = 1, yi = 1: Si = 0, Co = 1

Write a Verilog module "one_bit_adder" that implements the above truth table and satisfies the requirements mentioned above. The module should be self-contained and should not require any external modules.
