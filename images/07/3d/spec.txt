
You are tasked with designing a simple firewall that filters packets based on specific criteria. The firewall will check incoming packet headers for a predefined source IP and destination IP. If both IP addresses match, the packet is allowed; otherwise, it is blocked. The source and destination IPs are represented as 8-bit binary numbers (0-255). The firewall should have a reset functionality to clear the states. Implement the logic to check the packets against the allowed source and destination IPs.
