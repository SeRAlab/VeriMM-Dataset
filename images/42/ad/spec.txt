Design a clock gating cell that controls the propagation of the input clock based on an enable signal. When enable is high, the gated output clock replicates the input clock; when enable is low, the output maintains its last state, effectively preventing further clock signal propagation. This design is useful for power management by selectively enabling clock signals to certain parts of a circuit when needed.
module top_module(
  input clk,
  input enable,
  output gated_clk
);
