Design a 4-bit counter that can increment or decrement based on input conditions. The counter is clocked by the input `clk`, can be reset to zero when `rst` is high, and operates only when `en` (enable) is high. The counting direction is controlled by the `dir` input; it increments the count when `dir` is high and decrements when `dir` is low.
module top_module(
    input clk,
    input rst,
    input en,
    input dir,
    output reg [3:0] count
);
