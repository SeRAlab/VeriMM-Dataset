Design a 32-bit ALU (Arithmetic Logic Unit) in Verilog that can perform the following operations based on a 4-bit opcode:
- 0000: Addition
- 0001: Subtraction
- 0010: Bitwise AND
- 0011: Bitwise OR
- 0100: Bitwise XOR
- 0101: Left Shift
- 0110: Right Shift
- 0111: Set on Less Than (SLT)
- 1000: Set on Less Than Unsigned (SLTU)

The ALU should take two 32-bit inputs (`A` and `B`), a 4-bit opcode input (`ALU_op`), and output a 32-bit result (`ALU_out`). Additionally, an output flag (`ALU_zero`) should indicate if the result is zero.
