Design a four-bit binary counter with a clock, reset, and enable inputs. When enabled, the counter increments on each clock cycle and resets to zero upon reaching its maximum value (15). The counter can be reset asynchronously with the reset input, which initializes the counter to zero and sets the state to idle. The design utilizes a simple state machine to manage the counting process and transitions between an IDLE state and a COUNT state based on the enable signal. The current count value is continuously updated and outputted.
module top_module(
  input clk,
  input reset,
  input enable,
  output reg [3:0] count
);
