

You have been tasked with designing a Verilog module for a D-latch with an active-low reset and an active-high gate. The module should have the following inputs and outputs:

Inputs:
- D: Data input
- GATE: Active-high gate input
- RESET: Active-low reset input
- VPWR: Positive power supply voltage
- VGND: Ground reference voltage

Outputs:
- Q: Latched output

The D-latch should operate as follows:
- When the gate input is high, the D-latch should transparently pass the data input to the output.
- When the gate input is low, the D-latch should hold the previous value of the data input at the output.
- When the reset input is low, the output should be forced to a low state regardless of the state of the gate and data inputs.

Your task is to design a Verilog module that implements this D-latch functionality. Your module should be self-contained and should not rely on any external modules or libraries. Your module should also be less than 200 lines of Verilog code.
