Design a 2-stage pipeline processor that consists of an instruction fetch (IF) stage and an instruction decode (ID) stage. The processor should take a 5-bit instruction input, and the output of the ID stage should be a 3-bit opcode and a 2-bit instruction type. The pipeline should have a clock signal input and a reset signal. On the rising edge of the clock, if reset is high, the output should be cleared; otherwise, the output should be updated based on the instruction input.
