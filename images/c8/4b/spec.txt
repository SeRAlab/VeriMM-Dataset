
You are tasked with designing a module that takes in four inputs (A, B, C, D) and outputs their logical AND operation (X). The module should be named `and4_module` and should be written in Verilog within 200 lines of code. The inputs and outputs should be declared as follows:

```
input A;
input B;
input C;
input D;
output X;
```

The module should also include the following voltage supply signals:

```
supply1 VPWR;
supply0 VGND;
supply1 VPB ;
supply0 VNB ;
```

Ensure that the module is synthesizable and meets the following requirements:
- The output X should be high only when all four inputs (A, B, C, D) are high.
- The module should be optimized for area and power consumption.
