Design a power gating controller in Verilog. The controller should take three inputs: enable (1 bit), power_gate_control (1 bit), and sensor_input (1 bit). The output should be a power gate signal that is active only when the enable input is high, the power_gate_control input is high, and the sensor_input is also high. Otherwise, the output should be low. Create logic to ensure that the power gate signal is only active when all conditions are met.
