Design a 4-bit left shift register with load control. When the load signal is asserted, the register captures the 4-bit input value. If load is deasserted, the register shifts its current value left by one bit and fills the least significant bit with a zero. The current state of the register is available on the output.
module top_module(
    input clk,
    input load,
    input [3:0] in,
    output [3:0] out
);
