Design a register file with a read and write capability. The module contains a 32x32-bit memory array, accessed by two read selectors (rdsel1 and rdsel2) for reading data and a write selector (wtsel) for writing data. Upon reset, all registers are initialized to zero. On each clock pulse, the module reads data from the specified addresses into outputs rdata1 and rdata2. If the write enable signal (wenable) is asserted, it updates the memory at the address specified by wtsel with the input data (wtdata).
