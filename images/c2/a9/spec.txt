

You are tasked with designing a module that takes in two inputs, A and B, and outputs their logical AND. The module should be named "and_gate" and should have the following interface:

```
module and_gate (
    input A,
    input B,
    output X
);
```

Your module should be able to handle both rising and falling edge clock signals. The output should be updated only on the rising edge of the clock signal. You should also implement a reset signal that sets the output to 0.

You should write a Verilog module that implements this logic. Your module should be self-contained and should not rely on any external modules or libraries. Your module should be no more than 200 lines of Verilog code.
