
Design a Verilog module for a Flash memory cell that can store a single bit of data. The cell should have the following inputs: `data_in` (1-bit input to write data), `write_enable` (1-bit input to control write operations), and `clk` (clock signal for synchronization). The output should be `data_out` (1-bit output that reflects the stored data). The flash memory cell should retain its value until a write operation is performed.
