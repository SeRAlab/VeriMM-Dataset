Design a 4-to-1 multiplexer that selects one of four 5-bit input signals (a, b, c, d) based on a 2-bit select input (sel). The output (o) reflects the value of the selected input according to the state of sel, where sel = 00 outputs a, sel = 01 outputs b, sel = 10 outputs c, and sel = 11 outputs d.
module top_module(
	input [1:0] sel,
	input [4:0] a,
	input [4:0] b,
	input [4:0] c,
	input [4:0] d,
	output reg [4:0] o
    );
