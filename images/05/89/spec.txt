Design a 32-bit Arithmetic Logic Unit (ALU) that can perform the following operations based on a 3-bit operation code (opcode):
- 000: Addition
- 001: Subtraction
- 010: Bitwise AND
- 011: Bitwise OR
- 100: Bitwise XOR
- 101: Set on Less Than (A < B ? 1 : 0)

The ALU should take two 32-bit inputs (A and B) and output a 32-bit result (R) based on the selected operation. Additionally, the ALU should have a zero flag output which indicates if the result is zero.
