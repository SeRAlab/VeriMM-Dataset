
Design a simple SPI (Serial Peripheral Interface) controller in Verilog that can perform the following functions: 
1. Initialize the SPI bus.
2. Send a single byte of data to the SPI bus.
3. Receive a single byte of data from the SPI bus.
The controller should have inputs for the clock signal (SCK), chip select (CS), and data (MOSI). It should output the received data (MISO) and a signal indicating that the data is valid (data_valid). The SPI operates in mode 0 (CPOL = 0, CPHA = 0).
