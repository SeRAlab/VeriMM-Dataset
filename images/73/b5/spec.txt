Design a 4-to-1 multiplexer that selects one of four 32-bit wide input data lines (din_0, din_1, din_2, din_3) based on the two-bit selection input (sel). When sel is 00, dout outputs din_0; when sel is 01, dout outputs din_1; when sel is 10, dout outputs din_2; and when sel is 11, dout outputs din_3. If an invalid sel value is used, dout is assigned to a default value of all zeros.
module top_module(
    sel, dout, din_0, din_1, din_2, din_3
    );
