
Design a 32-bit data bus multiplexer (MUX) that takes three 32-bit inputs (A, B, and C) and a 2-bit selector (sel). Based on the value of the selector, the MUX should output one of the inputs:
- If sel = 00, output A
- If sel = 01, output B
- If sel = 10, output C
- If sel = 11, output 0 (zero output).
