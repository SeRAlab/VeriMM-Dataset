Design a simple signal distribution module that takes four input power and ground signals (in_VPWR, in_VGND, in_VPB, and in_VNB) and directly outputs them as out_VPWR, out_VGND, out_VPB, and out_VNB. This module effectively acts as a buffer or pass-through, ensuring that the input power connections are routed to the corresponding outputs without modification.
module top_module(
    input in_VPWR,
    input in_VGND,
    input in_VPB,
    input in_VNB,
    output out_VPWR,
    output out_VGND,
    output out_VPB,
    output out_VNB
);
