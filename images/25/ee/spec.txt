Design a JK latch in Verilog that includes a clock input, J and K inputs, and a Q output. The latch should operate according to the following behavior: When the clock goes from low to high, if J and K are both low, Q remains unchanged; if J is high and K is low, Q is set to 1; if J is low and K is high, Q is set to 0; if J and K are both high, Q toggles. Implement this behavior using a Verilog module.
