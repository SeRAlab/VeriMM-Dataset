Design an SR flip-flop in Verilog. The SR flip-flop should have two inputs: S (Set) and R (Reset) and two outputs: Q and Qbar. The flip-flop should have the following behavior:
- If S is 1 and R is 0, Q should be set to 1.
- If S is 0 and R is 1, Q should be set to 0.
- If S is 0 and R is 0, Q should retain its previous state.
- If S is 1 and R is 1, the output state is indeterminate (this case should not occur in practice). 
Implement this behavior in Verilog code.
