Design a clocked, 8-bit wide data register with an active-low reset and a write-enable signal. When the reset signal is asserted (low), the output data is cleared to zero. On a rising edge of the clock, if the write-enable signal is high, the register updates its output to the value present on the input data. If the write-enable is low, the output retains its previous value.
module top_module(
    input wire reset,
    input wire wenb,
    input wire [7:0] in_data,
    input wire clk,
    output reg [7:0] out_data
);
