

You are tasked with designing a verilog module that implements a 4-bit binary to Gray code converter. The module should take in a 4-bit binary input and output the corresponding 4-bit Gray code. The module should have the following interface:

Inputs:
- `in` : 4-bit binary input

Outputs:
- `out` : 4-bit Gray code output

You should name your module `binToGray`.
