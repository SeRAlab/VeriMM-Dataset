Construct a Verilog module to create a 16-bit linear feedback shift register (LFSR) with a synchronous load. The LFSR should load a seed value when the load signal is high. Otherwise, it should shift left and the new bit should be the XOR of the 15th and 13th bits.

module lfsr(
	input clk,
	input load,
	input [15:0] seed,
	output [15:0] lfsr_out);
