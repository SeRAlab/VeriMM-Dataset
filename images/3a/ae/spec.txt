
Create a Verilog module that implements a simple neuron which takes 3 inputs (x1, x2, x3) and produces an output (y). The output is calculated using the following formula:  
y = w1*x1 + w2*x2 + w3*x3 + b  
Where w1 = 2, w2 = -1, w3 = 3, and b = 1.  
The module should be synthesized and tested for different input combinations.
