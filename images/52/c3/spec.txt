Create a Verilog module for an 8-bit parallel-to-serial shift register with load and shift enable. The register should load parallel data when the load signal is high, otherwise, it should shift its bits to the right on the rising edge of the clock if the shift enable signal is high.
module parallel_to_serial_shift_register(
    input clk,
    input load,
    input shift_enable,
    input [7:0] parallel_data,
    output reg serial_out);
