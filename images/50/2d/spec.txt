Implement the Verilog module based on the following description.
Given the following Moore state machine with 1 input (in) and 1 output (out). Unless otherwise stated in the diagram below, assume outputs are 0 and inputs are don't cares.

The state machine has the following states and their corresponding outputs: 
1. state S (out=0).
2. state T (out=1).
3. state U (out=1).

State transitions:
1. From state S: If in = 0, then transition to state U. If in = 1, then transition to state T.
2. From state T: If in = 0, then transition to state S. If in = 1, then transition to state U.
3. From state U: If in = 0, then remain in state U. If in = 1, then transition to state S.

At reset, the state machine starts in state "S". Derive next-state logic equations and output logic equations by inspection assuming the following one-hot encoding is used: (S, T, U) = (3'b001, 3'b010, 3'b100)

Write code that generates the following equations:

- S_next -- next-state logic for state S
- T_next
- U_next
- out -- output logic

module top_module(
    input in,
    input [2:0] state,    // 3-bit one-hot current state
    output reg S_next,
    output reg T_next,
    output reg U_next,
