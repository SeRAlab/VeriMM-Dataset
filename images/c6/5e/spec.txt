

You are tasked with designing a Verilog module that implements a 4-bit counter that can be reset and incremented by a clock signal. The counter should have a synchronous reset input that sets the counter to 0 when asserted. The module should also have an asynchronous enable input that allows the counter to be enabled or disabled at any time.

Write a Verilog module that takes in the following inputs:
- `clk`: the clock signal
- `reset`: the synchronous reset signal
- `enable`: the asynchronous enable signal

The module should output the following:
- `count`: the 4-bit counter value

You should use the following requirements:
- The counter should be reset to 0 when `reset` is asserted.
- The counter should increment by 1 on each positive edge of `clk` when `enable` is asserted.
- The counter should not increment when `enable` is deasserted.
