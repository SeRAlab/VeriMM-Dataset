

You are tasked with designing a verilog module for a 4-bit binary adder. The module should have the following inputs and outputs:

Inputs:
- `clk` (1 bit) - clock signal
- `rst` (1 bit) - asynchronous reset signal
- `a` (4 bits) - first input to the adder
- `b` (4 bits) - second input to the adder

Outputs:
- `sum` (4 bits) - the sum of the two inputs
- `carry_out` (1 bit) - the carry out bit

The module should use behavioral modeling and should be synthesizable. The adder should be able to handle both unsigned and signed inputs.
