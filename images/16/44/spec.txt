Design a Verilog module for a Flash memory cell that allows for programming, erasing, and reading. The module should have an input for data (D), control signals for program (P), erase (E), and read (R), and an output for the stored data (Q). The Flash memory should hold a single bit of data and behave according to the following rules: 
- When P is high, the data D is written to Q (programming).
- When E is high, Q is reset to 0 (erasing).
- When R is high, the current value of Q is output.
- The operations are edge-triggered on a clock (CLK).
