Design a D-type flip-flop with asynchronous set and reset inputs, as well as a clock enable feature. The module outputs a stored value 'Q' and its complement 'Q_N' based on the clock signal (CLK). On the rising edge of CLK, if the clock enable (CE) is active, the flip-flop captures the value of the input (D); if CE is inactive, the output retains its previous value. The asynchronous SET input forces 'Q' high and 'Q_N' low when activated, while the RESET input forces 'Q' low and 'Q_N' high when activated. This design enables flexible control of the flip-flop state based on multiple signals.
module top_module(
    input D,
    input CLK,
    input SET,
    input RESET,
    input CE,
    output reg Q,
    output reg Q_N
);
