
Implement a UART receiver in Verilog. The UART receiver should be able to receive a serial data stream, detect the start bit, and sample the data bits at the correct time. The receiver should output the received byte and indicate when a byte has been successfully received. Assume standard UART settings: 8 data bits, no parity, 1 stop bit, and a baud rate of 9600 with a 50 MHz clock.
