Design a simple calculator module capable of performing four basic arithmetic operations: addition, subtraction, multiplication, and division, on signed 16-bit input values. The operation to perform is selected through a 2-bit input (`op`), with `00` for addition, `01` for subtraction, `10` for multiplication, and `11` for division. The respective results are outputted through dedicated output ports, while ensuring that only the relevant output is active at any time, with others set to zero. The module also includes a safety check for division by zero, outputting a predefined value in such cases.
module top_module(a, b, op, add_out, sub_out, mul_out, div_out);
