Design a Verilog module that implements a simple state machine for an SD card interface. The state machine should have the following states: IDLE, READ, WRITE, and ERROR. The module should have a clock input, a reset input, and a start signal. The state transitions should be as follows: 
- From IDLE to READ on start signal
- From IDLE to WRITE on start signal
- From READ to IDLE on read complete signal
- From WRITE to IDLE on write complete signal
- Any state can transition to ERROR on error signal
The module should output the current state of the state machine.
