Implement a 4-bit shift register with parallel load functionality. When the load signal is asserted, the data register is loaded with the input data. Otherwise, on each clock cycle, the shift register shifts its content to the left by one bit and introduces the shift_in signal as the least significant bit. The current state of the shift register is output on data_out.
module top_module(
  input [3:0] data_in,
  input shift_in,
  input load,
  input clk,
  output reg [3:0] data_out
);
