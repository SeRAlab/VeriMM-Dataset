

You are tasked with designing a verilog module that synchronizes an input signal to an output signal based on a clock and reset signal. The module should have the following ports:

- `clk`: input clock signal
- `data_in`: input data signal
- `reset_n`: input reset signal
- `data_out`: output synchronized data signal

The module should implement a single flop to delay the input signal by one clock cycle before being synchronized to the output signal. The flop should be reset to 0 when the reset signal is asserted low. The module should meet the following requirements:

- The output signal should be synchronized to the input signal based on the rising edge of the clock signal.
- When the reset signal is asserted low, the output signal should be immediately set to 0.
- The module should be synthesizable and meet the timing requirements of the target FPGA.

Implement the module in verilog and simulate it to verify its functionality.
