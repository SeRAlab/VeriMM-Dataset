Design a forwarding circuit that resolves data hazards in a pipeline by selecting the appropriate source operands for two 4-bit wide inputs, A and B. The module produces two selection outputs, A_sel and B_sel, which indicate whether to use data directly from the inputs or from the execution (EX) or memory (MEM) stages based on control signals (ctrl_ex and ctrl_mem) and matching read addresses (ex_rd and mem_rd). When a match is found with the control signals, the circuit prioritizes forwarding to eliminate delays in data access.
module top_module(
	input wire [3:0] A, B,
	input wire [3:0] ex_rd, mem_rd,
	input wire ctrl_ex, ctrl_mem,
	output reg [1:0] A_sel, B_sel
    );
