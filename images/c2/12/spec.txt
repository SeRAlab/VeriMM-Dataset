
You have been tasked to design a verilog module that takes in two 8-bit inputs (A and B) and a carry-in signal (CI) and outputs a 9-bit sum (SUM) and a carry-out signal (COUT_N). The module should be named `adder_8bit`.

The module should have the following behavior:
- If CI is high, the module should add A, B, and 1 and output the 9-bit sum and a carry-out signal.
- If CI is low, the module should add A and B and output the 9-bit sum and a carry-out signal.

The module should have the following interface:
- Two 8-bit inputs: A and B.
- One input: CI.
- One 9-bit output: SUM.
- One output: COUT_N.
