Design a 2nd-order IIR filter with the following transfer function:
H(z) = (b0 + b1*z^-1 + b2*z^-2) / (1 + a1*z^-1 + a2*z^-2)
The filter should be capable of processing 16-bit signed input samples and produce 16-bit signed output samples. It should have two states representing the previous inputs and outputs. The coefficients b0, b1, b2, a1, and a2 should be provided as parameters. Implement the necessary state updates in the sequential logic.
