Design a simple GPIO controller that can read and write to a set of GPIO pins. The controller should have the following features:
- An input signal `mode` that determines the operation mode (0 for input, 1 for output).
- An array of GPIO pins represented as a 5-bit vector `gpio_pins`.
- An input signal `data_in` for input mode and `data_out` for output mode.
- When in input mode, the value of `gpio_pins` should be captured into `data_in`.
- When in output mode, `data_out` should update `gpio_pins` with its value.
The GPIO controller should have a clock input and a reset signal that initializes the GPIO pins to 0.
