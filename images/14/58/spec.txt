Design a combinational circuit that implements a simple Huffman encoding scheme for a fixed set of input characters. The input will be a 4-bit binary value representing one of 16 different characters. The output should be a variable-length binary code according to the Huffman coding scheme. For this problem, you can use the following character-to-code mapping:
- 0000 -> 0
- 0001 -> 10
- 0010 -> 110
- 0011 -> 1110
- 0100 -> 1111
- 0101 -> 1100
- 0110 -> 11100
- 0111 -> 11101
- 1000 -> 111110
- 1001 -> 111111
- 1010 -> 11000
- 1011 -> 11001
- 1100 -> 1010
- 1101 -> 1011
- 1110 -> 1000
- 1111 -> 1001
The output should be represented as a 6-bit code, where the last two bits are used for length indication (000 - 0 bits, 001 - 1 bit, 010 - 2 bits, etc.). If the input character does not match any of the characters in the mapping, the output should be 000000.
