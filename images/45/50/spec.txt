Design a pulse-width modulation (PWM) generator. The module takes an 8-bit control input to determine the duty cycle of the PWM output signal. The PWM output toggles between high and low based on a counter that increments with each clock cycle. When the counter value is less than the control value, the output is high; otherwise, it is low. The counter resets to zero once it reaches its maximum value, creating a continuous PWM signal with adjustable duty cycle according to the `ctrl` input.
module top_module(
  input clk,
  input [7:0] ctrl,
  output pwm
);
