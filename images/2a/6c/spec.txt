Design a JK flip-flop in Verilog. The flip-flop should have inputs J, K, clock (clk), and a reset signal (reset). The output should be Q. When reset is high, Q should be reset to 0. On the rising edge of clk, the behavior should be as follows: if J and K are both 0, Q remains the same; if J is 1 and K is 0, Q is set to 1; if J is 0 and K is 1, Q is set to 0; if both J and K are 1, Q toggles.
