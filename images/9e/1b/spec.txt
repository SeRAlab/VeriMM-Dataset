Design a hysteresis comparator circuit that outputs a digital signal based on input voltage levels relative to two threshold voltages, Vthp and Vthn. The circuit toggles its output high when the input exceeds the positive threshold (Vthp) and sets it low when the input drops below the negative threshold (Vthn). This design includes memory of the previous output state to implement hysteresis, preventing rapid toggling around the threshold values, thus providing noise immunity and stable switching behavior.
module top_module(
  input in,
  input Vthp,
  input Vthn,
  output out
);
