Design a JK flip-flop using Verilog. The flip-flop should have inputs J, K, Clock, and Reset. When Reset is high, the output Q should be reset to 0. On the rising edge of the Clock, if J and K are both low, Q remains unchanged; if J is high and K is low, Q is set to 1; if J is low and K is high, Q is reset to 0; if both J and K are high, Q toggles.
