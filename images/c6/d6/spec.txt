

You are tasked to implement a module that calculates the sum of two 4-bit unsigned numbers using Verilog HDL. The module should have two inputs, `A` and `B`, which are 4-bit unsigned binary numbers, and one output, `SUM`, which is also a 4-bit unsigned binary number. The module should be self-contained and should not require any other modules to function.

Your module should be able to perform the addition of two 4-bit unsigned binary numbers and output the result in binary format. If the sum of the two numbers is greater than 15, the module should output an error message.

You can assume that the inputs `A` and `B` will always be valid 4-bit unsigned binary numbers.

You should name your module `sum4bits`.
