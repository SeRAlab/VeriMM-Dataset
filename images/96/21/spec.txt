Design a synchronous D flip-flop with set and reset functionality. When the clock signal rises, if the set input (ss) is high, the flip-flop outputs a logic high (q=1). If the reset input (sr) is high during the clock edge, the output is set to logic low (q=0). If neither the set nor the reset inputs are active, the output follows the data input (d). This design allows for controlled state management in sequential circuits.
module top_module(
    input clk,
    input ss,
    input sr,
    input d,
    output reg q
);
