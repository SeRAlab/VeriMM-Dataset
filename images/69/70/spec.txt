Design a 4-to-1 multiplexer that takes a 4-bit input (`data_in`) and uses a 2-bit select signal (`select`) to choose which bit to output (`data_out`). Based on the value of `select`, the module outputs one of the four input bits: when `select` is 00, it outputs the least significant bit; when 01, the second bit; when 10, the third bit; and when 11, the most significant bit.
module top_module(
	input [3:0] data_in,
	input [1:0] select,
	output reg data_out
);
