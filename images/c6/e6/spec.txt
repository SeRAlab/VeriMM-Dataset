

You are tasked with designing a module that implements a 2-to-1 multiplexer using Verilog. The module should have two input signals, A and B, and one select signal, SEL. When SEL is low, the output of the module should be equal to A, and when SEL is high, the output should be equal to B.

Your module should be named "mux_2to1" and should be defined as follows:

```verilog
module mux_2to1(
    input A,
    input B,
    input SEL,
    output Y
);
```

Your task is to implement the functionality of the 2-to-1 multiplexer using the above module definition. You are not allowed to use any other modules in your implementation.
