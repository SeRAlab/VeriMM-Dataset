Design a 32-bit counter circuit that increments on the rising edge of the clock signal while also supporting reset and halt functionalities. When the reset (rstd) signal is asserted low, both the main counter and a final output register (counter_fin) are set to zero. If the halt signal is asserted high, the current value of the counter is stored in the counter_fin register and the counting operation pauses. Otherwise, with each clock cycle, the counter increments by one.
