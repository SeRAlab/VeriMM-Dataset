Design a 4-bit barrel shifter capable of shifting its input data either left or right based on the specified shift amount. The shift amount is specified as a signed 4-bit input, where positive values indicate left shifts and negative values indicate right shifts. The output provides the appropriately shifted 4-bit data.
module top_module(
    input [3:0] data_in,
    input [3:0] shift_amount,
    output reg [3:0] data_out
);
