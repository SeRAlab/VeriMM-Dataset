Design a configurable flip-flop module capable of simulating different types of flip-flops based on the `flip_flop_type` parameter. It supports four configurations: a D flip-flop, a JK flip-flop, a T flip-flop, and an SR flip-flop. The module uses a clock input to control state changes, while providing set and reset functionality. Depending on the selected flip-flop type, the output `q` and its complement `q_bar` are assigned values according to the defined logic for each flip-flop, allowing for versatile storage and control behavior in digital circuits.
module top_module(
  input clk,
  input reset,
  input set,
  input d,
  output reg q,
  output reg q_bar
);
