

You are tasked with designing a Verilog module that implements a simple logic circuit. The circuit has three inputs and three outputs as follows:

- Input 1 (a): a single-bit input
- Input 2 (b): a single-bit input
- Input 3 (c): a single-bit input
- Output 1 (x): a single-bit output
- Output 2 (y): a single-bit output
- Output 3 (z): a single-bit output

The logic circuit is defined as follows:
- If input `a` is high, then output `x` should be high and output `y` should be low.
- If input `a` is low and input `b` is high, then output `y` should be high and output `x` should be low.
- If both inputs `a` and `b` are low and input `c` is high, then output `z` should be high and outputs `x` and `y` should be low.
- In all other cases, all outputs should be low.

Implement this logic circuit as a Verilog module named `logic_circuit` that takes the inputs and outputs described above. Use the code snippet below as a starting point. Your task is to complete the module by filling in the missing logic.

```verilog
module logic_circuit(
    input a,
    input b,
    input c,
    output x,
    output y,
    output z
    );

    // Your code here

endmodule
```
