Implement a 4-bit down counter that counts down from 15 to 0. The counter is clocked by the rising edge of the input clock signal. When the reset signal is asserted, the counter resets to its maximum value of 15. If the down signal is active, the counter decrements its value by 1 on each clock cycle; otherwise, it retains its current value.
module top_module(
	input clk,
	input rst,
	input down,
	output reg [3:0] q
);
