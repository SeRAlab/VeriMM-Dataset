Design a 16-bit wide register with load and clear functionality. The module outputs the value Q, which is reset to zero when RST is high. It loads the input D into Q when LD is asserted. If neither RST nor LD is active and CE is high, the output Q increments by one on each positive edge of the CLK signal. This design functions as a counter or a register with configurable load capabilities.
