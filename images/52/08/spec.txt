Design a 4-bit barrel shifter capable of shifting input data either left or right based on a 2-bit shift amount. The module accepts a 4-bit input, `data_in`, and a 2-bit input, `shift_amount`, which specifies the number of positions to shift. The `direction_left` input determines the shifting direction—if true, the data is shifted left, otherwise, it is shifted right. The output, `data_out`, reflects the result of the shift operation, maintaining the data width and filling the vacated bits with zeros.
module top_module(
    input [3:0] data_in,
    input [1:0] shift_amount,
    input direction_left,
    output reg [3:0] data_out
);
