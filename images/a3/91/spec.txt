Design a 4-bit adder/subtractor circuit. The module takes two 4-bit inputs, `a` and `b`, along with a mode control signal. When the mode is low (0), the circuit outputs the sum of `a` and `b`; when the mode is high (1), it outputs the difference of `a` and `b`. The functionality is implemented using combinational logic for sum and difference calculations, followed by sequential logic to select the appropriate output based on the mode signal.
module top_module(
    input [3:0] a,
    input [3:0] b,
    input mode,
    output reg [3:0] result
);
