
Design a 2-channel DMA controller that allows two different devices to transfer data to and from memory. The DMA controller should have the following features:
1. Each channel should have a request (REQ) input and a grant (GNT) output.
2. Each channel should have a data transfer enable (DT_EN) signal to start the transfer.
3. Implement a round-robin arbitration scheme such that if both channels request access simultaneously, the channel that requested last receives the grant first for the next transfer.
4. A 2-bit counter is needed to keep track of the current active channel.
5. The controller should have a reset signal that initializes the state of the system.
