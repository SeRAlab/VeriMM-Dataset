Design a gated clock circuit that selectively enables a clock signal based on input control signals. The module takes a clock input (CLK), an enable input (EN), and a test enable input (TE), and produces an output clock signal (ENCLK) that is controlled by these signals. When both the enable and test enable signals are asserted, the output clock will be passed; otherwise, it remains inactive. This design helps in power management by allowing the clock to be gated off when it is not needed.
module top_module(
    input CLK,
    input EN,
    input TE,
    output ENCLK
);
