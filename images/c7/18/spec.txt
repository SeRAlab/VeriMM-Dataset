

You are tasked with designing a verilog module that implements a 2-to-1 multiplexer using behavioral modeling. The module should have two input ports, `in0` and `in1`, and one output port, `out`. Additionally, the module should have a control input port, `sel`, which determines which input is selected. When `sel` is high, the `in1` input is selected and output at `out`. When `sel` is low, the `in0` input is selected and output at `out`.

Use the following template to create the module:

```
module mux_2_to_1 (
    // Module ports
    input  in0,
    input  in1,
    input  sel,
    output out
);

    // Your code here

endmodule
```

Ensure that your module meets the following requirements:
- The module should use behavioral modeling.
- The module should have two input ports, `in0` and `in1`, and one output port, `out`.
- The module should have a control input port, `sel`, which determines which input is selected.
- When `sel` is high, the `in1` input is selected and output at `out`.
- When `sel` is low, the `in0` input is selected and output at `out`.
