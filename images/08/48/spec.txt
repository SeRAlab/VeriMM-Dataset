
Design a 4-bit SRAM cell that allows reading and writing data. The SRAM cell should have the following inputs: a 4-bit data input (`data_in`), a read enable (`read_en`), a write enable (`write_en`), and a 2-bit address (`addr`). The outputs should be a 4-bit data output (`data_out`). The 4-bit data should be written to the SRAM cell when `write_en` is high, and the data should be read from the SRAM cell when `read_en` is high.
