Design an SR flip-flop using Verilog. The flip-flop should have inputs S (Set) and R (Reset), and an output Q. The behavior should be as follows: when S is high and R is low, Q should be set to 1; when S is low and R is high, Q should be reset to 0; when both S and R are low, Q should maintain its previous state; when both S and R are high, the state is undefined.
