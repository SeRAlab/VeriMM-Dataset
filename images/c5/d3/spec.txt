

You are tasked with implementing a simple 2:1 multiplexer using Verilog. The module should have two input wires, `in0` and `in1`, and a select wire `sel`. The output wire, `out`, should be equal to `in0` when `sel` is low, and `in1` when `sel` is high. 

The module should be named `mux_2to1` and should be defined in a file named `mux_2to1.v`. 

Write the Verilog code for the `mux_2to1` module.
