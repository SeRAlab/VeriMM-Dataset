Design a JK flip-flop module that takes inputs J, K, clock (clk), and reset (rst). The flip-flop should toggle its output (Q) based on the following rules: if J=1 and K=0, Q should be set to 1; if J=0 and K=1, Q should be reset to 0; if J=1 and K=1, Q should toggle; if reset is asserted, Q should be set to 0 regardless of J and K.
