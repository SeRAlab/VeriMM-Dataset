
Create a 16-bit ALU that supports the following operations:
1. Addition
2. Subtraction
3. Bitwise AND
4. Bitwise OR
5. Bitwise XOR

The ALU should take two 16-bit input operands and a 3-bit control signal to select the operation. The output should be a 16-bit result. The ALU should also include a Zero flag that indicates if the result is zero.
