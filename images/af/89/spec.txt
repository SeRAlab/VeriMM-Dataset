Develop a write enable decoder that generates four distinct output signals (r0 to r3) based on a 2-bit selector input (sel) and an enable input (WrEn). Each output represents a different channel, activated when WrEn is high and sel indicates the corresponding channel; specifically, r0 is active when sel is 00, r1 for 01, r2 for 10, and r3 for 11. This design effectively enables one of four write actions based on the selector inputs.
module top_module(
input WrEn,
input [1:0] sel,
output r0,
output r1,
output r2,
output r3
);
