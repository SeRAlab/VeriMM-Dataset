Design a 4-bit shift register that loads a 16-bit input composed of four 4-bit inputs (A, B, C, D) when the load signal is asserted. Upon each positive edge of the clock, if the load signal is low, the register shifts its current value left by one bit, introducing a zero at the least significant bit. The output represents the current state of the register.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input [3:0] C,
    input [3:0] D,
    input load,
    input clk,
    output reg [3:0] Q
);
