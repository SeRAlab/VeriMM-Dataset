Design a toggle flip-flop with asynchronous set and reset functionality. The circuit outputs Q and its complement QN, which toggle their state on the rising edge of the clock (CLK) when T (toggle) input is active. If the set (S) input is high, Q is set to 1 and QN to 0 regardless of T; if the reset (R) input is high, Q is set to 0 and QN to 1, also disregarding T. This design allows for flexible control of the flip-flop's state based on the inputs T, S, and R.
