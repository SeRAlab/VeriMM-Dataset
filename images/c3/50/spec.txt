

You are working on a project that requires you to design a module in Verilog that takes three input signals A1, A2, and B1, and produces a single output signal X. You need to write a Verilog module that implements this functionality and can be synthesized into hardware. 

The module should be named "three_input_gate" and should have the following interface:

```
module three_input_gate (
    input A1,
    input A2,
    input B1,
    output X
);
```

The module should implement the following logic:

- If A1 is high and A2 is low, X should be high.
- If A1 is low and A2 is high, X should be high.
- If B1 is high, X should be low.
- If A1 and A2 are both high or both low, X should be low.

Write a Verilog module that implements this functionality and can be synthesized into hardware. The module should be self-contained and should not rely on any other Verilog modules or libraries. Your solution should be within 200 lines of Verilog code.
