Design a Verilog module that implements a simple SD card interface state machine. The state machine should have the following states: IDLE, READ, WRITE, and ERROR. The module should handle input signals for READ and WRITE requests and output a signal indicating the current state. When a READ request is received, the state should transition from IDLE to READ. When a WRITE request is received, it should transition from IDLE to WRITE. If an error occurs during either operation, it should transition to ERROR state. The state should return to IDLE after completing a READ or WRITE operation.
