Design an Infinite Impulse Response (IIR) filter that takes a 16-bit input sample and processes it using a feedback equation: 
output = (b0 * input + b1 * input_delay1 + b2 * input_delay2 - a1 * output_delay1 - a2 * output_delay2) >> 15;
Where b0, b1, b2, a1, and a2 are filter coefficients. The filter should maintain the previous output and input samples for feedback in its internal state.
