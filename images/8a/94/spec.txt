Design a combinational logic circuit that outputs a HIGH signal, Y2, based on specific conditions of a 3-bit input, y, and a single-bit input, w. The output Y2 will be HIGH if y is equal to the binary values B (001) or F (101), or if y is equal to C (010) while w is HIGH, or if y is equal to E (100) while w is also HIGH. This logic effectively creates a decoder-like function with particular conditions applied to the outputs based on the input values.
module top_module(
    input [3:1] y,
    input w,
    output Y2);
