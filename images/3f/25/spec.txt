Design a 4-bit SRAM cell that allows for reading and writing operations. The SRAM cell should have the following inputs: a 4-bit data input (D), a write enable signal (WE), a read enable signal (RE), and a clock signal (CLK). The output should be a 4-bit data output (Q) that holds the current value stored in the SRAM cell. When WE is high, the data input D should be written to the cell on the rising edge of the clock. When RE is high, the current stored value should be driven to the output Q.
