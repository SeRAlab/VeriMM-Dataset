Design a module that performs both addition and subtraction on two 4-bit inputs, A and B, based on a select control input C. When C is 0, the output S provides the sum of A and B. When C is 1, S reflects the difference (A - B). Additionally, the module produces an output D that is adjusted to provide correct representation in the case of subtraction resulting in a negative value, effectively implementing a form of signed arithmetic.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input C,
  output [3:0] S,
  output [3:0] D
);
