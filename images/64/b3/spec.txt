Develop a keypad input interface that detects key presses from a 4x4 matrix of keys. The module outputs a 4-bit binary representation of the pressed key and a validity signal. On a rising clock edge, if the reset signal is active, both outputs are set to zero. During normal operation, if a specific row input is detected, the corresponding column input determines which key is pressed, updating the key output and setting the valid signal high. The design handles debouncing by checking the status only on clock edges.
module top_module(input clk, input rst, input [3:0] row, input [3:0] col, output reg [3:0] key, output reg valid);
