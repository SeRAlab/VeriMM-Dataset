
Design a 16-bit SRAM cell with read and write functionalities. The SRAM cell should have the following inputs and outputs:
- Input: `data_in` (16 bits) for writing data.
- Input: `addr` (4 bits) for selecting the SRAM address.
- Input: `we` (1 bit) for write enable (1 for write, 0 for read).
- Output: `data_out` (16 bits) for reading data.
The SRAM will have a memory array of 16 entries, each 16 bits wide. The `addr` will select which memory entry to read from or write to.
