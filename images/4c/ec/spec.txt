Create a Verilog module for a D flip-flop with asynchronous reset and enable. The flip-flop should store the value of the data input (d) on the rising edge of the clock (clk) when enable is high. When reset is high, the output (q) should be set to 0 immediately.

Write the Verilog code for the D flip-flop module with the following signals:
- clk: clock signal
- reset: asynchronous reset signal
- enable: enable signal
- d: data input
- q: output

module d_ff(
    input clk,
    input reset,
    input enable,
    input d,
    output reg q
);
