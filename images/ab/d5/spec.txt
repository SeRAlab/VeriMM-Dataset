Design a clock gating cell that generates a gated clock signal. The gated clock output (gclk) is produced by performing a logical AND operation between the input clock signal (clk) and an enable signal (en). When the enable signal is high, the gated clock follows the input clock; when the enable signal is low, the gated clock output is disabled, effectively reducing power consumption in digital circuits by turning off the clock to inactive sections.
module top_module(
  input clk, // clock signal
  input en, // enable signal
  output gclk // gated clock signal
);
