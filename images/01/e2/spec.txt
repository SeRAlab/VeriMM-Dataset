Implement a simple SD card controller that can read and write data. The controller should have the following inputs: a clock signal (clk), a reset signal (reset), a read/write signal (rw), and a 4-bit address (addr). The data input (data_in) is a 16-bit data input used for writing, and the data output (data_out) is a 16-bit data output used for reading. When the rw signal is high, the controller should store data_in at the specified address, and when rw is low, it should read the value from the specified address into data_out. The memory should be implemented as a simple array of 16-bit registers. The controller should also have a ready signal (ready) that goes high when the operation is complete.
