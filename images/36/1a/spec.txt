Design a 4-channel DMA (Direct Memory Access) controller that transfers data from a source memory location to a destination memory location. The controller should have the following inputs: a clock signal, a reset signal, a start signal, and four channel select signals (channel0, channel1, channel2, channel3). The output should indicate which channel is currently transferring data. Each channel should have a data bus for reading from the source and writing to the destination. The DMA controller should operate in a round-robin fashion, granting access to each channel in sequence upon receiving the start signal.
