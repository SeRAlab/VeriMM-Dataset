Design a circuit that performs various bitwise operations based on a control signal. This module accepts two n-bit wide inputs and uses a 2-bit control signal to determine the operation: a bitwise AND when ctrl is '00', a bitwise OR for '01', a bitwise XOR for '10', and a bitwise NOT on the first input when ctrl is '11'. The result of the selected operation is output as an n-bit wide result.
module top_module(
  input [n-1:0] input1,
  input [n-1:0] input2,
  input [1:0] ctrl,
  output [n-1:0] result
);
