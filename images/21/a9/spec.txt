Design a 7-stage pipelined processor that can perform a simple addition operation. The processor should have a 24-bit input and output. The stages of the pipeline should include: Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), Write Back (WB), and two additional stages that handle Control and Status Update. The processor should be able to take in two 24-bit operands and output a 24-bit result after processing through the pipeline.
