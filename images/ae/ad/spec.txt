Develop a dual-port video RAM (VRAM) that allows simultaneous read and write operations. The module features one write port (using p1_addr, p1_data, and p1_we) and one read port (using p2_addr). Data can be written to the memory at the address specified by p1_addr when p1_we is asserted. At the same time, p2_data outputs the data stored at p2_addr. The memory is organized as an array of 8-bit wide entries, supporting a total of 6144 bytes of storage. This design is suited for applications needing fast access to video frame data, enabling efficient graphics rendering in systems like GPUs.
