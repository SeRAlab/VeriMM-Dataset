Design a gated D flip-flop that captures the input data (d) on the rising edge of the clock (clk) only when the enable signal (en) is high. When the enable signal is low, the output (q) retains its previous state, effectively holding the last captured value until the next enable event.
module top_module(
  input clk, // gated clock input
  input en, // enable input
  input d, // data input
  output reg q // output
);
