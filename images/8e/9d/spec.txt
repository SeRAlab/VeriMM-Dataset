Design a module that performs various bitwise operations on two n-bit input signals, A and B. It supports AND, OR, XOR, and NOT operations, with the output Y determined by a 2-bit selection signal (sel). Depending on the value of sel, the module outputs the result of the corresponding operation: when sel is 00, it outputs A AND B; when sel is 01, it outputs A OR B; when sel is 10, it outputs A XOR B; and when sel is 11, it outputs the NOT of A. This function effectively implements a multi-functional logic unit.
module top_module(
  input [n-1:0] A,
  input [n-1:0] B,
  input [1:0] sel,
  output reg [n-1:0] Y // Change output from wire to reg
);
