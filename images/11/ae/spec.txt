Design a LIFO (Last In, First Out) stack using Verilog. The stack should support the following operations: push, pop, and check if the stack is empty. The stack should have a fixed depth, and both push and pop operations should be synchronous. The module should have an input to push data onto the stack, a clock signal, and a reset signal. It should also have an output for the popped data and a flag to indicate if the stack is empty.
