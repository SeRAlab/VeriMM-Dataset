Design a negative-edge-triggered D flip-flop with asynchronous set and reset functionality. When the RESET_B signal is low, the output Q is set to 0 and Q_N to 1. Conversely, when the SET_B signal is low, Q is set to 1 and Q_N to 0. On each positive edge of the CLK_N signal, the output Q captures the value of input D, while Q_N outputs the inverse of D. This module provides a standard memory element with additional asynchronous control inputs for setting and resetting.
module top_module(
    input D,
    input CLK_N,
    input SET_B,
    input RESET_B,
    output Q,
    output Q_N
);
