Implement the Verilog module based on the following description.
Given a 3-bit up/down counter with enable, up/down control, and synchronous reset inputs:

1. The counter increments when up_down is high and decrements when up_down is low.
2. The counter is synchronously reset to zero when reset is high.

Write Verilog implementing this counter.
module up_down_counter (
        input clk,
        input enable,
        input reset,
        input up_down,
        output reg [2:0] count);
