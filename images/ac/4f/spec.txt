Design a 4-bit adder-subtractor circuit that adds two 4-bit inputs, A and B, with the capability to output the result as a 4-bit value, X. The circuit utilizes a 4-bit adder and incorporates external power and ground connections for operational integrity. The output, X, is calculated by subtracting the constant value 5 (binary 0101) from the sum of A and B, effectively allowing the module to perform the subtraction of 5 from the result of A + B. This design is suitable for applications requiring basic arithmetic operations, specifically addition and subtraction.
module top_module(
    input        [3:0] A,
    input        [3:0] B,
    input              VPWR,
    input              VGND,
    input              VPB,
    input              VNB,
    output reg [3:0]   X
);
