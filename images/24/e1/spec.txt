
Design a Verilog module that performs a 1-level Discrete Wavelet Transform (DWT) using the Haar wavelet. The module should have two inputs: an 8-bit signal `x` representing the input data and a clock signal `clk`. The output should consist of two 8-bit signals: `cA` for the approximation coefficients and `cD` for the detail coefficients. The processing should occur on each rising edge of the clock, and you should account for the input size being exactly 2^n (in this case, n=3 for 8 input values).
