Design an interrupt controller that manages multiple interrupt request signals (IRQ). It monitors up to four IRQ signals and determines which has the highest priority based on predefined values for priority levels. The controller outputs up to two interrupt acknowledgment signals (IAK), setting them active based on the IRQ with the highest priority. The module continuously checks the active status of the IRQs and updates the IAKs accordingly, ensuring that the highest priority interrupt is acknowledged while lower priority signals are ignored.
module top_module(
  input [n-1:0] irq,
  output [m-1:0] iak
);
