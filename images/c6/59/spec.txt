

You are tasked with designing a module that performs binary addition of two 4-bit numbers. The module should have three inputs and two outputs. The inputs are A and B, two 4-bit binary numbers to be added, and CI, a carry-in bit. The outputs are SUM, the 4-bit binary sum of A and B, and COUT_N, a carry-out bit. 

Design a module named "binary_adder" that performs the required binary addition. The module should use only combinational logic and should be written in Verilog. The module should be self-contained and should not rely on any external modules.

You should test your module by instantiating it in a testbench and providing test vectors for A, B, and CI. The testbench should check that the SUM and COUT_N output by the module are correct for each test vector.
