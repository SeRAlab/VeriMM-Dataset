Implement a 12-bit wide synchronous dual-port block memory. The module allows for data to be written into a memory array at the address specified by `addra` when the write enable signal (`wea`) is high during the rising edge of the clock (`clka`). The output (`douta`) continuously reflects the contents of the memory at the specified address, allowing simultaneous read and write operations.
