Design an 8-bit DRAM cell with read and write capabilities. The DRAM cell should have the following inputs and outputs:
- Input: `data_in` (8-bit data to be written), `wr_enable` (write enable signal), `rd_enable` (read enable signal), `clk` (clock signal)
- Output: `data_out` (8-bit data read from the DRAM cell)

When `wr_enable` is high, the data from `data_in` should be written to the cell on the rising edge of the clock. When `rd_enable` is high, the stored data should be output on `data_out` on the rising edge of the clock.
