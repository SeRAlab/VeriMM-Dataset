Design a Verilog module that implements a simplified RSA encryption algorithm. The module should take a plaintext input, a public exponent, and a modulo as inputs, and output the encrypted ciphertext. The encryption should be performed sequentially, utilizing a state machine to handle the different stages of RSA encryption. Ensure that the exponentiation is done using a simple square-and-multiply method, and the module should support 8-bit plaintext inputs. The public exponent and modulo will be fixed values for the purpose of this problem.
