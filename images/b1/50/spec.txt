Design a 32-bit Arithmetic Logic Unit (ALU) capable of performing various arithmetic and bitwise operations based on a 3-bit operation code (ALUOp). The module can execute addition, subtraction, bitwise AND, bitwise OR, logical right shift, and arithmetic right shift based on the selected ALU operation. The output, C, reflects the result of the operation performed on the two 32-bit input operands, A and B.
module top_module(
    input [31:0] A,
    input [31:0] B,
    input [2:0] ALUOp,
    output [31:0] C
    );
