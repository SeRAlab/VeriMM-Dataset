

You are tasked with designing a Verilog module that implements a 4-bit binary to Gray code converter. The module should have a single 4-bit input port and a single 4-bit output port. The input port should be named "bin" and the output port should be named "gray". The module should convert the binary input to its equivalent Gray code and output it on the "gray" port.

Gray code is a binary numeral system where two successive values differ in only one bit. The Gray code equivalent of a binary number can be obtained by performing an exclusive OR operation between the binary number and its right-shifted version. For example, the Gray code equivalent of binary number 1011 (11 in decimal) is 1101 (13 in decimal) because:

1011 XOR 0101 = 1101

Your module should implement this conversion logic. You may assume that the input binary number is always a valid 4-bit value.
