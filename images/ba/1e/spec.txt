Design a 4-to-1 multiplexer circuit that selects one of four 1-bit input signals (A[0] to A[3]) based on a 2-bit selection input (S[1:0]). The output (X) reflects the selected input signal, with S[0] and S[1] determining which input is routed to the output: when S=00, A[0] is selected; S=01 selects A[1]; S=10 selects A[2]; and S=11 selects A[3]. Additionally, the module includes internal wiring for intermediate selection logic and an external multiplexer instance for the primary selection mechanism.
module top_module(
    input [3:0] A,
    input [1:0] S,
    output X
);
