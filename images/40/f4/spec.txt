
Design a 16-bit Digital to Analog Converter (DAC) in Verilog. The DAC should take a 16-bit input value and produce a corresponding 16-bit output value, which is the same as the input value. The input can range from 0 to 65535 (0x0000 to 0xFFFF). Additionally, the output should be valid only when a control signal `valid` is high. If `valid` is low, the output should be set to 0.
