Design a state-space controller in Verilog that implements a simple state-space representation for a discrete-time system. The state-space controller should accept a state vector (x), an input vector (u), and produce an output vector (y) based on given matrices A, B, C, and D. Assume the dimensions of the state vector is 2, and input vector is 1. The matrices are represented as 2x2 for A, 2x1 for B, 1x2 for C, and 1x1 for D.
