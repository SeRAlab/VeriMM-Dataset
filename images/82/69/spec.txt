Design a 32-bit dual-port RAM (DPRAM) module with a configurable write clock inversion feature. This memory module allows concurrent read and write operations, where the output O reflects the data stored at address A and can be updated with the data input DI when write enable (WE) is asserted. The address for writing is specified by WA, while the initial memory content can be set using the INIT_00 parameter. The write operation is synchronized with the clock signal CLK, which can be inverted based on the configurable parameter IS_WCLK_INVERTED.
module top_module(output [31:0] O, input [31:0] DI, input CLK, WE, input [4:0] A, WA);
