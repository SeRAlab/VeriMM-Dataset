
Design a 2-stage pipeline processor that performs a simple arithmetic operation. The pipeline has two stages: 
1. The first stage fetches two 4-bit operands and an operation code (2 bits) that specifies the operation to be performed (00: ADD, 01: SUB, 10: AND, 11: OR).
2. The second stage processes the operands based on the operation code and produces a 4-bit result.

The design must include registers to hold the operands and the result between the two stages.
