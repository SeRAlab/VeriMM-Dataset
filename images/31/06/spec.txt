
Design a 3x3 Gaussian blur filter in Verilog. The module should accept a 3x3 matrix of pixel values as input and output a single blurred pixel value. The Gaussian blur can be approximated using the following weights for each pixel in the 3x3 matrix:
```
0.061, 0.124, 0.061
0.124, 0.244, 0.124
0.061, 0.124, 0.061
```
The output pixel value should be the weighted sum of the input pixel values. The inputs will be provided as 9-bit unsigned integers (0-255).
