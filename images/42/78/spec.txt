Design a synchronous 2-bit binary adder with carry-in and carry-out capabilities, clocked by the input signal `clk`. The module takes two 2-bit inputs `a` and `b`, along with a single-bit carry-in `cin`, and produces a 2-bit sum output `sum` and a 1-bit carry-out output `cout`. On every rising edge of the clock, the module computes the sum of the inputs and carry-in, storing the result for the next clock cycle. The carry-out signal indicates if there is an overflow from the addition operation.
module top_module(
    input clk,
    input [1:0] a,
    input [1:0] b,
    input cin,
    output reg [1:0] sum,
    output reg cout
);
