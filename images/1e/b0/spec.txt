
Design a Verilog module that simulates a Flash memory cell. The Flash memory cell should have a mechanism to store a single bit of data (0 or 1) and should include the following operations:
1. Write: Store a new bit of data.
2. Read: Output the stored bit.
3. Erase: Reset the stored bit to 0.

The module should have the following inputs and outputs:
- Inputs: `clk` (clock), `write_en` (write enable), `erase_en` (erase enable), `data_in` (the bit to store).
- Outputs: `data_out` (the stored bit).
