

You are tasked with designing a module that performs a 2-to-1 multiplexer. The module should take two 32-bit inputs, `a` and `b`, and a 1-bit select input `sel`. If `sel` is 0, the output of the module should be `a`. If `sel` is 1, the output should be `b`.

Design a Verilog module that implements this 2-to-1 multiplexer.

Your module should be named `mux2to1_32` and should have the following ports:
- `input wire sel`: the 1-bit select input
- `input wire [31:0] a`: the 32-bit input `a`
- `input wire [31:0] b`: the 32-bit input `b`
- `output reg [31:0] o`: the 32-bit output

Your module should use a single always block to implement the multiplexer logic.
