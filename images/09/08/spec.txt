Design a fixed-priority arbiter in Verilog that takes 4 request signals (req[3:0]) and grants access to one of them based on a fixed priority scheme. The priority order is req[3] > req[2] > req[1] > req[0]. Implement the arbiter so that it grants access to the highest priority request that is asserted. The output should be a 4-bit grant signal (grant[3:0]) indicating which request is being granted.
