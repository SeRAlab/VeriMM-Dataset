Design a 32-bit wide register that stores data on the rising edge of the clock. When the reset signal is high, the register is cleared to zero. Otherwise, the register loads the value from the input data enable signal (d_en) upon the clock edge, and the output reflects the current stored value of the register (data).
module top_module(
    input wire status,
    input wire reset,
    input wire clk,  
    input wire [31:0] d_en, 
    output wire [31:0] data    
);
