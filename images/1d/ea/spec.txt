Design a FIFO (First-In-First-Out) queue that can store 4-bit data. The FIFO should have the following inputs: `clk` (clock), `reset` (active high), `push` (to add data), `pop` (to remove data), and `data_in` (4-bit input data). The outputs should include `data_out` (4-bit output data) and `empty` (indicates if the FIFO is empty). The FIFO should support basic push and pop operations.
