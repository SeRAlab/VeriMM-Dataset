Design a circuit that compares two 8-bit inputs, A and B. The module outputs three signals: 'equal' indicates if A is equal to B, 'A_greater_than_B' signifies if A is greater than B, and 'A_less_than_B' indicates if A is less than B. This functionality allows for relational comparisons between the two 8-bit binary numbers.
module top_module(
    input [7:0] A,
    input [7:0] B,
    output equal,
    output A_greater_than_B,
    output A_less_than_B
);
