
Design a 4-input logistic regression unit that takes four binary inputs (x1, x2, x3, x4) and produces an output (y) which is a binary value (0 or 1) based on the logistic regression formula:
y = 1 / (1 + exp(-w1*x1 - w2*x2 - w3*x3 - w4*x4))
where weights w1, w2, w3, w4 are predefined constants. For simplicity, you can set the weights to fixed binary values.
