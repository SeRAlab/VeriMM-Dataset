Design a module that serves as a programmable interrupt controller with edge detection capabilities. The module monitors an input signal (`in_port`) and generates an interrupt request (`irq`) based on configured edge conditions, using a mask (`irq_mask`) and capturing edge transitions with a register (`edge_capture`). It includes an addressable register space for reading and writing control settings, enabling the user to manipulate the interrupt behavior via separate addresses. The `readdata` output reflects values based on the address input, allowing the retrieval of the current state of the input signal, the interrupt mask, or the edge capture status. The design ensures proper synchronization and state management through clock and reset controls.
module top_module(
  input   [1:0] address,
  input         chipselect,
  input         clk,
  input         in_port,
  input         reset_n,
  input         write_n,
  input  [31:0] writedata,
  output        irq,
  output reg [31:0] readdata  // Changed output to reg to allow assignment in always block
);
