

You are tasked with designing a verilog module that takes in two 8-bit inputs and outputs the sum of those inputs. The module should also output a carry bit indicating if there is a carry-out from the most significant bit. Assume that the inputs are unsigned integers. 

Your module should have the following interface:

```
module adder (
    input [7:0] a,
    input [7:0] b,
    output [7:0] sum,
    output carry
);
```

Your module should be synthesizable and should use only combinational logic. 

Write the verilog code for the adder module.
