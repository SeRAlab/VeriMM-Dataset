Design a Verilog module that simulates a simple EEPROM memory cell. The EEPROM has a data input (D), a read enable (RE), a write enable (WE), and a clock (CLK). When WE is high, the data input should be written to the memory cell on the rising edge of the clock. When RE is high, the data stored in the memory cell should be output on the data output (Q). If both RE and WE are low, the memory cell should retain its value. Implement this functionality in Verilog.
