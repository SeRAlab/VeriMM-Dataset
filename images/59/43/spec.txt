Design a D flip-flop with an asynchronous active-low reset. The circuit samples the input D on the rising edge of the clock signal CLK. If the asynchronous reset signal SET_B is low, the output Q is immediately set to LOW. Otherwise, the value of D is transferred to Q on each clock edge. The module also provides the complementary output Q_N as the logical negation of Q.
module top_module(
    input D,
    input SET_B,
    input SCD,
    input SCE,
    input CLK,
    output Q,
    output Q_N
);
