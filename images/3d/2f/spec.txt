
Design an HMAC (Hash-based Message Authentication Code) module in Verilog. The HMAC should take a message and a key as inputs and output the HMAC value. The HMAC calculation should be based on a simple hash function module that will be provided as a submodule in your design. The module should have two input signals for the message and key, a valid signal to indicate when inputs are valid, and an output signal for the HMAC result. After receiving valid inputs, the HMAC should be computed and outputted on the next clock cycle.
