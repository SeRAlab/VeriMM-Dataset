Please act as a professional verilog designer.

Design a Verilog module for an 8-bit binary to Gray code converter. The module converts an 8-bit binary input to an 8-bit Gray code output.

Module name:  
    binary_to_gray_8bit  

Input ports:
    binary_in: Binary input data with a data width of 8 bits.

Output ports:
    gray_out: Gray code output data with a data width of 8 bits.

Implementation:
Gray code conversion:
The most significant bit of the Gray code is the same as the most significant bit of the binary input. Each subsequent bit of the Gray code is the XOR of the corresponding binary bit and the next more significant binary bit.
