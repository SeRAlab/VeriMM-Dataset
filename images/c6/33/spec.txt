

You have been tasked with designing a module in Verilog that implements a combinational logic circuit. The circuit should take in 5 inputs (A1, A2, A3, B1, and C1) and produce 1 output (X). The module should be named "my_comb_logic" and should have the following ports:

- A1, A2, A3, B1, C1: input
- X: output

The circuit should implement the following logic:

- If A1, A2, and A3 are all high, X should be high.
- If B1 is high and C1 is low, X should be high.
- In all other cases, X should be low.

Your module should be self-contained and should not rely on any other modules or external libraries. Additionally, your module should be no more than 200 lines of Verilog code.
