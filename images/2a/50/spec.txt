Design a simple SATA controller state machine that manages the state transitions among the following states: IDLE, ACTIVE, and ERROR. The controller should transition from IDLE to ACTIVE when a start signal is received. In ACTIVE state, if a stop signal is received, it should transition back to IDLE. If an error signal is received at any time, it should transition to ERROR state. The controller should output the current state in binary format (2 bits: 00 for IDLE, 01 for ACTIVE, 10 for ERROR).
