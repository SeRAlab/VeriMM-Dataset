
Design a JK latch using Verilog. The JK latch should have inputs J and K, a clock signal (CLK), and output Q. It should follow the standard JK latch behavior:
- If J = K = 0, the output Q remains unchanged.
- If J = 1 and K = 0, the output Q is set to 1.
- If J = 0 and K = 1, the output Q is reset to 0.
- If J = K = 1, the output Q toggles.
