Design a register-based module that interfaces with a clock for data storage and retrieval, functioning as a memory-mapped I/O device. The module allows data to be written to an 8-bit register when the chip is selected and write enable is asserted. It supports asynchronous reset functionality to initialize the register. The output includes an 8-bit port that reflects the stored data and a 32-bit read data output, which signifies the data in a wider format. The module specifically responds to address-encoded inputs for data handling, simplifying integration into larger systems.
module top_module(
  input [1:0] address,
  input chipselect,
  input clk,
  input reset_n,
  input write_n,
  input [31:0] writedata,
  output reg [7:0] out_port,
  output reg [31:0] readdata
);
