Design a circuit that first reverses an 8-bit input and then selects one of four 4-bit inputs based on a 2-bit selection signal. The selected 4-bit input is combined with the upper 4 bits of the reversed input using a bitwise AND operation. The result of this operation is produced as a 4-bit output. This module effectively functions as a combination of a reverse unit, a multiplexer, and an AND gate.
module top_module(
    input [7:0] in,
    input [3:0] in0,
    input [3:0] in1,
    input [3:0] in2,
    input [3:0] in3,
    input [1:0] sel,
    output [3:0] out
);
