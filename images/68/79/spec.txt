Design a circuit that implements both combinational and sequential XOR logic based on two input signals. The combinational output (`out_xor_comb`) reflects the instantaneous XOR result of `in_1` and `in_2`. In contrast, the sequential output (`out_xor_seq`) generates an XOR output that changes only when there is a transition on either input signal, effectively latching the XOR result until a subsequent change is detected. The circuit is synchronized to a clock signal and incorporates a reset functionality to initialize its state.
module top_module(
  input clk,
  input reset,
  input in_1,
  input in_2,
  output out_xor_comb,
  output out_xor_seq
);
