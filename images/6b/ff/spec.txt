Design a Fredkin gate, a reversible binary logic gate with three inputs (x, y, z) and three outputs (p, q, r). The output p directly mirrors the input x, while outputs q and r perform controlled swapping based on the value of x: if x is LOW, outputs q and r respectively take the values of y and z; if x is HIGH, q takes the value of z and r takes the value of y. This functionality allows the gate to conditionally control the state of the other two inputs based on the state of x.

    input x,y,z,
    output p,q,r
