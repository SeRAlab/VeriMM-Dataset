Design a 4th-order IIR filter that takes a 16-bit signed input and produces a 16-bit signed output. The filter should have the following coefficients: a0 = 0.1, a1 = 0.2, a2 = 0.3, a3 = 0.4, b0 = 0.5, b1 = 0.6, b2 = 0.7, b3 = 0.8. The filter should also maintain state for previous inputs and outputs.
