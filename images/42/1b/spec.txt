Design a finite state machine that processes two 32-bit input values, a and b, to produce a 32-bit result and a done signal. The machine operates upon the rising edge of a clock and begins processing when the start signal is asserted. Initially, the state resets all outputs. In state 0, if the start signal is active, it transitions to state 1 and clears the done signal. In state 1, it stores the input values a and b, then moves to state 2. Finally, in state 2, it outputs the value stored from a as the result and asserts the done signal before returning to the reset state 0. The system effectively captures the first input and outputs it while signaling completion.
