Implement a Verilog module that calculates the factorial of a given number. The module should have the following specifications:
- `clk`: The clock signal.
- `reset`: An active-high synchronous reset signal.
- `start`: An active-high signal that starts the calculation.
- `n`: The input number for which the factorial is to be calculated.
- `result`: The output which holds the factorial of the input number.
- `done`: An active-high signal indicating the completion of the calculation.
