Design a circuit that functions as a simple DRAM memory module. It has addressable memory locations where each location is 8 bits wide and the total memory depth is determined by the address width parameter. On the rising edge of the clock, if the enable signal is active, the module can either write data into the specified address (when the write enable signal is asserted) or read data from that address into the output. The memory is initialized to zero upon module reset, providing a clear state before any operations are performed.
