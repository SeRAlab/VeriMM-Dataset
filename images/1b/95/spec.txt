Design a 5-stage pipeline processor in Verilog that includes Fetch, Decode, Execute, Memory Access, and Write Back stages. Each stage will have a simple operation: Fetch retrieves an instruction, Decode interprets it, Execute performs an operation, Memory Access reads/writes data, and Write Back writes the result back to a register. The pipeline must handle forwarding to avoid data hazards. Implement the pipeline control logic to ensure correct operation across stages.
