Design a simple parallel I/O (PIO) module that facilitates data writing and reading. The module uses a two-bit address and is controlled by a chip select signal and a write signal. When the chip is selected and the write signal is low, data from the `writedata` input is stored in a register on the rising edge of the clock, but only when the address is zero. The `out_port` continuously outputs the stored data, while the `readdata` output reflects the stored value when the address is zero, effectively functioning like a register-based memory. The reset ability allows the stored data to be initialized to low when the reset signal is activated.
module top_module(address,chipselect,clk,reset_n,write_n,writedata,out_port,readdata);
