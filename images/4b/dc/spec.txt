Design a toggle switch circuit that utilizes a clock signal for operation. When the reset input (rst) is activated, the output (out) is set LOW. Upon each rising edge of the clock (clk), if the reset is not active and the trigger input (trigger) is HIGH, the output state toggles between HIGH and LOW. This design enables controlled toggling of the output based on the clock and trigger signals, effectively serving as a flip-flop with a manual trigger mechanism.
module top_module(input  clk,
			  input  rst,
			  input  trigger,
			  output out);
