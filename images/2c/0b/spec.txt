Design a simple FIFO (First In First Out) queue with a depth of 4. The FIFO should have the following signals: `clk`, `rst`, `enq` (input data), `deq` (output data), and `full` and `empty` flags to indicate the status of the FIFO. The FIFO should allow data to be enqueued if not full, and dequeued if not empty. Use a simple 4-element register array to implement the storage.
