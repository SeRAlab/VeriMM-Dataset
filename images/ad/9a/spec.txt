Design a one-bit full adder circuit that takes three inputs: two binary digits A and B, and a carry input CI. The module produces a sum output (SUM) which is the result of the bitwise addition of A, B, and CI, and a carry-out output (COUT) that indicates if there is a carry generated from the addition. The SUM output is computed using the XOR operation, while the COUT is computed using a combination of AND and OR operations to account for carry generation from any two of the three inputs being high.
module top_module(
    input A,
    input B,
    input CI,
    output reg SUM,
    output reg COUT
);
