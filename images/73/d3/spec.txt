Design a four-bit binary adder that takes two 4-bit inputs, A and B, along with a carry-in input (Cin). The module computes the sum of these inputs, producing a 4-bit output (S). The output is derived from the least significant 4 bits of the total sum, which accommodates a potential carry from the addition, effectively enabling the addition of two 4-bit numbers with a carry-in.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    output [3:0] S
);
