Design a register file interface module that synchronously captures and outputs various control and data signals. It utilizes a clock and an active-low reset input to manage state changes. On each rising edge of the clock, if the reset is inactive, the module stores the input values for `rs1_i`, `rt2_i`, and `instr_i` as well as the control signals `Mem2Reg_i` and `RegWrite_i` into their corresponding output registers: `rs1_o`, `rt2_o`, `instr_o`, `Mem2Reg_o`, and `RegWrite_o`. When reset, all outputs are cleared to zero, ensuring a defined state for subsequent operations.
module top_module( clk_i, rst_n, rs1_i, rs1_o, rt2_i, rt2_o, instr_i, instr_o, Mem2Reg_i, Mem2Reg_o, RegWrite_i, RegWrite_o );
