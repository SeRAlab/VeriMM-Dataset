

You are tasked with designing a Verilog module for a binary to gray code converter. The module should have one input, a 4-bit binary number, and one output, a 4-bit gray code number. The module should output the correct gray code equivalent of the binary input.

Gray code is a binary numeral system where two successive values differ in only one bit. For example, the 4-bit binary number 0101 is equal to the 4-bit gray code number 0111.

Use the following code snippet as a starting point:

```
module binary_to_gray (
    input [3:0] binary,
    output [3:0] gray
);

// Your code here

endmodule
```
