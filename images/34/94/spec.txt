Design a 4-bit DRAM cell with read and write capabilities. The DRAM cell should have a data input (4 bits), a data output (4 bits), a read enable signal, a write enable signal, and a clock signal. The DRAM cell should remember the written data until it is overwritten. The read operation should output the stored data when the read enable signal is high and the write operation should store the input data when the write enable signal is high.
