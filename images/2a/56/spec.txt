
Design a 4-bit SRAM cell. The SRAM cell should have a 4-bit data input (`data_in`), a 4-bit data output (`data_out`), a write enable signal (`we`), and a clock signal (`clk`). When `we` is high, the SRAM cell should store the `data_in` value on the rising edge of the clock. When `we` is low, the `data_out` should reflect the stored value in the SRAM cell.
