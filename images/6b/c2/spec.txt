Design a 4-input XOR gate that outputs a single bit result, X. The output is true when an odd number of the inputs A, B, C, or D are true. The design achieves this by first computing the XOR of inputs A and B to get an intermediate result AB, then computing the XOR of inputs C and D to get another intermediate result CD, and finally XORing these two intermediate results to produce the final output X.
module top_module(
    output X,
    input  A,
    input  B,
    input  C,
    input  D
);
