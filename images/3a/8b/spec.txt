Design a simple Bluetooth module interface that takes a 4-bit input representing a command and outputs a 3-bit status code. The command can be one of the following: 0000 (No Command), 0001 (Connect), 0010 (Disconnect), 0011 (Send Data), 0100 (Receive Data). The output status codes are: 000 (Idle), 001 (Connected), 010 (Disconnected), 011 (Data Sent), 100 (Data Received).
