Design a 4-bit SRAM cell that allows for reading, writing, and holding data. The SRAM cell should have the following inputs: `data_in` (4 bits for input data), `addr` (2 bits for address selection), `write_enable` (1 bit to enable writing), and `clk` (1 bit for clock). The output should be `data_out` (4 bits for output data). The cell should store data in a 4x4 memory array and should implement read and write operations based on the address and write enable signals.
