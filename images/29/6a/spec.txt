
Design a simple packet filtering firewall in Verilog. The firewall will accept packets based on a set of rules defined by two inputs: the source IP address (5 bits) and the destination IP address (5 bits). The firewall will allow packets if the source IP address is within a certain range (e.g., 00000 to 01111) and the destination IP address is exactly 10101. The output will be a single bit indicating whether the packet is accepted (1) or rejected (0).
