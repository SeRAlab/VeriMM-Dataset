

You are tasked with designing a Verilog module that implements a 4-to-1 multiplexer. The module should have four 8-bit input ports and one 8-bit output port. The module should also have two select input ports, S1 and S0, which select which input port to output on the output port. If S1S0 = 00, output the first input port on the output port. If S1S0 = 01, output the second input port on the output port. If S1S0 = 10, output the third input port on the output port. If S1S0 = 11, output the fourth input port on the output port.
