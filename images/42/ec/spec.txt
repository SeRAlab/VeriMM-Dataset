Develop a Verilog module that generates an 8-bit binary counter with synchronous reset and load functionality. The counter should increment on every positive clock edge if the load signal is low, and load the input value when the load signal is high. Reset to 0 when the reset signal is high.
module binary_counter(
	input clk,
	input reset,
	input load,
	input [7:0] load_value,
	output reg [7:0] count);
