
Design a Verilog module for a Flash memory cell that can store one bit of information. The Flash memory cell should have a control signal for writing and reading data. The module should have the following ports:
- `input wire clk`: Clock signal for sequential operation.
- `input wire write_en`: Write enable signal.
- `input wire data_in`: Input data (1 bit).
- `output reg data_out`: Output data (1 bit).
When `write_en` is high, the value of `data_in` should be stored in the memory cell at the rising edge of `clk`. When `write_en` is low, `data_out` should reflect the stored value.
