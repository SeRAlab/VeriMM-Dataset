Design a circuit that performs a series of conditional rotations on an 11-bit input `data_in` based on the value of a 4-bit control signal `n`. Each bit of `n` determines whether to perform a specific rotation on the data: if `n[3]` is high, the lower 8 bits of `data_in` are rotated to the left with the upper 3 bits; if `n[2]` is high, the result is rotated 4 bits to the left; if `n[1]` is high, it is rotated 2 bits to the left; and if `n[0]` is high, the least significant bit is moved to the most significant position, completing the cycle. The final output is `data_out`, which reflects all the applied rotations based on the control bits.
module top_module(input wire [3:0] n, input wire [10:0] data_in, output wire [10:0] data_out);
