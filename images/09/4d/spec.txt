Design a GPIO controller that allows for reading and writing to a set of general-purpose input/output pins. The controller should have the following features:
1. A 4-bit input for data to be written to the GPIO pins.
2. A 4-bit output for reading the current state of the GPIO pins.
3. Control signals: `write_enable` (1 bit) to enable writing to the pins and `read_enable` (1 bit) to enable reading from the pins.
4. A reset signal to initialize the pins to a known state (0).
