Design a 3-bit finite state machine (FSM) counter that cycles through four states (0 to 3) in response to a clock signal. On each clock cycle, the counter advances to the next state: from 0 to 1 to 2 to 3 and then wraps back to 0. The counter can be reset asynchronously; when the reset signal is asserted, the state and counter are both initialized to 0. This module provides a simple counting functionality suitable for applications requiring state tracking in digital systems.
module top_module(
  input clk,
  input reset,
  input [2:0] counter,
  output reg [2:0] next_counter
);
