
Design a JK flip-flop in Verilog that has the following functionality:
- The flip-flop should have inputs J, K, clock, and enable.
- When enable is high and on the rising edge of the clock:
  - If J = 1 and K = 0, the output Q should be set to 1.
  - If J = 0 and K = 1, the output Q should be set to 0.
  - If J = 1 and K = 1, the output Q should toggle.
  - If J = 0 and K = 0, the output Q remains unchanged.
- The flip-flop should have an asynchronous reset input that sets Q to 0 when activated.
