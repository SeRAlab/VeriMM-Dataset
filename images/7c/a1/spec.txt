Design a circuit that controls the state of four LEDs based on the corresponding state of four switches. Each LED will light up (turn HIGH) when its associated switch is pressed (SW_n = 0) and will remain off (turn LOW) when the switch is not pressed (SW_n = 1). This module effectively serves as a basic switch-to-LED indicator system.
module top_module(
    input SW_0,
    input SW_1,
    input SW_2,
    input SW_3,
    output LED_0,
    output LED_1,
    output LED_2,
    output LED_3
);
