

You are tasked with designing a verilog module that takes in three inputs, A, B, and C. The module should output a 1 if the input values are in ascending order, and a 0 otherwise. Assume that the input values are unsigned 8-bit integers. 

Design a verilog module that takes in three 8-bit unsigned integers, A, B, and C, and outputs a 1 if A < B < C, and a 0 otherwise.
