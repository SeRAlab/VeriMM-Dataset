
Design a simple 2-bit Branch History Table (BHT) for a branch predictor. The BHT will use a 2-bit saturating counter for each entry, which will be incremented on a taken branch and decremented on a not-taken branch. The initial state of each counter should be 00 (strongly not taken). The design should have inputs for the branch address and the branch outcome (taken or not taken), and output the prediction based on the current state of the BHT.
