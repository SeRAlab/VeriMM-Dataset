Design a temperature control system. The system has a temperature sensor input (temp) and a setpoint input (setpoint). The system controls a heater (heat) and a cooler (cool). If the temperature is below the setpoint, the heater is turned on. If the temperature is above the setpoint, the cooler is turned on. If the temperature is equal to the setpoint, both the heater and cooler are turned off.
