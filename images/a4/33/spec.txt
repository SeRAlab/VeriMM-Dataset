Please act as a professional Verilog designer.

Design a 6-bit synchronous loadable counter. The counter should load a specific value when the load signal is active. The counter should reset to 0 when the reset signal is active.

Module name:
    LoadableCounter
Input ports:
    clk: Clock signal used for synchronous operation.
    reset: Active-high reset signal.
    load: Active-high signal to load the counter.
    load_value: 6-bit input value to load into the counter.

Output ports:
    count: 6-bit output representing the current count value.
