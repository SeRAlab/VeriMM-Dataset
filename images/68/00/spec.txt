Design a 4-to-1 multiplexer that selects one of four 1-bit inputs (A0, A1, A2, A3) based on the values of two select lines (S0 and S1). The output (X) will reflect the selected input: when S0 and S1 are both low, output A0; when S0 is low and S1 is high, output A1; when S0 is high and S1 is low, output A2; and when both S0 and S1 are high, output A3.
module top_module(
    input A0,
    input A1,
    input A2,
    input A3,
    input S0,
    input S1,
    output X
);
