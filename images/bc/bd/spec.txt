Design a circuit that performs unsigned multiplication of two 4-bit numbers, 'multiplier' and 'multiplicand', producing an 8-bit wide 'product' output. The multiplication is realized using a shift-and-add algorithm, where each bit of the 'multiplier' is checked, and for every active bit, the corresponding bits in 'multiplicand' are added to the appropriate positions in the 'product'. This module effectively implements a simple but functional multiplier suitable for small-scale digital systems.
module top_module(
    input [3:0] multiplier,
    input [3:0] multiplicand,
    output reg [7:0] product
);
