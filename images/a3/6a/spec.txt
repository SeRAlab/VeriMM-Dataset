Design a 17-bit signed register that can be initialized and updated based on control signals. On a positive clock edge, the register outputs a value controlled by the following conditions: if the reset signal (rst) is high, the output is set to zero; if the enable signal (en) is active, the output takes the value from the serial input (serIn); and if the initialization signal (init) is active, the output is loaded with a pre-defined initialization value (init_value).
module top_module(input signed [16:0] serIn , input [16:0] init_value , input en, input clk, input rst , input init , output reg signed [16:0] Q);
