Design a 3-bit up/down counter that increments or decrements its count based on the up_down control signal. When the clock signal (clk) receives a rising edge, the counter updates its value; if the reset signal (rst) is activated, the counter resets to zero. If up_down is high, the counter increments the previous value; if up_down is low, it decrements. The counter maintains its current count in a 3-bit register called count, making it suitable for counting applications where bi-directional counting is required.
module top_module(
    input clk,
    input rst,
    input up_down,
    output reg [2:0] count
);
