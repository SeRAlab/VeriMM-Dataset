Design an SR latch using Verilog. The latch should have two inputs (S for Set, R for Reset) and two outputs (Q and Qn). The output Q should be set to high when S is high and R is low, and it should reset to low when R is high and S is low. If both S and R are low, the latch should maintain its previous state. If both S and R are high, it should be considered an invalid state.
