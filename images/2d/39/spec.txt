Create a Verilog module that implements a simple singly linked list traversal. The module should take an input signal representing the head of the list and traverse through the list, outputting the current node value at each clock cycle until reaching the end of the list (indicated by a null pointer). The linked list node structure consists of a value (8 bits) and a pointer to the next node (also 8 bits, 0 indicates the end of the list).
