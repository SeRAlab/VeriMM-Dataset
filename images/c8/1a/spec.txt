Please act as a professional Verilog designer. Create a module that implements a 4-bit counter with a synchronous reset. The counter should increment on every rising edge of the clock (clk) input and reset to 0 when the reset (areset) input is asserted. The module should have an output (count) that is a 4-bit vector representing the current count value. Additionally, the module should have an input (enable) that allows the counter to be enabled or disabled. When the enable input is low, the counter should not increment and the count output should remain constant. Implement this counter using behavioral Verilog code.
