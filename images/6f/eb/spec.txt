Design a dual-port RAM module that can read and write data to two separate 8-bit RAM banks, each with 16 locations, controlled by a common clock and reset signal. When the module is reset, the output read_data initializes to a specific state. The module allows simultaneous read and write operations; when write_en is active, it writes the provided write_data to both RAM banks at the specified write_addr. If read_en is activated, it reads data from either RAM bank based on the most significant bit of the read_addr, outputting the corresponding data to read_data.
module top_module(
    input clk,
    input rst_n,
    input write_en,
    input [3:0] write_addr,
    input [7:0] write_data,
    input read_en,
    input [3:0] read_addr,
    output reg [7:0] read_data
);
