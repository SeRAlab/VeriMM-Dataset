
You have been tasked with designing a verilog module that performs a specific operation on a 4-bit input signal. The module should take in a 4-bit input signal `in`, a clock signal `clk`, and output a 2-bit signal `out`. The module should perform the following operation on the input signal:
- On every rising edge of the clock signal, the module should output the last two bits of the input signal in reverse order.

Write a verilog module that performs this operation and test it using a testbench.
