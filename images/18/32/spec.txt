Design a 16-bit Linear Feedback Shift Register (LFSR) that generates pseudo-random sequences. The LFSR should have a feedback polynomial of x^16 + x^14 + x^13 + x^11 + 1. The LFSR should take a clock signal and a reset signal as inputs, where the reset signal initializes the LFSR value to a non-zero state. The output should be the current LFSR value.
