Design a 4-bit Serial-in Serial-out (SISO) shift register. The shift register should take a serial input and shift it through the 4 bits. It should have a clock input and a reset input. On each clock cycle, if the reset is not asserted, the new bit should be shifted in and the oldest bit should be outputted. After 4 clock cycles, the output should reflect the last 4 bits that were shifted in.
