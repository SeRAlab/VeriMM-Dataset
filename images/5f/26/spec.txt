Design a 4-to-1 multiplexer that selects one of four 32-bit input signals (in0, in1, in2, in3) based on a 2-bit select input. The output (out) reflects the chosen input based on the select value, with each combination yielding a corresponding input: 00 selects in0, 01 selects in1, 10 selects in2, and 11 selects in3. If the select input is invalid, the output is assigned an undefined state.
module top_module(out, in0, in1, in2, in3, select);
