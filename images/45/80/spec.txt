Design a 32-bit wide arithmetic logic unit (ALU) that performs various arithmetic and logical operations based on a 4-bit operation code (aluc). The ALU supports operations including addition, subtraction, logical AND, logical OR, logical XOR, left and right shifts, and loading upper immediate values. Each operation is selected through the aluc input, and the corresponding result is output on the 'result' wire. When the aluc value does not match any specified operation, the default behavior is to perform addition.
module top_module(
    input [31:0] a, b,
    input [3:0] aluc,
    output reg [31:0] result
);
