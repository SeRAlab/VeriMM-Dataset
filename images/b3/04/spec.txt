Design a circuit to compute the parity of an n-bit input data bus. This module generates a single parity bit (p) by performing a bitwise XOR on all input bits, indicating whether the count of '1's is even or odd. Additionally, it outputs an error flag (e) that is set high when the parity bit is odd, signaling a potential discrepancy in the transmitted data. The parameter n allows for flexibility in defining the size of the input data.
module top_module(
  input [n-1:0] data,
  output p,
  output e
);
