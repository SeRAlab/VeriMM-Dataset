
You are tasked with designing a module that takes in 3 inputs and outputs their XOR combination. The module should be named `xor3` and should be written in Verilog. The module should have the following interface:

```
module xor3(
  input a,
  input b,
  input c,
  output x
);
```

Your design should be optimized for area and should use the minimum number of gates possible. You are not allowed to use any pre-built XOR gates or other modules. You can only use AND, OR, and NOT gates to implement your design.
