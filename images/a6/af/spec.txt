Design a Fibonacci sequence generator that outputs the current Fibonacci number at each clock cycle. On a reset signal, the output is initialized to 0. The module updates the output to 1 if it is currently 0, and subsequently computes the next Fibonacci number by adding the last two generated numbers in the series on each rising clock edge.
module top_module(
  input clk,
  input reset,
  output reg [31:0] fib_num
);
