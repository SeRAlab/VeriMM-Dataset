Design a Direct Memory Access (DMA) controller that can transfer data from a source memory address to a destination memory address over a specified number of cycles. The DMA controller should have the following inputs: a clock signal, a reset signal, a start signal, a source address, a destination address, a data bus, and a transfer count. It should output a busy signal indicating when the DMA is active, and a completed signal indicating when the transfer is complete. The data transfer should happen one word at a time on each clock cycle until the specified transfer count is reached.
