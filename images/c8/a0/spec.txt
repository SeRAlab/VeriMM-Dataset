

You are tasked with designing a module that implements a 2-to-1 multiplexer using Verilog HDL. The module should have the following interface:

```
module mux_2_to_1 (
    input a,
    input b,
    input sel,
    output out
);
```

The `a` and `b` inputs are binary values and `sel` is a select signal that determines which input is passed to the output. If `sel` is `0`, then `a` is passed to the output, and if `sel` is `1`, then `b` is passed to the output. The output `out` is also a binary value.

Your module should be designed to be synthesizable and should not use any behavioral constructs. Additionally, your module should be designed to be used in a larger system, so it should not have any input/output delays.

Write a Verilog module that implements the 2-to-1 multiplexer described above. Your module should be contained within 200 lines of Verilog code.
