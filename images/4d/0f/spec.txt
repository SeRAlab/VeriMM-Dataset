Design a 8-entry register file capable of reading and writing 8-bit data. The module allows writing data to one of the registers on a clock edge when the write enable signal is asserted, while it continuously provides the current values of two registers specified by their respective read addresses. The first three bits of each address determine which of the eight registers to access, and register 0 is initialized to zero and not writable.
