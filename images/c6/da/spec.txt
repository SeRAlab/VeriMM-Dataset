

You have been given the task of designing a Verilog module for a D flip-flop with an asynchronous reset functionality. The module should have the following inputs and outputs:

Inputs:
- D: a single-bit input representing the data to be stored in the flip-flop
- RESET: a single-bit input representing the asynchronous reset signal. When RESET is high, the Q output should be set to 0.
- CLK: a single-bit input representing the clock signal. The flip-flop should store the value of D on the rising edge of CLK.

Outputs:
- Q: a single-bit output representing the value stored in the flip-flop.

Design a Verilog module that implements the above functionality. Name the module "dff_async_reset".
