Design a Direct Memory Access (DMA) controller in Verilog that initiates a data transfer between a source address and a destination address in memory. The controller should have the following inputs: `clk`, `reset`, `start`, `src_addr`, `dest_addr`, and `data_in`. It should have a single output `data_out`. The controller should move data from `src_addr` to `dest_addr` when `start` is asserted, and it should handle 4-byte data transfers. The DMA should complete the transfer when all bytes have been moved, and then it should set a `done` signal high.
