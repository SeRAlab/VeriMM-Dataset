Implement a 16-bit wide register file with 8 registers for a digital CPU architecture. The module allows for reading from one of the registers specified by the `rra` input and writing to another register specified by the `rwa` input, controlled by the `rwe` write enable signal. On a positive clock edge, if the `ena` (enable) signal is asserted, the address for reading is stored, and if `rwe` is also asserted, the data from `rwd` is written into the selected register. The design facilitates register-based data manipulation essential for CPU operations.
