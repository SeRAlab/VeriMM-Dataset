
You are tasked with designing a module in Verilog that performs a simple logic operation on a set of inputs. The module must be able to take in two 4-bit binary numbers, A and B, and perform a logical AND operation on them. The result should be output as a 4-bit binary number, C. The module should be named "and_logic" and should be contained within 200 lines of Verilog code.

Assume that the input values for A and B will always be valid 4-bit binary numbers. The output value for C should be calculated using standard logical AND operations. The module should also include a reset input, which when set to 1, should reset the output value C to 0.

Ensure that your module is self-contained and can be tested without the need for additional testbench code.
