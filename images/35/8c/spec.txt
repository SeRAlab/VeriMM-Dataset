Design an SR flip-flop using Verilog. The flip-flop should have inputs S (Set), R (Reset), and a clock signal (CLK). The output should be Q, which represents the state of the flip-flop. The flip-flop should follow the characteristic behavior: when S is high and R is low, Q should become 1; when S is low and R is high, Q should become 0; when both S and R are low, Q should hold its state; and when both S and R are high, the output is considered undefined. Implement the SR flip-flop as a D flip-flop with the appropriate logic. Ensure the state changes only on the rising edge of the clock.
