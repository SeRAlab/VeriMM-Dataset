Implement the Verilog module based on the following description.
Build a 16-bit register with asynchronous positive edge triggered reset, synchronous active high enable signal, and a count enable signal.
(1) reset: Resets register to zero.
(2) enable: Enables the register to load data.
(3) count_enable: Enables the register to count up.
(4) data: The data to be loaded into the register.
(5) q: The contents of the register.

module top_module(
    input clk,
    input reset,
    input enable,
    input count_enable,
    input [15:0] data,
    output reg [15:0] q);
