Design a 5-to-1 multiplexer that selects one of five input signals (in0 to in4) based on a 3-bit select line (sel). The output (out) will reflect the value of the selected input, with the select codes corresponding to each input: sel=000 for in0, sel=001 for in1, sel=010 for in2, sel=011 for in3, sel=100 for in4. If none of these select codes are used (sel > 100), the output will default to LOW.
module top_module(
    out,
    in0,
    in1,
    in2,
    in3,
    in4,
    sel
);
