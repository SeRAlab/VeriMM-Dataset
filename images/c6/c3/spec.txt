

You are tasked with designing a verilog module that implements a 4-bit counter. The counter should have an asynchronous reset input and a clock input. The counter should count up on each positive edge of the clock signal. The counter should also have an enable input that allows the counter to count only when the enable signal is high. If the enable signal is low, the counter should hold its current value.

Design a verilog module that implements the above specifications. The module should have the following inputs and outputs:

Inputs:
- `CLK`: Clock input
- `RST`: Asynchronous reset input
- `EN`: Enable input

Outputs:
- `COUNT`: 4-bit count output

Assume that the initial value of the counter is 0.
