Design a 4-to-1 multiplexer that selects one of four input signals (a0, a1, a2, a3) based on the 2-bit select inputs (s0, s1). The output (x) will reflect the value of the selected input. When both select signals are low, a0 is chosen; when s0 is low and s1 is high, a1 is selected; when s0 is high and s1 is low, a2 is output; and with both select signals high, a3 is routed to the output.
module top_module(
    output x,
    input a0,
    input a1,
    input a2,
    input a3,
    input s0,
    input s1
);
