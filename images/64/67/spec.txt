Design a 3-bit circular shift register that captures the input data on each rising edge of the clock signal. The most recent input bit `d` is shifted into the least significant position, while the existing data within the register is shifted to the left. The output `q` provides the current value of the least significant bit of the register, effectively making it a FIFO structure that retains three bits of input history.
