

You have been hired to design a module that implements a D flip-flop with asynchronous reset and inverted output. The module should have the following ports:

- `clk`: input clock signal
- `rst`: asynchronous reset signal (active low)
- `d`: input data signal
- `q`: output data signal (inverted)

Implement the module and ensure that it adheres to the following specifications:

- The output `q` should be the inverted version of the input `d`
- The output `q` should be synchronous to the input `clk`
- When the reset signal `rst` is asserted, the output `q` should be set to 1
