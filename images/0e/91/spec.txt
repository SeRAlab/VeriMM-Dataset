Design a 7-stage pipeline processor that can handle a simple instruction set including Load, Store, Add, and Subtract. The processor should have a 5-bit instruction input, with the following encoding:
- Load: 00001
- Store: 00010
- Add: 00011
- Subtract: 00100
The processor should be able to process instructions in a pipelined manner, with each stage taking one clock cycle. The output should indicate the instruction being executed at each stage of the pipeline.
