
Design a 16-bit SRAM cell with read and write functionality. The SRAM cell should have the following inputs: 
- `clk`: clock signal
- `we`: write enable signal (active high)
- `addr`: 4-bit address for selecting one of the 16 SRAM cells
- `din`: 16-bit data input for writing
- `dout`: 16-bit data output for reading

When `we` is high, the value on `din` should be written to the SRAM cell addressed by `addr` on the rising edge of the clock. When `we` is low, the value at the addressed SRAM cell should be output on `dout` on the rising edge of the clock.
