Design a module that generates a one-hot encoded output based on selected chip and lane inputs. The module takes an 8-bit chip selection input and a 3-bit lane selection input. For each chip, upon the rising edge of the clock, it assigns the state of the selected chip to a corresponding 8-bit section of the output, effectively creating a one-hot representation of the chip selection based on the lane selection. Each section of the output accommodates a specific lane, ensuring that only one bit is set for each combination of chip and lane.

    clk,
