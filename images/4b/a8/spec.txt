Implement a dual-port memory module with 12-bit addressing capability, which connects to two interfaces: a core interface and a bus interface. The module allows writing and reading 4 bits of data per byte, with each byte selectable by individual control signals for both core and bus operations. On the rising edge of the clock, if the core interface is enabled and a corresponding byte write signal is asserted, the specified 4 bits are written to the memory location indicated by the `io_core_addr`. Simultaneously, it outputs the most recently written data to the core interface based on the address accessed. The design effectively functions as a shared memory resource that can facilitate data communication between a core and a bus by using dedicated read and write controls for efficient data handling.
