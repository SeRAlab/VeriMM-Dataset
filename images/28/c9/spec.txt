Design a 1-bit DRAM cell that has the following characteristics:  
- It has a data input (D), a control signal (WE for Write Enable), and a data output (Q).  
- When WE is high, the data input D should be written to the cell, and when WE is low, the cell should hold the stored value, which is output on Q.  
- The cell should also respond to a reset signal (RST), which, when high, sets Q to 0 regardless of WE.
