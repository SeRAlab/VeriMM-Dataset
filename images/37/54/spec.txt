Design a 16-bit digital-to-analog converter (DAC) that takes a 16-bit input and outputs a voltage level corresponding to the digital value. The output voltage should be scaled according to a reference voltage of 3.3V. The output should be represented as a 12-bit value suitable for a PWM signal generator, where the 12-bit output represents the duty cycle of the PWM signal. The output should change immediately based on the input value.
