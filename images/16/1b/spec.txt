Design a LIFO stack module in Verilog. The stack should support the following operations: push, pop, and peek. The stack should have a parameterized depth and should be able to hold data of a specified width. Implement a 4-entry stack with 8-bit wide data. The push operation should add data to the top of the stack, while the pop operation should remove data from the top and return it. The peek operation should return the data at the top without removing it. The module should also include an overflow check for the push operation and an underflow check for the pop operation.
