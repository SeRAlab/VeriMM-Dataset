

You are tasked with designing a Verilog module that takes in a 32-bit input signal `a` and outputs a 32-bit signal `y`. The output signal should be the result of shifting the input signal left by 3 bits. 

Write a Verilog module that implements this functionality. 

Your module should be named `sl3` and should have the following ports:
- `a` : a 32-bit input signal
- `y` : a 32-bit output signal

You may assume that the input signal `a` is always valid and does not contain any undefined values.
