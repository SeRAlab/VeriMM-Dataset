
You have been tasked with designing a verilog module that implements a 4-bit adder. The module should have two 4-bit inputs (A and B) and one 4-bit output (S). The module should also have a control input (Cin) that determines whether the adder should perform an addition or subtraction. If Cin is 0, the adder should perform an addition; if Cin is 1, the adder should perform a subtraction. The output of the module should be the result of the addition or subtraction.

Design a verilog module that meets the above requirements. You may use any verilog constructs, but you must use at least one always block.
