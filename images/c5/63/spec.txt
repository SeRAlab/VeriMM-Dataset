

You are tasked with creating a verilog module that takes in two input signals, `a` and `b`, and an enable signal `en`. The module should output the result of `a` XOR `b` if `en` is high, and the value of `a` if `en` is low`. 

Create a verilog module with the following specifications:

- Module name: `xor_en`
- Inputs:
  - `a` (1-bit)
  - `b` (1-bit)
  - `en` (1-bit)
- Outputs:
  - `out` (1-bit)

Your solution should implement the functionality described above and should be synthesizable.
