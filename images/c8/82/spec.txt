

You are tasked with designing a verilog module that implements a 4-bit binary counter with a synchronous reset. The counter should count up on the rising edge of a clock signal and reset to zero when a reset signal is asserted. The counter should also have an enable signal that allows it to be turned on and off. 

Your module should have the following inputs and outputs:
- `clk`: the clock signal
- `reset`: the synchronous reset signal
- `enable`: the enable signal
- `count`: a 4-bit output representing the current count value

Your module should have the following requirements:
- The counter should count up on the rising edge of the clock signal.
- The counter should reset to zero when the reset signal is asserted.
- The counter should only count when the enable signal is asserted.
