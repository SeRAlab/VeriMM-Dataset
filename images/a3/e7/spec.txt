Design a module that takes a 3-bit input vector and outputs it directly while also providing individual outputs for each bit of the input. The output `outv` replicates the input `vec`, while `o2`, `o1`, and `o0` serve as separate outputs corresponding to the most significant, middle, and least significant bits of the input vector, respectively.
module top_module( 
    input wire [2:0] vec,
    output wire [2:0] outv,
    output wire o2,
    output wire o1,
    output wire o0  );
