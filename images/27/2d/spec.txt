Design a 5-bit Parallel-in Parallel-out (PIPO) shift register. The shift register should have a parallel load input (`load`), a clock input (`clk`), a reset input (`reset`), and a 5-bit data input (`data`). When the `load` signal is high, the `data` should be loaded into the register on the rising edge of the clock. If `reset` is high, the register should be cleared to zero. If `load` is low, the register should shift left by one bit on each rising edge of the clock, with the most significant bit being filled with 0.
