Design a Verilog module that implements a 4-bit binary up-counter with enable and an asynchronous preset. The counter should increment on the rising edge of the clock if the "enable" signal is high. The counter should preset to a given value (input preset_val) when the asynchronous preset (preset) is high. The counter value should be output to the "count" signal.

module top_module
(
    input clk,
    input preset,
    input enable,
    input [3:0] preset_val,
    output reg [3:0] count
);
