Design a clocked storage circuit that captures and outputs three 32-bit wide input signals (i_x, i_y, i_z) when an enable signal is active. Upon a reset signal, the outputs (o_x, o_y, o_z) are set to zero. This module effectively acts as a synchronous register set, holding the input values based on the clock signal while providing initial zeroing functionality upon reset.
module top_module(
	//Inputs
	clock,
	reset,
	enable,
	
	i_x, 
	i_y, 
	i_z, 

	//Outputs
	o_x,
	o_y,
	o_z
);
