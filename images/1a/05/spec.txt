
Create a Verilog module that implements a simple 3x3 Gaussian blur filter on a 2D grayscale image pixel. The input will be a 3x3 matrix of pixel values, and the output will be a single pixel value representing the blurred result. The Gaussian blur can be approximated using the following weights:
```
0.075 0.125 0.075
0.125 0.200 0.125
0.075 0.125 0.075
```
