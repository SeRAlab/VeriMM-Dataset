
You are tasked with designing a Verilog module that implements a 8-bit subtractor. The module should have a single clock input and two 8-bit inputs, `A` and `B`. The module should output an 8-bit result, `Y`, which is equal to `A - B`.

Your module should be designed using the following guidelines:
- The module should be named `subtractor`.
- The module should have the following inputs:
  - `clk`: a single-bit clock input
  - `A`: an 8-bit input
  - `B`: an 8-bit input
- The module should have the following output:
  - `Y`: an 8-bit output
- The module should subtract `B` from `A` on the rising edge of the clock.
- The module should only update the value of `Y` on the rising edge of the clock.
- The module should behave correctly when `A` is less than `B`. In this case, `Y` should be equal to `0`.
- The module should be designed using behavioral Verilog, and should be no more than 200 lines of code.
