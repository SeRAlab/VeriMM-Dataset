Design a debouncing circuit for a push-button input. This module processes a noisy input signal from a button using a clock signal to ensure that changes in the button state are only registered after a defined delay, controlled by a parameterized limit. The circuit counts clock cycles when the button state differs from the debounced output, and once the count reaches a specified threshold, it updates the output to reflect the stable state of the button. This functionality prevents false triggers caused by mechanical bounce when the button is pressed or released.
