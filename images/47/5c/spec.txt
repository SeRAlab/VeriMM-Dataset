Design a simple register file with a 3-element array to store 4-bit data. When a new 4-bit data value is provided via `in_data`, it is written into the array at the index specified by `in_addr`. The output, `out_data`, is determined by the value stored in the array at the index indicated by `out_addr`. This module allows for the flexible reading and writing of data within a small memory structure based on input address signals.
