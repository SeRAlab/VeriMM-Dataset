Design a 16-bit barrel shifter that conditionally shifts the input value (IN) based on the SHIFT and DIR control signals. When SHIFT is high, if DIR is set to high, the input is shifted left by one position, with a zero filled in on the least significant bit; if DIR is low, the input is shifted right by one position, with a zero filled in on the most significant bit. If SHIFT is low, the output directly mirrors the input.
module top_module(
    input [15:0] IN,
    input SHIFT, DIR,
    output [15:0] OUT
);
