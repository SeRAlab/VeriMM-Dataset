

You are tasked with designing a verilog module for a 4:1 multiplexer. The module should have four 4-bit input ports (A, B, C, and D), and a 2-bit select port (S0, S1) that selects which input port to output to the single 4-bit output port (Y). The select port should be active high, meaning that if S0 is high and S1 is low, the output should be the value of input port B.

Design a verilog module that meets these requirements.
