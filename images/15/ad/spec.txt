Design a Verilog module that implements a simple Rapidly-exploring Random Tree (RRT) algorithm that processes 5 input coordinates (x, y) in a 2D space. The module should have a clock input, reset input, and a valid input signal that indicates when new coordinates are available. The output should indicate whether the new coordinates can be added to the tree based on certain predefined constraints (e.g., the distance to the last point should not exceed a threshold). The output should be a single bit indicating success (1) or failure (0).
