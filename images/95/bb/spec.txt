Implement a 4-bit Johnson counter module that counts from 0 to 15 in a specific pattern and then repeats. The count should increment on every rising edge of the clock signal.

Module name:
    johnson_counter

Input ports:
    clk: Clock signal used for synchronous operation.
    rst_n: Active-low reset signal. Defined as 0 for reset and 1 for reset signal inactive.

Output ports:
    count: 4-bit output representing the current Johnson count value.

Implementation:
The module includes a 4-bit register, count, which is updated in the always block, triggered on the positive edge of the clock signal (posedge clk) or the negative edge of the reset signal (negedge rst_n).
On reset, indicated by ~rst_n, the count register is cleared to 0.
On every rising edge of the clock, the most significant bit of count is inverted and shifted into the least significant bit, while the other bits are shifted right.
