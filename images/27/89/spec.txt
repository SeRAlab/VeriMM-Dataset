
Design a simple state machine with two states (S0 and S1). The state machine should toggle between these two states on the rising edge of a clock input. The state should be retained when the reset input is low. Implement the state machine with the following behavior:
- In state S0, if the input `data` is high, transition to state S1.
- In state S1, if the input `data` is low, transition to state S0.
