Design a simple Phase-Locked Loop (PLL) system in Verilog that synchronizes an output clock based on an input clock signal. The PLL should have the following features: it will take an input clock signal and an enable signal to turn the PLL on or off. When enabled, the PLL should generate an output clock signal that is a multiple of the input clock signal. Implement a basic feedback mechanism to adjust the phase of the output clock based on the input clock.
