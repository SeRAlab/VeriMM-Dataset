Design a 4-bit ripple carry adder that computes the sum of two 4-bit input values, A and B, along with a carry-in signal, Cin. The module outputs a 4-bit sum, S, and a carry-out signal, Cout. The carry-out is asserted when the result exceeds the maximum value representable within 4 bits (i.e., when S is greater than 7).
module top_module(
  input [3:0] A,
  input [3:0] B,
  input Cin,
  output reg [3:0] S,    // Change output S to reg
  output reg Cout        // Change Cout to reg as well
);
