Design a circuit that drives a 4-bit LED output based on the states of three input signals (light1, light2, light3). When light3 is active, the LEDs display 0111; if light2 is active, the output is 0011; if only light1 is active, the output will be 0001; and if none of the lights are active, the LEDs will remain off at 0000. This design allows for a basic priority-based output system for visual indication via LEDs.
