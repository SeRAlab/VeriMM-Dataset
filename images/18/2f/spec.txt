Implement a simplified version of the Data Encryption Standard (DES) algorithm. The design should include an 8-bit input data block and a 8-bit key. The initial permutation (IP) should be performed on the data block, followed by a single round of DES which includes the expansion, substitution, and permutation steps. Finally, the output after the final permutation (FP) should be provided. The testbench should validate the output against expected values.
