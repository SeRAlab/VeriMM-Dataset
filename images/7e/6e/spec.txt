Design a synchronous RAM module with configurable word and address widths. It has an input clock signal for synchronization, a write enable signal to control data writing, and separate read and write addresses for accessing memory locations. On the rising edge of the clock, it outputs the data from the specified read address while allowing data to be written to the specified write address only when the write enable signal is active. This module facilitates efficient data storage and retrieval in digital systems.
