

You are required to design a verilog module that implements a 1-to-2 multiplexer with an asynchronous active-high reset. The module should have the following ports:

- `clk`: input clock signal
- `rst`: asynchronous active-high reset signal
- `din0`: input data signal 0
- `din1`: input data signal 1
- `sel`: selection signal
- `dout`: output data signal

When `rst` is high, `dout` should be set to 0. When `sel` is high, `dout` should be equal to `din1`. When `sel` is low, `dout` should be equal to `din0`.

You are required to use behavioral verilog to implement this module.
