

You are tasked with implementing a multiplexer module in Verilog. The module should have two 1-bit data inputs, `D0` and `D1`, one control input `ctrl`, and one 1-bit output `S`. The output `S` should be equal to `D0` if `ctrl` is 0, and equal to `D1` if `ctrl` is 1.

You should implement this module within 200 lines of Verilog code. The module should be named `Multiplexer` and should be self-contained, meaning that it should not rely on any external modules or libraries.

Write a Verilog module that satisfies the above requirements. Your solution should include the following:

- The module declaration, including the input and output ports.
- The module implementation, including any necessary wires and logic gates.

Your solution should be correct and efficient, and should not include any unnecessary code.
