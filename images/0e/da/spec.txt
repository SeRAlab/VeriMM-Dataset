Design a 1-bit DRAM cell in Verilog. The DRAM cell should have a data input (D), a data output (Q), a word line (WL), and a bit line (BL). The cell should be able to store a bit and retain its value until it is refreshed. When the word line is active (high), the data can be written to the cell or read from the cell. Implement the necessary logic for writing and reading data.
