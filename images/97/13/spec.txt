Upon each clock cycle, the module detects the edges by outputting a signal where a bit is set to HIGH only if it transitioned from LOW to HIGH since the last clock cycle. The detected edges are stored in a register to enable this comparison with the current input.

    input clk,
    input [7:0] in,
