Design a 16-bit DRAM cell that can store a single 16-bit data word. The cell should have inputs for address, data to be written, a read enable signal, and a write enable signal. When the write enable signal is high, the data input should be written to the specified address. When the read enable signal is high, the data from the specified address should be outputted. Both the read and write operations should be synchronous to a clock signal.
