
Design a GPIO Controller with the following specifications:
1. The controller has a 4-bit input for the GPIO pins (gpio_in).
2. There is a 1-bit input signal to latch the current state of the GPIO pins (latch).
3. When latch is high, the current state of gpio_in should be stored in a 4-bit latched output (gpio_out).
4. If latch is low, the gpio_out should retain its previous value.
5. The initial state of gpio_out should be 0000.
