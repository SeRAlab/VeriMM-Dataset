Design a circuit that performs either addition or subtraction on two 8-bit inputs, A and B, based on the value of a mode control signal. When mode is 0, the circuit outputs the sum of A and B; when mode is 1, it subtracts B from A by adding the two's complement of B to A. The output is an 8-bit result reflecting the selected operation.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input mode,
    output [7:0] result
);
