

You are hired as a verilog designer to create a module that implements a 2-to-1 multiplexer. The module has three inputs and one output. The first input is a 1-bit select signal, and the other two inputs are 1-bit data signals. If the select signal is 0, the output should be the first data signal. If the select signal is 1, the output should be the second data signal. Use the following module header:

```
module mux_2_to_1 (
    select,
    data_0,
    data_1,
    out
);

    input select;
    input data_0;
    input data_1;
    output out;

    // your code here

endmodule
```

Write the verilog code for the module that implements the 2-to-1 multiplexer.
