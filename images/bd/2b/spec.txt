Design a quad 2-to-1 multiplexer with active low enable functionality. This module takes four pairs of inputs (a and b) and a select line, directing the outputs based on the selection and enable conditions. When the enable signal is low, all outputs are set to LOW. When the enable signal is high, the outputs are determined by the select line; if it is low, the outputs will reflect the values of the 'a' inputs, and if it is high, they will reflect the values of the 'b' inputs.
module top_module(
   output p4_o1,
   output p7_o2,
   output p9_o3,
   output p12_o4,


   input  p2_a1,
   input  p3_b1,
   input  p5_a2,
   input  p6_b2,
   input  p11_a3,
   input  p10_b3,
   input  p14_a4,
   input  p13_b4,
   input  p1_sel,
   input  p15_enable_n
   );
