Design a 1-bit DRAM cell. The DRAM cell has an input data line (D), a gate line (G), and an output data line (Q). The DRAM cell should be able to store a single bit of data. When the gate line (G) is activated (high), the input data (D) is written to the cell, and when the gate line is low, the stored bit is output on the Q line. The DRAM cell should hold its state until a new value is written.
