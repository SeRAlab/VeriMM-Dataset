

You are tasked to design a verilog module that takes in five inputs and produces one output. The module should be named `my_module` and should have the following port declarations:

- `input [3:0] A`
- `input [3:0] B`
- `input [3:0] C`
- `input [3:0] D`
- `input [3:0] E`
- `output reg X`

Inside the module, you should declare the following signals:

- `reg [3:0] sum`
- `reg [3:0] max`

The behavior of the module should be as follows:

- `sum` should be the sum of all the inputs `A`, `B`, `C`, `D`, and `E`.
- `max` should be the maximum value of all the inputs `A`, `B`, `C`, `D`, and `E`.
- `X` should be 1 if the value of `sum` is greater than or equal to `max`, and 0 otherwise.

Your task is to write the verilog code for the `my_module` module that implements this behavior.
