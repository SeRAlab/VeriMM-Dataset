
Design a simple Bluetooth module state machine in Verilog. The module should have three states: IDLE, CONNECT, and DISCONNECT. The state transitions occur based on the input signals: `start` (to transition from IDLE to CONNECT) and `stop` (to transition from CONNECT to DISCONNECT). The module should output the current state as a 2-bit value where `00` represents IDLE, `01` represents CONNECT, and `10` represents DISCONNECT.
