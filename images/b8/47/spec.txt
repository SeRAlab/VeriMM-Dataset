Design a 4-bit adder/subtractor circuit. The circuit takes two 4-bit inputs, A and B, and a control input, C, which indicates the operation mode: when C is 0, the circuit performs addition (A + B), and when C is 1, it performs subtraction (A - B). The output is a 4-bit sum or difference, S, and a carry-out signal, Cout, which reflects whether an overflow occurred during addition or underflow during subtraction.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input C,
    output [3:0] S,
    output Cout
);
