Design a branch control circuit that determines the next program counter (PC) source based on various branch conditions. The module takes a 2-bit branch operation code (BranchOp), a 16-bit register value (Rs), and control signals for branching (Branch), immediate PC offset (PCImm), and jump instruction (Jump). It evaluates whether to take a branch based on the value of Rs and the specified BranchOp: it checks if Rs is zero, negative, or their negations depending on the operation type. The output, PCSrc, signifies whether to use the immediate value, jump to a specified address, or proceed with the determined branch condition.
