

You are tasked with designing a verilog module that takes in four inputs, A1, A2, A3, and B1, and outputs X. The module should be named "my_module".

The inputs A1, A2, A3, and B1 are all single-bit signals. The output X is also a single-bit signal.

The module should implement the following logic:

- If all of the inputs A1, A2, A3, and B1 are 0, then X should be 0.
- If any of the inputs A1, A2, or A3 are 1, and B1 is 0, then X should be 1.
- If all of the inputs A1, A2, and A3 are 0, and B1 is 1, then X should be 1.
- In all other cases, X should be 0.

You should implement this logic using only one module, and the module should be no more than 200 lines of verilog code.
