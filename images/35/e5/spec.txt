
Design a temperature sensor controller that monitors the temperature in degrees Celsius. The controller takes a 4-bit binary input representing the temperature (from 0 to 15 degrees Celsius) and outputs a 1-bit signal indicating if the temperature exceeds a threshold of 10 degrees Celsius. The controller will have a clock signal and a reset signal. On every clock cycle, if reset is low, the controller should read the temperature input and update the output accordingly.
