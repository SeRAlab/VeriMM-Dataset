
Design an 8-bit divider that takes a 8-bit dividend and a 8-bit divisor as inputs and produces an 8-bit quotient and an 8-bit remainder as outputs. The division operation should be performed using a sequential state machine. The output should be valid after a specified number of cycles, and the operation should respond to a start signal which initiates the division process. The state machine should handle cases where division by zero occurs by setting the quotient and remainder to zero.
