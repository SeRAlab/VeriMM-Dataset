Design an 8-bit Arithmetic Logic Unit (ALU) that can perform the following operations based on a 3-bit control signal:  
- 000: AND  
- 001: OR  
- 010: ADD  
- 011: SUBTRACT  
- 100: XOR  
The ALU should take two 8-bit inputs and output an 8-bit result. Additionally, the ALU should set a zero flag if the result is zero.
