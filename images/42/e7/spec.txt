Design a 32-bit comparator module that evaluates two input operands (op1 and op2) based on a three-bit operation code. The module outputs a single binary result (res) indicating the condition defined by the operation code: it checks for equality when operation is 000, greater than when 010, and less than for operation codes 101 and 110. If an invalid operation code is presented, the result is set to an unknown state.
module top_module(
        input   wire [31:0]   op1,
        input   wire [31:0]   op2,
        input   wire [2:0]    operation,
        output  wire          res
    );
