Design a circuit that converts a 4-bit binary input into a 4-bit Gray code output on the rising edge of a clock signal. The most significant bit of the Gray code output is directly taken from the most significant bit of the binary input, while the remaining bits are generated by performing an exclusive OR (XOR) operation between consecutive bits of the binary input. This ensures that only one bit changes at a time between successive values, a key characteristic of Gray code.

    input [3:0] binary_in,
    input clk,
    output reg [3:0] gray_out
