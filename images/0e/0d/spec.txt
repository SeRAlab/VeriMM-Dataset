Design a 24-bit ADC controller that takes a 24-bit input value representing the analog signal and outputs a 1-bit signal indicating whether the analog value exceeds a threshold. The controller should have a clock and reset input. When reset is low, the output should be low. On the rising edge of the clock, if the input value exceeds the threshold (e.g., 2^23), the output should be set high, otherwise, it should be low.
