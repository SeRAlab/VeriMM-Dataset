
Design a synchronous SR-latch using D flip-flops. The SR-latch should have two inputs: S (Set) and R (Reset), and one output Q. The output Q should be updated on the rising edge of a clock signal. The D flip-flops should be used to implement the desired behavior of the SR-latch such that when S is high, Q should be set to high, and when R is high, Q should be reset to low. If both S and R are low, Q should retain its previous state.
