

You are tasked with designing a Verilog module that implements a D-type flip-flop with reset functionality. The module should have the following inputs and outputs:

Inputs:
- `D`: the data input
- `RESET_B`: the reset signal (active low)
- `CLK`: the clock signal

Outputs:
- `Q`: the output signal

The module should operate as follows:
- When `RESET_B` is low, the output `Q` should be set to 0, regardless of the value of `D`.
- When `RESET_B` is high and the rising edge of `CLK` occurs, the output `Q` should be updated with the value of `D`.

You can assume that `CLK` has a frequency of 50 MHz.

Write a Verilog module that implements the above functionality. Your module should be self-contained and should not require any external modules. Your module should be no longer than 200 lines of Verilog code.
