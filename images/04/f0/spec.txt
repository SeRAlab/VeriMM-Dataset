Implement a simple Support Vector Machine (SVM) decision boundary where the input consists of 2D feature vectors (x1, x2) and the output is a binary classification (0 or 1). The SVM will use a linear threshold to classify the input based on the equation: if (w1*x1 + w2*x2 + b) > 0 then output = 1 else output = 0. Use w1 = 2, w2 = -1, and b = -1 for this problem.
