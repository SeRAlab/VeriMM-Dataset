Design a D-type flip-flop with asynchronous reset functionality. On the rising edge of the clock (CLK), the flip-flop captures the value of the data input (D) and outputs it as Q, while the complementary output (NQ) is the logical negation of D. If the reset input (RST) is asserted low, the outputs Q and NQ will reset to 0 and 1, respectively, regardless of the CLK state.
module top_module(
    input       D,
    input       CLK,
    input       RST, 
    output  reg Q,
    output  reg NQ
);
