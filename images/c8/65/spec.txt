

You are tasked with designing a module that takes in two input bits `A` and `B`, a select bit `S`, and outputs the result `MO`. The output `MO` is the negation of either `A` or `B`, depending on the value of `S`. If `S` is 1, `MO` should be the negation of `B`, otherwise `MO` should be the negation of `A`. Your task is to implement this module in Verilog.

Design a module `negate` with the following ports:
- `A`: a single bit input
- `B`: a single bit input
- `S`: a single bit input
- `MO`: a single bit output

Your module should implement the following logic:
- If `S` is 1, `MO` should be the negation of `B`
- If `S` is 0, `MO` should be the negation of `A`

You should use the ternary operator to implement the logic.
