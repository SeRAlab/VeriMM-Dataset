Design a 4-bit DRAM cell type that can read and write data. The cell will have a 4-bit data input (D), a 4-bit data output (Q), a write enable signal (WE), and a clock signal (CLK). When WE is high, the data on the input (D) should be written to the cell on the rising edge of the clock. When WE is low, the data stored in the cell should be output to Q on the rising edge of the clock.
