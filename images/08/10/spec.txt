Design a Verilog module for a flash memory cell with the following functionality: The flash memory cell should support a simple read and write operation. It should have inputs for the write enable signal (WE), the data input (DI), and a clock signal (CLK). The output should be the data stored in the memory cell (DO). On the rising edge of the CLK, if WE is asserted, the data input (DI) should be written to the memory cell. If WE is not asserted, the stored data should be available at the output (DO) without change.
