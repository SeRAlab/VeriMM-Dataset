Design a 4-bit barrel shifter that performs left or right shifting based on the value of the input B. When B is non-negative, the module shifts input A to the left by B positions; when B is negative, it shifts A to the right by the absolute value of B. The output will reflect the result of the shifting operation. This allows for data manipulation in data paths where flexible shifting is needed, such as in arithmetic operations or data alignment.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output reg [3:0] result
);
