Write a Verilog module to implement a 6-bit up-counter with synchronous reset and load. The counter should increment on each positive clock edge. The reset signal should set the counter to 6'b000000. The load signal should load a given value into the counter.

module up_counter
(
    input clk,
    input reset,
    input load,
    input [5:0] load_value,
    output reg [5:0] count
);
