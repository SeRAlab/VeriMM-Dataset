
Design an 8-bit DRAM cell that can store a single bit of data (0 or 1) for each of the 8 bits in a register. The cell should have a write enable signal (`we`), an address input (`addr`), and a data input (`data_in`). When `we` is high, the data at `data_in` should be written to the memory location specified by `addr`. When `we` is low, the data stored at the specified address should be output on `data_out`.
