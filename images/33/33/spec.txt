
Design a combinational logic circuit that implements a simple decision tree for classifying a set of inputs into one of four categories based on a series of binary decisions. The inputs to the circuit are three binary values: A, B, and C. The outputs will be two bits representing the category of the input. The decision tree logic is as follows:
- If A = 0:
  - If B = 0: Output 00 (Category 0)
  - If B = 1: Output 01 (Category 1)
- If A = 1:
  - If C = 0: Output 10 (Category 2)
  - If C = 1: Output 11 (Category 3)
