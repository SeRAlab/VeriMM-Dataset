

You are tasked with designing a verilog module that takes in a 4-bit input (A) and a 1-bit control signal (S), and outputs a 4-bit result (Y) based on the following conditions:
- If S = 0, Y should be the 2's complement of A
- If S = 1, Y should be the bitwise complement of A

You are not allowed to use any predefined operators or functions in your design. You must implement the operations using basic verilog constructs.

Design a verilog module that satisfies the above requirements.
