Implement the Verilog module based on the following description.
Design a Verilog module that implements an 8-bit Johnson counter with enable and synchronous reset. The counter should shift left and insert the complement of the MSB at the LSB on the rising edge of the clock if the "enable" signal is high. The counter should reset to 0 when the synchronous reset (sreset) is high. The counter value should be output to the "count" signal.

module top_module
(
    input clk,
    input sreset,
    input enable,
    output reg [7:0] count
);
