Design a register-controlled output circuit that updates its output based on the input signal when a selection signal is asserted. When sel is high, data_out takes the value of data_in; otherwise, it holds its previous state. The output is reset to LOW upon a reset signal (rst). This functionality effectively implements a synchronous data latch with a reset feature.
module top_module(
		input   	    sel,
		input 		data_in,
		output  reg	data_out,		
		input 		clk,
		input 		rst

	);
