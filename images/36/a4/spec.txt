Design a SR flip-flop using Verilog. The flip-flop should have two inputs, S (set) and R (reset), and two outputs, Q and Qn (not Q). The flip-flop should respond to changes in S and R inputs on the rising edge of a clock signal. The behavior of the SR flip-flop should be defined as follows: if S = 1 and R = 0, then Q = 1; if S = 0 and R = 1, then Q = 0; if S = 0 and R = 0, then Q retains its value; if S = 1 and R = 1, the state is indeterminate (you can choose to hold the previous state or set Q to 0).
