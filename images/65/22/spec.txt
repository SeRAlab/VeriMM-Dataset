Design a 16x8 RAM module that operates with an 8-bit data bus. The module features read and write enable signals for data manipulation, utilizing a 4-bit address input to select one of 16 memory locations. On a positive clock edge, if read enable (rd_en) is active, the data at the specified address is outputted; if write enable (wr_en) is active, data from the input bus is stored in the selected memory location. Additionally, data is outputted on the bus when the output enable (out_en) signal is activated, and high-impedance is driven when not in use.

    out_en,
