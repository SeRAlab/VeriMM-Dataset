Design a finite state machine (FSM) that controls a traffic light system. The module cycles through three states: GREEN, YELLOW, and RED, represented by the corresponding LED outputs. On a clock edge, if a reset signal is not active, the FSM transitions from GREEN, where only the green LED is lit, to YELLOW with the yellow LED on, and finally to RED with the red LED illuminated. This sequential operation ensures proper traffic light signaling for a road intersection.
module top_module(
  input clock,
  input reset,
  output reg green_led,
  output reg yellow_led,
  output reg red_led
);
