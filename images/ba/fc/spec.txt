Design a finite state machine (FSM) that operates as an arithmetic sequence generator based on a 4-bit input. The module begins in an idle state and transitions to an operational state when the start signal is activated. In this operational state, it counts from zero up to the value specified by the input `din`, simultaneously generating an output that is incremented by 5 at each clock cycle. Once the count reaches the input value, the FSM transitions to a done state, asserting a done signal and providing the accumulated output value. After completing the operation, the FSM returns to the idle state, ready for a new operation.
