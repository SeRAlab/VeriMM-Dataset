Design a 2-bit binary counter that increments its value on each positive clock edge when the enable input (ce) is active. The counter output (q) serves as a control signal for a 4-to-1 decoder, which generates specific output patterns (an) based on the current value of the counter. When q is 0 to 3, the decoder outputs a unique 4-bit select line to control four different outputs, ensuring one output is LOW while the others remain HIGH.
module top_module(input clk, output reg [1:0] q = 0, 
               input ce,  output wire [3:0] an);
