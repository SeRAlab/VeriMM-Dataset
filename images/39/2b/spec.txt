Design a Verilog module that acts as a simple WiFi connection state machine. The state machine has three states: IDLE, CONNECTING, and CONNECTED. The module receives a clock signal, a reset signal, and a go signal. When the go signal is asserted, it transitions from IDLE to CONNECTING, and once the connection is established, it transitions to CONNECTED. The state machine should return to IDLE when the reset signal is asserted. Define the states using parameters and output the current state as a 2-bit binary value.
