Design a 16-bit timer that counts up from 0 to a specified maximum value (MAX). The timer should have a clock input (clk), a reset input (rst), and a load input (load) to load a new value into the timer. When the load signal is active, the timer should take the value from a 16-bit input (data_in). When reset is active, the timer should reset to 0. When counting, the timer increments on each clock cycle until it reaches MAX, where it should hold that value. The timer should have a flag output (done) that goes high when the timer has reached MAX.
