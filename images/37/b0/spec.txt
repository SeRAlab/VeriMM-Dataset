
Design a 2-channel DMA (Direct Memory Access) controller in Verilog. The DMA controller should manage two channels, allowing data transfer from a source address to a destination address for each channel. Each channel should be able to initiate a transfer and control the read/write operations with a simple handshaking mechanism. The controller should have the following inputs and outputs:
- Input: `clk` (clock), `rst` (reset), `start_ch1` (start signal for channel 1), `start_ch2` (start signal for channel 2), `src_addr_ch1`, `dest_addr_ch1` (source and destination addresses for channel 1), `src_addr_ch2`, `dest_addr_ch2` (source and destination addresses for channel 2).
- Output: `done_ch1` (transfer done signal for channel 1), `done_ch2` (transfer done signal for channel 2).
