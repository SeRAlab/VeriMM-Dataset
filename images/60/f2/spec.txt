Design a circuit that functions as a 6-to-1 multiplexer with an additional feature. The module selects one of six 4-bit data inputs based on a 3-bit selection signal (`sel`). For selection values 0 to 5, it outputs the corresponding data input. When `sel` is 6 or 7, the module computes the bitwise AND of the least significant bits of all input data and outputs this result. Therefore, it combines standard multiplexing functionality with a logic operation, providing versatile data output based on the selection criteria.
module top_module(
    input [2:0] sel,
    input [3:0] data0,
    input [3:0] data1,
    input [3:0] data2,
    input [3:0] data3,
    input [3:0] data4,
    input [3:0] data5,
    output reg [3:0] out
);
