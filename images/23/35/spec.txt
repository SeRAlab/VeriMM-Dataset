
Design a Verilog module that implements a simple finite state machine (FSM) for a light controller. The FSM should have three states: OFF, ON, and BLINK. The module should transition between these states based on two inputs: a clock signal and a control signal. The control signal will dictate the transitions: 
- If the control signal is 0, the state remains the same.
- If the control signal is 1, the FSM should toggle between ON and OFF states.
- In ON state, if the control signal is 2, the FSM should transition to BLINK state, which will toggle the light output every clock cycle.
The module should have a single output that indicates the state of the light (1 for ON, 0 for OFF, and 2 for BLINK).
