Design a four-bit arithmetic unit capable of performing addition and subtraction. The module accepts two four-bit inputs, A and B, a carry-in signal (Cin), and an operation control signal (Op). When Op is 0, the circuit computes the sum of A, B, and Cin; when Op is 1, it calculates the sum of A and the two's complement of B (effectively performing A - B), along with the carry-in. The output consists of a four-bit sum (Sum) and a carry-out signal (Cout).
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    input Op,
    output [3:0] Sum,
    output Cout
);
