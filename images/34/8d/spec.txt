Design a simple SPI master controller that can send a byte of data to an SPI slave device. The module should include a clock input, a data input line (MOSI), a data output line (MISO), a chip select line (CS), and a clock output line (SCK). The master will send data on the rising edge of SCK and will latch the data on the falling edge of SCK. The module should have a behavior to initiate communication when CS is low.
