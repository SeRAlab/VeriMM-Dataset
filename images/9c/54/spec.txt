Implement the Verilog module based on the following description.
Design a 4-bit binary counter with a loadable initial value and enable. The counter has four inputs: clk (clock), reset (asynchronous reset), load (load signal), and data (4-bit input data). The counter should load the value of data into count when load is high. If enable is high, the counter should increment on each clock cycle. If reset is high, the counter should reset to zero.

Write Verilog code for this loadable counter.
