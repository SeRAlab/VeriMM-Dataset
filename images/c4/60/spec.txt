Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a memory arbiter block. A memory arbiter block is a type of digital circuit that is used to control access to a shared memory resource. The inputs to the circuit are requests from multiple sources for access to the memory, and the output is a grant signal that indicates which request has been granted access to the memory.

Your module should have the following inputs and outputs:

Inputs: 
- a set of n request signals (REQ1, REQ2, ..., REQn)
- a clock signal (CLK)
- a reset signal (RST)

Outputs: 
- a grant signal (GRANT)

The module should also have the following parameters:
- n: the number of request signals

Your module should implement the following functionality:
- The circuit should grant access to the memory to only one request at a time.
- The circuit should prioritize requests based on their order of arrival and ensure that no request is granted access to the memory twice in a row.
- The circuit should implement a round-robin scheduling algorithm to ensure that requests are granted access in a fair and equitable manner.

To implement the memory arbiter block, you should use Verilog code to define the priority and scheduling algorithms based on the inputs and parameters. You should then use this code to connect the inputs to the output to generate the grant signal.
