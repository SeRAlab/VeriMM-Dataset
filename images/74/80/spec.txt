Create a 12-bit binary counter with an enable signal and a terminal count output. The counter increments its value when the enable signal is high and wraps around to zero after reaching its maximum value. The terminal count output goes high when the counter reaches its maximum value.
module binary_counter (
    input clk,
    input enable,
    output [11:0] count,
    output terminal_count );
