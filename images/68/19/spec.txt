Design a versatile logic selector circuit that takes two inputs, A and B, and a 2-bit select signal (sel) to output one of four possible logic operations. Depending on the value of sel, the output Y can be the result of either the XOR, AND, OR, or NAND operation between inputs A and B. Specifically, sel=0 selects the XOR output, sel=1 selects the AND output, sel=2 selects the OR output, and for sel=3, it outputs the NAND result.
module top_module(
    input [1:0] sel,
    input A,
    input B,
    output Y
);
