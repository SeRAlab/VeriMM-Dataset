Design a circuit that counts the number of HIGH (1) inputs among three given signals (a, b, c) and outputs a 2-bit value representing that count. The output will range from 00 to 11, corresponding to 0 to 3 ones detected in the inputs. This is essentially a 3-input one-hot counter implemented using a combinational logic block with a case statement.
module top_module(
  input a,
  input b,
  input c,
  output reg [1:0] count
);
