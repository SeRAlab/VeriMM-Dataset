
Create a packet filtering module that evaluates incoming packets based on source IP address and destination port. The module should output a 'permit' or 'deny' signal for each packet based on predefined rules. The rules are as follows:
1. Permit packets from source IP "192.168.1.1" to any destination port.
2. Deny packets from source IP "10.0.0.1" to destination port 80.
3. Permit packets from any other source IP to any destination port.
The source IP will be a 32-bit input, and the destination port will be a 16-bit input.
