Design a 4-bit SRAM cell that can store a 4-bit value with read and write capabilities. The SRAM has two control inputs: 'write_enable' and 'read_enable'. When 'write_enable' is high, the input data is written to the SRAM cell. When 'read_enable' is high, the stored value is outputted. The SRAM cell should have a reset feature that clears the stored value when 'reset' is high.
