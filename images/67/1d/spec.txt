Design a circuit that calculates the absolute value of a signed n-bit input signal. If the sign bit is 0, the output is the same as the input; if the sign bit is 1, the output is the negation of the input plus one, effectively converting the negative value to its positive equivalent. The module is parameterized to handle different bit-widths, with n defaulting to 8 bits.
module top_module(
  input signed [n-1:0] input_signal,
  output reg [n-1:0] output_signal
);
