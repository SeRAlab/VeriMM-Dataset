Design an 8-bit Linear Feedback Shift Register (LFSR) that uses the polynomial x^8 + x^6 + x^5 + x^4 + 1. The LFSR should have an enable signal that, when high, allows the LFSR to shift and generate new bits. If the enable signal is low, the LFSR should maintain its current state. The LFSR should also have a reset signal that resets its state to a predefined value (e.g., 8'b00000001).
