Design a circuit that performs a 100-bit barrel shift operation with the capability to capture and utilize a 5-bit shift register. On each clock cycle, the circuit shifts the input data to the left or right depending on the state of the shift register, which is updated with the most significant bit of the input. The system initializes its state upon receiving a reset signal. The final output is a 100-bit wide value reflecting the shifted result of the input data.
module top_module(
    input clk,
    input rst,
    input [99:0] in,
    output [99:0] out
);
