The module uses a clock signal (CLK) and a reset signal (RST) to control its operation. Upon a reset, both outputs are set to LOW. On each positive edge of the clock, if the voltage at VPB is greater than VNB, HI is set to HIGH and LO to LOW. Conversely, if VNB is greater than VPB, LO is set to HIGH and HI to LOW. If both voltages are equal, both outputs remain LOW.
