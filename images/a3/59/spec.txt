Design a synchronous 4-bit counter that increments its output (Q) on the rising edge of the clock (CLK) when the enable (EN) signal is high. The counter resets to zero when the reset (RST) signal is asserted. This module effectively tracks and counts up to 15, providing a binary count value in a 4-bit register format.
module top_module(
    input CLK,
    input RST,
    input EN,
    output reg [3:0] Q
);
