
Design a simple SATA controller state machine that manages the initialization and data transfer states. The controller should have the following states: IDLE, INIT, and DATA. The transitions are:
- From IDLE to INIT when a start signal is asserted.
- From INIT to DATA when initialization is complete.
- From DATA to IDLE when data transfer is complete.
The controller should output the current state as a 2-bit value: 00 for IDLE, 01 for INIT, and 10 for DATA.
