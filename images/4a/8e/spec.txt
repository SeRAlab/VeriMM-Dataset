Design a 4-bit ripple carry adder that computes the sum of four 4-bit input numbers (A, B, C, and D) along with a carry-in (Cin). The module generates a 4-bit output (Sum) representing the least significant bits of the total sum, while the carry-out (Cout) indicates if there is an overflow beyond the 4 bits, allowing for add operations beyond the representable range of 4 bits.
module top_module(
    input [3:0] A, B, C, D,
    input Cin,
    output [3:0] Sum,
    output Cout
);
