Design a 1-bit SRAM cell that can store a single bit of data. It should have the following inputs: 
- `data_in`: the bit to be written to the cell
- `write_enable`: a signal to enable writing to the cell
- `read_enable`: a signal to enable reading from the cell
It should output `data_out`, the currently stored bit. The cell should hold its value when not being written to and should output the stored value when read.
