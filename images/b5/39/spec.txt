Design a synchronous 4-bit up counter with an output toggle feature. The counter increments its value on each positive clock edge unless the reset signal is active, which sets the count to zero and resets the output to LOW. Additionally, the output toggles its state with each count increment, providing a square wave signal synchronized with the counter's operation.
module top_module(
    input clk,
    input reset,
    output reg [3:0] count,
    output reg out
);
