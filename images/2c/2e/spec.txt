
Design a 1-bit DRAM cell with the following specifications:
- The cell should store a single bit of data.
- It should have two inputs: `data_in` (the data to be stored) and `write_enable` (an enable signal for writing).
- It should have one output: `data_out` (the data stored in the cell).
- When `write_enable` is high, `data_in` should be stored in the cell; when `write_enable` is low, the stored value should remain unchanged.
