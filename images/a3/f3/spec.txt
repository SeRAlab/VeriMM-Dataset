Design a 3-bit up/down counter with load capability. On a positive clock edge, when the load signal (L) is high, the counter outputs the value of the input D. If L is low, the counter increments (when U is high) or decrements (when U is low) the current output value. This allows for both counting operations and loading a preset value into the counter.
