Design a circuit that detects both rising and falling edges of a single input signal synchronized to a clock. The module outputs a high signal on 'rising_edge' when the input transitions from low to high, and a high signal on 'falling_edge' when it transitions from high to low. The previous state of the input signal is stored in a register to enable accurate edge detection on each clock cycle.
module top_module(
  input signal_in,
  input clock,
  output reg rising_edge,
  output reg falling_edge
);
