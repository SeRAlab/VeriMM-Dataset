Design a 4-channel Direct Memory Access (DMA) controller. This controller should take requests from 4 channels and grant access to a single channel when it's available. The controller should also have a request signal (req), a grant signal (gnt), and a clock signal (clk). The channel with the highest priority (Channel 0) should be granted access first, followed by Channel 1, Channel 2, and Channel 3. The output should indicate which channel has been granted access.
