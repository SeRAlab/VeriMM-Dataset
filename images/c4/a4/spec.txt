Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a pipeline register. 
A pipeline register is a type of digital circuit that is used to synchronize data between different stages of a pipeline. 
The inputs to the circuit are connected to the output of the previous stage, and the outputs are connected to the input of the next stage. 
The pipeline register is used to hold the data for one clock cycle, to ensure that the next stage has a stable input.

Your module should have the following inputs and outputs:

Inputs: a data signal (data_in) and a clock signal (clk)
Outputs: a data signal (data_out)

Your module should implement the following functionality:

The circuit should have a pipeline register that synchronizes the data_in signal with the clock signal.
The data_in signal should be latched on the rising edge of the clock signal.
The data_out signal should be the same as the data_in signal, delayed by one clock cycle.
To implement the pipeline register, you should use Verilog code to define the flip-flop that latches the data_in signal on the rising edge of the clock signal. 
You should also use the flip-flop to delay the data_in signal by one clock cycle, to produce the data_out signal.
