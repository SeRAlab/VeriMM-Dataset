The output result is calculated based on the signs of a and b: if a is negative and b is positive, or if a is positive and b is negative, the result is the negation of the computed modulo; otherwise, the result is the computed modulo itself. This ensures proper handling of sign when performing the modulo operation.
module top_module(
  input signed [31:0] a,
  input signed [31:0] b,
  output reg signed [31:0] result  // Change to reg
);
