Design a 4-to-1 multiplexer that selects one of four 16-bit input lines (InputA, InputB, InputC, InputD) based on a 2-bit selection signal (Select). The selected input is routed to the 16-bit output (Output) according to the value of the Select signal, where Select = 00 corresponds to InputA, 01 to InputB, 10 to InputC, and 11 to InputD.
module top_module(
    input [1:0] Select,
    input [15:0] InputA,
    input [15:0] InputB,
    input [15:0] InputC,
	 input [15:0] InputD,
    output reg [15:0] Output
    );
