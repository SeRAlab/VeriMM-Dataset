Design a 32-bit reversible counter that increments or decrements its value based on control inputs. The counter operates on the negative edge of the clock signal; it resets to zero when the reset signal is low. The counting direction is determined by the 'dir' input: when 'dir' is high, the counter increments; when low, it decrements. The counter only changes its value when the 'enable' signal is asserted.
module top_module(
    input wire clk,
    input wire rst,
    input wire enable,
    input wire dir,
    output reg [31:0] cnt
    );
