Design a 2-channel DMA controller that can read data from two sources and write it to two destinations. The controller must be able to handle requests from both channels and prioritize them based on a round-robin scheme. The controller should have the following inputs: `request_channel_1`, `request_channel_2`, `data_in_channel_1`, `data_in_channel_2`, and the outputs should be: `data_out_channel_1`, `data_out_channel_2`, and `grant_channel`. The `grant_channel` signal should indicate which channel is currently granted access to the data bus.
