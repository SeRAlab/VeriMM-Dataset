Please act as a professional Verilog designer. Create a module that implements a priority encoder. The priority encoder should take a 4-bit input "in" and output a 2-bit value "pos". "pos" should represent the highest priority bit set in "in". For example, if "in" is 0101, "pos" should be 01. If "in" is 1100, "pos" should be 10. If "in" is 0000, "pos" should be 00. If multiple bits in "in" are set, the highest priority bit should be selected. If "in" is 0100 and "in" is 0010, "pos" should be 10. If "in" is 1111 and "in" is 0010, "pos" should be 11. If "in" is 1111 and "in" is 0000, "pos" should be 11. The value of "pos" should be set every clock cycle.
