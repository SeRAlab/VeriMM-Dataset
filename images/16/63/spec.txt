Design a 32-bit Linear Feedback Shift Register (LFSR) based on the polynomial x^32 + x^22 + x^18 + x^17 + 1. The LFSR should generate pseudo-random numbers and be able to reset its state. Implement a Verilog module that includes a clock input, reset input, and a 32-bit output representing the current state of the LFSR.
