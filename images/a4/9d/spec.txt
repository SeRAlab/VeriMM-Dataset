Design a 32-bit pipelined barrel shifter that performs variable left or right shifts based on the selected shift direction and shift amount. The module accepts a 32-bit input data word and a 5-bit shift amount, producing a 32-bit output that contains the data shifted accordingly. When the shift direction input is zero, it performs a left shift, while a non-zero value indicates a right shift.
module top_module(
    input [31:0] data,
    input [4:0] shift_amount,
    input shift_direction,
    output [31:0] shifted_output
);
