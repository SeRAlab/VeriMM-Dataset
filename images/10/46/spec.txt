
Design a simple 8-bit SRAM (Static Random Access Memory) cell with read and write capabilities. The SRAM cell should have a write enable signal (we), an address input (addr), data input (data_in), and a data output (data_out). When the write enable signal is high, the data input should be written to the specified address. When the write enable signal is low, the data output should reflect the data stored at the specified address.
