
You are tasked with designing a module that takes in 5 inputs and produces 1 output. The inputs are A1, A2, A3, A4, and B1. The output is Y. The module should be named "logic_gate". 

The inputs are binary values, either 0 or 1. The output should be the result of the following logic expression: 

Y = (A1 AND A2 AND A3 AND A4) OR B1

You should implement the module using Verilog syntax.
