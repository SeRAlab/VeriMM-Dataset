Design a hazard detection circuit for a combinational logic circuit with two inputs (A, B) and one output (Y). The output Y should be high if there is a potential hazard detected based on the following conditions: 
1. If A and B are both high, Y should be high.
2. If A is high and B goes low, Y should remain high for one clock cycle.
3. If A is low and B is high, Y should be high.
4. If both A and B are low, Y should be low.
