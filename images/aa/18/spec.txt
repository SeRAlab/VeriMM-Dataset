Design a combinational circuit that takes three 4-bit inputs (a, b, and c) and produces a 9-bit output (y). The output y is determined by comparing inputs a and b: if a is less than b, it left shifts the concatenation of a and five zero bits by the value of c; if a is greater than b, it performs a similar operation with b; if a equals b, it computes the bitwise AND of a and b. This module effectively serves as a comparison and manipulation unit for the inputs based on their relational values.
module top_module(
  input [3:0] a,
  input [3:0] b,
  input [3:0] c,
  output reg [8:0] y
);
