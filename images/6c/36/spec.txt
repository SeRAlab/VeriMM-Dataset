Design a clocked Set-Reset Flip-Flop (SRFF) with synchronous and asynchronous reset capabilities. The module has inputs for a clock signal, a synchronous reset, a set signal, a reset signal, and an asynchronous reset signal, producing a single output that reflects the flip-flop's state. The output will be set to HIGH when the set signal is activated, reset to LOW when the synchronous reset or reset signal is activated, and will also respond immediately to the asynchronous reset. The design ensures that the flip-flop maintains its state across clock cycles unless triggered by the reset or set inputs.
