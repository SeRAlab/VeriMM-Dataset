Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs: 
1. state G (output 1).
2. state H (output 0).
3. state I (output 1).

State transitions:
1. From state G: If s = 0, then transition to state H. If s = 1, then transition to state I.
2. From state H: If s = 0, then transition to state G. If s = 1, then transition to state I.
3. From state I: If s = 0, then transition to state H. If s = 1, then transition to state G.

Resets into state G. For this part, assume that a one-hot code is used with the state assignment a[3:1] = 001, 010, 100 for states G, H, I, respectively.

Write Verilog for the next-state signals A2 and A3 corresponding to signal a[2] and a[3]. Derive the logic equations by inspection assuming a one-hot encoding.
