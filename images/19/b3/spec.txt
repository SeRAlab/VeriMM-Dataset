Design a 2-bit SR latch using Verilog. The latch should have two inputs, S (set) and R (reset), and two outputs, Q and Qn (not Q). The behavior of the latch should follow these rules: 
1. If S = 1 and R = 0, then Q = 1 and Qn = 0
2. If S = 0 and R = 1, then Q = 0 and Qn = 1
3. If S = 0 and R = 0, then Q and Qn retain their previous values
4. If S = 1 and R = 1, the output state is undefined (hold state).
