

You are tasked with designing a verilog module for a 4-bit counter that counts from 0 to 9 and then resets to 0. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock signal
- `rst`: a synchronous reset signal

Outputs:
- `count`: a 4-bit output representing the current count value

Your module should have the following behavior:
- On the rising edge of the `clk` signal, the counter should increment by 1.
- If the counter reaches 10, it should reset to 0 on the next clock cycle.
- If the `rst` signal is asserted, the counter should immediately reset to 0.

Write the verilog code for this module.
