Design a simple GPIO controller in Verilog that allows setting and getting the state of GPIO pins. The GPIO controller should have the following functionalities: it has a 4-bit input for the state of the GPIO pins, a 4-bit output representing the current state of the pins, and a control signal to update the state. When the control signal is high, the input state should be loaded into the output state. When the control signal is low, the output state should hold its previous value.
