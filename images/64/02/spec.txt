Design a 4-to-1 multiplexer that selects one of four input signals (A, B, C, or D) to output at Y based on two select lines (S0 and S1). When S0 and S1 are both low, input A is chosen; with S0 low and S1 high, input B is selected; when S0 is high and S1 is low, input C is routed to the output; and when both S0 and S1 are high, input D is the output.
module top_module(
    input A,
    input B,
    input C,
    input D,
    input S0,
    input S1,
    output Y
);
