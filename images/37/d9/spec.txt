Design a simple branch predictor that uses a 2-bit saturating counter for each entry in a pattern history table (PHT). The predictor should take a 2-bit input representing the current prediction and a 2-bit input representing the actual outcome (0 for taken, 1 for not taken). The output should be the updated prediction after processing the actual outcome. The 2-bit counter should increment on a correct prediction and decrement on a wrong prediction, saturating at both ends (00 and 11).
