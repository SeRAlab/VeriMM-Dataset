
Design an 8-bit SRAM cell with read and write capabilities. The SRAM cell should have a write enable signal (`we`), an address input (`addr`), an 8-bit data input (`data_in`), an 8-bit data output (`data_out`), and a clock signal (`clk`). When the write enable signal is high, the data input should be written to the specified address on the rising edge of the clock. When the write enable signal is low, the data from the specified address should be output on `data_out`.
