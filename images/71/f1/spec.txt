Design a D-type flip-flop with asynchronous SET and CLEAR inputs. The flip-flop captures the value of the data input (D) on the rising edge of the clock (CLK), and its output can be asynchronously set high or cleared low based on the SET and CLR signals. The module outputs the current state (Q) and its complement (Q_N).
module top_module(
    input CLK,
    input D,
    input SET,
    input CLR,
    output Q,
    output Q_N
);
