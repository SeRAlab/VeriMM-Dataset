Design a read/write controller that manages two request signals, `wr_req` (write request) and `rd_req` (read request), in conjunction with a clock and active-low reset signal `nrst`. The module outputs a write status `wr_sta` indicating the status of the write operation, which is set directly by `wr_req` when the system is active. Additionally, it generates a read status `rd_sta`, which indicates when a read operation is pending but only if there is no current write operation in progress; this is controlled by the `rd_req` signal. The `rd_sta` signal is reset when either the `nrst` signal is activated or a successful read operation (`rd_sta`) completes, providing a coordinated interface for managing read/write requests in a synchronous system.
