

You are given a Verilog module `inc` which has an input `i` of 4 bits and an output `o` of 4 bits. The module increments the input by 1 and assigns it to the output. The module uses a combinational logic to perform this operation.

Your task is to modify the `inc` module to implement a configurable increment operation. The new module should have two inputs, `i` and `inc_val`, where `i` is the input of 4 bits and `inc_val` is a configurable increment value of 4 bits. The output `o` should be the result of incrementing `i` by `inc_val`. The module should use a combinational logic to perform this operation.

You need to implement the combinational logic for the modified `inc` module.
