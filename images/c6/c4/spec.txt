

You have been asked to design a verilog module that takes in a 2-bit input `A` and a 1-bit input `B`. The output `Z` is set to 1 if the input `A` is greater than or equal to the input `B`, otherwise `Z` is set to 0.

Design the verilog module with the following specifications:
- The module should be named `compare_module`.
- The module should have the following ports:
  - `input [1:0] A`
  - `input B`
  - `output Z`
- The module should use only combinational logic.
- The module should have an `always` block for the output `Z`.
