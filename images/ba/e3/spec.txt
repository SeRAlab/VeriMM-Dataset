Implement a BCD (Binary-Coded Decimal) encoder that takes a 4-bit input A representing decimal digits 0 through 9 and outputs two 4-bit values: OUT1 and OUT2. OUT1 serves as a high nibble, which is set to 0 for inputs 0-3, 1 for inputs 4-7, and 2 for inputs 8-9. OUT2 represents the binary equivalent of the decimal digits, where the corresponding binary values are output according to the input A. If the input exceeds the valid BCD range (0-9), both OUT1 and OUT2 are set to zero.
module top_module(
    input [3:0] A,
    output reg [3:0] OUT1,
    output reg [3:0] OUT2
);
