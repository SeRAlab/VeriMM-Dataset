Module name:  
    counter_updown_64bit 

Input ports:
    clk: Clock signal used for synchronous operation.
    rst: Reset signal. Defined as 1 for reset and 0 for normal operation.
    up_down: Control signal to determine counting direction (1 for up, 0 for down).

Output ports:
    count: Current count value with a data width of 64 bits.

Parameter:
    width = 64

Implementation:
Counter operation:
On the positive edge of the clock signal (clk), if reset (rst) is high, the count is set to 0.
If reset (rst) is low, the count is updated based on the up_down control signal.
If up_down = 1, the count is incremented.
If up_down = 0, the count is decremented.
