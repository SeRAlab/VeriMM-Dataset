

Implement a verilog module for a 4-bit binary to gray code converter. The module should have the following interface:
- `input wire [3:0] bin`: the 4-bit binary input
- `output reg [3:0] gray`: the 4-bit gray code output

The module should use the following algorithm to convert the binary input to gray code:
- The most significant bit (MSB) of the gray code output is the same as the MSB of the binary input.
- Each subsequent bit of the gray code output is the XOR of the corresponding bit of the binary input and the previous bit of the gray code output.
