Design a 4-to-16 decoder with an active low output. The module uses two select lines to determine which of the 16 output lines is activated based on the binary value of `select`. When the `enable` input is high, the output corresponding to the `select` value is LOW (active), while all other outputs are HIGH. If `enable` is low, all outputs remain HIGH (inactive).
module top_module(
    input enable,
    input [1:0] select,
    output [15:0] out
);
