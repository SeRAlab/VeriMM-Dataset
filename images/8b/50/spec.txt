Design a clock-gated D flip-flop with enable and test functionality. The module generates a gated clock signal that is active only when the enable input (EN) is high, thereby reducing power consumption. On each positive edge of the gated clock, if the test input (TE) is high, the output (ENCLK) is reset to low; otherwise, if EN is high, ENCLK is set to high, maintaining its previous state otherwise. This design aims to enhance efficiency by controlling clock signals based on enable conditions.
module top_module(
  input CLK,
  input EN,
  input TE,
  output reg ENCLK
);
