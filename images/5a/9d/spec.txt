Design a digital potentiometer circuit that generates an analog output based on a digital input. The module accepts an n-bit wide digital input representing the desired resistance level, adjusts the resistance in steps defined by a parameterized step size, and outputs the corresponding resistance value. The module includes a clock signal for synchronization and a reset signal to initialize the counters and output states. Additionally, it provides a 'done' signal that indicates when the potentiometer has completed its adjustment, based on reaching a maximum defined resistance level.
module top_module(
  input [n-1:0] in,
  input clk,
  input rst,
  output reg out,
  output reg done
);
