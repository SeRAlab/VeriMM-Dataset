
Create a GPIO controller with read and write functionality. The controller should have the following features:
- It should have an input for a 5-bit data bus.
- It should have a read enable signal and a write enable signal.
- On a rising edge of the clock, if the write enable is high, the data should be written to the GPIO register.
- When the read enable is high, the GPIO register data should be output on a data bus.
