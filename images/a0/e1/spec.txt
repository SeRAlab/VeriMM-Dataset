Design a simple calculator module capable of performing arithmetic operations on two signed 8-bit numbers (num1 and num2). The module accepts a 2-bit opcode to select the operation: 00 for addition, 01 for subtraction, 10 for multiplication, and 11 for division. The result of the operation is clocked into a signed 8-bit output (result) on the rising edge of the clock signal.
module top_module(
    input signed [7:0] num1,
    input signed [7:0] num2,
    input [1:0] opcode,
    input clk,
    output reg signed [7:0] result
);
