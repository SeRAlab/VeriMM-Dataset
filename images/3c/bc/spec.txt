Design a fan speed controller that adjusts the fan speed based on temperature readings. The controller has a clock input and a reset input. The temperature is provided as a 4-bit input. The fan speed is adjusted based on the following temperature ranges: 
- 0-3: Off
- 4-7: Low
- 8-11: Medium
- 12-15: High
The fan speed output should be a 2-bit value indicating the speed level. The system should retain the last fan speed until the temperature input changes significantly (e.g., change in temperature value).
