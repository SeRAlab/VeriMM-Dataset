Design a 24-bit ADC input processing module that scales the input value to a 10-bit output value. The input is a 24-bit unsigned integer, and the output should be the 10-bit representation scaled to the range of 0-1023. The scaling should be done by dividing the input value by 2^14. If the input value exceeds 2^24 - 1, the output should be set to 1023 (the maximum value for a 10-bit number).
