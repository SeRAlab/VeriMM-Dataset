Design a power gating circuit that takes a 2-bit control signal `ctrl` and a 4-bit data input `data_in`. When `ctrl` is `00`, the output `data_out` should be `0000` (power off). When `ctrl` is `01`, the output should be equal to `data_in`. When `ctrl` is `10`, the output should be `data_in` inverted. When `ctrl` is `11`, the output should be `data_in` incremented by 1 (modulo 16).
