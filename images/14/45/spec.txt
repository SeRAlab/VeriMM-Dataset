Design a 4-bit Up/Down counter with the following specifications:
1. The counter should count up when the 'up_down' signal is high and count down when it is low.
2. The counter should reset to zero when the 'reset' signal is asserted.
3. The counter should have a clock input to synchronize the counting.
4. The counter should wrap around when reaching the maximum count (15 for up) or minimum count (0 for down).
