Design a versatile 8-bit Arithmetic Logic Unit (ALU) capable of performing a variety of operations based on a 4-bit operation code (`op`). The ALU supports addition, subtraction, bitwise operations (AND, OR, XOR, complement), as well as rotation and swapping of bits. The outputs include an 8-bit result (`y`), a carry-out flag (`cout`), and a zero flag (`zout`) that indicates whether the result is zero. The carry-out for the addition and subtraction operations is captured, and specific handling for the carry in (`cin`) is incorporated during rotation operations. The design efficiently determines the operation to perform using a combinational logic structure driven by the input operation code.
module top_module(
   op,
   a,
   b,
   y,
   cin,
   cout,
   zout
);
