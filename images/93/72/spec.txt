Implement a pipelined XOR gate that operates on two input signals, `a` and `b`. The module has a clock input (`clk`) and processes the inputs across two stages in a clocked sequential manner. On each rising edge of the clock, the first stage computes the XOR of `a` and `b`, which is then stored in the `stage1` register. In the next stage, the value from `stage1` is assigned to `stage2`. Finally, the output is the XOR of the current `stage1` and `stage2` values. This design introduces latency and allows for synchronous processing of the XOR operation, suitable for pipelined architectures.
module top_module(
    input clk,
    input a,
    input b,
    output reg out
);
