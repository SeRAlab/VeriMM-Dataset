
Design a state-space controller in Verilog that can implement a simple discrete-time state-space representation defined by the following equations:
1. x[n+1] = Ax[n] + Bu[n]
2. y[n] = Cx[n] + Du[n]
Where A, B, C, and D are given matrices for a single-input, single-output (SISO) system. You will need to implement state updating and output generation based on inputs and the current state.
