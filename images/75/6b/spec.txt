Design a Direct Memory Access (DMA) request generator that manages data transfer requests. It receives clock and reset signals, a valid request flag, and burst count input, generating a unique request ID each time a new transfer is initiated. Upon activation, it decrements the burst count until a transfer is complete, indicated by an end-of-transfer (EOT) signal, and signals readiness for new requests based on the status of the enable and pause inputs. This module efficiently coordinates data requests while ensuring synchronization with response signals from the memory.
module top_module(
    input req_aclk,
    input req_aresetn,

    output [C_ID_WIDTH-1:0] request_id,
    input [C_ID_WIDTH-1:0] response_id,

    input req_valid,
    output reg req_ready,
    input [C_BURSTS_PER_TRANSFER_WIDTH-1:0] req_burst_count,

    input enable,
    input pause,

    output eot
);
