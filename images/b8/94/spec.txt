Design a 4-to-2 priority encoder that accepts four single-bit inputs (A, B, C, D) and provides a two-bit output (X) and a single-bit output (Y). The output X encodes the index of the highest-priority active input, with input D having the highest priority, followed by C, B, and A. If any of the inputs are active (logic high), Y outputs a logic high signal; otherwise, it outputs logic low. This design is useful for applications where multiple signals need to be prioritized and encoded efficiently.
module top_module(
    input A,
    input B,
    input C,
    input D,
    output reg [1:0] X,
    output reg Y
);
