Design a synchronous 8-bit adder circuit that sums two 8-bit input values, `a` and `b`. The addition occurs on the rising edge of the clock signal. If the reset input is activated, the adder's output registers are cleared to zero. The final 8-bit output, `sum`, represents the least significant 8 bits of the computed sum, while an extra bit is used internally to accommodate any potential carry from the addition.
module top_module(
  input          clock,
  input          reset,
  input   [7:0] a,
  input   [7:0] b,
  output [7:0]  sum
);
