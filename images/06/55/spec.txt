
Design an 8-bit SRAM cell that can store a single byte of data. The SRAM will have the following inputs: 
- `data_in` (8 bits): the data to be written to the SRAM.
- `write_enable` (1 bit): when high, the SRAM writes the `data_in` into the cell; when low, it retains the stored data.
- `data_out` (8 bits): the data output from the SRAM.

The SRAM cell should be able to store data on the rising edge of a clock signal if `write_enable` is high.
