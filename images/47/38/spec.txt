Design a dual-port RAM module that manages a memory space for MAC address transactions. The module allows data to be written from an external source when a write enable signal is asserted and reads data based on an incrementing address during read operations. It features a reset functionality to initialize the address registers and to clear the write signals, ensuring reliable operation in synchronous and asynchronous states. Upon initialization, the read address is reset, while a controlled read address is incremented each time the read signal is asserted.
