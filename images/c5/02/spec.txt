

You are tasked with designing a module in Verilog that implements a D flip-flop with asynchronous reset and set. The module should have the following inputs and outputs:

- `D`: input data signal
- `CLK`: input clock signal
- `RESET`: asynchronous reset signal
- `SET`: asynchronous set signal
- `Q`: output data signal
- `Q_N`: output inverted data signal

The module should follow the following specifications:
- The flip-flop should be implemented using a positive-edge triggered clock
- The output should be updated on the rising edge of the clock signal
- When the reset signal is asserted (`RESET=0`), the output should be set to 0
- When the set signal is asserted (`SET=0`), the output should be set to 1
- When both reset and set signals are asserted at the same time, the output should be set to 0

You should implement the module in Verilog within 200 lines of code.
