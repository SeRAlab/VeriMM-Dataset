Design a register file write stage that captures and holds values from the processor's memory write logic. This module, activated on the positive edge of the clock, stores data inputs for the next stage of processing – specifically, the memory data output (mmo), the ALU output (malu), the destination register number (mrn), and control signals to indicate whether to write to the register file (wwreg) and if the value should be written back from memory (wm2reg). Additionally, it incorporates an asynchronous clear feature to reset all outputs when the clear signal (clrn) is asserted low.
