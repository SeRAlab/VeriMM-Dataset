Design a 2-bit wide, 4-to-1 multiplexer. The multiplexer selects one of four input 2-bit pairs (A, B, C, D) based on a 2-bit select signal (S1, S0). When S1 and S0 are both 0, the output is set to the values of input A. When S1 is 0 and S0 is 1, the output reflects input B. If S1 is 1 and S0 is 0, the output comes from input C, and when both S1 and S0 are 1, the output corresponds to input D.

	       		B1, B0,
	       		C1, C0,
	       		D1, D0,
 	       		S1, S0,
	       		Out1, Out0);
