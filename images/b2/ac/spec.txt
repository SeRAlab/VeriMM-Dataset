Design a 4-to-1 multiplexer with 5-bit wide inputs. The module selects one of the four 5-bit inputs (I0, I1, I2, I3) to pass through to the 5-bit output (o) based on the 2-bit select signal (Sel). When Sel is 00, I0 is output; when Sel is 01, I1 is output; when Sel is 10, I2 is output; and when Sel is 11, I3 is output.
module top_module(input [1:0] Sel,
					 input [4:0] I0,
					 input [4:0] I1,
					 input [4:0] I2,
					 input [4:0] I3,
					 output reg[4:0] o
					);
