When not in reset, the module computes the AND of the inputs and sets the `valid` signal high, indicating that the output is ready and valid.
module top_module(
  input clk,
  input rst,
  input [7:0] a,
  input [7:0] b,
  output reg [7:0] out,
  output reg valid
);
