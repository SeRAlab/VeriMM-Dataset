Design a synchronous 4-bit ripple carry adder with carry-in functionality. The module receives two 4-bit inputs, A and B, along with a single-bit carry-in, Cin. On each rising edge of the clock, the adder computes the sum of A, B, and Cin, outputting the result as a 4-bit Sum. Additionally, it provides a carry-out signal, Cout, which indicates if there was an overflow beyond the 4-bit limit. A reset input allows for asynchronous clearing of the outputs, setting both the sum and carry to zero.
module top_module(
  input clk,
  input reset,
  input [3:0] A,
  input [3:0] B,
  input Cin,
  output [3:0] Sum,
  output Cout
);
