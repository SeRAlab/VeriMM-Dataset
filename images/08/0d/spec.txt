
Design an up counter in Verilog that counts from 0 to a specified maximum value and then resets back to 0. The counter should have a clock input, a reset input, and an enable input. When the reset input is high, the counter should reset to 0. When the enable input is high, the counter should increment by 1 on each rising edge of the clock until it reaches the maximum value, at which point it should wrap back to 0. The maximum value should be configurable via a parameter in the Verilog code.
