Design a 4-bit wide synchronous memory module that supports read and write operations. The module uses address lines to select one of 16 memory locations and includes a write enable signal (WE) to control data written to the memory. Upon the rising edge of WE, the input data is stored in the specified memory address, and when WE is low, the module outputs the data from the addressed memory location onto the DATA bus, using a high-impedance state when not accessing. The memory is initialized to contain values from 0 to 14 during startup.
