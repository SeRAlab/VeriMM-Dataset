Design a 4-input NAND multiplexer. The module takes two data inputs (A and B), one additional input (C), and two select lines (sel1 and sel2). It outputs Y by first determining the appropriate conditions based on the select lines. When both select lines are low, the output is NANDed with inputs A, B, and C, reflecting the multi-level selection of data based on the select signals. The output Y will thus produce a NAND operation of the chosen inputs based on the provided selections.
module top_module(
    input A,
    input B,
    input C,
    input sel1,
    input sel2,
    output Y
);
