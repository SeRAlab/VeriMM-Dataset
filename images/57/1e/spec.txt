Design a 2-to-1 multiplexer with an enable signal. When the enable (en) signal is high, the output (mux_out) will reflect the value of input a; when en is low, mux_out will reflect the value of input b. The inputs and output are 4 bits wide, allowing for the selection between two 4-bit wide data sources.
module top_module(
  input [3:0] a,
  input [3:0] b,
  input en,
  output reg [3:0] mux_out
);
