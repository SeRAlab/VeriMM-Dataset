Design a simple Automatic Repeat reQuest (ARQ) error correction system. The system should have an input for received data (5 bits), a signal indicating if the data is valid (1 bit), and an output for the corrected data (5 bits). If the data is not valid, the system should request a retransmission by asserting a request signal (1 bit). The system should also keep track of the number of retransmissions (3 bits).
