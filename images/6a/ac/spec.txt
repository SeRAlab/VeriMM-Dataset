Design a dual-port video RAM (VRAM) module capable of reading from and writing to a shared memory space. The circuit includes two ports: Port 1 allows for both read and write operations, controlled by the `p1_we` (write enable) and `p1_re` (read enable) signals; when writing, data at `p1_addr` is stored, and when reading, the data is output to `p1_data_out`. Port 2 provides a read-only access, delivering the contents of `p2_addr` directly to `p2_data`. This memory can handle up to 153,600 bytes of 8-bit data, making it suitable for applications requiring high-speed memory access, such as graphics processing.

	    input [7:0]      p1_data,
            output reg [7:0] p1_data_out, 
	    input            p1_we,
            input            p1_re,

	    input [19:0]     p2_addr,
	    output reg [7:0] p2_data);
