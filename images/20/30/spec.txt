Design a simple PNG compressor that takes an 8-bit pixel value and outputs the corresponding 8-bit compressed value using a basic run-length encoding technique. The input pixel values will be provided in a sequence, and the output will indicate the length of consecutive identical pixel values followed by the pixel value itself. For instance, if the sequence of pixels is [255, 255, 255, 128], the output should be [3, 255, 1, 128]. The module should handle up to 8 consecutive identical pixels.
