 
Design a data forwarding unit that resolves data hazards in a pipelined processor. The unit takes three 5-bit inputs: `src1`, `src2` (the source registers), and `dest` (the destination register). The output should be a 2-bit signal `forward` which indicates whether the data should be forwarded from one of the two source registers or not. The forwarding logic is defined as follows:
- If `src1` matches `dest`, forward from the destination (output `01`).
- If `src2` matches `dest`, forward from the destination (output `10`).
- If neither matches, no forwarding is needed (output `00`).
