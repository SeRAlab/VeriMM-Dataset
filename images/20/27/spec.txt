Design a 24-bit Digital to Analog Converter (DAC) with an additional control input to set the output voltage level. The DAC converts a 24-bit binary input value into a corresponding voltage level, where the voltage range is from 0V to 5V. The module should have a control input that determines whether the output is valid (1) or invalid (0). If the control input is 0, the output should be set to 0V regardless of the input value.
