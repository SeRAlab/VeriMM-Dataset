
Design a Network Address Translation (NAT) module that translates an internal IP address to an external IP address based on a predefined mapping. The module should have an input for the internal IP address, an external IP address output, and a control signal to perform the translation. The translation should only occur on the rising edge of the clock when the control signal is high. If there is no mapping for the internal IP address, the output should be set to a default external IP address (e.g., 0.0.0.0).
