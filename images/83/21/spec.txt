Implement the Verilog module based on the following description.
You are given a six-bit input vector in[5:0]. We want to compute some relationships between the bits and their neighbours: 
// (1) out_and: Each bit of this output vector should indicate whether both the corresponding input bit and its neighbour to the left (higher index) are '1'. For example, out_and[3] should indicate if in[3] and in[4] are both 1. Since in[5] has no neighbour to the left, the answer is obvious so we don't need to know out_and[5]. 
// (2) out_or: Each bit of this output vector should indicate whether either the corresponding input bit or its neighbour to the right are '1'. For example, out_or[4] should indicate if either in[4] or in[3] are 1. Since in[0] has no neighbour to the right, the answer is obvious so we don't need to know out_or[0]. 
// (3) out_xor: Each bit of this output vector should indicate whether the corresponding input bit is different from its neighbour to the left. For example, out_xor[2] should indicate if in[2] is different from in[1]. For this part, treat the vector as wrapping around, so in[5]'s neighbour to the left is in[0].
