Develop a synchronous 4-bit binary adder with a reset feature. When the reset signal is low, both the sum and carry registers are cleared to zero. On each rising edge of the clock, if reset is high, the module computes the sum of two 4-bit inputs, A and B, incorporating an additional carry value to handle overflow conditions. The sum is stored in a register and made available at the output, ensuring the functionality of the adder is robust for multiple clock cycles.
module top_module(
  input clk,
  input reset,
  input [3:0] A,
  input [3:0] B,
  output [3:0] S
);
