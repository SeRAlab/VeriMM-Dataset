

You are tasked with designing a Verilog module for a 3-to-8 decoder. The module should have three input bits and eight output bits. The output bit corresponding to the input value should be high, while all other output bits should be low. 

Create a module named `decoder_3to8` that meets these requirements. Your module should be written in Verilog and should be self-contained, meaning that any necessary input and output definitions should be included in the module.

In addition, your module should be designed to be easily testable. You should include a test plan that covers all possible input combinations and verifies that the output is correct.
