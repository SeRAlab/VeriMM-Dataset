Design a 3-bit up/down counter with load capability. The counter increments its value on each clock cycle when the up_down signal is high, and decrements when it is low. If the load signal is asserted, the counter loads a specified 3-bit value from the data input instead of incrementing or decrementing.
module top_module(
    input clk,
    input load,
    input up_down,
    input [2:0] data,
    output reg [2:0] count
);
