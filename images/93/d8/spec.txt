Design a 4-to-1 multiplexer that selects one of four 1-bit data inputs (D[0] to D[3]) based on a 2-bit select signal (S). The output Y will reflect the value of the selected data input, where S[1:0] determines the specific input: if S is 00, output D[0]; if S is 01, output D[1]; if S is 10, output D[2]; and if S is 11, output D[3]. In case of invalid selection, the output is driven to high-impedance (Z).
module top_module(
  input  [3:0] D,
  input  [1:0] S,
  output Y
);
