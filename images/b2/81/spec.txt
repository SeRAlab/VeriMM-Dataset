Design a 32-bit up/down counter that increments or decrements its value based on control inputs. The counter operates on the rising edge of a clock signal and resets to zero when the reset input is high. When the enable signal is asserted, the counter will increment its count if the up_down input is high, and decrement if it is low.
module top_module(
    input clk,
    input rst,
    input up_down,
    input enable,
    output reg [31:0] count
);
