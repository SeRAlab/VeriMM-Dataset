Design a 4-bit SRAM cell that allows reading and writing of a 4-bit data input. The SRAM cell should have an input data line (D), an output data line (Q), a write enable signal (WE), and a clock signal (CLK). When WE is high, the data on the D line should be written into the SRAM cell on the rising edge of CLK. When WE is low, the data stored in the SRAM cell should be available on the Q line.
