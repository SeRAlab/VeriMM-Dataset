
Design a finite state machine (FSM) that simulates a simplified SLAM process. The FSM should have three states: IDLE, LOCALIZING, and MAPPING. The FSM should transition between these states based on two inputs: start (to initiate localization) and complete (to indicate mapping is done). The FSM should output the current state as a 2-bit value, where IDLE is '00', LOCALIZING is '01', and MAPPING is '10'.
