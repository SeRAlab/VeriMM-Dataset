Design a simple Direct Memory Access (DMA) controller that transfers data from a source address to a destination address in memory. The controller should have inputs for a clock, a reset signal, a start signal to initiate the transfer, a source address, and a destination address. It should have outputs indicating the status of the transfer (busy or idle) and a data output that sends the data being transferred. The data size is fixed at 8 bits, and the controller should transfer a total of 4 words (32 bits) before completing the operation.
