Design a 2-to-1 multiplexer that selects between two 32-bit input signals, `in0` and `in1`, based on the control signal `MemtoReg`. When `MemtoReg` is low, the output `out` will reflect the value of `in0`; when `MemtoReg` is high, it will reflect the value of `in1`. The module also takes a clock signal as input, though it is not used in the output assignment.
module top_module(
	input clk,
	input MemtoReg,
	input [31:0] in0,
	input [31:0] in1,
	output wire[31:0] out
);
