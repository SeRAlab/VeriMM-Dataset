Design a synchronous 2-to-1 multiplexer with a reset feature. The module takes two input signals, A0 and A1, and a select signal S. When the reset signal (rst) is asserted, the output X is set to LOW. Otherwise, when S is high, X outputs the value of A1; when S is low, X outputs the value of A0. The output changes state on the rising edge of either the reset or select signals.
module top_module(
    input A0,
    input A1,
    input S,
    input rst,
    output reg X
);
