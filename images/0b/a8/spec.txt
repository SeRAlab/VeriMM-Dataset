Design an 8-channel DMA controller that allows data transfer between memory and peripherals. The controller should have the following inputs: `start` (to initiate the transfer), `channel_sel` (to select which channel to operate on), `data_in` (data input), and `clk` (clock signal). It should output `data_out` (data output) and a `busy` signal indicating whether a transfer is in progress. The controller should transfer data on a rising edge of the clock when `start` is asserted.
