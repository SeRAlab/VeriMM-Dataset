Design an interrupt controller that can handle multiple interrupt requests. The controller has three types of interrupts: high priority, medium priority, and low priority. It should have an input for requests and an output to indicate which interrupt is being processed. The requests are given as a 3-bit input where each bit represents a different priority level (bit 0 for low, bit 1 for medium, and bit 2 for high). The output should indicate the interrupt type being processed based on the priority of the requests.
