Design a Verilog module that implements a simple RNN cell for inference. The RNN should take as input a 4-bit value (input_data) and a 4-bit hidden state (hidden_state), and output a new hidden state (new_hidden_state) that is calculated as follows: new_hidden_state = tanh(W * input_data + U * hidden_state), where W and U are predefined weight matrices. For simplicity, use fixed weights for W and U. The output should be valid after a clock pulse.
