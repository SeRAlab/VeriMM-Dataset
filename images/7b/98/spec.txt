Design a D-type flip-flop with asynchronous reset and set functionality. The output Q captures the value of the input D on the rising edge of the clock (CLK) while allowing for external control through the RSTB and SETB signals. When RSTB is low, Q is reset to 0 and QN to 1. When SETB is low, Q is set to 1 and QN to 0. Otherwise, the flip-flop operates normally, transferring D to Q and providing the inverted output QN. This module is essential for temporary data storage with additional control for initialization.
