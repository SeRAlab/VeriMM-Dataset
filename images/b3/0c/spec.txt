Design a 4-bit binary adder that computes the sum of two 4-bit inputs, A and B, and outputs a 4-bit sum, S, along with a carry-out signal, Cout. The module uses intermediate wires to handle the addition and carry generation for each bit. The carry-out signal is determined by the final carry from the most significant bit addition, providing indication when an overflow occurs.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output [3:0] S,
    output Cout
);
