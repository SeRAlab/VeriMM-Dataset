
Design an 8-bit SRAM cell with separate read and write enable signals. The cell should store an 8-bit data word and allow reading and writing of that data based on the control signals. The cell should have the following ports:
- `data_in`: 8-bit input data for writing
- `data_out`: 8-bit output data for reading
- `we`: write enable signal (1 for write, 0 for read)
- `re`: read enable signal (1 for read, 0 for no read)
- `clk`: clock signal for synchronization
