Design an 8-bit deserializer that converts a serial input stream of bits into an 8-bit parallel output. The deserializer should accept a serial input signal, a clock signal, and a reset signal. On each clock cycle, it should shift in one bit from the serial input into an internal register. When 8 bits have been received (i.e., after 8 clock cycles), the output should be updated with the parallel value and the deserialization process should start over.
