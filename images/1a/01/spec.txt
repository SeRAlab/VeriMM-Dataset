Design a SR flip-flop with asynchronous reset. The flip-flop should have the following behavior:
- If S (Set) is high and R (Reset) is low, the output Q should be high.
- If S is low and R is high, the output Q should be low.
- If both S and R are low, the output Q should retain its previous state (memory effect).
- If R is high (asynchronous reset), the output Q should be reset to low regardless of S.
- The flip-flop should have a clock input to sample the S and R inputs.
