The module includes two independent ports: Port A (with write capability) and Port B (read-only). When enabled, Port A can write data to a specified address and also provide the data stored at that address, while Port B can read data from any specified address without writing. Both ports are clock-driven, ensuring synchronized operation during data access.

    input clk
);
