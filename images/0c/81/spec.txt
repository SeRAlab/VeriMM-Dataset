Design a thermal sensor calibration circuit that adjusts the output reading based on a 3-bit input representing the raw temperature data. The output should be a 4-bit calibrated temperature reading, where the calibration logic adds a fixed offset based on the input value. Specifically, if the input is less than 4, the output should be the input value plus 2; if the input is 4 or more, the output should be the input value minus 1.
