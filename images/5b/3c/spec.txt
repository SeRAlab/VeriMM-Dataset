Please act as a professional Verilog designer.

Design a Verilog module for a 16-bit register with a synchronous load. The register loads a new value from the input on the rising edge of the clock when the load signal is active.

Module name:
    reg_16bit_sync_load

Input ports:
    clk: Chip clock signal.
    load: Synchronous load signal.
    data_in: Input data signal with a data width of 16 bits.

Output ports:
    data_out: Output data signal with a data width of 16 bits.

Implementation:
Register operation:
On every positive edge of the clock signal (clk), the register (data_out) loads the value from data_in if the load signal (load) is active. Otherwise, it retains its previous value.
