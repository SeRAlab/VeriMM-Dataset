Design a circuit that functions as a 4-to-1 multiplexer based on a 2-bit selection input (SEL). The module takes four input signals (Y1, Y2, Y3, Y4) generated by the same logic gate instances driven by inputs A1, A2, A3, and B1. Depending on the value of SEL, the output Y will select one of these four Y signals to pass through: when SEL is 00, Y1 is selected; when SEL is 01, Y2; when SEL is 10, Y3; and when SEL is 11, Y4. This configuration allows for controlled routing of the output based on the selection lines.
module top_module(
    output Y,
    input SEL,
    input A1,
    input A2,
    input A3,
    input B1
);
