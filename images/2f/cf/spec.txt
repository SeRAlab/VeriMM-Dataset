
Design a 16-bit DRAM cell with read and write capabilities. The DRAM cell should have inputs for a 16-bit data line (data_in), a control signal for read (read_enable), a control signal for write (write_enable), and a 4-bit address line (addr). The DRAM cell should output the 16-bit value stored at the given address when read is enabled. When write is enabled, it should store the data_in at the specified address.
