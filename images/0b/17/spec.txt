Implement a simple NAT (Network Address Translation) device that translates an internal IP address to an external IP address when a packet is sent. The NAT device maintains a mapping table where it maps internal addresses to external addresses. The NAT should also be able to reverse the process when a packet is received from the external network. The system has to support 5 internal addresses and 5 external addresses. The input to the device will be a packet with an internal or external address and the output will be the translated address.
