Design a pulse width modulation (PWM) generator that produces a PWM output signal based on an 8-bit input level. The module increments a counter on each rising edge of the clock signal, and when the counter value is less than the specified level, the output is set high; otherwise, it is low. The counter resets to zero when the reset signal is activated, allowing for adjustable duty cycles corresponding to the value of the input level.
module top_module(
    input wire clk,
    input wire reset,
    output wire out,
    input wire [7:0] level
    );
