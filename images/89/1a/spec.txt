Design a 4-bit ripple carry adder that computes the sum of two 4-bit inputs, A and B, along with a carry-in input (Cin). The module produces a 4-bit output (Sum) representing the least significant bits of the addition result, and a carry-out output (Cout) that reflects any overflow beyond the 4-bit sum. This design effectively handles the addition of two 4-bit binary numbers while indicating if there is a carry to the next higher bit.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    output [3:0] Sum,
    output Cout
);
