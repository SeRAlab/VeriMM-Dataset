
Create a Verilog module that implements a simple linear regression model using combinational logic. The model should take two inputs, representing features (x1 and x2), and output the predicted value (y) based on the linear equation: y = w1 * x1 + w2 * x2 + b, where w1 and w2 are the weights, and b is the bias. Use fixed values for w1, w2, and b (for example, w1 = 2, w2 = 3, b = 1).
