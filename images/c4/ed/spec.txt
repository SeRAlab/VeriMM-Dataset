

You are tasked with designing a verilog module that will implement a 4-bit adder. The module should have two 4-bit input ports, A and B, and one 4-bit output port, S. The module should also have a single input port, Cin, which represents the carry-in bit. The module should implement the following logic:

- The output port S should be the sum of the input ports A and B, plus the carry-in bit Cin.
- If the sum of A, B, and Cin is greater than 15 (4 bits), the output port S should be truncated to the least significant 4 bits.

You should name your module "four_bit_adder".
