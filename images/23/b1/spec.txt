
Design a FIFO queue in Verilog that can store up to 8 4-bit data values. The module should have the following inputs and outputs:
- `clk` (clock input)
- `rst` (reset input)
- `enq` (enqueue signal)
- `deq` (dequeue signal)
- `data_in` (4-bit input data)
- `data_out` (4-bit output data)
- `full` (indicates if the FIFO is full)
- `empty` (indicates if the FIFO is empty)
The FIFO should support enqueuing and dequeuing of data, with appropriate signals to indicate the status of the FIFO.
