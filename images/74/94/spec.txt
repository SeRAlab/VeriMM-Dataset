Design a 3-to-1 multiplexer that selects one of three input signals based on a 2-bit selection input. The module takes three inputs (a, b, c) of specified bit width and outputs one of these inputs (y) depending on the value of the selection signal (sel). If sel is 00, output a; if sel is 01, output b; and if sel is 10, output c. The design accommodates 32-bit wide data inputs, as predefined by the parameter.
module top_module(sel, a, b, c, y);
