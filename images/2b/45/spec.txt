
Design a 32-bit timer module that counts up from zero. The timer should have a clock input, a reset input, and an output that represents the current count. The count should increment by 1 on each rising edge of the clock when the reset is not asserted. If reset is asserted, the count should be reset to zero. The timer should also have a maximum value of 2^32 - 1, at which point it should roll over back to 0.
