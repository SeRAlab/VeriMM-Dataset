Please act as a professional Verilog designer.

Design a Verilog module for a 12-bit binary counter with enable and synchronous reset. The counter increments its value on the rising edge of the clock when the enable signal is active and resets to 0 when the reset signal is active.

Module name:
    binary_counter_12bit

Input ports:
    clk: Chip clock signal.
    reset: Synchronous reset signal.
    enable: Enable signal.

Output ports:
    count: Counter output signal with a data width of 12 bits.

Implementation:
Counter operation:
On every positive edge of the clock signal (clk), the counter (count) increments its value by 1 if the enable signal (enable) is active and the reset signal (reset) is not active. If the reset signal is active, the counter resets to 0.
