

You are tasked with designing a verilog module to implement a 4-bit binary counter with parallel load functionality. The module should have the following inputs and outputs:

Inputs:
- `clk`: the clock signal
- `reset`: asynchronous reset signal
- `load`: load signal to load a new value into the counter
- `data`: 4-bit input data to be loaded into the counter when `load` is asserted

Outputs:
- `count`: 4-bit output representing the current count value of the counter

The counter should increment on every rising edge of the `clk` signal, and should reset to 0 when the `reset` signal is asserted. When the `load` signal is asserted, the counter should immediately load the value of `data` into the counter and start counting from that value.

Your task is to implement the verilog module for the 4-bit binary counter with parallel load functionality.
