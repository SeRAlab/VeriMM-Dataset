Design a 1-bit DRAM cell that can store a bit of data. The cell should have the following inputs and outputs:
1. `data_in`: The data to be written to the cell (1 bit)
2. `write_enable`: A control signal to enable writing to the cell (1 bit)
3. `data_out`: The data output from the cell (1 bit)
4. `reset`: A signal to reset the cell to 0 (1 bit)

The operation should be as follows: 
- When `write_enable` is high, the `data_in` value should be stored in the cell.
- When `reset` is high, the cell should be reset to 0 regardless of the `write_enable`.
- Otherwise, the cell should retain its previous value.
