Please act as a professional Verilog designer.

Implement a dual-port RAM module with separate read and write addresses and a data width of 8 bits. The RAM should have 256 locations and support synchronous read and write operations on the rising edge of the clock.

Module name:
    dual_port_ram

Parameter:
DATAWIDTH = 8
ADDRWIDTH = 8

Input ports:
    clk: Clock signal used for synchronous operation.
    we: Write enable signal.
    write_addr: 8-bit input signal [ADDRWIDTH-1:0] representing the write address.
    read_addr: 8-bit input signal [ADDRWIDTH-1:0] representing the read address.
    din: 8-bit input signal [DATAWIDTH-1:0] representing the data to be written.

Output ports:
    dout: 8-bit output signal [DATAWIDTH-1:0] representing the read data.
