

You are tasked with designing a module that takes in a 4-bit input signal `in_signal` and produces a 3-bit output signal `out_signal`.
The output signal is to be generated according to the following rules:
- If the input signal is less than 4, the output signal should be equal to the input signal.
- If the input signal is between 4 and 7 (inclusive), the output signal should be equal to the input signal minus 1.
- If the input signal is greater than 7, the output signal should be equal to the input signal minus 2.

Write a Verilog module that implements the above rules and takes in a single input signal `in_signal` and produces a single output signal `out_signal`.
