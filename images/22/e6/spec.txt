
Design a 16-bit SRAM cell that can store a 16-bit data word. It should have the following inputs and outputs:
- Inputs: 
  - clk (clock)
  - wr_en (write enable)
  - addr (4-bit address)
  - data_in (16-bit input data)
- Outputs:
  - data_out (16-bit output data)

When wr_en is high, the data_in value should be written to the memory location specified by addr at the rising edge of clk. When wr_en is low, the data_out should reflect the value stored at the address addr.
