
Create a Verilog module that acts as a packet filter for a simple firewall. The module should accept a 16-bit packet, a 4-bit protocol identifier (0-15), and a 1-bit enable signal. It should output a 1-bit signal indicating whether the packet is allowed (1) or blocked (0). The packet is allowed if the protocol is 1, 2, or 3 and the enable signal is high. If the protocol is 0, or if the enable signal is low, the packet is blocked.
