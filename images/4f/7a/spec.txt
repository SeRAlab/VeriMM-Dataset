Design a circuit that performs a shuffling operation on three signed 32-bit input values (valX, valY, valI) based on a 2-bit selector input (kind). The outputs (valA, valB, valC) are assigned different combinations of these inputs depending on the value of kind: for kind=00, it outputs valX, valY, valI; for kind=01, it outputs valX, valI, valY; for kind=10, it outputs valI, valX, valY; and for kind=11, it outputs a zero followed by valX and valI. This module essentially functions as a configurable output selector for the provided inputs.
module top_module(input[1:0] kind, input signed[31:0] valX, valY, valI,output reg signed[31:0] valA, valB, valC);
