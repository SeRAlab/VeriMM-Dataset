Design an NVMe controller command queue manager that can store up to 8 commands. The module should take a clock signal, a reset signal, a command input, a command valid signal, and a command complete signal. When a command is received and valid, it should be pushed to the command queue. The command complete signal should allow the module to pop commands from the queue, making them available for processing. The design should maintain the state of the queue and output the current command at the head of the queue.
