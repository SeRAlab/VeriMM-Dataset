
Design an 8-bit AES encryption module that performs the following operations:
1. The module should take an 8-bit plaintext input and a 8-bit key input.
2. It should perform a simple round of AES encryption which includes:
   - Byte substitution using a predefined S-box.
   - Row shifting (for 8 bits, it's a single byte shift).
   - Mix columns (in a simplified manner).
3. The output should be an 8-bit cipher text.
4. Implement a reset functionality to initialize the state.
