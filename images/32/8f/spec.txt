Design an 8-bit ADC (Analog to Digital Converter) that converts a 4-bit binary input to an 8-bit output. The 4-bit input represents a voltage level ranging from 0 to 15, where each step corresponds to 16 levels of an 8-bit output representing a range from 0 to 255. The conversion can be done by multiplying the 4-bit input by 16 to scale it to an 8-bit value.
