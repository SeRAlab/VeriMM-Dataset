Design a JK flip-flop in Verilog. The flip-flop should have inputs J, K, clock (clk), and reset (rst). The outputs should be Q (the current state) and Qn (the inverted state). The flip-flop should reset to 0 when rst is high. The state should change on the rising edge of clk according to the rules: if J=1 and K=0, Q should be set to 1; if J=0 and K=1, Q should be set to 0; if J=1 and K=1, Q should toggle; if J=0 and K=0, Q remains unchanged.
