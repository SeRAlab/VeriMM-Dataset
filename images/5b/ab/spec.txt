Design a simple synchronous memory module with read and write capabilities, supporting a 32-bit data width. The module features a reset signal that initializes the memory array of 1024 bytes to zero upon activation. It allows writing four consecutive bytes to the memory when the write enable signal (MEM_W_EN) is asserted, utilizing the provided address adjusted for an offset. Concurrently, it can read four bytes from the specified address into a 32-bit output when the read enable signal (MEM_R_EN) is asserted. The memory is organized as an array of 8-bit registers, facilitating word-wide data handling.
