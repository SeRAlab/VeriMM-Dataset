Design a FIFO (First-In-First-Out) queue with a depth of 4. The FIFO should have the following inputs: `clk` (clock), `rst` (reset), `enq` (enqueue signal), `deq` (dequeue signal), and `data_in` (input data). It should have one output `data_out` (output data) which gives the dequeued data. The FIFO should maintain a count of the number of elements, and it should not allow enqueue operations if the FIFO is full or dequeue operations if it is empty.
