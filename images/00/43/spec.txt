Design a Verilog module that interfaces with an SD card. The module should take a 4-bit command input and produce a 4-bit response output based on a predefined command-response table. The commands and their corresponding responses are: 
- Command 0: Response 1
- Command 1: Response 2
- Command 2: Response 3
- Command 3: Response 4
- Commands 4 to 15: Response 0 (default response for unrecognized commands).
