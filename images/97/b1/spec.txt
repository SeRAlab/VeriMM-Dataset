Design a 4-to-1 multiplexer that selects one of four input lines to output based on a 2-bit selection signal. The module takes a 4-bit input vector and a 2-bit selector; depending on the value of the selector, it outputs one of the four input values. When the selector is 00, it outputs the first input; 01 selects the second input; 10 selects the third input; and 11 selects the fourth input.
module top_module(
    input [3:0] I,
    input [1:0] S,
    output O
);
