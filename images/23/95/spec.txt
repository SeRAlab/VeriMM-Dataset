Design a Verilog module that performs matrix inversion for a 2x2 matrix. The module should take a 2x2 matrix as input and produce the inverse of the matrix as output. The inversion formula for a 2x2 matrix [[a, b], [c, d]] is given by (1/(ad-bc)) * [[d, -b], [-c, a]], provided that the determinant (ad-bc) is not zero.
