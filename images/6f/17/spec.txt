Design a 4-bit up/down counter that increments or decrements its count based on a direction input. When the reset signal is active, the counter resets to zero. If the direction is set to high, the counter counts up, rolling over from 15 back to 0. If the direction is low, the counter counts down, rolling over from 0 back to 15.
module top_module(
  input clk,
  input reset,
  input direction,
  output reg [3:0] count
);
