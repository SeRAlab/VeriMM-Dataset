
Design a 4-bit DRAM cell that can perform read and write operations. The cell should have the following inputs: 
- `data_in` (4 bits): data to be written to the cell.
- `we` (1 bit): write enable signal (1 to write, 0 to read).
- `clk` (1 bit): clock signal for synchronization.
- `data_out` (4 bits): data read from the cell.

The cell should retain its value after a write operation until another write occurs, and it should output the stored value when read.
