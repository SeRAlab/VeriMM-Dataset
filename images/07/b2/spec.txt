
Design a 3-bit linear voltage regulator control circuit that takes in a 3-bit input voltage (V_in) and produces a 3-bit output voltage (V_out) based on the following logic:
- If V_in is less than 3, set V_out to 3.
- If V_in is greater than or equal to 3 and less than 6, set V_out to V_in.
- If V_in is 6 or greater, set V_out to 6.
