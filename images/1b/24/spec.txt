Design a hazard detection unit for a 5-stage pipelined processor. The unit should detect data hazards caused by read-after-write (RAW) situations when the same register is read and written in different pipeline stages. The inputs to the hazard detection unit will be the register addresses used in the Write and Read operations, as well as control signals indicating if the operations are occurring in the execution stage or further down the pipeline. The output should be a signal indicating if a hazard is detected, and if so, it should also indicate which stage it originates from.
