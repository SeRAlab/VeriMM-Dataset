
Design a Verilog module that implements a simple Support Vector Machine (SVM) classifier. The classifier should take a 2D input feature vector (x1, x2) and a set of weights (w1, w2) and a bias (b). The module should output a single bit indicating the class to which the input belongs. Use the following decision function:
If (w1 * x1 + w2 * x2 + b) > 0, output 1; else output 0.
