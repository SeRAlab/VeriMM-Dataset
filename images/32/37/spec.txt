Design an 8-bit SRAM cell with read and write capabilities. The cell should have the following inputs: a 8-bit data input (`data_in`), a 1-bit write enable signal (`we`), a 1-bit read enable signal (`re`), and a clock signal (`clk`). It should output the 8-bit data output (`data_out`). When `we` is high, the input data should be written to the memory cell on the rising edge of the clock. When `re` is high, the data stored in the cell should be available at the output.
