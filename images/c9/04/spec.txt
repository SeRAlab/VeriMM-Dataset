

You are tasked with designing a Verilog module that takes in a 36-bit input and outputs a 36-bit output. The output is generated by taking the input and performing a bitwise AND operation with a 36-bit constant value. The constant value is defined as a parameter in the module and is set to be `0x0000FFFFF`.

Design a Verilog module that takes in a 36-bit input and performs the above operation to generate a 36-bit output.

Your module should be named `bitwise_and` and have the following port:

- `input [35:0] in`
- `output [35:0] out`

You should also define a parameter named `CONSTANT_VALUE` which is set to `0x0000FFFFF`.
