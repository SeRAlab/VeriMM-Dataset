Design a simple 4-bit calculator module that performs addition and subtraction based on a selected operation mode. When the mode input is 0, the module computes the sum of inputs A and B, and when the mode input is 1, it computes the difference (A - B) and inverts the result. The output Y reflects the result of these operations, defaulting to zero if an unrecognized mode is encountered.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input mode,
    output reg [3:0] Y
);
