Design a D flip-flop with an asynchronous reset and a load input. The module captures the input data `d` on the rising edge of the clock `clk` when the `ld` (load) signal is high, allowing for dynamic data storage. If the `reset` signal is asserted, the output `q` is asynchronously reset to LOW regardless of the clock or load conditions. This design is intended for use in synchronous digital circuits where low-latency data storage and control over when to capture or reset stored data is required.
