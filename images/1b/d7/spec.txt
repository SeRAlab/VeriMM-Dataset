Design a Verilog module that simulates a simple Flash memory cell. The cell should support operations for reading, writing, and erasing. The input signals are `clk`, `wr_enable`, `erase_enable`, `data_in`, and `read_out`. The memory cell should have a state that indicates if it is programmed (1) or erased (0). The operations should be as follows: On the rising edge of `clk`, if `erase_enable` is high, the cell should be erased (set to 0). If `wr_enable` is high, the cell should store the value of `data_in`. On read, `read_out` should reflect the current state of the cell. The output should be synchronized with the clock.
