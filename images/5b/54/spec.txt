Design a 4-bit adder/subtractor circuit. The module takes two 4-bit inputs (in0 and in1) and a control input (SUB) to determine the operation mode. When SUB is low (0), the circuit performs addition, outputting the sum of in0 and in1. When SUB is high (1), it computes the subtraction of in1 from in0 by adding in0 and the two's complement of in1. The result is provided as a 4-bit output (out).
module top_module(
    input [3:0] in0,
    input [3:0] in1,
    input SUB,
    output reg [3:0] out
);
