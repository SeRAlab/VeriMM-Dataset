Design a simple EEPROM cell in Verilog. The EEPROM cell should allow for the following operations: Write, Read, and Erase. The Write operation should store a 1-bit value in the cell, the Read operation should retrieve the stored value, and the Erase operation should reset the cell to 0. The input control signals for Write, Read, and Erase should be provided, along with the input data for Write operations.
