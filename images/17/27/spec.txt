
Design a 32-bit timer that counts up from zero. The timer should have the following inputs:
1. `clk`: Clock input
2. `reset`: Asynchronous reset input (active high)
3. `start`: Start counting input (active high)

The timer should increment its count on the rising edge of `clk` if `start` is high and `reset` is low. If `reset` is high, the timer should reset to zero. The timer's current count should be output as a 32-bit value.
