Design a synchronous, resettable data latch. This module captures the input data (D) on the rising edge of the GATE signal while allowing for an active-low reset (RESET_B) that clears the output (Q) when asserted. When GATE is low, the output Q is driven to zero, effectively disabling the retention of input data. The design ensures that data is only updated when the GATE is high, thus functioning as a controlled latch with reset capability.
