- RESET_B: the asynchronous reset input (active low)
- SET_B: the asynchronous set input (active low)

The circuit should have the following output:

- Q: the output

The circuit should be designed using only one module within 200 lines of Verilog code. You can use the provided code snippet as a reference for creating your module.

Your task is to complete the implementation of the D flip-flop with asynchronous reset and set inputs. You should ensure that the circuit meets the following requirements:

- When RESET_B is asserted, the output Q should be set to 0.
- When SET_B is asserted, the output Q should be set to 1.
- When neither RESET_B nor SET_B is asserted, the output Q should follow the input D on the rising edge of the clock CLK.
