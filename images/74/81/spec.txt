Design a 3-to-8 line demultiplexer that routes a single data input (Y) to one of eight outputs (I) based on a 3-bit select input (SEL) when an enable signal (EN) is asserted. When EN is high, the output corresponding to the value of SEL is driven by the input Y, while all other outputs remain inactive.
module top_module(
    input [2:0] SEL,
    input EN, Y,
    output [7:0] I
    );
