

You are tasked with designing a module that takes in two inputs `A` and `B`, and outputs a value `C` that is the result of performing a bitwise XOR operation on `A` and `B`. You should implement this module using only combinational logic.

Your module should be named `XOR_GATE` and should have the following interface:

```
module XOR_GATE (
    input A,
    input B,
    output C
);
```

The inputs `A` and `B` are single-bit values, and the output `C` should also be a single-bit value.

You should ensure that your module is synthesizable and that it can be implemented using only basic logic gates such as AND, OR, and NOT gates.
