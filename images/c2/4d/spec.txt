

You are tasked with designing a verilog module for a 4-input majority gate. The module should take in 4 inputs, A, B, C, and D, and output the majority value of the inputs. The majority value is defined as the value that appears more than half the time. In the case of a tie, the output should be 0. 

You should create a module named `majority_gate` that has the following ports:
- `input A, B, C, D`
- `output X`

You can assume that all inputs are binary values (0 or 1).

You should use the following template for your module:

```
module majority_gate (
    // input ports
    ,
    ,
    ,
    ,
    // output ports
    ,
);

    // your code goes here

endmodule
```
