Implement a one-bit D Flip-Flop with an enable feature and asynchronous reset. On the rising edge of the clock, if the reset signal is asserted, the output is set to LOW. If the reset is not asserted and the clock enable is active, the output is set to HIGH. If the clock enable is not active, the previous state of the output is retained.
