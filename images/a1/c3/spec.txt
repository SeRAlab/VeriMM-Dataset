Design a parameterized binary decoder with enable functionality. The module takes a binary input and produces a one-hot output, where the active output corresponds to the binary value of the input, provided that the enable signal is asserted. If the enable signal is low, all outputs will remain low, effectively disabling the decoder. The parameters allow for customization of the bit-width of the input and the size of the output, facilitating flexibility in various applications.
