Design a 4-channel DMA controller that allows data transfer from one memory block to another. The controller should have the ability to enable or disable each of the four channels and must include a clock input and a reset input. Each channel has a request input (req), an acknowledge output (ack), and a data bus for transferring data. The controller should prioritize the channels based on their request signals, giving priority to channel 0, then channel 1, and so on.
