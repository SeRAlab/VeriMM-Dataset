Design a synchronous 8-bit up counter that increments its count output when a rising edge on the 'in' input is detected, provided the 'reset' input is not active. The counter periodically resets to zero when the 'reset' signal is asserted. The design also incorporates edge detection for the 'in' signal, ensuring that the count increments only on the first rising edge of 'in' following a low state.
module top_module(
    input wire clk,
    input wire reset,
    input wire in,
    output reg [7:0] count_out
);
