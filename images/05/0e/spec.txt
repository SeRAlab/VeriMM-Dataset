Design a simple 2D Support Vector Machine (SVM) decision boundary circuit that takes two input values (x1, x2) and outputs a binary classification (0 or 1). The decision boundary can be represented by the equation: y = w1*x1 + w2*x2 + b, where weights w1 and w2 and bias b are predefined constants. The circuit should output 1 if y > 0, and 0 otherwise.
