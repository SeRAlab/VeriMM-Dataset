Design a 4-bit up/down counter that increments or decrements its count based on the input control signal `up_down`. When `up_down` is high, the counter increments on each clock pulse, while if `up_down` is low, it decrements. The counter can be reset to zero asynchronously with the `rst` signal. Additionally, a parallel load feature is implemented where the counter can be set to a specific value via the `data_in` input when the `load` signal is asserted. The current count is output through the `q` signal.
module top_module(
    input clk,
    input rst,
    input up_down,
    input load,
    input [3:0] data_in,
    output reg [3:0] q
);
