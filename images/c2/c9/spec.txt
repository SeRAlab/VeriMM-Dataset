As a professional Verilog designer, create a pipelined module that implements a 16-bit barrel shifter. The module should have two inputs (data and shift_amount) and one output (shifted_data). 
The shift_amount input should be a 4-bit unsigned value that determines the number of bits to shift the data input to the left. If the shift_amount input is greater than 15, the output should be 0. If the shift_amount input is less than or equal to 15, the output should be the data input shifted to the left by the number of bits specified by the shift_amount input. 
Use pipeline structure to achieve this functionality.
