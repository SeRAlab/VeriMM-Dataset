Please act as a professional verilog designer.

Create a Verilog module for a 4-bit synchronous binary counter with an enable signal and a synchronous reset signal. The counter increments by 1 on each clock cycle when enabled and resets to zero when the reset signal is active.

Module name:  
    binary_counter  

Input ports:
    clk: Chip clock signal.
    rst: Active-high reset signal. Defined as 1 for chip reset and 0 for reset signal inactive.
    en: Enable signal for the counter.

Output ports:
    q: Counter output signal with a data width of 4 bits.

Implementation:
Counter operation:
On every positive edge of the clock signal (clk), the counter register (q) is updated.
If the reset signal (rst) is high, the counter register (q) is set to 0.
If the enable signal (en) is active, the counter increments by 1.
If the enable signal (en) is inactive, the counter remains unchanged.
