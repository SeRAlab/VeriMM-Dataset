

You are tasked with designing a verilog module that implements a 4-bit synchronous counter. The counter should increment on the rising edge of the clock input and should reset to zero when a reset input is asserted. The counter output should be displayed on four output wires.

You are given the following code snippet as a starting point:

```
module synchronous_counter (
    input wire clk,
    input wire reset,
    output wire [3:0] count
);

// your code here

endmodule
```

Using this code snippet, implement a synchronous counter that meets the requirements stated above. Your solution should include:

1. A declaration for a 4-bit register to hold the current count value.
2. A combinational logic block that increments the count register on the rising edge of the clock input.
3. A synchronous reset block that resets the count register to zero when the reset input is asserted.
4. A continuous assignment statement that assigns the value of the count register to the count output wires.
