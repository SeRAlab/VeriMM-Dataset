
Design a temperature sensor controller that takes a 5-bit binary input representing temperature in Celsius (0 to 31 degrees) and outputs a 1-bit signal indicating if the temperature exceeds a threshold value of 25 degrees. The output should be registered on the rising edge of a clock signal. If the temperature exceeds 25 degrees, the output should be set to 1; otherwise, it should be set to 0. The design should also have an asynchronous reset input that will clear the output to 0.
