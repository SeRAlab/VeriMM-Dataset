Design a 32-bit configurable up counter that increments its value on each positive edge of the clock. The counter resets to zero when the reset signal is high or when it reaches a specified count limit, which is provided as a 32-bit input. This design can be used in applications requiring a count-up operation with a defined maximum threshold.
module top_module(
	input clk,
	input rst,
	input [31:0] count_limit,
	output reg [31:0] count_value
);
