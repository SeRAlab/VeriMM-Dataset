
Design a Verilog module to perform LU decomposition of a 2x2 matrix. Your module should take a 2x2 matrix as input and output the lower triangular matrix (L) and upper triangular matrix (U). The input matrix will be defined as:
```
A = | a11 a12 |
    | a21 a22 |
```
The output matrices will be:
```
L = | 1     0   |
    | l21  1   |

U = | u11  u12 |
    | 0     u22 |
```
Where:
- l21 = a21 / a11
- u11 = a11
- u12 = a12
- u22 = a22 - l21 * u12
