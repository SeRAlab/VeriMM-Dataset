Implement a simple Control and Status Register (CSR) interface for a processor. The module always indicates it is ready to accept CSR operations (eai_csr_ready = HIGH) and provides a constant output of zero for any read operation (eai_csr_rdata), regardless of the input address or write commands. The design includes inputs for validation, address, write enable, and data, along with clock and reset signals but does not perform any actual read or write operations.
