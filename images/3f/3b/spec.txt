Design a 3-to-8 decoder with enable input. The decoder should take a 3-bit input (A2, A1, A0) and produce an 8-bit output (Y0 to Y7) based on the binary value of the input. If the enable input is low, all outputs should be zero. If the enable input is high, the output corresponding to the binary value of the input should be high (1), and all others should be low (0).
