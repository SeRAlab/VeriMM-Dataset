

You are tasked with designing a verilog module that implements a 4-bit synchronous up-counter with a synchronous reset input. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock signal
- `reset`: a synchronous reset signal

Outputs:
- `count`: a 4-bit output signal representing the current count value

The counter should increment on every rising edge of the clock signal, and the count value should reset to 0 when the reset signal is asserted.

Use the following code snippet as a template to implement the module:

```
module up_counter_4bit
   (count,
    clk,
    reset);
  output reg [3:0] count;
  input clk, reset;

  // Your code here

endmodule
```
