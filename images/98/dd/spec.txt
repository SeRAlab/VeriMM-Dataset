Design a 4-bit barrel shifter that allows for right and left shifting of input data. The module takes a 4-bit input (data_in) and a 2-bit shift control signal. Based on the value of the shift control, the module outputs the original data (no shift), shifts the data left by one position with a zero inserted at the least significant bit, shifts the data right by one position with a zero inserted at the most significant bit, or shifts the data right by two positions.
module top_module(
    input [3:0] data_in,
    input [1:0] shift,
    output [3:0] data_out
);
