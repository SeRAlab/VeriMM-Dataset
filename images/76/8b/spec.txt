If sel_b1 is 1 and the secondary select line (sel_b2) is 0, the output will be the value of input 'b'. If both select lines are high (sel_b1 = 1 and sel_b2 = 1), the output will be the logical OR of inputs 'a' and 'b'.
module top_module(
    input a,
    input b,
    input sel_b1,
    input sel_b2,
    output reg out_always   
);
