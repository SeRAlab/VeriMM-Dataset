Module name:  
    up_down_counter_3bit  

Input ports:
    clk: Chip clock signal.
    rst_n: Active-low reset signal. Defined as 0 for chip reset and 1 for reset signal inactive.
    up_down: Control signal. Defined as 1 for count up and 0 for count down.

Output ports:
    count: 3-bit count value.

Implementation:
On every positive edge of the clock signal (clk) or the falling edge of the reset signal (rst_n), the counter value is updated.
If the reset signal (rst_n) is low, the counter value is set to 0.
If the control signal (up_down) is high, the counter increments by 1.
If the control signal (up_down) is low, the counter decrements by 1.
