

You are tasked with designing a module that implements a 2-to-1 multiplexer (MUX) with two 8-bit inputs and one 1-bit select input. The module should have one 8-bit output that is selected based on the value of the select input. If the select input is 0, the output should be equal to the first input. If the select input is 1, the output should be equal to the second input.

Design a Verilog module that implements this 2-to-1 MUX and test it using the provided testbench. The testbench instantiates the MUX module and provides two 8-bit inputs and a select input to the MUX. The testbench initializes the inputs to 0 and waits for 100 ns before setting the select input to 1 and waiting for another 100 ns. Finally, the select input is set back to 0.

Your Verilog module should be named "mux2_1" and should have the following ports:
- input1 (8-bit input)
- input2 (8-bit input)
- select (1-bit input)
- selected_out (8-bit output)

Your module should be able to synthesize on FPGA.
