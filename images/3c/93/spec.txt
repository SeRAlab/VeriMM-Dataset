Design a Verilog module that implements a simple SD card interface controller. This controller needs to handle a read and write operation. The controller should have an input for a command signal (`cmd`), a clock signal (`clk`), and a reset signal (`reset`). Based on the command, the controller should toggle an output signal (`sd_busy`) indicating if the SD card is busy processing a command. When the command is a read (`cmd` = 1), `sd_busy` should be set high for 3 clock cycles. When the command is a write (`cmd` = 0), `sd_busy` should be high for 5 clock cycles. The module should also handle the reset, which should clear the `sd_busy` signal.
