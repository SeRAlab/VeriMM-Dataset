Design an interrupt controller that handles two types of interrupts: maskable and non-maskable. The controller should have inputs for two interrupt requests (irq1, irq2), a mask signal (mask), and a clock signal (clk). When a non-maskable interrupt is received, it should be serviced immediately, regardless of the mask status. If a maskable interrupt is received and unmasked, it should be serviced on the next clock cycle. The output should indicate which interrupt was serviced (output_irq).
