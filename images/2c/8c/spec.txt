Design a simple memory allocator that can allocate and free memory blocks. The memory manager will have the following inputs:
- `request`: a request signal to allocate or free memory
- `size`: the size of the memory block to allocate or free
- `free`: a signal to indicate if the operation is a free operation (1 for free, 0 for allocate)

The output will be an `allocated` signal indicating whether the allocation was successful or not. The memory manager should keep track of allocated memory and ensure that it does not allocate more than the available memory.
