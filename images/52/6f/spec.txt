Design a 6-bit shift register with load and reset functionalities. On a positive clock edge, if the reset signal is low, the register outputs zero; otherwise, if the load signal is high, it stores the input data. If neither reset nor load is asserted, the register performs a right circular shift of its current value, moving the most significant bit to the least significant bit position. The output reflects the current state of the register.
module top_module(
  input clk,
  input reset,
  input load,
  input [5:0] data,
  output [5:0] q
);
