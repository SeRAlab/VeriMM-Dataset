Implement a synchronous 32-entry register file that supports read operations based on a 5-bit address input. The module captures the address and, on each positive edge of the clock, retrieves a 16-bit data value corresponding to the specified address. The values are predefined for addresses 0 through 31, with each address mapping to a specific 16-bit constant. The output data updates in a two-stage pipeline, with the current output reflecting the value from the previous clock cycle, allowing for efficient sequential data processing.
