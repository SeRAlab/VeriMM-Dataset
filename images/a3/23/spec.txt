Design a synchronous counter circuit that increments or decrements a 4-bit count value based on the UP_DOWN input signal. When RESET is asserted, the count resets to zero. The parity bit for the count is calculated using XOR, and this parity bit is stored separately. The output Q is conditionally assigned: when SELECT is high, Q outputs the current count value; when SELECT is low, Q outputs the parity bit as the least significant bit while the other bits are zero. The module effectively combines counting, parity calculation, and conditional output selection.
module top_module(
    input CLK, RESET, UP_DOWN, SELECT,
    input [3:0] in,
    output reg [3:0] Q,
    output parity
);
