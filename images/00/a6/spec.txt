
Design a FIFO (First-In-First-Out) queue in Verilog. The FIFO should have the following parameters:
- The depth of the FIFO (number of entries).
- A data width that specifies the size of each entry.
- It should support the following operations:
  - Enqueue: to add an element to the end of the queue.
  - Dequeue: to remove an element from the front of the queue.
  - A full flag to indicate when the queue is full.
  - An empty flag to indicate when the queue is empty.
The FIFO should also have a clock and reset signal.
