Design a Verilog module that models a simple linear voltage regulator. The regulator should take an input voltage (Vin) and produce an output voltage (Vout) that is a fixed fraction of the input voltage. The fraction can be represented as a 3-bit binary value (control signal) that determines the gain of the regulator. The output voltage should be calculated as: Vout = Vin * (Control Signal / 8). The module should also include a ready signal that indicates when the output voltage is stable and ready for use.
