Design a Run-Length Encoding (RLE) module in Verilog that takes a stream of binary input data and encodes it into run-length format. This module should be able to handle a maximum of 8 bits of input data and encode it in a way that the output contains pairs of values: the first value being the length of the run (1 to 8) and the second being the binary value of the run (0 or 1). The encoding should reset after each complete run is processed.
