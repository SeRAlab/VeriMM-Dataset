Design a traffic light controller that manages the operation of a traffic signal at an intersection. It features three output states: red, yellow, and green lights, controlled via a clock signal and a reset input. The system begins in a reset state, displaying a red light. Depending on the elapsed time indicated by a counter, it transitions through the green and yellow states. If a pedestrian button is pressed, the green light duration is adjusted to accommodate pedestrian crossing needs. This controller operates with specific timing rules to ensure safe and efficient traffic flow.
module top_module(
  input clk,
  input reset,
  input pedestrian_button,
  output reg red,
  output reg yellow,
  output reg green
);
