Design a state-space controller in Verilog that has a 2-bit state register and takes a 2-bit input signal. The controller should have the following states: 00 (Idle), 01 (Processing), 10 (Complete), and 11 (Error). The transitions between states are defined as follows: 
- If in Idle (00) and input is 01, transition to Processing (01).
- If in Processing (01) and input is 10, transition to Complete (10).
- If in Complete (10) and input is 11, transition to Error (11).
- If in Error (11) and input is 00, return to Idle (00).
- For any other cases, remain in the current state.
