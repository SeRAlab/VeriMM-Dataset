

You are tasked with designing a module that takes in a 4-bit binary input `A` and outputs a 4-bit binary value `Y`. The output `Y` should be the binary value of the input `A` shifted left by 2 bits. For example, if `A` is `0101`, then the output `Y` should be `010100`. 

Your module should be named `shift_left_2` and should have the following module ports:
- `input [3:0] A`: a 4-bit binary input
- `output [3:0] Y`: a 4-bit binary output

Your module should also have the following internal signals:
- `wire [5:0] shifted_A`: a 6-bit wire to hold the shifted value of `A`

You are required to write the Verilog code for this module.
