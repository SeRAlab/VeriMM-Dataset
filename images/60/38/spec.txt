Design a serial transmission module that converts an 8-bit parallel input into a serial output. The module operates on a clock signal, with the ability to reset its internal state and load new data upon receiving the load signal. When loaded, the module initializes a shift register containing the parallel input followed by a zero, and it begins shifting out bits serially, starting with the least significant bit, while maintaining a count to control the shifting frequency. The output 'serial_out' reflects the serialized data, and an 'empty' signal indicates when the shifting process has completed and the module is in a ready state. The design includes state management to facilitate operational transitions between data loading and shifting phases.
module top_module(clk, reset, load, empty, parallel_in, serial_out);
