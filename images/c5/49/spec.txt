

You have been tasked with designing a verilog module for a 4-to-1 multiplexer using behavioral modeling. The module should have four input ports, one output port, and two control ports. The output port should be connected to one of the four input ports based on the values of the control ports as follows:

- If Sel1 and Sel2 are both 0, the output should be connected to In0
- If Sel1 is 0 and Sel2 is 1, the output should be connected to In1
- If Sel1 is 1 and Sel2 is 0, the output should be connected to In2
- If Sel1 and Sel2 are both 1, the output should be connected to In3

Design the verilog module for the 4-to-1 multiplexer and name it "mux4to1". Ensure that the inputs and outputs are named as follows:

- Four input ports: In0, In1, In2, In3
- Two control ports: Sel1, Sel2
- One output port: Out
