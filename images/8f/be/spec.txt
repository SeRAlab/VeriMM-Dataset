Implement a Verilog module for a 4-bit shift register. The shift register should have a clock input `clk`, an asynchronous reset input `reset`, a data input `d`, and a 4-bit data output `q`. The shift register should shift its contents to the left on every rising edge of the clock, with `d` being shifted in at the least significant bit.

module shift_register(
	input wire clk,
	input wire reset,
	input wire d,
	output reg [3:0] q
);
