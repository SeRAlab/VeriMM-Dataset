
Create a 4-bit DRAM cell that allows writing and reading of data. The DRAM cell should have a write enable signal (WE), a clock signal (CLK), a 4-bit data input (DATA_IN), and a 4-bit data output (DATA_OUT). When WE is high on a rising edge of the clock, the data from DATA_IN should be stored in the memory. When WE is low, the data from the memory should be output to DATA_OUT on the next rising edge of the clock.
