Design a 2-to-1 multiplexer that selects between two 8-bit inputs, `a` and `b`. The selected input is concatenated with eight zero bits to produce a 16-bit output, `mux_out`. When the select signal `sel` is 0, the output will be the value of `a` padded with zeros; when `sel` is 1, the output will be the value of `b` padded with zeros.
module top_module(
  input [7:0] a,
  input [7:0] b,
  input sel,
  output reg [15:0] mux_out
);
