Please act as a professional verilog designer.

Design a Verilog module for a 5-bit up/down counter with a control signal. The counter increments its value on the rising edge of the clock when the control signal is high, and decrements its value when the control signal is low.

Module name:  
    counter_5bit  

Input ports:
    clk: Chip clock signal.
    ctrl: Control signal for up/down counting.

Output ports:
    count: Counter output signal with a data width of 5 bits.

Implementation:
Counter operation:
On every positive edge of the clock signal (clk), the counter (count) is incremented if the control signal (ctrl) is high. If the control signal is low, the counter is decremented.
