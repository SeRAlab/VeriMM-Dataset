Design a 4-bit ripple carry adder that computes the sum of two 4-bit inputs, `in0` and `in1`, along with a carry-in input. The module outputs the resulting 4-bit sum while also indicating if a carry-out occurs when the sum exceeds the maximum value representable by 4 bits (i.e., 15). The carry-out signal is set high if an overflow occurs during addition.
module top_module(
    input [3:0] in0,
    input [3:0] in1,
    input carry_in,
    output reg [3:0] sum,
    output reg carry_out
);
