
Design a Verilog module for a 1-bit Flash memory cell. The Flash memory cell should have the following inputs and outputs:
- Input: `write_enable` (1-bit), `data_in` (1-bit)
- Output: `data_out` (1-bit)

The Flash memory cell should behave as follows:
- When `write_enable` is high (1), the `data_in` value should be stored in the cell and output on `data_out`.
- When `write_enable` is low (0), the last stored value should be retained and output on `data_out`.
