Design a Verilog module for a linear voltage regulator that takes an input voltage and produces an output voltage. The module should have the following parameters:
- Input Voltage (Vin)
- Output Voltage (Vout)
- Enable signal (EN) to turn on/off the regulator

The output voltage should be a scaled version of the input voltage based on a gain factor specified in the module (for instance, Vout = Vin * Gain). For simplicity, assume Gain can be set to 1, 2, or 3 (as an integer). The module should only produce an output voltage when EN is high. If EN is low, the output voltage should be 0. Include proper handling for inputs and outputs.
