
Create a FIFO queue with the following specifications:
1. The queue should have a width of 8 bits and a depth of 4.
2. The queue should support two operations: enqueue and dequeue.
3. The enqueue operation should take a data input and add it to the queue if there is space.
4. The dequeue operation should remove data from the queue if it is not empty.
5. The queue should have a full and empty flag.
