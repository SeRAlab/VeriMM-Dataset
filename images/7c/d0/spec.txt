Please act as a professional verilog designer.

Design a Verilog module for an 8-bit register with synchronous set and clear signals. The register stores data on the rising edge of the clock and sets or clears the stored value based on the set and clear signals.

Module name:  
    register_8bit  

Input ports:
    clk: Chip clock signal.
    set: Synchronous set signal.
    clr: Synchronous clear signal.
    data_in: Input data with a data width of 8 bits.

Output ports:
    data_out: Register output signal with a data width of 8 bits.

Implementation:
Register operation:
On every positive edge of the clock signal (clk), the register (data_out) is set to all 1s if the set signal (set) is active, cleared to all 0s if the clear signal (clr) is active, and otherwise stores the input data (data_in).
