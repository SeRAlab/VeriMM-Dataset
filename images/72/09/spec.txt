Design a four-bit adder-subtractor circuit that takes two 4-bit inputs (A and B) along with a control input (C) to determine the operation. When C is low (0), the circuit computes the sum of A and B; when C is high (1), it calculates A minus B by adding the two's complement of B. The output is a 5-bit result (S) that includes the sum or difference along with a carry-out bit, effectively allowing the operation to be properly represented in a wider bit-width format.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input C,
    output [4:0] S
);
