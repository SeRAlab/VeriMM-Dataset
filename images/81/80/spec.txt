Design a circuit for a 4-bit signed subtractor that calculates the difference between two 4-bit inputs A and B. Additionally, it includes a control signal C that, when asserted (C = 1), allows for the computation of the two's complement of the result, effectively enabling subtraction of B from A or adding B to A depending on the value of C. The output is a 5-bit wide result to accommodate potential overflow.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input C,
  output reg [4:0] diff
);
