Design a 2-bit binary adder that computes the sum of two 2-bit inputs, A and B. The module generates a 2-bit output, S, representing the sum with the least significant bit (LSB) calculated by XORing the corresponding bits of A and B, and the most significant bit (MSB) computed using the carry from the LSB addition. Additionally, the module outputs a carry-out signal, C, which indicates an overflow that occurs when the sum exceeds the maximum representable value for 2 bits.
module top_module(
  input [1:0] A,
  input [1:0] B,
  output [1:0] S,
  output C
);
