Design a 4-to-1 multiplexer that takes four single-bit inputs (a, b, c, d) and selects one of them to output based on a 2-bit selection signal (s). The output (y) will correspond to the input indicated by the binary value of s: when s=00, output a; when s=01, output b; when s=10, output c; and when s=11, output d. In the event of an invalid selection, the output is set to LOW (0).
module top_module(
    input  wire a,
    input  wire b,
    input  wire c,
    input  wire d,
    input  wire [1:0] s,
    output reg y
);
