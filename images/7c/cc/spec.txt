Design a 32-bit wide calculator capable of performing arithmetic operations based on a two-bit operation selector. The module accepts two 32-bit inputs, a and b, and an operation selector op that determines the operation to execute: addition for 00, subtraction for 01, multiplication for 10, and division for 11. The result of the operation is output as a 32-bit value c, with a safeguard to output zero if the operation code is invalid.
module top_module(
    input [31:0] a,
    input [31:0] b,
    input [1:0] op,
    output reg [31:0] c
);
