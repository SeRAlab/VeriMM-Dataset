Design a simple 8-bit shift register with parallel load functionality. The shift register should shift left on each clock cycle if the shift enable signal is high. If the load enable signal is high, the register should load the parallel input data on the rising edge of the clock.

Module name:
    ShiftRegister
Input ports:
    clk: Clock signal used for synchronous operation.
    load: Load enable signal.
    shift_en: Shift enable signal.
    parallel_in: 8-bit input for parallel loading.

Output ports:
    serial_out: 1-bit output for serial data output.
