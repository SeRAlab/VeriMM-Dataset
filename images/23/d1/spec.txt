Design a SR flip-flop using Verilog that has two inputs (S and R) and one output (Q). The flip-flop should hold its state unless the S or R inputs are activated. When S is activated, the output Q should be set to 1, and when R is activated, the output Q should be reset to 0. If both S and R are inactive, the output Q should retain its previous state. In case both S and R are active simultaneously, the output should be undefined.
