
Design a Verilog module for an Echo Cancellation system that takes an input signal and a reference signal to produce an output signal. The module should implement a simple adaptive filter using the Least Mean Squares (LMS) algorithm. The output signal should be the result of subtracting the filtered reference signal from the input signal. The adaptation of the filter coefficients should happen on every clock cycle based on the error signal calculated from the difference between the input and the filtered reference.
