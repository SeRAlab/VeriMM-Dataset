 Design a 4-to-2 priority encoder with active high inputs. The priority encoder should output a 2-bit binary number corresponding to the highest-priority input that is active (i.e., high). If no inputs are active, the outputs should be set to 0. The encoder has four inputs (I0, I1, I2, I3) and two outputs (Y1, Y0). The priority is from I3 (highest) to I0 (lowest).
