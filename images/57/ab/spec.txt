Design a one-bit wide, 2-to-1 multiplexer. The module outputs in0 when the select signal (sel) is 0 and outputs the negation of in1 when sel is 1. The design employs logic gates to achieve this functionality, utilizing inverters and AND/OR gates to conditionally combine the inputs based on the select signal.
module top_module(
    input in0,
    input in1,
    input sel,
    output out
);
