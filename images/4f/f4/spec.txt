Design a 4-bit adder/subtractor that performs addition or subtraction based on the value of the input control signal 'sub'. When 'sub' is low, it computes the sum of inputs 'a' and 'b'; when 'sub' is high, it computes the difference between 'a' and 'b'. The output 'sum' represents the lower 4 bits of the result, while 'overflow' indicates if the operation resulted in an overflow condition, either from the addition exceeding the 4-bit limit or from the subtraction resulting in a negative value.
module top_module(
    input [3:0] a,
    input [3:0] b,
    input sub,
    output reg [3:0] sum,
    output overflow
);
