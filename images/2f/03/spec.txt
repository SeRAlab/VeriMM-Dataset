Implement a simplified version of the ChaCha20 stream cipher's quarter round function. The function takes four 32-bit inputs and produces four 32-bit outputs. The quarter round function operates on the inputs as follows:  
1. Add the first input to the second input.
2. Rotate the result of the second input left by 16 bits.
3. Add the result of step 2 to the third input.
4. Rotate the result of step 3 left by 12 bits.
5. Add the result of step 4 to the fourth input.
6. Rotate the result of step 5 left by 8 bits.
7. Add the result of step 6 to the first input.
8. Rotate the result of step 7 left by 7 bits.  
The output will be the modified values of the four inputs after applying the quarter round function.
