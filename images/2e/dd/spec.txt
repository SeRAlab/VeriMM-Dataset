Design a reset controller that manages a reset signal for a finite state machine (FSM). The FSM has three states: IDLE, RUN, and ERROR. The reset controller should take an asynchronous reset signal and a clock input. When the reset is asserted, the FSM should transition to the IDLE state. The FSM should operate normally when the reset is deasserted. If an error condition occurs, the FSM should transition to the ERROR state. The outputs should indicate the current state of the FSM.
