Design a simple SPI controller that can transmit and receive data. The controller should have a clock input (clk), a reset input (reset), a data input (data_in), a data output (data_out), chip select (cs), and a ready signal (ready). The controller should operate in a way that when cs is low, data can be shifted in on the rising edge of the clock. When cs goes high, the data_out should reflect the data that was shifted in, and the ready signal should be asserted.
