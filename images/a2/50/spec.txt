Design a 4-bit binary adder that conditionally adds two 4-bit inputs, `a` and `b`, along with a carry-in (`cin`). The `ctrl` input determines the operation mode: when `ctrl` is high (1), it performs the addition of `a`, `b`, and `cin`, producing a 4-bit sum output and a carry-out (`cout`); when `ctrl` is low (0), it bypasses the addition and simply outputs `a` while providing the carry-out as the carry-in value (`cin`).
module top_module(
  input [3:0] a,
  input [3:0] b,
  input cin,
  input ctrl,
  output [3:0] sum,
  output cout
);
