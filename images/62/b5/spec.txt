Design a Pulse Width Modulation (PWM) controller that drives an LED based on a 4-bit input. The module accumulates the PWM input over clock cycles and utilizes the most significant bit of a 5-bit register to control the LED state. When the accumulated value in the register exceeds a certain threshold, the LED turns ON; otherwise, it remains OFF, resulting in a brightness effect that corresponds to the PWM input.
