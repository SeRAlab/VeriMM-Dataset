Design a reset controller that manages a reset signal for a system. The reset controller should have an active-high reset input (`reset_in`), a reset enable input (`reset_enable`), and a reset output (`reset_out`). The reset output should remain high (`1`) when `reset_in` is high or when `reset_enable` is high. The reset output should go low (`0`) when both inputs are low. The controller should also have a clock input (`clk`) to synchronize the output changes.
