
Design a Verilog module that computes the logistic regression function for a given input vector and weights. The module shall take a 5-bit input vector (x0, x1, x2, x3, x4) and a 5-bit weight vector (w0, w1, w2, w3, w4). The output should be a single bit that indicates whether the computed probability (after applying the sigmoid function) is greater than or equal to 0.5. The logistic function is defined as:
P(y=1|x) = 1 / (1 + exp(-z)) where z = w0*x0 + w1*x1 + w2*x2 + w3*x3 + w4*x4.
