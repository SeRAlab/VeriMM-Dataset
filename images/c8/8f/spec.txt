

You are tasked with designing a verilog module that takes in three input signals A1, A2, and A3, and two additional input signals B1 and C1. The module should output a single signal X. 

The module should be named "my_module" and should use the following syntax:

```
module my_module (
    input A1,
    input A2,
    input A3,
    input B1,
    input C1,
    output X
);
```

Your task is to write the verilog code for the my_module module that meets the following specifications:

1. If A1 is high, the output X should be high.
2. If A1 is low and A2 is high, the output X should be high.
3. If A1 and A2 are low and A3 is high, the output X should be high.
4. If none of the above conditions are met, the output X should be low.

You may assume that the input signals A1, A2, A3, B1, and C1 are all single-bit signals.
