Design a synchronous 32-bit register that captures input data on the rising edge of the clock when enabled. It features a reset input to initialize the register to zero and a start signal to conditionally load the data from `data_in` into the register only if the `sync` signal is asserted. The output, `data_out`, reflects the stored value in the register, ensuring that data is only updated based on the clock signal and control inputs.
module top_module(
input  [31:0] data_in, 
input          clk, clk_en,    
input          reset,start,  
input          sync,    
output [31:0] data_out 
);
