Design a flip-flop that captures the value of the input signal 'in' on the rising edge of the clock 'clk'. The flip-flop is asynchronously reset by the 'reset' signal; when 'reset' is LOW, the output 'out' is set to 0, irrespective of the clock signal. Once the reset is HIGH, the flip-flop will store the value of 'in' at each rising edge of 'clk', ensuring that 'out' reflects the latest valid input.
module top_module(
  input reset,
  input clk,
  input in,
  output out
);
