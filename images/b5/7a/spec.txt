Design a 7-bit up/down counter that increments the count on the rising edge of the clock when the 'up' input is high and decrements the count when the 'cross_h' input is asserted, provided the count is above zero. The counter is limited to a maximum value of 99. The current count is available at the output.
module top_module(
    input clk,
    input up,
    input cross_h,
    output [6:0]count
);
