Design a 4-bit up/down counter with reset functionality. Upon receiving a clock signal, the counter increments its value when the UP input is high, wrapping back to zero at 15 (4'b1111). Conversely, when the UP input is low, the counter decrements its value, wrapping back to 15 when it reaches zero (4'b0000). The counter resets to zero when the RST input is asserted.
module top_module(
    input CLK,
    input RST,
    input UP,
    output reg [3:0] OUT
);
