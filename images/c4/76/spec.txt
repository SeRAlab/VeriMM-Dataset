

You have been tasked with designing a module that implements a D flip-flop with asynchronous reset and set inputs. The module should have the following inputs and outputs:

- `CLK`: clock input
- `D`: data input
- `RESET`: asynchronous reset input (active low)
- `SET`: asynchronous set input (active low)
- `Q`: output
- `QN`: complement of output

The module should follow the following specifications:

- The output `Q` should follow the input `D` when the clock is rising edge.
- When the reset input is asserted (`RESET` = 0), the output `Q` should be set to 0.
- When the set input is asserted (`SET` = 0), the output `Q` should be set to 1.
- The output `QN` should be the complement of `Q`.
- The module should have setup and hold times of 2ns for all inputs.

Write the code for the D flip-flop module.
