Design a synchronous random-access memory (RAM) module with 32 locations, where each location can store an 8-bit value. On the positive edge of the clock or the negative edge of the reset signal, the module initializes predefined values at specific addresses. If the reset signal is low, the RAM is populated with these initial values; if reset is high and write enable (writeEn) is asserted, the module writes the input data (dataIn) to the specified address. If write enable is not asserted, it outputs the value stored at the specified address to ramOut.
