Design a 2-to-1 multiplexer for 32-bit wide data inputs. The module selects between two 32-bit inputs, IN0 and IN1, based on the value of the SEL signal. When SEL is low (0), the output OUT is assigned the value of IN0; when SEL is high (1), OUT takes the value of IN1. This functionality allows for conditional data routing based on the selection signal.
module top_module(
    input SEL,
    input [31:0] IN0,
    input [31:0] IN1,
    
    output reg [31:0] OUT
    );
