Design a 4-bit shift register with a clear and load capability. On the rising edge of the clock, if the clear (CLR) signal is active, both the output (Q) and next state (Q_next) are reset to zero. If the load (LOAD) signal is active, the register takes the 4-bit input (D) and loads it into both Q and Q_next. Otherwise, the module shifts the current contents of Q to the left by one bit, with the most significant bit being replaced by the most significant bit of D, effectively implementing a left shift operation.
module top_module(
    input CLK,
    input LOAD,
    input CLR,
    input [3:0] D,
    output reg [3:0] Q,
    output reg [3:0] Q_next
);
