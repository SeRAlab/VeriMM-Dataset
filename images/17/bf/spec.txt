Design a FIFO queue that can hold up to 8 8-bit data entries. The FIFO should have the following interfaces: 
1. `push`: a signal that indicates when to push data into the queue.
2. `pop`: a signal that indicates when to pop data from the queue.
3. `data_in`: an 8-bit input data to be pushed into the FIFO.
4. `data_out`: an 8-bit output data to be popped from the FIFO.
5. `full`: a flag to indicate when the FIFO is full.
6. `empty`: a flag to indicate when the FIFO is empty.
The FIFO should operate in a first-in, first-out manner.
