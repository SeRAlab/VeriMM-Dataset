Design a 4-bit two's complement converter. The module takes a 4-bit input A and, on each positive clock edge, updates an internal register A_reg with the value of A unless a reset signal is active, in which case A_reg is set to zero. The output B provides the two's complement of the value stored in A_reg, calculated by inverting A_reg and adding one.
