Design a combinational logic circuit that provides various basic logical operations on three input signals (a, b, c). The module outputs fixed true and false values, and computes the results for several combinations of AND, OR, and NOT operations: three AND outputs (from different combinations of the inputs), three OR outputs (also from various combinations), and two NOT outputs (inverting the first two input signals). This module serves as a foundational building block for more complex digital circuits involving basic logical functions.
module top_module(
    input a,
    input b,
    input c,
    output true_val,
    output false_val,
    output and1,
    output and2,
    output and3,
    output or1,
    output or2,
    output or3,
    output not1,
    output not2
);
