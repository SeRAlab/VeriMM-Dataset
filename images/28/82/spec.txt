
Design a 2-channel DMA (Direct Memory Access) controller in Verilog. The controller should have two channels, each capable of transferring data independently. Each channel should have a request (req) and acknowledge (ack) signal. The DMA controller should prioritize channel 1 over channel 2. When both channels have a request, channel 1 should be served first. The controller should also have a busy signal indicating whether it is currently transferring data.
