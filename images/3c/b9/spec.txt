Design a UART transmitter that sends 8 bits of data serially. The transmitter should have the following inputs: a clock signal (clk), a reset signal (rst), a start signal (start), and an 8-bit data input (data_in). When the start signal is asserted, the transmitter should begin sending the data serially at a baud rate determined by the clock. The output should be a serial data line (tx). The transmitter should also indicate when it is busy sending data.
