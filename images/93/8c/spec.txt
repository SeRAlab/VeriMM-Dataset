Design a Verilog module for a simple 4-bit up/down counter that increments or decrements based on the `up_down` control signal. The counter should increment when `up_down` is high and decrement when `up_down` is low. The counter should reset to 4'b0000 when the `reset` signal is high. Assume the counter operates on the positive edge of the clock.

module counter_module (
        input clk,
        input reset,
        input up_down,
        output reg [3:0] count);
