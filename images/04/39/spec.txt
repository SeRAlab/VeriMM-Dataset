
Design a Cyclic Redundancy Check (CRC) module in Verilog. The CRC polynomial used is \( x^3 + x^2 + 1 \). The input is a 4-bit data value, and the output is a 3-bit CRC checksum. The module should compute the CRC checksum as the data is provided in a serial fashion. The CRC computation should be clocked, and the module should have a reset that initializes the state.
