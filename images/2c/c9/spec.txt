 Design a data forwarding unit for a simple 5-stage pipeline. The forwarding unit should determine if a value from a previous instruction can be forwarded to the current instruction based on the register addresses being used. The inputs will be the destination register of the previous instruction and the source registers of the current instruction. The outputs will be the signals indicating which forwarding paths are available. Implement a forwarding unit that checks for the following: 
1. Forwarding from the first EX stage to the second EX stage. 
2. Forwarding from the second EX stage to the second EX stage.
You need to create a module that takes in the destination register of the previous instruction and the source registers of the current instruction, and outputs signals for forwarding paths.
