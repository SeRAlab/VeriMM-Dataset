Design a 4-register memory module that allows for reading and writing 1-bit wide data. Each of the four registers can be written to when the corresponding enable signal is active (EN_write_x). On each clock cycle, the module either updates the registers with the provided input values or resets them to a defined reset value when the reset signal (RST_N) is low. The current values of the registers are available for reading through designated output signals (read_x).
module top_module(
    CLK,
    RST_N,
    read_0,
    write_0,
    EN_write_0,
    read_1,
    write_1,
    EN_write_1,
    read_2,
    write_2,
    EN_write_2,
    read_3,
    write_3,
    EN_write_3
);
