
Design a Watchdog Timer in Verilog. The timer should count clock cycles and reset if it does not receive a reset signal within a specified timeout period. The timer should have the following inputs:
- clk: clock signal
- rst: active-high reset signal
- enable: active-high enable signal for the watchdog timer
- timeout: a number of clock cycles after which the timer resets if no reset occurs

The outputs should be:
- timeout_expired: active-high signal indicating that the timeout period has expired
