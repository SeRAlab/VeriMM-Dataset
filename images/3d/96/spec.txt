Design a simple WiFi module status decoder that takes a 3-bit status input representing different states of a WiFi module and outputs a corresponding 2-bit code. The status input has the following encoding: 
- 000: Off
- 001: Connecting
- 010: Connected
- 011: Error
- 100: Disconnecting
- 101: Unknown

The output codes are defined as:
- 00: Module Off
- 01: Module Connecting
- 10: Module Connected
- 11: Module Error/Disconnecting/Unknown (for simplicity, we group these states)
