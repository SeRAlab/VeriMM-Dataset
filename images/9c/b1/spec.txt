Design a one-bit wide, 4-to-1 multiplexer. The output 'o' is determined by the 2-bit select input 's'; when 's' is 00, the output is 'i0'; when 's' is 01, the output is 'i1'; when 's' is 10, the output is 'i2'; and when 's' is 11, the output is 'i3'.
module top_module(
		output o,
		input [1:0]s,
		input i0,i1,i2,i3);
