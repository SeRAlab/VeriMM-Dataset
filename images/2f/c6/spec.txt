Design a 2-channel DMA controller that can transfer data from a source address to a destination address. The DMA controller should have two channels, allowing it to operate on two separate transfers simultaneously. The controller should have the following inputs: a clock signal (clk), a reset signal (rst), channel select (sel), source address (src_addr), destination address (dst_addr), and start signal (start). The outputs should indicate when data is being transferred (transfer_active) and which channel is currently active (active_channel).
