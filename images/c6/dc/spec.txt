

You have been tasked with designing a verilog module for a 2-to-1 multiplexer. The module should have two input signals, A and B, and one output signal, Y. The module should also have a select signal, SEL, which will determine which input signal is passed through to the output signal. If SEL is 0, then A should be passed through to Y. If SEL is 1, then B should be passed through to Y. 

Design the verilog module for the 2-to-1 multiplexer and ensure that it meets the following requirements:
- The module should be named `mux2to1`.
- The input signals should be named `A`, `B`, and `SEL`.
- The output signal should be named `Y`.
- The module should be synthesizable.
- The module should be able to handle both rising and falling edge clock signals.
