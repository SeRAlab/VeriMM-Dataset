Design an 8-bit binary adder circuit that computes the sum of two 8-bit inputs (a and b) along with a carry-in input (cin). The addition operation is performed on the rising edge of the clock, and the result is registered in a flip-flop, allowing for synchronous operation. The module also has an active reset input (rst) to clear the sum to zero when asserted. The output includes both the 8-bit sum and a carry-out signal (cout) indicating if there was an overflow from the most significant bit.
module top_module(input [7:0] a, input [7:0] b, input cin, input rst, input clk, output [7:0] sum, output cout);
