
Design a 16-to-4 priority encoder in Verilog. The encoder should have 16 input lines (I0 to I15) and 4 output lines (O3 to O0) representing the binary value of the highest priority input. The highest priority input is I15, and the lowest is I0. If no input is active, the outputs should be undefined (you can choose to set them to 4'bXXXX).
