Design a 1-bit SR flip-flop with asynchronous reset. The flip-flop should have inputs S (Set), R (Reset), and CLK (Clock), and an output Q. The behavior should be as follows: when CLK is high, if S is high, Q should be set to 1; if R is high, Q should be reset to 0; if both S and R are low, Q retains its previous state. The reset input (R) should override the set input (S) when both are high, and the output should reflect the state of Q. The asynchronous reset should reset Q to 0 regardless of the clock state when R is high.
