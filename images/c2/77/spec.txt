

You are tasked with designing a Verilog module that takes in a 4-bit input signal `a` and outputs a 4-bit signal `b`. The output signal `b` is the result of a bitwise XOR operation between the input signal `a` and a constant 4-bit value `c`.

Design a Verilog module that takes in a 4-bit input signal `a` and outputs a 4-bit signal `b`. The module should include the following:
- A 4-bit input port named `a`
- A 4-bit output port named `b`
- A 4-bit constant value named `c` that is set to `4'b1011`
- A combinational logic block that performs the XOR operation between `a` and `c` and assigns the result to `b`

Your Verilog module should be named `xor_module`.
