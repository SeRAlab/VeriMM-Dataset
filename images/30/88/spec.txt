
Design an 8-bit Analog-to-Digital Converter (ADC) functionality in Verilog that takes an 8-bit input representing an analog voltage level and converts it to a 4-bit digital output. The conversion process should consider a simple mapping where the output is the upper 4 bits of the input. The ADC should also include a validation mechanism to ensure the input is within the acceptable range (0 to 255). If the input exceeds this range, the output should be set to zero.
