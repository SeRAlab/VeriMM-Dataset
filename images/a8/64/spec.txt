Design a D latch with asynchronous reset functionality. The latch captures the input data (D) on the rising edge of the gate signal (GATE) when the clock (CLK) is active. The output (Q) reflects the state of D, while Q_N outputs the complemented state. The RESET_B input allows for asynchronous clearing of the latch; when RESET_B is LOW, it sets Q to LOW regardless of the clock or data inputs. This module provides controlled data storage with an ability to reset the output independently.
module top_module(
    input D,
    input RESET_B,
    input GATE,
    input CLK,
    output Q,
    output Q_N
);
