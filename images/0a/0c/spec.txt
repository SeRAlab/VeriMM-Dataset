
Design a packet filtering firewall circuit in Verilog that checks incoming packets based on predefined rules. The input is a packet with a source IP address (32 bits), destination IP address (32 bits), and a protocol (8 bits). The circuit outputs a decision signal (1 bit) indicating whether to allow (1) or deny (0) the packet based on the following filtering rules:
1. Allow packets from source IP `192.168.1.1` to any destination IP with protocol `TCP`.
2. Deny packets from source IP `10.0.0.1` to destination IP `172.16.0.1` with any protocol.
3. Allow all other packets.
