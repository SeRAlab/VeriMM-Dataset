Design a 3-bit up/down counter that operates on the rising edge of the clock signal. The counter has a load input that, when asserted, initializes the output to a random value. If the load signal is not active, the counter increments its output when the up_down control signal is high and decrements its output when up_down is low.
module top_module(
    input clk,
    input load,
    input up_down,
    output reg [2:0] out
);
