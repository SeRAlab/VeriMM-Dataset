Design a 4-to-1 multiplexer that selects one of four 1-bit input signals (in0, in1, in2, in3) based on a 2-bit select input (sel). The output (out) reflects the value of the selected input, determined by the sel input; if sel is 00, out is set to in0, 01 to in1, 10 to in2, and 11 to in3. An unspecified default case outputs a LOW signal.
module top_module(in0, in1, in2, in3, sel, out);
