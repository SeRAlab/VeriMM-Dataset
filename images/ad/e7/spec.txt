Design a gated D flip-flop with active-low reset functionality. On the rising edge of the clock signal (CLK), the output nQ is set to the inverse of the input D. If the active-low reset signal (nRST) is asserted, the output nQ is immediately set to HIGH. The initial state of the output can be configured using the INIT parameter, allowing for flexible initialization.
