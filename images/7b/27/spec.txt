Design a 4-bit up/down counter that increments or decrements its count based on the direction control signal. When the reset signal is high, the counter resets to zero. The counter operates on the positive edge of the clock and only counts when the enable signal is high: if the direction signal is high, the counter increments; if low, it decrements.
module top_module(
    input clk,
    input rst,
    input en,
    input dir,
    output reg [3:0] count
);
