
Design a fan speed control system using a Verilog module. The system should have a 2-bit input to represent the desired speed level (00 for off, 01 for low, 10 for medium, 11 for high) and a clock input. The system should output a 2-bit current speed level. The speed level should change on the rising edge of the clock based on the input. If the input is "00", the output should remain "00" (off). The output should be updated with the input value on each clock cycle.
