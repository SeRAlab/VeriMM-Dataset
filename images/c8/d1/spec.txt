

You are tasked with designing a Verilog module that implements a clock gate with an enable signal and a data input. The module should have a single output that is the input data gated by the clock and the enable signal. The module should only be one module within 200 lines of Verilog code.

The module should be named "clock_gate_en" and have the following inputs and outputs:

Inputs:
- clk: a single bit input representing the clock signal
- en: a single bit input representing the enable signal
- data_in: a single bit input representing the data signal to be gated

Outputs:
- data_out: a single bit output representing the gated data signal

The module should have the following functionality:
- When the enable signal is low, the output data should be low, regardless of the clock signal or the input data signal.
- When the enable signal is high and the clock signal is low, the output data should be low, regardless of the input data signal.
- When the enable signal is high and the clock signal is high, the output data should be the same as the input data signal.

You may assume that the input signals are clean and free of glitches.
