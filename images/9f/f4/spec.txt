Implement a simple synchronous dual-port RAM (Random Access Memory) module designed for 32-bit data words and 16-bit address space. The module retrieves data from memory using two separate address inputs (addr_a and addr_b) while allowing for data writes on addr_b when the write enable signal (data_b_we) is asserted, provided that the address is within a specific range (0x0000 to 0xFFFF). It outputs the corresponding data for each address on data_a and data_b outputs while providing a strobe signal (strobe_b) to indicate valid access to memory. The circuit is clocked by a rising edge of clk and reset functionality is planned through an input, enabling proper initial conditions when required.
