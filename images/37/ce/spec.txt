Design a simple SATA controller state machine that manages the data transmission states: Idle, Sending, and Receiving. The controller should have the following behavior: it starts in the Idle state, transitions to Sending when a 'send' signal is asserted, and transitions to Receiving when a 'receive' signal is asserted. If in the Sending state and 'send' is de-asserted, it should return to Idle. If in the Receiving state and 'receive' is de-asserted, it should also return to Idle. The state machine should output the current state as a 2-bit value, where Idle = 00, Sending = 01, and Receiving = 10.
