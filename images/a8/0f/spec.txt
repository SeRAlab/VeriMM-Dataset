Design a digital potentiometer circuit that adjusts an output voltage based on a 4-bit digital input value (d_val). The resistance value is determined through a combinational logic that maps specific digital inputs to corresponding resistance values, consequently influencing the output voltage (v_out) when the clock signal (clk) is active. The output voltage is calculated as a fraction of the total resistance based on the selected resistance value multiplied by a defined step size. Additionally, the circuit includes a reset functionality that sets the output voltage to zero upon receiving a reset signal, ensuring controlled initialization.
module top_module(
  input [3:0] d_val,
  input clk,
  input reset,
  output reg v_out
);
