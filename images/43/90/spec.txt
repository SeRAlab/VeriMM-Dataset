Implement the Verilog module based on the following description.
We want to create a module that:

// (1) receives a 4-bit binary number,
// (2) determines if the number is greater than or equal to 8,
// (3) sets the output 'is_geq_8' to 1 if the number is greater than or equal to 8, otherwise 0,
// (4) provides a reset mechanism to reset the output.

// The input binary number is available on the input signal 'binary_num'. The reset signal is active high synchronous.

module geq_8_check_module(
    input wire clk,
    input wire reset,
    input wire [3:0] binary_num,
    output reg is_geq_8
);
