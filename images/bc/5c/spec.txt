Implement the Verilog module based on the following description.
We want to create a module that:

// (1) receives a 4-bit binary number,
// (2) checks if the number is greater than or equal to 10,
// (3) counts the number of 1s in the binary number,
// (4) outputs a flag if the number is a perfect square,
// (5) provides a reset mechanism to reset all outputs.

// The input binary number is available on the input signal 'binary_num'. The output 'is_gte10' should be set to 1 if the number is greater than or equal to 10 and 0 otherwise. The number of 1s in the binary number should be output on 'count_ones[2:0]'. The perfect square flag should be set on 'is_perfect_square' if the number is a perfect square. The reset signal is active high synchronous.

module top_module(
    input wire clk,
    input wire reset,
    input wire [3:0] binary_num,
    output reg is_gte10,
    output reg [2:0] count_ones,
    output reg is_perfect_square
);
