Design a circuit that implements a combination of logic gates. Specifically, it computes the logical AND of two input signals (IN1 and IN2), and then further ANDs the result with the inverted value of a third input signal (IN3). The final output, Q, is HIGH only when both IN1 and IN2 are HIGH, and IN3 is LOW.
module top_module(
    input IN1,
    input IN2,
    input IN3,
    output Q
);
