Please act as a professional verilog designer.

Design a Verilog module for a 32-bit ALU (Arithmetic Logic Unit) that performs addition, subtraction, and bitwise AND operations. The operation to be performed is selected using a 2-bit control signal.

Module name:  
    alu_32bit  

Input ports:
    A: 32-bit input operand A.
    B: 32-bit input operand B.
    ctrl: 2-bit control signal to select operation.

Output ports:
    result: 32-bit output result of the ALU operation.

Implementation:
ALU operation:
00: Perform A + B (addition).
01: Perform A - B (subtraction).
10: Perform A & B (bitwise AND).
