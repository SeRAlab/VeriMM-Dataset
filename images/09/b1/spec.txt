Design a JK latch using Verilog. The JK latch should have inputs J, K, and a clock signal, and it should output Q and Q_bar. The latch should have the following behavior: When the clock signal is high, if J and K are both low, Q remains unchanged; if J is high and K is low, Q is set to high; if J is low and K is high, Q is set to low; if both J and K are high, Q toggles.
