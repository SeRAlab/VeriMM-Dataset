Design a Verilog module that simulates a simple Network Address Translation (NAT) functionality. The NAT will handle a mapping of an internal IP address and port to an external IP address and port. The module should accept the internal IP address, internal port, and external IP address, and it should output the mapped external port. The internal IP address, internal port, and external IP address will be 32 bits, 16 bits, and 32 bits respectively. The NAT should maintain a simple table with at least 4 entries for active connections and handle basic mapping.
