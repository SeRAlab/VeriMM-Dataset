Design a binary decoder that converts a binary input address into a one-hot output. The decoder has an enable signal; when enabled, it sets one specific bit in the output bitline high based on the address value, while all other bits are set low. If the enable signal is low, the output will be entirely low regardless of the address input. The size of the address determines the number of output lines, as specified by the LOG_SIZE parameter.
module top_module(
    input [LOG_SIZE-1:0] address,
    input enable,
    output reg [(1<<LOG_SIZE)-1:0] bitline
);
