Design a 2-to-16 binary decoder that generates one active-low output line from the 16 available outputs based on the 2-bit input 'select' and an enable signal 'en'. When 'en' is low, the decoder activates the corresponding output line (active LOW) for each value of 'select' (00, 01, 10, or 11), while all other outputs remain inactive. If 'en' is high, all outputs will be inactive regardless of the 'select' input.
module top_module(
    input [1:0] select,
    input en,
    output [15:0] out
);
