

You are tasked with designing a Verilog module that implements a synchronized flip-flop circuit with four inputs and four outputs. The module should have the following inputs and outputs:

Inputs:
- `D` (4-bit input): Data input
- `CLK` (1-bit input): Clock input
- `AR` (1-bit input): Asynchronous reset input

Outputs:
- `Q` (4-bit output): Data output

The circuit should implement the following behavior:
- On every rising edge of the clock signal (`CLK`), the circuit should latch the value of the `D` input into the `Q` output.
- If the `AR` input is asserted (i.e. is logic 1), the circuit should reset the value of the `Q` output to 0.

Your task is to implement this circuit in a Verilog module named `synchronizer_ff`.
