Design an 8-bit Hamming encoder that takes an 8-bit data input and produces a 12-bit encoded output. The encoding must use Hamming (12, 8) code which adds 4 parity bits to the original 8 bits. The parity bits should be calculated based on the data bits to ensure that the encoded data can detect and correct single-bit errors. The output must be in the format of a 12-bit vector.
