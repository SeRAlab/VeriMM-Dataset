Design a 16-bit Digital-to-Analog Converter (DAC) module in Verilog. The DAC should take a 16-bit input signal and output a corresponding analog voltage level represented as a 16-bit binary value. The output should be scaled such that an input of `16'h0000` corresponds to `0V` and an input of `16'hFFFF` corresponds to `Vmax`, where `Vmax` is a defined constant (e.g., `5V`). The module should also include a simple enable signal that, when low, drives the output to `0V`.
