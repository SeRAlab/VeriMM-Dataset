Design a button checker circuit that identifies button press events among four inputs (Uin, Din, Lin, Rin) and generates corresponding output signals (Uout, Dout, Lout, Rout). Each output is high when its respective input is asserted while ensuring that no conflicting inputs are pressed simultaneously; for instance, Uout is high when Uin is pressed without Din being pressed, and similarly for the other outputs. This setup effectively acts as a simple state detector for button presses.
module top_module(
    input Uin,
    input Din,
    input Lin,
    input Rin,
    output Uout,
    output Dout,
    output Lout,
    output Rout
    );
