A Voltage-Controlled Oscillator (VCO) takes a control voltage as input and produces an output frequency that is proportional to the input voltage. Design a VCO module in Verilog that outputs a square wave with a frequency that varies based on a 4-bit control input. The frequency should have the following mapping: 0000 -> 1 Hz, 0001 -> 2 Hz, 0010 -> 4 Hz, ..., 1111 -> 16 Hz. Implement a counter that generates these frequencies based on a 100 Hz clock input.
