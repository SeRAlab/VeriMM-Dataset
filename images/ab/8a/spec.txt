Design a 4-to-1 multiplexer that selects one of four 1-bit inputs (A, B, C, or D) based on a 2-bit select signal formed by S1 and S0. The output Y reflects the selected input according to the value of the select lines: if S1S0 is 00, output A; if 01, output B; if 10, output C; and if 11, output D.
module top_module(
  input [3:0] A, B, C, D,
  input S0, S1,
  output reg Y
);
