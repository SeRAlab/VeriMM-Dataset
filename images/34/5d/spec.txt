Design a cache memory system that implements the Least Recently Used (LRU) and First-In-First-Out (FIFO) cache replacement policies. The cache should support operations for reading and writing data, and it should keep track of which cache line to replace based on the selected policy. The cache size is defined as 4 lines, and each line can hold one 8-bit data value. The input for the cache controller will be a write enable signal, an address for the data, and the data to be written. The output will be the data read from the cache and the cache status.
