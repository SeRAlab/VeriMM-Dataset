Design a circuit that generates a new program counter (newPC) based on the current program counter (CurPC) and control signals. The module can select between three operations depending on the value of the PCSrc input: (0) it outputs the address of the next sequential instruction (CurPC + 4); (1) it adds a sign-extended offset (ExtOut left-shifted by 2) to the sequential address; and (2) it forms a jump address by concatenating the upper portion of the sequential address with a 26-bit jump address, zero-filling the last two bits. This module serves as a key component in a control unit for managing instruction flow in a processor.
module top_module(
    input CLK,
    input [1:0] PCSrc,
    input [31:0] CurPC,
    input [31:0] ExtOut,
    input [25:0] JumpAddr,
    output reg [31:0] newPC
    );
