```
module four_bit_adder (
    input [3:0] a,
    input [3:0] b,
    input cin,
    output [3:0] sum,
    output cout
);

// your code here

endmodule
```

Your task is to complete the module with the necessary logic to implement a 4-bit adder that meets the above requirements.
