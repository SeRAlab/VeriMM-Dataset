Design a peripheral interface module that acts as a simple Avalon slave device for a configurable system. The module takes a 2-bit address input, chip select, clock, reset (active low), and write control signals to manage data transactions. When the chip is active and a write operation is initiated to address 0, it stores a 32-bit input data value. The output port consistently reflects the stored data, while the read operation outputs the data when queried. The design incorporates basic signal handling and reset functionality, making it suitable for automating light control mechanisms in an embedded system context.
module top_module(
  input [1:0] address,
  input chipselect,
  input clk,
  input reset_n,
  input write_n,
  input [31:0] writedata,
  output reg out_port,
  output reg [31:0] readdata
);
