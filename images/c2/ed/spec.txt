

Write a Verilog module that takes in two 8-bit unsigned inputs, `a` and `b`, and outputs their product, `p`. The output should be a 16-bit unsigned number. 

The module should have the following inputs and outputs:
- `a`: an 8-bit unsigned number
- `b`: an 8-bit unsigned number
- `p`: a 16-bit unsigned number

You may not use any built-in Verilog operators for multiplication or division.
