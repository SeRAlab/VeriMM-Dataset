Design a Verilog module that models a 10-bit decrementer with enable and asynchronous reset signals. The module should have an input clock signal (clk), an input enable signal (en), an input asynchronous reset signal (rst), and a 10-bit output signal (count). On the rising edge of the clock, if enable is high, count should decrement by 1. If reset is high, count should be set to 1023.
module decrementer (
  input clk,
  input en,
  input rst,
  output reg [9:0] count);
