Implement a 32-bit adder with carry-in and carry-out. The adder should output the sum of two 32-bit input data signals and a carry-out signal.

Module name:
    adder_32bit

Input ports:
    a: 32-bit input data A.
    b: 32-bit input data B.
    cin: carry-in signal.

Output ports:
    sum: 32-bit sum output.
    cout: carry-out signal.
