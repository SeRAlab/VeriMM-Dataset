Design a 4-bit arithmetic unit that performs addition or subtraction based on a control signal. When the control signal C is set to 1, the module computes the sum of the 4-bit inputs A and B; when C is 0, it calculates the difference by subtracting B from A. The result is stored in the output register Q.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input C,
    output reg [3:0] Q
);
