Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state I (output 1).
2. state J (output 0).
3. state K (output 1).
4. state L (output 0).

State transitions:
1. From state I: If x = 1, then transition to state J. If x = 0, then transition to state L.
2. From state J: If x = 1, then transition to state K. If x = 0, then transition to state I.
3. From state K: If x = 1, then transition to state L. If x = 0, then transition to state I.
4. From state L: If x = 1, then transition to state J. If x = 0, then transition to state I.

Assume that a one-hot code is used with the state assignment y[3:0] = 0001(I), 0010(J), 0100(K), 1000(L)

Write a Verilog for the signal Y1, which is the input of state flip-flop y[1], for the signal Y2, which is the input of state flip-flop y[2]. Derive the Verilog by inspection assuming a one-hot encoding.
