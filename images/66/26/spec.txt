Design a simple arithmetic calculator that performs various operations on two 8-bit inputs, A and B, based on a 3-bit operation selector (op). The operations include addition (op=000), subtraction (op=001), multiplication (op=010), and division (op=011), with a special condition to handle division by zero, outputting 0xFF in such cases. For any other input op values, the output C is set to zero.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input [2:0] op,
    output reg [7:0] C
);
