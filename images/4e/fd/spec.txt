Design a four-to-one multiplexer that selects one of four 8-bit data inputs (D0, D1, D2, D3) based on a combined selection signal formed by two input lines (S0 and S1). The output (Y) reflects the selected input, and in the event of an invalid selection, it defaults to 0. This configuration allows for flexible data routing within digital systems.
module top_module(
    input [7:0] D0,
    input [7:0] D1,
    input [7:0] D2,
    input [7:0] D3,
    input [2:0] S0,
    input [2:0] S1,
    output reg [7:0] Y
);
