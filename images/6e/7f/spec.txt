Design a 4-bit barrel shifter that allows for both left and right shifts of the input value A based on the control input B. When B is non-negative, the module performs a left shift on A by B positions; when B is negative, it performs a right shift on A by the absolute value of B. The output, result, reflects the shifted value.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output reg [3:0] result
);
