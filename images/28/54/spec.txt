
Design a simple OFDM modulator that takes an input data stream of 4 bits and produces 16 outputs. The modulator will map each 4-bit input to a corresponding 16-bit output by assigning 1 to the position of the input value and 0 to others. For example, an input of `0001` should produce an output of `0000000000000001`, `0010` should produce `0000000000000010`, and so on. The output should be valid after a clock cycle.
