Design a 8-to-1 multiplexer that selects one of eight 32-bit input data lines based on a 3-bit control signal. Each control value corresponds to one of the input data lines (i_data0 to i_data7), and the selected input is routed to the output (o_data). In the case of an invalid control signal, the output defaults to the first input (i_data0).
module top_module(
	i_data0,
	i_data1,
	i_data2,
	i_data3,
	i_data4,
	i_data5,
	i_data6,
	i_data7,
	i_ctrl,
	o_data
	);
