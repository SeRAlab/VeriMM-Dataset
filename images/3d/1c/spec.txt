
Design a simple interrupt controller that can handle multiple interrupt requests and provide a mechanism to acknowledge the interrupts. The controller should have the following specifications:
- It should accept 4 interrupt requests (IRQ0 to IRQ3) as inputs.
- It should include a single acknowledge signal (ACK).
- When an interrupt request is received, the controller should latch the interrupt request and set the corresponding interrupt acknowledge signal. The acknowledge signal should be toggled to indicate that the interrupt has been acknowledged.
- The output should show which interrupt was acknowledged through a 2-bit output signal (IRQ_ACK) that indicates the highest priority interrupt.

The priorities of interrupts are as follows: 
- IRQ0 has the highest priority, followed by IRQ1, IRQ2, and then IRQ3.

The controller should clear the acknowledged interrupt when the ACK signal is asserted.
