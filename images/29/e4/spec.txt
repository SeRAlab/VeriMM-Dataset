
Design a simple Ethernet MAC controller's state machine that handles the transmission of data frames. The state machine should have the following states: IDLE, TRANSMIT, and WAIT_FOR_ACK. The controller will transition between these states based on the input signals: `start_transmit`, `ack_received`, and `done_transmitting`. The output will indicate the current state and a `frame_sent` signal when in the TRANSMIT state.
