Design a 3-bit binary up-counter that increments on each positive edge of the clock signal (clk). If the reset signal (rst) is asserted, the counter resets to zero. The counter wraps around to zero after reaching its maximum value of 7 (3'b111). The current count value is reflected in the output (out).
module top_module(
    input clk,
    input rst,
    output reg [2:0] out
);
