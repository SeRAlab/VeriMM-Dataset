Design a control unit for an Arithmetic Logic Unit (ALU). This module takes a clock signal, a 2-bit ALU operation selector (alu_op), and a 6-bit function code (func) to generate a 3-bit ALU operation output (ALU_operation). The alu_op codes determine the general operation, while specific func codes specify detailed operations when alu_op is set to 2'b10. The module effectively routes the appropriate ALU operation based on the combination of inputs, enabling various arithmetic and logical functions such as addition, subtraction, and bitwise operations.
