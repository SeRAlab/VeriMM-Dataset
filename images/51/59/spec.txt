Develop a Verilog module for a 3-bit binary decoder. The module should take a 3-bit binary number as input and output an 8-bit one-hot encoded signal.

Write the Verilog code for the decoder module with the following signals:
- a: 3-bit input
- y: 8-bit output

module decoder3bit(
    input [2:0] a,
    output [7:0] y
);
