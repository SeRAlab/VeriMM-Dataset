Design a circuit that functions as a controlled 8-bit AND operation between two inputs. It uses two selection signals, sel_b1 and sel_b2, to determine which of the two 8-bit inputs (a or b) to select. If both sel_b1 and sel_b2 are high, the circuit selects input b; otherwise, it selects input a. The selected input is then ANDed with a 4-bit input c, resulting in an 8-bit output.
module top_module(
    input [7:0] a,
    input [7:0] b,
    input sel_b1,
    input sel_b2,
    input [3:0] c,
    output [7:0] out
);
