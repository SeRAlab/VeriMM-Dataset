Design a Verilog module that models a 14-bit Johnson counter with asynchronous reset and synchronous enable signals. The module should have an input clock signal (clk), an input enable signal (en), an input asynchronous reset signal (rst), and a 14-bit output signal (count). On the rising edge of the clock, if reset is high, count should be set to 0. If enable is high, the counter should rotate its bits to the left and invert the bit that is shifted in.
