
Design a simple NVMe controller state machine that handles three states: IDLE, READ, and WRITE. The controller should transition between these states based on a 2-bit input signal (`ctrl`). The signal `ctrl` defines the following operations: 
00 - IDLE, 
01 - READ, 
10 - WRITE, 
11 - RETURN TO IDLE. 
The state machine should output the current state as a 2-bit output (`state`).
