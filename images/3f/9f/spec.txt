Design a digital phase shifter that takes a 3-bit control input and generates a 3-bit output that represents the phase shift. The phase shifter should have a clock input and a reset input. On the rising edge of the clock, if the reset is active, the output should be set to zero. Otherwise, the output should be updated based on the current state and the control input, where each control value represents a specific phase shift. For example, control value 0 represents no shift, 1 represents a 120-degree shift, and so on, with wrap-around after reaching the maximum.
