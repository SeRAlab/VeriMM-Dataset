
You are tasked with designing a module that takes in 2 inputs, `data_in` and `control_in`, and produces 2 outputs, `data_out` and `control_out`. The `data_in` input is a 16-bit unsigned integer, and the `control_in` input is a 4-bit unsigned integer. The `data_out` output should be the result of adding 1 to the `data_in` input. The `control_out` output should be the `control_in` input shifted left by 1 bit. 

Design a module that implements this functionality. Your module should be named `data_control` and should have the following interface:

Inputs:
- `data_in`: a 16-bit unsigned integer
- `control_in`: a 4-bit unsigned integer

Outputs:
- `data_out`: a 16-bit unsigned integer
- `control_out`: a 4-bit unsigned integer
