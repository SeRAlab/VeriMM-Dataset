Design a 16-bit Arithmetic Logic Unit (ALU) capable of performing various operations based on a 4-bit command input. The module takes two 16-bit inputs, 'a' and 'b', and executes operations such as addition, subtraction, bitwise AND, OR, and XOR, as well as logical shifts and multiplication. The results of these operations are stored in two separate 16-bit output registers, 'rLeft' and 'rRight'. Additionally, the module includes an output signal 'zero' that indicates whether both output registers are zero, effectively functioning as a zero flag.
module top_module(
  input      [15:0] a,
  input      [15:0] b,
  input      [3:0]  cmd,
  output reg [15:0] rLeft,
  output reg [15:0] rRight,
  output zero
);
