
Design a 24-bit digital-to-analog converter (DAC) that takes a 24-bit binary input and produces an analog output corresponding to the binary value. The output should be a scaled version of the input, where the maximum 24-bit value (2^24 - 1) corresponds to a maximum output voltage (e.g., 5V). The DAC output can be represented as a 12-bit integer value that corresponds to the scaled voltage output.
