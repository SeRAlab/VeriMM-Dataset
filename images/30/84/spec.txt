
Design a simple Bluetooth control module that manages a connection state. The module should have a state machine with the following states: IDLE, CONNECTING, CONNECTED, and DISCONNECTED. The state transitions are triggered by the following input signals: 
- `start_connect` (to initiate connection), 
- `disconnect` (to terminate connection), 
- `connection_success` (to indicate successful connection). 

The module should output the current state as a 2-bit value.
