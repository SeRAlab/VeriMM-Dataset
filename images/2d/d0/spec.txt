Design a 16-bit ADC (Analog to Digital Converter) module in Verilog that takes a 12-bit input value and converts it into a 16-bit output value. The 12-bit input value represents the voltage level that should be scaled to fit in the 16-bit output range. The scaling factor should be determined based on a reference voltage of 3.3V, where the maximum 12-bit input value (4095) corresponds to the maximum output value (65535). Ensure the output is zero-padded on the lower bits to maintain the 16-bit width.
