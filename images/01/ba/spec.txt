
Design a 16-bit SRAM cell with write and read capabilities. The SRAM cell should have the following inputs and outputs:
- Inputs: `clk` (clock), `we` (write enable), `addr` (4-bit address), `d` (16-bit data input)
- Outputs: `q` (16-bit data output)
When `we` is high, the data `d` should be written to the address specified by `addr` on the rising edge of `clk`. When `we` is low, the data at the address specified by `addr` should be read and output to `q`.
