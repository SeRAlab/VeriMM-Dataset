Design a dual-port synchronous RAM module with a data width of 32 bits and an address space of 1024 locations. The module features two independent access ports (addr0 and addr1), allowing simultaneous reading and writing of data. When enabled (ce0), writing occurs to the RAM at addr0 with the provided data (d0) if the write enable (we0) is asserted; otherwise, it reads the stored value from the same address into output q0. The second port (addr1) allows reading from the RAM into output q1 when enabled (ce1). Both operations are synchronized to the rising edge of the clock signal.
