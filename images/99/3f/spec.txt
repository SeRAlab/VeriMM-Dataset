Design a Verilog module that models an 8-bit accumulator with an enable signal and an asynchronous reset signal. The module should have an input clock signal (clk), an input enable signal (en), an input asynchronous reset signal (rst), an 8-bit input data signal (d), and an 8-bit output signal (acc). On the rising edge of the clock, if reset is high, acc should be set to 0. If enable is high, acc should be incremented by the value of d.
module accumulator (
  input clk,
  input en,
  input rst,
  input [7:0] d,
  output reg [7:0] acc);
