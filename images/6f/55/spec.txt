Design a single-port SRAM (Static Random Access Memory) with a 32-bit wide data path, capable of reading and writing based on control signals. The output O provides the data read from memory, while input D represents the data to be written. The write enable (WE) and write clock (WCLK) signals control the memory operation, allowing data to be written to or read from addresses defined by the 5 input address lines (A0 to A4). The module accepts an initialization parameter for memory contents and includes an option to invert the write clock signal.
module top_module(
  output O,
  input  D, WCLK, WE,
  input  A0, A1, A2, A3, A4
);
