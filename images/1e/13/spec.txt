Design a state-space controller that takes a 3-bit binary input representing the state of a system and outputs a 3-bit control signal based on the current state and a control input. The controller should implement a simple state transition diagram defined by the following rules:
- If the current state is 000 (State 0), and the control input is 0, stay in State 0; if the control input is 1, transition to State 1.
- If the current state is 001 (State 1), and the control input is 0, transition to State 2; if the control input is 1, stay in State 1.
- If the current state is 010 (State 2), and the control input is 0, transition to State 0; if the control input is 1, transition to State 1.
- If the current state is 011 (State 3), and the control input is 0, transition to State 2; if the control input is 1, stay in State 3.
- If the current state is 100 (State 4), and the control input is 0, stay in State 4; if the control input is 1, transition to State 3.
- If the current state is 101 (State 5), and the control input is 0, transition to State 4; if the control input is 1, transition to State 5.
- If the current state is 110 (State 6), and the control input is 0, transition to State 5; if the control input is 1, transition to State 0.
- If the current state is 111 (State 7), and the control input is 0, transition to State 6; if the control input is 1, stay in State 7.
