Please act as a professional Verilog designer. Create a module that implements a 2-to-1 multiplexer with an enable signal. It has 3 input ports: 2 8-bit input ports (a, b) and a 1-bit enable port (en). It also has one 8-bit output port (out). It routes the value of one of the two inputs to the output port (out) based on the value of the enable port (en). The default value of the output is '0'. If en is 0, the output is assigned to '0'. If en is 1, the output is assigned to the input a if a is not '0', otherwise the output is assigned to the input b.
