Design a 3-to-1 multiplexer that selects one of three 32-bit input lines (ina, inb, inc) based on a 2-bit selection signal (sel). When sel is set to 00, output ina; when sel is set to 01, output inb; and when sel is set to 10, output inc. The output will be driven with the selected input value.
module top_module(input [31:0] ina, inb, inc,
              input [1:0] sel,
              output reg [31:0] out);
