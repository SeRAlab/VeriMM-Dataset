Design a 4-to-1 multiplexer with 8-bit wide outputs. The module uses a 2-bit select input (S) to choose between four 8-bit data inputs (A, B, C, D) and routes the selected input to the output (Y). The output corresponds to the data input that matches the value of S: when S=00, output A; S=01 selects B; S=10 selects C; and S=11 selects D.
