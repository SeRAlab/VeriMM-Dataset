Design a 1-bit DRAM cell in Verilog. The DRAM cell should be able to read and write a single bit of data. It should include a word line (WL), a bit line (BL), and the stored data (Q). The write operation is triggered when the Write Enable (WE) signal is active, and the read operation occurs when the WE signal is inactive. The cell should also have a reset functionality that sets the stored data to 0 when the reset signal is activated.
