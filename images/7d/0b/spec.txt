Construct a 4-bit binary subtractor that computes the difference between two 4-bit inputs, a and b. If a is greater than or equal to b, the output diff is the result of a minus b. If a is less than b, the output diff is the two's complement of the result of b minus a, effectively representing a negative difference in a 4-bit signed format.
module top_module(
    input [3:0] a,
    input [3:0] b,
    output reg [3:0] diff
);
