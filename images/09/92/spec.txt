
Design a 16-bit ADC (Analog-to-Digital Converter) controller in Verilog. The controller should take a 16-bit input signal and convert it to a 12-bit output signal. The conversion should include a simple scaling operation where the input is divided by 16 (right shift by 4 bits). The output should also include a valid signal that indicates when the output is ready. Additionally, implement a reset functionality that clears the output when activated.
