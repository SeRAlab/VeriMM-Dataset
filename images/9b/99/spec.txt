Design a one-bit wide, 2-to-1 multiplexer for 16-bit inputs. It selects between two 16-bit inputs (a_in and b_in) based on the value of the control signal sel. When sel is 0, the output (out) reflects the value of a_in; when sel is 1, out takes the value from b_in. If sel is neither 0 nor 1, the output defaults to 0.
module top_module(
    input wire sel,
    input wire [15:0] a_in,
    input wire [15:0] b_in,
    output reg [15:0] out
);
