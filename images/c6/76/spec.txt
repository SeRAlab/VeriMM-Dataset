Please act as a professional verilog designer. Create a module that implements a 4-bit synchronous counter with a parallel load input. The module should have two inputs, a 4-bit load input and a clock input. If the load input is high, the module should load the counter with the value of the load input on the next rising edge of the clock. Otherwise, the counter should increment on each rising edge of the clock. The module should have one 4-bit output, q, which is the current value of the counter.
