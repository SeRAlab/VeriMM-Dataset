Design a circuit that implements a three-input logical function. The output Y is HIGH when either A1 is TRUE and A2 is FALSE, or A1 is FALSE and A2 is TRUE (effectively capturing the XOR condition between A1 and A2), or when B1 is TRUE. The circuit also includes power and ground connections (VPB, VPWR, VGND, VNB) for proper operation in a digital system.
module top_module(
    input  A1  ,
    input  A2  ,
    input  B1  ,
    output Y   ,
    input  VPB ,
    input  VPWR,
    input  VGND,
    input  VNB
);
