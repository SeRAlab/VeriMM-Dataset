Design a 32-bit wide arithmetic calculator module that performs basic arithmetic operations based on a 2-bit opcode input. The supported operations include addition, subtraction, multiplication, and division, determined by the OPCODE (`00` for addition, `01` for subtraction, `10` for multiplication, and `11` for division). Additionally, the module includes a RESET input that, when activated, sets the output result to zero. The final result is provided as a 32-bit output.
module top_module(
    A,
    B,
    OPCODE,
    RESET,
    RESULT
);
