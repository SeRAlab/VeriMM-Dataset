
Design an 8-bit DRAM cell that can store a single bit of data. The cell should have the following inputs: a data input (D), a read/write control signal (RW), and a clock signal (CLK). The read/write control signal will determine if the data is being written to the cell (RW=1) or read from the cell (RW=0). The output should be the stored data (Q). The cell should also incorporate a simple enable feature, which will allow writing/reading only when enable signal (EN) is high.
