Design a D flip-flop with an asynchronous active-low reset. When the RESET_N signal is asserted low, the flip-flop output Q is reset to 0 and Q_N is set to 1. On the rising edge of the CLK signal, if the reset is not active, the flip-flop captures the value of the D input, setting Q to D and Q_N to the inverted value of D.

    input D,
    input CLK,
    input RESET_N,
    output reg Q,
    output reg Q_N
);
