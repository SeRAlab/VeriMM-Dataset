Design a 32-bit multiplier that takes two 32-bit inputs and produces a 64-bit output. The module should be named `multiplier` and have the following ports:  
- input [31:0] a,  
- input [31:0] b,  
- output [63:0] product.  
Ensure that the multiplication is done using combinational logic, and that the product is valid immediately after the inputs are provided.
