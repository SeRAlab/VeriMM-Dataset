
Create a 16-bit Linear Feedback Shift Register (LFSR) that uses a polynomial defined by the taps: x^16 + x^14 + x^13 + x^11 + 1. The LFSR should be capable of shifting and generating a new bit each clock cycle. The initial seed should be provided as input, and the LFSR should produce a pseudo-random output for a defined number of cycles.
