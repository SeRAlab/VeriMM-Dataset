Design a 4-bit shift register that captures a serial input signal on each positive edge of the clock. When the reset signal is activated, the shift register is cleared to zero. Otherwise, it shifts the current contents left by one bit, inserting the new serial input at the least significant bit while maintaining the previous bits. The module outputs the 4-bit content as parallel data.
module top_module(
    input clk,
    input reset,
    input serial_in,
    output [3:0] parallel_out
);
