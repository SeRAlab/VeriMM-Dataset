Design a circuit that concatenates four one-bit input signals (in1, in2, in3, in4) into a four-bit output. Additionally, if the control signal (ctrl) is asserted, the most significant two bits (corresponding to in1 and in2) of the output will be inverted, allowing for conditional modification of the output based on the control signal.
module top_module(
    input in1,
    input in2,
    input in3,
    input in4,
    input ctrl,
    output reg [3:0] out
);
