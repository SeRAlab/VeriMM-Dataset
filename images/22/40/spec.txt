Design a simple HMAC (Hash-based Message Authentication Code) module. The module should take a key and a message as inputs and produce a message authentication code (MAC) as output. Use a simple XOR operation to simulate the hashing process for the sake of the problem. The key and message will be of fixed size (e.g., 8 bits each). The output should be the result of XORing the key and message. The module should have a clock input to synchronize the output with the key and message inputs.
