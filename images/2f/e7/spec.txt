Design a Verilog module that performs linear regression using the least squares method. The module should take 5 input pairs of x and y values and compute the slope (m) and y-intercept (b) of the best-fit line using the formulas:  
m = (N * Σ(xy) - Σx * Σy) / (N * Σ(x^2) - (Σx)^2)  
b = (Σy - m * Σx) / N  
where N is the number of points (5 in this case). The module should output m and b as fixed-point numbers.
