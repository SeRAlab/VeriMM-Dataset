

You have been tasked with designing a verilog module for a 3-input XNOR gate. The module should have three input ports (A, B, and C) and one output port (X). Additionally, the module should have four power input ports (VPB, VPWR, VGND, and VNB).

Your task is to design a verilog module that meets these requirements. The module should be solvable by only one module within 200 lines of verilog code.
