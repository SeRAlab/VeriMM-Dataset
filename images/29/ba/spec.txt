Design an 8-bit SRAM cell that can read and write data. The SRAM cell should have the following inputs: a write enable signal (WE), a chip enable signal (CE), a word address (3 bits for 8 locations), and an 8-bit data input (D). The outputs should be the 8-bit data output (Q). When CE is low, the SRAM cell is selected, and when WE is low, data on D is written to the addressed location. Otherwise, data at the addressed location is read out on Q.
