Design a 4-to-1 multiplexer with 8-bit wide inputs. The module accepts four 8-bit inputs (in0, in1, in2, in3) and uses a two-bit select signal (sel) to output one of these inputs based on the selected index, providing a single 8-bit output. When sel corresponds to a particular input (00 for in0, 01 for in1, 10 for in2, and 11 for in3), that input is routed to the output.
module top_module(
  input wire [7:0] in0,
  input wire [7:0] in1,
  input wire [7:0] in2,
  input wire [7:0] in3,
  input wire sel,
  output wire [7:0] out
);
