Design a circuit that takes a signed 32-bit input value and produces a signed 16-bit output value along with a sign flag. The output value is generated by right-shifting the input value by 16 bits, effectively extracting the upper 16 bits of the input. The sign flag indicates if the original input value is negative, yielding a high signal when the input is less than zero and low otherwise.
module top_module(
    input signed [31:0] input_value,
    output signed [15:0] output_value,
    output signed sign_flag
);
