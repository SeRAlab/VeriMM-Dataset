

Write a verilog module for a 2-to-1 multiplexer with the following specifications:

- The module should be named `mux2to1`.
- The module should have three input ports `a`, `b`, and `sel`, and one output port `out`.
- The input ports should be 1-bit wide, and the output port should be 1-bit wide.
- When `sel` is 0, the output `out` should be equal to `a`. When `sel` is 1, the output `out` should be equal to `b`.
- Use only combinational logic (no sequential logic).
