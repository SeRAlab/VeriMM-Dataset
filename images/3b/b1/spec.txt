
Create a simple combinational logic circuit that performs gradient descent optimization for a function defined as f(x) = x^2. The circuit should take an input value of x and a learning rate, and output the updated value of x after one iteration of gradient descent. The gradient of f(x) at any point x is given by f'(x) = 2*x. The new value of x should be calculated as: x_new = x - learning_rate * f'(x).
