Design a binary to Gray code converter module with a 4-bit input and output. The module captures a 4-bit binary input on the rising edge of the clock, provided the reset signal is not active. If the reset signal is active, the internal register holding the binary value is cleared to zero. The Gray code output is generated by XORing each bit of the stored binary value with its immediate right neighbor, ensuring that only one bit changes at a time when transitioning between successive binary values.
module top_module(
  input clk,
  input reset,
  input [3:0] binary_in,
  output [3:0] gray_out
);
