Design a 32-bit shifter module that performs a left or right shift based on the specified control signal. The module takes a direction input (SH_DIR) to determine whether to shift left (SH_DIR=1) or right (SH_DIR=0), along with a 5-bit amount input (SH_AMT) that indicates the amount of shift. When the third bit of SH_AMT is set (SH_AMT[2]=1), the module shifts the input data (D_IN) by four bits; otherwise, it simply passes the input data unchanged to the output (D_OUT). The vacated bits are filled with either the sign bit (for left shifts) or zeros (for right shifts).
