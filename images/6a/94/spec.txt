Design a Verilog module for a 4-bit up/down counter with synchronous reset. The counter should increment or decrement its value on each positive clock edge based on the direction signal and reset to 4'b0000 when the reset signal is high.

module up_down_counter
(
    input clk,
    input reset,
    input direction, // 1 for up, 0 for down
    output reg [3:0] count
);
