Design a Verilog module for an SR latch using D flip-flops. The module should take two inputs, S and R, and produce two outputs, Q and Qn. The SR latch should have the following behavior: when S is high and R is low, Q should be set to high. When S is low and R is high, Q should be reset to low. If both S and R are low, Q should maintain its previous state. If both S and R are high, the state is considered invalid.
