

You are tasked with designing a Verilog module that performs a specific logic function. The module should have three input ports (`A`, `B`, `Ci`) and two output ports (`S`, `Co`). The module should implement the following logic function:
```
S = (A XNOR B) XNOR Ci
Co = (A NAND B) NAND (A NAND Ci) NAND (B NAND Ci)
```
where `XNOR` represents the exclusive-NOR operation and `NAND` represents the logical NAND operation.

Design a Verilog module that implements the above logic function. Your module should be self-contained and should not rely on any external modules or libraries. Your module should be named `logic_function` and should have the following ports:
- `A`: a 1-bit input port
- `B`: a 1-bit input port
- `Ci`: a 1-bit input port
- `S`: a 1-bit output port
- `Co`: a 1-bit output port

Your module should be implemented within 200 lines of Verilog code.
