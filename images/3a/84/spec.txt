Design a JK flip-flop using Verilog. The JK flip-flop should have two inputs (J and K), a clock input (clk), and an output (Q) that reflects the current state. The flip-flop should toggle the output based on the J and K inputs on the rising edge of the clock. If J and K are both high, the output should toggle. If J is high and K is low, the output should set to high. If J is low and K is high, the output should set to low. If both J and K are low, the output should retain its previous state.
