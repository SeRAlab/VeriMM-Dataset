
Design a simple interrupt controller that can handle multiple interrupt requests (IRQ) from external devices. The controller should have the following features:
- It accepts a 4-bit input representing 4 different IRQ lines.
- It has a 1-bit output indicating which IRQ line is currently being serviced.
- It has a priority order for servicing the interrupts: IRQ3 > IRQ2 > IRQ1 > IRQ0.
- It includes a clock and reset signal to manage the state of the controller.
- On reset, the controller should clear any active interrupts and not service any IRQ lines.
