Design a 1-bit DRAM cell using Verilog. The DRAM cell should have a data input (D), a data output (Q), a write enable (WE), and a clock (CLK) signal. When WE is high, the value of D should be stored in the cell on the rising edge of the clock. When WE is low, the stored value should be available at the output Q. The behavior of the DRAM cell should hold the value until a new value is written.
