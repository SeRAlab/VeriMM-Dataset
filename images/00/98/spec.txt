Design a simple state machine that simulates a basic SLAM operation. The state machine should have three states: INIT, MAP, and LOCALIZE. The state transitions occur based on the following conditions: 
- From INIT to MAP when the 'start' input signal is high.
- From MAP to LOCALIZE when the 'map_ready' input signal is high.
- From LOCALIZE back to MAP when the 'localize_done' input signal is high.
The current state should be output along with the 'error' signal which is high if the state is INIT and 'start' is high.
