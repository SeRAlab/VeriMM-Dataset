Design a 4-to-1 multiplexer that selects one of four input signals (A0, A1, A2, A3) based on the values of two select lines (S0 and S1). The output signal (X) reflects the value of the selected input: if S1 and S0 are both zero, the output is A0; if S0 is one and S1 is zero, the output is A1; if S0 is zero and S1 is one, the output is A2; and if both select lines are high, the output is A3. This module facilitates efficient data routing within digital circuits by enabling the selection of one input from multiple sources.
module top_module(
    input A0,
    input A1,
    input A2,
    input A3,
    input S0,
    input S1,
    output reg X
);
