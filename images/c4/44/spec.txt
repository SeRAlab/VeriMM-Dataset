

You are tasked with designing a module in Verilog that can perform a simple mathematical operation on two input values. The module should take in two 8-bit unsigned integers, `a` and `b`, and output their sum as an 8-bit unsigned integer, `c`. The module should be named `add8`.

In addition to the basic functionality, the module should also include a control input, `reset`, which when set to 1, will reset the output `c` to 0. The module should also include a control input, `enable`, which when set to 1, will enable the module to perform the addition operation.

You are only allowed to use one module within 200 lines of Verilog code to complete this task.
