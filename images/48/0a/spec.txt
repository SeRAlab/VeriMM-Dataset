Design a decimal counter that increments from 0 to 9 when enabled and clocked. It has capabilities to reset the count to zero, load a preset value, and signal when it reaches its maximum count of 9. The counter outputs a 4-bit value representing the current count and a carry-out signal that indicates when the counter overflows back to zero.
module top_module(
    input clk_cin,
    input rst,
    input EN,
    input load,
    input[3:0] preset,
    output[3:0] out,
    output cout
    );
