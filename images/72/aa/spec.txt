Design a 4-to-1 multiplexer that selects one of four 32-bit input data lines (din0, din1, din2, din3) based on the 2-bit select signal. The selected input is routed to the 32-bit output (dout). If the select signal is within the valid range, dout reflects the corresponding input; otherwise, it outputs an undefined state.
module top_module(
	input [1:0]select,
	input [31:0]din0,din1,din2,din3,
	output reg [31:0]dout
   );
