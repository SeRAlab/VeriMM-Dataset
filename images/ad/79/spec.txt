Design a 32-bit to 64-bit sign extender module. The module takes a 32-bit immediate value (Imm32) and extends it to a 64-bit output (BusImm) based on the Ctrl signal. If Ctrl is high, the upper 32 bits of the output are filled with zeros; if Ctrl is low, the upper 32 bits are filled with the sign bit of the Imm32 input (bit 31). This allows for proper sign extension when transitioning between different bit-width representations in a processor architecture.
