Design a GPIO controller that can read and write to a set of GPIO pins. The controller has the following specifications:
- It has an 8-bit data input (input_data) and an 8-bit data output (output_data).
- It has a 1-bit read (read_en) and write (write_en) enable signals.
- When write_en is high, input_data should be written to output_data.
- When read_en is high, output_data should be available for reading.
- The controller should have a reset signal (reset) that resets output_data to 0 when asserted.
