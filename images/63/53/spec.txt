Design a 4-bit wide arithmetic and logic unit (ALU) that performs various bitwise operations based on a 3-bit select input. The operations include bitwise AND, OR, XOR, NAND, and NOR between two 4-bit inputs, x and y. The result of the operation is stored in a 4-bit output register, q, which is updated on the rising edge of the clock signal. The specific operation is determined by the value of the select input, s.
module top_module(
    input wire [3:0] x,
    input wire [3:0] y,
    input wire s,
    input wire clk,
    output reg [3:0] q
    );
