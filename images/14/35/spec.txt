Design a 2x2 matrix inversion module. Given a 2x2 matrix, the module should compute its inverse, if the determinant is non-zero. The matrix is represented as four inputs (a, b, c, d) corresponding to the matrix:  
| a  b |  
| c  d |  
The inverse is given by:  
| d/det  -b/det |  
| -c/det  a/det |  
where det = ad - bc. The output should be the four elements of the inverted matrix.
