Design a Verilog module that implements a simple OFDM symbol generator. The module should take a 4-bit input representing the data symbols and generate an output that represents the modulated OFDM symbol. The OFDM symbol can be represented as a simple concatenation of the input bits with a predefined cyclic prefix added at the beginning. The cyclic prefix will be the first 2 bits of the input data. The output will be a 6-bit wide signal that combines the cyclic prefix and the data symbols.
