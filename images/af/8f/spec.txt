Design a circuit that combines a 100-bit shift register with a NOR gate. The shift register can be loaded with a 100-bit input and supports right and left shifting based on the enable signals; when `ena` is `01`, it shifts right, while `ena` as `10` performs a left shift. Additionally, the module computes the output of a NOR operation on two inputs, `a` and `b`, producing a signal that is the logical negation of their OR.
module top_module(
    input clk,
    input load,
    input [1:0] ena,
    input [99:0] data,
    input a,
    input b,
    output out
);
