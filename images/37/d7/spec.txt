
Design a 4-channel DMA controller that allows data transfers from one memory location to another. The DMA controller should have the following specifications:
- Four channels, each channel can be enabled or disabled.
- Each channel has a source address and a destination address.
- A transfer request signal (`req`) that initiates the transfer for the enabled channel.
- A transfer acknowledge signal (`ack`) that indicates the transfer has been completed.
- A clock signal to synchronize the operations.
- The output should indicate which channel is currently transferring data.

The controller should be able to handle multiple requests by prioritizing channels based on the order they were requested. Implement this functionality in Verilog.
