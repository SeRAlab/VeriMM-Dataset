Design a pulse generator circuit that produces a pulse output synchronized with a delayed version of the clock signal. The module has an enable input which, when asserted, triggers the generation of a high pulse. The clock signal is used to create a delayed clock output, and the pulse output is reset at every clock cycle based on the enable signal. This functionality is useful in applications requiring precise timing pulses that are controlled by an external enable signal.
module top_module(
    input  clk,   // clock
    input  ena,   // pulse enable
    output pulse, // pulse
