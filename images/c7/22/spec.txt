

You are tasked with designing a Verilog module that can perform a binary addition of two 8-bit inputs and output the result. The module should have two inputs, A and B, and one output, C. The inputs and output should be 8 bits wide. The module should be named "adder_8bit".

In addition, the module should have a control input, "enable", which should be a single bit. When enable is high, the module should perform the addition of A and B and output the result on C. When enable is low, the module should output 0 on C.

The module should be designed to be synthesizable and should be implemented using only combinational logic. The module should be contained within a single Verilog file and should be no more than 200 lines of code.

Assume that the inputs A and B are valid and stable when the enable signal is high.
