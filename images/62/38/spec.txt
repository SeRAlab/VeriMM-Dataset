Design a 3-to-1 multiplexer with four identical outputs. Depending on the value of the control input, the module selects one of the three inputs (a, b, or c) to drive all outputs (w, x, y, z) simultaneously. When control is 0, output signals will reflect input 'a'; when control is 1, they will reflect input 'b'; and when control is 2, they will reflect input 'c'.
module top_module(
    input a, b, c, control,
    output w, x, y, z
);
