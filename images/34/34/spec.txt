Design a 16-QAM modulator that takes 4 bits of input data and produces a 2-bit I (In-phase) and a 2-bit Q (Quadrature) output. The I and Q outputs are determined by the following mapping:  
```
00 -> (1, 1)  
01 -> (1, -1)  
10 -> (-1, 1)  
11 -> (-1, -1)  
```
The modulator should have a clock input and a reset input. On each rising edge of the clock, if the reset is low, the modulator should read the input bits and produce the corresponding I and Q outputs. If the input is not valid (not 4 bits), the I and Q outputs should be set to zero. The 4-bit input data should be shifted in on a data input line.
