
Design a 5-stage instruction pipeline for a simple processor architecture. The pipeline stages are:
1. Instruction Fetch (IF)
2. Instruction Decode (ID)
3. Execute (EX)
4. Memory Access (MEM)
5. Write Back (WB)

The design should include a mechanism to handle hazards such as data hazards and control hazards. Use a simple register file that supports reading and writing of two registers per cycle. Ensure that the pipeline can perform register forwarding to resolve data hazards.
