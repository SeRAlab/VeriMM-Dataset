Design a GPIO controller that allows for reading and writing to a 4-bit GPIO port. The controller should have two 4-bit registers: one for the data to be written (GPIO_OUT) and one for the data that has been read (GPIO_IN). There should be control signals to enable writing and reading operations. The controller should be able to toggle the state of the GPIO_IN register based on the GPIO_OUT register when a write enable signal is high. Implement the controller with appropriate clock and reset behavior.
