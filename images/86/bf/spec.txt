Design a 8-bit shift register that captures a 4-bit input (`data_in`) on each positive clock edge. When the `reset` signal is asserted, the shift register initializes to zero. Otherwise, it shifts its contents to the left by one bit and inserts the new `data_in` on the least significant bit side. The module outputs the lower 4 bits of the shift register as `data_out`.
module top_module(
  input clk,
  input reset,
  input [3:0] data_in,
  output reg [3:0] data_out
);
