Design a simple PCIe interface signal decoder. The interface has three inputs: clk, pcie_data (a 8-bit data bus), and pcie_ctl (a 2-bit control signal). The output should be an 8-bit signal data_out. The data_out signal should be equal to pcie_data when pcie_ctl is '01' and should be zeroed out when pcie_ctl is '00'. For any other control signal, data_out should remain unchanged. Implement this functionality in Verilog.
