The module has a finite state machine (FSM) to manage its operation states: it starts in an idle state waiting for a multiplication trigger, then computes the partial products of the input values in the multiply state, and finally sums the products in the sum state. The result of the multiplication is an 8-bit output, and a done signal is provided to indicate the completion of the operation.
