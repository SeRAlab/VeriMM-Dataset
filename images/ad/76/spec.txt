Design a 4-bit binary adder that adds two 4-bit inputs, A and B, along with a carry-in (CIN) signal. The addition operation occurs on the rising edge of the clock (CLK), and the resulting 4-bit sum is output as SUM, while the carry-out (COUT) indicates any overflow from the addition. This module effectively performs arithmetic operations in synchronous digital circuits.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input CIN,
  input CLK,
  output [3:0] SUM,
  output COUT
);
