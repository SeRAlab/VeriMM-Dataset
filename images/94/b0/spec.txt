Design a tone sequencer that generates a 2-bit output based on the state of an input key and three other control signals (nrq1, nrq2, nrq3). The sequencer transitions through states based on clock edges: starting from zero, it can transition to state 1 if the key is pressed; from state 1 or 2, it moves to state 2 or 3, respectively, when the corresponding control signals are active; and it cycles back to state 0 if the key is not pressed or based on the conditions of nrq3. The output provides the current state of the sequencer, which can be used for further signal processing or control logic.
module top_module(input clk, input key, input nrq1, input nrq2, input nrq3, output [1:0] mux);
