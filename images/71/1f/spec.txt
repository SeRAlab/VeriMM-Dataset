Design a 4-bit counter with load and clear functionalities. When the CLK signal has a rising edge, if the CTRL input is asserted, the output Q is reset to zero. If LOAD is asserted, the counter loads the value from the 4-bit input D into Q. If neither CTRL nor LOAD is asserted, Q increments by one on each clock cycle, effectively counting upwards.
module top_module(
    input CLK,
    input CTRL,
    input LOAD,
    input [3:0] D,
    output reg [3:0] Q
);
