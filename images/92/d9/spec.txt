Design a 4-bit synchronous register that captures input data (D) on the rising edge of the clock (CLK) if the enable signal (EN) is asserted. If EN is not asserted, the register outputs a zero value. The module also computes the logical AND of the four bits stored in the register and outputs this result as Q_AND. This functionality can be useful for implementing state retention and performing logical operations based on the stored state.
module top_module(EN,
    D,
    CLK,
    Q_AND);
