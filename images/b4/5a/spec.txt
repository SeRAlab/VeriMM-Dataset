Design a 2-to-1 multiplexer that selects between two 5-bit inputs, `rt` and `rd`. The selection is determined by the `selectCode` input; when `selectCode` is 0, the output `out` reflects the value of `rt`, and when `selectCode` is 1, the output reflects the value of `rd`.
module top_module(
    input [5:1] rt,rd,
    input selectCode,
    output [5:1] out
    );
