Design a 16-bit signed maximum value selector that takes three signed inputs (a, b, c) and outputs the maximum value to the output y. The module first compares inputs a and b to determine the larger of the two, then compares that result with input c to find the overall maximum. The output y will therefore always reflect the highest value among the three inputs.
module top_module(
  input signed [15:0] a, b, c,
  output signed [15:0] y
);
