Implement the Verilog module based on the following description.
Build a 16-bit register with an asynchronous positive edge triggered clear, synchronous load signal, and synchronous enable signal.
(1) clear: Clears the register to zero.
(2) enable: Enables the register to hold its value.
(3) load: Loads the register with a 16-bit value from input "data".
(4) data: 16-bit data input to the register.
(5) q: The contents of the register.

module top_module(
    input clk,
    input clear,
    input enable,
    input load,
    input [15:0] data,
    output reg [15:0] q);
