
Design a 2nd-order Butterworth filter in Verilog. The filter should have a 4-bit input representing the sampled signal and a 4-bit output representing the filtered signal. The filter should implement the following difference equation:
y[n] = 0.25 * x[n] + 0.25 * x[n-1] + 0.25 * y[n-1] + 0.25 * y[n-2]
where x[n] is the current input, x[n-1] is the previous input, y[n-1] is the previous output, and y[n-2] is the output before the previous one.
