Design a simple NVMe command decoder. The decoder takes a 4-bit command input and outputs a 3-bit command type, where each command input corresponds to a specific command type. The commands and their corresponding types are:  
- Command 0 (0000) -> Type 0 (000)  
- Command 1 (0001) -> Type 1 (001)  
- Command 2 (0010) -> Type 2 (010)  
- Command 3 (0011) -> Type 3 (011)  
- Command 4 (0100) -> Type 4 (100)  
- Command 5 (0101) -> Type 5 (101)  
- Command 6 (0110) -> Type 6 (110)  
- Command 7 (0111) -> Type 7 (111)  
- Any command 8 (1000) or higher should output Type 7 (111).
