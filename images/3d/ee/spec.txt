
Design a FIFO (First-In-First-Out) queue in Verilog. The FIFO should have the following specifications:
- It should have a parameterizable depth (number of items it can hold).
- It should have two primary operations: enqueue (to add an item) and dequeue (to remove an item).
- The enqueue operation should have a flag that indicates if the FIFO is full.
- The dequeue operation should have a flag that indicates if the FIFO is empty.
- The data width for each item in the FIFO should also be parameterizable.
- The FIFO should be clocked, meaning it should operate on a positive edge of the clock signal.
