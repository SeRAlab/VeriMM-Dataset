Design a simple Bluetooth module that takes a 5-bit input representing a command and produces a 5-bit output representing the status. The output should be a simple transformation of the input: if the command is 0, the status should be 1; if the command is 1, the status should be 2; if the command is 2, the status should be 3; if the command is 3, the status should be 4; for any other command, the status should be 0.
