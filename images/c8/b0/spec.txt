

You have been tasked with designing a module that implements a 4-input logic gate. The module should have four input ports named A, B, C, and D. The output port should be named Y. The module should implement the following logic function:

Y = A & ~B & C | D

You should write a Verilog module that implements this function. The module should be self-contained and should not rely on any external modules or libraries.

Your module should be named "logic_gate" and should be contained in a file named "logic_gate.v". The module should be defined with the following ports:

- A (input): a single bit that represents the value of input A.
- B (input): a single bit that represents the value of input B.
- C (input): a single bit that represents the value of input C.
- D (input): a single bit that represents the value of input D.
- Y (output): a single bit that represents the value of the output Y.

Your module should be implemented using only combinational logic. You may use any standard Verilog operators or constructs to implement the logic function.
