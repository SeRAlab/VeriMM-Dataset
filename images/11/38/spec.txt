Design a watchdog timer in Verilog. The timer should have an input signal `reset` to restart the timer, an input signal `timeout` that indicates a timeout condition, and an output signal `timer_expired` that goes high when the timer expires after a specified number of clock cycles (let's say 10 clock cycles). The timer should start counting when the `reset` signal is low and should reset when the `reset` signal is high or when a timeout occurs.
