Design a 4-to-1 multiplexer that selects one of four 32-bit wide input signals (in0, in1, in2, in3) to output based on a 4-bit selection signal composed of s0, s1, s2, and s3. When the appropriate select line is asserted, the corresponding input is routed to the output. If none of the selection lines are active, the output is set to an unknown state.
module top_module(out, in0, s0, in1, s1, in2, s2, in3, s3);
