Design a 16x8 read-only memory (ROM) that retrieves data on the falling edge of the clock signal. The module accepts a 4-bit address input, which allows access to one of the 16 eight-bit wide stored values. The ROM is pre-loaded with predefined data values during initialization, allowing sequential or random data access based on the address provided.
