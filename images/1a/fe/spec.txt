Design a 4-channel DMA controller that allows data transfer between memory and peripheral devices. The controller should have the following inputs: request lines for each channel (req0, req1, req2, req3), an acknowledge line (ack), a clock (clk), and a reset line (reset). The controller should prioritize requests in the order of channel 0 to channel 3. When a request is granted, the corresponding grant line should be activated (gnt0, gnt1, gnt2, gnt3), and the controller should wait for the acknowledge before moving on to the next channel request. The registers should hold the state of the request and grant lines.
