Design a simple virtual memory page table management system that manages the mapping of virtual addresses to physical addresses. The system should include a valid bit to indicate whether a page is in memory and a dirty bit to indicate whether the page has been modified. On each clock cycle, the system should take a virtual address input and output the corresponding physical address if the page is valid. If the page is not valid, the output should be an indication that a page fault has occurred. The system should also update the dirty bit when a write operation is performed.
