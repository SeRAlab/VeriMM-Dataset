
Design a simple watchdog timer in Verilog. The timer should have an input signal called `reset` and a clock signal `clk`. When the `reset` signal is asserted, the timer should reset its count. The timer should increment every clock cycle until it reaches a predefined maximum count value (for example, 8). When the count reaches the maximum, the output signal `timeout` should be asserted high. If the `reset` is deasserted before the count reaches the maximum, the count should be held at the current value.
