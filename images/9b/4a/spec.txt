Implement a Verilog module for a 3-bit up/down counter with synchronous reset and enable. When reset is asserted, the counter should be set to 0. The counter should increment when the up input is high and decrement when the up input is low, on each rising edge of clk, provided enable is high.
module up_down_counter (
    input clk,
    input reset,
    input en,
    input up,
    output reg [2:0] q);
