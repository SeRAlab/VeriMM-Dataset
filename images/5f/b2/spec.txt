Design a Binary-Coded Decimal (BCD) converter that takes a 4-bit binary input and produces two 7-bit BCD outputs. The first output, `bcd_out_1`, remains zero for all input values except for binary values 8 to 15, where it outputs a binary 1. The second output, `bcd_out_2`, encodes the values directly from 0 to 7 for binary inputs from 0 to 7, and for inputs from 8 to 15, it outputs binary representations from 0 to 7 accordingly. This design allows for visualization of decimal numbers in BCD format.
module top_module(
    input [3:0] bin_in,
    output reg [6:0] bcd_out_1,
    output reg [6:0] bcd_out_2
);
