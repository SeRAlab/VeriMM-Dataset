
Design a 2-channel DMA controller that can transfer data from memory to two different peripheral devices. The DMA controller should have the following specifications:
- Two channels with enable signals (`chan1_en`, `chan2_en`).
- Each channel has a memory address (`chan1_addr`, `chan2_addr`) and a data bus to transfer data (`data_out`).
- A control signal (`start`) initiates the DMA transfer for the enabled channel.
- The controller should complete the transfer in one clock cycle for each channel when enabled.
- A done signal (`done`) indicates that the transfer for the enabled channel is complete.
