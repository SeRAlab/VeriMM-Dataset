
Create a Verilog module for a 24-bit ADC (Analog-to-Digital Converter) that takes a 24-bit input signal representing an analog value and provides a 10-bit output signal representing the digital value. The output should be updated on the rising edge of a clock signal. Implement the module with a simple rounding mechanism, where the least significant bits are dropped, and only the most significant 10 bits are retained for the output.
