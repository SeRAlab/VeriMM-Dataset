Design a 16-QAM modulator in Verilog. The modulator takes a 4-bit input representing the digital data and outputs a 2-bit I (In-Phase) and a 2-bit Q (Quadrature) output for the modulation. The mapping of the input bits to the I and Q output is as follows:
- 0000 -> I = 00, Q = 00
- 0001 -> I = 00, Q = 01
- 0010 -> I = 01, Q = 00
- 0011 -> I = 01, Q = 01
- 0100 -> I = 10, Q = 00
- 0101 -> I = 10, Q = 01
- 0110 -> I = 11, Q = 00
- 0111 -> I = 11, Q = 01
- 1000 -> I = 00, Q = 10
- 1001 -> I = 00, Q = 11
- 1010 -> I = 01, Q = 10
- 1011 -> I = 01, Q = 11
- 1100 -> I = 10, Q = 10
- 1101 -> I = 10, Q = 11
- 1110 -> I = 11, Q = 10
- 1111 -> I = 11, Q = 11
