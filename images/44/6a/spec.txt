Develop a 4-bit register that can either load a new value or sum its current value with an input. The module features a clock input for synchronous operation and a reset input to initialize the register to zero. When the load signal is active, the register takes the 4-bit input D; otherwise, it adds the current value of the register with D on each clock cycle. The current value of the register is outputted as Q.
module top_module(
  input clk,
  input rst,
  input load,
  input [3:0] D,
  output [3:0] Q
);
