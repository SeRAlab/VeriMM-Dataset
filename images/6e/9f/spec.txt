Design a 4-bit signed adder that computes the sum of two signed 4-bit inputs, A and B, along with an optional carry-in input. The module outputs a 4-bit sum and a single-bit overflow flag. The overflow flag indicates if the result exceeds the range of a 4-bit signed integer, specifically if the sum is greater than 7 or less than -8, which indicates an overflow condition in signed arithmetic.
module top_module(
    input signed [3:0] A, B,
    input carry_in,
    output signed [3:0] sum,
    output overflow
);
