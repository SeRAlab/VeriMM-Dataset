Design a 32-entry register file with read and write capabilities. The module supports input for writing data to specific registers based on a given write address, controlled by a write enable signal, and resets all registers to their address values when activated. It also allows for concurrent reading from three different registers, outputting their values on the falling edge of the clock. The first two read addresses output data to data_out_1 and data_out_2, while a debug read address outputs to data_out_debug. The system initializes each register with its respective index upon startup.
module top_module(input wire clock,input wire clock_debug,input wire reset,input wire WriteEnable,input wire [4:0] read_address_1,input wire [4:0] read_address_2,input wire [4:0] read_address_3,input wire [31:0] write_data_in,input wire [4:0] write_address,input wire [4:0] read_address_debug,output reg [31:0] data_out_1,output reg [31:0] data_out_2,output reg [31:0] data_out_3,output reg [31:0] data_out_debug);
