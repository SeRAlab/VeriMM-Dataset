Implement a 4-bit ripple carry adder that computes the sum of two 4-bit inputs, A and B, along with a carry-in input, Cin. The module generates a 4-bit sum output, S, and a carry-out output, Cout. If the resulting sum exceeds the maximum representable value for 4 bits (which is 15), the Cout output is set to 1; otherwise, it remains 0.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    output reg [3:0] S,
    output reg Cout
);
