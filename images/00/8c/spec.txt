Design a simple ARQ (Automatic Repeat reQuest) system that uses a single-bit acknowledgment (ACK) and negative acknowledgment (NACK). The system will send a data bit and wait for an acknowledgment. If an ACK is received, the next data bit is sent; if a NACK is received, the same data bit is resent. The input will be a serial stream of data bits and the acknowledgment signal. The output will be the same serial stream of data bits but will handle retransmissions based on the acknowledgments received.
