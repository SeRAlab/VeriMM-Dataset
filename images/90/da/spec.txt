Design a 4-bit signed arithmetic calculator capable of performing basic operations. The module accepts two signed 4-bit inputs (a and b) and a 2-bit operation selector (op). Based on the value of op, the calculator computes the result of addition, subtraction, multiplication, or division of the input values, and outputs the signed 4-bit result.
module top_module(
    input signed [3:0] a,
    input signed [3:0] b,
    input [1:0] op,
    output reg signed [3:0] result
);
