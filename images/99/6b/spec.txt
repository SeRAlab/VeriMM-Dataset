Design a 2-to-1 address selector circuit that produces a 2-bit write address based on a 2-bit selection input. When the select input is 00, the output is fixed to 00. If select is 01, the output corresponds to the value from reg_field0. If select is 10, the output derives from reg_field1. For any other value of select, the default output is set to 10. This module acts as a multiplexer for selecting a write address from one of the two register fields or a fixed address.
module top_module(input [1:0] select, input [1:0] reg_field0, reg_field1, output reg [1:0] write_address);
