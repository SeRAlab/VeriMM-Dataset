Design a parameterized asynchronous D flip-flop with active-high reset functionality. The module captures the input data 'D' on the rising edge of the clock signal 'CLK' if the asynchronous reset 'ARST' is not asserted. If 'ARST' is active, the output 'Q' is set to a predefined value specified by 'ARST_VALUE'. It allows customization of the bit-width of the data signal and the polarities for both the clock and reset signals.
