Design a 4-bit SRAM cell with read and write capabilities. The cell should have an input data bus (D), a 4-bit output bus (Q), a write enable signal (WE), a read enable signal (RE), and a clock signal (CLK). When WE is high, the data on the input bus (D) should be written into the cell on the rising edge of CLK. When RE is high, the data stored in the SRAM cell should be output onto the output bus (Q) on the falling edge of CLK. If both WE and RE are low, the output bus should retain its previous value.
