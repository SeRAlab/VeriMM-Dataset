
Design a 16-bit DRAM cell with read and write operations. The cell should have a 16-bit input data bus, a single 16-bit output data bus, and control signals for reading and writing. The read operation should output the stored value, while the write operation should store the input value. The control signals are defined as follows: `write_enable` (active high) for writing data, and `read_enable` (active high) for reading data. The cell should hold the last written value until a new write occurs.
