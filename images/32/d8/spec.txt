Design a Verilog module that implements a simplified version of the ChaCha20 stream cipher, focusing on the quarter-round function. The module should take a 32-bit input and produce a 32-bit output. This basic quarter-round operation will be part of the larger ChaCha20 algorithm, but for this problem, you only need to implement the quarter-round function, which performs a series of arithmetic and bitwise operations on the input words.
