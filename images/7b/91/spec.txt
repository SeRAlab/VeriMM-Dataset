Design a 4-bit arithmetic logic unit (ALU) that performs various operations based on a 3-bit operation selector. The unit accepts two 4-bit inputs, `a` and `b`, and based on the value of `op`, it can perform addition, subtraction, bitwise AND, bitwise OR, bitwise XOR, and a left shift on `a`. If an unsupported operation is specified, the output is set to zero.
module top_module(
    input [3:0] a,
    input [3:0] b,
    input [2:0] op,
    output reg [3:0] out
);
