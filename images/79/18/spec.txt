Design a 4-bit up/down counter that increments or decrements its count based on the Up and Down control signals, respectively. The counter resets to zero when the Reset signal is asserted and updates its value on the rising edge of the Clock signal. When Up is high, the count increases by one; when Down is high, the count decreases by one, allowing for dynamic counting in both directions.
module top_module(
    input Up,
    input Down,
    input Clk,
    input Reset,
    output reg [3:0] Count
);
