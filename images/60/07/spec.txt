Design a signed arithmetic operation selector. The module takes two signed 8-bit and 11-bit inputs (a and b), a signed 16-bit input (c), and a 2-bit selection signal (sel) to choose from four operations: addition of a and b, subtraction of b from a, and addition of a and c. If sel does not match any defined cases, the result (res) will be undefined. The output is a signed 16-bit result based on the selected operation.
module top_module(
  input signed [7:0]       a,
  input signed [10:0]      b,
  input signed [15:0]      c,
  input [1:0]              sel,
  output reg signed [15:0] res
  );
