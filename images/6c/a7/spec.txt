Design a simple register module that operates on a 2-bit wide data. It features a reset functionality to clear the register and allows write operations to a specific address (ADDR=0) based on the WRITE signal. When the WRITE signal is high, data from the WRITE_DATA input is stored in the register. The READ_DATA output provides the current contents of the register at address 0 when accessed. This module essentially functions as a small memory element controlled by a clock, capable of writing and reading 2-bit values.
module top_module(CLK, RST, WRITE, READ, ADDR, WRITE_DATA, READ_DATA);
