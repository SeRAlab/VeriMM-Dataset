
Design a D-flip-flop with asynchronous reset and enable signals. The D-flip-flop should have the following behavior:
- When the reset signal is high, the output Q should be set to 0 regardless of the D input.
- When the enable signal is high, the output Q should take the value of D on the rising edge of the clock.
- When the enable signal is low, the output Q should hold its previous value.
