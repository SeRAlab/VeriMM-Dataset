Design a simple dual-buffer system that allows synchronous data transfer. The module accepts input data (put) and provides it as output (get) based on control signals. The output RDY_put is asserted when data is ready to be sent, depending on the enable signal for receiving (EN_put), and RDY_get indicates when data can be fetched based on the enable signal for sending (EN_get). Upon receiving a clock (CLK) and reset (RST), this module facilitates coordinated data flow between its input and output interfaces while maintaining a single-bit data width.
module top_module(CLK,RST,put,EN_put,RDY_put,get,EN_get,RDY_get);
