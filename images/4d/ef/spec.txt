Design a synchronous block RAM module that behaves as a memory store. It has an 8-bit wide data output (douta) and supports write operations controlled by an enable signal (ena) and a write enable signal (wea). The module uses a 12-bit address input (addra) to access a memory array of 4096 locations. On the rising edge of the clock (clka), if the enable signal is high, it writes data (dina) to the specified address in memory when the write enable signal is asserted, and concurrently reads the data stored at that address to produce the output (douta).
module top_module(douta,
    ena,
    clka,
    addra,
    dina,
    wea);
