Design a 1-of-256 demultiplexer that takes a 1024-bit input and an 8-bit select signal. The output is a 4-bit wide value that corresponds to 4 consecutive bits from the input, selected based on the value of the select signal multiplied by 4. Each unique value of the select signal determines which 4-bit segment is outputted, effectively allowing for one of 256 possible selections from the input data.
