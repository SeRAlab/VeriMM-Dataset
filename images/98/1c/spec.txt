Construct a one-bit wide, 2-to-1 multiplexer controlled by the ALUSrcA signal. When ALUSrcA is low, the module outputs in0; when ALUSrcA is high, it outputs in1. The design allows for the selection of one of two 32-bit input sources based on the control signal.
module top_module(
	input clk,
	input ALUSrcA,
	input [31:0]in0,
	input [31:0]in1,
	output wire[31:0]out
);
