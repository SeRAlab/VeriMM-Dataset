

You are tasked with designing a module that takes in a 4-bit binary input and outputs the 2's complement of the input. The module should be named "twos_comp" and should have the following input and output ports:
- input [3:0] bin_in
- output [3:0] twos_comp_out

The module should implement the following steps to compute the 2's complement of the input:
1. Invert all bits of the input.
2. Add 1 to the inverted input.

For example, if the input is 0101, the 2's complement should be 1011.

Your task is to write the "twos_comp" module in Verilog. You may assume that the input will always be a valid 4-bit binary number.
