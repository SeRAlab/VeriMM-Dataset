
Design a PCIe endpoint controller that can handle a simple packet receiving operation. The controller should be able to receive a 32-bit data packet and a valid signal indicating that the packet is ready to be processed. Once the valid signal is high, the data should be latched into a register on the next clock edge, and an output signal should indicate that the packet has been successfully received. If a reset signal is asserted, the controller should clear the received data and the output signal.
