
Design a sliding window protocol for reliable data transmission with the following specifications:
1. The sender can send a maximum of 4 frames before needing an acknowledgment (ACK).
2. The receiver sends an ACK for the received frames.
3. Implement a counter to keep track of the number of sent frames, and a state machine to handle the sending and acknowledgment states.
4. The sender will wait for an ACK before sending the next frame, but can send multiple frames up to the window limit.
