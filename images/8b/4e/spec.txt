Design a 4-to-1 multiplexer that selects one of four 32-bit input signals (zero_in, one_in, two_in, three_in) based on a 2-bit control signal (signal). Each value corresponds to a specific input: when signal is 00, the output (mux_out) is set to zero_in; when it is 01, one_in is selected; when it is 10, two_in is chosen; and when it is 11, three_in is outputted. The selected input is assigned to the output mux_out, enabling the selection of one of the four inputs based on the control signal.
module top_module(input [31:0] zero_in,
              one_in,
              two_in,
              three_in,
              input [1:0] signal,
              output reg [31:0] mux_out);
