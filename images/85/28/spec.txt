Design a synchronous 4-bit counter with the capability to reset and enable counting. The counter increments its value on each positive clock edge if the enable signal is active. Upon activation of the reset signal, the counter resets all internal registers to zero. The design uses three registers to hold the intermediate counting values, ensuring that the output represents the result of a stable counting process. The output will reflect the current value of the counter based on the enable condition.
module top_module(
    input clk,
    input reset,
    input enable,
    output reg [3:0] count
);
