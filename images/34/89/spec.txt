Design a simple WiFi control module that manages the connection state of a device. The module has a clock input, a reset input, and a connection request input. When a connection request is received, the module transitions from a DISCONNECTED state to a CONNECTING state. After a certain number of clock cycles (defined as CONNECT_TIME), it transitions to a CONNECTED state. If a reset signal is received at any time, the module should return to the DISCONNECTED state. The module should output the current state as a 2-bit value (00 for DISCONNECTED, 01 for CONNECTING, and 10 for CONNECTED).
