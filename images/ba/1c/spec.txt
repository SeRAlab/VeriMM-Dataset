Design a digital circuit that implements a 7-tap Finite Impulse Response (FIR) filter. The module processes incoming data at each clock cycle when new data is indicated as ready, applying a set of fixed coefficients to the current and previous input samples. The output of the FIR filter is a wide data bus representing the filtered result, and a control signal indicates when the output data is ready for retrieval. The filtering operation sums the products of the input data and its delayed samples, each scaled by their respective coefficients, enabling signal processing applications.
