Implement a Verilog module for a simple edge detector. The edge detector should have a clock input `clk`, an asynchronous reset input `reset`, an input `signal`, and an output `edge_detected`. The output `edge_detected` should be high for one clock cycle whenever a rising edge is detected on the `signal` input.

module edge_detector(
	input wire clk,
	input wire reset,
	input wire signal,
	output reg edge_detected
);
