Design a simple NVMe command decoder that takes a 5-bit opcode as input and decodes it into a 3-bit command type (Read, Write, and Ident). The opcodes are defined as follows: 
- Opcode 00000: Read
- Opcode 00001: Write
- Opcode 00010: Ident
- Opcode 00011: Reserved
- Opcode 00100: Reserved
- All other opcodes: Invalid
