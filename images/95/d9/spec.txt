Implement a 2-to-4 line decoder. The module takes a 2-bit input (sw) and activates one of the four corresponding output LEDs (led) based on the value of sw, with each output representing a binary value corresponding to the input. When sw is 00, the first LED lights up; when sw is 01, the second LED lights up; when sw is 10, the third LED lights up; and when sw is 11, the fourth LED lights up.
module top_module(
    input [1:0] sw,
    output [3:0] led
    );
