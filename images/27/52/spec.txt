
Design a Verilog module for a simple Flash memory cell. The memory cell should have the following features:
- A single data input (D).
- A write enable signal (WE) that allows data to be written to the cell when high.
- A read enable signal (RE) that allows data to be read from the cell when high.
- An output (Q) that reflects the stored data when read enabled.

The memory cell should maintain its state between writes and reads. If WE is high, the cell should store the data from D. If RE is high, the output Q should reflect the stored data.
