Design a Cryptographically Secure Pseudo-Random Number Generator (CSPRNG) using a Linear Feedback Shift Register (LFSR). The LFSR should be 5 bits wide and use the polynomial x^5 + x^2 + 1. The output should be a 5-bit random number generated on each clock cycle. The design should include a reset signal that initializes the LFSR to a non-zero state.
