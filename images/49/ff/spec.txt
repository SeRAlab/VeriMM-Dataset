Design a 32-bit Arithmetic Logic Unit (ALU) that performs various operations based on a 3-bit operation selector (S_Op). The ALU can execute addition, subtraction, multiplication, division, bitwise OR, bitwise AND, and comparison (less than) between two 32-bit inputs (Op1 and Op2). The result of the selected operation is output as R_Op, and a zero flag (ZF) is set to indicate if the result is zero. If an unsupported operation is selected, R_Op is set to an undefined state.
module top_module(
		
		
		input [31:0]Op1,
		input [31:0]Op2,
		input [2:0]S_Op,
		
		output reg ZF,
		output reg[31:0]R_Op
);
