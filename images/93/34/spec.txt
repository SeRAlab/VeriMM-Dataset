Design a circuit that processes a 4-bit input (A) based on a 2-bit control signal (B) and produces a 3-bit output (C). The module performs four distinct operations: left shift by 1 bit when B is 00, right shift by 1 bit when B is 01, add 1 to the input when B is 10, and subtract 1 from the input when B is 11. The output C captures the relevant bits from the operation specified by B, allowing for flexible manipulation of the input data.
module top_module(
    input [3:0] A,
    input [1:0] B,
    output reg [2:0] C
);
