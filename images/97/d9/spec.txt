Design a 32-bit register with asynchronous reset and write enable functionality. On the rising edge of the clock, if the reset signal is high, the output q is set to zero. If reset is low and the write enable (wren) signal is high, the output q takes on the value of the input data. Otherwise, the output retains its previous value, effectively implementing a D-type flip-flop that can store a 32-bit value.
