Design a circuit that performs logical operations on a four-bit input, producing three outputs: a single output for the logical AND operation across the four input bits, a single output for the logical OR operation across the four bits, and a single output for the cumulative XOR operation across the same four bits. The logical AND output will be low unless all four input bits are high, the logical OR output will be high if at least one of the input bits is high, and the XOR output will reflect high if an odd number of the input bits are high.
module top_module(
    input [4:0] in,
    output out_and,
    output out_or,
    output out_xor
);
