Design a register module for a Nios II processor's debug and monitoring interface that handles various control signals and settings. The module features a 2-register address space, allowing writes to control single-step execution and interrupt masking. It updates outputs based on the write operations conditioned on debug access. The module includes logic to reset its state on a reset signal and respond to clock edges, effectively managing the operational settings related to debugging, while providing data on demand through designated output signals based on selected addresses.
