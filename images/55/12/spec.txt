Design a Verilog module that implements a 3-bit up/down counter with asynchronous reset. The counter should increment when the up signal is high, and decrement when the down signal is high. If both signals are high, the counter should hold its value. The reset signal should set the counter to 3'b111.

module up_down_counter(
	input clk,
	input reset,
	input up,
	input down,
	output [2:0] count);
