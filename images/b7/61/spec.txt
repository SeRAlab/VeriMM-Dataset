Design a circuit that performs YCbCr color thresholding. The module takes in Y, Cb, and Cr color components, as well as threshold values Ta, Tb, Tc, and Td. It outputs a binary value of 8'hFF (indicating a match) if the Cb component lies between Ta and Tb, and the Cr component lies between Tc and Td; otherwise, it outputs 8'h00 (indicating no match).
module top_module(
    input [7:0] Y,
    input [7:0] Cb,
    input [7:0] Cr,
    input [7:0] Ta,
    input [7:0] Tb,
    input [7:0] Tc,
    input [7:0] Td,
    output [7:0] binary
    );
