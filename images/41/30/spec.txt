Design a synchronous 8-bit up counter with reset and enable functionality. When the counter is enabled (cnt_en =1) and the count is below the specified maximum of 255, it increments on each positive edge of the clock (clk). If the reset signal (rst) is asserted, the counter resets to zero. Additionally, if the counter reaches the maximum count or is not enabled, it also resets to zero.
module top_module(
  input clk,
  input rst,
  input cnt_en,
  output reg [7:0] count
);
