
Design a simple memory allocation system using Verilog. The system should have the following features: 
1. A request to allocate a certain number of memory blocks (size = 1 bit) should be made using an input signal `alloc_req` and the size of allocation through `alloc_size` (a 3-bit signal, 1 to 7). 
2. If the allocation is successful, an output signal `alloc_success` should be high, and the `allocated_mem` should reflect the allocated memory blocks.
3. A request to free the allocated memory should be made using an input signal `free_req`. If the free request is successful, the `alloc_success` should go low and the `allocated_mem` should reset to 0.
4. The memory can only be allocated once until it is freed.
