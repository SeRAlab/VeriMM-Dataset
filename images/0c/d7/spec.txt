Design a fan speed controller that takes an input temperature and controls the fan speed based on predefined thresholds. The fan has three speeds: low, medium, and high. If the temperature is below 20°C, the fan should run at low speed. If the temperature is between 20°C and 30°C, the fan should run at medium speed. If the temperature is above 30°C, the fan should run at high speed. The system should also have a reset input to set the fan speed to low.
