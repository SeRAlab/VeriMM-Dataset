Design an SR flip-flop using Verilog that has two inputs (S and R) and one output (Q). The flip-flop should operate according to the following truth table:  
- If S = 0 and R = 0, Q remains unchanged.  
- If S = 1 and R = 0, Q sets to 1.  
- If S = 0 and R = 1, Q resets to 0.  
- If S = 1 and R = 1, the output is undefined (we can choose to keep it unchanged).  
The flip-flop should be edge-triggered on the rising edge of a clock signal. Use a clock signal for simulation purposes.
