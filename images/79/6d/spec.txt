Design a 4-bit comparator that evaluates two 4-bit inputs. The module outputs three signals: `eq` which indicates if the inputs are equal, `gt` which signals if the first input is greater than the second, and `lt` which indicates if the first input is less than the second. The comparison is performed combinationally, responding to changes in either input.
module top_module(
    input [3:0] in0,
    input [3:0] in1,
    output reg eq,
    output reg gt,
    output reg lt
);
