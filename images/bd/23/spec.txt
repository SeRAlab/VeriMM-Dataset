Design a one-bit controlled multiplexer that selects between a constant value and a given input address. When the control signal RegRA is asserted (i.e., set to 1), the output raRegAddr is set to a predefined address (5'b11111); otherwise, it outputs the value from RegAddr. This module is useful for directing signal flow in digital circuits where an address may either be a specific constant or a variable input.
module top_module(
	 input  RegRA,               
	 input  [4:0] RegAddr,       
	 output  [4:0] raRegAddr    
	 );
