Design an 8-bit shift register with synchronous loading capability. The shift register should have the following inputs: a clock signal (clk), a reset signal (rst), a serial input (serial_in) for shifting, and a parallel input (parallel_in) for synchronous loading. The output should be the current state of the 8-bit register (shift_reg). When the reset is high, the register should be reset to 0. On the rising edge of the clock, if the reset is low and load is high, the register should load the parallel input. If load is low, the register should shift left and input the serial input at the least significant bit (LSB).
