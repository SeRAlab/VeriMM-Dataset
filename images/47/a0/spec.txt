Design a simple calculator capable of performing addition and subtraction operations on two 8-bit inputs, A and B. The operation is controlled by the OP input, where OP=0 selects addition (A + B) and OP=1 selects subtraction (A - B). The operation is synchronized with a clock signal, CLK, and can be reset with the RST input, which initializes the output to zero. The result of the operation is output as an 8-bit value, C.
module top_module(
    input  [7:0] A,
    input  [7:0] B,
    input        OP,
    input        CLK,
    input        RST,
    output [7:0] C
);
