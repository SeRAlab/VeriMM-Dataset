Design a priority encoder for handling interrupts. The module takes in external and internal interrupt signals, along with a processor state write interrupt (PSWI). It outputs the address of the highest-priority active interrupt, a corresponding interrupt number, and a flag indicating whether an interrupt is present. The priority is determined by the order of input bits, with higher index bits taking precedence. If an external interrupt is asserted while PSWI is active, or if any internal interrupt is active, the module signals that an interrupt is present, providing the relevant details for processing.
