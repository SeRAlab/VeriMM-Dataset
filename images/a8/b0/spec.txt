Develop a Verilog module for a 4-bit decade counter with enable and asynchronous reset. The counter should increment its value on each positive clock edge if enable is high and wrap around to 4'b0000 after reaching 4'b1001. If reset is high, the counter should reset to 4'b0000.
module decade_counter (
    input clk,
    input reset,
    input enable,
    output reg [3:0] q
);
