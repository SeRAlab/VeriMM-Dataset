Design a synchronous memory module with a 4-bit address and an 8-bit data bus. The memory can store up to 16 bytes, where data is written to the memory at the rising edge of the clock pulse using the provided address, and it captures new input data as well as the address for the next operation. On each clock cycle, the current content of the specified memory address is outputted, while the module can be reset to clear its state. The purpose of this design is to provide a simple memory storage solution for use in digital circuits, enabling both read and write operations based on the clock signal.
