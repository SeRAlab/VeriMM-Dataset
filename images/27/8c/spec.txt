
Design a 24-bit ADC interface module that takes a 24-bit digital input and produces a 4-bit output based on the following logic:
- If the 24-bit input is less than 1/16 of the maximum value (i.e., less than 0x0FFFFFF / 16), output should be 0.
- If the 24-bit input is between 1/16 and 1/8 of the maximum value, output should be 1.
- If the 24-bit input is between 1/8 and 3/16 of the maximum value, output should be 2.
- If the 24-bit input is between 3/16 and 1/4 of the maximum value, output should be 3.
- If the 24-bit input is greater than or equal to 1/4 of the maximum value, output should be 4.
