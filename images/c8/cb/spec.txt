

You are tasked with designing a verilog module that implements a 2-bit up counter. The module should have the following inputs and outputs:

Inputs:
- `CLK`: a clock signal
- `RST`: a reset signal

Outputs:
- `Q`: a 2-bit output representing the current count value

The module should have the following behavior:
- On the rising edge of `CLK`, the output `Q` should increment by 1.
- If `RST` is high, the output `Q` should be set to 0.

Use the following code snippet as a template for your module:

```
module up_counter(
    input CLK,
    input RST,
    output reg [1:0] Q
);

    // your code here

endmodule
```
