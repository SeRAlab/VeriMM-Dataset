Design a shift register with an 8-bit width that can either load a new input in parallel or perform left/right shifting. When the load signal is asserted, the module captures the input data; otherwise, it shifts the stored data left or right based on the shift direction signal. The output reflects the most significant bit of the current data stored in the register after the load or shift operation.
module top_module(
  input in,
  input load,
  input shift_left,
  output out
);
