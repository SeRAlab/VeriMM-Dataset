Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state P (output 0).
2. state Q (output 1).
3. state R (output 1).
4. state S (output 0).

State transitions:
1. From state P: If b = 1, then transition to state Q. If b = 0, then transition to state S.
2. From state Q: If b = 1, then transition to state R. If b = 0, then transition to state P.
3. From state R: If b = 1, then transition to state S. If b = 0, then transition to state P.
4. From state S: If b = 1, then transition to state Q. If b = 0, then transition to state P.

Assume that a one-hot code is used with the state assignment t[3:0] = 0001(P), 0010(Q), 0100(R), 1000(S)

Write a Verilog for the signal T2, which is the input of state flip-flop t[2], for the signal T3, which is the input of state flip-flop t[3]. Derive the Verilog by inspection assuming a one-hot encoding.

module top_module (
        input [3:0] t,
        input b,
        output reg T2,
        output reg T3);
