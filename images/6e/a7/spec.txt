Design a forwarding unit for a pipelined processor to resolve data hazards. The module takes source register identifiers (rs, rt) and control signals indicating write operations in the memory write-back (MEM_WB) and execute (EX_MEM) stages. Depending on these inputs, it determines the appropriate forwarding paths by generating two 2-bit output signals (forwardA, forwardB). If the reset signal is active, both outputs are set to zero. Otherwise, forwarding is activated if the destination register of a preceding operation matches the source registers, effectively preventing stale data from being used in subsequent operations.
