Design a one-bit wide, 2-to-1 multiplexer using behavioral modeling. The module takes two data inputs, in0 and in1, and a select input, sel. When sel is 0, the output, out, reflects the value of in0; when sel is 1, the output takes the value of in1. This functionality allows for the dynamic selection of one of the two inputs based on the control signal.
module top_module(
    input wire in0,
    input wire in1,
    input wire sel,
    output reg out
);
