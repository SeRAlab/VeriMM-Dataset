Design a one-bit wide, 2-to-1 multiplexer. The module outputs a signal X that is determined by the selection input S: when S is logic high (1), output X is assigned the value of input A1, and when S is logic low (0), output X takes the value of input A0. The implementation uses a standard library component for the multiplexer functionality and a buffer to drive the output.

    output X,
    input  A0,
    input  A1,
    input  S
