Design a 4-to-1 multiplexer for 32-bit wide inputs. The module takes in three 32-bit input signals (select_0, select_1, select_2) and a 2-bit selection signal to choose which 32-bit input to output on OutAddress. When selection is 00, OutAddress outputs select_0; when selection is 01, it outputs select_1; and when selection is 10, it outputs select_2. Note that selection values for 11 are not handled in this design.
module top_module(
    input [31:0] select_0,
    input [31:0] select_1,
    input [31:0] select_2,
    input [1:0] selection,
    output [31:0] OutAddress
    );
