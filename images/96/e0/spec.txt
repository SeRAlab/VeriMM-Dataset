Design a simple synchronous data memory module that functions as a 5-entry RAM. The module has a 32-bit wide data input (WD) and a 32-bit address input (A), allowing read and write operations triggered by a clock signal (clk) and a write enable signal (WE). Upon a reset signal (reset), the memory initializes all entries to zero. On each rising edge of the clock, if the reset is not active, the module writes the data from WD to the memory location specified by A, provided the appropriate write enable line is active. Simultaneously, on reading, if reset is not asserted and WE is inactive, it outputs the data from the specified address in memory (A) to the output (RD), otherwise RD defaults to zero.
