Design a four-bit ripple-carry adder that computes the sum of two 4-bit binary numbers, `a` and `b`, along with an initial carry input (`ci`). The module outputs a 4-bit sum (`s`) and a carry-out (`co`). Four single-bit adder instances are utilized to handle the addition for each bit position sequentially, propagating the carry from one bit to the next.
module top_module(
    input wire a,
    input wire b,
    input wire ci,
    output wire s,
    output wire co
);
