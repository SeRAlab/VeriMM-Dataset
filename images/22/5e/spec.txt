Design a 2nd-order Infinite Impulse Response (IIR) filter using Verilog. The filter should have two input values (X[n] and X[n-1]), and produce one output value (Y[n]). The filter coefficients are to be fixed as 0.2, 0.3 for the feedback (Y values) and 0.5, 0.5 for the feedforward (X values). The filter structure should allow for proper state retention across clock cycles.
