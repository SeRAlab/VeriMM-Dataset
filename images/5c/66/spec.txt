Design a signed 8-bit calculator capable of performing addition, subtraction, multiplication, and division based on a 2-bit operation selector. The calculator outputs a result and flags for overflow, underflow, and error conditions. Overflow and underflow checks are specifically implemented for multiplication operations, while an error is indicated for division by zero.
module top_module(
    input signed [7:0] A,
    input signed [7:0] B,
    input [1:0] op,
    output reg signed [7:0] result,
    output reg overflow,
    output reg underflow,
    output reg error
);
