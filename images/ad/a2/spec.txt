Develop a simple arithmetic calculator that performs either addition or subtraction on two 8-bit inputs, a and b. The output, result, reflects the addition of a and b when the add control signal is high, the subtraction of b from a when the sub control signal is high, and outputs zero when neither operation is selected. The design effectively utilizes multiplexing based on the control signals to determine which arithmetic operation's result to present on the output.
module top_module(
    input [7:0] a,
    input [7:0] b,
    input add,
    input sub,
    output [7:0] result
);
