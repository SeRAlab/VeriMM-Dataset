
You have been tasked with designing a module that performs a 4-to-1 multiplexer. The module should have four 8-bit inputs (data0, data1, data2, data3), a 2-bit select input (selectInput), and one 8-bit output (out). The output should be the selected input based on the selectInput value. The selectInput should be interpreted as follows:
- 00: select data0
- 01: select data1
- 10: select data2
- 11: select data3

Design a Verilog module that implements this 4-to-1 multiplexer. Ensure that the module is self-contained and does not require any external modules. The module should be synthesizable and meet timing requirements.
