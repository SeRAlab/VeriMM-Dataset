
Design a 24-bit digital-to-analog converter (DAC) that takes a 24-bit binary input and outputs a corresponding analog voltage level. The output voltage is linearly scaled based on a reference voltage, which is provided as a 12-bit input. The formula for the output voltage (V_out) can be defined as follows:
V_out = (Input_value / 2^24) * Reference_voltage
where Input_value is the 24-bit input to the DAC. The output should be represented as a 32-bit fixed-point number to allow for greater precision.
