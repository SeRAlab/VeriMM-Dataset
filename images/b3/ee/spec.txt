Design a 4-bit wide adder/subtractor circuit. This module takes two 4-bit inputs, A and B, alongside a control input C which determines the operation: if C is 0, the circuit performs addition (A + B); if C is 1, it computes A - B by first taking the two's complement of B. The output, S, is a 4-bit value representing the result of the operation, while carry is generated for overflow detection.
