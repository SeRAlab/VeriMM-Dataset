Create a Verilog module that implements a simple SD card command decoder. The module should take a 4-bit command input and produce a 3-bit response based on the command. The responses are as follows:  
- Command 0000 (0) -> Response 000 (0)  
- Command 0001 (1) -> Response 001 (1)  
- Command 0010 (2) -> Response 010 (2)  
- Command 0011 (3) -> Response 011 (3)  
- Command 0100 (4) -> Response 100 (4)  
- Command 0101 (5) -> Response 101 (5)  
- For commands 0110 (6) and above, the response should be 111 (7).  
The module should use combinational logic to determine the response based on the command input.
