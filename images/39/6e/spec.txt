
Design a fixed-priority arbiter in Verilog. The arbiter should take in a set of request signals and grant a signal based on fixed priority. The priority is determined by the order of the request signals: req[0] has the highest priority, followed by req[1], and so on. The output grant signal should indicate which request has been granted. Ensure that the arbiter can handle concurrent requests and that only one grant signal is active at a time.
