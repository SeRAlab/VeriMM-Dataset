Develop a simple 4-bit calculator that performs basic arithmetic operations. The module takes two 4-bit inputs, `a` and `b`, along with a 2-bit control signal, `ctrl`, to select the desired operation. Based on the value of `ctrl`, the calculator can perform addition, subtraction, multiplication, or division on the inputs and output the result as a 4-bit value.
module top_module(
  input [3:0] a, b,
  input [1:0] ctrl,
  output reg [3:0] result
);
