Design a circuit that functions as an 8-bit adder. It takes two 8-bit input operands, `operand_a` and `operand_b`, and on each rising edge of the clock signal `clk`, it outputs the sum of these operands as a 7-bit value in the `out` register. The output is effectively limited to 7 bits, discarding the overflow if the sum exceeds 255.
module top_module(
  input clk,
  input [7:0] operand_a,
  input [7:0] operand_b,
  output reg [6:0] out
);
