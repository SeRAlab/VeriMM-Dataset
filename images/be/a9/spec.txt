Design a synchronous read-write memory module with a Reset functionality. The module has 4096 addressable locations, each capable of storing 25 bits of data. On a rising clock edge, when reset is activated, it initializes all memory entries to zero, setting specific predefined values at addresses 64, 65, and 66. When the reset is not active, if the write enable signal is high, it writes data to the specified address; otherwise, it reads data from that address and outputs it.
