

You are tasked with designing a verilog module that implements a 2-to-1 multiplexer. The module should have two 1-bit inputs (`a` and `b`), one 1-bit select input (`sel`), and one 1-bit output (`out`). When `sel` is high, the output should be equal to `a`. When `sel` is low, the output should be equal to `b`. You should use only combinational logic to implement the multiplexer.

Write a verilog module that implements the 2-to-1 multiplexer as described above. Your module should be named `mux_2to1` and should have the following interface:

```
module mux_2to1(
   input a,
   input b,
   input sel,
   output reg out
);
```
