
Design a Serial-in Parallel-out (SIPO) shift register in Verilog. The shift register should take in a serial input data stream and output the stored data in parallel. The shift register should have a width of 5 bits, and it should shift the data on the rising edge of a clock signal. An active low enable signal should control when the register stores new data. When enabled, the register should accept new serial data on the input pin and shift it into the register. When the enable signal is low, the register should maintain its current state.
