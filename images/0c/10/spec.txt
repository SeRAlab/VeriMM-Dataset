
Design a simple Automatic Repeat reQuest (ARQ) protocol in Verilog that will handle error correction for a single data bit transmission. The protocol should include a sender and a receiver. The sender transmits a data bit and awaits an acknowledgment (ACK) from the receiver, which indicates whether the bit was received correctly or if a retransmission is needed (NACK). Implement a mechanism to handle retransmission if a NACK is received. The sender should have a maximum of 3 retransmissions for a single bit before giving up.
