Design a simple arithmetic calculator that performs basic operations on two signed 32-bit integer inputs, `a` and `b`, based on a 2-bit operation selector `op`. When the `ready` signal is asserted, the calculator will perform addition, subtraction, multiplication, or division according to the value of `op`, producing the result as a signed 32-bit output.
module top_module(
    input wire signed [31:0] a,
    input wire signed [31:0] b,
    input wire [1:0] op,
    input wire ready,
    output reg signed [31:0] result
);
