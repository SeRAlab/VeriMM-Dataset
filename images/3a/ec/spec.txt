Design an SR flip-flop using Verilog. The flip-flop should have inputs S (set), R (reset), and a clock signal CLK. The output Q should reflect the state of the flip-flop based on the inputs and the clock signal. The flip-flop operates as follows: if S=1 and R=0, Q should be set to 1; if S=0 and R=1, Q should be reset to 0; if S=0 and R=0, Q should maintain its previous state. If both S and R are 1, this condition should be considered invalid.
