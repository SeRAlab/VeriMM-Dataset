Design a simple hash table with basic insertion and retrieval functionalities using Verilog. The hash table should support a fixed number of entries and handle collisions using chaining. The module should allow inserting key-value pairs and retrieving values based on their keys. The keys are 4-bit values, and the values are 8-bit values. The hash function should be a simple modulo operation based on the number of entries in the table. The module should also have a reset functionality to clear the table.
