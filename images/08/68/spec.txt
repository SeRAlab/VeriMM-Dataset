Design a 2x2 matrix multiplier in Verilog. The module should multiply two 2x2 matrices (A and B) and produce a 2x2 result matrix (C). The input matrices are provided as 4-bit wide inputs, and the output matrix is also 4-bit wide. The multiplication should be performed as follows:  
C[0][0] = A[0][0] * B[0][0] + A[0][1] * B[1][0]  
C[0][1] = A[0][0] * B[0][1] + A[0][1] * B[1][1]  
C[1][0] = A[1][0] * B[0][0] + A[1][1] * B[1][0]  
C[1][1] = A[1][0] * B[0][1] + A[1][1] * B[1][1]
