Design a 4-to-1 multiplexer that selects between two input signals (in0 and in1) based on two selection lines (sel0 and sel1). The output will be high when either in0 or in1 is active, influenced by the states of the selection lines. The output logic ensures that the correct input is routed to the output according to the combination of the selection inputs.
module top_module(
    input in0,
    input in1,
    input sel0,
    input sel1,
    output out
);
