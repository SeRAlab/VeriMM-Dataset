
You are tasked with designing a module that implements a binary counter with an enable signal. The counter should have a 4-bit output, and the enable signal should be active-high. When the enable signal is high, the counter should increment by 1 on every rising clock edge. When the enable signal is low, the counter should hold its current value. Your module should have the following inputs and outputs:
- `clk`: a clock input
- `en`: an active-high enable signal input
- `out`: a 4-bit binary output

Write a Verilog module that implements this counter.
