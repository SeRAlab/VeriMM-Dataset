Create a Verilog module that implements an 8-bit shift register with parallel load. The module should have the following specifications:
- `clk`: The clock signal.
- `reset`: An active-high synchronous reset signal.
- `load`: An active-high signal that triggers the parallel load.
- `data_in`: The 8-bit input data for parallel load.
- `shift_in`: The serial input data for shifting.
- `shift_out`: The serial output data after shifting.
- `q`: The 8-bit output representing the current state of the shift register.
