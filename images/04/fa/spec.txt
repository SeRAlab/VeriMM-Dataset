Design a 4-input logistic regression function using a combinational logic circuit. The circuit should take four binary inputs (x1, x2, x3, x4) and output a single binary value (y) based on the logistic regression formula: y = 1 / (1 + exp(-(w1*x1 + w2*x2 + w3*x3 + w4*x4 + b))), where w1, w2, w3, w4 are weights, and b is a bias. For simplification, use fixed-point representation for the weights and bias. You should implement the step function to determine the binary output. The weights will be: w1 = 1, w2 = 2, w3 = -1, w4 = 0.5, and b = -1.5.
