
Design a 16-bit CRC (Cyclic Redundancy Check) generator using Verilog. The CRC polynomial to be used is `x^16 + x^12 + x^5 + 1`. The generator should take a 16-bit data input and a start signal to begin the CRC calculation. The output should be a 16-bit CRC value. The design should also include a reset signal to initialize the CRC value.
