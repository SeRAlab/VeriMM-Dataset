
Design an SR flip-flop using Verilog. The flip-flop should have two inputs, S (set) and R (reset), and one output Q. When S is asserted, Q should be set to 1. When R is asserted, Q should be reset to 0. If both S and R are low, Q should maintain its previous state. If both S and R are high, the behavior is undefined, and you can choose to make Q 0 in this case.
