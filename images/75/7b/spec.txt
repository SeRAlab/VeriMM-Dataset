Design a synchronous RAM module with configurable data and address widths. The module features a write operation controlled by the write enable signal (WEN) which, when asserted, stores the input data (WDAT) at the specified write address (WADR) on the rising edge of the clock (CLK). Additionally, it supports a read operation, where the data at a specified read address (RADR) is output to RDAT on the same clock edge, with the read enabled by the read enable signal (REN). This module is suitable for general memory applications requiring synchronous read and write access.
