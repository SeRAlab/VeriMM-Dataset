
Design a Bluetooth Signal Controller that manages the state of a Bluetooth module. The controller should have the following states: 
- IDLE: Waiting for a signal
- CONNECTED: Bluetooth is connected
- DISCONNECTED: Bluetooth is disconnected
 
The controller should respond to the following inputs:
- 'connect' signal to transition from IDLE to CONNECTED state.
- 'disconnect' signal to transition from CONNECTED to DISCONNECTED state.
- 'reset' signal to go back to IDLE state from any state.

The output should be the current state of the Bluetooth module in a 2-bit encoding:
- 00: IDLE
- 01: CONNECTED
- 10: DISCONNECTED
