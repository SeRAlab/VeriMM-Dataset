
Design a FIFO (First-In-First-Out) queue with the following specifications:
- The FIFO should have a width of 8 bits and can store up to 4 words.
- It should have inputs for data to be pushed into the queue, a read enable signal, a write enable signal, and a reset signal.
- The outputs should include the data at the front of the queue and an empty flag indicating whether the queue is empty.
