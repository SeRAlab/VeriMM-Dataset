Design a Verilog module for a 10-bit synchronous BCD counter with enable and synchronous reset. The counter should count from 0 to 999 and reset on overflow.
// (1) enable: Enables the counter. Active high.
// (2) reset: Synchronous reset of the counter. Active high.
// (3) clk: Clock signal.
// (4) q: 10-bit output of the counter.
module top_module(
	input clk,
	input enable,
	input reset,
	output reg [9:0] q);
