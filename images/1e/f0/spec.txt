Design a state machine that behaves as follows: it has two states, S0 and S1. It will start in state S0. On receiving an input signal 'input_signal' that transitions from 0 to 1, the state should transition from S0 to S1. If the input_signal remains 1 for three clock cycles, the state should transition back to S0. If the input_signal transitions back to 0 at any time, the state should remain in S0 until it transitions to 1 again.
