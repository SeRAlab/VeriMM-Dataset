Design a circuit that converts a 4-bit binary input into a one-hot output format. The module takes a 4-bit binary input, 'B', and activates one of the four output lines (O0 to O3) based on the value of 'B'. When 'B' corresponds to a specific value (1, 2, 4, or 8), only the respective output is set to high (1), while all other outputs remain low (0). If 'B' has any other value, all outputs are set to low.
module top_module(
    input [3:0] B,
    output reg O0,
    output reg O1,
    output reg O2,
    output reg O3
);
