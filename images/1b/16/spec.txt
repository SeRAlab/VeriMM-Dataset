Design an 8-bit DRAM cell that can write and read data. The cell should have a data input signal (data_in), a data output signal (data_out), a write enable signal (we), and a clock signal (clk). When the write enable signal is high, the data from data_in should be stored in the cell on the rising edge of the clock. When write enable is low, the current stored data should be output to data_out on the rising edge of the clock.
