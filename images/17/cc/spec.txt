
Design a convolutional encoder with the rate of 1/2. The encoder should take a 1-bit input and produce a 2-bit output. The encoder uses the following polynomial representation for the convolutional encoding:
- Output bit 0 is generated by XORing the current input and the previous input (memory).
- Output bit 1 is generated by XORing the current input and the previous two inputs (memory).
You should implement this encoder as a module and ensure that it handles the input properly over a defined clock cycle.
