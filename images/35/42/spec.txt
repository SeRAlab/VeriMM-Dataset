
Create a Verilog module that implements a 16-QAM (Quadrature Amplitude Modulation) mapper. The module should take 4 bits as input, representing the symbol to be mapped, and produce 2 output signals representing the in-phase (I) and quadrature (Q) components. The mapping should be as follows:
- 0000 -> (1, 1)
- 0001 -> (1, 3)
- 0010 -> (1, 1)
- 0011 -> (3, 1)
- 0100 -> (3, 3)
- 0101 -> (3, 1)
- 0110 -> (1, 3)
- 0111 -> (1, 1)
- 1000 -> (1, 3)
- 1001 -> (3, 3)
- 1010 -> (3, 1)
- 1011 -> (1, 1)
- 1100 -> (3, 1)
- 1101 -> (1, 3)
- 1110 -> (1, 1)
- 1111 -> (3, 3)
