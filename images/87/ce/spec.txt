Design a circuit that drives a 7-segment display based on a 4-bit binary input (`number`). When enabled, the circuit maps the input value (0 to 15) to the corresponding pattern needed to display hexadecimal digits (0-9 and A-F) on the display, while defaulting to an "off" state (all segments off) when the input does not correspond to a valid hex digit. The output (`seven_seg`) represents the segment states to illuminate the appropriate segments of the display for each digit.
module top_module(
    input [3:0] number,
    output reg [7:0] seven_seg,
    input enable
);
