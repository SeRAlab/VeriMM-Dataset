Design an 8-bit DRAM cell that can store a single bit of data in each cell. The cell should have the following inputs: a data input (1-bit), a write enable signal (we), a read enable signal (re), and an address input (3-bit) to select one of the 8 cells. The output should be the data stored in the selected cell when the read enable is activated. When the write enable is activated, the input data should be stored in the selected cell.
