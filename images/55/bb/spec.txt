Design a circuit that performs both XOR and XNOR operations on two 4-bit inputs, `a` and `b`. The output is determined by the `select` signal: when `select` is high, the output will be the XNOR result of the inputs; when `select` is low, the output will be the XOR result. The operations are triggered on the rising edge of the clock.
module top_module(
    input [3:0] a,
    input [3:0] b,
    input select,
    input clk,  // Added clk as an input
    output reg [3:0] out
);
