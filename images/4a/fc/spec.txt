Design a 3-to-1 multiplexer with two selection inputs (sel0 and sel1) and two data inputs (in0 and in1). When both selection inputs are low (sel0=0, sel1=0), the output (out) will be in0. If sel0=1 and sel1=0, the output will be in1. If sel0=0 and sel1=1, the output will be hardwired to LOW. When both selection inputs are high (sel0=1, sel1=1), the output will resolve to an unknown state (1'bx). This design allows the selection of one active input or a predetermined output based on the selection signals.
module top_module(
  output reg out,
  input in0,
  input in1,
  input sel0,
  input sel1
);
