Design a circuit that functions as a flag indicator based on a comparison of two 2-bit inputs. The circuit sets the output "bandera" high when the inputs "Rx" and "identidad" are equal, and it is reset to low either when a reset signal is activated or when the inputs do not match. The operation is synchronized with the clock, ensuring that changes to "bandera" occur only on the rising edge of the clock signal.
module top_module(
		input [1:0]Rx,
		input clk, 
		input reset,
		input [1:0] identidad, 
		output reg bandera
    );
