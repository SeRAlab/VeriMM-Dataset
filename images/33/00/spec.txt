
Design a 4-to-1 multiplexer with data forwarding. The multiplexer should take four 4-bit inputs (A, B, C, D) and a 2-bit select input (S) to choose which input to forward to the output. Additionally, if the selected input is equal to a 4-bit value defined as "FORWARD", the output should forward the previous output instead. The "FORWARD" value is defined as 4'b1010.
