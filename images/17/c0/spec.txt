Design a Verilog module that implements a simple state machine for a WiFi module. The state machine should have the following states: IDLE, CONNECTING, CONNECTED, and DISCONNECTED. The module should have inputs for a start signal and a disconnect signal, and an output that represents the current state. The state transitions should be:  
- From IDLE to CONNECTING on the start signal.  
- From CONNECTING to CONNECTED if a connection is successful (simulated by a signal).  
- From CONNECTED to DISCONNECTED on the disconnect signal.  
- From DISCONNECTED back to IDLE on a new start signal.
