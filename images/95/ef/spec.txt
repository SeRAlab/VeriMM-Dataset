Create a Verilog module for an 8-bit Johnson counter with synchronous reset and enable signals. The module should have an input clock signal (clk), an input enable signal (en), an input synchronous reset signal (rst), and an 8-bit output signal (count). On the rising edge of the clock, if reset is high, count should be set to 8'b00000000. If enable is high, the counter should shift its bits to the right and the inverted MSB should be placed at the LSB.
