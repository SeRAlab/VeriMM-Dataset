Design an IIR filter with a feedback loop where the output at each clock cycle is computed based on the previous output and current input samples. The filter should be able to process 8-bit input data and produce an 8-bit output. Implement the filter using a simple first-order difference equation: y[n] = a * x[n] + b * y[n-1], where 'a' and 'b' are coefficients defined in the module parameters.
