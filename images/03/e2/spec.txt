Design a Verilog module that implements a basic PNG filter, specifically the Paeth filter. The module should take three inputs, which are the left pixel (L), above pixel (A), and upper-left pixel (U), and output the filtered pixel value (P) according to the Paeth algorithm. The Paeth filter is defined as follows:
1. Compute the differences: 
   - P = L + A - U
2. Choose the closest of the three pixels (L, A, U) to P. 
3. Output the chosen value as the filtered pixel.
