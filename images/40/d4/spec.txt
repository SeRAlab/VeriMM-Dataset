
Design a 1-bit SRAM cell with the following specifications:
- The SRAM cell has a single data input (D), a single data output (Q), a write enable signal (WE), and a clock signal (CLK).
- When WE is high, the data input (D) should be written into the cell at the rising edge of the clock.
- When WE is low, the data output (Q) should reflect the stored value in the SRAM cell.
