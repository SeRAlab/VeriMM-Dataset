Implement the Verilog module based on the following description.
Design a state machine with 1 input (in) and 1 output (out). The state machine has the following states and their corresponding outputs:
1. state G (out=1).
2. state H (out=0).
3. state I (out=1).

State transitions:
1. From state G: If in = 0, then transition to state H. If in = 1, then transition to state I.
2. From state H: If in = 0, then remain in state H. If in = 1, then transition to state G.
3. From state I: If in = 0, then transition to state G. If in = 1, then remain in state I.

At reset, the state machine starts in state "G". Derive next-state logic equations and output logic equations by inspection using the following one-hot encoding: (G, H, I) = (3'b001, 3'b010, 3'b100).

Write code that generates the following equations:

- G_next -- next-state logic for state G
- H_next
- I_next
- out -- output logic

module fsm_model(
    input in,
    input [2:0] state,    // 3-bit one-hot current state
    output reg G_next,
    output reg H_next,
    output reg I_next,
    output reg out
);
