Design a JK latch in Verilog. The JK latch should have two inputs (J and K), one clock input (CLK), and one output (Q). The latch should operate such that when CLK is high, the output Q follows the behavior defined by J and K. If J and K are both low, Q remains unchanged. If J is high and K is low, Q should set to 1. If J is low and K is high, Q should reset to 0. If both J and K are high, Q should toggle its state. The output should be a reg type.
