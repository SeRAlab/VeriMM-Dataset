Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a memory encryption and decryption block. 
The memory encryption and decryption block encrypts and decrypts data stored in memory using an encryption algorithm. 
The module should have the following inputs and outputs:

Inputs: 
- clk: clock signal
- reset: reset signal
- data_in: input data to be encrypted or decrypted
- key: encryption or decryption key
- enable: enable signal for encryption or decryption

Outputs: 
- data_out: output data after encryption or decryption

Your module should implement the following functionality:
- When the enable signal is low, the output should be the same as the input (i.e., no encryption or decryption is performed).
- When the enable signal is high, the input data should be encrypted or decrypted using the key.
- The encryption and decryption algorithm used should be a simple bitwise XOR operation between the input data and the key.
- The key should be a user-defined input to the module.

To implement the memory encryption and decryption block, you should use Verilog code to define the XOR operation between the input data and the key when the enable signal is high. 
You should then use this function to generate the output data. 
You should also include logic to ensure that the output data is the same as the input data when the enable signal is low. 
Finally, you should ensure that the circuit is synchronous to the clock signal and that it can be reset using the reset signal.
