

You are tasked with implementing a module in Verilog that emulates a register file with 32 registers. The module should have the following inputs:

- `clk`: a clock signal
- `wen`: a write enable signal
- `waddr`: a 6-bit write address
- `raddr1`: a 6-bit read address for the first output
- `raddr2`: a 6-bit read address for the second output
- `wdata`: a 32-bit write data

The module should have the following outputs:

- `rdata1`: a 32-bit output corresponding to the value stored in the register specified by `raddr1`
- `rdata2`: a 32-bit output corresponding to the value stored in the register specified by `raddr2`

The module should store the 32 registers in an array of 32 32-bit registers called `regs`. The module should update the value of the register specified by `waddr` with the value of `wdata` on the positive edge of the clock if `wen` is high. The module should output the value of the register specified by `raddr1` on `rdata1` and the value of the register specified by `raddr2` on `rdata2` at all times.

You should implement this module in Verilog within 200 lines of code.
