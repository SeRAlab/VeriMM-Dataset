Design a five-bit wide output LED driver that interprets a nine-bit binary key input. Depending on which of the first six bits of the key_input is set, one of five predetermined patterns will be driven to the led_output: specific bits are turned on corresponding to values 1 to 5, while the sixth bit resets the output to zero, and the seventh bit turns all outputs on. Any input that does not match these conditions results in an undefined output.
module top_module(
    input [8:0] key_input,
    output reg [4:0] led_output
);
