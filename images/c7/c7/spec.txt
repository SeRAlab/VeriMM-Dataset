

Write a Verilog module for a 4-bit binary-to-Gray code converter. The module should have the following ports:

- `input [3:0] binary`: the 4-bit binary input
- `output [3:0] gray`: the 4-bit Gray code output

The module should use combinational logic to convert the binary input to Gray code output. You may not use any built-in Verilog functions or operators for this conversion.
