
Create a GPIO controller that has the following functionality:
- It has 8 GPIO pins which can be configured as input or output.
- A register holds the current state of the GPIO pins.
- A control signal determines whether the GPIO pins should operate in input or output mode.
- If in output mode, the state of the GPIO pins can be set through a write operation.
- If in input mode, the state of the GPIO pins can be read back through a read operation.
- The controller should also have an enable signal that must be high for the controller to operate.
