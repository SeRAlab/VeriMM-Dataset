
Design a simple Automatic Repeat reQuest (ARQ) error correction system that utilizes a simple acknowledgment mechanism. The system will consist of a sender that can send a data bit and a receiver that checks for errors. If an error is detected, the receiver will request the sender to resend the data. Implement your solution in Verilog with the following specifications:
- The sender will send a 5-bit data.
- The receiver will check for parity (even parity).
- The sender will resend the data if the receiver sends a negative acknowledgment.
