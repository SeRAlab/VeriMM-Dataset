Design an interrupt controller that manages two types of interrupts: type A and type B. The controller should have the following inputs: clk (clock), rst (reset), intA (interrupt type A), intB (interrupt type B). It should output a signal 'irq' that goes high for one clock cycle whenever an interrupt is detected. The controller should prioritize interrupt type A over type B. If both interrupts are active at the same time, only irq for type A should be asserted. The irq signal should be reset when the rst signal is high.
