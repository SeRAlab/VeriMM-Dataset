Design a 5-bit shift register with load capability. The register can either be loaded with a parallel input (`data`) when the `load` signal is asserted or it can perform a shift operation where a new input bit (`si`) is shifted in at the least significant bit position on each clock cycle. The most significant bit of the shift register is output as `so`. The internal state of the shift register is managed using a combination of D flip-flops to ensure proper sequential storage and shifting of data.
module top_module(
    clock,
    si,
    load,
    data,
    so
);
