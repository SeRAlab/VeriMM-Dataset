
Design a SR flip-flop with asynchronous reset and set inputs. The flip-flop should have inputs S (set), R (reset), and a clock signal CLK. The output should be Q, which reflects the state of the flip-flop. If S and R are both high, the output should remain unchanged. If reset (R) is high, the output Q should be 0. If set (S) is high, the output Q should be 1. The output should only change on the rising edge of the clock signal.
