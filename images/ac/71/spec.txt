Design a 4-bit up/down counter that increments or decrements its value based on the input control signal 'in' on each positive edge of the clock 'clk'. When 'in' is high, the counter increments; when 'in' is low, it decrements. The counter resets to zero when the 'rst' signal is asserted. The current count value is output on the 'out' signal.
