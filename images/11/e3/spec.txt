Design a 1-bit SRAM cell using Verilog. The SRAM cell should have the following inputs: `data_in`, `write_enable`, `read_enable`, and an output `data_out`. When `write_enable` is high, the value of `data_in` should be stored in the SRAM cell. When `read_enable` is high, the stored value should be outputted on `data_out`. Ensure proper handling of control signals to avoid conflicts and implement a reset functionality to clear the stored value.
