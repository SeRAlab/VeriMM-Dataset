Design a Direct Memory Access (DMA) controller that can transfer data from a source address to a destination address in memory. The controller should have a start signal to initiate the transfer, an input for the source address, an input for the destination address, a data input line, and a data output line. Once the transfer is complete, an output signal should indicate the completion of the transfer. The controller should support a simple handshaking mechanism, where the transfer starts on the rising edge of the start signal and completes on the next clock edge after the data is transferred.
