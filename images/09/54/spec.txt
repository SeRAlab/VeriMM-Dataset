Design a SR flip-flop with asynchronous reset and set inputs. The flip-flop should have inputs S (set), R (reset), clk (clock), and outputs Q and Q_n (Q not). The behavior should be such that when S is high, Q is set to high. When R is high, Q is reset to low. If both S and R are low, the output Q should follow the clock edge. The flip-flop should also have an asynchronous reset that sets Q to low regardless of the clock when reset is high.
