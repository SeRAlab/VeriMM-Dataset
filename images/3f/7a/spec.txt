
Design a simple SATA controller state machine that has the following states: IDLE, ACTIVE, and ERROR. The controller starts in the IDLE state. It transitions to ACTIVE when a 'start' signal is received. If an 'error' signal is received in the ACTIVE state, it transitions to the ERROR state. The controller returns to the IDLE state after one clock cycle in the ERROR state or when the 'reset' signal is asserted.
