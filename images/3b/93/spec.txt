Design a 2-channel DMA controller that transfers data from a source to a destination based on a control signal. The controller should have two channels (Channel 0 and Channel 1), each with a start signal, a busy signal, and a data register. When a start signal is received on either channel, the corresponding busy signal should be asserted while the transfer is in progress. The transfer completes when a stop signal is received. The data register should hold the data being transferred.
