
Design a fan speed controller that adjusts the speed of a fan based on temperature levels. The controller should read a temperature input and output the corresponding fan speed. The fan speed should be defined as follows:
- If the temperature is less than 20 degrees Celsius, the fan speed is 0 (off).
- If the temperature is between 20 and 25 degrees Celsius, the fan speed is 1 (low).
- If the temperature is between 26 and 30 degrees Celsius, the fan speed is 2 (medium).
- If the temperature is greater than 30 degrees Celsius, the fan speed is 3 (high).
The controller should implement a simple state machine to handle the temperature readings and fan speed outputs.
