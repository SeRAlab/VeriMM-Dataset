Module name:
    up_down_counter

    clk: Clock signal used for synchronous operations.
    rst_n: Reset signal. Defined as 0 for reset and 1 for reset signal inactive.
    dir: Direction signal. When high, the counter counts up. When low, the counter counts down.

Output ports:
    count: 3-bit output representing the current count value.

Implementation:
On every positive clock edge, if the reset signal (rst_n) is low, the counter value (count) should be set to 0. If the reset signal is high, the counter should increment by 1 if the direction signal (dir) is high, and decrement by 1 if the direction signal is low.
