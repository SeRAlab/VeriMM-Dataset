

You are tasked with designing a verilog module that implements an 8-bit, 2-to-1 multiplexer. The module should have the following inputs and outputs:

Inputs:
- `a`: 8-bit input signal
- `b`: 8-bit input signal
- `sel`: 1-bit selection signal (0 for `a` input, 1 for `b` input)

Outputs:
- `out`: 8-bit output signal

Implement the module using behavioral verilog.
