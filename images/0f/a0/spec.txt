
Design a JK latch using Verilog. The JK latch should have inputs J, K, and a clock signal (CLK). The output should be Q and its complement Qn. The latch should toggle its state on the rising edge of the clock based on the values of J and K. If J and K are both low, the output should remain unchanged. If J is high and K is low, the output should set to high. If J is low and K is high, the output should set to low. If both J and K are high, the output should toggle.
