Design a simple WiFi module controller that manages the connection state (connected or disconnected). The module should have a clock signal, a reset signal, and a connection request input. When the reset signal is asserted, the module should initialize to a disconnected state. When a connection request is received, the module should transition to a connected state on the next clock cycle. If a connection request is not received, the state should remain unchanged. The output should indicate the current connection state: 1 for connected, 0 for disconnected.
