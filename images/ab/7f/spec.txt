Design a positive-edge-triggered D flip-flop with preset functionality and enable control. The flip-flop outputs Q, which is initialized to a specified value (INIT). On a rising clock edge, if the PRESET signal is high, the output Q is set to 1. Otherwise, if the CE (clock enable) signal is active, the output Q takes the value of the input D. This design allows for synchronous data storage with specific conditions for presetting and enabling data capture.
