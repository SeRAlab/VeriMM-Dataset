Design a synchronous random-access memory (RAM) module that supports both read and write operations while being initialized with a clock signal. When the `init` signal is asserted, the module allows data to be written to the memory from `mem_dat_in` at the specified `mem_addr` if the `wr` signal is high. Conversely, it retrieves data from the memory and outputs it to `mem_dat_out` when the `rd` signal is activated. The memory can store up to 256 addresses, each capable of holding 16 bits of data.
module top_module(clk, init, mem_dat_in, mem_dat_out, mem_addr, rd, wr);
