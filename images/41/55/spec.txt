Design a circuit that performs a 4-input NOR function. The circuit takes four inputs: A, B, C, and D (with D being active low), and produces an output X that is the logical NOR of these inputs, effectively implementing the operation X = ~(A | B | C | D). The output X will be LOW if any of the inputs are HIGH, and will be HIGH only if all inputs are LOW.
module top_module(
    input  A  ,
    input  B  ,
    input  C  ,
    input  D_N,
    output X
);
