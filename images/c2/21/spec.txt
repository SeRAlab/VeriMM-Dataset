

You are tasked with designing a Verilog module for a 4-bit adder/subtractor. The module should have two 4-bit inputs, A and B, and a control input, C, which determines whether the module should perform addition or subtraction. The module should output a 4-bit sum, S, and a carry-out signal, Cout.

The module should be designed to be synthesizable and should be no more than 200 lines of Verilog code. You may use any standard Verilog constructs, including if/else statements and for loops.

Assume that the inputs A and B are always valid 4-bit values and that the control input C will be either 0 or 1.

You should also ensure that your module is named "adder_subtractor" and has the following ports:

- input [3:0] A
- input [3:0] B
- input C
- output [3:0] S
- output Cout
