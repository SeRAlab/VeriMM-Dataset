

You have been tasked to design a verilog module that will implement a 2:1 multiplexer with an enable signal. The module should have the following ports:

- `data_in_0`: input, one bit data signal
- `data_in_1`: input, one bit data signal
- `enable`: input, one bit enable signal
- `data_out`: output, one bit data signal

The module should output `data_in_0` when `enable` is low and `data_in_1` when `enable` is high.

Design the verilog module for the 2:1 multiplexer with enable signal.
