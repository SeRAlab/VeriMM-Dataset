Design a memory module for video data that allows pixel color information to be written and read based on specified x and y coordinates. The module supports writing color values (4 bits each for Red, Green, and Blue) to a 640x480 pixel memory array when the write signal is active. When reading, it outputs the corresponding color channels of the pixel at the specified coordinates for display purposes.
module top_module(
	input wr,
	input [10:0] pos_x,
	input [10:0] pos_y,
	input [3:0] Red_in,
	input [3:0] Green_in,
	input [3:0] Blue_in,
	output [3:0] Red_out,
	output [3:0] Green_out,
	output [3:0] Blue_out
	);
