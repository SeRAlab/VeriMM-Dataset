Design a dual-edge-triggered D flip-flop with asynchronous set and reset functionalities. The flip-flop captures the value of input D on the negative edge of the clock (CLK_N), and it can be directly set or reset with active low signals (SET_B and RESET_B). The module outputs the stored value as Q, while Q_N provides the inverted output. Utilize a standard cell approach alongside power and ground connections for reliable operation, making it suitable for integration into larger digital systems.
