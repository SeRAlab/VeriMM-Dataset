Design a 4-bit DRAM cell that can store a 4-bit data word and allows reading and writing to it. The DRAM cell should have the following ports: a clock input (clk), a write enable (we), a 4-bit data input (data_in), a 4-bit data output (data_out), and a 2-bit address input (addr). The cell should support writing data when we is high and the clock rises, and it should output the stored data when we is low and the clock rises.
