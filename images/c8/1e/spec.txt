

You have been tasked with designing a module that will take in several inputs and output a single signal. Specifically, you need to create a Verilog module that will implement a 2-input AND gate with an additional input and output. The module should be named "and_gate_extra" and should take in the following inputs and output:

- Input A (1 bit)
- Input B (1 bit)
- Input C (1 bit)
- Output Y (1 bit)

Your module should be able to compute the following Boolean expression:

Y = A & B & ~C

In other words, the output Y should be 1 if and only if A and B are both 1 and C is 0. You can assume that all inputs are valid (i.e., either 0 or 1).

Your module should be contained within 200 lines of Verilog code and should only use standard Verilog constructs (i.e., no system tasks or functions).
