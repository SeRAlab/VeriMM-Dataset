Design a digital logic module that implements a variety of fundamental logic gates. The module takes three input signals (in1, in2, and in) and produces five outputs: out_AND for the logical AND operation between in1 and in2, out_OR for the logical OR operation between in1 and in2, out_NOT for the logical NOT operation on in, out_XOR for the logical XOR operation between in1 and in2, and out_XNOR for the logical XNOR operation between in1 and in2. This module can be used in digital circuits requiring basic combinational logic functions.
module top_module(
  input in1,
  input in2,
  input in,
  output out_AND,
  output out_OR,
  output out_NOT,
  output out_XOR,
  output out_XNOR
);
