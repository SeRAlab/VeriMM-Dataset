Design a module that functions as a source immediate multiplexer. It takes an 8-bit instruction as input and selects between two different immediate values based on the control signals `src1sel` and `l_sw`. When `src1sel` is asserted, it outputs a sign-extended version of the instruction's lower 8 bits to a 16-bit `imm_src1`. If `l_sw` is asserted instead, it outputs a sign-extended version of the lower 4 bits of the instruction. If neither control signal is active, it outputs zero. The module also provides an enable output `en`, which is asserted whenever either control signal is high.
module top_module(instr, src1sel, l_sw, en, imm_src1);
