
Design a FIFO (First-In-First-Out) queue in Verilog. The FIFO should have a parameterized depth, with the following functionalities:
- Enqueue: Add data to the queue.
- Dequeue: Remove data from the queue.
- Check if the queue is empty.
- Check if the queue is full.
Implement appropriate control signals for enqueue and dequeue operations, along with a reset signal.
