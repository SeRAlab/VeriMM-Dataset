Implement a 16-bit register with load enable and synchronous reset. The register holds its value unless the load enable signal is asserted.

Module name:
    register_16bit

Input ports:
    clk: Clock signal used for synchronous operation.
    rst: Active-high synchronous reset signal. Defined as 1 for reset and 0 for reset signal inactive.
    load: Load enable signal to update the register value.
    data_in: 16-bit input data to be loaded into the register.

Output ports:
    data_out: 16-bit output representing the current register value.

Implementation:
The register is triggered on the positive edge of the clock signal (posedge clk).
If the reset signal is asserted (rst == 1), the register is cleared to 0 on the next clock cycle.
If the load signal is asserted (load == 1), the register is loaded with data_in.
