Design a JK latch using Verilog. The JK latch should have inputs J, K, and a clock (CLK), and outputs Q and Qn. The latch should toggle its state based on the JK inputs at the rising edge of the clock. If J and K are both 0, the output should remain unchanged. If J is 1 and K is 0, the output Q should be set to 1. If J is 0 and K is 1, the output Q should be set to 0. If both J and K are 1, the output Q should toggle.
