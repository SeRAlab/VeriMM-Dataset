
Design a UART (Universal Asynchronous Receiver-Transmitter) controller in Verilog that transmits 8 bits of data serially. The module should have inputs for the data to be transmitted, a send signal, and a clock. The output should be the serial data being transmitted. The UART should support a baud rate of 9600, assuming a clock frequency of 1.0 MHz. Implement the state machine to manage the transmission of data bits, starting with a start bit, followed by 8 data bits, and ending with a stop bit.
