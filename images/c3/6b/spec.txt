

You are tasked with designing a module in Verilog that implements a 4-to-1 multiplexer. The module should have four input ports, each with a single bit, and a select port that is two bits wide. The output of the module should be a single bit that is the value of the selected input.

The module should be named "mux_4to1" and should be contained within a single Verilog file that is no more than 200 lines long. You should use the "always" block to implement the logic of the module.

You may assume that the input values will be either 0 or 1 and that the select value will be a binary number between 0 and 3. If the select value is outside this range, the output value should be 0.
