Design a 4-input, 1-output multiplexer that selects one of four 8-bit inputs (a, b, c, or d) based on a 2-bit operational code (op). When op is '00', the output y is assigned the value of input a; for '01', it takes the value of b; for '10', it selects c, and for any other value, it defaults to d. This module facilitates conditional data routing based on the specified operation code.
