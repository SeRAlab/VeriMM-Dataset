Design an 8-bit DRAM cell that supports read and write operations. The cell should have a data input (D), a data output (Q), a write enable (WE), a read enable (RE), and an 8-bit address input (ADDR). When WE is high, the data on D should be written to the cell at the address ADDR. When RE is high, the data at the address ADDR should be output on Q. Ensure that both read and write operations can't occur simultaneously.
