Design a Verilog module that implements a simple NAT (Network Address Translation) mechanism. The module should take an internal IP address and a corresponding external IP address as inputs. The module should have a control signal to indicate whether to perform the translation. If the control signal is high, the output should be the external IP address; if it's low, the output should be the internal IP address. Additionally, there should be a reset signal that resets the output to the internal IP address.
