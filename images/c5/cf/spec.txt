
You are tasked with designing a module in Verilog that will take a 16-bit input signal and perform a bitwise AND operation with a 16-bit mask. The output of the module should be the result of this operation. The mask should be stored in a separate 16-bit input signal. The module should also include a control input signal that will enable or disable the operation.

The module should have the following ports:
- `input [15:0] data_in`: the 16-bit input signal
- `input [15:0] mask`: the 16-bit mask
- `input enable`: the control input signal that enables or disables the operation
- `output [15:0] data_out`: the 16-bit output signal

The module should perform the following operation:
- If `enable` is 0, `data_out` should be equal to `data_in`.
- If `enable` is 1, `data_out` should be equal to `data_in` AND `mask`.

Write a Verilog module that meets these requirements within 200 lines of code.
