Design a 1-bit DRAM cell that can store a single bit of data and can be read and written to. The DRAM cell has a data input (D), a data output (Q), a word line (WL) for activating the cell, and a bit line (BL) for reading the data. The read operation should occur when WL is high, and the write operation should occur when WL is high and D is valid. The output Q should reflect the stored data when a read operation is performed.
