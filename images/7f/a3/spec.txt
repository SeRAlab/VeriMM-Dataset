Design a D flip-flop with asynchronous clear and set functionality. On the rising edge of the clock (CLK), the module captures the input (D) and outputs it (Q). If the clear (CLR) signal is asserted low, the output is reset to 0 (Q) while the complementary output (QN) is set to 1. Conversely, if the set (SET) signal is asserted high, the output is set to 1 (Q) and the complementary output (QN) is driven to 0.
