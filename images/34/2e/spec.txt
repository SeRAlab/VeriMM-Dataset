Design a simple SD card interface controller that handles read and write operations. The controller should have an input `cmd` to specify the operation (0 for read, 1 for write), an 8-bit `data_in` for input data during write operations, and an 8-bit `data_out` for output data during read operations. The controller should have a clock signal `clk` and a reset signal `rst`. On reset, the output data should be cleared. During a write operation, the input data should be stored in an internal register, and during a read operation, the output data should be set to the value of that register.
