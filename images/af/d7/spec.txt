Design a 4-to-1 multiplexer that takes a 4-bit wide input and uses a 2-bit select signal to output one of the four inputs. When the select signal is 00, the output is the first input; for 01, it selects the second input; for 10, the third input; and for 11, the fourth input is chosen as the output.
module top_module(
    input [3:0] inputs,
    input [1:0] select,
    output reg out
);
