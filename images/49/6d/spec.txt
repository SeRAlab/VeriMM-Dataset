Design a 6-bit wide sequential counter with asynchronous clear functionality. The output Q represents the current count value and is updated on the rising edge of the slowest synchronous clock when the count enable signal (seq_cnt_en) is active. The next state of the counter is determined through a series of lookup tables (LUTs), which implement specific combinational logic to define the counting sequence. The counter resets to zero when the seq_clr input is asserted.
