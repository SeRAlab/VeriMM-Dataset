Design a JK latch using Verilog. The JK latch should have inputs J, K, and a clock signal CLK. The output Q should change state based on the values of J and K when the CLK signal transitions from low to high. The behavior should be as follows: if J and K are both low, Q remains unchanged; if J is high and K is low, Q should set to high; if J is low and K is high, Q should reset to low; if both J and K are high, Q should toggle its state.
