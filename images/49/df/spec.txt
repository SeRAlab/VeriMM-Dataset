Design a module that performs simultaneous counting using both a binary counter and a Gray code counter, with a synchronous active-high reset feature. The binary counter increments on each clock cycle, resetting to zero upon activation of the reset signal. The Gray code counter cycles through its states in a specific sequence, also resetting on the same signal. The output is the 5-bit binary sum of both counters, allowing for combined values to be observed in a single output.
module top_module(
  input clk,
  input reset, // Synchronous active-high reset
  output [4:0] sum // Binary sum output
);
