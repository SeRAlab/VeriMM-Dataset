Design a 4-bit comparator that outputs a 3-bit signal indicating the relationship between two 4-bit inputs, A and B. The output, O, will be set to 000 if A is less than B, 001 if A is equal to B, and 010 if A is greater than B. This module thus provides a mechanism to determine and signal the relative ordering of two 4-bit values.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output reg [2:0] O
);
