Implement an 8-bit down counter with a synchronous reset. The counter should decrement the count on each positive clock edge. If the reset signal is high, the counter should reset to 8'b11111111 on the next positive clock edge.

Module name:
    down_counter

Input ports:
    clk: Clock signal used for synchronous operations.
    rst: Active-high reset signal. Defined as 1 for reset and 0 for reset signal inactive.

Output ports:
    count: Output 8-bit down counter value.

Implementation:
Counter Logic:
The module includes an 8-bit register, count, to store the current counter value.
On the positive edge of the clock signal (clk) or the positive edge of the reset signal (rst), the module updates the counter value. If the reset signal (rst) is high, indicating a reset condition, the counter value is set to 8'b11111111. Otherwise, the counter value is decremented by 1.
