Design a multi-port RAM module featuring two independent read ports and one write port. This RAM can store data with a width of 8 bits and a depth of 256 entries. When the write_enable signal is asserted, data is written to the specified address. Simultaneously, if read_enable1 or read_enable2 is asserted, the module outputs the data from the respective read addresses for both ports. This design allows for simultaneous reading and writing operations, enhancing memory access efficiency in applications requiring concurrent data processing.
module top_module(
  input write_enable,
  input [ADDRESS_WIDTH-1:0] write_address,
  input [width-1:0] write_data,
  input read_enable1,
  input [ADDRESS_WIDTH-1:0] read_address1,
  input read_enable2,
  input [ADDRESS_WIDTH-1:0] read_address2,
  output reg [width-1:0] read_data1,
  output reg [width-1:0] read_data2
);
