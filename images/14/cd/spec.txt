Design a 5-bit EEPROM cell read/write control logic. The design should take a 5-bit input data (DATA_IN), a read enable signal (READ_EN), and a write enable signal (WRITE_EN). When WRITE_EN is high, DATA_IN should be stored in the EEPROM output (DATA_OUT). When READ_EN is high, DATA_OUT should output the currently stored value. If both READ_EN and WRITE_EN are low, DATA_OUT should hold its previous state.
