Design a 4-bit wide multiplexer that selects one of four 4-bit input signals (a, b, c, or d) based on a 2-bit selection input (sel). Depending on the value of sel, the output (out) will reflect the selected input: when sel=0, output a; when sel=1, output b; when sel=2, output c; and when sel=3, output d. If sel has an invalid value, the output will be set to an undefined state.
module top_module(
output reg [0:3] out, 
input [0:3] a, b, c, d, 
input [0:1] sel
);
