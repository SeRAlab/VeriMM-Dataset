Design a Verilog module that converts RGB color values to YUV color space. The module should take 8-bit inputs for Red (R), Green (G), and Blue (B) and produce 8-bit outputs for Y, U, and V components according to the following formulas:
Y  = 0.299 * R + 0.587 * G + 0.114 * B
U  = -0.14713 * R - 0.28886 * G + 0.436 * B + 128
V  = 0.615 * R - 0.51499 * G - 0.10001 * B + 128
Make sure to round the results appropriately and handle any necessary saturation for the output values.
