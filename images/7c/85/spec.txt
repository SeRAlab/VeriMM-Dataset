Design a 32-bit up-counter that increments on the rising edge of the clock signal when enabled. The counter resets to zero when the reset signal is high or when it reaches a specified maximum value, `max_count`. The output provides the current count value.
module top_module(
  input clk,
  input reset,
  input enable,
  input [31:0] max_count,
  output reg [31:0] count
);
