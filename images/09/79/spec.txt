
Design a 4-bit DRAM cell that can perform read and write operations. The DRAM cell should have the following characteristics:
- It should take a 4-bit data input to be written to the cell.
- It should have a read enable (RE) signal to read the data stored in the cell.
- It should have a write enable (WE) signal to write the data to the cell.
- The output should be a 4-bit data which reflects the current state of the DRAM cell when RE is high.
- The DRAM cell should maintain its state until a new write operation is performed.
