Design a write address generator for a FIFO (First-In-First-Out) buffer. The module outputs a write address that increments on each clock cycle when the FIFO is not full and a write enable signal is active. If the reset signal is low, the write address is initialized to zero. The write address width is defined by the parameter FIFO_PTR_WIDE, allowing the design to accommodate various FIFO sizes.
