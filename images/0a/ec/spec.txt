Design a 16-bit ADC (Analog to Digital Converter) module that takes a 16-bit binary input and converts it to a 4-bit output representing the range of values. The output should represent the quantized value based on the input. The input value is assumed to be in the range of 0 to 65535 (i.e., 16 bits), and the output should be scaled down to a value between 0 and 15 (i.e., 4 bits).
