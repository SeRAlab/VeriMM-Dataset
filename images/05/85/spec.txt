Design a simple 8-bit Digital-to-Analog Converter (DAC) in Verilog. The DAC will take an 8-bit binary input and produce a corresponding analog voltage output represented by a 10-bit unsigned value. The output voltage can be considered proportional to the input value. For simplicity, assume a reference voltage of 5V (the analog output will range from 0 to 1023 for 0V to 5V). The output should be an integer value calculated as (input_value * 1023) / 255.
