Design a 2-bit barrel shifter that can shift a 2-bit input value (00, 01, 10, 11) either left or right based on a 1-bit control signal. The control signal 'shift' will determine the direction of the shift: if shift = 0, the input will be shifted left; if shift = 1, the input will be shifted right. The output should be a 2-bit value representing the shifted result.
