

You have been tasked with designing a module that implements a simple binary counter. The counter should have a synchronous reset input, a clock input, and an output that represents the current count value. The counter should increment on each rising edge of the clock input, and reset to zero on the rising edge of the reset input.

Design a Verilog module that meets the following specifications:

- The module should be named `BinaryCounter`.
- The module should have the following inputs:
  - `clk`: a 1-bit clock input
  - `rst`: a 1-bit synchronous reset input
- The module should have the following output:
  - `count`: a 4-bit output representing the current count value
- The module should use only combinational logic and D flip-flops to implement the counter.
- The counter should increment on each rising edge of the clock input and reset to zero on the rising edge of the reset input.
- The counter should count from 0 to 15 (in binary) and then wrap around to 0.

Write a Verilog module that implements the `BinaryCounter` module as described above.
