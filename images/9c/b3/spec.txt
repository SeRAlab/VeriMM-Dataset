Design a 6-bit wide demultiplexer with reset functionality. The module takes a 6-bit input and directs it to one of two output lines (D0_out or D1_out) based on the value of the 'destiny' input. When 'destiny' is 0, the input is passed to D0_out, and when it is 1, the input is directed to D1_out. If the reset signal (reset_L) is low, both outputs are set to zero, effectively resetting the demultiplexer.
module top_module(input [5:0] mux_arbitro_1,
                    input reset_L, destiny,
                    output reg [5:0] D0_out, D1_out);
