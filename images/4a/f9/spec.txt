Design a 4-bit up/down counter that can be enabled and loaded with new data. The counter increments its value when the up_down signal is high and decrements when it is low, provided that the enable signal is active. If the load signal is asserted, the counter's output is set to the value from data_in instead of counting.
module top_module(
    input clk,
    input up_down,
    input load,
    input en,
    input [3:0] data_in,
    output reg [3:0] out
);
