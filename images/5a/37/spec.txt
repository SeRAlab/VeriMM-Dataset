Design a four-input, one-bit wide multiplexer. The module selects one of the four input signals (in0, in1, in2, in3) based on the values of the two selection signals (sel0 and sel1). Specifically, when sel1 and sel0 are both high, the output will be in3; when sel1 is high and sel0 is low, the output will be in2; when sel1 is low and sel0 is high, the output will be in1; and when both selection signals are low, the output will be in0. If the selections are invalid, the output is assigned an unknown state.
module top_module(
    input  wire in0,
    input  wire in1,
    input  wire in2,
    input  wire in3,
    input  wire sel0,
    input  wire sel1,
    output wire out
);
