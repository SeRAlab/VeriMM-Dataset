Design a Verilog module that models a 9-bit Gray code counter with enable and synchronous reset signals. The module should have an input clock signal (clk), an input enable signal (en), an input synchronous reset signal (rst), and a 9-bit output signal (gray_count). On the rising edge of the clock, if reset is high, gray_count should be set to 0. If enable is high, gray_count should increment to the next Gray code value.
