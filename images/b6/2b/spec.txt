Design a circuit that implements a rotating LED pattern using a 24-bit counter. The circuit increments the counter on each rising edge of the system clock, and when the counter reaches a value of 10 million, it shifts the LEDs in a circular manner. Specifically, the first LED lights up initially, and with each cycle of the counter, the lit LED moves to the next position, creating a visual effect of rotation. The operation can be reset with an active low reset signal.
module top_module(
    input               sys_clk  ,  
    input               sys_rst_n,  
	 
    output  reg  [3:0]  led         
);
