
Design a simple Direct Memory Access (DMA) controller that transfers data from a source memory address to a destination memory address. The DMA controller should have the following inputs: a clock signal, a reset signal, a start signal to initiate the transfer, a source address, a destination address, and a data input signal. It should output the transferred data and a done signal indicating the completion of the transfer. The data transfer should happen in a single clock cycle for simplicity.
