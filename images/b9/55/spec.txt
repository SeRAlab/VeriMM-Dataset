Design a 4-bit barrel shifter that can shift the input value A left or right based on the control signal C. When C is 0, the module performs a left shift on A by the number of positions specified by the 4-bit input B. When C is 1, it performs a right shift instead. The resulting shifted value is output as a 4-bit signal called shifted_value.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input C,
    output [3:0] shifted_value
);
