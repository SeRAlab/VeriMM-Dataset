Design a positive-edge triggered D flip-flop with asynchronous active-low reset functionality. The module captures the value of the D input on the rising edge of the CLK signal and outputs it at Q. When the RESET_B signal is low, the flip-flop resets its output Q to low, regardless of the CLK or D inputs. This design is suitable for digital storage applications, effectively retaining state information based on clock cycles.
module top_module(
    input CLK,
    input D,
    input RESET_B,
    output reg Q
);
