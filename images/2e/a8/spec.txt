
Design an SR latch using Verilog. The SR latch should have two inputs, S (Set) and R (Reset), and two outputs, Q and Qn (not Q). The behavior of the SR latch should follow these rules:
1. If S = 1 and R = 0, then Q = 1 and Qn = 0 (Set state).
2. If S = 0 and R = 1, then Q = 0 and Qn = 1 (Reset state).
3. If S = 0 and R = 0, then Q and Qn retain their previous state (Hold state).
4. If S = 1 and R = 1, the outputs should be undefined (consider as invalid state).
