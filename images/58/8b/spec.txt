Design a temperature-controlled fan management system. It activates the fan when the temperature exceeds a specified threshold and adjusts the fan speed based on the current temperature reading. The fan speed is increased or decreased gradually to reach a target speed derived from the temperature, ensuring smooth operation while maintaining a maximum speed limit. The system also includes a reset feature to turn off the fan and reset the speed when required.
module top_module(
  input clk,
  input reset,
  input [7:0] temperature,
  output reg fan_on,
  output reg [7:0] fan_speed
);
