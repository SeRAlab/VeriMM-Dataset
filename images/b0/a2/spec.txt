Design a combinational logic block that works as a 3-to-8 decoder with additional output management. The module takes a 3-bit input and produces four separate outputs (out0 to out3), with only one being active high at a time, corresponding to the binary value of the input. The module also has an aggregate output (out), which is set high whenever any of the outputs out0 to out3 are high, effectively indicating a valid input range from 0 to 8, with all outputs low for invalid values outside this range.
module top_module(
    input wire in,
    output reg out0,
    output reg out1,
    output reg out2,
    output reg out3,
    output reg out
);
