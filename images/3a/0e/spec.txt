Design a Serial-In Serial-Out (SISO) shift register that has a width of 5 bits. The shift register should have a clock input, a reset input, a serial data input, and a serial data output. On each rising edge of the clock, if the reset is not asserted, the shift register should shift in the new serial data bit from the input, and the oldest bit should be shifted out to the output. The reset input should clear the shift register to all zeros when asserted.
