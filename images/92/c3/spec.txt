Design a 4-bit barrel shifter that performs shifting operations based on the specified direction and shift amount. The module takes a 4-bit input (A) and a 2-bit control signal (shift_amount) to determine how many positions to shift. When the shift_dir signal is high, it performs a left shift, appending zeroes on the right; when shift_dir is low, it performs a right shift, appending zeroes on the left. The resulting shifted value is output as a 4-bit signal (Y).
module top_module(
    input [3:0] A,
    input [1:0] shift_amount,
    input shift_dir,
    output [3:0] Y
);
