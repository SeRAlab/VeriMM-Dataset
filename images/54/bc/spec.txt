Design a 4-bit shift register with load capabilities. On each rising edge of the clock, if the reset signal is asserted, the output is cleared to zero. If the load signal is active, the register takes in a new 4-bit input value; otherwise, the current output shifts left by one bit, with a zero filling in the least significant bit.

    input [3:0] in,
    output reg [3:0] out
