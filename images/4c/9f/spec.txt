Implement a hazard detection unit that prevents pipeline stalls in a CPU by asserting a stall signal when there is a potential data hazard. The module checks if the previous instruction in the pipeline reads from memory and if its destination register matches either the source registers of the current instruction. If a match is detected, the stall output is asserted, indicating that the pipeline must be stalled to resolve the hazard.
