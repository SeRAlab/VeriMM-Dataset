Design a 4-to-1 multiplexer that selects one of four 16-bit input signals based on a 2-bit control signal. The selected input is outputted as a 16-bit signal. The multiplexer responds to changes in the inputs and control signal, directing the appropriate input to the output. Note that the design does not exhibit any synchronous behavior based on the clock signal.

    input [15:0] in4,
    input [1:0] control,
    input clock,
    output reg [15:0] out
    );
