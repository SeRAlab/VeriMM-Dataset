Design a program counter (PC) module that holds the current instruction address in a processor pipeline. The module updates its state on the rising edge of the clock signal. If the reset signal is active (logic low), the program counter is initialized to -4. When the write control signal (wpcir) is inactive (logic low), it updates the counter with the value from the next instruction address (npc); otherwise, it retains its current value. The output is the current value of the program counter, providing a mechanism to track instruction execution in a sequential manner.
