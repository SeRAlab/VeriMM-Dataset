Design a Verilog module that implements a 6-bit binary up-counter with synchronous reset and load functionality. The counter should increment on the rising edge of the clock. The counter should load a given value (load_val) when the load (ld) signal is high. The counter should reset to zero when the synchronous reset (sreset) is high. The counter value should be output to the "count" signal.

module up_counter_with_load
(
    input clk,
    input ld,
    input sreset,
    input [5:0] load_val,
    output reg [5:0] count
);
