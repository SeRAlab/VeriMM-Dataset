

You are tasked with designing a Verilog module that implements a 4-bit adder with two input ports (`a` and `b`) and one output port (`sum`). The module should also have a control input `ctrl` which, when set to 1, enables the adder and when set to 0, disables it. 

You may use any built-in Verilog operators and functions. The module should have the following interface:

```verilog
module adder_4bit (
  input [3:0] a,
  input [3:0] b,
  input ctrl,
  output [3:0] sum
);
```
