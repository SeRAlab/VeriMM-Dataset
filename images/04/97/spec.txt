
Design a simple Direct Memory Access (DMA) controller that can transfer data from a source memory location to a destination memory location. The controller should have the following inputs: 
1. clk: clock signal
2. rst: reset signal
3. start: signal to start the transfer
4. src_addr: source address for the data
5. dest_addr: destination address for the data
6. data_in: input data from the source memory
7. transfer_complete: output signal indicating the completion of the transfer.

The output should be the data transferred to the destination address.
