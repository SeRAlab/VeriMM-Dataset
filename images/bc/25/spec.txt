Design a Verilog module that implements a 2-to-1 multiplexer with an enable signal. The module should have two 4-bit inputs, a select signal, an enable signal, and one 4-bit output. When the enable signal is 1, the output should be based on the select signal; when the enable signal is 0, the output should be 4'b0.

module mux2to1_enable (
    input [3:0] in0,
    input [3:0] in1,
    input sel,
    input en,
    output reg [3:0] out
);
