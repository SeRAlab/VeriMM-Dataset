Create a state-space controller that implements a simple state feedback control system. The controller should take a 2-bit state input and produce a control output based on a 2-bit input state. The state transitions should be defined in a finite state machine (FSM) manner, where the system has four states: 00, 01, 10, and 11. The control output will be a 2-bit value determined by the current state. The system should also have a reset functionality that initializes the state to 00.
