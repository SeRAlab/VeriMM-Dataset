Design a synchronous D flip-flop with a reset, which supports the operation of set, clear, and enable signals. The flip-flop captures the input data (D) on the rising edge of the clock (CLK) when the enable (SCE) signal is active, allows for asynchronous resetting through RESET_B, and features a separate clear input (SCD) to force the output to a known state. The additional power and ground connections (VPWR, VGND, VPB, VNB) cater to the specific requirements of a low-power technology library.
module top_module(
    output Q,
    input CLK,
    input D,
    input SCD,
    input SCE,
    input RESET_B,
    input VPWR,
    input VGND,
    input VPB,
    input VNB
);
