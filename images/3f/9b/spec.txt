Design a fixed-priority arbiter in Verilog that grants access to one of four requestors based on fixed priorities. The arbiter should have four request inputs, one grant output, and an enable signal. The requestors have the following priorities: Requestor 0 has the highest priority, followed by Requestor 1, Requestor 2, and Requestor 3 having the lowest priority. The output should indicate which requestor is granted access based on the active request signals.
