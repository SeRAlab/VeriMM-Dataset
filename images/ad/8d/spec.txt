Design a 5-to-23 line decoder. The module takes a 5-bit input and outputs a 23-bit signal where only one bit is set to HIGH corresponding to the value of the input, effectively activating the output line indicated by the input while all other output lines remain LOW. The output bit that is set HIGH corresponds to a left-shift of the binary value represented by the input.
