Design a 1-bit DRAM cell that has the following functionalities:
1. A single data input (D) and a single data output (Q).
2. A write enable signal (WE) that determines whether the cell should write the input data.
3. A read enable signal (RE) that determines whether the cell should output the stored data.
4. The cell should maintain its state when neither WE nor RE is active. Implement the cell as a D flip-flop with additional control logic for write and read operations.
