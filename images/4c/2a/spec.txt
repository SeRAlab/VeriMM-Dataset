Design a finite state machine (FSM) that operates as a 3-bit binary counter. The counter counts through the states A (000), B (001), and C (010) in a cyclical manner on the rising edge of the clock, and resets back to state A upon receiving a reset signal. The output 'count' reflects the current state of the FSM, generating a binary output corresponding to the active state at each clock cycle.
module top_module(
  input clk,
  input reset,
  output reg [2:0] count
);
