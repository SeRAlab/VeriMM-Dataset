Design an SR latch using D flip-flops. The latch should have two inputs, S (set) and R (reset), and two outputs, Q and Qn (not Q). The behavior should be as follows: when S is high and R is low, Q should be set to high. When S is low and R is high, Q should be reset to low. If both S and R are low, Q should retain its previous state. If both S and R are high, the output state is indeterminate.
