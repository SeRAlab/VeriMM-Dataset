Design a 3-port block RAM module with a depth of 2K words and a width of 8 bits per port. The module is clocked and is controlled by an enable (EN) and a write enable (WE) signal, which manages data input and output operations based on a 13-bit address input. It utilizes three instantiations of 2Kx8 RAMs, selecting the appropriate RAM based on the upper bits of the address. The output multiplexer routes the selected data and its parity output from the active RAM to the module's output lines, allowing for simultaneous read operations from different memory banks while efficiently managing memory access.
