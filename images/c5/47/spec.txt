Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a clock divider. 
A clock divider is a digital circuit that takes an input clock signal and outputs a slower clock signal. 
The slower clock signal is generated by dividing the frequency of the input clock signal by a specified integer value.
Your module should have the following inputs and outputs:

Inputs: 
- clk_in: the input clock signal
- rst: a reset signal that resets the divider to its initial state

Outputs: 
- clk_out: the output clock signal, which is a slower version of the input clock signal

Your module should also have the following parameter:

- div_factor: the integer value by which the input clock signal will be divided

To implement the clock divider, you should use Verilog code to create a counter that counts up to the div_factor and then resets to zero. 
You should use the counter to generate the slower clock signal by toggling the clk_out signal every time the counter reaches its maximum value.
The rst input signal should be used to reset the counter to zero.
