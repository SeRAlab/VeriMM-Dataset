Design a BCD (Binary-Coded Decimal) encoder circuit that takes a 4-bit binary input represented by the signals A, B, C, and D and produces two 4-bit output signals: out_high and out_low. The out_low output represents the lower digit of BCD based on the binary input value, while the out_high output indicates the current digit's tens value (either 0 or 1). The specific mappings are defined such that for binary inputs from 0 to 9, the out_high remains 0000, and from inputs 8 to 15, out_high becomes 0001 to represent the next range of BCD values. This encoder is useful for converting binary numbers into a format more suitable for digital display or counting applications in BCD format.
module top_module(
    input A,
    input B,
    input C,
    input D,
    output reg [3:0] out_high,
    output reg [3:0] out_low
);
