Design a 4-bit ripple carry adder that sums two 4-bit inputs, A and B, along with a carry-in bit, Cin. The module produces a 4-bit sum output, S, and a carry-out signal, Cout. Each bit of the sum is computed using a separate full adder, which takes into account the carry from the previous bit's addition, allowing for the sequential addition of the bits from least significant to most significant.
module top_module(
    output S,     // Sum output
    output Cout,  // Carry output
    input A,      // First input
    input B,      // Second input
    input Cin     // Carry input
);
