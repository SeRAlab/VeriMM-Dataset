Design a 4-bit shift register with configurable shift direction. This module captures a 4-bit input on the rising edge of the clock and shifts the value either left or right based on the `shift_dir` control signal—where `shift_dir = 0` indicates a left shift, and `shift_dir = 1` indicates a right shift. The shifted output is then provided on the `out` signal.
module top_module(
    input [3:0] in,
    input shift_dir,
    input clk,
    output reg [3:0] out
);
