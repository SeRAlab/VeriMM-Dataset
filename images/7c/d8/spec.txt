Design a 10-bit universal counter that can be configured to count up, count down, hold its current value, or load a preset value based on two select inputs (S1 and S0). The counter has inputs for a start count (BeginCount), an end count (EndCount), and a preset value (P). It resets to BeginCount when the Reset signal is high and counts up by incrementing its value until it reaches EndCount (at which point it signals TerminalCount). Conversely, it counts down until it reaches BeginCount, also triggering TerminalCount. When both S1 and S0 are high, the counter loads the preset value P. This module effectively serves as a versatile counter that supports multiple counting modes and reset functionality.
