
Design a Verilog module that evaluates a polynomial of the form P(x) = a4*x^4 + a3*x^3 + a2*x^2 + a1*x + a0, where a4, a3, a2, a1, and a0 are the coefficients provided as inputs and x is the input variable. The module should output the result of the polynomial evaluation for given values of x and the coefficients.
