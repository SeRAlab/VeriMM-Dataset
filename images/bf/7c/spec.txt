Design a positive-edge-triggered D flip-flop with asynchronous clear functionality. The module captures the input data 'd' on the rising edge of the clock signal 'clk'. If the clear signal 'clr' is asserted low, the output 'q' is reset to zero. The complementary output 'qbar' is continuously generated as the inverse of 'q'. This design effectively stores one bit of data and provides the ability to reset its state when necessary.
