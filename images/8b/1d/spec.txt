Design a 32-bit Arithmetic Logic Unit (ALU) that performs various arithmetic and logical operations based on a three-bit operation selector (ALUop). It can execute addition, subtraction, bitwise shifts, and logical operations such as AND, OR, and XOR. Additionally, it supports comparison operations to determine if one input is less than another, including signed and unsigned comparisons. The module also outputs a zero flag that indicates if the result is zero and a sign flag that reflects the sign of the result (0 for positive, 1 for negative).
module top_module(
    input [31:0] ALUSrcA,
    input [31:0] ALUSrcB,
    input [2:0] ALUop,
    output zero,
    output sign,
    output reg[31:0] result
    );
