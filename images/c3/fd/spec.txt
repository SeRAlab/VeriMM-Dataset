

You are tasked with designing a 4-to-1 multiplexer using Verilog. The module should have 4 input bits (A0, A1, A2, A3), 2 select bits (S0, S1), and 1 output bit (Y). The multiplexer should select one of the four inputs based on the values of the select bits. If S1S0 is 00, Y should be equal to A0. If S1S0 is 01, Y should be equal to A1. If S1S0 is 10, Y should be equal to A2. If S1S0 is 11, Y should be equal to A3. The module should also have two input pins for power (VPWR) and ground (VGND).

Your task is to write a Verilog module that implements this 4-to-1 multiplexer. The module should be named "mux4to1" and should have the following inputs and outputs:

Inputs:
- A0, A1, A2, A3: 4-bit input signals
- S0, S1: 2-bit select signals
- VPWR: power input
- VGND: ground input

Outputs:
- Y: 1-bit output signal

You should ensure that your design follows good Verilog coding practices, and that it synthesizes correctly.
