Design a simple virtual memory management unit (MMU) in Verilog that translates a virtual address to a physical address using a basic page table. The unit should have the following interface: a clock input, a reset input, a valid bit input, and a virtual address input. On a valid signal, the MMU should translate the virtual address into a physical address using a predefined page table. The page table should contain a fixed number of entries (e.g., 4) for simplicity, and the output should be the corresponding physical address. If the virtual address does not match any entry in the page table, the output physical address should be set to a specific error code (e.g., 32'hFFFFFFFF).
