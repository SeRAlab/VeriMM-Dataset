Design a D flip-flop with asynchronous reset and set functionalities. The flip-flop captures the input data (d) at the rising edge of the clock (clk). When the reset (rst) input is high, the output (q) is set to LOW and the not output (qn) is set to HIGH. Conversely, when the set (set) input is activated, q is set to HIGH and qn to LOW. If neither reset nor set is active, the output follows the input data (d) on the clock edge, while qn outputs the inverse of q.
