
You are tasked with implementing a flip-flop module in Verilog. The module should have the following inputs and outputs:

- Inputs:
  - `clk`: a clock signal
  - `reset`: a reset signal
  - `d`: a 17-bit input signal
- Outputs:
  - `q`: a 17-bit output signal

The module should have the following behavior:

- When `reset` is asserted, the output `q` should be set to 0.
- On each positive edge of the clock signal `clk`, the output `q` should be set to the value of the input `d`.

You should also include the following in your implementation:

- The `q` output should be implemented using a `reg` variable.
- The `reset` input should be active-low.

Please write the Verilog code for this module.
