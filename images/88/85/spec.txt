Design a logic circuit that produces a single output based on multiple control signals and two 4-bit inputs. If control signal `c` is high, output `f` is set to 1. If control signal `d` is high, output `f` is set to 0. If control signal `e` is high, output `f` is again set to 1. If none of the control signals are active, output `f` computes the sum of inputs `a` and `b`.
module top_module(
    input [3:0] a,
    input [3:0] b,
    input c,
    input d,
    input e,
    output reg f
);
