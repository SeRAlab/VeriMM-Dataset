Design a digital potentiometer circuit that adjusts a resistance value based on a 4-bit input. The circuit outputs a 10-bit wide resistance value that corresponds to one of 16 discrete steps, scaled by a maximum resistance of 100 ohms. Upon receiving a reset signal, it initializes the output resistance to zero. With each clock cycle, if not in a reset state, it calculates the new resistance using the provided input value and updates the output accordingly.
module top_module(
  input [3:0] D,
  input CLK,
  input RST,
  output reg [9:0] W
);
