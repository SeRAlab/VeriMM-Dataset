Design a 4-to-1 multiplexer that selects one of four 4-bit wide input signals (A, B, C, D) based on a 2-bit selection input (SEL). Depending on the value of SEL, the output Y will reflect the chosen input: Y outputs A when SEL is 00, B when SEL is 01, C when SEL is 10, and D when SEL is 11.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input [3:0] C,
    input [3:0] D,
    input [1:0] SEL,
    output reg [3:0] Y
);
