

You are tasked with designing a Verilog module for a D-type flip-flop with enable functionality. The module should have the following inputs and outputs:

- `D`: input data signal
- `EN`: enable signal
- `CLK`: clock signal
- `Q`: output data signal

The flip-flop should only update its output when the enable signal is high. When the enable signal is low, the output should remain constant. The flip-flop should update its output on the rising edge of the clock signal.

Design a Verilog module that meets these specifications within 200 lines of code.
