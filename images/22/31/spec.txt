Design an 8-bit Linear Feedback Shift Register (LFSR) that uses the polynomial x^8 + x^6 + x^5 + x^4 + 1. The LFSR should generate a pseudo-random sequence of 8-bit values. It should have an input clock signal and a reset signal. On reset, the LFSR should initialize to a non-zero value (e.g., 8'b00000001) and on each clock edge, it should shift and feedback the new bit according to the defined polynomial.
