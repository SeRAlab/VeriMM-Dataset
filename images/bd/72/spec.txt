Design a Verilog module that models a 12-bit up/down counter with enable and direction signals. The module should have an input clock signal (clk), an input enable signal (en), an input direction signal (dir), and a 12-bit output signal (count). On the rising edge of the clock, if enable is high, count should increment by 1 if direction is high, otherwise it should decrement by 1.
module up_down_counter (
  input clk,
  input en,
  input dir,
  output reg [11:0] count);
