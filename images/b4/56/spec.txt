Design a module that performs one of four specified bitwise logical operations based on a parameter. This module accepts two single-bit inputs, in1 and in2, and outputs the result of an operation determined by the parameter 'op', which can execute AND, OR, XOR, or NOT operations. When op is set to 0, it performs a logical AND between in1 and in2. If op is 1, it performs a logical OR; if op is 2, it executes a logical XOR. If op is 3, it outputs the logical NOT of in1, disregarding in2.
module top_module(
  input in1,
  input in2,
  output out
);
