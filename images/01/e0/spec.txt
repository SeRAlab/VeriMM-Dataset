
Design an 8-bit SRAM cell with read and write operations. The SRAM cell should have the following inputs: `data_in` (8 bits for data to be written), `addr` (3 bits for address selection), `we` (write enable signal), and `clk` (clock signal). The output should be `data_out` (8 bits for data read from the selected address). The SRAM should have 8 memory locations, and it should support concurrent read and write operations depending on the `we` signal.
