
Design a 8-bit Serial-In Parallel-Out (SIPO) shift register in Verilog. The module should have a single data input (serial), a clock input, a reset input, and an 8-bit parallel output. The shift register should shift in new bits on the rising edge of the clock and output the stored data when a separate signal called "load" is activated. When the reset signal is high, the output should be cleared to zero.
