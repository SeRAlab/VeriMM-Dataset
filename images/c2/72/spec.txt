

You have been tasked to design a circuit that incorporates a D flip-flop with enable and set functionality. The circuit should be implemented in Verilog and should be contained within a single module with no more than 200 lines of code.

The module should have the following inputs and outputs:
- `C`: a clock input
- `E`: an enable input
- `S`: a set input
- `D`: a data input
- `Q`: a data output

The circuit should operate as follows:
- When `E` is high, the circuit should be enabled and the flip-flop should be able to store data.
- When `S` is high, the output `Q` should be set to 1 regardless of the value of `D`.
- When `S` is low and `E` is high, the output `Q` should take on the value of `D` on the falling edge of the clock `C`.

Implement the circuit as a single module in Verilog.
