Design a 3-to-8 line decoder that activates one of the eight output lines corresponding to the binary value of the 3-bit input in. On each positive clock edge, the input is latched and the decoder logic will set the output to a one-hot encoded representation, where the selected output line is driven LOW while all others are driven HIGH. If the input is out of range, all outputs will remain HIGH.
