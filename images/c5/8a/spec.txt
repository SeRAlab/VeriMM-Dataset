

You have been tasked with designing a clock gating module in Verilog. The module should have a clock input `CLK`, an enable input `EN`, a test enable input `TE`, and an output `ENCLK`. The module should be able to gate the clock signal based on the enable input and test enable input. The module should only allow the clock signal through when both the enable input and test enable input are high.

You are required to write a Verilog module with the following specifications:

1. The module should be named `clock_gate`.
2. The module should have four inputs:
   - `CLK`: a 1-bit input representing the clock signal.
   - `EN`: a 1-bit input representing the enable signal.
   - `TE`: a 1-bit input representing the test enable signal.
   - `D`: a 1-bit input representing the data signal.
3. The module should have one output:
   - `ENCLK`: a 1-bit output representing the gated clock signal.
4. The module should only allow the clock signal through when both `EN` and `TE` are high.
5. The module should only update the `ENCLK` output on the rising edge of the clock signal.

Assume that all inputs are synchronous to the rising edge of the clock signal.

Your task is to implement the `clock_gate` module in Verilog.
