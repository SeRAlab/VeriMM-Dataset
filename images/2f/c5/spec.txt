Design an SR flip-flop using Verilog. The flip-flop should have two inputs S (set) and R (reset) and two outputs Q and Qbar (not Q). When S is high, Q should be set to 1, and when R is high, Q should be reset to 0. If both S and R are low, Q should retain its previous value. If both S and R are high, the state is considered invalid.
