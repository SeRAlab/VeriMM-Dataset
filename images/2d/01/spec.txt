
Design a temperature sensor controller in Verilog that reads a 3-bit temperature value from a sensor. The controller should implement a simple state machine that transitions through three states: IDLE, READ, and PROCESS. In the IDLE state, the controller waits for a read signal. In the READ state, it captures the temperature value. In the PROCESS state, it checks whether the temperature is above a certain threshold (e.g., 4). If the temperature exceeds the threshold, it sets an alarm signal. The controller should also have an output signal that indicates the current state.
