
Create a simple DMA controller that transfers data from a source address to a destination address. The controller should have the following inputs: 
- `start` (1-bit): signal to start the transfer
- `clk` (1-bit): clock signal
- `reset` (1-bit): reset signal
- `src_addr` (8-bit): source address
- `dest_addr` (8-bit): destination address
- `data_in` (8-bit): data to be transferred
The output should be `data_out` (8-bit) which will hold the data from the `data_in` when the transfer is in progress.
