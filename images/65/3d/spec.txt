    shift_register_8                
Input ports:
    clk: Clock signal

    shift_left: Signal to control left shift
    shift_right: Signal to control right shift
    load: Signal to control parallel load
    data_in: 8-bit parallel input data
Output ports:
    data_out: 8-bit output representing the current register value

Implementation:
If the reset signal is active (rst), the register is cleared to 0. If the load signal is high, the register is loaded with the parallel input value (data_in).
