Design a LED controller that manages a 4-bit output based on a simple memory-mapped I/O interface. It features an input address, chip select, clock, reset, and write signals. When chipselect is active and write_n is low while the address is 0, the controller writes the lower 4 bits of the incoming writedata to an internal register. The output port reflects the state of this register. Additionally, it provides a readback function, where the readdata output will return the current value of the data_out register when accessed. The system resets the data_out to zero upon a reset signal, with the module sensitive to clock edges for updates.
module top_module(
  input [1:0] address,
  input chipselect,
  input clk,
  input reset_n,
  input write_n,
  input [31:0] writedata,
  output [3:0] out_port,
  output [31:0] readdata
);
