

You are tasked to design a module in Verilog that implements a 4-bit adder with carry. The module should have the following inputs and outputs:

Inputs:
- `a`: a 4-bit binary number
- `b`: a 4-bit binary number
- `cin`: a single bit representing the carry-in value

Outputs:
- `sum`: a 4-bit binary number representing the sum of `a` and `b`
- `cout`: a single bit representing the carry-out value

You should name your module `adder_4bit_carry`.

Your module should use only combinational logic (no clocked logic allowed). The module should also be designed to minimize the number of gates used.
