
Design a combinational logic circuit that implements a decision tree for a simple classification. The circuit should take five binary inputs (A, B, C, D, E) and produce one binary output (Y) based on the following decision rules:
1. If A is 1 and B is 0, then Y is 1.
2. If A is 0 and C is 1, then Y is 1.
3. If D is 1, then Y is 1.
4. If A is 0, B is 1, and E is 0, then Y is 0.
5. In all other cases, Y is 0.
