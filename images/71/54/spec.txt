Implement the Verilog module based on the following description.
Build a 4-bit ring counter with an asynchronous positive edge triggered reset, synchronous enable signal, and synchronous active high load signal.
(1) reset: Resets counter to one-hot encoding.
(2) enable: Enables the counter to shift right by one bit.
(3) load: Loads the counter with a 4-bit value from input "data".
(4) data: 4-bit data input to the counter.
(5) q: The current count of the counter.

module top_module(
    input clk,
    input reset,
    input enable,
    input load,
    input [3:0] data,
    output reg [3:0] q);
