Design a 3-input, 4-output multiplexer with a 2-bit select input. The module takes three individual inputs (a, b, c) and, based on the value of the select input, activates one of the four output lines (w, x, y, z) while setting the others to LOW. Specifically, when select is 00, output w reflects input a; when select is 01, output x reflects input b; when select is 10, output y reflects input c; and when select is 11, output z is set HIGH, while all others are LOW.
module top_module(
    input a, b, c,
    input [1:0] select,
    output reg w, x, y, z
);
