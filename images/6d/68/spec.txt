Design a 4-to-1 multiplexer that selects one of four input signals (in0, in1, in2, in3) based on the values of two select lines (sel0 and sel1). The output will correspond to in0 when both select lines are low, in1 when sel0 is high (and sel1 is low), in2 when sel0 is low (and sel1 is high), and in3 when both select lines are high. If the select lines are not within the expected range, the output is set to an indeterminate state (1'bx).
module top_module(
  input in0,
  input in1,
  input in2,
  input in3,
  input sel0,
  input sel1,
  output out
);
