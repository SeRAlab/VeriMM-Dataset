Design a Serial-In Parallel-Out (SIPO) shift register that accepts a 5-bit input serially and outputs the 5 bits in parallel after a load signal is asserted. The design should have a clock input, a reset input, a load input, and a 5-bit output. The register should shift in the serial data on the rising edge of the clock when the load signal is high. When the reset signal is asserted, the output should be set to zero.
