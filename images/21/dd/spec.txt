
Create a 24-bit ADC (Analog to Digital Converter) simulator in Verilog. The ADC should take a 12-bit input representing the analog value and scale it to a 24-bit output. The scaling factor should be \(2^{12}\) (4096), meaning that the maximum 12-bit input (4095) should correspond to the maximum 24-bit output (16777215). Additionally, handle the case where the input is larger than the maximum 12-bit value by clamping it to the maximum.
