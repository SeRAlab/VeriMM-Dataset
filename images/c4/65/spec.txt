

Create a verilog module for a 2-to-1 multiplexer with the following interface:

Inputs:
- `sel`: a single bit input used to select between the two inputs
- `in0`: a 1-bit input to be selected when `sel` is 0
- `in1`: a 1-bit input to be selected when `sel` is 1

Outputs:
- `out`: a 1-bit output that is equal to `in0` when `sel` is 0, and equal to `in1` when `sel` is 1

Implement the module using the `assign` statement.
