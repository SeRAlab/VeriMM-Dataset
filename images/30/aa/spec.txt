
Create a 16-bit DRAM cell that supports read and write operations. The DRAM cell should store 16 bits of data and be controlled by read and write enable signals. The module should have the following inputs: `clk` (clock), `wen` (write enable), `ren` (read enable), and `data_in` (16-bit input data). It should have one output: `data_out` (16-bit output data). The DRAM cell should allow writing when `wen` is high and output the stored data when `ren` is high.
