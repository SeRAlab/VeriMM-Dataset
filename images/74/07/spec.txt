Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state V (output 1).
2. state W (output 0).
3. state X (output 1).
4. state Y (output 0).

State transitions:
1. From state V: If z = 1, then transition to state W. If z = 0, then transition to state Y.
2. From state W: If z = 1, then transition to state X. If z = 0, then transition to state V.
3. From state X: If z = 1, then transition to state Y. If z = 0, then transition to state V.
4. From state Y: If z = 1, then transition to state W. If z = 0, then transition to state V.

Assume that a one-hot code is used with the state assignment y[3:0] = 0001(V), 0010(W), 0100(X), 1000(Y)

Write a Verilog for the signal Y1, which is the input of state flip-flop y[1], for the signal Y2, which is the input of state flip-flop y[2]. Derive the Verilog by inspection assuming a one-hot encoding.
