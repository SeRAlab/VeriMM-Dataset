Design a finite state machine (FSM) that manages an acknowledgment signal within a request-response protocol. The module transitions between two states: an idle state (RC_Idle) and a request acknowledgment state (RC_ReqAck). When in the idle state and a request is received (indicated by rc_reqn being low), it transitions to the request acknowledgment state, where it asserts rc_ackn (the acknowledgment signal) low until it detects that the requestor (rc_is_idle) has become idle again, at which point it returns to the idle state and drives rc_ackn high. The FSM resets to the idle state on a negative reset signal.
