Design a 4-to-1 multiplexer that selects one of four 1-bit data inputs (D[0] to D[3]) based on two select signals (S0 and S1). The output (Y) will reflect the value of the selected input, where the combination of S0 and S1 determines the specific data input to output: when S1S0 = 00, output D[0]; when 01, output D[1]; when 10, output D[2]; and when 11, output D[3].
module top_module(
    // module ports
    input [3:0] D,
    input S0,
    input S1,
    output Y
);
