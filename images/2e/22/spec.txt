Design a 2-channel DMA controller that can read data from two different sources and write it to memory. The controller should have two channels, each capable of transferring one byte of data at a time. The controller should have a clock signal, a reset signal, and two channel enable signals. When a channel is enabled, the controller will read from the source and write to the memory. The controller should output the current state of each channel (idle, reading, writing) and the data being transferred.
