Design a combinational logic circuit that generates two outputs, X and Y, based on four input signals (A, B, C, and D). Output X is set to high when input A is high, or under the condition where B is high or C is high while D is low. Output Y is set to high when B is low or C is high while D is high. The design effectively combines multiple conditions to produce the desired outputs, creating a logic function based on the specified inputs.
module top_module(
    input wire A,
    input wire B,
    input wire C,
    input wire D,
    output reg X,
    output reg Y
);
