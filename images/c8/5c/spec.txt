

You are tasked with designing a verilog module for a 2-bit comparator that takes two 2-bit inputs, A and B, and outputs a 2-bit signal, C. The output C is 00 if A is less than B, 01 if A is equal to B, and 10 if A is greater than B. The module should be named "comparator_2bit". 

The module should have the following ports:
- input [1:0] A: a 2-bit input signal
- input [1:0] B: a 2-bit input signal
- output [1:0] C: a 2-bit output signal

You can assume that A and B are unsigned integers. You may use if statements, case statements, or any other control structures you deem necessary.
