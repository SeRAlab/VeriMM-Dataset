Design a 16-bit adder/subtractor circuit that performs addition or subtraction based on the MODE input. When MODE is 0, the circuit calculates the sum of inputs A, B, and the carry input CIN. When MODE is 1, the circuit computes the difference by subtracting B and CIN from A. The result is output through the Q signal.
module top_module(
    input [15:0] A,
    input [15:0] B,
    input MODE,
    input CIN,
    output reg [15:0] Q
);
