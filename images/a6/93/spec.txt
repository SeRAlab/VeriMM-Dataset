Design a traffic light controller that manages the timing of a three-color light system. The module cycles through red, yellow, and green states based on predefined time intervals for each color, as well as a brief blank state. A timer increments with each time signal, and upon exceeding the total cycle time, it resets. The reset input allows for initialization to the red state, ensuring safe operation. The outputs indicate the active light: 'red' is active during the red state, 'yellow' during the yellow state, and 'green' during the green state, following the specified durations.
module top_module(	
 
		input wire time_signal,
		input wire reset,
		output wire red,
		output wire yellow,
		output wire green		
		);
