Design a circuit that connects inputs a, b, and c to four outputs w, x, y, and z. The output w directly mirrors input a, while output z directly mirrors input c. Outputs x and y function as a 2-to-1 multiplexer, selecting between inputs b and c based on the value of the select signal; when select is 0, both x and y output b, and when select is 1, both output c. This effectively allows for controlled selection of the input signals based on the select line.
module top_module(
    input a, b, c,
    input select,
    output w, x, y, z
);
