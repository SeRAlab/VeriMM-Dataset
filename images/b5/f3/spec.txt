Design a one-bit full adder that computes a sum and carry output. The adder takes three inputs: A, B, and a carry-in (Cin). It produces a sum output (Sum) that is the XOR of the three inputs, and a carry-out (Cout) that is generated according to the rules of binary addition, indicating if there is an overflow into the next significant bit.
module top_module(
    input A,
    input B,
    input Cin,
    output Sum,
    output Cout
    );
