Design a D flip-flop with asynchronous reset functionality. The module captures the value of the input D on the rising edge of the clock (CLK) and stores it in a register (q_reg). If the SCE (scan enable) signal is high, the flip-flop will override the D input with the SCD (scan data) input. The output Q reflects the stored value of q_reg, effectively allowing for a data capturing mechanism with additional scan capabilities for testing or debugging purposes.
