Develop a pipelined digital circuit that processes a parallel input signal through three stages. It takes n input bits and outputs m bits, where, at each clock cycle, the first stage simply passes the input, the second stage increments the first stage's output by one, and the third stage doubles the value obtained in the second stage. The final output is thus the result of a sequence of simple arithmetic operations in a clock-synchronized manner, effectively performing an operation of increment followed by a multiplication.
module top_module(
  input clk, // Add clock input
  input [n-1:0] in,
  output [m-1:0] out
);
