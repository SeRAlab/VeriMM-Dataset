Design a LIFO stack in Verilog with the following specifications:
1. The stack should have a maximum size of 8 elements.
2. Inputs:
   - `push`: a signal to push data onto the stack (active high).
   - `pop`: a signal to pop data from the stack (active high).
   - `data_in`: an 8-bit input data for pushing onto the stack.
3. Outputs:
   - `data_out`: an 8-bit output data that indicates the value popped from the stack.
   - `empty`: a flag indicating if the stack is empty.
   - `full`: a flag indicating if the stack is full.
