
Design a Verilog module that simulates a simple Flash memory cell. The Flash memory cell should have an input for data (D), a write enable signal (WE), a read enable signal (RE), and an output for the stored data (Q). When WE is high, the data D should be written to the memory cell. When RE is high, the output Q should reflect the stored data. If both WE and RE are low, the cell should retain its previous value.
