Design an 8-bit DRAM cell with read and write capabilities. The DRAM cell should have the following inputs: `data_in` (8 bits), `addr` (3 bits), `wr_en` (write enable), and `clk` (clock). The outputs should be `data_out` (8 bits) when read access is performed. The write operation occurs when `wr_en` is high, and the data is stored in a memory array indexed by `addr`. The read operation occurs when `wr_en` is low.
