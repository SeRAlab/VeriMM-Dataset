When the enable signal (ena) is high, the module activates one of the eight output lines based on the 3-bit binary input (data_in), setting the corresponding output to low while all others remain high. If the enable signal is low, all outputs are set to high. This implementation allows for a straightforward mapping of a 3-bit input to a unique low signal on one of the eight outputs, serving to drive additional logic or devices in a digital system.

    input ena,
    output reg [7:0] data_out
    );
