

You are tasked with creating a verilog module that will take in 4 input signals and output a single signal. The module should be named `my_module` and should have the following ports:

- `input [3:0] data_in`: A 4-bit input signal
- `output data_out`: A single output signal

Inside the module, you should declare the following signals:

- `reg [3:0] data_reg`: A 4-bit register
- `wire [3:0] data_wire`: A 4-bit wire

The module should have the following behavior:

- On the rising edge of the clock signal, the value of `data_in` should be stored in `data_reg`
- The value of `data_reg` should be assigned to `data_wire`
- If the value of `data_wire` is less than or equal to 5, `data_out` should be set to 1. Otherwise, `data_out` should be set to 0.
