Design a simple calculator module that performs basic arithmetic operations based on a 2-bit operation selector. The module takes two 8-bit inputs (a and b) and produces a 16-bit result. The operations include addition, subtraction, multiplication, and division (with zero handling), depending on the value of the operation selector (`op`). The calculator resets its output to zero when the reset signal is activated. The resulting output is a computed value based on the specified operation.
module top_module(
  input wire [1:0] op,
  input wire [7:0] a,
  input wire [7:0] b,
  input wire reset,
  output wire [15:0] result
);
