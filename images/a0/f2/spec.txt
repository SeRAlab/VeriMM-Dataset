Design a 16-bit shift register that supports loading of data and shifting operation. On a rising clock edge, if the reset signal is active, the register clears to zero. If the load signal is high, the register stores the input data. Otherwise, the register shifts its current value left by one bit, filling the least significant bit with zero. The current value of the register is continuously output on the data_out port.
