Implement a 1-bit SR flip-flop in Verilog. The flip-flop should have two inputs, S (Set) and R (Reset), and one output Q. The flip-flop should follow the standard behavior: when S is high, Q should be set to 1; when R is high, Q should be reset to 0; if both S and R are low, Q should retain its previous value. If both S and R are high, the output should be undefined.
