Develop an 8-bit shift register that supports both serial and parallel data operations. The module utilizes a clock signal to dictate when data is shifted. If the `peripheralClkEdge` signal is high, the register shifts in new data from the `serialDataIn` input. When the `parallelLoad` signal is asserted, the register loads data from the `parallelDataIn` input instead of shifting. The output `serialDataOut` provides the most significant bit of the register, while `parallelDataOut` reflects the entire contents of the register at any given time.
