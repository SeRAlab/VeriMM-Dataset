Design a simple Ethernet MAC controller's transmit state machine that handles the following states: IDLE, TRANSMITTING, and WAITING for the transmission to complete. The state machine will change states based on a start signal and a done signal. The state transitions should be as follows:  
- From IDLE to TRANSMITTING on start signal.  
- From TRANSMITTING to WAITING on done signal.  
- From WAITING back to IDLE when the done signal is asserted again.  
Implement the state machine and define the output state signal.
