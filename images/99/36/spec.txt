Design a 4-bit up-counter that increments its count on the positive edge of the clock when the enable signal is active. The counter resets to zero when the reset signal is high and wraps around back to zero after reaching a count of 12. The current count value is provided as a 4-bit output.
module top_module(
 input enable,
 input clk,
 input reset,
 output [3 : 0] count
 );
