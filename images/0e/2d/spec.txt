Design a SR flip-flop using Verilog. The flip-flop should have two inputs (S and R) and one output (Q). The output should be updated on the rising edge of a clock signal. The conditions for the SR flip-flop are as follows: If S=1 and R=0, Q should be set to 1. If S=0 and R=1, Q should be reset to 0. If S=0 and R=0, Q should maintain its previous state. If S=1 and R=1, the state is considered invalid, and Q should not change.
