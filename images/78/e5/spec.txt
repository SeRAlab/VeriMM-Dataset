Design a dual-function multipliers module capable of performing both unsigned and signed multiplication of two n-bit input numbers, A and B. The module outputs a result P that represents the lower n bits of the unsigned product. For signed multiplication, it employs Booth's algorithm, extending the input bit-width to handle sign bits, thereby supporting both positive and negative inputs effectively. The parameter 'n' specifies the bit-width, which defaults to 8 bits, and can be adjusted as needed for larger or smaller operands.
module top_module(
  input [n-1:0] A,
  input [n-1:0] B,
  output [n-1:0] P
);
