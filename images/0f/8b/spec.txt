Design an 8-bit ADC (Analog-to-Digital Converter) that takes an 8-bit binary input representing an analog voltage level and outputs a corresponding 4-bit binary value representing the quantized level. The input range is from 0 to 255, and the output should be the 4-bit value representing the nearest quantization level among 16 levels (0-15). Each step corresponds to a voltage increment of 16, so the output should be calculated as the input divided by 16.
