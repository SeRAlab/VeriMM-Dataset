
Design a Verilog module to implement a simple SD card command response controller. The module should take a 4-bit command (`cmd`) and a clock signal (`clk`) as inputs, and generate a 1-bit response signal (`response`) based on the command received. The response should be high for a specific command (e.g., `4'b0001`) and low for all other commands. The response should remain stable for one clock cycle after the command is received.
