Design a Verilog module that implements a simple state machine for a SLAM-like system. The state machine should have three states: IDLE, LOCATING, and MAPPING. The state transitions occur based on a start signal, and the outputs should indicate the current state. The input signals are a start signal and a reset signal. The state transitions are as follows: 
1. From IDLE to LOCATING on start signal.
2. From LOCATING to MAPPING on a second start signal.
3. From MAPPING back to IDLE on a reset signal.
