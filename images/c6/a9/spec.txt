

You are tasked with designing a 2-input NAND gate using Verilog. The inputs to the gate are A and B, and the output is Z. You should use the following template to design the gate:

```
module nand_gate (
    Z,
    A,
    B
);

    output Z;
    input A;
    input B;

    // Your code here

endmodule
```

Your task is to fill in the code between the `module` and `endmodule` statements to implement the NAND gate. You should use the `nand` operator to implement the gate.
