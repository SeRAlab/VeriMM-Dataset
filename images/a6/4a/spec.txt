Design a 4-bit shift register with load, shift, and reset functionalities. The register is capable of loading a 4-bit input when the load signal is active, shifting the stored data to the left on each clock cycle when the shift signal is asserted, and maintaining the original data when neither the load nor shift signals are active. Additionally, the register resets to zero when the reset signal is activated. The output reflects the current state of the register.
module top_module(
    input [3:0] data_in,
    input shift,
    input load,
    input clk,
    input reset,
    output [3:0] data_out
);
