Design a D-type flip-flop with asynchronous set and reset capabilities. On the rising edge of the clock (CLK), the flip-flop captures the value of the data input (D) unless overridden by the asynchronous set (SET) or reset (RESET) signals. If SET is activated, the output (Q) is set to high; if RESET is activated, the output is set to low. Additionally, the inverted output (Q_N) is generated by inverting Q.
module top_module(
    input D, CLK, SET, RESET,
    output reg Q, Q_N
);
