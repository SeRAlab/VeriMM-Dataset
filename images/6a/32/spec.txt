Design a 3-bit up/down counter that counts based on the state of the DIR input. When DIR is set to 0, the counter increments its value on each clock cycle; when DIR is set to 1, it decrements the value. The counter also includes a RESET input that initializes the counter to zero. The current value of the counter is available at the output Q.
module top_module(
    input CLK,
    input RESET,
    input DIR,
    output reg [2:0] Q
);
