Design a WiFi module state machine that has the following states: IDLE, CONNECTING, CONNECTED, and DISCONNECTING. The module should transition between these states based on the following inputs: `start_connect` (to initiate connection), `success` (indicates a successful connection), and `disconnect` (to disconnect). The output should indicate the current state in a 2-bit binary format: IDLE (00), CONNECTING (01), CONNECTED (10), DISCONNECTING (11).
