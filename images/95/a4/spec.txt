Design a 2-to-1 multiplexer with two selection lines (S0 and S1) for a broader range of selection options. The output Y will be driven to A when S0 and S1 are both LOW or when S0 is LOW and S1 is HIGH, and it will be driven to B when S0 is HIGH or when S1 is HIGH. This design allows for two input signals (A and B) to be selectively routed to the output based on the values of the two selection lines, effectively combining them into a single output.
module top_module(
    input A,
    input B,
    input S0,
    input S1,
    output Y
);
