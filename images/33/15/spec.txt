
Design a simple HMAC (Hash-based Message Authentication Code) module in Verilog. The module should take a key and a message as inputs, and output a hashed value. Use a simple XOR operation to simulate the hashing process for this problem. The key and message will be 8 bits each, and the output should be 8 bits as well. The HMAC can be computed as follows: HMAC(key, message) = Hash(key XOR message), where Hash is a simple XOR operation for this exercise. Implement an FSM (Finite State Machine) to process the input data and generate the output.
