Design a D-type flip-flop register with asynchronous clear and preset functions. The flip-flop captures the input data (d) on the rising edge of the clock (clk) when the enable (ena) signal is active. If the clear (clrn) signal is low, the output (q) is reset to zero, overriding other inputs. If the preset (prn) signal is low, the output is set to one, also taking precedence over the data input. This allows for flexible control of the register's state based on the control signals.
module top_module(
    input clk,
    input ena,
    input d,
    input clrn,
    input prn,
    output reg q
);
