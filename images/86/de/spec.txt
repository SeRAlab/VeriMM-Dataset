Design a simple LED driver circuit that serves as a binary counter output. It increments a 27-bit counter on each positive clock edge. When the reset signal is active, the counter resets to zero. The state of the counter is used to control five individual LEDs, with each LED representing a specific bit of the counter’s output. Specifically, `led` through `led5` display the values of the 26th to 22nd bits of the count, allowing for a visual representation of the counter's state.
module top_module(
    input clock,
    input reset,
    output led, led2, led3, led4, led5
    );
