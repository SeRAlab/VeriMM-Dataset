

You are tasked with designing a verilog module that takes in a 16-bit unsigned input `a`, and outputs a 16-bit unsigned output `y`. The output `y` should be the result of shifting the input `a` to the right by 2 bits, and then adding the original input `a` to the shifted input.

Write a verilog module that implements this functionality. You may assume that the input and output are unsigned 16-bit integers.

Your module should be named `shift_add`, and have the following ports:

- `input [15:0] a`: the 16-bit unsigned input
- `output [15:0] y`: the 16-bit unsigned output
