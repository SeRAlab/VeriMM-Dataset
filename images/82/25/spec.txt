Design a combinational logic circuit that serves as a 10-to-1 logical selection mechanism. The output X will be high when any of the following conditions are met: all three inputs A1, A2, and A3 are high; both inputs B1 and B2 are high; both inputs C1 and C2 are high; or all three inputs D1, D2, and D3 are low. This circuit effectively combines multiple input signals to produce a single output based on the specified logical conditions.
module top_module(
  input A1,
  input A2,
  input A3,
  input B1,
  input B2,
  input C1,
  input C2,
  input D1,
  input D2,
  input D3,
  output X
);
