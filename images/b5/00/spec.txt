Develop a Verilog module for a 3-bit binary down-counter with a synchronous load signal. The module should have an input clock signal (clk), an input reset signal (rst), an input load signal (load), an input [2:0] load_value, and a 3-bit output signal (count). On the rising edge of the clock, if reset is high, count should be set to 3'b111. If load is high and reset is low, count should be set to load_value. Otherwise, it should decrement by 1.
