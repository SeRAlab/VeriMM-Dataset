Design a Verilog module that implements a simplified version of the ChaCha20 stream cipher's core transformation function. This module should take in a 32-bit input key and a 32-bit nonce, perform a basic series of operations (additions, XORs, and rotations), and output a 32-bit ciphertext. The module should have a clock and reset signal, and the output should be valid after a specific number of clock cycles.
