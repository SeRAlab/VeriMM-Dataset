Design a 4-bit barrel shifter that can perform both left and right shifts based on the 2-bit control signal S. The first bit of S (S[0]) determines whether to perform a shift operation (when S[0] = 1) or to pass the input directly to the output (when S[0] = 0). The second bit of S (S[1]) specifies the shift direction: a value of 0 results in a left shift while a value of 1 results in a right shift. The output B reflects the resulting 4-bit value after the shifting operation.
module top_module(
    input [3:0] A,
    input [1:0] S,
    output [3:0] B
);
