Design a 4-bit up/down counter with load capabilities. The counter increments its value when the up/down control signal (UD) is high, decrements when UD is low, and loads a preset value from the LOAD_IN input when the load signal (LD) is asserted. It resets to zero upon receiving a reset signal (RST). The output Q reflects the current count value.
module top_module(
    input CLK, RST, LD, UD,
    input [3:0] LOAD_IN,
    output reg [3:0] Q
);
