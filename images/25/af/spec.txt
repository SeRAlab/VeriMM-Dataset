
Design a Bluetooth module that includes a simple state machine. The module should have three states: IDLE, CONNECTING, and CONNECTED. The state transitions should occur based on the input signals:
- A signal `start` that transitions from IDLE to CONNECTING.
- A signal `connect_done` that transitions from CONNECTING to CONNECTED.
- A signal `reset` that transitions back to IDLE from any state.
The output should indicate the current state as a 2-bit binary value, where:
- IDLE = 00
- CONNECTING = 01
- CONNECTED = 10
