Implement a Verilog module that shifts a 16-bit input data left by a given number of positions. The module should have the following specifications:
- `clk`: The clock signal.
- `reset`: An active-high synchronous reset signal.
- `start`: An active-high signal that starts the shifting.
- `data_in`: The 16-bit input data.
- `shift_amount`: The number of positions to shift.
- `data_out`: The output which holds the shifted data.
- `done`: An active-high signal indicating the completion of the shifting.
