Design a 4-bit adder/subtractor circuit that performs addition or subtraction based on the value of the SUB control signal. When SUB is 0, the module calculates the sum of inputs A and B; when SUB is 1, it computes the difference A minus B. The output is a 4-bit result reflecting the chosen arithmetic operation.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input SUB,
  output reg [3:0] out
);
