Design a sprite priority controller for a graphics system. This module assesses the priority of up to four sprites based on their encoding and compares it against bitmap layer priorities specified in input registers. Specifically, it establishes a 'sprcode' value representing which sprite should be prioritized, then determines if the first or second playfield is in front of the sprite based on comparisons with the encoded priority levels. Finally, the module outputs a selection signal ('sprsel'), indicating whether the sprite should be rendered in the foreground or background relative to the playfields.
