
Design a Verilog module that implements a simple PNG compression type filter, specifically the "Sub" filter. The "Sub" filter computes the difference between the current pixel and the pixel to the left. Given a pixel data input and a pixel to the left, the module should output the filtered pixel data. The input will be an 8-bit current pixel and an 8-bit pixel to the left. The output should also be an 8-bit filtered pixel.
