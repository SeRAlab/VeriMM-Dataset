Design a 4-bit shift register with load and shift capabilities. When the RESET signal is asserted, the output Q is cleared to zero. If the LOAD signal is activated, the shift register loads the 4-bit data input DIN into Q. When the SHIFT signal is triggered, the contents of Q are shifted left by one position, with a zero being introduced into the least significant bit, effectively enabling serial data shifting operations.
module top_module(
    input clk,
    input [3:0] DIN,
    input LOAD,
    input SHIFT,
    input RESET,
    output reg [3:0] Q
);
