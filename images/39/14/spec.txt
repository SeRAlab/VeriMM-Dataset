
Design a FIFO (First-In-First-Out) queue with the following specifications:
- The FIFO should have a depth of 4.
- The write operation should occur on the rising edge of the clock, and an input signal 'write_en' will indicate when to write new data.
- The read operation should occur on the rising edge of the clock, and an input signal 'read_en' will indicate when to read data.
- The FIFO should generate an output signal 'full' when it is full and an output signal 'empty' when it is empty.
- The data width of the FIFO should be 8 bits.
