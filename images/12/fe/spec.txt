
Design a Verilog module that implements a Quadrature Amplitude Modulation (QAM) encoder for 4-QAM (also known as QPSK). The module should take 2 bits of input data (representing the symbols) and output the corresponding I (In-phase) and Q (Quadrature) components as 4-bit values. The mapping should be as follows:
00 -> I =  1, Q =  1
01 -> I =  1, Q = -1
10 -> I = -1, Q =  1
11 -> I = -1, Q = -1
Ensure that the output is registered and changes on the rising edge of the clock.
