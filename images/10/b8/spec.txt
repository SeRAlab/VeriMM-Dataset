Design a Verilog module that simulates a Flash memory cell, which can be in one of two states: programmed (1) or erased (0). The module should take a control signal 'write' that indicates whether to write a value to the memory cell. If 'write' is high, the value of 'data_in' should be stored in the memory cell. If 'write' is low, the memory cell should retain its current value. The output should be 'data_out', representing the current state of the memory cell.
