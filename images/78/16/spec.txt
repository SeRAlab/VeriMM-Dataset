Design a module that implements a 2-bit logic operation unit. This unit takes two 32-bit operands and a 2-bit selector to perform logical operations based on the value of the selector—specifically, a bitwise AND when the selector is 00, a bitwise OR when it is 01, a bitwise XOR when it is 10, and outputs zero for any other value. The resulting output is a 32-bit value corresponding to the selected logical operation.
module top_module(
    input [1:0] logic_op_x,
    input [31:0] operand_0_x,
    input [31:0] operand_1_x,
    output [31:0] logic_result_x
);
