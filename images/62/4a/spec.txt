Design a D flip-flop with enable functionality. The module captures the input data (D) on the rising edge of a gated clock (ENCLK), which is derived from the original clock (CLK) using an external clock gating logic that is controlled by the enable signal (EN). When enable is high, the flip-flop updates its output (Q) with the value of D; otherwise, it retains its previous value. This design effectively reduces power consumption by disabling the clock when not needed.
module top_module(
  input CLK,
  input D,
  input EN,
  output reg Q
);
