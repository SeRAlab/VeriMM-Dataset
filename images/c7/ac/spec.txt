

You have been tasked with designing a module that takes in three input signals and outputs a single signal. The module should be named `three_to_one` and should have the following interface:

```
module three_to_one (
    input  A,
    input  B,
    input  C,
    output X
);
```

The input signals `A`, `B`, and `C` are single bit signals, while the output signal `X` is also a single bit signal. Your task is to design the logic for the `three_to_one` module such that the output signal `X` is set to 1 if and only if at least two of the input signals `A`, `B`, and `C` are set to 1.

You should write a verilog module named `three_to_one` that implements this functionality. Your module should be no longer than 200 lines of code.
