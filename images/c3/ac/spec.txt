

You have been tasked with designing a module that implements a D flip-flop with synchronous clear functionality. The module should have three inputs: Clk (clock), D (data), and Clr (clear). The output of the module should be a single bit, Q.

The module should behave as follows:
- When Clr is high (1), Q should be set to 0, regardless of the value of D.
- When Clr is low (0), Q should take on the value of D on the rising edge of Clk.

Write a Verilog module that implements this functionality. Your module should be named "d_ff_with_sync_clr" and should use the "always" keyword to define its behavior. You may assume that all inputs are synchronous to the same clock signal.
