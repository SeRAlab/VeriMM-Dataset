

You are tasked with designing a verilog module that implements a simple 2-bit counter. The module should have the following inputs and outputs:

- `clk`: a clock input
- `rst`: a reset input
- `en`: an enable input
- `count`: a 2-bit output representing the current count value

The counter should increment by 1 on each rising edge of `clk` when `en` is high. If `rst` is high, the counter should reset to 0. If `en` is low, the counter should hold its current value.

Write the verilog code for the counter module.
