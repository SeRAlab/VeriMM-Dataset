Design a simple EEPROM cell that can read, write, and reset data. The EEPROM cell should have inputs for data (D), a write enable signal (WE), a read enable signal (RE), and an output for the stored data (Q). The behavior should be as follows: 
1. When WE is high, the input data D should be written to the output Q.
2. When RE is high, the output Q should reflect the stored data.
3. If both WE and RE are low, Q should hold its previous state.
