Design a 4-bit ring counter that shifts its output value left by one position on each clock cycle when enabled. The counter initializes to a zero state upon receiving a reset signal. The current state of the counter is stored in a register, with the output continuously reflecting the next state of the counter after a shift operation. When the reset signal is deactivated and enable is asserted, the ring counter cycles through its states, creating a repeating sequence of values.
module top_module(
    input clk,
    input enable,
    input reset,
    output reg [3:0] q
);
