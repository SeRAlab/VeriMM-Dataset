

You have been tasked with designing a module that takes in 5 inputs and produces 1 output. The module should be named `multiplier` and should be implemented in Verilog. The inputs are `A`, `B`, `C`, `D`, and `E`, and the output is `Y`. The module should use the following equation to calculate the output:

```
Y = (A * B) + (C * D * E)
```

The inputs and output are all 8-bit unsigned integers. The module should have the following interface:

```
module multiplier(
    input [7:0] A,
    input [7:0] B,
    input [7:0] C,
    input [7:0] D,
    input [7:0] E,
    output reg [15:0] Y
);
```

Your task is to implement the `multiplier` module in Verilog, ensuring that it correctly calculates the output using the given equation.
