
Create a Verilog module for a simple QAM modulator that takes a 4-bit input representing a symbol and outputs two signals: I (in-phase) and Q (quadrature). The mapping should be as follows:
- 0000 -> I = 0, Q = 0
- 0001 -> I = 0, Q = 1
- 0010 -> I = 1, Q = 0
- 0011 -> I = 1, Q = 1
- 0100 -> I = 0, Q = -1
- 0101 -> I = 0, Q = -2
- 0110 -> I = 2, Q = 0
- 0111 -> I = 2, Q = 1
- and so on for other combinations.
