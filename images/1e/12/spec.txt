Design a Verilog module for a Low Dropout Regulator (LDO) that takes an input voltage (Vin) and a control signal (Enable) and produces an output voltage (Vout). The output voltage should be equal to the input voltage when the Enable signal is high, and should be zero when the Enable signal is low. The module should also include a simple current limiting feature; if the input voltage exceeds a certain threshold, the output should clamp to this threshold.
