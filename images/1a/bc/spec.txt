
Create an interrupt controller that manages two interrupt requests (IRQ0 and IRQ1). The controller will have a clock signal and a reset signal. When an interrupt request is received, it will be acknowledged on the next clock cycle, and the output will indicate which interrupt has been acknowledged. The output should be a 2-bit signal where `00` means no interrupt, `01` means IRQ0 acknowledged, and `10` means IRQ1 acknowledged. If both interrupts are requested simultaneously, IRQ0 takes priority.
