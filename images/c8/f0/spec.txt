Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a clock gating cell. 
A clock gating cell is a type of digital circuit that is used to reduce power consumption in a design by gating the clock signal to a block of logic.
Your module should have the following inputs and outputs:

Inputs: 
- clk: the input clock signal
- enable: the input enable signal

Outputs: 
- clk_out: the gated clock signal

Your module should implement the following functionality:
- When the enable signal is high, the output clock signal should be the same as the input clock signal.
- When the enable signal is low, the output clock signal should be held low.

To implement the clock gating cell, you should use Verilog code to define the functionality of the enable signal. 
You should then use this signal to control the clock output signal using an AND gate. 
Finally, you should use a D flip-flop to synchronize the output clock signal with the input clock signal.
