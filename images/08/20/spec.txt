
Design a LIFO (Last In First Out) stack in Verilog that supports the following operations:
1. Push: Add an item to the top of the stack.
2. Pop: Remove the item from the top of the stack.
3. Peek: Retrieve the item on the top of the stack without removing it.
4. IsEmpty: Check if the stack is empty.
The stack should have a fixed size of 8 elements and use a 4-bit input to represent the data.
