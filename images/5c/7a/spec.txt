Implement a 4-bit binary counter with an enable signal. When the enable signal is high, the counter counts up on every positive clock edge. If the enable signal is low, the counter holds its value. The counter should reset to 0 when the reset signal is active.

Module name:
    binary_counter

Inputs:
    clk: Clock signal.
    rst: Reset signal (active high).
    en: Enable signal.

Outputs:
    q[3:0]: A 4-bit output representing the current count value.
