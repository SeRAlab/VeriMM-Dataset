Design a 1-bit DRAM cell using Verilog. The cell should have a data input (D), a word line (WL) to control whether the data can be written to it, a bit line (BL) for reading the data, and an output (Q) for the stored data. The DRAM should also have an enable signal (EN) to control read/write operations. When EN is high, the DRAM should write D to Q when WL is high; otherwise, when EN is low, Q should hold the last value written. When reading, BL should reflect the value of Q when EN is low and WL is low.
