Design a module that interfaces with an ADC (Analog-to-Digital Converter) by transforming its input data from two channels (CHA and CHB). The module captures the 14-bit data from the ADC for both channels on each rising edge of the provided ADC clock. It also includes a clock duty cycle stabilizer that is always enabled and outputs a constant clock source value to indicate generation is disabled. The output data for both channels is transformed into a 2's complement representation, effectively inverting the lower 13 bits while preserving the sign bit for a negative slope. This module is ideal for applications where ADC outputs must be standardized for further DSP (Digital Signal Processing) tasks.
module top_module(
  // ADC IC
  input    [ 14-1: 0] adc_dat_a_i        ,  //!< ADC IC CHA data connection
  input    [ 14-1: 0] adc_dat_b_i        ,  //!< ADC IC CHB data connection
  input               adc_clk            ,
  output [ 2-1: 0]    adc_clk_source     ,  // optional ADC clock source
  output              adc_cdcs_o         ,  // ADC clock duty cycle stabilizer
 
  // user interface
  output   [ 14-1: 0] adc_dat_a_o        ,  //!< ADC CHA data
  output   [ 14-1: 0] adc_dat_b_o        ,  //!< ADC CHB data
  input               adc_rst_i             //!< ADC reset - active low
);
