

You have been tasked with creating a Verilog module that implements a simple 16-bit adder. The module should have two 16-bit inputs, A and B, and a 16-bit output, S. The module should also have a single input, CIN, which represents the carry-in bit for the addition operation. The module should implement the following equation to calculate the output S:

S = A + B + CIN

Your task is to write the Verilog code for this module.
