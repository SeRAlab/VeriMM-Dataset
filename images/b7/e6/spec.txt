Design a logic module that outputs a value based on several conditions. The output X is set to high (1) if both inputs A1 and A2 are high (1). If input B1_N is low (0), the output is forced low (0). Additionally, if power conditions (VPWR is high and VGND is low) are met, output X is set to high (1). Conversely, if the bias conditions (VPB is high and VNB is low) are satisfied, output X goes low (0). If none of the specified conditions are met, the output defaults to high (1).
module top_module(
    output X,
    input A1,
    input A2,
    input B1_N,
    input VPWR,
    input VGND,
    input VPB,
    input VNB
);
