Create a JK latch using Verilog. The JK latch should have inputs J, K, and a clock signal (clk). The outputs should be Q and Q_bar. The latch should toggle its state based on the J and K inputs on the rising edge of the clock. If both J and K are low, the state should remain unchanged. If J is high and K is low, the output should be set (Q = 1). If J is low and K is high, the output should be reset (Q = 0). If both J and K are high, the output should toggle.
