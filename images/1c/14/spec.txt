 
Design a 4-to-2 encoder in Verilog. The encoder should take 4 input lines (I0, I1, I2, I3) and provide 2 output lines (Y0, Y1) that represent the binary encoding of the highest priority input line that is asserted (active high). If none of the inputs are active, the outputs should be set to a defined "invalid" state (e.g., 2'b00).
