
Design a simple Finite State Machine (FSM) that has three states: IDLE, WORKING, and DONE. The FSM transitions between states based on a single input signal `start`. The transitions are defined as follows:
- When in IDLE state, if `start` is high, transition to WORKING.
- When in WORKING state, if `start` is low, transition to DONE.
- When in DONE state, if `start` is high, transition back to IDLE.
The output should indicate the current state with a 2-bit binary code: IDLE = 00, WORKING = 01, DONE = 10.
