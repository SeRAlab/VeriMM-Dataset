Design a dual-edge triggered D flip-flop with asynchronous set and reset functionalities. When the reset (rst) signal is asserted, the flip-flop outputs are set to LOW (q=0, q_bar=1). When the set (set) signal is asserted, the outputs are set to HIGH (q=1, q_bar=0). In the absence of both reset and set signals, the flip-flop captures the value of the data input (d) at the rising edge of the clock (clk) and produces an inverted output (q_bar). This module effectively allows for controlled initialization and state retention based on clock events.
