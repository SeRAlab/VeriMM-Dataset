Design a register that stores a 12-bit input address value. On the rising edge of the clock signal, the current address input is latched into the register. The output, q, reflects the address value when the clock is high, and retains the previous registered value when the clock is low. This behavior allows for controlled data flow based on the clock, typical for synchronous designs.
