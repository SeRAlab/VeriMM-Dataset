

You have been tasked with designing a module for a digital circuit that takes in a single input and produces a single output. The module should be named `my_module` and should have the following port definitions:

- One input named `in` of size 8 bits.
- One output named `out` of size 8 bits.

The module should perform the following operation on the input `in` to generate the output `out`:

1. If the most significant bit (MSB) of `in` is 1, set the MSB of `out` to 0 and set all other bits of `out` to 1.
2. If the MSB of `in` is 0, set the MSB of `out` to 1 and set all other bits of `out` to 0.

You should implement the module using only combinational logic. You may use any number of intermediate signals.

Write the `my_module` module in Verilog, ensuring that your code is no more than 200 lines long and that it is well-structured and easy to read.
