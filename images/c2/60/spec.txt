

You are tasked with designing a module in Verilog that implements a simple 4-bit adder. The module should have two 4-bit inputs, A and B, and a 1-bit input, Cin, representing the carry-in bit. The module should also have two outputs, Sum and Cout, representing the sum of A and B and the carry-out bit, respectively. The module should be named "four_bit_adder".

Your module should implement the following equation for the sum output:
```
Sum = A + B + Cin
```
Where the addition is performed in binary arithmetic.

If the sum of A, B, and Cin is greater than 15, the Cout output should be set to 1, indicating that there was a carry-out from the most significant bit. Otherwise, Cout should be set to 0.

You may assume that the inputs A and B are valid 4-bit binary numbers and that Cin is a valid 1-bit binary number.

Your module should be contained within 200 lines of Verilog code.
