Create a Verilog module for a 16-bit gray code counter with synchronous reset and enable signals. The module should have an input clock signal (clk), an input enable signal (en), an input synchronous reset signal (rst), and a 16-bit output signal (gray). On the rising edge of the clock, if reset is high, gray should be set to 16'b0000000000000000. If enable is high, gray should increment in gray code sequence.
