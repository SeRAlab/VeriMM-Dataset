Create a module for a 2-to-1 multiplexer with a 4-bit wide data input. The module should have two 4-bit data inputs, one 1-bit select input, and one 4-bit output. The output should be one of the two inputs based on the value of the select signal.

Module name:
    mux2to1
Input ports:
    a: a 4-bit data input
    b: a 4-bit data input
    sel: a 1-bit select input
Output ports:
    y: a 4-bit output representing the selected input

Implementation:
The module uses an always block to assign the output 'y' based on the value of the select signal. If the select signal is '0', the output 'y' is assigned the value of input 'a'. If the select signal is '1', the output 'y' is assigned the value of input 'b'.
