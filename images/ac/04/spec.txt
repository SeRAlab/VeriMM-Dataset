Design a 32-bit linear feedback shift register (LFSR) based pseudo-random number generator. The module generates a sequence of pseudo-random numbers based on an input seed, which can be loaded when the loadseed_i signal is asserted. It resets to zero on the reset signal and, on each clock cycle when not loading a new seed, shifts the current number while generating new bits using a feedback function derived from specific bits of the internal state. The output number_o reflects the current state of the LFSR.
