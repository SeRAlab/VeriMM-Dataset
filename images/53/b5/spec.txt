Design a 32-bit up counter that increments on each positive clock edge. The counter resets to zero when the reset signal is high and indicates when it has reached its maximum value of 2^32 - 1 through a separate output signal. When the count reaches its maximum, the `max_reached` output will be set to high, otherwise, it will be low. This module is suitable for applications requiring overflow detection in counting operations.
module top_module(
    input clk,
    input rst,
    output reg [31:0] count,
    output reg max_reached
);
