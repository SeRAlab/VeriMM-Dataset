Design a Direct Memory Access (DMA) controller in Verilog. The DMA controller should be able to transfer data from a source memory address to a destination memory address based on control signals. It should hold the current address, and on a valid transfer signal, it should read from the source and write to the destination. The data width for the transfer should be 8 bits, and the addresses should be 8 bits as well. The controller should also support a simple handshaking mechanism with an 'ack' signal for successful data transfer.
