
Design a simple interrupt controller that handles up to 4 different interrupt requests (IRQs). The controller should acknowledge an interrupt when the corresponding IRQ signal is active, and it should produce an interrupt acknowledge signal (ACK) for the highest priority active interrupt. The priority order is IRQ0 > IRQ1 > IRQ2 > IRQ3. If no interrupts are active, the ACK signal should remain low. The controller should also provide a reset input to clear any active interrupts and reset the ACK signal.
