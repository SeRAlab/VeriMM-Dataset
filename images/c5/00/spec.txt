

Design a Verilog module that takes a 4-bit input `data_in` and outputs a 2-bit value `data_out`. The `data_out` value should be determined based on the following rules:
- If the input value is less than or equal to 4, the output should be 00.
- If the input value is between 5 and 8 (inclusive), the output should be 01.
- If the input value is between 9 and 12 (inclusive), the output should be 10.
- If the input value is greater than 12, the output should be 11.

Your module should be named `data_converter` and should have the following interface:
- `data_in`: a 4-bit input.
- `data_out`: a 2-bit output.

You may assume that the input value will always be a valid 4-bit binary number.
