Design a hardware-based true random number generator (TRNG) that produces an 8-bit random output (R) when enabled. The module employs a clock signal (clk) and an enable signal (en) to control its operation. It uses feedback from the output state to generate new random values based on a series of XOR operations and bit-shifting techniques. When enabled, it updates its internal state with new random values derived from the previous output, leveraging a combination of internal registers and combinational logic to ensure randomness. The output value reflects the most recent state after synchronization with the clock.
