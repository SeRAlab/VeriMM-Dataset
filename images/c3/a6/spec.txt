

You are tasked with designing a verilog module for a simple calculator. The calculator should be able to perform basic arithmetic operations such as addition and subtraction. The module should have the following inputs and outputs:

Inputs:
- `clk`: clock signal
- `reset`: reset signal
- `operation`: a 2-bit input that specifies the operation to perform. `00` represents addition, and `01` represents subtraction.
- `operand1`: a 8-bit input that represents the first operand.
- `operand2`: a 8-bit input that represents the second operand.

Outputs:
- `result`: an 8-bit output that represents the result of the operation.

You should implement the calculator using a single always block.
