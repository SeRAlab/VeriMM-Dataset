Design a circuit that implements an 8-to-1 multiplexer. The module selects one of four 8-bit inputs (a, b, c, d) based on the 4-bit selection input (sel). According to the value of sel, the corresponding input is routed to the output (mux_out). Each input can be selected multiple times for specific selection values, allowing for greater flexibility in routing among four 8-bit data sources.
module top_module(
  input [3:0] sel,
  input [7:0] a,
  input [7:0] b,
  input [7:0] c,
  input [7:0] d,
  output reg [7:0] mux_out
);
