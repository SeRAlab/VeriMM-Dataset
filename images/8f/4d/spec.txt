Design a 4-bit shift register that operates on the rising edge of the clock. When the shift signal is LOW, it loads the input data D into the register. When the shift signal is HIGH, it performs a right shift operation, moving the existing register data right by one bit and inserting the most significant bit from D into the least significant position. The module outputs the most significant bit (Q3) of the register's current state.
module top_module(
    input clk,
    input shift,
    input [3:0] D,
    output reg Q3
);
