
Design a Verilog module that implements a simple Flash memory cell interface. The module should have a data input (`data_in`), a control signal for write (`write_enable`), and a data output (`data_out`). When the `write_enable` signal is high, the `data_in` value should be stored and output on `data_out`. When `write_enable` is low, `data_out` should reflect the last written value.
