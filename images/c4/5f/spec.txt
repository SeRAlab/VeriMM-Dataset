

You have been hired to design a verilog module for a digital clock gate. The module should have four inputs: a clock signal `CLK`, an enable signal `EN`, a test enable signal `TE`, and an output enable clock signal `ENCLK`. The module should be named `my_clock_gate`.

The module should implement a gated clock, where the output clock signal `ENCLK` is enabled only when the input clock signal `CLK` is high and the enable signal `EN` is also high. Additionally, the clock gate should be sensitive to the test enable signal `TE`, which should be used to test the module.

The module should use a flip-flop to store the enable signal `EN`. The flip-flop should be sensitive to the clock signal `CLK` and the test enable signal `TE`. The output of the flip-flop should be connected to a buffer, which should generate the output enable clock signal `ENCLK`.

You should write the verilog code for the `my_clock_gate` module that implements the above requirements.
