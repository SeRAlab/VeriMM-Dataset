

You have been tasked with designing a verilog module that implements a 4-to-1 multiplexer using only 2-to-1 multiplexers. Your module should have four input signals (D0, D1, D2, D3), two select signals (S0, S1), and one output signal (Y).

Your module should have the following interface:
```
module MUX4to1_using_2to1 (D0, D1, D2, D3, S0, S1, Y);
input D0, D1, D2, D3, S0, S1;
output Y;
// your code here
endmodule
```
You should not use any other verilog constructs, such as if-else statements or case statements, to implement the 4-to-1 multiplexer.
