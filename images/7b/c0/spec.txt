Implement a 4-bit binary counter that counts from 0 to 15 and then wraps around to 0. The counter increments on the positive edge of the clock signal and has an active-low synchronous reset signal.

Module name:
    binary_counter

Input ports:
    clk: Clock signal used for synchronous operation.
    rst_n: Active-low synchronous reset signal.

Output ports:
    count: 4-bit output representing the current count.

Implementation:
Use a 4-bit register to store the current count. On the positive edge of the clock signal, if the reset signal is asserted, reset the count to 0. Otherwise, increment the count by 1. When the count reaches 15, it wraps around to 0 on the next increment.
