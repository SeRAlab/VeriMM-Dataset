Design a dual-port RAM module with a size of 1024 words, each 16 bits wide. The module supports simultaneous read and write operations: when the 'we' (write enable) signal is high, data is written to the memory location specified by 'waddr' on the rising edge of the clock. Regardless of the write operation, the data from the memory location specified by 'raddr' is always output to 'rdata' on each clock cycle. This design allows for efficient data storage and retrieval in applications requiring concurrent access to memory.
