Design a JK latch using Verilog. The JK latch should have inputs J, K, and a clock signal. The output should be Q and its complement Qn. The behavior should be such that on the rising edge of the clock, if J and K are both low, the output Q should hold its previous value. If J is high and K is low, Q should be set to high. If J is low and K is high, Q should be set to low. If both J and K are high, Q should toggle.
