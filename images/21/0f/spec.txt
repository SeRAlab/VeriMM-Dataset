
Design a simple instruction pipeline that supports two types of instructions: LOAD and ADD. The pipeline should consist of three stages: Instruction Fetch (IF), Instruction Decode (ID), and Execute (EX). The instruction format is as follows:
- LOAD: opcode (2 bits), address (4 bits)
- ADD: opcode (2 bits), source (4 bits), destination (4 bits)

The pipeline should handle instruction execution with a simple control logic to manage data hazards. Implement a state machine to transition between the stages of the pipeline.
