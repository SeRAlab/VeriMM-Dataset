
Design a 32-bit Linear Feedback Shift Register (LFSR) with a primitive polynomial x^32 + x^22 + x^9 + x^8 + x^7 + x^5 + 1. The LFSR should have a reset function and produce a new output on every clock cycle. The output of the LFSR should be a 32-bit value that changes with each cycle. Include an enable signal to start and stop the generation of new values.
