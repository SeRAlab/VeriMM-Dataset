Design a JK latch using Verilog that has the following behavior: The latch should have two inputs (J and K) and one output (Q). The latch should toggle its state based on the J and K inputs according to the following rules:  
- If J=1 and K=0, set Q to 1.  
- If J=0 and K=1, set Q to 0.  
- If J=0 and K=0, hold the current state of Q.  
- If J=1 and K=1, toggle Q.  
The latch should also have a clock input (clk) that triggers the changes on the rising edge of the clock.
