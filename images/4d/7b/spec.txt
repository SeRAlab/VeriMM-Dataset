Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state J (output 0).
2. state K (output 1).
3. state L (output 0).

State transitions:
1. From state J: If i = 1, then transition to state K. If i = 0, then transition to state L.
2. From state K: If i = 1, then transition to state L. If i = 0, then transition to state J.
3. From state L: If i = 1, then transition to state K. If i = 0, then transition to state J.

Assume that a one-hot code is used with the state assignment a[2:0] = 001(J), 010(K), 100(L)

Write a Verilog for the signal A0, which is the input of state flip-flop a[0], for the signal A1, which is the input of state flip-flop a[1]. Derive the Verilog by inspection assuming a one-hot encoding.

module top_module (
        input [2:0] a,
        input i,
        output reg A0,
        output reg A1);
