Create a combinational logic circuit that outputs a 4-bit value based on the inputs c and d. The output mux_in produces different 4-bit values depending on the conditions: if both c and d are high, output 1001; if only c is high, output 0101; if only d is high, output 0001; and if both are low, output 0100. This functionality can be seen as a form of a priority encoder.
module top_module(
    input c,
    input d,
    output [3:0] mux_in
);
