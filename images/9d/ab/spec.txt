Design a simple 4-bit wide calculator that performs either addition or subtraction based on a control signal. When the control signal (op) is 0, the module subtracts the second input (B) from the first input (A); when the control signal is 1, it adds the two inputs together. The result is output as a 4-bit value.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input op,
    output reg [3:0] result
);
