Design a D-type flip-flop with asynchronous reset and set inputs, as well as a toggle enable feature. On each positive clock edge, if the reset (RN) signal is active, the output is set to LOW; if the set (SN) signal is active, the output is set to HIGH. If the toggle enable (TE) signal is asserted, the output takes the value from the next state register (Q_next). Otherwise, the output follows the data input (D). The module outputs the least significant bit of the 2-bit register Q_reg as the final output Q.
