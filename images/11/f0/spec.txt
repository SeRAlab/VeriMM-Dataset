Design a simple NVMe command decoder that takes a 4-bit command input and outputs a corresponding 3-bit command type. The decoder should output a specific command type based on the input command using the following mapping:  
- 0000: 000 (No Operation)  
- 0001: 001 (Read)  
- 0010: 010 (Write)  
- 0011: 011 (Erase)  
- 0100: 100 (Flush)  
- 0101: 101 (Check Status)  
- 0110: 110 (Get Features)  
- 0111: 111 (Set Features)  
For any command not in the range 0000 to 0111, output should be 111 (Invalid Command).
