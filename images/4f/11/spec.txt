Design a multi-input logical circuit that generates a single output based on a combination of inputs. The output is high if either both inputs 'a' and 'b' are high, at least one of the inputs 'c' or 'd' is high, at least one of the inputs 'e' or 'f' is low, input 'g' is high, input 'h' is low, or input 'i' is high. This design effectively combines various logical operations (AND, OR, NOT) across nine input signals to produce a versatile output based on specific criteria.
module top_module(
    input a,
    input b,
    input c,
    input d,
    input e,
    input f,
    input g,
    input h,
    input i,
    output out
);
