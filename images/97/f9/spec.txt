Implement a 16K x 8-bit low-power RAM module that operates with a clock signal. The module features an address input for selecting memory locations, alongside control signals for chip select (cs), write enable (we), and output enable (oe). When chip select is active and write enable is asserted, data is written to the specified memory address. Conversely, when chip select is active and write enable is deactivated, the module reads data from the addressed memory location and drives that data onto a bidirectional data bus, provided that output enable is also active. If either the output enable is inactive or the write enable signal is asserted, the data bus is tri-stated.
