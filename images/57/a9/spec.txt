Module name:  
    ShiftReg_16_load              
Input ports:
    clk: Clock signal used for synchronous operation.
    rst: Active-high reset signal to initialize the shift register.
    load: Active-high load signal to load a specific value into the shift register.
    load_val: 16-bit value to be loaded into the shift register when load is high.
Output port:
    Q: 16-bit register representing the current shift register value.

On every rising edge of the clock signal (clk), the shift register value is updated.

Otherwise, the shift register shifts left by 1 bit, with the LSB set to 0.
