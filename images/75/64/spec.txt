The output Y is high when either the combination of inputs A and B is high or when the combination of inputs C and D is high, effectively functioning as a two-input OR gate receiving inputs from two separate two-input AND gates.
module top_module(
    output Y,
    input  A,
    input  B,
    input  C,
    input  D
);
