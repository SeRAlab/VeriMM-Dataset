Design an NVMe controller status register that tracks the state of multiple command submissions. The register should be capable of indicating whether commands are in progress, completed, or if there's an error. The state should be updated based on input signals: `cmd_submitted`, `cmd_completed`, and `cmd_error`. The state machine should be able to handle these changes in a synchronous manner based on a clock signal `clk` and an active-high reset signal `rst_n`.
