Design a logic function module with three outputs (Y1, Y2, Y3) based on the value of input C. When C is LOW (0), Y1 reflects the value of input A and Y2 reflects the value of input B, while Y3 outputs a LOW. Conversely, when C is HIGH (1), Y2 outputs a LOW and Y3 reflects the value of input B. This design effectively implements conditional output selection based on the state of input C.
module top_module(
  input A,
  input B,
  input C,
  output Y1,
  output Y2,
  output Y3
);
