Design a 4-to-1 multiplexer with an additional reset functionality. The module selects one of four input signals (A, B, C, D) based on the two select lines (SEL0 and SEL1). If the RESET signal is activated, the output (Y) is set to LOW; otherwise, the output reflects the value of the selected input. This multiplexer effectively allows for the selection of one of four data lines, making it useful for various digital applications requiring data routing.
module top_module(
    input A,
    input B,
    input C,
    input D,
    input SEL0,
    input SEL1,
    input RESET,
    output reg Y
);
