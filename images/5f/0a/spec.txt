Design a digital circuit that outputs a logic level X based on the states of five input signals. The output X is set to HIGH (1) when all three inputs A1, A2, and A3 are HIGH. If A1, A2, and A3 are not all HIGH, X will be LOW (0) only when both B1 and B2 are HIGH; in any other case, X will remain HIGH (1). This module effectively serves as a combination of logic gates that prioritize conditions from the A inputs before considering the B inputs.
module top_module(
    input A1,
    input A2,
    input A3,
    input B1,
    input B2,
    output X
);
