Design a JK flip-flop in Verilog that has the following characteristics: It should have inputs J, K, a clock signal (clk), and an asynchronous reset (reset). The output should be Q, which represents the current state of the flip-flop. The flip-flop should toggle its state based on the values of J and K at the rising edge of clk, and it should reset to 0 when reset is high.
