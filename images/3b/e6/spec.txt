Design a 4-bit DRAM cell with read and write operations. The DRAM cell should have a 4-bit data input (D), a 4-bit data output (Q), a write enable (WE), and a clock (clk). When WE is high, the input data D should be written to the memory cell on the rising edge of the clock. When WE is low, the current stored value should be read out to Q on the rising edge of the clock.
