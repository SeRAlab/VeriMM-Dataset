Design a 3-to-8 decoder with an active LOW enable signal. When the enable input (en) is LOW, the output (y) will be all zeros. When the enable input is HIGH, the decoder outputs a single HIGH signal on the output pin corresponding to the binary value of the 3-bit input (w), while all other output pins will be LOW. This functionality allows the module to select one of eight outputs based on the input value, effectively implementing a decoder circuit.
