
Design a Verilog module that performs LU decomposition of a given 2x2 matrix. The input will be a 2x2 matrix represented as two 8-bit inputs (A11, A12 for the first row and A21, A22 for the second row). The output should be two 8-bit values for each of the lower (L) and upper (U) triangular matrices resulting from the LU decomposition.
