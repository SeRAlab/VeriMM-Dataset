The state transitions occur on clock edges, with a reset functionality that initializes the state to S0. The output logic is explicitly defined based on the current state and input conditions, effectively creating a sequential circuit that reacts to its inputs according to predefined behaviors.
module top_module(
  input clk,
  input reset,
  input data_in,
  input enable,
