
Create a Verilog module that implements a simple Network Address Translation (NAT) functionality. The module should take a 32-bit internal IP address and a 32-bit external IP address as inputs, as well as a 16-bit internal port and a 16-bit external port. The output should be a 32-bit mapped external address with a 16-bit mapped external port. The mapping should be done as follows:
- The internal IP should be mapped to the external IP.
- The internal port should be mapped to the external port.
- The output should remain valid for a clock cycle after the inputs are stable before outputting the result.
