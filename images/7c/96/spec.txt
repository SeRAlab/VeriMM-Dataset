Design a hazard detection unit for a pipelined processor architecture. This module monitors control signals and register dependencies to determine if there are data hazards that would require stalling the instruction pipeline. Specifically, it checks if any instructions in the execution stage may read from a register being written to by either a memory operation or an instructive dependency. Based on this analysis, it controls the flow by asserting signals that halt the program counter (PCWrite) and the instruction fetch stage (IFIDWrite) while also indicating whether to set the output to zero (ctrlSetZero). This ensures that data hazards do not result in incorrect program execution.
