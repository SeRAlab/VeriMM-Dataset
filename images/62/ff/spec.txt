Design a binary counter that increments its value on each clock cycle. When the reset signal is low, the counter output is initialized to zero. The counter continues to increment until it reaches a specified maximum count value, at which point it wraps around back to zero. The counter operates on an 8-bit width, allowing it to count from 0 to a maximum of 255, as defined by the input `max_count`.
module top_module(
    input clk,
    input reset,
    input [7:0] max_count,
    output reg [7:0] count_out
);
