

You have been tasked with designing a Verilog module for a flip-flop with asynchronous reset. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock signal with a 50% duty cycle.
- `reset`: an asynchronous reset signal. When `reset` is high, the output of the flip-flop should be set to 0.
- `d`: the data input to the flip-flop.

Outputs:
- `q`: the output of the flip-flop.

You should name your module `async_reset_ff`.
