Design a circuit that functions as an 8-bit edge detector, which is triggered on the rising edge of the clock. The module receives an 8-bit input and compares it with its previous state to identify any changes. If a change is detected (i.e., a transition from 0 to 1), the corresponding bit in the output will be set to 1. The output will indicate which bits of the input have experienced a positive transition since the last clock cycle.
module top_module(
    input clk,
    input [7:0] in,
    output reg [7:0] anyedge
);
