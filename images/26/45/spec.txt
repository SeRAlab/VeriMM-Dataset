
Design a fan speed control system that takes an input temperature reading and adjusts the fan speed accordingly. The system has three states: Low, Medium, and High. The fan speed is set as follows:
- If the temperature is below 20 degrees, the fan speed is Low.
- If the temperature is between 20 and 30 degrees, the fan speed is Medium.
- If the temperature is above 30 degrees, the fan speed is High.
The system should use a clock to sample the temperature input and change the fan speed state only on the rising edge of the clock.
