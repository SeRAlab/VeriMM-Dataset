Develop a circuit that combines the functionality of a 2-to-1 multiplexer and a decoder with a synchronous reset. The multiplexer selects between two inputs, `a` and `b`, where if `a` is LOW (0), it outputs `b`; otherwise, it outputs `a`. Additionally, the design employs a decoder-like logic using NAND gates to further manipulate the output based on the states of `a` and `b`. Importantly, there is a synchronous reset mechanism that sets the output `final_output` to LOW when the reset signal is activated.
module top_module(
  input a,
  input b,
  input reset,
  output reg final_output
);
