Design a 2nd-order IIR filter that takes 16-bit signed input data and outputs a 16-bit signed output. The filter coefficients should be defined as parameters: b0, b1, b2 for the feedforward coefficients and a1, a2 for the feedback coefficients. The filter should implement the difference equation:  
y[n] = b0*x[n] + b1*x[n-1] + b2*x[n-2] - a1*y[n-1] - a2*y[n-2]  
Assume initial conditions for the output are zero.
