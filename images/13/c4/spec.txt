Design a 2-channel DMA (Direct Memory Access) controller in Verilog. The DMA controller should manage two channels and allow for data transfer from a source address to a destination address. The controller should have the following inputs: 
- clk: Clock signal
- reset: Asynchronous reset signal
- start: Start signal to initiate the DMA transfer
- channel_select: Signal to select between Channel 0 and Channel 1
- src_addr: Input source address for data transfer
- dest_addr: Input destination address for data transfer
- data_in: Input data to be transferred

The outputs should be:
- busy: Indicates if the DMA controller is currently transferring data
- data_out: Output data that has been transferred
- transfer_complete: Signal that indicates the transfer has completed
