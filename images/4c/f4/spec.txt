Design a channel bridge module that interfaces two data streams in a way that validates and transfers data between them. The module stores incoming data, channel identifiers, and packet start/end indicators when both the input is valid and the output is ready. It signals readiness to accept input data through the `in_ready` output and generates a valid output (`out_valid`) based on the availability of incoming data. If the specified channel is greater than zero, it suppresses the output, indicating through a message that the channel is inactive. The functionality is orchestrated by a clock signal with an active-low reset, ensuring synchronous operation and clear state management.
module top_module(
    input clk,
    input reset_n,
    input in_valid,
    input [7:0] in_data,
    input [7:0] in_channel,
    input in_startofpacket,
    input in_endofpacket,
    output reg in_ready,
    input out_ready,
    output reg out_valid,
    output reg [7:0] out_data,
    output reg [7:0] out_channel,
    output reg out_startofpacket,
    output reg out_endofpacket
);
