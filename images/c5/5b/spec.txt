Please act as a professional verilog designer. Design a module that implements a 4-bit barrel shifter. The module should have two inputs, a 4-bit data input (data_in) and a 2-bit shift input (shift). The module should output the shifted data (data_out) based on the shift input. If shift=00, data_out should be the same as data_in. If shift=01, data_out should be data_in shifted left by one bit. If shift=10, data_out should be data_in shifted right by one bit. If shift=11, data_out should be data_in shifted right by two bits.
