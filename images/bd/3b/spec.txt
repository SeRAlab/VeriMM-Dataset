Design a 32-bit incrementer circuit that conditionally adds one to a 32-bit input based on a control bit. The module takes a 33-bit input, where the most significant bit (bit 32) serves as a control signal. If this control bit is high (1), the module outputs the input value incremented by one; otherwise, it simply outputs the lower 32 bits of the input unchanged.
