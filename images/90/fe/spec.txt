Design a module that performs arithmetic and comparison operations on two 16-bit inputs, `in1` and `in2`. It computes the sum and difference of the inputs with an adder and a subtractor, respectively, and compares the inputs using a comparator. The output, a 16-bit wide signal, is determined by a control signal: when `control` is high, the output signals the result of the comparison as an extension, while when `control` is low, it outputs either the sum or the difference based on the selection of the control signal. This module effectively functions as a basic arithmetic and comparison unit.
module top_module(
  input wire [15:0] in1,
  input wire [15:0] in2,
  input wire control,
  output wire [15:0] out
);
