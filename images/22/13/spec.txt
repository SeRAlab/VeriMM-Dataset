
Design a 1-bit SRAM cell in Verilog. The SRAM cell should have an input data line (D), a write enable (WE), and a read enable (RE) signal. When WE is high, the data on the D line should be written to the cell. When RE is high, the data from the cell should be output on the Q line. The cell should maintain its state when both WE and RE are low.
