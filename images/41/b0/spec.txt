Design a dual-port audio buffer that facilitates reading and writing audio samples with separate read and write clocks. The module features two buffers, each capable of storing up to 100 audio samples, allowing for interleaved access. When the read command is issued, it uses a write pointer to fetch audio data from one of the buffers, alternating between them upon reaching the end of the buffer. Audio interrupt signals are generated to indicate when new data is available for processing. The system can reset the pointers and buffer states, ensuring reliable operation in an audio handling environment.
