Design a simple dynamic range compression unit in Verilog that takes an 8-bit input signal and a control signal to determine the level of compression. The output should be a compressed 8-bit signal. The compression should reduce the dynamic range of the input signal based on a simple threshold mechanism, such that if the input exceeds a certain threshold, it should be scaled down. For example, if the threshold is set to 128, any input greater than 128 should be scaled down to a maximum of 128. The control signal will enable or disable the compression functionality.
