Design a circuit that decodes a 3-bit binary input (count) into a 7-segment display output. For each possible value of count ranging from 0 to 7, the module assigns a unique 7-bit code to the display output that corresponds to the segments needed to represent the decimal digits 0 through 7. For any count value outside this range, the display outputs all segments off.
module top_module(input [2:0] count,output reg [6:0] display);
