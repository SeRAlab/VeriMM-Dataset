Design a registered flip-flop with asynchronous reset and load functionality. The module stores a SIZE-bit wide data input (din) and is clock-triggered; upon a rising clock edge, it either loads the input data into the output (q) if the load signal is high or retains the current output value. Additionally, if the asynchronous reset signal (rst_l) is low, the output is reset to zero regardless of the clock or load signal.
