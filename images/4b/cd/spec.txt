Design a synchronous memory module with 256 locations, each capable of storing 16 bits of data. The module has a clock input that controls data writing and reading. When the write enable signal (wren) is active, data from the input is written to the memory location specified by the address. When the read enable signal (rden) is active, the data from the specified location is read and stored in the output register, which holds the last read value for output. The system allows for asynchronous reading during clock cycles, ensuring that memory operations are synchronized with the clock signal.
