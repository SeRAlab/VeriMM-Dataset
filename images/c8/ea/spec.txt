

You are tasked with designing a module that will take in two 4-bit inputs, A and B, and output the difference between them. The output should be a 5-bit 2's complement number. The module should also have a control input, C, which when set to 1 will negate the output.

Write a Verilog module that implements this functionality. You may use any Verilog constructs that you see fit.
