Design an elevator controller that determines which floor to select based on the requested floor number and the direction of travel. The module includes a priority encoder that encodes the requested floor number into a binary representation, followed by a conversion to Gray code to reduce the chances of errors during transitions. The control logic then selects the appropriate output based on the Gray code value and the specified direction, ensuring that the elevator moves efficiently towards the intended floor while avoiding unnecessary stops.
module top_module(
    input [3:0] floor_num,
    input [1:0] direction,
    output reg [2:0] floor_select
);
