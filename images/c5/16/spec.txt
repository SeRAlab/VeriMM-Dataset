

You have been tasked with designing a verilog module that takes in three inputs: `in1`, `in2`, and `in3`. The output of the module should be the result of the following operation: `in1 & in2 | ~in3`. 

Design a verilog module to implement this function. 

Your module should be named `bitwise_logic` and should have the following inputs and outputs:

Inputs:
- `in1`: a 1-bit input
- `in2`: a 1-bit input
- `in3`: a 1-bit input

Outputs:
- `out1`: a 1-bit output that represents the result of the operation `in1 & in2 | ~in3`

You may not use any built-in verilog operators or functions to perform the bitwise logic operation.
