
Design a 4-bit Cyclic Redundancy Check (CRC) circuit using Verilog. The CRC should compute the CRC for 4-bit input data using a polynomial divisor of x^4 + x + 1 (binary 10101). The output of the CRC circuit should be the 4-bit CRC checksum for the input data. The circuit should have an enable signal to start the computation. The CRC computation starts at the rising edge of the clock when the enable signal is high. The output should be ready after 4 clock cycles.
