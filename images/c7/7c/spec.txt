

You have been tasked with designing a module in Verilog that implements a 4-input AND gate. The module should have 4 input ports (A, B, C, D) and 1 output port (Y). The output Y should be high only if all the input ports are high. If any of the input ports are low, the output Y should be low.

Design a module that implements the 4-input AND gate described above. Your module should be named "and4" and should be contained within 200 lines of Verilog code. Your module should be self-contained and should not require any external modules or libraries.

Your module should be able to handle inputs of arbitrary bit widths, but for simplicity, you can assume that all inputs are 1-bit wide.
