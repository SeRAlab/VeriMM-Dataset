Design a Fibonacci number generator that computes Fibonacci values on each clock cycle. The module takes an input n, which specifies how many terms of the Fibonacci sequence to calculate, and it outputs the current Fibonacci number in 'result'. Upon reset, it initializes the calculations. The 'ready' signal indicates when the computation is complete, allowing the user to know when the desired Fibonacci number has been produced. The design incorporates state tracking through internal registers for the last computed value and the current count, enabling sequential computation of Fibonacci numbers based on input parameters.
