Design a simple Ethernet MAC controller state machine that processes incoming frames. The state machine should have the following states: IDLE, RECEIVE, PROCESS, and TRANSMIT. The state transitions are triggered by the signals `start_receive`, `frame_received`, `process_done`, and `transmit_done`. The state machine should output the current state as a 2-bit value (00 for IDLE, 01 for RECEIVE, 10 for PROCESS, and 11 for TRANSMIT).
