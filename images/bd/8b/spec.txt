Design a 4-bit shift register with load, shift right, and shift left capabilities. When the load (LD) signal is asserted, the register captures and stores the input data (D). When the shift right (SR) signal is activated, the bits in the register are shifted one position to the right, with the most significant bit (MSB) wrapping around to the least significant bit (LSB). Similarly, activating the shift left (SL) signal shifts the bits to the left, wrapping the LSB back to the MSB.
module top_module(
    input [3:0] D,
    input LD,
    input SR,
    input SL,
    output reg [3:0] Q
);
