Design a packet filtering module that checks incoming packets against a set of predefined rules to determine if they should be allowed or blocked. The input to the module is a 16-bit packet and the output is a single bit indicating whether the packet is allowed (1) or blocked (0). The filtering rules are as follows: 
1. Block packets with the source address 0xAAAA.
2. Allow packets with the destination address 0x1234.
3. Block packets with the protocol type 0x01 (e.g., ICMP).
4. Allow all other packets.

The input packet format is: 
- Bits 15-0: Packet data (assume that the first 4 bits represent source address, next 4 bits represent destination address, and the last 8 bits represent protocol type).
