
Create a 5-stage pipelined processor that can execute a simple instruction set. The instructions are ADD, SUB, AND, and OR. Each instruction takes one clock cycle in each of the stages: Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). The processor should handle two instructions simultaneously in the pipeline and be able to detect hazards (data hazards) and stall the pipeline when necessary.
