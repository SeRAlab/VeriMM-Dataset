Create a GPIO controller that allows setting and getting the state of 8 GPIO pins. The controller should have the following functionality:  
1. A register to hold the state of the GPIO pins (8 bits).  
2. An input signal to set the state of the pins (8 bits).  
3. An output signal to read the current state of the pins (8 bits).  
4. A clock input to synchronize state changes.  
5. An enable signal that allows the setting of the GPIO pins when high (1). If the enable signal is low (0), the state should not change.  
6. The output should reflect the current state of the GPIO pins. Implement necessary reset functionality to clear the GPIO state.
