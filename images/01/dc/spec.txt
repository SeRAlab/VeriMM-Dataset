Design a Verilog module that performs LU decomposition on a 2x2 matrix. The LU decomposition should factorize a matrix A into a lower triangular matrix L and an upper triangular matrix U such that A = LU. The inputs to the module will be the elements of the matrix A, and the outputs will be the elements of the matrices L and U. The operation should be clocked and should process the input data in a single cycle.
