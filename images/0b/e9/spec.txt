
Design an SPI master controller that can send data to an SPI slave. The controller should include a state machine to handle the different phases of the SPI communication (idle, transmit, and receive). The master should have control signals like clk, cs (chip select), mosi (master out slave in), and miso (master in slave out) to communicate with the slave. The data to be transmitted should be provided as input and the received data should be output.
