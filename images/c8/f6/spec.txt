
You are tasked with creating a Verilog module that generates a constant output value. The module should have four inputs: `clk` (a clock signal), `ce` (an active-high clock enable signal), `clr` (an active-high clear signal), and `op` (an 8-bit output signal). The output signal should always be set to the constant value `00000001` (binary) when the module is enabled (i.e., `ce` is high) and not cleared (i.e., `clr` is low).

Write a Verilog module that meets the above specifications. Your module should be self-contained and not rely on any other modules.
