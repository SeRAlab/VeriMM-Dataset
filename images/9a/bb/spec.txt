Design a 4-bit Gray code counter with enable functionality. Upon receiving a positive edge on the EN input, the counter resets all internal registers to zero. If EN is low, the counter increments its value and generates the corresponding Gray code outputs (Q0 to Q3) based on the XOR operation of two pipelined registers. This module effectively produces a sequence of Gray code values, ensuring that only one bit changes at a time with each increment, suitable for applications requiring minimal error during state transitions.
module top_module(
    input EN,
    output reg Q0,
    output reg Q1,
    output reg Q2,
    output reg Q3
);
