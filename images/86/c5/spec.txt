Design a key press detection module that generates an interrupt signal (IRQ) upon detecting a key press change. The module compares the inverted input key (an 8-bit value) with a stored state. On each positive clock edge, if the reset signal is asserted, the module resets the stored state and IRQ signal to zero. If the stored data does not match the inverted key input, it updates the stored data with the inverted key and asserts the IRQ signal. Additionally, the stored key state is combined with leading zeros to form a 32-bit output (Key_RD) for external recognition, effectively capturing the latest key press event.
