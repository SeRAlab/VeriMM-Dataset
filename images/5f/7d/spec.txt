Design a right shift register that takes a 32-bit input data and shifts it right by one bit on each positive edge of a clock signal. The shifting operation occurs only when the Enable signal is asserted; otherwise, the output retains the original data. The clock signal is simulated with a newClock that toggles every 125 time units.
module top_module(
    input wire Clock,
    input wire [31:0] Data,
    input wire Enable,
    output reg [31:0] Shifted_Data
);
