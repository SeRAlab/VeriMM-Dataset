Design a 4-bit barrel shifter capable of shifting the input value either left or right based on the direction control signal. The shift amount is determined by a 2-bit input, allowing for shifts of 0 to 3 positions. When dir=0, the module performs a left shift operation on the input; when dir=1, it performs a right shift, with the result outputted through the output port.
module top_module(
    input [3:0] in,
    input [1:0] shift_amt,
    input dir,
    output reg [3:0] out
);
