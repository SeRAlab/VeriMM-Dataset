Design a 2x2 matrix inversion module that takes a 2x2 matrix as input and produces the inverted matrix as output. The matrix is expressed as four separate inputs: a, b, c, d, representing the matrix [[a, b], [c, d]]. The output should also be represented as four separate outputs: a_inv, b_inv, c_inv, d_inv, representing the inverted matrix [[a_inv, b_inv], [c_inv, d_inv]]. The inversion formula for a 2x2 matrix [[a, b], [c, d]] is given by 1/(ad-bc) * [[d, -b], [-c, a]]. If the determinant (ad - bc) is zero, the inversion should yield a fixed output indicating no inversion is possible.
