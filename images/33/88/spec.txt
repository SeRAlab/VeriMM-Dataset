Implement a 2nd-order IIR filter with the following difference equation:
y[n] = (b0 * x[n] + b1 * x[n-1] + b2 * x[n-2] - a1 * y[n-1] - a2 * y[n-2])
where x is the input signal, y is the output signal, and b0, b1, b2, a1, a2 are filter coefficients. The filter should be able to handle signed 16-bit input and output.
