
Design a simple Automatic Repeat reQuest (ARQ) error correction system in Verilog. The ARQ system will have the following features:
1. A sender module that transmits data and waits for an acknowledgment (ACK) from the receiver.
2. A receiver module that checks the received data for errors and sends back an ACK or NACK (Negative Acknowledgment) based on the validity of the data.
3. The system should be able to retry sending the data if a NACK is received.
4. Implement a simple parity check for the error detection.
5. The sender should have a maximum of 3 retries before giving up.

The sender and receiver should communicate through a simple handshake mechanism.
