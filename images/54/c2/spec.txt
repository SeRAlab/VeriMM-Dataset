Design a synchronous Random Access Memory (RAM) module with a parameterized address size and data width. The module features a write enable signal to control data storage: when write_enable is asserted, it stores write_data at the specified address. Regardless of the write operation, it continuously outputs the data from the specified address, thereby facilitating simultaneous read and write operations. The RAM has a defined number of memory locations and each location can hold a certain number of bits, making it suitable for flexible memory storage in digital systems.
module top_module(
  input [n-1:0] address,
  input [k-1:0] write_data,
  input write_enable,
  output reg [k-1:0] read_data
);
