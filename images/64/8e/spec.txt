Design a synchronous calculator module that performs basic arithmetic operations (addition, subtraction, multiplication, and division) on two 8-bit inputs (A and B). The operation is selected by a 3-bit operation code (op) provided as an input. Upon the rising edge of the clock, the result is computed based on the selected operation; if the reset signal is activated, the output is set to zero. The module functions as a simple arithmetic logic unit (ALU), enabling the execution of specified mathematical calculations under synchronous control.
module top_module(
    input wire clk,
    input wire reset,
    input wire [7:0] A,
    input wire [7:0] B,
    input wire [2:0] op,
    output reg [7:0] result
);
