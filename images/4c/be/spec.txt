Design a circuit that computes the even parity of an 8-bit input word. The module takes an 8-bit input `data_in` and produces a single-bit output `parity_out`. On each rising edge of the clock (`clk`), if the `reset` signal is active, the output is reset to LOW; otherwise, the output is updated to indicate the parity of the input data, specifically generating a HIGH output if the number of 1s in `data_in` is odd, and LOW if it is even.
module top_module(
  input clk,
  input reset,
  input [7:0] data_in,
  output reg parity_out
);
