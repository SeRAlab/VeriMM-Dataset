
Design a 128-bit AES encryption module that takes a 128-bit plaintext and a 128-bit key as inputs and produces a 128-bit ciphertext as output. The module should have the following inputs and outputs:
- Inputs: 
  - clk (clock signal)
  - rst (reset signal, active high)
  - plaintext (128-bit input data)
  - key (128-bit encryption key)
- Outputs:
  - ciphertext (128-bit output data)
The module should implement the key expansion and the series of transformations described in the AES specification including SubBytes, ShiftRows, MixColumns, and AddRoundKey.
