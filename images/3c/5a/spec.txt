
Create a 1-bit DRAM cell that can store a single bit of data. The cell should have an input data line (D), a write enable signal (WE), and a read output line (Q). When WE is high, the data on the D line should be written to the cell. When WE is low, the value stored in the cell should be presented on the Q line. The cell should retain its value until it is overwritten.
