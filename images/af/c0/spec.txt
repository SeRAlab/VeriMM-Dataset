Design a synchronous dual-port SRAM (Static Random Access Memory) module that allows two independent sets of read and write operations. It features separate data inputs, address inputs, write enable signals, and read enable signals for each port. The module supports a memory depth of 256 words with each word being 36 bits wide, facilitating the storage and retrieval of data on the rising edge of the clock signal. When a write enable signal is asserted for a specific address, the corresponding data input is stored in the memory. Conversely, when a read enable signal is asserted for an address, the data stored at that address is output.
