Design a 16-bit DRAM cell with the following functionality: it should support read and write operations. The DRAM cell should have a data input, a data output, a read enable signal, a write enable signal, and a clock signal. The data output should reflect the data stored in the cell when the read enable signal is asserted, and it should store the incoming data when the write enable signal is asserted. The DRAM cell can be implemented as a simple register that is updated on the clock edge.
