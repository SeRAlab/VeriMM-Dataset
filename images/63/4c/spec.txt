Design a 4-bit ripple carry adder that computes the sum of two 4-bit inputs, `a` and `b`, along with an input carry `cin`. The output consists of a 4-bit sum `s` and a carry-out signal `cout`. The design utilizes four instances of a full adder, cascading the carry output from each adder to the next, enabling the accumulation of carry bits across the addition process.
module top_module(
    input a,
    input b,
    input cin,
    output s,
    output cout
);
