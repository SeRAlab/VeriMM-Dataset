Design a four-bit calculator module capable of performing addition and subtraction operations. The module takes two four-bit inputs, `a` and `b`, and a control signal `addSub`. When `addSub` is high, it computes the sum of `a` and `b`; when `addSub` is low, it calculates the difference between `a` and `b`. The result is provided as a four-bit output.
module top_module(input [3:0] a, input [3:0] b, input addSub, output reg [3:0] result);
