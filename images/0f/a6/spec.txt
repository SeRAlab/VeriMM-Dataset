Design a Parallel-in Serial-out (PISO) shift register that accepts a 5-bit parallel input and shifts out the bits serially on a clock signal. The register should have a parallel load enable signal (load), a clock signal (clk), and a reset signal (rst). When load is high, the input should be loaded into the register. Otherwise, on each clock cycle, the output should be the least significant bit of the register, and the contents of the register should shift right. The register should reset to 0 when rst is high.
