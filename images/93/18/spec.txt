Design a simple FIFO (First-In, First-Out) buffer module that holds one-bit wide data elements. The module has an output flag (AS) indicating when the buffer is full, an output (out) that reflects the current data at the head of the buffer, and an input (in0) that receives new data. On each rising edge of the write clock (wr_clk), if the buffer is not full, it will accept the new data; otherwise, it retains the existing data. The buffer can hold two states, controlling the flow of data through the use of combinational logic to check for fullness and update the buffer accordingly.
