

You have been tasked with designing a module for a digital circuit that will take in three inputs and produce two outputs. The module should be named "my_module" and should be written in Verilog. The inputs are named "in1", "in2", and "in3", and the outputs are named "out1" and "out2". The following constraints apply:

1. The module should only be 200 lines or fewer.
2. The output "out1" should be the result of an XOR gate between "in1" and "in2".
3. The output "out2" should be the result of an AND gate between "in2" and "in3".
4. The design should be synchronous, and the output should only be updated on the rising edge of the clock signal.
5. The module should have a reset input named "reset", which, when asserted, should set both outputs to zero.

Write the "my_module" module that satisfies the above constraints.
