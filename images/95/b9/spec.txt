Design a circuit that generates a parity bit and detects errors for n input signals. The parity output, `par`, is computed as the XOR of all input bits, providing an even or odd parity indication. The error output, `err`, is set to high when there is a discrepancy between the computed parity and the parity of the input bits, thereby signaling a parity error in the data. The circuit supports a configurable input width defined by the parameter n, which is set to 4 by default.
module top_module(
  input [n-1:0] in,
  output par,
  output err
);
