Design a 2-bit counter that counts up by 1 on each clock cycle while enabled. The counter resets to zero when the reset signal is high or when it reaches a count of three, at which point it also outputs a HIGH signal (true) indicating that the count is equal to three. When enabled and not at three, it increments; otherwise, it remains at zero.
module top_module(
	input wire clk,
	input wire reset,
	input wire enable,
	output wire out
);
