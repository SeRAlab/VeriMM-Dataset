Design a 4-bit barrel shifter that can perform various shifting and rotating operations on 4-bit input data. The module accepts control signals for left and right shifting, as well as for left and right rotating. Depending on the control signals provided, the output will either be the data shifted or rotated accordingly. If no valid operation is selected, the output will retain the original input data.
module top_module(
    input [3:0] data,
    input [1:0] shift,
    input shift_right,
    input shift_left,
    input rotate_right,
    input rotate_left,
    output reg [3:0] result
);
