Design a gated D flip-flop with synchronous and asynchronous reset capabilities. The module takes a data input (D) and clock signal (CLK), along with an active-low reset signal (nSR), to control the output (Q). Upon a positive clock edge, if the reset is not asserted (nSR high), the flip-flop loads the value of D into Q. If the reset is asserted (nSR low), Q is set to a specified mode value (SRMODE), which can be configured via a parameter. The initial state of Q can also be defined using the INIT parameter.
