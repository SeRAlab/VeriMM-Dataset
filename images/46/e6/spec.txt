Design a shift register module that can perform various shifting operations based on the input signal. This module includes four types of shift registers: a serial shift register that can shift data left or right based on the shift control input; a parallel shift register that loads input data on a shift signal; a left shift register that consistently shifts bits to the left; and a right shift register that consistently shifts bits to the right. The output is determined by the configuration being utilized at any given time. The module is parameterized for flexibility in the number of output bits.
module top_module(
  input [n-1:0] in,
  input shift,
  output reg [m-1:0] out
);
