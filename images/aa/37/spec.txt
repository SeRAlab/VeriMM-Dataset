Design a clocked D flip-flop with an asynchronous reset feature. On each rising edge of the clock, if the reset signal is high, the stored data is set to LOW; otherwise, the flip-flop captures the value of the input data signal. The output reflects the currently stored data, providing a robust mechanism for synchronous data storage in digital circuits.
