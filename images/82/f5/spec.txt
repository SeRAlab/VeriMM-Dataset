Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs: 
1. state T (output 1).
2. state U (output 0).
3. state V (output 1).

State transitions:
1. From state T: If q = 0, then transition to state U. If q = 1, then transition to state V.
2. From state U: If q = 0, then transition to state T. If q = 1, then transition to state V.
3. From state V: If q = 0, then transition to state U. If q = 1, then transition to state T.

Resets into state T. For this part, assume that a one-hot code is used with the state assignment k[3:1] = 001, 010, 100 for states T, U, V, respectively.

Write Verilog for the next-state signals K2 and K3 corresponding to signal k[2] and k[3]. Derive the logic equations by inspection assuming a one-hot encoding.
