Create a simple 2-input Support Vector Machine (SVM) classifier that outputs 1 if the inputs correspond to a positive class and 0 otherwise. The logic should be defined by weights and a bias term. Use weights w1 = 1, w2 = -1 and bias b = 0. The decision rule is: if (w1 * x1 + w2 * x2 + b) > 0, output 1; otherwise, output 0.
