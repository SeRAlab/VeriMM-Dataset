Implement the Verilog module based on the following description. Create a finite state machine that controls traffic lights at a four-way intersection. There are four states: Green North-South, Yellow North-South, Green East-West, and Yellow East-West. The traffic light changes states in the following sequence: Green North-South -> Yellow North-South -> Green East-West -> Yellow East-West. Use an asynchronous reset to set the initial state to Green North-South.
