Implement a Verilog module based on the following description.
Design a 4-bit binary up-counter with carry out and synchronous reset. The counter should reset to 0 on the rising edge of the clock if the reset signal is high. If reset is low, the counter should increment by 1. The carry_out signal should be high if the counter overflows.
module binary_counter(
    input clk,
    input reset,
    output reg [3:0] count,
    output reg carry_out);
