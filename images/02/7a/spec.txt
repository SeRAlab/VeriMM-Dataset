Design a 4-bit DRAM cell that can store a 4-bit value and has input and output control signals for reading and writing. The cell should have the following inputs: `data_in` (4 bits), `write_enable` (1 bit), and `read_enable` (1 bit). When `write_enable` is high, the `data_in` value should be written to the memory. When `read_enable` is high, the stored value should be output on `data_out` (4 bits). The cell should retain its state until it is overwritten.
