Design a Verilog module that detects hazards in a given combinational logic circuit based on the input signals. The module should take three input signals, A, B, and C, and output a signal 'hazard' indicating whether a hazard is detected or not. A hazard is detected when there are two or more changes on the input signals that could cause a glitch in the output. The output should be high (1) if a hazard is detected, and low (0) otherwise.
