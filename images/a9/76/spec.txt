Design a D Flip-Flop with scan capability. The module captures a data input (din) on the rising edge of the clock (clk) when the enable signal (en) is active. It includes a scan mode controlled by the scan-enable signal (se), allowing for testability; in this mode, the flip-flop captures the scan input (si) instead of the regular data input. The output (q) holds the captured value, and a scan output (so) reflects the current state of q. When not in scan mode and the enable is inactive, the flip-flop retains its previous output value. This configuration is useful for integrating testing functionalities into synchronous digital designs.
