Design a 4-bit adder that computes the sum of two 4-bit inputs, `a` and `b`, when the control signal `ctrl` is high. If `ctrl` is low, the output remains undefined. The result of the addition is output as a 4-bit signal `sum`.
module top_module(
  input [3:0] a,
  input [3:0] b,
  input ctrl,
  output [3:0] sum
);
