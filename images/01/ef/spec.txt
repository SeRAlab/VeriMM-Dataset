
Design a fan speed control system that adjusts the fan speed based on the temperature input. The system should have the following states:
- State 0: Fan off (Temperature < 20°C)
- State 1: Low speed (20°C ≤ Temperature < 30°C)
- State 2: Medium speed (30°C ≤ Temperature < 40°C)
- State 3: High speed (Temperature ≥ 40°C)

The fan speed should change on the rising edge of a clock signal.
