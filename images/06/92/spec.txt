
Design a Direct Memory Access (DMA) controller in Verilog that can transfer data between memory and an I/O device. The DMA controller should include the following features:
1. A request signal (req) to initiate the transfer from an I/O device.
2. An acknowledge signal (ack) from the DMA controller to indicate readiness to transfer.
3. A data bus (data) to transfer the actual data.
4. Address bus (addr) to specify the memory location.
5. A counter to keep track of the number of data bytes transferred.
The controller should operate in a way that it responds to the request and performs data transfers for a specified number of bytes.
