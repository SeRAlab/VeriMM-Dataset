Design a circuit that counts the number of zero bits in a 128-bit input vector. The module continuously monitors the input `data`, and upon any change, it traverses all 128 bits to increment a counter (`count`) each time it encounters a zero. The result is an 8-bit output that represents the total count of zero bits within the input data.
module top_module(
  input [127:0] data,
  output reg [7:0] count
);
