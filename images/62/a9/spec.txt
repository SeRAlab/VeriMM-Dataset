Design a signal delay circuit that introduces a programmable delay based on a specified wait count. The module takes a clock signal and an input signal (sigIn), along with a wait count value. When the input signal changes, the circuit starts a timer that counts clock cycles until it reaches the specified wait count. After the countdown, the module outputs the value of sigIn as sigOut, effectively delaying the input signal's transition by the defined number of clock cycles.
