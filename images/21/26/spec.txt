Design a Verilog module that implements a simplified version of the PNG filtering process. The filter will take an 8-bit pixel value as input and apply the Sub filter, which computes the difference between the current pixel and the pixel to the left. If there is no pixel to the left (i.e., the first pixel in a row), the output should simply be the input pixel value. The module should have an input for the current pixel and the previous pixel, and it should output the filtered pixel value.
