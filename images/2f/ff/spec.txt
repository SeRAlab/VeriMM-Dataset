Design a 1-bit SRAM cell that can store a single bit of data. The SRAM cell should have two inputs: `D` (data input) and `WE` (write enable), and one output `Q` (data output). When `WE` is high, the value of `D` should be written to the cell. When `WE` is low, the cell should retain its value and output it on `Q`. Implement this using Verilog.
