Design a circuit that computes the logical AND between the output of a 2-input OR gate (formed from inputs A1 and A2) and a third input B1. This result is then buffered and gated with a power input (VPWR) to produce the output X. If VPWR is LOW, X will also be LOW, regardless of the other inputs. The module effectively combines elements of combinational logic with power management, ensuring output X is only valid when the VPWR signal is active.
module top_module(
    input A1,
    input A2,
    input B1,
    input VPWR,
    output X
);
