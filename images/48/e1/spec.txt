Design a 32-bit register that can hold a value and is synchronized to a clock signal. When the `clr` input is activated, it asynchronously resets the output `Rout` to zero. On the rising edge of the clock, if `write_enable` is asserted, the register updates its output with the provided `write_value`. If `write_enable` is not active, the current value of `Rout` is retained.
