

You are tasked with designing a module that takes in eight inputs and produces one output. The module should be named `multifunc` and should be written in Verilog. The eight inputs are as follows:

- `a`: 1-bit input
- `b`: 1-bit input
- `c`: 1-bit input
- `d`: 1-bit input
- `e`: 1-bit input
- `f`: 1-bit input
- `g`: 1-bit input
- `h`: 1-bit input

The output of the module, `out`, should be a 1-bit value that is determined by the following rules:

- If `a` is 1, `out` should be the logical AND of `b` and `c`.
- If `a` is 0, `out` should be the logical OR of `d`, `e`, `f`, `g`, and `h`.

Write the Verilog code for the `multifunc` module that satisfies the above requirements.
