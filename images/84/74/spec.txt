Design a 4-to-1 multiplexer that selects one of four 8-bit input data lines (D0, D1, D2, D3) based on a 2-bit select signal (SEL). The output (Y) will correspond to the input line indicated by the select signal, with D0 being chosen when SEL is 00, D1 for 01, D2 for 10, and D3 for 11. If none of the specified selections is made, the output defaults to zero.
module top_module(
  input [7:0] D0,
  input [7:0] D1,
  input [7:0] D2,
  input [7:0] D3,
  input [1:0] SEL,
  output [7:0] Y
);
