Design a module for instruction fetch in a pipelined processor. It manages the program counter (PC) to determine the address of the next instruction to fetch based on various control signals, including reset, branch conditions, and stalls. The module can initialize the PC to zero, update it sequentially, or set it to a specified branch address if a branch is taken. Additionally, the module has a halt condition that triggers when a specific instruction is encountered, preventing further instruction fetches under certain circumstances. The outputs include the next program counter value, the current program counter, and status indicators for halting and branching initiation.
