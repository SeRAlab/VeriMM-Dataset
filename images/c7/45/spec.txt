

You are tasked with designing a Verilog module to implement a 2-input AND gate. The module should have the following inputs and outputs:

Inputs:
- A (1-bit)
- B (1-bit)

Outputs:
- Y (1-bit)

Your module should be named `and_gate` and should use the following template:

```
module and_gate (
    input A,
    input B,
    output Y
);

// your code here

endmodule
```

Ensure that your module declaration includes the correct number of inputs and outputs, and that the input and output names match those provided above.
