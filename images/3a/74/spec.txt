Design a 1-bit DRAM cell that can be written to and read from. The DRAM cell should have a data input (D), data output (Q), a write enable signal (WE), and a clock signal (CLK). When WE is high, the value at D should be stored in the DRAM cell at the rising edge of CLK. When WE is low, the value stored in the DRAM cell should appear at Q.
