

You are tasked with designing a verilog module that implements a 4-bit D flip-flop with reset functionality. The module should have the following inputs and outputs:

- `CLK`: a clock input
- `D`: a 4-bit data input
- `RST`: a reset input
- `Q`: a 4-bit output representing the state of the flip-flop

The module should behave as follows:
- On the rising edge of the clock, the current value of `D` should be stored in `Q`.
- If `RST` is asserted (logic 1), all bits of `Q` should be reset to 0.

Write the verilog code for this module.
