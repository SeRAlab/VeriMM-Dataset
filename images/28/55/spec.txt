Design a 16-bit ADC output processor that takes a 16-bit input representing the ADC value and outputs a 4-bit binary value representing the range of the input value. The output should be as follows: if the ADC value is between 0-1023, output 0; if between 1024-2047, output 1; if between 2048-3071, output 2; if between 3072-4095, output 3; and for values above 4095, output 15 (indicating an error condition).
