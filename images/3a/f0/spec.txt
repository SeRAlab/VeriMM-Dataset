Design a 16-bit ALU that takes two 16-bit inputs (A and B) and a 4-bit control signal (ALUop) to perform the following operations:
- ALUop = 0000: A + B (Addition)
- ALUop = 0001: A - B (Subtraction)
- ALUop = 0010: A & B (Bitwise AND)
- ALUop = 0011: A | B (Bitwise OR)
- ALUop = 0100: A ^ B (Bitwise XOR)
- ALUop = 0101: A << 1 (Logical left shift)
- ALUop = 0110: A >> 1 (Logical right shift)
- ALUop = 0111: A < B (Set on less than, output 1 if A < B, else 0)
The output should be a 16-bit result and a 1-bit zero flag that indicates if the result is zero.
