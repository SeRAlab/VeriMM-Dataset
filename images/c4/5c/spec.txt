
You are tasked to design a verilog module for a 4:1 multiplexer with enable. The module should have 4 input ports, 1 output port, and an enable signal. The output should be equal to the input that is selected by the 2-bit select signal. If the enable signal is low, the output should be zero. Please use the following module template as a starting point:

```
module mux4(enable, select, in0, in1, in2, in3, out);
    input enable;
    input [1:0] select;
    input in0, in1, in2, in3;
    output out;
    
    // Your code here
    
endmodule
```
