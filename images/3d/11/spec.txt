Design a 24-bit DAC (Digital-to-Analog Converter) that takes a 24-bit input and outputs a corresponding 8-bit value based on a specified scaling factor. The scaling factor will be a 4-bit input representing the fraction of the maximum analog value. The output should be a scaled value of the 24-bit input, limited to 8 bits. If the scaled value exceeds 255 (the maximum for an 8-bit value), it should be clamped to 255.
