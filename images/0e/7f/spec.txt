Design a 16-bit shift register with synchronous loading capability. The shift register should be able to shift left or right based on a control signal. If a load signal is high, the register should load a new 16-bit value present on the input bus. The shift direction should be controlled by a single bit signal: if the signal is high, the register shifts left; if low, it shifts right. The register should also have a clock and reset signal. The output of the register should be available on a separate output bus.
