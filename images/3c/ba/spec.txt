Design a 16-bit shift register with parallel load functionality. The shift register should support shifting left or right based on a control signal. It should have a clock input, a reset input, a load input, an input data line for parallel loading, and an output data line to reflect the current state of the shift register. When the load signal is high, the data should be loaded in parallel. When the load signal is low, on the rising edge of the clock, the data should shift left or right based on a direction control signal.
