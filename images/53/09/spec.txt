Design a D flip-flop with asynchronous reset and set inputs. The module captures the value of input D on the rising edge of the CLK signal. It features two control signals, SCD and SCE, for asynchronous clear and set functionality, respectively, while SET_B is an active-low set signal. When SCD is asserted low, the output Q is reset to 0; when SCE is asserted low or SET_B is asserted low, Q is set to 1. If neither control signal is active, Q retains its value based on the input D. This circuit allows for flexible control over the stored data and state reset operations.
