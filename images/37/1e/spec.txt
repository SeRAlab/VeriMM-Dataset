Design a Parallel-in Parallel-out (PIPO) shift register in Verilog. The shift register should have the following features:
- It should have a width of N bits.
- It should have a parallel load input, a clock input, and a reset input.
- On the rising edge of the clock, if the load signal is high, the data should be loaded into the register.
- If the load signal is low, the data should shift out of the register one bit at a time.
- The output should reflect the current state of the register.
