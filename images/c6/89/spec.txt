

You are tasked with designing a module in Verilog that implements a 4-bit synchronous counter. The counter should have three inputs: a clock signal (`CLK`), a reset signal (`RST`), and an enable signal (`EN`). When `EN` is high, the counter should increment on every rising edge of `CLK`. When `RST` is high, the counter should reset to 0. The counter should output a 4-bit value (`Q`) representing the current count.

Your module should be named `sync_counter` and should be designed such that it can be easily integrated into larger Verilog designs. Your implementation should be contained within 200 lines of code.
