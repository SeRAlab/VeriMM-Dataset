Design a fan speed control system that adjusts the fan speed based on temperature input. The fan has three speed settings: low, medium, and high. The temperature inputs are in degrees Celsius, and the fan speed settings are as follows:  
- If temperature < 20, set speed to low (00)  
- If 20 <= temperature < 25, set speed to medium (01)  
- If temperature >= 25, set speed to high (10)  
The current state of the fan should be stored, and the system should update the fan speed on every clock cycle based on the current temperature input.
