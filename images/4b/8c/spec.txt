Implement an 8-to-1 multiplexer with a 3-bit select input. The multiplexer should output one of the eight 16-bit input data signals based on the value of the select input.

Module name:
    mux_8to1

Input ports:
	sel: 3-bit select input.
	in0: 16-bit input data 0.
	in1: 16-bit input data 1.
	in2: 16-bit input data 2.
	in3: 16-bit input data 3.
	in4: 16-bit input data 4.
	in5: 16-bit input data 5.
	in6: 16-bit input data 6.
	in7: 16-bit input data 7.

Output ports:
	out: 16-bit output data based on the select input.
