Implement a circuit that processes a 4-bit input signal. The output is a 4-bit signal where the most significant bit (MSB) is set to 0 if the least significant bit (LSB) of the input is 0, otherwise, it is set to 1. The remaining three bits of the output replicate the three most significant bits of the input. This design functions as a conditional bit manipulator that modifies the MSB based on the LSB of the input.
module top_module(
    input [3:0] in,
    output reg [3:0] out
);
