Design a 2-to-1 multiplexer with 2-bit wide data inputs. The mux selects between the two inputs, D0 and D1, based on the value of the select signal S; when S is 0, the output Q is equal to D0, and when S is 1, the output Q reflects D1.
module top_module(input wire [1:0] D0, D1,
    input wire S,
    output wire [1:0] Q);
