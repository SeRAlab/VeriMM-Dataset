Design a 2-to-4 line decoder with enable and reset functionalities. The module takes a 2-bit binary input (in_data) and, based on its value, drives one of the four output lines (out_data) high when the enable signal is asserted. If the reset signal is low, all outputs are driven low regardless of the input. This circuit can be used in applications requiring signal selection or routing in digital systems.
module top_module(
  input wire [1:0] in_data,
  input wire enable,
  input wire reset,
  output reg [3:0] out_data
);
