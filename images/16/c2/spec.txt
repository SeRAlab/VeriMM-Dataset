
Design a 4-input priority arbiter. The arbiter should output a grant signal to the highest priority input that requests access. The priority order is assigned as follows:
- Input 0 has the highest priority
- Input 1 has the second highest priority
- Input 2 has the third highest priority
- Input 3 has the lowest priority

The request signals are 4 bits wide (req[3:0]) and the grant signal should indicate which input has been granted access (grant[3:0]), where only one bit in the grant signal should be high at any time.
