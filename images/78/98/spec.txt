Design a digital circuit that functions as a display controller. It utilizes a 4-to-1 decoder to select one of four 7-segment displays based on a 2-bit counter generated by a clock signal, cycling through the displays on each clock pulse. The `anodo` output selects which display to activate by controlling the anode lines, while the `catodo` output drives the content of the selected display using 8-bit inputs. The module features asynchronous reset functionality to initialize the counter.
module top_module(
   
	input wire clk,rst,
	input [7:0] in3,in2,in1,in0,
	output reg [3:0] anodo,
	output reg [7:0] catodo
    );
