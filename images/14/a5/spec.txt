
Design a Verilog module for a simplified Flash memory cell. The module should have inputs for a control signal (`control`), a data input (`data_in`), and a clock signal (`clk`). The module should store the value of `data_in` when `control` is high on the rising edge of the clock. When `control` is low, the output (`data_out`) should retain its previous value. The module should also include a reset signal (`reset`) that initializes the `data_out` to a default value of 0 when activated.
