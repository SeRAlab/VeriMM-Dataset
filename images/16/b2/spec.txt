Design a Verilog module for a SR-latch using two D flip-flops. The SR-latch should have two inputs, S (Set) and R (Reset), and two outputs, Q and Qn (not Q). Implement the functionality such that when S is high, Q is set to high and when R is high, Q is set to low. If both S and R are low, the latch should maintain its previous state. If both S and R are high, the output is considered to be in an invalid state.
