Design a Verilog module for a 12-bit binary counter with both synchronous reset and enable signals. The counter increments its value on the rising edge of the clock when the enable signal is active and resets to 0 when the reset signal is active.

Module name:  
    counter_12bit  

Input ports:
    clk: Chip clock signal.
    rst: Synchronous reset signal.
    en: Enable signal.

Output ports:
    count: Counter output signal with a data width of 12 bits.

Implementation:
Counter operation:
On every positive edge of the clock signal (clk), the counter (count) is reset if the reset signal (rst) is active. Otherwise, it increments its value if the enable signal (en) is active. If both reset and enable signals are inactive, the counter retains its current value.
