Design a 4-to-1 multiplexer that selects one of four 1-bit inputs (A, B, C, D) based on a 2-bit select input (S). When S is 00, the output Y equals A; when S is 01, Y equals B; when S is 10, Y equals C; and when S is 11, Y equals D. The output is implemented as a registered signal that reflects the selected input according to the value of S.
module top_module(
    input [3:0] A, B, C, D,
    input [1:0] S,
    output reg Y
);
