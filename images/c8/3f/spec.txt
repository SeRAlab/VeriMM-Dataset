

You have been tasked with designing a module for a digital circuit that performs the exclusive-or (XOR) operation. The module should have two input pins, A and B, and one output pin, Y. The XOR operation should be performed on the two input pins such that if A and B are the same, the output should be 0, otherwise the output should be 1.

Design a Verilog module that implements the XOR operation. The module should be named "xor_gate" and should follow the template below:

```
module xor_gate(
    input A,
    input B,
    output Y
);

// your code here

endmodule
```
