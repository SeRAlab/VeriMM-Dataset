Design a simple Direct Memory Access (DMA) controller that transfers data from a source address to a destination address based on a control signal. The DMA controller should have the following inputs: `clk` (clock), `reset` (active high reset), `start` (control signal to initiate data transfer), `src_addr` (source address), `dst_addr` (destination address), and `data_in` (data to be transferred). It should output `data_out` (data transferred) and `done` (indicates transfer completion).
