Implement the Verilog module based on the following description.
Create a 2-bit Gray code counter with synchronous reset and enable.
(1) reset: Resets the counter to the initial state.
(2) enable: Enables the counter to advance to the next Gray code.
(3) q: The contents of the counter in Gray code.

module top_module(
    input clk,
    input reset,
    input enable,
    output reg [1:0] q);
