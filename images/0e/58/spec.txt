
Create a clock-gated D flip-flop that only updates its output when the clock enable signal is high. The flip-flop should have a data input (D), a clock input (clk), a clock enable input (clk_en), and an output (Q). When clk_en is low, the output Q should hold its previous value. When clk_en is high, Q should be updated to the value of D on the rising edge of clk.
