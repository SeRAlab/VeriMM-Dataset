Design a 16-bit DRAM cell with read and write functionality. The DRAM cell should consist of an array of 16 cells. Each cell can be written to and read from based on control signals. Implement the following interfaces: a write signal (`wr`), a read signal (`rd`), a 16-bit data input (`data_in`), a 16-bit data output (`data_out`), and a 4-bit address input (`addr`). The output should reflect the data stored in the cell specified by the address when reading, and the data should be written to the specified address when writing.
