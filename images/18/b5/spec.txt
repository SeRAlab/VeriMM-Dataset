
Design a temperature sensor controller that takes a 5-bit binary input representing the temperature in degrees Celsius (0 to 31 degrees). The output should be a 1-bit signal indicating whether the temperature is too high (1) or within acceptable limits (0). Assume that the acceptable temperature range is from 0 to 25 degrees Celsius. This controller should also handle edge cases where the input exceeds the range (e.g., negative values should be treated as 0).
