If multiple inputs are active, the encoder will prioritize the highest significant bit. The outputs will indicate the position of that active input: "00" for input 0, "01" for input 1, "10" for input 2, and "11" for input 3. If no inputs are active or if multiple lower priority inputs are active, the output defaults to "00".
