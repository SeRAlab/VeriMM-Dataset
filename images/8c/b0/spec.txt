Create a Verilog module that implements a 4-bit synchronous binary counter with enable and load capability. The module should have the following specifications:
- `clk`: The clock signal.
- `reset`: An active-high synchronous reset signal.
- `enable`: An active-high signal that enables the counter.
- `load`: An active-high signal that loads the data into the counter.
- `data_in`: The 4-bit input data to be loaded.
- `count`: The 4-bit output representing the current count.
