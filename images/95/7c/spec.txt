Implement a Verilog module for a 6-bit binary counter with a load and clear signal. When the load signal is high, the counter loads a given value. When the clear signal is high, the counter is cleared to 0. The reset input is active high synchronous and should reset the counter to 0.
module top_module(
    input clk,
    input reset,
    input load,
    input clear,
    input [5:0] load_value,
    output reg [5:0] q);
