Design a fan speed control system that adjusts the fan speed based on temperature readings. The fan has three speed settings: low, medium, and high. The temperature input will be a 4-bit binary number representing temperature in degrees Celsius. The fan speed is controlled based on the following conditions:
- If temperature < 20°C, set fan speed to low (00).
- If 20°C <= temperature < 30°C, set fan speed to medium (01).
- If temperature >= 30°C, set fan speed to high (10).
The system should have a clock input and a reset input. On the rising edge of the clock, the fan speed should be updated based on the temperature input. The reset input will initialize the fan speed to low.
