Write a Verilog module for a 4-bit synchronous counter with enable and load. The counter should count from 0 to 15 and then wrap around to 0. Assume positive clock/clk edge triggered. When enable is low, the counter holds its value. When load is high, the counter loads the input value.

module synchronous_counter (
  input clk,
  input enable,
  input load,
  input [3:0] value,
  output reg [3:0] count
);
