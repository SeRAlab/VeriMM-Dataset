Design a Verilog module that implements a 5-bit binary down-counter with a synchronous reset and enable signal. The counter should decrement on the rising edge of the clock if the enable (en) signal is high. The counter should reset to '11111' when the synchronous reset (sreset) is high. The counter value should be output to the "count" signal.

module down_counter_with_reset
(
    input clk,
    input en,
    input sreset,
    output reg [4:0] count
);
