Design a 16-bit DRAM cell that can read and write data. The DRAM cell should include a 16-bit data input (D), a 16-bit data output (Q), a write enable signal (WE), and an address signal (A) that selects which bit of the memory to write to or read from. When WE is high, the data at input D should be written to the specified address. When WE is low, the data at that address should be output to Q.
