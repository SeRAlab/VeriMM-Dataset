Design a simple state machine that simulates a robot's movement in a 2D grid for SLAM. The state machine has three states: IDLE, MOVE, and MAP. When in the IDLE state, the system waits for a start signal. Upon receiving the signal, it transitions to the MOVE state to update its position. After moving, it transitions to the MAP state to create a map of its surroundings. After mapping, it goes back to the IDLE state. The current position (x, y) will be updated based on the movement direction (up, down, left, right).
