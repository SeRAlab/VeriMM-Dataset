Design a LIFO stack in Verilog that supports push and pop operations. The stack should have a depth of 4. The push operation should add a value to the top of the stack, and the pop operation should remove the value from the top of the stack. The stack should also have an overflow condition when pushing to a full stack and an underflow condition when popping from an empty stack. Outputs should indicate the top value and status of overflow/underflow.
