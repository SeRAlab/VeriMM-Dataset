Design a Parallel-in Parallel-out (PIPO) shift register that can store an 8-bit input data. The shift register should have a clock input, a parallel load enable (PL) signal, and a reset signal. When the reset signal is high, the output should be cleared to 0. If the PL signal is high, the input data should be loaded into the register on the next clock edge. If PL is low, the output should retain its value until the next load or reset.
