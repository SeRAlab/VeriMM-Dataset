The adder implements full-adder logic for each bit, generating a carry output that propagates to the next higher bit. The first bit uses an XOR gate to calculate the sum and an AND gate to detect any carry. This logic is similarly applied for the second through fourth bits, with carry-forward handled through OR operations to aggregate carry outputs from the preceding bits.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output [3:0] S
);
