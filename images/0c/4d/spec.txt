Design a Bluetooth module state machine that transitions between three states: IDLE, SCAN, and CONNECT. The module should have an input signal 'start' to transition from IDLE to SCAN, and an input signal 'connect' to transition from SCAN to CONNECT. The state machine should return to IDLE from CONNECT after a specified time period determined by a clock signal. The outputs of the state machine are the current state represented as a 2-bit value.
