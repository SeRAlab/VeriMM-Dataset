Design a 4-to-1 multiplexer with an enable signal. The module takes four 1-bit inputs (A, B, C, D) and a 2-bit selector (SEL) to choose one of the inputs to output on Y based on the selected value. If the enable signal (EN) is high, the multiplexer's output will reflect the selected input; if EN is low, the output Y is set to LOW.
module top_module(
    input [3:0] A, B, C, D,
    input [1:0] SEL,
    input EN,
    output reg Y
);
