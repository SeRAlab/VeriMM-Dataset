Design a circuit that serves as a 3-bit shift register, which resets to zero upon the assertion of the 'probe' input. On the rising edge of 'source_clk', if 'probe' is high, the output 'source' is cleared to zero. If 'probe' is low, the current value of 'source' is shifted left by one bit, with a zero being introduced at the least significant bit (LSB) position.
module top_module(
    input probe,
    input source_clk,
    output reg [2:0] source
);
