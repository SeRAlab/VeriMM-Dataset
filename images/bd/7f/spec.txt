Design a distributed memory module that provides read and write capabilities. This module has a configurable depth of 1024 locations, each capable of storing 16-bit wide data. On the positive edge of the clock, it outputs the data stored at the address specified by `outAddr`. If the `writeSel` signal is asserted, it writes the input data `in` to the memory location indicated by `inAddr`. This module effectively serves as a synchronous read/write memory, allowing for dynamic data storage and retrieval during operation.
