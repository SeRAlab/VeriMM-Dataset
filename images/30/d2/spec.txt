Design a simple WiFi module state machine that operates in three states: IDLE, CONNECTING, and CONNECTED. The state machine should transition based on a start signal and a connection success signal. The state definitions are as follows: 
- IDLE: waiting for a start signal.
- CONNECTING: attempting to connect.
- CONNECTED: successfully connected.
The state machine should output the current state in binary (2 bits) whenever it transitions. There should be a clock and reset signal to control the operation.
