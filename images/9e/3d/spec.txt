Design a 4-to-1 multiplexer with an enable signal. The module selects one of the four 1-bit wide inputs based on the 2-bit select signal. If the enable signal is high, the selected input is passed to the 4-bit output; if enable is low, the output is set to zero regardless of the select value.
module top_module(
  input [3:0] data_in,
  input [1:0] select,
  input enable,
  output reg [3:0] data_out
);
