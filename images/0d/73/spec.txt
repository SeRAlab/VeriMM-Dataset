Design a fan speed controller that adjusts the fan speed based on the temperature readings. The fan has three speed settings: low, medium, and high. The system should have a clock input for synchronization and a reset signal. The temperature input is a 4-bit binary number where 0000 represents 0°C and 1111 represents 15°C. Based on the temperature, the fan speed is controlled as follows:
- 0°C to 5°C: Low speed (00)
- 6°C to 10°C: Medium speed (01)
- 11°C to 15°C: High speed (10)
The fan speed output is a 2-bit value indicating the current speed. Implement this functionality in Verilog.
