Design a Verilog module that implements a 4-to-1 multiplexer. The module should have four 2-bit inputs, a 2-bit select signal, and one 2-bit output. The output should be one of the inputs based on the value of the select signal.

module mux4to1 (
    input [1:0] in0,
    input [1:0] in1,
    input [1:0] in2,
    input [1:0] in3,
    input [1:0] sel,
    output reg [1:0] out
);
