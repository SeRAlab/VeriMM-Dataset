Design a 4x4 keypad decoder that converts a 4-bit horizontal input (`h_p`) and a 3-bit vertical input (`v_p`) into a 5-bit output (`num`). The output provides a unique value corresponding to each key position on the keypad, enabling the identification of the pressed key. When `v_p` is 0, the output range is from 0 to 3; when `v_p` is 1, it ranges from 4 to 7, and so forth, up to `v_p` equals 3, which covers values from 12 to 15. If the inputs do not match any defined key, the output defaults to 16, indicating an invalid or unpressed key.
module top_module(input[3:0] h_p,input [3:0] v_p,output [4:0] num);
