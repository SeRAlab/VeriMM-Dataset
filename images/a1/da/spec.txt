Design a 32-bit shift register with adaptive input handling. This module takes a 32-bit input and, based on the sign of the input value, either left-shifts or right-shifts the input by one bit when the clock signal activates. The shifted output is stored in the internal shift register and is provided as output. The module also incorporates a reset functionality to initialize the shift register, ensuring it can be reset asynchronously.
