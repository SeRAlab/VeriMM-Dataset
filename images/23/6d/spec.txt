
Design an SR flip-flop using Verilog. The SR flip-flop should have two inputs, S (set) and R (reset), and two outputs, Q and Qn (not Q). The behavior should be such that:
- When S = 1 and R = 0, Q should be set to 1.
- When S = 0 and R = 1, Q should be reset to 0.
- When S = 0 and R = 0, Q should hold its previous state.
- When S = 1 and R = 1, the state is considered invalid (you can choose to hold the previous state or set Q to 0).
