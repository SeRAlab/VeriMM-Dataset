
Design an 8-bit DRAM cell with the following specifications:
1. The cell should be able to store a single 8-bit value.
2. It should have a read and write operation controlled by a clock signal.
3. The write operation takes an 8-bit input and stores it when a write enable (we) signal is high.
4. The read operation outputs the stored value when a read enable (re) signal is high.
5. The cell should have a reset signal to clear the stored value.
