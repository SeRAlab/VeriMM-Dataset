
Design a SATA controller state machine that handles the following states: 
1. IDLE
2. CONNECTING
3. CONNECTED
4. DISCONNECTING

The state machine should transition between these states based on the following inputs:
- start_connection (to move from IDLE to CONNECTING)
- connection_success (to move from CONNECTING to CONNECTED)
- start_disconnection (to move from CONNECTED to DISCONNECTING)
- disconnection_success (to move from DISCONNECTING to IDLE)

The output should indicate the current state of the SATA controller.
