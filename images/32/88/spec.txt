
Design a JK flip-flop in Verilog. The JK flip-flop should have the following inputs and outputs:
Inputs: 
- J (1-bit)
- K (1-bit)
- CLK (1-bit, clock signal)
- RST (1-bit, active high reset signal)

Outputs:
- Q (1-bit, current state)
- Qn (1-bit, inverted current state) 

The JK flip-flop should reset the output Q to 0 when RST is high. On the rising edge of CLK, if J and K are both low, Q remains unchanged; if J is high and K is low, Q is set to 1; if J is low and K is high, Q is set to 0; if both J and K are high, Q toggles its state.
