Design a 4-bit Arithmetic Logic Unit (ALU) that performs different operations based on a 2-bit operation selector (op). The ALU computes the sum, difference, bitwise AND, or bitwise OR of three 4-bit inputs (A, B, and C), depending on the value of op. Specifically, with op set to 00, it outputs the sum of A, B, and C; with op set to 01, it outputs the difference A minus B minus C; with op set to 10, it outputs the bitwise AND of A, B, and C; and with op set to 11, it outputs the bitwise OR of A, B, and C.
module top_module(output reg [3:0]Z, input [1:0]op, input [3:0] A, B, C);
