Design a bidirectional 8-bit counter that increments or decrements its value based on an input control signal, `up_down`. When `rst` is high, the counter resets to 0. If `up_down` is high, the counter counts up to a maximum of 255 and wraps around to 0. If `up_down` is low, the counter counts down to 0 and wraps around to 255.
module top_module(
  input clk,
  input rst,
  input up_down,
  output reg [7:0] count
);
