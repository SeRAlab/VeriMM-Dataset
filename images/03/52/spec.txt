
Design a JK flip-flop using Verilog. The flip-flop should have inputs for J, K, the clock (clk), and a reset (rst) signal. The output should be Q. When rst is high, Q should be reset to 0. On the rising edge of clk, the JK flip-flop should update its output Q based on the values of J and K as follows:
- If J=0 and K=0, Q remains unchanged.
- If J=1 and K=0, Q is set to 1.
- If J=0 and K=1, Q is set to 0.
- If J=1 and K=1, Q toggles its state.
