
Design a 4-bit DRAM cell that can read and write data. The DRAM cell should have the following features:
1. A 4-bit data input (D[3:0]) for writing data.
2. A 4-bit data output (Q[3:0]) for reading data.
3. A control signal (WE) for enabling write operations (active high).
4. A clock signal (CLK) for synchronization.
5. An additional signal (CS) for chip select (active high) to enable the DRAM cell.
If CS is low, the cell should not perform any read or write operations. The default state of the DRAM cell should be zero when it is not selected.
