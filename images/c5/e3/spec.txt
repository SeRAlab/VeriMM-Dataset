

You are tasked with designing a Verilog module that can perform a binary to Gray code conversion. The module should have a 4-bit input and a 4-bit output. The module should take the binary input and convert it to Gray code, and output the Gray code.

Gray code is a binary numeral system where two successive values differ in only one bit. For example, the binary number 0101 is represented as 0111 in Gray code. The conversion from binary to Gray code can be performed by XORing each bit with its adjacent bit to the left.

You should write a Verilog module named `bin2gray` that has the following inputs and outputs:

Inputs:
- `in` (4-bit binary input)

Outputs:
- `out` (4-bit Gray code output)

The module should perform the binary to Gray code conversion and output the result on the `out` port.
