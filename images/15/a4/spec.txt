Design a current sensor that measures the average current over a specified number of clock cycles. The current values are sampled every clock cycle, and the average should be updated on every sampling. The sensor should have an input 'current_in' (5 bits wide), a clock input 'clk', and an output 'avg_current' (5 bits wide). The number of samples to consider for the average is defined by a 3-bit input 'sample_count', which can range from 1 to 7.
