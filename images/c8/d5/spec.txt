

You are tasked with designing a Verilog module that will take in two 8-bit inputs, A and B, and output a single 8-bit output, Y. The output Y is the result of adding A and B, but with a twist: if the sum of A and B is greater than 255, then the output Y should be set to 255. 

Your module should be named "adder" and should have the following inputs and outputs:
- Input A: an 8-bit unsigned integer
- Input B: an 8-bit unsigned integer
- Output Y: an 8-bit unsigned integer

Write the Verilog code for the "adder" module that satisfies the above requirements.
