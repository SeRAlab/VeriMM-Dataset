Implement a Verilog module for a 1-bit D flip-flop with synchronous reset and enable. The flip-flop should have a clock input `clk`, a synchronous reset input `reset`, an enable input `en`, a data input `D`, and a data output `Q`. When `reset` is high, `Q` should be set to 0. When `en` is high, `Q` should be set to `D` on the rising edge of `clk`.

module d_flip_flop(
	input wire clk,
	input wire reset,
	input wire en,
	input wire D,
	output reg Q
);
