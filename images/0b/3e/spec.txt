Design a Verilog module that implements a simple state machine for a SLAM algorithm. The state machine should have three states: IDLE, MAPPING, and LOCALIZING. The state transitions are triggered by a control signal called `start`. When `start` is high, the machine transitions from IDLE to MAPPING. In MAPPING state, if a second signal `map_complete` is high, it transitions to LOCALIZING. In LOCALIZING state, if the `localize_complete` signal is high, it returns to IDLE. The module should include a 3-bit output representing the current state.
