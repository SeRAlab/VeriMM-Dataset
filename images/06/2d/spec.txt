Design a voltage-controlled oscillator (VCO) that generates a frequency output based on a 3-bit control input. The VCO should increase its frequency for each increment of the control input. The output frequency can be represented as a toggle of an output bit every N clock cycles, where N is determined by the control input. For example, if the control input is 000, the output should toggle every 8 clock cycles; if 001, every 4 clock cycles; if 010, every 2 clock cycles; if 011, every 1 clock cycle; and if 100, the output should remain stable (not toggle). The output should reset whenever the control input changes.
