Design a module that performs bitwise operations on four 16-bit input signals. When the reset signal is active, the outputs are set to zero. Otherwise, the module computes `out1` as the bitwise AND of `in1` and `in2`, and `out2` as the bitwise XOR of `in3` and `in4`.
module top_module(
    input [15:0] in1,
    input [15:0] in2,
    input [15:0] in3,
    input [15:0] in4,
    input reset,
    output reg [15:0] out1,
    output reg [15:0] out2
);
