Design a 4-to-1 multiplexer with an additional shuffle functionality. The module takes four 32-bit input values (regValA, regValB, regValC, regValD) and outputs one based on a 2-bit index. The output is selected from the inputs either based on a specified shuffle index (idxShuf) or a default index (idxDfl), which is determined by the doShuf control signal. When doShuf is high, the module shuffles the inputs according to idxShuf; otherwise, it uses idxDfl for selecting the output.
module top_module(
	regValA,	regValB,	regValC,	regValD,
	regOut,		idxShuf,	idxDfl,		doShuf);
