Implement a simple branch predictor using a 2-bit saturating counter. The 2-bit counter will have four states: 00 (Strongly Not Taken), 01 (Weakly Not Taken), 10 (Weakly Taken), 11 (Strongly Taken). The predictor will take a branch prediction input (1 for taken, 0 for not taken) and the actual branch outcome (1 for taken, 0 for not taken) and update the counter based on the actual outcome. The output will be the predicted outcome based on the current state of the counter.
