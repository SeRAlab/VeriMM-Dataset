Implement a 4-bit ripple carry adder with an asynchronous reset. The module takes two 4-bit binary inputs, A and B, and produces a 4-bit sum output, S, and a carry-out signal, C. When the asynchronous reset (areset) is activated, the sum output and carry-out are reset to zero. Otherwise, the module computes the sum of the inputs A and B, along with any carry from the previous operation, utilizing the ripple carry technique to propagate any carry beyond the least significant bit.

    input [3:0] A,
    input [3:0] B,
    input areset,
    output [3:0] S,
    output C
);
