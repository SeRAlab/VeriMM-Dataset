Design a circuit that functions as a 4-bit adder/subtractor. The circuit takes two 4-bit inputs, A and B, and a control input mode. When mode is set to 0, it performs the addition of A and B, indicating a carry out if the result exceeds 4 bits. When mode is set to 1, it performs the subtraction of B from A, signaling a carry out when the result is negative (when the most significant bit is zero). The outputs are a 4-bit result and a carry out signal, allowing for arithmetic operations in a single module.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input mode,
  output [3:0] sum,
  output carry_out
);
