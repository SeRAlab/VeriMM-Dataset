Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs: 
1. state P (output 0).
2. state Q (output 1).
3. state R (output 1).

State transitions:
1. From state P: If y = 0, then transition to state Q. If y = 1, then transition to state R.
2. From state Q: If y = 0, then transition to state P. If y = 1, then transition to state R.
3. From state R: If y = 0, then transition to state Q. If y = 1, then transition to state P.

Resets into state P. For this part, assume that a one-hot code is used with the state assignment h[3:1] = 001, 010, 100 for states P, Q, R, respectively.

Write Verilog for the next-state signals H2 and H3 corresponding to signal h[2] and h[3]. Derive the logic equations by inspection assuming a one-hot encoding.
