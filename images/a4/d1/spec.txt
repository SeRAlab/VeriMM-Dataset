Design a D-type flip-flop with asynchronous reset functionality. On the rising edge of the clock signal, the flip-flop captures the input data (d) and holds it at the output (q) until the next clock edge. When the reset signal is asserted (active low), the output (q) is set to LOW regardless of the clock. The complementary output (q_n) is generated by inverting the q output.
module top_module(
    input clk,
    input reset,
    input d,
    output reg q,
    output reg q_n
);
