Design a two-bit wide register that captures and holds an input value provided by the `wnd` signal. The output `w` is reset to zero upon receiving a reset signal (`rst`) or an initialization signal (`init`). On the rising edge of the clock (`clk`), if neither reset nor initialize signals are asserted, the module updates the output `w` with the current value of `wnd`.
module top_module(input [1:0] wnd,input init,clk,rst,output reg [1:0] w);
