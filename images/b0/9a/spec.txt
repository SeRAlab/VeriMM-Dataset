Design a D flip-flop with reset and set functionalities. The flip-flop captures the value of the input D on the rising edge of the clock (CK). When the reset input (RN) is asserted, the output Q is set to LOW regardless of D, while when the set input (SN) is asserted, Q is set to HIGH. In the absence of reset or set conditions, Q will follow the D input. The complementary output QN is generated as the logical NOT of Q.
