Design a Direct Memory Access (DMA) Controller in Verilog that allows a device to access memory directly, bypassing the CPU. The DMA controller should support the following features:
- A Read request signal that indicates when a device wants to read data from memory.
- A Write request signal that indicates when a device wants to write data to memory.
- An address bus to specify the memory location.
- A data bus to transfer data.
- A ready signal that indicates when the memory is ready for the next transaction.
- A clock signal for synchronization.

The controller should operate in a simple cycle: upon receiving a read or write request, it initiates a transfer, and the data should be available on the data bus after one clock cycle. The controller should handle one transaction at a time.
