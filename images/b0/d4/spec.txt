Design a sequential circuit that functions as a three-input logic unit with a clock. The module takes two inputs (A1 and A2) along with a third input (B1) and produces an output (Y) based on specific conditions evaluated at the rising edge of the clock. When both A1 and A2 are high, the output Y is set to high. If both A1 and A2 are low, the output Y is set to low. If A1 is high and A2 is low, the output Y is the inverse of B1. In the remaining case, where A1 is low and A2 is high, the output Y directly reflects the value of B1.
module top_module(
    input A1,
    input A2,
    input B1,
    output Y,
    input clk
);
