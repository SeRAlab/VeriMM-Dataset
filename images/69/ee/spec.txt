Design a temperature control system with a fan, heater, and air conditioning unit. The heater activates when the mode is set to "on" (indicating heating mode) and the temperature is "too cold." Conversely, the air conditioning unit activates when the mode is set to "off" (indicating cooling mode) and the temperature is "too hot." The fan operates whenever the fan is switched on or if either the heater or air conditioning is active, ensuring effective air circulation based on the temperature conditions and user settings.
module top_module(
    input too_cold,
    input too_hot,
    input mode,
    input fan_on,
    output heater,
    output aircon,
    output fan
);
