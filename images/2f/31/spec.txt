Design an 8-bit shift register with both left and right shift capabilities. The shift register should have a parallel load feature. It should have the following inputs: a clock signal (clk), a reset signal (rst), a shift direction signal (dir, where 0 means left shift and 1 means right shift), a parallel load signal (load), and an 8-bit data input (data_in). The output should be the current state of the shift register (data_out).
