Design a Verilog module for a 12-bit linear feedback shift register (LFSR) with synchronous enable. The module should have an input clock signal (clk), an input enable signal (en), and a 12-bit output signal (lfsr). On the rising edge of the clock, if enable is high, the LFSR should shift right and the new bit should be the XOR of the current bits 11 and 9.
