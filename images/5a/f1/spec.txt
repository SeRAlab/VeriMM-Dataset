Design a Verilog module that simulates a 2-bit gray code counter with an enable signal. The module should have an input clock signal (clk), an input reset signal (rst), an input enable signal (en), and a 2-bit output signal (gray). On the rising edge of the clock, if reset is high, gray should be set to 2'b00. If enable is high and reset is low, gray should count in a gray code sequence.
