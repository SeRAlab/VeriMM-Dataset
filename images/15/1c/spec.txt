Design a 32-bit CRC (Cyclic Redundancy Check) generator. The generator takes a 32-bit input data and produces a 32-bit CRC output using a specified polynomial. The CRC must be calculated over multiple cycles, allowing for an input stream to be processed bit by bit. The circuit should have a load signal to load the initial data and a clock signal to process the data. You should output the CRC once the data processing is complete.
