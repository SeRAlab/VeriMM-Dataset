Design a combinational logic circuit that performs LU decomposition on a 2x2 matrix. The input will be a 4-bit number representing the elements of a matrix A, arranged as follows: A[0], A[1], A[2], A[3]. The output should be the lower triangular matrix L and the upper triangular matrix U, each represented as 4-bit numbers. The output should be structured such that L is in the upper bits and U is in the lower bits.
