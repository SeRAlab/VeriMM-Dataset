Design a priority multiplexer that selects one of four 4-bit inputs (A, B, C, D) based on their values. The selection is made by comparing the inputs, and the highest-valued input among A, B, C, and D is output. The module generates a 2-bit selection signal that corresponds to the input with the highest priority, with A having the highest priority and D the lowest. The output will always reflect the chosen input with the highest value from the provided inputs.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input [3:0] C,
    input [3:0] D,
    input [1:0] S,
    output reg [3:0] out
);
