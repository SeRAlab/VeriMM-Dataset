Design a 4-to-1 multiplexer that selects one of four inputs (A0, A1, A2, A3) based on a 2-bit selection signal (S). The output (X) will reflect the value of the selected input, where S=00 outputs A0, S=01 outputs A1, S=10 outputs A2, and S=11 outputs A3. The module also includes connections for power and ground, denoting its integration in a larger circuit.
module top_module(
    input A0,
    input A1,
    input A2,
    input A3,
    input [1:0] S,
    output X,
    input VPB,
    input VPWR,
    input VGND,
    input VNB
);
