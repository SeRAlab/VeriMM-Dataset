Design a combinational logic circuit that implements a specific output based on the input combinations of four binary variables (x1, x2, x3, x4). The circuit outputs a HIGH signal (y) if any of the predefined conditions, represented by various combinations of these inputs, are met. Specifically, the output is generated through a series of AND operations on different combinations of the inputs, followed by an OR operation to consolidate the results. This module effectively realizes a simplified representation of a 4-variable Karnaugh map for optimization of logical expressions.
module top_module(
  input x1,
  input x2,
  input x3,
  input x4,
  output y
);
