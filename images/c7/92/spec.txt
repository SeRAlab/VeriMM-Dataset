

You are tasked with designing a verilog module for a power management system. The module should be named `power_mgmt` and should have the following input and output signals:

Inputs:
- `sleep`: A single bit input signal that indicates whether the system is in sleep mode.
- `vpwr`: A single bit input signal that indicates whether the system is receiving power.
- `vgnd`: A single bit input signal that indicates whether the system is grounded.

Outputs:
- `pwrgood`: A single bit output signal that indicates whether the power supply is stable and within the acceptable range.

Your task is to design the `power_mgmt` module using the provided signals. The module should implement the following logic:

- If the `sleep` input signal is high, the `pwrgood` output signal should be low.
- If the `vpwr` input signal is low, the `pwrgood` output signal should be low.
- If the `vgnd` input signal is low, the `pwrgood` output signal should be low.
- Otherwise, the `pwrgood` output signal should be high.
