Design a Verilog module that calculates the Internet Protocol (IP) checksum for a given 16-bit words input. The module should take a stream of 16-bit words as input and output a 16-bit checksum. The checksum is calculated by taking the one's complement of the sum of all the 16-bit words. The input will be valid when 'valid' signal is high, and the output will be generated when 'done' signal is high.
