

You are tasked with designing a module that takes in two 8-bit data inputs, d0 and d1, and a single select signal, s. The module should output the selected data input based on the value of the select signal. If s is 0, the output should be d0. If s is 1, the output should be d1.

Create a Verilog module named "mux8" that implements this functionality. The module should have the following inputs and outputs:

Inputs:
- d0: an 8-bit data input
- d1: an 8-bit data input
- s: a single-bit select signal

Outputs:
- y: an 8-bit output that is either d0 or d1, depending on the value of s

Your module should be written in a way that allows it to be easily reused in other designs.
