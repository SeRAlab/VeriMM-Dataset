Design a 16-bit wide, 2-to-1 multiplexer. The module selects between two 16-bit inputs, In_A and In_B, based on the value of the control signal muxCntrl. When muxCntrl is 0, the output out reflects the value of In_A; when muxCntrl is 1, the output reflects the value of In_B. If an unexpected value is provided for muxCntrl, the output defaults to zero.
module top_module(muxCntrl, In_A, In_B, out);
