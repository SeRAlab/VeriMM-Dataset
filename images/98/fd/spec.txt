Design a 64-bit wide multiplexer that selects between three different data inputs—Lo_ReadData, Hi_ReadData, and MEM_Result—based on the control signals EXE_MEM_LoRead and EXE_MEM_HiRead. When EXE_MEM_LoRead is asserted, the output MEM_Data will be assigned the value of Lo_ReadData; when EXE_MEM_HiRead is asserted, it will take the value from Hi_ReadData; and if neither control signal is asserted, MEM_Data will output MEM_Result. This circuit is intended to manage data selection in a memory operation scenario within a larger digital system, such as a processor's memory stage.
