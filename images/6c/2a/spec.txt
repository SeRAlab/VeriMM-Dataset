Design a finite state machine (FSM) that manages a simple state progression through five defined states: IDLE, S1, S2, S3, and DONE. The FSM transitions from one state to the next on each clock cycle, starting from IDLE and moving sequentially to DONE, while asserting the output 'ack' when the DONE state is reached. Additionally, it includes a mechanism for indicating the current state as an ASCII string representation for debugging or monitoring purposes, allowing the user to easily identify which stage the FSM is currently in. The module is reset asynchronously with a low signal on the reset input.

                             input  clk,
                             input  rst_n,
