Design a temperature sensor module that converts a signed 10-bit Celsius input to a signed 16-bit Fahrenheit output. When the reset signal is activated, the Fahrenheit output is set to zero. Otherwise, the conversion formula (temp_F = temp_C * 1.8 + 32) is applied to compute the temperature in Fahrenheit based on the Celsius input.
module top_module(
    input signed [9:0] temp_C,
    input reset,
    output signed [15:0] temp_F
);
