Design a circuit for encryption and decryption using a simple XOR operation. The module takes a single bit of input data and a single bit key, along with a mode signal. When the mode is set to 0, it performs encryption by XORing the data with the key. When the mode is set to 1, it performs decryption by XORing the data with the inverted key. This design serves as a basic toggle mechanism for data manipulation based on the mode of operation.
module top_module(
  input data_in,
  input key_in,
  input mode,
  output data_out
);
