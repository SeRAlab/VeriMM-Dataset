Design a synchronous up-counter with load capability. The counter has a configurable size, defined by the parameter SIZE (defaulting to 4 bits), and operates on the positive edge of the clock signal. It can be reset to zero when the reset signal (rst) is activated or can load a specified input value (din) when the load signal is high. In the normal operation mode, the counter increments its current value by one on each clock cycle. The current state of the counter is continuously outputted through the signal q.
