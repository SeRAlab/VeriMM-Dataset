Design a sequence detector that recognizes the specific input sequence A, B, C, followed by D. The module transitions between different states to track the detection of each input—the IDLE state, the A state, the AB state, and the ABC state—and, upon detecting the complete sequence, it outputs a HIGH signal (Y) indicating that the sequence has been successfully detected. The state is updated on the positive edge of the clock.
module top_module(
    input clk,   // Added input for clock signal
    input A,
    input B,
    input C,
    input D,
    output reg Y
);
