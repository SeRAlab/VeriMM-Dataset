Design a simple PCIe request and response state machine. The state machine should have the following states: IDLE, REQUEST, and RESPONSE. It should transition from IDLE to REQUEST on a 'start' signal, from REQUEST to RESPONSE on a 'ack' signal, and return to IDLE after RESPONSE when a 'done' signal is asserted. The module should also output the current state as a 2-bit binary value (00 for IDLE, 01 for REQUEST, and 10 for RESPONSE).
