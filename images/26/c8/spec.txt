Design a 2-channel Direct Memory Access (DMA) controller in Verilog. The controller should support two channels that can request memory access. Each channel has a request signal (req), a grant signal (grant), and a data bus (data). The controller should prioritize channel 1 over channel 2 when both channels request simultaneous access. The grant signal should be asserted for the channel that gets the access, and the data bus should carry the channel's data during the granted access period. The controller should have a clock input (clk) and a reset input (reset).
