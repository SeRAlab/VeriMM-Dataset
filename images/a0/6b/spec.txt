Create a hex to seven-segment display decoder. This module converts a 4-bit binary input representing a hexadecimal digit (0-F) into the corresponding 7-segment display encoding. It drives the output segment signals to represent the digit on the display. Additionally, an optional decimal point (dp) signal can be used to turn on the decimal point segment. If an invalid input is detected, the module defaults all segments to off.
module top_module(
    input [3:0] hex_in,
    input dp,
    output reg [6:0] sseg
);
