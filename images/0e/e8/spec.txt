Design a simple hash table module in Verilog that takes a 5-bit input key and produces a 3-bit output index. The module should implement a basic hashing function which is the modulo of the key by the number of slots in the hash table (8 in this case). The module should also include a 3-bit output for a status flag indicating if the key is valid (1) or not (0) based on a predefined range of valid keys (0-31).
