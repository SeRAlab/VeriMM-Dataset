Design a 4-bit shift register with load and shift capabilities. Upon a reset signal, the output is initialized to zero. When the load signal is high, the register captures the 4-bit input data. If the shift signal is activated, the register shifts its contents to the left by one bit, inserting a zero at the least significant bit position.
module top_module(
    input clk,
    input rst,
    input load,
    input [3:0] data_in,
    input shift,
    output reg [3:0] data_out
);
