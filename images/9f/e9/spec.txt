Implement the Verilog module based on the following description.
Given a 3-bit up-down counter:

1. The counter increments on each rising edge of the clock if the up signal is high.
2. The counter decrements on each rising edge of the clock if the down signal is high.
3. The counter holds its value if both up and down signals are low or both are high.
4. The counter resets to 0 when the reset signal is high.

Write Verilog implementing this 3-bit up-down counter.
module up_down_counter_3bit (
    input clk,
    input reset,
    input up,
    input down,
    output reg [2:0] count);
