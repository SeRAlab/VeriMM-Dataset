Design a 4-bit adder/subtractor circuit. The module takes two 4-bit inputs, A and B, and a mode control signal. When mode is low, the module performs the addition of A and B, and when mode is high, it computes A minus B by calculating the two's complement of B and adding it to A. The output F provides the 4-bit result, and Cout indicates the carry-out, which also signifies whether a borrow occurred in subtraction.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input mode,
    output [3:0] F,
    output Cout
);
