Design a 4-to-1 multiplexer that selects one of four input signals (A1, A2, B1, B2) based on the value of the select signal C1. The output Y will reflect the selected input, with the specific selection defined as follows: when C1 is low (0), the output Y will be determined by inputs A1 and A2; when C1 is high (1), it will be determined by inputs B1 and B2.
module top_module(
    input A1,
    input A2,
    input B1,
    input B2,
    input C1,
    output Y
);
