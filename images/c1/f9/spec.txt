

You are tasked with designing a Verilog module that can perform a simple arithmetic operation on two 4-bit inputs. The module should take in two 4-bit inputs, a 2-bit control signal, and output a 4-bit result. The control signal determines the type of operation to be performed (addition or subtraction). 

The module should implement the following truth table: 

| Control | Input 1 | Input 2 | Output |
|---------|---------|---------|--------|
| 00      | 0000    | 0000    | 0000   |
| 00      | 0000    | 0001    | 1111   |
| 00      | 0001    | 0000    | 1111   |
| 00      | 0001    | 0001    | 1110   |
| 01      | 0000    | 0000    | 0000   |
| 01      | 0000    | 0001    | 1111   |
| 01      | 0001    | 0000    | 0001   |
| 01      | 0001    | 0001    | 0000   |

Implement the module within 200 lines of Verilog code.
