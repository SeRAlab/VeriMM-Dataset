
Design a cryptographic random number generator (RNG) using a linear feedback shift register (LFSR). The LFSR should be a 5-bit register, and it should produce a random sequence of bits based on the feedback polynomial x^5 + x^4 + x^3 + x^2 + 1. The output of the RNG should be available as a 5-bit wide output. The RNG should be clocked, and it should reset to a known state when the reset signal is asserted.
