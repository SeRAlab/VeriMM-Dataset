Design a CRC module that computes the CRC-8 of an input data stream. The CRC polynomial to be used is x^8 + x^7 + x^4 + 1. The module should have a 1-bit input for each bit of data and a 1-bit clock signal. The output should be an 8-bit CRC value. The module should reset the CRC value on a reset signal. The computation should be done on the rising edge of the clock.
