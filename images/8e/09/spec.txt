Design a D flip-flop with asynchronous clear and load capabilities. The circuit captures the value of the input 'd' on the rising edge of the clock 'clk'. When the asynchronous clear signal 'clrn' is low, the output 'q' resets to low. The 'aload' signal also allows for asynchronous loading of 'd' into 'q' regardless of the clock, while the 'sload' signal enables synchronous loading of 'd' on the next clock edge.
module top_module(
    input d,
    input clk,
    input clrn,
    input aload,
    input sload,
    output reg q
    );
