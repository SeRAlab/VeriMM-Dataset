Design a 128x32-bit synchronous RAM module capable of performing read and write operations. The module receives a clock signal, and on the rising edge, it writes data to a specified address if the write enable signal is asserted. It also updates the output to reflect the contents of a different specified address, allowing for simultaneous read and write capabilities. The memory is organized as an array of 128 entries, each 32 bits wide.
module top_module(
  input  wire           clock,
  input  wire [  7-1:0] wraddress,
  input  wire           wren,
  input  wire [ 32-1:0] data,
  input  wire [  7-1:0] rdaddress,
  output reg  [ 32-1:0] q
);
