Design an SR latch using Verilog. The SR latch should have two inputs, S (Set) and R (Reset), and two outputs, Q and Qn (not Q). The latch should maintain its state until the inputs change, adhering to the following behavior: if S=1 and R=0, Q should become 1; if S=0 and R=1, Q should become 0; if S=0 and R=0, Q should remain unchanged; and if S=1 and R=1, it should be considered an invalid state, and the outputs should not change.
