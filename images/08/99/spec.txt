
Design an 8-bit DRAM cell that can store a single bit of data. The cell should have the following inputs: 
- `data_in` (1-bit input to write data to the cell)
- `write_enable` (1-bit input to control the write operation)
- `read_enable` (1-bit input to control the read operation)

The cell should output:
- `data_out` (1-bit output that reads the stored data when `read_enable` is high)

The DRAM cell should maintain its state when not in the write mode.
