Design a temperature-based shutdown system that monitors a temperature input and activates a shutdown signal if the temperature exceeds a predefined threshold. The system should have two inputs: a clock signal and a temperature value (in degrees Celsius). The threshold is set to 75 degrees Celsius. If the temperature exceeds this threshold, the shutdown signal should be asserted after one clock cycle. If the temperature drops below 70 degrees Celsius, the shutdown signal should be deasserted after one clock cycle.
