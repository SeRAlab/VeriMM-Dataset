Design a controller for a vending machine that manages product selection and monetary transactions. The module accepts a 2-bit product selection input and a 4-bit input representing the amount of money inserted. It calculates the total cost based on the selected product, determines if the money input is sufficient to make the purchase, and generates a dispense signal to release the product. If the purchase is completed, it also computes the change due to the user, outputting this as a 4-bit change value. The design effectively implements the logic for handling product sales and managing customer payments in a vending machine environment.
module top_module(
    input [1:0] product_sel,
    input [3:0] money_in,
    output reg dispense,
    output reg [3:0] change
);
