
Design a 16-bit Cyclic Redundancy Check (CRC) generator. The CRC generator should take a 16-bit input data and produce a 16-bit CRC output based on a polynomial divisor (e.g., x^16 + x^12 + x^5 + 1). The CRC should be computed in a sequential manner, where the input data is provided in a series of clock cycles. The module should have a `start` signal to initiate the computation, and a `done` signal to indicate the completion of the CRC calculation.
