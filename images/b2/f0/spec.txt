Design a 4-bit asynchronous counter that increments its count value on a rising clock edge while remaining active low to an external reset signal (set_l). The counter will output its current count as a 4-bit register. Upon receiving a low signal on set_l, the counter will reset to zero. The design utilizes four asynchronous flip-flops to hold each bit of the count and relies on combinational logic to generate the next count value by adding one to the current count.
module top_module(
  input clk,
  input set_l,
  output reg [3:0] count
);
