Design a data-enabled flip-flop that captures the input data (D) on the rising edge of the clock (CLK) only when the data enable signal (DE) is asserted high. The output Q will reflect the input D at the clock edge if DE is active; otherwise, Q retains its previous state. This functionality combines a standard flip-flop with an enable mechanism, allowing for controlled data storage based on the DE signal.

    input logic CLK,
    input logic D,
    input logic DE,
    output logic Q
);
