Design an 8-bit Linear Feedback Shift Register (LFSR) that generates pseudo-random sequences. The LFSR should have taps at bits 8, 6, 5, and 4. The LFSR should be initialized with a non-zero seed value and should be able to produce 8 output bits with each clock cycle. It should also have a reset input to set the LFSR back to the initial state.
