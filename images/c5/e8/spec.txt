

You are tasked with creating a verilog module for a binary to gray code converter. The module should have one 4-bit input, `bin`, and one 4-bit output, `gray`. The module should output the corresponding gray code for the given binary input. 

The binary input should be interpreted as unsigned, meaning that the highest bit represents 8 and the lowest bit represents 1. The gray code output should follow the same convention, with the highest bit representing 8 and the lowest bit representing 1.

You may assume that the input is valid and that there will be no undefined behavior due to the input.

You should use the following code snippet as a template for your module:
```
module bin_to_gray(
    input [3:0] bin,
    output [3:0] gray
);

    // Your code here

endmodule
```
