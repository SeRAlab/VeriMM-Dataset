

You have been assigned to design a verilog module for a 4-bit adder that can perform both addition and subtraction. The module should have two 4-bit input ports, A and B, and a 1-bit select port, S. When S is 0, the module should perform addition and when S is 1, it should perform subtraction. The module should also have a 4-bit output port, F, which should store the result of the operation.

Write a verilog module for the 4-bit adder that meets the above requirements. You can use any verilog operators and constructs that you deem necessary.
