Design a combinational circuit that takes a 4-bit input and produces three outputs: the AND of all combinations of the input bits, a collective OR of the input bits, and the XOR of the input bits. The `out_and` output is high only if all AND gate combinations are true, `out_or` will be high if at least one OR gate combination is true, and `out_xor` returns the parity based on the XOR operations across pairs of input bits.
module top_module(
    input [3:0] in,
    output out_and,
    output out_or,
    output out_xor
);
