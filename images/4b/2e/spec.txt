Write a Verilog module for an 8-bit binary counter with enable, asynchronous reset, and terminal count. Assume positive clock/clk edge triggered. When enable is low, the counter holds its value. When reset is high, the counter resets to 0. The counter should also have a terminal count output that goes high when the counter reaches its maximum value (255).

module binary_counter (
  input clk,
  input reset,
  input enable,
  output reg [7:0] count,
  output reg terminal_count
);
