Develop a behavioral 2-to-1 multiplexer with additional selection inputs. The module outputs the value of input `a` if `sel_a` is high. If `sel_a` is low and both `sel_b1` and `sel_b2` are also low, the output will be assigned the value of input `b`. Essentially, it allows direct selection of `a` or `b` based on the defined selection conditions.
module top_module(
  input a,
  input b,
  input sel_a,
  input sel_b1,
  input sel_b2,
  output reg out_mux
);
