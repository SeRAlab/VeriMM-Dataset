Design a 4-bit SRAM cell that can store a 4-bit data word and has control signals for read and write operations. The SRAM cell should have the following ports: `input_data` (4 bits), `output_data` (4 bits), `write_enable`, `read_enable`, and a clock signal. When `write_enable` is high, the `input_data` should be stored on the rising edge of the clock. When `read_enable` is high, the stored data should be output on `output_data` on the next clock cycle.
