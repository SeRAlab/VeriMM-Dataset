Develop an AXI4-Lite bridge module that facilitates communication between an AXI4-Lite master and the connected bus, enabling address and data transactions. This module implements a straightforward passthrough mechanism for both write and read operations, signaling readiness based on valid input conditions. It provides basic response handling, always returning a fixed OKAY status for write operations and a zeroed data response for read requests, indicating no data available. The design ensures proper synchronization with external clock and reset signals, fulfilling the required interface specifications for an AXI4-Lite compliant transaction controller.
