Design an 8-bit DRAM cell that can store a single bit of data. The DRAM cell should have a data input (D), a word line (WL) to enable the write operation, a sense line (SL) for reading the data, and an output (Q) for the stored bit. The cell should allow writing to the cell when WL is high and reading the data when SL is high. If WL is low, the cell should retain its value.
