Write a Verilog module that outputs the 8-bit result of a bitwise NAND operation between inputs a and b when the enable signal is high. The output nand_result should be reset to 0 when the reset signal is high.

module nand_module (
    input [7:0] a,
    input [7:0] b,
    input enable,
    input reset,
    output reg [7:0] nand_result);
