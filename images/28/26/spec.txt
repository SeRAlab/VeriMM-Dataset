Design a combinational logic circuit that performs a simplified version of the JPEG compression method. The circuit should take an 8-bit pixel value as input and output a 4-bit compressed value based on the following mapping: 
- If the pixel value is 0-63, output 0.
- If the pixel value is 64-127, output 1.
- If the pixel value is 128-191, output 2.
- If the pixel value is 192-255, output 3.
The output should represent the quantization of the pixel value into 4 levels.
