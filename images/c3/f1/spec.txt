

You have been tasked with designing a Verilog module that implements a 4-input NOR gate. The module should have the following inputs and outputs:

Inputs:
- A, B, C, D: 1-bit inputs representing the four inputs to the NOR gate
- VPWR, VGND: power and ground supply voltages
- VPB, VNB: positive and negative voltage supplies

Outputs:
- Y: 1-bit output representing the output of the NOR gate

You are given the following code snippet as a starting point:

```
module sky130_fd_sc_lp__nor4_0 (
    Y   ,
    A   ,
    B   ,
    C   ,
    D   ,
    VPWR,
    VGND,
    VPB ,
    VNB
);

    output Y   ;
    input  A   ;
    input  B   ;
    input  C   ;
    input  D   ;
    input  VPWR;
    input  VGND;
    input  VPB ;
    input  VNB ;
    sky130_fd_sc_lp__nor4 base (
        .Y(Y),
        .A(A),
        .B(B),
        .C(C),
        .D(D),
        .VPWR(VPWR),
        .VGND(VGND),
        .VPB(VPB),
        .VNB(VNB)
    );

endmodule
```

Your task is to complete the module implementation by writing the Verilog code for the NOR gate.
