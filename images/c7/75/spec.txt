

You are tasked with designing a module that takes in a 4-bit input signal and outputs a 2-bit signal. The output signal should be the result of taking the two's complement of the input signal and then adding 1 to it. You must implement this using Verilog.

Create a module named `twos_comp_add_one` that has the following ports:
- `in`: a 4-bit input signal
- `out`: a 2-bit output signal

You may assume that the input signal is always valid and that the output signal will not overflow.
