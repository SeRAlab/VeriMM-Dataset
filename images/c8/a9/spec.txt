

You are tasked with designing a module that takes in four input signals and outputs a single signal based on the following logic:
- If A1 and A2 are both high, Y should be high.
- If B1 and B2 are both high, Y should be low.
- If both A1 and B1 are high, and A2 and B2 are low, Y should be high.
- If both A2 and B2 are high, and A1 and B1 are low, Y should be low.
- In all other cases, Y should be low.

Design a Verilog module that implements this logic and has the following interface:
- Inputs: A1, A2, B1, B2 (all single-bit signals)
- Outputs: Y (single-bit signal)

You should use the module template provided below:

```
module logic_module (
    input A1,
    input A2,
    input B1,
    input B2,
    output Y
);

    // your code here

endmodule
```
