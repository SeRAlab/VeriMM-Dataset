Design a simple model predictive controller (MPC) in Verilog that takes in a 4-bit input representing a desired state and a 4-bit input for the current state. The controller will compute the next state based on a simple predictive model, which adds a constant value to the current state if the desired state is greater than the current state. If the desired state is less than or equal to the current state, it will simply hold the current state. The output is a 4-bit value representing the next state.
