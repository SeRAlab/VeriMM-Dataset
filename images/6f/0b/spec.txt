Develop a module that parses a 32-bit instruction input from a processor, extracting relevant fields based on the opcode. The module identifies whether the instruction is of the R-type format (indicated by an opcode of `6'b000000`) or I-type format. If it is R-type, it outputs the register source (`rs`), destination (`rd`), target (`rt`), function code (`funct`), and shift amount (`shamt`). For I-type instructions, it outputs the source register (`rs`), target register (`rt`), and a 16-bit immediate address. The extracted fields are critical for further instruction execution and control within the CPU.
