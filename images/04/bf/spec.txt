
Design a Verilog module that implements a simple 3-input multiplexer (MUX). The MUX should select one of the three inputs (A, B, C) based on a 2-bit select signal (sel). When sel is 00, the output should be A; when sel is 01, the output should be B; when sel is 10, the output should be C; and when sel is 11, the output should be undefined (or you can set it to a default value).
