Implement a comparator circuit that can perform both signed and unsigned comparisons on two n-bit wide input numbers. The module takes two n-bit inputs (num1 and num2) and a comparator mode signal (cmp_mode) to determine the type of comparison. When cmp_mode is 0, it executes unsigned comparisons, producing outputs for greater than (gt), equal to (eq), and less than (lt). When cmp_mode is 1, it performs signed comparisons instead. This facilitates the assessment of numerical relationships between the two inputs based on the selected mode.
module top_module(
  input [n-1:0] num1,
  input [n-1:0] num2,
  input cmp_mode,
  output gt,
  output eq,
  output lt
);
