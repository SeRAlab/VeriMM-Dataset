Design a simple EEPROM cell with read and write operations. The EEPROM cell should have a data input (D), a data output (Q), a write enable (WE), and a read enable (RE) signal. When WE is high, the data at D should be written to the cell. When RE is high, the stored data should be output to Q. If both WE and RE are high simultaneously, the output should remain undefined. The initial state of the EEPROM cell should be 0.
