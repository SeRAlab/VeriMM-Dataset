Implement an 8-bit Parallel In Serial Out (PISO) shift register module that shifts data out serially. The data is loaded in parallel and then shifted out bit by bit on each clock cycle.

Module name:
    piso_shift_register
                 
Input ports:
    clk: Clock signal used for synchronous operation.
    rst_n: Active-low reset signal. Defined as 0 for reset and 1 for reset signal inactive.
    load: Load signal used to load data in parallel.
    parallel_in: 8-bit input signal representing the data to be loaded.

Output ports:
    serial_out: 1-bit output signal representing the current bit being shifted out.

Implementation:
The module includes an 8-bit register, shift_reg, which represents the current state of the shift register.
The shift_reg register is updated in the always block, triggered on the positive edge of the clock signal (posedge clk) or the negative edge of the reset signal (negedge rst_n).
On reset, indicated by ~rst_n, the shift_reg register is cleared to 0.
When the load signal is active, the shift_reg register is loaded with the parallel_in data.
On each clock cycle, the shift_reg is shifted right, and the rightmost bit is output as serial_out.

Give me the complete code.

module piso_shift_register(
  input clk,
  input rst_n,
  input load,
  input [7:0] parallel_in,
  output reg serial_out
