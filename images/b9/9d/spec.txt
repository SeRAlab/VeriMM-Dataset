Design a signed magnitude comparator for 4-bit numbers. The module compares two signed inputs, A and B, determining if A is greater than or equal to B. The output C is set to '1' if A is greater than or equal to B and '0' otherwise. The comparison accounts for the sign of the numbers, handling cases where one input is positive and the other is negative, as well as situations where both inputs have the same sign.
module top_module(
    input signed [3:0] A,
    input signed [3:0] B,
    output reg C
);
