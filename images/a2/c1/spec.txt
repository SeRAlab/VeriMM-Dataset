Design a n-bit wide Johnson counter. This counter cycles through a specific sequence of states generated by feeding back the inverted output of the last state bit, effectively creating a self-complementing state pattern. On each rising edge of the clock signal, the current state shifts left while the least significant bit is set to the inverted value of the most significant bit, producing a unique counting sequence that uses half the number of flip-flops compared to a binary counter of the same width.
