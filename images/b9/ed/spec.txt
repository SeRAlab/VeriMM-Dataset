Module name:
    up_counter_12bit

Input ports:
    clk: Clock signal used for synchronous operation.
    rst_n: Active-low reset signal.
    enable: Enable signal for the counter.

Output ports:
    count: 12-bit output signal representing the current count.
    tc: Terminal count signal, goes high when the counter reaches its maximum value (4095).

Operation:
On the positive edge of the clock signal (clk) or the falling edge of the reset signal (rst_n), the module performs the counting operation.
If the reset signal (rst_n) is low, the count is set to 0.
If the enable signal is high, the count is incremented by 1.
If the count reaches its maximum value (4095), it wraps around to 0 and the terminal count signal (tc) goes high.
