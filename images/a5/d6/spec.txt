Design a D flip-flop with asynchronous set functionality. When the SET input is high, the output Q is set to high regardless of the clock signal. On the positive edge of the clock (CK), the flip-flop captures the value of the data input (D) and outputs it at Q, while QN provides the complement of Q. This module effectively stores a single bit of data and can be reset to a high state independently of the clock.
module top_module(
  input SET, 
  input CK, 
  input D, 
  output Q, 
  output QN 
);
