Design a circuit that performs sign extension and zero extension on a 16-bit input. The module takes a 16-bit immediate value and an extension selector signal (ExtSel). If ExtSel is high, it checks the most significant bit of the immediate value to determine if the value is negative; if so, it fills the upper 16 bits of the result with ones, otherwise fills them with zeros. If ExtSel is low, the upper 16 bits are always filled with zeros, effectively creating a zero extension of the original 16-bit input. The final output is a 32-bit result.
module top_module(input [15:0] immediate,input ExtSel,output [31:0] result);
