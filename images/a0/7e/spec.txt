Design a 2-bit binary counter with synchronous reset functionality. The counter increments its value on each positive edge of the clock input. If the reset signal is asserted, it sets the counter back to zero. The counter cycles through the states 00, 01, 10, and 11, returning to 00 after reaching its maximum value. This design can be used in applications requiring a simple state progression or counting.
module top_module(
  input clk,
  input reset,
  output reg [1:0] count
);
