

You are tasked with designing a module in Verilog that implements a 2:1 multiplexer. The module should have one output port and two input ports. The output port should be connected to one of the input ports based on the value of a control signal. If the control signal is 0, the output port should be connected to the first input port. If the control signal is 1, the output port should be connected to the second input port.

The module should be named `mux_2_1` and should have the following ports:
- `input a`: a single bit input port representing the first input to the multiplexer
- `input b`: a single bit input port representing the second input to the multiplexer
- `input sel`: a single bit input port representing the control signal
- `output out`: a single bit output port representing the output of the multiplexer

You should write a module that implements the above functionality within 200 lines of Verilog code. Your module should be synthesizable and should not use any special constructs or features that are specific to a particular FPGA or ASIC technology.
