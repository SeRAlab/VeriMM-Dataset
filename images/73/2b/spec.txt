Design a signed 16-bit calculator capable of performing four basic arithmetic operations: addition, subtraction, multiplication, and division. The module takes two signed 16-bit inputs (A and B) and a 2-bit operation selector (op). Based on the value of op, the calculator outputs the result of the specified operation. The addition, subtraction, and multiplication operations are straightforward, while division includes a safeguard against division by zero, returning the maximum 16-bit signed number in such cases.
module top_module(
    input signed [15:0] A,
    input signed [15:0] B,
    input [1:0] op,
    output reg signed [15:0] result
);
