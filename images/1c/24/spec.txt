Design a Verilog module that implements a simple linear classifier based on Support Vector Machine (SVM) concept. The module should take three inputs: two feature values (x1 and x2) and a bias term (b). The output should be a single bit that indicates the class of the input (1 for positive class, 0 for negative class) based on the decision function: output = (w1 * x1 + w2 * x2 + b) > 0, where w1 and w2 are the weights initialized as constants.
