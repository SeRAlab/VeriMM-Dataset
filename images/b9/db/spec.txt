Design a dual-port 16-bit asynchronous SRAM (Static Random Access Memory) with separate upper and lower byte storage. The RAM is parameterized with a size that determines the addressable memory range. On the rising edge of the clock, it can write data to either the upper byte or the lower byte based on the byte enable signals (be_i) and a write enable signal (wren_i). If wren_i is low and the respective byte enable signal is low, the corresponding byte from data_i is written to the specified address. The output data (data_o) is the concatenation of the upper and lower bytes stored at the given address, effectively allowing read and write operations on 16-bit data with byte-level control.
