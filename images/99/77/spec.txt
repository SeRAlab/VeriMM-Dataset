Design a four-bit binary adder that computes the sum of two four-bit inputs, `a` and `b`, along with a carry-in bit `cin`. The module produces a four-bit output `sum`, which represents the least significant four bits of the addition result, and a carry-out output `cout`, which indicates if there is a carry from the most significant bit of the summed output. The carry-out will be set to 1 if the sum exceeds the maximum value representable in four bits.
module top_module(
  input [3:0] a,
  input [3:0] b,
  input cin,
  output reg [3:0] sum, // Changed to output reg
  output reg cout       // Changed to output reg
);
