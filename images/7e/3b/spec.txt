Design a clock divider that outputs a toggled signal at half the frequency of the input clock. The module takes a clock input (clk_in), an enable signal, and a reset signal. When the reset is active, the output (clk_out) is set to LOW. If the reset is inactive and the enable signal is asserted, the output toggles its state on each positive edge of the input clock, effectively generating a divided clock output.
