
Design a 16-bit DRAM cell with the following functionalities:
1. The DRAM cell should have a 16-bit data input (D), a read/write control signal (RW), and a clock signal (CLK).
2. If RW is high (1), data on the input D should be written to the cell on the rising edge of CLK.
3. If RW is low (0), the cell should output the stored data on a data output (Q) on the rising edge of CLK.
