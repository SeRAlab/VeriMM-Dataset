Design a three-stage pipeline flip-flop circuit with an active-low clear signal and a single bit input/output. The module captures the input data 'd' on the rising edge of the clock if the clear signal 'clrn' is high; otherwise, it resets the output to LOW. The data is sequentially passed through three registers, effectively delaying the input signal by three clock cycles before presenting the output 'q'. The design purpose is to facilitate synchronous data storage with clear functionality for signal reset in digital systems.
module top_module(
  input clock,
  input clrn,
  input [0:0] d,
  output [0:0] q
);
