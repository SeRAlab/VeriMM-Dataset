Design a 4-bit adder/subtractor circuit. The module takes two 4-bit inputs, A and B, and a control signal C. When C is low, it performs addition of A and B, producing a 4-bit sum S and generating a carry-out C_out if there is an overflow. When C is high, it performs subtraction (A - B), setting S to the result and determining C_out based on whether A is less than B, indicating a borrow condition.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input C,
  output reg [3:0] S,
  output reg C_out
);
