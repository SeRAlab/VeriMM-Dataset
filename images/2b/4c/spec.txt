
Design a simple Automatic Repeat reQuest (ARQ) protocol system in Verilog. The system will have a sender that can send a data packet and a receiver that can acknowledge the reception of the packet. If the sender does not receive an acknowledgment within a certain number of clock cycles, it will resend the packet. The system should have an input for the data to send, a clock, and an enable signal. The output will be a valid acknowledgment signal and a resend signal.
