Design a simple Automatic Repeat reQuest (ARQ) error correction system. The system should have a sender that transmits a 5-bit data word and a receiver that can either accept the data correctly or request a retransmission based on a parity bit. If the parity bit indicates an error, the receiver will send an error signal back to the sender to indicate a need for retransmission. The sender should continue to retransmit the last transmitted data until it is acknowledged by the receiver without error.
