

You are tasked with designing a verilog module that will implement a 4-bit binary to Gray code converter. The module should have the following input and output ports:

Input Ports:
- `binary_in`: a 4-bit input port representing the binary input.
- `clk`: a clock input port.

Output Ports:
- `gray_out`: a 4-bit output port representing the Gray code output.

The module should use the positive edge of the clock to sample the binary input and generate the corresponding Gray code output. The module should be synthesizeable and should not use any behavioral constructs.

Design Requirements:
- The module should use only combinational logic.
- The module should use the minimum number of logic gates.
- The module should have a maximum delay of 2 ns.
