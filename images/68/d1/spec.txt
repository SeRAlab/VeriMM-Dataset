Develop a module for generating and verifying parity bits for an n-bit data input. The module provides a parity bit output, which can either be even or odd based on the control input. Additionally, it includes a data output that combines the original data with the generated parity bit. The status output indicates the success of parity verification at the receiver side, ensuring data integrity by checking if the number of 1s in the combined data and parity bit adheres to the expected even or odd condition defined by the control signal.
module top_module(
  input [n-1:0] data,
  input ctrl,
  output p,
  output status
);
