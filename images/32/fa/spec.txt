
Design a 4-bit DRAM cell that can store a 4-bit value. The DRAM cell should have the following inputs and outputs:
- Inputs: 
  - `clk`: Clock signal
  - `we`: Write enable signal (1: write mode, 0: read mode)
  - `data_in`: 4-bit input data
- Outputs:
  - `data_out`: 4-bit output data
The DRAM cell should store the `data_in` when `we` is high and output the stored value on `data_out` when `we` is low.
