Design an interrupt controller that has the following functionality: It takes a signal `interrupt` which is asserted (high) when an interrupt request occurs. The controller should have a clock input `clk` and a reset input `rst`. When `rst` is asserted, the output `irq` should be reset to 0. On the rising edge of `clk`, if `interrupt` is asserted, `irq` should be set to 1, indicating that an interrupt has been acknowledged. If `interrupt` is not asserted, `irq` should remain 1 until the next reset. The output `irq` is a single-bit signal.
