Design a Verilog module that implements a simple state machine for a robot in a SLAM system. The state machine should have three states: IDLE, MOVING, and MAPPING. The state transitions are as follows: from IDLE to MOVING on input 'start', from MOVING to MAPPING on input 'map', and from MAPPING to IDLE on input 'reset'. The state should be output as a 2-bit binary value (00 for IDLE, 01 for MOVING, and 10 for MAPPING).
