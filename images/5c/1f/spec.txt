Implement the Verilog module based on the following description.
Create a module that implements a 4-bit binary counter with load. The counter increments on each clock cycle. When the 'load' input is high, the counter should load the value of the 4-bit input 'd'. The reset input is active high synchronous, and should set the output to 4'b0000.
module binary_counter_with_load(
	input clk,
	input reset,
	input load,
	input [3:0] d,
	output reg [3:0] q);
