Design a dual-port Static Random Access Memory (SRAM) module capable of simultaneous read and write operations. The module supports two separate write addresses and corresponding data buses, allowing data to be written to the memory at the specified addresses when the write enable (WE) signal is active. It utilizes a clock signal for synchronous operation, updating the memory contents on the rising edge of the clock. Additionally, it delivers two output buses that provide the data stored at the specified read addresses, enabling two distinct read operations in parallel. The memory organization consists of 512 entries, each holding 192 bits of data.
