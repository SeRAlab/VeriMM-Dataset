Create a Verilog module for a 3-bit up/down counter with synchronous reset. The counter should count up when the up signal is high and count down when the down signal is high. If both up and down are high, the counter should hold its value. If reset is high, the counter should reset to 0.
module up_down_counter(
	input clk,
	input reset,
	input up,
	input down,
	output reg [2:0] count);
