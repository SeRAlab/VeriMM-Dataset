Design a 4-to-1 multiplexer that selects a 32-bit address output based on a 3-bit control signal (PCSrc). The multiplexer has four input sources: PCAdd4, B, J, and Jr. Depending on the value of PCSrc, the output nextAddr will be assigned to one of the inputs: when PCSrc is 000, it outputs PCAdd4; 001 selects B; both 010 and 011 select J; and both 100 and 101 select Jr. This module facilitates the branching logic in a processor by directing the next program counter address based on various control signals.
