Design a 2-to-1 selector (commutator) circuit that outputs one of two N-bit wide input signals, x1 or x2, based on the control signal alpha. When alpha is low (0), the output will be the value from x1; when alpha is high (1), the output will be taken from x2. The output assignment is delayed by 2 time units, simulating a propagation delay.
module top_module(output [N-1:0]out, input [N-1:0]x1, input [N-1:0]x2, input alpha);
