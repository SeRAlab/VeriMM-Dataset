Design a Verilog module that implements a simplified version of the SHA-256 compression function. The module should take a 512-bit input message and a 256-bit state as inputs and output a new 256-bit state. The SHA-256 function involves bitwise operations, modular additions, and a series of constants. Your task is to design this compression function in Verilog, ensuring that it correctly implements the core operations of SHA-256.
