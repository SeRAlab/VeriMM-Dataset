

You are tasked with designing a module that counts the number of 1's in a 32-bit input signal. The module should have the following ports:

- `clk`: input clock signal
- `rst`: asynchronous reset signal
- `in`: 32-bit input signal to be counted
- `count`: 6-bit output signal representing the number of 1's in `in`

The module should have the following behavior:

- On the rising edge of `clk`, if `rst` is high, `count` should be set to 0.
- On the rising edge of `clk`, if `rst` is low, `count` should be updated to the number of 1's in `in`.
- The module should be combinational, i.e. it should not have any flip-flops other than the one used for `rst`.

Write the verilog code for this module.
