Implement the Verilog module based on the following description.
Create a 2-bit Johnson counter. The counter outputs a 2-bit sequence where each bit toggles based on the inverse of the other bit. It resets to "00" when the reset signal is high.

// Signals are defined as below:
// (1) clk: The clock signal.
// (2) reset: Resets the counter to "00". Active high.
// (3) q: The 2-bit output of the counter.
module johnson_counter(
    input clk,
    input reset,
    output reg [1:0] q);
