Design a circuit that functions as an 8-bit calculator capable of performing various arithmetic operations based on a 3-bit operation code (OP). The module takes two 8-bit inputs, A and B, and, depending on the value of OP, computes the sum, difference, product, quotient, or modulus of these inputs, with the result output as an 8-bit value. If an unrecognized operation code is provided, the output is set to a high impedance state, indicating invalid operation.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input [2:0] OP,
    output reg [7:0] RESULT
);
