

You are tasked with designing a verilog module that takes in 2 input signals `A` and `B` and outputs the sum of the two signals. The module should also have a `carry_out` output signal that is high when there is a carry from the addition of the two signals. The module should be named `add_two_signals`.

You are given the following code snippet to use as a starting point:

```
module add_two_signals (
    input [3:0] A,
    input [3:0] B,
    output reg [3:0] sum,
    output reg carry_out
);

// Your code here

endmodule
```
