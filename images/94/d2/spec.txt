    up_down_counter

    CLK: Clock input
    RST: Active high reset signal

Output ports:
    count: 8-bit output representing the current count value

Implementation:
The up_down_counter module uses an always block to update the count value based on the clock signal, reset signal, and control signal.
The always block triggers on the positive edge of the clock signal (posedge CLK) or the positive edge of the reset signal (posedge RST). If the control signal is low, it decrements the count value.
