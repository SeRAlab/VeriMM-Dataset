
Design a 16-bit up/down counter that can count up or down based on an input signal. The counter should increment or decrement on the rising edge of a clock signal based on the value of the 'up_down' input signal. The counter should be reset to zero when the 'reset' signal is asserted. Additionally, implement a load functionality to load a specific value into the counter when the 'load' signal is asserted, using a 16-bit input value 'load_value'.
