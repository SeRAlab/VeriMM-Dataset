Design a module that behaviors as an interactive digital display system. The module utilizes five switches (SW4 to SW0) as input to select a number from 0 to 9, or displays an 'E' for an invalid input. It drives a 7-segment display (HEX0) to show the corresponding digit or 'E'. Additionally, it provides two outputs: LEDG lights up when SW0 is OFF (logical 0), and LEDR lights up when SW0 is ON (logical 1). The display updates on the rising edge of the clock signal (CLK).
module top_module(SW4, SW3, SW2, SW1, SW0, LEDG, LEDR, HEX0, CLK);
