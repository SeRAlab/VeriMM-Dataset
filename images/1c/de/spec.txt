
Design an 8-bit Digital-to-Analog Converter (DAC) module in Verilog that takes an 8-bit input and outputs a corresponding 8-bit analog value (simulated as an 8-bit output). The DAC should implement a simple linear conversion where the output value is equal to the input value. Additionally, include a 3-bit control signal that selects between different scaling factors (1x, 2x, 4x) applied to the input value before generating the output. The control signal will be 3 bits wide: '000' for 1x, '001' for 2x, and '010' for 4x scaling. Ensure that the output value does not exceed 8 bits.
