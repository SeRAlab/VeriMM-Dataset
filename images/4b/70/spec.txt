Design a 4-to-1 multiplexer that selects one of four 4-bit input data lines (in0, in1, in2, in3) based on the two select lines (sel0 and sel1). The output (out) will correspond to the selected input: when both select lines are high, output in3; when sel1 is high and sel0 is low, output in2; when sel1 is low and sel0 is high, output in1; and when both select lines are low, output in0.
module top_module(
    input [3:0] in0,
    input [3:0] in1,
    input [3:0] in2,
    input [3:0] in3,
    input sel0,
    input sel1,
    output [3:0] out
    );
