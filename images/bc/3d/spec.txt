Design a synchronous sequential state machine with 8 states that responds to inputs A and B. On a positive clock edge or reset, the machine transitions between states S0 to S3 based on the values of A and B while reverting to S0 when both inputs are high. The output C is asserted (set high) when the machine is in states S1 or S2, and it is low otherwise. The reset input initializes the state machine to state S0 and output C to low.
module top_module(
  input clk,
  input reset,
  input A,
  input B,
  output reg C
);
