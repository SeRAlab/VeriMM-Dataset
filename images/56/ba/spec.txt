Design a 4-bit shift register with both parallel and serial input capabilities. On the rising edge of the clock, if a non-zero parallel input is detected, the register is loaded with that value; otherwise, it shifts left and incorporates a new serial input bit. The output is the least significant bit of the register, providing the ability to read the shifted-out bit serially.
module top_module(
    input clk,
    input [3:0] parallel_in,
    input serial_in,
    output serial_out
);
