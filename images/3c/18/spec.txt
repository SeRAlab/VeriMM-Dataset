
Design a 2-bit divider that takes two 2-bit inputs, A and B, and produces a 2-bit output Q, which is the quotient of A divided by B. The output should be defined as follows:
- If B = 00, output should be 00 (to avoid division by zero).
- If B = 01, output should be A.
- If B = 10, output should be A/2 (integer division).
- If B = 11, output should be A/3 (integer division).
