
Design a 16-bit Digital-to-Analog Converter (DAC) system in Verilog. The DAC takes a 16-bit binary input and converts it to an 8-bit analog output. The output should be calibrated such that the output value ranges from 0 to 255 corresponding to the input value from 0 to 65535. The DAC should also include a feature to allow the user to select between two modes: normal and inverted mode. In normal mode, the output value is directly proportional to the input. In inverted mode, the output value is inversely proportional (255 - output).
