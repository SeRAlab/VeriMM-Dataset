Design a UART receiver module that converts incoming serial data into parallel data format. The module operates in several states: IDLE, START, DATA, and STOP. Upon detecting a start bit (when `rx` transitions from high to low), it synchronizes with a provided clock signal to sample the data bits, which are collected over a specified duration corresponding to the baud rate. The module stores the received bits in an 8-bit register and signals completion of the reception with `rx_done_tick` after all bits have been received and the stop bit has been detected. The parallel data can be accessed through the `dout` output.
module top_module(
	input wire        clk,
	input wire        reset,
	input wire        rx,
	input wire        s_tick,
	output reg        rx_done_tick,
	output wire [7:0] dout
);
