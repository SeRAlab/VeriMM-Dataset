
Design a JK latch using Verilog. The JK latch should have two inputs (J and K), one clock input (CLK), and one output (Q). The behavior should be as follows:
- If J = 1 and K = 0, Q should set to 1.
- If J = 0 and K = 1, Q should reset to 0.
- If J = 1 and K = 1, Q should toggle its current state.
- If J = 0 and K = 0, Q should maintain its current state.
