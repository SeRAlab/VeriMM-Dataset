Design an 8-bit DRAM cell that can perform the following operations: write data, read data, and reset the cell. The cell should have a data input (8 bits), a data output (8 bits), a write enable signal, a read enable signal, and a reset signal. When the reset signal is high, the cell should reset its stored value to zero. The write enable signal determines when the incoming data should be written into the cell, while the read enable signal allows for the data output to reflect the stored value when enabled.
