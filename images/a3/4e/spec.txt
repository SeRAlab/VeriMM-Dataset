    gray_code_counter

    clk: Clock signal used for synchronous operation.

Implementation:
The module includes a 3-bit register, count, which represents the current count.
The Gray code is derived from the count using the formula gray_code = count ^ (count >> 1).
The count register is updated in the always block, triggered on the positive edge of the clock signal (posedge clk) or the negative edge of the reset signal (negedge rst_n).
On reset, indicated by ~rst_n, the count register is cleared to 0.
The counter increments by 1 on each clock cycle, and the Gray code is updated accordingly.
