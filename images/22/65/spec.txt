Design a combinational logic circuit for Huffman encoding. The circuit should take a 4-bit binary input representing a character and output a 3-bit binary code corresponding to its Huffman encoding. The mapping is as follows:
- 0000 -> 00
- 0001 -> 01
- 0010 -> 10
- 0011 -> 110
- 0100 -> 111
- All other inputs should output '111' (not found in encoding).
The encoded values should be outputted as a 3-bit code.
