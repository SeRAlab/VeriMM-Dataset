Design a 32-bit wide, 2-to-1 multiplexer module. The module takes two 32-bit input signals, IN0 and IN1, and a single control signal, CTRL. When CTRL is low, the output OUT1 reflects the value of IN0; when CTRL is high, OUT1 takes the value of IN1. This is achieved by instantiating 32 individual 2-to-1 multiplexers, each handling one bit of the input signals and combining their results to form the complete 32-bit output.
