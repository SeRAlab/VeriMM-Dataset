Design an SR flip-flop in Verilog that has asynchronous set and reset inputs. The flip-flop should also include a clock input and output the current state of Q and its complement Qn. The following conditions must be met: when S=1 and R=0, Q should be set to 1; when S=0 and R=1, Q should be reset to 0; when both S and R are 0, Q should hold its last state; and when both S and R are 1, it is an invalid condition.
