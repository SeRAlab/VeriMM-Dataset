
Design a data forwarding unit that improves the performance of a simple CPU by forwarding data from the output of one pipeline stage to the input of another. The forwarding unit should take two input operands (A and B), a select signal (sel), and generate two output signals (forward_A and forward_B). The outputs should be determined by the select signal, where:
- If sel = 00, forward_A = A and forward_B = B
- If sel = 01, forward_A = 0 and forward_B = B
- If sel = 10, forward_A = A and forward_B = 0
- If sel = 11, forward_A = 0 and forward_B = 0
