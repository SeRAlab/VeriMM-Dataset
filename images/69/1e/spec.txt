When the enable signal (EN) is high and the 3-bit input (ABC) represents a value from 1 to 7, the corresponding output line from the 8-bit output (Y) is set high; otherwise, all outputs are low. The decoder effectively converts the binary input into a unique active output line, allowing for signal routing in digital circuits.

    input [2:0] ABC,
