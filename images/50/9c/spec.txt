Design a shift register that operates synchronously with a clock signal. This module accepts a 1-bit input data signal (d) and shifts it into an internal register, while also providing the most significant bit of the register as an output (q). The width of the shift register can be configured via the parameter `bitWidth`, which defaults to 8 bits. On every rising edge of the clock, the current contents of the register are shifted left by one bit, and the new input data is introduced at the least significant bit position.
