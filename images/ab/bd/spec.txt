Design a one-bit full adder circuit. This module takes three inputs: A, B, and a carry-in (CI), and produces a sum output (SUM) by performing a binary addition operation. Additionally, it generates a carry-out (COUT_N) signal, which is the negation of the carry output that indicates an overflow in the addition. The module also includes power and ground connections for proper operation.
module top_module(
    input A,
    input B,
    input CI,
    output reg SUM,
    output reg COUT_N,
    input VPB,
    input VPWR,
    input VGND,
    input VNB
);
