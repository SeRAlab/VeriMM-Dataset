Design a simple circuit that manipulates a 4-bit input to generate a 2-bit output. The output's first bit (O[0]) is set to LOW when the most significant bit of the input (I[3]) is HIGH, and HIGH when I[3] is LOW. Conversely, the second output bit (O[1]) is set to HIGH when I[3] is HIGH, and LOW when I[3] is LOW. This effectively inverts the most significant bit of the input to produce the two output bits.
module top_module(
    input  wire [3:0] I,
    output wire [1:0] O
);
