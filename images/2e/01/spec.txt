Design a 4-bit edge-triggered D Flip-Flop with asynchronous reset and enable. The flip-flop should have the following inputs: D (4-bit data input), CLK (clock input), RESET (asynchronous reset), and EN (enable input). The output should be Q (4-bit data output) which holds the value of D when CLK goes high, provided that EN is high and RESET is low. If RESET is high, Q should be set to 0 regardless of other inputs.
