
Design a simple sliding window protocol that simulates an acknowledgment (ACK) mechanism. The protocol will use a sender that can send a fixed number of packets (up to 'N'), and a receiver that sends ACKs back. The receiver is allowed to acknowledge packets only if they are in the range of the current window. The window size is defined by the parameter 'N'. The sender should not send packets if the window is full (i.e., if it has sent 'N' packets and has not received an ACK for the first packet in the window). Implement this functionality in Verilog.
