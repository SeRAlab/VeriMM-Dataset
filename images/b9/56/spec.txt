Design a synchronous up-counter that increments its count on each rising edge of the clock when the count input is high. The counter will reset to zero when the reset input is asserted. The counter's width is configurable through the parameter `Size`, which defaults to 8 bits. The output, `data_o`, holds the current count value.
module top_module(
   input wire clock,
   input wire reset,
   input wire count,
   output reg [(Size) - ('b1):0] data_o
);
