Design a 8-entry register file with 16-bit wide registers. The module allows two read operations specified by read address inputs (ra1 and ra2) and a write operation controlled by the write address (wa) and write data (wd). When the read address matches the zero register (3'b000), it outputs zero; otherwise, it retrieves the value from the corresponding register. The write operation occurs on the rising edge of the clock (clk) and is enabled when RegWrite is high, preventing writes to the zero register.
