
Design an 8-bit SRAM cell with read and write functionality. The SRAM cell should have the following inputs and outputs:
- Inputs: 
  - `data_in` (8 bits): Data to be written to the SRAM.
  - `addr` (3 bits): Address for the SRAM cell (0 to 7).
  - `we` (1 bit): Write enable signal (1 for write, 0 for read).
  - `clk` (1 bit): Clock signal for synchronous operation.
- Output:
  - `data_out` (8 bits): Data read from the SRAM cell.
