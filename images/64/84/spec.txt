Design a 4-to-1 multiplexer that selects one of four 8-bit wide input signals (A, B, C, D) based on a 2-bit select input (S). The output (Y) reflects the chosen input signal corresponding to the value of S, effectively routing the selected input to the output. If S is not valid, the output defaults to zero.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input [7:0] C,
    input [7:0] D,
    input [1:0] S,
    output reg [7:0] Y
    );
