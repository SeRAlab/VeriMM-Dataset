

You are tasked with designing a verilog module named `counter` that takes in a clock signal and an enable signal. The module should output a 4-bit binary value that increments by 1 every positive edge of the clock signal when the enable signal is high. When the enable signal is low, the counter should hold its current value. 

The module should have the following ports:

- `clk`: input clock signal
- `en`: input enable signal
- `out`: output 4-bit binary value

You should use a synchronous design approach for this problem.
