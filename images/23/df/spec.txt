
Design a Verilog module that implements a simple RRT (Rapidly-exploring Random Tree) algorithm core that generates a tree of points in a 2D space. The module should take an input point and a target point, and iteratively expand the tree by sampling random points in the space, connecting the new points to the nearest point in the tree. The output should be the new point added to the tree and a signal indicating a successful connection to the target point.
