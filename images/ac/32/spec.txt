Design a 3-to-8 decoder that activates one of the eight output lines (Y0 to Y7) based on the 3-bit input (A, B, C) when the enable signal (EN) is high. Each output corresponds to a unique combination of the inputs, with the active output being set to high while the others remain low. If the enable signal is low, all outputs are set to low, effectively disabling the decoder.
module top_module(
    input A, B, C, EN,
    output reg Y0, Y1, Y2, Y3, Y4, Y5, Y6, Y7
);
