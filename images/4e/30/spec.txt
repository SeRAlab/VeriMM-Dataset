Design a circuit that acts as a 2-to-1 data selector with bitwise inversion. The module takes an 8-bit input from one of two groups (In0-In3 or In4-In7) based on the Addr signal, and it outputs a 32-bit inverted value composed of the selected inputs. If Addr is 0, it outputs the inverted concatenation of In0 to In3; if Addr is 1, it outputs the inverted concatenation of In4 to In7.
module top_module(
	 input Addr,
    input [7:0] In0,
    input [7:0] In1,
    input [7:0] In2,
    input [7:0] In3,
	 input [7:0] In4,
    input [7:0] In5,
    input [7:0] In6,
    input [7:0] In7,
    output [31:0] DOut
    );
