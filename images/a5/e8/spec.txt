Design a program counter (PC) that updates its value based on a next program counter (NPC) input and control signals. When Reset is low, the PC initializes to the address 0x300, aligned to a 4-byte boundary. On each positive clock edge, if Reset is high and PCWr is asserted, the PC takes the value of the NPC; otherwise, it retains its current value. This module primarily facilitates the tracking of the next instruction address in a synchronous digital system.
