Design a 4-bit binary counter with reset and enable functionality. The counter increments on each rising edge of the clock when the enable signal is active. Upon reaching its maximum value (15 in decimal), it resets to zero and raises an overflow signal to indicate that it has wrapped around. The counter can be reset to zero asynchronously when the reset signal is active.
module top_module(
  input clk,
  input rst,
  input en,
  output reg [3:0] count,
  output reg overflow
);
