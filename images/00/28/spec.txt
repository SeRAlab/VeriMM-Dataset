
Design a 16-bit SRAM cell with the following functionalities:
- It should have a write enable signal (WE) to control writing to the memory.
- It should have a chip enable signal (CE) to activate the memory.
- It should accept a 16-bit data input (D) and a 4-bit address input (A) for write operations.
- It should output the stored data on a read operation when CE is active and WE is low.
