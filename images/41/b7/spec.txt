Design a combinational logic circuit that produces a single output, X, based on multiple input conditions. The circuit checks the states of inputs A1, A2, B1, C1, and D1 to determine the output: X is set to 1 if both A1 and A2 are high, or if A1 is low while A2 is high with B1 high and C1 low, or if D1 is high. X is set to 0 if A1 is high while A2 is low, or if A1 is low and A2 is high with B1 high and C1 high. This functionality allows for a complex decision-making process based on a combination of input signals.
module top_module(
    input  A1,
    input  A2,
    input  B1,
    input  C1,
    input  D1,
    output X
);
