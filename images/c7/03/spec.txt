

You have been tasked with designing a Verilog module that takes in a 4-bit input and outputs a 2-bit output. The output should be the sum of the first 2 bits of the input and the difference of the last 2 bits of the input. 

Design a Verilog module that implements this functionality. 

You should name your module `sum_diff` and it should have the following inputs and outputs:
- `input [3:0] a`: a 4-bit input
- `output [1:0] o`: a 2-bit output

You should use the following internal wires in your module:
- `wire [1:0] sum`: a 2-bit wire that represents the sum of the first 2 bits of the input
- `wire [1:0] diff`: a 2-bit wire that represents the difference of the last 2 bits of the input

You should implement your module using the following steps:
1. Create a wire `sum` that is the sum of the first 2 bits of the input.
2. Create a wire `diff` that is the difference of the last 2 bits of the input.
3. Assign the output `o` to be the concatenation of `sum` and `diff`.

Write a Verilog module that implements this functionality and name your module `sum_diff`.
