
Create a Verilog module for a simple linear voltage regulator. The module should take a 3-bit input representing the voltage level and output a regulated 2-bit voltage level. The mapping for the voltage levels is as follows:
- Input 000 -> Output 00 (0V)
- Input 001 -> Output 01 (1V)
- Input 010 -> Output 10 (2V)
- Input 011 -> Output 10 (2V)
- Input 100 -> Output 11 (3V)
- Input 101 -> Output 11 (3V)
- Input 110 -> Output 11 (3V)
- Input 111 -> Output 11 (3V)
