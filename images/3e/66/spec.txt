Design a simple SD card controller that manages the read and write operations. The controller has an input for a command indicating whether to read or write, a 16-bit data input for the data to write, a 16-bit data output for the data read, a clock input, and a reset input. The controller will output the data on the next clock cycle after a write command, and will output the data read from a simulated SD card for a read command after a delay of two clock cycles.
