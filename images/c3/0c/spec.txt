
You are tasked with designing a Verilog module for a 4-bit adder with the following interface:
- Two 4-bit inputs, A and B
- One 4-bit output, SUM
- One input, CIN, representing a carry-in bit
- One output, COUT, representing a carry-out bit

The module should implement the following logic:
- The SUM output should be the sum of A, B, and CIN
- The COUT output should be 1 if the sum of A, B, and CIN is greater than 9, and 0 otherwise

Design a Verilog module that meets these requirements.
