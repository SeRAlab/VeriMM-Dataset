Design a synchronous circuit that computes the sum of a 4-bit counter output and a 4-bit multiplexer output based on a select signal. The module features a synchronous active-high reset that clears the accumulated sum to zero. Upon each positive edge of the clock, the sum is updated; if the select input is high, the equivalent value from the multiplexer is added to the counter output, otherwise, zero is added. The result is stored in an 8-bit register and assigned to the output.
module top_module(
    input clk,
    input reset,      // Synchronous active-high reset
    input [3:0] counter_out,  // 4-bit output from the counter
    input [3:0] mux_out,  // 4-bit output from the multiplexer
    input select,     // Select input to choose between mux inputs
    output reg [7:0] out // 8-bit output from the functional module
);
