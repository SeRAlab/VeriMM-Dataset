Design a fractional-N Phase-Locked Loop (PLL) in Verilog that allows dynamic adjustment of the division ratio using a control signal. The PLL should lock onto an input frequency and generate an output frequency that is a fractional multiple of the input frequency. The division ratio can be modified through a 4-bit control signal, which allows for 16 different division values. The PLL should include a phase detector, a low-pass filter, and a voltage-controlled oscillator (VCO).
