Design a Verilog module that implements a simple TCP segmentation type classifier. The module will classify incoming packets based on the TCP flags and determine if the packet is a SYN, ACK, or DATA segment. The module should have a 3-bit input for the TCP flags and a 2-bit output indicating the type of segmentation: 00 for SYN, 01 for ACK, and 10 for DATA. If none of these types match, output 11.
