Design a 16-bit wide, 2-to-1 multiplexer. The output will select between two 16-bit inputs, in1 and in0, based on the value of the select signal (sel). When sel is high (1), the output will be in1; when sel is low (0), the output will be in0.
module top_module(
	input sel,
	input [15:0] in1,
	input [15:0] in0,
	output wire [15:0] out
);
