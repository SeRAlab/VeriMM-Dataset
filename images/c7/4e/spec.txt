

You are tasked to design a verilog module that takes in 3 inputs and 1 output. The inputs are A, B, and C, and the output is X. The module should implement the following logic:

- If A = 1, then X should be equal to B.
- If A = 0, then X should be equal to C.

You can assume that A, B, and C are all 1-bit inputs.

Design the verilog module that implements this logic.
