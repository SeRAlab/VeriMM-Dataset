
Design a simple sliding window protocol controller that manages the sending of packets. The controller should have the following inputs and outputs:
- Inputs:
  - clk: Clock signal
  - rst: Reset signal
  - send: Signal to initiate sending a packet
  - ack: Acknowledgment signal from the receiver
- Outputs:
  - current_window: The current window size (number of packets allowed to send)
  - packet_to_send: The packet number currently being sent
  - window_valid: Indicates if the current window is valid for sending
