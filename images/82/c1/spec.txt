Design a circuit that performs either addition or subtraction on two 4-bit inputs, A and B, based on the control signal SUB. When SUB is high, the circuit computes A - B - CIN and indicates a borrow condition, which occurs if A is less than the adjusted B. When SUB is low, it calculates A + B + CIN and flags a borrow if the sum overflows A or B. The operation is clocked, ensuring synchronization with an external clock signal CLK.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input CIN,
    input SUB,
    input CLK,
    output reg [3:0] SUM,
    output reg BORROW
);
