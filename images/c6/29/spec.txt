

You are tasked with designing a verilog module that implements a 4-bit synchronous counter. The counter should have a reset input, a clock input, and an output that represents the current count value. The counter should increment on every rising edge of the clock input, and should reset to 0 when the reset input is asserted. 

Design your module to be named "sync_counter" and have the following inputs and outputs:

Inputs:
- rst: a synchronous reset input
- clk: a clock input

Outputs:
- count: a 4-bit output representing the current count value
