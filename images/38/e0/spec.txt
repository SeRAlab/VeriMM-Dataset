
Design a simple decision tree inference module in Verilog. The module takes three binary inputs (A, B, C) and produces one binary output (Y) based on the following decision tree:
- If A is 1, then Y = 1
- If A is 0 and B is 1, then Y = 1
- If A is 0, B is 0, and C is 1, then Y = 0
- If A is 0, B is 0, and C is 0, then Y = 0
