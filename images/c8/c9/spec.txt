

You are tasked with designing a module in Verilog that takes three inputs, `a`, `b`, and `c`, each of which is a 1-bit signal, and produces a single output `out`, which is also a 1-bit signal. The module should implement the following logic:

- If `a` is 1, `out` should be 1
- If `a` is 0 and `b` is 1, `out` should be 1
- If `a` and `b` are both 0 and `c` is 1, `out` should be 1
- Otherwise, `out` should be 0

Your module should be named `logic_module` and should have the following interface:

```
module logic_module (
  input a,
  input b,
  input c,
  output out
);
```
