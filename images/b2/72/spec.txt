Design a register file that serves as a dual-port memory storage for 32 one-word (32-bit) registers. On each clock cycle, it outputs the value of the register indexed by rn1 to do1. If the write enable signal (we2) is low, it outputs the value of the register indexed by rn2 to do2; if we2 is high, it writes the input data (di2) to the register indexed by rn2 and outputs this same data through do2. This module allows simultaneous read and write operations on different registers for efficient data handling in digital systems.
