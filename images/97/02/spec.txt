Design a full adder circuit that computes the sum of three one-bit inputs: A, B, and CIN (carry input). The module outputs a one-bit SUM, which represents the least significant bit of the result, and a carry-out COUT, which indicates if there is a carry to the next higher bit. The logic utilizes XOR and wire interconnections to derive the SUM and COUT outputs based on the input values.
module top_module(
    input A,
    input B,
    input CIN,
    output SUM,
    output COUT
);
