
Design a PCIe endpoint controller that can handle requests for memory read and write operations. The controller should have the following inputs: `request` (a signal indicating a read or write operation), `address` (the address for the operation), `data_in` (the data to be written if it is a write operation), and `clk` (the clock signal). The controller should output `data_out` (the data read from memory) and `done` (a signal indicating the operation is complete). The memory should be emulated using a simple array. The controller should handle up to 8 addresses.
