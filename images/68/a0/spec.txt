Design a circuit that performs a nibble swapping operation on an 8-bit input. Upon receiving a clock pulse, if the reset signal is active, the output is initialized to zero. If reset is not active, the circuit rearranges the input bits by swapping the lower nibble (the least significant 4 bits) with the upper nibble (the most significant 4 bits), producing an 8-bit output.
module top_module(
  input clk,
  input reset,
  input [7:0] in,
  output reg [7:0] out
);
