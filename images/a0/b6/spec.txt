Design a 4-to-1 multiplexer that selects one of four 1-bit data inputs (D[0] to D[3]) based on a 2-bit select signal (S). The output (Y) corresponds to the selected data input: if S is 00, Y outputs D[0]; if S is 01, Y outputs D[1]; if S is 10, Y outputs D[2]; and if S is 11, Y outputs D[3].
module top_module(
    input [3:0] D,
    input [1:0] S,
    output Y
);
