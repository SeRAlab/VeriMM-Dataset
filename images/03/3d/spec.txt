
Design a 5-bit Johnson counter using Verilog. The counter should have a clock input and a reset input. On each clock edge, the counter should shift its state to the left and the inverted output of the last flip-flop should enter the first flip-flop. The counter should be reset to 0 when the reset signal is asserted. Provide the Verilog code for the counter and a testbench to validate its functionality.
