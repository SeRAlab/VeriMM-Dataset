Design a 3-to-1 multiplexer with a 2-bit select input, allowing it to choose one of three 16-bit wide data inputs—register (rg), memory (mem), or immediate value (imm)—to output. When opsource is 00, the output will be the value from rg; when opsource is 01, it will output from mem; when opsource is 10, it will output from imm; and for any other select value, the output will default to zero.
module top_module(opsource, rg, mem, imm, out);
