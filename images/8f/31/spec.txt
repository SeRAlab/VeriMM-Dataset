Design a linear weight memory module for a neural network, capable of storing and retrieving weights in a 10x10 array format. The module uses input signals to either write new weights (when the write enable signal `wt` is high and read enable `rd` is low) or read weights sequentially from the array (when `rd` is high and `wt` is low). Data outputs are provided for all ten weight rows, facilitating access to stored weights during the reading process. The design operates on a clock edge, ensuring synchronized data handling.
