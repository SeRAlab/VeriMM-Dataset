Design a PCIe endpoint state machine that transitions through the following states based on input signals: IDLE, CONFIG, DATA, and ERROR. The state transitions occur on the rising edge of the clock and depend on the input signal `start`, which triggers the transition from IDLE to CONFIG. The state should also transition to DATA on receiving `config_done`, and to ERROR if an `error` signal is high. The state machine should return to IDLE from ERROR or DATA based on a `reset` signal.
