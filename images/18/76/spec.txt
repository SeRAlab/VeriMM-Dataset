Design a 16-bit data bus multiplexer (MUX) that takes four 16-bit input data lines (A, B, C, D) and a 2-bit select line (S). The output (Y) should be one of the input lines selected by the select line. For example, if S is '00', Y should output A; if S is '01', Y should output B; if S is '10', Y should output C; and if S is '11', Y should output D.
