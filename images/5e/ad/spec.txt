Implement a Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state F (Y = 1).
2. state G (Y = 0).
3. state H (Y = 1).
4. state I (Y = 0).

State transitions:
1. From state F: If g = 0, then transition to state G. If g = 1, then transition to state H.
2. From state G: If g = 0, then transition to state I. If g = 1, then transition to state F.
3. From state H: If g = 0, then transition to state I. If g = 1, then transition to state G.
4. From state I: If g = 0, then transition to state H. If g = 1, then transition to state F.

Assume that you want to Implement the FSM using two flip-flops and state codes z[1:0] = 00, 01, 10, 11 for states F, G, H, I, respectively. Implement just the next-state logic for z[1] in Verilog. The output Y is z[1].
