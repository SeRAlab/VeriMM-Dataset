Design a data demultiplexer that handles data from an XADC (Analog-to-Digital Converter). It routes 16-bit data to two specific output channels based on the input channel signal. If the 'channel' is 5'h10, the data is stored in the xadc_vaux0_data output, and the associated ready flag (xadc_vaux0_ready) is asserted. If the 'channel' is 5'h18, the data is stored in the xadc_vaux8_data output, and its ready flag (xadc_vaux8_ready) is asserted. Both output registers are reset to zero when the reset signal is activated, ensuring clean initialization. The module synchronizes input data processing with a clock signal to ensure reliable data capture in a digital logic environment.
