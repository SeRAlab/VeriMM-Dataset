Design a simple 4-bit EEPROM cell that can store a 4-bit value. The cell has a write enable (`we`) signal, a 4-bit data input (`data_in`), and a 4-bit data output (`data_out`). When `we` is high, the value from `data_in` should be stored. When `we` is low, the output `data_out` should reflect the stored value.
