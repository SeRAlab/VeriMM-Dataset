Design a 4-bit adder-subtractor circuit with overflow detection. The module takes two 4-bit inputs, A and B, along with a control input C, which determines the operation: when C is 0, the circuit performs addition (A + B); when C is 1, it performs subtraction (A - B). The output S provides the result of the selected operation, while the OVF output indicates an overflow condition based on the signed interpretation of the results.
module top_module(
    A,
    B,
    C,
    S,
    OVF
);
