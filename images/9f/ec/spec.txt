Design a 4-to-1 multiplexer that selects one of four 4-bit wide input signals (A0, A1, A2, A3) based on two select lines (S0 and S1). The output (X) reflects the selected input signal, where S0 and S1 form a binary selection to choose among the inputs: when S1S0 is 00, output A0; 01 selects A1; 10 selects A2; and 11 selects A3.
module top_module(
    input [3:0] A0,
    input [3:0] A1,
    input [3:0] A2,
    input [3:0] A3,
    input S0,
    input S1,
    output reg [3:0] X
);
