Design a logic circuit that produces a single output based on the states of eight input signals. The output is determined primarily by the first two inputs; if either input1 or input2 is HIGH, output1 is set to HIGH. If both input1 and input2 are LOW, output1 is HIGH only if at least one of the remaining six input signals (input3 to input8) is HIGH. This functionality effectively combines elements of logical decision-making based on a priority scheme defined by the inputs.
module top_module(
    input input1,
    input input2,
    input input3,
    input input4,
    input input5,
    input input6,
    input input7,
    input input8,
    output output1
);
