
Create a Verilog module that performs 2x2 matrix inversion. The module takes a 2x2 matrix as input and outputs the inverted matrix. The formula for inverting a 2x2 matrix [[a, b], [c, d]] is given by:
```
inverse = (1/det) * [[d, -b], [-c, a]]
```
where `det = ad - bc`. The output should be valid only if the determinant is non-zero; otherwise, output zeros indicating that the matrix cannot be inverted.
