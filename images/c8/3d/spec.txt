

You have been tasked with designing a verilog module that adds two 3-bit numbers and stores the result in a register. The module should have the following inputs and outputs:

Inputs:
- A: a 3-bit input representing the first number to be added
- B: a 3-bit input representing the second number to be added
- CLK: a clock input
- RST: a reset input

Outputs:
- Q: a 3-bit output representing the sum of A and B, stored in a register

The module should perform the addition on the rising edge of the clock input and should hold the sum in the register until the next rising edge of the clock input. The module should also be able to reset the register to 0 using the RST input.

Write a verilog module that meets the requirements described above. Your solution should be contained within a single module and should not exceed 200 lines of code.
