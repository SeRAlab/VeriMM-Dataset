
Design a 16-bit ADC (Analog to Digital Converter) with the following specifications:
1. The ADC should have a 16-bit input data signal and a clock signal.
2. On every positive edge of the clock, the ADC should capture the input data and store it in an internal register.
3. The output of the ADC should be the value stored in the internal register.
4. There should be an enable signal that, when low, prevents the ADC from capturing new data and retains the current output.
