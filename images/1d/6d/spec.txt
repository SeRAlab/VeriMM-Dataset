Design a 16-bit DRAM cell that can store a single 16-bit value. The DRAM cell should have the following inputs: a 16-bit data input (D), a write enable signal (WE), and a clock signal (CLK). When WE is high, the value on the data input should be written to the cell on the rising edge of the clock. The current value of the DRAM cell should be available on a 16-bit data output (Q) at all times.
