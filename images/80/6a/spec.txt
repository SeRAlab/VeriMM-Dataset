Design a circuit that converts a 4-bit binary input (A) to a Binary-Coded Decimal (BCD) output. The module outputs two 4-bit registers: one (B) represents the tens place, and the other (C) represents the units place of the BCD representation. For inputs 0 to 9, B remains 0, and C reflects the input value; for inputs 10 to 15, B increments to 1 while C ranges from 0 to 7, effectively encoding the corresponding BCD values.
module top_module(
    input [3:0] A,
    output reg [3:0] B,
    output reg [3:0] C
);
