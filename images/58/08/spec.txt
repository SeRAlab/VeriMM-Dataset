Design a stack-based memory module that supports push and pop operations with a specified depth. The module includes a clock, reset, and control signals for push and pop actions. When the reset signal is activated, the stack pointer is initialized to zero. On the rising edge of the clock, if the push signal is active, the input data is stored at the current stack pointer location, and the pointer is incremented. Conversely, if the pop signal is asserted, the pointer is decremented, and the output reflects the value at the top of the stack before the pop operation. This design allows for dynamic data storage and retrieval in a Last In, First Out (LIFO) manner.
