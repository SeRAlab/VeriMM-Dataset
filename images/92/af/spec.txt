Design a 32-bit wide, 32-entry register file with single-read and single-write functionality. The module supports writing data to a specified register when the write enable signal is high, and allows reading data from a specified register, with the read value available on the output. The register file is synchronized with a clock signal and can be reset.
module top_module(
    rf_clock,

    rf_reset,

    rf_rd_addr_0,
    rf_rd_data_0,

    rf_wr_enable,
    rf_wr_addr,
    rf_wr_data
);
