Design an NVMe command processing module that takes a command signal (`cmd`), a command address (`addr`), and a command valid signal (`cmd_valid`). The module should store the command and address in internal registers when `cmd_valid` is high. When a `process` signal is asserted, the module should output the stored command and address, setting a `ready` signal high to indicate that the output is valid. Ensure that the internal registers are reset when a `reset` signal is asserted.
