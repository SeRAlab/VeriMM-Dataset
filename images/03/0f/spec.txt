Design a 24-bit digital-to-analog converter (DAC) that takes a 24-bit input and outputs a corresponding analog value. The DAC's output is represented as an integer value scaled to a maximum of 1,000,000 (for the maximum 24-bit value). The converter should include a mechanism to ensure the output does not exceed this maximum. The output must be a 32-bit value to allow for the full range of representation.
