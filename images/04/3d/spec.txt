
Design a simple Automatic Repeat reQuest (ARQ) system with error correction. The system should be able to send a 5-bit data word and receive an acknowledgment (ACK) or negative acknowledgment (NACK) based on a parity bit error-checking mechanism. If the received data has an even number of 1's, it is considered correct (ACK), otherwise, it's incorrect (NACK). The system should retry sending the data for up to 3 attempts before giving up.
