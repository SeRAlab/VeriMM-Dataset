Design an 8-bit ALU that can perform the following operations based on a 3-bit operation code (op): 
1. Addition (op = 3'b000)
2. Subtraction (op = 3'b001)
3. AND (op = 3'b010)
4. OR (op = 3'b011)
5. XOR (op = 3'b100)
The inputs A and B are 8-bit values. The ALU should output the result and a zero flag that indicates if the result is zero.
