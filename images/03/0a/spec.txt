
Design an 8-bit DRAM cell with the following behavior: 
- The DRAM cell should have an 8-bit data input (D), a single-bit write enable (WE), and a single-bit read enable (RE).
- When WE is high, the data on the input (D) should be written to the output (Q).
- When RE is high, the output (Q) should reflect the stored data.
- If both WE and RE are low, the output (Q) retains its previous value.
