
Design a Verilog module that implements a simple Kalman filter for sensor fusion. The module should take inputs of the estimated state, the measurement, and the process noise covariance. The output should be the updated state estimate after applying the Kalman filter equations. The Kalman filter equations to implement are as follows:
1. Predict the next state: \[ \hat{x}_{k|k-1} = F \hat{x}_{k-1|k-1} + B u_k \]
2. Compute the Kalman Gain: \[ K_k = P_{k|k-1} H^T (H P_{k|k-1} H^T + R)^{-1} \]
3. Update the state estimate: \[ \hat{x}_{k|k} = \hat{x}_{k|k-1} + K_k (z_k - H \hat{x}_{k|k-1}) \]
4. Update the error covariance: \[ P_{k|k} = (I - K_k H) P_{k|k-1} \]
Assume the matrices F, B, H, R, and the identity matrix I are constants defined in the module.
