Design an 8-bit Arithmetic Logic Unit (ALU) that can perform the following operations based on a 3-bit operation code (opcode):
0: Addition
1: Subtraction
2: Bitwise AND
3: Bitwise OR
4: Bitwise XOR
5: Bitwise NOT
6: Logical Shift Left
7: Logical Shift Right

The ALU should take two 8-bit inputs (A and B), an operation code (opcode), and output an 8-bit result. The ALU should also have a carry-out output for the addition and subtraction operations.
