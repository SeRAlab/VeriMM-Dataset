

Write a Verilog module that implements a 4-bit binary counter with asynchronous reset and load. The counter should increment on each rising edge of the clock signal and reset to 0 when the asynchronous reset input is asserted. Additionally, the counter should load a new value from the input data bus when the load input is asserted, and continue counting from that value.

The module should have the following inputs and outputs:

- `clk`: the clock signal (1-bit input)
- `rst`: the asynchronous reset signal (1-bit input)
- `load`: the load signal (1-bit input)
- `data`: the input data bus for loading a new value (4-bit input)
- `count`: the 4-bit output representing the current count value

Assume that the module is used in a larger system and that the inputs will be held constant for a sufficient amount of time for the counter to reach its maximum value.
