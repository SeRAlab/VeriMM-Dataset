

You are tasked with designing a verilog module that takes in a 32-bit input signal `data_in` and outputs a 16-bit signal `data_out`. The module should perform the following operations on the input signal:
1. If the first 8 bits of `data_in` are all 1's, set the first 4 bits of `data_out` to 1's and the last 12 bits to 0's.
2. If the last 8 bits of `data_in` are all 0's, set the last 4 bits of `data_out` to 1's and the first 12 bits to 0's.
3. If neither of the above conditions are met, set the first 8 bits of `data_out` to the first 8 bits of `data_in` and the last 8 bits of `data_out` to the last 8 bits of `data_in`.

Assume that the input signal `data_in` is always valid and that the output signal `data_out` should be updated on every positive edge of the clock signal `clk`.

Declare all input and output signals as `reg`.
