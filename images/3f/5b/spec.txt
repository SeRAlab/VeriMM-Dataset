Implement a simplified version of the A* search algorithm that takes a 5x5 grid with obstacles and returns the shortest path from the start position to the goal position. The grid is represented as a 25-bit input, where each bit indicates whether a cell is walkable (1) or an obstacle (0). The start position and goal position are represented as 5-bit inputs indicating the row-major index of the grid. The output should be a 25-bit path, where each bit indicates whether the corresponding cell is part of the path (1) or not (0).
