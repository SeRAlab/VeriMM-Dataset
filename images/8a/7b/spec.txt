Design a video system interface module that manages a small memory array with four 32-bit entries. It provides a way to write data to or read data from the specified memory addresses based on input signals. When selected via the `chipselect` signal, it allows writing data to the memory if `write_n` is low, or outputs the least significant 8 bits of the chosen memory address to `data_out` if `write_n` is high. The module employs positive edge clocking and asynchronous reset, initializing its state upon reset and handling data reads through the `readdata` output. The resulting `out_port` outputs the current 8-bit data value.
module top_module(
  input [1:0] address,
  input chipselect,
  input clk,
  input reset_n,
  input write_n,
  input [31:0] writedata,
  output reg [7:0] out_port,
  output reg [31:0] readdata
);
