Design a Verilog module that implements a simplified version of the MD5 hash function. The module should take a 512-bit input (message) and produce a 128-bit output (hash). The hash function must be capable of handling a single block of input and performing the necessary transformations. The hash should be initialized to a specific constant value (e.g., the MD5 initialization vector), and you should implement the core MD5 transformation steps including bitwise operations, modular addition, and rotation.
