Design a 4-key password management module that captures key inputs and stores them in one of four 4-bit wide password registers (pw0 to pw3). The behavior is controlled by a clock signal, reset, and a lock key. Upon system reset, the state is initialized, and when the module is locked, it reverts to the initial state. In each state, if the clear signal is activated, the respective password register is set to zero. Otherwise, if the lock key is not engaged, the module assigns the key value to the current active password register based on its state. The states are defined as state0, state1, state2, and state3, corresponding to the storage of each password register in a sequential manner.
module top_module(clk,reset,clear,lockkey,keyvalue,pw0,pw1,pw2,pw3);
