Design a finite state machine (FSM) for a CPU control unit that manages data sending based on an acknowledgment signal. The module has two states: in state 0, it does not send data; in state 1, it sends data while providing random output values. The state transitions occur on the rising edge of a clock signal, resetting to state 0 if a reset signal is active. The FSM transitions to state 1 when the ACK signal is low and returns to state 0 when ACK is high, enabling the outSEND_cpu signal to indicate when data is being sent.
