Design a Verilog code for an SR latch using D flip-flops. The SR latch should have two inputs, S (Set) and R (Reset), and two outputs, Q and Q_bar. The latch should behave such that when S is high, Q should be set to 1, and when R is high, Q should be reset to 0. If both S and R are low, Q should retain its previous state. If both S and R are high, the behavior is considered invalid.
