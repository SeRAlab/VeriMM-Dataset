Create a Verilog module for an 8-bit up/down counter with enable and synchronous clear. Assume positive clock/clk edge triggered. The counter should increment by 1 on each clock cycle when enable is high and direction is 1, decrement by 1 when direction is 0. When clear is high, the counter should reset to 0.

module up_down_counter_8bit_sync_clear (
  input clk,
  input clear,
  input enable,
  input direction,
  output reg [7:0] count
);
