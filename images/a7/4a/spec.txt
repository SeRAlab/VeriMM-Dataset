Given a 4-bit input (Num), the module outputs an 8-bit signal (Out) that corresponds to the visual representation of the decimal digits 0 through 9, as well as representations for digits A through F, suitable for driving a 7-segment display or similar indicator. Each output value is encoded to activate the appropriate segments of the display for the corresponding input value.
module top_module(
    input [3:0] Num,
    output [7:0] Out
    );
