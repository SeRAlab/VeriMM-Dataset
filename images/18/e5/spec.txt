Design a simple SR flip-flop using Verilog. The flip-flop should have inputs S (Set), R (Reset), and a clock signal C. The output Q should reflect the state of the flip-flop based on the inputs and the clock edge. If S is high and R is low, Q should be set to high. If R is high and S is low, Q should be reset to low. If both S and R are low, Q should retain its previous state. If both S and R are high, it should be considered as an invalid state and should maintain the previous value.
