Module name:  
    up_down_counter_4bit  

Input ports:
    clk: Chip clock signal.
    rst_n: Active-low reset signal. Defined as 0 for chip reset and 1 for reset signal inactive.
    up_dn: Control signal to determine counting direction.

Output ports:
    count: 4-bit count value.

Implementation:
On every positive edge of the clock signal (clk) or the falling edge of the reset signal (rst_n), the counter value is updated.
If the reset signal (rst_n) is low, indicating a reset condition, the counter value is set to 0.
If the up/down control signal (up_dn) is high, the counter increments by 1.
If the up/down control signal (up_dn) is low, the counter decrements by 1.
