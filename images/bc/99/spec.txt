Design a 4-bit adder/subtractor circuit that operates based on a mode control signal. The module takes two 4-bit inputs, A and B, and a single-bit MODE input to determine the operation: if MODE is high (1), the circuit performs the subtraction of B from A; if MODE is low (0), it performs the addition of A and B. The output consists of a 4-bit RESULT and two additional flags: COUT, which indicates a carry-out from the most significant bit, and BOUT, which indicates a borrow condition during subtraction.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input MODE,
  output [3:0] RESULT,
  output COUT,
  output BOUT
);
