Design a SR-latch using D flip-flops. The latch should have two inputs S (Set) and R (Reset) and two outputs Q and Q'. The behavior should be such that when S is high and R is low, Q should be set to 1; when S is low and R is high, Q should be reset to 0; when both S and R are low, Q should maintain its previous state; and it should not allow both S and R to be high at the same time.
