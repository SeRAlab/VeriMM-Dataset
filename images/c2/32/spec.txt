

You are tasked with designing a verilog module for a 4-to-1 multiplexer. The module should have four input signals, two select signals, and one output signal. The output signal should be the value of the input signal selected by the select signals. The truth table for the module is as follows:

| Select1 | Select0 | Input0 | Input1 | Input2 | Input3 | Output |
|---------|---------|--------|--------|--------|--------|--------|
|    0    |    0    |   X    |   X    |   X    |   X    |   X    |
|    0    |    1    |   I0   |   I1   |   X    |   X    |   Y    |
|    1    |    0    |   X    |   X    |   I2   |   I3   |   Y    |
|    1    |    1    |   X    |   X    |   X    |   X    |   X    |

Where X represents a don't care value.

Design a verilog module for the 4-to-1 multiplexer that meets the above requirements.
