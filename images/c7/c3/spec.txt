

You are tasked with designing a module that can be used to interface with the sky130_fd_sc_ls__a21bo_2 module. The module should have three inputs and one output. The inputs are A, B, and C, and the output is X. The module should perform the following logic:

- If A and B are both high, X should be high.
- If A and C are both high, X should be high.
- If B and C are both high, X should be high.
- If none of the above conditions are met, X should be low.

Your module should be named `interface_module` and should be written in Verilog. The module should be no more than 200 lines of code.
