Design a 4-channel DMA controller that allows for data transfer between memory and four different peripheral devices. The controller should have the following inputs: a clock signal (clk), a reset signal (reset), a start signal (start), a channel select (channel_sel), and data input (data_in). The outputs should indicate the current status of the transfer (transfer_done) and the data output (data_out) for the selected channel. The controller should handle transfers sequentially, giving priority to the lowest channel number first.
