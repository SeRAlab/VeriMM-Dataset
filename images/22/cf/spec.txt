Design an 8-channel DMA (Direct Memory Access) controller that transfers data from one memory region to another. The controller should consist of 8 channels, each capable of initiating a data transfer upon receiving a request signal. Each channel has a request signal (req), an acknowledge signal (ack), and a data bus (data). The DMA controller should use a round-robin arbitration scheme to handle requests from multiple channels. If a channel's request is acknowledged, it should transfer a block of data (8 bits) to the destination. The controller should also have a reset signal to initialize the state of the channels.
