Design a 4-bit up/down counter that increments or decrements its output based on the DIR input signal. The counter operates on the rising edge of the CLK signal and resets to zero when the RST signal is asserted high. When DIR is low, the counter counts up, while a high DIR signal causes it to count down.
module top_module(
    input CLK,
    input RST,
    input DIR,
    output reg [3:0] Q
);
