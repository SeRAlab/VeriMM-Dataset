Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs: 
1. state D (output 0).
2. state E (output 1).
3. state F (output 1).

State transitions:
1. From state D: If r = 0, then transition to state E. If r = 1, then transition to state F.
2. From state E: If r = 0, then transition to state D. If r = 1, then transition to state F.
3. From state F: If r = 0, then transition to state E. If r = 1, then transition to state D.

Resets into state D. For this part, assume that a one-hot code is used with the state assignment j[3:1] = 001, 010, 100 for states D, E, F, respectively.

Write Verilog for the next-state signals J2 and J3 corresponding to signal j[2] and j[3]. Derive the logic equations by inspection assuming a one-hot encoding.
