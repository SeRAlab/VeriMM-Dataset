Design a circuit that functions as a shader, iterating over an input array of 32 values. On each rising edge of the clock, it compares a 5-bit index `n` against these values, which determine the output for each corresponding bit in a 32-bit output register `rows`. When the value of `n` is less than the specific value in the input array, the corresponding bit in `rows` is set to HIGH; otherwise, it remains LOW. The reset signal ensures that `n` starts from 0, allowing for a controlled progression through the values on subsequent clock cycles.
module top_module(input clk,input rst_n,input [(32*5-1):0] values,output reg [31:0] rows);
