Implement a 16-bit barrel shifter that performs left or right shifting based on a 4-bit SHIFT input. On each clock cycle, if SHIFT is positive, the circuit shifts the input DIN left by the specified number of positions; if SHIFT is negative, it shifts DIN right by the absolute value of SHIFT. The output DOUT reflects the result of this shifting operation.
module top_module(
    input clk,
    input [15:0] DIN,
    input [3:0] SHIFT,
    output reg [15:0] DOUT
);
