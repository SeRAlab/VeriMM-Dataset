Design a parameterized n-bit wide comparator that compares two input signals, `in1` and `in2`. The module outputs a two-bit signal, `comp`, indicating the result of the comparison: `01` for `in1 < in2`, `10` for `in1 = in2`, and `11` for `in1 > in2`. The comparison logic is implemented using an always block that reacts to changes in the input signals.
module top_module(
  input [n-1:0] in1,
  input [n-1:0] in2,
  output reg [1:0] comp
);
