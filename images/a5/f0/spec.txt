Design a 2-to-1 multiplexer that selects between two 64-bit inputs, a and b, based on the CONTROL_ALUSRC signal. When CONTROL_ALUSRC is 0, the output will be equal to input a; when CONTROL_ALUSRC is 1, the output will reflect input b. The output is a 64-bit data signal, making it suitable for integration in an ALU (Arithmetic Logic Unit) design, where it can determine the source of an operand based on the control signal.
module top_module(
  input [63:0] a,
  input [63:0] b,
  input CONTROL_ALUSRC,
  output reg [63:0] out
);
