Implement the Verilog module based on the following description. Create a finite state machine that controls an elevator system. The elevator has three floors: Floor 1, Floor 2, and Floor 3. It can move up or down between these floors. The system has two inputs: up and down signals, which indicate the direction of the elevator movement. The elevator will move up when the up signal is 1, and move down when the down signal is 1. If both signals are 1 or both are 0, the elevator does not change its state. Use an asynchronous reset to set the elevator to Floor 1.
