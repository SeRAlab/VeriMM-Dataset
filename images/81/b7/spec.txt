Design a Verilog module that implements a 3-bit binary up-counter with an enable signal and asynchronous reset. The counter should increment on the rising edge of the clock if the enable (en) signal is high. The counter should reset to zero when the asynchronous reset (areset) is high. The counter value should be output to the "count" signal.

module small_up_counter
(
    input clk,
    input en,
    input areset,
    output reg [2:0] count
);
