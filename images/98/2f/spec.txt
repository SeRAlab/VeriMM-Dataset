Design a binary converter that transforms a 4-bit binary input (D) into a 3-bit output (Q). If the input value is less than or equal to 7 (4'b0111), the output will be the lower 3 bits of the input. For input values greater than 7, the output will be the result of subtracting 3 from the upper 2 bits of the input, effectively mapping the higher range of input values to a lower 3-bit representation.
module top_module(
    input [3:0] D,
    output [2:0] Q
);
