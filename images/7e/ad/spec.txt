Write a Verilog module for an 8-bit shift register with enable, synchronous reset, and shift right. Assume positive clock/clk edge triggered. When enable is low, the register holds its value. When reset is high, the register resets to 0. When enable is high, the register shifts its contents to the right by one bit.

module shift_register (
  input clk,
  input reset,
  input enable,
  input data_in,
  output reg [7:0] q
);
