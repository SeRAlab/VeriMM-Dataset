Design a 32-bit ripple carry adder that computes the sum of two 32-bit input values, A and B. The module produces a 32-bit output, C, representing the result of the addition. The carry-out for each bit is propagated to the next higher bit, allowing the addition to be performed sequentially from the least significant bit to the most significant bit. This structure reflects a straightforward implementation of binary addition through bit-wise XOR and AND operations for sum and carry, respectively.
module top_module(
    input [31:0] A,
    input [31:0] B,
    output [31:0] C
);
