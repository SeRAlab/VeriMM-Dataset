Design a Verilog module for an SR flip-flop with asynchronous reset. The flip-flop should change its output based on the inputs S (set) and R (reset) according to the following behavior: when S is high, Q should be set to 1; when R is high, Q should be reset to 0; if both S and R are low, Q should hold its current state. An asynchronous reset input should force Q to 0 regardless of S and R.
