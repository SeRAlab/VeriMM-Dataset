Design a synchronous memory module with a 32-bit word size and a depth of 32 words. This module features a reset input to initialize all memory contents to zero. Upon receiving a clock edge, it allows writing to its memory array when the write signal is asserted, storing the provided write data at the specified address. On the falling edge of the clock, it can read data from the same address into the output when the read signal is active. This functionality allows for read/write operations in a clock-driven manner, producing outputs based on address inputs, thereby functioning as a basic RAM.
