Design a 2-to-1 input multiplexer that selects between two 32-bit input data lines (a0 and a1) based on a 6-bit selection address (sel_addr). When sel_addr is set to 6'b110000, the multiplexer outputs a0; when sel_addr is set to 6'b110001, it outputs a1. The output y is a 32-bit signal reflecting the selected input based on the value of sel_addr.
