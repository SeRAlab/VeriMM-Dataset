Design an asynchronous finite state machine (FSM) that transitions between four states based on the input signal and produces a single-bit output. The FSM resets to state 00 when the reset signal is active. Depending on the current state and the value of the input signal `inp`, it transitions through the states as follows: from state 00 it can go to state 01 or 11; from state 01 it can transition to state 10 or 11; from state 10 it remains in state 10 if `inp` is high or goes to state 11 if `inp` is low; and state 11 is a sink state that remains unchanged. The output `outp` is asserted high (1) only when the FSM is in state 10, and is low (0) in all other states.
