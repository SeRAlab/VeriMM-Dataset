Design a synchronous RAM module optimized for FPGA implementation with 1-bit data width and 4-bit address space, supporting 16 memory locations. It includes a chip enable (ce0) signal for activation and a write enable (we0) signal for writing data (d0) to the specified address (addr0) on the rising edge of the clock (clk). When writing, the output (q0) reflects the new data; when reading, it outputs the data from the memory location addressed by addr0, provided ce0 is asserted.
