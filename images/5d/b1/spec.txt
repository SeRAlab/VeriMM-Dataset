Design a D-type flip-flop (DFF) with asynchronous set functionality. The output Q is initialized to a specified value (INIT) and updates on the rising edge of the clock (CLK). When the SET input is high, Q is set to logic HIGH regardless of the D input; otherwise, Q takes the value of D on the next clock edge. This design allows for both standard flip-flop behavior and the ability to asynchronously reset the output.
