Design a circuit that uses button inputs to drive an LED output based on a logical AND operation. The functionality consists of ANDing the first two buttons to produce a signal 'a' and ANDing the last two buttons to produce a signal 'b'. The output LED at position 1 is lit if both 'a' and 'b' are high, indicating that all four buttons are pressed simultaneously. The remaining LED outputs (0 and 2 to 5) are driven LOW, effectively showing only the result of the combined button activity at LED 1.
module top_module(
  input CLK_125MHZ_FPGA,
  input [3:0] BUTTONS,
  input [1:0] SWITCHES,
  output [5:0] LEDS
);
