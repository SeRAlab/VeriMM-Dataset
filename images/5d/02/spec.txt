Design a 4-bit Gray code counter that resets and starts counting when the enable (EN) signal is high. The output consists of four registers (Q0, Q1, Q2, Q3) representing the Gray code values derived from a 4-bit binary count. When EN is asserted, the counter initializes to zero and updates the outputs based on the Gray code logic derived from the binary count. If EN is low, the outputs retain their current values. This module is useful for applications requiring Gray code representation to minimize errors during transitions.
module top_module(
    input EN,
    output reg Q0,
    output reg Q1,
    output reg Q2,
    output reg Q3
);
