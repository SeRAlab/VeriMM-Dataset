Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state L (output 0).
2. state M (output 1).
3. state N (output 1).
4. state O (output 0).

State transitions:
1. From state L: If g = 1, then transition to state M. If g = 0, then transition to state O.
2. From state M: If g = 1, then transition to state N. If g = 0, then transition to state L.
3. From state N: If g = 1, then transition to state O. If g = 0, then transition to state L.
4. From state O: If g = 1, then transition to state M. If g = 0, then transition to state L.

Assume that a one-hot code is used with the state assignment y[3:0] = 0001(L), 0010(M), 0100(N), 1000(O)

Write a Verilog for the signal Y0, which is the input of state flip-flop y[0], for the signal Y1, which is the input of state flip-flop y[1]. Derive the Verilog by inspection assuming a one-hot encoding.

module top_module (
        input [3:0] y,
        input g,
        output reg Y0,
        output reg Y1);
