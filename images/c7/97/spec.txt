

You have been tasked with designing a verilog module for a 4-bit adder with carry-in and carry-out signals. The module should have the following inputs and outputs:

Inputs:
- `a`: a 4-bit binary number
- `b`: a 4-bit binary number
- `cin`: a carry-in signal

Outputs:
- `sum`: a 4-bit binary number representing the sum of a and b
- `cout`: a carry-out signal

You should use the following code snippet as a template for your module:

```
module four_bit_adder (
    input [3:0] a,
    input [3:0] b,
    input cin,
    output [3:0] sum,
    output cout
);

// your code here

endmodule
```

Your task is to complete the module by writing the verilog code for the 4-bit adder. You may use any combinational logic gates or other modules you deem necessary.
