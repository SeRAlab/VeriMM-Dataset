Design a circuit that functions as a 2-to-1 data selector based on a 2-bit control input (interruptor_sinc). Depending on the value of interruptor_sinc, the circuit outputs predefined 4-bit data values: when interruptor_sinc is '00', it outputs '0101'; when '01', it outputs '1010'; when '10', it outputs '1111'; and for any other value, it outputs the current address from direccion_actual. The selected data is provided at the output datos_por_escribir for further processing.
module top_module(input [1:0] interruptor_sinc,
		output [3:0] datos_por_escribir, input [3:0] direccion_actual
    );
