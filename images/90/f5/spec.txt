Design a digital calculator module that performs arithmetic operations on two 8-bit wide inputs, A and B. Based on a 2-bit select input, the circuit can execute addition, subtraction, multiplication, or division. The addition and subtraction operations are directly computed, while the multiplication uses a straightforward product. For the division operation, the module includes a check to handle division by zero by outputting zero if the denominator is zero. This module effectively implements a basic arithmetic logic unit (ALU) functionality for unsigned 8-bit integers.
module top_module(
  input [7:0] A,
  input [7:0] B,
  input [1:0] select,
  output reg [7:0] result
);
