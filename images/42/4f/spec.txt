Design a 4-bit synchronous adder with a reset functionality. On the rising edge of the clock signal (CLK), if the RESET_B input is low, the output SUM is set to zero. If RESET_B is high, the module computes the sum of the two 4-bit inputs A and B, updating the SUM output accordingly.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input RESET_B,
    input CLK,
    output reg [3:0] SUM
);
