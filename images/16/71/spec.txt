Design a JK flip-flop with asynchronous reset and preset inputs. The flip-flop should have inputs J, K, Clock, Reset, and Preset, and outputs Q and Qn. The behavior of the flip-flop should be defined as follows:
- On the rising edge of the Clock:
  - If Reset is high, Q should be reset to 0.
  - If Preset is high, Q should be set to 1.
  - If J and K are both 0, Q remains unchanged.
  - If J is 1 and K is 0, Q is set to 1.
  - If J is 0 and K is 1, Q is set to 0.
  - If J and K are both 1, Q toggles.
