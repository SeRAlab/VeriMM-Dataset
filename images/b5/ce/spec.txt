Design a synchronous circuit that captures a single-bit input signal and outputs it after one clock cycle. On the negative edge of the clock, the input signal (din) is sampled and stored in a flip-flop (din_flop). Subsequently, on the positive edge of the clock, the output (dout) is updated to reflect the value stored in din_flop, effectively delaying the input signal by one clock period. This design can be utilized for signal synchronization or timing adjustments in digital systems.

              input  din,
              output reg dout);
