The module provides three output signals: `greater_than`, which indicates if A is greater than B; `less_than`, which signifies if A is less than B; and `equal_to`, indicating if A is equal to B. Additionally, it includes a `valid` output that asserts true as long as the comparison is valid. This logic allows for comparison operations in digital systems, useful in applications such as sorting, data validation, and control logic.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output greater_than,
    output less_than,
    output equal_to,
    output valid
);
