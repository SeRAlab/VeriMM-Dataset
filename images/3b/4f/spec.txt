Design a 4-bit shift register that can perform left and right shifts. The shift register should have a serial input for shifting and a parallel load option. If the load signal is high, the 4-bit data will be loaded into the register. If the load signal is low, the shift direction can be controlled by a select signal: if select is 0, shift left; if select is 1, shift right. The output should be the current state of the shift register.
