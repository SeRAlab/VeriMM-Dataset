Design an 8-bit adder circuit with an enable and clear functionality. When the CLR input is asserted, the adder resets its output sum to zero. When EN is asserted and CLR is not active, the circuit adds two 8-bit inputs (A and B), while keeping track of carry-out through an additional bit in the sum. The sum output (S) provides the lower 8 bits of the result, and COUT indicates any carry generated from the addition, allowing for operations beyond 8-bit range.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input EN,
    input CLR,
    output [7:0] S,
    output COUT
);
