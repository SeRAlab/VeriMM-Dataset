Design a 3-bit ripple carry adder that computes the sum of two 3-bit inputs (A and B) along with a carry-in (Cin). The addition operation is synchronized to the positive edge of the clock, with the result being stored in the output register S and the carry-out (Cout) produced as a separate output. This module effectively performs multi-bit binary addition, propagating carries between each bit.
module top_module(
    input [2:0] A,
    input [2:0] B,
    input Cin,
    input clk,
    output reg [2:0] S,
    output reg Cout
);
