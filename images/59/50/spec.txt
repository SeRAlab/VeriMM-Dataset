Design a circuit that compares two n-bit signed integers, a and b, and outputs a signal indicating whether a is greater than b. The module utilizes a parameterized bit-width (n) for input signals, ensuring flexibility for different sizes. The comparison result is provided as a single output signal, greater, which is asserted when the first input is larger than the second.
module top_module(
  input [n-1:0] a,
  input [n-1:0] b,
  output greater
);
