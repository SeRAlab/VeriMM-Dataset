Design a 16-bit shift register with an adjustable starting value. The module takes a 4-bit address input (A0 through A3) that selects a specific bit from the 16-bit data register (initialized to a specified value via the parameter INIT). On each rising edge of the clock (CLK), if the clock enable (CE) signal is high, the register shifts its contents to the left by one bit, inserting the input data (D) into the least significant bit. The output (Q) provides the value of the bit at the selected address.
