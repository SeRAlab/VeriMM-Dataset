Design a Verilog module that implements a simple Logistic Regression unit. The module should take three 8-bit inputs (representing the features) and produce a single output bit (the prediction: 0 or 1). The logistic regression function can be represented by the equation: 
output = 1 / (1 + exp(-(w0*x0 + w1*x1 + w2*x2 + b))) >= 0.5
For simplicity, assume fixed weights and bias:
w0 = 1, w1 = 2, w2 = 3, b = -4, where x0, x1, and x2 are the inputs.
