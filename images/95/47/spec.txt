Design a synchronous SRAM (Static Random Access Memory) module with 256 addresses, each capable of storing 32-bit data. The module provides outputs based on a chip select signal; when CSram is high and the EscrMem signal is asserted, data at the specified address (Direc) is written into the memory. On the other hand, if the LeerMem signal is asserted, the module reads from the specified address and outputs the stored data (Dataout); otherwise, it outputs zero. This design facilitates both reading and writing operations controlled by external signals.
module top_module(clk,CSram,Direc,Datain,LeerMem,Dataout,EscrMem);
