Design a 2nd-order IIR filter using Verilog. The filter has two input coefficients (b0, b1, b2) and two output coefficients (a1, a2), and takes an input sample (x) to output a filtered sample (y). The filter is described by the difference equation: y[n] = b0*x[n] + b1*x[n-1] + b2*x[n-2] - a1*y[n-1] - a2*y[n-2]. The design should use registers to store past input and output samples.
