
Design a combinational logic circuit that implements a simplified version of the A* search algorithm. The circuit should take as input:
- A 4-bit value representing the current cost to reach a node (g(n)).
- A 4-bit value representing the heuristic estimate to reach the goal from that node (h(n)).
The output should be a 4-bit value representing the total estimated cost (f(n) = g(n) + h(n)) to reach the goal from the start node.
