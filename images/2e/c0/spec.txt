Design a 3-bit SR Flip-Flop with asynchronous reset and set functionality. The Flip-Flop should have two inputs (S and R) and one output (Q). It should also include an asynchronous reset (reset) that, when activated, sets Q to 0 regardless of S and R. Similarly, there should be an asynchronous set (set) input that sets Q to 1 regardless of S and R.
