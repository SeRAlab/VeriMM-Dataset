Design a 3-bit up/down counter with asynchronous reset and enable. The counter should increment or decrement its value on each clock cycle when the enable signal is active. Module name:  
    UpDownCounter               
Input ports:
    clk: Clock signal for synchronous operation.
    rst_n: Active-low reset signal. Defined as 0 for reset and 1 for reset signal inactive.
    en: Enable signal to allow counting.
    up_down: Signal to control the direction of counting. Defined as 1 for up counting and 0 for down counting.

Output ports:
    count: 3-bit output representing the current state of the counter.

Implementation:
Up/Down Counter:
The module includes a register count to hold the current state of the counter.
The always block triggers on the positive edge of the clock signal (posedge clk) or the negative edge of the reset signal (negedge rst_n).
On reset, indicated by !rst_n, the count register is cleared to 0.
If the enable signal is active, the count register increments by 1 if the up_down signal is 1, and decrements by 1 if the up_down signal is 0 on each clock cycle.
