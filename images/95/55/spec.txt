Please act as a professional Verilog designer.

Implement an 8-bit shift register with an enable signal. The shift register should shift its contents to the right on each positive edge of the clock signal when the enable signal is active. New data should be shifted in from the leftmost bit.

Module name:
    ShiftRegister

Input ports:
    clk: Clock signal used for synchronous operation.
    rst: Active-high reset signal. Defined as 1 for reset and 0 for reset signal inactive.
    en: Enable signal to allow shifting.
    data_in: Data input signal to be shifted in.

Output ports:
    q: 8-bit output signal representing the current state of the shift register.
