Design a flip-flop based register module for a CPU pipeline stage. This module captures and holds the instruction and program counter increment values (pcplus) during rising clock edges, allowing for controlled data flow between pipeline stages. When enabled, it updates its stored values with the inputs; when reset, it initializes the instruction to zero while holding pcplus constant. The outputs provide the stored instruction and pcplus for subsequent processing stages.
