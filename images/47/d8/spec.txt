Implement a 40-bit parallel-in, serial-out (PISO) shift register. The module captures a 40-bit input (Shifted) when enabled and shifts out each bit serially on the negative edge of the clock (Sclk) when the Frame signal is asserted. The operation can be reset with the Clear signal, which initializes the internal registers and counters. The output signal Serial_out provides the shifted data, and OutReady indicates when the data is ready to be read. The bit counting is managed with a bit_count register, ensuring all bits are transmitted before the output is disabled.
