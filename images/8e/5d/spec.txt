Design a 4-bit up/down counter that increments or decrements its count based on the control signals. The counter resets to zero when the "clear" signal is high, loads a specified 4-bit value from the "data" input when the "load" signal is asserted, increments the count when "up_down" is high, and decrements the count when "up_down" is low, all synchronized to the rising edge of the clock.
module top_module(
    input clk,
    input clear,
    input load,
    input up_down,
    input [3:0] data,
    output reg [3:0] count
);
