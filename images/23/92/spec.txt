Design a 4-bit DRAM cell that includes a data input, data output, a word line, and a bit line. The cell should be able to store 4 bits of data when the word line is activated (high) and should retain the data when the word line is inactive (low). The output should reflect the stored data when the word line is low, and the data should be written when the word line is high. Additionally, ensure that the cell does not change its state unless the word line is engaged.
