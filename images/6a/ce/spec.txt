Design a 16-bit Arithmetic Logic Unit (ALU) that performs various arithmetic and logical operations based on a 4-bit control signal (aluCtr). The ALU can execute subtraction, addition, bitwise AND, bitwise OR, NOR operations, and a comparison to check if the first input is less than the second. The result of the operation is provided as the output (aluRes), and the module also includes a zero flag that indicates whether the result equals zero after a subtraction operation.
module top_module( 
input [15:0] input1, 
input [15:0] input2, 
input [3:0] aluCtr, 
output reg[15:0] aluRes, 
output reg zero 
);
