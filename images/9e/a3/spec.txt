Implement the Verilog module based on the following description.
Create a module that implements an 8-bit shift register with synchronous reset. The shift direction is controlled by 'left' and 'right' inputs. When 'left' is high, the register shifts left. When 'right' is high, the register shifts right. The reset input is active high synchronous, and should set the output to 8'b00000000.
module shift_register(
	input clk,
	input reset,
	input left,
	input right,
	input [7:0] d_in,
	output reg [7:0] q);
