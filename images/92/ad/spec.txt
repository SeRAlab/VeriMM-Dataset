Design a four-input, one-bit wide multiplexer. The outputs will select one of the four inputs (A, B, C, or D) based on the state of the two selection lines (sel0 and sel1). When sel0 and sel1 are both 0, input A is selected; when sel0 is 1 and sel1 is 0, input B is selected; when sel0 is 0 and sel1 is 1, input C is selected; and when both sel0 and sel1 are 1, input D is chosen as the output Y.
module top_module(
    input A,
    input B,
    input C,
    input D,
    input sel0,
    input sel1,
    output Y
);
