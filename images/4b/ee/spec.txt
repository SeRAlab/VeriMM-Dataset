Design a Verilog module that implements a 8-bit synchronous clear register. The module should have an 8-bit input, a clock signal, a synchronous clear signal, and an 8-bit output. The output should be the input value if clear is not asserted, otherwise it should be zero on the rising edge of the clock.

module reg8bit_clear (
    input [7:0] data_in,
    input clk,
    input clear,
    output reg [7:0] data_out
);
