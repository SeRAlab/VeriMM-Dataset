

You are tasked with designing a verilog module for a D flip-flop with asynchronous reset. The module should have the following inputs and outputs:

- `clk`: a clock input
- `reset`: an asynchronous reset input
- `d`: a data input
- `q`: a data output
- `qn`: the complement of the data output

The module should have the following behavior:

- When `reset` is asserted, both `q` and `qn` should be set to 0.
- On the rising edge of `clk`, the value of `d` should be latched into `q` and `qn` should be the complement of `q`.

Write the verilog code for this module and simulate it using a testbench.
