
Design a Verilog module that implements a simple OFDM modulator. The module should take in a stream of binary data and modulate it using QPSK (Quadrature Phase Shift Keying). The output should be the I (In-phase) and Q (Quadrature) components of the modulated signal. The module should have a clock signal and a reset signal. The data input should be 2 bits, representing the QPSK symbols.
