Design a JK flip-flop with asynchronous reset and a clock enable input. The flip-flop should have two inputs (J and K), a clock input (CLK), an asynchronous reset input (RESET), and one output (Q). The behavior should be that on the rising edge of CLK, if RESET is high, Q should be set to 0. If RESET is low, the state of Q should toggle if J is high and K is low, remain unchanged if J and K are both low, and set to 1 if J is high and K is high.
