Design a 4-to-1 multiplexer that takes four single-bit inputs (A, B, C, D) and outputs one single-bit output (Y) based on a two-bit select signal (S). The output Y will be set to A when S is 00, B when S is 01, C when S is 10, and D when S is 11, effectively routing the selected input to the output based on the binary value of S.
module top_module(
    input A,
    input B,
    input C,
    input D,
    input [1:0] S,
    output Y
);
