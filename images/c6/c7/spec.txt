
You are tasked with designing a verilog module that takes in two 4-bit input signals, A and B, and outputs a 4-bit signal Y. The output Y should be the result of adding the two input signals. If the sum of the two input signals exceeds 15 (4'b1111), the output signal Y should be saturated at 15 (4'b1111). The module should be named "add_4bit_sat" and should contain the following ports:

- A: a 4-bit input signal
- B: a 4-bit input signal
- Y: a 4-bit output signal

You should use the following code snippet as a starting point for your module:

```
module add_4bit_sat (
    input [3:0] A,
    input [3:0] B,
    output reg [3:0] Y
);
    
endmodule
```
