Create a 16-bit LFSR (Linear Feedback Shift Register) that produces a pseudorandom sequence of bits. The LFSR should be implemented using the polynomial x^16 + x^14 + x^13 + x^11 + 1, and it should have a reset signal that initializes the register to a specific seed value. The LFSR should shift on each clock cycle and output the current state of the LFSR.
