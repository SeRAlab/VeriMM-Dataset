Design a combinational logic circuit that takes four single-bit binary inputs (A, B, C, D) and produces two outputs (X and Y). The output X is determined based on the value of A; if A is high (1), X is the logical AND of B and C; if A is low (0), X is the logical OR of B and C. The output Y is generated by taking the XOR of X with input D.
module top_module(
    input A,
    input B,
    input C,
    input D,
    output X,
    output Y
);
