Design a 4-to-1 multiplexer that selects one of four input lines (A, B, C, D) based on the values of two select lines (S0 and S1). When both select lines are LOW, output Y is the value of A; when S0 is HIGH and S1 is LOW, Y is the value of B; when S0 is LOW and S1 is HIGH, Y is the value of C; and when both select lines are HIGH, Y is the value of D.
module top_module(
    input A,
    input B,
    input C,
    input D,
    input S0,
    input S1,
    output Y
);
