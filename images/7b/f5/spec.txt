Design a synchronous D flip-flop with reset and scan capabilities. The module outputs the stored value Q, which is updated on the rising edge of the clock (CK). It has an active-low reset (RN) that forces Q to 0 when asserted. Additionally, when the scan enable (SE) is high, the flip-flop takes its input from the scan input (SI) instead of the standard data input (D), allowing for easy testing and debugging of the circuit.
