Design a 4-to-1 multiplexer that selects one of four input lines (A, B, C, or D) based on the values of two select lines (S0 and S1). The output (Y) reflects the value of the selected input, where S0 and S1 determine which input to route to the output: when both select lines are low, output A; when S1 is low and S0 is high, output B; when S1 is high and S0 is low, output C; and when both select lines are high, output D.
module top_module(
  input wire A,
  input wire B,
  input wire C,
  input wire D,
  input wire S0,
  input wire S1,
  output wire Y
);
