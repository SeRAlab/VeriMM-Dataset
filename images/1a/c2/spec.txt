
Design a synchronous SR flip-flop with active high set (S) and reset (R) inputs. The flip-flop should toggle its output (Q) based on the inputs S and R. When S is high, Q should be set to 1, and when R is high, Q should be reset to 0. If both S and R are low, the output Q should hold its previous state. Provide a clock input (clk) for synchronization.
