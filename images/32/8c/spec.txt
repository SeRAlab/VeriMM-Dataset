
Design a simplified version of the ChaCha20 stream cipher's quarter round function in Verilog. This function takes four 32-bit inputs (a, b, c, d) and produces four 32-bit outputs (a_out, b_out, c_out, d_out) based on the ChaCha20 quarter round operation defined as follows:
1. a += b; d ^= a; d <<<= 16;
2. c += d; b ^= c; b <<<= 12;
3. a += b; d ^= a; d <<<= 8;
4. c += d; b ^= c; b <<<= 7;

Implement this operation as a clocked process where inputs are latched on the rising edge of a clock.
