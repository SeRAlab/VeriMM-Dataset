A LIFO stack that supports push and pop operations with a specified depth. The stack should have an input for data to push, a control signal to indicate a push or pop operation, and a clock signal for operation. If the control signal indicates a push operation, the data should be added to the stack unless it is full. If it indicates a pop operation, the data should be removed from the stack unless it is empty. Additionally, provide an output signal to indicate the top of the stack.
