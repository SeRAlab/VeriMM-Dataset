Design a simple Kalman filter that estimates the state of a system. The Kalman filter should take as input the measured value (z), the previous estimate (x_prev), the process noise covariance (Q), the measurement noise covariance (R), and produce an updated state estimate (x_est) and the error covariance (P). The equations to implement are:
1. Kalman Gain: K = P / (P + R)
2. Update Estimate: x_est = x_prev + K * (z - x_prev)
3. Update Error Covariance: P = (1 - K) * P + Q
