Design a module that implements a simplified version of the SHA-256 transformation function. The module should take a 32-bit input and produce a 32-bit output. The SHA-256 transformation function involves bitwise operations (AND, OR, NOT, XOR) and right rotation. Implement the function such that it can be clocked, and the output is valid on the rising edge of the clock. The state of the module should include the input data, output data, and an enable signal to control when the transformation should occur.
