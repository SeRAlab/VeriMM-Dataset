Design a 4-to-1 multiplexer that selects one of four input signals (A, B, C, D) based on the values of two selection inputs (S0 and S1). The output Y reflects the chosen input, with S0 and S1 determining which input to pass through: when S0=0 and S1=0, output A; when S0=1 and S1=0, output B; when S0=0 and S1=1, output C; and when S0=1 and S1=1, output D.
module top_module(
    input A,
    input B,
    input C,
    input D,
    input S0,
    input S1,
    output Y
);
