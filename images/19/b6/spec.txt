
Design a Verilog module for a 16-QAM modulator that takes in a 4-bit input symbol and outputs a pair of 4-bit signals representing the I (in-phase) and Q (quadrature) components. The mapping for the 4-bit input to the I and Q outputs is as follows:

- 0000 -> I = 0000, Q = 0000
- 0001 -> I = 0000, Q = 0001
- 0010 -> I = 0001, Q = 0000
- 0011 -> I = 0001, Q = 0001
- 0100 -> I = 0000, Q = 0010
- 0101 -> I = 0001, Q = 0010
- 0110 -> I = 0010, Q = 0000
- 0111 -> I = 0010, Q = 0001
- 1000 -> I = 0010, Q = 0010
- 1001 -> I = 0011, Q = 0000
- 1010 -> I = 0011, Q = 0001
- 1011 -> I = 0011, Q = 0010
- 1100 -> I = 0000, Q = 0011
- 1101 -> I = 0001, Q = 0011
- 1110 -> I = 0010, Q = 0011
- 1111 -> I = 0011, Q = 0011
