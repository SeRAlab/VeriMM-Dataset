
Design a thermal sensor calibration module that takes in a raw sensor value and a calibration offset. The sensor value is a 10-bit input, and the calibration offset is a 4-bit input. The module should output a calibrated sensor value, which is the result of adding the raw sensor value and the calibration offset. The calibrated value should be a 10-bit output, and the module should have a clock and reset input to synchronize operations. On reset, the output should be zero.
