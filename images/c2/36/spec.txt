

You have been tasked with designing a verilog module for a 2-input buffer with a multi-cycle clock constraint. The module should have the following specifications:
- The module name should be INBUF_MCCC
- The module should have two input ports, PAD and CLK
- The module should have one output port, Y
- The module should have a parameter ACT_PIN that is a string and a parameter ACT_CONFIG that is a single bit
- The module should be a black box with the PAD port being the black box pad pin
- The module should be synthesized with a multi-cycle clock constraint

Write the verilog code for the INBUF_MCCC module that meets these specifications.
