Design a synchronous edge-triggered D-type latch with enable (E) and set (SE) control inputs. The output (Q) follows the clock (CK) input on the rising edge of the external clock (ECK) when the enable (E) is high and the set control (SE) is low. If the enable (E) is low, the latch holds its previous state but still captures the clock (CK) value on the rising edge of the external clock (ECK). When the set control (SE) is high, the output (Q) is set to logical high on the rising edge of ECK, overriding other conditions. This design integrates both edge-triggered behavior and asynchronous set functionality.
