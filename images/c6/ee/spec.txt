

You are tasked with designing a module that takes in 5 inputs and produces 1 output. The module should be named `five_to_one`. The inputs are as follows:

- `in1`: a 2-bit input
- `in2`: a 3-bit input
- `in3`: a 1-bit input
- `in4`: a 4-bit input
- `in5`: a 2-bit input

The output, `out1`, should be a 1-bit output.

The module should perform the following operation:

- If `in1` is greater than or equal to 2, set `out1` to 1.
- If `in2` is greater than or equal to 4, set `out1` to 1.
- If `in3` is 1, set `out1` to 1.
- If the sum of `in4` and `in5` is greater than or equal to 5, set `out1` to 1.

If none of these conditions are met, `out1` should be set to 0.

You should write the `five_to_one` module in Verilog.
