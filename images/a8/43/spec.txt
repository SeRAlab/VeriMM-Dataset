Design a synchronous 4-bit counter that increments its value on each rising edge of the clock signal. It has a reset input that sets the counter to zero when activated. The output of the counter is directly assigned to a 4-bit wide output representing the state of LEDs, effectively visualizing the current count on the LEDs.
module top_module(
    input clk,
    input rst,
    output reg [3:0] count,
    output reg [3:0] leds
);
