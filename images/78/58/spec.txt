Design a 4-bit adder/subtractor that can perform addition or subtraction based on the mode input. When the mode is set to 0, the module adds the 4-bit inputs A and B, and when the mode is set to 1, it subtracts B from A. The output includes a 4-bit sum and an additional carry/borrow signal which indicates if an overflow occurs during the operation.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input mode,
  output [3:0] sum,
  output carry_borrow
);
