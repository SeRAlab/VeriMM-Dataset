Design a simple 32-bit calculator that performs basic arithmetic operations. The module takes two 32-bit inputs (A and B) and a 2-bit operation selector (Op) that determines the operation. The operations include addition (Op=00), subtraction (Op=01), multiplication (Op=10), and division (Op=11), where the division also provides a special case to handle division by zero. The result of the chosen operation is output as a 32-bit value (C).
module top_module(
    input [31:0] A,
    input [31:0] B,
    input [1:0] Op,
    output reg [31:0] C  // Change wire to reg for output
);
