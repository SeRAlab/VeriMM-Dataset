Design a circuit that performs either addition or subtraction on two 4-bit inputs, A and B, based on a mode control signal. When the mode signal is high (1), the circuit outputs the sum of A and B; when the mode signal is low (0), it outputs the difference of A and B. The output is registered and updated on the positive edge of the clock signal.
module top_module(
    input clk,
    input [3:0] A,
    input [3:0] B,
    input mode,
    output reg [3:0] out
);
