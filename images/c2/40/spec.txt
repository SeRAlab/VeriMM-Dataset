

You have been tasked with designing a verilog module that implements a 4-bit shift register with parallel load. The module should have three inputs and one output:

- `clk`: a clock input
- `load`: a control input that loads the input data into the shift register when high
- `in`: a 4-bit input that is loaded into the shift register when `load` is high
- `out`: a 4-bit output that contains the current contents of the shift register

The shift register should shift its contents to the left on each clock cycle, with the most significant bit being lost and the least significant bit being shifted into a new position. When `load` is high, the contents of `in` should be loaded into the shift register and the shift register should stop shifting until `load` goes low again.

Write the verilog code for the shift register module.
