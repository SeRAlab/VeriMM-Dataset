Implement a Verilog module for a 3-bit binary up-down counter with enable and synchronous reset. The counter should have a clock input `clk`, a synchronous reset input `reset`, an enable input `en`, an up-down control input `up_down`, and a 3-bit output `count`. When `reset` is high, `count` should be set to 0. When `en` is high, if `up_down` is high, the counter should count up, otherwise it should count down on each rising edge of `clk`.

module up_down_counter(
	input wire clk,
	input wire reset,
	input wire en,
	input wire up_down,
	output reg [2:0] count
);
