Design a dual-port RAM module with 16 x 8-bit storage capacity. This module allows data to be written to the memory at a specified address (AW) when the write enable (WE) signal is active during the negative edge of the clock (clk). Additionally, it has two outputs: QW outputs the data at the write address AW, while QR outputs the data at a separate read address AR, allowing simultaneous read and write operations.
