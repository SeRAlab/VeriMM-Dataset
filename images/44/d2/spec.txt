Design a 4-bit shift register with load and shift capabilities. On the rising edge of the clock, if the reset signal is active, the register clears to zero. If the load signal is activated, the register loads the input data (data_in). If the shift signal is activated, the contents of the register are shifted right, with the most significant bit wrapping around to the least significant bit position. The output (data_out) reflects the current state of the register.
module top_module(
    input clk,
    input reset,
    input load,
    input shift,
    input [3:0] data_in,
    output [3:0] data_out
);
