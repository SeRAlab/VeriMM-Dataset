Design a 16-bit wide, 2-to-1 multiplexer. When the select signal is LOW (0), the output MuxOut will be equal to in1; when the select signal is HIGH (1), MuxOut will be equal to in2. The module effectively routes one of the two 16-bit input signals to the output based on the value of the select signal.
module top_module(input select, input [15:0]in1,in2, output [15:0]MuxOut);
