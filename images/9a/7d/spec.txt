Design a 4-to-16 line decoder with an enable signal. The decoder takes a 4-bit input and, when enabled (ena=1), activates one of the 16 output lines by driving it low (logic 0), while all other outputs remain high (logic 1). If the enable signal is not asserted (ena=0), all output lines are set high regardless of the input, effectively disabling the decoder's output.
module top_module(
    input [3:0] in,
    input ena,
    output reg [15:0] out
);
