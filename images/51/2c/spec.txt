Design a synchronous memory module featuring 4096 locations, each 16 bits wide. The module allows data to be written to memory when the write enable signal (wr_en) is active on the rising edge of the clock, writing the input data (data_in) to the specified address (addr). For read operations, when the read enable signal (rd_en) is asserted, it outputs the data stored at the specified address; if rd_en is not active, it outputs a default value of zero. This design implements a simple SRAM architecture that supports both read and write operations.
module top_module(
  input clk,
  input wr_en,
  input rd_en,
  input [11:0] addr,
  input [15:0] data_in,
  output [15:0] data_out
);
