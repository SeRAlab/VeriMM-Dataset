
Create a 2-channel DMA controller that allows two channels to transfer data from source to destination. The DMA controller should be able to select which channel is currently active and transfer data accordingly based on a control signal. The controller should have inputs for the source address, destination address, data to be transferred, a control signal to select the active channel, and a start signal to initiate the transfer. The controller should output the status of the transfer and be able to indicate when the transfer is complete.
