Design a 32-bit Linear Feedback Shift Register (LFSR) which generates pseudo-random numbers. The LFSR should use the polynomial x^32 + x^22 + x^21 + x^17 + 1 as its feedback polynomial. The design should have a clock input, a reset input, and a 32-bit output. The output should be the current state of the LFSR after each clock cycle.
