Design a circuit that converts RGB color values into a grayscale representation. The module takes three 12-bit inputs representing the red, green, and blue color intensities, computes their average using a combination of addition and division, and generates a 12-bit grayscale output. If the computed grayscale value can fit in a 12-bit representation, the output retains this value; otherwise, it saturates to a predefined maximum level (12'hff8).
module top_module(
  input [11:0] r,
  input [11:0] g,
  input [11:0] b,
  output [11:0] gray
  );
