
Create a Verilog module that performs a linear regression calculation. The module should take in two data points (x1, y1) and (x2, y2) as inputs and output the slope (m) and y-intercept (b) of the line that fits those two points using the formula:
m = (y2 - y1) / (x2 - x1)
b = y1 - m * x1
Provide appropriate handling for the case when x1 == x2 to avoid division by zero.
