Design a synchronous ROM (Read-Only Memory) block that outputs a 4-bit data value based on a 4-bit address input. On the rising edge of the clock, if the reset signal is asserted, the output is set to zero. Otherwise, it retrieves specific pre-defined values corresponding to the address: for address 0, output 3; for address 1, output 2; and for address 2, output 1. For any other address, it defaults to output 0.
