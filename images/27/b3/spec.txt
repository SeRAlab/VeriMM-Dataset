The problem is to design an interrupt controller that handles multiple interrupt requests and provides an output signal indicating which interrupt has been accepted. The controller has three interrupt request inputs (irq[2:0]), an interrupt acknowledge input (ack), and an output signal (int_out) that indicates the active interrupt. The controller should prioritize interrupts such that irq[0] has the highest priority, followed by irq[1], and then irq[2]. When an interrupt is acknowledged, the controller should reset the active interrupt until another interrupt is received.
