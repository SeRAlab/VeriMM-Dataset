Design a WiFi module status controller that manages the connection state based on input signals. The module has an input signal `connect` which indicates a request to connect to a WiFi network, an input signal `disconnect` which indicates a request to disconnect, and a clock signal `clk`. The current state of the connection must be represented by a 2-bit output `state`. The state should transition as follows: 00 (DISCONNECTED) → 01 (CONNECTING) → 10 (CONNECTED) → 11 (DISCONNECTING) and back to 00. The state should remain until a connect or disconnect request is received.
