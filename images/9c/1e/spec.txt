Design a D flip-flop with asynchronous set and clear inputs. The flip-flop captures the value of the D input on the rising edge of the CLK signal. If the SCD (Set Clear Deactivate) signal is high, the output Q is asynchronously cleared to 0. Conversely, if the SCE (Set Clear Enable) signal is high, the output Q is set to 1 asynchronously. Otherwise, the output follows the D input when the clock signal transitions.
module top_module(
    input CLK,
    input D,
    input SCD,
    input SCE,
    output reg Q
);
