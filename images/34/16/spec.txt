
Design an echo cancellation system that processes a digital audio signal. The system should have two inputs: the original audio signal (input_signal) and the echoed signal (echo_signal). The echo cancellation is implemented using a simple finite state machine (FSM) that adjusts the output based on a feedback mechanism. The output (canceled_signal) should be the result of subtracting the echoed signal from the original signal. The state machine should maintain a state that represents the feedback level and modifies the output accordingly.
