Design a configurable one-bit lookup table (LUT) that produces an output based on a single input signal I0. The behavior of the output LO is determined by the parameter INIT, which specifies the lookup values. If both bits of INIT are equal, the output LO is constant and determined by INIT[0]; otherwise, the output reflects the value defined in INIT corresponding to the state of I0. This allows for flexible logic implementations based on the parameterization of the INIT values.
