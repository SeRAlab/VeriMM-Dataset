Design a Verilog module that performs LU decomposition on a 2x2 matrix. The input to the module will be a 2x2 matrix represented as two 8-bit inputs (A and B) for the two rows of the matrix, and the output will be the two matrices L and U also represented as two 8-bit outputs (L and U) for each row. The matrix A is given as:  
A = | a11 a12 |  
    | a21 a22 |  
The output should be:  
L = | l11 0   |  
    | l21 l22 |  
U = | u11 u12 |  
    | 0   u22 |  
Where:  
l11 = a11,  
l21 = a21/a11,  
u11 = a11,  
u12 = a12,  
u22 = a22 - l21 * u12.
