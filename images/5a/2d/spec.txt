Design a D flip-flop with asynchronous set and reset capabilities. When the clock signal (CLK) experiences a rising edge, the flip-flop will capture the input data (D). If SET_B is asserted (active low), the output (Q) is set high regardless of the clock or data input. Conversely, if RESET_B is asserted (also active low), the output is set low. The complementary output (Q_N) is always the inverse of the main output (Q). This module is useful in applications requiring controlled data storage with the ability to override the stored value through reset and set operations.
