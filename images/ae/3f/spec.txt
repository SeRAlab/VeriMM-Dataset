Create a Verilog module for a simple FSM with three states (X, Y, Z) and one input signal (in). Use one-hot state encoding where X=3'b001, Y=3'b010, Z=3'b100. The FSM has an output signal (out) which is driven based on the current state and input.

The FSM has the following states and their corresponding outputs:
1. state X (out = ~in).
2. state Y (out = in).
3. state Z (out = 1).

State transitions:
1. From state X: If in = 1, then transition to state Y. If in = 0, then transition to state Z.
2. From state Y: If in = 0, then transition to state X. If in = 1, then transition to state Z.
3. From state Z: If in = 0, then transition to state Y. If in = 1, then transition to state X.

module fsm_3 (
  input in,
  input [2:0] state,
  output reg [2:0] next_state,
  output reg out);
