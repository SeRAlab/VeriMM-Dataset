Design a 4-bit binary adder circuit with carry input and output capabilities. This module takes two 4-bit binary inputs, A and B, along with a carry-in (Cin) signal. It performs the addition of these inputs and produces a 4-bit sum output (S) and a carry-out (Cout). The adder operates synchronously with a clock (Clk) and features a reset function that sets the sum and carry outputs to zero. The design ensures that the operation is resettable and allows for a clean initialization state. Careful handling of the carry-out logic is incorporated to account for possible overflow during the addition.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    input reset,
    input Clk,
    input Clk_180,
    output [3:0] S,
    output Cout
);
