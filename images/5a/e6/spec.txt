Design a combinational logic module that performs various bitwise operations on two 3-bit inputs, `a` and `b`. The module outputs the result of a bitwise XOR between `a` and `b`, along with the bitwise AND, XOR, and NOR results of the two inputs, each as 3-bit outputs. Additionally, it provides a 6-bit output containing the bitwise NOT of both inputs concatenated together. This design effectively implements a versatile bitwise operation unit for digital systems.
module top_module( 
    input [2:0] a,
    input [2:0] b,
    output out_xor,
    output [2:0] out_and_bitwise,
    output [2:0] out_xor_bitwise,
    output [2:0] out_nor_bitwise,
    output [5:0] out_not
);
