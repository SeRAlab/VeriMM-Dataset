
Create an SR flip-flop in Verilog that has asynchronous reset functionality. The SR flip-flop should have two inputs: S (Set) and R (Reset), and two outputs: Q (output) and Qn (inverted output). The flip-flop should only respond to the S and R inputs when the clock edge occurs. If R is asserted, Q should be reset to 0 regardless of the S input. If S is asserted and R is not, Q should be set to 1. If both S and R are low, the output should hold its previous state. The flip-flop should also have an active-low asynchronous reset input that resets the output to 0 immediately when asserted.
