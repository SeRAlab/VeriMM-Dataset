Implement the Verilog module based on the following description.
Create a module that implements a 16-bit shift register with a serial input. On each rising edge of the clock, the register shifts its contents to the left and the serial input bit is shifted in. The reset input is active high synchronous, and should set the register to 16'b0.
module shift_register(
	input clk,
	input reset,
	input serial_in,
	output reg [15:0] q);
