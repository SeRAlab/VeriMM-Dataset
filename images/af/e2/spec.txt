Implement a Verilog module for a 6-bit bi-directional shift register with synchronous reset and enable signals. The module should have an input clock signal (clk), an input enable signal (en), an input synchronous reset signal (rst), an input direction signal (dir), a 6-bit input parallel_data signal, and a 6-bit output signal (q). On the rising edge of the clock, if reset is high, q should be set to 6'b000000. If enable is high, the register should shift left if dir is high, otherwise it should shift right. If parallel_data is provided, it should load the data.
