

You are tasked with designing a verilog module that implements a combinational circuit that takes two 4-bit inputs `A` and `B`, and produces a 4-bit output `Y` based on the following rules:

- If `A` is greater than or equal to `B`, then `Y = A - B`.
- If `A` is less than `B`, then `Y = B - A`.

Implement the above rules using a single always block and assign the output `Y` to `0` if both `A` and `B` are equal.

Your module should have the following interface:

```verilog
module comparator(
  input [3:0] A,
  input [3:0] B,
  output reg [3:0] Y
);
```
