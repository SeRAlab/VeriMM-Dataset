
You are tasked with designing a combinational circuit that takes in four inputs, A1, A2, B1_N, and selects the output Y based on the following rules:
- If A1 and A2 are both high, Y should be high.
- If A1 is high and A2 is low, Y should be low.
- If A1 is low and A2 is high, Y should be low.
- If A1 and A2 are both low, Y should be high if and only if B1_N is high.

You must implement this circuit in a single module using Verilog. The module should have the following inputs and outputs:
- Input A1: a single bit representing the A1 input.
- Input A2: a single bit representing the A2 input.
- Input B1_N: a single bit representing the B1_N input.
- Output Y: a single bit representing the output of the circuit.

You may assume that all inputs are valid and will only be either high or low.

Your task is to write the Verilog code for this module, ensuring that it is correct and meets the given specifications.
