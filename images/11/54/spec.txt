Design a Verilog model for a Low Dropout Regulator (LDO) that takes an input voltage (Vin), a control signal (Vctrl), and produces an output voltage (Vout) based on the following conditions: If Vctrl is high, Vout should be equal to Vin minus a fixed dropout voltage (Vdrop). If Vctrl is low, Vout should be zero. Assume Vdrop is 1V for the design.
