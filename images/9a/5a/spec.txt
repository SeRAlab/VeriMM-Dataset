Design a module that manages a SHA (Secure Hash Algorithm) processing unit. It interfaces with external inputs and outputs, handling a 256-bit message input (p_mosi) and producing a 256-bit digest output (p_miso). The module signals various control flags for the SHA operation: it generates a reset signal (sha_reset_n) based on the validity of incoming data (p_valid), initializes the SHA process (sha_init) when a valid input transition occurs, and defines a fixed mode and block for the SHA operation. The sha_block outputs a concatenated value of the input data, facilitating the SHA hashing process. The internal logic utilizes registered state to track previous validity states, ensuring proper sequencing of SHA operations on clock cycles.
