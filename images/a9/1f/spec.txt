Design a 3-bit binary counter that increments its count on the rising edge of the clock when the enable signal is asserted. If the reset signal is activated, the counter resets its output to zero. This module effectively tracks and counts clock pulses, providing an output that represents the current count value in binary format.
module top_module(
    input clk,
    input reset,
    input enable,
    output reg [2:0] count
);
