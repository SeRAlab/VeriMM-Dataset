Design a circuit that performs a three-input XOR operation. The module takes three single-bit inputs (A, B, and C) and outputs a single bit (X) that represents the logical XOR of these inputs. The output is high when an odd number of inputs (either one or three) are high, and low when all inputs are low or when two inputs are high. The implementation uses AND gates to generate intermediate signals for pairs of inputs, OR gates to combine these signals, and a NOT gate to achieve the correct XOR function.
module top_module(
    input A,
    input B,
    input C,
    output X
);
