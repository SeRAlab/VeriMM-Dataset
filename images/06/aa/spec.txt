
Create a Verilog module that implements a simple PID controller. The PID controller should take a setpoint and a measured value as inputs and produce an output that represents the control signal. The PID constants (Kp, Ki, Kd) should be parameters of the module. The output should be updated on every clock cycle based on the current error, integral of the error, and derivative of the error. The integral term should have a simple reset mechanism.
