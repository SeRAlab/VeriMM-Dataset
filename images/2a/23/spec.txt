
Design a Verilog module for a simple Bluetooth state machine with three states: IDLE, CONNECTING, and CONNECTED. The state machine should transition between states based on two inputs: `start_connection` and `connection_success`. The state transitions are defined as follows:
- From IDLE to CONNECTING when `start_connection` is high.
- From CONNECTING to CONNECTED when `connection_success` is high.
- From CONNECTED to IDLE when `start_connection` is low.
- Remain in the current state if the inputs do not trigger a transition.
Implement the state machine using a clock and reset signal.
