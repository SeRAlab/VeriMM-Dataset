Design a simple packet filtering module that checks if a packet meets certain filtering criteria. The packet has a 16-bit source address (src_addr) and a 16-bit destination address (dest_addr). The filtering criteria are defined by two 16-bit registers: allowed_src_addr and allowed_dest_addr. The module outputs a single bit (allow) indicating whether the packet is allowed (1) or blocked (0). The packet is allowed if both the source address and destination address match the allowed addresses.
