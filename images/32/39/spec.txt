
Design a Parallel-in Serial-out (PISO) shift register in Verilog. The PISO shift register should have the following features:
- An input data width of 5 bits.
- A parallel load enable signal (load) that when asserted, loads the input data into the register.
- A clock signal (clk) that shifts out the data serially when the load signal is not asserted.
- An output signal (serial_out) that outputs the data serially one bit at a time on the rising edge of the clock after the data has been loaded.
- A control signal (shift) that determines whether the register should shift out the data or load new data.
