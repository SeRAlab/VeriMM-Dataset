Implement a binary to Gray code converter. On each rising edge of the clock, the module takes a 4-bit binary input and produces a corresponding 4-bit Gray code output. The output bits are generated by applying the XOR operation between the current and previous bits of the binary input. This design effectively converts the binary value into its equivalent Gray code representation.
module top_module(
  input clk,
  input [3:0] bin_in,
  output reg [3:0] gray_out
);
