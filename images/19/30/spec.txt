
Design a 1-bit SRAM cell using Verilog. The SRAM cell should have the following features:
- One data input (D) for writing data
- One data output (Q) for reading data
- One write enable (WE) signal to control when data is written
- One chip enable (CE) signal to control when the cell is active
- The SRAM cell should be able to hold its state when not being written to.
