Design a half-wave rectifier circuit using a diode. The circuit takes a signal input (DIODE) and power supplies (VPWR and VGND) to produce a RECTIFIED_SIGNAL output. When the DIODE input is high, the output will reflect the DIODE input; otherwise, it will produce a low output, effectively allowing only one polarity of the input signal to pass through while blocking the other.
module top_module(
    input DIODE,
    input VPWR,
    input VGND,
    output reg RECTIFIED_SIGNAL
);
