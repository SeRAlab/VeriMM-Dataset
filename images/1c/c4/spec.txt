
Design a Verilog module that implements a simple Run-Length Encoding (RLE) encoder. The module should take a stream of binary data (1 bit wide) and compress it into a run-length encoded format. The output should consist of pairs of (count, value) where 'count' is the number of consecutive bits (0s or 1s) and 'value' is the bit itself. The module should handle a sequence of up to 256 bits. It should have a clock input and a reset input to initialize the state.
