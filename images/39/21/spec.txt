Design a simple Network Address Translation (NAT) module that translates a private IP address to a public IP address. The module should have inputs for the private IP address (32 bits), a NAT rule (which maps private IPs to public IPs), and a clock signal. The output should be the public IP address based on the NAT rule. The NAT rule can be a simple 32-bit value that indicates the public IP. The module should update the public IP output on the rising edge of the clock whenever the private IP input changes.
