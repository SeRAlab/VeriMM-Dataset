Design a 16-bit SRAM cell with read and write capabilities. The SRAM cell should have the following inputs:  
- clk (clock signal)  
- we (write enable signal)  
- addr (4-bit address input)  
- din (16-bit data input)  
The outputs should be:  
- dout (16-bit data output)  
The cell should store data when we is high, and output the stored data at the address specified by addr when we is low.
