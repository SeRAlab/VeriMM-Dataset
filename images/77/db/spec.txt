Design a configurable shift register that can shift its contents either left or right based on the `dir` input signal. It takes a `n`-bit input and has an `m`-bit output. When the `shift` signal is asserted, the contents of the register shift in the specified direction, with the `in` value being inserted into the shift register from the appropriate end. The output is taken from the lower `m` bits of the shift register.
module top_module(
  input [n-1:0] in,
  input shift,
  input dir,
  output [m-1:0] out
);
