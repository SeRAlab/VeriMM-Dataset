Implement a 2nd-order IIR filter in Verilog. The filter should take a 16-bit signed input and produce a 16-bit signed output. The IIR filter should use fixed coefficients for simplicity, and the output should be based on the previous two inputs and the previous two outputs. The coefficients can be hardcoded as follows: a1 = 0.5, a2 = 0.25, b0 = 1.0, b1 = -0.5, b2 = 0.25. The output should be rounded to 16 bits.
