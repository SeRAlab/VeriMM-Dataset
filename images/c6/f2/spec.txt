

You are tasked with designing a clock gating module in Verilog that will be used in a larger ASIC design. The module should take in a clock signal (`CLK`), an enable signal (`EN`), and a test enable signal (`TE`). The module should output a gated clock signal (`ENCLK`), which is a version of the `CLK` signal that is only enabled when `EN` and `TE` are both high. 

Your task is to implement this clock gating module in Verilog. Your module should be named `clock_gate_module` and should have the following input and output ports:

- `CLK` (1-bit input): the clock signal
- `EN` (1-bit input): the enable signal
- `TE` (1-bit input): the test enable signal
- `ENCLK` (1-bit output): the gated clock signal

Assume that all input signals are synchronous to the same clock domain, and that `ENCLK` is also synchronous to this clock domain.
