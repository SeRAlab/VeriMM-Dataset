Design a simple Model Predictive Control (MPC) based finite state machine (FSM) that changes its state based on the input values from a sensor. The FSM has three states: IDLE, RUN, and STOP. The control logic should determine the next state based on the current state and an input signal. The FSM transitions from IDLE to RUN when the input signal is high, from RUN to STOP when the input signal is low, and from STOP back to IDLE when the input signal is high. The output should indicate the current state of the FSM.
