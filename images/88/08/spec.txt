Implement a Verilog module for a binary counter with three states: Idle, Counting, and Done. Use the following one-hot state encoding: IDLE=3'b001, COUNTING=3'b010, DONE=3'b100. The counter should count up to a specified limit and then move to the Done state. Derive state transition and output logic equations by inspection assuming a one-hot encoding. Implement only the state transition logic and output logic (the combinational logic portion) for this state machine.

module binary_counter (
  input clk, 
  input reset, 
  input [3:0] limit, 
  input [2:0] state, 
  output reg [2:0] next_state, 
  output reg [3:0] count, 
  output reg done);
