Create a 16-bit shift register with the following functionalities:  
1. On a rising clock edge, if the `shift_enable` signal is high, shift the register right by one position, with the least significant bit (LSB) being filled with the `data_in` signal.  
2. If `load_enable` is high, load the `data_in` signal directly into the register instead of shifting.  
3. The register should also provide a synchronous reset that clears all bits to 0 when the `reset` signal is high.
