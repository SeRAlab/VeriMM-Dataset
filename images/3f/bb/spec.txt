Design a JK latch using Verilog. The JK latch should have inputs J, K, and enable (E) and outputs Q and Qn (not Q). The latch should only change its output state when enable is high. If J and K are both low, the output should remain in its previous state. If J is high and K is low, the output should be set (Q=1). If J is low and K is high, the output should be reset (Q=0). If both J and K are high, the output should toggle.
