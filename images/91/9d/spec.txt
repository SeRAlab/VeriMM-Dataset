Design a circuit that implements a multifunctional logic block. It outputs a result based on the value of input 'a': if 'a' is HIGH, the output is the result of a 2-input AND operation between inputs 'b' and 'c'; if 'a' is LOW, the output is derived from a 5-input OR operation on inputs 'd', 'e', 'f', 'g', and 'h'.
module top_module(
  input a,
  input b,
  input c,
  input d,
  input e,
  input f,
  input g,
  input h,
  output out
);
