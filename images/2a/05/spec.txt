
Design a deadbeat controller in Verilog that takes a 4-bit binary input value and generates a control signal. The controller should aim to bring the output to a desired value in a fixed number of clock cycles (for this case, 4 clock cycles). The control signal should be calculated based on a simple proportional control strategy, where the control signal sharply responds to the input to minimize the error in the output to reach the desired state. Your controller should also include a reset functionality to initialize the state.
