Design a finite state machine (FSM) for a Bluetooth module that has three states: IDLE, CONNECTING, and CONNECTED. The FSM transitions between states based on the following inputs: `start` (to begin connecting) and `disconnect` (to disconnect). The output should indicate the current state as a 2-bit binary value: 00 for IDLE, 01 for CONNECTING, and 10 for CONNECTED. The state should remain in the current state if no valid transition occurs.
