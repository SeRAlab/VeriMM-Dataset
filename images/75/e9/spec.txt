Design a D flip-flop with an active-low asynchronous reset. When the RESET_B signal is low, the output Q will be set to 0 and Q_B will be set to 1, regardless of the CLK or D input. On the rising edge of the CLK, if RESET_B is high, the output Q takes the value of the D input, while Q_B provides the complemented output of Q.
module top_module(
    input D,
    input RESET_B,
    input CLK,
    output reg Q,
    output reg Q_B
);
