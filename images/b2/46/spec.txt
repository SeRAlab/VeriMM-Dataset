Implement the Verilog module based on the following description.
We want to create a module that:

// (1) receives a 6-bit binary number,
// (2) outputs the reverse of the bits on 'reversed[5:0]',
// (3) provides a reset mechanism to reset the output.

// The input binary number is available on the input signal 'binary_num'. The reset signal is active high synchronous.

module reverse_bits_module(
    input wire clk,
    input wire reset,
    input wire [5:0] binary_num,
    output reg [5:0] reversed
);
