Design a circuit that functions as an edge detector for a digital signal. The module detects rising and falling edges of the input signal, `semnal`, by monitoring transitions between its current and previous states. When a rising edge is detected, the `pos_detected` output is asserted high, and when a falling edge occurs, the `neg_detected` output is asserted high. The circuit is reset by the `rst` signal, which initializes the internal state.
module top_module(
                     input clock,
                     input rst,
                     input semnal,                     
                     output pos_detected,
                     output neg_detected                     
                     );
