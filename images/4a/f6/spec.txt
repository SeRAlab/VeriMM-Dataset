Design a circular shift register, or ring counter, that operates based on a clock signal. It has a parameterizable width, defined by the parameter `n`, which determines the number of output bits. On each rising edge of the clock, the least significant bit of the current state is shifted to the most significant bit position. The output reflects the current state of the counter, continuously cycling through a sequence of states that corresponds to shifting the bits in a circular manner.

  input clk,
  output reg [n-1:0] out
