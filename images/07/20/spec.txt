
Design a PCIe endpoint controller that handles read and write requests. The controller should have the following inputs: clock, reset, read_request, write_request, and data_in. The outputs should be: read_ready, write_ready, and data_out. The controller should toggle the read_ready and write_ready signals based on the requests and should store the input data for a write operation. It should also provide the data for a read operation when requested.
