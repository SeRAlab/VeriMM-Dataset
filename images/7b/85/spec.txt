Design a 4-to-1 multiplexer that selects one of four single-bit inputs (a, b, c, d) based on a 2-bit select signal (sel). The output (y) reflects the selected input: when sel is 00, output a; when sel is 01, output b; when sel is 10, output c; and when sel is 11, output d. If an invalid state occurs, the default selection also outputs a.
module top_module(
    input [1:0] sel,
    input a,
    input b,
    input c,
    input d,
    output reg y
    );
