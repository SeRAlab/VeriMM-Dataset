Design a 32-bit data bus controller that performs the following functionality: 
1. It has a 32-bit input data bus.
2. It has a 1-bit control signal that indicates when the data is valid (1) or invalid (0).
3. When the control signal is high, the data is latched into a register.
4. The output should be the latched data when the control signal is high, and it should output zero when the control signal is low.
