Design a 24-bit ADC controller that takes a 24-bit digital input from an ADC and converts it into two 12-bit outputs. The first 12 bits should be the upper part of the input, and the second 12 bits should be the lower part of the input. The controller should have a clock input and a reset input. On each rising edge of the clock, if reset is not asserted, the outputs should update with the corresponding bits from the ADC input.
