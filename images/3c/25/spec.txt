
Design a simple EEPROM memory cell in Verilog that can store 1 bit of data. The cell should have the following operations:
1. Write: Set the cell's value to a given input bit when a write enable signal (we) is high.
2. Read: Output the value of the cell when a read enable signal (re) is high.
3. Reset: Clear the stored value to 0 when a reset signal (rst) is high.

The module should have the following ports:
- input wire we (write enable)
- input wire re (read enable)
- input wire rst (reset)
- input wire d (data input)
- output reg q (data output)
