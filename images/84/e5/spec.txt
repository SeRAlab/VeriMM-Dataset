Create a Verilog module for a 4-bit shift register with parallel load capability. The module has the following functionalities:
- It shifts right on the positive edge of clk.
- It loads the parallel input data (d) when load is high.
- It has an asynchronous active-high reset (areset) that clears the register to 0.

module shift_register (
        input clk,
        input areset,
        input load,
        input [3:0] d,
        output reg [3:0] q);
