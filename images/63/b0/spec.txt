Design a 4-bit arithmetic unit capable of performing either addition or subtraction based on a mode control signal. When the mode input is set to 1, the module adds the two 4-bit inputs 'a' and 'b'; when the mode is set to 0, it subtracts 'b' from 'a'. The result is updated on the rising edge of the clock signal.
module top_module(
  input [3:0] a,
  input [3:0] b,
  input mode,
  input clk,
  output reg [3:0] result
);
