Design a 4-bit adder/subtractor circuit. The module takes two 4-bit inputs, A and B, along with a control signal, Sub. When Sub is low, the circuit performs binary addition of A and B; when Sub is high, it computes the subtraction of B from A. The output is a 4-bit Sum, with an additional carry-out signal, Cout, indicating an overflow or carry condition from the operation. The design utilizes bitwise operations and conditions to determine the appropriate computation based on the Sub control signal.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Sub,
    output [3:0] Sum,
    output Cout
);
