Design an SR flip-flop using Verilog. The flip-flop should have two inputs (S and R) and two outputs (Q and Qn). The outputs should change according to the SR flip-flop behavior: when S = 1 and R = 0, Q should be set to 1; when S = 0 and R = 1, Q should be reset to 0; when S = 0 and R = 0, Q should remain in its previous state; and when S = 1 and R = 1, it should be considered an invalid state. You need to implement this behavior in your Verilog code.
