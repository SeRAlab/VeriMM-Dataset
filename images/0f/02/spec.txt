
Design a 16-bit SRAM cell with read and write operations. The SRAM cell should have the following inputs and outputs:
- Inputs: `address` (4 bits), `data_in` (16 bits), `we` (write enable), `clk` (clock).
- Outputs: `data_out` (16 bits).

When `we` is high, the value of `data_in` should be written to the memory location specified by `address` on the rising edge of `clk`. When `we` is low, the value at the specified memory address should be output on `data_out`.
