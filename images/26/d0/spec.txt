Design a simple Ethernet MAC controller state machine that responds to a few control signals. The state machine should have three states: IDLE, TRANSMIT, and RECEIVE. The state transitions are controlled by two inputs: `start_tx` (to start transmission) and `start_rx` (to start reception). The state machine should output the current state as a 2-bit value. The state encoding is: 00 for IDLE, 01 for TRANSMIT, and 10 for RECEIVE.
