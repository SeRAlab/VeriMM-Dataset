Design a 32-bit shift register with synchronous parallel load capability. The register should have a clock input (clk), a reset input (rst), a load input (load), a 32-bit parallel data input (data_in), and a 32-bit output (data_out). When the load signal is high, the register should load the data from data_in on the rising edge of the clock. If load is low, the register should shift left by one bit on each rising clock edge, with the most significant bit (MSB) filled with 0. The reset signal should set the output to 0 when asserted.
