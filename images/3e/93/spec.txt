
Design an 8-bit SRAM cell with read and write capabilities. The SRAM cell should have the following inputs:
- `data_in` : 8-bit data input for writing data into the memory cell.
- `write_enable` : A single-bit control input that enables writing when high.
- `read_enable` : A single-bit control input that enables reading when high.
The outputs should be:
- `data_out` : 8-bit data output that reflects the data stored in the memory cell when reading.
The SRAM cell should maintain its state until a write operation is performed.
