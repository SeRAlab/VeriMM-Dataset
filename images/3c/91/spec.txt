
Create a Verilog module that implements a simple state machine with three states: IDLE, COUNT, and RESET. The state machine should transition based on an input signal `start`. When `start` is high, it should transition from IDLE to COUNT. In the COUNT state, it should increment a counter on each clock cycle until it reaches a maximum value (e.g., 5), after which it transitions to the RESET state. In the RESET state, it should reset the counter and transition back to IDLE when `reset` is activated.
