Design a 24-bit digital to analog converter (DAC) which takes a 24-bit input and produces a 24-bit output. The output should be equivalent to the input value scaled to a certain range, for instance, for a 24-bit DAC, the maximum value (2^24 - 1) should correspond to 1.0 (or maximum voltage). The circuit should implement a simple scaling function where the output is directly proportional to the input.
