Design a 4-bit synchronous up counter that increments its value on each positive edge of the clock when enabled. The counter resets to zero when the reset input is low. When the reset is released and enabled, the counter increments from its current value, allowing counting from 0 to 15.
module top_module(
  input clk,
  input reset,
  input enable,
  output reg [3:0] count
);
