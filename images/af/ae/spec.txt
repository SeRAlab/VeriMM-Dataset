Please act as a professional verilog designer.

Implement a synchronous FIFO with parameterizable depth and width (parameter DEPTH = 16, parameter WIDTH = 8). The FIFO uses a single clock domain for both read and write operations. The FIFO supports overflow and underflow protection. The module should have input ports for the clock signal, reset signal, write enable, read enable, and write data. It should have output ports for the read data, full signal, and empty signal. 

Module name: 
    sync_fifo

Input ports:
	clk: Clock signal used for synchronous operations.
	rstn: Reset signal, active low.
	wren: Write enable signal. Used to trigger write operations.
	rden: Read enable signal. Used to trigger read operations.
	wdata: Write data input. The width [WIDTH-1:0] is configurable and represents the data to be written into the FIFO.

Output ports:
	full: Write full signal. Indicates if the FIFO is full and cannot accept further write operations.
	empty: Read empty signal. Indicates if the FIFO is empty and cannot provide any data for read operations.
	rdata: Read data output. The width [WIDTH-1:0] is configurable and represents the data read from the FIFO.

Parameter:
	WIDTH = 8
	DEPTH = 16
