Design a 2-to-1 multiplexer for 32-bit wide data inputs. The module takes two 32-bit inputs, IN1 and IN2, and a control signal IR_CU. When IR_CU is set to 0, the output OUT is assigned the value of IN1; when IR_CU is set to 1, OUT receives the value of IN2. This allows for dynamic selection between the two input data signals based on the control signal.
module top_module(input [31:0] IN1,IN2,input IR_CU,output [31:0] OUT);
