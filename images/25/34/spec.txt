Design a Run-Length Encoding (RLE) module in Verilog that takes a sequence of binary data (1-bit input) and outputs the run-length encoded data as a count of consecutive bits and the corresponding bit value. The module should output the RLE data when a 'valid' signal is asserted. The input is a stream of bits with a 'valid' signal indicating valid data input. The output should consist of two values: the count of consecutive bits and the bit value. The module should reset on a 'reset' signal.
