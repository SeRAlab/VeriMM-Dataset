
Design a digital temperature sensor interface that takes a 10-bit binary input representing temperature values ranging from 0 to 1023. The output should be a 4-bit binary code that signifies whether the temperature is in the following ranges:
- 0-100: output 0 (0000)
- 101-200: output 1 (0001)
- 201-300: output 2 (0010)
- 301-400: output 3 (0011)
- 401-500: output 4 (0100)
- 501-600: output 5 (0101)
- 601-700: output 6 (0110)
- 701-800: output 7 (0111)
- 801-900: output 8 (1000)
- 901-1023: output 9 (1001)

After the temperature input is received, the system should maintain its output until a new temperature input is given.
