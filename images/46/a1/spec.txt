Design a simple 8-bit microprocessor capable of executing basic arithmetic and logic operations. The processor maintains an accumulator for calculations and a program counter to track instruction execution. It reads instructions from memory based on the program counter and performs operations such as addition, subtraction, logical AND, OR, XOR, as well as loading from memory and storing to memory, depending on the value of the fetched instruction. The accumulator's value is output continuously, while the system can be reset to initialize the accumulator and program counter.
