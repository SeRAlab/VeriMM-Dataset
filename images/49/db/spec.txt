Design a positive edge-triggered D flip-flop with a reset and a clock enable feature. The output Q initializes to a specified value (INIT), which defaults to 0. On each rising edge of the clock (CLK), if the RESET signal is high, the output Q is asynchronously cleared to 0. If CE (clock enable) is high and RESET is low, the input D is sampled and assigned to the output Q.
