
Design a 16-bit ADC (Analog to Digital Converter) output encoder in Verilog. The circuit should take a 16-bit input representing the ADC output and encode it into a 4-bit binary code representing the range of the input. The encoding should be as follows: 
- If the input is 0-1023, output 0
- If the input is 1024-2047, output 1
- If the input is 2048-3071, output 2
- If the input is 3072-4095, output 3
- If the input is greater than 4095, output 3 (clamped)
