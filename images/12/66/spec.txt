Design a 5-bit ring counter in Verilog. The counter should have a reset input that clears the counter, and a clock input that shifts the '1' bit around the counter. The output should be a 5-bit wide signal representing the current state of the ring counter. When the counter is reset, it should start from the state '00001'. The counter should cycle through the states '00001', '00010', '00100', '01000', '10000' and then back to '00001'.
