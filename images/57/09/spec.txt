Design a synchronous 4-bit counter with an asynchronous reset and enable functionality. The counter increments its value on every rising edge of the clock (clk) when the enable signal (en) is asserted. If the reset signal (rst) is activated, the counter is reset to zero regardless of the enable signal. The current count value is output as a 4-bit vector Q.
module top_module(
    input clk,
    input rst,
    input en,
    output [3:0] Q
    );
