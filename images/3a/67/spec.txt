
Create a 2-channel DMA controller that can read data from two different sources and transfer it to a destination. The controller should have the following features:
- Two input channels (channel1 and channel2) that indicate the readiness of data for transfer.
- Two address registers (addr1 and addr2) to hold the source addresses for each channel.
- A data register (data_out) that holds the data being transferred to the destination.
- A control signal (start_transfer) that initiates the transfer process.
- An output signal (transfer_done) that indicates when the transfer is complete.
- The controller should handle transfers in a round-robin manner between the two channels.
