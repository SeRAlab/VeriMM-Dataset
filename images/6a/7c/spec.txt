Design a versatile digital module that combines several functionalities, including a 4-bit priority encoder, a binary-to-Gray code converter, and a true dual-port RAM. The module captures the highest-priority input signal from a 4-bit input and encodes it into a 2-bit output. Alongside, it allows for reading from and writing to an 8-word memory block, with the ability to reset and initialize memory values. The final output is a 6-bit signal that concatenates the Gray code derived from the position indicated by the priority encoder with the data read from the RAM, effectively integrating memory operations and encoding in a single circuit design.
module top_module(
    input clk,
    input rst_n,
    input [3:0] in,
    output reg [1:0] pos,
    input write_en,
    input [7:0] write_addr,
    input [3:0] write_data,
    input read_en,
    input [7:0] read_addr,
    output reg [3:0] read_data,
    output reg [5:0] final_output
);
