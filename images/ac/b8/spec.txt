Design a Verilog module that models a 4-bit synchronous down-counter with synchronous enable and reset signals. The module should have an input clock signal (clk), an input enable signal (en), an input reset signal (rst), and a 4-bit output signal (count). On the rising edge of the clock, if reset is high, count should be set to 4'b1111. If enable is high, count should decrement by 1.
module down_counter (
  input clk,
  input en,
  input rst,
  output reg [3:0] count);
