
Design a Verilog module that implements a simple checksum mechanism for a 5-bit input data. The module should receive a 5-bit data input every clock cycle and calculate a running checksum that is also a 5-bit output. The checksum is computed as the sum of the input data bits modulo 32. The module should have an enable signal that allows the checksum calculation to occur only when asserted. When the enable signal is low, the checksum output should retain its previous value.
