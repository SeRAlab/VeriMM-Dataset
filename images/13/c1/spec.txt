Design a Network Address Translation (NAT) device that translates a given private IP address to a public IP address and vice versa. The device should have the following inputs: a clock signal, a reset signal, a mode signal (0 for NAT from private to public, 1 for reverse), a 32-bit private IP address, and a 32-bit public IP address. The output should be the translated IP address. The NAT should use a simple predefined mapping for demonstration purposes.
