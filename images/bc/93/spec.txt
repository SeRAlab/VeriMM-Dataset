Design a synchronous 8-bit adder that computes the sum of two 8-bit inputs, `a` and `b`. The addition occurs on the rising edge of the clock signal (`clk`), with the added logic to asynchronously reset the output (`sum`) to zero when the reset signal (`rst`) is high. When `rst` is not asserted, the module continuously provides the sum of `a` and `b` as its output.
module top_module(
    input       [7:0]   a,
    input       [7:0]   b,
    input               clk,
    input               rst,
    output reg  [7:0]   sum
);
