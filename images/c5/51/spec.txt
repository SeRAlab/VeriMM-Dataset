

You have been tasked with designing a module that takes in a 2-bit input signal, `A`, and outputs a 2-bit signal, `Q`. The `Q` output should be the same as the `A` input, but with the bits swapped. For example, if `A` is `01`, then `Q` should be `10`. 

Your task is to create a Verilog module, `swap_bits`, that implements this functionality. The module should be self-contained and should not rely on any other modules or external libraries. Additionally, the module should be no more than 200 lines of Verilog code.

Please write the Verilog code for the `swap_bits` module that implements the functionality described above.
