Design a 32-bit program counter (PC) that increments by 4 on each clock cycle, assuming it is not being reset or loaded with a new value. When the reset signal is active (low), the counter resets to 0. If the 'ld' input is asserted (high), the counter is loaded with a provided 32-bit input value instead of incrementing. The current value of the counter is outputted as a 32-bit signal.
module top_module(
  input clk,
  input reset,
  input [31:0] in,
  input ld,
  output [31:0] out
  );
