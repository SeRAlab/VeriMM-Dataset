Design a simple Stop-and-Wait ARQ (Automatic Repeat reQuest) system that can transmit a single bit of data. The system should implement error detection using a parity bit. When a sender transmits a bit along with its parity bit, the receiver checks the parity. If the received parity is correct, it sends an acknowledgment (ACK); otherwise, it sends a negative acknowledgment (NACK). The sender should retransmit the bit upon receiving a NACK and stop upon receiving an ACK.
