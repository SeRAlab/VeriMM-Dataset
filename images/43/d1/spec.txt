Design a 4-to-1 multiplexer that selects one of four 5-bit wide input signals (a, b, c, d) based on a 2-bit select signal (sel). The output (o) reflects the value of the selected input according to the binary value of sel; when sel is 00, output a; when sel is 01, output b; when sel is 10, output c; and when sel is 11, output d.
module top_module(
	input wire sel,
	input wire [4:0] a,
	input wire [4:0] b,
	input wire [4:0] c,
	input wire [4:0] d,
	output reg [4:0] o
);
