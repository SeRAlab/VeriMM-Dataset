Implement a simple Direct Memory Access (DMA) controller that can transfer data from a source memory address to a destination memory address. The controller should have the following inputs: `start` (to initiate the transfer), `clk` (clock signal), `reset` (to reset the controller), `src_addr` (source address), `dest_addr` (destination address), and `data_in` (data to be transferred). The output should be `data_out` (data transferred to the destination). The transfer should occur on the rising edge of the clock when `start` is high. The controller should also handle reset conditions.
