Design a 4-bit serial-in parallel-out (SIPO) shift register. On each rising edge of the clock, if the reset (rst) signal is active, the output (q) is cleared to zero. Otherwise, the input (in) is shifted into the least significant bit of the output, while the existing bits in the output are shifted to the left. This operation allows serial data to be captured and stored in a parallel format.
