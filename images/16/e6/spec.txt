Design a LIFO stack in Verilog that supports push, pop, and check empty operations. The stack should have a fixed size of 8 elements. Implement the following functionalities:
- A `push` operation that adds an element to the top of the stack.
- A `pop` operation that removes the top element from the stack and returns it.
- A `check_empty` operation that returns true if the stack is empty and false otherwise.
