    binary_counter

Input ports:
    clk: Clock signal used for synchronous operations.
    rstn: Active-low reset signal. Defined as 0 for reset and 1 for reset signal inactive.

Output ports:
    count: 4-bit output signal representing the current count value.

Implementation:
The module includes a 4-bit register, count, to store the current count value.

If the reset signal (rstn) is high, the counter increments its value by 1. If the counter reaches its maximum value of 15, it rolls over to 0.
