
Design a 7-stage pipeline processor that can handle a simple instruction set with the following stages:
1. Fetch (IF)
2. Decode (ID)
3. Execute (EX)
4. Memory Access (MEM)
5. Write Back (WB)
6. Stall (ST)
7. Flush (FL)

The processor should handle stalling and flushing based on control signals and should output the current instruction in the pipeline at each stage.
