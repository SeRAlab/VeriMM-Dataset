The `rst` input is synchronous and active high, and when asserted, the counter should reset to zero. The `en` input is synchronous and active high, and when asserted, the counter should increment on the positive edge of the `clk` signal. The module should have one output `count` which represents the current count value.

```

	// insert your code here
