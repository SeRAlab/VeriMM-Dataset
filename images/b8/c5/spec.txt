Design a 4-bit binary adder that computes the sum of two 4-bit inputs, `a` and `b`. The module produces a 4-bit output `sum` representing the lower four bits of the sum and a `carry_out` signal indicating if there is a carry from the most significant bit. The design utilizes a temporary wire for intermediate sum storage and captures the carry generated from the addition.
module top_module(
    input [3:0] a,
    input [3:0] b,
    output [3:0] sum,
    output carry_out
);
