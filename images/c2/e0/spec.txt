

You have been tasked with designing a verilog module to implement a 4-to-1 multiplexer. The module should have the following inputs and outputs:

Inputs:
- `a`, `b`, `c`, and `d`: Four single-bit data inputs to be multiplexed
- `sel`: A single-bit selection input that determines which data input is selected and outputted

Outputs:
- `out`: The selected data input based on the value of `sel`

Write the verilog code for the 4-to-1 multiplexer module.
