Design a simple 4-bit calculator that performs arithmetic operations based on a control signal. The module takes two 4-bit inputs (a and b) and a 2-bit mode selector that determines the operation: addition (mode 00), subtraction (mode 01), multiplication (mode 10), and division (mode 11). If the clear input is activated, it resets the result to zero. The calculated result is made available as a 4-bit output.
module top_module(a, b, mode, clear, result);
