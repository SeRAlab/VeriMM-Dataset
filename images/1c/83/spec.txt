Design a 5-stage pipelined processor that can perform simple addition and subtraction operations based on a control signal. The stages are: Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). The processor should take an operation code (opcode), two operands, and produce a result. The opcodes are: 00 for addition and 01 for subtraction.
