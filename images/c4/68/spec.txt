

You are tasked with designing a module that implements a 4-bit synchronous counter. The counter should have a synchronous reset input, an enable input, and an output that displays the current count value. The counter should increment on the rising edge of the clock signal only when the enable input is high. If the reset input is high, the counter should reset to 0. The counter should be designed using Verilog.

Design a Verilog module that implements the 4-bit synchronous counter described above. The module should have the following inputs and outputs:

- `clk`: a clock input
- `rst`: a synchronous reset input
- `en`: an enable input
- `count_out`: a 4-bit output that displays the current count value

Assume that `clk` has a frequency of 50 MHz.
