Design a Verilog module for a 32-bit register file with 4 registers, synchronous read and write operations. The write operation occurs on the rising edge of the clock if the `write_enable` signal is high. The read operation outputs data from the register addressed by `read_address`.
module reg_file(
    input clk,
    input write_enable,
    input [1:0] write_address,
    input [1:0] read_address,
    input [31:0] write_data,
    output reg [31:0] read_data);
