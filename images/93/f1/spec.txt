Design a 128-bit instruction cache (I-cache) with a size of 64 entries, which supports reading data and storing new instructions. The module takes a 32-bit address input and outputs corresponding data from the cache or a signal indicating the status of the read operation. When the read signal is activated, it checks if the cache tag at the derived index matches the requested address. If there is a match, it retrieves and outputs the cached data. If not, it indicates a cache miss, updates the cache with new data and the appropriate tag, and sets the output address for the operation. Additionally, it iteratively manages cache updates across all entries, ensuring efficient data handling in instruction fetching.
