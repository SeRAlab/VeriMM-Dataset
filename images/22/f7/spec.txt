Design a Verilog module that implements a simple state machine simulating a part of an RRT algorithm. The state machine should have the following states: IDLE, EXPLORE, and GOAL. The transitions should be defined as follows: From IDLE to EXPLORE on an input signal 'start', from EXPLORE to GOAL on an input signal 'reach', and from GOAL back to IDLE on an input signal 'reset'. The module should have appropriate input and output signals to reflect the current state.
