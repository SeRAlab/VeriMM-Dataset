

You are tasked with designing a verilog module that takes in a 4-bit input signal and outputs a 2-bit signal. The output should be the 2 most significant bits of the input signal. Additionally, the output signal should be inverted when a control signal is high.

Design a verilog module that satisfies the above requirements. The module should be named "bit_selector" and should have the following inputs and outputs:

Inputs:
- in_signal: a 4-bit input signal
- control_signal: a control signal

Outputs:
- out_signal: a 2-bit output signal

Ensure that the module is synthesizable and that the output signal is only updated when the control signal changes.
