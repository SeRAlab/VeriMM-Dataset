Design a lightweight random number generator with a 3-bit output. The module uses a clock (CLK) and a reset (RST) signal to regulate its operation. Upon receiving a reset, the counter (CNT) initializes to zero. When the START signal is activated, the output (NUM) generates a value based on the current count, with the counter incrementing each clock cycle until both the highest and lowest bits of CNT are set, at which point it resets to zero. The output provides a pseudo-random sequence based on the state of the START signal.
