Design a D flip-flop with asynchronous set functionality. The module takes a clock (CLK), data input (D), and an active-low set input (SET_B) to control the state of the output (Q) and its complement (Q_N). When SET_B is low, the flip-flop sets its output high irrespective of the clock or data inputs. On the rising edge of the clock, the flip-flop captures the value on the data input D and outputs it on Q while generating Q_N as its inverse. The module incorporates necessary supply connections and signal delays for proper operation.
