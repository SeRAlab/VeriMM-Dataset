Design a Verilog module for a 3-bit binary subtractor. The module should take two 3-bit binary numbers as inputs and output their 3-bit difference and a borrow-out bit.

Write the Verilog code for the subtractor module with the following signals:
- a: 3-bit input
- b: 3-bit input
- difference: 3-bit output
- borrow_out: 1-bit output

module subtractor3bit(
    input [2:0] a,
    input [2:0] b,
    output [2:0] difference,
    output borrow_out
);
