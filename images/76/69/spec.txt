Design a synchronous 8-bit register with asynchronous reset functionality. When the clock signal (clk) has a rising edge, the register captures the input data (d) and stores it into the internal register (q_reg). If the asynchronous reset signal (areset) is high, the register initializes to zero, overriding the input data. The output (q) reflects the current state of the register.
module top_module(
    input clk,
    input areset,   
    input [7:0] d,
    output [7:0] q
);
