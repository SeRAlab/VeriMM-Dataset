Design a module that integrates a 4-to-1 multiplexer, a 2-bit adder, and a XOR operation. The multiplexer selects one of the four 2-bit input signals (a, b, c, or d) based on a 2-bit select signal and provides it as output (mux_out). The selected input from the multiplexer combines with the second input (b) in a 2-bit adder, which adds a constant value of 1 to the result, producing the adder output (adder_out). Finally, the module computes the XOR between the multiplexer output and the adder output to produce the final output (final_output).
module top_module(
    input [1:0] a,b,c,d,
    input [1:0] sel,
    output [1:0] mux_out,
    output [1:0] adder_out,
    output [1:0] final_output
);
