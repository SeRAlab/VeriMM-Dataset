Design a synchronous up-counter that increments its count on every positive edge of the clock when enabled (en). It initializes the count to zero on a reset signal (rst) and wraps around to zero once it reaches the specified maximum count (max_count). The counter is 32 bits wide, allowing it to track a range up to 2^32 - 1.
module top_module(
    input clk,
    input rst,
    input en,
    input [31:0] max_count,
    output reg [31:0] count
);
