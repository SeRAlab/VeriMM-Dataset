

Write a Verilog module for a 2-input LUT-based synchronous reset D flip-flop. The module should have the following ports:

- `clk`: input clock signal
- `rst`: input reset signal (active low)
- `d`: input data signal
- `q`: output data signal

The module should have the following behavior:

- When `rst` is asserted, `q` should be set to 0 regardless of the value of `d`
- When `rst` is deasserted and a rising edge of `clk` occurs, `q` should be updated with the value of `d`

Use behavioral Verilog to implement the module.
