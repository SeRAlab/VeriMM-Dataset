Implement a Verilog module for a 5-bit linear feedback shift register (LFSR) with enable. The LFSR should only shift its value when the enable signal is high. The counter should have an asynchronous active-high reset that sets the LFSR to 00001.

module lfsr (
    input clk,
    input reset,
    input enable,
    output reg [4:0] lfsr_out
);
