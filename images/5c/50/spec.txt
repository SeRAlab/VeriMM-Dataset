Design a simple SRAM interface module that reads data based on a chip select mechanism. The module features a 2-bit address input where the chip select is activated only when the address is `00`. On a positive clock edge, if the reset is not asserted, the module updates the 32-bit output `readdata` with the value of `in_port`, but only if the chip select condition is satisfied. If the reset is active, `readdata` is cleared to zero.
module top_module(
  input [1:0] address,
  input clk,
  input in_port,
  input reset_n,
  output reg [31:0] readdata
);
