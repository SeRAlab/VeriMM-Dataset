

You have been tasked with designing a verilog module for a 4-bit synchronous counter. The counter should increment on every positive edge of the clock signal, and reset to 0 when the reset signal is asserted. The module should have the following ports:

- `CLK`: input clock signal
- `RST`: input reset signal
- `Q`: output 4-bit counter value

Design a verilog module that meets the above specifications.
