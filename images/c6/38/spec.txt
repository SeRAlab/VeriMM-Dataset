

You have been tasked with designing a verilog module that will take in a 32-bit input and output the same value as a 32-bit output. However, the output should always be a constant value of 0 or 1, depending on the value of a control signal.

You should create a module named "constant_output" that takes in the following inputs and outputs:

Inputs:
- `input [31:0] din`: a 32-bit input value
- `input control`: a control signal that determines the output value

Outputs:
- `output reg [31:0] dout`: a 32-bit output value that is always either 0 or 1, depending on the value of the control signal

If the control signal is 0, the output should be 0. If the control signal is 1, the output should be 1.

Write the verilog code for the "constant_output" module that meets the above requirements.
