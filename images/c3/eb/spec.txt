

You are tasked with designing a verilog module that takes in four input signals A1, A2, B1, and C1, and produces a single output signal X. The module should be named `four_input_gate` and should be defined as follows:

- A1, A2, B1, and C1 are all single-bit input signals.
- X is a single-bit output signal.
- The module should implement the following logic: X = (A1 & A2) | (~A1 & B1) | (~A1 & ~B1 & C1)

Write the verilog code for the `four_input_gate` module.
