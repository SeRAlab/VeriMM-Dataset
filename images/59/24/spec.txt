Design a 4-bit circular shift register with parallel load capability. When the load signal (PL) is active, the register captures the input data (D). Otherwise, on each rising edge of the clock (CLK), the bits in the shift register rotate right, with the most significant bit (MSB) shifting into the least significant bit (LSB) position. The output (Q) provides the current state of the least significant bit of the shift register.
module top_module(
    input [3:0] D,
    input PL,
    input CLK,
    output reg Q
);
