Design a 16-bit wide arithmetic calculator that performs four basic operations: addition, subtraction, multiplication, and division based on a 2-bit operation code (op). The calculator takes two 8-bit operands packed into a single 16-bit input; the lower 8 bits are used for the first operand and the upper 8 bits for the second operand. The specified operation is executed on these operands, and the result is stored in a 16-bit output. The module includes error handling for division by zero, invalid operations, and arithmetic overflow/underflow conditions, denoting them via system messages.
module top_module(
  input [1:0] op,
  input [15:0] operands,
  output reg [15:0] result
);
