Design a 3-input multiplexer that selects one of three inputs based on two control signals. The module takes inputs u, v, and w, and uses the select lines s0 and s1 to determine the output. When s0 is low, the output m corresponds to input u; when s0 is high, the output m corresponds to input v. The second select line s1 allows for further selection: if s1 is low, the output m reflects the selected input from u or v depending on s0, and if s1 is high, the output m switches to the input w.
module top_module(
    input u,
    input v,
    input w,
    input s0,
    input s1,
    output m
    );
