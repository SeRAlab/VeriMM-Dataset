Design a 2-to-1 multiplexer with power management features. The circuit selects between two outputs, B1 or B2, based on the logical OR of inputs A1 and A2 (which determines the select signal). If either A1 or A2 is HIGH, the output X will be B1 if A1 is HIGH, and B2 if A2 is HIGH; otherwise, it outputs a LOW. Additionally, the module includes power supply inputs VPB, VPWR, VGND, and VNB for potential power and ground management tasks, indicating that this multiplexer may be used in low-power or battery-operated designs.
module top_module(
  input A1,
  input A2,
  input B1,
  input B2,
  output X,
  input VPB,
  input VPWR,
  input VGND,
  input VNB
);
