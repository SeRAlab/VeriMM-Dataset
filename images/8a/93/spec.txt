Design a one-bit wide, 2-to-1 multiplexer. The module selects between two input data lines, `data_in_0` and `data_in_1`, based on the value of the select signal `sel`. When `sel` is 0, the output `out` will reflect `data_in_0`. When `sel` is 1, the output will take the value of `data_in_1`. The internal logic utilizes NOT, AND, and OR gates to implement the selection mechanism.
module top_module(
    sel,
    data_in_0,
    data_in_1,
    out
);
