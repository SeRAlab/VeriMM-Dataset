Design a combinational arithmetic logic unit (ALU) capable of performing a variety of operations on two 8-bit inputs, A and B, based on a 4-bit selector input, Sel. The ALU supports functions including addition, subtraction, logical operations (AND, OR, XOR), bit shifting, and negation. It also incorporates a carry-in input (C_IN) for certain operations and generates two output flags: C_FLAG to indicate a carry from the most significant bit and Z_FLAG to signal when the result is zero. The resulting operation is output as an 8-bit sum (SUM).
module top_module(
    input [7:0] A,
    input [7:0] B,
    input C_IN,
    input [3:0] Sel,
    output [7:0] SUM,
    output C_FLAG,
    output Z_FLAG
);
