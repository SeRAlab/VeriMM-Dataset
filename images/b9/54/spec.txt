Design a 4-input priority encoder that outputs a 2-bit coded value based on the highest priority active input. When input A (least significant) is active, the output will convey the highest priority as Y1 = 1 and Y0 = 0. When input B is active, Y1 = 0 and Y0 = 1. If inputs C, D, or any combination of inputs besides A and B are active, the output will be Y1 = 0 and Y0 = 0, indicating no valid encoding is produced for those cases.
module top_module(
    input A, B, C, D,
    output reg Y1,
    output reg Y0
);
