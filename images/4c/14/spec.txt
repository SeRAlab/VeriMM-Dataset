Design a 4-to-1 multiplexer with an enable signal. The module selects between four input signals (in0, in1, in2, in3) based on a 2-bit selection input (sel). If the enable signal (en) is high, it forwards the selected input to the output; if en is low, the output is forced to LOW. This module effectively allows controlled data routing based on the selection and enable conditions.
module top_module(
    input [1:0] sel,
    input en,
    input in0,
    input in1,
    input in2,
    input in3,
    output out
);
