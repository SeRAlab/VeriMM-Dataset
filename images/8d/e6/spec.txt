Design a dual-port memory module that allows simultaneous read and write operations to two separate memory banks. Each bank (bankA and bankB) consists of 256 16-bit wide entries. The module is triggered by two separate clock inputs; write operations can occur independently on each bank controlled by their respective write enable signals. The output is the most recent data read from the addressed bank, supporting operations in a time-multiplexed manner based on the clock signals and write enable controls.
module top_module(
    input   [1:0]       iv_clk,
    input   [1:0]       iv_wen,
    input   [15:0]      iv_addr,
    input   [15:0]      iv_wdata,
    output  reg [15:0]  ov_rdata  // Changed to reg to be able to assign values in always block
    );
