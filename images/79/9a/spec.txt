Design a monitoring module that outputs status messages based on the SLEEP signal. When SLEEP is asserted (high), it indicates that the layer controller is in a power-gated state, and a corresponding message is displayed with the current simulation time. Conversely, when SLEEP is deasserted (low), it shows that the layer controller is powered ungated, along with the current simulation time. This functionality is implemented with formatted output to visually differentiate the two states in the simulation environment.
