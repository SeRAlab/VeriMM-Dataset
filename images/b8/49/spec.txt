Design a signed 4-bit adder that computes the sum of two signed inputs, a and b. The module outputs the 4-bit result of the addition and an overflow flag, which indicates if the signed addition resulted in an overflow condition. Overflow is detected if both inputs are positive and the result is negative, or if both inputs are negative and the result is positive.
module top_module(
    input signed [3:0] a,
    input signed [3:0] b,
    output signed [3:0] result,
    output overflow
);
