
Design a thermal sensor calibration system that takes in a raw temperature reading and calibrates it based on a calibration factor. The calibration factor is applied to the raw reading to produce a calibrated temperature output. The system should also provide an enable signal to activate the calibration process. The design should include an input for the raw temperature, the calibration factor, an enable signal, and an output for the calibrated temperature. The output should only update when the enable signal is high.
