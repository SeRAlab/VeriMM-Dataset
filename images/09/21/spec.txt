Design a DVFS controller that adjusts the voltage and frequency of a system based on a given temperature input. The controller should have the following features:
1. It has an input temperature (in degrees Celsius) that ranges from 0 to 100.
2. Based on the temperature input, the controller should output a voltage and frequency setting according to the following criteria:
   - Temperature < 40: Voltage = 1.0V, Frequency = 1.0GHz
   - 40 ≤ Temperature < 70: Voltage = 1.2V, Frequency = 1.5GHz
   - Temperature ≥ 70: Voltage = 1.5V, Frequency = 2.0GHz
3. The state should retain the last value until a new temperature value is provided.
