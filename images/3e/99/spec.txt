
Design a Verilog module that implements a simple Bluetooth packet checker. The module should take a 8-bit input representing a Bluetooth packet and a clock. It will have a valid signal that indicates whether the packet is valid based on the following rules:
1. The packet should start with '10101010' and end with '11001100'.
2. If the packet is valid, a status register (1-bit) should be set to '1' otherwise it should be '0'.
