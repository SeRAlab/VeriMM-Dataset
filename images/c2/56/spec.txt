

You are tasked with designing a verilog module that implements a 4-bit adder with carry in and carry out. The module should have the following inputs and outputs:

Inputs:
- `A`: 4-bit input signal
- `B`: 4-bit input signal
- `Cin`: carry input signal

Outputs:
- `Sum`: 4-bit output signal representing the sum of `A`, `B`, and `Cin`
- `Cout`: carry output signal

The module should be named `adder4` and should use only basic verilog constructs (no pre-defined adder modules).
