Design a fixed-priority arbiter that has three request lines (req0, req1, req2) and one grant line (grant). The arbiter should grant access to the highest priority request. The priority is defined as req0 > req1 > req2. If multiple requests are made at the same clock cycle, the arbiter should retain the last granted request until it is de-asserted. The module should include a reset input that resets the grant line.
