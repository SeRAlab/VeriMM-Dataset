

You are tasked with designing a verilog module that performs a binary addition of two 4-bit input numbers. The module should have two 4-bit input ports (`A` and `B`) and one 5-bit output port (`SUM`). The output port should be able to represent the sum of two 4-bit numbers. If there is an overflow, the most significant bit of the output (`SUM[4]`) should be set to 1, otherwise it should be set to 0. 

Design the module `add4bit` that performs the addition of two 4-bit numbers and outputs the 5-bit sum with overflow bit.
