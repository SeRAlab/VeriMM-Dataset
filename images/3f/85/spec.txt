
Design a simple PCIe endpoint controller that has a state machine with three states: IDLE, READ, and WRITE. The controller should change states based on input signals. It should have an input signal `start`, which when asserted, transitions from IDLE to READ state. In the READ state, if a signal `data_valid` is asserted, it should transition to the WRITE state. In the WRITE state, if a signal `complete` is asserted, it should return to the IDLE state. The controller should output the current state as a 2-bit value.
