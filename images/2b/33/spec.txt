
Design a Parallel-in Parallel-out (PIPO) shift register in Verilog. The shift register should have a width of 8 bits. It should have the following inputs: a clock signal, a load signal, and an 8-bit data input. When the load signal is high, the data input should be loaded into the shift register on the rising edge of the clock. When the load signal is low, the contents of the shift register should be available on the output. The output should also be an 8-bit data output.
