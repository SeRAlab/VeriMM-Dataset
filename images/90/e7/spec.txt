Design a configurable flip-flop that captures the value of input D on the negative edge of the CLK_N signal. This flip-flop includes set and reset functionalities through SET_B and RESET_B, respectively. Additionally, it features synchronous control inputs SCD and SCE: when SCD is high, the output is forcibly set to LOW, and when SCE is high, it is set to HIGH. The outputs Q and Q_N allow for both the stored value and its inversion to be accessed.
module top_module(
    Q      ,
    Q_N    ,
    D      ,
    SCD    ,
    SCE    ,
    CLK_N  ,
    SET_B  ,
    RESET_B
);
