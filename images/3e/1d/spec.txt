
Design an 8-bit SRAM cell that supports read and write operations. The SRAM should have the following ports:
- `data_in`: 8-bit input data for writing.
- `data_out`: 8-bit output data for reading.
- `write_enable`: a signal to enable writing.
- `read_enable`: a signal to enable reading.
- `clk`: clock signal for synchronization.
