Write a Verilog module for a 4-bit binary up/down counter with enable and synchronous reset. The module should have a clock input "clk", a reset input "reset", an enable input "en", a direction input "dir" (1 for up, 0 for down), and a 4-bit output "count".

module up_down_counter (
  input clk,
  input reset,
  input en,
  input dir,
  output reg [3:0] count);
