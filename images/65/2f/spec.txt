Design a parity generator and checker for an n-bit input. The module accepts an n-bit data input and a parity mode input, where the mode determines whether to check for even or odd parity. It calculates the number of ones in the input data to generate a parity bit, which is then compared against the provided parity input to determine if the data is valid. The output indicates whether the parity matches (out) and whether an error was detected (err).
module top_module(
  input [n-1:0] in,
  input parity_mode,
  output out,
  output err
);
