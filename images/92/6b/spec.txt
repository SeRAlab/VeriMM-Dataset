Design a 4-bit barrel shifter that can shift its input left or right based on the direction control signal. The module takes a 4-bit input and a 2-bit shift amount to determine how many bit positions to shift. When the direction signal is low (0), the input is shifted to the right, and when high (1), it is shifted to the left. The output reflects the result of the specified shift operation.
module top_module(
  input [3:0] in,
  input [1:0] shift,
  input dir,
  output [3:0] out
);
