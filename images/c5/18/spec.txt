Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a control register block. 
A control register block is a type of digital circuit that is used to control the behavior of other circuits in a system. 
The inputs to the circuit are connected to a set of control bits, and the outputs are connected to the circuits that need to be controlled. 
The control register block contains a set of registers that can be loaded with control values, which are then used to control the behavior of the circuits.

Your module should have the following inputs and outputs:

Inputs: a set of n control signals (ctrl1, ctrl2, ..., ctrln)
Outputs: a set of m output signals (out1, out2, ..., outm)

The module should also have the following parameters:

n: the number of control signals
m: the number of output signals
r: the number of registers in the control register block

Your module should implement the following functionality:

The circuit should have r registers, each of which can be loaded with a value to control the behavior of the circuits.
The inputs to the circuit should be connected to the control bits of the registers.
The outputs of the circuit should be connected to the circuits that need to be controlled.
The control register block should be able to load the values of the registers with new control values.
The control register block should be able to output the current values of the registers to the circuits that need to be controlled.

To implement the control register block, you should use Verilog code to define the registers and the control logic that connects the inputs to the registers and the registers to the outputs. 
You should also define the control logic that allows the registers to be loaded with new values.
