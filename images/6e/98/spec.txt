Design a 32-bit wide bitwise left rotator. The module takes a 32-bit input and a 5-bit shift amount; it outputs the data after performing a rotation to the left by the specified number of bits. If the shift amount is zero, the output is the same as the input. Otherwise, the bits shifted out on the left are wrapped around to the right side of the output.
module top_module(
    input wire [31:0] data_in,
    input wire [4:0] shift_amount,
    output reg [31:0] rotated_data
    );
