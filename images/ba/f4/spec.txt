Design a negative edge-triggered single data input flip-flop with asynchronous reset functionality. The module outputs a value (Q) that is updated on the falling edge of the clock signal (CLK_N). If the reset signal (RESET_B) is low, the output is set to low. If the signal control data (SCD) is high, the output is also forced to low. If the enable control signal (SCE) is low, the previous output is retained. When SCE is high, the output (Q) takes the value of the data input (D).
module top_module(
    Q      ,
    CLK_N  ,
    D      ,
    SCD    ,
    SCE    ,
    RESET_B
);
