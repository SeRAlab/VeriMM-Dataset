Design a 3-bit synchronous counter that increments its count value on each rising edge of the clock signal, provided that the enable input is active (en=1). If the reset input (rst) is activated, the counter resets to zero. The counter can represent values from 0 to 7, utilizing a 3-bit output to indicate the current count.
module top_module(
    input clk,
    input rst,
    input en,
    output reg [2:0] count
);
