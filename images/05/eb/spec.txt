Design an 8-channel DMA controller that can transfer data from a memory location to multiple peripheral devices. The controller should have the following inputs: a clock signal (clk), a reset signal (rst), a start signal (start), an address input (addr), and a channel selector (chan_sel). It should have a data output (data_out) that corresponds to the selected channel's data. The controller should handle the transfer of data across the 8 channels and assert a done signal (done) when the transfer is complete. It should also have a read signal (read) indicating when data is being transferred.
