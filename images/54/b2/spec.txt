Design a program counter (PC) module that updates its current value based on a clock signal and a write enable signal. When the write enable signal (pc_we) is asserted (set to 1), the PC updates its value to the specified next value (pc_next) on the rising edge of the clock. When pc_we is not asserted, the current value of the PC remains unchanged.
