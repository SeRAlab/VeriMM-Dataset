Design a simple PCIe receiver module that accepts 32-bit data and a 2-bit command. The receiver should have a clock input and a reset signal. When the reset is low, the module should store the incoming data and command into internal registers. On the rising edge of the clock, if the command is '01', the data should be passed to an output register. If the command is '00', the data should be ignored. The output should be a valid signal that indicates whether valid data is available on the output register.
