Create an SPI master controller with the following specifications: It should be able to transmit data on the MOSI line, receive data on the MISO line, and control the clock signal on the SCK line. The controller should support a configurable data width of 8 bits and have a slave select (SS) signal to indicate which slave device to communicate with. The master should wait for a transaction start signal and then transmit and receive data in a synchronous manner, handling the clock signal and the data lines accordingly.
