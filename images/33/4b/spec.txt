Design a simple WiFi module state machine that can handle three states: IDLE, CONNECTING, and CONNECTED. The module should transition between these states based on the input signal 'start' to begin connecting, and 'connected' to indicate a successful connection. When in the IDLE state, if 'start' is asserted, the state should change to CONNECTING. Once 'connected' is asserted, it should change to CONNECTED. If 'reset' is asserted at any time, the state should return to IDLE.
