Design a Verilog module that performs 2x2 matrix multiplication. The module should take two 2x2 matrices as inputs and produce one 2x2 matrix as output. The matrices are defined as follows:
Matrix A:
| A[0][0] A[0][1] |
| A[1][0] A[1][1] |

Matrix B:
| B[0][0] B[0][1] |
| B[1][0] B[1][1] |

Output Matrix C:
| C[0][0] C[0][1] |
| C[1][0] C[1][1] |

The multiplication should be defined as:
C[0][0] = A[0][0] * B[0][0] + A[0][1] * B[1][0]
C[0][1] = A[0][0] * B[0][1] + A[0][1] * B[1][1]
C[1][0] = A[1][0] * B[0][0] + A[1][1] * B[1][0]
C[1][1] = A[1][0] * B[0][1] + A[1][1] * B[1][1]
