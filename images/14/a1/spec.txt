
Design a 4-bit SRAM cell with read and write operations. The SRAM cell should have the following inputs and outputs:
- Inputs: 
  - `data_in`: 4-bit data input for writing
  - `address`: 2-bit address input to select the SRAM cell
  - `write_enable`: write enable signal (1 for write, 0 for read)
  - `clock`: clock signal for synchronous operations
- Outputs:
  - `data_out`: 4-bit data output for reading
The SRAM should consist of four 4-bit storage elements, and the selected element's data should be outputted when reading.
