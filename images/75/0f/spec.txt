Design a dual-port block memory module with a 32-bit wide data bus and a 64-bit output. The module contains two separate 128-word memory arrays (mem0 and mem1), allowing for simultaneous read and write operations. Depending on the least significant bit of the input address (api_addr), it selectively writes incoming data (api_wr_data) to either mem0 or mem1. The output data (api_rd_data) can be read from either memory array, determined by the same address bit. Furthermore, it supports reading internal data using a separate internal address, with output provided as a concatenation of data from both memory arrays. Overall, this module functions as a block RAM enabling concurrent access for both API and internal operations.
