Design a simple state machine that takes a 5-bit binary input and produces a 1-bit output based on the state. The states are as follows:  
- State 0: If input is 0, stay in State 0; if input is 1, go to State 1.  
- State 1: If input is 0, go to State 2; if input is 1, stay in State 1.  
- State 2: If input is 0, go to State 0; if input is 1, go to State 3.  
- State 3: If input is 0, go to State 1; if input is 1, stay in State 3.  
The output is 1 when in State 2. The state machine should reset to State 0 on a reset signal.
