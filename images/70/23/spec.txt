Design a simple multiplier circuit that multiplies two 8-bit inputs, A and B, and produces a 16-bit output, Z. The multiplication operation is performed on the rising edge of the clock signal, with the option to clear the accumulator using the clr signal, which resets the output Z to zero. This module efficiently computes the product of A and B, storing the result in a 16-bit accumulator before driving the output.
module top_module(
    input  wire        clk,
    input  wire        clr,
    input  wire [ 7:0] A,
    input  wire [ 7:0] B,
    output reg  [15:0] Z
);
