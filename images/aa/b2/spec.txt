Design a 3-to-1 multiplexer with a 12-bit wide input bus. The output will be controlled by a 3-bit select signal (sel), allowing it to choose from eight different bits (i[0] to i[7]) of the 12-bit input (i). If the select signal corresponds to values from 0 to 7, the output will reflect the state of the corresponding input bit; for any other value of sel, the output will default to LOW.
module top_module(
    input [11:0] i,
    input [2:0] sel,
    output reg out
);
