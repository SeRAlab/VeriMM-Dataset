Design a 32-bit signed shifter that supports both logical and arithmetic shifts in left and right directions. The module takes a signed 32-bit input and shifts it based on two control inputs: `dir` specifies the direction (0 for left, 1 for right), while `shift_type` distinguishes between logical and arithmetic shifts. The number of positions to shift is controlled by the `shift_amt` input, allowing for flexible manipulation of the input data. The output presents the shifted result.
module top_module(
  input signed [31:0] in,
  input [1:0] dir,
  input [4:0] shift_amt,
  input [1:0] shift_type,
  output signed [31:0] out
);
