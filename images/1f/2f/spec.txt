Design a simple Stop-and-Wait protocol in Verilog. The protocol should have a sender and a receiver. The sender can send data and will wait for an acknowledgment (ACK) from the receiver before sending the next data. The sender will have input data and a clock signal, and an output signal to indicate successful transmission (send_done). The receiver will have an input signal to receive data and an output to send an acknowledgment (ack). The sender will only send new data when it has received an acknowledgment.
