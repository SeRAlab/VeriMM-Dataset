Implement a 4-to-1 multiplexer that selects one of four one-bit inputs (a, b, c, or d) based on a two-bit select line (sel1, sel0). The output `out` reflects the value of the chosen input, with the selection being determined by the concatenated values of sel1 and sel0. When sel1 and sel0 are 00, the output is a; when 01, the output is b; when 10, the output is c; and when 11, the output is d.
module top_module(
  input a,
  input b,
  input c,
  input d,
  input sel0,
  input sel1,
  output reg out
);
