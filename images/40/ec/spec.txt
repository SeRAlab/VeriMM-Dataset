Design a Verilog module that implements a simplified version of a Rapidly-exploring Random Tree (RRT) algorithm. The module should take in a start point and a goal point, and it should output a path represented as a series of coordinates that connect the start to the goal. The path should be updated on every clock cycle based on the current state of the tree. The module should also have a reset functionality to clear the tree and restart the process. The coordinates should be 5 bits each for both x and y values.
