Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state N (output 0).
2. state O (output 1).
3. state P (output 0).
4. state Q (output 1).

State transitions:
1. From state N: If x = 1, then transition to state O. If x = 0, then transition to state P.
2. From state O: If x = 1, then transition to state Q. If x = 0, then transition to state N.
3. From state P: If x = 1, then transition to state Q. If x = 0, then transition to state O.
4. From state Q: If x = 1, then transition to state P. If x = 0, then transition to state N.

Assume that a one-hot code is used with the state assignment y[3:0] = 0001(N), 0010(O), 0100(P), 1000(Q)

Write a Verilog for the signal Y0, which is the input of state flip-flop y[0], for the signal Y2, which is the input of state flip-flop y[2]. Derive the Verilog by inspection assuming a one-hot encoding.
