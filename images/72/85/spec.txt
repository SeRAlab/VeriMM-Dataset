Design a circuit that functions as an 8-bit wide multiplexer with eight input lines. It selects one of the eight 8-bit inputs—representing seconds, minutes, hours, day, month, and year—based on a 4-bit selector. Depending on the value of the selector, the output, Dato_Reg, will be assigned one of the input values, while a default case routes to zero if an invalid selector is provided.
module top_module( 
    input [7:0] Seg_RT, 
    input [7:0] Min_RT, 
    input [7:0] Hor_RT,
    input [7:0] Dia,
    input [7:0] Mes,
    input [7:0] Ao,
    output [7:0] Dato_Reg, 
    input [3:0] Selector 
    );
