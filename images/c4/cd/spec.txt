

You are tasked with designing a module that counts the number of times a signal goes high in a given period. The module should have the following inputs and outputs:

Inputs:
- `clk`: the clock signal
- `signal`: the signal to be counted
- `period`: the period for which the signal should be counted

Outputs:
- `count`: the number of times the signal went high in the given period

Assume that the `signal` input is synchronous with the `clk` input and that it goes high for one clock cycle and then goes low for one clock cycle. The `period` input is given in clock cycles.

Write a Verilog module `count_signal` that implements this functionality. You can assume that the `period` input is a multiple of 2.
