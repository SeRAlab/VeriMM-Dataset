Design a one-bit wide, two-to-one multiplexer with active-low selection. The output y is determined by the value of the selection input s0: when s0 is LOW, the output y will reflect the value of input I0; when s0 is HIGH, the output y will reflect the value of input I1. The design utilizes a NOT gate to create an inverted selection signal, effectively enabling the multiplexing functionality based on the selection input state.
