Design a synchronous data memory module capable of both read and write operations. It accepts a memory address, data input, and control signals for reading (Mem_rd) and writing (Mem_wr). On a read operation, it outputs the data stored at the specified address after a specified delay (T_rd), while on a write operation, it stores the provided data input at the specified address after a different delay (T_wr) on the negative edge of the clock. The memory is organized as an array of 32-bit words, supporting up to 1024 entries.
