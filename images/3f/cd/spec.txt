
Design a Verilog module that implements a simple gradient descent optimization algorithm to find the minimum of a quadratic function f(x) = (x - 5)^2. The module should take an initial guess for x and a learning rate and iteratively update x according to the gradient descent rule x_new = x_old - learning_rate * f'(x_old), where f'(x) = 2 * (x - 5). The optimization process should continue for a fixed number of iterations.
