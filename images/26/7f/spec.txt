Design a 4-bit DRAM cell which can store a single bit of data for each of the 4 bits. The cell should include a write enable signal (we) to allow writing data into the cell. The data is provided as a 4-bit input, and when the write enable signal is high, the corresponding data bits should be stored in the memory. When the write enable signal is low, the stored data should remain unchanged. The stored data should be output as a 4-bit output.
