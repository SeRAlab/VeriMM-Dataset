Design a circuit that implements a fifth-order cascaded integrator-comb (CIC) filter which processes signed 16-bit input data (d_in) on the rising edge of a clock signal (clk). The circuit has an asynchronous active-low reset (rst_n) to clear internal states. It accumulates input samples in a series of integrators, and after every four clock cycles (as determined by a decimation count), it calculates the output based on the difference between the last integration result and prior comb outputs. The output is a signed 28-bit value (d_out) with a valid flag (d_out_valid) indicating when the output is ready. This module is intended for use in digital signal processing applications requiring decimation and filtering of data streams.
module top_module(
    input  clk, 
    input  rst_n, 
    input  signed [15:0] d_in, 
    output reg signed [27:0] d_out, 
    output reg d_out_valid
    );
