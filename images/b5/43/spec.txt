Design a 3-to-8 line decoder with an enable input. When the enable signal (E) is high, the module decodes the three input lines (A, B, C) to activate one of the eight outputs (Y0 to Y7) based on the binary value represented by the inputs. If the enable signal is low, all output lines are driven low. This circuit effectively selects one of the eight outputs based on the three input bits while allowing external control over its operation using the enable signal.
module top_module(
  input A,
  input B,
  input C,
  input E,
  output reg Y0,
  output reg Y1,
  output reg Y2,
  output reg Y3,
  output reg Y4,
  output reg Y5,
  output reg Y6,
  output reg Y7
);
