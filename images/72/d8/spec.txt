Design a synchronous counter that counts upwards on each rising edge of the clock signal, provided the enable input is active. The counter can be reset to zero when the reset input is asserted. It supports a configurable width, allowing for counts of up to 2^WIDTH-1 based on the parameter WIDTH, which defaults to 8 bits.
module top_module(
  input clk,
  input reset,
  input enable,
  output reg [WIDTH-1:0] count
);
