Design a 4-bit shift register that can either load new data or perform a circular shift operation. When the load signal is high, the register captures the input data; when the shift signal is asserted, the data within the register is shifted left by one position, with the most significant bit wrapping around to the least significant bit position. The current state of the register is provided as output.
module top_module(
    input [3:0] data,
    input shift,
    input load,
    output [3:0] shifted_data
);
