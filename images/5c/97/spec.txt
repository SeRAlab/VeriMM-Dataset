Design a circuit that performs a binary XOR operation on two one-bit inputs, a and b. The output of this XOR operation is then split into a three-bit output vector, outv, with individual bits assigned to separate output wires o2, o1, and o0. Each of these outputs corresponds to a bit of the XOR result, allowing for the representation of the resulting 3-bit value. This module effectively provides both a direct XOR result and a structured output format.
module top_module(
    input wire a,
    input wire b,
    output wire [2:0] outv,
    output wire o2,
    output wire o1,
    output wire o0
);
