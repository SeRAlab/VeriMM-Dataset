Design a single-cycle synchronous read data module that responds to a clock signal and a reset condition. It takes a 2-bit address input to selectively read from an external input port when the address is 0, and outputs this data as a 32-bit readdata. Upon reset, the output is set to zero. If no reset is asserted, the module captures the value from the input port and supplies it as the output. The functionality is akin to a simple memory read operation where data is selectively loaded based on the specified address.
module top_module(
  input [1:0] address,
  input clk,
  input in_port,
  input reset_n,
  output reg [31:0] readdata
);
