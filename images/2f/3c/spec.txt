
Create a simple SPI controller that can be used to transmit and receive data. The SPI controller should have the following inputs and outputs:
- clk: Clock input
- reset: Reset signal
- mosi: Master Out Slave In
- miso: Master In Slave Out
- cs: Chip Select
- sclk: Serial Clock
- data_out: Data output from the SPI controller
- data_in: Data input to the SPI controller
- ready: Indicates when the SPI controller is ready to transfer data

The controller should transmit 8 bits of data from data_in when cs is low, and shift them out on the rising edge of sclk. Simultaneously, it should receive data on miso and store it in data_out.
