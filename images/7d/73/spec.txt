Design a synchronous FIFO memory module that supports read and write operations. The module accepts a write clock signal (`wr_clk`), a write enable signal (`wr_write`), and data inputs (`wr_data` and `wr_addr`) to store data in an array-sized memory defined by the address width. On the rising edge of the clock, if the write enable is asserted, the input data is written to the specified write address. The module also provides an output for read data (`rd_data`), which is accessible via a read address input (`rd_addr`). The memory size is determined by the address width parameter, allowing for flexible design based on the specified data width (DW) and address width (AW).
