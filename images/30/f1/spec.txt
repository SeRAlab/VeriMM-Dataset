
Design a temperature-based shutdown system in Verilog. The system should monitor a 5-bit temperature input and activate a shutdown signal when the temperature exceeds a threshold. The threshold is set at 28 degrees (binary 11100). The system should have a clock input and a reset input. On reset, the shutdown signal should be deactivated, and on each clock cycle, if the temperature exceeds the threshold, the shutdown signal should be activated; otherwise, it remains deactivated.
