

You are tasked with creating a verilog module that implements a 32-bit adder with a synchronous reset and clock enable. The module should have the following inputs and outputs:

Inputs:
- `A` (32-bit signed integer): First input to the adder
- `B` (32-bit signed integer): Second input to the adder
- `C` (1-bit): Clock input
- `CE` (1-bit): Clock enable input
- `R` (1-bit): Reset input

Outputs:
- `S` (32-bit signed integer): Result of the addition

The module should perform the addition of `A` and `B` when `CE` is high and the clock edge is detected. If `R` is high, the output should be set to 0. If `CE` is low, the output should remain unchanged.
