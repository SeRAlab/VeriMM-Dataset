
Design a simple instruction pipeline for a CPU that can handle three stages: Fetch (F), Decode (D), and Execute (E). Create a Verilog module that simulates this pipeline. The input to the pipeline is a 32-bit instruction, and the output is a 32-bit result from the Execute stage. Ensure that the module can handle instruction fetching and provide appropriate outputs for all three stages sequentially. You must include a mechanism to handle data hazards.
