Design a memory arbiter that manages access requests from multiple sources. It takes in a set of request signals and, based on a priority scheme, grants access to one request at a time. The arbiter prioritizes the requests according to the order they are received, ensuring that if multiple requests are made simultaneously, only the highest priority request is serviced. It outputs a single access signal corresponding to the granted request, facilitating orderly and conflict-free memory access within a system.

  input [n-1:0] req,
  output [m-1:0] access
);
