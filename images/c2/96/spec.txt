

You have been tasked to design a module in Verilog that takes in a 32-bit input signal `data_in` and outputs a 16-bit signal `data_out` which is the sum of the most significant 16 bits and the least significant 16 bits of `data_in`. If there is an overflow during addition, the module should output an overflow signal `ovf` set to 1, otherwise, `ovf` should be set to 0. 

In addition, the module should have an enable signal `en` which, when set to 0, should cause the module to output 0 for `data_out` and 0 for `ovf`. 

The module should be named `sum16` and should be implemented within 200 lines of Verilog code.
