Design a Watchdog Timer in Verilog. The timer is reset when an input signal called 'reset' is high. If the 'reset' signal remains low for a predefined period defined by a parameter 'TIMEOUT', the timer will indicate a timeout condition by asserting an output signal 'timeout'. The timer operates on a clock signal 'clk'. Use a counter to measure the elapsed time. The 'timeout' signal should be asserted only once when the timeout condition is met.
