Design a 4-bit up-counter with a synchronous reset. On the rising edge of the clock, if the reset signal is activated, the counter is initialized to the input value (i_value). If the counter reaches its maximum value of 15 (4'hF), it wraps around and resets to 0. Otherwise, it increments the counter by 1 with each clock cycle.
module top_module(
   input clk,
   input reset,
   input [3:0] i_value,
   output reg [3:0] value
);
