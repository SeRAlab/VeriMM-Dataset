
Design a 2nd order Infinite Impulse Response (IIR) filter using Verilog. The filter should take a 16-bit input signal and produce a 16-bit output signal. The filter coefficients should be provided as parameters in the module. The filter should maintain state across clock cycles and should be able to process input data on the rising edge of the clock. The output of the filter should be updated on each clock cycle based on the current input and the previous output values.
