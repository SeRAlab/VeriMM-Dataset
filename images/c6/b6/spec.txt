

You are tasked with designing a digital circuit that implements a D flip-flop with asynchronous reset functionality. The circuit should be implemented in Verilog and should be contained within a single module. The module should have the following inputs and outputs:

Inputs:
- D: the data input to the flip-flop
- C: the clock input to the flip-flop
- R: the asynchronous reset input to the flip-flop

Outputs:
- Q: the output of the flip-flop

The module should operate as follows:
- On the rising edge of the clock input, the output Q should be updated to the value of the input D.
- If the reset input R is asserted (i.e., goes low), the output Q should be immediately set to 0.

Please note that the module should be designed using behavioral Verilog (i.e., using always blocks), and not using structural Verilog (i.e., instantiating gates and other modules).
