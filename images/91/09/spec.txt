Design a negative edge-triggered D flip-flop with active-low set and reset inputs. The module takes a data input (D) and clock input (CLK_N), allowing the state of the output (Q) to be updated on the falling edge of the clock signal. It includes active-low asynchronous set (SET_B) and reset (RESET_B) inputs for overriding the flip-flop state. The design also incorporates power supply and ground pins (VPWR and VGND) for proper operation. The output Q reflects the stored value, while Q_N outputs the inverse of Q.
module top_module(
    input D,
    input CLK_N,
    input SET_B,
    input RESET_B,
    input VPWR,
    input VGND,
    output Q,
    output Q_N
);
