
You have been tasked with designing a verilog module that performs a full adder operation. The module should have the following input and output ports:

Inputs:
- A (1-bit)
- B (1-bit)
- CI (1-bit)

Outputs:
- SUM (1-bit)
- COUT (1-bit)

The module should implement the following logic:

- The SUM output should be the sum of A, B, and CI.
- The COUT output should be the carry-out bit of the addition operation.

You should write a verilog module that implements this logic. Your module should be self-contained and should not rely on any external modules or libraries. The module should be no more than 200 lines of verilog code.
