Design a combinational logic circuit that produces an output Y based on multiple input conditions. The output Y will be HIGH if either both A1 and A2 are HIGH, or if all inputs B1, C1, and D1 are HIGH, or if the power supply is active (VPWR is HIGH while VGND is LOW), or if the bipolar properties are satisfied (VPB is HIGH while VNB is LOW).
module top_module(
    input A1,
    input A2,
    input B1,
    input C1,
    input D1,
    input VPWR,
    input VGND,
    input VPB,
    input VNB,
    output Y
);
