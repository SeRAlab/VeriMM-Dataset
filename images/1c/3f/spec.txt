Design a 16-bit ADC (Analog to Digital Converter) which takes a 16-bit digital input and produces a 5-bit output representing the quantized value. The output should be calculated by taking the 16-bit input value and dividing it by a scaling factor of \(2^{11}\) (which is 2048). The result must be truncated to fit into 5 bits. If the input value is greater than the maximum representable value of 5 bits (31), the output should be capped at 31.
