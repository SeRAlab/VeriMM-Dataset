Design a Verilog module that calculates a simple checksum of an 8-bit input data. The checksum should be the sum of the bits in the input data, reduced to 4 bits. The module should have an 8-bit input and a 4-bit output. The output should indicate whether the input data is valid based on the checksum. If the checksum matches the sum of the bits, the output should be high; otherwise, it should be low.
