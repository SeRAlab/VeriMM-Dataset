

You are tasked with designing a Verilog module for a simple counter that counts from 0 to 9 and then restarts from 0 again. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock signal
- `reset`: a synchronous reset signal

Outputs:
- `count`: a 4-bit output representing the current count value

The module should count up on every rising edge of the `clk` signal, and should reset to 0 on the rising edge of the `reset` signal. The module should be synchronous, and should not have any combinational logic.

Write the Verilog code for this module.
