
Design a D flip-flop with an asynchronous reset. The flip-flop should have the following specifications:
- It should have a D (data) input, a CLK (clock) input, an RST (reset) input, and a Q (output).
- On the rising edge of CLK, if RST is low, Q should take the value of D.
- If RST is high, Q should be reset to 0.
