Design a 4-bit adder/subtractor circuit. The module takes two 4-bit inputs, A and B, and a control signal SUB. When SUB is 0, the circuit performs addition of A and B. When SUB is 1, it subtracts B from A by adding the two's complement of B to A. The result is output as a 4-bit value OUT.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input SUB,
    output [3:0] OUT
);
