Design a 4-bit restoring divider in Verilog that divides a 4-bit binary number (dividend) by a 2-bit binary number (divisor). The output should be the quotient and a remainder. The division should be clocked, and the operation should begin on a start signal, which will be high for one clock cycle. The operation should complete in a fixed number of cycles, and the output should be valid after the operation is complete.
