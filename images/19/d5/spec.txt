
Design a 4-bit CORDIC-based vectoring unit that computes the angle (theta) given a vector (x, y) in the range of [-1, 1] for both x and y inputs. The unit should use a 4-stage CORDIC algorithm. The output should be a 4-bit angle in radians represented in fixed-point format (0.1). The circuit should include an enable signal to start the computation and a done signal to indicate when the computation is complete.
