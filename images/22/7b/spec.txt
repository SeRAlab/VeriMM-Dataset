Design a 4-bit DRAM cell that can read and write data. The cell should have the following inputs: `addr` (2 bits for selecting the cell), `data_in` (4 bits for writing data), `wr_en` (write enable, 1 bit), and `clk` (1 bit for clock signal). The output should be `data_out` (4 bits for the data read from the cell). When `wr_en` is high, the data should be written to the cell on the rising edge of `clk`. When `wr_en` is low, the data should be read from the cell and output on `data_out` at the next rising edge of `clk`.
