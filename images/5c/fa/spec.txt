Design a clock divider that generates a lower frequency output clock (`clkOut`) based on a specified `Divisor`. The circuit counts clock cycles derived from an input clock (`clk`), resetting the counter (`count_i`) and the output clock state (`clkOut_i`) when a reset signal (`rst`) is asserted. When the counter reaches the value of `Divisor - 1`, it toggles the output clock and resets the count, thereby effectively dividing the input clock frequency by `Divisor`. The current count value is also made available as a 32-bit output (`count`).
module top_module(
    Divisor,
    clkOut,
    count,
    clk,
    rst
);
