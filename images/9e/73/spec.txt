It can be reset to zero with the rst input, and it can load a specific 4-bit value from the load_val input when the load signal is asserted. The output reflects the current count state.
module top_module(
    input clk,
    input rst,
    input load,
    input up_down,
    input [3:0] load_val,
    output reg [3:0] out
);
