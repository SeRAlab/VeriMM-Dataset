Design a 4-bit synchronous counter with load and reset functionalities. On the rising edge of the clock (CLK), when reset (RST) is asserted, the counter output (Q) is set to zero. If reset is not asserted, and the enable signal (EN) is active, the counter will either load a new value (D) into Q when the load signal (LOAD) is asserted, or increment the current value of Q by 1 otherwise.
module top_module(
    input CLK,
    input RST,
    input EN,
    input LOAD,
    input [3:0] D,
    output reg [3:0] Q
);
