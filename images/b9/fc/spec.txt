Design a 32-bit arithmetic unit that performs various arithmetic operations on two 32-bit inputs, `a` and `b`, based on a two-bit operation selector `op`. The module supports addition, subtraction, multiplication, and division, corresponding to the values 00, 01, 10, and 11 of `op`, respectively. The output `result` reflects the outcome of the selected operation, and a default case ensures the result is zero if an invalid operation is chosen.
module top_module(
  input [31:0] a, b,
  input [1:0] op,
  output reg [31:0] result
);
