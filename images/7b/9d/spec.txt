Design a flip-flop based storage element that holds a 32-bit value. On the positive edge of the clock, if the reset signal is active, the output is set to zero. If the reset is inactive and the write enable (we4) signal is active, the output is updated with the input data (d).
module top_module(
	input wire clk,reset, we4,bt,
	input wire [31:0]d,
	output reg [31:0]q
);
