

You have been given a Verilog module `counter` with the following ports:
- `clk` (input): a clock signal
- `rst` (input): a reset signal
- `en` (input): an enable signal
- `out` (output): a 3-bit output signal

The module should implement a synchronous counter that increments by 1 on every rising edge of the clock signal if the enable signal is high. The counter should reset to 0 when the reset signal is high.

Write the Verilog code for the `counter` module that satisfies the above requirements.
