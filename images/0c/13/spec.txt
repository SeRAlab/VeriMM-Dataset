Design a Verilog module that simulates a simple TCP segmentation mechanism. The module should accept a data input signal of 32 bits and a control signal that indicates when to segment the data. When the control signal is asserted, the module should output a 16-bit segment that represents the first half of the data input and a separate 16-bit segment for the second half. The module should also have a valid signal that indicates when the output segments are valid.
