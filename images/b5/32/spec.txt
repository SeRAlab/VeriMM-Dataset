Implement a 3-bit up/down counter module. The counter should increment by 1 when the UP signal is high and decrement by 1 when the DOWN signal is high on each positive edge of the clock signal. Module name:  
    up_down_counter  

Input ports:
    CLK: Clock input
    RST: Active high reset signal
    UP: Up count signal
    DOWN: Down count signal

Output ports:
    COUNT: 3-bit output representing the counter value

Implementation:
The up_down_counter module uses an always block to update the counter value based on the clock signal, reset signal, UP, and DOWN signals. The always block triggers on the positive edge of the clock signal (posedge CLK) or the positive edge of the reset signal (posedge RST). If the reset signal is active (RST), the counter value (COUNT) is set to 0. If the UP signal is high and the DOWN signal is low, the counter value is incremented by 1. If the DOWN signal is high and the UP signal is low, the counter value is decremented by 1. If both signals are high, the counter value remains unchanged.

Give me the complete code.
