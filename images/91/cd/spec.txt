Design a 4-bit up/down counter with load capability. The counter increments when the `up_down` input is high and decrements when it is low. It can be initialized to a specific value when the `load` input is activated, and it resets to zero when the `reset` input is asserted. The counter operates on the rising edge of a clock signal.
module top_module(
    input clk,
    input reset,
    input load,
    input up_down,
    input [3:0] in_value,
    output reg [3:0] count
);
