Implement a 4-bit barrel shifter that allows for circular shifting of the input data based on a 2-bit shift_amount control signal. The output will be the result of shifting the input data either left or right, effectively rotating the bits around. Specifically, when shift_amount is 00, the output is the same as the input; when it is 01, the data is shifted left by one position; when it is 10, the data is shifted left by two positions; and when it is 11, the data is shifted left by three positions, wrapping around the bits appropriately.
module top_module(
    input [3:0] data,
    input [1:0] shift_amount,
    output reg [3:0] result
);
