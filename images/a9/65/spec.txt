Design a simple arithmetic calculator that performs basic operations on two 8-bit inputs based on a 2-bit operation selector. The calculator, synchronized to a clock, supports addition, subtraction, multiplication, and division. It resets the output to zero when the reset signal is activated. The output, which is also 8 bits wide, is updated with the result of the operation dictated by the op input; if division is attempted with a zero divisor, the output is set to zero to prevent undefined behavior.
