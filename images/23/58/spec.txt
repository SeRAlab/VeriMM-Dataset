Design an 8-bit deserializer that takes a serial input bit stream and outputs the corresponding 8-bit parallel data. The deserializer should operate on a clock signal and a valid signal that indicates when the serial data is valid. When the valid signal is high, the deserializer should collect one bit of the serial data on each clock edge until it has collected 8 bits, at which point it should output the 8-bit parallel data and reset for the next byte.
