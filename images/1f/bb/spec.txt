Design a 4th-order IIR filter with the following specifications: The filter will have two inputs (in0 and in1) and one output (out). The filter coefficients are fixed for the design: b0 = 0.1, b1 = 0.2, b2 = 0.3, b3 = 0.4, b4 = 0.5, a1 = 0.6, a2 = 0.7, a3 = 0.8, a4 = 0.9. Implement the state variables needed to compute the output based on the inputs and the coefficients. Ensure that the output is updated on each clock cycle based on the current input and the previous outputs.
