Design a four-input NAND gate with one active-low input (A_N). The circuit first inverts the active-low input A_N, then performs a series of AND operations on the inverted A_N, input B, input C, and finally input D. The output Y is high unless all conditions leading to the final AND operation result in a high signal, which occurs only when A_N is low, B, C, and D are all high. This module is designed for digital logic applications where NAND functionality is needed.
module top_module(
    input A_N,
    input B,
    input C,
    input D,
    output Y,
    input VPB,
    input VPWR,
    input VGND,
    input VNB
);
