Design a synchronous decade counter that counts from 0 to 9 in response to a clock signal. The counter resets to 0 upon receiving a reset signal and increments its value with each clock cycle when both the enable and gameStart signals are active. Additionally, it provides a terminal count output (tc) that indicates when the counter has reached 9 and is ready to reset.
module top_module(
    input clk,
    input rst,
    input gameStart,
    output reg [3:0] Q,
    input en,
    output tc
    );
