Implement a configurable 2-to-1 multiplexer operating on (MuxLen + 1) bits. It selects between two input signals, mux_in0 and mux_in1, based on the value of the mux_sel control signal. When mux_sel is 0, the output, mux_out, is set to mux_in0; when it's 1, mux_out is set to mux_in1. This design allows for bit-width flexibility, as determined by the parameter MuxLen.
