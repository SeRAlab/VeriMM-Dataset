When sub is low (0), the circuit performs addition of A and B, and when sub is high (1), it conducts subtraction by computing A minus B. The output is a 4-bit sum, and an overflow flag is indicated by a fifth bit which is used to signal if an arithmetic overflow has occurred during the operation.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input sub,
    output [3:0] sum,
    output overflow
);
