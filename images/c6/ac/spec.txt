

Your task is to design a module that can implement a D flip-flop with negative edge-triggered clock using Verilog. The module should have three inputs, D, C, and R, and one output, Q. The D input represents the data input, C represents the negative edge-triggered clock input, and R represents the reset input. The output Q represents the output of the flip-flop. 

The module should implement the following behavior:
- When the reset input R is high, the output Q should be low regardless of the value of the D input.
- When the negative edge of the clock input C arrives, the output Q should take on the value of the D input at that time.
- The output Q should remain stable until the next negative edge of the clock input C arrives, regardless of the value of the D input.

You can assume that the input signals are glitch-free and have valid timing. Your module should be designed in such a way that it can be easily integrated into a larger Verilog design.

Your solution should consist of a single module implementation and should not exceed 200 lines of Verilog code.
