Design a 2-channel DMA controller that can transfer data between memory and two different peripherals. The DMA controller should have the following inputs: `request1`, `request2`, `acknowledge1`, `acknowledge2`, and a clock signal. The controller should grant access to one of the channels based on which request is received first. The output should indicate which channel is currently active (`active_channel`), and a signal `transfer_complete` should indicate when a transfer has finished. Use a simple round-robin mechanism for channel access. The active channel should toggle based on requests received.
