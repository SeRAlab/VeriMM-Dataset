Design a Verilog module that implements a simple 16-QAM modulator. The modulator should take a 4-bit input representing two bits for each of the I (in-phase) and Q (quadrature) components and output a corresponding 8-bit value. The mapping is as follows: 00 -> 00000000, 01 -> 00000001, 10 -> 00000010, 11 -> 00000011 for I, and the same mapping for Q. The I and Q values should be combined in the output as follows: output = (I << 4) | Q. The module should have a clock and a reset input for sequential behavior.
