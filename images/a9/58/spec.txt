Design a 32-register file with 32-bit wide data storage, which allows read and write operations. Upon a positive clock edge or reset signal, the module resets the first register to zero. When writing data, if the write enable (`D_En`) is active and the destination address is not zero, it stores the incoming 32-bit data (`D`) into the specified register (`D_Addr`). It simultaneously provides the contents of two registers (`S_Addr` and `T_Addr`) as outputs `S` and `T`, enabling access to register values based on the provided addresses.
