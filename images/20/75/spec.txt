Design a Voltage-Controlled Oscillator (VCO) using Verilog. The VCO should take a control voltage (a 4-bit binary input) and generate a frequency output based on that control voltage. The output frequency should be represented as a 4-bit binary output. The relationship between the control voltage and the output frequency is defined such that each increment in the control voltage corresponds to an increment in the output frequency. Specifically, the output frequency can be represented as `2 * control_voltage` (where control_voltage is interpreted as an unsigned integer).
