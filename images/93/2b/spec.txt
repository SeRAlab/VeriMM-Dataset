Design a barrel shifter capable of performing both left and right arithmetic shifts on a 26-bit signed input. When the direction input is set to 1, the module shifts the input to the right by a specified number of bits (shiftby); otherwise, it shifts the input to the left. The output reflects the shifted value of the input.
module top_module(
    direction,
    shiftin,
    shiftby,
    shiftout
);
