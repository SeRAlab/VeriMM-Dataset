Design a circuit that functions as a 4-bit to 2-bit data converter with synchronous reset capability. On each rising edge of the clock, if the reset signal is active, the output will be cleared to zero. Otherwise, the module captures and outputs the two most significant bits of the 4-bit input data.
module top_module(
    input [3:0] data_in,
    input clk,
    input rst,
    output reg [1:0] data_out
);
