

You are tasked with designing a verilog module for a 4-bit binary to gray code converter. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock signal
- `rst`: a synchronous reset signal
- `bin`: a 4-bit binary input

Outputs:
- `gray`: a 4-bit gray code output

The module should convert the 4-bit binary input to its corresponding 4-bit gray code output. The module should operate on the rising edge of the clock signal and should be reset to 0 on the rising edge of the reset signal.
