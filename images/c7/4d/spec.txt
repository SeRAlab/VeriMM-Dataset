

You have been tasked with designing a module that will act as a simple calculator, capable of performing addition and subtraction operations on two 4-bit numbers. The module should take in two 4-bit inputs (A and B), a 1-bit input (op), and output a 4-bit result (Z).

If the op input is 0, the module should perform addition, adding the two input values together and outputting the result in Z. If the op input is 1, the module should perform subtraction, subtracting the second input value from the first input value and outputting the result in Z.

You should write the verilog code for this module and ensure that it is synthesizable.
