

You are tasked with designing a Verilog module that takes in 3 input signals A1, A2, and B1, and outputs a single signal Y. Additionally, the module should have 4 input power signals: VPB, VPWR, VGND, and VNB.

The module should be named "my_module" and should be written in no more than 200 lines of Verilog code.

The output signal Y should be calculated as follows:
- If A1 is high and A2 is low, Y should be high
- If A1 is low and A2 is high, Y should be high
- If B1 is high, Y should be high
- If none of the above conditions are met, Y should be low

The power signals should be used as follows:
- VPB is the power supply voltage for the module
- VPWR is the power supply voltage for the output signal Y
- VGND is the ground voltage for the module
- VNB is the negative power supply voltage for the module

Ensure that your module is self-contained and can be simulated without any additional code.
