

You have been tasked with designing a clock gating module for a digital circuit. The module should take in three inputs: `CLK`, `EN`, and `TE`, and output a clock signal `ENCLK`. The `CLK` input is a clock signal, the `EN` input is an enable signal, and the `TE` input is a test enable signal. The module should only enable the clock signal when both `EN` and `TE` are high.

Your task is to implement a Verilog module that meets these specifications. The module should be named `clock_gate` and should be no more than 200 lines of code.
