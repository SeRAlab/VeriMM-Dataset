Design a 1-bit DRAM cell in Verilog. The cell should have inputs for data (D), a write enable signal (WE), and a clock signal (CLK). The output should be the stored data (Q). On the rising edge of the clock, if the write enable (WE) is high, the data input (D) should be stored in the cell. If WE is low, the stored data should remain unchanged. The output Q should always reflect the stored data.
