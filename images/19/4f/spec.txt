
Design a 4-bit ring counter using Verilog. The ring counter should have a reset input and a clock input. When the reset is activated, the counter should set to a predefined state (e.g., 0001). On each rising edge of the clock, the '1' should shift to the right, and the last bit should wrap around to the first bit to maintain the ring structure. Implement the counter such that it can be easily simulated and tested.
