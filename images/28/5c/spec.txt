Design a stop-and-wait flow control protocol in Verilog. The protocol should consist of a sender and a receiver, where the sender sends data and waits for an acknowledgment (ACK) from the receiver before sending the next data packet. The sender should have a data input, a send signal, and an ACK output, while the receiver should have a data output and an ACK input. The system should handle a maximum of 4 data packets (0 to 3).
