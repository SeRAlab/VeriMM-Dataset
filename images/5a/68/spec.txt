Design a 3-bit shift register that incorporates XOR feedback for serial input processing. Upon each positive clock edge, the module shifts the bits within the register, inserting an XOR combination of the most significant bit and the incoming serial data into the least significant bit. The output `serial_out` presents the most significant bit of the shift register, while the output `q` provides the least significant bit. This design can be utilized for applications such as digital signal processing or error detection in serial data transmission.
module top_module(
    input clk,
    input serial_in,
    output reg serial_out,
    output reg q
);
