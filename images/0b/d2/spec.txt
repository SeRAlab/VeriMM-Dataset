Design a 16-bit SRAM cell with read and write capabilities. The SRAM should have a 16-bit data input (D), a 16-bit data output (Q), an address input (ADDR), a write enable (WE), and a clock signal (CLK). When WE is high, the input data D should be written to the memory location specified by ADDR on the rising edge of CLK. When WE is low, the data at the memory location specified by ADDR should be output to Q on the rising edge of CLK.
