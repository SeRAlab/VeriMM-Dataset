

Write a Verilog module that implements a 2-to-1 multiplexer with the following interface:

```
module mux2to1
  (
   input a,
   input b,
   input sel,
   output reg out
   );
endmodule
```

The `a` and `b` inputs are single-bit signals that are to be selected based on the value of the `sel` input. If `sel` is 0, the output should be equal to `a`, and if `sel` is 1, the output should be equal to `b`.

Your implementation should use a `case` statement.
