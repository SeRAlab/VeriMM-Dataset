Design a Verilog module that implements an 8-bit parallel load register. The register loads data from an 8-bit input (d) when the load_enable signal is high on the positive clock edge, and retains its value otherwise. It also has an active-high reset signal that sets the register to zero.
module parallel_load_reg (
	input clk,
	input reset,
	input load_enable,
	input [7:0] d,
	output reg [7:0] q);
