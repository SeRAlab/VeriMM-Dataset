Design a 32-bit program counter that updates its output based on the clock signal. On the negative edge of the clock, it captures the incoming 32-bit input value. On the positive edge of the clock, if the reset signal is low (inactive), it assigns the captured value to the output; if the reset signal is high (active), it sets the output to zero.
module top_module(
	input wire clock,
	input wire[31:0] in,
	input wire reset,
	output reg[31:0] out
);
