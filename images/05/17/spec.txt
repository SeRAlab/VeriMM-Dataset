
Design an interrupt controller that has 3 interrupt requests (IRQ0, IRQ1, IRQ2) and a global interrupt enable signal (GIE). The controller should output a single interrupt signal (INT) that goes high when any of the IRQs are active and GIE is also high. The INT signal should be latched until it is acknowledged by the processor via an Acknowledge signal (ACK). The INT signal should only go low when all IRQs are inactive and GIE is low.
