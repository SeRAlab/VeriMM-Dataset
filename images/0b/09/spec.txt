Design a Cryptographically Secure Pseudo-Random Number Generator (CSPRNG) using a Linear Feedback Shift Register (LFSR) architecture. The CSPRNG should utilize a 5-bit LFSR with taps at positions 5 and 3. The circuit should output a 1-bit random number on each clock cycle and should have an enable signal to start and stop the generation. The output should be resettable, such that after resetting, the output should start from a predefined seed value.
