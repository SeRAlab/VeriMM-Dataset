
Design a Verilog module that acts as a simple temperature sensor comparator. The module should take a 5-bit binary input representing the temperature in degrees Celsius. If the temperature exceeds a threshold of 20 degrees Celsius (represented as 10100 in binary), the output should be '1' (indicating an overheating condition) or '0' (indicating normal conditions). Create the module with an input `temp` and an output `overheat`.
