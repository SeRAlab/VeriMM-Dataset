Design a simple Direct Memory Access (DMA) controller that transfers data from a source address to a destination address in memory. The controller should have a start signal to initiate the transfer, and it should transfer one byte of data on each clock cycle until the specified byte count is reached. The inputs are the source address (`src_addr`), destination address (`dst_addr`), byte count (`byte_count`), and a `start` signal. The output is a `done` signal that indicates when the transfer is complete.
