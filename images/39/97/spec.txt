
Design a state-space controller in Verilog that takes a 3-bit state representation and a 2-bit control input. The controller should transition between states based on the control input and produce a 3-bit output representing the next state. The state transition is defined as follows: 
- If the current state is 000 and control input is 00, next state is 001.
- If the current state is 001 and control input is 00, next state is 010.
- If the current state is 010 and control input is 00, next state is 011.
- If the current state is 011 and control input is 00, next state is 100.
- If the current state is 100 and control input is 00, next state is 000.
- Similarly, define transitions for control inputs 01, 10, and 11 to cycle through states differently.
