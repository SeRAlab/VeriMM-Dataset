Design a branch hazard detector for a pipelined processor. The module generates two outputs, `branch_flushD` and `branch_flushE`, to manage control signals for flushing pipeline stages in the presence of potential hazards. The `branch_flushD` signal indicates a need to flush the decode stage when a jump instruction requires a register or there is a misprediction. The `branch_flushE` signal determines if the execution stage should be flushed based on conditions involving the register writes from the execute and memory stages, specifically when register write enables and corresponding register addresses match those from the decode stage inputs. This ensures the correct execution of branch instructions and maintains pipeline integrity.
