
Design a 7-stage pipeline for a simple arithmetic operation (addition and subtraction) with the following stages: 
1. Instruction Fetch (IF)
2. Instruction Decode (ID)
3. Execute (EX)
4. Memory Access (MEM)
5. Write Back (WB)
6. Pipeline Register (PR)
7. Output Stage (OS)

The pipeline should take in an instruction (indicative of an operation) and two operands, and output the result after processing through all stages.
