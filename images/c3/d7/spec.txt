
You are tasked with designing a module in Verilog that takes in 5 inputs and produces 1 output. The module should be named `parity` and should output a 1 if the number of 1's in the inputs is odd, and a 0 if the number of 1's is even. The inputs should be named `a`, `b`, `c`, `d`, and `e`. 

Your module should be designed to be easily testable, meaning that it should be possible to write a testbench that verifies that the module works correctly. 

You should write a module that is no more than 200 lines of Verilog code.
