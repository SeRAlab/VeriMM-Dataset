
Design a fixed-priority arbiter in Verilog that controls access to a shared resource. The arbiter should have three request inputs (req0, req1, req2) and one grant output (grant). The priority order is req0 > req1 > req2. The arbiter should grant access based on the requests, and it should only grant one request at a time. If multiple requests are received simultaneously, the one with the highest priority should be granted.
