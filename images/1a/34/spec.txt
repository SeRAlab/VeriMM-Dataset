Design a simple state machine that represents a robot navigating through a grid. The robot can move in four directions: Up, Down, Left, and Right. The state machine should take in a direction input and an enable signal. If the enable signal is high, the current state (position of the robot) should update according to the direction input. The state is represented by a 2-bit value indicating the row and column of the grid (0-3 for both row and column), allowing traversal within a 4x4 grid.
