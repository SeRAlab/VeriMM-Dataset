Design a Verilog module that performs matrix multiplication of two 2x2 matrices. The two matrices are given as inputs and the output is the resultant 2x2 matrix. The input and output matrices are defined as follows:
- Input A: 2x2 matrix (A[0][0], A[0][1], A[1][0], A[1][1])
- Input B: 2x2 matrix (B[0][0], B[0][1], B[1][0], B[1][1])
- Output C: 2x2 matrix (C[0][0], C[0][1], C[1][0], C[1][1]) where C = A * B
