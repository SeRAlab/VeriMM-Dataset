Design a 4-to-1 multiplexer that selects one of four input signals (in0, in1, in2, in3) based on two select lines (sel0 and sel1). The output will reflect the selected input: when sel0 and sel1 are both low, the output is in0; when sel0 is low and sel1 is high, it outputs in1; when sel0 is high and sel1 is low, it outputs in2; and when both select lines are high, it outputs in3. This module is suitable for applications requiring data routing from multiple sources to a single output line.
module top_module(
    out,
    in0,
    in1,
    in2,
    in3,
    sel0,
    sel1
);
