

You are tasked with designing a module that implements a flip-flop with set and clear capabilities. The module should have the following inputs and outputs:

Inputs:
- `CLK`: a clock signal
- `D`: a data input
- `SET`: a set signal
- `CLR`: a clear signal

Outputs:
- `Q`: the output of the flip-flop

The module should operate as follows:
- When `SET` is high, the output `Q` should be set to high, regardless of the value of `D`.
- When `CLR` is high, the output `Q` should be set to low, regardless of the value of `D`.
- When both `SET` and `CLR` are low, the output `Q` should follow the input `D` on the rising edge of the clock signal `CLK`.

You should implement this module in Verilog, using no more than 200 lines of code.
