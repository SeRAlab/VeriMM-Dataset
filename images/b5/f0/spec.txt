Design a register that captures and holds 8 bits of data. Upon receiving a positive clock edge, the register resets to zero if the reset signal is active. If the reset is not active and the write enable signal (wenb) is low, the register updates its value with the incoming data (in_data). If wenb is high, the register retains its current value. This module effectively functions as a register with reset and write enable capabilities for managing fault status data.
