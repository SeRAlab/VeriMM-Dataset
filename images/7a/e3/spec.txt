Design a countdown timer circuit that decrements a 32-bit register on each clock cycle when enabled (EN) and resets to zero on a reset signal (RST). The timer can be preset to a specific value using the PRESET signal and the PRESET_VAL input. The output signal ZERO indicates when the timer has reached zero, providing a high signal when the countdown is complete.
module top_module(
  input RST,
  input CLK,
  input PRESET,
  input EN,
  input [31:0] PRESET_VAL,
  output ZERO
);
