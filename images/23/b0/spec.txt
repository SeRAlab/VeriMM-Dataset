Design a FIFO (First-In-First-Out) queue with a depth of 4. The FIFO should have the following ports: a clock input (`clk`), a reset input (`rst`), a data input (`data_in`), a write enable input (`wr_en`), a read enable input (`rd_en`), and an output for the data (`data_out`). The FIFO should output the data that is read and manage the queue's internal state to maintain the order of the data. It should also have a flag for full and empty conditions.
