Design a 2nd-order IIR filter in Verilog. The filter takes a 16-bit signed input sample and produces a 16-bit signed output sample based on the following difference equation:  
y[n] = a1 * y[n-1] + a2 * y[n-2] + b0 * x[n] + b1 * x[n-1].  
Assume the coefficients a1, a2, b0, and b1 are fixed values. The filter should have a clock input and a reset input.
