Design a module that performs multiple logical operations on two 3-bit input vectors, `a` and `b`. The module generates a 3-bit output representing the result of a bitwise OR operation between `a` and `b`, outputs a single bit indicating if any corresponding bits from `a` or `b` are high (logical OR), produces a 6-bit output consisting of the NOT values of both `a` and `b`, and finally combines the results of the bitwise OR and logical OR into a 4-bit output. This design serves to provide both bitwise and logical operations along with negation functionality in a compact form.
module top_module(
    input [2:0] a,
    input [2:0] b,
    output [2:0] out_or_bitwise,
    output out_or_logical,
    output [5:0] out_not,
    output [3:0] out_final
);
