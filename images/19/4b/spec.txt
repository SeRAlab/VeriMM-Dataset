Design a Verilog module that implements a run-length encoding (RLE) compression algorithm. The module should take a sequence of bits as input and output the run-length encoded result. The input will be a stream of bits (1s and 0s), and the output should include the number of consecutive bits of the same value followed by the value itself. For instance, if the input is '000111', the output should be '3 0 3 1'. The module should have a clock and reset input. On each rising edge of the clock, if reset is low, it should process one bit of input and produce the corresponding output. The module must handle inputs up to a maximum size of 64 bits.
