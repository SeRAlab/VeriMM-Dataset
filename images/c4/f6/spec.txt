Please act as a professional Verilog designer. Your task is to create a Verilog module that implements clock gating cells. 
Clock gating is a technique used to reduce power consumption in digital circuits. 
In clock gating, the clock signal to a circuit block is turned off when the block is not in use. 
This reduces the amount of power consumed by the circuit, as well as reducing the amount of heat generated by the circuit.

Your module should have the following inputs and outputs:

Inputs: 
1. clock signal (clk)
2. enable signal (en)

Outputs: 
1. gated clock signal (gclk)

Your module should implement the following functionality:

When the enable signal is high, the gated clock signal should be the same as the clock signal.
When the enable signal is low, the gated clock signal should be 0.

To implement the clock gating cells, you should use Verilog code to define the logic for the gated clock signal. 
You should use an AND gate to combine the clock signal with the enable signal. 
The output of the AND gate should be the gated clock signal. 
When the enable signal is low, the output of the AND gate will be 0, which will turn off the clock signal.
