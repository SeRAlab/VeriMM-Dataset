
Design a Verilog module for a simple Flash memory cell that can be either in a programmed state (logic '1') or erased state (logic '0'). The module should have a clock input, a reset input, a write input for programming the cell, and a read output to output the current state of the memory cell. The behavior should be as follows:
- On reset, the memory cell should be in the erased state (logic '0').
- On the rising edge of the clock, if write input is high (logic '1'), the memory cell should transition to the programmed state (logic '1').
- If write input is low (logic '0'), the memory cell retains its current state.
- The read output should always reflect the current state of the memory cell.
