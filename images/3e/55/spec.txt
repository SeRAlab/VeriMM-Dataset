Design a 2x Phase Locked Loop (PLL) system in Verilog that takes an input clock signal and generates an output clock signal that is twice the frequency of the input clock. The PLL should include a phase detector, a low-pass filter, and a voltage-controlled oscillator (VCO). The VCO should output a clock that toggles at the desired frequency based on a control voltage signal that is derived from the phase detector's output.
