Design an 8-bit DRAM cell with read and write functionalities. The DRAM cell should be able to store an 8-bit value and be controlled by a write enable signal. The cell will have an input for the data to write, an address input, a read enable signal, and an output for the stored data. The DRAM cell should behave as follows: when the write enable signal is high, the input data is written to the cell at the specified address; when the read enable signal is high, the data from the specified address is outputted. The addressing should allow for up to 256 different 8-bit cells, corresponding to the address range of 0-255.
