Design a simple arithmetic calculator that performs addition or subtraction on two 8-bit inputs, a and b. The operation is selected by the op input, where op=0 triggers addition (a + b) and op=1 triggers subtraction (a - b). The result is updated on the rising edge of the clock and resets to zero when the rst signal is high.
module top_module(
    input clk,
    input rst,
    input [7:0] a,
    input [7:0] b,
    input op,
    output reg [7:0] result
);
