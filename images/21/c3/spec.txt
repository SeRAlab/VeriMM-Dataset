Design a 1-bit SRAM cell that can store a single bit of data. The SRAM cell should have inputs for data (D), read enable (RE), and write enable (WE). When WE is high, the value of D should be stored in the SRAM cell. When RE is high, the stored value should be output on the Q line. If both RE and WE are low, the output Q should hold the last stored value.
