Design a circuit that outputs the result of combining two logical operations: a three-input AND gate processing inputs A1, A2, and A3, and a two-input AND gate processing inputs B1 and B2. The final output, X, is the result of an OR operation applied to the outputs of these two AND gates. This module effectively implements a combinational logic function where X is high if either the first group of inputs (A1, A2, A3) produces a high output or the second group (B1, B2) produces a high output.
module top_module(
    input A1,
    input A2,
    input A3,
    input B1,
    input B2,
    output X
);
