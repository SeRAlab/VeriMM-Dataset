Design a 2-to-4 line decoder that activates one of four output lines based on a 2-bit input when the enable signal is asserted. If the enable signal is low, all output lines are set to low. When enabled, the module generates a one-hot encoded output corresponding to the binary value of the input, effectively turning on precisely one of the four outputs for input values 00 through 11.
module top_module(
    input enable,
    input [1:0] in,
    output reg [3:0] out
);
