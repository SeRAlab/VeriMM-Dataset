

You are tasked with designing a 2-bit comparator using Verilog. The module should have two 2-bit inputs, A and B, and one 2-bit output, EQ. The EQ output should be high when A and B are equal and low otherwise. You are given the following code snippet as a starting point:

```
module comparator (
    A,
    B,
    EQ
);

    input [1:0] A;
    input [1:0] B;
    output reg EQ;

    // Your code here

endmodule
```

You can assume that the inputs A and B will always be valid 2-bit values.
