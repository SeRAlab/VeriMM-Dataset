Design a module to generate immediate values from a 32-bit instruction based on the opcode. The module extracts a 64-bit immediate value (imm_data) and a 12-bit immediate value (imm_data12) depending on different instruction types (load, arithmetic, store, and branch) indicated by the opcode. It uses bit manipulation and conditionally selects the appropriate bits from the instruction to construct the immediate values, thereby enabling the execution of various types of operations in a RISC-V computational context.
module top_module(input [31:0] ins, output [63:0] imm_data, output [11:0] imm_data12);
