

You are tasked with designing a verilog module that performs a bitwise XOR operation on two 8-bit inputs. The module should have the following interface:

Inputs:
- A (8-bit unsigned integer)
- B (8-bit unsigned integer)

Outputs:
- Z (8-bit unsigned integer)

The module should be named "XOR_8". You should use the "wire" keyword to create the internal signals.

Write a verilog module that meets these specifications.
