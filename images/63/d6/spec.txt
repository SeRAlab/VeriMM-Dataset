Design a register file that supports reading and writing to an array of six 32-bit registers. The module utilizes a clock signal for synchronization, allowing data to be written into a specified register when the write signal is asserted, provided the destination register index is within bounds. Two separate read operations are performed, outputting the contents of specified registers (ReadRegID1 and ReadRegID2) while avoiding any read from a register at index zero. This design serves as a component typical in CPU architectures for temporary data storage and retrieval.
