Design a circuit that compares two 4-bit inputs, A and B. If A is less than B, the output C is the sum of A and B. If A is greater than B, C is the result of subtracting B from A. If A is equal to B, C outputs the bitwise OR of A and B. The output C is 5 bits wide to accommodate the possible values from the addition.
module top_module(
  input [3:0] A,
  input [3:0] B,
  output reg [4:0] C
);
