Design a circuit that performs an 8-bit binary addition of two inputs, A and B, generating an 8-bit output Sum. Additionally, it detects if an overflow occurs during the addition, indicating whether the result exceeds the maximum representable value for 8 bits. The Overflow output is a single signal that is high if an overflow occurs, based on the carry out of the most significant bit.
module top_module(
    input [7:0]A,
    input [7:0]B,
    output [7:0] Sum,
    output Overflow
    );
