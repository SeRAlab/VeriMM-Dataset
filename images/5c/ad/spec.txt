Create a Verilog module that outputs the 8-bit OR result of two 8-bit inputs a and b when the enable signal is high. The output or_result should be reset to 0 when the reset signal is high.

module or_module (
    input [7:0] a,
    input [7:0] b,
    input enable,
    input reset,
    output reg [7:0] or_result);
