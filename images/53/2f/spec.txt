Design a D flip-flop with asynchronous set and reset functionality. When the clock signal (CLK) rises, if the SET input is high, the output Q is set to high (1) and Q_N to low (0). If the RESET input is high, Q is set to low (0) and Q_N to high (1). If neither SET nor RESET is active, Q is updated to reflect the value of the D input, while Q_N outputs the complementary value of D. This module can be utilized in digital systems for state storage and control.
module top_module(
    input D,
    input CLK,
    input SET,
    input RESET,
    output reg Q,
    output reg Q_N
);
