Design a 4-bit linear feedback shift register (LFSR) based random number generator. When the reset signal is active low, it initializes the register to the value 15 (1111 in binary). On each rising edge of the clock, the output register is updated with a new value derived from the current state using a feedback mechanism, specifically employing bits 3 and 1 for feedback. The resulting 4-bit output on `rand_out` provides a pseudo-random sequence.
module top_module(
	input clk, 
	input resetn, 
	output [3:0] rand_out);
