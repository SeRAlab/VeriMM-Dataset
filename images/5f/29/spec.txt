Design a circuit that performs an 8-bit barrel shift operation. The module takes an 8-bit input (DATA) and a 3-bit input (SHIFT_AMOUNT) to determine how many positions to shift. The SHIFT_DIRECTION input controls the direction of the shift: when SHIFT_DIRECTION is 0, the data is left shifted; when SHIFT_DIRECTION is 1, the data is right shifted. The result of the shift operation is output as SHIFTED_DATA.
module top_module(
    input [7:0] DATA,
    input [2:0] SHIFT_AMOUNT,
    input SHIFT_DIRECTION,
    output [7:0] SHIFTED_DATA
);
