Design a one-bit wide, 2-to-1 multiplexer that selects between two input signals. When the select line (sel) is low (0), the output will be equal to input in1; when sel is high (1), the output will be equal to input in2. The output is generated as a reg type, allowing it to be updated in response to changes in the inputs or selector line.
module top_module(
  input in1,
  input in2,
  input sel,
  output reg out
);
