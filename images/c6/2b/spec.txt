
You are tasked with designing a verilog module that implements a 16-bit adder-subtractor. The module should have four inputs: two 16-bit operands (A and B), a control signal (C), and a clock signal (CLK). The control signal C is a single bit that determines whether the operation performed is addition or subtraction. If C is 0, the module should perform addition; if C is 1, the module should perform subtraction. The output of the module should be a 16-bit result (R).
