Create a Verilog module for a 16-bit register with an asynchronous negative edge triggered reset, an enable signal, and a synchronous active high load signal. The register should load data from the input when load is high.
(1) reset: Resets the register to zero.
(2) enable: Enables the register.
(3) load: Loads the register with a 16-bit value from input "data".
(4) data: 16-bit data input to the register.
(5) q: The current content of the register.
