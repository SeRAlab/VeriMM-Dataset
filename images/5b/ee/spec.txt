Design a 4-bit binary adder-subtractor with an additional control input to determine the operation mode. When the Sub input is low, the module performs addition of input A and B, producing the result in the output Sum, while indicating no borrow. When the Sub input is high, the module instead performs subtraction, calculating the difference of A and B, and sets the Borrow output to indicate if a borrow occurred (i.e., if A is less than B).
module top_module(
  input [3:0] A,
  input [3:0] B,
  input Sub,
  output reg [3:0] Sum,
  output reg Borrow
);
