Design an 8-bit adder with an enable signal. When the enable input is high, the circuit adds two 8-bit inputs (a and b) and outputs a 9-bit sum. If the enable signal is low, the output will be zero. The additional bit in the output accommodates potential carry from the addition.
module top_module(
    input [7:0] a,
    input [7:0] b,
    input enable,
    output reg [8:0] sum
);
