Design a fan speed control system that adjusts the speed based on temperature readings. The system has a clock input, a reset input, and a temperature input. The fan speed is controlled by the following rules: If the temperature is below 20°C, the fan runs at low speed (1). If the temperature is between 20°C and 30°C, the fan runs at medium speed (2). If the temperature is above 30°C, the fan runs at high speed (3). Implement this using a state machine.
