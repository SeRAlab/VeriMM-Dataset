

You are tasked with designing a Verilog module that takes in a 24-bit input and outputs the same 24-bit value. The module should be named `data_pass_module` and should have the following ports:

- `input [23:0] data_in`: the 24-bit input
- `output [23:0] data_out`: the 24-bit output

The module should be able to handle a maximum clock frequency of 50MHz.

In addition, the module should have the following behavior:

- On the rising edge of the clock, the input value should be latched into the module.
- On the falling edge of the clock, the latched input value should be output.

Your task is to write the Verilog code for the `data_pass_module` that satisfies the above requirements. Your code should be no more than 200 lines long.
