Design a D flip-flop with synchronous clear and set functionality. The flip-flop captures the input value D on the rising edge of the clock (CLK) and updates its output Q accordingly. If the synchronous clear signal (SCD) is asserted, Q is reset to 0 regardless of D. If the synchronous set signal (SCE) is asserted, Q is set to 1. The output Q_N represents the complement of Q. This module is useful for storing a single bit of data with control over its state through clear and set operations.
