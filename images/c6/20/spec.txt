

In digital circuit design, a NAND gate is a logic gate that produces a low output (logic 0) only if all its inputs are high (logic 1). Otherwise, it produces a high output (logic 1). In this problem, you are required to design a Verilog module for a 4-input NAND gate.

You should create a module named `nand4` with the following interface:

```
module nand4 (
    input A,
    input B,
    input C,
    input D,
    output Y
);
```

The inputs A, B, C, and D are single-bit binary signals, and the output Y is a single-bit binary signal. The module should implement the logic of a 4-input NAND gate, as described above.

You are not allowed to use any built-in Verilog operators or functions to implement the NAND gate. You should only use basic logic gates such as AND, OR, NOT, and XOR to implement the NAND gate.

Your Verilog module should be self-contained, meaning that it should not require any external modules or libraries. Your module should be solvable within 200 lines of Verilog code.
