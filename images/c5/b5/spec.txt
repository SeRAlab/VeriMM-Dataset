

You have been tasked with designing a module that implements a simple logic gate. The module should take in two inputs, A and B, and output the result of the logical AND operation on those inputs. The module should be designed to be easily integrated into larger circuits.

Your module should be named `and_gate` and should be written in Verilog. The module should have the following interface:

```
module and_gate (
    input A,
    input B,
    output Y
);
```

You should assume that A and B will be either 0 or 1, and that Y should be 1 only if both A and B are 1.
