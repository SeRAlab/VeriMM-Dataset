
Design a 4-deep FIFO (First In, First Out) queue in Verilog. The FIFO should have the following features:
- It should be parameterizable for the width of the data (e.g., 8 bits).
- The FIFO should have input (write) and output (read) control signals.
- It should include a full flag and an empty flag for indicating the status of the FIFO.
- The FIFO should allow for read and write operations to be performed in a synchronous manner.
