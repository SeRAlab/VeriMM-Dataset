
Design a fixed-priority arbiter in Verilog. The arbiter should take 4 request signals (req0, req1, req2, req3) and output a grant signal (grant) based on fixed priority: req0 has the highest priority, followed by req1, req2, and req3. If multiple requests are made simultaneously, the arbiter should grant the one with the highest priority. The implementation should also include a simple state machine to handle the grant logic.
