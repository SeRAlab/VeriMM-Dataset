If the directive EIC_USE_EXPLICIT_VECTOR_OFFSET is defined, the output IRQ number is calculated by subtracting a specified handler base address from the IRQ offset and then right-shifting the result by 4 bits. If this directive is not defined, the output directly concatenates two leading zero bits with the 6-bit IRQ vector to form the output.
