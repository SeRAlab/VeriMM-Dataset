Design a simple 8-bit calculator that performs basic arithmetic operations based on a 2-bit operation code (opcode). The module takes two 8-bit inputs, `a` and `b`, and uses the `opcode` to determine the operation: `00` for addition, `01` for subtraction, `10` for multiplication, and `11` for division. The result of the selected operation is output as an 8-bit value.
module top_module(
  input [7:0] a,
  input [7:0] b,
  input [1:0] opcode,
  output reg [7:0] result
);
