Design a 4-to-2 multiplexer with enable functionality. The module takes four input signals (A0, A1, A2, A3) and two select lines (S0, S1). When the enable signal (EN) is active, it selects one of the four inputs based on the values of the select lines; specifically, A0 is chosen when S0=1 and S1=0, A1 when S0=0 and S1=1, A2 when both select lines are low, and A3 when both are high. If the enable signal is not active, the output will always be low regardless of the select lines or inputs.
module top_module(
    input  wire A0,
    input  wire A1,
    input  wire A2,
    input  wire A3,
    input  wire S0,
    input  wire S1,
    input  wire EN,
    output wire X
);
