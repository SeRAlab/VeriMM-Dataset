Design a main control unit for a simple processor that decodes the 6-bit operation code (Op) to generate control signals for various operations. The module determines whether the instruction is an R-format (register operation), load word (lw), store word (sw), or branch equal (beq), and accordingly sets the output control signals: RegDst, ALUSrc, MemtoReg, RegWrite, MemRead, MemWrite, Branch, and two ALU operation signals (ALUOp1 and ALUOp2). By doing so, it facilitates appropriate data flow and operation execution within the processor's datapath based on the decoded instruction type.
module top_module(Op,RegDst,ALUSrc, MemtoReg, RegWrite,
MemRead, MemWrite,Branch,ALUOp1,ALUOp2);
