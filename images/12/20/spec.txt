Design an SR flip-flop using Verilog. The flip-flop should have two inputs (S and R) and two outputs (Q and Qn). The outputs should update on the rising edge of a clock signal. The behavior should be as follows: 
- If S=1 and R=0, then Q should be set to 1.
- If S=0 and R=1, then Q should be reset to 0.
- If S=0 and R=0, then Q should hold its previous state.
- If S=1 and R=1, it should be considered an invalid state, and Q should be set to 0.
