

You are tasked with designing a verilog module that takes in 3 input signals and produces 2 output signals. The module should be sensitive to the rising edge of a clock signal. The inputs and outputs are all 4-bit signals. The module should perform the following operations:

1. The first input signal should be multiplied by 2 and the result should be stored in the first output signal.
2. The second input signal should be divided by 4 and the result should be stored in the second output signal.
3. The third input signal should be added to the first output signal and the result should be stored in the first output signal.
4. The third input signal should be subtracted from the second output signal and the result should be stored in the second output signal.

The module should be named "multi_div_add_sub" and should have the following inputs and outputs:

Inputs:
- clk: a single bit clock signal
- in0: a 4-bit input signal
- in1: a 4-bit input signal
- in2: a 4-bit input signal

Outputs:
- out0: a 4-bit output signal
- out1: a 4-bit output signal
