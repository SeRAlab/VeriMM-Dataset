
You have been hired by a company to design a 4-bit adder circuit using Verilog. The circuit should take two 4-bit input numbers and produce a 5-bit output, where the first bit represents the carry-out bit. The company has specified that the circuit should be designed using only one module within 200 lines of Verilog code.

You should design a module named "four_bit_adder" that takes the following inputs and outputs:

Inputs:
- A (4-bit input)
- B (4-bit input)
- Cin (1-bit input)

Outputs:
- Sum (4-bit output)
- Cout (1-bit output)

The module should perform the addition of A and B, and add the value of Cin to the result. The output should be the Sum of the addition and the Cout (carry-out) bit.

You should also ensure that your module follows the following guidelines:
- The module should use only combinational logic.
- The module should be synthesizable and meet timing requirements for a 50 MHz clock.
- The module should be designed in such a way that it can be easily modified for adding more bits in the future.
