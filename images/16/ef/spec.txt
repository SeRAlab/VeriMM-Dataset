Design a 24-bit ADC (Analog to Digital Converter) controller in Verilog that accepts a 24-bit input signal and produces a 24-bit output signal. The controller should have a clock input and a reset input. On the rising edge of the clock, if reset is not asserted, the controller should load the input value into an internal register. The output should always reflect the value in the internal register. If the reset is asserted, the internal register should be cleared to zero.
