
Design an Automatic Repeat reQuest (ARQ) error correction module using Verilog. The module should accept a 5-bit data input and a 1-bit acknowledgment signal, and it should output the received data if the acknowledgment is high. If the acknowledgment is low, the module should hold the previous value of the data output until a new valid acknowledgment is received. The module should also have a reset signal to initialize the output to zero.
