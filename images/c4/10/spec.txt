

Write a Verilog module that implements a 5-input LUT and four D flip-flops. The module should have the following inputs and outputs:

Inputs:
- `in0`, `in1`, `in2`, `in3`, `in4`: 1-bit inputs
- `clk`: clock input
- `reset`: asynchronous reset input

Outputs:
- `q0`, `q1`, `q2`, `q3`: 1-bit outputs

The LUT should implement the following Boolean function:
```
f(in0, in1, in2, in3, in4) = in0 & in1 & in2 & in3 & in4
```
The flip-flops should be positive-edge triggered and should be initialized to 0 on reset.
