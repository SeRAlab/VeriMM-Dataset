Design a circuit that finds the maximum value between two 4-bit inputs, A and B, on the rising edge of the clock signal. The circuit outputs the maximum value on a 4-bit wide output and indicates which input was greater using a separate output signal: 'max_sel' is set to 1 if A is greater than B and set to 0 otherwise.
module top_module(
    input clk,
    input [3:0] A,
    input [3:0] B,
    output reg [3:0] max,
    output reg max_sel
);
