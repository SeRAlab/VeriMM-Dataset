

You are tasked with creating a module that takes in a 9-bit control signal and outputs a 4-bit td_mode signal based on the following truth table:

| Control Bits | td_mode |
|--------------|---------|
| 000          | 0000    |
| 001          | 1000    |
| 010          | 0100    |
| 011          | 1100    |
| 100          | 0010    |
| 101          | 1010    |
| 110          | 0101    |
| 111          | 1111    |

Create a Verilog module `td_mode_generator` that takes in a 9-bit control signal `ctrl` and outputs a 4-bit td_mode signal `td_mode`. Use a case statement to map the control bits to the appropriate td_mode value.
