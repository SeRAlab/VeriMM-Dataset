Design a dual 4-to-1 multiplexer that selects one of four 2-bit input values (inA, inB, inC, inD) based on a 2-bit select signal (sel). The module incorporates an enable signal (notIE) to control the output; when notIE is low, the selected input is passed to the output; when notIE is high, the output will be effectively disabled (set to 0). The output reflects the selected input after a specified propagation delay. This design enables flexible data routing in digital systems where multiple data sources need to be dynamically selected and output under control conditions.
