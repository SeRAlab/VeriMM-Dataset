Design a 4-bit ripple carry adder that computes the sum of two 4-bit binary inputs (A and B) along with a carry-in (Cin). The result is a 4-bit output (S) representing the sum, while the carry-out (Cout) indicates if there is an overflow beyond the 4-bit limit. The calculations are triggered on the positive edge of a clock signal, ensuring synchronous operation.
module top_module(
  input clk,
  input [3:0] A,
  input [3:0] B,
  input Cin,
  output [3:0] S,
  output Cout
);
