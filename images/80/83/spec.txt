Design a 2-to-1 multiplexer with priority control. The module selects between two 4-bit inputs, A and B, based on the priority signal P. When P is high (1), the output Y reflects the value of A; otherwise, Y takes the value of B. This design ensures that A has priority over B in determining the output.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input P,
    output reg [3:0] Y
);
