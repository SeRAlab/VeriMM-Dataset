Design a circuit that functions as a shift register or a simple binary counter based on the select input. When select is LOW, the module shifts in a 1-bit input (d) into a 3-bit shift register (shift_reg), effectively implementing a 3-bit serial-in parallel-out shift register. When select is HIGH, the module increments a 3-bit binary counter (counter) on each clock pulse. The output (q) reflects either the current state of the shift register or the counter, depending on the value of select.
module top_module( input clk, input d, input select, output [2:0] q );
