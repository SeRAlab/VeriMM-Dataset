Implement a simple cache with a Least Recently Used (LRU) replacement policy. The cache should consist of 4 lines, each capable of storing a single 8-bit data word. The system should take an 8-bit address input and a "write" signal. If the "write" signal is high, the data should be written to the cache at the specified address, replacing the least recently used line if necessary. If the "write" signal is low, the system should output the data stored in the cache for the given address.
