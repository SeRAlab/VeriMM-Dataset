Design an Infinite Impulse Response (IIR) filter that takes in a 16-bit signed input sample and produces a 16-bit signed output sample. The filter should have two coefficients, a and b, which will affect the output based on the previous output and the current input. The formula for the IIR filter is:  
output[n] = a * output[n-1] + b * input[n]  
where output[n-1] is the previous output, input[n] is the current input, and a and b are fixed-point coefficients. Ensure to handle the fixed-point arithmetic properly with appropriate bit shifts.
