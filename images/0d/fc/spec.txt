Design a 4-bit DRAM cell that can store and retrieve a 4-bit value. The DRAM cell should have a write enable signal (we), a read enable signal (re), a 4-bit data input (data_in), and a 4-bit data output (data_out). On the rising edge of the clock, if write enable is high, the data input should be stored in the cell. If read enable is high, the stored value should be output on data_out.
