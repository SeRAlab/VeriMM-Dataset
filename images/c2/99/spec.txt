
You are tasked with designing a module that implements a 4-bit counter with synchronous reset functionality. The module should have the following inputs and outputs:

Inputs:
- `CLK` (1-bit): Clock input
- `RST` (1-bit): Asynchronous reset input
- `EN` (1-bit): Enable input

Outputs:
- `Q` (4-bit): Counter output

When `EN` is high, the counter should increment on every positive edge of `CLK`. When `RST` is high, the counter should reset to zero, regardless of the value of `EN`. The counter should be initialized to zero when `RST` is low and `EN` is high.
