Design a Parallel-in Parallel-out (PIPO) shift register in Verilog that allows for loading a 5-bit input in parallel and shifting the bits out serially. The register should have a clock input, a load input to enable loading of the data, and an output for the shifted data. The behavior should shift the data left on each clock cycle when the load signal is low, and if the load signal is high, it should load the 5-bit data on the rising edge of the clock.
