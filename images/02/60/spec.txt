
Design a JK flip-flop in Verilog. The flip-flop should have inputs J, K, and a clock signal (CLK). The flip-flop should toggle its output Q based on the following conditions:
- If J = 1 and K = 0, Q should be set to 1.
- If J = 0 and K = 1, Q should be set to 0.
- If J = 1 and K = 1, Q should toggle its current state.
- If J = 0 and K = 0, Q should remain in its current state.
