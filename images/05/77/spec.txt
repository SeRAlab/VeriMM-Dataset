Design a temperature-based shutdown system that monitors the temperature of a device. The system should activate a shutdown signal when the temperature exceeds a predefined threshold. The temperature is represented as a 5-bit binary number (0 to 31 degrees Celsius), and the threshold is set to 25 degrees Celsius. The system should have an input for the current temperature, and a single output for the shutdown signal, which should be active high when the temperature exceeds the threshold.
