Design a 4-to-1 multiplexer with an enable signal. The module selects one of the four input signals based on a 2-bit select line; when the enable signal is high, the selected input is passed to the output. If the enable signal is low, the output is set to LOW regardless of the selected input.

                      input wire [1:0] sel,
                      input wire ena,
                      output reg out);
