
You are tasked with designing a verilog module that takes in 4 inputs and provides 2 outputs. The module should be named "parity_checker". The inputs are a 4-bit binary number "data_in", an active-low reset signal "rst", an active-high enable signal "en", and a clock signal "clk". The output signals are "even_parity" and "odd_parity". When "en" is high, the module should calculate the even and odd parity of the input and output the results. When "en" is low, the output should be held at the last calculated parity values. When "rst" is low, the output should be reset to 0.
