

Write a Verilog module that implements a 4-bit counter with a synchronous reset. The counter should increment on every positive edge of the clock signal. The counter should also have a synchronous reset input that resets the counter to zero when asserted. The module should have the following inputs and outputs:
- `clk`: clock input
- `reset`: synchronous reset input
- `count_out`: 4-bit output representing the current count value
