Design a 2-to-1 multiplexer that operates on 32-bit wide data inputs. The module selects between two 32-bit inputs, `input0` and `input1`, based on a single-bit `address` input. When `address` is 0, the output is assigned to `input0`; when `address` is 1, the output is assigned to `input1`.
module top_module(
output [31:0] out,
input         address,
input  [31:0] input0, input1
);
