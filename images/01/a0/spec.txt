Design a simple NVMe controller state machine that manages the command processing state. The controller should have the following states: IDLE, PROCESSING, and DONE. The controller receives a command input signal and transitions between these states based on the state machine logic. When a command is received, it transitions from IDLE to PROCESSING, and once the command is completed, it transitions to DONE. The state machine should also have a reset signal to return to IDLE state. Define the state transitions and output the current state.
