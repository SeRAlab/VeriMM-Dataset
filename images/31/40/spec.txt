
Design a state-space controller in Verilog that takes in a 4-bit input representing the state and produces a 4-bit output representing the control action. The controller should have a clock input and a reset input. The state transition should follow the following logic:
- From state 0000, if input is 0, remain in 0000; if input is 1, transition to state 0001.
- From state 0001, if input is 0, transition to state 0000; if input is 1, transition to state 0010.
- From state 0010, if input is 0, transition to state 0001; if input is 1, transition to state 0011.
- From state 0011, if input is 0, transition to state 0010; if input is 1, transition to state 0000.
The output should equal the current state.
