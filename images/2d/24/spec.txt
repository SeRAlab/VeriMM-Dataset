Design a Verilog module that implements LU decomposition for a 2x2 matrix. The input will be a 2x2 matrix represented as four separate inputs (a, b, c, d) and the output will be the decomposed L and U matrices represented as six outputs (l11, l21, u11, u12, u22). The LU decomposition should ensure that L is a lower triangular matrix and U is an upper triangular matrix.
