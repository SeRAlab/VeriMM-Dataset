Design a 4-bit arithmetic and logical unit (ALU) that performs four operations: addition, subtraction, logical AND, and logical OR. The module takes two 4-bit inputs A and B, a carry-in (CIN) for addition and subtraction, and a binary invert control (BINV) to optionally negate input B. Operation selection is managed via a 2-bit input (OP). The output includes a 4-bit result (Y) and a carry-out signal (COUT) that indicates overflow for addition and underflow for subtraction.
module top_module(
  input [3:0] A, B,
  input CIN, BINV,
  input [1:0] OP,
  output reg COUT,
  output reg [3:0] Y
);
