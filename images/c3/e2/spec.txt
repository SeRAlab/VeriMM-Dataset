

You are tasked with designing a verilog module that takes in a 4-bit input signal `in_signal` and outputs a 2-bit signal `out_signal`. The 2-bit output signal should represent the highest and lowest bits of the input signal.

Design the module `high_low` with the following ports:
- `input  logic [3:0] in_signal`
- `output logic [1:0] out_signal`

Ensure that your module has the following functionality:
- The highest bit of `in_signal` should be assigned to `out_signal[1]`.
- The lowest bit of `in_signal` should be assigned to `out_signal[0]`.
