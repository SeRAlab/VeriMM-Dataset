Implement a 4-bit binary to Gray code converter. On each rising edge of the clock, if the reset signal is low, the module computes the Gray code equivalent of the 4-bit binary input by performing a bitwise XOR operation between the input and a right-shifted version of itself. When reset is activated, the output is set to zero, ensuring the output starts from a known state. The resulting Gray code is then outputted continuously as long as the clock and reset conditions are met.

    input [3:0] bin,
    output [3:0] gray,
    input reset,
    input clk
);
