Design a dynamic range compression module in Verilog. The module should take a signed 16-bit input audio sample and produce a compressed output sample. The compression should be controlled by a parameter that defines the ratio of compression. For example, if the compression ratio is 2:1, an input of 4 should produce an output of 2, and an input of -4 should produce an output of -2. The module should also include an enable signal that activates the compression when high.
