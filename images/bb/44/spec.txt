Design a clock divider circuit that takes an input clock signal and divides its frequency by a programmable factor specified by a 24-bit input value, `clock_divider`. The output clock (`output_clock`) toggles to a high state once per full cycle of the divided clock period, while a counter is used to track the remaining cycles. The output is reset and updated on the rising edge of the input clock.
module top_module(
	input wire clock,
	input wire[23:0] clock_divider,
	output reg output_clock = 0
);
