Design a coprocessor with a small register file that can store three 32-bit registers (specifically registers 12, 13, and 14). This module allows for writing data into these registers based on input signals—when the write enable signal (`reg_we`) is asserted, data from `wdata` can be written to the specified register address (`reg_W_addr`), while the program counter input (`pc_i`) can be stored in register 14 when `EPCWrite` is asserted. Additionally, the coprocessor can store interrupt causes in register 13 if `CauseWrite` is activated. The module outputs the contents of the register specified by `reg_R_addr` and always provides the value of register 14 as `epc_o`. The functionality includes a reset mechanism to initialize registers 12 and 13 to zero upon receiving a reset signal.
