
Design a 16-bit DRAM cell module that supports read and write operations. The module should have the following inputs and outputs:
- Inputs: 
  - `clk`: clock signal
  - `we`: write enable signal (1-bit)
  - `addr`: address (4-bits, for addressing 16 locations)
  - `data_in`: data input (16-bits)
- Outputs:
  - `data_out`: data output (16-bits)
The behavior should be such that when `we` is high, the `data_in` is written to the specified `addr` at the rising edge of the clock. When `we` is low, `data_out` should reflect the value stored at the specified `addr`.
