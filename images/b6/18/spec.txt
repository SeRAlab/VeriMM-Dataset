Design a 2-to-4 line decoder that activates one of four output lines based on two input bits and an enable signal. When the enable signal is high (en=1), the output corresponding to the binary value of the input bits (a) will be set to high, while all other outputs will remain low. If the enable signal is low (en=0), all outputs will be low, effectively disabling the decoder's outputs.
