Implement a simple Model Predictive Control (MPC) system that predicts the next output based on the current state and a setpoint. The system should take a 4-bit signed input representing the current state, and a 4-bit signed input representing the setpoint. It will produce a 4-bit signed output representing the control action. The control action is computed as the difference between the setpoint and the current state, with saturation limits set to the range of -8 to 7.
