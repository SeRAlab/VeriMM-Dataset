Design a 24-bit Digital-to-Analog Converter (DAC) that takes a 24-bit input and produces a corresponding 8-bit output representing the analog voltage level. The output voltage is scaled such that an input of 0 corresponds to 0V and an input of 2^24-1 (16777215) corresponds to 5V. The output should be the integer value of the corresponding voltage level scaled to an 8-bit range (0 to 255). Use the formula: output = (input * 255) / 16777215.
