Design a 4th-order IIR filter that takes in a 16-bit signed input sample and outputs a 16-bit signed output sample. The filter should have the following coefficients: a[0] = 1, a[1] = -1.8, a[2] = 0.81, b[0] = 0.1, b[1] = 0.2, b[2] = 0.3, and b[3] = 0.4. Use fixed-point arithmetic for the operations.
