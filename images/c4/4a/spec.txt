

You are tasked with designing a module that will take in a 4-bit binary input and output the Gray code equivalent of that input. Gray code is a binary code where two consecutive values differ by only one bit. For example, the Gray code equivalent of 0010 (decimal 2) is 0110 (decimal 3). 

Design a verilog module that takes in a 4-bit binary input, converts it to Gray code, and outputs the Gray code equivalent. Your module should be named "gray_converter" and have the following inputs and outputs:

Inputs:
- `bin_in`: a 4-bit binary input

Outputs:
- `gray_out`: a 4-bit Gray code output

Assume that the input is valid (i.e., it will always be a 4-bit binary number).
