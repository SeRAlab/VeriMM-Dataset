Design a simple SPI controller that can send and receive data. The SPI controller should have the following inputs: a clock signal (clk), a reset signal (rst), a data input (data_in), and a chip select signal (cs). The output should be a data output (data_out) and a valid signal (valid). The controller should operate in a way that when cs is low, it shifts in data from data_in on the rising edge of clk and outputs it on data_out, while also asserting valid.
