Design a 4-to-1 multiplexer that accepts four 8-bit input data lines (data_in0, data_in1, data_in2, data_in3) and utilizes a 2-bit select signal to determine which input is routed to the 8-bit output (data_out). The selected input is output whenever the corresponding select input value is asserted, allowing for dynamic data selection based on the control signal.
module top_module(
    input [7:0] data_in0,
    input [7:0] data_in1,
    input [7:0] data_in2,
    input [7:0] data_in3,
    input [1:0] select,
    output reg [7:0] data_out
);
