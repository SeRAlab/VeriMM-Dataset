

You are tasked with designing a module that takes in four input signals and produces one output signal. The module should be named `my_module` and should have the following ports:

- `input A1`
- `input A2`
- `input B1`
- `input B2`
- `output X`

The output signal `X` should be equal to `1` if the following conditions are met:

- `A1` and `A2` are both equal to `1`
- `B1` and `B2` are both equal to `0`

Otherwise, the output signal `X` should be equal to `0`.

You are free to use any gates or combination of gates to implement the module, but the entire module must be contained within 200 lines of Verilog code.

Implement the `my_module` module and verify its functionality using a testbench.
