
Design a 2-channel DMA controller that can handle two data transfer requests. The controller should be able to select one of the two channels to transfer data from a source to a destination. Each channel will have its own request (req), acknowledge (ack), source address (src), and destination address (dst). The controller should output the selected channel's data when the transfer is complete. The controller should also implement a simple round-robin arbitration for channel selection.
