Design an 8-bit DRAM cell that can perform read and write operations. The DRAM cell should have the following inputs: `clk` (clock), `we` (write enable), `addr` (3-bit address), and `data_in` (8-bit data input). The outputs should be `data_out` (8-bit data output) and `ready` (indicating the DRAM is ready for the next operation). When `we` is high, the `data_in` should be written to the address specified by `addr`. When `we` is low, the data at the address specified by `addr` should be read to `data_out`. The `ready` signal should be high when an operation is complete.
