Design a 4-bit up/down counter that increments or decrements its count value based on control signals. The counter is clock-driven with a reset capability; upon receiving a reset signal, it initializes the count to zero. When enabled, if the control signal is high, the counter decrements; if the control signal is low, the counter increments.
module top_module(
    input clk,
    input rst,
    input en,
    input ctrl,
    output reg [3:0] count
);
