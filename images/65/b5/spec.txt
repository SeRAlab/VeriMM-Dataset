Design a synchronous 8-bit counter with reset and enable functionalities. The counter increments on each positive clock edge while the enable signal is high. It resets to zero either when the reset signal is low or when the clear signal is activated. Additionally, it generates a carry output that indicates when the counter has reached its maximum value of 255 (0xFF) while enabled and not cleared.
module top_module(
	input clk,
	input rst_n,
	output reg [7:0] counter,
	output C,
	input en,
	input clr
    );
