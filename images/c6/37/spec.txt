

You are tasked to design a module that implements a 2-to-1 multiplexer using Verilog. The module should have two inputs, `A` and `B`, and one select input, `S`. If `S` is 0, the output should be equal to `A`. If `S` is 1, the output should be equal to `B`.

You should define the module as follows:
```
module mux2to1 (
    input A,
    input B,
    input S,
    output X
);
```

The module should be self-contained, meaning that you should not reference any other modules or external libraries. You should also ensure that your solution is synthesizable and that it meets timing requirements.
