Design a combinational logic circuit with three inputs (a, b, and c) that generates a single output (q). The output logic is defined as follows: if input 'a' is HIGH, output 'q' is HIGH; if 'a' is LOW and 'b' is HIGH, output 'q' is LOW; if both 'a' and 'b' are LOW and 'c' is LOW, output 'q' is HIGH; otherwise, output 'q' follows the value of 'c'. This module effectively combines conditions to create a specific output behavior based on the state of the inputs.
module top_module(
    input wire a,
    input wire b,
    input wire c,
    output reg q
    );
