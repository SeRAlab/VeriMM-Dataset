

You are tasked with designing a module that takes in a 4-bit binary number and outputs its corresponding decimal value. The module should have two input ports and one output port. The first input port, A, is a 4-bit binary input that represents the number to be converted. The second input port, clk, is a clock signal with a frequency of 1 Hz. The output port, X, is a 3-bit decimal output that represents the decimal equivalent of the input binary number. You can assume that the binary number is always positive and that the input will only change on the rising edge of the clock signal.

You should design the module with the following specifications:
- Use Verilog to design the module.
- The module should be self-contained and not require any additional modules.
- The module should use combinational logic to convert the binary input to decimal output.
- The module should be synchronous and only update the output on the rising edge of the clock signal.
- The module should use the following equation to convert the binary input to decimal output: X = 2^0 * A[0] + 2^1 * A[1] + 2^2 * A[2] + 2^3 * A[3].

Implement the module and verify its functionality with a testbench.
