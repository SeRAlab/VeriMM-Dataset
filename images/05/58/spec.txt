
Design a fan speed controller that adjusts the fan speed based on the temperature sensor input. The device has three speed settings: 00 (Off), 01 (Low), 10 (Medium), and 11 (High). The fan speed should increase as the input temperature increases. The temperature input is a 2-bit binary number representing the range from 0 to 3 (00 for 0°C, 01 for 1°C, 10 for 2°C, 11 for 3°C). The fan speed state should hold its value until the temperature input changes.
