Design a current sensor circuit that takes a 4-bit binary input representing an analog current level and outputs a 3-bit binary code representing the status of the current. The output should indicate if the current level is low, medium, or high based on predefined thresholds. For example, if the input is less than 4 (0000 to 0011), output should be 3'b000 (low), if the input is between 4 and 11 (0100 to 1011), output should be 3'b001 (medium), and if the input is greater than 11 (1100 to 1111), output should be 3'b010 (high).
