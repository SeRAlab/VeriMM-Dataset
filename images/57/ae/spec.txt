Design a D flip-flop with asynchronous active-low reset and clear functionality. On the rising edge of the clock, if the reset signal is low, the output q is set to LOW; otherwise, it takes the value of the input din. Additionally, if the clear signal is asserted high at any time, the output q is immediately set to HIGH, overriding the clock and reset conditions. This component is useful in synchronous digital circuits requiring state retention with specific reset and clear controls.
module top_module(
  input din,
  input clk,
  input reset,
  input clear,
  output reg q
);
