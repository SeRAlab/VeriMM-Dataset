Design a 4-to-1 multiplexer that selects one of four input signals (a, b, c, or d) based on the values of two selection inputs (sel_1 and sel_0). When both selection inputs are low, output a; when sel_1 is low and sel_0 is high, output b; when sel_1 is high and sel_0 is low, output c; and when both selection inputs are high, output d. The output is updated whenever there is a change in the inputs due to the sensitivity of the always block.
module top_module(
    input a,
    input b,
    input c,
    input d,
    input sel_1,
    input sel_0,
    output reg out_always
);
