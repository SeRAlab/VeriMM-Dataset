Design a 1-bit DRAM cell which can store a single bit of data. The cell should have the following ports: 
- `data_in` (input): the bit to be stored or written.
- `data_out` (output): the bit that is currently stored in the cell.
- `we` (input): write enable signal, which allows writing to the cell when high.
- `clk` (input): clock signal to control the timing of writes and reads.
The DRAM cell should retain its value until a write operation is performed. Implement a synchronous behavior for writing and reading data from the cell.
