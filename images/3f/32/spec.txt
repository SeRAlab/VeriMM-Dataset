
Design a Serial-in Parallel-out (SIPO) shift register in Verilog. The SIPO shift register takes a serial input `data_in`, a clock signal `clk`, and a reset signal `rst`. It outputs the current state of the register as `data_out`, which has a width of 5 bits. The register should shift in the serial data on each rising edge of the clock, and it should load new data when reset is low.
