Design a dual-purpose 8-bit data memory module that functions as a read-write memory. The module allows data to be written to or read from an array of memory locations (256 in total), based on the provided address input. When the write enable signal is active, incoming data is stored at the specified address; when not writing, the currently stored data at that address is output in a tri-state manner. Additionally, a reset signal initializes the entire memory to zero, ensuring all data is cleared. This facilitates interaction with other components in a digital system, serving as a basic memory block for data storage and retrieval operations.
