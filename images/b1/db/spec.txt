Design a 4-bit adder/subtractor circuit that operates based on a control signal (M). When M is low, the circuit performs addition of inputs A and B and generates a carry output (C) if an overflow occurs. When M is high, it performs subtraction, indicating a borrow through the carry output if A is less than B. The circuit is synchronous, responds to the rising edge of the clock (CLK), and can be reset to zero using the reset signal (RST).
module top_module(
  input [3:0] A,
  input [3:0] B,
  input M,
  input CLK,
  input RST,
  output reg [3:0] S,
  output reg C
);
