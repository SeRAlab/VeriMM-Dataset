Design a 3-bit up/down counter that increments or decrements its count based on the `up_down` control signal. On each positive clock edge, if `reset` is asserted, the count resets to zero; otherwise, the counter will increment when `up_down` is high or decrement when it is low. The output `max_reached` indicates when the counter has reached its maximum value of 7 (binary 111).
module top_module(
    input clk,
    input reset,
    input up_down,
    output reg [2:0] count,
    output max_reached
);
