Design a circuit that functions as a clock-controlled multiplexer, alternating between two data inputs, data_in_a and data_in_b, based on a toggling state driven by a clock signal and an enable flag. When enabled, the state toggles on each positive edge of the clock; if the enable signal is inactive, the state is fixed to one. The output data_out reflects the selected input data based on the current state, ultimately allowing for controlled switching between the two inputs while synchronizing with the clock.
module top_module(
	data_in_a, 
	data_in_b, 
	clk, 

	enable, 
	data_out
);
