Design a 1-bit DRAM cell in Verilog which includes a data input (D), a word line (WL), a bit line (BL), and a read/write control line (RW). The DRAM cell should store a single bit of data and be able to read from and write to the cell depending on the control signals. If RW is high, the data should be written to the cell when WL is high. If RW is low, the data should be read from the cell when WL is high, and the output should be reflected on BL.
