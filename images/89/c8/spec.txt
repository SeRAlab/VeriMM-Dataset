Implement a 16-bit wide barrel shifter. The module takes a 16-bit input and a 4-bit shift amount to either left or right shift the input based on the value of the shift_left control signal. If shift_left is asserted, the input is shifted to the left by the specified number of positions, with the vacant bits filled by zeros. Conversely, if shift_left is not asserted, the input is shifted to the right in a similar manner. The output reflects the result of the shift operation.
module top_module(
    input [15:0] in,
    input [3:0] shift_amt,
    input shift_left,
    output reg [15:0] out
);
