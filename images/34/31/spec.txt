Design a data forwarding unit for a processor that detects data hazards in a pipelined architecture. The unit should take inputs for register addresses, the values of the registers, and output the forwarded data if a hazard is detected. The inputs include two source register addresses (src1, src2), a destination register address (dest), and the value of the destination register (data_out). If either src1 or src2 matches dest, the corresponding forwarded data must be output. Otherwise, the output should be zero. Ensure that your design can handle all cases of hazards.
