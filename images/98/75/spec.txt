Design a dual-port block memory module that supports both read and write operations. On the rising edge of the clock (clka), if the write enable (wea) is asserted, the input data (dina) is stored in the memory at the specified address (addra). Regardless of the write operation, the output data (douta) is updated to reflect the contents of the memory at the address indicated by addra, enabling the retrieval of stored data simultaneously. This module can store 2048 locations of 12-bit wide data, making it suitable for applications that require efficient data storage and retrieval.

     addra,
