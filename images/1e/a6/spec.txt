Design a 5-stage pipelined processor that performs a simple arithmetic operation (addition) on two 5-bit inputs. The stages are: Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). The processor should support a simple operation where an operation code (opcode) will determine whether to add or perform a no operation (NOP). The opcode for addition is `2'b00` and for NOP is `2'b01`.
