Design a basic arithmetic calculator module that performs four operations: addition, subtraction, multiplication, and division on two 8-bit input numbers (num1 and num2). The operation to be performed is selected via a 2-bit control signal (op) and is clocked by a rising edge. The module outputs the computed result and a validity flag indicating whether the output is valid, which is reset in case of a reset signal.
module top_module(clk, rst, op, num1, num2, result, valid);
