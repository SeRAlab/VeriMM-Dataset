Design a simple Verilog module that performs a basic MD5-like transformation on a 32-bit input value. The module should take a 32-bit input value and a 1-bit control signal. When the control signal is high, the module should output the transformed value, which is the input value XORed with a constant value (for simplicity, use `32'hA0A0A0A0`). The module should have a reset signal that resets the output to zero.
