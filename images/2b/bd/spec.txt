
Design a 16-bit SRAM cell that supports the following operations:
1. Write operation: When the write enable (WE) signal is high, the data input (D) should be written to the SRAM cell.
2. Read operation: When the read enable (RE) signal is high, the data stored in the SRAM cell should be output to the data output (Q).
The SRAM cell should have a reset functionality that initializes the stored value to zero when the reset (RST) signal is high.
