Design an 8-bit SRAM memory cell that can read and write data. The SRAM cell should have inputs for a write enable signal (we), an 8-bit data input (data_in), an 8-bit data output (data_out), and a clock signal (clk). The memory should store the data when the write enable signal is high and the clock has a rising edge. When the write enable is low, the output should always reflect the stored data.
