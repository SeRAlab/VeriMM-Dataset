When the input is 00, the first output (out0) is set high; when the input is 01, the second output (out1) is set high; for 10, the third output (out2) is high; and for 11, the fourth output (out3) is activated. This module effectively translates a binary input to a single active output line, serving as a key component for larger digital systems that require signal routing or selection.
module top_module(
    input [1:0] in,
    output reg out0,
    output reg out1,
    output reg out2,
    output reg out3
);
