Design a SPI controller that can send and receive data. The controller should have a clock input, a chip select (CS) input, a data input (MOSI), and a data output (MISO). The controller should operate in mode 0 (CPOL = 0, CPHA = 0) and should be able to send an 8-bit command followed by an 8-bit data byte. The output should be valid on the next rising edge of the clock after the chip select is asserted and the data should be valid on the output when CS is low.
