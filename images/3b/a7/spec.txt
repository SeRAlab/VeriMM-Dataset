Design a dynamic voltage and frequency scaling controller in Verilog. The controller takes a request signal indicating the desired performance level (0-4), and based on this signal, it adjusts the output voltage and frequency. The mapping is as follows:  
0 -> 0.5V, 1 -> 1.0V, 2 -> 1.5V, 3 -> 2.0V, 4 -> 2.5V.  
The output frequency is also scaled accordingly:  
0 -> 100MHz, 1 -> 200MHz, 2 -> 300MHz, 3 -> 400MHz, 4 -> 500MHz.  
The controller must be able to hold the state until a new request is received.
