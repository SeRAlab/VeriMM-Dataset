Design a fixed-priority arbiter with 4 request inputs (req[3:0]) and 1 grant output (grant). The arbiter should grant access to the highest priority request input that is asserted. The priority order is from req[3] (highest) to req[0] (lowest). The output grant should be active for one clock cycle for the granted request. Implement a reset functionality to ensure that the system is in a known state after a reset signal is applied.
