Design a combinational logic circuit that produces an output Y based on the values of inputs A1, A2, and the negated input B1_N. The output Y is set to HIGH (1) only when both A1 and A2 are HIGH. If A1 is HIGH and A2 is LOW, or if A1 is LOW and A2 is HIGH, the output Y is LOW (0). In all other cases, when both A1 and A2 are LOW, the output Y takes the value of the negated input B1_N.
module top_module(
    input A1,
    input A2,
    input B1_N,
    output reg Y
);
