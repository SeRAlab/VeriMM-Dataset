Design a Verilog module that implements a simple audio mixer. The mixer takes two 8-bit audio signals as inputs (audio1 and audio2), and produces a single 8-bit output (mixed_audio). The output should be the average of the two input audio signals, rounded down. The module should have the following ports:
- input [7:0] audio1
- input [7:0] audio2
- output [7:0] mixed_audio
