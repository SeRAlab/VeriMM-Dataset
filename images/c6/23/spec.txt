

You have been hired to design a verilog module for a 4-input AND gate using 2-input AND gates. You are only allowed to use the 2-input AND gates and NOT gates in your design. Write a verilog module that takes four inputs, A, B, C, and D, and provides the output of the 4-input AND gate. Use the following port declaration:

```
module and_4 (
    input A,
    input B,
    input C,
    input D,
    output Y
);
```
