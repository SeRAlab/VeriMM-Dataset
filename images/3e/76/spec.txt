Design a Verilog module that implements a simple Quadrature Amplitude Modulation (QAM) modulator. The module should take in 4 bits of input data, which represent the I (In-phase) and Q (Quadrature) components, and produce a 2-bit output representing the modulation state. The mapping of the input data to the output should be as follows:
- 00 -> 00 (Modulation state 0)
- 01 -> 01 (Modulation state 1)
- 10 -> 10 (Modulation state 2)
- 11 -> 11 (Modulation state 3)
