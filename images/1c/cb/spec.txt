Design a flash memory cell controller in Verilog. The controller should be able to read, write, and erase data from a memory cell. The controller has three inputs: clk (clock), op (operation), and data_in (data to be written). The output should be data_out (data read from the cell). The operations are defined as follows: 
00 - Read
01 - Write
10 - Erase
11 - No operation (NOP)
