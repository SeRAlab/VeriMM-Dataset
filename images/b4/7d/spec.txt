Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state M (output 1).
2. state N (output 0).
3. state O (output 1).
4. state P (output 0).

State transitions:
1. From state M: If c = 1, then transition to state N. If c = 0, then transition to state P.
2. From state N: If c = 1, then transition to state O. If c = 0, then transition to state M.
3. From state O: If c = 1, then transition to state P. If c = 0, then transition to state M.
4. From state P: If c = 1, then transition to state N. If c = 0, then transition to state M.

Assume that a one-hot code is used with the state assignment y[3:0] = 0001(M), 0010(N), 0100(O), 1000(P)

Write a Verilog for the signal Y0, which is the input of state flip-flop y[0], for the signal Y2, which is the input of state flip-flop y[2]. Derive the Verilog by inspection assuming a one-hot encoding.
