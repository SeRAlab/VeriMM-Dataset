Design a simple 4-bit calculator that performs addition or subtraction based on a single operation input. When the operation input (op) is 0, the module adds the two 4-bit inputs (a and b), producing a 4-bit result and generating a carry out if the addition overflows. When op is 1, it subtracts b from a, returning the 4-bit result without generating a carry output. The design effectively allows for basic arithmetic operations between two 4-bit numbers.
module top_module(
  input op,
  input [3:0] a,
  input [3:0] b,
  output [3:0] result,
  output carry
);
