Design a 4-to-1 multiplexer that takes a 4-bit input (`data_in`) and uses a 2-bit selection signal (`sel`) to choose one of the four input bits to output. When `sel` is 00, it outputs either `data_in[0]` or `data_in[1]`; when `sel` is 01, it outputs either `data_in[2]` or `data_in[3]`. In cases that don't match these selections, the output defaults to LOW.
module top_module(
  input [3:0] data_in,
  input [1:0] sel,
  output reg out
);
