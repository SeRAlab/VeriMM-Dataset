Design a Parallel-in Parallel-out (PIPO) shift register that can store 8 bits of data. The shift register should have a clock input, a reset input, a parallel load input, and a data input for loading data. When the parallel load input is high, the data input should be loaded into the register on the next clock edge. The output should be the current content of the shift register. The register should also shift right on every clock edge when the parallel load input is low.
