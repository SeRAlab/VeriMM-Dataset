Design a four-bit binary adder that computes the sum of two 4-bit inputs, A and B. The module outputs a 4-bit result S, representing the lower four bits of the sum, and a carry-out C that indicates if there is an overflow from the most significant bit during addition. The carry-out is determined by checking the fifth bit of the sum, signaling whether a carry occurred.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output [3:0] S,
    output C
);
