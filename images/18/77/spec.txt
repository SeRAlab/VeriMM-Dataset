Design a 4-bit Serial-In Serial-Out (SISO) shift register. The shift register should have a clock input, a serial data input (data_in), and a serial data output (data_out). On each rising edge of the clock, the data_in should be shifted into the register, and the output data_out should provide the value of the register after the last shift operation. The shift register should also have a reset input (reset), which clears the register when activated.
