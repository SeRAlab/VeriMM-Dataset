Implement a sign extension circuit that converts a 16-bit signed integer input into a 32-bit signed integer output. The module takes a 16-bit input and extends its sign to the higher order bits of the 32-bit output; if the most significant bit of the input (sign bit) is 1, the output's upper 16 bits are filled with ones; if it is 0, those bits are filled with zeros. This allows for proper representation of negative values when transitioning from a smaller bit-width to a larger one.
