
Design a LIFO stack module in Verilog that supports push and pop operations. The stack should have a fixed size of 8. The module should have the following inputs and outputs:
- `clk`: Clock signal
- `reset`: Reset signal
- `push`: Signal to indicate a push operation
- `pop`: Signal to indicate a pop operation
- `data_in`: Input data to be pushed onto the stack
- `data_out`: Output data from the top of the stack when popping
- `full`: Flag indicating if the stack is full
- `empty`: Flag indicating if the stack is empty
