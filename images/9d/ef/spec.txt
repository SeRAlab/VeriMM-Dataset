Design a 32-bit wide, 2-to-1 multiplexer. The module outputs one of the two 32-bit input signals (in_1 or in_2) based on the value of the select input. When select is 0, the output is driven by in_1; when select is 1, the output is driven by in_2. If select is unknown (x), the output will also be unknown.
module top_module(
  output [31:0] out,
  input [31:0] in_1, in_2,
  input select
);
