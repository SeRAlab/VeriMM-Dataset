Design a 4-bit binary adder with a 5-bit output sum. The module takes two 4-bit inputs, 'a' and 'b', computes their sum using bitwise XOR operations for the sum bits and evaluates the carry for each bit using logical AND and OR operations. The result is a 5-bit wide output, 'sum', that includes any carry out generated from the most significant bit addition, thereby allowing for outputs that can represent sums greater than 15 (maximum value for 4 bits).
module top_module(
    // Inputs
    input [3:0] a,
    input [3:0] b,
    // Outputs
    output [4:0] sum
);
