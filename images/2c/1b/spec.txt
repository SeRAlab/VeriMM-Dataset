Design a 4th-order IIR filter in Verilog. The filter should take a 16-bit signed input sample and produce a 16-bit signed output sample. The coefficients for the filter will be predefined in the module. The filter should implement the following difference equation for the output:
y[n] = a1*y[n-1] + a2*y[n-2] + b0*x[n] + b1*x[n-1] + b2*x[n-2]
where x[n] is the input and y[n] is the output. The filter should have a clock input for synchronous operation and a reset input to initialize the filter state.
