
Design a 16-bit Linear Feedback Shift Register (LFSR) that uses the polynomial x^16 + x^14 + x^13 + x^11 + 1 for feedback. The LFSR should have a clock input and should generate a pseudo-random sequence of bits. The output of the LFSR should be the current state of the 16 bits. Implement the LFSR in Verilog and ensure that it initializes correctly and cycles through its states.
