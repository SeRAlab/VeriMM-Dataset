Design a 4-bit counter with synchronous load and reset functionality. The counter increments its value on each clock pulse when enabled, and can be reset to zero with an active reset signal. Additionally, it allows loading a preset 4-bit value through the `data_in` input when the `load` signal is high, overriding the normal increment behavior. The current counter value is continuously outputted on `data_out`.
module top_module(
   input         clk, reset, enable, load,
   input  [3:0]  data_in,
   output [3:0]  data_out);
