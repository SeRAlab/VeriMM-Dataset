Design a 4-to-1 multiplexer that selects one of the four input signals (A, B, C, or D) based on the values of the two selection lines (S0 and S1). When S0 and S1 are both LOW, the output Y will be A; if S0 is HIGH and S1 is LOW, Y will be B; if S0 is LOW and S1 is HIGH, Y will be C; and when both selection lines are HIGH, Y will produce D.
module top_module(
    input A,
    input B,
    input C,
    input D,
    input S0,
    input S1,
    output Y
);
