Implement the Verilog module based on the following description.
Given the following 4-bit binary counter with a parallel load input and a load data input:

1. The counter increments on the rising edge of the clock if the load input is low.
2. The counter loads the data input on the rising edge of the clock if the load input is high.

Write Verilog implementing this counter.
module binary_counter (
        input clk,
        input load,
        input [3:0] data_in,
        output reg [3:0] count);
