Design a monophonic note handler circuit that processes musical note events based on input signals. The module takes in a clock signal, a reset signal, and control signals for note activation (note_on) and deactivation (note_off). It tracks active notes using a 128-bit register, where each bit represents the status of a note. When a note is activated, it sets the corresponding bit high and sets an output note and gate signal accordingly. The output note reflects the highest active note found in the register, while the output gate signal indicates the presence of any active notes. If no notes are active, the output gate is low, transitioning the system back to a ready state after processing.
