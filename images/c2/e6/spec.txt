Please act as a professional Verilog designer. Your task is to create a Verilog module that implements Fletcher's checksum generator and checker. 
Fletcher's checksum is a hash function used to detect errors in data transmission or storage. 
The checksum is calculated by dividing the data into blocks and then adding the values of each block together. 
The result is a 16-bit checksum that can be used to verify the integrity of the data.

Your module should have the following inputs and outputs:

Inputs: a set of n 8-bit data blocks (data1, data2, ..., datan)
Outputs: a 16-bit Fletcher's checksum (checksum)

Your module should implement the following functionality:

The circuit should divide the data into blocks of size 8 bits.
For each block, the circuit should calculate two 8-bit checksum values (s1 and s2) using the Fletcher's algorithm.
The 16-bit checksum should be calculated by concatenating s1 and s2.
The circuit should output the 16-bit checksum.

To implement Fletcher's algorithm, you should use Verilog code to calculate s1 and s2 for each block of data. 
You should then use these values to calculate the final 16-bit checksum. 
The Verilog code should be designed in such a way that it can handle any number of data blocks.
