Implement a Verilog module based on the following description.
Design a 4-bit binary to Gray code converter with synchronous reset. If the reset signal is high on the rising edge of the clock, the output should be set to 0. If reset is low, the output should be the Gray code equivalent of the input.
module bin_to_gray(
    input clk,
    input reset,
    input [3:0] bin,
    output reg [3:0] gray);
