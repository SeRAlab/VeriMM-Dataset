Design a multi-bit comparator that compares two n-bit binary numbers (default n=8). The module outputs three signals: 'greater' indicates if the first number is larger than the second, 'equal' indicates if they are equal, and 'less' indicates if the first number is smaller. The comparator performs subtraction to determine the relationship between the inputs and updates the output signals accordingly. The design encompasses both positive and negative values, ensuring accurate comparison outputs irrespective of the sign of the inputs.
module top_module(
  input [n-1:0] num1,
  input [n-1:0] num2,
  output reg greater, // Change to reg
  output reg equal,   // Change to reg
  output reg less     // Change to reg
);
