Design a basic 8-bit calculator that performs arithmetic operations based on the selected opcode. The module takes two 8-bit inputs (num1 and num2) and a 2-bit opcode to determine the operation (addition, subtraction, multiplication, or division) to execute. The operation is conducted only when the enable signal is high, and the result of the operation is output as an 8-bit value.
module top_module(
    input [7:0] num1,
    input [7:0] num2,
    input [1:0] opcode,
    input enable,
    output reg [7:0] result
);
