Design a 2-to-1 multiplexer for 5-bit inputs that selects between two 5-bit data inputs (in0 and in1) based on the RegDst control signal. When RegDst is low, the output is in0; when RegDst is high, the output is in1. The module also includes a clock input, although it is not used in this implementation.
module top_module(
	input clk,
	input RegDst,
	input [4:0] in0,
	input [4:0] in1,
	output wire[4:0] out
);
