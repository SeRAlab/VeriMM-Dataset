Implement the Verilog module based on the following description.
We want to create a module that:

// (1) receives a 12-bit binary number,
// (2) checks if the number is a multiple of 8,
// (3) counts the number of 0s in the binary number,
// (4) outputs a flag if the number is a palindrome in binary,
// (5) provides a reset mechanism to reset all outputs.

// The input binary number is available on the input signal 'binary_num'. The output 'is_multiple_of_8' should be set to 1 if the number is a multiple of 8 and 0 otherwise. The number of 0s in the binary number should be output on 'count_zeros[3:0]'. The palindrome flag should be set on 'is_palindrome' if the number is a palindrome. The reset signal is active high synchronous.

module top_module(
    input wire clk,
    input wire reset,
    input wire [11:0] binary_num,
    output reg is_multiple_of_8,
    output reg [3:0] count_zeros,
    output reg is_palindrome
);
