Create a simple GPIO controller that allows reading and writing to a 5-bit GPIO port. The controller should have the following signals: a 5-bit input `gpio_in`, a 5-bit output `gpio_out`, a control signal `wr_en` (write enable), and a clock signal `clk`. When `wr_en` is high, the value on `gpio_in` should be written to `gpio_out` on the rising edge of the clock. Otherwise, `gpio_out` should retain its previous value.
