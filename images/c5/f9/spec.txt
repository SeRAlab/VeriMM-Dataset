

You are tasked with designing a module that implements a 4-bit counter. The counter should have the following functionality:
- It should have a synchronous reset input, which when asserted should reset the counter to 0.
- It should have an enable input, which when asserted should allow the counter to increment on each rising clock edge.
- It should have a 4-bit output, which should output the current count value.

Design a Verilog module that implements the 4-bit counter with the above functionality. Your module should be named "four_bit_counter" and should have the following inputs and outputs:
- input clk: The clock signal.
- input rst: The synchronous reset signal.
- input en: The enable signal.
- output reg [3:0] count: The 4-bit count output.

Your module should have the following behavior:
- When rst is asserted, the count should be reset to 0.
- When en is asserted and a rising edge of clk occurs, the count should increment.
- The count output should always reflect the current count value.
