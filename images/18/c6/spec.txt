Design a 4-channel DMA (Direct Memory Access) controller in Verilog that allows multiple data channels to transfer data to a memory without CPU intervention. The controller should have the following inputs: channel_select (2 bits), request (1 bit), and a clock signal. The output should be a valid signal when a channel is active and a memory address (3 bits) corresponding to the selected channel. The controller should handle requests in a round-robin fashion.
