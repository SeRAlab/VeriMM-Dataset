Design a 5-input Logistic Regression model that takes five binary inputs (x1, x2, x3, x4, x5) and outputs a single binary value (y) representing the predicted class. The logistic regression function can be simplified for this problem as a threshold check on the weighted sum of the inputs. For simplicity, let's assume weights are predefined as w1 = 1, w2 = 1, w3 = 1, w4 = 0, w5 = 0, and the threshold is 2. If the weighted sum is greater than or equal to the threshold, the output should be 1; otherwise, it should be 0.
