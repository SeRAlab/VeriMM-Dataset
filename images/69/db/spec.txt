Design a logic circuit that outputs a HIGH signal based on several input conditions. The output X is HIGH if any of the following are true: both A1 and A2 are HIGH, both B1 and B2 are HIGH, both C1 and C2 are HIGH, the power supply VPWR is HIGH while VGND is LOW, or the body bias VPB is HIGH while VNB is LOW. This circuit essentially functions as a multi-input combinational logic gate that combines AND and OR operations across the specified inputs to determine the final output.
module top_module(
    input A1,
    input A2,
    input B1,
    input B2,
    input C1,
    input C2,
    input VPWR,
    input VGND,
    input VPB,
    input VNB,
    output X
);
