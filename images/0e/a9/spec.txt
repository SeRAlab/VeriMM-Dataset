
Design a combinational logic circuit that takes in a 5-bit binary number representing a portfolio of assets and outputs a 5-bit binary number that represents the optimal selection of those assets based on a predefined optimization criteria. The optimization criteria is that if the input bit is 1, it is included in the output; otherwise, it is excluded. However, to avoid selecting the last asset if the second last asset is selected, the logic should ensure that if bit 3 (second last bit) is 1, then bit 4 (last bit) must be 0 in the output.
