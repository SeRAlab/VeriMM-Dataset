
Design a simple SPI (Serial Peripheral Interface) controller that communicates with a slave device. The SPI controller should be able to send and receive data in 8-bit packets. The controller should have the following inputs: 
- `clk`: clock signal
- `reset`: active high reset signal
- `start`: signal to start the transmission
- `data_in`: 8-bit data input to be sent to the slave device

The outputs should be:
- `data_out`: 8-bit data output received from the slave device
- `done`: signal indicating that the transmission is complete
