Design a Verilog module for a simple Flash memory cell. The memory cell should have a D flip-flop behavior with additional control signals for write and read operations. The cell should store a single bit, with the ability to write a value (1 or 0) to it when the write enable (WE) signal is high and read the stored value when the read enable (RE) signal is high. The module should have the following ports: `input wire D` (data input), `input wire WE` (write enable), `input wire RE` (read enable), `output reg Q` (data output).
