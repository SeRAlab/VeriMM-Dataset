
Design an EEPROM cell in Verilog that includes a write, read, and erase functionality. The EEPROM cell should have a 1-bit data input, a write enable signal, a read enable signal, and an erase signal. The read operation should provide the stored value on its output, while the write operation should store the input data in the cell if the write enable signal is active. The erase operation should reset the stored value to 0.
