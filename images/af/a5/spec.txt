Design a pseudo-random number generator that produces an 8-bit random output. The module initializes the random value to 100 on reset and generates new random bits on each clock edge when enabled. The random number is derived using a feedback shift register mechanism, with feedback obtained from specific bits of the register. After 8 clock cycles, it outputs the generated random number through the `rnd` output.
module top_module(
	input clock,
    input reset,
    input enable,
    output [7:0] rnd
    );
