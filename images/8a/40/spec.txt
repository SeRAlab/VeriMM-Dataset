Create a Verilog module for an 8-bit pseudo-random binary sequence generator using a Galois LFSR with a specific polynomial. The module should have an input clock signal (clk), an input enable signal (en), and an 8-bit output signal (prbs). On the rising edge of the clock, if enable is high, the LFSR should shift right and the new bit should be the XOR of the current bits 7, 5, 4, and 3.
