Design a 4-bit DRAM cell that can write and read data. The cell should have a write enable signal (we), a read enable signal (re), a 4-bit data input (data_in), a 4-bit data output (data_out), and a clock signal (clk). On the rising edge of the clock, if write enable (we) is high, the data input should be stored in the cell. If read enable (re) is high, the stored data should be outputted. Ensure that both write and read operations cannot occur simultaneously.
