Design a 4-bit DRAM cell that can perform read and write operations. The DRAM cell should have the following inputs: 
- `clk` (clock)
- `write_enable` (1-bit signal to enable writing)
- `address` (2-bit address to select which of the 4 bits to write/read)
- `data_in` (4-bit data input for writing)
Output:
- `data_out` (4-bit data output for reading) 
The cell should hold data when `write_enable` is high during a clock edge; it should output the stored data when read.
