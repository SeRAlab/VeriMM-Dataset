
Design a 7-stage pipelined processor controller that manages the flow of data through the pipeline stages. The controller should have a clock input and a reset input. It should have a 3-bit input signal to represent the instruction type, and it should output the control signals for each stage of the pipeline. The control signals should indicate whether each stage (Fetch, Decode, Execute, Memory, Write Back, and two additional custom stages) is active or inactive.
