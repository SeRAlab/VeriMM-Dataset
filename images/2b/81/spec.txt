Design a 4-bit DRAM cell that can store a 4-bit data input and has a control signal for read and write operations. The DRAM cell should have the following ports:
- Input: 4-bit data input (data_in), control signal (control), and a clock signal (clk).
- Output: 4-bit data output (data_out).
The control signal should determine if the data is being written to (control = 1) or read from (control = 0) the cell.
