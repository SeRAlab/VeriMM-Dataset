
Design a 5-stage instruction pipeline for a simple CPU. The stages are: Fetch (IF), Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). Implement a module that simulates the behavior of the pipeline, where each stage operates on a single instruction at a time. The input to the pipeline should be an instruction stream, and the output should indicate the state of each stage for the current clock cycle.
