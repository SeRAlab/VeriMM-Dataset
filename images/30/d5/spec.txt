Design an SPI (Serial Peripheral Interface) controller that allows for data transmission and reception with a configurable clock rate. The controller should support the following operation: it should be able to receive data on the MOSI line while simultaneously sending data on the MISO line. The controller should include a state machine to manage the transmission and reception of data, and a register to hold the transmitted data. It must also have a clock input, an enable signal, and a reset signal.
