
Design a temperature-based shutdown system that monitors the temperature and shuts down the system if the temperature exceeds a predefined threshold. The system should also have a reset input that can bring the system back to normal operation if the temperature has cooled down. The threshold temperature is set at 75 degrees Celsius. The system should have the following inputs and outputs:
- Inputs: `temp` (8-bit temperature input), `reset` (1-bit reset signal).
- Outputs: `shutdown` (1-bit output indicating if the system is shut down).
The shutdown output should be high when the temperature exceeds the threshold and should remain high until a reset signal is received.
