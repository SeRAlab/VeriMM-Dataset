The carry-out signal indicates if there is an overflow beyond the 4-bit result. This module uses full adder principles to perform bit-wise addition while considering the carry propagation through each bit of the inputs.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input CI,
    output [3:0] C,
    output CO
);
