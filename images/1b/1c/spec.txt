Design a finite state machine (FSM) with three states: IDLE, PROCESS, and DONE. The FSM should transition from IDLE to PROCESS on a start signal, from PROCESS to DONE when a done signal is received, and return to IDLE after a reset signal is received. The output should indicate the current state of the FSM as a 2-bit value (00 for IDLE, 01 for PROCESS, 10 for DONE).
