

You have been tasked with designing a module that takes in two inputs, `c_in` and `d_in`, and outputs `out1`. The `out1` output should be the result of a bitwise XOR operation between `temp` and `d_in`. The `temp` signal should be the result of a bitwise AND operation between `c_in` and `d_in`.

Write a Verilog module that implements the above functionality. Your module should be named `xor_and` and should have the following ports:
- `c_in`: input bit
- `d_in`: input bit
- `out1`: output bit
