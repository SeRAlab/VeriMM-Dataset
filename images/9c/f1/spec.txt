Implement a Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state A (U = 1).
2. state B (U = 0).
3. state C (U = 1).
4. state D (U = 0).

State transitions:
1. From state A: If h = 0, then transition to state B. If h = 1, then transition to state C.
2. From state B: If h = 0, then transition to state D. If h = 1, then transition to state A.
3. From state C: If h = 0, then transition to state D. If h = 1, then transition to state B.
4. From state D: If h = 0, then transition to state C. If h = 1, then transition to state A.

Assume that you want to Implement the FSM using two flip-flops and state codes t[1:0] = 00, 01, 10, 11 for states A, B, C, D, respectively. Implement just the next-state logic for t[1] in Verilog. The output U is t[1].
