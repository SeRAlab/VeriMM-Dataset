

You are tasked with designing a verilog module that implements a 4-bit binary adder. The module should take two 4-bit inputs (A and B) and produce a 4-bit output (C) that represents the sum of the inputs. Additionally, the module should have a control input (Cin) that determines whether or not the input should be treated as a carry-in bit. 

Your module should have the following inputs and outputs:
- A: a 4-bit input
- B: a 4-bit input
- Cin: a single bit input that determines whether or not the input should be treated as a carry-in bit
- C: a 4-bit output that represents the sum of the inputs

Your module should implement the following logic:
- If Cin is 0, the output C should be the sum of A and B.
- If Cin is 1, the output C should be the sum of A, B, and Cin.

You should name your module "binary_adder" and ensure that it compiles without errors or warnings.
