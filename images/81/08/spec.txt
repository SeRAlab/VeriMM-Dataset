Design a sequential circuit that generates a one-bit output based on the logical OR of two input signals, ai and bi, with synchronous reset functionality. Upon the rising edge of the clock, if the reset signal, rst_i, is asserted, the internal register is set to zero. Otherwise, if either ai or bi is high, the internal register is set to one; otherwise, it is reset to zero. The output, yo, reflects the state of the internal register.
module top_module(
        input  clk_i,
        input  rst_i,
        input  ai,
        input  bi,
        output yo
    );
