Design a 4-to-1 multiplexer that selects one of four 32-bit wide input signals (A, B, C, D) based on a 2-bit select input (S). Depending on the value of S, the output (Y) will reflect the corresponding input: when S is 00, Y equals A; when S is 01, Y equals B; when S is 10, Y equals C; and when S is 11, Y equals D.
module top_module(
  input [31:0] A,
  input [31:0] B,
  input [31:0] C,
  input [31:0] D,
  input [1:0] S,
  output reg [31:0] Y
);
