

You have been tasked with designing a verilog module for a 4-bit RAM (Random Access Memory) with 8 memory locations. The module should have the following inputs and outputs:

Inputs:
- `clk`: the clock signal
- `addr`: a 3-bit address bus
- `din`: an 4-bit input data bus
- `en`: an enable signal
- `we`: a write enable signal

Outputs:
- `dout`: a 4-bit output data bus

Your module should be implemented using behavioral Verilog and should use a reg data type to store the memory. The RAM should be initialized with all 0's.
