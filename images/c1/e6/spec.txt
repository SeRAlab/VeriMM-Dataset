

You are tasked with designing a module that takes in 7 inputs and produces 1 output. The module is named `seven_input_one_output` and it should be able to handle the following inputs:

1. `a`: a 1-bit input signal
2. `b`: a 1-bit input signal
3. `c`: a 1-bit input signal
4. `d`: a 1-bit input signal
5. `e`: a 1-bit input signal
6. `f`: a 1-bit input signal
7. `g`: a 1-bit input signal

The module should also produce the following output:

1. `x`: a 1-bit output signal

The module should be designed such that if the input signals `a`, `b`, `c`, `d`, `e`, `f`, and `g` are all high, then the output signal `x` should also be high. Otherwise, the output signal `x` should be low.

Design this module and provide the code for it.
