Design a Verilog module that takes a 16-bit TCP payload and a 3-bit segmentation type as inputs. Based on the segmentation type, the module will output the segmented TCP payload. The segmentation types are as follows: 
- 000: No segmentation (output the entire payload)
- 001: Segment the payload into two 8-bit segments
- 010: Segment the payload into four 4-bit segments
- 011: Segment the payload into eight 2-bit segments
- 100: Segment the payload into sixteen 1-bit segments
For types 101 to 111, output an error signal indicating invalid segmentation type.
