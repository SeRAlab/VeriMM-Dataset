Design a D latch that captures the value of input D when the enable signal GN is high (active). When GN goes low (inactive), the latch holds its current outputs Q and QN, maintaining their last state. When GN is active, Q is set to the value of D, while QN is set to the complement of D. This module thus functions as a level-sensitive memory element, storing input data based on the enable condition.
