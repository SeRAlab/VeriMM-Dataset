Develop a VGA controller that generates synchronization signals for video output. The module handles horizontal and vertical counting based on a 25 MHz clock, resetting the counts when necessary. It produces horizontal (hSync) and vertical (vSync) sync signals, along with x and y coordinates for drawing pixels on the screen. The drawing area is defined as the first 256 pixels horizontally and the first 320 pixels vertically, managing the drawing state through the `draw` signal that indicates valid coordinates.
module top_module(input clk25, input reset, output reg vSync, output reg hSync, output [7:0] xCoord, output [8:0] yCoord, output draw);
