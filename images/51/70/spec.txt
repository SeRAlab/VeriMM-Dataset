Design a shift register module capable of both serial and parallel shifting for an n-bit input. This module features a configurable shift direction (up or down), shift mode (serial or parallel), and incorporates a clock and reset mechanism. When activated, it shifts the bits from the input based on the specified parameters, with the output reflecting the current state of the shift register after each clock cycle. The output is defined as an m-bit wide register that showcases the result of the shifting operation applied to the input data.
module top_module(
  input [n-1:0] in,
  input shift_dir,
  input shift_mode,
  input clk,
  input reset,
  output [m-1:0] out
);
