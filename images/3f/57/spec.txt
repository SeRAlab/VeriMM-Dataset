Design a Verilog module that implements a simplified version of HMAC. The module should take a key and a message as inputs, and produce an HMAC output. The HMAC computation can be simplified to a combination of a hash function (for the purpose of this problem, you can use a simple XOR-based hash for demonstration) and a key. The key and message should be of fixed length (e.g., 8 bits each), and the output should be 8 bits as well.
