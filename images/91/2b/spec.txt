Design a flag register that can hold a single-bit output (OUT_FLAG) based on specific control signals. The module features inputs for data (IN_FLAG), a set signal (SET), a load signal (LD), and a clear signal (CLR), along with a clock signal (CLK). When SET is activated, OUT_FLAG is set to high; when CLR is activated, it is reset to low. If LD is enabled, the register captures the value of IN_FLAG. The output retains its previous state when none of the control signals are asserted. This functionality is encapsulated within a flip-flop structure, ensuring the flag can be updated in synchrony with the clock.

    SET,
