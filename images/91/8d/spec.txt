Design a 4-to-1 multiplexer that selects one of four input lines (In0, In1, In2, In3) based on the combination of two select signals (Sel1 and Sel2). The selected input is output as Out, with the specific input chosen corresponding to the binary value of the select lines: Sel1 and Sel2 determine which of the four inputs is passed to the output.
module top_module(
    In0,
    In1,
    In2,
    In3,
    Sel1,
    Sel2,
    Out
);
