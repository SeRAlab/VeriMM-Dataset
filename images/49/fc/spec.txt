Design a 64x8-bit RAM module that supports reading and writing operations. The module has inputs for write data, read and write addresses, clock, write enable, read enable, and reset signals. On the rising edge of the clock, if the reset signal is active, the memory is initialized to zero; otherwise, if the write enable is asserted, the module stores the write data at the specified write address. When read enable is active, the output provides the data from the specified read address; if read enable is not active, the output is high-impedance.
module top_module(ReadData, WriteData, Reset,readAddress,writeAddress, Clk, writeEn,readEn);
