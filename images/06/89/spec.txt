Design a FIFO queue with a specified depth. The FIFO should have the following parameters: a data width of 8 bits, a depth of 4 entries, signals for write enable, read enable, clock, and reset. The queue should support enqueueing and dequeueing operations. The status of the queue (full or empty) should be indicated by output signals. Implement the necessary logic to handle the FIFO behavior, including wrap-around when the end of the queue is reached.
