Design a color output circuit for a bullet object in a game. It takes the bullet's RGB color and a default color as inputs and tracks the number of hits received. When the bullet has been hit four times (`hit_times` equals 4) and is currently marked as hit (`is_hit` is true), the output color (`rgb_out`) is set to the default color; otherwise, it retains the bullet's original color.
module top_module(
    input [8:0] rgb_bullet,
    input [8:0] default_color,
    input [4:0] hit_times,
    input is_hit,
    output [8:0] rgb_out
    );
