Design a simple Automatic Repeat reQuest (ARQ) error correction receiver system in Verilog. The ARQ system should verify received data against a checksum and respond with an acknowledgment signal (ACK) or a negative acknowledgment signal (NACK) based on error detection. The system should include an enable signal to start the check process, an input for data, and an input for the checksum. The output should be the acknowledgment signal. An additional output should indicate if data is valid or invalid.
