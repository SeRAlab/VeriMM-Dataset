
Design a Verilog module that simulates a simple Flash memory cell. The memory cell should have an input data bus (D) for writing data, a control signal (WE) for writing data, and a read output (Q) that reflects the stored data. When WE is high, the data on the input bus D should be written to the memory cell. When WE is low, the output Q should reflect the current stored value in the memory cell. Initialize the memory cell to zero on reset.
