Design a simple GPIO controller that allows reading and writing of data to a 5-bit GPIO port. The controller should have two modes: input and output. In input mode, it reads the external data and stores it in a register. In output mode, it writes the data from a register to the GPIO port. The current mode is controlled by a mode signal (0 for input, 1 for output). Include a clock (clk) and reset (rst) signal for synchronous operation.
