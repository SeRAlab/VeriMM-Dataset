Design a 4-bit DRAM cell that can store a 4-bit word and includes read and write functionality. The DRAM cell should accept a write enable signal, a 4-bit input data, and a read enable signal. When the write enable signal is high, the input data should be stored in the cell. When the read enable signal is high, the stored data should be output. The design should not have any timing constraints, and it should be straightforward to simulate and implement.
