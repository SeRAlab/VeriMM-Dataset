

You are tasked with designing a module that takes in three inputs: `a`, `b`, and `c`. The output, `out`, should be the maximum value among these inputs. Write a Verilog module that implements this logic.

The module should be named `max_value` and have the following ports:
- `a`: input, 1 bit
- `b`: input, 1 bit
- `c`: input, 1 bit
- `out`: output, 1 bit

You should use a combinational logic block to determine the maximum value among `a`, `b`, and `c`. If two or more inputs are equal and the maximum value, the output should be that value.
