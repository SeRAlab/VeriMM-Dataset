Design a Verilog module that simulates a simple Flash memory cell. The module should have a single data input (D), a write enable control signal (WE), and an output (Q) that reflects the stored value. When WE is high, the value of D should be stored in Q; when WE is low, Q should maintain its current value. Additionally, implement a reset input (RST) that, when asserted, sets Q to 0 regardless of WE. The output Q should be 1 bit wide.
