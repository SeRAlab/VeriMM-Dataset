Design an 8-bit DRAM cell that can store a single bit of data (0 or 1) for each bit of the 8-bit word. The design should have inputs for data (8 bits), a write enable signal (WE), and a read enable signal (RE). When WE is high, the data input should be stored in the cell, and when RE is high, the stored data should be output. The output should be valid only when RE is high and WE is low. The design should also include a reset signal (RST) that clears the stored data when asserted.
