Design a JK flip-flop in Verilog that toggles its output based on the J and K inputs. The flip-flop should also have a clock input and an asynchronous reset input. When reset is high, the output should be reset to 0. Otherwise, the output should change based on the following rules: if J=K=0, the state remains the same; if J=1 and K=0, the state sets to 1; if J=0 and K=1, the state resets to 0; if J=K=1, the state toggles.
