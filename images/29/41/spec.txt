
Design a 4-bit SRAM cell that can store and retrieve a 4-bit value. The cell should have the following ports: 
- `data_in` (4 bits) for input data
- `data_out` (4 bits) for output data
- `we` (1 bit) for write enable (active high)
- `clk` (1 bit) for the clock signal
- `q` (4 bits) as the output of the stored data.
The cell should store the input data when `we` is high on the rising edge of the clock and output the stored data on `q`.
