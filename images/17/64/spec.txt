Design a 4-bit SRAM cell that allows writing data to it and reading data from it based on a write enable signal. The SRAM should have the following ports: 
- `data_in`: 4-bit input data
- `data_out`: 4-bit output data
- `we`: Write enable (1 means write, 0 means read)
- `clk`: Clock signal
- `reset`: Asynchronous reset (active high)
