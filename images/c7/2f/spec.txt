

You are tasked with designing a Verilog module for a 4-bit synchronous up-counter with a synchronous reset. The module should have the following inputs and outputs:

Inputs:
- clk: a 1-bit clock signal
- rst: a 1-bit synchronous reset signal

Outputs:
- count: a 4-bit output representing the current count value

The module should have the following behavior:
- On the rising edge of the clock signal, if the reset signal is high, the count should be reset to 0.
- On the rising edge of the clock signal, if the reset signal is low, the count should increment by 1.

Your task is to complete the Verilog module for this 4-bit synchronous up-counter with a synchronous reset.
