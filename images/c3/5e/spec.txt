

You are tasked with designing a verilog module that implements a 2-to-1 multiplexer. The module should have two inputs, `A` and `B`, and one output, `Z`. The output should be the same as the input selected by the control input `S`. If `S` is 0, then `Z` should be equal to `A`. If `S` is 1, then `Z` should be equal to `B`. You are not allowed to use the `if` statement or any other conditional constructs in your design. You need to use only the `buf` primitive to implement the multiplexer.

To help you get started, here is the skeleton of the verilog module:

```
module mux2to1 (A, B, S, Z);
input A, B, S;
output Z;

// your code goes here

endmodule
```
