Design a gated D latch with an inverted output. The latch has a data input (D), an active-low clock input (nCLK), and an active-low set input (nSET). When nSET is low, the output (nQ) is forced to low. On a falling edge of nCLK, the output nQ is updated to the inverse of the D input. The initial state of nQ can be set using the parameter INIT.
module top_module(input D, input nCLK, input nSET, output reg nQ);
