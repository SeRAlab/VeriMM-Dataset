Design a priority encoder that takes a 4-bit input and activates a corresponding 4-bit LED display based on the highest priority input bit set to '1'. The output `led_display` will reflect the number of the set bit, with higher-priority inputs corresponding to different values, while a default case of all zero inputs results in turning off the LEDs (outputting zero).
module top_module(
  input [3:0] data,
  output reg [3:0] led_display
);
