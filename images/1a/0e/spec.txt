Design a 2nd-order IIR filter with the following parameters:
- Coefficients: b0 = 0.5, b1 = 0.5, b2 = 0.0, a1 = -0.3, a2 = 0.2
- Input: x[n] (current input sample)
- Output: y[n] (current output sample)
- Previous outputs: y[n-1], y[n-2]
- Previous inputs: x[n-1], x[n-2]
Implement the IIR filter in Verilog.
