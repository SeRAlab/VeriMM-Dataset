
Design a 4-to-1 round-robin arbiter in Verilog. The arbiter should provide access to one of four requestors (Requestor 0 to Requestor 3) based on round-robin scheduling. The arbiter should have four inputs (req[3:0]) for request signals and one output (grant[3:0]) to indicate which requestor has been granted access. The arbiter should also have a clock (clk) and a reset (reset) signal. The grant output should be asserted for one clock cycle for the requestor that is granted access. If multiple requestors assert their requests simultaneously, the arbiter should grant access to the requestor that comes next in sequence based on the last granted requestor.
