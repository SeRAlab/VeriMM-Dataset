
Design a dynamic range compressor that compresses an input signal based on a predefined threshold. The output of the compressor should be calculated based on the following rules:
1. If the input signal is below the threshold, the output should be equal to the input.
2. If the input signal is above the threshold, the output should be calculated as:
   output = threshold + (input - threshold) / compression_ratio
The module should take a 10-bit input signal and output a 10-bit compressed signal. The threshold and compression ratio will be provided as inputs.
