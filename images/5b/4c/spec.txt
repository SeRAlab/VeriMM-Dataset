Design a circuit that computes the sum of the products of two 8-bit inputs, A and B, on each rising edge of a clock signal, clk. The output, Z, is a 16-bit register that accumulates the result. If the reset signal, rst, is asserted, Z is initialized to zero; otherwise, Z is updated by adding the current product of A and B to its previous value.
module top_module(
    input  wire        clk,
    input  wire        rst,
    input  wire [ 7:0] A,
    input  wire [ 7:0] B,
    output reg  [15:0] Z
);
