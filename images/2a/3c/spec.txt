Design a Verilog module that implements a 4-bit CRC (Cyclic Redundancy Check) generator. The module should take a 4-bit data input and generate a 3-bit CRC output. The generator should use a polynomial of x^4 + x^3 + x^2 + 1 (binary representation: 1101). The CRC should be computed on every rising edge of a clock signal. The design should include a reset signal to initialize the CRC output to zero. The module should also provide a valid signal to indicate when the CRC output is valid after processing the input data.
