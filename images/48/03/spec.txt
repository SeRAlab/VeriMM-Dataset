Design a D-type flip-flop with reset and enable features, capable of synchronous loading of data. The flip-flop operates on the rising edge of the clock; when the active-low reset signal (rst_l) is asserted, it clears the output (q) to zero. If the reset is not active and the enable signal (en) is high, the module captures and holds the input data (din) on the clock edge. Additionally, it includes a scan enable (se) feature that allows for test data (si) to be loaded into the output (q) when se is high. The output (q) is also fed back to provide the scan output (so).
