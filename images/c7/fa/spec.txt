

You have been tasked with designing a module in Verilog that implements a 2-to-1 multiplexer. The module should have two input signals, A and B, and one output signal, Y. Additionally, the module should have a select signal, S, that determines which input signal is passed through to the output. If S is 0, the output should be equal to A, and if S is 1, the output should be equal to B. 

Your module should be named "mux_2to1" and should be contained within 200 lines of Verilog code. The module should implement the following logic:

- If S is 0, Y should be equal to A.
- If S is 1, Y should be equal to B.
- If S is neither 0 nor 1, Y should be set to 0.

You may assume that A, B, and S are all single-bit signals.
