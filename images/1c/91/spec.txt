Design a Carrier Frequency Recovery circuit using a Phase-Locked Loop (PLL) in Verilog. The PLL should have the following parameters: 
- Input signal (data_in): 1-bit digital signal.
- Reference clock (clk): 1-bit clock signal.
- Output signal (data_out): 1-bit recovered signal, synchronized with the input signal frequency.
The PLL should include a phase detector, a loop filter, and a voltage-controlled oscillator (VCO) to achieve frequency and phase alignment.
