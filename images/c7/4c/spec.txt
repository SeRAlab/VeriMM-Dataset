

You are tasked with designing a verilog module that will perform a 32-bit left shift operation on an input signal. The module should have the following interface:

```
module left_shift_32(input [31:0] data_in, output [31:0] result);
```

The module should take in a 32-bit input signal `data_in` and perform a left shift operation on it, shifting all bits to the left by 1. The resulting 32-bit output signal should be stored in the `result` output.

You should ensure that your module is synthesizable and can be implemented on an FPGA.
