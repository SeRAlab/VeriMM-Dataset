Design a 16-bit SRAM cell that can read and write data. The SRAM cell should be able to store a 16-bit value and allow reading and writing based on control signals. The signals should include a "write" signal to indicate if the data should be written, an "address" input to select the memory location, and a "data_in" input for the data to write. The output should be "data_out" which reflects the value at the selected address.
