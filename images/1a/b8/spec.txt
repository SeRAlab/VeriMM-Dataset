Design an interrupt controller that handles 4 different interrupt requests (IRQ0, IRQ1, IRQ2, IRQ3) and a global interrupt enable (GIE) signal. The controller should have a register that keeps track of the highest priority interrupt and outputs it. The priority of the interrupts is defined as IRQ0 > IRQ1 > IRQ2 > IRQ3. If GIE is disabled, the output should be zero regardless of the interrupt requests.
