

You are tasked with designing a Verilog module that takes in two 8-bit inputs, `a` and `b`, and outputs their sum as an 8-bit value. The module should also contain a 1-bit input, `cin`, which represents the carry-in bit for the addition operation. The module should output a 1-bit value, `cout`, which represents the carry-out bit for the addition operation.

Your module should be named `adder` and should follow the interface below:

```
module adder(
    input [7:0] a,
    input [7:0] b,
    input cin,
    output [7:0] sum,
    output cout
);
```

You should assume that all inputs and outputs are initially set to 0. You should also assume that the addition operation is performed using unsigned arithmetic.
