Design a bidirectional 4-to-1 multiplexer with a write capability. The module allows data to be written to one of four internal 16-bit registers based on the 2-bit select input when the write_enable signal is active. It then routes the selected internal register's data to the shared data_out line. Additionally, the module enables reading data back from any of the four registers through the inout data lines, effectively facilitating bidirectional data flow between the registers and external connections.
module top_module(
  input clk,
  input [1:0] select,
  input write_enable,
  input [15:0] write_data,
  inout [15:0] data_in_0,
  inout [15:0] data_in_1,
  inout [15:0] data_in_2,
  inout [15:0] data_in_3,
  output reg [15:0] data_out  // Change inout to output reg
);
