Design a circuit that performs a multiply-accumulate operation on a set of six 16-bit input data signals. On each positive clock edge, it calculates a weighted sum of the inputs, where data_s0, data_s1, data_s2, data_s3, data_s4, and data_s5 are multiplied by specific coefficients (2, 1, 3, 1, 2, and 1 respectively). The resulting 16-bit product is then output in two forms: mac_data_0 outputs the full 16 bits, while mac_data_1 outputs the least significant 15 bits of the calculated product.
module top_module(
  input clk,
  input [15:0] data_s0,
  input [15:0] data_s1,
  input [15:0] data_s2,
  input [15:0] data_s3,
  input [15:0] data_s4,
  input [15:0] data_s5,
  output reg [15:0] mac_data_0,
  output reg [15:0] mac_data_1
);
