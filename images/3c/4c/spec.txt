Design a JK flip-flop in Verilog that takes inputs J, K, clock, and reset. The flip-flop should toggle its output Q based on the following conditions:  
1. If J = 1 and K = 0, set Q to 1.  
2. If J = 0 and K = 1, reset Q to 0.  
3. If J = 1 and K = 1, toggle Q.  
4. If reset is high, set Q to 0, regardless of J and K.  
Ensure that the flip-flop operates on the rising edge of the clock.
