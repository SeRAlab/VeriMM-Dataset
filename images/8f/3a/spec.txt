Implement a 2-bit Gray code counter module that counts in Gray code sequence. The count should increment on every rising edge of the clock signal.

Module name:
    gray_counter

Input ports:
    clk: Clock signal used for synchronous operation.
    rst_n: Active-low reset signal. Defined as 0 for reset and 1 for reset signal inactive.

Output ports:
    count: 2-bit output representing the current Gray code count value.

Implementation:
The module includes a 2-bit register, count, which is updated in the always block, triggered on the positive edge of the clock signal (posedge clk) or the negative edge of the reset signal (negedge rst_n).
On reset, indicated by ~rst_n, the count register is cleared to 0.
On every rising edge of the clock, the count is incremented in Gray code sequence.
