Design a 256-to-1 multiplexer that selects one of the 256 input lines based on an 8-bit select signal. The output will reflect the chosen input line, where the specific input is determined by the value of the select signal. When sel is assigned to a binary value representing the desired input line, the corresponding bit from the input vector will be outputted, effectively routing the selected input to the output.
module top_module(
    input [255:0] in,
    input [7:0] sel,
    output out
);
