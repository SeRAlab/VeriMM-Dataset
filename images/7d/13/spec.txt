Design a flip-flop based circuit that serves as a carry-out signal generator. When the reset signal is high, the carry-out is set to LOW. When the reset is not active and the enable signal is high, the carry-out will equal the carry-in input on the rising edge of the clock.
module top_module(
    input carry_in,
    input clk,
    input rst,
    input en,
    output reg carry_out
    );
