Implement a module that computes the SHA-256 hash of a 512-bit input message. The module should accept a 512-bit input message and produce a 256-bit hash output. It should have a clock input and a reset input, and it should compute the hash over multiple clock cycles, with valid output signals to indicate when the hash is ready. The internal state of the SHA-256 algorithm, including the message schedule and hash values, should be preserved across clock cycles.
