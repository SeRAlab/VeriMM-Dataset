
Design a 24-bit Digital-to-Analog Converter (DAC) controller that takes a 24-bit input data bus and produces a corresponding 8-bit output that represents the analog voltage level. The output should be calculated as follows: the 8-bit output is derived from the most significant 8 bits of the 24-bit input. The controller should have an enable signal that, when high, allows the output to be updated based on the current input; when low, the output should hold its previous value.
