Design a 4-bit shift register with a loading capability. When the LOAD signal is asserted, the register captures the input value A and stores it in Q. On each positive edge of the clock (CLK), if LOAD is not asserted, the register performs a circular shift to the right, moving the current bits left and bringing the most significant bit to the least significant bit position.
module top_module(
    input [3:0] A,
    input LOAD,
    input CLK,
    output reg [3:0] Q
);
