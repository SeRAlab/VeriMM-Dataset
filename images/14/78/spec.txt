Design a Direct Memory Access (DMA) controller that allows a peripheral device to read and write data to/from memory without continuous CPU intervention. The DMA controller should have the following inputs: a clock signal (`clk`), a reset signal (`rst`), a start signal (`start`), a read/write signal (`rw`), an address bus (`addr`), and a data bus (`data_in`). The outputs should include a data bus (`data_out`), a ready signal (`ready`), and an error signal (`error`). The DMA should be able to handle multiple transfers and signal when it is ready for the next operation. Implement the basic functionality without any advanced features like burst mode or priority handling.
