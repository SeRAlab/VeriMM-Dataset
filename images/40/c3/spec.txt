
Design a temperature monitoring system that uses a flip-flop to store the current temperature. The system should take a 5-bit binary input representing the temperature in degrees Celsius. If the temperature exceeds a threshold of 25 degrees (represented as 11001 in binary), an alert signal (1-bit output) should be set high. The system should have a clock and a reset signal. On the rising edge of the clock, if reset is low, it updates the stored temperature and evaluates the alert; if reset is high, it should clear the stored temperature and the alert.
