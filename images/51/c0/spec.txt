Design a 16-bit register that stores input data D on the rising edge of the CLOCK signal. If the RESET signal is activated, the register will clear its output Q to zero. Otherwise, the current value of D will be transferred to Q, effectively allowing the register to hold and update its value based on the clock signal and reset conditions.
module top_module(
    input CLOCK,
    input RESET,
    input [15:0] D,
    output reg [15:0] Q
    );
