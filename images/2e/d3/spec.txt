Implement an HMAC (Hash-based Message Authentication Code) unit using a simplified model. The HMAC takes a key and a message as inputs and produces a fixed-size output hash. For this problem, assume the hash function is a simple XOR operation for demonstration purposes. The inputs will be 128 bits for both the key and the message, and the output will be 128 bits. The HMAC process will use the formula: HMAC(key, message) = Hash((key XOR opad) || Hash((key XOR ipad) || message)), where `opad` and `ipad` are constants defined as 0x5c and 0x36 respectively. The circuit should handle the key and message in a sequential manner, processing them on a clock edge.
