
Design a combinational logic circuit that performs matrix inversion on a 2x2 matrix. The input will be a 2x2 matrix represented by 4 bits for each element. If the matrix is invertible, the output should be the inverted matrix; otherwise, the output should be a specified error value. The matrix will be represented as follows:
```
| a  b |
| c  d |
```
The inverted matrix is given by:
```
|  d/(ad-bc)  -b/(ad-bc) |
| -c/(ad-bc)   a/(ad-bc) |
```
If the determinant (ad - bc) is zero, output an error code (e.g., 0xFFFF).
