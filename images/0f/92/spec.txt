Design a Verilog module for a Bluetooth module controller that accepts a 4-bit command input and outputs a 3-bit response based on the following command-response mapping:  
- Command 0000 -> Response 000  
- Command 0001 -> Response 001  
- Command 0010 -> Response 010  
- Command 0011 -> Response 011  
- Command 0100 -> Response 100  
For any other command, the response should be 111. The module should have a clock input to synchronize command reading.
