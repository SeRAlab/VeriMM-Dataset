Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state M (output 1).
2. state N (output 0).
3. state O (output 1).
4. state P (output 0).

State transitions:
1. From state M: If x = 1, then transition to state O. If x = 0, then transition to state N.
2. From state N: If x = 1, then transition to state P. If x = 0, then transition to state M.
3. From state O: If x = 1, then transition to state N. If x = 0, then transition to state P.
4. From state P: If x = 1, then transition to state M. If x = 0, then transition to state O.

Assume that a one-hot code is used with the state assignment y[3:0] = 0001(M), 0010(N), 0100(O), 1000(P)

Write a Verilog for the signal Y1, which is the input of state flip-flop y[1], for the signal Y3, which is the input of state flip-flop y[3]. Derive the Verilog by inspection assuming a one-hot encoding.
