
Design a 16-bit serializer that converts a 16-bit parallel input into a serial output. The serializer should have an input enable signal (`in_en`) that controls when the serializer accepts new data. On each clock cycle, if `in_en` is high, the serializer should output the bits of the input in a serial manner, starting from the least significant bit (LSB) to the most significant bit (MSB). The serializer will also have an output `data_out` for the serialized output and a `valid` signal that indicates when the output is valid.
