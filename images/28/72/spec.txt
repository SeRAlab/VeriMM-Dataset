Design a Verilog module that implements a simple state machine for a Rapidly-exploring Random Tree (RRT) algorithm. The state machine should have three states: IDLE, EXPLORE, and GOAL. The module should have inputs for a trigger signal to transition from IDLE to EXPLORE, and a signal to transition from EXPLORE to GOAL. The output should indicate the current state of the state machine: 2'b00 for IDLE, 2'b01 for EXPLORE, and 2'b10 for GOAL.
