

You have been tasked with designing a Verilog module that takes an 8-bit input signal and outputs two 4-bit signals. The first output signal should contain the most significant 4 bits of the input signal, while the second output signal should contain the least significant 4 bits of the input signal. You are required to write a module that performs this functionality.

Your module should have the following interface:

```
module split_bytes (
 input [7:0] input_signal,
 output [3:0] output_signal_1,
 output [3:0] output_signal_2
);
```

The `input_signal` input is an 8-bit signal that contains the input data. The `output_signal_1` output is a 4-bit signal that should contain the most significant 4 bits of the input signal. The `output_signal_2` output is a 4-bit signal that should contain the least significant 4 bits of the input signal.

Your Verilog module should be self-contained and should not require any additional modules or libraries to function. Your module should be no longer than 200 lines of code.
