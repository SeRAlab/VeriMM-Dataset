Design an IIR filter in Verilog that takes a 16-bit input sample and outputs a 16-bit filtered sample. The filter coefficients should be defined as parameters. The filter should implement a simple one-pole IIR filter defined by the equation: 
output[n] = b0 * input[n] + a1 * output[n-1], where b0 and a1 are the filter coefficients. The design should include a clock and reset signal for synchronous operation.
