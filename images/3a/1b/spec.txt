Design an SR Flip-Flop using Verilog. The flip-flop should have two inputs: S (Set) and R (Reset), and one output Q. The behavior should be: 
- If S = 1 and R = 0, Q should be set to 1.
- If S = 0 and R = 1, Q should be reset to 0.
- If both S and R are 0, Q should hold its previous value.
- If both S and R are 1, it should be considered invalid and Q should be undefined.
