Design a digital circuit that performs basic logic operations on two binary inputs. This module computes the AND, OR, and XOR of the inputs, providing the results as separate outputs. Additionally, it generates a 3-bit binary output representing the sum of these logical results, concatenating the AND, OR, and XOR outputs. 
module top_module(
    input in1, // Binary input 1
    input in2, // Binary input 2
    output out_and, // AND output
    output out_or, // OR output
    output out_xor, // XOR output
    output [2:0] sum // Sum of the three outputs in binary form
);
