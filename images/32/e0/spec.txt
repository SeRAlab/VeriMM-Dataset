Design an 8-bit Linear Feedback Shift Register (LFSR) that generates a pseudo-random sequence of bits. The LFSR should use the polynomial x^8 + x^6 + x^5 + x^4 + 1 as its feedback taps. The LFSR should be able to load an initial seed value and shift on each clock cycle. Provide a reset signal that clears the LFSR.
