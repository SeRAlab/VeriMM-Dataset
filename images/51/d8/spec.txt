Design a D-type flip-flop with asynchronous set and clear functionalities. The flip-flop captures the input data (D) on the rising edge of the clock (CLK), unless an asynchronous clear (SCD) or set (SCE) condition is triggered. When SCD is asserted, the output (Q) is set to LOW regardless of the CLK or D inputs. Conversely, when SCE is asserted, the output is set to HIGH. The output complement (Q_N) is also generated as the inverse of Q.
