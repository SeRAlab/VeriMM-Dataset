Design a GPIO (General Purpose Input/Output) controller that interfaces a configurable number of GPIO pins with a system clock. The module supports read and write operations controlled by an external strobe signal, allowing data to be written to or read from an array of state registers based on the specified address. When the read-write (rw) signal is high, data from the input bus (data_i) is written to the designated state register; otherwise, data from the specified register is output on the data_o bus, with unused bits zero-padded. The controller utilizes a reset mechanism to clear all registers and includes logic to manage bidirectional GPIO pin states based on the current register's values.
module top_module(clk, strobe, rw, reset, addr, data_i, data_o, gpio);
