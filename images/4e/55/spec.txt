Design a four-to-one multiplexer that selects one of four one-bit input signals (data_in[0] to data_in[3]) based on a two-bit select input (sel). The output (out) reflects the chosen input, where sel = 00 outputs data_in[0], sel = 01 outputs data_in[1], sel = 10 outputs data_in[2], and sel = 11 outputs data_in[3].
module top_module(
    input [3:0] data_in,
    input [1:0] sel,
    output reg out
);
