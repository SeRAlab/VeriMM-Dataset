
Design an 8-bit SRAM cell with read and write operations. The SRAM cell should have the following inputs: 
- `data_in` (8 bits): Data to be written to the cell.
- `address` (3 bits): Address of the cell (for the sake of simplicity, we will assume a single cell here).
- `write_enable`: Control signal to enable writing to the cell.
- `read_enable`: Control signal to enable reading from the cell. 
The output should be `data_out` (8 bits): Data read from the cell.
