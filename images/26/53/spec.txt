Design a simple 8-bit EEPROM cell that allows reading, writing, and erasing of the stored data. The EEPROM cell should have a write enable signal, a read enable signal, an erase signal, and an 8-bit data input/output. The behavior is as follows: when the write enable signal is high, the data input is written to the cell; when the erase signal is high, the cell is set to 0; when the read enable signal is high, the stored data is output.
