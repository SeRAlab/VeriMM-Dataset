Design a D flip-flop with asynchronous reset and set functionality. Upon a rising edge of the clock, if the reset (R) signal is asserted low, the output Q is set to LOW. If the set (S) signal is asserted low, Q is set to HIGH. If neither reset nor set is active, the output Q takes the value of the data input D. This module provides versatile control over the stored value, allowing for immediate output changes independent of the clock under certain conditions.
module top_module(
  input CLK,
  input D,
  input R,
  input S,
  output reg Q
);
