Design a Binary-Coded Decimal (BCD) incrementor that takes a 12-bit BCD input and produces a 12-bit BCD output representing the incremented value. The module separates the input into three groups of 4 bits (representing the hundreds, tens, and units places). It increments the units place by one and applies BCD correction (adding 6) if the resulting value exceeds 9. If the increment to the units place causes a carry, it then increments the tens place similarly, applying the correction as needed. Lastly, it checks for a carry from the tens to the hundreds place, performing the same logic. The final output is the 12-bit BCD representation of the input value incremented by one.
