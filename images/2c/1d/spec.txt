
Design a Finite State Machine (FSM) for a sliding window protocol that controls the sending of packets. The FSM should have the following states: IDLE, SEND, and WAIT. The protocol should allow for a window size of 3 packets. The FSM should transition between states based on the signals `send_packet` (to send a packet) and `ack_received` (to acknowledge receipt of a packet). The output should indicate the current packet being sent and whether the window is full or not.
