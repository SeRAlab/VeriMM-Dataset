Design a keyboard interface module that manages an 80-bit keyboard state. The module captures input data over a bus using two control signals: `nWR_i` (write) and `nRD_i` (read) to respectively update or retrieve sections of the keyboard data. On a positive clock edge, if not in reset, the module can either reset the keyboard state or modify specific 8-bit segments based on the provided 4-bit address `A_i`, allowing for the reading of data from different segments or writing new data to them. Additionally, it has a feature to clear the entire keyboard state or invert the current state based on certain bits within the input data.
module top_module( 
	output reg [79:0] keyboard_o,
	
	input busclk_i,	
	input nreset_i,
	input [3:0] A_i,	
	input [7:0] D_i,
	output reg [7:0] D_o,
	input nWR_i,
	input nRD_i	
	);
