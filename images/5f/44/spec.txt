Implement a Verilog module for a 2-bit priority encoder with enable. The encoder should have a 4-bit input `in`, an enable input `en`, and a 2-bit output `out`. When `en` is high, the output `out` should represent the position of the highest-order set bit in `in`. When `en` is low, `out` should be set to 0.

module priority_encoder(
	input wire [3:0] in,
	input wire en,
	output reg [1:0] out
);
