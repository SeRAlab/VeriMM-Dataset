
Create a Verilog module for a 2-to-1 multiplexer with data forwarding capability. The multiplexer should select between two data inputs based on a single select line. If the select line is high, the output should reflect the second input; otherwise, it should reflect the first input. Implement data forwarding such that if the first input is the same as the output from a previous operation, it will directly use that without going through the multiplexer.
