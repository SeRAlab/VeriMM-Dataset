

You have been tasked with designing a 4-to-1 multiplexer using verilog. The module should have four input signals, `A`, `B`, `C`, and `D`, and two select signals, `S0` and `S1`. The output signal, `Y`, should be selected based on the values of `S0` and `S1` as follows:

- If `S0` and `S1` are both 0, `Y` should be equal to `A`.
- If `S0` is 0 and `S1` is 1, `Y` should be equal to `B`.
- If `S0` is 1 and `S1` is 0, `Y` should be equal to `C`.
- If `S0` and `S1` are both 1, `Y` should be equal to `D`.

The module should also have two power supply signals, `VPWR` and `VGND`, and two bias signals, `VPB` and `VNB`, which are not used in the module.

Your task is to complete the verilog module `mux4to1`, which should implement the 4-to-1 multiplexer functionality described above.
