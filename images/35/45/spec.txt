Design a power gating circuit that takes a 2-bit control signal `ctrl` and a 4-bit data input `data_in`. The output `data_out` should be the same as `data_in` when `ctrl` is '11' (power on) and should be '0000' when `ctrl` is '00' (power off). For any other value of `ctrl`, `data_out` should be 'XXXX' (unknown).
