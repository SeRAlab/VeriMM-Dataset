Design a 4-bit synchronous counter with load functionality. On the rising edge of the clock, the counter will reset to zero if the reset signal is high. If the load signal is asserted, the counter will be set to the value provided on the data_in input. Otherwise, it will increment its current count by one on each clock cycle.
module top_module(
    input clk,
    input reset,   // Synchronous active high reset
    input load,    // Synchronous load
    input [3:0] data_in,
    output reg [3:0] count
);
