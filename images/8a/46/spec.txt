Design a D latch that holds a single bit of data. When the clock signal (Clk) is active, the latch captures the input (D) and maintains the output (Q) as long as the clock remains active. If Clk is low, the output retains its previous value, effectively storing the data until the next active clock edge. This design utilizes cross-coupled NOR gates to create a memory element capable of changing its stored value based on the input signal.
