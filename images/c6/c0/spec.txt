

You are tasked to design a verilog module that takes in a 32-bit input signal and outputs the maximum value of the input signal. You should name your module `max32` and it should have the following ports:

- `input [31:0] in1`: a 32-bit input signal
- `output [31:0] out1`: a 32-bit output signal that represents the maximum value of the input signal

You should assume that the input signal is a signed integer, and the output signal should also be a signed integer.

You should ensure that your design is synthesizable and meets the following requirements:

- Your design should be optimized for area
- Your design should be able to handle all possible input values, including the maximum and minimum values for a signed 32-bit integer
