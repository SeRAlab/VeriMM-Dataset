
Design a SR flip-flop using Verilog. The SR flip-flop should have two inputs (S and R) and one output (Q). The behavior of the flip-flop should be such that:
- When S = 1 and R = 0, Q should become 1 (set state).
- When S = 0 and R = 1, Q should become 0 (reset state).
- When S = 0 and R = 0, Q should hold its previous state.
- When S = 1 and R = 1, the state is indeterminate (you can choose to keep the previous state or set Q to 0).
Your design should include a clock input that triggers the flip-flop operation.
