Design a circuit that performs byte swapping on a 32-bit input. The module takes a 32-bit input signal and rearranges its bytes so that the least significant byte becomes the most significant, effectively changing the endianness of the data. The output consists of the reordered bytes, with the first byte coming from the original last byte and so on, thereby allowing for compatibility between little-endian and big-endian systems.
module top_module(
	input [31:0] inval,
	output [31:0] endian_twiddled_data);
