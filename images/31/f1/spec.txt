
Design a simple branch predictor that uses a 2-bit saturating counter for each branch instruction. The counter has four states: 00 (strongly not taken), 01 (weakly not taken), 10 (weakly taken), and 11 (strongly taken). The branch predictor should take a branch direction (0 for not taken and 1 for taken) as input and output the predicted direction for the next branch along with updating the state of the counter based on the actual branch direction.
