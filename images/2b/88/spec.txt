Design an SR latch using D flip-flops. The latch should have two inputs, Set (S) and Reset (R), and two outputs, Q and Q'. The state of the latch should change based on the inputs in the following manner: 
- If S = 1 and R = 0, then Q should be 1.
- If S = 0 and R = 1, then Q should be 0.
- If S = 0 and R = 0, then Q should hold its previous state.
- If S = 1 and R = 1, then the state is undefined, and the latch should be assumed to maintain its previous state (not used in this problem).
