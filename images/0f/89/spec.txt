Design an SR latch using Verilog. The latch should have two inputs, S (Set) and R (Reset), and two outputs, Q and Qn (complement of Q). The latch should hold its state until S or R is activated. The behavior should be defined as: when S is activated, Q should be set to 1; when R is activated, Q should be reset to 0; if both S and R are inactive, Q should maintain its previous state. If both S and R are activated simultaneously, the output should be invalid.
