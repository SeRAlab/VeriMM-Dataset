
Design a 16-bit timer that counts up from 0 to a maximum value defined by a 16-bit input. The timer should have the following features:
1. A clock input (clk) to drive the timer.
2. A reset input (rst) that sets the timer to zero when high.
3. A load input (load) that, when high, loads the input value into the timer.
4. An enable input (enable) that, when high, increments the timer on each clock cycle.
5. The timer should wrap around to zero after reaching its maximum value.
The timer state should be output as a 16-bit value.
