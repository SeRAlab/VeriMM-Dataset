Design a 4-bit register with write enable functionality and a hit indicator. The module captures 4-bit input data on the rising edge of the clock when the write enable signal (wrenb) is active, storing the input data in an internal register. It also generates a hit signal that indicates whether the input data is within the valid range of 0 to 15. If wrenb is not asserted, the module outputs a single-bit input signal (din) instead while resetting the hit indicator to zero. The outputs consist of the stored data and the hit status, facilitating data handling and validation in digital circuits.
module top_module(
  input  wire [3:0] in_data,
  input  wire       clk,
  input  wire       wrenb,
  input  wire       din,
  output wire [3:0] out_data,
  output wire       hit
);
