

You are tasked with designing a module for a 4-to-1 multiplexer. The module should have 4 input signals (A, B, C, D) and 2 control signals (S0, S1) which determine which input signal is passed through to the output signal (Y). If S0 and S1 are both 0, then Y should equal A. If S0 is 0 and S1 is 1, then Y should equal B. If S0 is 1 and S1 is 0, then Y should equal C. If S0 and S1 are both 1, then Y should equal D.

Your module should have the following interface:

```
module mux4to1 (
  input wire A,
  input wire B,
  input wire C,
  input wire D,
  input wire S0,
  input wire S1,
  output wire Y
);
```
