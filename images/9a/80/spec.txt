Design a D flip-flop with asynchronous set and reset capabilities. The flip-flop captures the input D on the rising edge of the clock signal (CLK) and updates the outputs Q and Q_N accordingly, while also allowing for immediate control through SET_B and RESET_B inputs. When SET_B is low, Q is set to high and Q_N is set to low, regardless of the clock. Conversely, when RESET_B is low, Q is set to low and Q_N is set to high, overriding the state captured on the clock edge.
module top_module(
    input D,
    input SET_B,
    input RESET_B,
    input CLK,
    output reg Q,
    output reg Q_N
);
