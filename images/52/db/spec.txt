Design a 32-bit wide pre-adder circuit that computes the sum of three 32-bit input values (rx_a, rx_b, and rx_c). The module outputs a 32-bit result (tx_sum) and a carry bit (tx_carry). The carry bit is set to 1 if the resulting sum exceeds the maximum value representable by a 32-bit integer (0xFFFFFFFF), indicating an overflow occurred during addition.
module top_module(
    input [31:0] rx_a,
    input [31:0] rx_b,
    input [31:0] rx_c,
    output reg [31:0] tx_sum,
    output reg tx_carry
);
