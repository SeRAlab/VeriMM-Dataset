Write a Verilog module for an 8-bit register with asynchronous clear and enable. The module has the following ports: a clock input "clk", a clear input "clr", an enable input "en", an 8-bit input "data", and an 8-bit output "q". The register should load "data" into "q" on the rising edge of the clock when "en" is high, and clear "q" to 0 when "clr" is high.

module reg_with_clear (
  input clk,
  input clr,
  input en,
  input [7:0] data,
  output reg [7:0] q);
