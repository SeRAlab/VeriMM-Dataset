Design a circuit that takes a 4-bit input vector (`in_vec`) and, based on a select signal (`sel_comp`), computes either the two's complement or the one's complement of the input. When `sel_comp` is high (1), the output (`complement`) represents the two's complement of `in_vec` (flip bits and add one). When `sel_comp` is low (0), it outputs the one's complement (flip bits only). Additionally, the module also outputs the original input vector (`outv`).
module top_module(
    input [3:0] in_vec,
    input sel_comp,
    output [3:0] outv,
    output [3:0] complement
);
