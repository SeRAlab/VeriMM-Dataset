Design an 8-bit deserializer that takes a serial input signal and produces an 8-bit parallel output. The deserializer should have a clock input to shift in the bits serially. The serial data should be valid on the rising edge of the clock. Use a 3-bit counter to keep track of the number of bits received. Once 8 bits are received, the output should be available for one clock cycle before being updated with the next set of incoming bits.
