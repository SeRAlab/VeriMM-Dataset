Design a Verilog module for a Flash Memory Cell that can store a single bit of data. The module should have inputs for 'write_enable', 'data_in', and 'read_enable', and outputs the stored 'data_out'. If 'write_enable' is high, the 'data_in' should be stored. If 'read_enable' is high, the stored data should be outputted. The output 'data_out' should remain the same when neither read nor write is enabled.
