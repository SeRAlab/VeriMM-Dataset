Design a circuit that performs the function of a negative AND gate for two separate inputs. The first output, p1y, is the logical NOR of four input signals (p1a, p1b, p1c, p1d), producing a LOW output only when all four inputs are HIGH. Similarly, the second output, p2y, is the logical NOR of another set of four input signals (p2a, p2b, p2c, p2d), functioning identically.
module top_module( 
    input p1a, p1b, p1c, p1d,
    output p1y,
    input p2a, p2b, p2c, p2d,
    output p2y );
