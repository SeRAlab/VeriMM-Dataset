Design a circuit that functions as an 8-bit barrel shifter. It takes an 8-bit input and allows for shifting the bits either left or right by a specified amount, determined by a 3-bit shift_amount input. The shift_direction input selects the shifting mode; when it is high, the circuit performs a left shift, and when it is low, it performs a right shift, outputting the resulting shifted data.
module top_module(
  input [7:0] data_in,
  input [2:0] shift_amount,
  input shift_direction,
  output [7:0] data_out
);
