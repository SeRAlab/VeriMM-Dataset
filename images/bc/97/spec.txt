Design a scan-enabled D-type flip-flop (DFF) with reset functionality. The circuit captures an input (in) on the rising edge of the clock when reset is inactive (reset_l = 1). Additionally, it supports scan operations controlled by the scanen signal; when scanen is high and sin is low, the flip-flop's output is set to the state of the D input, while if sin is high, it takes the scanned input directly. The output (out) is also reset to low when reset_l is low. This design facilitates both normal DFF operation and scan-based testing.
