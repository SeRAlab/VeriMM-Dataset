Design a 4-to-1 multiplexer that selects one of four inputs (in0, in1, in2, in3) based on a 2-bit select signal (sel). The output (out) will reflect the value of the selected input: when sel is 00, the output is in0; when sel is 01, the output is in1; when sel is 10, the output is in2; and when sel is 11, the output is in3. The design uses AND gates to isolate each input based on the select signals and an OR gate to combine the results into a single output.
module top_module(
    output out,
    input  in0, in1, in2, in3,
    input  [1:0] sel
);
