

You are tasked with designing a Verilog module for a 4-bit binary to Gray code converter. The module should have a 4-bit input and a 4-bit output, where the output represents the Gray code equivalent of the input.

Gray code is a binary numeral system where two consecutive values differ by only one bit. For example, the 4-bit binary number 0101 would be represented as 0111 in Gray code.

Your module should be named "bin2gray" and should take in a 4-bit input named "bin_in" and output a 4-bit Gray code named "gray_out". You may assume that the input will always be a valid 4-bit binary number.

You should implement this module using only combinational logic, using no more than 200 lines of Verilog code.
