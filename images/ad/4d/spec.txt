Design a serial-to-parallel converter that captures incoming serial data on each falling edge of a bit clock (bclk) signal. The module utilizes a linearly rolling mechanism controlled by a left-right clock (lrclk) signal to indicate when to shift in the next bit. When lrclk transitions from low to high (as detected by a delayed signal), it triggers the storage of the serial input (in_data) into a 16-bit output register (data). The module also incorporates a reset functionality to initialize the output data and a bit counter that tracks the number of bits received until all 16 bits are collected, with the counter reset being triggered by an active low reset signal.
module top_module(input bclk, input lrclk, input reset_n, input in_data, output reg [15:0] data);
