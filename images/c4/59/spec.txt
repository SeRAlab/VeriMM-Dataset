

You are tasked with designing a Verilog module that takes in three input signals, A1, A2, and B1_N, and outputs a single signal, Y. The module should have the following functionality:

- The output signal, Y, should be the result of a series of logic gates that take in the three input signals.
- The input signals, A1 and A2, should be OR'ed together.
- The input signal, B1_N, should be inverted.
- The inverted signal, B1_N, should be NAND'ed with the OR'ed signal from A1 and A2.
- The final result of the NAND operation should be the output signal, Y.

You are required to implement the module using only one module within 200 lines of Verilog code. Your module should have the following ports:

- Y: output signal
- A1: input signal
- A2: input signal
- B1_N: input signal

Your module should also have the following supplies:

- VPWR: supply1
- VGND: supply0
- VPB: supply1
- VNB: supply0
