Please act as a professional verilog designer.

Design an 8-to-1 multiplexer using Verilog. The multiplexer has a selection signal to choose between eight 1-bit input signals.

Module name:  
    mux_8to1  

Input ports:
    a: Input signal a.
    b: Input signal b.
    c: Input signal c.
    d: Input signal d.
    e: Input signal e.
    f: Input signal f.
    g: Input signal g.
    h: Input signal h.
    sel: 3-bit Selection signal.

Output ports:
    y: Output signal.

Implementation:
Multiplexer operation:
If the selection signal (sel) is 000, the output (y) is assigned the value of input a.
If the selection signal (sel) is 001, the output (y) is assigned the value of input b.
If the selection signal (sel) is 010, the output (y) is assigned the value of input c.
If the selection signal (sel) is 011, the output (y) is assigned the value of input d.
If the selection signal (sel) is 100, the output (y) is assigned the value of input e.
If the selection signal (sel) is 101, the output (y) is assigned the value of input f.
If the selection signal (sel) is 110, the output (y) is assigned the value of input g.
If the selection signal (sel) is 111, the output (y) is assigned the value of input h.
