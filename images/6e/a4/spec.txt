Design a 4-bit arithmetic unit capable of performing both addition and subtraction based on a mode selection input. When the mode input is 0, the circuit adds the 4-bit inputs A and B along with a carry-in bit (Cin), producing a 4-bit sum output (S) and a carry-out (Cout) that indicates if there was an overflow. When the mode input is 1, the circuit subtracts B and Cin from A, also generating the 4-bit result (S) and Cout, which signifies whether the result is non-negative.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input Cin,
  input mode,
  output reg [3:0] S,
  output reg Cout
);
