Design a simple PCIe request-response controller. The controller has an input signal 'req' for an incoming request and outputs 'ack' when the request is acknowledged. The controller should also have a clock and reset signal. When 'reset' is high, 'ack' should be low regardless of 'req'. If 'req' is high and 'ack' is low, 'ack' should be set high on the next clock cycle. If 'req' goes low, 'ack' should return to low on the next clock cycle.
