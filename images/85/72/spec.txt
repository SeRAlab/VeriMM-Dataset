Design a 4-to-1 multiplexer that accepts four 2-bit input signals (a, b, c, d) and outputs one of these inputs based on a 2-bit selection signal (sel). The output will be assigned the value of the selected input according to the value of sel, where sel=00 selects input a, sel=01 selects input b, sel=10 selects input c, and sel=11 selects input d.
module top_module(
input   wire    [1:0]   a,  
input   wire    [1:0]   b,  
input   wire    [1:0]   c,  
input   wire    [1:0]   d,  
input   wire    [1:0]   sel,    

output  reg     [1:0]   out 
);
