Design a 4-bit shift register with load and shift functionality. When the LD signal is high, the register loads the 4-bit input data D into the output Q. When the SH signal is active, the register performs a right shift operation, moving the current bits to the right and inputting a zero at the most significant bit position. This design allows for both loading new data and shifting the stored data effectively.
module top_module(
    input [3:0] D,
    input LD,
    input SH,
    output reg [3:0] Q
);
