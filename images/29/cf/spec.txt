
Design a Voltage-Controlled Oscillator (VCO) that generates a square wave output. The frequency of the output should change based on a 3-bit input control signal. The control signal will determine how many clock cycles the output signal stays high or low. For example, if the control signal is '000', the output should have a frequency of 1 Hz, and if the control signal is '111', it should have a frequency of 7 Hz. Implement the VCO using a clock input and a reset input.
