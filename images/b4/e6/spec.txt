Design a 4-bit up/down counter that increments or decrements its output based on the UP_DOWN control input. When the RESET input is activated, the output is set to zero. On each positive edge of the clock signal, if UP_DOWN is high, the counter increments by one; if UP_DOWN is low, it decrements by one, allowing for bidirectional counting with clear reset functionality.
module top_module(
    input CLK,
    input UP_DOWN,
    input RESET,
    output reg [3:0] OUT
);
