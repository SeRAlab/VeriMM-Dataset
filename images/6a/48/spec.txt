Implement the Verilog module based on the following description.
You are given a twelve-bit input vector in[11:0]. We want to compute some relationships between the bits and their neighbours: 
// (1) out_and: Each bit of this output vector should indicate whether both the corresponding input bit and its neighbour to the left (higher index) are '1'. For example, out_and[8] should indicate if in[8] and in[9] are both 1. Since in[11] has no neighbour to the left, the answer is obvious so we don't need to know out_and[11]. 
// (2) out_or: Each bit of this output vector should indicate whether either the corresponding input bit or its neighbour to the right are '1'. For example, out_or[3] should indicate if either in[3] or in[2] are 1. Since in[0] has no neighbour to the right, the answer is obvious so we don't need to know out_or[0]. 
// (3) out_xor: Each bit of this output vector should indicate whether the corresponding input bit is different from its neighbour to the right. For example, out_xor[6] should indicate if in[6] is different from in[5]. For this part, treat the vector as wrapping around, so in[0]'s neighbour to the right is in[11].
