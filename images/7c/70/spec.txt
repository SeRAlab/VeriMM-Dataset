Design a 4-bit ripple carry adder that computes the sum of two 4-bit binary inputs, `a` and `b`, along with a carry-in input `cin`. The module produces a 4-bit output `sum` representing the least significant bits of the result and a `cout` output indicating an overflow or carry-out from the most significant bit. The carry-out is generated based on the fifth bit of the internal addition result.
module top_module(
    input [3:0] a,
    input [3:0] b,
    input cin,
    output [3:0] sum,
    output cout
    );
