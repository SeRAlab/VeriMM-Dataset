Implement a Verilog module that describes a 24-hour digital clock with hours, minutes, and seconds counters. Each counter should increment on the rising edge of the clock and reset appropriately to form a valid 24-hour time format.
module digital_clock(
    input clk,
    input reset,
    output reg [4:0] hours,
    output reg [5:0] minutes,
    output reg [5:0] seconds);
