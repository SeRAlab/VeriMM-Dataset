Implement the Verilog module based on the following description.
Create a 3-bit ring counter. The counter generates a 3-bit sequence that loops every 3 clock cycles. 

// Signals are defined as below:
// (1) clk: The clock signal.
// (2) reset: Resets the counter to the initial state. Active high.
// (3) q: The 3-bit output of the counter.
module ring_counter(
    input clk,
    input reset,
    output reg [2:0] q);
