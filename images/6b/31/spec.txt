Design a module that converts ASCII character inputs representing hexadecimal digits into their corresponding 4-bit hexadecimal values. The input can be an ASCII character from '0' (0x30) to '9' (0x39) for the decimal values and from 'a' (0x61) to 'f' (0x66) for the hexadecimal values. The output is a 4-bit register that reflects the decoded hexadecimal value, defaulting to 0 for any other input.
module top_module(
    input [7:0]in,
    output reg [3:0]out
    );
