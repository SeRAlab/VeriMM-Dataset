Design a sequential circuit that computes an output based on the states of two input signals (A1, A2) and one additional input (B1) upon the rising edge of a clock signal (clk). If both A1 and A2 are HIGH, the output Y will be LOW. If A1 is LOW and A2 is HIGH, Y will be set to HIGH. If A1 is HIGH and A2 is LOW, Y will take the value of B1. In all other cases, Y will be set to HIGH. This module effectively acts as a conditional logic gate that integrates gating logic with sequential behavior.
module top_module(
    input clk,
    input A1,
    input A2,
    input B1,
    output reg Y
);
