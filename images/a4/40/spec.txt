Design a D flip-flop (DFF) with asynchronous reset (R) and preset (P) functionalities. The module takes an input D and a clock signal C; it outputs Q, which captures the value of D on the rising edge of C. If the reset signal R is asserted, Q is set to 0, while asserting the preset signal P sets Q to 1, overriding the D input. This design allows for flexible control over the flip-flop's output state, facilitating various memory or state-holding applications in digital circuits.
