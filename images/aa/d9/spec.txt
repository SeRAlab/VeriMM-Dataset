Develop a binary to Binary-Coded Decimal (BCD) converter. The module takes a 4-bit binary input and produces two 4-bit BCD outputs. Upon each rising clock edge, it processes the binary input: if any bit of the input is 5 or greater, it adjusts the BCD representation accordingly, distributing the value into two separate BCD digits. The outputs represent the converted BCD values from the binary input, allowing for accurate decimal representation in two 4-bit segments.

  input [3:0] bin_in,
  input clk,
  output reg [3:0] bcd_out1,
  output reg [3:0] bcd_out2
);
