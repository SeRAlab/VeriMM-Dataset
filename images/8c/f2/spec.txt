Design a four-input, one-output multiplexer (mux). The module selects one of the four input signals (A1, A2, A3, A4) as the output (Y) based on the values of the two selection lines (S0, S1). Specifically, when S0 and S1 are both low, the output will be A1; when S0 is low and S1 is high, the output will be A2; when S0 is high and S1 is low, the output will be A3; and when both S0 and S1 are high, the output will be A4.
module top_module(
    input A1,
    input A2,
    input A3,
    input A4,
    input S0,
    input S1,
    output reg Y
);
