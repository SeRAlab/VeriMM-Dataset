Design an 8-bit SRAM cell with read and write capabilities. The SRAM cell should have the following inputs: `data_in` (8 bits), `write_enable` (1 bit), `address` (3 bits), and a `clk` (1 bit). The outputs should include `data_out` (8 bits). The SRAM should store data at the specified address when `write_enable` is high and output the data stored at the specified address when `write_enable` is low.
