Write a Verilog module for a 3-bit bidirectional shift register with enable, asynchronous reset, and direction control. The shift register should shift left if direction is 1 and shift right if direction is 0 on each positive clock edge when enable is high. If reset is high, the shift register should reset to 3'b000.
module bidirectional_shift_register (
    input clk,
    input reset,
    input enable,
    input direction,
    output reg [2:0] q
);
