Design a register-based accumulation circuit with an 8-bit output. The module captures and holds the value of the input data when the enable signal (ena) is high, and it is triggered on the rising edge of the clock signal (clk). If the reset signal (rst) is asserted, the accumulator resets its value to zero. Otherwise, if ena is active, the accumulator updates to the latest data value.
