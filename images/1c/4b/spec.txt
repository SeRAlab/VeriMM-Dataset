
Design a thermal sensor calibration system that takes a 10-bit input temperature reading and adjusts it based on a calibration factor. The calibration factor is a 4-bit signed integer. The output should be the calibrated temperature, which is also a 10-bit value. Ensure that the temperature does not exceed a maximum range of 1023 (10-bit maximum). Implement a state to hold the current reading and another state for the calibration factor.
