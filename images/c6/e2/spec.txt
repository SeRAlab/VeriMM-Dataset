

You are tasked with designing a verilog module that implements a 4-bit binary adder with carry-in and carry-out. The module should have two 4-bit inputs, A and B, and a 1-bit input, Cin, representing the carry-in. The module should output a 4-bit sum, S, and a 1-bit carry-out, Cout.

Your module should be named "binary_adder" and should include the following:

- A 4-bit input port named "A"
- A 4-bit input port named "B"
- A 1-bit input port named "Cin"
- A 4-bit output port named "S"
- A 1-bit output port named "Cout"

You should use only basic logic gates (AND, OR, XOR, NOT) and the verilog "+" operator to implement your module.
