Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state R (output 1).
2. state S (output 0).
3. state T (output 1).
4. state U (output 0).

State transitions:
1. From state R: If a = 1, then transition to state S. If a = 0, then transition to state U.
2. From state S: If a = 1, then transition to state T. If a = 0, then transition to state R.
3. From state T: If a = 1, then transition to state U. If a = 0, then transition to state R.
4. From state U: If a = 1, then transition to state S. If a = 0, then transition to state R.

Assume that a one-hot code is used with the state assignment y[3:0] = 0001(R), 0010(S), 0100(T), 1000(U)

Write a Verilog for the signal Y0, which is the input of state flip-flop y[0], for the signal Y3, which is the input of state flip-flop y[3]. Derive the Verilog by inspection assuming a one-hot encoding.
