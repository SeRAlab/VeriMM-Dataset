Design a synchronous 1-bit register with an active-low reset and a load functionality. The register captures input data (D) on the rising edge of the clock (clk) when the load signal is high; otherwise, it maintains its current state. The reset signal (rst) forcefully sets the output (Q) to zero when asserted. This design utilizes flip-flops and combinational logic to control data loading and reset behavior, enabling basic storage and state retention in digital circuits.
