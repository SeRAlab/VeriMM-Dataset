

You are tasked with designing a module that takes in a 4-bit binary input and outputs the binary equivalent of its two's complement representation. The module should have the following ports:

- `input [3:0] A`: the 4-bit input
- `output [3:0] Y`: the 4-bit two's complement output

The two's complement representation of a binary number is obtained by inverting all the bits and adding 1 to the result. For example, the two's complement of 0101 is 1011.

Your module should be self-contained and should not rely on any other modules. You may use any logic gates and operators that are available in Verilog. Your module should be synthesizable and should not use any non-synthesizable constructs.

Write a Verilog module that implements this functionality.
