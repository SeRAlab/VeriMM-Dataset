Design a 2-to-4 line decoder that takes two binary inputs (A and B) and produces four distinct outputs (Y0, Y1, Y2, Y3). Each output corresponds to a unique combination of the inputs such that when A and B are both low (0), Y0 is high (1), when A is low and B is high (1), Y1 is high, when A is high and B is low (1), Y2 is high, and when both A and B are high (1), Y3 is high. The implementation utilizes logic gates to derive the outputs from the input states, effectively demultiplexing the input signals into individual outputs.
module top_module(
    input A,
    input B,
    output Y0,
    output Y1,
    output Y2,
    output Y3
);
