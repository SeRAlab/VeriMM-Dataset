Design a vending machine controller that determines whether an item can be vended based on the received coin value and selected item. It takes a 2-bit input for coins, a 2-bit input for item selection, and a dispense signal. The module outputs a vend signal that indicates whether the selected item can be dispensed: no item is vended if none is selected, item A requires at least 5 cents to vend, item B requires at least 10 cents, and item C requires at least 15 cents, all contingent upon the dispense signal being active.
module top_module(
    input [1:0] coin,
    input [1:0] item,
    input dispense,
    output reg vend
);
