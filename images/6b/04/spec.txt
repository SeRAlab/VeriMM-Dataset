Design a 32-bit arithmetic shifter. The module takes a 32-bit input and performs either a logical right shift or a logical left shift based on the ShiftType input (where 1 represents a right shift and 0 a left shift). The amount of shifting is determined by the 5-bit ShiftAmount input, which specifies how many positions to shift the input value. The resulting shifted output is provided as output.
module top_module(In, ShiftType, ShiftAmount, Out);
