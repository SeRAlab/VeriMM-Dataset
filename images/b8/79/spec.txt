Design a 4-bit binary counter with load, enable, and reset functionality. The counter increments on each clock pulse when enabled and can be loaded with a specific value through the input signal when the load control is active. It resets to zero when the reset signal is asserted. Additionally, the counter includes an overflow output, which indicates when the counter has reached its maximum value of 15 (binary 1111). The current count value is available at the output.
module top_module(
    input clk, reset, enable, load,
    input [3:0] in,
    output [3:0] out,
    output overflow
);
