

You have been tasked with designing a module that takes ten inputs and produces one output. The module should be named "ten_to_one" and should be defined as follows:

Inputs:
- A1: a single bit
- A2: a single bit
- A3: a single bit
- B1: a single bit
- B2: a single bit
- C1: a single bit
- C2: a single bit
- D1: a single bit
- D2: a single bit
- D3: a single bit

Outputs:
- X: a single bit

The module should implement the following logic:

- If A1, A2, and A3 are all 1, set X to 1.
- If B1 and B2 are both 1, set X to 1.
- If C1 and C2 are both 1, set X to 1.
- If D1, D2, and D3 are all 0, set X to 1.
- Otherwise, set X to 0.

Your task is to implement the "ten_to_one" module in Verilog and verify its correctness using a testbench.
