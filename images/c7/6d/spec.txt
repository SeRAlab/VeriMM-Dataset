

You have been tasked with designing a module that implements a 3-bit up-counter using D flip-flops. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock signal
- `reset`: a synchronous active-high reset signal

Outputs:
- `count`: a 3-bit output representing the current count value

The counter should increment on the rising edge of the clock signal and should reset to zero when the reset signal is asserted.

Design the module and write the verilog code to implement it.
