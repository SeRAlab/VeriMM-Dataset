Design a 4-bit counter module with load and reset functionalities. On each rising edge of the clock, if the reset signal is asserted, the counter output (q) is reset to zero. If the load signal is active, the counter loads the input data (data_in) instead of incrementing. In normal operation, when neither reset nor load is active, the counter increments its output value by one.
module top_module(
  input clk,
  input reset,
  input load,
  input [3:0] data_in,
  output reg [3:0] q
);
