Design a 16-bit SRAM cell type in Verilog. The SRAM should have the following features:
- It should have an input data port for writing data.
- It should have an address port to select a specific memory location.
- It should have a write enable signal (we) to control the writing operation.
- It should have an output data port for reading data.
- It should support simultaneous read and write operations using the same address.
- It should be able to store data across multiple write operations.
