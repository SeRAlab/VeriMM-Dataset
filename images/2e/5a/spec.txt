
Design an 8-bit ADC (Analog to Digital Converter) that takes an 8-bit binary input representing an analog signal voltage level and produces a 4-bit binary output representing the voltage level in a specific range. The ADC converts the 8-bit input voltage, assuming it ranges from 0 to 255, to a 4-bit output that represents it in a scale of 0 to 15 (i.e., 0-255 input maps to 0-15 output). The mapping is done by dividing the input by 16 (since 256/16 is 16).
