Implement a flag register that manages a single-bit flag based on control signals. The flag can be loaded with an input value (IN_FLAG) when the LD signal is active, set to high when the SET signal is active, or cleared to low when the CLR signal is active. The flag's state is updated on the rising edge of the clock (CLK), and the current value of the flag is output as OUT_FLAG. This module is useful in applications requiring state retention and control over a binary condition.
