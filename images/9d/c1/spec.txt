Design a circuit for an 8-bit signed multiplier that computes the product of two 8-bit two's complement numbers, `a` and `b`, producing a 16-bit result. The circuit handles positive and negative inputs correctly: if both inputs are negative, it returns the negation of the product; if both are positive, it returns the product directly; and if the inputs have different signs, it also returns the negated product, resulting in a proper signed multiplication output.
module top_module(
    input [7:0] a,
    input [7:0] b,
    output reg [15:0] result
);
