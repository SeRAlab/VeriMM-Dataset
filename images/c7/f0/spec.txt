

You are tasked with designing a verilog module that takes in 4 inputs, `A`, `B`, `C`, and `D`, and produces an output `Y` based on the following logic:

- If `A` is high and `B` is low, `Y` should be high.
- If `C` is high and `D` is low, `Y` should be low.
- If both conditions above are not met, `Y` should be low.

Your module should be named `logic_gate` and should have the following interface:

```
module logic_gate(
    input A,
    input B,
    input C,
    input D,
    output Y
);
```
