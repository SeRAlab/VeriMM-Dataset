Design a fixed-priority arbiter in Verilog. The arbiter should have 4 request inputs (req[3:0]) and one grant output (grant[3:0]). The highest priority request should be granted. If multiple requests are received simultaneously, the arbiter should grant the request based on the fixed priority order: req[0] > req[1] > req[2] > req[3]. If no requests are active, the grant output should be 0.
