Design a 6-bit address counter that increments from a starting value of 32 (6'b100000) on each positive clock edge, provided a count signal (cnt) is asserted. If the counter reaches a maximum value of 36 (6'b100100), it resets to the starting value of 32. The output, 'address', reflects the current value of the internal register 'internAddr', which is reset when the reset signal (res) is activated.
