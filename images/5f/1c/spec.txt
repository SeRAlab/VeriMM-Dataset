Create a synchronous 4-bit binary adder that takes two 4-bit inputs (a and b) along with a carry-in (cin) signal. The module registers these inputs on the rising edge of the clock and calculates their sum, storing the result in a sum output, while also generating a carry-out (cout) based on the fifth bit of the sum. The design ensures that the addition operation adheres to synchronous design principles, making it suitable for integration in larger digital systems.
module top_module(
    input [3:0] a,
    input [3:0] b,
    input cin,
    input clk,                // Added clk input
    output reg [3:0] sum,

);
