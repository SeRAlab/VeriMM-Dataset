
Design a QAM modulator that takes a 4-bit input representing the symbol to be transmitted and a clock signal. The modulator should output a corresponding 2-bit in-phase (I) and 2-bit quadrature (Q) signal based on the following mapping:
- 0000 -> (00, 00)
- 0001 -> (00, 01)
- 0010 -> (01, 00)
- 0011 -> (01, 01)
- 0100 -> (10, 00)
- 0101 -> (10, 01)
- 0110 -> (11, 00)
- 0111 -> (11, 01)
- 1000 -> (00, 10)
- 1001 -> (00, 11)
- 1010 -> (01, 10)
- 1011 -> (01, 11)
- 1100 -> (10, 10)
- 1101 -> (10, 11)
- 1110 -> (11, 10)
- 1111 -> (11, 11)
The modulator should output the I and Q signals at the rising edge of the clock.
