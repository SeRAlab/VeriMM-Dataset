Design a 16-bit simple calculator that performs basic arithmetic operations based on a two-bit operation selector. The module takes two 16-bit inputs, operand_a and operand_b, and based on the value of the operation input, it computes either the sum, difference, product, or quotient of the operands. The operations are defined as: operation = 00 for addition, 01 for subtraction, 10 for multiplication, and 11 for division, with the result output as a 16-bit value.
module top_module(
    input [15:0] operand_a,
    input [15:0] operand_b,
    input [1:0] operation,
    output reg [15:0] result
);
