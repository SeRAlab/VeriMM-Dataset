Design a 4-to-1 multiplexer with an enable signal. The circuit selects one of the four input lines (in[0] to in[3]) based on the two-bit selection input (sel). If the enable signal is high (1), the output (out) reflects the selected input; otherwise, the output is forced to LOW. This design introduces an enabling function to control when the multiplexer can pass its input to the output.
module top_module(
  input [3:0] in,
  input [1:0] sel,
  input enable,
  output reg out
);
