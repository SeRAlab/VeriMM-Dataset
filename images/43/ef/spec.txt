Design a 3-bit up/down counter that increments or decrements its count based on the enable signal (en). The counter resets to zero on the active high reset signal. Upon a positive clock edge, if en is high, the count value will increase by one. If en is low, the count value will decrease by one.
module top_module(
  input clk,
  input reset,
  input en,
  output reg [2:0] count
);
