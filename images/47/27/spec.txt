The output data (`tr_data`) is determined by the state of the internal phases, enabling conditional data transmission based on clock phase.
module top_module(
    input clk,
    input clkx2,
    input jrst_n,
    input [35:0] tw,
    output reg tr_clk,
    output reg [17:0] tr_data
);
