Design a SATA controller state machine that manages the states of a SATA connection. The controller should have the following states: IDLE, ACTIVE, and ERROR. The state transitions should be based on the input signals "start" and "error". The "start" signal transitions the state from IDLE to ACTIVE, while the "error" signal transitions the state to ERROR. Once in the ERROR state, the controller should only return to IDLE when the "reset" signal is activated.
