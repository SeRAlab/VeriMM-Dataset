Design a datapath module that controls the position and color of a graphical element based on input signals. The module takes a clock signal, reset, and enable signals, alongside position and color inputs, to load values into registers for x and y coordinates, as well as color data. On a clock edge, if reset is inactive, the module initializes the registers; if active, it will conditionally load x, y, and color based on control inputs. Additionally, it maintains an index value that increments while enabled, allowing for dynamic position adjustments. The outputs include the modified x and y coordinates, as well as the color, all of which are derived from the internal state of the registers and the index.
