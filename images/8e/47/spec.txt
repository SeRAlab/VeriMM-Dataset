Design a basic arithmetic module that performs either addition or subtraction on two 8-bit inputs, A and B, based on a control input C. When C is high, the module calculates the sum of A and B and outputs it while setting the difference to zero. Conversely, when C is low, the module computes the difference between A and B and outputs it, setting the sum to zero. This module effectively acts as a simple arithmetic unit capable of executing one of two operations governed by the control signal.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input C,
    output reg [7:0] Sum,
    output reg [7:0] Difference
);
