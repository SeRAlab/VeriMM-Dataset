Design a convolutional encoder in Verilog with a constraint length of 3 and two output bits for each input bit. The input data is a 4-bit data stream, and the encoder generates the corresponding 8-bit encoded output. The convolutional encoder should use the following generator polynomials: G1 = 111 and G2 = 101. Implement the state behavior and ensure proper feeding of the input data. The encoder should be resettable and should keep its state between successive inputs.
