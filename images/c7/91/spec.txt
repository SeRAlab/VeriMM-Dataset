

You are tasked with designing a verilog module that takes in a 16-bit input signal and outputs the maximum value of that signal. You should implement this module using behavioral modeling.

The module should have the following ports:
- `clk`: a clock signal input
- `in`: a 16-bit input signal
- `max_val`: a 16-bit output signal representing the maximum value of `in`

The module should perform the following operations:
- On every rising edge of `clk`, it should compare the current value of `in` to the current value of `max_val`.
- If `in` is greater than `max_val`, then `max_val` should be updated to equal `in`.
- If `in` is less than or equal to `max_val`, then `max_val` should remain unchanged.

Your implementation should be done using behavioral modeling.
