Design a 4-to-1 multiplexer that selects one of four 1-bit input signals (in0, in1, in2, in3) based on two select lines (sel0 and sel1). When sel1 and sel0 are both low, the output will be in0; sel0 high and sel1 low selects in1; sel1 low and sel0 high selects in2; and when both select lines are high, in3 is chosen as the output.
module top_module(
    input in0,
    input in1,
    input in2,
    input in3,
    input sel0,
    input sel1,
    output out
);
