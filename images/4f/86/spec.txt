Design a constant voltage driver that outputs specific fixed voltage levels based on a two-bit mode input. The module accepts a 4-bit data input (which is not utilized in determining the output) and generates a 10-bit output voltage that corresponds to one of four predefined voltage levels: 0V, 1.25V, 2.5V, or 3.75V. The selected voltage is determined by the value of the mode input, with each mode mapping directly to a corresponding voltage output.
module top_module(
  input [3:0] data_in,
  input [1:0] mode,
  output reg [9:0] v_out
);
