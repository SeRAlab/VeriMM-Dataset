
Design a 4-channel DMA controller that allows for data transfer between memory and four peripheral devices. The controller should have the following inputs and outputs:
- Inputs:
  - `req[3:0]`: Request signals from the peripherals (active high).
  - `clk`: Clock signal.
  - `rst`: Reset signal (active high).
- Outputs:
  - `ack[3:0]`: Acknowledge signals to the peripherals (active high).
  - `selected_channel`: The channel currently selected for data transfer (0 to 3).
  The controller should grant access to the highest priority request signal when multiple requests are active.
