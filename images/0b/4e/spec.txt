Design a state machine that simulates a simple SLAM (Simultaneous Localization and Mapping) algorithm. The state machine should have three states: IDLE, MAP, and LOCATE. The transitions between these states are controlled by two inputs: `start` and `reset`. When `start` is high, the state machine should transition from IDLE to MAP, and then to LOCATE after one clock cycle. When `reset` is high, the state machine should return to the IDLE state. The output should indicate the current state as a 2-bit binary value, where 00 = IDLE, 01 = MAP, and 10 = LOCATE.
