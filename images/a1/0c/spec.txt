Design a simple arithmetic calculator that performs basic operations on two 8-bit input values. The module takes two 8-bit inputs, 'in1' and 'in2', and a 2-bit operation selector, 'op', which determines the arithmetic operation to execute: addition, subtraction, multiplication, or division. The output is an 8-bit result of the specified operation. Additionally, there is a clear input signal that, when activated, resets the output to zero. The design focuses on performing arithmetic calculations based on the selected operation while providing a reset functionality.
module top_module(
    input [7:0] in1,
    input [7:0] in2,
    input [1:0] op,
    input clear,
    output reg [7:0] out
);
