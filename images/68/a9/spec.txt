If the load signal is high, it loads the provided 2-bit input data instead of incrementing. Otherwise, it increments the counter by 1 on each clock cycle, effectively counting from 0 to 3.
module top_module(
    input clk,
    input load,
    input reset,
    input [1:0] data_in,
    output reg [1:0] data_out
);
