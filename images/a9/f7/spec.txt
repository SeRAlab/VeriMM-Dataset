Design a D-type flip-flop with enable, set, and reset functionality. When the clock signal (CLK) rises, if the enable (EN) signal is asserted, the flip-flop will either set its output (Q) to high when SET is active, reset its output to low when RESET is active, or transfer the input (D) to output (Q) under normal operation. Additionally, the output (Q_bar) is provided as the inverse of Q. This design allows for flexible control of the flip-flop's state under specific conditions.
module top_module(
  input CLK,
  input D,
  input EN,
  input SET,
  input RESET,
  output reg Q,
  output reg Q_bar
);
