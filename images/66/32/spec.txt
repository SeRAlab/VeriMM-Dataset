Design a circuit that functions as a shift register combined with a 4-to-1 multiplexer. The shift register stores incoming 4-bit data values and shifts them in on each clock cycle, while the output selection is determined by the 2-bit value derived from the two least significant bits of the shift register. The implemented multiplexer outputs one of the four bits from the upper half of the shift register based on the current value of the selection bits, enabling dynamic data routing based on the state of the shift register.
module top_module(
    input clk,
    input reset,
    input [3:0] data_in,
    output reg out
);
