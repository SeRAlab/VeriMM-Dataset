Design a 4-to-1 multiplexer with an enable signal. The multiplexer selects one of the four input data lines based on the 2-bit select signal. If the enable signal is active, the corresponding data line is forwarded to the output; otherwise, the output retains its previous value, allowing for the implementation of data latching.
module top_module(
    input [3:0] data_in,
    input [1:0] select,
    input enable,
    output reg [3:0] data_out
);
