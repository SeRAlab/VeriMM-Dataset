
You have been tasked with designing a module that implements a 4-input XNOR gate. The module should have the following inputs:
- A, B, C, D: 4-bit binary inputs
- VPWR, VGND: power and ground supply voltages
- VPB, VNB: positive and negative bias voltages

The module should have a single output, Y, which will be high (1) if all four inputs are either 0 or 1, and low (0) otherwise.

Design a verilog module that implements the 4-input XNOR gate. Your solution should be self-contained and should not rely on any external modules or libraries. Additionally, your solution should be no longer than 200 lines of verilog code.
