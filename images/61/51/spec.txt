Implement the Verilog module based on the following description.
Create a 3-bit synchronous binary counter with carry out. The counter increments by 1 on each clock cycle and resets to zero when the reset signal is high. The carry out signal goes high when the counter rolls over from its maximum value (7) to zero.

// Signals are defined as below:
// (1) clk: The clock signal.
// (2) reset: Resets the counter to zero. Active high.
// (3) cout: Carry out signal. Goes high when the counter rolls over.
// (4) q: The 3-bit output of the counter.
module binary_counter_cout(
    input clk,
    input reset,
    output reg cout,
    output reg [2:0] q);
