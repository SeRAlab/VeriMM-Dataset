Design a 4-bit up counter with enable and reset functionality. When enabled (ce = 1), the counter increments on each rising clock edge (sys_clk). If the reset signal (R) is asserted, the counter resets to zero. The counter output is a 4-bit value (Q) that counts from 0 to 15, indicated by the TC signal, which becomes high when Q equals 15. The CEO signal provides a high output when both the clock enable (ce) is active and TC is asserted.
