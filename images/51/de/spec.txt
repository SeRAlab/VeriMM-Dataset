Design a 4-bit register that updates its stored value on the rising edge of the clock signal. It resets to zero when the reset input is deactivated (logic low) and loads new data from the data_in input when the load signal is asserted (logic high). The current contents of the register are continuously available at the data_out output.
module top_module(
  input clk,
  input reset,
  input load,
  input [3:0] data_in,
  output [3:0] data_out
);
