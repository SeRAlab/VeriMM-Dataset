Design a 4-bit binary counter that increments or decrements its value based on UP and DOWN control signals, respectively. The counter resets to zero when the RST signal is low. Additionally, the output CODE is generated by applying a specific transformation to the current counter value, where CODE is calculated as the bitwise XOR of the counter and a right-shifted version of itself. The module effectively combines counting functionality with a unique encoding scheme for its output.
module top_module(
               input            CLK,
               input            RST, 
               input            UP,
               input            DOWN,
               output reg [3:0] CODE
               );
