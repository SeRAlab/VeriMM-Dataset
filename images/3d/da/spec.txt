Design a 16-bit SRAM cell that can read and write data. The SRAM cell should have a 16-bit data input, a 16-bit data output, a read enable (RE), a write enable (WE), and a clock signal (CLK). When WE is high, the data should be written to the SRAM on the rising edge of CLK. When RE is high, the data should be output from the SRAM on the rising edge of CLK. If both RE and WE are high simultaneously, the SRAM should prioritize the write operation.
