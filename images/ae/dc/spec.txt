Design a D flip-flop with asynchronous reset and enable functionality for n-bit wide data. When the clock signal transitions from low to high, if the reset signal is asserted, the output will be set to zero. If the reset is not asserted and the enable signal is active, the output will take the value of the input data. If both reset and enable signals are inactive, the output retains its previous state.
