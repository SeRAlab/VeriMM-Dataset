Design a reset controller that manages a reset signal for a system. The reset controller should have the following features: it takes an active low reset signal (`reset_n`), a clock signal (`clk`), and outputs a reset signal (`reset_out`). The `reset_out` should be high when `reset_n` is high and should go low for a specified number of clock cycles when `reset_n` goes low. After the reset duration, `reset_out` should return high. Additionally, the reset duration should be adjustable via a parameter called `RESET_DURATION` which is a positive integer value.
