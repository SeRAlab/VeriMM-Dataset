Design a Parallel-in Parallel-out (PIPO) shift register in Verilog. The shift register should have a data input, a load control signal, a clock signal, and an output. When the load signal is high, the input data should be loaded into the register on the rising edge of the clock. When the load signal is low, the current value of the register should be available at the output without any changes. The register should be of length N (for example, N=5).
