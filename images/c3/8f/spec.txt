

You are tasked with designing a register file module in Verilog. The module should have 8 8-bit registers, with the ability to read from and write to any of the registers. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock signal
- `we`: a write enable signal
- `d_in`: an 8-bit data input
- `adr`: a 3-bit address input

Outputs:
- `d_out`: an 8-bit data output

Design the register file module in Verilog, ensuring that it is synchronous and that all inputs and outputs are correctly defined.
