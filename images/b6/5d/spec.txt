Design a multi-bit comparator module that compares two n-bit wide inputs, `a` and `b`. The module generates three output signals: `eq`, which indicates equality (a equals b); `gt`, which signifies that `a` is greater than `b`; and `lt`, which indicates that `a` is less than `b`. The comparison results are determined using combinational logic, and the size of the inputs is parameterizable through the `n` parameter, with a default value of 8 bits.
module top_module(
  input [n-1:0] a,
  input [n-1:0] b,
  output eq,
  output gt,
  output lt
);
