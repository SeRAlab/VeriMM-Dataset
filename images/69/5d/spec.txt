Design a 4-to-1 multiplexer that selects one of four 4-bit data inputs (data0, data1, data2, data3) based on a 2-bit selection signal (sel). The selected data is output through a 4-bit result line. When sel is 00, data0 is chosen; 01 selects data1; 10 selects data2; and 11 selects data3. The result reflects the value of the selected input while ensuring the other inputs do not influence the output.
module top_module(
    input [3:0] data0,
    input [3:0] data1,
    input [3:0] data2,
    input [3:0] data3,
    input [1:0] sel,
    output [3:0] result
);
