The output X defaults to a specific value based on the conditions: if A1 is high, X outputs a high signal; if A2 is high, X outputs low; if A3 is high, X outputs the inverse of A4; if B1 is high, the output defaults to low. The circuit is intended to provide flexible logic control based on the prioritized input conditions.
module top_module(
    output X,
    input  A1,
    input  A2,
    input  A3,
    input  A4,
    input  B1
);
