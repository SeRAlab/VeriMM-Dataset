Design a 4-bit barrel shifter that allows for left or right shifting of an input data word based on a 2-bit control signal. When the shift amount is specified by the control signal S, the module can perform zero, one, two, or three-bit shifts. The behavior of the shifting operation is determined by the shift_right input, which decides whether to shift the bits to the right or left, while preserving the most significant bit during right shifts or the least significant bit during left shifts. The output reflects the shifted value of the input data D.
module top_module(
    input [3:0] D,
    input [1:0] S,
    input shift_right,
    output reg [3:0] Q
);
