Design a shift register with a parameterizable number of bits (n = 8 by default). The module takes a single data input and a clock signal; it shifts incoming data into the register upon each rising edge of the clock. When the reset signal is asserted, all bits in the shift register are cleared to zero. The output represents the most significant bit (MSB) of the shift register, allowing for serial input data processing and delayed output retrieval.
module top_module(
  input data,
  input clk,
  input reset,
  output shifted_data
);
