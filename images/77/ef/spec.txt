Design a 32-bit instruction register that captures and holds instruction data from memory. On the rising edge of the clock, if the reset signal is active, the register is reset to zero. If the reset is inactive and the IRWr (instruction register write) signal is asserted, the module updates the IR output with the new instruction data provided on IMData. This functionality is essential in a processor to store the current instruction being executed.
module top_module(input clk,reset,IRWr,input [31:0] IMData,output reg [31:0] IR);
