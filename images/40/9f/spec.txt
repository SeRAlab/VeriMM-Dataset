Design a Verilog module that implements a simple state machine for a SLAM function. The state machine should have three states: IDLE, MAP, and LOCALIZE. The state transitions should occur based on the input signals 'start', 'map_done', and 'localize_done'. The output should indicate the current state of the machine. When in IDLE state, it should transition to MAP state on 'start'. When in MAP state, it should transition to LOCALIZE state on 'map_done'. When in LOCALIZE state, it should transition back to IDLE on 'localize_done'.
