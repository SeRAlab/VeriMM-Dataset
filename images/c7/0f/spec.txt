

You are given a Verilog module called BOTTOM_MUX that implements a 2-to-1 multiplexer. The module takes two 5-bit inputs, a and b, a 1-bit select signal, sel, and outputs the selected input as y. 

You are tasked with completing the implementation of the BOTTOM_MUX module. Specifically, you must add the logic to select the appropriate input based on the value of sel. If sel is 1, the output y should be equal to input a. If sel is 0, the output y should be equal to input b. 

You must also simulate the module using the provided testbench. The testbench initializes the inputs a, b, and sel, and then changes their values at various times. Your task is to observe the output y at each time step and ensure that it matches the expected value based on the input values and the value of sel.

Note that the module and testbench are provided to you. You should only modify the BOTTOM_MUX module to complete the implementation.
