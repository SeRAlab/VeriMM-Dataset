
Create a 16-bit SRAM cell with read and write operations. The SRAM cell should have the following ports:
- `clk`: Clock signal
- `we`: Write enable (1 for write, 0 for read)
- `addr`: 4-bit address for selecting one of the 16 16-bit SRAM cells
- `data_in`: 16-bit data input for writing
- `data_out`: 16-bit data output for reading
Implement the SRAM cell such that it can store a value at the specified address during the write operation and output the stored value during the read operation.
