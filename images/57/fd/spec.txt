Design a program counter (PC) that outputs a 32-bit address. This PC updates its value based on a next program counter input (npc) at every rising edge of the clock (clk). When a reset signal (rst) is activated, the PC resets to a predefined initial address (0x0000_3000). Otherwise, it takes the value of the provided npc, allowing it to progress through program instructions in a controlled manner.
