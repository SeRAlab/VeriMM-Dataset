Design a synchronous flip-flop with asynchronous set and reset functionalities. The circuit has an 8-bit input (`data_in`) and outputs the 8-bit value (`data_out`). On the rising edge of the clock, if the `set` signal is activated, `data_out` is set to all 1's. If the `reset` signal is asserted, `data_out` is reset to all 0's. If neither the set nor reset is active, the flip-flop latches the value of `data_in` to `data_out`.
module top_module(input clk, input set, input reset, input [7:0] data_in, output reg [7:0] data_out);
