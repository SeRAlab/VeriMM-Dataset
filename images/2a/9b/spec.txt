Design a 32-bit Arithmetic Logic Unit (ALU) that can perform the following operations based on a 3-bit operation code (opcode):
1. Addition (opcode = 000)
2. Subtraction (opcode = 001)
3. Bitwise AND (opcode = 010)
4. Bitwise OR (opcode = 011)
5. Bitwise XOR (opcode = 100)
The ALU should take two 32-bit inputs and output a 32-bit result along with a zero (Z) flag that indicates if the result is zero.
