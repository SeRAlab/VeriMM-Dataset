Implement an 8-bit up-counter with enable and asynchronous reset. The module should count up on each clock cycle when enable is asserted and reset the count asynchronously when reset is asserted.

Module name:
    up_counter_8bit
Input ports:
    clk: clock input
    reset: asynchronous reset input
    enable: enable input
Output ports:
    count: 8-bit output

Implementation:
The module uses an always block that triggers on the clock's positive edge and another always block for the asynchronous reset. It increments the count when enable is asserted and resets the count when reset is asserted.
