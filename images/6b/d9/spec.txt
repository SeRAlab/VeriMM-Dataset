Please act as a professional verilog designer.

Design a 4-to-1 multiplexer using Verilog. The multiplexer has a selection signal to choose between four 4-bit input signals.

Module name:  
    mux_4to1  

Input ports:
    a: Input signal a with a data width of 4 bits.
    b: Input signal b with a data width of 4 bits.
    c: Input signal c with a data width of 4 bits.
    d: Input signal d with a data width of 4 bits.
    sel: 2-bit Selection signal.

Output ports:
    y: Output signal with a data width of 4 bits.

Implementation:
Multiplexer operation:
If the selection signal (sel) is 00, the output (y) is assigned the value of input a.
If the selection signal (sel) is 01, the output (y) is assigned the value of input b.
If the selection signal (sel) is 10, the output (y) is assigned the value of input c.
If the selection signal (sel) is 11, the output (y) is assigned the value of input d.
