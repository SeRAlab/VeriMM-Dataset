Implement a module of a 4-bit up/down counter that can count either up or down based on the control signal up_down. The counting can be paused using the input signal enable. The counter resets to 0 when the reset signal (rst_n) is active.

Module name:  
    up_down_counter               
Input ports:
    rst_n: Reset signal (active low)
    clk: Clock signal
    enable: Signal to enable counting
    up_down: Signal to control count direction (1 for up, 0 for down)
Output ports:
    count: 4-bit output representing the current count value

Implementation:
If the reset signal is active (!rst_n), the counter is reset to 0 by assigning the value 4'b0000 to the output register (count). If the enable signal is 1, the counter increments or decrements based on the up_down signal. If the up_down signal is 1, the counter increments the count value by 1; if it is 0, the counter decrements the count value by 1. If the enable = 0, the counter will stop, and the output register (count) remains unchanged.
