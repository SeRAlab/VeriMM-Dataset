Design a 32-bit wide memory register with load and clear functionalities. On the rising edge of the clock, if the clear signal is asserted, the register is initialized to a value of 0xFF0. If the load signal is asserted, the register captures the input memory data. Otherwise, the register retains its current value.
module top_module(input clock,
			input [31:0] mem_input,
			input load,
			input clear,
			output reg [31:0] memreg
);
