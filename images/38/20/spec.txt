Design a simple RNN cell in Verilog that takes a 4-bit input and a 4-bit hidden state, producing a 4-bit output and a new hidden state. The RNN should use a basic activation function like ReLU (Rectified Linear Unit) for simplicity. The hidden state is updated based on the input and the previous hidden state with a simple weight matrix multiplication (for this problem, assume fixed weights). The circuit should be capable of processing multiple time steps sequentially.
