Design a 4-bit wide, 8-to-1 multiplexer. The module selects one of eight 4-bit input data lines (in0 to in7) based on a 3-bit select input (sel). The output (out) reflects the value of the selected input, allowing for dynamic data routing within a digital circuit.
module top_module(
    input [3:0] in0,
    input [3:0] in1,
    input [3:0] in2,
    input [3:0] in3,
    input [3:0] in4,
    input [3:0] in5,
    input [3:0] in6,
    input [3:0] in7,
    input [2:0] sel,
    output reg [3:0] out  // Changed 'output' to 'output reg'
);
