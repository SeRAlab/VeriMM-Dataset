Design a 7-stage pipelined processor that takes a 5-bit input instruction and produces a 5-bit output result. The processor should support an add operation, where the first 2 bits of the instruction specify the operation (00 for add, 01 for nop), the next 3 bits specify the input value (0-7). The output should show the result after 7 clock cycles, where nop operations do not alter the output.
