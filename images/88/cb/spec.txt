Design a 4-to-1 bus selector with tri-state outputs. When the enable signal is active, one of the four input buses (bus0 to bus3) is selected based on a 2-bit select input `s`, while the outputs are in a high-impedance state otherwise. The selected bus is routed to `busout`, allowing for efficient data sharing between different sources in a system.
