Design a 4-bit wide shift register with load capabilities. This module stores a 4-bit input data when the load signal is asserted; otherwise, it shifts the stored data through four registers on each clock cycle. Upon a reset signal, all registers are initialized to zero. The output presents the content of the last register (reg4), effectively yielding the result of the shifting operation.
module top_module(
    input clk,
    input reset,
    input load,
    input [3:0] data_in,
    output reg [3:0] data_out
);
