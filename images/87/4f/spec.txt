Design a D latch with a gate control. When GATE is low and the clock (CLK) signal has a rising edge, the latch captures and retains the input data (D) until the next rising edge, at which point the output (Q) reflects the stored value. If GATE is high, the output remains unchanged, effectively disabling the latch.
module top_module(
    input GATE,
    input CLK,
    input D,
    output Q
);
