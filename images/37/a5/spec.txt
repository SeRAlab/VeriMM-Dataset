Design an 8-bit SRAM cell with read and write functionality. The SRAM cell should have a write enable signal (WE), an output enable signal (OE), an address input (A), a data input (D), and an 8-bit data output (Q). When WE is high, the data at input D should be written to the SRAM at the specified address. When OE is high, the data stored at the specified address should be outputted to Q. If both WE and OE are low, Q should be in a high-impedance state.
