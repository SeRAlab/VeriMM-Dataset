
Create a FIFO queue with a width of 8 bits and a depth of 4. The FIFO should support the following operations:
1. Write data to the FIFO (input signal `wr_en` for write enable, and `data_in` for input data),
2. Read data from the FIFO (input signal `rd_en` for read enable, and output signal `data_out` for output data),
3. Indicate when the FIFO is empty (output signal `empty`), and when it is full (output signal `full`).
