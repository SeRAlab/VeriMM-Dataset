Design a cache controller that implements a Least Recently Used (LRU) cache replacement policy. The cache has 4 lines, and each line can hold an 8-bit data value. The controller should take a 2-bit index to specify which line to access, a 1-bit read/write signal, and an 8-bit data input. It should output the data read from the specified line and a 4-bit signal indicating which line is replaced when a write occurs and the cache is full.
