
Create a LIFO stack module in Verilog that supports the following operations:
1. Push: Adds an element to the top of the stack.
2. Pop: Removes the element from the top of the stack.
3. Peek: Returns the element at the top of the stack without removing it.
4. IsEmpty: Returns a flag indicating whether the stack is empty.
The stack should have a maximum size of 8, and the data width is 8 bits.
