Design a simple Low Dropout Regulator (LDO) circuit in Verilog that simulates the behavior of adjusting the output voltage based on an input voltage and a feedback control signal. The output voltage should be determined based on the input voltage and the feedback signal with a basic condition: if the feedback signal is high, the output should be equal to the input; if it is low, the output should be the input minus a fixed voltage drop (let's say 1V, which can be represented in the simulation). The input voltage will be 5V, and the feedback signal will be a single bit.
