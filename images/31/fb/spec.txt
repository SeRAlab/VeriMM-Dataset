Design a Verilog module that implements a simple decision tree for binary classification based on three input features (A, B, C). The output should be a single-bit classification (0 or 1) based on the following rules:  
1. If A > 2, output 1.  
2. If A <= 2 and B > 3, output 1.  
3. If A <= 2 and B <= 3 and C > 1, output 0.  
4. If A <= 2 and B <= 3 and C <= 1, output 0.  
The inputs A, B, and C are 4-bit numbers representing the features. The output should be a single bit representing the classification result.
