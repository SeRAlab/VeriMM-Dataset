
Design a 5-stage pipeline processor that performs a simple arithmetic operation (addition) on two 5-bit binary numbers. The processor should have the following stages:
1. Instruction Fetch (IF)
2. Instruction Decode (ID)
3. Execute (EX)
4. Memory Access (MEM)
5. Write Back (WB)

Each stage should be clocked, and the output from the Write Back stage should be a 5-bit result. The processor should also handle a simple control signal to indicate when to start processing.
