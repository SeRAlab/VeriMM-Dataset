Design a debouncing circuit for a button input to produce a stable output signal. The module uses a synchronous approach to filter out noise generated by mechanical bouncing of the button. It employs two D-type flip-flops (DFF1 and DFF2) along with a shift register (q_reg) to count the duration of stable input. When the button state remains unchanged for a certain number of clock cycles, the circuit asserts the debounce_output signal, which reflects the stable state of the button input. The implementation is parameterized for configurability, allowing adjustment of the debounce timing by changing the bit-width of the counter.
