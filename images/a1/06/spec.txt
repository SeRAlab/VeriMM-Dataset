Design a Verilog module for a simple FSM with four states (I, J, K, L) and one input signal (X). Use one-hot state encoding where I=4'b0001, J=4'b0010, K=4'b0100, L=4'b1000. The FSM has an output (out) which is dependent only on the current state.

The state machine has the following states and their corresponding outputs:
1. state I (out = 0).
2. state J (out = 1).
3. state K (out = 1).
4. state L (out = 0).

State transitions:
1. From state I: If X = 1, then transition to state J. If X = 0, stay in state I.
2. From state J: If X = 0, then transition to state K. If X = 1, stay in state J.
3. From state K: If X = 1, then transition to state L. If X = 0, stay in state K.
4. From state L: If X = 0, then transition to state I. If X = 1, stay in state L.

module fsm_4 (
  input X,
  input [3:0] state,
  output reg [3:0] next_state,
  output reg out);
