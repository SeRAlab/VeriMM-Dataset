Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a 4:1 multiplexer (MUX). 
A MUX is a type of digital circuit that selects one of four inputs and passes it to the output based on the value of two select lines. 
Your module should have the following inputs and outputs:

Inputs: four input signals (in0, in1, in2, in3), two select signals (sel0, sel1)
Outputs: one output signal (out)

Your module should implement the following functionality:

When sel0 and sel1 are both equal to 0, the output signal should be equal to in0.
When sel0 is equal to 0 and sel1 is equal to 1, the output signal should be equal to in1.
When sel0 is equal to 1 and sel1 is equal to 0, the output signal should be equal to in2.
When sel0 and sel1 are both equal to 1, the output signal should be equal to in3.

To implement the MUX, you should use Verilog code to create a case statement that determines the output signal based on the values of sel0 and sel1. 
You should then use this case statement to connect the inputs to the output signal.
