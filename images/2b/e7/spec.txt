
Design a Verilog module for a simple Flash memory cell with a write, read, and erase functionality. The module should have the following inputs: `clk` (clock), `write_enable` (to write data), `erase_enable` (to erase the data), and `data_in` (the data to be written). The output should be `data_out` (the current stored data). The behavior should be such that on a positive clock edge, if `write_enable` is high, `data_in` should be stored in the memory cell, if `erase_enable` is high, the cell should be reset to 0, and if neither is high, the stored data should remain unchanged.
