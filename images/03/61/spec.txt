Design a 1-bit DRAM cell with a bitline, wordline, and a storage capacitor. The cell should be able to read and write data based on control signals. The DRAM cell should operate with the following inputs: `write_enable`, `read_enable`, `data_in`, and produce `data_out` as output. Implement the behavior such that when `write_enable` is high, the `data_in` value is stored in the cell; when `read_enable` is high, the stored value is output to `data_out`.
