

You are tasked with designing a module that will act as a buffer for a clock signal. The module should have the following inputs and outputs:

Inputs:
- `CLK_IN`: input clock signal
- `RST`: reset signal

Outputs:
- `CLK_OUT`: output clock signal

The module should operate as follows:
- While `RST` is high, `CLK_OUT` should be held low.
- When `RST` goes low, `CLK_OUT` should be a buffered version of `CLK_IN`.
- If `CLK_IN` changes while `RST` is low, `CLK_OUT` should update to reflect the new value of `CLK_IN`.

Design a Verilog module that implements this behavior. You may use any standard Verilog libraries, but your module should be self-contained and not rely on any external modules.
