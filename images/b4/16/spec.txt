Design a synchronous 8-bit shift register with a reset function. On each negative edge of the clock, if the reset input is active, the register is cleared to zero. Otherwise, the register shifts left, inserting the least significant bit of the data input into the most significant bit position. The current state of the shift register is reflected at the output q.
module top_module(
    input clk,
    input reset,            // Synchronous reset
    input [7:0] d,
    output reg [7:0] q
);
