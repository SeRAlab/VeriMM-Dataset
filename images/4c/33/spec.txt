Design a 4-bit adder/subtractor module that performs either addition or subtraction based on a mode control signal. When mode is set to 0, the module outputs the sum of inputs A and B; when mode is set to 1, it outputs the difference (A - B). The inputs and outputs are registered to synchronize with a clock signal, ensuring that operations are performed in a controlled manner.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input mode,
    input clk,  // Added clock input
    output reg [3:0] Q
);
