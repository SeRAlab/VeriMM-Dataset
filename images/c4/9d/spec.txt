

You are tasked with designing a module that takes in 4 inputs `A1_N`, `A2_N`, `B1`, `B2` and outputs a single bit `X`. The module should implement the following logic function:

```
X = (NOT A1_N AND NOT A2_N) AND (B1 OR B2)
```

You need to design a module that implements this logic function using only one module within 200 lines of verilog code. 

Assume the inputs are valid and do not require any additional error checking. The output should be a single bit that is either 0 or 1.
