Design a Verilog module that implements a Breadth-First Search (BFS) algorithm for a fixed-size graph represented as an adjacency matrix. The graph has 4 nodes. The module should take a start node as input and output the order of node visits in a register. The BFS should be controlled by a clock and a reset signal. The module must have enable input to start the BFS process, and it should take one clock cycle to process each layer of nodes.
