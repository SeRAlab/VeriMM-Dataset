Design a JK-latch in Verilog. The JK-latch should have two inputs (J and K), a clock input (CLK), and two outputs (Q and Qn). The output Q should follow the behavior of a JK-latch, where:
- If J = K = 0, the output Q remains unchanged.
- If J = 1 and K = 0, the output Q is set to 1.
- If J = 0 and K = 1, the output Q is reset to 0.
- If J = K = 1, the output Q toggles on each clock edge.
