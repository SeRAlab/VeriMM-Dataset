Design a UART controller that transmits data serially. The UART controller must take an 8-bit data input and a start signal. Upon receiving the start signal, it should begin sending the 8 bits of data serially, followed by a stop bit. The transmission should be at a fixed baud rate, and a clock signal will be provided to synchronize the transmission. The output should be a single bit representing the transmitted data. The controller should also have a ready signal to indicate when it is ready to accept new data.
