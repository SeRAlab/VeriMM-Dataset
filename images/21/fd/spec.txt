Design an Ethernet MAC controller that takes a 32-bit data input and a 4-bit control signal. The controller should perform the following operations based on the control signal:  
- '0001': Pass the data unchanged to output.  
- '0010': Reverse the data bits.  
- '0011': Invert the data bits.  
- '0100': Pass the upper 16 bits of the data to output.  
- Any other control signal: Output a default value of 0.  
The output should be a 32-bit value.
