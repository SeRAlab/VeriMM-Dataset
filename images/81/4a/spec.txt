Develop a Verilog module that represents a 6-bit barrel shifter. The input is a 6-bit number (input [5:0] data) and the number of positions to shift (input [2:0] shift_amount). The direction of the shift is controlled by an input signal (input direction; 1 for right shift, 0 for left shift). The result should be output as a 6-bit bus (output [5:0] out).
