Design a UART controller that transmits a byte serially. The controller should have the following functionality:
1. Start bit (1 bit)
2. Data bits (8 bits)
3. Stop bit (1 bit)
The controller should accept a byte of data and transmit it serially, starting with a start bit (0), followed by the data bits, and ending with a stop bit (1). Include a clock signal input for timing purposes.
