

You are tasked with designing a verilog module that implements a 4-bit adder-subtractor. The module should have two input ports: `A` and `B`, and two control input ports: `S` and `C`. `S` is a control signal that determines whether the module should perform addition or subtraction. If `S` is high, the module should perform subtraction, otherwise it should perform addition. `C` is a carry-in signal that can be used to add an additional bit to the operation. The module should have two output ports: `F` and `C_out`. `F` is the result of the addition or subtraction, and `C_out` is the carry-out signal.
