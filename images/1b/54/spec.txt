Design a SR flip-flop in Verilog. The flip-flop should have two inputs, S (Set) and R (Reset), and one output Q. The behavior should follow the standard SR flip-flop rules: when S is high, Q should be set to high; when R is high, Q should be reset to low; if both S and R are low, Q retains its previous state; if both S and R are high, the behavior should be considered invalid (you can choose to set Q to a default state in this case).
