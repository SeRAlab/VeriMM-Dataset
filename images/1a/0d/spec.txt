
Design a 1-bit Flash memory cell with the following specifications:
- The memory cell has a data input (D), a write enable signal (WE), a read enable signal (RE), and an output (Q).
- When WE is high, the data input (D) is written to the cell.
- When RE is high, the value stored in the cell (Q) is output.
- When both WE and RE are low, the last written value remains unchanged.
