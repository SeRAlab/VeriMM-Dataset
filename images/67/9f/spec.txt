Design a 4-bit binary counter with asynchronous reset and load functionality. When reset is asserted, the counter is set to zero. If the counter is enabled and load is not asserted, the counter increments by one on each positive clock edge. If load is asserted, the counter is loaded with the value provided on input `d`.
module top_module(
    input clk,
    input reset,
    input enable,
    input load,
    input [3:0] d,
    output reg [3:0] count
);
