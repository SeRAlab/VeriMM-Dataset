Design a 2-to-1 multiplexer with output enable functionality for 32-bit wide data. The module selects between two 32-bit input signals, in0 and in1, based on the value of the 'select' signal. When 'enable' is high, the output reflects the selected input; when 'enable' is low, the output is forced to zero. This allows controlled output based on both the selection and enable signals.
module top_module(
  input wire [31:0] in0,
  input wire [31:0] in1,
  input wire select,
  input wire enable,
  output reg [31:0] out  // Change wire to reg
);
