

You have been tasked with designing a verilog module that takes in a 4-bit binary input `in` and outputs a 4-bit binary number `out` that is the result of adding 3 to the input. The module should have the following interface:

```
module AddThree (
    input [3:0] in,
    output [3:0] out
);
```

Write a verilog module that implements this functionality using a combinational logic circuit. The module should be named `AddThree` and should have the following ports:

- `in`: a 4-bit binary input
- `out`: a 4-bit binary output that is the result of adding 3 to the input

Assume that the input `in` is a valid 4-bit binary number.
