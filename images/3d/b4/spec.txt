Design a GPIO controller that has an 8-bit input data register and a 3-bit output control register. The GPIO controller will have the following functionality:
- On a rising edge of the clock, if the enable signal is high, the data input will be transferred to the data register.
- If the control signal is set to '001', it will set the first output pin high. If the control signal is '010', it will set the second output pin high, and so on. If the control signal is '000', all output pins will be low.
