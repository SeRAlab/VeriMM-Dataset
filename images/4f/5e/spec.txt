Design a flip-flop with asynchronous set, clear, and preset functionalities. This module outputs Q based on the clock signal (CLK) and the input data (D), while also responding immediately to the SET, CLR, and PRE signals. If SET or PRE is triggered, Q is set to HIGH; if CLR is triggered, Q is set to LOW. In the absence of these signals, the output Q follows the input D on the rising edge of CLK. Additionally, the module provides the inverted output Q_N.
module top_module(
    input CLK,
    input D,
    input SET,
    input CLR,
    input PRE,
    output reg Q,
    output reg Q_N
);
