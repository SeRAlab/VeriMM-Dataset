Design a 32-bit shifter that performs various shift operations on the input data based on a specified shift direction. The module accepts a 32-bit input data and a 5-bit shift amount, allowing for logical left shifts, logical right shifts, and arithmetic right shifts, determined by a 2-bit shift direction input. The output of the shifting operation is provided as the result, with an additional output signal indicating whether the result is zero, facilitating the detection of a zero output after shifting.
module top_module(
    input [31:0] data_in,
    input [4:0] shift_amount,
    input [1:0] shift_direction,
    output [31:0] result,
    output zero
);
