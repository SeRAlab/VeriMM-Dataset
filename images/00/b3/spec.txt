Design a simple memory allocator that supports dynamic allocation (malloc) and deallocation (free) of a fixed number of memory blocks. The allocator should have a fixed size and maintain the state of each block (allocated or free). The memory blocks are represented as a simple array of bits where '1' indicates an allocated block and '0' indicates a free block. The interface will include two operations: allocate a memory block and free a previously allocated block. The module should provide output indicating whether the allocation was successful or if the requested block was already allocated.
