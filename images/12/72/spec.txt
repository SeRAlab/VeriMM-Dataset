Design a simple SPI controller that manages data transmission with a slave device. The controller should have a clock input, a chip select (CS) input, and a data input (MOSI) signal. It should generate a data output (MISO) signal that echoes the data received on the MOSI line when the chip is selected (CS is low). Data transmission occurs on the rising edge of the clock. The module should also have a state output to indicate whether it is idle or transmitting data.
