Implement the Verilog module based on the following description.
Build a 3-bit up-down counter with synchronous active low reset signal, enable signal, and direction control signal. When the enable signal is high, the counter increments or decrements based on the direction control signal.
// (1) reset_n: Resets the counter to 3'b000 when low.
// (2) enable: Enables the counter to count when high.
// (3) up_down: Direction control signal (1 for up, 0 for down).
// (4) count: The current count value of the counter.

module up_down_counter(
    input clk,
    input reset_n,
    input enable,
    input up_down,
    output reg [2:0] count);
