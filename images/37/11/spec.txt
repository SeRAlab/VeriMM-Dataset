Design a 1-bit SRAM cell using Verilog. The SRAM cell should have the following inputs: `data_in` (the data to be stored), `write_enable` (to control whether data should be written), and `read_enable` (to control whether data should be read). The output should be `data_out` which reflects the stored value when read. Implement necessary control logic to handle the read and write operations properly. Ensure that the state holds the last written value when not writing.
