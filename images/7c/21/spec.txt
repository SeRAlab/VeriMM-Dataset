Design a D flip-flop with synchronous set and reset functionality. When a clock pulse (C) is received, the flip-flop will store the value of the data input (D). If the set input (S) is asserted, the output (Q) will be set to HIGH regardless of D. Conversely, if the reset input (R) is asserted, the output (Q) will be set to LOW. If neither S nor R is active, Q will follow the D input on the rising edge of the clock.
module top_module(
    input D,
    input C,
    input S,
    input R,
    output reg Q
);
