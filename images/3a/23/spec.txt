Design a portfolio optimization module that takes a set of weights for three assets and calculates the expected return based on predefined returns for each asset. The returns are 10% for Asset 1, 15% for Asset 2, and 20% for Asset 3. The output should be the expected return as a scaled integer (e.g., 10% as 10, 15% as 15, etc.). The input weights are 5-bit binary numbers representing the percentage weights of each asset, which must sum to 100%.
