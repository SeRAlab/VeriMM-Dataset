Design a combinational logic circuit that performs a simple portfolio optimization by calculating the expected return of a portfolio given the weights of three different assets. The expected return is calculated by the formula: 
Expected Return = (Weight1 * Return1) + (Weight2 * Return2) + (Weight3 * Return3).
The weights and returns for each asset are provided as 4-bit binary inputs, and the output should be a 6-bit binary value representing the expected return, which can range from 0 to 63.
