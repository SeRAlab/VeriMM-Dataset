Design a simple 8-bit WiFi module state machine that handles the following states: IDLE, SCANNING, CONNECTING, and CONNECTED. The state machine should transition between these states based on a 2-bit input signal that indicates the desired operation: 00 for IDLE, 01 for SCANNING, 10 for CONNECTING, and 11 for CONNECTED. The state machine should have a clock and reset input, with the reset transitioning the state back to IDLE.
