Design a 1K x 1-bit RAM module that operates synchronously with two separate address buses. When enabled by chip select (CS1) and a read signal (READ), it outputs data from the specified address (AB1). The module is initialized with a predefined fill pattern. It allows writing to the memory at the specified address (AB1) on the positive edge of CLK1 when CS1 is active and READ is low. A second interface allows reading from another address (AB2) when CS2 is active. The module can output data in a tri-state manner when not selected.
