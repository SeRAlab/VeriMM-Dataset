Design a finite state machine (FSM) that manages a request-handling protocol with four states: IDLE, BBUSY, BWAIT, and BFREE. The module outputs a grant signal (`gnt`) when it is in the BBUSY or BWAIT states, indicating that a request is being processed. In the IDLE state, it transitions to BBUSY when a request (`req`) is received. In the BBUSY state, it can either remain in that state if the operation is incomplete or transition to BWAIT if a delay (`dly`) condition is met, or to BFREE when done. The BWAIT state allows for handling delays, looping back to itself until the delay condition is resolved, and then transitioning to BFREE. The system resets to IDLE state upon a negative reset signal (`rst_n`). This FSM is suitable for systems requiring coordinated request handling, such as in bus arbitration or resource sharing scenarios.
