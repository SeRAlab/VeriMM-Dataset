Design a 2-to-4 decoder that converts a 2-bit binary input (A and B) into one of four outputs (Y), activated by an enable signal (EN). When EN is asserted (high), the decoder outputs a single high output corresponding to the binary value of the inputs (00, 01, 10, or 11), with each output representing one of the four possible combinations. If the enable signal is low, all outputs remain low.
module top_module(
    input A,
    input B,
    input EN,
    output reg [3:0] Y
);
