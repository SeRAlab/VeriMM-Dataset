Design a D flip-flop with asynchronous set (SN) and reset (RST) functionalities. The flip-flop captures the input data (D) on the rising edge of the clock (CK) and has the ability to prioritize the reset condition over set when both are active. If SN is high and RST is low, the output (Q) is set to high. If RST is high and SN is low, Q is reset to low. In cases where both SN and RST are high, the reset takes precedence, ensuring Q is low. The complementary output (QN) is provided as the inverse of Q.
