Design a flip-flop with asynchronous reset and clock enable functionality. The module captures the value of input 'd' on the rising edge of 'clk' when 'ce' (clock enable) is high, while also providing an asynchronous reset that sets the output 'q' to LOW when 'reset' is asserted. Additionally, it includes a notifier output that indicates when the output 'q' changes, which helps in fault detection or monitoring within the circuit.
module top_module(
    input clk,
    input reset,
    input ce,
    input d,
    output reg q,
    output reg notifier
);
