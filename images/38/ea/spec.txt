
Design a 16-bit SRAM cell that includes a write and read operation. The SRAM should have an enable signal, a write enable signal, a 16-bit data input, a 16-bit data output, and a 4-bit address input to select one of 16 possible memory locations. Ensure that the read operation happens on the rising edge of a clock signal and that the write operation can occur only if the write enable signal is active.
