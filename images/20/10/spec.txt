
Design a 1-bit SRAM cell that can store a binary value (0 or 1). The SRAM cell should have two input signals: a data input (D) and a write enable (WE). When WE is high, the value present at D should be written to the cell; when WE is low, the cell should retain its current value. The cell should also have an output signal (Q) to provide the stored value.
