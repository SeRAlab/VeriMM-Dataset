
Design a Verilog module that implements a simple SD card command decoder. The module should take a 4-bit command input and provide a 3-bit response output based on predefined command types. The commands are as follows:
- Command 0: Response 001
- Command 1: Response 010
- Command 2: Response 011
- Command 3: Response 100
- Command 4: Response 101
- All other commands should yield a default response of 000.
