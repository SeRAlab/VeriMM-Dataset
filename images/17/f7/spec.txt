
Design a 16-bit Linear Feedback Shift Register (LFSR) that generates pseudo-random sequences. The LFSR should be initialized with a non-zero seed and should use the polynomial x^16 + x^14 + x^13 + x^11 + 1 for feedback. The output should be available on a 16-bit output port, and the LFSR should have a clock input and a reset input.
