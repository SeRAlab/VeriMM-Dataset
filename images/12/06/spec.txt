
Design a packet filtering unit that acts as a simple firewall. The unit should accept a 32-bit packet header and a 32-bit filter mask. If the packet matches the filter (using bitwise AND operation), it should be considered as a valid packet; otherwise, it should be rejected. The unit has a clock and reset input. On every rising edge of the clock, if the reset is asserted, the output should be reset to 0. If the reset is not asserted, check the packet against the filter and set the output to 1 for valid packets and 0 for invalid packets. Additionally, the module should provide a valid signal indicating whether the packet was accepted or rejected.
