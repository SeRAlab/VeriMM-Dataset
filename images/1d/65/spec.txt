
Design a simple Ethernet MAC controller that handles a basic frame transmission. The controller should support frame transmission initiation via a `start` signal, and the output `frame_valid` signal should indicate when the frame is being transmitted. The controller should also include a `data` input that represents the data to be transmitted. The transmission should take a number of clock cycles represented by a parameter `TRANSMIT_TIME`, after which the `frame_valid` signal should go low, indicating the end of the transmission. The MAC controller should also reset the transmission state with a `reset` signal.
