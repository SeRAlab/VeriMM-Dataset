Design a synchronous 2-bit wide register with additional control features. The register captures the value of a 2-bit input (D) on the rising edge of the clock (clk) when the enable signal (en) is asserted. In the event of a reset signal (rst), the output (Q) is set to zero. If the enable signal is not active, the output maintains its previous value. This design allows for controlled data storage in digital systems, effectively functioning as a synchronous storage element.
