Design a simple 2-bit branch predictor that uses a 2-bit saturating counter to predict the outcome of a branch instruction. The predictor should have an input for the branch instruction (a single bit) and output the prediction (also a single bit). The prediction should be updated based on the actual branch outcome. The 2-bit counter should have the following states: 00 (strongly not taken), 01 (weakly not taken), 10 (weakly taken), 11 (strongly taken). Transitions between states should occur on every clock cycle based on the input signal.
