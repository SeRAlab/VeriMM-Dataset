Design a circuit that converts a 4-bit Binary-Coded Decimal (BCD) input into its corresponding 7-segment display output. The module takes a 4-bit BCD value and activates the appropriate segments (a, b, c, d, e, f, g) of the 7-segment display based on the value of the BCD, where each segment is represented by a dedicated output. The behavior is defined for BCD values 0 through 9, with a default case that turns off all segments for invalid inputs.
module top_module(
    input [3:0] BCD,
    output reg a, b, c, d, e, f, g
);
