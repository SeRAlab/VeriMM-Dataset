Design a simple Direct Memory Access (DMA) controller in Verilog that allows a peripheral device to read and write data from/to memory without CPU intervention. The DMA controller should support initiating a transfer, controlling the address and data bus, and signaling the completion of the transfer. It should have an input signal for starting a transfer, a memory address input, and a data input/output. The controller should also have a busy signal to indicate when it is actively transferring data.
