Design a register file controller that functions as a multi-port memory with a configurable depth of 64 registers, each 24 bits wide. It has asynchronous reset functionality and a data input (DIN) that can be loaded into any of the registers when the corresponding LOAD signal is activated. The current contents of the register file are output as a concatenated data bus (DOUT) that spans all registers, allowing simultaneous access to the stored data.
