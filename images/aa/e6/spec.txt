Implement a two-bit binary up-counter with reset functionality. When the clock (CLK) signal receives a rising edge, the counter increments its output state from `00` to `11`, and then rolls over back to `00`. The counter can be reset to `00` when the reset (RST) input is activated. The outputs Q1 and Q0 represent the two bits of the counter, with Q1 being the most significant bit and Q0 the least significant bit.
module top_module(
    input CLK,
    input RST,
    output reg Q1,
    output reg Q0
);
