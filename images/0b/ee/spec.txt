Design a simple GPIO controller that allows reading and writing to a set of GPIO pins. The controller should have a 5-bit input for data, a control signal to determine whether to write or read (1 for write, 0 for read), and a 5-bit output to reflect the current state of the GPIO pins. The GPIO pins are initialized to 0. When the write control signal is asserted, the data should be written to the GPIO pins. When reading, the output should reflect the current state of the GPIO pins.
