
Design a Verilog module for a simple Flash memory cell that can store a single bit. The module shall have an input for data (D), a write enable signal (WE), a read enable signal (RE), and an output for the stored data (Q). When WE is high, the module should store the input data on the rising edge of the clock. When RE is high, the module should output the stored data. If both WE and RE are low, the output Q should maintain its previous state. The module should have an asynchronous reset (RST) that clears the stored data when activated.
