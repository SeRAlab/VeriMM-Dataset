

You have been tasked with designing a verilog module for a 4-bit unsigned comparator. The module should have two 4-bit inputs, A and B, and a single output, EQ, which should be high if A and B are equal, and low otherwise. You should use the following module definition:

```
module comparator_4bit (
    input [3:0] A,
    input [3:0] B,
    output EQ
);
```

You should implement the comparator using a combination of logic gates, such as AND, OR, and XOR gates, and any other necessary components.
