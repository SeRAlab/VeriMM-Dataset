Design a Verilog module for a 4-bit binary counter with carry-out and synchronous reset. The counter should count up on each positive clock edge. The carry-out signal should go high when the counter overflows. The reset signal should synchronously set the counter to 4'b0000.

module counter_with_carry_out
(
    input clk,
    input reset,
    output reg [3:0] count,
    output reg carry_out
);
