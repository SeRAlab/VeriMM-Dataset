Design a Verilog module that implements a simple JPEG compression-like encoding process. The module should take an 8-bit input pixel value and reduce it to a 4-bit representative value based on a simplified mapping (for example, mapping the input value to the nearest lower value in the set {0, 16, 32, 48, 64, 80, 96, 112, 128, 144, 160, 176, 192, 208, 224, 240}). The output should be the 4-bit encoded value.
