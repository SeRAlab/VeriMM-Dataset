Implement the Verilog module based on the following description.
We want to create a 4-bit synchronous binary counter with enable and reset that:

// (1) counts up on every clock cycle when 'enable' is high,
// (2) holds its value when 'enable' is low,
// (3) resets to zero when 'reset' is high,

// The counter value is output on 'count[3:0]'. The reset signal is active high synchronous.

module top_module(
    input wire clk,
    input wire reset,
    input wire enable,
    output reg [3:0] count
);
