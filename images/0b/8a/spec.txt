Design a fan speed control system that takes a temperature input and adjusts the fan speed accordingly. The fan has three speed settings: low, medium, and high. The temperature input is a 4-bit value, with the following speed settings:  
- 0-3: Low speed  
- 4-7: Medium speed  
- 8-15: High speed  
The system should be designed using a finite state machine (FSM) to control the fan speed based on temperature input. The FSM should transition between states based on the temperature value.
