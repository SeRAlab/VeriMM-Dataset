Implement the Verilog module based on the following description. Design a finite state machine to control a washing machine. The washing machine has four states: Idle, Washing, Rinsing, and Spinning. It accepts two inputs: start (which initiates the washing cycle) and done (which indicates completion of a phase). The machine transitions through the states in the following order: Idle -> Washing -> Rinsing -> Spinning -> Idle. Use an asynchronous reset to set the machine to Idle state.
