Design a 4-bit SRAM cell. The SRAM cell should have the following functionalities: It should have a 4-bit data input (D), a 4-bit data output (Q), a write enable signal (WE), and a clock signal (CLK). When WE is high and a clock edge occurs, the data input (D) should be written into the memory. When WE is low, the data stored in the SRAM cell should be output on Q.
