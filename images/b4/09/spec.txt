Design a D flip-flop with asynchronous set and reset functionalities. The flip-flop captures the value of the input D on the rising edge of the CLK signal, but it will output a logic HIGH (1) when the SET input is activated and a logic LOW (0) when the RESET input is activated, regardless of the CLK state. Additionally, the output QN provides the logical complement of the output Q.
module top_module(
  input CLK,
  input D,
  input SET,
  input RESET,
  output reg Q,   // Changed to output reg
  output QN      // Left as wire
);
