Implement the Verilog module based on the following description.
Build a 4-bit counter with synchronous active low reset signal and an enable signal. When the enable signal is high, the counter increments by 1.
// (1) reset_n: Resets the counter to 4'b0000 when low.
// (2) enable: Enables the counter to increment when high.
// (3) count: The current count value of the counter.

module counter(
    input clk,
    input reset_n,
    input enable,
    output reg [3:0] count);
