
Design a Verilog module that implements an HMAC (Hash-based Message Authentication Code) for a given input message and a key. The HMAC should use a simple hash function (for example, a XOR operation) for demonstration purposes. The module should take a 128-bit key and a 128-bit message as input and produce a 128-bit HMAC as output. The output HMAC should be computed upon receiving a valid start signal.
