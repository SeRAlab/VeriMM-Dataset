
Design a 16-bit SRAM cell that can store a value and be read from. The SRAM cell should have the following inputs: an address (4 bits), a write enable signal (we), a data input (16 bits), and a data output (16 bits). When the write enable signal is asserted, the data input should be stored at the specified address. When the write enable signal is not asserted, the data output should reflect the value stored at the specified address.
