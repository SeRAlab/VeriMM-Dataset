Create a 32-bit wide program counter register that holds the value of the next program counter. The register is updated on the rising edge of the clock signal (clk) with the input value next_pc_pc_reg_i, unless the reset signal is asserted, in which case it will be set to zero. The output provides the current value of the register, allowing subsequent stages in a digital design to access the next instruction address.
module top_module(
        input   wire        clk,
        input   wire        reset,
        input   wire[31:0]  next_pc_pc_reg_i,
        output  wire[31:0]  next_pc_pc_reg_o
    );
