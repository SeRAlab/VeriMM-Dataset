Design a memory register module capable of reading from and writing to a memory array. It consists of a 4096-entry register file, each entry being 16 bits wide. The module is controlled by a clock signal, with write operations performed on the falling edge of the clock when WRITE_EN is asserted, storing the input data at the specified address. Conversely, when READ_EN is asserted, it retrieves data from the given address into the output. This design allows for basic storage and retrieval functionality in digital circuits, acting as a simple register bank.
