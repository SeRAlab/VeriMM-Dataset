Design a register file that supports read and write operations for a collection of registers, with features to lock the writing process. The module consists of a set of registers capable of storing 32-bit data, identified by a 4-bit register address. When a clock signal is present, if the LOCK signal is asserted, data input (DIN) can be written to the specified register (DR) if the write enable (WE) signal is active. The outputs, SR1OUT and SR2OUT, present the values of the registers corresponding to the source register addresses (SR1 and SR2), being capable of delivering the most recent written value if it's the same register that was just written to, otherwise providing the saved value. This allows for simultaneous reading and writing operations while preventing unwanted changes during the LOCK state.
