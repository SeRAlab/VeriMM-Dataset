

You are tasked with designing a synchronous sequential circuit in Verilog that acts as a 4-bit counter. The circuit should have a single input `reset` which when set to 1, should reset the counter to 0. The circuit should have a single output `count` which should output the current count value in binary. Your design should make use of a single always block with a positive edge-triggered clock input `clk`. You should also make use of non-blocking assignments in your implementation.
