Design an SR latch using D flip-flops. The SR latch should have two inputs, S (Set) and R (Reset), and one output Q, where Q represents the state of the latch. When S = 1 and R = 0, Q should be set to 1. When S = 0 and R = 1, Q should be reset to 0. If both S and R are 0, Q should maintain its previous state. If both S and R are 1, the behavior should be undefined (but can be ignored in simulation).
