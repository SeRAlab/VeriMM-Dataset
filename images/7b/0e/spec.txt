Design a 3-bit up/down counter that increments or decrements its value based on control signals. The counter triggers on the rising edge of the CLK signal, resetting to zero when RST is high. If the UP signal is asserted and DOWN is not, the counter increases its value by one. Conversely, if the DOWN signal is asserted and UP is not, the counter decreases its value by one. This design allows for flexible counting in both directions based on external inputs.
module top_module(
    input CLK,
    input UP,
    input DOWN,
    input RST,
    output reg [2:0] Q
);
