
Design a Parallel-in Parallel-out (PIPO) shift register that allows loading data in parallel and reading it out in parallel. The register should have a parameterizable width defined by a parameter `N`. The register should have the following ports:
- `clk`: Clock signal
- `load`: Load signal (active high)
- `data_in`: Parallel input data of width `N`
- `data_out`: Parallel output data of width `N`
- `reset`: Asynchronous reset signal (active high)
