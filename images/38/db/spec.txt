
Create a Verilog module for a simple Bluetooth module state machine. The module should have an input signal for "connect", an input signal for "disconnect", and an output signal that indicates the current state of the Bluetooth module (IDLE, CONNECTED, DISCONNECTED). The state transitions should follow these rules:
- Initial state is IDLE.
- On "connect" input, transition to CONNECTED state.
- On "disconnect" input, transition to DISCONNECTED state.
- From CONNECTED state, if "disconnect" is received, transition back to IDLE.
- From DISCONNECTED state, if "connect" is received, transition back to IDLE.
