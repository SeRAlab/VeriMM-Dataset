
Create a Verilog module that implements a simplified RSA encryption scheme. The module should take a 16-bit plaintext input and a 16-bit public key ( consisting of a 16-bit exponent and a 16-bit modulus) and output a 32-bit ciphertext. Ensure the encryption follows the RSA formula: ciphertext = (plaintext^exponent) mod modulus. The exponent and modulus should be assumed to be valid for each input plaintext.
