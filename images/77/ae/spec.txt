Design a 4-bit binary adder with carry input and output. The module computes the sum of two 4-bit inputs (a and b) along with a carry-in (cin) on each rising edge of the clock. If the reset signal is activated, the sum and carry-out outputs are set to zero. The module outputs the 4-bit sum and a carry-out signal (cout) that indicates whether an overflow occurs when the sum exceeds the maximum representable value for a 4-bit number (i.e., 15).
module top_module(input clk, input reset,
                 input [3:0] a, input [3:0] b, input cin,
                 output [3:0] sum, output cout);
