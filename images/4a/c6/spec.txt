Design a module that performs basic bitwise operations on two n-bit wide input signals, `a` and `b`. The module outputs the results of the AND, OR, XOR operations between these two inputs, as well as the NOT operation applied to input `a`. It is parameterized with `n`, allowing for flexibility in the bit-width of the operations, defaulting to 8 bits. This functionality can be utilized in various digital applications requiring combinatorial logic processing.
module top_module(
  input [n-1:0] a,
  input [n-1:0] b,
  output [n-1:0] and_out,
  output [n-1:0] or_out,
  output [n-1:0] xor_out,
  output [n-1:0] not_out
);
