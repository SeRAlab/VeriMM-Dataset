Design a 1-bit SRAM cell in Verilog which consists of two cross-coupled inverters and two control signals: a write enable (we) and a read enable (re). The cell should be able to store a bit of data, allow reading and writing based on the control signals, and output the stored value. When we is high, the cell should accept a new input (data_in) to store. When re is high, the cell should output the stored value to data_out.
