
Design an 8-channel DMA (Direct Memory Access) controller. The DMA controller should have the following features:
- It supports 8 channels, each capable of reading or writing data from an external memory.
- There is a request signal for each channel (`req[7:0]`).
- A corresponding acknowledge signal (`ack[7:0]`) is generated when a request is serviced.
- The DMA controller should cycle through requests in a round-robin fashion, servicing each channel one at a time.
- A `clk` signal is used to trigger state updates, and a `reset` signal is used to initialize the state.
