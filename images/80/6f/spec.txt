Develop a basic calculator module that performs arithmetic operations based on a two-bit operation selector. It supports addition, subtraction, multiplication, and division of two 4-bit inputs (A and B). The module includes error handling for division by zero and overflow conditions. When an operation is executed, if the reset signal is active, the output is set to zero; otherwise, the result of the operation or an error message is displayed on a 4-bit output, LED.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input [1:0] op,
    input reset,
    output [3:0] LED
);
