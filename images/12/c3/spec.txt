Implement a simplified version of the ChaCha20 stream cipher's quarter round function, which processes four 32-bit words and produces four output 32-bit words. The function is defined by the following operations:  
1. a += b; d ^= a; d <<<= 16;  
2. c += d; b ^= c; b <<<= 12;  
3. a += b; d ^= a; d <<<= 8;  
4. c += d; b ^= c; b <<<= 7;  
The inputs are four 32-bit words (a, b, c, d) and the outputs are the processed four words (a_out, b_out, c_out, d_out). The quarter round function should be implemented in a clocked process. The function should be called every clock cycle, and the outputs should be valid after the last operation is performed.
