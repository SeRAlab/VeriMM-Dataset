Implement the Verilog module based on the following description.
Given the following Moore state machine with 1 input (in) and 1 output (out). Unless otherwise stated in the diagram below, assume outputs are 0 and inputs are don't cares.

The state machine has the following states and their corresponding outputs: 
1. state J (out=0).
2. state K (out=1).
3. state L (out=0).

State transitions:
1. From state J: If in = 1, then transition to state K. If in = 0, then remain in state J.
2. From state K: If in = 0, then transition to state L. If in = 1, then transition to state J.
3. From state L: If in = 1, then remain in state L. If in = 0, then transition to state J.

At reset, the state machine starts in state "J". Derive next-state logic equations and output logic equations by inspection assuming the following one-hot encoding is used: (J, K, L) = (3'b001, 3'b010, 3'b100)

Write code that generates the following equations:

- J_next -- next-state logic for state J
- K_next
- L_next
- out -- output logic

module top_module(
    input in,
    input [2:0] state,    // 3-bit one-hot current state
    output reg J_next,
    output reg K_next,
    output reg L_next,
