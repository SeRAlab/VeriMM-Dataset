Design a simple GPIO controller that can read and write to a GPIO pin. The controller should have the following functionality:
- A 1-bit input signal for writing to the GPIO pin.
- A 1-bit output signal for reading the GPIO pin's current state.
- A clock signal to synchronize the read and write operations.
- A reset signal that, when asserted, sets the GPIO pin to a low state (0).
The controller should maintain the state of the GPIO pin across clock cycles and only change the output when a new value is written.
