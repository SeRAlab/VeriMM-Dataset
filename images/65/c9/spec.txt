Design a 4-to-1 multiplexer with an enable feature for 8-bit wide data inputs. When the enable signal is low, the output is forced to zero. If the enable signal is high, the module selects one of the four data inputs (data0, data1, data2, or data3) based on the 2-bit selection input (sel), directing the chosen input to the output.
module top_module(
  input [7:0] data0,
  input [7:0] data1,
  input [7:0] data2,
  input [7:0] data3,
  input enable,
  input [1:0] sel,
  output reg [7:0] out
);
