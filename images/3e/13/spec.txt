
Design a fixed-priority arbiter in Verilog that grants access to one of four request lines (r0, r1, r2, r3) based on fixed priority. The arbiter should have a clock (clk) and reset (rst) signal, and once a request is granted, it should hold that grant until the request is deasserted. The priority order from highest to lowest is r0 > r1 > r2 > r3. The arbiter should output which request is currently granted (g0, g1, g2, g3).
