Design a combinational logic circuit that produces an output based on the logical conditions of five input signals. Specifically, the circuit computes an intermediate signal that activates if either both A1 and A2 are high, both A1 and A3 are high, or both B1 and B2 are high. The final output Y directly reflects the state of this intermediate signal.
module top_module(
    input  A1,
    input  A2,
    input  A3,
    input  B1,
    input  B2,
    output Y
);
