

You are tasked with designing a module in Verilog that implements a 2-to-1 multiplexer using the SkyWater 130nm process library. The module should have the following interface:

```
module mux_2to1 (
    input  wire a,
    input  wire b,
    input  wire sel,
    output wire y
);
```

The `a` and `b` inputs are the two inputs to the multiplexer, `sel` is the select signal that determines which input is passed to the output, and `y` is the output of the multiplexer.

Your module should be implemented using only the SkyWater 130nm process library and should be no more than 200 lines of Verilog code.
