

You are tasked with designing a verilog module that implements a 4-bit binary adder. The module should have two 4-bit input ports, A and B, and a 4-bit output port, S. The module should also have a single input port, C, which is the carry-in bit. The module should output the sum of A, B, and C in binary format. You may use any verilog built-in operators or functions to implement the adder.

Write a verilog module that implements the above requirements.
