Design a 4-bit adder with a carry-in feature, which performs the addition of two 4-bit inputs, A and B, on the rising edge of a clock signal (Clk). If the carry-in (Cin) is asserted, the circuit adds an additional 1 to the sum. The result is provided as a 4-bit output (S), and a carry-out (Cout) signal indicates if there is an overflow on the addition.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    input Clk,
    output [3:0] S,
    output Cout
);
