

You are tasked with designing a module that performs the bitwise XOR operation on two 8-bit inputs. The module should have three input ports: `input [7:0] A`, `input [7:0] B`, and `input clk`. The module should also have one output port: `output reg [7:0] X`. The module should be named `xor8`.

The module should perform the XOR operation on the two inputs, `A` and `B`, and output the result on `X`. The operation should be performed on every rising edge of the `clk` signal. If the `clk` signal is low, the module should hold the output value.

You should implement the module using only basic logic gates (AND, OR, NOT, XOR, etc.) and flip-flops. You should not use any pre-built XOR gates or any other pre-built modules.

Write a Verilog module that implements the `xor8` module as described above.
