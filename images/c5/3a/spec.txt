

You are tasked with creating a verilog module called `CountOnes` that takes in a 8-bit input vector `in` and outputs a 4-bit value `out`. The output value should represent the number of ones in the input vector.

Your module should have the following ports:
- `in`: an 8-bit input vector
- `out`: a 4-bit output value representing the number of ones in `in`

You should implement this module using behavioral verilog.
