Design a simple PCIe endpoint controller logic that takes a 5-bit input representing a command and outputs a 3-bit status based on the command. The commands are defined as follows: 
- Command 0: Status 0 (No operation)
- Command 1: Status 1 (Operation completed)
- Command 2: Status 2 (Error occurred)
- Command 3: Status 3 (Ready)
- Command 4: Status 4 (Busy)
All other commands should output Status 5 (Invalid command).
