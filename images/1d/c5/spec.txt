Design a packet filtering module for a simple firewall that checks incoming packets against a set of rules. Each packet has a source IP address (32 bits), destination IP address (32 bits), and a protocol type (8 bits). The module should output "ALLOW" or "BLOCK" based on whether the packet matches the defined rules. The rules are stored in a 2D array (up to 4 rules, where each rule consists of source IP, destination IP, and protocol type). The module should output "ALLOW" if a matching rule is found, otherwise "BLOCK".
