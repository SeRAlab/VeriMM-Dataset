Design a Set-Reset Flip-Flop (SRFF) with asynchronous reset functionality. The module features two inputs, set (s) and reset (r), receiving clock (clk) and reset (rst) signals, and outputs the current state (q) along with its inverted output (qb). On the positive edge of the clock, if the reset is activated, the output q is set to LOW. If both set and reset inputs are LOW, the output maintains its previous state. If reset is activated (r=1) while set is deactivated (s=0), the output resets to LOW. When the set input is activated (s=1) while reset is deactivated (r=0), the output is set to HIGH. If both inputs are HIGH, the output enters an indeterminate state (q=1'bx). The inverse of q is continuously assigned to qb.
