Design a basic arithmetic calculator that performs addition, subtraction, multiplication, and division on two 4-bit inputs (num1 and num2) based on a 2-bit operation selector (op). The module processes the arithmetic operations sequentially on each clock cycle, transitioning through states for each operation, while also allowing for asynchronous reset functionality. The final result from the selected operation is assigned to a 4-bit output (result), and the computed output is presented on another 4-bit display (display). This design emphasizes state management to control the sequence of operations while ensuring that the calculator is resettable.
module top_module(input [3:0] num1, input [3:0] num2, input [1:0] op, input clk, input rst, output [3:0] result, output [3:0] display);
