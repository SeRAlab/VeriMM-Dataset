
Create a simple 5-stage pipeline for a basic instruction execution model. The pipeline should consist of the following stages:
1. Instruction Fetch (IF)
2. Instruction Decode (ID)
3. Execute (EX)
4. Memory Access (MEM)
5. Write Back (WB)

The pipeline should take a 5-bit instruction as input and propagate it through each of the stages, with appropriate registers for each stage.
