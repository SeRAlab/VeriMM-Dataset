
Design a 5-stage pipelined processor that executes a simple instruction set. The pipeline consists of the following stages: Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). The architecture should be able to handle hazards, including data hazards and control hazards. You should implement the forwarding logic to resolve data hazards and include a simple branch prediction mechanism to handle control hazards.
