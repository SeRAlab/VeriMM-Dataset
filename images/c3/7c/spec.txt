

You are tasked with designing a verilog module that implements a 16-bit shift register with a parallel load feature. The module should have the following inputs and outputs:

Inputs:
- `clk`: a 1-bit clock signal
- `load`: a 1-bit signal that enables parallel loading of data
- `data_in`: a 16-bit input signal that contains the data to be loaded into the shift register
- `shift_en`: a 1-bit signal that enables shifting of the data in the shift register

Outputs:
- `data_out`: a 16-bit output signal that contains the current state of the shift register

The shift register should shift the data to the left on every positive edge of the clock signal when `shift_en` is high. When `load` is high, the data in `data_in` should be loaded into the shift register on the next positive edge of the clock signal.
