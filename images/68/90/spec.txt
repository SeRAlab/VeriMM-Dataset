Design a program counter (PC) module that updates its output based on a clock signal and control signals. When reset is low, the output is set to zero, effectively clearing the counter. If reset is high, the output will be updated to the value of `input_pc` only when the `PCWre` (program counter write enable) signal is asserted. If `PCWre` is low, the output retains its previous value. This design allows for controlled updates to the program counter, typical in digital systems for instruction sequencing.
module top_module(
	 clk,    
	 reset,  
	 input_pc,  
	 output_pc, 
	 PCWre   
);
