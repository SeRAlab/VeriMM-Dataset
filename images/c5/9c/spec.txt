

You are tasked with designing a module that performs a bitwise AND operation on two 8-bit input values. The module should have three inputs: `input [7:0] a`, `input [7:0] b`, and `input clk`. The module should also have one output: `output [7:0] result`.

The module should operate on the inputs on the rising edge of the clock signal and should output the result on the next rising edge of the clock signal. If the inputs change before the next rising edge of the clock signal, the module should ignore the changes and use the previous values of the inputs to compute the result.

Your module should be named `and8` and should be implemented in Verilog. You may use any Verilog constructs necessary to implement the module.
