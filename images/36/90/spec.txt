
Design a simple Bluetooth state machine that manages the connection status of a Bluetooth device. The state machine should have three states: IDLE, CONNECTED, and DISCONNECTED. The state transitions are as follows:
- From IDLE, it can transition to CONNECTED on the input signal `connect`.
- From CONNECTED, it can transition to DISCONNECTED on the input signal `disconnect`.
- From DISCONNECTED, it can transition back to IDLE on the input signal `reset`.
The output of the module should indicate the current state of the Bluetooth device.
