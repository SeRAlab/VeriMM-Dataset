Design a Verilog module for a Moore state machine with two states (S, T) and one input signal (C). The states are encoded as one-hot: S=2'b01, T=2'b10. The state machine has an output (out) that is dependent only on the state.

The state machine has the following states and their corresponding outputs:
1. state S (out = C).
2. state T (out = ~C).

State transitions:
1. From state S: If C = 1, then transition to state T. If C = 0, stay in state S.
2. From state T: If C = 0, then transition to state S. If C = 1, stay in state T.

module moore_fsm (
  input C,
  input [1:0] state,
  output reg [1:0] next_state,
  output reg out);
