Design a fan speed control system that adjusts the speed of a fan based on an input temperature value. The system should have the following logic: if the temperature is below 20 degrees Celsius, the fan should be off. If the temperature is between 20 and 30 degrees, the fan should run at low speed. If the temperature is between 30 and 40 degrees, the fan should run at medium speed. If the temperature is above 40 degrees, the fan should run at high speed. The system should also include a reset functionality that can be triggered to turn off the fan immediately.
