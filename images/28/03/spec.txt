Design a 4-to-16 line decoder. The decoder takes 4 input lines and activates one of the 16 output lines corresponding to the binary value of the inputs. If the inputs are 0000, output line 0 should be active (1), if the inputs are 0001, output line 1 should be active (1), and so on up to 1111 where output line 15 should be active (1). All other output lines should be inactive (0).
