
Design a simple Kalman filter for sensor fusion that estimates the position of an object based on noisy sensor measurements. The system should include the following parameters:
- State vector: [position, velocity]
- Measurement vector: [measured_position]
- Process noise covariance, measurement noise covariance, and state estimate covariance should be defined as constants. 
The Kalman filter should be implemented in a clocked manner and should update the state based on the sensor measurements at each clock cycle.
