Design a 4-to-2 priority encoder with an enable signal. When enabled, the circuit outputs a 2-bit code corresponding to the highest order active input (from the 4-bit input), where an input value of 8 maps to output 01, an input value of 4 maps to output 10, and an input value of 2 maps to output 11. If the enable signal is not asserted, the output remains at its default low state.
