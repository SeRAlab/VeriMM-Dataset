
You are tasked with designing a verilog module that takes in a 4-bit binary input and outputs the 2's complement of the input. The module should have the following interface:

Inputs:
- `in`: a 4-bit binary input

Outputs:
- `out`: a 4-bit binary output representing the 2's complement of the input

Your module should follow the following rules:
1. The 2's complement of a binary number is obtained by inverting all the bits of the number and adding 1 to the result.
2. The module should be synthesizable and should not use any behavioral constructs.
3. The module should be named `twos_comp` and should be defined in a verilog file named `twos_comp.v`.
