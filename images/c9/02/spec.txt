
You are tasked with designing a verilog module that implements a 4-bit up-counter with synchronous reset. The module should have the following ports:

- `CLK`: a clock input
- `RST`: a synchronous reset input
- `OUT`: a 4-bit output representing the current count value

The counter should increment on every rising edge of the clock input and reset to 0 on every rising edge of the reset input.

Implement the counter using a single always block and make sure that the counter is synchronous to the clock input.
