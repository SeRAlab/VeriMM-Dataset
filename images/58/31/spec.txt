Design a 4-bit binary counter with a finite state machine (FSM) driven by a clock signal. The counter has four sequential states (S0, S1, S2, S3) and counts up by one in each state upon the rising edge of the clock. The counting process resets to 0 when the reset signal is asserted, and the state machine also resets to the initial state S0. This design allows for a controlled counting sequence that can be integrated into larger digital systems needing a simple count function.
module top_module(
  input clk,
  input reset,
  output reg [3:0] count
);
