When `sel` is high, the output `res` computes the sum of `a` and `b`; when `sel` is low, the output computes the difference of `a` and `b`. This effectively creates an arithmetic unit that can perform addition or subtraction based on the control signal.
module top_module(
  input [15:0]  a,
  input [15:0]  b,
  input         sel,
  output [15:0] res
  );
