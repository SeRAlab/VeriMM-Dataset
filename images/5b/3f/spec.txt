Design a simple memory interface module that operates on the rising edge of a clock signal. This module incorporates a 32x32-bit memory array and facilitates both writing and reading operations based on specific control signals. When the MemoryWrite signal is asserted, it writes the provided writedata to the memory location specified by the address input. If the out signal is asserted, it retrieves the data from the address location and outputs it on dataout. Additionally, if the reset signal is activated, it sets dataout to the value at memory address 0, which is initialized to zero.
module top_module(clock, address, writedata, dataout, out, MemoryWrite, reset);
