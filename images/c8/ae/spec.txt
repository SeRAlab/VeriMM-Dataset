

You are tasked to design a verilog module that takes in a 4-bit input and outputs the number of 1's in the input. For example, if the input is 4'b0101, the output should be 2.

You are given the following template to start with:

```
module count_ones (
    input [3:0] in,
    output reg count
);

// your code here

endmodule
```

Your task is to fill in the code to implement the desired functionality. You may use any combinational logic gates or other modules as necessary. The output `count` should be a single bit.
