

You are tasked with designing a Verilog module for a 4-input AND gate with one output. The module should have the following interface:

```
module and_gate (
    input  A,
    input  B,
    input  C,
    input  D,
    output Y
);
```

The inputs A, B, C, and D are single-bit binary values, and the output Y is also a single-bit binary value. The module should implement a standard 4-input AND gate, where the output Y is 1 if and only if all four inputs A, B, C, and D are 1.

Your task is to write the Verilog code for the and_gate module. Your code should be self-contained, meaning it should not rely on any external modules or libraries. Additionally, your code should not exceed 200 lines of Verilog code.
