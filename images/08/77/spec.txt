
Design a Verilog module for a Flash memory cell that allows for reading, writing, and erasing operations. The operations should be controlled by a clock signal. The module should have the following inputs and outputs:
- Input: `clk` (clock), `write_enable` (control signal for writing), `erase_enable` (control signal for erasing), `data_in` (input data), and `read_enable` (control signal for reading).
- Output: `data_out` (output data).
The operations should be sequenced such that writing can only occur when `write_enable` is high and `read_enable` should output the stored data when it is high. The erase operation should reset the stored data to a predefined value (e.g., 0).
