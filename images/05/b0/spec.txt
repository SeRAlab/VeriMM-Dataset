Design a fixed-point multiplication module in Verilog that takes two fixed-point numbers as inputs, each represented as 16-bit signed integers, and produces a 32-bit signed integer output. The multiplication should be performed with a scale factor of 2^n, where n is the number of fractional bits you decide, for example, n=8. The input numbers should be multiplied, scaled, and the result should be correctly rounded to fit in the output format.
