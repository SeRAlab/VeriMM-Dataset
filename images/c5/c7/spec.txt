

You have been tasked with designing a module in Verilog to implement a 2-input, 3-output logic function. The module should take in two input signals, A and B, as well as a control signal, C, and output Y1, Y2, and Y3. The output signals should be determined by the following rules:

- If C is 0, then Y1 should be equal to A and Y2 should be equal to B.
- If C is 1, then Y1 should be equal to A and Y3 should be equal to B.

Write a Verilog module that implements this logic function. Your module should be self-contained and take in the following signals:

- A: input signal
- B: input signal
- C: input signal
- Y1: output signal
- Y2: output signal
- Y3: output signal

Your module should be no more than 200 lines of Verilog code.
