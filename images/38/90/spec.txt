Design a Deadbeat Controller that takes a 4-bit input signal `x` and produces a 4-bit output signal `y` such that the output reaches the desired steady-state value of `0000` within one clock cycle for an input value of `1111` (15 in decimal). For any other input value, the output should remain unchanged. The output should be `0000` when the input is `1111` and `0001` for all other inputs.
