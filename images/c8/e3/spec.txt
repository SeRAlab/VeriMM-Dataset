

You are tasked with designing a module that can perform a specific arithmetic operation. The module should take in two 4-bit binary numbers, A and B, and a control signal, S. The output of the module should be the result of the arithmetic operation performed on A and B, depending on the value of S. 

The arithmetic operation to be performed is determined by the value of S. If S is 0, the module should output the sum of A and B. If S is 1, the module should output the difference between A and B.

Your task is to design a Verilog module that can perform this operation. The module should be named "arithmetic_op" and should be self-contained, meaning that it should not rely on any other modules. The module should be able to perform the operation in a single clock cycle, and should not use any loops or conditionals. The module should be implemented within 200 lines of Verilog code.

You can assume that the inputs A and B will always be valid 4-bit binary numbers, and that the control signal S will always be either 0 or 1.
