
Design a 5-stage instruction pipeline with the following stages: 
1. Instruction Fetch (IF)
2. Instruction Decode (ID)
3. Execution (EX)
4. Memory Access (MEM)
5. Write Back (WB)

The pipeline should handle stalls (bubbles) when there are data hazards. Implement a simple control logic that introduces a stall when a data hazard is detected between the EX stage and the ID stage. Assume a simple architecture with 2 registers and one ALU operation.
