Design a D flip-flop with asynchronous reset and set functionalities. The flip-flop captures the value of input D on the rising edge of the CLK signal unless overridden by the active low RESET or SET inputs. When RESET is asserted, the output Q is set to LOW, while asserting SET forces the output Q to HIGH regardless of D and CLK. The output Q_N provides the inverted value of Q.
module top_module(
    input D,
    input CLK,
    input RESET,
    input SET,
    output reg Q,  // Changed 'output Q' to 'output reg Q'
    output Q_N
);
