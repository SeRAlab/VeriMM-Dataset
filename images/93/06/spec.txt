Design a Verilog module to implement a 4-bit binary counter with the following functionalities:
- The counter increments on each positive edge of the clock (clk).
- It has an asynchronous active-high reset (areset) that sets the counter to 0.
- It also has an enable (en) signal. When en is low, the counter does not increment.

module counter (
        input clk,
        input areset,
        input en,
        output reg [3:0] q);
