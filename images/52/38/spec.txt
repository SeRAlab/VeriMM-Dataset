1. The counter loads the input data when the load input is high.
2. The counter increments on the rising edge of the clock if the enable input is high.
3. The counter resets to zero when the reset input is high.

Write Verilog implementing this counter.
module async_counter (
        input clk,
        input load,
        input enable,
        input reset,
        input [7:0] data,
        output reg [7:0] count);
