

You are tasked with designing a verilog module for a D flip-flop with synchronous reset. The module should have the following inputs and outputs:

- `clk`: a clock signal
- `rst`: a synchronous reset signal
- `d`: the data input
- `q`: the output

The D flip-flop should store the value of `d` on the rising edge of `clk`. If `rst` is high, the output `q` should be set to 0. Otherwise, `q` should retain its previous value.

You should write a verilog module that implements this D flip-flop with synchronous reset. The module should be self-contained and should not rely on any other modules or external definitions.

Your module should be no more than 200 lines of verilog code.
