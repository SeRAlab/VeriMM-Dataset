
You are tasked with designing a 2-to-1 multiplexer using Verilog. The multiplexer should have two data inputs, `D0` and `D1`, and one control input, `ctrl`. If `ctrl` is 0, the output should be equal to `D0`. If `ctrl` is 1, the output should be equal to `D1`.

You should implement this multiplexer as a Verilog module named `mux2to1`. The module should have the following inputs and outputs:

- `ctrl`: a single-bit input representing the control signal
- `D0`: a single-bit input representing the first data input
- `D1`: a single-bit input representing the second data input
- `S`: a single-bit output representing the output of the multiplexer

Your implementation should be contained within 200 lines of Verilog code. You may not use any Verilog constructs that have not been covered in class, such as generate blocks or always_ff.
