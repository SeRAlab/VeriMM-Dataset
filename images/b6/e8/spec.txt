Design a D latch with asynchronous reset functionality. The latch captures the input D and holds its value at the output Q when the GATE input is high. If the RESET input is activated, the output Q is immediately set to LOW, overriding the D input regardless of the GATE state. This structure is useful in digital circuits where temporary storage of a data bit with an immediate reset capability is required.
module top_module(
    input wire D,
    input wire RESET,
    input wire GATE,
    output reg Q
);
