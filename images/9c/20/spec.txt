Design a synchronous RAM module with 8-bit wide data storage and 32-addressable locations. This module features a write enable signal (WE) for writing data to specified addresses, and outputs data on read operations. On each positive clock edge, if the testStart signal is activated, it initializes the first 18 entries in the RAM with predefined bit patterns. If WE is active, the module updates the RAM at the given address with the incoming data. If WE is inactive, it retrieves the data from the specified address and outputs it.
