Design a simple 4-bit calculator that performs addition or subtraction based on a control signal. When the control signal `op` is 0, the module outputs the sum of inputs `a` and `b`; when `op` is 1, it outputs the difference of `a` and `b`. The result is a 4-bit value representing either the addition or subtraction operation.
module top_module(
    input [3:0] a,
    input [3:0] b,
    input op,
    output [3:0] result
);
