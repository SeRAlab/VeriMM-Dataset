Design a clock gating circuit that outputs a controlled clock signal, ENCLK. The output clock is enabled (equal to the input clock, CLK) only when the enable signal (EN) is asserted and the test enable signal (TE) is not asserted. If either the test enable signal is active or EN is low, the output ENCLK will be permanently driven to LOW. This design is typically used to reduce power consumption by selectively disabling the clock signal in certain conditions.
module top_module(
  input CLK, EN, TE,
  output ENCLK
);
