Design a 4-bit counter with load capabilities. The counter increments its value on every positive clock edge when enabled. If the reset signal is asserted, it resets the count to zero. Additionally, if a non-zero load value is provided, it will load that value into the counter instead of incrementing.
module top_module(
    input [3:0] load,
    input enable,
    input reset,
    input clk,
    output reg [3:0] count
);
