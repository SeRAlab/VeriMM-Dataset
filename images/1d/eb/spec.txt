Design a Verilog module that performs bilinear interpolation on a 2x2 grid of input pixels. The module takes four 8-bit pixel values as inputs (top-left, top-right, bottom-left, bottom-right) and outputs the interpolated pixel value as an 8-bit output. The bilinear interpolation formula is given by:
```
f(x, y) = (1-x)*(1-y)*Q11 + x*(1-y)*Q12 + (1-x)*y*Q21 + x*y*Q22
```
where Q11, Q12, Q21, and Q22 are the pixel values, and x and y are the fractional parts of the coordinates (0 ≤ x, y < 1). The output should be rounded to the nearest integer.
