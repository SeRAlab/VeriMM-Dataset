Implement a Verilog module that performs an 8-bit subtraction with borrow-in and borrow-out. The module should have the following specifications:
- `clk`: The clock signal.
- `reset`: An active-high synchronous reset signal.
- `start`: An active-high signal that starts the subtraction.
- `data1`: The first 8-bit input data (minuend).
- `data2`: The second 8-bit input data (subtrahend).
- `borrow_in`: The borrow-in input.
- `difference`: The output which holds the difference of the inputs.
- `borrow_out`: The output which holds the borrow-out.
- `done`: An active-high signal indicating the completion of the subtraction.
