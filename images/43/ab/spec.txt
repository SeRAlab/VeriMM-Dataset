Design a 3-bit Gray code counter that increments or decrements its count based on a control signal, while also resetting to zero when indicated. The module generates the corresponding Gray code output and calculates the sum of the current count and the Gray code value, outputting this sum as an 8-bit signal. The design utilizes a flip-flop structure for counting and combinational logic to handle Gray code conversion and summation.
module top_module(
    input clk,
    input reset,
    input control,
    output reg [2:0] count,
    output reg [7:0] gray_out,
    output reg [7:0] sum_out
);
