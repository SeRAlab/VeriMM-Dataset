Design a 64-bit wide program counter (PC) module that updates its output based on clock edges. On a rising clock edge, if the reset signal is asserted, the output will be set to zero. If the reset is not active and the write signal is high, the module will store the input value (data_in) into the output (pcout). This allows the program counter to be reset or loaded with a new value, suitable for instruction sequencing in a processor.
