Design a simple virtual memory management unit (MMU) that maps a virtual address to a physical address. The MMU will use a basic page table structure to manage this mapping. The inputs to the MMU will be a virtual address (VA), a write enable signal, and a clock signal. The outputs will be the corresponding physical address (PA) and a valid signal indicating if the translation was successful. The page table will be a simple array that contains the mapping of virtual pages to physical pages.
