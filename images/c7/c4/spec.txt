

In digital circuit design, multiplexers (MUX) are important components that allow for the selection of one of several input signals to be outputted based on a select signal. In this problem, you are tasked with designing a 2:1 MUX using Verilog.

Your MUX should have two input signals, `A` and `B`, and one select signal, `S`. If `S` is 0, then the output should be `A`, and if `S` is 1, then the output should be `B`.

Your Verilog module should be named `mux_2to1` and should have the following inputs and outputs:
- `input A`: a single bit representing the first input signal
- `input B`: a single bit representing the second input signal
- `input S`: a single bit representing the select signal
- `output Y`: a single bit representing the output signal

Your Verilog module should only contain combinational logic and should not use any built-in Verilog primitives (e.g., `always` blocks, `if` statements, etc.). Your MUX should be designed using only basic logic gates (AND, OR, NOT, XOR, etc.).
