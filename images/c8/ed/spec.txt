

You are tasked with designing a Verilog module that can perform a bitwise logical AND operation on two 16-bit input vectors, A and B. The output should be a 16-bit vector C, where each bit of C is the result of the corresponding bits in A and B being ANDed together.

Your module should have the following interface:

```
module bitwise_and(
  input [15:0] A,
  input [15:0] B,
  output [15:0] C
);
```

Assume that the inputs A and B will always be 16-bit vectors, and that the output C should also be a 16-bit vector.

Your module should be implemented using only basic Verilog operators (e.g. &, |, ^, ~), and should not rely on any built-in Verilog functions or libraries.

Write a Verilog module that satisfies the above requirements and can perform the bitwise AND operation on two 16-bit input vectors.
