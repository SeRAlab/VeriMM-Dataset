
Design a Model Predictive Control (MPC) system that predicts the next state of a system based on the current state and input signals. The design should have the following characteristics:
- It takes a current state (4 bits), an input (4 bits), and a control signal (1 bit) that determines whether to update the state or hold the current state.
- If the control signal is high (1), the next state is calculated as the sum of the current state and the input, constrained to a maximum of 15 (4 bits).
- If the control signal is low (0), the next state remains the same as the current state.
- The state should update on a clock edge.
- Provide a simple counter that increments every clock cycle to simulate time steps.
