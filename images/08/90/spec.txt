Design a combinational logic circuit that converts RGB color values to YUV color values. The RGB input values are 8-bit each (R, G, B) and the output should be 8-bit each (Y, U, V). The conversion formulas are as follows:
Y = 0.299 * R + 0.587 * G + 0.114 * B
U = -0.14713 * R - 0.28886 * G + 0.436 * B + 128
V = 0.615 * R - 0.51499 * G - 0.10001 * B + 128
Since the outputs are in the range of 0 to 255, rounding and clipping might be necessary to fit the output into 8 bits.
