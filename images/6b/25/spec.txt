Develop a Verilog module for a 4-bit binary to Gray code converter. The conversion should take place at every positive edge of the clock.

Time 0ns: clk = 0, binary_in = 4'b0000, gray_out = 4'b0000.
Time 5ns: clk = 1, binary_in = 4'b0001, gray_out = 4'b0001.
Time 10ns: clk = 0, binary_in = 4'b0010, gray_out = 4'b0011.
Time 15ns: clk = 1, binary_in = 4'b0011, gray_out = 4'b0010.
Time 20ns: clk = 0, binary_in = 4'b0100, gray_out = 4'b0110.

module binary_to_gray (
	input clk,
	input [3:0] binary_in,
	output reg [3:0] gray_out);
