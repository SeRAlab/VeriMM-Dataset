Design a module that performs both addition and subtraction on two 8-bit inputs, A and B. The module produces two outputs: S, which represents the sum of A and B, and D, which represents the difference A minus B. The selection input, sel, controls the outputs such that when sel is asserted, S will output the value of D and D will output the value of S, effectively swapping the results.
module top_module(
  input [7:0] A,
  input [7:0] B,
  input sel,
  output [7:0] S,
  output [7:0] D
);
