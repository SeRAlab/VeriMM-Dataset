The comparison is performed over four stages, where the inputs are progressively right-shifted at each stage, allowing for a detailed analysis of the bitwise differences between A and B. The circuit is clocked, enabling it to reset and restart the comparison process after completing all stages.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input clk, // Added clk input
    output equal,
    output A_greater_than_B,
    output A_less_than_B
);
