Design a Verilog module for a 10-bit binary down counter with an asynchronous reset. The counter decrements its value on the falling edge of the clock and resets to 0 when the reset signal is active.

Module name:  
    counter_10bit_down  

Input ports:
    clk: Chip clock signal.
    rst: Asynchronous reset signal.

Output ports:
    count: Counter output signal with a data width of 10 bits.

Implementation:
Counter operation:
On every falling edge of the clock signal (clk), the counter (count) is decremented. If the asynchronous reset signal (rst) is active, the counter resets to 0 immediately regardless of the clock signal.
