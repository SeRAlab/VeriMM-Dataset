Design a virtual memory address translation circuit that converts a virtual address into a physical address using page tables. The circuit should take a virtual address as input, along with control signals to indicate read or write operations, and output the corresponding physical address. Assume a simple page table where each page is 4KB and there are 256 entries. The page table is stored in an array inside the design. The output should also indicate if the operation was successful or if there was a page fault.
