Design a 4-bit arithmetic module capable of performing both addition and subtraction based on a control signal. When the SUB input is low, it outputs the sum of inputs A and B. When SUB is high, it computes the difference by negating B and adding it to A. The module also includes overflow detection, asserting the OVF output when an overflow condition occurs during the calculation—specifically when the operation sign changes unexpectedly. This functionality is critical for arithmetic operations in digital systems.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input SUB,
  output reg [3:0] S,
  output reg OVF
);
