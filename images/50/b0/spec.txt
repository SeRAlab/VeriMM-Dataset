Design a next program counter (PC) module for a processor, which determines the next address to fetch based on control signals and inputs. The module receives an incremented PC value and an immediate 26-bit value, along with flags indicating branch conditions (beq, bne) and jump (j). It produces a new PC output (pc_out) that is calculated based on these conditions: if a branch is taken (determined by the beq and bne signals in conjunction with the zero flag), it computes the PC as the incremented value plus an offset derived from the immediate value. If a jump is activated, it sets the PC to the immediate address. The pc_src output indicates which path is taken for the next instruction fetch.
module top_module(pc_src,increm,zero,j,bne,beq,pc_out,imm26);
