Design a one-bit full adder circuit that computes the sum and carry-out of three input bits: A, B, and a carry-in (cin). The module outputs the sum (S) and the carry-out (cout). The sum is derived by performing an exclusive OR operation on A, B, and cin, while the carry-out is generated based on the combination of the input bits that would produce a carry.
module top_module(
input	A,
input	B,
input	cin,
output	S,
output	cout
);
