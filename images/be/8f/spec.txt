Design a D flip-flop with active-low reset and set functionality, featuring power supply and ground connections. The flip-flop captures the input D on the rising edge of the clock (CLK) and outputs the stored value on Q. When RESET_B is active (low), it resets the output Q to low, and the complementary output Q_N is generated accordingly. The design utilizes a series of NAND, NOR, AND, and OR gates to implement the required logic while ensuring proper voltage levels with provided power supply connections. This module is suitable for digital circuits requiring state retention with reset capability.
module top_module(
    input D, RESET_B, CLK,
    output reg Q, Q_N
);
