Design a 32-bit arithmetic unit that performs either addition or subtraction based on a control signal. Inputs `a` and `b` are the operands, and the `sub` input selects the operation: when `sub` is 0, it computes the sum (a + b), and when `sub` is 1, it computes the difference (a - b). The result is stored in a register and provided as the output `sum`.
module top_module(
    input [31:0] a,
    input [31:0] b,
    input sub,
    input clk,                   // Added clk input
    output [31:0] sum
);
