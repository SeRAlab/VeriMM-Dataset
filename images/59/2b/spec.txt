Design a D-type flip-flop with asynchronous reset and set capabilities. The output `q` holds the value of input `d` on the rising edge of `clk` unless a reset is triggered, in which case `q` is set to LOW and `q_n` is set to HIGH. If the set signal is activated, `q` is set to HIGH and `q_n` is set to LOW. In the absence of both reset and set, the module operates as a standard D flip-flop.
module top_module(
    input clk,
    input reset,
    input set,
    input d,
    output reg q,
    output reg q_n
);
