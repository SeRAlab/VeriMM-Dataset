Design a Verilog module that implements a Dynamic Voltage and Frequency Scaling (DVFS) controller. The DVFS controller should take a temperature input and adjust the voltage and frequency levels based on predefined temperature thresholds. The controller should have the following specifications:
- When the temperature is below 25°C, set voltage to 1.0V and frequency to 1.0GHz.
- When the temperature is between 25°C and 70°C, set voltage to 0.8V and frequency to 0.8GHz.
- When the temperature is above 70°C, set voltage to 0.6V and frequency to 0.6GHz.
The module should also have a clock input for synchronous operation and a reset input to reset the state to the default settings.
