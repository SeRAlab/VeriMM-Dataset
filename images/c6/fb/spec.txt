

You are tasked with designing a Verilog module that implements a 32-bit register. The module should have the following inputs and outputs:

- Input `IN`: a 32-bit input signal to be stored in the register.
- Input `Clk`: a clock signal.
- Input `Reset`: a reset signal that sets the register to 0.
- Input `Load`: a control signal that loads the input signal into the register.
- Output `OUT`: the 32-bit value stored in the register.

Your Verilog module should be able to store the input signal in the register when the `Load` signal is high. The stored value should be maintained until the `Load` signal is high again, at which point the register should be updated with the new input signal. The module should also be able to reset the register to 0 when the `Reset` signal is high.

Your module should be self-contained and should not rely on any other modules or external signals. Your module should not exceed 200 lines of Verilog code.
