Design a 4-to-1 multiplexer with differential output. The module selects one of four input lines based on a 2-bit selector signal, S. Depending on the value of S, one of the four inputs (I[0] to I[3]) is routed to the primary output (O), while the complementary output (OB) is generated as the logical NOT of the primary output. The differential output buffer enhances the integrity of the signals being output for use in high-speed applications.
module top_module(
    input [3:0] I,
    input [1:0] S,
    output O,
    output OB
);
