Design a data forwarding logic for a simple 2-input multiplexer. The multiplexer should select one of two inputs based on a select signal. If the select signal is high (1), the output should be the first input; if it is low (0), the output should be the second input. Additionally, implement data forwarding such that if the first input is equal to the output of the multiplexer from a previous computation, it should be forwarded to the output directly.
