Implement a 24-bit Digital-to-Analog Converter (DAC) that takes a 24-bit input and produces a 4-bit output which represents the scaled value of the input. The output should be calculated as follows: output = (input >> 20) & 0xF, which means the upper 4 bits of the 24-bit input will be output. Ensure that the output is only valid when a valid signal is asserted.
