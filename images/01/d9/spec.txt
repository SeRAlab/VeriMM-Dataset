
Create a simple PCIe endpoint controller that manages a data transfer request. The controller should have inputs for a request signal (`req`), a clock signal (`clk`), a reset signal (`rst`), and an input data signal (`data_in`). The output should be an acknowledgment signal (`ack`) and an output data signal (`data_out`). The acknowledgment signal should be asserted when a request is received, and the data should be transferred to the output on the rising edge of the clock after the acknowledgment.
