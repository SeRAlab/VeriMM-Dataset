Design a Verilog module that implements Nearest Neighbor Interpolation for a 2x2 pixel block. The input consists of the pixel values (4 bits each) of the 2x2 pixel block, and the output should be the interpolated pixel values (4 bits each) for a 4x4 pixel image. The interpolation should be such that for each 2x2 pixel block, the output will be replicated to form a 4x4 block.
