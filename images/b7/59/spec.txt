Design a touch sensor module that can operate as either a capacitive or resistive touch sensor based on the specified `sensor_type`. When configured as a capacitive sensor, it detects touch by measuring changes in capacitance by comparing the current input signals with previous ones. If there is a difference, it outputs a high signal indicating touch detection. As a resistive sensor, it checks if all input signals exceed a certain threshold to determine if pressure is applied. The module outputs a high signal when touch is detected in either mode.

  output out
