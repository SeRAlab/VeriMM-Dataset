Design a 4-to-1 multiplexer that selects one of the four input lines (A0, A1, A2, A3) based on the values of two select lines (S0, S1). The output, Y, corresponds to the selected input: when S1 and S0 are both 0, Y outputs A0; when S1 is 0 and S0 is 1, Y outputs A1; when S1 is 1 and S0 is 0, Y outputs A2; and when both S1 and S0 are 1, Y outputs A3.
module top_module(
    input  A0,
    input  A1,
    input  A2,
    input  A3,
    input  S0,
    input  S1,
    output Y
);
