Design a module to compare two 64-bit time values. The module outputs a signal indicating if the current time matches the trigger time, if the current time is later than the trigger time, or if it is earlier than the trigger time. Additionally, it has a constant output for "too_early" that is always low. When the current time is equal to the trigger time, the "now" output is high; if the current time exceeds the trigger time, the "late" output is high; and if neither condition is true, the "early" output indicates that the current time is earlier than the trigger time.
module top_module(input [63:0] time_now,input [63:0] trigger_time,output now,output early,output late,output too_early);
