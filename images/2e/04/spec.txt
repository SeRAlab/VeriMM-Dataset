Design an interrupt controller that manages multiple interrupt requests (IRQ). The controller should have the following features:
1. It should accept 4 interrupt requests (IRQ0 to IRQ3).
2. It should have an enable signal to allow and disable the interrupt requests.
3. When enabled, the controller should prioritize IRQ3 > IRQ2 > IRQ1 > IRQ0.
4. The controller should output the highest priority IRQ that is active as the interrupt signal (INT).
5. The controller should have a clear signal to reset the interrupt status.
