Design a 24-bit digital-to-analog converter (DAC) that takes a 24-bit binary input and outputs a corresponding analog value. The DAC output should be represented as a 32-bit integer where the least significant byte represents a portion of the analog output. The input is a 24-bit unsigned value ranging from 0 to 16,777,215 corresponding to an analog voltage level from 0V to 5V. The mapping from binary to analog voltage should be done using a simple scaling factor. The output should be the scaled integer representation.
