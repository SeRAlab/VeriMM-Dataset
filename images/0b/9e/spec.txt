Design a GPIO (General Purpose Input/Output) controller that can be configured to operate in two modes: input mode and output mode. The controller should have a 4-bit data bus, a mode select input, and an enable input. When in input mode, the controller reads the 4-bit data from the external pins. When in output mode, the controller drives the external pins with the 4-bit data provided to it. The output should be stored and held until the mode is switched or the enable signal is deactivated. Ensure that the data is valid only when the enable signal is high.
