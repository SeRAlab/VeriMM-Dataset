Design a clock divider that generates a lower frequency output clock signal from an input clock. The module takes a reset signal and an 8-bit divisor as inputs; upon receiving a positive edge of the input clock, it increments a counter. When the counter reaches the specified divisor value, it toggles the output clock signal and resets the counter. The reset signal allows for synchronous initialization of the output and counter.
module top_module(
  input clk_in,
  input rst,
  input [7:0] divisor,
  output reg clk_out
);
