Design a D latch with reset and enable functionality. When the reset (RST) input is LOW, the output (Q) is set to LOW, and the complementary output (Qbar) is set to HIGH. When reset is not active, if the enable (EN) signal is HIGH, the latch captures the value of the data input (D) and updates the output (Q) accordingly, while the complementary output (Qbar) is driven to the logical NOT of D. This module effectively serves as a memory element that allows storing a single bit with a reset feature.
module top_module(
    input D,
    input EN,
    input RST,
    output reg Q,
    output reg Qbar
);
