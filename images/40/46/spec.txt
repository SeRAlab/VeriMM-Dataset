Design a 1-bit SRAM cell with read and write functionalities. The SRAM cell should have inputs for data (D), a write enable signal (WE), and a read enable signal (RE). The output should be the stored data (Q). When WE is high, the data D should be written to the cell. When RE is high, the stored data should be available at output Q. If both RE and WE are low, the output Q should maintain its previous state.
