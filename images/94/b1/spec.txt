Implement a synchronous multiplier circuit that computes the product of two 16-bit inputs, `a` and `b`. The circuit has a clock and a reset signal; on each rising edge of the clock, if the reset is high, the output `p` is reset to zero. Otherwise, it calculates the product of `a` and `b` and stores the result in the output register `p`, which is also 16 bits wide.
module top_module(
  input clk,
  input reset,
  input [15:0] a,
  input [15:0] b,
  output reg [15:0] p
);
