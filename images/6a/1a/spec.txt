Design a simple 32-bit calculator that performs basic arithmetic operations based on a 2-bit selection input. The operations include addition (when sel=00), subtraction (when sel=01), multiplication (when sel=10), and integer division (when sel=11, with a safeguard against division by zero). The output, Z, reflects the result of the chosen operation on the inputs A and B.
module top_module(
    input [31:0] A,
    input [31:0] B,
    input [1:0] sel,
    output reg [31:0] Z
);
