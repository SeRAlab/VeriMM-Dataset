Design a circuit that operates as a conditional output selector based on the state of input B1. When B1 is high, the output Y is the logical AND of the four inputs A1, A2, A3, and A4. When B1 is low, the output Y is the logical OR of the same four inputs. This design effectively combines the functionalities of both an AND gate and an OR gate, dependent on the control signal B1.
module top_module(
    input A1,
    input A2,
    input A3,
    input A4,
    input B1,
    output Y
);
