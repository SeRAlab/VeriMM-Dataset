Design a Verilog module that models a 12-bit register with synchronous load and reset signals. The module should have an input clock signal (clk), an input load signal (ld), an input reset signal (rst), a 12-bit input data signal (d), and a 12-bit output signal (q). On the rising edge of the clock, if reset is high, q should be set to 0. If load is high, q should be set to the value of d.
module register_12bit (
  input clk,
  input ld,
  input rst,
  input [11:0] d,
  output reg [11:0] q);
