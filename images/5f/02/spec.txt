Implement a Verilog module for an 8-bit binary up/down counter with enable. The counter should increment when the up signal is high and decrement when the down signal is high, only if the enable signal is high. The counter should have a synchronous active-high reset that sets the counter to zero.

module up_down_counter_with_enable (
    input clk,
    input reset,
    input enable,
    input up,
    input down,
    output reg [7:0] count
);
