
Design a 4-bit DRAM cell that can store a 4-bit data value. The DRAM cell should have a write enable signal (we) to control when data should be written to the cell. On the rising edge of the clock, if the write enable signal is high, the data input should be stored in the cell. Otherwise, the stored value should remain unchanged. The DRAM cell should also have a read output that reflects the current stored value.
