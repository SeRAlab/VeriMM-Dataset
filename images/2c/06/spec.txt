Design a Verilog module that implements a simple switching regulator control logic. The module takes an input voltage (Vin), a reference voltage (Vref), and produces an output signal (Vout) that is either on or off based on the comparison between Vin and Vref. If Vin is greater than Vref, Vout should be 1 (on), otherwise Vout should be 0 (off).
