Design a module that checks the write protection status of different address sectors in an on-chip flash memory. It takes a 3-bit address input and signals whether the corresponding sector (from sector 1 to sector 5) is writable based on individual writable inputs for each sector. The output indicates if the address can be written to, which is determined by whether the input address matches a writable sector.
