Design a 4-bit asynchronous up counter with a reset functionality. The counter increments its value on each positive edge of the clock when the `slowena` signal is asserted and the current count is less than 9. If the count reaches 9, it resets back to 0. Additionally, if the `reset` signal is active, the counter is set to 0 regardless of the clock or enable state. The output `q` provides the current count value.
module top_module(
    input clk,
    input slowena,
    input reset,
    output [3:0] q);
