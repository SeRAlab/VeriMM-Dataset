Design a data integrity checker with a checksum mechanism. The design should take an 8-bit data input and a 4-bit checksum input. The module should compute the checksum of the incoming data and compare it with the provided checksum. If they match, the output `valid` should be set to 1; otherwise, it should be set to 0. The checksum is computed as the one's complement of the sum of the 8-bit data. The circuit should also include a reset signal that initializes the output.
