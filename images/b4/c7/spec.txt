Implement a memory management module that features a simple RAM-like array with an 8-entry depth, each 4 bits wide. The module can reset all memory entries to their index values on a reset signal. On each clock cycle, if the mode signal is high, the content of each memory location is incremented by one; if the mode signal is low, the memory entry at the provided address is set to zero. The output data corresponds directly to the memory content at the specified address, allowing for data retrieval based on the input address while offering basic read, write, and increment functionalities.
module top_module(clk, reset, mode, addr, data);
