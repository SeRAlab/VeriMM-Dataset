
Design a 4-channel Direct Memory Access (DMA) controller in Verilog. The DMA controller should have the following features:
- Four channels (Channel 0 to Channel 3).
- Each channel has a request line (req), an acknowledge line (ack), and a control signal (ctrl).
- The controller should grant access to the channel with the highest priority that has its request line active.
- Once a channel is granted access, it should hold the access until it is acknowledged.
- The controller should be capable of handling simultaneous requests from multiple channels.
