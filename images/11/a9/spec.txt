Design a JK latch using Verilog. The JK latch should have the following behavior:
- J input sets the latch when J = 1 and K = 0.
- K input resets the latch when J = 0 and K = 1.
- If both J and K are 1, the latch toggles its output.
- If both J and K are 0, the latch maintains its current state.
The latch also has a clock input and an asynchronous reset.
