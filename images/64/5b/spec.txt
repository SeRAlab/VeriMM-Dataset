Design a module that converts an 8-bit binary number into its Binary-Coded Decimal (BCD) representation. The input `num` can be either a hexadecimal or decimal representation, controlled by the `hex` input signal. If `hex` is true, the module takes the input as a hexadecimal value and calculates the BCD representation, dividing `num` by 16 for the high nibble and taking the remainder for the low nibble. If `hex` is false, it treats `num` as a decimal number, performing similar operations with division by 10 and its remainder. The output `bcd` is an 8-bit wide signal that holds the resulting BCD value.
module top_module(num, hex, bcd);
