Implement the Verilog module based on the following description.
Design an 8-bit register with synchronous reset and enable. The register should reset to 0 on the rising edge of the clock if the reset signal is high. If reset is low and the enable signal is high, the register should load the data_in value. If reset is low and the enable signal is low, the register should retain its current value.
module top_module(
    input clk,
    input reset,
    input enable,
    input [7:0] data_in,
    output reg [7:0] reg_out);
