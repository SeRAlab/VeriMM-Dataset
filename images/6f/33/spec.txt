   - 0110: 1111101 (6)

   - 1000: 1111111 (8)
   - 1001: 1101111 (9)
   - 1010: 1110111 (A)
   - 1011: 1111100 (b)
   - 1100: 0111001 (C)
   - 1101: 1011110 (d)
   - 1110: 1111001 (E)
   - 1111: 1110001 (F)

Write Verilog implementing this 7-segment display controller.
module seven_segment_controller (
        input [3:0] bin_in,
        output reg [6:0] seg_out);
