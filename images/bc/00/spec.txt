Design a 4-bit counter with both addition and subtraction capabilities. The counter increments when the mode input is high and decrements when the mode is low. It supports an asynchronous reset function to clear the counter and a load function to set the counter to a specific 4-bit value provided as input. The output, which reflects the current counter value, is updated on the rising edge of the clock.
module top_module(
    input clk,
    input reset,
    input load,
    input mode,
    input [3:0] data_in,
    output reg [3:0] result
);
