Design a combinational logic module that computes three different logic operations based on three input signals: `a`, `b`, and `c`. The module outputs the results as follows: `Z1` represents the logical AND operation between inputs `a` and `b`, `Z2` represents the logical OR operation between inputs `a` and `c`, and `Z3` represents the logical XOR operation between inputs `b` and `c`.
module top_module(
  input a,
  input b,
  input c,
  output reg Z1,
  output reg Z2,
  output reg Z3
);
