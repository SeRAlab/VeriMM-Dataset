Develop a simple 4-bit counter that counts from 0 to 9 with each pulse of the input clock signal. The counter's value is encoded and represented on a 7-segment display output, where the binary value of the counter correlates to the specific segment activations. When the counter exceeds 9, it resets back to 0. The design provides a visual representation of the count value in decimal format on a 7-segment display.
