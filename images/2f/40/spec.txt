Design a 16-bit SRAM cell with read and write functionality. The SRAM cell should have the following inputs: a 16-bit data input (`data_in`), a 16-bit data output (`data_out`), a write enable signal (`we`), and an address input (`addr`). The data should be written to the memory when `we` is high and read when `we` is low. The address should be a 4-bit input to address 16 memory locations.
