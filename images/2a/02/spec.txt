Design a Verilog module that implements a simple decision tree for binary classification. The decision tree will classify input features based on predefined thresholds. The module should take in three input signals (feature1, feature2, feature3) and output a single bit (classification output). The rules for classification are as follows:
1. If feature1 < 5, output 0.
2. If feature1 >= 5 and feature2 < 10, output 1.
3. If feature1 >= 5 and feature2 >= 10 and feature3 < 15, output 2.
4. If feature1 >= 5 and feature2 >= 10 and feature3 >= 15, output 3.
