

You are tasked with designing a verilog module that takes in two 8-bit inputs, A and B, and outputs a 16-bit result. The module should perform the following operation:

If the value of A is greater than or equal to the value of B, the output should be the sum of A and B. If the value of A is less than the value of B, the output should be the difference between B and A.

You should name your module "compare".
