Design an SR flip-flop in Verilog where S is the set input, R is the reset input, and Q is the output. The flip-flop should behave as follows: when S is high and R is low, Q should be set to high; when R is high and S is low, Q should be set to low; if both S and R are low, Q should maintain its previous state; if both S and R are high, the state is considered invalid and should not change. The code should also include a clock input to trigger the state changes.
