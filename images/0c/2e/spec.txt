
Create a decision tree module in Verilog that takes a 3-bit input and produces a 2-bit output based on the following conditions:
- If the input is 000, output 00
- If the input is 001 or 010, output 01
- If the input is 011 or 100, output 10
- If the input is 101, output 11
- If the input is 110 or 111, output 10
