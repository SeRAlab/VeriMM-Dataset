Design a temperature sensor that converts a 5-bit binary input representing temperature in Celsius (0 to 31) to a 3-bit output that indicates whether the temperature is low (000), medium (001), or high (010). The conditions for categorizing the output are: Low (0-10), Medium (11-20), High (21-31). If the input exceeds the defined range, the output should be set to an invalid state (111).
