
You are tasked with designing a module for a digital circuit that will take in a single data signal and output a single output signal. The module should also have a control signal that, when set, will force the output signal to a specific value. The module should be clocked and have power inputs for both voltage and ground.

Your task is to write a Verilog module that implements this functionality. The module should have the following inputs and outputs:

Inputs:
- D: a single-bit data signal
- SET_B: a single-bit control signal
- CLK: a clock signal
- VPWR: a voltage input
- VGND: a ground input

Outputs:
- Q: a single-bit output signal

The module should function as follows:
- When SET_B is set to 1, Q should be forced to 1.
- When SET_B is set to 0, Q should follow the value of D on the rising edge of CLK.

Write the Verilog code for this module.
