Design a Verilog module to calculate the following. Assume positive clock/clk edge triggering unless otherwise specified.
You have a twenty-bit input vector in[19:0]. Compute the following:
// (1) out_xor_wrap: Each bit of this output vector should indicate the XOR between the corresponding input bit and its neighbour to the right. For example, out_xor_wrap[5] should be the XOR of in[5] and in[4]. For this part, treat the vector as wrapping around, so in[0]'s neighbour to the right is in[19].
// (2) out_nor: Each bit of this output vector should indicate the logical NOR between the corresponding input bit and its neighbour to the left. For example, out_nor[13] should be the NOR of in[13] and in[14]. Since in[19] has no neighbour to the left, out_nor[19] is not needed.
// (3) out_and: Each bit of this output vector should indicate the logical AND between the corresponding input bit and its neighbour to the right. For example, out_and[8] should be the AND of in[8] and in[7]. Since in[0] has no neighbour to the right, out_and[0] is not needed.
