4. state Q3 (out1=1, out2=1).

1. From state Q0: If clk = 0, then transition to state Q1. If clk = 1, then transition to state Q2.

3. From state Q2: If clk = 0, then transition to state Q0. If clk = 1, then transition to state Q3.
4. From state Q3: If clk = 0, then transition to state Q2. If clk = 1, then transition to state Q1.

At reset, the state machine starts in state "Q0". Derive next-state logic equations and output logic equations by inspection assuming the following one-hot encoding is used: (Q0, Q1, Q2, Q3) = (4'b0001, 4'b0010, 4'b0100, 4'b1000)

Derive state transition and output logic equations by inspection assuming a one-hot encoding. Implement only the state transition logic and output logic (the combinational logic portion) for this state machine.

Write code that generates the following equations:

- Q0_next -- next-state logic for state Q0

- Q2_next
- Q3_next
- out1 -- output logic
- out2
