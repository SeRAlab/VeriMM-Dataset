
Design a combinational logic circuit in Verilog that performs matrix inversion for a 2x2 matrix. The input to the circuit will be a 2x2 matrix represented as four 8-bit inputs, and the output should be the inverted 2x2 matrix, also represented as four 8-bit outputs. The matrix inversion formula for a 2x2 matrix is given by:

If the matrix is:
```
| a  b |
| c  d |
```
The inverted matrix is:
```
|  d/(ad-bc)  -b/(ad-bc) |
| -c/(ad-bc)   a/(ad-bc) |
```
Assume that the determinant (ad - bc) is non-zero for all inputs.
