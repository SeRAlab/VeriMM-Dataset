

You are tasked with designing a module that implements a register with a single bit of storage. The module should have four inputs and one output. The inputs are:
- `clk`: a clock signal that runs the module
- `rst`: a reset signal that sets the output to 0
- `flush`: a signal that clears the output to 0
- `LLbit_i`: a single-bit input that is written to the register when `we` is high
- `we`: a write-enable signal that indicates when `LLbit_i` should be written to the register

The output of the module is a single bit `LLbit_o`, which is the value stored in the register.

The module should have the following behavior:
- When `rst` is high, the output should be 0.
- When `flush` is high, the output should be cleared to 0.
- When `we` is high, the input `LLbit_i` should be written to the register.
- The output should always reflect the value stored in the register.

Write a Verilog module that implements this behavior. Your module should be self-contained and should not require any external modules or libraries. Your module should be no more than 200 lines of Verilog code.
