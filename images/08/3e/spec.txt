
Design a 16-bit ADC (Analog to Digital Converter) output processor that takes a 16-bit binary input representing the digital value from the ADC and produces two outputs: 
1. A 4-bit binary number representing the upper 4 bits of the input (most significant bits).
2. A 4-bit binary number representing the lower 4 bits of the input (least significant bits).
The module should be designed such that it processes the input and outputs the corresponding upper and lower bits simultaneously.
