
Design a fan speed control system that adjusts the fan speed based on the temperature input. The system should have the following characteristics:
1. A 3-bit temperature input (T[2:0]) representing temperatures from 0 to 7 degrees Celsius.
2. The fan speed is controlled with a 2-bit output (F[1:0]):
   - If T <= 2, F = 00 (Fan Off)
   - If 3 <= T <= 5, F = 01 (Low Speed)
   - If 6 <= T <= 7, F = 10 (High Speed)
3. The system should have a clock (clk) and reset (rst) inputs. The fan speed output should update on the rising edge of the clock.
