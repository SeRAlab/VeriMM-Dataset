
Design a Verilog module for a 4-bit Flash memory cell that supports read, write, and erase operations. The module should have the following ports:
- `input [3:0] data_in`: Data to be written to the memory cell.
- `input write_enable`: Signal to enable writing.
- `input erase_enable`: Signal to enable erasing.
- `input read_enable`: Signal to enable reading.
- `output reg [3:0] data_out`: Data read from the memory cell.
The memory cell should retain the data unless erased or overwritten. If both write and erase signals are high, the write operation should take priority.
