Design a timer module that handles a 32-bit counter and a mask for expiration. The counter increments with each clock cycle unless reset, and its value can be loaded from a bus when a write enable signal is active at a specific address. The mask value can also be programmed via the bus. The module outputs a signal indicating whether the counter has met or exceeded the mask threshold, and it can read the current counter and mask values over the bus based on the specified address.
