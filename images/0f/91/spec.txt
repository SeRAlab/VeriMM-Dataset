
Design a reset controller that manages the reset state of a system. The reset controller should have the following functionalities:
- It should have a reset input signal (reset_n) that is active low.
- When reset_n is low, the output (reset_out) should be asserted high, indicating that the system is in a reset state.
- When reset_n transitions from low to high, the output should remain high for a fixed number of clock cycles before deasserting the reset (reset_out) signal to low.
- The number of clock cycles for which the reset should be held can be configured via a parameter (CYCLES).
