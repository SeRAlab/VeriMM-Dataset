Design a 4-bit binary counter with synchronous reset functionality. On each rising edge of the clock, if the reset signal is high, the counter resets to zero. Otherwise, it increments the count until it reaches its maximum value of 15 (4'b1111), at which point it wraps around back to zero. This module effectively tracks the number of clock cycles, providing a count from 0 to 15 in a continuous loop.

  input clk,
