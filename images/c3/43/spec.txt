

You are tasked with designing a verilog module for a 4-bit multiplier. The module should have the following inputs and outputs:

Inputs:
- `clk` (1-bit): the clock signal
- `a` (4-bit): the first operand
- `b` (4-bit): the second operand

Outputs:
- `result` (8-bit): the result of multiplying `a` and `b`

The module should use registers to store the intermediate values, and should only update the output on the rising edge of the clock signal.

Write the verilog code for the multiplier module.
