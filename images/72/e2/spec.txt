Design a circuit that functions as a 4-line to 1-line merger. The module takes four individual (1-bit) input lines (BUS0, BUS1, BUS2, BUS3) and concatenates them to create a single 4-bit output (BUS), with BUS0 assigned to the least significant bit and BUS3 assigned to the most significant bit.
module top_module(input wire BUS0, input wire BUS1, input wire BUS2, input wire BUS3, output wire [3:0] BUS);
