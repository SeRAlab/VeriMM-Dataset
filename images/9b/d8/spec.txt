Design a 4-to-1 multiplexer that takes four 8-bit inputs and selects one of them as the output based on two selection signals, sel1 and sel2. The module outputs data_in_0 when sel1 and sel2 are both 0, data_in_1 when sel1 is 0 and sel2 is 1, data_in_2 when sel1 is 1 and sel2 is 0, and data_in_3 when both sel1 and sel2 are 1.
module top_module(
    input [7:0] data_in_0,
    input [7:0] data_in_1,
    input [7:0] data_in_2,
    input [7:0] data_in_3,
    input sel1,
    input sel2,
    output reg [7:0] data_out
);
