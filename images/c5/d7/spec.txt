- Input: a 4-bit unsigned binary number named "in"

- Output: a 4-bit unsigned binary number named "out"

You should use the provided code snippet as a reference for how to declare and initialize the input and output ports.

Your module should use the bitwise negation operator to calculate the 1's complement of the input number. You should then assign the result to the output port.

Your module should also include an initial block that tests your module by setting the input port to a value of 5 (binary 0101) and displaying the output value using the $display function.
