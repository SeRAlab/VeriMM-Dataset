
Design a Verilog module that converts RGB color values to YUV color values. The module should take 8-bit RGB components (R, G, B) as inputs and output 8-bit Y, U, and V components. The conversion formulas are as follows:
- Y = 0.299 * R + 0.587 * G + 0.114 * B
- U = -0.14713 * R - 0.28886 * G + 0.436 * B + 128
- V = 0.615 * R - 0.51499 * G - 0.10001 * B + 128
