Design a D flip-flop with an asynchronous active-low set input. When the clock (CLK) rises, the output Q takes the value of D, and the complementary output Q_N is the inverse of D. If the asynchronous set input (SET_B) is low, it overrides the clock signal and sets Q to HIGH and Q_N to LOW, regardless of the clock or D input. This ensures that the flip-flop can be set immediately without waiting for a clock edge.
