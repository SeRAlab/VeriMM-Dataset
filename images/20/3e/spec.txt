Design a simple elliptic curve point doubling operation in Verilog. The operation should take a point (x, y) on the curve and return the doubled point (x', y') according to the ECC point doubling formula:  
x' = (s^2 - 2x) mod p  
y' = (s(x - x') - y) mod p  
where s = (3x^2 + a) / (2y) mod p.  
Assume the curve parameters (a, p) are given as constants, and that the inputs will be valid points on the curve for the sake of this exercise.
