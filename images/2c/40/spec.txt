Design a noise suppression circuit using a finite state machine (FSM). The circuit takes a noisy digital input signal and produces a clean output signal by filtering out rapid fluctuations. The state machine should have two states: IDLE (0) and ACTIVE (1). When the input signal is stable (i.e., it remains the same for a certain number of clock cycles), the output should reflect the stable input. If the input fluctuates, the output should hold the last stable value.
