During a reset, the module initializes the digital output and internal sampled values to zero. The conversion process involves shifting the sampled analog input to align with the defined output bit-width, allowing it to produce a digital representation of the signal.
module top_module(
  input analog_in,
  input clk,
  input rst,
  output reg [bits-1:0] digital_out
);
