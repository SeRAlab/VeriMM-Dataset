    binary_counter

Input ports:
    CLK: Clock input
    RST: Active high reset signal

Output ports:
    COUNT: 4-bit output representing the current counter value

Implementation:
The binary counter module uses an always block to update the value of the counter based on the clock signal and reset signal.
The always block triggers on the positive edge of the clock signal (posedge CLK) or the positive edge of the reset signal (posedge RST). It checks if the reset signal is active (RST) and sets the counter value (COUNT) to 0. If the counter value is 15, it wraps around and sets the counter value to 0. Otherwise, it increments the counter value by 1.

Give me the complete code.
