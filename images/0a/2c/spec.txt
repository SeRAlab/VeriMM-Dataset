
Design a 4-bit shift register with synchronous load and shift capabilities. The register should have the following features:
1. A 4-bit wide output.
2. A load input that, when high, loads a new 4-bit value into the register.
3. A shift input that, when high, shifts the contents of the register to the right by one bit.
4. A reset input that asynchronously resets the register to zero.
