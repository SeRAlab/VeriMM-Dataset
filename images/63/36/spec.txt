Design a 32-bit shifter module that performs various types of bit shifts based on the specified shift type. The module accepts a 32-bit input value, a 5-bit shift amount to determine how many positions to shift, and a 2-bit selector for the shift type—left logical shift, right logical shift, or right arithmetic shift. The output is the result of the shift operation applied to the input, effectively enabling flexible manipulation of the bit representation of the input data.
module top_module(
  input [31:0] in,
  input [4:0] shift_amount,
  input [1:0] shift_type,
  output reg [31:0] out
);
