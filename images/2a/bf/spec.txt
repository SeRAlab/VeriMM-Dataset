Design a simple combinational logic circuit that implements a decision tree based on three binary inputs (A, B, C). The output Y should be determined by the following rules:  
1. If A is 1 and B is 0, then Y = 1.  
2. If A is 0 and B is 1, then Y = 0 if C is 0, otherwise Y = 1.  
3. If A is 0 and B is 0, then Y = 0.  
4. In all other cases, Y = 1.  
The goal is to implement this logic in Verilog.
