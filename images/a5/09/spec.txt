Please act as a professional verilog designer.

Create a Verilog module for an 8-bit synchronous up/down counter with an enable signal and a direction signal. The counter increments when the direction signal is high and decrements when it is low. It also includes a reset signal to set the counter to zero.

Module name:  
    counter_updown  

Input ports:
    clk: Chip clock signal.
    rst_n: Active-low reset signal. Defined as 0 for chip reset and 1 for reset signal inactive.
    en: Enable signal for the counter.
    dir: Direction signal for counting. High for up, low for down.

Output ports:
    q: Counter output signal with a data width of 8 bits.

Implementation:
Counter operation:
On every positive edge of the clock signal (clk) or the falling edge of the reset signal (rst_n), the counter register (q) is updated.
If the reset signal (rst_n) is low, indicating a reset condition, the counter register (q) is set to 0.
If the enable signal (en) is active, the counter increments if the direction signal (dir) is high and decrements if the direction signal (dir) is low.
If the enable signal (en) is inactive, the counter remains unchanged.
