Design a Verilog module for a Flash memory cell which stores a single bit of data. The module should have the ability to program (set the bit to 1), erase (set the bit to 0), and read the current state of the cell. The inputs to the module will be 'program', 'erase', and 'clk', while the output will be the stored data 'data_out'. The module should ensure that the erase operation takes precedence over the program operation if both are triggered simultaneously.
