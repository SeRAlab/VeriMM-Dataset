
Design a convolutional encoder with a constraint length of 3 and a rate of 1/2. The encoder should take a single input bit and produce two output bits. Use the following connection and polynomial:
- The first output bit is generated by the XOR of the input bit and the previous two bits of the input (shift register).
- The second output bit is generated by the XOR of the input bit and the previous bit of the input (shift register).
