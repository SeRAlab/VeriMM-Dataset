Design a register that captures the input signal S on each positive clock edge when enabled, and maintains an 8-bit shift register (denoted by q) to store the last 8 values of S. The output Z is a single bit derived from the register, selected using a 3-bit input formed by the combination of inputs A, B, and C, which serves as an address to access the corresponding bit in the shift register.
module top_module(
	input clk,
	input enable,
	input S,
	
	input A, B, C,
	output reg Z
);
