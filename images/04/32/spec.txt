Design a Verilog module that implements a simple RRT logic. The module will take a 5-bit input representing a random point in a 5-dimensional space (x, y, z, a, b) and output a 5-bit line which is the nearest point in the space. Assume the nearest point is calculated based on the minimum Manhattan distance to a predefined set of points stored in memory. The memory contains 5 fixed points in the 5D space.
