
Design a Verilog module that performs a Gaussian blur on a 3x3 pixel input image. The input is a 3x3 grid of pixel values (each pixel is 8 bits), and the output is a single pixel value that represents the blurred version of the center pixel using a Gaussian kernel. The Gaussian kernel can be represented as follows:
```
1  2  1
2  4  2
1  2  1
```
The output pixel value should be calculated as the weighted sum divided by 16 (the sum of the weights in the kernel).
