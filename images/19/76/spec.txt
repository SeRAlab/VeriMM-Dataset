Design an 8-bit SRAM cell with read and write operations. The cell should have an 8-bit data input, an 8-bit data output, a write enable signal, a chip enable signal, and a read enable signal. On the rising edge of the clock, if the chip is enabled and the write enable signal is high, the data input should be stored in the cell. If the chip is enabled and the read enable signal is high, the data stored in the cell should be outputted.
