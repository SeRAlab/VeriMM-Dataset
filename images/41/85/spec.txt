Implement the Verilog module based on the following description.
Design a Verilog module that implements an 8-bit binary up-counter with enable and asynchronous reset. The counter should increment on the rising edge of the clock if the "enable" signal is high. The counter should reset to 0 when the asynchronous reset (areset) is high. The counter value should be output to the "count" signal.

module top_module
(
    input clk,
    input areset,
    input enable,
    output reg [7:0] count
);
