Design a RAM module that allows for bidirectional data transfer. The module has a memory size of 2048 bytes and operates with 8-bit wide data. It supports both read and write operations controlled by the RWSelect signal and is activated by the _Enable signal. When writing, data is stored in the memory array on the negative edge of the write clock (WClock) if the module is enabled. For reading, data is retrieved from the memory on the negative edge of the read clock (RClock) when enabled, and it outputs the retrieved data onto the Data line based on the RWSelect signal. If RWSelect is high, the output is driven by the Data buffer; otherwise, the Data line is tri-stated.
