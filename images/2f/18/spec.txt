
Design a 2nd-order Infinite Impulse Response (IIR) filter. The filter should have a feedback structure where the output is a combination of the previous outputs and the current input. The filter coefficients are defined as follows: 
- b0 = 0.2 (feedforward coefficient)
- b1 = 0.3 (feedforward coefficient)
- b2 = 0.5 (feedforward coefficient)
- a1 = 0.4 (feedback coefficient)
- a2 = 0.6 (feedback coefficient)

The filter has a clock input, reset input, and a data input. The output should be computed on the rising edge of the clock signal.
