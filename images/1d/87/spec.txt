Design a Verilog module that implements a simple RNN cell for inference. The RNN cell should take an input vector and a hidden state vector, and output a new hidden state vector. The input and hidden state vectors will be of fixed size, for example, 4 bits. The update rule can be defined as follows: new_hidden = tanh(W_hh * hidden + W_xh * input + b), where W_hh and W_xh are weight matrices (for simplicity, we can use hardcoded values), and b is a bias vector (also hardcoded).
