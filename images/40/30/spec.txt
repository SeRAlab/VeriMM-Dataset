Design an 8-to-1 multiplexer (MUX) in Verilog. The multiplexer should have 8 data inputs (D0 to D7), 3 select inputs (S0, S1, S2), and 1 output (Y). The output Y should be the value of the selected data input based on the values of the select inputs. Implement this logic using a structural approach and ensure that the code is well-structured for synthesis.
