Design a combinational logic circuit that generates an output X based on the inputs A, B, C, and D. The output is set to 1 if A is true and B is false. If that condition is not met, X is set to 0 if C is true and D is false. In all other cases, X reflects a logical OR among all four inputs, resulting in a 1 if at least one input is true, or a 0 if all are false.
module top_module(
    input A,
    input B,
    input C,
    input D,
    output reg X
);
