
Design a simple neural network layer with backpropagation. The layer should take 3 inputs (X1, X2, X3), each represented as 4-bit signed integers, and output a single 4-bit signed integer representing the output of the neuron's activation function. The weights for the inputs will be initialized at the beginning of the simulation and will be updated using a fixed learning rate during backpropagation after each input is processed. The initial weights W1, W2, and W3 should be represented as 4-bit signed integers. The activation function is a simple linear function with no threshold. Implement the weight update rule: W_new = W_old + learning_rate * error * input.
