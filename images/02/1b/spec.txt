
Design a CRC-8 generator that computes the CRC for an 8-bit input data using a polynomial of x^8 + x^7 + x^4 + x^3 + x^2 + 1 (0x5D). The circuit should be capable of processing the input data serially, producing the CRC output after all bits have been processed. The output should be valid after the last bit of input is received.
