
Design a Verilog module that implements a simple flash memory cell. The memory cell should have the following functionality:
- It should be capable of storing a single bit (0 or 1).
- It should have two inputs: a data input (D) and a control input (C).
- When the control input (C) is high, the data input (D) should be written to the memory cell.
- When the control input (C) is low, the memory cell should retain its current value.
- The current value of the memory cell should be output as Q.
