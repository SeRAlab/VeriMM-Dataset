Design a simple alarm system that monitors an 8-bit sensor input. On each clock cycle, it captures the state of the sensors, and if any sensor is triggered (i.e., any bit in the sensor input is high), it activates the alarm output. The system can be reset using the reset input, which clears the sensor state and deactivates the alarm. This design serves to indicate any intrusion or event detected by the sensors through an alarm signal.
module top_module(
    input wire [7:0] sensor_bus,
    input wire reset,
    input wire clk,
    output reg alarm
);
