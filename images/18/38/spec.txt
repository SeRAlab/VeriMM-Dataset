Design a packet filtering module for a simple firewall. The module should take three 8-bit inputs: `src_ip`, `dest_ip`, and `protocol`. It should output `allow`, which is a single bit that indicates whether the packet is allowed (1) or blocked (0). The firewall should allow packets if they meet the following criteria: the source IP is `192.168.1.1` and the destination IP is `192.168.1.2` for protocol `TCP` (protocol value `6`), or the source IP is `10.0.0.1` and the destination IP is `10.0.0.2` for protocol `UDP` (protocol value `17`).
