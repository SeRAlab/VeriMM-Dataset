Design a fan speed control system that adjusts the speed based on temperature readings. The fan has three speed settings: low, medium, and high. The system should take a 4-bit temperature input (0-15) and adjust the fan speed according to the following rules:
- Speed 0 (off) for temperature 0-4
- Speed 1 (low) for temperature 5-9
- Speed 2 (medium) for temperature 10-13
- Speed 3 (high) for temperature 14-15
The output should be a 2-bit speed setting.
