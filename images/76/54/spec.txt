Implement a Verilog module for a 5-bit Johnson counter with synchronous reset. The counter should generate a 5-bit output sequence by shifting its bits to the left, with the inverted value of the last bit fed back into the first bit. When reset is high, the counter should reset to 0.

Write the Verilog code for the Johnson counter module with the following signals:
- clk: clock signal
- reset: synchronous reset signal
- q: 5-bit output

module johnson_counter(
    input clk,
    input reset,
    output reg [4:0] q
);
