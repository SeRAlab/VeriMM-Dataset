Design a 4-to-1 multiplexer that selects one of four 8-bit input signals (A, B, C, or D) based on a 2-bit selection signal (S). When S is 00, the output Y is assigned the value of A; when S is 01, Y takes the value of B; for S equal to 10, Y outputs C; and when S is 11, Y outputs D.
module top_module(
        input [1:0] S,
        input [7:0] A, B, C, D,
        output reg [7:0] Y
);
