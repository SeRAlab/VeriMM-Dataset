
Design a simple Kalman filter in Verilog for sensor fusion that estimates the state of a moving object based on noisy position measurements. The Kalman filter should take in the current state estimate, the measurement, and the associated uncertainties, and output the updated state estimate. The filter will utilize the following parameters:
- State (x): 16-bit unsigned integer
- Measurement (z): 16-bit unsigned integer
- Process noise covariance (Q): 16-bit unsigned integer
- Measurement noise covariance (R): 16-bit unsigned integer

The filter should implement the update equations:
1. Compute the Kalman Gain (K)
2. Update the estimate with the new measurement
3. Update the error covariance
