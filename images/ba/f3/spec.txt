Design a synchronous four-bit adder that computes the sum of two 4-bit binary inputs, A and B, along with a carry-in (Cin) signal. On each rising edge of the clock (CLK), the module calculates the sum, assigns the lower four bits to the output S, and outputs the carry-out (Cout) from the fifth bit of the sum. This module is useful for arithmetic operations in digital circuits requiring binary addition with carry handling.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    input CLK,
    output reg [3:0] S,
    output reg Cout
);
