Design a 16-bit SRAM cell that can read and write data. The SRAM cell should have the following inputs: a 16-bit data input (data_in), a write enable signal (we), and a clock signal (clk). It should also have a 16-bit data output (data_out). On the rising edge of clk, if we is high, the SRAM cell should store the data from data_in. If we is low, the SRAM cell should output the stored data on data_out.
