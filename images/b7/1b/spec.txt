Design a 4-bit binary counter that increments its value on each clock cycle. The counter has a load functionality, allowing it to be reset to zero or to load a specific 4-bit input value when the load signal is high. Upon a reset signal, the counter is initialized to zero. In each clock cycle, if the load signal is not asserted, the counter increments its current value by one. The current count is output as a 4-bit register.
module top_module(
    input clk,
    input reset,
    input load,
    input [3:0] data_in,
    output reg [3:0] count
);
