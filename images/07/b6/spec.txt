
Design a 1-bit DRAM cell that can store a single bit of data. The cell should have the following functionality:
1. It should accept a data input (`data_in`) and a write enable (`wr_en`) signal. When `wr_en` is high, the `data_in` value should be stored in the cell.
2. It should have a read enable (`rd_en`) signal. When `rd_en` is high, the stored data should be output on `data_out`.
3. The cell should retain its value until a new value is written.
