Design an 8-to-1 multiplexer that selects one of eight 16-bit input signals (a, b, c, d, e, f, g, h) based on a 3-bit selection input (sel). The output (o) corresponds to the selected input, where each combination of sel's bits determines which of the eight inputs is routed to the output.
module top_module(
    input [15:0] a,
    input [15:0] b,
    input [15:0] c,
    input [15:0] d,
    input [15:0] e,
    input [15:0] f,
    input [15:0] g,
    input [15:0] h,
    input [2:0] sel,
    output [15:0] o
    );
