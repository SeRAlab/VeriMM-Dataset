Design an 8-bit DRAM cell that can store a value and allow read and write operations. The DRAM cell will have the following inputs: a clock signal (clk), a write enable signal (we), an 8-bit data input (data_in), and a 3-bit address input (addr). The outputs will be the 8-bit data output (data_out) which reflects the stored value at the specified address, defaulting to zero if no write has been made to that address.
