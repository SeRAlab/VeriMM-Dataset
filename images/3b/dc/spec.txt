Design a simple Verilog module that implements a shift register with a width of 4 bits. The shift register should have a serial input and a clock input, where on each rising edge of the clock, the current data in the register shifts left, and the new bit from the serial input is added to the least significant bit (LSB). The register should also have an enable input to allow shifting only when enabled. The output should be the current value of the shift register.
