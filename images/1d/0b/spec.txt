
Design an 8-bit Linear Feedback Shift Register (LFSR) that generates pseudo-random numbers. The LFSR should use the polynomial x^8 + x^6 + x^5 + x^4 + 1 (meaning tap bits 8, 6, 5, and 4). The LFSR should be able to reset to a specific seed value and should have an enable input to start the shifting process. The output should be the current state of the LFSR.
