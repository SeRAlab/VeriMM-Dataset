Design a 4-bit shift register with parallel load capability. Upon each rising edge of the clock, the register shifts its contents right by one bit, while the most significant bit (reg1) can be loaded with a new 4-bit input when parallel_load is asserted. The output (out) represents the value of the least significant bit (reg4) after the shift operation, enabling data shifting and parallel input functionality.
module top_module(
    input clk,
    input parallel_load,
    input [3:0] in,
    output reg out
);
