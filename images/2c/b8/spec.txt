
Design a fan speed control system that adjusts the speed of a fan based on temperature readings. The system has a 3-bit input representing the temperature (0 to 7 degrees) and a 2-bit output representing the fan speed (00 for off, 01 for low, 10 for medium, 11 for high). 
- If the temperature is between 0 and 2 degrees, the fan speed should be off.
- If the temperature is between 3 and 4 degrees, the fan speed should be low.
- If the temperature is between 5 and 6 degrees, the fan speed should be medium.
- If the temperature is 7 degrees, the fan speed should be high.
