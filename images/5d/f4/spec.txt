Design a 3-to-1 multiplexer that selects one of three single-bit inputs based on a 2-bit selection signal. When the selection signal (`sel`) is 0, the output (`out`) will be equal to `in0`; when `sel` is 1, `out` will equal `in1`; when `sel` is 2, `out` will be `in2`. If an invalid selection is made, the output defaults to LOW.
module top_module(
    input [1:0] sel,
    input in0,
    input in1,
    input in2,
    output out
);
