Design a clock gating circuit that generates an enable clock output (ENCLK) based on control inputs. The module uses the input CLK to update a gated clock signal (gated_clk) at each positive edge of CLK. If the enable (EN) signal is HIGH and the test enable (TE) signal is LOW, gated_clk is set to HIGH; otherwise, it is set to LOW. This gated clock is then fed into a latch, allowing the clock signal to be enabled or disabled conditionally, thereby reducing power consumption by preventing the clock from propagating to other circuit elements when not needed.
