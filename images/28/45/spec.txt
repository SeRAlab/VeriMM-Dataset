Design an RNN inference module in Verilog that takes a sequence of 4 input values of fixed point representation (8 bits), processes them through a simple RNN cell with 8-bit weights, and produces an output value. The RNN cell will use a simple activation function (like tanh) implemented as a combinational function for this inference. The module should have a clock input, a reset input, an enable input, and a valid output signal to indicate when the output is ready. The state of the RNN should be updated on the clock edge and should hold its state until reset or a new input sequence is applied.
