Design a Verilog module that implements a simple SRT (Sweeney, Robertson, and Tocher) divider. The module should take a 16-bit dividend and a 16-bit divisor as inputs and output a 16-bit quotient and a 16-bit remainder. The SRT division algorithm should be implemented in a way that it can handle cases where the divisor is zero, in which case the module should output all zeros for the quotient and remainder.
