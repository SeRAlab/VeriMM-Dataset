

You are tasked with designing a Verilog module for a D flip-flop with asynchronous reset functionality. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock input
- `reset`: an asynchronous active-low reset input
- `d`: the data input

Outputs:
- `q`: the output of the flip-flop

The flip-flop should be sensitive to the rising edge of the clock input. When the reset input is asserted, the output `q` should be set to 0. Otherwise, the output `q` should follow the input `d`. 

Write a Verilog module that implements this functionality. Your module should be named `dff_async_reset` and should be contained within 200 lines of code.
