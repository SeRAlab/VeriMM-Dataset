Implement the Verilog module based on the following description.
Design a 32-bit register with synchronous reset and load enable. The register should reset to 0 on the rising edge of the clock if the reset signal is high. If reset is low and load_enable is high, the register should load the data_in value. If reset is low and load_enable is low, the register should retain its current value.
module top_module(
    input clk,
    input reset,
    input load_enable,
    input [31:0] data_in,
    output reg [31:0] reg_out);
