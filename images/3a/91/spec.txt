
Design a 2nd order Infinite Impulse Response (IIR) filter module in Verilog. The IIR filter should have two registers for state feedback and a single input data sample. The output should be computed based on the formula:
Y[n] = a1 * Y[n-1] + a2 * Y[n-2] + b0 * X[n] + b1 * X[n-1]
where Y[n] is the current output, X[n] is the current input, and a1, a2, b0, b1 are filter coefficients that you can set as parameters in your module.
