
Design a 2-channel DMA (Direct Memory Access) controller in Verilog. The controller should have the following specifications:
- Two channels for data transfer.
- Each channel can be independently enabled or disabled.
- A signal to indicate when a transfer is complete for each channel.
- A register to hold the address of the next data to transfer for each channel.
- A clock input to synchronize the operation.

The controller should have the following inputs and outputs:
Inputs:
- clk: Clock signal
- reset: Active high reset signal
- channel0_enable: Enable signal for channel 0
- channel1_enable: Enable signal for channel 1
- channel0_address: Address register for channel 0
- channel1_address: Address register for channel 1

Outputs:
- channel0_done: Signal indicating transfer completion for channel 0
- channel1_done: Signal indicating transfer completion for channel 1
