Design a simple memory module that operates on a 2-bit address space and supports data writing and reading. When the chip is selected, and the write signal is active low, it stores the least significant byte of the provided 32-bit write data into a designated memory location (address 0). The output port reflects the stored byte immediately upon a clock's rising edge, and the read data output is a concatenation of 32 bits, where the most significant 24 bits are zeroed. The module includes asynchronous reset functionality to initialize the memory content to zero.
module top_module(
  input [1:0] address,
  input chipselect,
  input clk,
  input reset_n,
  input write_n,
  input [31:0] writedata,
  output reg [7:0] out_port,
  output reg [31:0] readdata
);
