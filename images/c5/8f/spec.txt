

Your task is to design a verilog module that implements a 4-bit binary counter. The counter should have a synchronous reset, and should increment on every positive edge of the clock signal. The module should have the following ports:

- `clk`: input clock signal
- `reset`: input synchronous reset signal
- `out`: output 4-bit binary counter value

Your module should be named `binary_counter` and should be implemented within 200 lines of verilog code.

Assume that the input clock signal has a frequency of 50 MHz, and that the reset signal is active-high.
