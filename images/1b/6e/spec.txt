Design a 4-channel DMA (Direct Memory Access) controller that can transfer data between memory and peripherals without CPU intervention. The controller should have control signals for each channel and a state machine to manage data transfer requests. The controller should include a request input for each channel, a grant output for each channel, a busy signal to indicate when a transfer is occurring, and an input data bus and output data bus for data transfer. The controller should operate on a clock signal and have a reset signal to initialize the state machine.
