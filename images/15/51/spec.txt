Design a simple SD card controller that can read and write data blocks. The controller should have a clock input, a reset input, a read request input, a write request input, and a data bus for input and output. When a read request is asserted, the output should provide the data from a specified block after a delay of one clock cycle. When a write request is asserted, the input data should be stored in the specified block. The controller should handle up to 4 blocks of data (each block is 8 bits). The block addresses should be given as 2-bit inputs.
