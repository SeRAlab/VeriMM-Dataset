
Design a Verilog module that evaluates a polynomial of the form 
P(x) = a_n*x^n + a_(n-1)*x^(n-1) + ... + a_1*x + a_0 
where the coefficients a_n, a_(n-1), ..., a_1, a_0 are provided as inputs and x is the input variable. The module should take 5 coefficients (a4, a3, a2, a1, a0) and an input value x, then compute the polynomial value P(x).
