Design a digital phase shifter that takes a 3-bit input representing a phase shift value (0 to 7) and outputs a 3-bit representation of the corresponding shifted value. The phase shifter should map the input directly to an output based on a specific phase shift pattern defined as follows:
- Input 0 -> Output 0
- Input 1 -> Output 2
- Input 2 -> Output 4
- Input 3 -> Output 6
- Input 4 -> Output 1
- Input 5 -> Output 3
- Input 6 -> Output 5
- Input 7 -> Output 7
