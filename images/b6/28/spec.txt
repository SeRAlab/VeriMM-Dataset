Design a three-input AND gate with one of the inputs being active-low. The module outputs a HIGH signal (X) only when the active-low input (A_N) is HIGH, and both other inputs (B and C) are also HIGH. This circuit is suitable for applications requiring controlled AND logic where one input must be inverted before evaluation.
module top_module(
    input  wire        A_N,
    input  wire        B,
    input  wire        C,
    input  wire        VPWR,
    input  wire        VGND,
    input  wire        VPB,
    input  wire        VNB,
    output reg         X
);
