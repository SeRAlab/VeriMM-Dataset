Design a 2-to-4 line decoder with an enable input. When the enable signal (EN) is asserted, the module decodes the 2-bit input combination formed by A and B into one of the four output lines (Y), setting the corresponding output line high (active) based on the input values. If the enable signal is deasserted, all output lines are set to low. This design is useful for applications requiring controlled activation of specific outputs based on binary input values.
module top_module(
    input A,
    input B,
    input EN,
    input clk,          // Added input for clock signal
    output reg [3:0] Y
);
