Design a PID controller in Verilog that takes an error input and produces a control output. The controller should have three parameters: proportional gain (Kp), integral gain (Ki), and derivative gain (Kd). The output should be updated on each clock cycle based on the current error, the accumulated integral of the error, and the change in error from the previous cycle. Ensure that the PID control output is appropriately constrained within a defined range.
