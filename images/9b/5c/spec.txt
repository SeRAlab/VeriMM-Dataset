Design a synchronous 4-bit binary counter with a reset function. On each positive edge of the clock, the counter increments its value. When the reset signal is asserted, the counter is reset to zero. The current count is also output to a set of LEDs, allowing for visual indication of the counter's state.
module top_module(
    input wire clk,
    input wire reset,
    output reg [3:0] count,
    output wire [3:0] leds
);
