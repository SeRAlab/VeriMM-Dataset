

You are tasked with designing a verilog module for a simple circuit that implements a D-latch with a gated enable. The circuit should have one input, one output, and two control signals. The input signal, denoted D, is the data input to the latch, while the output signal, denoted Q, is the output of the latch. The two control signals are a clock enable signal, denoted G, and a clock signal, which is implied to be connected to the clock input of the latch.

The circuit should have the following behavior:
- When the clock enable signal, G, is high, the latch should be transparent, meaning that the output, Q, should follow the input, D.
- When the clock enable signal, G, is low, the latch should hold its previous state, regardless of the input, D.

Implement the circuit as a verilog module named "gated_d_latch", and ensure that the module has the following ports:
- D: the data input to the latch, a single bit
- G: the clock enable input to the latch, a single bit
- CLK: the clock input to the latch, a single bit
- Q: the output of the latch, a single bit

Your implementation should be contained within 200 lines of verilog code.
