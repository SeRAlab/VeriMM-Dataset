Design a 2-channel DMA (Direct Memory Access) controller that can transfer data between memory and peripheral devices. The controller should have the following inputs: `reqA`, `reqB` (request signals for channel A and B), `ackA`, `ackB` (acknowledge signals for channel A and B), `dataIn` (input data to be written), and `addrA`, `addrB` (addresses for channels A and B). The outputs should be `dataOutA`, `dataOutB` (output data from the channels). The controller should prioritize channel A over channel B. The DMA controller should transfer data when the corresponding request signal is high and acknowledge the transfer when the acknowledge signal is received.
