Design a Verilog module that implements a 3x3 Gaussian blur filter. The filter takes a 3x3 pixel input from an image and outputs a single pixel value that represents the blurred version of the input. The Gaussian blur filter coefficients are as follows:
```
1/16  2/16  1/16
2/16  4/16  2/16
1/16  2/16  1/16
```
The input will be 9 pixel values (each 8 bits) and the output will be a single 8-bit pixel value.
