Design a 3-bit up/down counter that increments or decrements its count based on the state of the `up_down` input signal. On each rising edge of the clock (`clk`), if the `rst` input is high, the counter resets to zero. If `up_down` is high, the counter increments by one; if low, it decrements by one.
module top_module(
    input clk,
    input up_down,
    input rst,
    output reg [2:0] count
);
