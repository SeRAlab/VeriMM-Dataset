
Design a 1-bit DRAM cell that consists of a single bit of storage. The cell should have an input (`D` for data), a control signal (`WE` for write enable), and an output (`Q`). When `WE` is high, the value of `D` should be stored in the cell; when `WE` is low, the stored value should be output on `Q`. The circuit should also include a reset signal that clears the stored value when asserted.
