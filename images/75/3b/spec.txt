Design a 4-to-16 line decoder with an enable signal. When the enable signal is low, the output is set to zero. When enabled, the decoder produces a one-hot output based on the 4-bit input value; for each binary value from 0 to 15, the output corresponds to a single high bit position in a 16-bit word, indicating the active input condition.
