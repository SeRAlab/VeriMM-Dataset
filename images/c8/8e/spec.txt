

You have been tasked with designing a Verilog module that concatenates two input signals, `In0` and `In1`, and outputs the result through `dout`. The `In0` signal is an 8-bit wide input, while the `In1` signal is a 2-bit wide input. The `dout` signal is a 10-bit wide output. 

Your Verilog module should have the following specifications:
- The module should be named `concat`.
- The module should have three input ports: `In0`, `In1`, and `clk`.
- The module should have one output port: `dout`.
- The `In0` input port should be 8 bits wide.
- The `In1` input port should be 2 bits wide.
- The `dout` output port should be 10 bits wide.
- The `clk` input port should be used as the clock signal for the module.

Your module should perform the following operations:
- The 2-bit input signal `In1` should be assigned to the most significant bits of the 10-bit output signal `dout`.
- The 8-bit input signal `In0` should be assigned to the least significant bits of the 10-bit output signal `dout`.

Write a Verilog module that meets the above specifications and performs the required operations.
