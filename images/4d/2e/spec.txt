Design a programmable up/down counter with a specified bit width (defaulting to 8 bits). The counter increments its value by one on each clock cycle when the 'up' input is asserted and decrements its value by one when the 'down' input is asserted. A reset signal ('rstn') is included, which asynchronously resets the counter to zero when asserted low. The current count value is available at the output, which reflects the internal count state.
