Design a four-bit up/down counter that increments or decrements its value based on control signals. The counter operates on the rising edge of the clock signal (clk) and can be reset to zero with the rst signal. When the enable (en) signal is high, the counter will increment when the up signal is asserted, or decrement when the down signal is asserted, allowing bidirectional counting functionality.
module top_module(
  input clk,
  input rst,
  input en,
  input up,
  input down,
  output reg [3:0] count
);
