Design a circuit that performs a 4-bit wide data manipulation, where the output can either be a rotated or shifted version of the input data. If the rotate signal is high, the bits of the input data are rotated to the right; otherwise, the input data experiences a logical left shift, with a zero filling the least significant bit (LSB).
module top_module(
    input [3:0] data,
    input rotate,
    output reg [3:0] shifted_data
);
