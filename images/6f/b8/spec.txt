Design a 3-to-8 line decoder with additional control signals for write operations. The module takes a 3-bit address input and generates an active HIGH output on one of the eight output lines corresponding to the address value. The outputs are registered and only updated on a clock edge when the WR (write) signal is asserted. If WR is low, all outputs will be zeroed. This design is useful for selecting specific peripherals or memory cells in a larger digital circuit using the address provided.
