Write a Verilog module for a 3-to-8 decoder with enable input. The module has the following ports: a 3-bit input "in", an enable input "en", and an 8-bit output "out". The output should be a one-hot encoded representation of the input when "en" is high, and all zeros when "en" is low.

module decoder3to8 (
  input [2:0] in,
  input en,
  output reg [7:0] out);
