Design a 32-bit wide counter with load and enable functionalities. On a rising clock edge, if reset is low, the counter resets to zero. If the load signal is active, the counter is set to the value of the input data. If enabled, the counter increments its value by one on each subsequent clock cycle.
module top_module(
    input clk,
    input rst,
    input en,
    input load,
    input [31:0] data_in,
    output reg [31:0] count
);
