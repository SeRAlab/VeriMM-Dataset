

You have been tasked with designing a verilog module that takes in a 4-bit binary input and outputs the same 4-bit binary value but with the most significant bit (MSB) inverted. For example, if the input is 1011, the output should be 0011. 

Design a verilog module that meets the following specifications:

- Module name should be `invert_msb`
- Input port should be named `i_binary` and should be 4-bit wide
- Output port should be named `o_inverted` and should be 4-bit wide
- The module should implement the desired functionality using only combinational logic.
