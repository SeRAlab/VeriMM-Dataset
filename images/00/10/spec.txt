
Design a simple WiFi module state decoder. The module has a 2-bit input representing the state of the WiFi module: 
00 - DISCONNECTED
01 - CONNECTING
10 - CONNECTED
11 - ERROR
The output will be a 3-bit binary value representing the status of the WiFi module as follows:
000 - Disconnected
001 - Connecting
010 - Connected
011 - Error
