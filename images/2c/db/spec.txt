Design a 4-bit DRAM cell with read and write functionality. The DRAM cell should be able to hold 4 bits of data and be controlled by a write enable signal (we) for writing data on the input. When the read signal (rd) is high, the stored data should be output. The inputs should be a 4-bit data input (data_in) and the outputs should be a 4-bit data output (data_out).
