
Design a Verilog module that performs a 2D convolution operation on a 3x3 input matrix using a 2x2 filter (kernel). The module should accept a 3x3 input and a 2x2 filter, and produce a single output value representing the convolution result. The output should be computed using the formula: 
```
output = (I[0][0] * K[0][0]) + (I[0][1] * K[0][1]) + (I[1][0] * K[1][0]) + (I[1][1] * K[1][1])
```
where I is the input matrix and K is the kernel.
