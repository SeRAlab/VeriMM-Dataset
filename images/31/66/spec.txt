Design a simple Ethernet MAC controller state machine that processes incoming frames. The MAC should have states for IDLE, RECEIVE, and PROCESS. The state machine should transition to the RECEIVE state when a frame is detected and then to the PROCESS state after the frame has been fully received. The system should return to the IDLE state after processing the frame. The inputs to the state machine include a frame_ready signal indicating when a frame has started arriving and a frame_done signal indicating when the frame has been fully received. The outputs include the current state of the state machine.
