
Design a 32-bit Linear Feedback Shift Register (LFSR) using Verilog. The LFSR should use a polynomial of x^32 + x^22 + x^21 + x^1 + 1. The LFSR should shift its bits on each clock cycle, and the feedback should be generated based on the specified taps. The initial seed value for the LFSR should be provided as a parameter.
