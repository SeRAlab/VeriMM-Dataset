Design a synchronous D flip-flop with an active-high reset and load features. On the rising edge of the clock, if the reset signal is asserted, the output (q) is set to LOW. If the load signal is asserted, the output (q) takes the value of the data input (d). If neither reset nor load is active, the output retains its previous state. This module serves as a memory element, storing a one-bit value based on clock events and control signals.
module top_module(
  input d,
  input clk,
  input reset,
  input load,
  output q
);
