Implement an 8-bit data processing module that operates on a clock signal with asynchronous reset. The module takes an 8-bit input (`data_in`), adds the constant value of 5 to it, and stores the result in a register on the rising edge of the clock, provided the reset is not asserted. The module then outputs this stored value decremented by 1. When the reset is active, the output is set to zero. This design functions as a simple arithmetic unit performing addition and subtraction operations on the incoming data.
module top_module(/*AUTOARG*/
   input clk,
   input reset,
   input [7:0] data_in,
   output reg [7:0] data_out
   );
