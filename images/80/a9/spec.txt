Implement a Verilog module that models an 8-bit register with the following functionalities:
- It latches data on the positive edge of clk.
- It has a synchronous active-high clear (clear) that sets the register to 0.
- It has a synchronous active-high load (load) that loads data into the register.

module register (
        input clk,
        input clear,
        input load,
        input [7:0] data,
        output reg [7:0] q);
