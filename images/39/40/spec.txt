Design a Verilog module to implement a simple PCIe Transaction Layer Packet (TLP) processor. The module should receive input signal `tlp_in` (8 bits) which represents a TLP and process it based on the control signal `valid`. When `valid` is high, the module should extract the first 4 bits from `tlp_in` and store it into register `transaction_type`. The `transaction_type` should be output on `tlp_out` (4 bits) when `valid` is high. The `tlp_out` should be held at its last value when `valid` is low.
