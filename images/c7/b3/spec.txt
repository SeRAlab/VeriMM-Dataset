

You are tasked with designing a verilog module that takes in a 32-bit input signal, and outputs a 64-bit signal that is twice the value of the input signal. The module should be named "double_signal".

The module should have the following I/O ports:

- Input: signal_in (32-bit unsigned integer)
- Output: signal_out (64-bit unsigned integer)

Your design should make use of the assign statement to perform the doubling operation.

Write the verilog code for the "double_signal" module.
