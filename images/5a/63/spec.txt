This module implements the instruction fetch stage of a pipelined processor. It maintains a program counter (PC) that tracks the address of the instruction to be fetched and allows for specific control over the program flow through branching, jumping, and resetting. The PC can be updated based on different sources such as sequential (the next instruction), branches, or jumps, controlled by the `pc_source` inputs. The module fetches the instruction at the calculated address and enables instruction reading, storing the fetched instruction and the address in the IF/ID pipeline registers when conditions permit. Additionally, it handles resetting the PC and pipeline registers effectively. Overall, this module is essential for the proper sequencing and retrieval of instructions in a CPU pipeline architecture.
