Design a 2-bit comparator that compares two 2-bit inputs, A and B. The output, Z, is a signed integer indicating the result of the comparison: 1 if A is greater than B, -1 if A is less than B, and 0 if they are equal. The comparator evaluates the most significant bit (MSB) first, and if the MSBs are equal, it proceeds to compare the least significant bit (LSB).
module top_module(
    input [1:0] A,
    input [1:0] B,
    output reg Z
);
