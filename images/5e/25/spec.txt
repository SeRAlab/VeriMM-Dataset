Design a 1-to-2^n demultiplexer that takes a single input signal and routes it to one of the 2^n output lines based on n selection signals. When the selection signal matches the index of an output, the input is transferred to that output; otherwise, the output is driven LOW. In this implementation, with n set to 3, the module can route the input to one of 8 outputs based on the 3-bit selection input.
module top_module(
  input in,
  input [n-1:0] sel,
  output [2**n-1:0] out
);
