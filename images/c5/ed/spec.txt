

You are tasked with designing a module that takes in four inputs A, B, C, and D_N and outputs the result of their logical OR operation. The module should be named `my_or` and should be implemented using Verilog in no more than 200 lines of code.

The module should have the following interface:

```
module my_or(
    input A,
    input B,
    input C,
    input D_N,
    output X
);
```

Where `A`, `B`, `C`, and `D_N` are the input signals and `X` is the output signal.

You should ensure that the module correctly implements the logical OR operation and that it can handle both positive and negative logic signals. The module should be synthesizable and should not contain any combinational loops.
