Design a module that processes a 3-bit input vector and generates multiple outputs based on the input values. The module assigns two of the three bits directly to outputs o1 and outv, while output o0 is determined based on inverted logic states reflecting vec's second and third bits. Additionally, o2 is driven from either the first or third bit of the input, depending on the inverted state of o2 itself. This design effectively manipulates the input vector to produce specific output configurations.
module top_module(
    input wire [2:0] vec,
    output wire [2:0] outv,
    output wire o2,
    output wire o1,
    output wire o0
);
