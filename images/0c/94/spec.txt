
Create a Direct Memory Access (DMA) controller that transfers data from a source address to a destination address in memory. The controller should be able to initiate a transfer when enabled and handle a simple state machine for the transfer process. The data width is 8 bits, and the memory size is 256 bytes. The controller should have inputs for the source address, destination address, enable signal, and a clock signal. It should output a status signal indicating whether the transfer is ongoing or completed.
