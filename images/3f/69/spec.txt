Design a packet filtering system (firewall) in Verilog that checks if an incoming packet matches a predefined set of rules. The firewall accepts an incoming packet if it matches either of the following rules: the source IP address must be '192.168.1.1' or the destination IP address must be '10.0.0.1'. Each IP address will be represented as a 32-bit binary number. The output should be a single bit indicating whether the packet is accepted (1) or rejected (0).
