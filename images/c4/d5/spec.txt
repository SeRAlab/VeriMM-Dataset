

You have been tasked with designing a 4-bit adder using Verilog. The adder should have two 4-bit inputs, A and B, and a 4-bit output, S. The adder should also have a carry-out output, Cout, which should be high (1) if the addition of A and B results in a carry-out. You should implement the adder using only one module without including other modules.

Your module should be named `four_bit_adder` and should have the following inputs and outputs:

Inputs:
- `A`: a 4-bit input
- `B`: a 4-bit input

Outputs:
- `S`: a 4-bit output representing the sum of A and B
- `Cout`: a 1-bit output representing the carry-out of the addition

You will need to use the `wire` keyword to declare internal signals for your module.
