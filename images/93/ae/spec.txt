The outputs o0, o1, o2, and o3 represent the least significant to the most significant bits of the input vector, effectively allowing separate access to each bit.
module top_module(
  input [3:0] in_vector,
  output [3:0] out_vector,
  output o0,
  output o1,
  output o2,
  output o3
);
