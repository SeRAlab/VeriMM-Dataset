Design a simple branch predictor using a 2-bit saturating counter. The branch predictor takes a 1-bit input indicating whether a branch was taken (1) or not taken (0), and outputs a 2-bit prediction state. The state transitions are as follows:
- 00: Strongly Not Taken
- 01: Weakly Not Taken
- 10: Weakly Taken
- 11: Strongly Taken
The transitions occur based on the actual branch outcome. Implement the state transition logic according to the branch prediction scheme.
