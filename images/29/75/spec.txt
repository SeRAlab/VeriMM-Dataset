Design a Verilog module for a flash memory cell type that can store a single bit. The module should have inputs for a data signal (D), a clock signal (CLK), and an enable signal (EN). On the rising edge of CLK, if EN is high, the data signal should be stored in a flip-flop. The stored value should be available on the output signal (Q). If EN is low, the output Q should retain its previous value.
