

You are tasked with designing a module that implements a 4-bit memory block with look-up table (LUT) functionality. The module should have four inputs and one output. The inputs are:
- `clka`: a clock signal
- `ena`: an enable signal
- `addra`: a 4-bit address signal
- `dina`: a 4-bit data input signal

The output is:
- `douta`: a 4-bit data output signal

The module should store the input data in memory at the specified address when the `ena` signal is high. When the `ena` signal is low, the module should output the data stored at the address specified by `addra`.

You are given the following code snippet as a starting point for your module:

```
module lut_mem_block(
  input wire clka,
  input wire ena,
  input wire [3:0] addra,
  input wire [3:0] dina,
  output wire [3:0] douta
);

// your code goes here

endmodule
```

Please write the code for the `lut_mem_block` module that implements the memory block with LUT functionality as described above.
