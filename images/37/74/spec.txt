Design a DVFS controller that adjusts the output frequency and voltage based on the load signal. The controller should have an input signal 'load' indicating the current load level (0 for low load, 1 for high load). Based on the load signal, the controller should output a frequency setting (freq_set) and a voltage setting (volt_set). The outputs should change according to the following logic: If load is 0, set freq_set to 1 MHz and volt_set to 1.0 V. If load is 1, set freq_set to 2 MHz and volt_set to 1.2 V. The controller should have a clock and reset signal for proper synchronization.
