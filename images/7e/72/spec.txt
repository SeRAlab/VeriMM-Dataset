Design a D flip-flop with asynchronous reset and enable inputs. The module captures the input 'data' on the rising edge of 'clock' when 'enable' is high. If 'reset' is low, the flip-flop outputs 'q' as 0 and 'qbar' as 1, overriding the data input regardless of the enable state.
