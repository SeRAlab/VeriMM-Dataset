Design a simple RRT (Rapidly-exploring Random Tree) controller that decides whether to add a new node or not based on a given condition. The controller should have a clock input, a reset input, a start input, and an output that indicates whether a new node is added (1) or not (0). If the reset is high, the output should be 0. If the start signal is high and the condition is met (which is determined by an input condition signal), the output should turn high for one clock cycle.
