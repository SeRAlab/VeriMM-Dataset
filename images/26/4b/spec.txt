
Design a simple state machine using Model Predictive Control (MPC) principles. The state machine should have three states: IDLE, RUNNING, and FINISHED. The state will transition based on an input signal called `start`. When `start` is high, the machine transitions from IDLE to RUNNING. When in RUNNING, it stays in this state for a certain number of clock cycles (specified by the parameter `RUN_TIME`) and then transitions to FINISHED. The machine should reset to IDLE when the `reset` signal is high.
