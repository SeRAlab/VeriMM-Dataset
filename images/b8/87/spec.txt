Design a one-bit wide, 2-to-1 multiplexer. The output Y will be determined by the selection input S; when S is LOW (0), the output Y is set to the value of input A, and when S is HIGH (1), the output Y reflects the value of input B. The module utilizes basic logic gates—AND and OR—to achieve this functionality.
module top_module(
    input A,
    input B,
    input S,
    output Y
);
