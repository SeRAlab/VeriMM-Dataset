Implement a simple matrix factorization function that takes two 4x4 matrices (A and B) as input and produces their product matrix (C). The multiplication of two matrices can be defined as:

C[i][j] = Σ (A[i][k] * B[k][j]) for k = 0 to 3

Your task is to write the Verilog code that performs this computation for 4x4 matrices.
