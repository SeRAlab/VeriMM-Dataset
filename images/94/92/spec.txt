Design a 2-to-4 line decoder with enable functionality. The module produces a 16-bit output where only one bit is set to high based on the 2-bit input selection signal (SEL), provided the enable signal (EN) is active. When EN is low, all output bits are driven to low. When EN is high, the output corresponds to the binary value of SEL, activating one of the four least significant bits in the output while the others remain low.
module top_module(
    input [1:0] SEL,
    input EN,
    output reg [15:0] Q
);
