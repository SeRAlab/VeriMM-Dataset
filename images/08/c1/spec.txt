
Design a simple OFDM modulator that takes in a parallel input data stream of 4 bits and generates a serial output. The modulator should include a simple memory element to hold the previous output and a clock signal to control the output timing. The output should be produced on every positive edge of the clock, and the input data should be shifted in on every negative edge of the clock. The serial output should be the combination of the current input data and the previous output data.
