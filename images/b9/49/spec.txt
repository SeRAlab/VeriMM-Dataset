Implement a 3-to-1 multiplexer for 32-bit wide data inputs. The module takes three 32-bit input signals (data0_in, data1_in, data2_in) and a 2-bit select signal. Based on the value of the select input, it outputs one of the three input data channels: if select is 00, output data0_in; if select is 01, output data1_in; and if select is 10, output data2_in.
