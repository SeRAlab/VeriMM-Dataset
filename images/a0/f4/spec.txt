Design a 2-input look-up table (LUT) module that generates a single output based on two binary inputs, I0 and I1. The output O is determined by the INIT parameter, which is a 2-bit input used to configure the lookup behavior. If both inputs I0 and I1 are LOW, the output is set to INIT[0]; otherwise, it produces INIT[1] when any of the inputs are HIGH. This functionality allows for flexible logic design based on the given INIT configuration.
module top_module(
	output O,
	input  I0,
	input  I1
);
