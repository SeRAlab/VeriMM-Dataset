
Design a Verilog module that implements a simple RRT (Rapidly-exploring Random Tree) algorithm for pathfinding in a 2D space. The module should take the current position and a target position as inputs, and at each clock cycle, it should attempt to extend the tree towards the target position by generating a random point within a defined range, and then updating the current position towards that point. The module should have an output that indicates the new position after each update.
