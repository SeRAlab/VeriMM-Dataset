Design a 3-bit up-counter that increments its count on each rising edge of the clock (CLK) when enabled (EN). The counter resets to zero when the reset signal (RST) is asserted. The current count is held in a 3-bit register (Q), which is updated based on the next count value computed in the always block. This design provides a simple counting mechanism useful in various digital applications where counting events or generating time-based sequences is required.
module top_module(
    input CLK,
    input RST,
    input EN,
    output reg [2:0] Q
);
