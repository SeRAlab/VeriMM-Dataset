
Design an EEPROM cell in Verilog that can perform the following operations:
1. Write a single bit (0 or 1) to the memory cell.
2. Read the stored bit from the memory cell.
3. The write operation should take one clock cycle, while the read operation should be performed immediately after the write. A control signal 'we' (write enable) indicates if the operation is a write (1) or a read (0).
