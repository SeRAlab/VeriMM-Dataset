Design an 8-bit SRAM cell with read and write operations. The SRAM should have the following inputs: an 8-bit data input (data_in), a read/write control signal (rw), a chip enable signal (ce), an address input (addr), and an output (data_out). When rw is high, the cell should write data_in to the address addr. When rw is low and ce is high, the cell should output the data stored at addr to data_out. When ce is low, the chip should ignore all operations.
