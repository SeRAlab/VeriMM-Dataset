
Design a temperature-based shutdown system. The system should monitor a temperature input and, if the temperature exceeds a certain threshold, it will activate a shutdown signal. The system should have the following specifications:
- A 4-bit temperature input (temp_in).
- A 1-bit shutdown output (shutdown).
- The threshold for triggering the shutdown is 12 (in decimal).
- The system should hold the shutdown signal until the temperature falls below the threshold, at which point it should reset.
