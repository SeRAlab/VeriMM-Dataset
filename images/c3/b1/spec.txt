

You have been tasked with designing a verilog module that takes in a 32-bit input signal `in` and outputs a 16-bit signal `out`. The `out` signal should contain the 16 least significant bits of the `in` signal. 

Design a verilog module that meets these requirements. 

Your module should be named `lsb_extractor` and should have the following ports:

- `input [31:0] in`: a 32-bit input signal
- `output [15:0] out`: a 16-bit output signal

Your module should extract the 16 least significant bits of the `in` signal and assign them to the `out` signal.
