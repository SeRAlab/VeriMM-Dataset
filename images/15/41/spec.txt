
Design a UART controller that can transmit a character serially. The controller should have the following specifications:
- It should support a baud rate of 9600 bits per second.
- It should have a data format of 8 data bits, no parity bit, and 1 stop bit.
- The input signal is a parallel 8-bit data input along with a start signal to initiate transmission.
- The output should be a serial data output which shifts out the bits starting with the start bit, followed by the data bits, and then the stop bit.
- The transmission should take place on a clock signal, where each bit is sent on the rising edge of the clock.
