Design a combinational logic circuit that generates a single output based on multiple inputs. The output, 'out', is determined by three conditions: if input 'C' is high, it outputs the value of 'A'; if input 'D' is high, it computes the bitwise XOR of 'A' and 'B'; and if all inputs 'E', 'F', 'G', and 'H' are high, it outputs a logical AND of those inputs. The final output is the logical OR of these three conditions, effectively allowing selective output generation based on the controls provided by inputs 'C' and 'D'.
module top_module(
    A,
    B,
    C,
    D,
    E,
    F,
    G,
    H,
    out
);
