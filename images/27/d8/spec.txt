
Design a convolutional encoder that takes a 2-bit input and generates a 4-bit output using the following generator polynomials:
- G1 = 101 (which corresponds to the first output bit)
- G2 = 111 (which corresponds to the second output bit)

The encoder should have a memory of one bit (i.e., it should have one historical bit to process the next input along with the current input). The state of this memory bit should be updated with each input. The output should be generated on each input clock cycle, and the system should be resettable.
