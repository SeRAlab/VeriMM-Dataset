Design a tri-state buffer with enable functionality. When the enable signal (EN) is high, the output (Z) directly follows input A. If EN is low, the module selects either input B or input C as the output: it outputs B if B is high; otherwise, it selects C as the output. This design allows for controlled routing of signals based on the enable condition and the states of the other inputs.
module top_module(
    input A,
    input B,
    input C,
    input EN,
    output reg Z
);
