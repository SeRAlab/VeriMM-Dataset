
Design a simple Automatic Repeat reQuest (ARQ) error correction system that utilizes a sender and a receiver. The sender transmits a 4-bit data word along with a single 1-bit acknowledgment (ACK) signal from the receiver. If the receiver detects an error in the received data, it sends back a NACK (negative acknowledgment) signal, prompting the sender to resend the data. The receiver will use a simple parity check for error detection. Implement this system in Verilog.
