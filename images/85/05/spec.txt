Create a 2-to-1 multiplexer with enable functionality. When the enable signal (en) is low (0), the module outputs the value from input in1. When the enable signal is high (1), the output is taken from input in2. This design effectively allows for controlled selection between two input signals based on the enable state.
module top_module(
    // ports
    output wire out,
    input wire in1,
    input wire in2,
    input wire en
);
