

You have been tasked with designing a Verilog module that implements a simple 2-bit counter. The module should have two inputs, a clock input, and a reset input. When the reset input is high, the counter should be reset to 0. When the clock input is high, the counter should increment by 1. The module should have one output, a 2-bit binary number that represents the current count.

Design a Verilog module that implements this simple 2-bit counter.
