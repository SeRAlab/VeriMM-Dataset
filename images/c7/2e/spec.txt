

You are tasked with designing a Verilog module for a 4-input AND gate. The module should have 4 input signals, A1, A2, A3, and A4, and 1 output signal, Y. The module should be named "and_gate". The output signal should be high (1) only if all input signals are high (1). Otherwise, the output signal should be low (0).

You should write a Verilog module that takes in the input signals and outputs the correct output signal based on the above specifications. Your module should be self-contained and should not rely on any external modules or libraries. The module should be no longer than 200 lines of Verilog code.
