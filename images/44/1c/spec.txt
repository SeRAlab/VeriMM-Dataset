Design an up/down counter that counts in increments or decrements based on the input control signals. The counter has a reset input (RST) to set the output to zero, a load input (LD) to load a specified 4-bit value (D) into the counter, and an up/down input (UD) to determine the counting direction. When UD is high, the counter increments the output (Q) by one at each clock pulse; when UD is low, it decrements the output by one.
module top_module(
    input CLK,
    input RST,
    input LD,
    input UD,
    input [3:0] D,
    output reg [3:0] Q
);
