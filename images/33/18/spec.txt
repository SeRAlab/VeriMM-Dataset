Design a GPIO controller in Verilog that can read input signals and control output signals based on a simple state machine. The GPIO controller should have the following features: it has an input signal for mode selection (0 for read, 1 for write), an input signal for the GPIO data, and an output signal to indicate the current state of the GPIO pins. The state transitions should be as follows: when in read mode, the output should reflect the input data; when in write mode, the output should remain unchanged until the next mode transition.
