Design a 4-bit up/down counter with load functionality. When reset is active, the counter initializes to zero. If the load signal is asserted, the counter loads the value from the data_in input. When up_down is high, the counter increments the current value on each clock cycle; when up_down is low, it decrements the value. 
module top_module(
    input clk,
    input reset,
    input load,
    input up_down,
    input [3:0] data_in,
    output reg [3:0] data_out
);
