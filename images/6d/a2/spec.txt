Design a 32-bit wide register with asynchronous reset and load capabilities. On a negative edge of the reset signal, the output is asynchronously set to zero. On the rising edge of the clock, if the load signal is asserted, the register updates its output to the value provided on the data input.

    input clk,
    input reset,
    input load,
    input [31:0] data_in,
    output reg [31:0] data_out
);
