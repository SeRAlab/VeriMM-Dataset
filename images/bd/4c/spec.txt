Design a dual-port memory system with a read-write pointer mechanism. The module supports one write operation and two simultaneous read operations. On each clock cycle, if the write signal is high, it stores the provided `write_data` into the memory at the address indicated by `ptr_reg`. The memory also outputs data from two addresses: one specified by `read_addr0` and the other from the current write location. The pointer can reset to zero or increment based on external control signals. The reset is asynchronous, ensuring initialization when required. This design serves applications needing dual-port access to a small memory array, suitable for various data handling scenarios.
