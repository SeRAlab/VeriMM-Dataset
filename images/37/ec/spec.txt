Design a decision tree inference module in Verilog that takes five binary input features and outputs a binary decision based on a simple decision tree. The tree is defined as follows:  
1. If feature 0 is 1, output 1.  
2. If feature 1 is 1 and feature 2 is 0, output 0.  
3. If feature 1 is 0 and feature 3 is 1, output 1.  
4. If feature 1 is 0 and feature 3 is 0, return the value of feature 4.  
Output should be a 1-bit signal.
