Design a synchronous 4-input multiplier circuit that computes the product of four 4-bit inputs (a, b, c, and d) on the rising edge of a clock signal. When the reset signal is asserted, the output is set to zero; otherwise, the output registers the result of the multiplication, which is an 8-bit wide value.
module top_module(
    input [3:0] a,
    input [3:0] b,
    input [3:0] c,
    input [3:0] d,
    input clk,
    input rst,
    output reg [7:0] out
);
