Design a single-port synchronous memory module with a 14-bit addressable space and 12-bit wide data. The module utilizes a clock signal (clka) for both writing and reading operations; when write enable (wea) is asserted, the data input (dina) is written to the specified address (addra) in memory. On every rising edge of the clock, the output (douta) is updated to reflect the data stored at the specified address, allowing for data retrieval after a write operation.

  clka,
  wea,
  addra,
  dina,
  douta
