Design a one-bit wide, 8-to-1 multiplexer. The module takes three select lines (s2, s1, s0) to choose from five data inputs (d0 to d4). Based on the binary value represented by the select lines, it outputs the corresponding data line to the output y; if the select lines do not correspond to any of the valid inputs (beyond d4), the output defaults to LOW.
module top_module(
    output reg y,
    input s2,
    input s1,
    input s0,
    input d4,
    input d3,
    input d2,
    input d1,
    input d0
);
