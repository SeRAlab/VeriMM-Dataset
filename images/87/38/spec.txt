Design a module that performs division of two 8-bit unsigned integers. The module takes two 8-bit inputs, A and B, and outputs the quotient and remainder of the division operation. It also includes a valid signal to indicate that the outputs are ready. If B is zero, which would result in an undefined operation, the quotient and remainder are set to zero, and valid is asserted to indicate that the operation is complete without errors.
module top_module(
    input [7:0] A,
    input [7:0] B,
    output reg [7:0] quotient,
    output reg [7:0] remainder,
    output reg valid
);
