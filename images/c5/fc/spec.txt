

You are tasked with designing a module that performs a specific logic function. The module should have one output port and one input port. The input port should be named "A", and the output port should be named "Y". The module should be named "my_module".

The module should have the following functionality:
- If the input is 0, the output should be 1.
- If the input is 1, the output should be 0.

You are allowed to use any of the following logic gates: NOT, AND, OR, XOR, NAND, NOR, XNOR. You are also allowed to use any number of these gates.

Your module should be written in Verilog and should be no longer than 200 lines of code.
