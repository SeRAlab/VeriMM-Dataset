Design a virtual memory management unit (MMU) that maps virtual addresses to physical addresses. The MMU should support a simple page table that can handle a limited number of pages. The design will include the following inputs: a virtual address, a page table base address, and a control signal to perform the mapping operation. The output should be the corresponding physical address. You need to implement a simple mechanism to handle page faults by returning a predefined error code when the requested page is not in the page table.
