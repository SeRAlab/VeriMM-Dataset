Design a Verilog module that simulates a simplified flash memory cell. The flash memory cell should have the following functionalities:
1. A `write` operation that sets the memory cell to a specified value.
2. A `read` operation that retrieves the value of the memory cell.
3. A `reset` operation that initializes the memory cell to a default state (e.g., 0).
The module should have inputs for the value to be written, a control signal for writing, a control signal for reading, and a reset signal. The output should be the current value of the memory cell.
