
Design a simple PCIe Endpoint Controller state machine that responds to a request signal. The controller has three states: IDLE, ACTIVE, and ERROR. When in the IDLE state, if a request signal is received, transition to the ACTIVE state. In the ACTIVE state, if an error signal is received, transition to the ERROR state. If the request signal is not asserted, remain in the ACTIVE state until the error signal is received. The controller should return to the IDLE state upon clearing the request signal or when an error is resolved.
