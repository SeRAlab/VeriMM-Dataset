Design a Verilog module that implements a Quadrature Amplitude Modulation (QAM) transmitter. The module should take in a stream of bits and output the corresponding I (in-phase) and Q (quadrature) signals based on 16-QAM modulation. The input is a 4-bit data word, where each word maps to one of the 16 possible modulation states. The module should have a clock input to synchronize the processing of the input data.
