Design a Mealy state machine that counts the number of consecutive '1's in a stream of input data. The module uses a clock and asynchronous reset to operate; on every rising edge of the clock, if the input data is '1', it increments the 3-bit count register. If the input data is '0', the count resets to zero. The output is a 3-bit register representing the current count of consecutive '1's, allowing for a maximum count of 7 before overflow.
module top_module(
  input clk,
  input reset,
  input data,
  output reg [2:0] count
);
