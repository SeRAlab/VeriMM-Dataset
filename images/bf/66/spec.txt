Design a 13-bit Linear Feedback Shift Register (LFSR) that generates pseudo-random numbers with each clock cycle. The LFSR shifts its bits while using a feedback mechanism based on a combination of specific bits to produce new outputs, resetting to an initial value when a reset signal is asserted. It counts up to 13 clock cycles, at which point it captures the current random output for external access. The final output `rnd` provides the random number generated by the LFSR.
module top_module(
    input clock,
    input reset,
    output [12:0] rnd 
    );
