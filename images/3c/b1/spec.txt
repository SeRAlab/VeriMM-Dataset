
Design a Verilog module that implements a simple decision tree for binary classification based on two input features (feature1 and feature2). The decision tree follows these rules:
- If feature1 <= 5 and feature2 <= 5, output class 0.
- If feature1 <= 5 and feature2 > 5, output class 1.
- If feature1 > 5 and feature2 <= 5, output class 2.
- If feature1 > 5 and feature2 > 5, output class 3.
The inputs feature1 and feature2 are 4-bit binary numbers, and the output class is a 2-bit binary number.
