Based on the direction control signal, it shifts the input either left (direction = 1) or right (direction = 0), and outputs the resulting 4-bit data.
module top_module(
    input [3:0] data_in,
    input [1:0] shift_amount,
    input direction,
    output [3:0] data_out
);
