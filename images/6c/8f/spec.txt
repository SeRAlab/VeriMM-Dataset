Design a D flip-flop with asynchronous reset functionality. The output Q is set to LOW when the active-low reset signal (RESET_B) is asserted. On the rising edge of the reset signal, the flip-flop captures the value of the input D. If RESET_B is not asserted, the output follows the input D, thereby allowing the flip-flop to operate normally.
module top_module(
    input D,
    input RESET_B,
    output reg Q
);
