

You are tasked with designing a multiplexer module in Verilog that takes two 1-bit inputs, `D0` and `D1`, and a control input `ctrl` to output a single 1-bit output `S`. The module should be named `mux_1bit`.

When the control input `ctrl` is 0, the output `S` should be equal to `D0`. When the control input `ctrl` is 1, the output `S` should be equal to `D1`.

Your task is to write a Verilog module that implements this functionality. The module should be self-contained and should not require any external inputs or outputs.

You are allowed to use any Verilog constructs you wish, including if-else statements, ternary operators, and case statements.

In addition, you should ensure that your module is no longer than 200 lines of Verilog code.
