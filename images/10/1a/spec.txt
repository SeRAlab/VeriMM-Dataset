Implement a simple RRT (Rapidly-exploring Random Tree) node expansion logic. The goal is to expand the tree by generating a new point in the space, given a current node's coordinates and a fixed step size. If the new point is valid (within boundaries), the node should be updated with this new point. The circuit should take as inputs the current node coordinates (x, y), a step size, and the boundaries of the space. The output should be the new node coordinates.
