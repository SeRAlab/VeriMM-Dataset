Design a sequential 4-to-1 multiplexer that selects one of four input signals (in0, in1, in2, in3) based on two selection lines (sel0 and sel1) and outputs the chosen signal on the rising edge of the clock (clk). The selected input is determined by the binary value of the selection lines: when sel1 and sel0 are both 0, in0 is output; when sel1 is 0 and sel0 is 1, in1 is selected; for sel1 = 1 and sel0 = 0, in2 is chosen; and when both are 1, in3 is output.
module top_module(
    input in0,
    input in1,
    input in2,
    input in3,
    input sel0,
    input sel1,
    input clk,
    output reg out
);
