Implement a basic FIFO (First-In-First-Out) buffer with control signals for enqueue and dequeue operations. The module features input signals for enabling a data enqueue operation (in_enq__ENA) and a corresponding data value (in_enq_v) while indicating when the enqueue operation is ready (in_enq__RDY). Additionally, it includes input for enabling a dequeue operation (out_deq__ENA) and outputs the first item in the queue (out_first) along with a readiness signal (out_first__RDY). However, as currently implemented, all readiness signals are hardcoded to indicate "not ready" and the output data is fixed to zero, suggesting that the FIFO functionality is not functional in this design.
