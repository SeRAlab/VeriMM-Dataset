

You are tasked with designing a module that takes in three inputs and outputs the logical AND of those inputs. The module should be named `My_AND3` and should have the following ports:

- `in1`: a single bit input
- `in2`: a single bit input
- `in3`: a single bit input
- `out`: a single bit output

Your module should implement the logical AND operation using only the following gates:

- AND (`&`)
- NOT (`~`)

You are not allowed to use any other gates or operators. Additionally, your module should be no more than 200 lines of Verilog code.

Write the Verilog code for your `My_AND3` module that satisfies the above requirements.
