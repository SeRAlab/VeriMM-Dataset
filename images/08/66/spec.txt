
Design a 16-bit ADC (Analog to Digital Converter) output decoder that takes a 16-bit binary input representing the digital value from the ADC and generates a 4-bit output that represents the corresponding range (0-15) of that value. The ranges are defined as follows:
- 0-1023 -> 0000
- 1024-2047 -> 0001
- 2048-3071 -> 0010
- 3072-4095 -> 0011
- 4096-5119 -> 0100
- 5120-6143 -> 0101
- 6144-7167 -> 0110
- 7168-8191 -> 0111
- 8192-9215 -> 1000
- 9216-10239 -> 1001
- 10240-11263 -> 1010
- 11264-12287 -> 1011
- 12288-13311 -> 1100
- 13312-14335 -> 1101
- 14336-15359 -> 1110
- 15360-65535 -> 1111
