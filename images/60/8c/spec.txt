Design a binary-coded decimal (BCD) converter that takes a 4-bit binary input and converts it into two 4-bit outputs: `bcd_high` and `bcd_low`. The `bcd_low` output represents the lower 4 bits of the BCD representation for values 0 to 9, while the `bcd_high` output indicates the tens place in BCD format, which is zero for input values from 0 to 9. The converter maps each 4-bit input directly to its corresponding BCD representation, assigning the appropriate values to both `bcd_high` and `bcd_low` based on the standard binary-to-BCD conversion, returning zeros for any invalid inputs outside this range.
module top_module(
    input [3:0] in,
    output reg [3:0] bcd_high,
    output reg [3:0] bcd_low
);
