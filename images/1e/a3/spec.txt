
Design a Verilog module that implements a simple state machine with three states (IDLE, PROCESS, DONE). The state machine transitions based on an input signal 'start'. When 'start' is high, it moves from IDLE to PROCESS, and after a fixed number of clock cycles (4 cycles), it moves to DONE. It should return to IDLE when 'reset' is high. The output 'state' should represent the current state in binary: IDLE = 00, PROCESS = 01, DONE = 10.
