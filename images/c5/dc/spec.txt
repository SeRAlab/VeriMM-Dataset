

You are tasked with designing a verilog module that implements a D flip-flop with reset. The module should have the following ports:

- `clk`: a clock input
- `reset`: a synchronous reset input
- `d`: a data input
- `q`: a data output

The D flip-flop should sample the input `d` on the rising edge of the clock `clk`, and hold the sampled value on the output `q` until the next rising edge of `clk`. If the reset input `reset` is asserted synchronously with the rising edge of `clk`, the output `q` should be reset to 0.

Implement the D flip-flop using only combinational logic and flip-flops. Do not use any behavioral constructs such as `always` blocks or `assign` statements.
