Design a 1-to-3 demultiplexer that routes a single bit of input data to one of three output channels based on a 2-bit select signal. When select is 00, the input is sent to channel 1; when select is 01, it goes to channel 2; and when select is 10, it is directed to channel 3. For any other select values, the input is routed to channel 2 by default while the other channels are set to LOW.
module top_module(
input wire data,
input wire [1:0] select,
output reg ch1,
output reg ch2,
output reg ch3
);
