Create a Verilog module for a 3-bit synchronous counter with active high reset and load functionality.
// (1) reset: Resets the counter to 3'b000 when high.
// (2) load: Loads the counter with the value on the input data signal when high.
// (3) data: 3-bit input data for loading into the counter.
// (4) q: The value of the counter.

module sync_counter(
    input clk,
    input reset,
    input load,
    input [2:0] data,
    output reg [2:0] q);
