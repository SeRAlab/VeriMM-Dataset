

You are tasked with designing a verilog module that will implement a 2-to-1 multiplexer. The module should have the following inputs and outputs:

- `input A`: a single bit input signal
- `input B`: a single bit input signal
- `input SEL`: a single bit input signal used to select which input to pass through to the output
- `output Y`: a single bit output signal representing the selected input

The module should implement the following logic:

- When `SEL` is high, the output `Y` should be equal to `B`
- When `SEL` is low, the output `Y` should be equal to `A`

You should use the `assign` statement to implement this logic.
