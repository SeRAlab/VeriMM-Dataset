Design a 4-to-1 multiplexer that selects one of four input data lines (d0, d1, d2, d3) based on a 2-bit select signal (s) and produces the corresponding output (y). When s is 00, y outputs d0; when s is 01, y outputs d1; when s is 10, y outputs d2; and when s is 11, y outputs d3. If s takes on an unexpected value, y defaults to 0. This multiplexer is capable of handling 32-bit wide input signals as specified by the width parameter.

s, y,
d0, d1, d2, d3);
