Design a 3-input XNOR gate in Verilog. The module should take three 1-bit inputs (A, B, C) and output a 1-bit result (Y). The output Y should be true if an even number of inputs A, B, and C are true (1). If 0 or 2 inputs are true, the output should be true. If all 3 inputs are true, the output should be false.
