Design a 4-to-1 multiplexer with an enable feature. The module selects one of four 8-bit input signals (in0, in1, in2, in3) based on a 2-bit selection input (sel). When enabled (en=1), the selected input is routed to the 8-bit output (out); if the enable signal is low (en=0), the output is set to zero regardless of the selection.
module top_module(
    input [7:0] in0,
    input [7:0] in1,
    input [7:0] in2,
    input [7:0] in3,
    input [1:0] sel,
    input en,
    output reg [7:0] out
);
