Design a 1-bit SRAM cell in Verilog. The SRAM cell should have the following ports: 
- A data input (d)
- A data output (q)
- A write enable signal (we)
- A clock signal (clk)

When `we` is high on the rising edge of `clk`, the input data `d` should be written to the cell. When `we` is low, the output `q` should hold the stored value of the cell.
