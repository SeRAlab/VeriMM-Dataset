
Design a JK latch in Verilog. The JK latch should have two inputs J and K and one output Q. The latch should change its state according to the following rules:
- If J = 0 and K = 0, Q remains unchanged.
- If J = 1 and K = 0, Q is set to 1.
- If J = 0 and K = 1, Q is reset to 0.
- If J = 1 and K = 1, Q toggles its state.
The latch should have an enable input, EN, which controls whether the inputs are processed or not.
