Implement a Verilog module based on the following description.
Build a simple 4-bit up/down counter with enable and reset signals. The counter increments on the positive edge of the clock when enabled and decrements on the positive edge of the clock when enabled. The counter is reset to 0 when the reset signal is high.

module counter (
	input clk,
	input reset,
	input enable,
	input up_down, // 1 for up, 0 for down
	output [3:0] count
);
