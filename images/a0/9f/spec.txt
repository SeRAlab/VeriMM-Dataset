Design a 3-bit up/down counter that increments or decrements its count based on control signals. When the 'up' signal is asserted, the counter increases its value by 1, wrapping back to 0 upon reaching its maximum of 7 (111 in binary). Conversely, when the 'down' signal is active, the counter decreases its value by 1, wrapping to 7 when it reaches 0. The counter resets to 0 when the 'reset' signal is asserted. This functionality allows the counter to operate in both counting directions, providing flexibility in various digital applications.
module top_module(
  input clk,
  input reset,
  input up,
  input down,
  output reg [2:0] count
);
