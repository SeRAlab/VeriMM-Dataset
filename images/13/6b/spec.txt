
Create a Verilog module for a 16-QAM (Quadrature Amplitude Modulation) encoder. The module should take in 4 bits of input data and output two signals representing the in-phase (I) and quadrature (Q) components. The mapping from the 4-bit input to the (I, Q) output should be as follows:
- 0000 -> (−3, −3)
- 0001 -> (−3, −1)
- 0010 -> (−3, 1)
- 0011 -> (−3, 3)
- 0100 -> (−1, −3)
- 0101 -> (−1, −1)
- 0110 -> (−1, 1)
- 0111 -> (−1, 3)
- 1000 -> (1, −3)
- 1001 -> (1, −1)
- 1010 -> (1, 1)
- 1011 -> (1, 3)
- 1100 -> (3, −3)
- 1101 -> (3, −1)
- 1110 -> (3, 1)
- 1111 -> (3, 3)
