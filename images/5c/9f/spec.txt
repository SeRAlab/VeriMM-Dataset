Design a combinational logic block that decodes a 3-bit input (in2, in1, in0) into two outputs (out1 and out0). The outputs are defined such that out1 is high only when the input equals either 000 or 111, while out0 is high for all other combinations of the input (from 001 to 110). If the input is something unexpected, both outputs default to low.
module top_module(
    input wire in2,
    input wire in1,
    input wire in0,
    output reg out1, // Changed from wire to reg
    output reg out0  // Changed from wire to reg
);
