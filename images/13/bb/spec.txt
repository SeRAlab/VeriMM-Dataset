Design a simple dynamic memory allocator that emulates the behavior of malloc and free functions. The module should have the following functionality:
- An input signal `req` to indicate a request (1 for malloc, 0 for free).
- An input signal `size` that indicates the size of the memory to allocate or free.
- An output signal `allocated` that will be set to 1 if the memory allocation is successful and 0 otherwise.
- A memory array of fixed size (e.g., 8 bytes).
- The `free` operation will only free memory that was previously allocated.
