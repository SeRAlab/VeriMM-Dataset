Design a 4-to-1 multiplexer with an enable signal. The module takes four different 1-bit data inputs and a 2-bit select input to determine which data input is routed to the output. When the enable signal is high, the output will always be LOW; when enable is low, the selected data input based on the `sel` lines is output. The use of inverted selection lines in conjunction with the data inputs allows for proper data selection, while the enable functionality provides control over the output state.
module top_module(data0, data1, data2, data3, sel, enable, out);
