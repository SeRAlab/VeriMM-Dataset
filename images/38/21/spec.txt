
Design a Verilog module that performs nearest neighbor interpolation on a 2D grayscale image. The module will take a pixel value and its neighboring pixel values as inputs and output the interpolated pixel value based on the nearest neighbor rule. The input will consist of the pixel's value and the values of its four neighbors (up, down, left, right). The output should be the pixel value of the nearest neighbor, which is the closest non-zero value among the neighbors.
