Design a 16-bit left shift register that shifts the input data left by one bit when the shift_control signal is high. On the rising edge of the clock, if shift_control is asserted, the most significant bit of the data_out is filled with a zero, effectively shifting all bits left; otherwise, data_out is unchanged and outputs the current value of data_in.
module top_module(
 input clk,
 input [15:0] data_in,
 input shift_control,
 output reg [15:0] data_out
);
