
Design a Verilog module that implements a basic SHA-256 hash function step, specifically the "Ch" (choose) function. The "Ch" function takes three 32-bit inputs `x`, `y`, and `z`, and computes the output as follows:
Ch(x, y, z) = (x AND y) XOR (NOT x AND z)
Implement this as a sequential module where the output is registered on the rising edge of a clock signal.
