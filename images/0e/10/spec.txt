
Design a simple ARQ (Automatic Repeat reQuest) mechanism for error correction. The system should have a sender and a receiver. The sender generates data, and the receiver checks for errors. If an error is detected in the received data, the receiver sends a negative acknowledgment (NAK) back to the sender, prompting it to resend the data. If the data is received correctly, the receiver sends an acknowledgment (ACK). The sender should keep track of the number of attempts made to send the data, and it should have a maximum attempt limit before giving up.
