
Design a Phase-Locked Loop (PLL) system that locks onto an input frequency. The PLL should consist of a phase detector, a low-pass filter, and a voltage-controlled oscillator (VCO). The phase detector will compare the phase of the input signal with the output of the VCO. Based on the phase difference, the low-pass filter will adjust the control voltage for the VCO to minimize the phase error. Implement this in Verilog, ensuring correct timing and functionality.
