Design a fixed-priority arbiter in Verilog that can handle 4 request lines (Req0, Req1, Req2, Req3). The arbiter should give priority to Req0 first, then Req1, followed by Req2, and finally Req3. The arbiter should output a grant signal (Grant) indicating which request is granted, and a valid signal (Valid) that indicates when the output is valid. The arbiter should also have a clock and reset signal. The output should only change on the rising edge of the clock.
