Design an 8-bit digital-to-analog converter (DAC) in Verilog. The DAC should take an 8-bit binary input and output a corresponding analog voltage level represented in a 10-bit format, assuming a maximum voltage of 5V. The output voltage can be calculated using the formula: V_out = (input_value / 255) * 5V. The output should be a 10-bit value representing the voltage as a proportion of the full scale.
