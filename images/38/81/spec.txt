Design a simple PCIe interface controller that manages the state transitions for a PCIe endpoint. The controller should have the following states: IDLE, REQUEST, and RESPONSE. It should transition to REQUEST when a signal `start` is asserted, remain in REQUEST while `req_valid` is high, and transition to RESPONSE when `req_ready` is asserted. The controller should return to IDLE after completing the RESPONSE state when `resp_done` is asserted.
