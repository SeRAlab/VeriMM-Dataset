
Design a fixed-priority arbiter in Verilog. The arbiter should have three request inputs (req0, req1, req2) and one grant output (grant). The priority order is req0 > req1 > req2. If multiple requests are made simultaneously, the highest priority request should be granted. The arbiter should be enabled by an input called 'en', and the grant output should be registered on the rising edge of a clock signal 'clk'.
