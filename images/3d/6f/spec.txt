Design a simple Verilog module that implements a state machine to control a robot movement in a grid based on inputs for direction. The robot can move Up, Down, Left, or Right based on a 2-bit control input. The state machine should take the current position of the robot on a 4x4 grid (2 bits for X and 2 bits for Y) and update the position based on the input direction. The output should be the new position of the robot after the movement.
