

You are tasked with designing a module in Verilog that implements a register with a specific address and data width. The module should be able to handle write operations and reset operations.

Your module should have the following inputs and outputs:

- `in_data` (8 bits): input data to be written to the register
- `wenb` (1 bit): write enable signal
- `reset` (1 bit): reset signal
- `clk` (1 bit): clock signal
- `reg_0x23` (8 bits): output register with address 0x23

The module should work as follows:

- When `reset` is asserted, the output register should be set to 0x00.
- When `wenb` is asserted, the input data should be written to the output register.
- When `wenb` is not asserted, the output register should retain its previous value.

Your task is to implement the Verilog module that meets these requirements. You should name your module `r_COMMAND`.
