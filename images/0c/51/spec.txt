Design a 1-bit SRAM cell that can store a single bit of data. The SRAM cell should have the following inputs: a write enable signal (WE), a data input (D), a read enable signal (RE), and two control signals (SET and RESET) to initialize the cell. The SRAM cell should output the stored bit (Q) when the read enable signal is high. If the write enable signal is high, the input data should be written to the cell. The cell should also respond to the SET and RESET signals to set the stored bit to '1' or '0', respectively.
