Design a 2-to-4 line decoder with an enable input. When the enable input (en) is LOW, the output (y) remains LOW (0000). When enabled and given a 2-bit input (x), the output will assert one of the four possible lines corresponding to the binary value of x: 00 activates output 0001, 01 activates output 0010, 10 activates output 0100, and 11 activates output 1000.
module top_module(
    input [1:0]x,
    input en,
    output [3:0]y
);
