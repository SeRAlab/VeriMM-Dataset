Develop an 8-bit simple calculator that performs arithmetic operations based on a control signal. The module takes two 8-bit inputs, 'a' and 'b', and uses a 2-bit 'control' input to select one of four operations: addition, subtraction, multiplication, or division. The result of the selected operation is output as an 8-bit value.
module top_module(
    input [7:0] a,
    input [7:0] b,
    input [1:0] control,
    output reg [7:0] result
);
