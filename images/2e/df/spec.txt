
Design a 1-bit SRAM cell in Verilog that can store a single bit of data. The cell should have two inputs: a data input (D) and a write enable signal (WE). It should have one output (Q) that reflects the stored value. When the write enable signal is high, the data input should be written to the cell. When the write enable is low, the stored value should be preserved. The module should also include a reset signal (RST) that initializes the stored value to 0 when asserted.
