Design a 3x3 image convolution module in Verilog. The module takes a 3x3 pixel input matrix and a 3x3 kernel as inputs and produces a single output pixel after applying the convolution operation. The output pixel should be a signed 16-bit value, and the input pixels and kernel should be in the range of 8 bits. The convolution formula is: output = sum(input[i][j] * kernel[i][j]) for i = 0 to 2 and j = 0 to 2.
