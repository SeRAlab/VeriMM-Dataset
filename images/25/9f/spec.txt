
Design a Verilog module that performs matrix inversion for a 2x2 matrix. The input will be a 4-bit representation of the matrix elements, and the output will be a 4-bit representation of the inverted matrix elements. The matrix inversion formula for a 2x2 matrix [[a, b], [c, d]] is given by (1/(ad - bc)) * [[d, -b], [-c, a]] when the determinant (ad - bc) is non-zero. If the determinant is zero, the output should be set to zero.
