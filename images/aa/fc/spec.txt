Design a 4-to-1 multiplexer that selects one of four 4-bit wide input signals (in0, in1, in2, in3) based on two selection signals (s0 and s1). The selected output (out) will be one of the four inputs, determined by the binary combination of the selection signals, where s0 and s1 together determine which of the four inputs is routed to the output.
module top_module(
    input [3:0] in0,
    input [3:0] in1,
    input [3:0] in2,
    input [3:0] in3,
    input s0,
    input s1,
    output [3:0] out
);
