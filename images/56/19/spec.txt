Design a memory controller that interfaces with a memory array, featuring a data bus width of 8 bits and an address bus width of 16 bits, supporting up to 1024 memory locations. The controller processes read and write operations synchronized to a clock signal; it reads from the specified memory address when the read_enable signal is asserted and writes to the specified address when the write_enable signal is asserted. It also resets the output read_data to zero upon receiving a reset signal.
module top_module(
  input clk,
  input reset,
  input read_enable,
  input write_enable,
  input [address_width-1:0] address,
  input [data_width-1:0] write_data,
  output reg [data_width-1:0] read_data
);
