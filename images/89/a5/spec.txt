Design a synchronous up/down counter that can count in both directions based on the up_down control signal. When up_down is high, the counter increments its value; when low, it decrements. The counter supports loading a preset 4-bit value from load_data when it is not zero. The counter operates on a clock signal and can be asynchronously reset to zero. This circuit essentially serves as a programmable counter, providing versatile counting capabilities suitable for various digital applications.
module top_module(
    input clk,
    input rst_n,
    input up_down,
    input [3:0] load_data,
    output reg [3:0] count
);
