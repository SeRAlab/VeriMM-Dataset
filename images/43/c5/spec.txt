Design a 4-bit upcounter that increments its output (`out`) on each positive edge of the clock (`clk`). It resets to zero either when the reset signal is asserted or when the counter reaches a specified limit (`N`). When the counter reaches the value of `N`, it wraps around and restarts from zero. This module is suitable for implementing a bounded counting system in digital circuits.
module top_module(
    input clk,
    input reset,
    input [3:0] N,
    output reg [3:0] out
);
