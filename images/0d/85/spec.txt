Design a simple 5-stage instruction pipeline for a basic RISC architecture. The pipeline consists of the following stages: Fetch (IF), Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). Implement a Verilog module that simulates the pipeline, handling instruction fetching and control signals for the pipeline stages. Ensure that there are no data hazards and implement a simple control logic to handle instruction execution flow.
