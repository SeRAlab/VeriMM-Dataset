
Design a simple 5-stage instruction pipeline for a basic CPU. The pipeline stages are: Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). Each stage should be represented by flip-flops to hold intermediate values of the instruction. The pipeline should also handle a simple control signal to indicate when to proceed to the next stage. The design should make sure that the instructions can be passed through the pipeline sequentially, with appropriate clock and reset signals.
