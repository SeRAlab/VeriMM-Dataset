Design a Fractional-N Phase-Locked Loop (PLL) in Verilog. The PLL should take an input reference frequency and a fractional value to generate a desired output frequency. Implement a simple feedback mechanism that adjusts the frequency output based on the phase difference between the reference and output signal. The PLL should have inputs for reference frequency (`ref_freq`), a fractional value (`frac_val`), and a clock signal (`clk`). The output should be the generated frequency (`out_freq`). You may assume a fixed resolution for the fractional control.
