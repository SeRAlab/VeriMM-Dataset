Design a 4-to-1 multiplexer that selects one of four 1-bit input signals based on a 2-bit select input. The output will be set to the value of the selected input, with each selection corresponding to a specific value of the select signal. When sel is 00, the output y will reflect input i[0]; when sel is 01, it will reflect i[1]; sel equal to 10 will make y equal to i[2]; and sel equal to 11 will set y to i[3].
module top_module(input [3:0]i,
input [1:0]sel,
output reg y);
