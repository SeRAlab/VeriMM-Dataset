
Design a JK latch using Verilog. The JK latch should have two inputs J and K, one clock input CLK, and one output Q. The latch should operate as follows: 
- If J = K = 0, Q remains unchanged.
- If J = 1 and K = 0, Q is set to 1.
- If J = 0 and K = 1, Q is reset to 0.
- If J = K = 1, Q toggles its state.
