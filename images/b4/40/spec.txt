Implement the Verilog module based on the following description.
Given a 5-bit FIFO queue with synchronous reset:

1. The queue shifts left on every clock cycle when en is high.
2. Data is added to the queue via the data_in signal.
3. The queue resets to all zeros when the reset signal is high.

Write Verilog implementing this FIFO queue.
module fifo_queue (
        input clk,
        input reset,
        input en,
        input data_in,
        output reg [4:0] queue);
