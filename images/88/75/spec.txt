Design a pulse generator that produces a square wave output with a variable duty cycle, controlled by a 7-bit input representing the percentage. The generator uses a clock signal to increment a counter that determines when to set the output pulse high and low. The pulse remains high for a duration (pulse_width) proportional to the duty cycle percentage of a fixed period. This module can be used in applications requiring PWM (Pulse Width Modulation) signals for LED brightness control, motor speed regulation, or other timing-related tasks.
module top_module(
    input clk,
    input [6:0] duty_cycle_percentage,
    output reg pulse
);
