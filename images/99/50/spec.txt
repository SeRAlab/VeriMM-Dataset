Design a 4-bit shift register with load and reset capabilities. Upon a reset signal, it clears the data to zero. When the load signal is activated, it captures the 4-bit input data. On each clock cycle, if neither reset nor load is active, the register shifts its contents to the right, with the most significant bit (MSB) dropping out as the least significant bit (LSB) is filled with a zero. The MSB also outputs the shifted-out value, while the current state of the register can be accessed via a separate output.
