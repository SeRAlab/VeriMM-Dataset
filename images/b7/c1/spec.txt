Design a 4-bit binary up counter with reset and overflow detection. The counter increments on each positive clock edge and resets to zero when the reset signal is active. It has an overflow output that indicates when the counter has reached its maximum value of 15 (4'b1111) and wraps around to zero.
module top_module(
  input clk,
  input rst,
  output reg [3:0] count_out,
  output reg overflow
);
