Create a Verilog module for an SR flip-flop with asynchronous reset and set. The flip-flop should have the following inputs: S (Set), R (Reset), CLK (Clock), and output Q. The output Q should follow the SR flip-flop behavior with the following truth table:  
When S = 1 and R = 0, Q = 1  
When S = 0 and R = 1, Q = 0  
When S = 0 and R = 0, Q holds its previous value  
When S = 1 and R = 1, the state is undefined. The flip-flop should also have an asynchronous reset that sets Q to 0 when Reset is active.
