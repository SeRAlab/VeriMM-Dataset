
You are tasked with designing a module that takes in 6 input signals and produces 1 output signal. The input signals, A1, A2, B1, B2, C1, and C2, are all of type `input`. The output signal, Y, is of type `output`. The module should be named `six_input_one_output`.

Your task is to create a Verilog module that implements this design. The module should take in the 6 input signals and produce a single output signal, Y. The module should be self-contained and not rely on any other modules.

The module should operate as follows:
- If A1 and A2 are both high, Y should be high.
- If B1 and B2 are both high, Y should be high.
- If C1 and C2 are both high, Y should be high.
- If none of the above conditions are met, Y should be low.
