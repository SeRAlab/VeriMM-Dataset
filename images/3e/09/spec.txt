Design a 16-bit Digital-to-Analog Converter (DAC) controller that takes a 4-bit input signal representing a channel selection (from 0 to 15) and a 16-bit data input representing the value to be converted. The output will be a 16-bit signal that represents the analog value for the selected channel. The DAC should be able to handle multiple channel selections, and the output should reflect the latest data for the selected channel.
