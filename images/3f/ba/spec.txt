Design a Verilog module that implements a 3x3 Gaussian blur filter for a grayscale image. The module takes a 3x3 matrix of pixel values as input and outputs a single blurred pixel value. The Gaussian blur formula to calculate the output pixel is as follows:  
output = (1/16) * (1*p00 + 2*p01 + 1*p02 + 2*p10 + 4*p11 + 2*p12 + 1*p20 + 2*p21 + 1*p22)  
where p00 to p22 are the pixel values in the 3x3 matrix.
