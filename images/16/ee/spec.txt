Design an SPI (Serial Peripheral Interface) controller that operates in master mode. The master device should be able to send and receive 8-bit data to/from a slave device using clock and chip select signals. The controller should manage the communication by generating the clock signal and controlling the chip select signal based on the state of the communication. Implement the SPI controller with the following inputs and outputs: 
- `clk`: System clock
- `reset`: Active-high reset
- `start`: Signal to start the transmission
- `data_in`: 8-bit data to be transmitted
- `MOSI`: Master Out Slave In (data sent to slave)
- `MISO`: Master In Slave Out (data received from slave)
- `SCLK`: Serial clock output to slave
- `CS`: Chip select output to slave
The controller should output the transmitted data on the `MOSI` line and the received data on the `MISO` line.
