

You are tasked with designing a verilog module that takes in two 8-bit inputs, A and B, and outputs a 16-bit signal, C. The output signal should be the sum of the two input signals, and should be updated whenever either input signal changes. You should implement this module using only combinational logic.

Your module should be named "Adder", and should have the following ports:

- A (input, 8 bits)
- B (input, 8 bits)
- C (output, 16 bits)

You may use any built-in verilog operators or constructs to complete this task.
