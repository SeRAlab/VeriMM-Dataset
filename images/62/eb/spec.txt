Design a clock gating module that controls the propagation of a clock signal based on an enable signal. When the inverted clock input (ck_inb) is high, the enable signal is latched to determine if the output clock (ck_out) should be active. The output clock only passes through when both the input clock (ck_in) is high and the enable condition is met, effectively reducing power consumption by disabling the clock when not needed.

    input wire ck_in,
    input wire enable,
