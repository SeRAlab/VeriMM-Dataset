
Design a 4-bit Up/Down counter that counts up when the `up_down` signal is high and counts down when it is low. The counter should have a synchronous reset signal that sets the counter to 0. The counter should also have an enable signal that allows counting only when it is high. If the counter reaches its maximum value (15) while counting up, it should wrap around to 0 on the next count. Similarly, if it reaches its minimum value (0) while counting down, it should wrap around to 15 on the next count.
