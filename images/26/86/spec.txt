Design a fixed-priority arbiter that grants access to one of the multiple requesters based on fixed priority. The arbiter should have 4 request inputs (req[3:0]) and a single grant output (grant). The priority order should be from req[0] (highest priority) to req[3] (lowest priority). If multiple requests are made at the same time, the highest priority request should be granted. Additionally, the arbiter should have a clock and reset signal, where the reset signal clears the grant, setting it to inactive.
