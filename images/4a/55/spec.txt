Design a 9-bit wide, 32x2 asynchronous read/write RAM module with dual port capability. It allows writing data into the memory at a specified address when the write enable signal is active. The memory can store up to 32 entries, each 9 bits wide. On the rising edge of the clock, it outputs the value stored at the read address. This design is suitable for applications requiring simultaneous read and write operations with a simple clock synchronization mechanism.
module top_module(
	input			clock,
	input			wren,
	input	[4:0]		wraddress,
	input	[4:0]		rdaddress,
	input	[8:0]		data,
	output	reg	[8:0]	q 
	);
