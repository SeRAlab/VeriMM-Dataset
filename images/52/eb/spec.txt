Design a dual-port RAM with a storage capacity of 256 words, each 32 bits wide. The module supports simultaneous read and write operations on two separate ports (port A and port B) using a clock signal. When write enable signals (wren_a or wren_b) are asserted, data can be written to the specified addresses in the memory. The outputs (q_a and q_b) provide the data from the read operations at the addresses specified, allowing for independent access to both ports. This configuration is suitable for applications requiring concurrent access to memory from different sources.
module top_module(
  input  wire           clock,
  input  wire           wren_a,
  input  wire [  8-1:0] address_a,
  input  wire [ 32-1:0] data_a,
  output reg  [ 32-1:0] q_a,
  input  wire           wren_b,
  input  wire [  8-1:0] address_b,
  input  wire [ 32-1:0] data_b,
  output reg  [ 32-1:0] q_b
);
