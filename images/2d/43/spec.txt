Design a 5-bit serial-in serial-out (SISO) shift register. The shift register should have a serial input (`s_in`), a clock input (`clk`), and a reset input (`rst`). When the reset is high, the output should be cleared to 0. On each rising edge of the clock, if the reset is low, the shift register should shift in the serial input and shift out the least significant bit (LSB) to the output (`s_out`). The shift register should hold the last 5 bits that were shifted in.
