Design a 4-bit synchronous adder that performs the addition of two 4-bit inputs, `a` and `b`, along with a carry-in signal `cin`. The module includes a reset feature to initialize the output sum and carry-out to zero. On each positive edge of the clock, if the reset signal is not asserted, it computes the sum and updates the outputs accordingly: the `sum` output provides the 4-bit result, while the `cout` output indicates any overflow from the addition.
module top_module(
    input clk,
    input rst,
    input [3:0] a,
    input [3:0] b,
    input cin,
    output [3:0] sum,
    output cout
);
