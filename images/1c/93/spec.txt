
Design an HMAC module in Verilog that takes a key and a message as inputs and produces a 128-bit HMAC output. The HMAC should use the SHA-256 hashing algorithm for the inner and outer hashes. The key should be padded or truncated to 64 bytes as required by the HMAC specification. Implement the module to include a valid output signal that indicates when the HMAC computation is complete.
