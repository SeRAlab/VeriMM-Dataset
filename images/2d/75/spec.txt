
Design a 3x3 morphological dilation operation on a binary image input. The input will be a 3-bit wide and 3-bit high array. The output should be a binary dilation result based on the defined structuring element (which in this case is a 3x3 matrix of ones). The dilation operation will set the output pixel value to 1 if any of the corresponding input pixels are 1 in the neighborhood defined by the structuring element.
