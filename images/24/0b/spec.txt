
Create a Run-Length Encoding (RLE) module in Verilog that takes a binary input stream of fixed length (for example, 8 bits) and outputs the encoded run-length pairs. Each run-length pair consists of the run-length (number of consecutive bits) and the value of the bits (0 or 1). The output should be in the form of a concatenated 16-bit value where the upper 8 bits represent the count and the lower 8 bits represent the bit value. If there are multiple pairs, they should be concatenated together.
