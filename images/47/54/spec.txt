Design a 4-bit magnitude comparator that compares two 4-bit inputs, A and B. The module outputs three signals: EQ (equal), GT (greater than), and LT (less than). The EQ output is asserted when A is equal to B, GT is asserted when A is greater than B, and LT is asserted when A is less than B. The comparison logic is implemented using a combinational always block and a case statement to determine the relationship between the two inputs.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output EQ,
    output GT,
    output LT
);
