Implement the Verilog module based on the following description.
Given a 2-bit binary counter with an enable input and an asynchronous reset:

1. The counter increments on the rising edge of the clock if the enable input is high.
2. The counter resets to zero when the asynchronous reset (reset) is high.

Write Verilog implementing this counter.
module binary_counter_2bit (
        input clk,
        input enable,
        input reset,
        output reg [1:0] count);
