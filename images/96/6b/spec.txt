Design a 4-bit up counter with a load option. The counter increments its value on each rising edge of the clock when the `inc` signal is high. If the counter reaches 9, it rolls over to 0 and sets the carry output high. The counter can be reset asynchronously to a default value specified by `def_value` when `rst_n` is low, or it can load this default value immediately when `ld_def` is asserted. The output `carry` indicates whether a rollover has occurred during the increment operation.
