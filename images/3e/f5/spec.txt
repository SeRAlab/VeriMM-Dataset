Design a Verilog module that performs a simple gradient descent optimization for a function defined as f(x) = x^2. The module should take an input value x and a learning rate alpha, and output the updated value of x after applying one step of gradient descent, which is given by the formula: x_new = x_old - alpha * df/dx, where df/dx = 2*x_old. The module should also retain the previous value of x for the next iteration.
