Design an EEPROM cell with a 1-bit data storage capability. The cell should have the following inputs: a write enable signal (WE), a read enable signal (RE), input data (D), and an output data (Q). The EEPROM cell should be able to write data on a rising edge of WE when RE is low and read data on a rising edge of RE when WE is low. The default state should be 0 when not writing or reading.
