
Design a simple Automatic Repeat reQuest (ARQ) error correction system. The system should take a 5-bit data input and a 1-bit ACK signal that indicates whether the received data was correct (ACK = 1) or incorrect (ACK = 0). If the ACK signal is 0, the system should re-transmit the last sent data; otherwise, it should send the new data. The output should indicate the current data being sent.
