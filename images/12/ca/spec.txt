Design an 8-bit DRAM cell that has a simple read and write operation. The DRAM cell should have inputs for an 8-bit data input (`data_in`), a read enable (`read_en`), a write enable (`write_en`), and a clock (`clk`). When `write_en` is high, the `data_in` should be stored in the cell at the rising edge of the clock. When `read_en` is high, the stored value should be outputted on `data_out`.
