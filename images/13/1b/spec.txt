
Design a 4-channel Direct Memory Access (DMA) controller that allows for data transfer between memory and peripheral devices. The DMA controller should have a control signal to select the active channel, and it should facilitate data transfer based on a simple request (REQ) and acknowledge (ACK) mechanism. Each channel will have a separate REQ and ACK signal. The DMA controller will also have an enable signal to start the transfer process. Implement the logic to manage the state transitions between idle, transfer, and wait states.
