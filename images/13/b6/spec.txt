
Design a simple NVMe controller state machine in Verilog. The NVMe controller should have three states: IDLE, READ, and WRITE. The state transitions should occur based on two inputs: `start_read` and `start_write`. When `start_read` is high, the controller should transition to the READ state. When `start_write` is high, it should transition to the WRITE state. The controller should return to the IDLE state after completing a read or write operation, which is signaled by a `complete` signal that is high for one clock cycle.
