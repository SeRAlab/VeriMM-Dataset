
Design a Verilog module that implements a Discrete Wavelet Transform (DWT) using the Haar wavelet transform. The module should take a 4-bit input signal (representing 4 data points), perform the DWT, and output the transformed 4-bit signal. The transformations should be as follows:
1. Compute the averages and differences for the input.
2. The output will consist of 2 bits for average and 2 bits for difference.
