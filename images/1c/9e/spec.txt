Design a 5-stage pipeline processor that can execute a simple instruction set. The processor should consist of the following stages: Fetch (IF), Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). Each instruction should be a 5-bit binary number, where the first 2 bits represent the operation, and the last 3 bits represent the operand. Implement the Verilog code for the pipeline registers and controls that handle instruction flow through these stages.
