Design a Schmitt trigger circuit that provides hysteresis for an input signal. It uses two threshold values, Vth_high and Vth_low, to determine the output state. When the input exceeds Vth_high, the output is driven high. Conversely, when the input falls below Vth_low, the output is driven low. For input values between the two thresholds, the output retains its previous state, thereby preventing rapid toggling. This design is essential for cleaning noisy input signals in digital circuits.
module top_module(
  input in,
  input Vth_high,
  input Vth_low,
  output out
);
