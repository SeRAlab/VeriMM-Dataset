
Design a simple WiFi connection status monitor. The module should track the connection status of a WiFi module based on a signal that indicates whether the WiFi is connected or disconnected. The status should be updated every clock cycle, and the output should indicate the current status of the WiFi connection as either "Connected" or "Disconnected." 
The input will be a single bit signal `wifi_connected` which is high when connected and low when disconnected. The design should also have a reset signal to initialize the state to "Disconnected."
