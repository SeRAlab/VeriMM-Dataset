Implement a circuit that calculates the Hamming distance between two 8-bit input values, val_a and val_b. The Hamming distance is determined by counting the number of differing bits between the two inputs. On each rising edge of the clock, the module updates the distance output, which is a 4-bit register representing the total count of differing bits computed by summing the individual bits of the XOR result between val_a and val_b.
module top_module(input wire clock,input wire [7:0] val_a, val_b,output reg [3:0] distance);
