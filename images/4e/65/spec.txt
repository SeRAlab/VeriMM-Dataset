Design a simple arithmetic calculator that performs basic operations on two 8-bit inputs, A and B. The module accepts a 2-bit operation selector, 'op', which determines the operation to perform: addition, subtraction, multiplication, or division. The result of the selected operation is output as a 16-bit value. This design allows for efficient computation of arithmetic expressions, making it suitable for integrating into larger digital systems requiring basic calculation functionalities.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input [1:0] op,
    output [15:0] result
);
