Design a multi-input logical function based on the A31O gate, which combines three inputs (A1, A2, A3) and an input (B1) to determine the output X. The output is high (1) when A1 is asserted and A2 is deasserted, or when all three inputs A1, A2, and A3 are asserted; it is low (0) when A2 is asserted and A1 is deasserted. If A1 and A2 are equal, the output directly takes the value of B1. Otherwise, in unspecified conditions, the output becomes an unknown state (1'bx). The design effectively acts as a complex combinational logic function with multiple conditions influencing the final output.
module top_module(
    input  A1,
    input  A2,
    input  A3,
    input  B1,
    output X
);
