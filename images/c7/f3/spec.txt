

You are tasked with designing a module that implements a full adder circuit. The full adder takes in three inputs, two bits to be added and a carry-in bit, and produces two outputs, a sum bit and a carry-out bit. The module should be named `full_adder` and should have the following inputs and outputs:

Inputs:
- `a` (1-bit): The first bit to be added
- `b` (1-bit): The second bit to be added
- `ci` (1-bit): The carry-in bit

Outputs:
- `sum` (1-bit): The sum of the two input bits and the carry-in bit
- `co` (1-bit): The carry-out bit

Your module should be synthesizable, and should be designed using only combinational logic. You should not use any sequential logic elements such as registers or flip-flops. You may use any other combinational logic elements such as gates, multiplexers, or decoders.

Write a Verilog module that implements a full adder circuit according to the above specifications.
