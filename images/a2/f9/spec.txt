On a reset signal, the output data is cleared to zero. The function shifts the current 16-bit output, discarding the oldest data and appending the new 2-bit input, allowing for dynamic data storage in a sequential manner.

    input  wire        clk,
    input  wire        reset,
    input  wire [1:0]  i_data,
    input  wire        en,
    output reg  [15:0] o_data
);
