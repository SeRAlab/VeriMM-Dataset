Design a parameterized FIFO (First-In-First-Out) queue in Verilog. The FIFO should support the following operations: enqueue (push data into the queue) and dequeue (remove data from the queue). Implement a size limit for the queue, and ensure that the enqueue operation fails when the queue is full and that the dequeue operation fails when the queue is empty. The FIFO should have a clock input for synchronous operation, and a reset input to clear the queue.
