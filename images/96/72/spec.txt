Design a 4-bit Gray code counter that increments on each positive clock edge when enabled. The counter resets to 0000 when the reset signal is low. If the enable (`ena`) signal is active, the counter generates the next Gray code value by applying the Gray code transformation to the current count. If `ena` is not active, the counter still performs the Gray code transformation and increments the count with the addition of one, effectively moving to the next Gray code value.
module top_module(
    input clk,
    input rst,
    input ena,
    output reg [3:0] q
);
