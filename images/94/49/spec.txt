Design a Schmitt Trigger circuit that provides hysteresis for input signals. The module takes a single input along with two threshold levels: VTHplus and VTHminus. It outputs a logic HIGH when the input exceeds VTHplus, a logic LOW when it drops below VTHminus, and maintains the last output state when the input is between these thresholds, thereby preventing rapid toggling due to noise or small fluctuations in the input signal.
module top_module(
  input in,
  input VTHplus,
  input VTHminus,
  output out
);
