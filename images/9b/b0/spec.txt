Design a 4-bit binary adder with carry output, which performs the addition of two 4-bit inputs A and B along with a carry-in (Cin) signal. The operation is synchronized to the rising edge of the clock signal (clk) and is initialized or reset low when the active low reset signal (rst_n) is asserted. The result of the addition is stored in a 4-bit output (S), and any carry generated from the addition is signaled through the Cout output.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input Cin,
  input clk,
  input rst_n,
  output reg [3:0] S,  // Change output to reg type
  output reg Cout      // Change output to reg type
);
