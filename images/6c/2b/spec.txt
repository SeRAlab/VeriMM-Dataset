Implement the Verilog module based on the following description.
Design a circuit that takes an input signal a and provides an output signal z. The input a goes to three different two-input gates: an AND, an OR, and an XNOR gate. Each of these gates is connected to the input of a D flip-flop. The outputs of the flip-flops are then fed into a three-input OR gate to produce the output z. The second input of the AND gate is its corresponding flip-flop's complemented output, the second input of the OR gate is its corresponding flip-flop's output, and the second input of the XNOR gate is its corresponding flip-flop's output.
