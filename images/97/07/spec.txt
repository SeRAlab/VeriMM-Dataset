Design a simple arithmetic calculator that performs addition or subtraction on two 4-bit inputs. The operation is determined by a single control signal: when the control signal `op` is 0, the module outputs the sum of `in1` and `in2`; when `op` is 1, it outputs the difference of `in1` and `in2`. The result is a 4-bit wide output.
module top_module(
    input [3:0] in1,
    input [3:0] in2,
    input op,
    output reg [3:0] out
);
