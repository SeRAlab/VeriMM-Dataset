Design an 8-channel DMA (Direct Memory Access) controller that allows multiple data transfers from memory to peripheral devices. The controller should have a control signal input that indicates when a transfer should occur, a select input to choose one of the 8 channels, and a data input for the data to be transferred. The output should indicate the status of the transfer for each channel (active or inactive). The DMA controller should also include a ready signal that indicates when the controller is ready for the next transfer.
