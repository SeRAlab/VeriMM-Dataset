
Design a simple GPIO controller in Verilog that allows reading and writing to a 5-bit data bus. The controller should have the following functionality:
- An input signal `wr_en` (write enable) to indicate when to write data to the GPIO output.
- An input signal `rd_en` (read enable) to indicate when to read data from the GPIO input.
- A 5-bit data input `data_in` and a 5-bit data output `data_out`.
- The output `data_out` should reflect the value of `data_in` when `wr_en` is high, and retain its last value when `rd_en` is high.
- The controller should keep the last written value until a new write occurs.
