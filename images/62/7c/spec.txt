Design a 256-bit binary adder that computes the sum of two 255-bit input values (add_in_0 and add_in_1) upon receiving a clock edge. The module resets the output (add_out) to zero when the reset signal (rst) is high. Otherwise, on each rising clock edge, it updates the output to the sum of the two inputs.
module top_module(
    input wire clk,
    input wire rst,

    input wire [254 : 0] add_in_0,
    input wire [254 : 0] add_in_1,

    output reg [255 : 0] add_out
    );
