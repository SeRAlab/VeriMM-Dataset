Design a 4-bit wide memory module that captures input data on the rising edge of the clock when the write enable signal (wrenb) is active. The module shifts the existing memory content left and appends the input data (din) at the least significant bit position. The output "dout" always provides the most significant bit (MSB) of the memory, while the "hit" output indicates the status of the specific address location by directly accessing the memory content at the given address (addr). This module effectively behaves like a simple shift register with read and write capabilities, while also specifying an addressable hit signal.
module top_module(input wire [3:0] addr,input wire clk,input wire wrenb,input wire din,output wire dout,output wire hit);
