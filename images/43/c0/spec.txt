Design a 8-to-1 multiplexer that selects one of eight 32-bit input signals based on the 3-bit select signal. The module outputs the selected input signal to a 32-bit output. When the select signal (s) ranges from 3'b000 to 3'b111, corresponding input I0 to I7 is routed to the output (o).
module top_module(input [2:0]s,
						input [31:0]I0,
						input [31:0]I1,
						input [31:0]I2,
						input [31:0]I3,
						input [31:0]I4,
						input [31:0]I5,
						input [31:0]I6,
						input [31:0]I7,
						
						output reg[31:0]o
						);
