Design a clock gating module that selectively enables or disables the output clock signal based on an enable input. When the enable (EN) signal is high, the output clock (CLK_G) follows the input clock (CLK); when EN is low, the output is set to LOW, effectively disabling the clock to downstream circuits. This implementation is useful for power management in digital designs, allowing for reduced power consumption when specific parts of the circuit are inactive.
module top_module(
  input CLK,
  input EN,
  output reg CLK_G
);
