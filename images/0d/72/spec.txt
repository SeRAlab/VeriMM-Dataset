Implement a 4-bit shift register with synchronous loading and shifting capabilities. The shift register should have the following inputs: a 4-bit data input (`data_in`), a shift control input (`shift`), a load control input (`load`), and a clock input (`clk`). When `load` is high, the `data_in` should be loaded into the register. When `shift` is high, the register should shift its contents to the right by 1 bit. If both `load` and `shift` are low, the register should hold its current value.
