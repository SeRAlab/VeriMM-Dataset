Design a 256x32-bit instruction memory module that supports both read and write operations. On a positive clock edge, if the reset signal is activated, the memory initializes with predefined instructions at specific addresses. If reset is not asserted and the write signal is high, it updates the memory at the specified address with the provided data input. In all cases, the module outputs the data stored at the given address, facilitating instruction fetching and storage for a processor.
