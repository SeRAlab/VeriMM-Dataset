Design a Verilog module that implements a simple Recurrent Neural Network (RNN) cell for inference. The RNN cell will take an input vector and the previous hidden state, and output the new hidden state. Assume the input and hidden state are both 4-bit wide, and the weights for the input and hidden states are provided as parameters. The output should be a 4-bit value representing the new hidden state computed as the activation of the weighted sum of the input and previous hidden state.
