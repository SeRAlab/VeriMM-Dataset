Design a synchronous 8-bit wide FIFO (First-In-First-Out) memory module with 16 storage locations. It has inputs for data (datain), read and write control signals (rd, wr), a reset signal (rst), and a clock signal (clk). The module outputs the data from the current read pointer (dataout) and indicates whether the FIFO is full or empty through the output signals (full, empty). It handles data storage by writing data to memory locations when the write signal is active and not full, and it reads data from memory when the read signal is active and not empty. The full and empty status signals are managed based on the read and write pointers to prevent overflows and underflows, ensuring robust data handling within the FIFO structure.
