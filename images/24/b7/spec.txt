
Design a Verilog module implementing a simple Kalman filter for sensor fusion. The module should take two inputs: sensor measurement and a predicted state, and output the updated state. The Kalman gain can be simplified as a constant for this problem. The equations for the Kalman filter should be implemented as follows:
1. Kalman Gain (K) = constant
2. Updated State = Predicted State + K * (Sensor Measurement - Predicted State)
