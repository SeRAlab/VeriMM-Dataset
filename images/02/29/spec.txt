Design an 8-to-3 priority encoder. The encoder should take 8 input lines (I0 to I7) and produce a 3-bit output (Y2, Y1, Y0) that represents the index of the highest-order active input line. If no input line is active (all inputs are low), the output should be set to 3'b000. The encoder should also have an active-high enable signal (EN). If EN is low, the output should be 3'b000 regardless of the inputs.
