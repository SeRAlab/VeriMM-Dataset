

You are tasked with designing a verilog module that takes in a 4-bit input signal `a` and outputs a 4-bit signal `b` based on the following rules:
- If the input signal is less than or equal to 4, the output signal should be `a` multiplied by 2.
- If the input signal is greater than 4, the output signal should be `a` divided by 2.

Write a verilog module that implements this functionality.
