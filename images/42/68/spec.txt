Design a two-stage 8-bit counter that increments its value on each clock cycle while the enable signal is asserted. Upon a reset signal, it initializes both stages of the counter to zero. The output reflects the value of the second stage, which serves to create a delay in the counting sequence, effectively doubling the clock frequency for the counted value.
module top_module(
    input clk,
    input reset,
    input enable,
    output reg [7:0] count
);
