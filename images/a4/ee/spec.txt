Design a dual-edge-triggered D flip-flop module with reset and set functionality. The module includes two outputs, Q1 and Q2, which capture the input data D on the rising edge and the falling edge of the clock signal C, respectively. Both outputs are controlled by clock enable (CE) signals; when CE is high, the input D is sampled, while active high reset (R) and set (S) override the corresponding output Q1 or Q2 by forcing them to low or high, respectively.
module top_module(
    output reg Q1, Q2,
    input wire C, CE, D, R, S
);
