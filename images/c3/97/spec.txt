

You are tasked with designing a module for a full adder using Verilog. The module should have three inputs, A, B, and CIN, and two outputs, SUM and COUT. The module should be able to add the two binary inputs A and B, along with a carry input CIN, and produce the binary sum in SUM and the carry out in COUT. 

The module should be named "full_adder" and should be contained within 200 lines of Verilog code. The inputs and outputs should be defined as follows: 

Inputs:
- A (1-bit)
- B (1-bit)
- CIN (1-bit)

Outputs:
- SUM (1-bit)
- COUT (1-bit)

The module should use the following Verilog primitives:
- XOR (^)
- AND (&)
- OR (|)

You may use any other Verilog constructs you see fit.
