Design a convolutional encoder with a constraint length of 3 and a code rate of 1/2. The encoder should take a 1-bit input data stream and produce a 2-bit output for every input bit processed. The generator polynomial can be defined as follows: G1 = 111 and G2 = 101. The output should be valid on the rising edge of the clock. Implement the encoder in Verilog and provide a testbench that verifies its functionality using specified test cases.
