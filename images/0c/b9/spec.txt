
Design a 16-bit timer module that counts up to a specified maximum value. The timer should have the following features:
1. A clock input for timing.
2. A reset input to initialize the timer to zero.
3. A start input to begin counting when activated.
4. A max_value input specifying the maximum count value.
5. An output that indicates the current count value.
6. The timer should wrap around to zero once it reaches the max_value.
