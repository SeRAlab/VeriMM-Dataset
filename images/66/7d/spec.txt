Design a module that converts a 4-bit Binary-Coded Decimal (BCD) input into an 8-bit ASCII output. The module adds an ASCII offset to the BCD value to map it to its corresponding ASCII character. Additionally, it provides specific ASCII representations for the characters '+' (plus sign), '-' (minus sign), and '=' (equal sign) when the BCD value corresponds to the ASCII codes for these characters. For all other BCD values, the output will be the ASCII representation of the numeric character corresponding to the BCD input.
module top_module(
    input [3:0] bcd_in,
    output reg [7:0] ascii_out
    );
