Design a 4-bit up/down counter with load and reset functionalities. The counter increments or decrements its value based on the DIR signal while also allowing for loading an external 4-bit value from D when LOAD is asserted. The counter resets to zero when the RESET signal is active. The counting operation is clocked by CLK, ensuring state updates occur on the rising edge, with the current state being stored in a register.

    input LOAD, RESET, DIR, CLK,
    input [3:0] D,
    output reg [3:0] Q
);
