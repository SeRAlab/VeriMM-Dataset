Design a clock gating circuit for a register file. The module outputs a clock signal (ENCLK) that is active when both the enable (EN) and test enable (TE) signals are asserted, allowing the clock (CLK) to pass through; otherwise, it outputs a LOW signal, effectively reducing dynamic power consumption by disabling the clock to parts of the circuit when they are not in use.
module top_module(
  input CLK,
  input EN,
  input TE,
  output ENCLK
);
