
You are tasked with designing a module that performs the function of a 2x1 multiplexer with 8-bit inputs and outputs. The module should have three inputs, A and B (both 8-bit) and SEL (1-bit), and one output, X (8-bit). The output X should be equal to A when SEL is 0 and equal to B when SEL is 1.

Your task is to create a Verilog module that implements this function. Your module should be named "MUX_2x1_8" and should have the following inputs and outputs:

- input [7:0] A: 8-bit input A
- input [7:0] B: 8-bit input B
- input SEL: 1-bit select input
- output [7:0] X: 8-bit output

Your module should be implemented using only combinational logic and should be no more than 200 lines of Verilog code.
