

You have been tasked with designing a verilog module that will implement a simple 4-bit binary adder. The module should have two 4-bit inputs, A and B, and one 4-bit output, S. The module should also have a single bit input, C_in, which represents the carry-in bit. The module should implement the following function: S = A + B + C_in. 

Design the verilog module that implements this function.
