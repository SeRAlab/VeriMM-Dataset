Design a simple Recurrent Neural Network (RNN) cell in Verilog. The RNN should have a single hidden state that updates based on the current input and the previous hidden state. The inputs to the RNN include the current input data and the previous hidden state. The output is the updated hidden state. The update function can be defined as: new_hidden_state = tanh(W * input + U * previous_hidden_state + b), where W, U, and b are constants (weights and bias) that can be set for simulation purposes.
