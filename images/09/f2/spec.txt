
Design a FIFO (First In, First Out) queue with the following specifications:
- The FIFO should have a configurable depth (number of elements it can hold).
- It should have two main operations: enqueue (to add an element) and dequeue (to remove an element).
- The FIFO should have an empty flag that indicates when it is empty and a full flag that indicates when it is full.
- The depth of the FIFO is parameterized.
