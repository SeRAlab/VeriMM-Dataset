Design a clock gating module that controls the output clock based on an input enable signal. When the input clock (ck_in) is high, the output clock (ck_out) will be derived from ck_in unless the enable signal is low, in which case ck_out will be driven low. This effectively allows the module to disable the clock when not needed, thereby saving power in the circuit.
