
Design a simple SD card controller that reads a block of data from an SD card and stores it in a register. The controller should have an enable signal (`en`), a clock signal (`clk`), and a reset signal (`rst`). When enabled, the controller reads data on the rising edge of the clock from an input data signal (`sd_data`) and stores it in an internal register (`data_reg`). The controller should also have an output signal (`data_out`) that reflects the contents of `data_reg`. The reset signal should clear `data_reg` when asserted.
