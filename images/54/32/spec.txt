Implement the Verilog module based on the following description.
Given a JK flip-flop:

1. The flip-flop toggles its output (Q) on the rising edge of the clock (clk) when both J and K are high.
2. If J is high and K is low, the output (Q) is set to 1.
3. If J is low and K is high, the output (Q) is reset to 0.
4. If both J and K are low, the output (Q) does not change.

Write Verilog implementing this JK flip-flop.
module jk_flip_flop (
        input clk,
        input J,
        input K,
        output reg Q);
