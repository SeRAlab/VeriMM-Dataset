Design a 3x3 Gaussian blur filter circuit in Verilog. The circuit should take a 3x3 pixel input and output a single pixel value representing the blurred result using a Gaussian kernel. The Gaussian kernel weights can be defined as follows:

```
| 1 | 2 | 1 |
| 2 | 4 | 2 |
| 1 | 2 | 1 |
```

The output pixel value is calculated as follows:
```
output_pixel = (1*P1 + 2*P2 + 1*P3 + 2*P4 + 4*P5 + 2*P6 + 1*P7 + 2*P8 + 1*P9) / 16
```
Where P1 to P9 are the pixel values of the input 3x3 matrix.
