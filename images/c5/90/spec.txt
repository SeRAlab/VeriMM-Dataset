

You have been tasked with designing a Verilog module that implements a simple counter. The module should have the following inputs and outputs:

Inputs:
- `clk`: the clock signal.
- `rst`: the reset signal. When `rst` is high, the counter should be reset to 0.
- `enable`: a signal indicating whether the counter should be counting or not.

Outputs:
- `count`: the current count value.

The counter should count up by 1 on each rising edge of the clock signal, if the `enable` signal is high. If the `rst` signal is high, the counter should be reset to 0.

Implement the counter module in Verilog.
