Implement a 3x3 Gaussian blur filter for a grayscale image. The input to the circuit will be a 3x3 matrix of pixel intensity values, and the output will be a single pixel value that represents the blurred result. The Gaussian kernel used for the blur operation is as follows:
```
1  2  1
2  4  2
1  2  1
```
Normalize the result by dividing the sum by 16 (the sum of the kernel). Your circuit should take a 9-bit input for each pixel value (0-255) and output a single 9-bit blurred pixel value.
