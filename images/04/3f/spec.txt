Design a simple SPI (Serial Peripheral Interface) controller that supports basic read and write operations. The controller should have inputs for clock, reset, chip select, MOSI (Master Out Slave In), and an output MISO (Master In Slave Out). The SPI controller should operate in mode 0 (clock polarity = 0, clock phase = 0), meaning data is sampled on the rising edge of the clock and changed on the falling edge. When chip select is low, the controller should read data from MOSI on the clock's rising edge and output the corresponding data on MISO when chip select is low.
