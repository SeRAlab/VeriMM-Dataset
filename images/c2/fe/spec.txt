

You are tasked with designing a verilog module that takes in two inputs, A1 and A2, and one input B1. The module should output a single bit, Y. You are also provided with voltage supply signals, VPWR, VGND, VPB, and VNB, which you should use in your design.

The module should implement the following logic:
- If A1 is high, Y should be high.
- If A1 is low and A2 is high, Y should be high.
- If A1 and A2 are both low and B1 is high, Y should be high.
- In all other cases, Y should be low.

Write the verilog code for the module using the provided inputs and logic.
