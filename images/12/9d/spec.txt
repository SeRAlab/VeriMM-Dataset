Design a 24-bit Digital to Analog Converter (DAC) that takes a 24-bit input signal and outputs a corresponding analog voltage level. The input signal should be treated as a binary representation where the maximum value (2^24 - 1) corresponds to the highest output voltage level, and the minimum value (0) corresponds to the lowest output voltage level. The voltage output can be calculated as (Input / 2^24) * V_ref, where V_ref is the reference voltage (for example, 5V).
