Design a circuit that samples a single input signal on each rising edge, storing the last four samples in a 4-bit register. It maintains a 2-bit counter to track which position to write the incoming sample, cycling through positions 0 to 3. The module outputs the individual bits from the register as separate outputs (out0 to out3), as well as a combined 4-bit output. This module effectively functions as a circular buffer, enabling the retention of the most recent four samples of the input signal.
module top_module(
    input wire in,
    output reg out0,
    output reg out1,
    output reg out2,
    output reg out3,
    output reg out
);
