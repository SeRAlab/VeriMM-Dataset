Design a 7-stage pipeline processor where each stage performs a specific arithmetic operation. The stages are as follows: Stage 1: Addition, Stage 2: Subtraction, Stage 3: Multiplication, Stage 4: Division, Stage 5: Modulus, Stage 6: Increment, Stage 7: Decrement. The processor takes an input value and processes it through each stage, passing the output of one stage as the input to the next stage. The final output should be available after the 7th stage. The design should be capable of handling 8-bit data.
