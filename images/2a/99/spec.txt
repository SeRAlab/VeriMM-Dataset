Design a LIFO stack module in Verilog that supports the following operations: 
1. Push: Push a data item onto the stack.
2. Pop: Remove the top item from the stack.
3. Peek: View the top item without removing it.
The stack should have a maximum size defined by a parameter. Implement a 4-bit data width and a 4-item maximum size in the stack. The module should also indicate whether the stack is empty or full.
