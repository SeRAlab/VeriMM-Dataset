
Create an 8-bit SRAM cell that allows reading and writing data. The SRAM cell should have a write enable signal (we), a clock signal (clk), an 8-bit data input (data_in), an 8-bit data output (data_out), and a 3-bit address input (addr) for selecting one of the 8 memory locations. When write enable is high, the data input should be written to the selected address on the rising edge of the clock. When write enable is low, the data at the selected address should be output to data_out on the rising edge of the clock.
