Design a 16-entry register file that supports read and write operations for 32-bit data. The module accepts a clock signal to synchronize updates. It allows writing to a specified register indexed by `a3`, provided the write enable signal `we3` is high. It also has a special register at index 15 that can be updated with a 32-bit input `r15`. When reading, it outputs the content of registers indexed by `a1` and `a2`, with the ability to select the value of the special register `r15` if either index equals 4'b1111.
module top_module(input clk,input we3,input [3:0]a1,input [3:0]a2,input [3:0]a3,input [31:0] wd3,input [31:0] r15,output [31:0]rd1 ,output[31:0] rd2);
