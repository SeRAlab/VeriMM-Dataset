Design a 4-to-1 multiplexer that takes four 1-bit input signals and selects one of them to output based on the value of two selection signals. When select_signals are 00, 01, 10, or 11, the corresponding input signal (input_signals[0], input_signals[1], input_signals[2], or input_signals[3]) is assigned to the output_signal. If the select signals are outside of the defined range, the output will result in an unknown state (1'bx).
module top_module(
    input [3:0] input_signals,
    input [1:0] select_signals,
    output reg output_signal
);
