Design a multi-input AND gate circuit that takes four inputs (A1, A2, A3, A4) and one additional input (B1) to produce a single output (Y). The output Y is set to HIGH only when all four inputs A1, A2, A3, and A4 are HIGH, and B1 is also HIGH. The design uses intermediate wires to combine the results of two pairs of AND operations before applying a final AND operation with B1.
module top_module(
    input A1,
    input A2,
    input A3,
    input A4,
    input B1,
    output Y
);
