Design a 24-bit digital-to-analog converter (DAC) using Verilog. The DAC should take a 24-bit input value and produce a corresponding analog output signal. The output signal should be represented as a 32-bit unsigned integer that scales the 24-bit input to a range of 0 to 2^32 - 1. The DAC should also include a simple gain control input that can adjust the output signal's amplitude by a factor of 1, 2, or 4.
