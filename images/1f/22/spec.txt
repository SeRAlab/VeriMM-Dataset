Design a 4-bit DRAM cell that includes functionalities for reading and writing data. The DRAM cell should have the following inputs and outputs: a 4-bit data input (DIN), a 4-bit data output (DOUT), a read signal (READ), a write signal (WRITE), and a clock signal (CLK). When the WRITE signal is high, the DIN should be stored in the internal memory on the rising edge of CLK. When the READ signal is high, the internal memory should output the stored value to DOUT on the rising edge of CLK.
