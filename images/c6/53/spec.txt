

You are tasked with designing a module that implements a D flip-flop with an asynchronous reset. The module should have three inputs and one output, as follows:

- `CLK` (input): the clock signal
- `D` (input): the data input
- `RST` (input): the asynchronous reset signal
- `Q` (output): the data output

The module should operate as follows:

- When `RST` is asserted (i.e., set to 1), `Q` should be set to 0, regardless of the value of `D`.
- When `RST` is deasserted (i.e., set to 0), `Q` should follow the value of `D` on the rising edge of the clock.

Your module should be implemented within 200 lines of verilog code.
