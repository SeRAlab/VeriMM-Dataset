Implement a Verilog module that calculates the 2's complement of an 8-bit input. The module should have the following specifications:
- `clk`: The clock signal.
- `reset`: An active-high synchronous reset signal.
- `start`: An active-high signal that starts the calculation.
- `data_in`: The 8-bit input data.
- `data_out`: The output which holds the 2's complement of the input data.
- `done`: An active-high signal indicating the completion of the calculation.
