
Design a FIFO (First-In-First-Out) queue with the following specifications:
- The FIFO should support a maximum depth of 8.
- The FIFO should have the following inputs:
  - `clk`: Clock signal.
  - `reset`: Asynchronous reset signal.
  - `enqueue`: Signal to enqueue data.
  - `dequeue`: Signal to dequeue data.
  - `data_in`: 8-bit data input.
- The FIFO should have the following outputs:
  - `data_out`: 8-bit data output.
  - `full`: Signal indicating if the FIFO is full.
  - `empty`: Signal indicating if the FIFO is empty.
