Design a circuit that performs various bitwise operations on two 4-bit inputs, `a` and `b`. The operation is determined by a 2-bit control signal, `ctrl`. The circuit outputs the result of a bitwise AND when `ctrl` is 00, a bitwise OR when `ctrl` is 01, a bitwise XOR when `ctrl` is 10, and a bitwise NAND when `ctrl` is 11. The design defaults to outputting zero for any undefined control values.
module top_module(
  input [3:0] a,
  input [3:0] b,
  input [1:0] ctrl,
  output reg [3:0] out
);
