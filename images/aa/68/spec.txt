Implement a Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state R (V = 1).
2. state S (V = 0).
3. state T (V = 1).
4. state U (V = 0).

State transitions:
1. From state R: If e = 0, then transition to state S. If e = 1, then transition to state T.
2. From state S: If e = 0, then transition to state U. If e = 1, then transition to state R.
3. From state T: If e = 0, then transition to state U. If e = 1, then transition to state S.
4. From state U: If e = 0, then transition to state T. If e = 1, then transition to state R.

Assume that you want to Implement the FSM using two flip-flops and state codes x[1:0] = 00, 01, 10, 11 for states R, S, T, U, respectively. Implement just the next-state logic for x[1] in Verilog. The output V is x[1].
