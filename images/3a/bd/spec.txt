Design a simple SATA controller state machine that manages the states of a SATA device. The controller should have the following states: IDLE, ACTIVE, and ERROR. The controller should transition from IDLE to ACTIVE on a 'start' signal and from ACTIVE to IDLE on a 'stop' signal. The controller should enter ERROR state if an 'error' signal is asserted while in ACTIVE state. The output of the controller should indicate the current state as a 2-bit binary value.
