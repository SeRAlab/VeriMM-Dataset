Implement a module of a 4-bit counter with enable and reset functionality. The counter increments its value on every positive clock edge when the enable signal is high. If the reset signal is asserted, the counter resets to 0.

Module name:  
    counter

Input ports:
    CLK: Clock input
    RST: Active high reset signal
    EN: Enable signal

Output ports:
    Q: 4-bit output representing the counter value

Implementation:
The counter module uses an always block triggered on the positive edge of the clock signal (posedge CLK) or the positive edge of the reset signal (posedge RST). If the reset signal is active (RST), the counter value (Q) is set to 0. If the enable signal (EN) is high and the reset signal is not active, the counter value increments by 1. Otherwise, the counter value remains unchanged.

Give me the complete code.

module counter(CLK, RST, EN, Q);
input CLK, RST, EN;
output [3:0] Q;
reg [3:0] Q;
