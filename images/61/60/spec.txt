Design a 4-bit counter with an integrated delay mechanism. The counter increments its value on every fourth clock cycle when enabled, while also allowing for an asynchronous reset that sets the counter to zero when the input signal 'in' is asserted. The counter's output can be monitored through the 'count' output, which reflects the current count value. The delay functionality is facilitated by a 2-bit delay counter that controls the timing of the increment.
module top_module(input clk, input reset, input enable, input in, output reg [3:0] count);
