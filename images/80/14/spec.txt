Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state P (output 1).
2. state Q (output 0).
3. state R (output 1).
4. state S (output 0).

State transitions:
1. From state P: If h = 1, then transition to state Q. If h = 0, then transition to state S.
2. From state Q: If h = 1, then transition to state R. If h = 0, then transition to state P.
3. From state R: If h = 1, then transition to state S. If h = 0, then transition to state P.
4. From state S: If h = 1, then transition to state Q. If h = 0, then transition to state P.

Assume that a one-hot code is used with the state assignment y[3:0] = 0001(P), 0010(Q), 0100(R), 1000(S)

Write a Verilog for the signal Y2, which is the input of state flip-flop y[2], for the signal Y3, which is the input of state flip-flop y[3]. Derive the Verilog by inspection assuming a one-hot encoding.
