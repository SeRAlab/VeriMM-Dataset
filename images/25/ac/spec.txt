Design a 4-channel DMA controller that handles requests from multiple devices. The DMA controller should have a clock input, reset input, and four request lines (req[3:0]). When a request is received, the controller should grant access to the requested channel and output the channel number on a grant line (grant[3:0]). The controller should also implement a round-robin scheduling algorithm for channel access. The controller should have a state to manage the current channel being serviced.
