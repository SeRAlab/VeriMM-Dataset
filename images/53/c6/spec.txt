Design a circuit that implements a delay mechanism, counting up to a specified number of clock cycles defined by the parameter WAIT_CYCLES. The module takes a clock signal (clk), a reset signal (rst), and an enable signal (en) as inputs. Upon resetting or when the enable signal is low, the counter resets to zero. When enabled, the counter increments on each rising edge of the clock. The output (rdy) is asserted high when the counter reaches the specified WAIT_CYCLES, indicating that the desired delay has been achieved.
module top_module(input clk, rst, en, output rdy);
