

You are tasked with designing a verilog module that performs a bitwise XOR operation between two 8-bit input vectors and generates an 8-bit output vector. The module should have the following ports:
- `input [7:0] a`: the first 8-bit input vector
- `input [7:0] b`: the second 8-bit input vector
- `output reg [7:0] result`: the 8-bit output vector

The module should also have the following functionality:
- The module should perform a bitwise XOR operation between the two input vectors and store the result in the `result` register.
- The module should be sensitive to any changes in the input vectors and update the output vector accordingly.
- The module should be synthesizable and meet timing requirements.

Design the module and test it with appropriate test cases to ensure correct functionality.
