Design a simple GPIO controller in Verilog that allows for reading from and writing to an 8-bit GPIO port. The controller should have an input for a write enable signal (we), a read enable signal (re), a data input (data_in), and a data output (data_out). When the write enable signal is high, the data input should be stored in the GPIO port. When the read enable signal is high, the stored data should be output. The GPIO port should maintain its state when both signals are low.
