Design a synchronous register adder that operates on two 8-bit inputs, d1 and d2. On the negative edge of the clock, if the reset signal is asserted, the registers are initialized to the value 0x34. Otherwise, reg1 is loaded with the value of d1 and reg2 is loaded with the value of d2. The output q continuously provides the sum of reg1 and reg2, effectively functioning as an adder circuit that updates its output based on the latest inputs and the clock signal.
module top_module(
    input clk,
    input reset,
    input [7:0] d1,
    input [7:0] d2,
    output [7:0] q
);
