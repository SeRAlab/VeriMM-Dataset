
Implement a FIFO (First In, First Out) queue in Verilog. The FIFO should support the following operations: enqueue (add an item to the end of the queue), dequeue (remove an item from the front of the queue), and check if the queue is empty. The queue should have a fixed size of 4. The interface should include a clock signal, reset signal, enqueue signal, dequeue signal, and a data input/output.
