Design a 4-bit adder/subtractor circuit. The module takes two 4-bit inputs, `a` and `b`, and a control signal `sub`. When `sub` is low, the circuit performs binary addition of `a` and `b`, outputting the result on `sum`. When `sub` is high, it performs binary subtraction of `b` from `a`, also outputting the result on `sum`.
module top_module(
    input [3:0] a,
    input [3:0] b,
    input sub,
    output reg [3:0] sum
);
