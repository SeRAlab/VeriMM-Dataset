Design a 32-bit wide, 4-to-1 multiplexer. It selects one of the three input buses (in1, in2, in3) based on a 2-bit select signal. If select is 00, output in1; if select is 01, output in2; if select is 10, output in3; and if select is 11, output a constant zero.
module top_module(
	input [1:0] select,
	input [31:0] in1,
	input [31:0] in2,
	input [31:0] in3,
 	output [31:0] out
);
