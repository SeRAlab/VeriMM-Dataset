Design a 4-bit shift register with load and reset functionality. On a rising clock edge, when the reset (RST) signal is high, all four registers are cleared to zero. If the load (LD) signal is asserted, the first register (reg1) is loaded with data from the input (D), and the other registers hold the values shifted from one register to the next. If LD is not asserted, the values are shifted through the registers sequentially. The output (OUT) is taken from the last register (reg4), providing the state of the shift register.
module top_module(
    input CLK,
    input RST,
    input LD,
    input [3:0] D,
    output reg [3:0] OUT
);
