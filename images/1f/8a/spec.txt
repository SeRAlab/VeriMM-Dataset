
Design a Verilog module that performs Huffman encoding for a fixed set of input characters. The module should take a 4-bit input representing a character and output a corresponding variable-length encoded binary string based on predefined Huffman codes. The output should be a 12-bit wide signal, where unused bits are filled with zeros. The Huffman codes for the characters A, B, C, D, and E are as follows:
- A: 00
- B: 01
- C: 10
- D: 110
- E: 111
