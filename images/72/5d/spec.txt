Design a 32-bit wide logical operations module that performs various bitwise operations based on a 3-bit operation selector. The operations include bitwise OR, AND, NOR (the negation of OR), and XOR, determined by the values of the `operation` input. The results of these operations are output as `res`. For operations not defined by the selector, the result will be set to an unspecified value.
module top_module(
        input   wire[31:0]  op1,
        input   wire[31:0]  op2,
        input   wire[2:0]   operation,
        output  wire[31:0]  res
    );
