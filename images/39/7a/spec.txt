
Design a Verilog module that simulates a basic EEPROM cell. The EEPROM cell should have the following characteristics:
- A 1-bit data input (D).
- A write enable signal (WE) that controls writing to the cell.
- A read enable signal (RE) that controls reading from the cell.
- A 1-bit data output (Q) which holds the stored value.
- The cell retains its value when not writing or reading.
