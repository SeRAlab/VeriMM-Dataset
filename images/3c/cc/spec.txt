
Design a simple Kalman filter in Verilog that estimates the state of a system given noisy measurements. The system will have the following parameters:
- State variable (x): a 16-bit signed integer
- Measurement variable (z): a 16-bit signed integer
- Process noise (q): a 16-bit signed integer
- Measurement noise (r): a 16-bit signed integer
- The Kalman gain (K), predicted state (x_pred), and estimated state (x_est) should be computed in a clocked process.
