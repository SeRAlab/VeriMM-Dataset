
Design a Verilog module that implements a simple gradient descent algorithm for minimizing a quadratic function of the form f(x) = ax^2 + bx + c. The module should take parameters a, b, and c as inputs and output the optimized value of x after a fixed number of iterations. The optimization step size (learning rate) should also be an input to the module. Implement the functionality to iterate a specified number of times and update the value of x based on the gradient descent formula x = x - learning_rate * df/dx, where df/dx = 2ax + b.
