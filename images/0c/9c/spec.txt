Design a simple firewall packet filtering system that checks incoming packets based on predefined rules. The system should include a shift register to store the current state of the packet being analyzed. It will accept a 5-bit packet input and a control signal indicating whether to accept or drop the packet. The system should have the following rules: If the packet matches a predefined bit pattern (e.g., `10101`), it is accepted; otherwise, it is dropped. The module should output a signal indicating whether the packet is accepted (1) or dropped (0).
