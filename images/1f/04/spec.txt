Design a 4-bit Serial-In Serial-Out (SISO) Shift Register. The shift register should have a serial input (data_in), a clock input (clk), and a reset input (reset). When reset is asserted, the shift register should be cleared. On each clock edge, the data should shift in from the input. The output (data_out) should be available after the last bit has been shifted in once the shift operation is complete.
