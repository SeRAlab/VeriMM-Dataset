
Create a simple Direct Memory Access (DMA) controller. The DMA controller should manage the transfer of data from a source address to a destination address in memory. It will have inputs for the source address, destination address, transfer size, and a start signal. The output will indicate when the transfer is complete. The transfer is controlled by a clock signal. When the start signal is asserted, the DMA should begin transferring data in a loop until the specified transfer size is complete.
