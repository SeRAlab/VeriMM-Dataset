

You are tasked with designing a module that performs a full adder operation on three input bits A, B, and CIN, and produces two output bits COUT and SUM. The module should be named "full_adder" and take the following inputs and outputs:

Inputs:
- A (1-bit): The first input bit
- B (1-bit): The second input bit
- CIN (1-bit): The carry-in bit

Outputs:
- COUT (1-bit): The carry-out bit
- SUM (1-bit): The sum of the three input bits

Your module should implement the following logic:

- The SUM output should be the XOR of the three input bits (A XOR B XOR CIN).
- The COUT output should be the OR of the following three conditions:
  - A AND B
  - A AND CIN
  - B AND CIN

Ensure that your module is self-contained and does not require any additional modules or libraries.
