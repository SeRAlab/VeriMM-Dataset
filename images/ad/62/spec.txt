Design a 4-bit synchronous counter with load capability. The counter increments its value on each positive clock edge unless RESET is asserted, in which case it resets to zero. If LOAD is activated, the counter will be set to the value specified by the LOAD_VAL input instead of incrementing. This design allows for both counting and loading specific values into the counter as needed.
module top_module(
    input CLK,
    input RESET,
    input LOAD,
    input [3:0] LOAD_VAL,
    output reg [3:0] Q
);
