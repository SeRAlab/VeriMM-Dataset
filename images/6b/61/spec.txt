Design a 4-bit ripple carry adder that adds two 4-bit inputs, A and B, along with a carry-in signal, Cin. The module outputs a 4-bit sum, S, and a carry-out signal, Cout, which indicates whether there is an overflow beyond the 4-bit result. The sum is calculated using combinational logic, and the carry-out is determined based on the most significant bit of the sum.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input Cin,
  output reg [3:0] S,  // Change to output reg
  output reg Cout      // Change to output reg
);
