Design a T flip-flop that toggles its output state based on the input signal 't' on the rising edge of the 'clk' signal. The flip-flop is asynchronous and will reset the output 'q' to LOW when the 'reset' signal is asserted LOW. When 'reset' is not active, if 't' is HIGH, the output 'q' will toggle between HIGH and LOW with each clock cycle.
module top_module(
  input clk,
  input reset,
  input t,
  output reg q
);
