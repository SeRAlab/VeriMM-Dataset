Design a 64-bit pseudorandom number generator that operates on the rising edge of a clock signal. The circuit initializes a state variable and then continually updates it using a series of linear feedback shift operations combined with constant multiplications to generate a new 64-bit value. Finally, it outputs the upper 32 bits of this generated value as the module's output. This design effectively implements a variant of the SplitMix random number generation algorithm.
