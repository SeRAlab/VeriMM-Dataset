
Design a 2-channel DMA (Direct Memory Access) controller that supports two channels. Each channel can be enabled or disabled independently. The DMA controller manages the data transfer between memory and peripherals. It should have the following inputs and outputs:
- Inputs:
  - clk: Clock signal
  - reset: Active-high reset signal
  - enable_ch1: Enable signal for channel 1
  - enable_ch2: Enable signal for channel 2
  - data_in_ch1: Data input for channel 1
  - data_in_ch2: Data input for channel 2
- Outputs:
  - data_out_ch1: Data output for channel 1
  - data_out_ch2: Data output for channel 2
  - transfer_complete_ch1: Transfer complete signal for channel 1
  - transfer_complete_ch2: Transfer complete signal for channel 2

The DMA controller should transfer data from the input to the output when the respective channel is enabled, and signal transfer completion after each data transfer.
