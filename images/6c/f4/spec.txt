Design a circuit that implements a 4-input NOR function. The module takes four single-bit inputs (A, B, C, D) and performs a NOR operation across those inputs, producing a single output (Y) that is LOW when any of the inputs are HIGH and HIGH only when all inputs are LOW. The design effectively combines two intermediate NOR operations on pairs of inputs before using another NOR to achieve the final output.
module top_module(
    input  A,
    input  B,
    input  C,
    input  D,
    output Y
);
