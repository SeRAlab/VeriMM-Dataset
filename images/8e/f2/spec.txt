Design a one-bit wide, 2-to-1 multiplexer. The output 'out' will select between two inputs, 'in0' and 'in1', based on the value of the select signal 'sel'; when 'sel' is 0, 'out' will match 'in0', and when 'sel' is 1, 'out' will match 'in1'.
module top_module(
    // Module ports
    input  in0,
    input  in1,
    input  sel,
    output out
);
