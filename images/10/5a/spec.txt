
Design a Verilog module that implements a simplified version of the Mersenne Twister pseudorandom number generator. The module should have an input clock, a reset signal, and a start signal. When the start signal is asserted, the module should begin generating pseudorandom numbers. The output should consist of a 32-bit random number every cycle until the start signal is de-asserted. The internal state should be properly updated in each clock cycle.
