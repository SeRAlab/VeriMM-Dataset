Design a simple decision tree for binary classification based on two input features (x1 and x2). The decision tree will classify the inputs into two output classes (0 or 1) based on the following rules:
- If x1 < 5 and x2 < 5, output 0.
- If x1 < 5 and x2 >= 5, output 1.
- If x1 >= 5 and x2 < 5, output 1.
- If x1 >= 5 and x2 >= 5, output 0.
