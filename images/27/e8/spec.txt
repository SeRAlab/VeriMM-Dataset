Design a LIFO stack module in Verilog. The stack should have the following functionalities: 
1. Push an 8-bit value onto the stack.
2. Pop an 8-bit value from the stack.
3. Check if the stack is empty.
4. Check if the stack is full (assuming a stack depth of 8).
The module should have the following ports:
- clk: Clock signal
- rst: Active high reset signal
- push: Active high push signal
- pop: Active high pop signal
- data_in: 8-bit input data to be pushed onto the stack
- data_out: 8-bit output data popped from the stack
- is_empty: Output signal that goes high if the stack is empty
- is_full: Output signal that goes high if the stack is full
