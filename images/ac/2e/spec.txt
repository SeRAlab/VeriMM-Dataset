State transitions:
1. From state K: If in = 0, then transition to state L. If in = 1, then transition to state M.
2. From state L: If in = 0, then transition to state N. If in = 1, then transition to state K.
3. From state M: If in = 0, then transition to state L. If in = 1, then transition to state N.
4. From state N: If in = 0, then transition to state K. If in = 1, then transition to state M.

Output logic:
1. From state K: out = 0.
2. From state L: out = in.
3. From state M: out = 1.
4. From state N: out = ~in.
