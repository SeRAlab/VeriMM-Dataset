
Design a simple Sliding Window Protocol implementation in Verilog that handles data transmission with a fixed window size of 4. The protocol should include mechanisms for sending data frames, receiving acknowledgments, and managing the window size based on received acknowledgments. Your design should support the following operations:
1. Sending data frames.
2. Receiving acknowledgments.
3. Handling timeouts (simulated with a simple toggle signal).
The design should have the following inputs and outputs:
- Input: `send_frame` (to trigger sending a frame), `ack` (to acknowledge receipt), `timeout` (to simulate a timeout).
- Output: `frame_sent` (indicates a frame has been sent), `frame_ack` (indicates a frame has been acknowledged).
