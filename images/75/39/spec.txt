Design a D-type flip-flop with asynchronous reset and an enable signal. On the rising edge of the clock, if the reset is low, the output q is set to LOW. If reset is not active and the enable signal is high, the output q captures the value of the input d. This module thus functions as a memory element that can be asynchronously reset and conditionally updated based on an enable signal.
