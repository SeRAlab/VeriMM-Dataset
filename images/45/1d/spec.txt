Please act as a professional Verilog designer.

Implement an 8-bit register with synchronous reset. The register should hold the input data on each positive clock edge when the reset signal is low. When the reset signal is high, the register should reset to zero on the next positive clock edge.

Module name:
    register

Input ports:
	clk: Clock signal used for synchronous operations.
	reset: Synchronous reset signal. When high, the register resets to zero.
	d: 8-bit input data.

Output ports:
	q: 8-bit output data.
