Design a virtual memory management unit that translates a virtual address to a physical address using a simple page table. The unit should have a clock input, a reset input, a virtual address input, and a physical address output. The page table is small and can hold 4 entries for simplicity. The virtual address will consist of 8 bits, where the upper 4 bits represent the page number and the lower 4 bits represent the offset. The module should handle address translation on the rising edge of the clock.
