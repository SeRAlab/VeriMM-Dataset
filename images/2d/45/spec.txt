Design a Verilog module that takes a 2x2 matrix as input and outputs its inverse. The input matrix is represented as four 8-bit values (a, b, c, d) representing the matrix:
```
| a b |
| c d |
```
The inverse of this matrix, if it exists, is given by the formula:
```
1/(ad - bc) * |  d -b |
              | -c  a |
```
If the determinant (ad - bc) is zero, the output should be set to zero to indicate that the matrix is not invertible.
