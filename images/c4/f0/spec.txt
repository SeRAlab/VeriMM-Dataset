

In digital circuit design, a flag register is a type of register that stores a single bit of information which can be used to indicate a certain condition or state. In this problem, you are required to design a flag register using Verilog HDL. The flag register should have the following inputs and outputs:

Inputs:
- IN_FLAG: a single bit input that sets the value of the flag register
- LD: a single bit input that loads the value of IN_FLAG into the flag register
- SET: a single bit input that sets the value of the flag register to 1
- CLR: a single bit input that clears the value of the flag register to 0
- CLK: a single bit input that serves as the clock signal

Outputs:
- OUT_FLAG: a single bit output that represents the current value of the flag register

You are required to write a Verilog module named "flag_register" that implements the flag register described above.
