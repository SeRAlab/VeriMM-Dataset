Design a dual-port memory module that allows simultaneous read and write operations using separate write enables and address lines. The module uses a clock signal for operation and can write to memory locations specified by `addra` and `addrb` when the corresponding write enables `wea` and `web` are asserted. Data written to memory can be either `dina` or `dinb`, depending on the active write enable. Additionally, it retrieves and outputs the data stored at address `addra` on request, providing a default output of zero when accessing an out-of-bounds address. This module is suitable for applications requiring controlled access to a shared memory space.
