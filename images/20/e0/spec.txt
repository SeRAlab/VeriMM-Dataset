Design a Verilog module that simulates a simple Flash memory cell with the ability to read and write a 1-bit value. The module should include a clock input, a write enable signal, an input data signal, and an output data signal. When the write enable signal is high, the input data should be written to the memory cell on the rising edge of the clock. The output data should reflect the current state of the memory cell at all times, regardless of the write enable signal.
