

You are tasked with designing a module that takes in a 4-bit binary input and outputs its two's complement representation. The module should be named `twos_complement` and should have the following ports:

- `input [3:0] in`: the 4-bit binary input
- `output [3:0] out`: the 4-bit two's complement output

The module should follow the two's complement rules for negative numbers: invert all bits and add 1 to the result. For example, the two's complement representation of -3 would be 1101 (invert 0010 and add 1).

Your module should be able to handle both positive and negative input values. If the input value is positive, the output should be the same as the input. If the input value is negative, the output should be the two's complement representation.

Assume that the input value will always be within the range of -8 to 7 (inclusive).

Write the verilog module `twos_complement` to solve this problem within 200 lines of code.
