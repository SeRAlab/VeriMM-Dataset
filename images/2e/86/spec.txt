Design a Verilog module that implements a simple state machine for a robot that can navigate through a grid based on input signals. The state machine has three states: IDLE, MOVING, and STOP. The input signals are 'start', 'stop', and 'move'. The output signal indicates the current state of the robot in binary format, where IDLE = 2'b00, MOVING = 2'b01, and STOP = 2'b10. The state machine transitions based on the input signals as follows: 
- From IDLE, if 'start' is high, go to MOVING.
- From MOVING, if 'stop' is high, go to STOP; if 'move' is high, stay in MOVING.
- From STOP, if 'start' is high, go back to MOVING.
