Design a 32-element RAM module capable of storing 32-bit data words. The module has a write enable signal (`we`), a clock signal (`clk`), a 32-bit input for data (`datain`), and a 32-bit address input (`addr`). On the rising edge of the clock, if `we` is asserted, the data input is written to the RAM at the specified address (using the upper 4 bits of the address for word selection). The data at the specified address can be read out through the `dataout` output. The RAM is initialized with specific values, with the rest set to zero. This module serves as a simple and efficient memory component for digital systems.
