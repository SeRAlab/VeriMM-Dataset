Design a 32-bit wide data memory module with a depth of 128 entries, functioning as a RAM. The module supports read and write operations controlled by a clock signal. When writing, if the write enable (WE) signal is asserted, the data input (WD) is stored at the address specified by the upper bits of the address input (A). Read operations return the data corresponding to the addressed entry unless the address exceeds the valid range, in which case the output is high-impedance. Initialization sets all memory entries to zero upon module instantiation.
module top_module(A,RD,WD,WE,Clk);
