Design a pulse-width modulation (PWM) generator. The module produces a digital output pulse that varies in width based on the value of the input 'width'. The pulse is high when the counter (which increments on every clock cycle) is less than 'width', and low otherwise. This allows for control over the duty cycle of the output pulse relative to the input clock frequency.
module top_module(
    input wire clk,
    input wire [13:0] width,
    output reg pulse
);
