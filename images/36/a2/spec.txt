
Design a Verilog module for a current sensor that processes an analog input signal representing current. The sensor should have a clock input and a reset input. On each rising edge of the clock, if the reset is low, the sensor should sample the current input signal and output a binary representation of the current value. The current value should be stored and held until the next clock edge. The current sensor should also provide an output flag indicating whether the current exceeds a certain threshold, which is defined as a parameter.
