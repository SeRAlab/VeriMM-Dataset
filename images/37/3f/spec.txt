Design a 2nd-order Infinite Impulse Response (IIR) filter in Verilog. The IIR filter should take a 16-bit signed input sample and produce a 16-bit signed output sample. The filter coefficients will be predefined as constants. The filter should implement the following difference equation:  
y[n] = b0 * x[n] + b1 * x[n-1] + b2 * x[n-2] - a1 * y[n-1] - a2 * y[n-2]  
with b0=1, b1=0.5, b2=0.25, a1=0.5, a2=0.25. The filter should have a clock input and a reset input, and it should produce output on the rising edge of the clock.
