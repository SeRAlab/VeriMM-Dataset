Design an 8-bit parallel-in serial-out (PISO) shift register. The register captures 8-bit parallel data on a load signal and then shifts the data out serially on every positive edge of the clock signal (clk).

Module name:  
    piso_shift_reg_8bit  

Input ports:
    clk: Chip clock signal.
    rst_n: Active-low reset signal. Defined as 0 for chip reset and 1 for reset signal inactive.
    load: Load signal to capture parallel data.
    pdata: 8-bit parallel data input.

Output ports:
    sdata: Serial data output.

Implementation:

If the load signal is high, the shift register captures the parallel data (pdata).
Otherwise, the shift register shifts the data out serially.
