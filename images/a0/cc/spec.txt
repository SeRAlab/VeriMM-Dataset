Design a Verilog module that implements an 8-bit shift register with a parallel load. The shift register shifts left by one bit on each positive clock edge if the shift_enable signal is high. If load_enable is high, it loads the input data instead.
module shift_register (
    input clk,
    input shift_enable,
    input load_enable,
    input [7:0] data_in,
    output [7:0] data_out );
