Implement a simple 2-bit branch predictor using a 2-bit saturating counter. The predictor should output a 'Taken' or 'Not Taken' signal based on the current prediction state. The predictor has two inputs: a `branch_signal` which indicates a branch instruction and an `actual_outcome` which indicates if the branch was actually taken or not. The counter should update its state based on the actual outcome after each branch instruction.
