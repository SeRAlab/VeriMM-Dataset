

You are tasked with designing a verilog module that takes in a 4-bit input, performs a bitwise AND operation with a 4-bit constant value, and outputs the result. The module should have the following ports:

- `input [3:0] in_data`: a 4-bit input
- `output [3:0] out_data`: a 4-bit output

The module should also have a parameter `const_val` that is set to the value `4'b1100`.

Write the verilog code for the module that meets the above requirements.
