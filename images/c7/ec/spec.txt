

You are tasked to design a verilog module that takes in two 4-bit inputs, A and B, and outputs a 4-bit result, Z. The output Z should be the bitwise OR of A and B, except for the third bit, where the output should be inverted. You are not allowed to use the bitwise NOT operator (~) in your solution.

Write a verilog module that implements this functionality, named `OR3`.

Inputs:
- A (4-bit): the first input
- B (4-bit): the second input

Outputs:
- Z (4-bit): the result of the operation described above

You may assume that the inputs A and B will always be valid 4-bit values.
