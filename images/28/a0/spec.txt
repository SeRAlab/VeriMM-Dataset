Design a 1-bit DRAM cell with the following specifications: 
- The cell should have a data input (D), a read enable (RE), a write enable (WE), and a clock (CLK) input. 
- On the rising edge of CLK, if WE is high, the value of D should be stored in the cell. 
- If RE is high, the value of the stored cell should be output to a signal (Q). 
- If neither RE nor WE is high, the cell should retain its previous value.
