Design a finite-state machine (FSM) that detects the 4-bit sequence "1010" in a streaming input signal. The module has inputs for clock and reset signals, as well as an incoming data bit. It shifts incoming data into a 4-bit shift register and changes state to indicate a match when the sequence "1010" is detected. Upon detection, it sets the output `match` high, and it can return to the initial state upon reset, clearing the shift register and match signal.
module top_module(
  input clk,
  input reset,
  input data,
  output reg match
);
