Design a dynamic range compressor that takes a 5-bit unsigned input signal and produces a compressed 3-bit output signal. The compression should be based on the following rules:  
- If the input signal is less than or equal to 3 (0b00011), the output should be the same as the input.
- If the input signal is greater than 3 but less than or equal to 12 (0b01100), the output should be the input value minus 3, clamped to a maximum of 7 (0b0111).
- If the input signal is greater than 12, the output should be fixed at 7 (0b0111).
