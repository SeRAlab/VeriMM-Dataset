
Design an interrupt controller that manages up to 4 different interrupt signals. The controller should have a clock input, a reset input, and four interrupt request inputs (irq[3:0]). It should also have an output that indicates which interrupt is currently being serviced (serviced_irq). The controller should prioritize interrupts in the order irq[0] > irq[1] > irq[2] > irq[3]. On reset, it should clear the serviced_irq output. When an interrupt is received, the controller should start servicing that interrupt on the next clock cycle, and must not change serviced_irq while servicing an interrupt.
