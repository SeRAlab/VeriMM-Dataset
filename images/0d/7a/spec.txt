
Design a 16-bit Digital-to-Analog Converter (DAC) circuit in Verilog. The DAC takes a 16-bit binary input and converts it into a corresponding 16-bit output that represents the analog value. The output should be scaled to a range of 0 to 65535 (for a 16-bit resolution). The circuit should also be able to handle a latch mechanism where the last input value is held until a new input is provided.
