
Design a simple WiFi module that tracks the connection status of a device. The module should have an input signal `connect` that indicates whether the device is trying to connect to the WiFi (1 for connect, 0 for disconnect), and a clock signal `clk`. The output signal `status` should indicate the current connection status: 2 for connected, 1 for connecting, and 0 for disconnected. The status should change from 0 to 1 on a rising edge of `clk` when `connect` is high, and change from 1 to 2 when the device is connected. The device should remain at status 2 until it receives a disconnect signal.
