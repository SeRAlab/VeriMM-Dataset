

You have been hired to design a verilog module for a 4-bit binary to Gray code converter. The module should have the following input and output ports:

**Inputs**
- `in` : a 4-bit binary input signal

**Outputs**
- `out` : a 4-bit Gray code output signal

The module should use a combinational logic circuit to convert the binary input signal to a Gray code output signal. You are allowed to use basic logic gates such as AND, OR, NOT, and XOR gates.

Design a verilog module for the 4-bit binary to Gray code converter that meets the above requirements.
