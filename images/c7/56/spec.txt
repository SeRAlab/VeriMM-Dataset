

You have been tasked with designing a verilog module that will take in three input signals and output a single signal. The module should be named `three_to_one` and should have the following ports:

- `input a` (1-bit)
- `input b` (1-bit)
- `input c` (1-bit)
- `output out` (1-bit)

The output signal should be the result of the following logic:

- If `a`, `b`, and `c` are all 1, `out` should be 1.
- If `a`, `b`, and `c` are all 0, `out` should be 0.
- If any two of `a`, `b`, and `c` are 1, `out` should be 1.
- If only one of `a`, `b`, and `c` is 1, `out` should be 0.

You may use any verilog operators or constructs to implement this logic.
