
Design an 8-bit DRAM cell that can store data and respond to read and write operations. The DRAM cell should have the following inputs and outputs:
- Inputs: `data_in` (8 bits), `addr` (3 bits), `we` (write enable), `clk` (clock)
- Outputs: `data_out` (8 bits)
When `we` is high, the `data_in` should be written to the memory location specified by `addr` on the rising edge of `clk`. When `we` is low, the `data_out` should output the value stored at the address specified by `addr`.
