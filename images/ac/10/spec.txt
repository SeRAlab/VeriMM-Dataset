Design a 6-to-1 multiplexer followed by a logic AND gate. The module takes a 3-bit selection input, `sel`, to choose one of six 4-bit data inputs (`data0` to `data5`). The selected data input is then logically ANDed with the binary value `1010`. The resulting output of this AND operation is driven on the 4-bit wide output `out`. This design enables conditional data routing combined with a specific logical operation for the output signal.
module top_module( 
    input [2:0] sel, 
    input [3:0] data0,
    input [3:0] data1,
    input [3:0] data2,
    input [3:0] data3,
    input [3:0] data4,
    input [3:0] data5,
    output [3:0] out
);
