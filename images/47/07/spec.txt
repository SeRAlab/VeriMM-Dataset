Please act as a professional verilog designer.

Design a Verilog module for a 1-bit D flip-flop with an asynchronous reset. The flip-flop captures the input data on the rising edge of the clock or resets to zero when the reset signal is active.

Module name:  
    d_flip_flop  

Input ports:
    clk: Chip clock signal.
    reset: Asynchronous reset signal.
    d: Input data.

Output ports:
    q: Flip-flop output signal.

Implementation:
Flip-flop operation:
On every positive edge of the clock signal (clk), the flip-flop (q) captures the input value (d) if the reset signal (reset) is not active. If the reset signal is active, the flip-flop resets to zero.
