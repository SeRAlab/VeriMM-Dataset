Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a random number generator. 
A random number generator is a type of digital circuit that can produce a sequence of random numbers. 
Your module should have the following inputs and outputs:

Inputs: a clock signal (clk) and a reset signal (rst)
Outputs: a random number (rand_num)
The module should also have the following parameters:

w: the width of the random number (in bits)
Your module should implement the following functionality:

The circuit should generate a random number every clock cycle.
The random number should be w bits wide and should be output on the rand_num signal.
The circuit should be resettable using the rst signal.
To implement the random number generator, you should use a linear feedback shift register (LFSR). 
An LFSR is a shift register whose input bit is a linear function of its previous state. 
You can use the LFSR to generate a pseudo-random sequence of numbers. 
You should use Verilog code to implement the LFSR and connect it to the clk and rst signals. 
You should also use Verilog code to extract the output random number from the LFSR.
