

You have been tasked with designing a Verilog module for a full adder circuit. The module should have five ports: `COUT`, `SUM`, `A`, `B`, and `CIN`. The `COUT` and `SUM` ports are outputs, while the `A`, `B`, and `CIN` ports are inputs. The module should implement the following logic:

```
SUM  = A xor B xor CIN
COUT = (A and B) or (CIN and (A xor B))
```

Your task is to write a Verilog module that implements this logic and has the specified inputs and outputs. The module should be named `full_adder`.
