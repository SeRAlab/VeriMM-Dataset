
Design a combinational logic circuit that implements a simplified version of Huffman encoding. The circuit should take a 4-bit input representing a character (0-15) and output a corresponding 3-bit encoded value based on a predefined Huffman tree. The following mappings should be used:
- 0 -> 000
- 1 -> 001
- 2 -> 010
- 3 -> 011
- 4 -> 100
- 5 -> 101
- 6 -> 110
- 7 -> 111
- Any input outside the range of 0-7 should output 111 (invalid character).
