

You are tasked with designing a verilog module that takes three inputs, A1, A2, and B1, and produces a single output, X. The module should be named `bitwise_and_module`. The output X should be equal to 1 if A1, A2, and B1 are all equal to 1, otherwise, X should be equal to 0. 

Declare all inputs and outputs as `wire` data types. The module should be designed using only bitwise operators (i.e., &, |, ^, ~).
