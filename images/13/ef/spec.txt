Design an I2C controller that receives a start condition and generates a stop condition after transmitting a byte of data. The controller should have inputs for the start signal (start), the data byte (data_in), and a clock signal (clk). The output should be the data transmitted (data_out) along with a stop signal (stop). When the start signal is received, the controller should begin transmitting the data byte on the clock signal. After the byte is transmitted, it should generate a stop condition.
