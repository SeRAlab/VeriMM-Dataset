Implement a Verilog module for a 10-bit parallel-to-serial shift register with synchronous reset and load. The module should have an input clock signal (clk), an input synchronous reset signal (rst), an input load signal (load), a 10-bit input data signal, and a serial output signal (serial_out). On the rising edge of the clock, if reset is high, the register should be set to 10'b0000000000. If load is high, the register should load the data. Otherwise, it should shift right and output the LSB.
