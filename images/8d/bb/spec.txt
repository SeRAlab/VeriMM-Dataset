Design a 4-bit barrel shifter that shifts the input signal A to the left by a number of positions specified by the input B. Each bit of B represents whether to shift the corresponding bits of A, with B[0] controlling a 1-position shift, B[1] a 2-position shift, B[2] a 4-position shift, and B[3] a 8-position shift. The output C reflects the result of this conditional shifting operation.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output [3:0] C
);
