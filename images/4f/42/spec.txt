Design a 4-bit binary adder with a control signal. When the control signal (ctrl) is 0, the module outputs the lower 4 bits of the sum; when ctrl is 1, it outputs the carry out of the addition operation. The adder can accommodate two 4-bit inputs (in1 and in2) and produces a 4-bit sum along with a carry-out signal.
module top_module(
    input [3:0] in1,
    input [3:0] in2,
    input ctrl,
    output [3:0] sum,
    output cout
);
