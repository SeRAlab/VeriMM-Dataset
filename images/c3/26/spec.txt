

You are tasked with designing a Verilog module for a clock gate with the following specifications:

Inputs:
- `CLK`: clock input
- `EN`: enable input
- `TE`: transparent enable input

Output:
- `ENCLK`: gated clock output

The module should implement a clock gate that gates the clock input (`CLK`) with the enable input (`EN`). The gated clock output (`ENCLK`) should be high only when the enable input (`EN`) is high. Additionally, the module should have a transparent enable input (`TE`) that, when high, allows the clock input (`CLK`) to pass through to the gated clock output (`ENCLK`) regardless of the enable input (`EN`).

You must implement this module within 200 lines of Verilog code.
