Design a programmable 8-bit up/down counter that increments or decrements its count based on the `dir` input signal. On a rising edge of the clock (`clk`), if the `rst` input is high, the count resets to zero. If `dir` is high, the counter increments its value, and if it reaches 255, it wraps around to 0. Conversely, if `dir` is low, the counter decrements its value, and if it reaches 0, it wraps around to 255.
module top_module(
  input clk,
  input rst,
  input dir,
  output reg [7:0] count
);
