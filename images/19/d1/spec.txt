Design a combinational logic circuit that takes a 16-bit TCP segment length and a 5-bit TCP flag as inputs. The output should indicate whether the segment is a FIN, SYN, or RST segment based on the TCP flags. The output should be a 2-bit value: '00' for no segment type, '01' for FIN, '10' for SYN, and '11' for RST. If the segment length is greater than 1500, the output should be '00'.
