

You are tasked with designing a module that takes in two inputs, `a` and `b`, and outputs the value of `a` if `b` is 1 and outputs the value of `b` if `a` is 0. If both inputs are 0, the output should be 0. 

Design a verilog module that implements this functionality. The module should be named `ab_mux` and should have the following ports:

- `input a`: a single bit input
- `input b`: a single bit input
- `output reg q`: a single bit output

Ensure that your module is synthesizable.
