Implement a 16-bit output selector module that extracts or modifies data from a 32-bit input based on the value of a 4-bit control signal. The module can output either the highest 16 bits of the input, the lowest 16 bits, or shifted values of either segment, while defaulting to zero for unrecognized control signals. This design effectively serves as a multiplexer with specific selection and transformation capabilities on the input data.
