

You are tasked to design a Verilog module that takes in 3 inputs and produces 2 outputs. The module should be named "three_to_two" and it should have the following inputs and outputs:
- Inputs:
  - A: a 1-bit input
  - B: a 1-bit input
  - C: a 1-bit input
- Outputs:
  - X: a 1-bit output
  - Y: a 1-bit output

The module should implement the following logic:
- If A is 1, then X should be 1 and Y should be the logical AND of B and C.
- If A is 0, then X should be 0 and Y should be the logical OR of B and C.

Write the Verilog code for the "three_to_two" module that implements the above logic.
