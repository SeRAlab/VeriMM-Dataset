Design a 16-bit wide multiplier module that takes five 16-bit inputs (a, b, c, d, e) and calculates their product. The module outputs a product that is set to zero if any input is zero or if any of the multiplicative conditions fail (ensuring that the inputs have not been altered through the operations). If all inputs are non-zero and valid, the module outputs the product of all five inputs. This design ensures both robustness against invalid inputs and accurate multiplication.
module top_module(
    input [15:0] a,
    input [15:0] b,
    input [15:0] c,
    input [15:0] d,
    input [15:0] e,
    output reg [15:0] product
);
