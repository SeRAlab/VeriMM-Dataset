Design a simple SPI controller that can read and write data. The SPI controller should have the following inputs: clock, reset, MOSI (Master Out Slave In), and an enable signal. The outputs should be MISO (Master In Slave Out), and data output. The SPI controller should perform a data transmission when enabled, shifting in data from MOSI and shifting out data to MISO on each clock edge. It should also provide a way to reset the state of the controller.
