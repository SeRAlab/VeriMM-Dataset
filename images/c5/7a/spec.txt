

You have been tasked with designing a module that takes in a 4-bit input and outputs a 2-bit output. The output should be the sum of the two most significant bits of the input and the two least significant bits of the input. If the sum is greater than or equal to 2, the output should be 2. Otherwise, the output should be the sum.

Design a module that implements this functionality. Your module should be named `sum2bits` and should have the following interface:

```verilog
module sum2bits (
    input [3:0] in,
    output reg [1:0] out
);
```

You can assume that the input will always be a valid 4-bit binary number.
