Design a 4-to-1 multiplexer circuit. The module takes two control inputs (sel) to select one of four data inputs (data0, data1, data2, data3). Depending on the value of sel, the output (out) is assigned the value of the selected data input, effectively routing one of the four inputs to the output based on the selection criteria.
module top_module(
    // Inputs
    input [1:0] sel,
    input data0,
    input data1,
    input data2,
    input data3,
    // Outputs
    output out
);
