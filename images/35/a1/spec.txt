Design a simple SD card interface controller that manages the read and write operations. The controller should have an input for a command to either read or write, a data input/output, and a clock signal. When a 'write' command is received, the data should be stored in a register. When a 'read' command is received, the data should be output from the register. The controller should also have an output signal indicating the status of the operation (IDLE, READ, WRITE).
