The module takes an 11-bit binary input and converts it to its decimal representation, outputting the values in four separate 4-bit registers: ones, tens, hundreds, and thousands. The conversion uses a systematic subtraction approach to isolate each decimal digit. The resulting BCD outputs are suitable for display or further processing in digital circuits.
module top_module(
    input wire [10:0] bin,

    output reg [3:0] hundreds,
    output reg [3:0] thousands
);
