Design a 4-bit ripple carry adder that computes the sum of two 4-bit inputs, A and B. The module outputs a 4-bit sum and a carry-out signal. The carry-out indicates if there is a carry generated from the most significant bit during the addition. The adder uses a combinational logic block to continuously update the sum and the carry signal based on the inputs. The carry signal is captured on the positive edge of the carry-out signal for sequential error handling.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output reg [3:0] sum,
    output reg carry_out  // Changed carry_out to reg
);
