Design a simple 8-bit calculator that performs arithmetic operations on two 8-bit inputs, `a` and `b`. The operation is determined by a 2-bit select input `op`, where `00` corresponds to addition, `01` to subtraction, `10` to multiplication, and `11` to division. The result of the chosen operation is output as an 8-bit value.
module top_module(
    input [7:0] a, b,
    input [1:0] op,
    output reg [7:0] result
);
