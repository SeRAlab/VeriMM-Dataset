Design a Verilog module for an SR flip-flop. The SR flip-flop should have two inputs (S and R) and one output (Q). The output Q should change state based on the inputs S (Set) and R (Reset). Implement the behavior where if S and R are both low, the output remains the same. If S is high, Q should be set to high. If R is high, Q should be reset to low. If both S and R are high, the output should be considered invalid (you may choose to keep the output unchanged in this case).
