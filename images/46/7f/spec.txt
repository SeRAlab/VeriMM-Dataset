Design a 4-input AND gate that produces an output based on the control signal. The module takes four 4-bit inputs (a, b, c, d) and computes their AND operation. If the control input (ctrl) is high, the output is the inverse of the AND result; if ctrl is low, the output is the direct AND result. Thus, it functions as an AND gate with the option to invert the output based on the control signal.
module top_module(
    input [3:0] a,
    input [3:0] b,
    input [3:0] c,
    input [3:0] d,
    input ctrl,
    input vdd,
    input gnd,
    output out
);
