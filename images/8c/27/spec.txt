Design a 4-to-1 multiplexer that selects one of four 1-bit inputs (IN0, IN1, IN2, IN3) based on the 2-bit select signal (SEL). The output (F) reflects the value of the selected input, where SEL[1:0] determines the chosen input: SEL=00 selects IN0, SEL=01 selects IN1, SEL=10 selects IN2, and SEL=11 selects IN3. In case of an invalid selection, the output defaults to an undefined state (1'bx).

  IN0,
  IN1,
  IN2,
  IN3,
  SEL,
  F
);
