
Design a Verilog module for a simple Recurrent Neural Network (RNN) cell that takes a single input and produces an output based on the previous hidden state. The RNN cell will have the following parameters:
- Input: 4 bits
- Hidden state: 4 bits
- Output: 4 bits
The output will be the sum of the input and the hidden state, and the next hidden state will be the same as the output (for simplicity).
