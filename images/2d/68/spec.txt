Implement an SR latch using D flip-flops. The SR latch should have two inputs (S for Set, R for Reset) and two outputs (Q and Q'). The output Q should be set to 1 when S is high and R is low, and reset to 0 when R is high and S is low. If both inputs are low, the latch should hold its previous state. If both inputs are high, it should be considered an invalid state.
