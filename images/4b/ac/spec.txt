Design a 4-bit shift register that can load a 4-bit input or perform a circular shift operation on each clock cycle. When the load signal is high, the register captures the input value. When the load signal is low, it shifts the stored bits to the left, with the most significant bit wrapping around to the least significant position. The module also provides a serial output that corresponds to the most significant bit of the register.
module top_module(
    input clk,
    input load,
    input [3:0] in,
    output [3:0] out,
    output ser_out
);
