Design a 4-bit binary adder that computes the sum of two 4-bit inputs, A and B. The output, S, represents the least significant 4 bits of the addition result. If the sum exceeds the maximum value representable by 4 bits (which is 15), the module wraps the result around by subtracting 16, effectively implementing modulo-16 behavior.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output reg [3:0] S
);
