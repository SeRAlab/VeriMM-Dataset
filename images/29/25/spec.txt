Design a fixed-priority arbiter that grants access to one of four requesters (request 0, request 1, request 2, request 3) based on fixed priority. The priority order is: request 0 > request 1 > request 2 > request 3. The arbiter should have a clock and reset input, and an output to indicate which requester has been granted access. In case of multiple simultaneous requests, the arbiter should grant access to the highest priority requester. The arbiter should also provide a valid output to indicate if the granted request is valid.
