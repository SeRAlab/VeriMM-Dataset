Design a parallel-in parallel-out (PIPO) register that captures a 4-bit input (DataIn) on the rising edge of the clock signal (clk). The module outputs the captured data to two separate 4-bit outputs (DataOut1 and DataOut2) simultaneously. When the reset signal (rst) is asserted, both outputs are set to zero. This design allows for simultaneous storage of data while enabling easy resetting of the outputs.
module top_module(
    DataIn,
    DataOut1,
    DataOut2,
    clk,
    rst
);
