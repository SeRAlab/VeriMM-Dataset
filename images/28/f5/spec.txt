Design a simple packet filtering module for a firewall that checks if a packet is allowed or blocked based on a defined source IP address. The module should take as input a 32-bit source IP address and an 8-bit port number. The firewall will allow packets from a specific IP address (e.g., 192.168.1.1) and a specific port (e.g., 80). The output should indicate whether the packet is allowed (1) or blocked (0).
