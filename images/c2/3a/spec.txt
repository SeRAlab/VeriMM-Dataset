

You have been tasked with designing a verilog module that implements a 2-bit counter with synchronous reset functionality. The module should have the following inputs and outputs:

Inputs:
- `CLK`: a clock signal
- `RESET_B`: an active low synchronous reset signal

Outputs:
- `Q`: a 2-bit output representing the current count value

The counter should increment on the rising edge of the clock signal and reset to 0 on the rising edge of the reset signal. The counter should count in the following sequence: 00, 01, 10, 11, 00, ...

You can use the following code snippet as a starting point:

```
module counter_2bit (
    Q      ,
    CLK    ,
    RESET_B
);

    // Module ports
    output reg [1:0] Q      ;
    input  CLK            ;
    input  RESET_B        ;

    // Your code here

endmodule
```
