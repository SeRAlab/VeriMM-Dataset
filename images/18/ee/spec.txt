
Create a packet filtering logic that checks whether a packet is allowed or denied based on its source and destination IP addresses, as well as a protocol type. The input consists of a 32-bit source IP, a 32-bit destination IP, a 4-bit protocol number, and a control signal to enable or disable the filtering. The output should indicate whether the packet is allowed (1) or denied (0). 
The filtering rules are as follows:
1. Allow packets from source IP `192.168.1.1` to any destination IP with protocol `TCP` (protocol number `6`).
2. Deny packets from source IP `10.0.0.1` to any destination IP with protocol `UDP` (protocol number `17`).
3. Allow all other packets.
