Design a 3-bit comparator that provides three outputs: EQ, GT, and LT. The EQ output indicates equality between the two 3-bit inputs A and B, being HIGH when A equals B. The GT output is HIGH when A is greater than B, while the LT output is HIGH when A is less than B, ensuring that only one of these outputs can be HIGH at any given time.
module top_module(
  input [2:0] A,
  input [2:0] B,
  output reg EQ,
  output reg GT,
  output reg LT
);
