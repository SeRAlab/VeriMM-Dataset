Design a 5-bit right shifter with enable, clock, and reset functionalities. The module shifts the input data D one position to the right and outputs the result to Q when the enable signal is active (en=1) on the rising edge of the clock (clk). If the reset signal (rst) is activated, the output Q is set to zero. Otherwise, the shifted data is stored in a register, ensuring synchronous operation.
