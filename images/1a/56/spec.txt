
Design a 16-bit SRAM cell that supports read and write operations. The SRAM cell should have the following ports:
- `data_in`: 16-bit input data for writing.
- `data_out`: 16-bit output data for reading.
- `we`: Write enable signal (1 for write, 0 for read).
- `clk`: Clock signal.
- `addr`: 4-bit address input to access different SRAM cells.
The SRAM should be able to store data at the specified address on a write operation and output the stored data on a read operation.
