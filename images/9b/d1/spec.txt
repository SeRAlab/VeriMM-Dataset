Implement the Verilog module based on the following description.
Given a 3-bit synchronous up/down counter with an enable input:

1. The counter increments if the up input is high.
2. The counter decrements if the down input is high.
3. If both up and down inputs are high, the counter does not change.
4. The enable input allows counting when high.

Write Verilog implementing this counter.
module counter (
        input clk,
        input enable,
        input up,
        input down,
        output reg [2:0] count);
