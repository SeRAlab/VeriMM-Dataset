

You are tasked with designing a verilog module to implement a 2-to-1 multiplexer using behavioral modeling. The module should have two input ports, A and B, and one select port, SEL. The output of the module should be the value of A when SEL is 0, and the value of B when SEL is 1.

You are given the following code snippet as a starting point:

```
module mux2to1 (
    input A,
    input B,
    input SEL,
    output reg Y
);

    // your code here

endmodule
```

Your task is to complete the module by filling in the code to implement the 2-to-1 multiplexer using behavioral modeling. Your implementation should use an if-else statement to select between A and B based on the value of SEL.
