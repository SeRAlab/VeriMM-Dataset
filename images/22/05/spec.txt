
Design a FIFO queue in Verilog that can store up to 8 4-bit data entries. The FIFO should support the following operations:
1. `push` - Push a 4-bit data into the FIFO.
2. `pop` - Pop the oldest data from the FIFO.
3. `full` - Indicate when the FIFO is full.
4. `empty` - Indicate when the FIFO is empty.
5. `size` - Return the current number of elements in the FIFO.

The FIFO should have an active-high `push` and `pop` signals to control the operations.
