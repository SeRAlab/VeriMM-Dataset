Design a sequence counter that increments a 4-bit counter each time a specific 3-bit sequence (101) is detected in the least significant bit of a 10-bit input data stream. The counter is synchronized with a clock and resets to zero upon receiving a reset signal. The output provides the current value of the counter, reflecting the number of times the target sequence has been detected during operation.
module top_module(
  input clk,
  input reset,
  input [9:0] data,
  output reg [3:0] count
);
