

You are tasked with designing a verilog module that takes in a 32-bit input and outputs a 16-bit output. The output should be the lower 16 bits of the input. 

Design a verilog module with the following specifications:

- Module name should be "lower_16_bits".
- Module should have one input port named "in" of size 32 bits.
- Module should have one output port named "out" of size 16 bits.
- The output should be the lower 16 bits of the input.
