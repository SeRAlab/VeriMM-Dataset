Design a 4-bit arithmetic unit capable of performing both addition and subtraction operations. The module takes two 4-bit inputs, A and B, a mode signal to select between addition (mode = 0) and subtraction (mode = 1), and a carry-in signal. It calculates the result and outputs a 4-bit sum along with a carry-out signal. In addition mode, it computes the sum of A, B, and cin, while in subtraction mode, it computes A minus B minus cin, effectively allowing for arithmetic operations with carry considerations.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input mode,
    input cin,
    output [3:0] sum,
    output cout
);
