Design a 4-to-1 multiplexer that selects one of four 12-bit input signals (a, b, c, d) based on the value of a 2-bit select line (sel). When sel is 00, the output is equal to input a; when sel is 01, the output is b; when sel is 10, the output is c; and when sel is 11, the output is d.
module top_module(

	input [11:0] a,
	input [11:0] b,
	input [11:0] c,
	input [11:0] d,
	input [1:0] sel,
	output [11:0] out
);
