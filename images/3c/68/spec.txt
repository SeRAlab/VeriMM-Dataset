Design a Fractional-N PLL (Phase Locked Loop) in Verilog that takes a reference clock input and generates an output clock at a fractional multiple of the input frequency. The PLL should include a phase detector, a loop filter, and a voltage-controlled oscillator (VCO). The PLL must be able to switch between different division values based on a 2-bit control input, which selects the division ratio from a predefined set.
