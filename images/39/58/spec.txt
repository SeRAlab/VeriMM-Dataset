Design a combinational logic circuit that implements a Huffman encoding mechanism. The circuit should take a 4-bit input representing a symbol and output a variable-length encoded binary string based on predefined Huffman codes for a set of symbols. The mapping for the symbols is as follows: 
- Symbol 0: 00
- Symbol 1: 01
- Symbol 2: 10
- Symbol 3: 11
- Symbol 4: 000
- Symbol 5: 001
- Symbol 6: 010
- Symbol 7: 011
- Symbol 8: 100
- Symbol 9: 101
- Symbol 10: 110
- Symbol 11: 111
The output should be a 12-bit wide output, which concatenates the Huffman code corresponding to the 4-bit input symbol.
