Design a comparator circuit that takes two n-bit wide inputs (a and b) and produces three outputs: 'gt' indicates if 'a' is greater than 'b', 'eq' indicates if 'a' is equal to 'b', and 'lt' indicates if 'a' is less than 'b'. The parameter 'n' defines the bit width for the input signals, allowing for flexibility in the size of the comparisons.
module top_module(
  input [n-1:0] a,
  input [n-1:0] b,
  output gt,
  output eq,
  output lt
);
