Design a 8-bit shift register with configurable loading and shifting capabilities. The register can either load an 8-bit input when the load signal is asserted or, depending on the control signal, shift its contents either left or right on each clock cycle. The output constantly reflects the current state of the register, allowing for both storage and manipulation of the data.
module top_module(
  input clk,      // clock input
  input load,     // load input
  input control,  // control input
  input [7:0] data_in,  // input data
  output [7:0] data_out // output data
);
