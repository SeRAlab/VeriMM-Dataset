Design a Verilog module that implements a binary logistic regression unit. The module takes in two 8-bit input feature values (x1 and x2) and computes the probability output (p) using the logistic function p = 1 / (1 + exp(-(w1*x1 + w2*x2 + b))) where w1, w2 are weights and b is the bias. The weights and bias are fixed as parameters in the module.
