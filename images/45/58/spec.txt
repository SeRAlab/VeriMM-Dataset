Please act as a professional verilog designer.

Implement a 4-to-1 multiplexer. The multiplexer should have four 1-bit data inputs (d0, d1, d2, d3), a 2-bit select input (sel), and a 1-bit output (y). The output should be equal to one of the data inputs based on the value of the select input.

Module name:
    mux4to1
Input ports:
    d0: a 1-bit data input
    d1: a 1-bit data input
    d2: a 1-bit data input
    d3: a 1-bit data input
    sel: a 2-bit select input
Output ports:
    y: a 1-bit output representing the selected data input

The multiplexer should select the data input based on the value of the select input as follows:
    - If sel is 2'b00, y should be equal to d0
    - If sel is 2'b01, y should be equal to d1
    - If sel is 2'b10, y should be equal to d2
    - If sel is 2'b11, y should be equal to d3
