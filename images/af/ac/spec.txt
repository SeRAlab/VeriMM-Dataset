Design a signal selector module that outputs a value based on the states of two input signals, A1 and A2. The output, X, is determined such that when both A1 and A2 are high, or when A1 is high and A2 is low, the output takes the value of B1. Conversely, if A1 is low while A2 is high, or if both A1 and A2 are low, the output is taken from B2. This effectively creates a multi-condition selector based on the input signals.
module top_module(
    input  A1,
    input  A2,
    input  B1,
    input  B2,
    output X
);
