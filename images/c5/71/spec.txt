

You are tasked with designing a Verilog module that implements a 4-bit shift register with a parallel load function. The shift register should have four inputs and one output. The inputs are:
- `clk`: a clock input
- `reset`: a reset input
- `load`: a parallel load input
- `data_in`: a 4-bit input

The output is:
- `data_out`: a 4-bit output

When `reset` is high, the shift register should be cleared. When `load` is high, the value of `data_in` should be loaded into the shift register. When `load` is low, the shift register should shift its contents to the left on every rising edge of `clk`. The most significant bit should be shifted out and lost, and the least significant bit should be shifted in from `data_in`.

Your module should be named `shift_register` and should be implemented within 200 lines of Verilog code.
