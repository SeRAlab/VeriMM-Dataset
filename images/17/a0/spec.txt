Design a 16-bit SRAM cell with read and write capabilities. The SRAM should have a write enable (we), a read enable (re), a chip enable (ce), a 16-bit data input (data_in), a 16-bit data output (data_out), and a 4-bit address input (addr). The SRAM cell should allow writing when we is high, reading when re is high, and remain inactive when ce is low.
