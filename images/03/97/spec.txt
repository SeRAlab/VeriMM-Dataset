
Design a Fixed-Priority Arbiter in Verilog that handles multiple request lines. The arbiter should prioritize requests based on fixed priority where the highest priority request gets access to the resource. The arbiter should have 4 request inputs (req[3:0]) and a single grant output (grant). The priority order should be: req[3] > req[2] > req[1] > req[0]. If multiple requests are active, the highest priority request should be granted access.
