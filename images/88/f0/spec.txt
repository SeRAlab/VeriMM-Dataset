Design a block RAM (Random Access Memory) module that supports both read and write operations synchronized to a clock signal. The module allows for data storage with 16 addressable memory blocks, each capable of holding 8 bits of data. When the write enable signal is active (wr_enable), the input data is written into the memory at the specified write address (wr_addr). Conversely, when the read enable signal is active (rd_enable), the module outputs the data stored at the specified read address (rd_addr). This functionality is crucial for applications requiring temporary data storage and retrieval in a digital circuit.
module top_module(clk, rd_enable, wr_enable, wr_addr, wr_data, rd_addr, rd_data);
