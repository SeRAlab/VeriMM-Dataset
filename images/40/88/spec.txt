
Design a 2nd order Infinite Impulse Response (IIR) filter using Verilog. The filter should take an input sample and produce an output sample based on the following difference equation:
Y[n] = a1 * Y[n-1] + a2 * Y[n-2] + b0 * X[n] + b1 * X[n-1]
where:
- Y[n] is the current output sample
- Y[n-1] is the previous output sample
- Y[n-2] is the output sample before the previous one
- X[n] is the current input sample
- X[n-1] is the previous input sample
The coefficients a1, a2, b0, and b1 are fixed point values.
