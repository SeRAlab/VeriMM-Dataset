Please act as a professional verilog designer. Design a module that implements a 8-bit priority encoder. The module should have eight inputs, I0 through I7, and three outputs, EN, V, and Q. If multiple inputs are asserted at the same time, the input with the highest priority (highest index) should be encoded. The Q output should be a 3-bit binary number representing the index of the highest-priority asserted input.
