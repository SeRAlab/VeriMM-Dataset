Design a binary converter that translates a 4-bit binary input (DATA_IN) into an 8-bit output (DATA_OUT). The mapping assigns a specific 8-bit value to each possible 4-bit input, where each corresponding output represents a power of two in the 8-bit format. For inputs 0 to 7, the output corresponds to single-bit positions in the 8-bit word, while inputs 8 and 9 produce outputs that add 1 and 2, respectively, to the least significant bit of the bitwise representation of the values. For any input above 9, the output defaults to all zeroes.
module top_module(
    input [3:0] DATA_IN,
    output reg [7:0] DATA_OUT
    );
