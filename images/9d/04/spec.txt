Design a 4-to-1 multiplexer that selects one of four single-bit input signals (A, B, C, D) based on two selection inputs (sel0 and sel1). When both selection inputs are low, the output Y is A; when sel0 is low and sel1 is high, Y is B; when sel0 is high and sel1 is low, Y is C; and when both selection inputs are high, Y becomes D.
module top_module(
  input A,
  input B,
  input C,
  input D,
  input sel0,
  input sel1,
  output reg Y
);
