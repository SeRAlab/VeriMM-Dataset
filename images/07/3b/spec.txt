Implement an edge-triggered D flip-flop with asynchronous reset. The flip-flop should have the following inputs: clock (clk), data input (d), and an asynchronous reset (rst). When the reset is high, the output (q) should be set to 0. On the rising edge of the clock, if reset is low, the output should take the value of the data input. The flip-flop should also have an inverted output (q_bar).
