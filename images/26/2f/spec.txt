
Design a LIFO stack module in Verilog. The stack should support push and pop operations, with a maximum depth of 8. The module should have the following ports: 
- `clk`: clock signal 
- `rst`: asynchronous reset 
- `push`: signal to push data onto the stack 
- `pop`: signal to pop data from the stack 
- `data_in`: 8-bit input data to be pushed 
- `data_out`: 8-bit output data that is popped from the stack 
- `full`: output signal that indicates if the stack is full 
- `empty`: output signal that indicates if the stack is empty
