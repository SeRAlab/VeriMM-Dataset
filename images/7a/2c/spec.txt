Design a 3-to-1 multiplexer that selects one of three 22-bit wide input data signals (data0x, data1x, data2x) based on a 2-bit selection signal (sel). When sel is 00, the output (result) is set to data0x; when sel is 01, it outputs data1x; and for sel 10, it outputs data2x. If the selection does not match any valid case (e.g., sel is 11), the output is assigned an undefined value, indicating an error state.

    data0x,
    data1x,
    data2x,
