

You are tasked with designing a verilog module that takes in two inputs and produces one output. The module should be named "multiplier" and should have the following ports:

- `input [7:0] a`: an 8-bit input
- `input [7:0] b`: an 8-bit input
- `output reg [15:0] result`: a 16-bit output

The module should multiply the two inputs `a` and `b` and store the result in `result`. You should use a sequential block to implement the multiplication.
