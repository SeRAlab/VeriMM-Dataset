

You are tasked with creating a verilog module that takes in two inputs, `data_in` and `write_en`, and outputs `data_out`. The module should implement a register with the following behavior:

1. When `write_en` is high, the value of `data_in` should be stored in the register.
2. When `write_en` is low, the value of `data_out` should be the value stored in the register.

Write a verilog module that implements this register behavior.
