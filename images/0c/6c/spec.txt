
Design a Verilog module for a simple EEPROM cell that can perform read and write operations. The module should have the following inputs and outputs: 
- Inputs: `clk` (clock), `we` (write enable), `addr` (address), `data_in` (data input).
- Outputs: `data_out` (data output).
The EEPROM cell should store one byte of data at a given address when `we` is high. When `we` is low, the data at the specified address should be available at `data_out` on the next clock cycle.
