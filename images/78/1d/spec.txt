Design a 4-to-1 multiplexer with enable functionality. The module takes a 4-bit input (`ABCD`), a 2-bit select input (`SEL`), and an enable signal (`EN`). When `EN` is high, the output `Y` is set to the value of the selected bit from the input; if `EN` is low, the output `Y` is forced to LOW. The multiplexer selects one of the four input lines based on the value of `SEL`.
module top_module(
    input [3:0] ABCD,
    input [1:0] SEL,
    input EN,
    output reg Y
);
