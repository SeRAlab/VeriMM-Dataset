Develop a circuit that implements a delayed negation of an input signal. The output will reflect the logical NOT of the input signal delayed by one clock cycle, provided that the enable signal is active. The circuit also incorporates a global reset functionality to initialize the output to LOW when activated.
module top_module(
    input  wire clk,       // System clock
    input  wire rst,       // Global reset signal (active high)
    input  wire en,        // Global enable signal (active high)
    input  wire in,        // Input signal
    output reg  out        // Output signal
);
