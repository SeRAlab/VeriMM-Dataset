Design a Verilog module that implements a simple 3x3 Sobel filter for edge detection. The module should take a 3x3 pixel input matrix and output the gradient magnitude at the center pixel position. The input pixels will be represented as an 8-bit unsigned integer, and the output should also be an 8-bit unsigned integer. The Sobel filter calculates the gradient in the x and y directions and combines them to output the resulting edge strength.
