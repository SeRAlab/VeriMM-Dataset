Design a simple GPIO controller that allows setting and clearing of GPIO pins with a 5-bit wide output. The controller should have the following inputs: a 5-bit data input (gpio_in), a control input (set_clear), and a clock input (clk). The set_clear input should determine whether to set (1) or clear (0) the GPIO pins. The output should be a 5-bit GPIO output (gpio_out). On the rising edge of the clock, if the set_clear input is high, the gpio_out should be set to gpio_in. If set_clear is low, gpio_out should be cleared to 0.
