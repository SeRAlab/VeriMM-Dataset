Design a 16-bit SRAM cell that can store data and has a read and write capability. The SRAM should have the following inputs: 
- `clk`: Clock signal
- `we`: Write enable signal (active high)
- `addr`: 4-bit address input (to select one of 16 cells)
- `data_in`: 16-bit data input
- `data_out`: 16-bit data output (read from the selected cell)

The SRAM should store data when `we` is high and allow data to be read when `we` is low.
