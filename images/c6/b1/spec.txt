

You are tasked with designing a verilog module that implements a 4-bit adder-subtractor circuit. The module should have two 4-bit inputs, A and B, and a control input SUB that determines whether the output should be the sum or difference of the two inputs. The output should be a 4-bit value that represents the result of the operation. Assume two's complement representation for negative values.

Design a module named "adder_subtractor" that implements the above requirements.
