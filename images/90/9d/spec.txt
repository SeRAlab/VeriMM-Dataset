Design a binary counter that counts up or down based on the `dir` input. The counter is controlled by a clock signal (`clk`) and can be reset to zero asynchronously using the `rst` input. The counter's width is parameterized by `n`, allowing for a customizable number of bits. When `dir` is high, the counter increments on each clock pulse; when `dir` is low, it decrements. The current count value is output through the `out` signal.
module top_module(
  input clk,
  input rst,
  input dir,
  output reg [n-1:0] out
);
