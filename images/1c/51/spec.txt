Design a FIFO (First In First Out) queue with a depth of 4. The FIFO should have a data input (`data_in`), a write enable (`wr_en`), a read enable (`rd_en`), a clock (`clk`), and a reset signal (`rst`). The FIFO should have a data output (`data_out`) and a full flag (`full`) that indicates when the FIFO is full, and an empty flag (`empty`) that indicates when the FIFO is empty.
