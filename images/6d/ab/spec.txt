Design a Verilog module that implements a 2-bit binary counter with enable signal. The module should have a clock input, a reset input, an enable input, and a 2-bit output. The counter should increment on every clock cycle when the enable signal is high and reset to 0 when the reset signal is high.

module counter2bit_en (
    input clk,
    input rst,
    input en,
    output reg [1:0] count
);
