Implement the Verilog module based on the following description.
Given the following 4-bit synchronous up-down counter:

1. The counter increments on the rising edge of the clock if the up input is high.
2. The counter decrements on the rising edge of the clock if the down input is high.
3. If both up and down inputs are high, the counter holds its value.

Write Verilog implementing this up-down counter.
module up_down_counter (
        input clk,
        input up,
        input down,
        output reg [3:0] count);
