Design a 32-bit comparator that takes two 32-bit inputs and outputs three signals: 
1. `a_gt_b` which is high if the first input `a` is greater than the second input `b`.
2. `a_lt_b` which is high if the first input `a` is less than the second input `b`.
3. `a_eq_b` which is high if the inputs `a` and `b` are equal.
