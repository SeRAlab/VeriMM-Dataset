Design a simple interrupt controller that can handle up to 4 different sources of interrupts. The controller should have an input signal `interrupt_req` (4 bits) to indicate which interrupt sources are requesting service, a clock signal `clk`, and a reset signal `rst`. The controller should output a 2-bit `interrupt_ack` signal indicating which interrupt has been acknowledged. The output should cycle through the interrupt requests in a round-robin fashion, with the highest priority given to the lowest numbered interrupt source. If multiple interrupts are requested, the controller should acknowledge them one at a time in the order of their priority.
