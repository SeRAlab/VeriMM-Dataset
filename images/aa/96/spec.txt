Design a 4-bit wide edge-triggered flip-flop with asynchronous reset and enable functionality. On the rising edge of the clock, if the reset signal is low, the flip-flop loads the input data d. If the reset is high and the enable signal en is active, the flip-flop updates its output q with the input data d. Otherwise, the output retains its previous value.
module top_module(
    input clk,
    input reset,
    input en,
    input [3:0] d,
    output reg [3:0] q
);
