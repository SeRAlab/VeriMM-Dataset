The output o_0 directly receives the value of i_0, o_1 receives the value of i_2, o_2 receives the value of i_1, and o_3 remains unchanged by directly passing through the value of i_3. This functionality can be viewed as a fixed permutation module for data routing.
module top_module(
      
               i_0,
               i_1,
               i_2,
               i_3,
               
               o_0,
               o_1,
               o_2,
               o_3
);
