Implement a 16-bit register with synchronous reset and enable. The register should store the input data on the positive edge of the clock if the enable signal is high.

Module name:
    reg_16bit

Input ports:
    clk: clock signal.
    rst: synchronous reset signal.
    en: enable signal.
    d: 16-bit input data.

Output ports:
    q: 16-bit output data.
