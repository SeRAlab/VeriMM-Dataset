Design a clock divider module that generates a subclock (out_clk) from an input clock (in_clk) based on a variable divider factor. The module counts clock cycles on the rising edge of in_clk using a counter (m) to toggle the output clock state at a frequency determined by the divider_factor. When the divider_factor is set to 0, out_clk follows in_clk directly. Otherwise, the output clock outputs a HIGH for the first half of the division period and a LOW for the second half, effectively creating a divided frequency output.
module top_module(input in_clk,input [15:0] divider_factor,output reg out_clk);
