
Design a simple ARQ (Automatic Repeat reQuest) error correction system that uses a simple acknowledgment (ACK) mechanism. The system should consist of a sender and a receiver. The sender will transmit a 5-bit data word. The receiver will check for errors and send back an acknowledgment signal. If the acknowledgment is not received within a certain number of clock cycles, the sender will retransmit the data. The system should handle a maximum of 3 retransmissions before giving up.
