

In digital circuit design, it is often necessary to use flip-flops to store binary values. In this problem, you are tasked with designing a module that implements a D flip-flop using Verilog. A D flip-flop stores a single bit of information, which is determined by the value of its data input (D) at the rising edge of the clock signal. The stored value is then output on the Q output.

Your module should have the following inputs and outputs:

Inputs:
- D: a single bit representing the data input.
- CLK: a single bit representing the clock input.

Outputs:
- Q: a single bit representing the stored value.

Your module should implement the following behavior:
- At the rising edge of the CLK input, the value of the D input should be stored in the flip-flop.
- The stored value should be output on the Q output.

You should implement your module within 200 lines of Verilog code.
