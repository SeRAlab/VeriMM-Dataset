Design a simple SD card interface controller that accepts a 4-bit command input and produces a 3-bit response output based on the command. The commands and their corresponding responses are as follows:
- Command 0000 -> Response 000
- Command 0001 -> Response 001
- Command 0010 -> Response 010
- Command 0011 -> Response 011
- Command 0100 -> Response 100
For any other command, the response should be 111.
