Design a 32-bit wide, 4-to-1 multiplexer. The output selects one of the four 32-bit input signals (in0, in1, in2, in3) based on the 2-bit select signal (sel). When sel=00, the output is set to in0; sel=01 selects in1; sel=10 selects in2; and sel=11 selects in3.
module top_module(
    output reg [31:0] out,
    input [31:0] in0,
    input [31:0] in1,
    input [31:0] in2,
    input [31:0] in3,
    input [1:0] sel
    );
