Implement a 4-bit binary to 7-segment decoder circuit. The module takes a 4-bit input digit and outputs the corresponding 7-segment display signals. Each unique digit (0 to F) is mapped to a specific 7-bit output configuration that controls the segments of the display to visualize the hexadecimal values properly. When provided with an invalid input, the output defaults to a configuration that turns off all segments.
