Design a circuit that functions as an n-to-2^n demultiplexer. For a given input signal, it routes the signal to one of the 2^n output lines based on the value of the n control signals. When the control signals match the index of an output line, that specific output line will reflect the input signal; all other outputs are driven LOW. This allows for selective activation of outputs based on the control signal combination.
module top_module(
  input in,
  input [n-1:0] ctl,
  output [2**n-1:0] out
);
