Design a 32-bit wide, 2-to-1 multiplexer. The module takes two 32-bit inputs, A and B, and outputs either A or B based on the value of the select signal; if select is 1, ArithOut outputs A, and if select is 0, it outputs B.
module top_module(
                        input  [31:0] A,
                        input  [31:0] B,
                        input   select,
                        output [31:0] ArithOut);
