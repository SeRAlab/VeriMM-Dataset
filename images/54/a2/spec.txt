Design a circuit that functions as an 8-bit wide 2-to-1 multiplexer. When the select input is 0, the output is taken from input 'a', and when the select input is 1, the output is taken from input 'b'. The most significant bit (MSB) of the selected input (either 'a' or 'b') is then assigned to the 'led' output, effectively representing the highest priority bit of the chosen input.
module top_module(
  input [7:0] a,
  input [7:0] b,
  input select,
  output reg led
);
