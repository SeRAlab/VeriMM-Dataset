Design a synchronous circuit that manages data input and output with valid and ready signals. The module processes an 8-bit input data signal and indicates its validity to downstream components. When `in_valid` is asserted, it captures the input data and passes it to the output while controlling the `out_valid` signal based on the readiness of the output interface indicated by `out_ready`. Additionally, the design ensures that the input can be accepted when the output is ready to receive data. This functionality is crucial for coordinating data flow in systems that rely on handshaking signals in a secure timing context.
module top_module(
    
      // Interface: clk
      input              clk,
      // Interface: reset
      input              reset_n,
      // Interface: in
      input              in_valid,
      input      [ 7: 0] in_data,
      // Interface: out
      output reg         out_valid,
      output reg [ 7: 0] out_data,
      input              out_ready
);
