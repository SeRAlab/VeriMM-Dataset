Create a Verilog module that implements a simple ALU (Arithmetic Logic Unit). The module should have the following specifications:
- `clk`: The clock signal.
- `reset`: An active-high synchronous reset signal.
- `a`: An 8-bit input operand.
- `b`: An 8-bit input operand.
- `op`: A 2-bit input specifying the operation (00: addition, 01: subtraction, 10: AND, 11: OR).
- `result`: The 8-bit output result of the ALU operation.
