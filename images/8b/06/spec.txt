Design a 4-bit counter module that increments its value on each clock cycle when enabled. The counter resets to zero when the reset signal is active. The output Q represents the current count value and is updated through a series of registers to ensure proper synchronization with the clock signal. The module effectively acts as a 4-stage pipeline, allowing for the management of timing and enhance stability in counting operations.
module top_module(
    input clk,
    input reset,
    input enable,
    output reg [3:0] Q
);
