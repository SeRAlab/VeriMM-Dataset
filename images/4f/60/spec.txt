Design a 4-to-1 multiplexer that selects one of four 4-bit input vectors (A, B, C, D) based on a 2-bit select signal (S). The output (Y) is a 4-bit wide signal, where each bit is determined by the selected input based on the value of S: when S indicates a specific input pair, the corresponding bits from those inputs are outputted. The design utilizes a combination of "AND" and "OR" gates to achieve the multiplexing functionality for each bit of the output.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input [3:0] C,
    input [3:0] D,
    input [1:0] S,
    output reg [3:0] Y
);
