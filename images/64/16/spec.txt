Design a 5-to-1 multiplexer that selects one of five 32-bit wide input data signals based on a 3-bit selection input (`load_option`). The selected output corresponds to the following conditions: when `load_option` is 000, the output is the lw input; 101 corresponds to lb; 001 to lbu; 111 to lh; and 011 to lhu. The output (`ext_Dout`) reflects the chosen input based on the value of `load_option`.
module top_module(lb,lbu,lh,lhu,lw,load_option,ext_Dout);
