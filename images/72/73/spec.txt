Design a simple 8-bit calculator that performs basic arithmetic operations. The module takes two 8-bit inputs, `a` and `b`, and a 2-bit operation selector `op`. Based on the value of `op`, the module can add, subtract, multiply, or divide the two inputs, providing the resulting 8-bit output in `result`. The operations correspond to the following opcodes: `00` for addition, `01` for subtraction, `10` for multiplication, and `11` for division.
module top_module(
    input [7:0] a,
    input [7:0] b,
    input [1:0] op,
    output reg [7:0] result
);
