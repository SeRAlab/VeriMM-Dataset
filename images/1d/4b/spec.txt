Design a 16-bit SRAM cell with read and write functionality. The cell should have a 16-bit data input (din), a 16-bit data output (dout), a read enable signal (read_en), a write enable signal (write_en), and a clock signal (clk). The SRAM should store the data on the rising edge of the clock when write_en is high, and output the stored data when read_en is high.
