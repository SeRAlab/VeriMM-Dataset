Implement an 8-bit shift register that supports bidirectional shifting based on the DIR control signal. When DIR is low (0), the data shifts to the left, with the bits moving from stage to stage in a leftward direction. Conversely, when DIR is high (1), the data shifts to the right, with the bits moving from stage to stage in a rightward direction. The output Q reflects the contents of the first stage of the shift register after the shifting operation.
module top_module(
    input [7:0] D,
    input DIR,
    output [7:0] Q
);
