
You are tasked with designing a Verilog module that takes in two 8-bit binary numbers A and B and outputs their sum in binary. The module should also output a carry-out signal indicating whether an overflow occurred during addition. You may assume that the inputs are valid 8-bit binary numbers.

Use the following code snippet as a starting point:
```
module binary_adder (
    input [7:0] A,
    input [7:0] B,
    output [7:0] sum,
    output carry_out
);

endmodule
```
