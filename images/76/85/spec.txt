Design a 4-to-1 multiplexer that selects one of three inputs (A, B, or C) based on the 2-bit select signal S. When S is 00, the output O is assigned the value of A. When S is 01, O takes the value of C. Finally, when S is 10, O outputs the value from B. Note that the design does not assign an output for the case when S is 11, leading to potentially undefined behavior in this state.
module top_module(input A, B, C, input [1:0] S, output reg O);
