Implement a memory module with write and read capabilities. The circuit allows writing 4 bits of data (wdata) into a selected byte (addr) of a memory array, based on a specified write offset (woffset). The memory array consists of 4 bytes, each 8 bits wide. On each positive clock edge, the specified 4 bits of data are written into the designated position within the chosen memory byte, and the entire byte is then read out as the output (rdata).
module top_module(clk, addr, woffset, wdata, rdata);
