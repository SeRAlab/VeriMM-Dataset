Design a simple finite state machine (FSM) that simulates a basic SLAM process. The FSM should have three states: `Idle`, `Mapping`, and `Localizing`. The system starts in the `Idle` state. The input signal `start` transitions the FSM to the `Mapping` state. The FSM remains in `Mapping` for a fixed number of clock cycles, after which it transitions to the `Localizing` state. If the `localize_done` signal is asserted, the FSM goes back to the `Idle` state.
