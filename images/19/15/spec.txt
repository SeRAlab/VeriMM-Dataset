Design a simple ARQ (Automatic Repeat reQuest) system that detects errors in transmitted data. The system should incorporate a sender and a receiver. The sender transmits a 5-bit data word and waits for an acknowledgment (ACK) from the receiver. If the receiver detects an error in the transmitted data, it sends a negative acknowledgment (NACK) back to the sender, which will then retransmit the same data word. The receiver should be able to check for errors using a simple parity bit mechanism.
