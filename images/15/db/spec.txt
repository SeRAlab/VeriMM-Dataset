Design a 1-bit SRAM cell that can store a single bit of data. The SRAM cell should have the following inputs: `write_enable`, `data_in`, and `clock`. The output should be `data_out`. When `write_enable` is high, the value of `data_in` should be written to the cell on the rising edge of the clock. If `write_enable` is low, the stored value should be maintained and output on `data_out`.
