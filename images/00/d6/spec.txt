Design an 8-bit SRAM cell that supports write and read operations. The SRAM cell should have the following inputs: a clock (clk), a write enable signal (we), an 8-bit input data (data_in), a 3-bit address (addr), and an 8-bit output data (data_out). When the write enable signal is high, the data input should be stored at the specified address on the rising edge of the clock. When the write enable signal is low, the output should reflect the data stored at the specified address.
