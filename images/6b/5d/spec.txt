Design a digital display controller capable of driving a 7-segment display for a 16-bit input number. It accepts a clock signal to manage timing and an input value in the form of a 16-bit binary number. The module operates with a ticking mechanism to enable one of the four anode lines every 1 ms, cycling through each digit. Depending on the active anode, it selects the corresponding 4-bit nibble from the input number and generates the appropriate 7-segment encoding to display hexadecimal digits (0-F). The output includes segment signals to display the selected digit and an active-low anode signal for drive control.
module top_module(
    input clk,
    input [15:0] disp_num,
    output reg [6:0] seg,
    output reg [3:0] anode
);
