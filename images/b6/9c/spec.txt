Design a digital-to-analog converter (DAC) that takes an 8-bit input (`dac_in`) and, based on a clock signal (`clk`) and a reset signal (`rst`), produces a 7-bit output (`dac_out`). Upon receiving a reset, the converter initializes its internal register to zero. When the conversion signal (`conv`) is triggered, the DAC updates its internal register with the new input value. The output is generated by converting the stored digital value from the register into a corresponding analog voltage level, scaled according to a reference voltage (`V_REF`) and resolution parameters.
module top_module(
    input [7:0] dac_in,
    input clk,
    input rst,
    input conv,
    output reg [6:0] dac_out
);
