Design a synchronous 8-bit binary adder with a carry-in capability. The module takes two 8-bit inputs, `a` and `b`, along with a carry-in `cin`. On each positive clock edge, if the `rst` signal is asserted, the output `sum` is reset to zero and the carry-out `cout` is cleared. Otherwise, it computes the sum of `a`, `b`, and `cin`, updating `sum` and `cout` accordingly.
module top_module(
    input clk,
    input rst,
    input [7:0] a,
    input [7:0] b,
    input cin,
    output reg [7:0] sum,
    output reg cout
);
