

You are tasked with designing a Verilog module that implements a D flip-flop with an asynchronous active low set input. The module should have the following inputs and outputs:

- `CLK`: a clock input
- `D`: a data input
- `SET_B`: an active low set input
- `Q`: a data output

The module should behave as follows:
- On the rising edge of `CLK`, the output `Q` should update to the value of input `D`.
- If `SET_B` is asserted (i.e., it is 0), then the output `Q` should immediately be set to 0, regardless of the value of `D`.
- The module should not have any race conditions or glitches.

You should implement the module within 200 lines of Verilog code.
