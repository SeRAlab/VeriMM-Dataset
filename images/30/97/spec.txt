
Create a 2nd order Infinite Impulse Response (IIR) filter with the following transfer function:
H(z) = (b0 + b1*z^(-1) + b2*z^(-2)) / (1 + a1*z^(-1) + a2*z^(-2))
where b0, b1, b2 are the feedforward coefficients and a1, a2 are the feedback coefficients. The inputs are 16-bit signed integers and the outputs are also 16-bit signed integers. Implement the filter using Verilog with a clock and reset signal. The filter should maintain state between clock cycles for the previous outputs and inputs.
