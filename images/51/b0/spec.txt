Design a 4-to-1 multiplexer that selects one of four 1-bit inputs based on a 2-bit select signal. The output will reflect the value of the selected input: when sel is 00, the output is in[0]; when sel is 01, the output is in[1]; when sel is 10, the output is in[2]; and when sel is 11, the output is in[3].
module top_module(
  input [3:0] in,
  input [1:0] sel,
  output reg out
);
