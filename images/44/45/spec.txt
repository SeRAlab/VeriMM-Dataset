Design a D-type flip-flop (DFF) with a scan input/output feature for testing purposes. The module captures the input data (din) on the rising edge of the clock (clk) and outputs it (q) under normal operation. When the scan-enable (se) signal is activated, the module captures the scan input (si) instead, allowing for test data to be shifted through the flip-flop. The scan output (so) provides the current state of the scan register, enabling efficient testing and debugging of the circuit by facilitating on-chip scanning.
