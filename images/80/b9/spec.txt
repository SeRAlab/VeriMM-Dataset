Design a Verilog module that implements a 1-byte wide, 4-depth FIFO buffer. The FIFO should have write and read operations controlled by write_enable and read_enable signals, respectively. The FIFO should output the current data on the read operation.
module fifo (
	input clk,
	input reset,
	input write_enable,
	input read_enable,
	input [7:0] data_in,
	output reg [7:0] data_out);
