

You are tasked with designing a verilog module that performs a certain operation on three input values A, B, and C. The module takes in a 9-bit input value Op and three 5-bit input values A, B, and C. The module outputs a 5-bit value O.

The operation is performed as follows:
- The 9th bit of Op determines whether the output value should be equal to A or the result of the operation.
- The 8th to 5th bits of Op are used to multiply A, B, and C by a certain factor.
- The 4th and 3rd bits of Op are used to multiply B by a certain factor.
- The 2nd and 1st bits of Op are used to multiply C by a certain factor.
- The output value is the sum of the three multiplied values, unless the 9th bit of Op is set to 1, in which case it is equal to A.

Design a verilog module that performs this operation and outputs the result.
