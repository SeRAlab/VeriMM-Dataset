Design a Verilog description for a Flash memory cell that maintains its state between clock cycles and can be programmed or erased based on control signals. The memory cell should have the following inputs: `clk` (clock), `ctrl` (control signal: 0 for read, 1 for program/erase), and `data_in` (data to be written). The output should be `data_out` (current state of the memory cell). When `ctrl` is high, the `data_in` should be stored in the memory cell on the rising edge of `clk`. When `ctrl` is low, the cell should maintain its current state until it is programmed again.
