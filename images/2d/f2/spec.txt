
Design a state-space controller for a discrete-time system. The system has a state vector x[n], an input vector u[n], and an output vector y[n]. The state transition is defined by the equation:
x[n+1] = Ax[n] + Bu[n]
The output is defined by:
y[n] = Cx[n] + Du[n]
Where A, B, C, and D are fixed matrices defined as follows:
A = [0 1; -1 -1]
B = [0; 1]
C = [1 0]
D = 0
Implement this controller in Verilog, ensuring that your design can handle a 2-bit state representation and 1-bit input/output.
