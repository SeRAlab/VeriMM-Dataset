
Design a simple Network Address Translation (NAT) logic that translates a private IP address to a public IP address based on a predefined mapping. The module should take in a 32-bit private IP address and output the corresponding 32-bit public IP address. The mapping should be stored in a register and should handle up to 5 entries. If the private IP does not exist in the mapping, the output should be a default value (e.g., 0.0.0.0).
