

You are tasked with designing a module in Verilog that implements a 3-bit counter with synchronous reset and enable. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock signal
- `rst`: a synchronous reset signal (active high)
- `en`: an enable signal (active high)

Outputs:
- `count`: a 3-bit output representing the current count value

The counter should increment on each rising edge of the clock signal when the enable signal is high, and reset to 0 when the reset signal is high. If both reset and enable are high, the counter should remain at 0.

You should name your module `counter_3bit`.
