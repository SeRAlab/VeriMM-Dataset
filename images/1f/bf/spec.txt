
Design a fan speed control system that adjusts the speed of a fan based on temperature readings. The system should have the following functionality:
- If the temperature is below 20 degrees Celsius, the fan speed should be set to low (1).
- If the temperature is between 20 and 30 degrees Celsius, the fan speed should be set to medium (2).
- If the temperature is above 30 degrees Celsius, the fan speed should be set to high (3).
The temperature input will be a 7-bit value representing the temperature in degrees Celsius.
