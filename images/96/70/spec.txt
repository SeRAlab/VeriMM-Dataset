Design a synchronous 4-bit binary counter that increments its value on each rising edge of the clock signal (CK) when the enable signal (EN) is asserted. The counter resets to zero when the reset signal (RST) is active. The current count value is represented by the 4-bit output Q, which updates according to the specified conditions.
