Design a 24-bit ADC (Analog to Digital Converter) output processing module that takes the 24-bit digital input value from the ADC and outputs a 4-bit status signal indicating the range of the input value. The ranges are defined as follows:
- If the input is between 0 and 15, set the output status to 4'b0001.
- If the input is between 16 and 255, set the output status to 4'b0010.
- If the input is between 256 and 4095, set the output status to 4'b0100.
- If the input is between 4096 and 65535, set the output status to 4'b1000.
- If the input is greater than 65535, set the output status to 4'b1111.
