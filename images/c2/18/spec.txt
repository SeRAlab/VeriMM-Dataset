

You are tasked to design a verilog module that implements a 4-input AND gate with the following input and output ports:

- `input [3:0] A`: 4-bit input bus
- `output Y`: 1-bit output

The module should be named `AND4_W9`. You are required to use only AND gates and NOT gates in your implementation.

Write the verilog code for the `AND4_W9` module.
