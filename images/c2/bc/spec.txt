

You are asked to create a verilog module for a simple calculator that can perform addition and subtraction operations on two 4-bit numbers. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock signal
- `reset`: a synchronous active-high reset signal
- `a`: a 4-bit input representing the first operand
- `b`: a 4-bit input representing the second operand
- `op`: a 1-bit input representing the operation to be performed (0 for addition, 1 for subtraction)

Outputs:
- `result`: a 4-bit output representing the result of the operation

The module should perform the following operations:
- If `reset` is high, the `result` output should be set to 0.
- If `op` is 0, the `result` output should be the sum of `a` and `b`.
- If `op` is 1, the `result` output should be the difference between `a` and `b`.
