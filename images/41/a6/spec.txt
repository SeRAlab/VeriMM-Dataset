Implement a 2-to-1 multiplexer that outputs a 16-bit data word. The output DATA is determined by the SEL signal: when SEL=0, DATA takes the value of the TRIGGERED input; when SEL=1, DATA outputs the value from the RAM_DATA input.
module top_module(input SEL, input TRIGGERED, input [15:0] RAM_DATA, output [15:0] DATA);
