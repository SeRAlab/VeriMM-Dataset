
Design a 2nd-order IIR filter using Verilog. The filter should have two input samples and produce one output sample based on the following difference equation:
y[n] = (b0 * x[n] + b1 * x[n-1] + b2 * x[n-2] - a1 * y[n-1] - a2 * y[n-2]) / (2^Q)
Where:
- b0, b1, b2 are the feedforward coefficients.
- a1, a2 are the feedback coefficients.
- x[n] is the current input sample.
- y[n] is the current output sample.
- Q is a scaling factor (set to 16 for this example).
The filter should be implemented in a way that handles input samples arriving at each clock cycle.
