
Create an 8-bit DRAM cell that can store a single bit of data per cell. The DRAM cell should have the following ports:
- `data_in`: 1-bit input data.
- `addr`: 3-bit address input (to select one of the 8 cells).
- `write_enable`: 1-bit signal to control write operation (1 means write, 0 means read).
- `data_out`: 1-bit output data.
- A clock signal `clk` to synchronize the read/write operations.
