Design a circuit that converts a 4-bit binary input into its corresponding 4-bit Gray code output. The conversion process is triggered by the rising edge of a clock signal, where the most significant bit of the Gray code directly mirrors the most significant bit of the binary input, and each subsequent bit is derived by performing a bitwise XOR operation between the current and previous bits of the binary input. The resulting Gray code is held in a register and outputted accordingly.
module top_module(
  input clk,
  input [3:0] binary_input,
  output [3:0] gray_output
);
