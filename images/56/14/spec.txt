Implement the Verilog module based on the following description.
Build an 8-bit counter with asynchronous positive edge triggered reset and a synchronous active high enable signal. The counter has an up/down control signal.
(1) reset: Resets the counter to zero.
(2) enable: Enables the counter to count.
(3) up: Determines the counting direction; up when high, down when low.
(4) count: The current value of the counter.

module counter(
    input clk,
    input reset,
    input enable,
    input up,
    output reg [7:0] count);
