Design a simple arithmetic and logic unit (ALU) that performs various operations on two 8-bit inputs, A and B, based on a 3-bit control signal. The unit supports addition, subtraction, bitwise AND, bitwise OR, bitwise XOR, left shift, right shift, and multiplication. The result of the selected operation is output as an 8-bit value. If the control signal does not match any defined operation, the output is set to zero.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input [2:0] control,
    output reg [7:0] result
);
