
Design a 16-bit SRAM cell that allows for write and read operations. The SRAM should have the following ports:
- `input [15:0] data_in`: 16-bit data input for writing to the SRAM.
- `input write_enable`: Control signal to enable writing to the SRAM.
- `input read_enable`: Control signal to enable reading from the SRAM.
- `output [15:0] data_out`: 16-bit data output for reading from the SRAM.
- `input clk`: Clock signal for synchronous operation.
