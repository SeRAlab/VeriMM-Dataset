

You have been tasked with designing a verilog module that implements a 2-input AND gate with an additional input 'C1' which is an active-high control signal. The module should be named 'and_gate_ctrl' and should have the following inputs and outputs:

Inputs:
- A: 1-bit input
- B: 1-bit input
- C1: 1-bit input

Outputs:
- Y: 1-bit output

The module should only output the AND of A and B when C1 is high. When C1 is low, the output Y should be set to 0.

Write the verilog code for the and_gate_ctrl module that meets the above specifications.
