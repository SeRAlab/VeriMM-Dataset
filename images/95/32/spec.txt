Design a Time-to-Digital Converter (TDC) that measures the time interval between a start and stop signal. When the start signal is asserted, the circuit initializes a counter and begins counting clock cycles. Upon receiving a stop signal, the counting halts, and the current count value is captured in the output register. The TDC outputs an n-bit digital representation of the time interval, where n is configurable, allowing for flexibility in timing resolution.
module top_module(
  input clk,         // Added clk input
  input start,
  input stop,
  output reg [n-1:0] tdc
);
