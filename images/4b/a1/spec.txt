Design a Verilog module that implements a 12-bit binary counter with load and synchronous reset. The module should have a clock input, a synchronous reset input, a load input, a 12-bit load value input, and a 12-bit output. The counter should increment on every clock cycle, load the load value when the load signal is high, and reset to 0 when the reset signal is high.

module counter12bit_sync_load (
    input clk,
    input rst,
    input load,
    input [11:0] load_value,
    output reg [11:0] count
);
