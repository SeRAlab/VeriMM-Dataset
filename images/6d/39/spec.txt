Design a byte-enable register that stores a 32-bit data value. It allows selective writing to specific bytes of the register based on the enable input and write enable signal. Upon receiving a reset signal, it initializes the register to a predefined value. The register updates its output with the corresponding bits from the input data when the write enable signal is active and the respective byte enable signals indicate that the corresponding byte is selected.
