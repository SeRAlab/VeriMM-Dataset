Implement a Binary Counter module that counts from 0 to 15. The counting should be done on the positive edge of the clock signal and should reset to 0 when the reset signal is active.

Module name:  
    binary_counter
                 
Input ports:
    clk: Clock signal used for synchronous operation.
    rst: Active-high reset signal. Defined as 1 for reset and 0 for reset signal inactive.

Output ports:
    count: 4-bit output signal representing the current count.

Implementation:
On reset, indicated by rst, the count register is cleared to 0.
On each positive edge of the clock signal, the count register is incremented by 1.
When the count reaches 15, it rolls over to 0 on the next clock edge.

Give me the complete code.

module binary_counter(
  input clk,
  input rst,
  output reg [3:0] count
);
