Design a D flip-flop with an asynchronous reset functionality. On the rising edge of the clock, if the reset signal (r) is low, the output (q) takes the value of the data input (d). If the reset signal is high, the output (q) is set to a logic high (1). This setup allows for immediate resetting of the flip-flop state independent of the clock signal.
module top_module(
  input clk,       // clock input
  input d,         // data input
  input r,         // asynchronous reset input
  output reg q     // flip-flop output
);
