Design a Verilog module that implements a PID controller. The PID controller should take an error signal as input and output a control signal. The controller parameters (Proportional, Integral, and Derivative gains) should be configurable through parameters. The output should be updated on every clock cycle with the calculated control signal based on the PID formula:  
   Control Signal = Kp * error + Ki * integral + Kd * derivative,  
   where integral is the cumulative sum of errors and derivative is the difference between the current error and the previous error.
