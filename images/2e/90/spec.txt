Design a noise suppression system using a finite state machine (FSM) that takes a noisy input signal and outputs a clean version of the signal. The FSM should have two states: IDLE and CLEAN. In the IDLE state, the system waits for a stable input signal for a specified number of clock cycles before transitioning to the CLEAN state when a valid signal is detected. In the CLEAN state, the system outputs the clean signal until it detects noise again, at which point it returns to the IDLE state.
