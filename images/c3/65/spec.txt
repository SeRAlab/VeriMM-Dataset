

You are tasked with designing a verilog module that takes in 4 input signals A1, A2, B1, and C1, and produces a single output signal X. You need to implement the module using the following logic:

- A1 and A2 are inputs to an OR gate.
- The output of the OR gate is connected to one input of an AND gate.
- The other two inputs of the AND gate are B1 and C1.
- The output of the AND gate is connected to the input of a buffer.
- The output of the buffer is the output signal X.

Implement the above logic in a verilog module named "logic_module". Ensure that the module has the correct input and output ports, and that the module is synthesizable.
