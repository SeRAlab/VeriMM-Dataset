Design a 4-to-2 multiplexer that takes four single-bit inputs (in0 to in3) and based on the 2-bit selection input (sel), outputs a 2-bit result. The most significant bit of the output is determined by the selected input, while the least significant bit is always set to LOW. When sel is 00, in0 is selected; when sel is 01, in1 is chosen; for sel 10, in2 is used; and for sel 11, in3 is selected.
module top_module(
  input in0,
  input in1,
  input in2,
  input in3,
  input [1:0] sel,
  output reg [1:0] out
);
