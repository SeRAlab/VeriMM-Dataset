Design a D flip-flop with reset and enable functionality. When RESET is asserted (active low), the output Q is set to 0. On the rising edge of the clock (CLK), if ENABLE (EN) is high, the flip-flop captures the value of input D and updates Q accordingly. If EN is low, Q retains its previous state, allowing for controlled data storage based on the enable signal.
module top_module(
    input D,
    input CLK,
    input RESET,
    input EN,
    output reg Q
);
