
Create a Verilog module for an SR latch. The latch should have two inputs, S (Set) and R (Reset), and two outputs, Q and Q_bar. The behavior should be such that when S is high, Q should be set to high, when R is high, Q should be set to low, and if both are low, Q should retain its previous state. Be sure to handle the case where both S and R are high, which is considered invalid for an SR latch.
