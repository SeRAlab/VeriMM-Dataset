Design an 8-bit Linear Feedback Shift Register (LFSR) using Verilog. The LFSR should use the polynomial x^8 + x^6 + x^5 + x^4 + 1 for feedback and produce a pseudo-random sequence of bits. The LFSR should be initialized with a non-zero seed value and should have a clock input and a reset input. Additionally, include an output that indicates when the LFSR has completed one full cycle.
