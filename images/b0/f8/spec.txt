Design a 16-bit wide program counter that updates its value based on a clock and reset signals. Upon resetting, the counter outputs zero. It can load a new value from an external input when the load enable signal is active. If the load enable signal is not asserted, it increments its current value by one when the increment signal is active, while retaining the current value otherwise. This module serves as a fundamental component in a CPU for tracking the address of the next instruction to execute.
