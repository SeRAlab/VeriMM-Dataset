
Design a JK flip-flop using behavioral Verilog. The JK flip-flop should include asynchronous reset functionality. The flip-flop should follow these behaviors:
- When J = 0 and K = 0, the state does not change.
- When J = 0 and K = 1, the output resets to 0.
- When J = 1 and K = 0, the output sets to 1.
- When J = 1 and K = 1, the toggle functionality occurs (output switches state).
- The flip-flop should be able to reset asynchronously when a reset signal is active high.
