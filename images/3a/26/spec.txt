Design a simple interrupt controller that can acknowledge an interrupt request (IRQ) and clear it when the interrupt is handled. The controller should have a clock (`clk`), an active-high interrupt request input (`irq`), an acknowledge output (`ack`), and a reset input (`rst`). When `rst` is high, the controller should reset. When `irq` is high and `rst` is low, the `ack` output should be set high until the interrupt is acknowledged, after which it should be cleared on the next clock cycle.
