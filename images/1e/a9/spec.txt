Design a system that adjusts the operating frequency and voltage of a processing unit based on the input load. The system should monitor a 3-bit input signal representing the load (from 0 to 7) and adjust the output frequency (also 3-bits) and voltage (2-bits) accordingly. The frequency and voltage levels should follow these rules:
- Load 0: Frequency = 000, Voltage = 00
- Load 1: Frequency = 001, Voltage = 01
- Load 2: Frequency = 010, Voltage = 01
- Load 3: Frequency = 011, Voltage = 10
- Load 4: Frequency = 100, Voltage = 10
- Load 5: Frequency = 101, Voltage = 11
- Load 6: Frequency = 110, Voltage = 11
- Load 7: Frequency = 111, Voltage = 11
