
You are tasked with designing a D flip-flop with synchronous reset and clock enable behavior in Verilog. The D flip-flop should have the following behavior:
- When the clock enable signal (ce) is high, the flip-flop should follow the input data (D) on the rising edge of the clock (Clk).
- When the clock enable signal (ce) is low, the flip-flop should hold its current state.
- When the synchronous reset signal (reset) is high, the flip-flop should be reset to 0 on the rising edge of the clock (Clk).
You should write a single module in Verilog that implements this behavior. Your module should have the following inputs and outputs:
- D: the input data
- Clk: the clock signal
- reset: the synchronous reset signal
- ce: the clock enable signal
- Q: the output of the flip-flop
You may assume that all input signals are synchronous to the same clock signal, and that the clock signal has a 50% duty cycle.
