Design a module for controlling an LED output based on a simple memory interface. This LED controller, which functions as an Avalon slave device, allows for the configuration of a 10-bit output representing the LED states. It accepts a 2-bit address and uses chip select, write enable, and clock signals to update the state of the LEDs. When a write operation is performed at address zero, the data written is captured to update the LED states, while the module also provides the current LED states for read-back. On reset, the LED states are initialized to a specific value (682 in decimal). The output provides both the LED state directly and the read-back data in the appropriate format.
module top_module(
  input [1:0] address,
  input chipselect,
  input clk,
  input reset_n,
  input write_n,
  input [31:0] writedata,
  output [9:0] out_port,
  output [31:0] readdata
);
