Design a register shifter that processes a 32-bit input to prepare it for memory write operations based on control signals. It shifts the input data according to the provided memory address and modifies a byte-enable output signal depending on the write operation. Specifically, when the instruction opcode (IR_out) indicates a store operation (101011), the full data is output with all byte enables active. For other opcodes, the output will be shifted left according to the specified memory address, thereby determining which bytes of the data are targeted for writing, while appropriately setting the byte enable signal to indicate active bytes.
