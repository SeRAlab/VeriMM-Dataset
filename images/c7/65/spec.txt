

You are tasked with designing a 4-to-1 multiplexer using Verilog. The module should have four input signals, a two-bit select signal, and one output signal. The select signal should determine which of the four input signals is passed through to the output signal. The module should be named "mux4to1".

Declare the following signals in the module:
- Four input signals: A, B, C, and D
- Two-bit select signal: S
- One output signal: Y

Ensure that the module has the following functionality:
- If S = 2'b00, Y should be equal to A
- If S = 2'b01, Y should be equal to B
- If S = 2'b10, Y should be equal to C
- If S = 2'b11, Y should be equal to D
