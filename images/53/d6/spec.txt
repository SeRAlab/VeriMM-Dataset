    parallel_load_register

Input ports:
    CLK: Clock input
    RST: Active high reset signal
    LOAD_EN: Load enable signal
    D: 4-bit data input

Output ports:

Implementation:
The parallel load register module uses an always block to update the contents of the register based on the clock signal, reset signal, and load enable signal.
