Design a one-shot pulse generator that produces a high output pulse for a specified duration (t clock cycles) each time a trigger signal (trig) is asserted. The pulse duration is configurable, and it is initiated on the rising edge of the clock signal (clk). When the trig signal is high, a counter is reset, and the output remains high until the counter reaches the specified duration, at which point the output is set low. During the counting period, the output continues to be high as long as the counter is less than the specified duration.
module top_module(
  input trig,
  input clk,
  output reg out
);
