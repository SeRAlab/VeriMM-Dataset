Design a voltage sensor that detects when the voltage exceeds a certain threshold (e.g., 5V). The sensor should have an input for the voltage level and a clock input. When the voltage exceeds the threshold on a rising clock edge, it should set an output signal to '1'. If the voltage is below the threshold, the output should be '0'. The design should also have an asynchronous reset input that resets the output to '0' regardless of the voltage level.
