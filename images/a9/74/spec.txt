Design a D flip-flop with asynchronous reset and preset features. The output Q is updated on the rising edge of the clock (CLK). When the RESET input is active, Q is set to LOW; when the PRESET input is active, Q is set to HIGH. If both RESET and PRESET are inactive, Q follows the input D, allowing for standard D flip-flop behavior.
module top_module(
    output reg Q,
    input CLK,
    input D,
    input RESET,
    input PRESET
);
