
The problem involves designing a simple temperature sensor interface that converts a 5-bit binary input representing temperature (in degrees Celsius) to a 3-bit binary output that indicates the corresponding temperature range. The output should be defined as follows:
- 000: Temperature < 10°C
- 001: 10°C <= Temperature < 20°C
- 010: 20°C <= Temperature < 30°C
- 011: 30°C <= Temperature < 40°C
- 100: 40°C <= Temperature < 50°C
- 101: Temperature >= 50°C
