Implement a Verilog module based on the following description.
Design a finite state machine with input x. The FSM starts in state S0. If x=1, it moves to state S1. In state S1, if x=0, it sets an output z to 1 in the following clock cycle, otherwise z is 0. The FSM returns to state S0 if x=0. Assume reset is active high synchronous.
