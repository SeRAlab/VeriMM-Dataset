
Design a simple Automatic Repeat reQuest (ARQ) error correction system that can detect errors in a transmitted data packet and request retransmission if an error is detected. The system will include an error detection mechanism using a parity bit. The transmitted data consists of 5 bits, and there will be a signal to indicate whether the received data is correct or erroneous. If an error is detected, the system should request a retransmission of the data. The output should indicate the status of the data (correct/incorrect) and whether a retransmission is in progress.
