Design an edge detector circuit that identifies rising and falling edges of an input signal. The module employs a clock signal for synchronization and a reset signal to initialize its state. The circuit outputs a high signal for `rising_edge` when the input transitions from LOW to HIGH and a high signal for `falling_edge` when the input transitions from HIGH to LOW. When the input remains unchanged, both output signals are LOW, ensuring accurate edge detection while keeping track of the previous input state.
module top_module(
  input clk,
  input reset,
  input in,
  output reg rising_edge,
  output reg falling_edge
);
