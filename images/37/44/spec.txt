Design a 4-bit DRAM cell that has the following functionality: it can store a 4-bit value and has a read and write capability. The DRAM cell will have a write enable signal (we), a read enable signal (re), a 4-bit data input (data_in), and a 4-bit data output (data_out). The cell should update its stored value on a write operation and output the stored value on a read operation.
