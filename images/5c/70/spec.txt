Develop a barrel shifter that allows for an 8-bit input data to be shifted either left or right based on a 3-bit shift amount and a single control bit indicating the direction. The output is updated through a three-stage pipeline, ensuring that the shifted data is available in a timely manner. When the shift direction is set to '0', the module performs a left shift; when set to '1', it performs a right shift, yielding the resulting shifted data at the output.
module top_module(
    input [7:0] DATA,
    input [2:0] SHIFT_AMOUNT,
    input SHIFT_DIRECTION,
    output [7:0] SHIFTED_DATA
);
