Design a 4-bit shift register with parallel input. The module shifts its contents left or right based on the `shift_dir` control signal on each rising edge of the clock. When `shift_dir` is 0, it shifts left and inserts the `in` value at the least significant bit position. When `shift_dir` is 1, it shifts right and inserts the `in` value at the most significant bit position.
module top_module(
    input [3:0] in,
    input shift_dir,
    input clk,
    output reg [3:0] out
);
