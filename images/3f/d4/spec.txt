
Design an 8-bit Linear Feedback Shift Register (LFSR) that utilizes the polynomial x^8 + x^6 + x^5 + x^4 + 1. The LFSR should have an active-high reset signal that initializes the register to a known value, and it should allow shifting of the bits on every clock cycle. The output of the LFSR should be given on a 8-bit output port.
