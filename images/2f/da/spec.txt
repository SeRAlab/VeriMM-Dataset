Design a BCD to 7-segment display decoder in Verilog. The module should take a 4-bit Binary-Coded Decimal (BCD) input and output a 7-bit signal representing the corresponding segments that should be lit for a 7-segment display. The BCD input should range from 0 to 9, and any input above 9 should output all segments off (i.e., 0 for all segments).
