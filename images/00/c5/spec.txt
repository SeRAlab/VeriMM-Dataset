Design an 8-bit Linear Feedback Shift Register (LFSR) that generates a pseudo-random sequence. The LFSR should use the polynomial x^8 + x^6 + x^5 + x^4 + 1 as the feedback polynomial. The LFSR should be initialized with a non-zero seed value and should have an enable input to start the shifting process. The output should be the current state of the LFSR after each clock cycle.
