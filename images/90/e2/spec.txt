Design a 4-to-1 multiplexer that routes one of four 1-bit inputs (in0, in1, in2, in3) to a single output based on a 2-bit selection input (sel). The output will reflect the selected input according to the values of sel: if sel is 00, out is set to in0; if sel is 01, out is set to in1; if sel is 10, out is set to in2; and if sel is 11, out is set to in3.
module top_module(
    input in0,
    input in1,
    input in2,
    input in3,
    input [1:0] sel,
    output reg out
);
