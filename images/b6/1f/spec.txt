Design a simple 32-bit Arithmetic Logic Unit (ALU) that performs addition or subtraction based on the value of the input control signal 'op'. When 'op' is 0, the module computes the sum of inputs 'a' and 'b', and when 'op' is 1, it computes their difference. The module also generates three additional outputs: 'z' for zero detection (asserted if the result is zero), 'n' for negative detection (asserted if the result is negative), and 'c' and 'w' are unused outputs set to zero. This ALU component can be used in larger arithmetic operations within digital systems.
module top_module(output [31:0] o,
	     output 	  z,
	     output 	  n,
	     output 	  c,
	     output 	  w, 
	     input [31:0] a,
	     input [31:0] b,
	     input 	  op);
