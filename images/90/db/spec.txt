Design a 4-bit barrel shifter that performs circular shifting on the input data. The module takes a 4-bit input DATA and a 2-bit SHIFT value, which determines the direction and amount of the shift. Depending on the value of SHIFT, the output RESULT will reflect the DATA shifted right by 0, 1, or 2 bits or left by 1 bit, effectively allowing for a versatile bit manipulation suitable for various digital applications.
module top_module(
    input [3:0] DATA,
    input [1:0] SHIFT,
    output [3:0] RESULT
);
