Design a circuit that generates three status flags based on a 16-bit input. The `flag_negative` output is set if the most significant bit (bit 15) of the input is high, indicating a negative value. The `flag_zero` output is asserted when all bits of the input are low, indicating a zero value. The `flag_positive` output is derived as the logical negation of both the `flag_negative` and `flag_zero` signals, indicating a positive value when neither of the other two flags is active.
module top_module(
    input [15:0] in,
    output flag_negative, flag_zero, flag_positive
    );
