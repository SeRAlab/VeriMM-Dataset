Design a simple NVMe controller register that takes a 5-bit command input and produces a 5-bit status output based on the following rules:  
- If the command is '00000', output '11111' (indicating SUCCESS).  
- If the command is '00001', output '11110' (indicating ERROR).  
- If the command is '00010', output '11101' (indicating TIMEOUT).  
- For any other command, output '00000' (indicating UNKNOWN).
