Design a one-bit wide, 4-to-1 multiplexer. The module takes a 4-bit input and a 2-bit select signal. Based on the value of the select signal, the output will be assigned one of the four input bits: when the select signal is 00, the output will be the first input; 01 will select the second input; 10 will choose the third input; and 11 will output the fourth input.
module top_module(
    input [3:0] I,
    input [1:0] S,
    output reg O
    );
