Design a decoding circuit that takes an 8-bit input vector and outputs two 8-bit data signals. The first output, `data1`, is set to the hexadecimal value `55` when the second bit of the input vector (`decode_vec`) is high, while the second output, `data2`, is set to `55` when the third bit is high. Both outputs are initialized to zero by default. The circuit continuously monitors the input vector and the resulting outputs for changes.
module top_module(
    input [7:0] decode_vec,
    output reg [7:0] data1,
    output reg [7:0] data2
);
