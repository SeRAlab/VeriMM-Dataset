
You are tasked with designing a module for a digital circuit that takes in a 4-bit binary input and outputs the binary equivalent of its Gray code. The module should be named `bin2gray` and should have the following inputs and outputs:

**Inputs:**
- `bin[3:0]`: a 4-bit binary input

**Outputs:**
- `gray[3:0]`: a 4-bit binary output representing the Gray code equivalent of `bin`

The module should be synchronous and should be triggered on the positive edge of the clock signal. The module should also have a reset input, `reset`, which when asserted should reset the output to all zeros.

You may assume that the inputs will always be valid 4-bit binary numbers.
