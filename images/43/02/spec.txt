Please act as a professional Verilog designer.

Design a 4-bit binary counter with enable signal. The counter should increment its value on each clock cycle when the enable signal is high. The counter should reset to 0 when the reset signal is active.

Module name:
    BinaryCounterWithEnable
Input ports:
    clk: Clock signal used for synchronous operation.
    reset: Active-high reset signal.
    enable: Signal to enable the counter.

Output ports:
    count: 4-bit output representing the current count value.
