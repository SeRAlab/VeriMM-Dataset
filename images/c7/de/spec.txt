

You have been tasked with designing a verilog module that implements a 4-bit adder with carry-in and carry-out functionality. The module should have the following inputs and outputs:

Inputs:
- `a` (4-bit input)
- `b` (4-bit input)
- `cin` (1-bit input)

Outputs:
- `sum` (4-bit output)
- `cout` (1-bit output)

The module should be named `adder_4bit`.
