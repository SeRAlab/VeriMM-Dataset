Design a 4-bit wide arithmetic unit capable of performing addition and subtraction operations based on a 3-bit control signal. When the control signal `C` is `000`, the module outputs the sum of inputs `A` and `B`; when `C` is `001`, it outputs the difference of `A` and `B`. For any other control signal value, the output is set to zero, indicating an invalid operation.
module top_module(
	input [3:0] A,
	input [3:0] B,
	input [2:0] C,
	output reg [3:0] R
	);
