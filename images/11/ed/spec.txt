
Design a JK flip-flop in Verilog that has the following behavior:
- J and K inputs control the state transitions.
- If J=K=0, the flip-flop holds its state.
- If J=K=1, the flip-flop toggles its state.
- If J=1 and K=0, the flip-flop sets the output to 1.
- If J=0 and K=1, the flip-flop resets the output to 0.
The flip-flop should also have a clock (clk) and an asynchronous reset (reset) input.
