Design an 8-bit shift register with synchronous loading and shifting. The shift register should have the following inputs: a clock signal (clk), a reset signal (rst), a load enable signal (load), and an 8-bit input data signal (data_in). When the load signal is high, the input data should be loaded into the shift register. When the load signal is low, the shift register should shift its contents to the right on each rising edge of the clock. The output should be the current state of the shift register.
