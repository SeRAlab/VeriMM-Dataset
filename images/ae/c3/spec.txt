Design a 4-bit synchronous up counter with reset and enable functionality. When the reset signal is activated, the counter resets to zero. If the enable signal is asserted, the counter increments its value on each rising edge of the clock. The current count is available at the output, allowing for external observation of the counter's state.

   input clk,
   input rst,
   input enable,
   output reg [3:0] out
);
