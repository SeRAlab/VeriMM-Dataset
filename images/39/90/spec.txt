
Design a simple Network Address Translation (NAT) module in Verilog. The module should accept a 32-bit internal IP address and a 32-bit external IP address as inputs and provide a 32-bit translated IP address as output. The NAT should use a simple mechanism where the first bit of the external address indicates whether the IP should be translated or not (0 for no translation, 1 for translation). If the first bit is 0, the output should be the internal IP; if 1, the output should be the external IP.
