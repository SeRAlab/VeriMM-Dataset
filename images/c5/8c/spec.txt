

You are tasked with designing a Verilog module that implements a D flip-flop with an enable input and a clock enable input. The module should have the following ports:

- `clk`: the clock input
- `en`: the enable input
- `enclk`: the clock enable input
- `d`: the data input
- `q`: the output

The D flip-flop should be positive-edge triggered and should only update its output when the enable input is high. When the clock enable input is low, the flip-flop should be disabled and should not update its output. 

You should write a Verilog module that implements this D flip-flop with the given ports. Your module should be no longer than 200 lines of code.
