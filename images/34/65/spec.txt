Design a simple SD card interface signal decoder. The decoder takes a 4-bit input representing command signals from the SD card and produces a corresponding output signal indicating whether a read or write operation is requested. The command signals are as follows:  
0000 - No Operation  
0001 - Read Request  
0010 - Write Request  
0011 - Erase Request  
0100 - Initialize Request  
All other inputs should produce a 'No Operation' output.
