
Implement a CRC-8 (Cyclic Redundancy Check) module that takes an 8-bit data input and a 1-bit control signal to compute the CRC value. The module should use a polynomial of x^8 + x^7 + x^6 + x^4 + x^3 + 1 (represented by the hex value 0x31). The control signal will initiate the CRC calculation on the falling edge. The output should be the computed 8-bit CRC value.
