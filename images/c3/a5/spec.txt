

Create a Verilog module for a 4-to-1 multiplexer with inputs A, B, C, and D and a 2-bit select input S. The output of the module is the selected input based on the value of S. The module should have the following interface:

```
module mux4to1(
    input wire [3:0] A,
    input wire [3:0] B,
    input wire [3:0] C,
    input wire [3:0] D,
    input wire [1:0] S,
    output wire [3:0] Y
);
```

The module should use a case statement to select the appropriate input based on the value of S. If S is 2'b00, the output should be A. If S is 2'b01, the output should be B. If S is 2'b10, the output should be C. If S is 2'b11, the output should be D.

Assume that the inputs A, B, C, and D are valid at all times and that the select input S changes only on the positive edge of the clock.
