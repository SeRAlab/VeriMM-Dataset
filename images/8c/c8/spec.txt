Design a 16-bit shift register with parallel load capability. Upon the rising edge of the clock, if the reset signal is activated, the register is cleared, and both the internal data and the output are set to zero. If the reset is not active and the shift signal is asserted, the module shifts the contents of the register to the left, outputs the most significant bit (MSB) to `shift_out`, and shifts in a new bit from the `shift_in` input on the least significant bit (LSB).
module top_module(
  input clk,
  input reset,
  input shift_in,
  input shift,
  output reg shift_out
);
