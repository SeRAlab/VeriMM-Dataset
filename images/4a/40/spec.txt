    decoder_2to4

    enable: Signal to enable the decoder.

Output ports:
    data_out: 4-bit output representing the decoded value.

If enable is high, data_out is set according to the value of data_in, where data_in = 2'b00 sets data_out to 4'b0001, data_in = 2'b01 sets data_out to 4'b0010, data_in = 2'b10 sets data_out to 4'b0100, and data_in = 2'b11 sets data_out to 4'b1000.
