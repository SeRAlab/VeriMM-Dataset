
Create a fan speed control system that takes a 3-bit input representing a temperature level (0-7) and outputs a 2-bit fan speed level (00 to 11). The fan speed is determined as follows: 
- If temperature <= 2, fan speed = 00 (off)
- If 3 <= temperature <= 5, fan speed = 01 (low)
- If temperature >= 6, fan speed = 11 (high)
The system should have a clock and reset signal to allow for proper sequential behavior.
