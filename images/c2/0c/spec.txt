

Write a Verilog module for a 4-bit counter that counts up from 0 to 15 and then resets back to 0. The module should have a clock input and a reset input. The counter value should be output as a 4-bit binary number. 

You should use the following inputs and outputs:
- `input clk`: the clock input
- `input rst`: the reset input
- `output reg [3:0] count`: the 4-bit binary counter output

Assume that the input clock frequency is 10MHz.
