Design a control logic module that generates a single output signal Y based on multiple input conditions. The module evaluates several logical conditions involving inputs A1, A2, A3, B1, C1, and a control signal CTRL. When CTRL is low, Y will be high if all A inputs (A1, A2, A3) are true. When CTRL is high, Y will be high if A1, A2, and A3 are true along with specific combinations of B1 and C1, allowing for various configurations based on these inputs. This module effectively acts as a conditional AND gate with branching logic based on the control signal.
module top_module(
    input A1,
    input A2,
    input A3,
    input B1,
    input C1,
    input CTRL,
    output Y
);
