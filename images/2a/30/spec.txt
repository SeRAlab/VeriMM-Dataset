
Design a convolutional encoder that takes a 1-bit input and produces two 1-bit outputs. The encoder has a memory of 2 bits. The encoding process is defined by the following polynomial equations:
- Output bit 0: x0 XOR x1
- Output bit 1: x1 XOR x2
where x0, x1, and x2 are the current and previous state bits. The state is updated with every new input bit.
