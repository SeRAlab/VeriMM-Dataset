Design a 5-bit synchronous counter with an active-high reset. When the reset signal is asserted, the counter sets its output to zero. During each clock cycle, if reset is not active, the counter increments its value by one, producing a binary count from 0 to 31. The current state of the counter is available at the output q. The increment is accomplished through a custom function that handles the binary addition logic, ensuring correct carry propagation.
