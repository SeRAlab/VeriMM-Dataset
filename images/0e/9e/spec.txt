
Design a simple sliding window protocol in Verilog. The protocol should implement a sender and a receiver with a configurable window size. The sender should send packets and wait for an acknowledgment from the receiver before sending new packets. The receiver should acknowledge received packets and indicate if it is ready for the next packet. The design should handle a maximum of 4 packets in the window and should not exceed this limit. The system should have inputs for the packet data, the acknowledgment signal, and outputs for the sent packets and acknowledgments.
