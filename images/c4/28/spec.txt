
You are tasked with designing a memory module using Verilog. The module should be able to store and retrieve data, and should have the following inputs and outputs:

Inputs:
- `data` (64-bit): the data to be written to memory
- `rdaddress` (26-bit): the address to read from
- `rdclken` (1-bit): the clock enable for reading
- `wraddress` (26-bit): the address to write to
- `wrclock` (1-bit): the clock for writing
- `wren` (1-bit): write enable signal

Outputs:
- `q` (64-bit): the data read from memory

The memory should be implemented using an array of registers, with each register being 64 bits wide. The memory should be able to store up to 67,108,864 (2^26) 64-bit words.

Implement a Verilog module that meets the above requirements. Your module should be self-contained and no more than 200 lines of code.
