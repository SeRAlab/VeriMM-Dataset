Design a small digital band-pass filter that processes input signals based on the enable signal. When enabled, the filter computes two accumulator values using previous and current input samples, applying specific shifts defined by filter coefficients K0 and K1. The output is generated from these accumulators and can be clamped within predefined bounds to prevent overflow. During reset, all internal states are cleared to zero. If the filter is not enabled, the output will directly mirror the input signal.
module top_module(
    input clk,        // System clock
    input rst,        // Reset, active high and synchronous
    input en,         // Filter enable
    input signed [WIDTH-1:0] dataIn,  // [WIDTH-1:0] Filter input
    output signed [WIDTH-1:0] dataOut // [WIDTH-1:0] Filter output
);
