 Design a combinational logic circuit that implements a simplified version of the JPEG DCT (Discrete Cosine Transform) for 8x8 blocks of pixel values. The input will be an 8x8 block of pixel intensities, and the output will be the transformed DCT coefficients. The DCT can be simplified as follows: 
- Each output coefficient is obtained by summing the product of the input pixel values with a fixed set of cosine basis functions. 
- For simplicity, let's assume the following fixed coefficients for the DCT operation:
