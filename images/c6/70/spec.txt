

You are tasked with designing a module that takes in four input signals `a`, `b`, `c`, and `d`, and outputs a single signal `y`. The module should implement the following logic:

- If `a` is high, or if `b` is high and either `c` or `d` is high, then `y` should be high.
- If all inputs are low, then `y` should be low.

You must implement this logic using a single Verilog module that is no more than 200 lines long. Your module should be named `logic_module` and should have the following interface:

```
module logic_module (
    input a,
    input b,
    input c,
    input d,
    output y
);
```

Your module should adhere to the following requirements:

- The output `y` should be a single bit.
- The inputs `a`, `b`, `c`, and `d` should be single bits.
- Your module should use only combinational logic (i.e. no stateful elements like flip-flops or latches).
- Your module should be fully synthesizable.

Write a Verilog module that meets these requirements.
