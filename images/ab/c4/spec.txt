Design a 4-entry FIFO (First In, First Out) buffer management circuit with a reset and clock control mechanism. Upon reset, the FIFO pointers are initialized to zero. On each clock cycle, if a push or pop operation is detected, the module updates the FIFO head positions based on the next pointer values, facilitating data flow through the FIFO structure. This design allows for modular expansion, supporting multiple FIFO management operations in a synchronized manner.
module top_module(
input reset,
input clk,
input any_push,
input any_pop
);
