Create a module that computes two addresses based on a current address and a displacement value. The `disp_addr` output is conditionally calculated: if `disp` is greater than or equal to 128, it adds the displacement to `cur_addr` adjusted by a specific offset; otherwise, it simply adds the displacement plus one to `cur_addr`. The `one_addr` output is simply the current address incremented by one. This design could be useful for address calculation in a processor or memory management system where conditional addressing is required.
module top_module(
cur_addr,
disp,
disp_addr,
one_addr
);
