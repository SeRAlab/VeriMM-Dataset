Implement the Verilog module based on the following description.
We want to create a module that:

// (1) receives an 8-bit binary number,
// (2) determines if the number is a palindrome (same forward and backward),
// (3) sets the output 'is_palindrome' to 1 if the number is a palindrome, otherwise 0,
// (4) provides a reset mechanism to reset the output.

// The input binary number is available on the input signal 'binary_num'. The reset signal is active high synchronous.

module palindrome_check_module(
    input wire clk,
    input wire reset,
    input wire [7:0] binary_num,
    output reg is_palindrome
);
