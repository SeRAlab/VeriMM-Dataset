
Create a Verilog module for a simple GPIO controller that manages input and output pins. The controller should have the following features:
1. It should have an input register to read the state of GPIO pins.
2. It should have an output register to drive the state of GPIO pins.
3. A mode control signal should toggle between input and output modes.
4. When in input mode (mode = 0), the controller should read the input state into the input register.
5. When in output mode (mode = 1), the controller should drive the output state based on the output register.
The GPIO pins should be represented by an 8-bit vector.
