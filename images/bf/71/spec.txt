Design a 4-bit counter that increments or decrements its value based on control inputs. The counter is clock-driven and resets to zero when the reset signal is asserted. When the increment signal is active without the decrement signal, the counter increases its value until it reaches the maximum of 15, at which point it wraps back to 0. Conversely, when the decrement signal is active without the increment signal, the counter decreases its value, wrapping from 0 back to 15.
module top_module(
   input clk,
   input rst,
   input inc,
   input dec,
   output reg [3:0] cnt
);
