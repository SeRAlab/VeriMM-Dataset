Design a basic arithmetic calculator module that performs addition or subtraction based on the input operation control signal. The module takes two 4-bit inputs, `a` and `b`, and a single-bit operation selector `op`. Upon receiving a clock edge, if the reset signal is active, it initializes the result to zero. If not, it outputs the sum of `a` and `b` when `op` is 0, or the difference when `op` is 1, yielding a 4-bit wide result.
module top_module(
   // Inputs
   clk,
   reset,
   a,
   b,
   op,

   // Outputs
   result
   );
