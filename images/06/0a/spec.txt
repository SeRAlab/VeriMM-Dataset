Create a data forwarding unit for a 5-stage pipeline. The forwarding unit should detect when data hazards occur due to dependencies between instructions in the pipeline and forward the correct data to the input stage. The forwarding unit has two inputs: EX_MEM_reg and MEM_WB_reg, which represent the registers holding the values from the EX/MEM and MEM/WB pipeline registers, respectively. The inputs will also include the source and destination register identifiers. Your task is to implement the data forwarding logic that generates the appropriate signals to select the correct source of data for the next instruction's execution stage.
