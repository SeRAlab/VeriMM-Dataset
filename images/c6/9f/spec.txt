

You are tasked with designing a verilog module that takes in two inputs, `A` and `B`, and outputs the sum of the two inputs, `sum`. The inputs and output are all 8-bit unsigned integers. The module should be named `adder_8bit`.

Your module should include the following ports:
- `A`: an 8-bit unsigned integer input
- `B`: an 8-bit unsigned integer input
- `sum`: an 8-bit unsigned integer output

Your module should use the following verilog constructs:
- `always` block
- `assign` statement
- `reg` declaration

You should design your module in such a way that it can be synthesized and implemented on an FPGA.
