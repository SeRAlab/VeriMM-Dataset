Implement the Verilog module based on the following description.
Create a 4-bit up-counter with synchronous reset. The counter counts from 0 to 15 and then wraps around. When the reset signal is high, the counter resets to 0.

// Signals are defined as below:
// (1) reset: Resets the counter to 0. Active high.
// (2) clk: The clock signal.
// (3) q: The 4-bit output of the counter.
module counter(
    input clk,
    input reset,
    output reg [3:0] q);
