Design a 4-bit ripple carry adder module that adds two 4-bit binary numbers, A and B, along with a carry-in (CI) input. The module produces a 4-bit sum output (S) and a carry-out (CO) that represents any overflow beyond the 4-bit sum. It employs four full adder instances to perform the addition sequentially, propagating the carry from one stage to the next through the use of intermediate carry signals.
module top_module(
    input A,
    input B,
    input CI,
    output SUM,
    output COUT
);
