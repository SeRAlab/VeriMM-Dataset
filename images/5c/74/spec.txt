Implement the Verilog module based on the following description. Create a finite state machine that models a door lock system. The system has three states: Locked, Unlocked, and Waiting. It accepts two inputs: key (which unlocks the door) and timeout (which triggers a timeout if no action is taken). If the key is inserted (key=1) while the door is Locked, it transitions to Unlocked. If the door is Unlocked and the key is removed (key=0), it transitions to Waiting. If the door is in the Waiting state and the timeout occurs (timeout=1), it transitions back to Locked. Use an asynchronous reset to set the system to Locked state.
