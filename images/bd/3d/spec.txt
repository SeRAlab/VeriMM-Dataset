Design a 2-bit binary comparator that outputs a single bit signal, X. The output X indicates whether the first input A is equal to the second input B. Specifically, X will be high (1) when A is greater than B, determined by checking both the borrow from the subtraction of B from A and the least significant bit of the difference. If there is no borrow, and the least significant bit indicates A is greater, X is asserted.
module top_module(
    input [1:0] A,
    input [1:0] B,
    output X
);
