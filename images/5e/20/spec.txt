Design a 4-bit binary adder that computes the sum of two 4-bit inputs, A and B, along with a carry-in input (Cin). The module generates a 4-bit output (Sum) representing the summed value and a carry-out (Cout) output to indicate if there is an overflow from the addition. The design utilizes bitwise operations, including XOR for sum calculation and AND/OR operations to determine the carry-out, effectively implementing the full adder logic for each bit position.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input Cin,
  output [3:0] Sum,
  output Cout
);
