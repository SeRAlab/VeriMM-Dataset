

You have been tasked with designing a verilog module that takes in a clock signal, a latch edge signal, and outputs a new clock signal that is synchronized with the latch edge signal. The module should be named "clock_synchronizer".

The module should have the following ports:
- clk_in (input): the input clock signal
- latch_edge (input): the edge signal that the output clock should be synchronized with
- clk_out (output): the synchronized clock signal

The module should operate as follows:
- When the latch_edge signal is high, the output clock signal should be high on the next rising edge of the input clock signal.
- When the latch_edge signal is low, the output clock signal should be low on the next rising edge of the input clock signal.

Write the verilog code for the "clock_synchronizer" module.
