
Design a simple sliding window protocol for data transmission. Implement a finite state machine (FSM) that handles three states: IDLE, SEND, and WAIT. The FSM should accept an input signal that indicates whether data is ready to be sent. If data is ready, it should transition from IDLE to SEND and then to WAIT after sending the data. The FSM should return to IDLE after a certain acknowledgment signal is received. The output should indicate the current state of the FSM (IDLE, SEND, or WAIT).
