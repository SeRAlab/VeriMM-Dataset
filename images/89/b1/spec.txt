Design a 4-bit carry lookahead adder (CLA) that computes the carry outputs for each bit based on the propagate (P) and generate (G) signals, along with an input carry (Cin). The module outputs a 4-bit carry signal, where each carry output is determined using combinations of current and previous propagate and generate signals, allowing for faster carry computation compared to a ripple-carry adder. This design effectively minimizes propagation delay in multi-bit addition operations.
module top_module(
  input Cin,
  input [3:0] P, G,
  output [4:1] Carry
);
