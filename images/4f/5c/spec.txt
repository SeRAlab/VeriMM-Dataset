Design a 32-bit Arithmetic Logic Unit (ALU) capable of performing various operations based on a 4-bit operation code (ALUOp). The ALU can execute bitwise AND, OR, addition, subtraction, logical shifts (left and right), signed right shifts, bitwise XOR, negation of OR, and both signed and unsigned comparisons. The result of the selected operation is output as ALUOUT, driven by the values of inputs A and B along with the specified ALUOp.
module top_module(
    input [31:0] A,
    input [31:0] B,
    input [3:0] ALUOp,
    output reg [31:0] ALUOUT
    );
