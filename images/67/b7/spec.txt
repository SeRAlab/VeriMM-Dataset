Design a 4-to-1 multiplexer that outputs a signal based on two selection inputs (sw6_a1 and sw5_a0) from four data inputs (sw4_d4, sw3_d3, sw2_d2, and sw1_d1). The output (led8_out) will reflect the value of the selected data input: when the selection inputs point to sw1_d1, it is active if sw6_a1=0 and sw5_a0=0; for sw2_d2, it is selected if sw6_a1=0 and sw5_a0=1; for sw3_d3, it is active when sw6_a1=1 and sw5_a0=0; and for sw4_d4, it is chosen when both sw6_a1 and sw5_a0 are high.
module top_module(
    input sw6_a1,
    input sw5_a0,
    input sw4_d4,
    input sw3_d3,
    input sw2_d2,
    input sw1_d1,
    output led8_out
    );
