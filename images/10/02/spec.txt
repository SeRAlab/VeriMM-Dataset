Design a Verilog module for a simple WiFi state machine. The state machine has three states: IDLE, CONNECTING, and CONNECTED. The input signal `start` initiates the transition from IDLE to CONNECTING. The `connect` input transitions the state from CONNECTING to CONNECTED. The `disconnect` input returns the state to IDLE from CONNECTED and also from CONNECTING if pressed. The output should be a 2-bit binary representation of the current state.
