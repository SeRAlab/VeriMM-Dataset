Design a NAT (Network Address Translation) module that maps an internal IP address to an external IP address. The module should have the following functionality:
- It takes a 32-bit internal IP address and a 32-bit external IP address as inputs.
- It generates a 32-bit translated IP address as output based on the mapping.
- It has an enable signal that allows the translation process to occur.
- The translated address should remain stable until a new internal address is given.
