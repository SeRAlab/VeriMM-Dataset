

You are tasked with designing a module that takes in a 4-bit binary input and outputs a 3-bit binary number that represents the number of ones in the input. For example, if the input is 0101, the output should be 2 (001 in binary). You are not allowed to use any built-in functions or operators.

Your module should have the following interface:

Inputs:
- `in`: a 4-bit binary input
- `clk`: a clock signal
- `rst`: a reset signal

Outputs:
- `out`: a 3-bit binary output representing the number of ones in the input

You may use any additional signals or modules as necessary.

Write the Verilog code for your module.
