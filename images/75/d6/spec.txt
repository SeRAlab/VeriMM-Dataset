Design a pixel copying module that stores and manages pixel data during image processing. The module operates synchronously with a primary clock (`clk`) and a read clock (`rdclk`). It captures 8-bit pixel data from the `data` input in two halves and combines them into a 16-bit output (`wrdata`) when `acapture` is asserted. The module keeps track of the horizontal pixel count (`horiz_count`) during data processing and generates a `write` signal to indicate when the combined data is ready for output. Upon deactivation of `acapture`, it resets the internal state and horizontal count, facilitating a new capture session.
