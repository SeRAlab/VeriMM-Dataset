Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs: 
1. state K (output 1).
2. state L (output 0).
3. state M (output 1).

State transitions:
1. From state K: If u = 0, then transition to state L. If u = 1, then transition to state M.
2. From state L: If u = 0, then transition to state K. If u = 1, then transition to state M.
3. From state M: If u = 0, then transition to state L. If u = 1, then transition to state K.

Resets into state K. For this part, assume that a one-hot code is used with the state assignment c[3:1] = 001, 010, 100 for states K, L, M, respectively.

Write Verilog for the next-state signals C2 and C3 corresponding to signal c[2] and c[3]. Derive the logic equations by inspection assuming a one-hot encoding.
