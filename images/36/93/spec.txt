Design an OFDM symbol mapper that takes in a 4-bit binary input and maps it to a corresponding 16-QAM (Quadrature Amplitude Modulation) symbol. The mapping should be based on the following table:
- 0000 -> -3 - 3j
- 0001 -> -3 - 1j
- 0010 -> -3 + 1j
- 0011 -> -3 + 3j
- 0100 -> -1 - 3j
- 0101 -> -1 - 1j
- 0110 -> -1 + 1j
- 0111 -> -1 + 3j
- 1000 -> +1 - 3j
- 1001 -> +1 - 1j
- 1010 -> +1 + 1j
- 1011 -> +1 + 3j
- 1100 -> +3 - 3j
- 1101 -> +3 - 1j
- 1110 -> +3 + 1j
- 1111 -> +3 + 3j
The output should be a 2-bit real part and a 2-bit imaginary part represented in 2's complement form.
