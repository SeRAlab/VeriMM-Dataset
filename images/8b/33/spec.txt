Implement a Verilog module that counts the number of high bits in an 8-bit input. The module should have the following specifications:
- `clk`: The clock signal.
- `reset`: An active-high synchronous reset signal.
- `start`: An active-high signal that starts the counting.
- `data_in`: The 8-bit input data.
- `high_bit_count`: The output which holds the number of high bits in the input data.
- `done`: An active-high signal indicating the completion of the counting.
