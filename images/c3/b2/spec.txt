
You are tasked with designing a Verilog module for a 2-to-1 multiplexer (MUX) with a control signal. The module should have three inputs: A0, A1, and S, and one output, X. The control signal S will determine which input is selected and passed to the output. If S is 0, then input A0 should be passed to the output X. If S is 1, then input A1 should be passed to the output X. Your module should be named "mux_2to1".

You should write a Verilog module with the above specifications and ensure that it can be simulated correctly.
