 
Design a 5-input logistic regression unit that takes 5 binary inputs and produces a binary output. The logistic function is defined as follows:
\[ 
output = \text{sigmoid}(W \cdot X + b) 
\]
For simplicity, use fixed weights W = [1, 2, 3, 4, 5] and bias b = -10. The output should be a binary value: 1 if the result of the sigmoid function is greater than or equal to 0.5, otherwise 0.
