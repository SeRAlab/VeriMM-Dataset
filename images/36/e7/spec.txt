
Design an 8-bit Digital-to-Analog Converter (DAC) in Verilog. The DAC takes an 8-bit input value and outputs a corresponding analog voltage level based on a reference voltage of 5V. The output voltage can be calculated as:
V_out = (input_value / 255) * V_ref
where input_value is the 8-bit input and V_ref is 5V. Implement the DAC such that it produces the correct analog voltage level for the provided 8-bit input values.
