Implement a Verilog module that performs an 8-bit addition with carry-in and carry-out. The module should have the following specifications:
- `clk`: The clock signal.
- `reset`: An active-high synchronous reset signal.
- `start`: An active-high signal that starts the addition.
- `data1`: The first 8-bit input data.
- `data2`: The second 8-bit input data.
- `carry_in`: The carry-in input.
- `sum`: The output which holds the sum of the inputs.
- `carry_out`: The output which holds the carry-out.
- `done`: An active-high signal indicating the completion of the addition.
