

You are tasked with designing a verilog module that implements a 4-input NAND gate. The module should be named `nand4` and should have the following input and output ports:

- `input a`
- `input b`
- `input c`
- `input d`
- `output y`

The module should implement the following logic:

```
y = ~(a & b & c & d)
```

Your implementation should be contained within a single module of no more than 200 lines of verilog code.
