Design a simple Virtual Memory Management Unit (VMU) that maps 4-bit virtual addresses to 4-bit physical addresses. The VMU should have an input for a 4-bit virtual address and a clock signal to trigger the mapping process. The output should be a 4-bit physical address based on a predefined mapping rule. For simplicity, the mapping will be direct; e.g., virtual address 0000 maps to physical address 0000, virtual address 0001 maps to physical address 0001, and so on. The VMU should reset and output a known state when the reset signal is activated.
