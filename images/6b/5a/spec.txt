Implement a 16-bit register with synchronous reset and load. The module should load a 16-bit input when load is asserted and reset the register synchronously when reset is asserted.

Module name:
    register_16bit
Input ports:
    clk: clock input
    reset: synchronous reset input
    load: load input
    data_in: 16-bit input
Output ports:
    q: 16-bit output

Implementation:
The module uses an always block that triggers on the clock's positive edge. It loads the data input when load is asserted and resets the register when reset is asserted.
