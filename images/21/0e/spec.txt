Design a fan speed control system that takes an input temperature and adjusts the fan speed accordingly. The system should have three levels of fan speed: low, medium, and high. The fan speed should change based on the temperature input: if the temperature is below 20 degrees Celsius, the fan should run at low speed; if the temperature is between 20 and 30 degrees Celsius, the fan should run at medium speed; and if the temperature is above 30 degrees Celsius, the fan should run at high speed. The system should also include a debounce mechanism to prevent rapid changes in fan speed due to noise in the temperature signal.
