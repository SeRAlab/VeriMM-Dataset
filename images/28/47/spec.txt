
Create a LIFO stack module in Verilog that supports the following operations:
1. Push: Add a data element to the top of the stack.
2. Pop: Remove the top element from the stack and return it.
3. Peek: Return the top element without removing it.
4. isEmpty: Indicate if the stack is empty.
The stack should have a fixed size of 8 elements, and it should handle overflow and underflow conditions appropriately.
