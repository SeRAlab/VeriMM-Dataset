
Design a reset controller that manages a synchronous reset signal for a simple digital system. The reset controller should have an active-high synchronous reset input signal `reset_n`, a clock input `clk`, and an output `reset_out`. The output `reset_out` should be asserted (high) when the `reset_n` signal is low, but it should only remain asserted for one clock cycle after the `reset_n` signal goes low. After the reset operation, the `reset_out` should revert to low on the next clock edge.
