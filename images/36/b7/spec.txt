Implement a finite state machine (FSM) that performs a Breadth-First Search (BFS) traversal on a binary tree. The FSM should have input signals for the current node and output signals for the next node to visit. The input will be a 4-bit binary representation of the current node, and the output will be a 4-bit binary representation of the next node in the BFS order. The FSM should handle five nodes with values from 0 to 4.
