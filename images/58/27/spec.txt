Design a circuit that extracts bits from a 32-bit input based on a specified mask, generating a variable-width output. The output consists of bits from the input where the corresponding mask bits are set to 1. The mask parameter, initialized to all 1's, determines which bits of the input are included in the output, while unused bits (where the mask is 0) are not transferred but are monitored for any non-zero value. This module effectively functions as a bit extractor or selective filter, generating a packed output of significant bits from the input data.
