Design a 4-to-1 multiplexer. The module takes four input signals (A, B, C, D) and two selector lines (S[1:0]). Based on the value of the selector inputs, it outputs one of the four input signals (Y). When S is 00, output A; when S is 01, output B; when S is 10, output C; and when S is 11, output D.
module top_module(
  input A,
  input B,
  input C,
  input D,
  input [1:0] S,
  output Y
);
