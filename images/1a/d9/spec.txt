
Design a power gating circuit in Verilog that takes a 2-bit control signal `ctrl` and a 5-bit data input `data_in`. When `ctrl` is `00`, the output `data_out` should be `data_in` (active mode). When `ctrl` is `01`, the output `data_out` should be `data_in` (active mode). When `ctrl` is `10`, the output `data_out` should be 5'b00000 (sleep mode). When `ctrl` is `11`, the output `data_out` should also be 5'b00000 (sleep mode).
