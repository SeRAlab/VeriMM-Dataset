Design a linear voltage regulator with the following specifications:
- The input voltage (Vin) can range from 0 to 5V.
- The output voltage (Vout) should be regulated to 3.3V if Vin is greater than or equal to 3.3V.
- If Vin is less than 3.3V, Vout should equal Vin.
- The output voltage should be represented as a 4-bit binary number ranging from 0V to 5V in increments of 0.3125V (i.e., 0V = 0000, 0.3125V = 0001, ..., 5V = 1111).
