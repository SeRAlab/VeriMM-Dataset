Create an ARQ (Automatic Repeat reQuest) error correction system that acknowledges received data packets and requests retransmission if an error is detected. The system should consist of a sender and receiver, where the sender transmits packets and the receiver checks for errors using a simple parity check. If an error is detected, the receiver sends a negative acknowledgment (NACK) to the sender, which will then resend the packet. If no error is detected, the receiver sends an acknowledgment (ACK). The sender should be able to keep track of the number of transmission attempts.
