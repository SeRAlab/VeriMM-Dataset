

In digital electronics, a multiplexer is a device that selects one of several input signals and forwards the selected input signal to a single output line. The selection of input signal is controlled by a set of control signals. In this problem, you are to implement a 2-to-1 multiplexer using Verilog.

Write a Verilog module named "mux_2to1" that takes two input signals, "in0" and "in1", and a control signal "ctrl". The module should have one output signal "out". When the control signal "ctrl" is 0, the output signal "out" should be equal to the input signal "in0". When the control signal "ctrl" is 1, the output signal "out" should be equal to the input signal "in1".

Your implementation should be within 200 lines of Verilog code and should not use any other Verilog modules. You may use basic Verilog operators such as "if-else", "assign", and "wire". You may also use Verilog primitives such as "and", "or", and "not".
