Design a 4-bit SRAM cell that can store a 4-bit value and allows read and write operations based on control signals. The SRAM cell should have inputs for data (4 bits), a read enable signal (read_en), a write enable signal (write_en), and an output for the stored data (4 bits). The behavior should be as follows: when write_en is high, the data is written to the SRAM cell; when read_en is high, the stored data is outputted. If both control signals are high, prioritize read operation over write.
