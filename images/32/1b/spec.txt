Design a D-latch in Verilog. The D-latch should take a data input 'D', a clock input 'CLK', and an enable input 'EN'. When 'CLK' is high and 'EN' is high, the output 'Q' should follow the input 'D'. When 'CLK' is low, 'Q' should hold its value regardless of 'D'. When 'EN' is low, 'Q' should retain its previous state regardless of 'D' or 'CLK'.
