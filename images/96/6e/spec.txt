Implement the Verilog module based on the following description.
Create a module that implements a 32-bit arithmetic logic unit (ALU) that can perform addition, subtraction, and bitwise AND operations based on a 2-bit control signal. module alu(
	input clk,
	input reset,
	input [31:0] operand1,
	input [31:0] operand2,
	input [1:0] control,
	output reg [31:0] result);
