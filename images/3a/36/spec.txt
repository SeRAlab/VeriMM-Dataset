Design a Verilog module for a simple RNN unit that takes 3 inputs (x, h_prev, and w) and produces an output h. The output h is computed as h = tanh(w * x + h_prev). For simplicity, assume that x, h_prev, and w are all 8-bit values. You need to implement the logic in Verilog, ensuring that the computation is done in a sequential manner, updating the state h with each clock cycle.
