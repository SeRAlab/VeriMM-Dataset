Design a 4-bit binary counter that increments its value on each rising edge of the clock signal when the enable input is high. The counter can be reset to zero asynchronously when the reset input is activated. This module is suitable for applications requiring count progression controlled by a clock, with the ability to reset to an initial state.
module top_module(
  input clk, // clock input
  input reset, // reset input
  input enable, // enable input
  output reg [3:0] count // binary count output
);
