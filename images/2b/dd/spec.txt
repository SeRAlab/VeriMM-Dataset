
Design a Parallel-in Serial-out (PISO) shift register that accepts 5 bits of parallel data and outputs the bits serially on a clock edge. The register should have a load signal to load the data, a clock signal to shift the data out, and a serial output signal. The serial output should shift out the data one bit per clock cycle after the data has been loaded. Include a control logic to reset the shift register and keep track of the number of bits shifted out.
