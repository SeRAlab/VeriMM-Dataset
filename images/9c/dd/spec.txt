Design a signed 8-bit calculator that performs addition on two signed inputs, `a` and `b`. The module continuously computes the sum of `a` and `b`, and detects overflow conditions based on the sign bits of the inputs and the result. An overflow occurs if both inputs have the same sign but the sign of the result is different. The calculated result is stored in the output `result`, while the overflow status is indicated by the output `overflow`.
module top_module(
  input signed [7:0] a,
  input signed [7:0] b,
  output reg signed [7:0] result,
  output reg overflow
);
