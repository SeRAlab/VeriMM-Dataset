Implement the Verilog module based on the following description.
Create a 4-bit binary counter with a terminal count output. The counter increments by 1 on each clock cycle and resets to zero when the reset signal is high. The terminal count output goes high when the counter reaches its maximum value (15).

// Signals are defined as below:
// (1) clk: The clock signal.
// (2) reset: Resets the counter to zero. Active high.
// (3) tc: Terminal count output. Goes high when the counter reaches 15.
// (4) q: The 4-bit output of the counter.
module binary_counter_tc(
    input clk,
    input reset,
    output reg tc,
    output reg [3:0] q);
