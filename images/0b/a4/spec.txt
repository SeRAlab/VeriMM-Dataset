A Master-Slave D-Latch is a type of flip-flop that captures the value of the D input on the rising edge of the clock signal and holds that value until the next rising edge. Implement a Master-Slave D-Latch in Verilog that works appropriately with a clock input and a data input (D). The output should reflect the value of D when the clock transitions from low to high, and remain constant until the next clock transition.
