Design a 2-channel DMA controller that can transfer data from a source address to a destination address for two different channels. The controller should have the following inputs: clk, reset, start, channel_select, src_addr, dest_addr, and data. The controller should output a busy signal indicating if a transfer is in progress and a done signal indicating that the transfer is complete. The controller should be able to handle channel selection for both channels and transfer data sequentially.
