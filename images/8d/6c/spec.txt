Design a 32-bit calculator that performs basic arithmetic operations: addition, subtraction, multiplication, and division. It takes two 32-bit inputs, `a` and `b`, and a 2-bit mode selection signal. Based on the mode, it outputs the result of the selected operation on `a` and `b`: when mode is `00`, it outputs the sum; `01` for the difference; `10` for the product; and `11` for the quotient. If the corresponding mode is not selected, the respective output remains zero.
module top_module(
  input [31:0] a,
  input [31:0] b,
  input [1:0] mode,
  output [31:0] add_out,
  output [31:0] sub_out,
  output [31:0] mul_out,
  output [31:0] div_out
);
