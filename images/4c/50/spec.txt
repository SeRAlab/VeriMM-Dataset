Design a 32-bit wide multiplexer with dual input selection based on a control signal. When md_signal is HIGH, the final output will depend on the md_control value: specifically, if md_control is "110", output res_hi; otherwise, output res_lo. If md_signal is LOW, directly output WriteData. This module enables conditional selection from two different sources (res_hi, res_lo) or a direct write value (WriteData) based on the specified control signals.
