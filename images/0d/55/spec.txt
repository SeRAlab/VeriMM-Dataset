Design a data forwarding unit for a 5-stage pipelined processor. The forwarding unit should detect data hazards and forward data from one pipeline stage to another without stalling the pipeline. The unit should check if the current instruction depends on the result of a previous instruction that has not yet been written back to the register file. Implement the necessary logic to forward data from the execution (EX) stage to the decode (ID) stage or from the memory (MEM) stage to the execute (EX) stage.
