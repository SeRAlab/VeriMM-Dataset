Design a 4-bit binary adder that sums two 4-bit inputs, `a` and `b`, along with a carry-in input `cin`. The module outputs a 4-bit sum as well as a carry-out signal `cout`. Each bit of the input is processed using a full adder circuit, which is implemented via two XOR gates for the sum calculation and a combination of AND and OR gates to handle the carry logic for each corresponding bit position. This design enables the addition of two 4-bit numbers while correctly managing potential overflow into a fifth bit.
module top_module(
  input [3:0] a,
  input [3:0] b,
  input cin,
  output [3:0] sum,
  output cout
);
