Design a module that changes the sign of a 32-bit input data signal. Upon receiving a clock pulse, if the input is negative (indicated by the most significant bit), the module outputs the negated value while setting a sign indicator output to 1. If the input is non-negative, it passes the input directly to the output and sets the sign indicator to 0. The module also incorporates an asynchronous reset that initializes the outputs to zero when activated.
