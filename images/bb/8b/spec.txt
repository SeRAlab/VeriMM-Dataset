Implement a basic arithmetic calculator that performs addition, subtraction, multiplication, and division on two signed 16-bit inputs, `a` and `b`. The operation to be executed is determined by a 2-bit select signal, `op`, where `00` corresponds to addition, `01` to subtraction, `10` to multiplication, and `11` to division. The result of the selected operation is output as a signed 16-bit value.
module top_module(
  input signed [15:0] a,
  input signed [15:0] b,
  input [1:0] op,
  output reg signed [15:0] result
);
