Design a 16-bit SRAM cell that supports read and write operations. The cell should have the following inputs: 16-bit data input (data_in), a control signal (we) for write enable (1 for write, 0 for read), and a 4-bit address input (addr). The output should be a 16-bit data output (data_out) which represents the data read from the specified address. The SRAM should be able to store up to 16 locations of 16-bit data.
