

You are tasked with designing a module that implements a 4-input AND gate. The module should be named `and4` and should have the following inputs and outputs:

- `in1`, `in2`, `in3`, `in4`: 4 input bits
- `out`: 1 output bit

The module should be defined in the following way:

```
module and4(
    input in1,
    input in2,
    input in3,
    input in4,
    output out
);
// your code here
endmodule
```

You should ensure that your module only uses basic logic gates such as AND, OR, NOT, and XOR gates. You should not use any other modules or pre-defined functions.
