Design a 4-to-1 multiplexer that takes four input signals (A0, A1, A2, A3) and selects one of them to output (X) based on the values of two select lines (S0 and S1). The selected input is determined by the binary combination formed by S0 and S1, where each combination corresponds to one of the four input signals.
module top_module(
    output X,
    input  A0,
    input  A1,
    input  A2,
    input  A3,
    input  S0,
    input  S1
);
