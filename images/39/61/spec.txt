Design a 16-bit ADC module that converts a 16-bit binary input to a voltage output. The voltage output should be represented as a 16-bit binary number, assuming a reference voltage of 5V. The output should be calculated as follows: Voltage = (Input / 65535) * 5V. The output should be rounded to the nearest integer value. The module should have a 16-bit input and a 16-bit output.
