Design a module that acts as a one-second pulse generator. The module uses a clock input to count cycles until it reaches a predefined limit corresponding to one second (26,999,999 clock cycles). When the count reaches this limit, it sets the enable_output high, enabling an output signal for one clock cycle. Additionally, if a reset signal is received, the count resets to zero, preparing the module to start counting from the beginning again.
