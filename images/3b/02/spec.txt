
Design a Bluetooth connection management module in Verilog. The module should maintain a state machine that transitions between different states: IDLE, SCANNING, CONNECTING, and CONNECTED. The state transitions should occur based on the following conditions:
- From IDLE to SCANNING on input start_scan.
- From SCANNING to CONNECTING on input connect.
- From CONNECTING to CONNECTED on input confirm_connection.
- From CONNECTED to IDLE on input disconnect.

Include a reset signal that resets the state machine to IDLE.
