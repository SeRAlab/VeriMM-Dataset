Design a Verilog module that evaluates a polynomial of the form P(x) = a_n*x^n + a_(n-1)*x^(n-1) + ... + a_1*x + a_0 for given coefficients a_n, a_(n-1), ..., a_1, a_0 and an input x. The module should be able to evaluate the polynomial for a 4th degree polynomial where n = 4, taking coefficients and x as inputs and producing the polynomial result as output.
