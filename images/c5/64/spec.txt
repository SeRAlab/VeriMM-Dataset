

You are tasked with designing a module that takes in 9 inputs and produces 1 output. The module should be named `multi_input_module` and should have the following input and output ports:

- `input a, b, c, d, e, f, g, h, i`
- `output out`

The module should perform the following operations:

1. If `a` and `b` are both high (`1`), set `out` to `1`. Otherwise, set `out` to `0`.
2. If `c` or `d` are high (`1`), set `out` to `1`. Otherwise, leave `out` as is.
3. If `e` and `f` are both low (`0`), set `out` to `0`. Otherwise, leave `out` as is.
4. If `g` is high (`1`), set `out` to `1`. Otherwise, leave `out` as is.
5. If `h` is low (`0`), set `out` to `0`. Otherwise, leave `out` as is.
6. If `i` is high (`1`), set `out` to `1`. Otherwise, leave `out` as is.

Design and implement the `multi_input_module` module using Verilog.
