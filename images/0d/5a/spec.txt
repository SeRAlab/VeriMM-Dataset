Design a 32-bit Linear Feedback Shift Register (LFSR) using Verilog. The LFSR should generate pseudo-random sequences based on a specified feedback polynomial. It should include a clock input, a reset input, and provide a 32-bit output representing the current state of the LFSR. The feedback polynomial can be defined as x^32 + x^22 + x^21 + x^20 + x^17 + x^15 + x^14 + x^13 + x^11 + x^10 + x^7 + x^6 + x^5 + x^4 + x^3 + 1.
