Design a sequential circuit that selects the index of the maximum value among three 5-bit inputs (a, b, and c) on each rising edge of the clock. The output is a 2-bit wide signal (out) that indicates which input holds the maximum value: '00' for input a, '01' for input b, '10' for input c, and '11' for an undefined case when two or more inputs are equal.
module top_module(
  input clk,
  input [4:0] a,
  input [4:0] b,
  input [4:0] c,
  output reg [1:0] out
);
