Design a circuit that generates the output sign bit based on the XOR of two input sign bits, in_sign_a and in_sign_b. The module synchronously captures in_sign_a and in_sign_b on the rising edge of the clock. If a reset signal (rst) is active, the output and internal state are set to LOW; otherwise, the output is updated to reflect the XOR of the two most recently captured sign bits. The final output, out_sign, reflects the computed sign state of the input signals.
module top_module(
    input clk,
    input rst,
    input in_sign_a,
    input in_sign_b,
    output out_sign
);
