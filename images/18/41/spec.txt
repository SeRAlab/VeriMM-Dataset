Design an 8-bit DRAM cell that can store a single bit of data. The DRAM cell has input signals for data (d), word line (wl), and bit line (bl). The cell should be able to read and write data based on the word line signal. When the word line is high, data can be written into the cell; when the word line is low, data can be read from the cell. Implement the appropriate logic to handle these operations.
