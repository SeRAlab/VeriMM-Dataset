Design a four-bit adder that computes the sum of two 4-bit inputs, A and B, along with a carry-in input (Cin). The circuit produces a 4-bit sum output (S) and a carry-out output (Cout). It includes overflow detection to handle cases where the resulting sum exceeds the 4-bit limit. If an overflow is detected, the output S is adjusted to represent only the lower three bits of the sum; otherwise, it presents the full 4-bit sum. The Cout output signals whether there was a carry out from the addition.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    output [3:0] S,
    output Cout
);
