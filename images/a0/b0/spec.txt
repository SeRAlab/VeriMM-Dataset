Design a Verilog module that models a 1-bit D flip-flop with an asynchronous reset signal. The module should have an input clock signal (clk), an input reset signal (rst), an input data signal (d), and a 1-bit output signal (q). If reset is high, q should be set to 0. Otherwise, on the rising edge of the clock, q should be set to the value of d.
module d_flipflop (
  input clk,
  input rst,
  input d,
  output reg q);
