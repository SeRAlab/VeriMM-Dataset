

You are tasked with designing a module that implements a 4-bit adder using Verilog. The module should have two 4-bit inputs (A and B) and one 4-bit output (C). The adder should perform unsigned addition, meaning that if the sum of A and B exceeds 15, the output should wrap around to 0. You should implement this using only one module and within 200 lines of Verilog code.

To help you get started, you are given the following code snippet:

```
module four_bit_adder(
    input [3:0] A,
    input [3:0] B,
    output reg [3:0] C
);

// Your code here

endmodule
```

You should complete the module by adding the necessary Verilog code to implement the 4-bit adder. You can assume that the inputs A and B are valid 4-bit unsigned integers.
