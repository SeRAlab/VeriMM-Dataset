Design a simple state machine that models a robot's state in a SLAM context. The robot can be in one of three states: 'Idle', 'Mapping', or 'Localizing'. The state transitions occur based on the input signals 'start_map' and 'start_localize'. The state machine should start in the 'Idle' state, transition to 'Mapping' when 'start_map' is asserted, and transition to 'Localizing' when 'start_localize' is asserted. It should return to 'Idle' when both signals are deasserted.
