Design a clock gating circuit that generates an output clock enable signal, ENCLK. The output is set to HIGH (1) on the positive edge of the input clock (CLK) only when both the enable (EN) and test enable (TE) signals are HIGH; otherwise, ENCLK is set to LOW (0). This functionality is often used to reduce power consumption in digital circuits by disabling the clock to certain parts of the circuit when not needed.
module top_module(
    input CLK,
    input EN,
    input TE,
    output reg ENCLK
);
