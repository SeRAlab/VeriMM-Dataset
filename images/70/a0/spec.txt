Design a GPIO (General Purpose Input/Output) controller with memory-mapped registers. The module supports asynchronous reset and operates on clock cycles, allowing data read and write operations to various control registers based on the input address. It manages the direction of data flow through a Data Direction Register (DDR) and produces output based on four configurable states driven by input signals for transmission (tx) and reception (rx). The module acknowledges transactions and handles data input/output through a 32-bit GPIO bus, enabling flexible interaction with external devices.
