Design a 4-to-1 multiplexer that selects one of four 4-bit input data lines (D0, D1, D2, D3) based on the states of two select lines (S0 and S1). The output (Y) will be the 4-bit value of the selected input line, determined by the combination of the select signals. When S1 and S0 are both LOW, D0 is selected; when S0 is HIGH and S1 is LOW, D1 is selected; when S1 is HIGH and S0 is LOW, D2 is selected; and when both S0 and S1 are HIGH, D3 is selected.
module top_module(
  input [3:0] D0,
  input [3:0] D1,
  input [3:0] D2,
  input [3:0] D3,
  input S0,
  input S1,
  output [3:0] Y
);
