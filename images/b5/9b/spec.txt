Design a signed 8-bit calculator that performs basic arithmetic operations—addition, subtraction, multiplication, and division—on two signed 8-bit inputs, A and B. The operation to be performed is selected through a 2-bit input, Op: 00 for addition, 01 for subtraction, 10 for multiplication, and 11 for division, with the result output as a signed 8-bit value C.
module top_module(
    input signed [7:0] A,
    input signed [7:0] B,
    input [1:0] Op,
    output reg signed [7:0] C
);
