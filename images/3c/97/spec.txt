
Design a Verilog module that implements a simple RRT (Rapidly-exploring Random Tree) algorithm for motion planning within a 2D space. The module will take in current coordinates (x, y) and a target coordinate (target_x, target_y). The output will be the next step coordinates (next_x, next_y) towards the target, moving a fixed distance (step_size) in the direction of the target. Additionally, the module should include a state signal to indicate whether it is currently moving towards the target or has reached it.
