Implement a 4-bit synchronous up/down counter with enable and reset signals.

Module name:  
    up_down_counter 

Input ports:
    clk: Clock signal used for synchronous operation.
    rst: The reset signal to initialize or reset the module.
    enable: 1-bit signal to enable the counter.
    up_down: 1-bit signal to control the count direction (1 for up, 0 for down).
Output ports:
    count: 4-bit output signal representing the current counter value.
