Design a 5-bit wide D flip-flop with additional reset and preset functionality. On the rising edge of the clock, if the reset (rstn) signal is low, the output (q) is set to all zeros and the inverted output (qn) to all ones. If the preset (prsn) signal is low, the output (q) is set to all ones and the inverted output (qn) to all zeros. Otherwise, the flip-flop captures the input data (d) and outputs it on (q), while (qn) outputs the bitwise negation of (d).
