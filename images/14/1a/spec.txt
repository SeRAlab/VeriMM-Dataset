Design a 24-bit ADC (Analog to Digital Converter) output processor that takes a 24-bit input and outputs a 12-bit value. The output should be calculated by taking the highest 12 bits of the input. For example, if the input is `101010101010101010101010`, the output should be `101010101010`. The output should be valid when the input is stable and should result in a valid output on the next clock cycle.
