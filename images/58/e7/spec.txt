Design a clock selection circuit that outputs one of two clock signals based on the state of an adjust input. When the adjust input is low, it selects the primary clock signal (clk); when the adjust input is high, it switches to the alternative clock signal (adj_clk). The output is a single clock signal for system use.
module top_module(
	input clk, adj_clk,
	input wire adjust,
	output clock
    );
