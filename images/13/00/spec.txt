Design a UART transmitter that takes an 8-bit data input and transmits it serially at a baud rate controlled by a clock input. The transmitter should have the following inputs: `data_in` (8 bits), `start` (1 bit), and `baud_rate` (clock input). The output should be `tx` (1 bit) which will transmit the data bit by bit. The transmission should be initiated when `start` is asserted, and it should send a start bit followed by the 8 data bits and a stop bit. The module should also include a mechanism to indicate when transmission is complete.
