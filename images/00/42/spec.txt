
Design a Parallel-in Serial-out (PISO) shift register in Verilog. The PISO should have the following specifications:
- It should have an input width of 5 bits.
- It should have a clock input, a load input, and a serial output.
- When the load signal is high, the 5-bit parallel data should be loaded into the shift register.
- On each clock pulse, the register should shift out one bit to the serial output, starting from the most significant bit (MSB).
- The chip should have a reset signal to clear the register.
