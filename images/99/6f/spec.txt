This module generates a formatted message based on a 16-bit Binary-Coded Decimal (BCD) input and an accompanying sign indicator. It takes a 16-bit BCD input, converts each 4-bit segment into an ASCII character corresponding to its decimal value by adding 48, and then constructs a 48-bit output message. The message begins with an ASCII representation of either a negative or positive sign, indicated by the 'signo' input (0 for negative, 1 for positive), followed by the ASCII values of the BCD digits and a termination character specified by the 'caracter_terminacion' input. The design serves as an encoding mechanism for displaying numerical messages in a human-readable format.
