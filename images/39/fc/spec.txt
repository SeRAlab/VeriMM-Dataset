
Design a Verilog module that implements a Cryptographically Secure Pseudo-Random Number Generator (CSPRNG) using a Linear Feedback Shift Register (LFSR) method. The output should be a 8-bit random number generated from a 4-bit seed input. The generator should have a clock input and a reset input, where the reset initializes the seed to a specific value. The output should provide a new random number on every rising edge of the clock.
