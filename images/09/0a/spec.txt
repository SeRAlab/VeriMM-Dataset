Design a 3-bit support vector machine (SVM) classifier that takes three inputs representing features of a data point and outputs a binary classification (0 or 1). The decision boundary is defined by a simple linear equation: \( w_0 \cdot x_0 + w_1 \cdot x_1 + w_2 \cdot x_2 + b > 0 \). For this problem, let \( w_0 = 1, w_1 = -1, w_2 = 1, b = 0 \). The inputs should be 3 bits each and the output should be 1 bit.
