Implement the Verilog module based on the following description.
A binary counter that counts from 0 to 15 and wraps around. The counter should have an enable signal that allows the counter to increment when asserted. It also has a reset signal that resets the counter to 0 when asserted.

Variables:

2. enable (input)
3. reset (input)
4. count (output, 4-bit)

module binary_counter (
    input clk,
    input enable,
    input reset,
    output reg [3:0] count);
