    counter_3bit

	clk: Clock signal used for synchronous operation.
	rst: Active-high synchronous reset signal.
	load: Load signal for parallel data input.
	enable: Count enable signal.
	parallel_data: 3-bit parallel data input.

Output ports:
    count: 3-bit output representing the counter value.

Implementation:
Counter Logic:
The always block triggers on the positive edge of the clock signal (posedge clk).
If the reset signal (rst) is active, the counter value is set to 0.
If the load signal (load) is active, the parallel data (parallel_data) is loaded into the counter.
If the enable signal (enable) is active, the counter increments its value by 1.
