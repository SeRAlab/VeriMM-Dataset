Design a five-bit wide sequential logic module that processes an input signal based on certain conditions upon receiving a clock edge. When a reset signal is activated, the output is set to zero. If the input signal is zero, the output remains zero. For non-zero inputs, if the input signal is even, the output is incremented by one; if the input is odd, the output is decremented by one. This design essentially provides modified output behavior based on the parity of the input, serving as a simple signal processing unit.
module top_module(
    input clk,
    input reset,
    input [4:0] input_signal,
    output reg [4:0] output_signal
);
