
Design a fan speed control system that adjusts the speed based on three input levels: low, medium, and high. The system should have a state machine that changes its state based on the input signals. The fan speed outputs should be represented as a 2-bit value: 
- 00 for OFF
- 01 for LOW 
- 10 for MEDIUM 
- 11 for HIGH 

The state transition should be as follows: 
- If the input changes to LOW, the state should change to LOW speed.
- If the input changes to MEDIUM, the state should change to MEDIUM speed.
- If the input changes to HIGH, the state should change to HIGH speed.
- The system should remain in the current state if no change is detected.
