Design a synchronous RAM module with read and write capabilities. This 32x8-bit memory allows data to be written to a specified address when the write enable signal is active. On the rising edge of the clock, the module updates its internal memory with the provided write data at the specified write address. Additionally, on each clock cycle, it reads data from a designated address (updated on the clock edge) and outputs the read data. The design features a registered read address to ensure that the read operation occurs consistently with the clock.
