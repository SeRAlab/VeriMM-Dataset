Design a synchronous set-reset flip-flop (SR flip-flop) that incorporates enable, clear, and preset functionalities. The module has inputs for set (s), reset (r), clock (clk), enable (ena), clear (clr), and preset (pre) signals, and produces a single output (q). When clear is asserted, the output is reset to LOW. When preset is asserted, the output is set to HIGH. On the rising edge of the clock, if enable is active and both set and reset are asserted, the output toggles; if only set (s) is asserted, the output is set to HIGH, and if only reset (r) is asserted, it is set to LOW. The module effectively allows for versatile control of the flip-flop's state based on the various input conditions.
