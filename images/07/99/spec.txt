Implement a simple virtual memory management unit (MMU) that translates a virtual address to a physical address. The MMU should take a 12-bit virtual address as input and output a 12-bit physical address. The mapping is defined by a simple table stored in a register. For this problem, we can assume a direct mapping where the first 4 bits of the virtual address are used to select an entry in a mapping table, which specifies the corresponding physical address. The MMU will output the physical address on the rising edge of a clock signal. An enable signal should control whether the MMU is active or not.
