Design a clock multiplexer that selectively outputs one of two input clock signals based on the value of the `sel` input. When `sel` is low (0), the output `clkout` follows the `clka` signal; when `sel` is high (1), the output follows the `clkb` signal. In the case of an unexpected value, `clkout` defaults to `clka`.
module top_module( input      sel,
                  input      clka,
                  input      clkb,
                  output reg clkout
                );
