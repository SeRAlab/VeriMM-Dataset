

You are tasked with designing a Verilog module that takes in a 4-bit input and a clock signal. The module should output a single bit signal named `Out` after exactly 25000 clock cycles have passed. The output should be 1 if a specific pattern is detected in the input, and 0 otherwise.

The pattern to be detected is the 15-bit binary number `001000010001100`. The input bits should be sampled on the rising edge of the clock signal.

You are given the following code snippet to start with:

```
module accepts(input [3:0] In, input Clock, output reg Out);

// Your code here

endmodule
```
