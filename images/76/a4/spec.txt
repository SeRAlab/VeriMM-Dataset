Given the following Moore state machine with 1 input (in) and 1 output (out). Unless otherwise stated in the diagram below, assume outputs are 0 and inputs are don't cares.

1. state G (out=0).
2. state H (out=1).
3. state I (out=1).

State transitions:
1. From state G: If in = 0, then remain in state G. If in = 1, then transition to state H.
2. From state H: If in = 0, then transition to state I. If in = 1, then remain in state H.
3. From state I: If in = 0, then transition to state G. If in = 1, then remain in state I.

At reset, the state machine starts in state "G". Derive next-state logic equations and output logic equations by inspection assuming the following one-hot encoding is used: (G, H, I) = (3'b001, 3'b010, 3'b100)

Write code that generates the following equations:

- G_next -- next-state logic for state G
- H_next
- I_next
- out -- output logic

    input in,
