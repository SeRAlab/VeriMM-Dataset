
You are tasked with designing a module that implements a D flip-flop with synchronous reset and enable using Verilog. The module should have the following inputs and outputs:
- `D`: a single-bit input representing the data to be stored.
- `C`: a single-bit input representing the clock signal.
- `CE`: a single-bit input representing the enable signal. When `CE` is high, the flip-flop should be enabled and respond to changes in `D` on the rising edge of `C`. When `CE` is low, the flip-flop should hold its current state.
- `S`: a single-bit input representing the synchronous reset signal. When `S` is high, the flip-flop should be reset to 0 regardless of the value of `D`. When `S` is low, the flip-flop should hold its current state.
- `Q`: a single-bit output representing the stored value of `D`.

Your module should be named `dff_se`.
