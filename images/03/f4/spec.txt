Design a simple SATA controller state machine that manages the link initialization process. The state machine should transition through the states: IDLE, LINK_QUAL, and LINK_ESTAB based on input signals. The state transitions are defined as follows: from IDLE to LINK_QUAL when the start signal is high, from LINK_QUAL to LINK_ESTAB when the link qualified signal is received, and from LINK_ESTAB back to IDLE when the reset signal is high. Implement the state machine using a clock and reset signal.
