Please act as a professional Verilog designer.

Implement a 8-bit binary up/down counter with synchronous reset. The counter should increment its value on every positive edge of the clock signal if the up_down signal is high, and decrement if the up_down signal is low. The counter should reset to 8'b00000000 on a positive edge of the reset signal.

Module name:
    up_down_counter

Input ports:
    clk: Clock signal.
    reset: Active-high reset signal.
    up_down: Control signal for up/down counting.

Output ports:
    count: 8-bit counter value.

Implementation:
Use a sequential block to implement the counter logic. The counter should increment or decrement on every clock edge based on the up_down signal and reset to 8'b00000000 when the reset signal is high.
