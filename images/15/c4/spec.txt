Design a 16-bit shift register with synchronous load and right shift functionality. The shift register should have an input for loading new data (16 bits), a clock signal, a reset signal, a shift enable signal, and an output for the shifted data. The register should load new data on the rising edge of the clock when the load signal is high, and it should shift right when the shift enable signal is high. The register should be cleared when the reset signal is high.
