Design a 16-bit binary up counter with synchronous reset functionality. On each rising edge of the clock signal, the counter increments its value. If the reset signal is asserted, the counter resets to zero. Additionally, when the counter reaches its maximum value of 65535, it wraps around and starts counting from zero again.
module top_module(
  input clk, // input clock signal
  input rst, // synchronous reset signal
  output reg [15:0] count // output count value
);
