Design a 4-bit binary counter that increments its value on each positive edge of a clock signal. The counter can be reset to zero when the reset signal is asserted. The counter's current value is represented by four output signals controlling individual LEDs, with each LED representing a bit of the counter. Specifically, led3 reflects the most significant bit, while led0 reflects the least significant bit.
module top_module(
    input wire clk,
    input wire reset,
    output reg led3, // changed to reg
    output reg led2, // changed to reg
    output reg led1, // changed to reg
    output reg led0  // changed to reg
);
