
Design a 4-channel Direct Memory Access (DMA) controller in Verilog. The DMA controller should have the following features:
- Four channels (channel_0 to channel_3) that can independently request data transfers.
- A clock input to synchronize operations.
- A reset input to initialize the controller.
- Each channel should have a request input (`req`), an acknowledge output (`ack`), and a data output (`data_out`).
- When a channel requests a transfer, it should be granted access in a round-robin manner.
