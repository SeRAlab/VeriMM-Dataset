Design a comparator circuit that evaluates two n-bit input signals, A and B, where n is defined as 4 bits. The module produces three output signals: EQ, GT, and LT. EQ is asserted high when A equals B, GT is asserted high when A is greater than B, and LT is asserted high when A is less than B, allowing for easy determination of the relational status between the two inputs.
module top_module(
  input [n-1:0] A,
  input [n-1:0] B,
  output reg EQ,
  output reg GT,
  output reg LT
);
