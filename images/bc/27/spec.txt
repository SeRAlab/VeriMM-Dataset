Please act as a professional Verilog designer.

Design a Verilog module for a 4-bit binary to Gray code converter. The module should take a 4-bit binary input and produce a 4-bit Gray code output.

Module name:
    binary_to_gray_4bit

Input ports:
    bin_in: 4-bit binary input.

Output ports:
    gray_out: 4-bit Gray code output.

Implementation:
The conversion from binary to Gray code for a 4-bit input is done as follows:
- The most significant bit (MSB) of the Gray code is the same as the MSB of the binary input.
- Each subsequent bit is obtained by XORing the corresponding binary bit with the previous binary bit.
