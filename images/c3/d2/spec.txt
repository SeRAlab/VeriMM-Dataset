

You have been tasked with designing a Verilog module for a digital logic circuit. The circuit will have three inputs: RESET_B, D, and GATE, and one output: Q. The module should be named "sky130_fd_sc_ms__dlrtp".

In addition to the inputs and output, the module should also include four voltage supply signals: VPWR, VGND, VPB, and VNB. VPWR and VGND should be connected to the positive and negative voltage supplies, respectively. VPB and VNB should be connected to the power and ground pins of the circuit, respectively.

The module should implement the following logic:
- When RESET_B is high, Q should be low.
- When RESET_B is low and GATE is high, Q should follow the value of D.
- When RESET_B is low and GATE is low, Q should hold its previous value.

Your task is to write the Verilog code for the "sky130_fd_sc_ms__dlrtp" module that implements the logic described above. Your code should be 200 lines or less.
