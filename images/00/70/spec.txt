
Design a 2-bit SR latch using D flip-flops. The latch should have two inputs, S (Set) and R (Reset), and two outputs Q and Q_bar. The behavior should be such that if S is high and R is low, Q should be set to 1. If R is high and S is low, Q should be reset to 0. If both S and R are low, Q should maintain its previous state. If both S and R are high, the state is undefined.
