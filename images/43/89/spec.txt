Design a synchronous FIFO (First In, First Out) memory buffer capable of storing a specified number of 32-bit wide data entries. The FIFO has write (wr) and read (rd) control signals to manage data flow. It includes full and empty status outputs to indicate when the buffer is at capacity or devoid of data. The resetn input allows for asynchronous reset of read and write pointers to initialize the buffer. The design incorporates an overflow condition and employs a counter to handle read operations, ensuring that data is only read when requested and not simultaneously with a new write operation.
