Design a 1-bit DRAM cell that can store a single bit of data. The cell should have the following inputs: `write_enable` (to write data), `data_in` (the data to be written), and `read_enable` (to read data). The output should be `data_out`. When `write_enable` is high, the `data_in` should be stored in the cell. When `read_enable` is high, the stored data should be outputted to `data_out`. The outputs should maintain their last state when neither operation is active.
