

You are tasked with designing a module that implements a D flip-flop with asynchronous reset and clock enable. The module should have the following inputs and outputs:

- `D` (input): data input
- `C` (input): clock input
- `CE` (input): clock enable input
- `R` (input): asynchronous reset input
- `Q` (output): data output

The module should be named `DFF_ASR_CE` and should be written in Verilog. You can assume that all inputs are synchronous to the same clock domain and that the clock has a 50% duty cycle.

You can use the following code snippet as a starting point:

```
module DFF_ASR_CE (
  input D,
  input C,
  input CE,
  input R,
  output reg Q
);

// your code here

endmodule
```

Your task is to implement the `DFF_ASR_CE` module that meets the above requirements. Specifically, the module should:

- Implement a D flip-flop with asynchronous reset and clock enable using the provided inputs and outputs.
- The output Q should be updated on the rising edge of the clock C, if and only if the clock enable input CE is high.
- If the asynchronous reset input R is high, the output Q should be asynchronously reset to 0, regardless of the clock and clock enable inputs.
