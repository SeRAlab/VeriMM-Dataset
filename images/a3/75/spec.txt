Design a register module that allows for data input and output, with configurable write capabilities and a reset function. The module has a parameterized width, set to 8 bits by default, and can take a default value to initialize the output when the reset signal is activated. On each positive edge of the clock, if the reset is triggered, the output is updated to the default value; otherwise, if the write signal is asserted, the data input is written to the output.
module top_module(DataIn, DataOut, Write, Clk, Reset, Default);
