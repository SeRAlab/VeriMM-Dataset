Design a simple NVMe controller state machine that transitions between three states: IDLE, READ, and WRITE. The controller should change states based on two inputs: "start" (to initiate a read or write operation) and "operation" (to specify whether it is a read or write). The state transitions should be as follows:  
- From IDLE: if start = 1 and operation = 0, go to READ state; if start = 1 and operation = 1, go to WRITE state.  
- From READ or WRITE: if operation is complete, return to IDLE state.  
The output should indicate the current state of the controller (IDLE, READ, WRITE).
