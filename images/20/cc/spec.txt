
Design a simple EEPROM cell behavior in Verilog. The EEPROM cell should have a data input (`data_in`), a write enable signal (`write_enable`), and an output (`data_out`). When `write_enable` is high, the data from `data_in` should be stored in the EEPROM cell and reflected on `data_out`. When `write_enable` is low, the last written data should remain on `data_out`.
