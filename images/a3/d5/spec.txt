Implement a 4-bit shift register that captures the input data on the rising edge of the clock signal. The shift register consists of four flip-flops connected in series, where each flip-flop shifts the output of the preceding one, effectively propagating the input data through the register. The final output (data_out) represents the last stage of the shift operation, holding the most recent data value that was shifted through the register.
module top_module(
    input clk,
    input [3:0] data_in,
    output [3:0] data_out
);
