Implement a Verilog module for an 8-bit register with load enable. The register captures the input data (d) on the rising edge of the clock (clk) when the load signal is high and retains its value otherwise. The register is asynchronously cleared with the reset signal.

module reg8 (
        input clk,
        input reset,
        input load,
        input [7:0] d,
        output reg [7:0] q);
