Design a general-purpose register (GPR) module that supports reading and writing of 32-bit registers. The module has a clock input for synchronous operation and includes control logic for writing data into a specified register based on a write address when the 'regwrite' signal is asserted. It outputs the contents of two registers identified by their respective addresses, providing a zero output for any read request to the register address zero. This design serves as a basic component for a CPU's register file, facilitating both data storage and access for processing tasks.
