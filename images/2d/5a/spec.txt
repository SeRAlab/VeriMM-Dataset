
Design a Verilog module for matrix factorization that takes a 2D input matrix of size MxN and outputs two matrices: a user-feature matrix of size MxK and an item-feature matrix of size KxN. The factorization will be simple, assuming K is fixed and small enough to be manageable. The input matrix will be provided as a flattened 1D array, and the output matrices will also be in a flattened form. The factorization will be based on simple averaging for the sake of this problem.
