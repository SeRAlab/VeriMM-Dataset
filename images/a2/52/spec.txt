Design a 6-to-1 multiplexer that selects one of six input signals based on a 3-bit selection input. When the selection input (Sel) corresponds to a specific binary value (000 to 101), the output (Out) will reflect the value of the selected input (In0 to In5). If an invalid selection (greater than 5) is made, the output will default to a LOW state (0).
