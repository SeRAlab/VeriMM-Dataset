Develop a binary to 7-segment display decoder. The module translates a 4-bit binary input into an 8-bit output that represents the active segments of a common cathode 7-segment display. Each combination of the binary input (0 to 9) corresponds to a specific pattern of segments being turned on or off, allowing for the display of decimal digits. For invalid inputs, the default pattern for zero is used.
module top_module(
input	wire	[3:0]	bin,

output	reg		[7:0]	seg
);
