Implement the Verilog module based on the following description.
Create a Verilog module for a 4-bit up/down counter with a terminal count output. It should take a clock signal (clk), a reset signal (rst), and an up/down control signal (up_down). The counter should reset to 0 when the reset signal is high. The terminal count output (tc) should go high when the counter reaches its maximum or minimum value, depending on the direction.
