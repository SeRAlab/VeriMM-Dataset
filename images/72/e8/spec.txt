Design a circuit that utilizes a clock signal to implement a 25-bit counter, which toggles the highest bit output (`led1` and `ld1`) on each clock cycle. The remaining LED outputs (`led2` and `led3`) are constant LOW values. Additionally, the module outputs a mode indicator (`ld4`), and the 4 least significant bits of a 4-bit ID input are directly routed to the respective outputs (`ld5` through `ld8`). This design serves as a simple state indicator with visual feedback via LEDs, influenced by the mode selection and ID input.
module top_module(
   input       clock,
   input       mode,
   input [3:0] id,
   output      led1, 
   output      led2, 
   output      led3, 
   output      ld1,
   output      ld2,
   output      ld3,
   output      ld4,
   output      ld5,
   output      ld6,
   output      ld7,
   output      ld8
   );
