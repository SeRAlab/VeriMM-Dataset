Design a simple Ethernet MAC controller state machine that can handle frame transmission and reception. The MAC controller should have states for IDLE, TRANSMIT, and RECEIVE. The inputs to the state machine are 'start_tx' for starting transmission and 'start_rx' for starting reception. The output should indicate the current state as a 2-bit signal: 00 for IDLE, 01 for TRANSMIT, and 10 for RECEIVE.
