Design a Verilog module for a simple dual-port memory with 16 8-bit words. The module should support simultaneous read and write operations. The write operation occurs on the rising edge of the clock if the `we` signal is high.
module dual_port_memory(
    input clk,
    input we,
    input [3:0] write_address,
    input [3:0] read_address,
    input [7:0] write_data,
    output reg [7:0] read_data);
