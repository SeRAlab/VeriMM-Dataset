Design a sign-extension module that converts a 16-bit input (imm16) into a 32-bit output (imm32). The ExtType input determines the extension type; if ExtType is 1 and the most significant bit of imm16 is 1, it performs sign-extension by prepending 16 ones to the imm16 value. Otherwise, it prepends 16 zeros, effectively performing zero-extension.
module top_module(
    input  [15:0] imm16,
    input         ExtType,
    output [31:0] imm32
);
