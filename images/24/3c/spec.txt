Design a GPIO controller that supports read and write operations. The GPIO controller should have the following functionality: It has a data register to hold the GPIO value, an input signal to write to the register, an output signal to read from the register, and a control signal to indicate whether the operation is a read or write. The control signal should be high for a write operation and low for a read operation. When writing, the input data should be stored in the data register. When reading, the output should reflect the current value of the data register. The data register should be 8 bits wide.
