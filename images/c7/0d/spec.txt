
You are tasked with designing a verilog module that performs a 2-bit comparator. The module should have two 2-bit input signals, A and B, and an output signal Y. The output signal Y should be high if A is greater than B, and low otherwise. 

Declare your module with the following name and ports:
```verilog
module two_bit_comparator (
    input [1:0] A,
    input [1:0] B,
    output Y
);
```
