Design a 4-bit SRAM cell type with read and write functionality. The SRAM cell should have a data input (D), a data output (Q), a write enable (WE), a read enable (RE), and a clock signal (CLK) to control the operations. When WE is high, the data at D should be written into the cell on the rising edge of CLK. When RE is high, the data stored in the cell should be outputted to Q on the rising edge of CLK. If both WE and RE are low, the cell should retain its previous state.
