Construct a Verilog module for a combinational logic system with four inputs g, h, i, and j, and one output k. The output should follow these conditions:

If g = 1, h = 0, i = 1, j = 0, then k = 1.
If g = 0, h = 1, i = 1, j = 0, then k = 0.
If g = 1, h = 1, i = 0, j = 1, then k = 1.
If g = 0, h = 0, i = 0, j = 1, then k = 0.
If g = 1, h = 1, i = 1, j = 1, then k = 1.

module logic_system (
	input g,
	input h,
	input i,
	input j,
	output reg k);
