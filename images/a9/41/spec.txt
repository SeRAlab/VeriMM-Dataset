Design a 4-bit adder/subtractor circuit. It takes two 4-bit inputs, A and B, and a mode signal to determine the operation: when mode is 0, it performs addition (A + B), and when mode is 1, it performs subtraction (A - B). The output is a 4-bit result (O), and a carry/borrow output (COUT) indicates overflow for addition and underflow for subtraction.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input mode,
    output reg [3:0] O,
    output reg COUT
);
