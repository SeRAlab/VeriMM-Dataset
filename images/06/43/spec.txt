Design a 1-bit DRAM cell that can store a single bit. The cell should have the following inputs and outputs:  
- Inputs:  
  - `write_enable`: Controls whether to write to the cell.  
  - `data_in`: The data to write when `write_enable` is high.  
  - `clk`: Clock signal for synchronous operation.  
- Outputs:  
  - `data_out`: The stored data in the cell, which should reflect the value of `data_in` when writing is enabled.  
The cell should retain its value when `write_enable` is low.
