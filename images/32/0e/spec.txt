Design a DVFS controller that adjusts the operating frequency based on the current load. The controller has an input signal `load` which indicates the system load (4-bit), and two output signals: `frequency` (3-bit) and `voltage` (3-bit). The frequency and voltage levels are defined as follows based on the load:
- Load 0000: frequency = 3'b000, voltage = 3'b000
- Load 0001: frequency = 3'b001, voltage = 3'b001
- Load 0010: frequency = 3'b010, voltage = 3'b010
- Load 0011: frequency = 3'b011, voltage = 3'b011
- Load 0100: frequency = 3'b100, voltage = 3'b100
- Load 0101: frequency = 3'b101, voltage = 3'b101
- Load 0110: frequency = 3'b110, voltage = 3'b110
- Load 0111 or higher: frequency = 3'b111, voltage = 3'b111
