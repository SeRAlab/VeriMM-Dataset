Design a 2-bit shift register with synchronous load and shift operations. The shift register should have a clock input, a reset input, a load input, and a 2-bit data input. On the rising edge of the clock, if reset is high, the shift register should reset to '00'. If load is high, the data input should be loaded into the shift register. If neither reset nor load is high, the contents of the shift register should be shifted to the right by one bit, with the most significant bit (MSB) set to '0'.
