Design a 32-bit comparator that determines whether input `a` is less than input `b`. The module computes the difference between `a` and `b` and outputs a single bit, `a_lt_b`, which indicates if `a` is less than `b` by checking the sign bit of the difference. If the most significant bit (MSB) of the result is 1, then `a` is less than `b`, otherwise, it is not.
module top_module(
    a,
    b,
    a_lt_b
);
