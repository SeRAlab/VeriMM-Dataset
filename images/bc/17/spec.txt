Design a combinational logic circuit with three inputs (a, b, c) that produces three outputs (x, y, z). The output x directly reflects the value of input a. The output y is active high (1) when input a is LOW (0) and input b is HIGH (1). The output z is active high (1) when both input a and input b are LOW (0), and input c is HIGH (1).
module top_module(
    input a,
    input b,
    input c,
    output x,
    output y,
    output z
    );
