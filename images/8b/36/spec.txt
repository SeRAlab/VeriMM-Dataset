Design a flip-flop module that operates with asynchronous reset and set functionalities. The flip-flop captures the input `d` on the negative edge of the clock `clk` unless the asynchronous reset `ar` is triggered, which sets the output `q` to LOW. If the set input `s` is HIGH, the output `q` will be set to HIGH, overriding the `d` input during the clock edge. This design allows for flexible control of the output state based on the reset, set, and data inputs.
module top_module(
  input clk,
  input ar,
  input s,
  input d,
  output reg q
);
