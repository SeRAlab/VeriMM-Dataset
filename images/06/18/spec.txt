Design a Phase-Locked Loop (PLL) module in Verilog that generates a feedback clock based on an input clock. The PLL should take an input clock signal and a reset signal. When the reset signal is low, the PLL should be able to lock onto the frequency of the input clock. The output should be a divided version of the input clock. The division factor is controlled by a parameter which can be set at instantiation. The output clock should toggle at a frequency that is equal to the input clock frequency divided by the division factor.
