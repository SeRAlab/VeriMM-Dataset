The module outputs an equality signal (EQ) that asserts true if all inputs are equal and a greater-than signal (GT) that asserts true if any input is greater than the subsequent inputs, or if all inputs are equal (A = B = C = D). The circuit includes intermediate signal calculations to determine pairwise equality and comparisons between the inputs.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input [3:0] C,
    input [3:0] D,
    output EQ,
    output GT
);
