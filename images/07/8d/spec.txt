Design a simple SATA controller that takes a 5-bit input representing a command and outputs a 3-bit status signal based on the command. The command will be interpreted as follows: 
- Command '00000' (0) -> Status '000' (Idle)
- Command '00001' (1) -> Status '001' (Ready)
- Command '00010' (2) -> Status '010' (Processing)
- Command '00011' (3) -> Status '011' (Completed)
- Command '00100' (4) -> Status '100' (Error)
For any other command, the status should be '111' (Unknown).
