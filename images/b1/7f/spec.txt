Design a 4-to-1 multiplexer that selects one of four input signals (A, B, C, D) based on the values of two select lines (S1 and S0). The output Y will be set to the chosen input based on the binary value formed by the select lines: when S1S0 is 00, output A; when 01, output B; when 10, output C; and when 11, output D. If none of the conditions are met, the output defaults to an unknown state (1'bx).
module top_module(
  output Y,
  input S0, S1, A, B, C, D
);
