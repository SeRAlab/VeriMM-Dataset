Design a register file that contains eight, 8-bit wide registers used for data storage. It operates with a clock signal (CLK) and has a reset functionality (RESET) to initialize all registers to zero. When WRITE is enabled, the module allows data input (IN) to be written to the register specified by the INADDRESS. The register file outputs the contents of two registers specified by OUT1ADDRESS and OUT2ADDRESS, allowing simultaneous access to their values.
module top_module(IN,OUT1,OUT2,INADDRESS,OUT1ADDRESS,OUT2ADDRESS,WRITE,CLK,RESET);
