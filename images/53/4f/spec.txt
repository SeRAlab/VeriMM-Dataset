Design a traffic light controller that manages the state of a traffic light system in a cyclical manner. It uses a finite counting mechanism driven by a clock, and outputs a 2-bit signal representing the light's state: red, yellow, or green. The light transitions through these states in a defined sequence, starting with red, followed by green for a specified number of cycles, then yellow for a brief period, before returning to red. The design incorporates a reset feature to initialize the light to red and the counter to zero, ensuring predictable operation upon system reset.
module top_module(
   input clk,
   input reset,
   output reg [1:0] light
);
