
Design a simple ARQ (Automatic Repeat reQuest) system in Verilog that includes error detection and a request for retransmission mechanism. The system should consist of a sender that transmits a message and a receiver that checks for errors. If an error is detected, the receiver should send a request signal back to the sender to retransmit the last message. The sender should wait for this signal before sending the message again. Implement this using flip-flops and combinational logic for control signals.
