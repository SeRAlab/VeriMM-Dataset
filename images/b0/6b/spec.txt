Design a combinational logic circuit that determines the output X based on the states of three input signals and a pair of additional inputs. This logic can be implemented through a series of conditional checks, making it suitable for scenarios where multiple input conditions dictate a binary output.
module top_module(
    input A1,
    input A2,
    input B1,
    input C1,
    output reg X
);
