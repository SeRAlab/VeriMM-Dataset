Design a 7-stage pipelined processor that can perform the following operations: addition, subtraction, multiplication, and division based on a 3-bit opcode. The processor should have a 32-bit input data width and a 32-bit output data width. Each stage of the pipeline must handle one of the operations, and the final output should be available after all stages are complete. It should also include a flip-flop to store the result after the last stage.
