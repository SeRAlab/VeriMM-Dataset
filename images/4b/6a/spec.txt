Develop a 3-bit wide comparator module that compares two 3-bit inputs, `a` and `b`. The module outputs three signals: `gt` indicates if `a` is greater than `b`, `eq` signals if `a` is equal to `b`, and `lt` shows if `a` is less than `b`. The comparisons are registered and updated on the rising edge of the clock, ensuring synchronous operation.
module top_module(
    input wire clk,      // Added the clk input
    input [2:0] a,
    input [2:0] b,
    output reg gt,
    output reg eq,
    output reg lt
);
