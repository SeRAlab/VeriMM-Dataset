Design a JK latch using Verilog. The JK latch should have inputs J, K, and a clock signal (clk), and an output Q. The latch should toggle the output Q based on the values of J and K on the rising edge of the clock. If J and K are both 0, the output should remain unchanged. If J is 1 and K is 0, Q should be set to 1. If J is 0 and K is 1, Q should be reset to 0. If both J and K are 1, Q should toggle between 0 and 1.
