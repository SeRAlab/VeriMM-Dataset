Design a 4-bit counter with load and enable functionality. The counter increments its value on each positive clock edge when the enable signal is high. It can be reset to zero when the reset signal is active, or it can be loaded with a specified 4-bit value when the load signal is asserted. The module outputs the current count value as a 4-bit register.
module top_module(
    input clk,
    input reset,
    input load,
    input [3:0] load_value,
    input enable,
    output reg [3:0] count
);
