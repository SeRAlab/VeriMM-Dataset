Design a 4-to-1 multiplexer with an asynchronous reset feature. The module selects one of the four input data lines based on the 2-bit `sel` signal and outputs it as `data_out`. If the `reset` signal is activated (on a positive edge), the `data_out` is set to LOW, overriding any selection from the multiplexer.
module top_module(
    input [3:0] data_in,
    input [1:0] sel,
    input reset,
    output reg data_out
);
