Design a 4-to-1 multiplexer with four single-bit inputs (A, B, C, D) and a 2-bit select signal (sel). The output (out) will reflect the value of the selected input based on the sel value: when sel is 00, the output will be A; when sel is 01, it will be B; when sel is 10, it will be C; and when sel is 11, it will be D. If an invalid sel value is encountered, the output will default to LOW.
module top_module(
    // Inputs
    input A,
    input B,
    input C,
    input D,
    input [1:0] sel,

    // Outputs
    output reg out
);
