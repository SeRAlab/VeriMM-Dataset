Design a 32-bit program counter (PC) module that updates its output (pc_o) based on clock events. On a rising edge of the clock, if the reset signal (rst_i) is low, the output is reset to zero. If the reset is not active and the start signal (start_i) is high, the program counter loads a new value from the input (pc_i). If the start signal is low, the output retains its current value, effectively allowing the counter to hold its state.
