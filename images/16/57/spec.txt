Design a Verilog module that implements a simple state machine for a SLAM-like system. The state machine should have the following states: IDLE, MAP, and LOCALIZE. The state transitions should be controlled by two inputs: 'start' and 'reset'. The module should output the current state as a 2-bit value (00 for IDLE, 01 for MAP, 10 for LOCALIZE). The state machine should transition to MAP when 'start' is high, go to LOCALIZE when 'MAP' is completed (indicated by a separate input 'map_done'), and return to IDLE when 'reset' is high.
