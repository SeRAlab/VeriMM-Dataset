

You are tasked with designing a Verilog module that can perform a simple arithmetic operation on two 8-bit input values. The operation to be performed is determined by a 2-bit control signal. The possible operations are:
- 00: Addition
- 01: Subtraction
- 10: Bitwise AND
- 11: Bitwise OR

The module should have the following ports:
- `input [7:0] A`: the first input value
- `input [7:0] B`: the second input value
- `input [1:0] op`: the control signal that determines the operation to perform
- `output [7:0] out`: the output value

Your module should be able to perform the specified operation and output the result on the `out` port. You should assume that the inputs are valid and that overflow/underflow is not a concern.

You are required to write a module that solves this problem within 200 lines of Verilog code.
