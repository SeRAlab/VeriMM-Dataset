

You are tasked with designing a verilog module to implement a simple 8-bit adder. The module should have two 8-bit inputs (A and B) and one 8-bit output (C). The module should also have two input wires, clk and rst, which represent the clock and reset signals, respectively. The output should update only on the positive edge of clk. The module should implement the following logic:

- When rst is high, C should be set to 0.
- When rst is low and clk is high, C should be set to the sum of A and B.

Write the verilog code for this module.
