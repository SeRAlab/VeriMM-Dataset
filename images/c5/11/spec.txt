

You are tasked with designing a verilog module that implements a simple multiplier. The module should have the following inputs and outputs:

Inputs:
- `clk` : a clock signal
- `rst` : a synchronous reset signal
- `A` : an 8-bit unsigned integer
- `B` : an 8-bit unsigned integer

Outputs:
- `Z` : a 16-bit unsigned integer representing the product of `A` and `B`

The module should have the following behavior:
- On reset (`rst` asserted), `Z` should be set to 0.
- On each rising edge of the clock (`clk`), the module should multiply `A` and `B` and store the result in `Z`.

You are free to use any verilog constructs to implement the module.
