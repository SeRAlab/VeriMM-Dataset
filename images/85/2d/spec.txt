Create a circuit that computes the sum of two 4-bit inputs, `in1` and `in2`, and outputs this sum on a 4-bit output `out`. Additionally, the circuit compares the sum with the value currently held in `out`, outputting the greater value on a separate 4-bit output `max_out`. The design features an adder for calculating the sum and a comparator to determine the maximum value between `out` and the sum.
module top_module( 
    input wire [3:0] in1,
    input wire [3:0] in2,
    output wire [3:0] out,
    output wire [3:0] max_out );
