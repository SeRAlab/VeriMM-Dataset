Design a Verilog module for a 14-bit ripple carry adder with an asynchronous positive edge triggered reset. The adder should add two 14-bit numbers and produce a 14-bit sum.
(1) reset: Resets the sum to zero.
(2) a: First 14-bit input number.
(3) b: Second 14-bit input number.
(4) sum: 14-bit output sum.
