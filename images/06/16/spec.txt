Design a fan speed control system that controls the speed of a fan based on temperature thresholds. The system should have an input for temperature and output for fan speed. The fan has three speeds: low, medium, and high. If the temperature is less than 20 degrees, the fan should be off. Between 20 and 25 degrees, the fan should run at low speed. Between 25 and 30 degrees, it should run at medium speed, and above 30 degrees, it should run at high speed. The system should also allow for fan speed changes only on the rising edge of a clock signal.
