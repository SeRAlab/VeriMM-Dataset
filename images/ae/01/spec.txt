Design a four-bit binary adder that computes the sum of two 4-bit inputs, A and B, along with a carry-in bit (C). The output will be a 4-bit sum (S) and a carry-out signal (Cout). The carry-out is determined by checking if the sum exceeds the maximum value representable by four bits (15 in decimal). If the sum exceeds this value, Cout is set to 1, otherwise it is set to 0.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input C,
    output [3:0] S,
    output Cout
);
