Design a Stop-and-Wait ARQ (Automatic Repeat reQuest) protocol in Verilog. The system will have a sender and a receiver. The sender sends a data packet and waits for an acknowledgment (ACK) from the receiver. If the sender receives an ACK, it will send the next packet; if not, it will resend the same packet. The sender will have a maximum of 5 packets (0 to 4) to send. The receiver will send an ACK if it receives the correct packet.
