Implement a 4-bit to 8-segment display decoder. This module converts a 4-bit binary input (SEG_VAL) into an 8-bit output (SEG) suitable for driving a 7-segment display, with each combination of the input selecting the corresponding pattern to represent numbers 0-9 and letters A-F on the display. The SEG output is determined asynchronously based on the value of SEG_VAL, enabling the display to show hexadecimal digits.
