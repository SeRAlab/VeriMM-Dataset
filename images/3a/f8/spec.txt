Design a 1-bit SRAM cell that can store a single bit of data. The SRAM cell should have two control signals: `write_enable` and `read_enable`. When `write_enable` is high, the SRAM cell should store the input data `data_in`. When `read_enable` is high, the SRAM cell should output the stored data through `data_out`. If both `write_enable` and `read_enable` are high at the same time, the SRAM should prioritize writing over reading.
