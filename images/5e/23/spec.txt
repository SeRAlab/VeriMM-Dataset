Design a joypad controller that interfaces with a game console. It has inputs for a clock, reset, an interrupt acknowledgment signal, an address bus, data inputs, read/write control signals, and a chip select. Upon receiving a write command to address 0xFF00, it captures the button selector from the data input. It generates an output data bus, which provides a status byte that includes a fixed identifier, the selected button, and corresponding button data when chip select is active. An interrupt request signal is generated based on write operations, ensuring proper communication between the joypad and the main system.
module top_module(
  input  wire        clock,
  input  wire        reset,
  input  wire        int_ack,  
  output reg         int_req,
  input  wire [15:0] A,
  input  wire  [7:0] Di,
  output wire  [7:0] Do,
  input  wire        rd_n,
  input  wire        wr_n,
  input  wire        cs,
  output reg   [1:0] button_sel,
  input  wire  [3:0] button_data
);
