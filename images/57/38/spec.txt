Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs: 
1. state X (output 1).
2. state Y (output 0).
3. state Z (output 1).

State transitions:
1. From state X: If w = 0, then transition to state Y. If w = 1, then transition to state Z.
2. From state Y: If w = 0, then transition to state X. If w = 1, then transition to state Z.
3. From state Z: If w = 0, then transition to state Y. If w = 1, then transition to state X.

Resets into state X. For this part, assume that a one-hot code is used with the state assignment f[3:1] = 001, 010, 100 for states X, Y, Z, respectively.

Write Verilog for the next-state signals F2 and F3 corresponding to signal f[2] and f[3]. Derive the logic equations by inspection assuming a one-hot encoding.
