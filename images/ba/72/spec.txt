Design a 2-bit saturating branch predictor that adjusts its prediction based on whether branches are taken or not. The module uses a counter to track the prediction state, which can increment or decrement based on input signals. When "taken_i" is high, the counter increases to suggest a branch is likely to be taken; otherwise, it decreases to indicate the opposite. The output "prediction_o" provides a prediction based on the current counter state, with randomization introduced to add variability in cases where state transitions occur. This helps enhance prediction accuracy in pipelined architectures, optimizing performance by minimizing stalling due to branch mispredictions.
