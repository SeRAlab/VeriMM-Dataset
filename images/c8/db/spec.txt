

You are tasked with designing a module that takes in two 4-bit inputs, `A` and `B`, and outputs the bitwise AND of `A` and `B`. You should implement this using only bitwise operators and assign statements. 

Your module should be named `bitwise_and_4bit` and should have the following inputs and outputs:
- `input [3:0] A`: a 4-bit input
- `input [3:0] B`: a 4-bit input
- `output [3:0] M`: a 4-bit output representing the bitwise AND of `A` and `B`

You should implement this by using the `&` operator to perform the bitwise AND operation on each bit of `A` and `B`. You should then assign the result to the output `M`.
