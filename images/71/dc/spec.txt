Design a 4-bit adder capable of performing both addition and subtraction based on a control signal. Inputs A and B are 4-bit numbers, and the signal S indicates whether to add (S=0) or subtract (S=1). The module outputs a 4-bit result Y, which is the sum or difference based on the operation selected, and a single-bit overflow flag V that indicates if an overflow condition has occurred during the operation.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input S,
    output [3:0] Y,
    output V
);
