

You have been tasked to design a clock gate module that can be used in a larger circuit. The module should have four inputs: `CLK`, `EN`, `TE`, and an output `ENCLK`. The `CLK` input is a clock signal, `EN` is an enable signal, and `TE` is a test enable signal. The `ENCLK` output is the gated clock signal.

You need to create a module called `clock_gate` that implements this functionality. The module should use a D flip-flop to store the clock signal and a logic gate to perform the clock gating. The module should only generate the `ENCLK` signal when both `EN` and `TE` are high.

Your module should be self-contained and not rely on any other modules. You can assume that the inputs `CLK`, `EN`, and `TE` are synchronous to each other and have the same clock frequency.

Write a Verilog module that implements the `clock_gate` functionality and test it using a testbench.
