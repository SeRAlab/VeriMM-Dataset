Design a simple WiFi status controller that takes a 2-bit input representing the current state of a WiFi module, where the states are defined as:  
00 - Disconnected  
01 - Connecting  
10 - Connected  
11 - Disconnecting  
The output should indicate whether the WiFi module is currently connected or not (1 for connected, 0 for not connected). The state transitions should occur on the rising edge of a clock signal.
