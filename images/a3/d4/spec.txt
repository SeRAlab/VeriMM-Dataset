Design a 4-bit up/down counter with asynchronous reset and load capabilities. The counter increments when the control signal (`ctrl`) is high and decrements when it is low, provided that the enable signal (`en`) is active. It can be reset to zero when the `rst` input is asserted, or it can load a 4-bit value from the `in` input when the `load` signal is high. The current count value is output on the `out` signal.
module top_module(
    input clk,
    input rst,
    input ctrl,
    input en,
    input load,
    input [3:0] in,
    output reg [3:0] out
);
