Implement the Verilog module based on the following description.
Create a Verilog module for a 8-bit up/down counter. It should take a clock input (clk), a reset input (rst), a direction input (dir), and produce an 8-bit output (count). The counter should increment when dir is 1 and decrement when dir is 0 on the positive edge of the clock signal. The reset should set the counter to 0.
