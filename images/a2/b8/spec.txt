Design a 4-bit adder module that computes the sum of two 4-bit inputs, `a` and `b`. The output, `sum`, will yield the result of the addition, but if the result exceeds the maximum value representable by 4 bits (which is 15), the module will wrap around by subtracting 16 from the sum. This effectively implements a 4-bit modulo-16 addition.
module top_module(
  input [3:0] a,
  input [3:0] b,
  output reg [3:0] sum
);
