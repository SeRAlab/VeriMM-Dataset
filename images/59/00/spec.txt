Design a 4-to-2 priority encoder that takes four input signals (A1, A2, A3, A4) and outputs a 2-bit code (X) indicating the position of the highest priority active input. The priority is assigned such that A4 has the highest priority, followed by A3, A2, and A1. If no inputs are active, the output X defaults to '00'.
module top_module(
    input A1,
    input A2,
    input A3,
    input A4,
    output reg [1:0] X
);
