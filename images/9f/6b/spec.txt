Design a synchronous dual-port RAM module with a 14-bit addressability, allowing for storage of 2-bit wide data words. The module features a clock input to synchronize operations. When the write enable (we) signal is active, data input (din) is written to the memory location specified by the address (addr) on the rising edge of the clock. In every clock cycle, irrespective of the write enable signal, the data output (dout) is updated to reflect the data stored at the specified address, facilitating read operations.
module top_module(
    input clk,
    input [13:0] addr,
    input [1:0] din,
    input we,
    output [1:0] dout
);
