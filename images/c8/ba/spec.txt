
You are tasked to design a module in Verilog that implements a 2-input AND gate with an additional input that is the logical OR of three other inputs. The module should have the following inputs and outputs:
- `in1`: 1-bit input
- `in2`: 1-bit input
- `in3`: 1-bit input
- `in4`: 1-bit input
- `out`: 1-bit output

The output `out` should be the logical AND of `in1` and `in2`, as well as the logical OR of `in3`, `in4`, and `out`.

Your module should be named `and_or_gate` and should be contained in a file named `and_or_gate.v`.
