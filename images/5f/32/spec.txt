Design a one-bit wide, 2-to-1 multiplexer using a lookup table (LUT). The output S is determined by the control signal ctrl; if ctrl is low (0), output S equals D0, and if ctrl is high (1), output S equals D1. This design is parameterized to allow for versatile integration in various digital circuits.
module top_module(ctrl,
    D0,
    D1,
    S);
