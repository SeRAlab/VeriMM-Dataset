Design a 4-bit DRAM cell that can store data and retrieve it on command. The cell should have an input for data (4 bits), a read enable signal, a write enable signal, and a clock signal. When the write enable signal is high, the data should be stored in the cell on the rising edge of the clock. When the read enable signal is high, the stored data should be outputted. The initial state of the cell should be set to zero. Ensure that both read and write operations are properly managed.
