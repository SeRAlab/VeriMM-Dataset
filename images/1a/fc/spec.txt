
Design a simple UART transmitter module that converts a parallel 8-bit data input into a serial output. The module should have a clock input, a data input (8 bits), a start signal to initiate transmission, and a serial output signal. The transmission should start with a start bit (0), followed by the data bits (LSB first), and end with a stop bit (1). The module should also include a transmitter enable signal to control whether the transmitter is active.
