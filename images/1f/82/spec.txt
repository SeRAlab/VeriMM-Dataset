Design a Verilog module that simulates a simple SLAM algorithm's update step. The module should incorporate the following features: 
1. It takes in a current position (x, y) and a new observation (dx, dy).
2. It outputs the updated position after applying the observation.
3. It should also include a clock input and reset signal to initialize the position to (0, 0) when reset is triggered. 
4. The module should maintain its internal state across clock cycles.
