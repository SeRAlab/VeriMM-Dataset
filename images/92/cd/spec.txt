Implement the Verilog module based on the following description.
We want to create a module that:

// (1) receives a 3-bit binary number,
// (2) checks if the number is greater than or equal to 5,
// (3) counts the number of 1s in the binary number,
// (4) outputs a flag if the number is an even number,
// (5) provides a reset mechanism to reset all outputs.

// The input binary number is available on the input signal 'binary_num'. The output 'is_gte5' should be set to 1 if the number is greater than or equal to 5 and 0 otherwise. The number of 1s in the binary number should be output on 'count_ones[1:0]'. The even number flag should be set on 'is_even' if the number is an even number. The reset signal is active high synchronous.

module top_module(
    input wire clk,
    input wire reset,
    input wire [2:0] binary_num,
    output reg is_gte5,
    output reg [1:0] count_ones,
    output reg is_even
);
