Design a 16-bit Linear Feedback Shift Register (LFSR) that generates pseudo-random output based on a clock signal. The circuit resets to zero when the active-low reset (RST_N) is asserted. Upon receiving a START signal, it initializes the state to zero and outputs that state. When the STOP signal is asserted, the state and output also reset to zero. Under normal operation, when neither START nor STOP is active, the LFSR shifts its state left while introducing a feedback mechanism for randomness, with the output reflecting the current state.

    input CLK,
    input RST_N,
