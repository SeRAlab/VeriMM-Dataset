
Design a 8-to-3 priority encoder in Verilog. The encoder should have 8 input lines (I0 to I7) and 3 output lines (Y0 to Y2). The output should represent the index of the highest priority input line that is active (i.e., high). If no input lines are active, the output should be 3'b000. Ensure that the output is valid only when at least one input line is high.
