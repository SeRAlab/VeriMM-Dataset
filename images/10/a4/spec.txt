Design a simple NAT (Network Address Translation) device that translates a private IP address and port to a public IP address and port. The device should take a private IP address (32 bits) and a private port (16 bits) as inputs and output a public IP address (32 bits) and a public port (16 bits). The NAT will be simulated to use a static mapping for demonstration purposes. The mapping will be as follows: Private IP `192.168.1.10` maps to Public IP `203.0.113.5` and Private Port `8080` maps to Public Port `80`.
