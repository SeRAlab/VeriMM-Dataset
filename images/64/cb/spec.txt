Develop a register-based memory element that operates on a clock signal. The module has a single-bit data input (write_0) controlled by a write enable signal (EN_write_0), allowing it to store data on the rising edge of CLK. When EN_write_0 is low, the register retains its previous value; when high, it updates to the value present on write_0. Additionally, the module outputs the currently stored value through read_0, providing a mechanism for data retrieval. This design serves as a basic synchronous register with configurable data size and reset capability.
module top_module(
    CLK,
    read_0,
    write_0,
    EN_write_0
);
