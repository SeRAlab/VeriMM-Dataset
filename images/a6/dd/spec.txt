Design a one-bit priority multiplexer that selects among three inputs: A, B, and C. The output Y is determined by the state of the control signals P and S. If P is high, input C is selected; if P is low and S is high, input B is chosen; otherwise, input A is selected. This module effectively prioritizes input C over B, and B over A based on the control signal states.
module top_module(
    input A,
    input B,
    input C,
    input S,
    input P,
    output Y
);
