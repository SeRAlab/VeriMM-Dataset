
You are tasked with designing a module that takes in a binary input of 4 bits and outputs the same 4 bits but with the leftmost bit shifted to the rightmost position. For example, if the input is 1101, the output should be 1011.

Design a Verilog module called `left_shift` that takes in a 4-bit input called `in` and outputs a 4-bit value called `out`. The module should include the following:

1. Module ports:
   - `in`: a 4-bit input
   - `out`: a 4-bit output

2. The module should include the following internal signals:
   - `temp`: a 4-bit wire
   - `shifted`: a 4-bit wire

3. The module should perform the following operations:
   - Assign the value of `in` to `temp`.
   - Shift the bits in `temp` to the left by one position and assign the result to `shifted`.
   - Assign the value of `shifted` to `out`.

Ensure that the module includes proper supply voltage and ground connections.
