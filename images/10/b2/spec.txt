Implement a simple RRT node management unit in Verilog that allows adding nodes and performing a random walk to generate a new node based on existing ones. The unit should support the following operations:
1. Add a new node with coordinates (x, y)
2. Perform a random walk operation that generates a new node based on the last added node.
The coordinates are 8 bits each for x and y. The unit should have an output that represents the coordinates of the last generated node.
