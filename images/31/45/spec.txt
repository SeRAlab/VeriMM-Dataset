
Design a temperature sensor data processing circuit that takes a 4-bit binary input representing temperature in degrees Celsius (0 to 15). The circuit should output a 3-bit binary value representing the following conditions:
- If the temperature is less than 5°C, output "000" (Cold).
- If the temperature is between 5°C and 10°C (inclusive), output "001" (Cool).
- If the temperature is between 11°C and 15°C (inclusive), output "010" (Warm).
- If the temperature is greater than 15°C, output "011" (Hot).
