Module name:
    shift_register_8              
Input ports:
    rst: Reset signal (active high)
    clk: Clock signal
    load: Signal to load parallel data
    shift: Signal to shift right
    parallel_in: 8-bit input for parallel loading
Output ports:
    data_out: 8-bit output representing the current state of the shift register

Implementation:
If the reset signal is active (rst), the register is reset to 0 by assigning the value 8'b00000000 to the output register (data_out). If the load signal is high, the register loads the parallel data (parallel_in). If the shift signal is high, the register shifts right by one bit. If neither load nor shift is high, the register maintains its current value.
