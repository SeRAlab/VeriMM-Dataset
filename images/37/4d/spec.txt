Design a simple Bluetooth state machine in Verilog that operates in three states: IDLE, CONNECTING, and CONNECTED. The state transitions should be based on two inputs: 'start' and 'disconnect'. The state machine should move from IDLE to CONNECTING when 'start' is asserted, and from CONNECTING to CONNECTED when 'connecting_done' is asserted. It should return to IDLE on 'disconnect' from any state. The output should indicate the current state as a 2-bit value.
