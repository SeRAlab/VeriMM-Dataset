1. state Closed (door_open = 0).
2. state Open (door_open = 1).

1. From state Closed: If open_button = 1, then transition to state Open. If open_button = 0, then transition to state Closed.
2. From state Open: If close_button = 1, then transition to state Closed. If close_button = 0, then transition to state Open.
