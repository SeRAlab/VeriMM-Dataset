
Create an 8-bit DRAM cell with the following specifications:
- It should have an 8-bit data input (D), an 8-bit data output (Q), a write enable signal (WE), a read enable signal (RE), and a clock signal (CLK).
- When WE is high and RE is low, the value at D is written to the cell on the rising edge of CLK.
- When RE is high and WE is low, the value stored in the cell is output on Q on the rising edge of CLK.
- If both WE and RE are high or both are low, the DRAM cell should maintain its previous state.
