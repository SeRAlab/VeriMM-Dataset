Write a Verilog module for a 4-bit up/down counter with enable and asynchronous reset. Assume positive clock/clk edge triggered. The counter should count up or down based on the direction input. When enable is low, the counter should hold its value. When reset is high, the counter should reset to 0.

module counter (
  input clk,
  input reset,
  input enable,
  input direction,
  output reg [3:0] count
);
