
Design a 1-bit DRAM cell that can store a single bit of data. The DRAM cell should have the following inputs and outputs:
- Inputs: 
  - `d`: Data input (1 bit)
  - `we`: Write enable (1 bit, active high)
  - `clk`: Clock (1 bit)
- Outputs:
  - `q`: Data output (1 bit)

The behavior of the DRAM cell should be as follows:
- When `we` is high, on the rising edge of `clk`, the value of `d` is stored in the cell.
- When `we` is low, the stored value should remain unchanged.
- The output `q` should always reflect the stored value in the DRAM cell.
