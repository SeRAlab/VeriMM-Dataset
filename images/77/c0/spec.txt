Create a Verilog module for a 6-bit counter with synchronous reset and load. The counter should load a specified value when the load signal is high.
(1) reset: Resets the counter to zero.
(2) load: Loads the specified value into the counter.
(3) load_value: The value to be loaded into the counter.
(4) q: The current value of the counter.

module top_module(
    input clk,
    input reset,
    input load,
    input [5:0] load_value,
    output reg [5:0] q);
