
Create a Verilog module that implements a simple decision tree for binary classification. The decision tree will utilize three input features (A, B, C) that are 1-bit wide. The output (Y) will be 1-bit wide, representing the classification result based on the following conditions:
1. If A is 1 and B is 0, then Y = 1.
2. If A is 0 and C is 1, then Y = 0.
3. If A is 0 and B is 1, then Y = 1.
4. In all other cases, Y = 0.
