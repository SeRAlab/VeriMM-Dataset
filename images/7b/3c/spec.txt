Design a 4-bit ripple carry adder/subtractor. The module takes two 4-bit inputs, A and B, and a control signal, SUB. If SUB is high, it computes A minus B using the two's complement method; if SUB is low, it performs A plus B. The module also outputs a 4-bit result (SUM), an overflow indicator (OV) that shows if the operation exceeds 4-bit representation, and a zero flag (ZERO) which indicates if the result is zero.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input SUB,
  output [3:0] SUM,
  output OV,
  output ZERO
);
