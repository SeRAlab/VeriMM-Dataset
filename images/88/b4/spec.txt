The output (Y) reflects the value of the selected input, where S0 and S1 determine the active input according to the following configuration: when S1=0 and S0=0, output A; when S1=0 and S0=1, output B; when S1=1 and S0=0, output C; and when S1=1 and S0=1, output D.
module top_module(
    input A,
    input B,
    input C,
    input D,
    input S0,
    input S1,
    output Y
);
