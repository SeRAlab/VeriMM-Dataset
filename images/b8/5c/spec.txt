Design a 2-bit up/down counter that utilizes a clock input for synchronous operation and supports asynchronous reset functionality. The counter state is determined by an enable signal, where '00' holds the current count, '01' increments the count by 1, and '10' decrements the count by 1. Upon receiving an asynchronous reset signal, the counter resets to zero. This design allows for flexible counting operations based on the provided control signals.
module top_module(
    input clk,
    input async_reset,
    input [1:0] enable,
    output reg [1:0] count
);
