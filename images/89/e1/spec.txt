Design a module that converts between binary and Gray code for an n-bit wide input. The first part of the code handles the conversion from binary to Gray code, where each bit of the Gray code output is generated by XORing the current bit of the binary input with the previous bit. The second part aims to convert from Gray code back to binary using a similar approach, again employing an XOR operation to derive the binary value from the Gray code input. This dual functionality allows the module to facilitate both conversions in a single design.
module top_module(
  input [n-1:0] in,
  output [n-1:0] out
);
