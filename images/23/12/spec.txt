Design a Verilog module for a simple WiFi connection state machine. The state machine should have three states: IDLE, CONNECTING, and CONNECTED. It should transition based on the following conditions: 
- From IDLE to CONNECTING when a signal `start_connect` is high.
- From CONNECTING to CONNECTED when a signal `connection_done` is high.
- From CONNECTED to IDLE when a signal `reset` is high.
The state machine should have an output that indicates the current state in binary form (2 bits).
