Design a 4-bit SRAM cell that allows for read and write operations. The cell should have a data input (d), data output (q), a write enable (we), a read enable (re), and a clock (clk) signal. When we write to the SRAM cell (we = 1 and re = 0), the data input should be stored in the SRAM cell. When we read from the SRAM cell (re = 1 and we = 0), the stored data should be output to q.
