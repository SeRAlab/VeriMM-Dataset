Design a simple packet filtering circuit that accepts or blocks packets based on their source IP address. The circuit has a 5-bit input representing the source IP address and a control bit that allows the user to specify whether to block or accept a specific IP address. The output should be a single bit indicating whether the packet is accepted (1) or blocked (0). The circuit should accept three specific IP addresses (00001, 00010, 00011) and block all others if the control bit is set to 1; if the control bit is 0, all packets should be accepted.
