Design a circuit implementing a read-only memory (ROM) that stores a predefined message "Hello World!" along with newline and carriage return characters. The module takes a 4-bit address input and, upon a clock pulse, outputs the corresponding 8-bit character. If the address exceeds the range of stored messages, it outputs a space character. This effectively allows for sequential access to a character string, suitable in applications like display systems or serial communication.
