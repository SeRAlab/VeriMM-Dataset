Design a 4-bit SRAM cell that can store a 4-bit value and allows for read and write operations. The SRAM cell should have the following inputs: a 4-bit data input (data_in), a control signal for write (write_enable), and a control signal for read (read_enable). The output should be a 4-bit data output (data_out). When write_enable is high, the data_in should be stored in the SRAM cell. When read_enable is high, the stored value should be output to data_out.
