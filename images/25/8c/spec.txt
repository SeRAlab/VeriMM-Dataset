Design a Verilog module that takes a 16-bit TCP segment and outputs a 3-bit TCP segment type based on the following criteria:  
- If the segment length is less than or equal to 64 bytes, the type is 3'b000 (Short).  
- If the segment length is between 65 and 128 bytes, the type is 3'b001 (Medium).  
- If the segment length is greater than 128 bytes, the type is 3'b010 (Long).  
The input is a 16-bit value representing the length of the TCP segment.
