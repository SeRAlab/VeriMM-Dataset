Design a synchronous 8-bit counter with control features. The counter increments on each rising edge of the clock when the `start` signal is asserted, and counts until it reaches the specified `max_value`. Upon reaching this limit or when the `reset` signal is activated, the counter resets to zero. The output is maintained in a register that updates with the next calculated count value.
module top_module(
  output logic [7:0] count,
  input logic clk,
  input logic reset,
  input logic start,
  input logic [7:0] max_value
);
