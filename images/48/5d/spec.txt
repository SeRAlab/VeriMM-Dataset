Design a 2-to-1 multiplexer that selects between two 8-bit input signals, `pc_addr_in` and `data_addr_in`, based on the `sel` control signal. When `sel` is 0, the output `mux8_out` will reflect the value of `pc_addr_in`; when `sel` is 1, it will reflect the value of `data_addr_in`. If neither condition is met, the output defaults to 0, although this case would not typically occur with binary selection.
module top_module(
input sel,
input [7:0] pc_addr_in,data_addr_in,
output [7:0] mux8_out
);
