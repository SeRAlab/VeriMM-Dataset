Design a program counter capable of addressing a memory space of 256 locations (using 8 bits). It increments its current address output with each clock cycle unless a reset signal is active, which initializes it to zero. Additionally, if a channel signal is asserted, it updates the address to match the value present on the jump address input. The output reflects the current address held by the counter at all times.
