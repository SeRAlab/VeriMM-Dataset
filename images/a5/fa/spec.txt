Given a 4-bit shift register with serial input and parallel output:

2. New data is shifted in from the serial input (sin).
3. The parallel output is represented by a 4-bit register (pout).

Write Verilog implementing this shift register.
module shift_register (
        input clk,
        input sin,
        output reg [3:0] pout);
