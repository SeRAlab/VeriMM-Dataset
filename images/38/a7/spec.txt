
Design a 16-bit Linear Feedback Shift Register (LFSR) with an initial seed value. The LFSR should use the polynomial x^16 + x^14 + x^13 + x^11 + 1 for generating pseudo-random numbers. The LFSR should shift and feedback the values on each clock cycle, and the output should be a 16-bit value representing the current state of the LFSR.
