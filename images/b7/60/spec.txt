Design a dual-edge-triggered D flip-flop with asynchronous set and clear capabilities. The module outputs the value of D on the rising edge of the CLK signal unless the RESET_B is low, in which case it resets Q to 0. It also incorporates a feature where the output Q toggles its state when the SCD signal is asserted. The circuit allows for control of data loading or toggling through the SCE and SCD inputs, making it suitable for applications requiring precise data storage and control in synchronous digital systems.
