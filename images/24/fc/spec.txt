Design a SR-flip-flop in Verilog that has set (S), reset (R), and a clock (CLK) input. The flip-flop should have two outputs, Q and Qbar. The behavior is as follows: when S is high and R is low, Q should be set to 1. When R is high and S is low, Q should be reset to 0. If both S and R are low, Q should retain its previous value. If both S and R are high, it should be considered an invalid state, and Q should not change. Implement this SR-flip-flop along with a testbench to verify its functionality.
