

You are tasked with designing a module that acts as a 3-input OR gate. The module should have the following inputs and outputs:

Inputs:
- A (1-bit)
- B (1-bit)
- C (1-bit)
- VPB (1-bit)
- VPWR (1-bit)
- VGND (1-bit)
- VNB (1-bit)

Outputs:
- X (1-bit)

The module should be named "or3" and should be written in Verilog. The module should be self-contained and not require any additional modules to function.

Design the module to be power efficient and follow the sky130_fd_sc_hdll standard. Ensure that the module is synthesizable and can be simulated.
