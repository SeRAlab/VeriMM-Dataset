Implement a 4-bit binary to Gray code converter. The module takes a 4-bit binary input and produces a 4-bit Gray code output, where the most significant bit of the Gray code is directly taken from the binary input, and each subsequent bit is generated by XORing the corresponding bit of the binary input with the previous bit. This conversion is useful in minimizing errors during digital signal transitions.

    input [3:0] binary,
    output [3:0] gray
