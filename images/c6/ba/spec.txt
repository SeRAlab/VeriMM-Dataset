

You are tasked with designing a module that takes in a 3-bit input `a`, a 3-bit input `b`, and a 1-bit control signal `sel`. The module should output a 3-bit value `out` based on the following conditions:

- If `sel` is 0, `out` should be equal to `a`.
- If `sel` is 1, `out` should be equal to `b`.

Write a Verilog module that implements this functionality. Your module should be named `mux3` and should have the following ports:

- `input [2:0] a`: the 3-bit input `a`
- `input [2:0] b`: the 3-bit input `b`
- `input sel`: the 1-bit control signal `sel`
- `output reg [2:0] out`: the 3-bit output
