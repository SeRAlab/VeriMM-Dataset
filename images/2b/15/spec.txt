
Design a 2-channel DMA controller that can transfer data from two different sources to a common destination. The controller should have two request signals (`req1`, `req2`) to indicate when each channel wants to transfer data. The controller should have a clock input (`clk`) and a reset input (`reset`). When a request is made, the controller will grant access to one of the channels based on priority (channel 1 has higher priority than channel 2). The output should indicate which channel is granted access (`grant1`, `grant2`). After the data transfer, the channel must de-assert its request signal.
