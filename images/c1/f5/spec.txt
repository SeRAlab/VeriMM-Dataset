

You are asked to design a verilog module to implement a 4-bit magnitude comparator. The module should have two 4-bit inputs A and B, and three outputs: EQ, GT, and LT. EQ should be high if A is equal to B, GT should be high if A is greater than B, and LT should be high if A is less than B. You should implement this module using behavioral modeling (i.e., using an always block to describe the module's behavior).
