Implement a one-bit wide, 2-to-1 multiplexer. The module selects between two input signals, `data_in_0` and `data_in_1`, based on the control signal `ctrl`. When `ctrl` is low (0), the output `data_out` takes the value of `data_in_0`, and when `ctrl` is high (1), it outputs `data_in_1`. Additionally, the module includes voltage supply signals to manage power levels across the circuit.
module top_module(
    input  data_in_0,
    input  data_in_1,
    input  ctrl,
    output data_out
);
