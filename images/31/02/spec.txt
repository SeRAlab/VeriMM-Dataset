
Design a 7-stage pipeline processor that performs the following operations:
1. Fetch (IF)
2. Decode (ID)
3. Execute (EX)
4. Memory Access (MEM)
5. Write Back (WB)
6. Forwarding (FW)
7. Hazard Detection (HD)

The processor should accept a 32-bit instruction input and a 5-bit register address for write-back purposes. It should output the status of the pipeline stages, including the current instruction at each stage.
