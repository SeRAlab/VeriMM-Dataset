
Design a Verilog module that computes a simple checksum for a 5-bit input data. The checksum is defined as the XOR of all input bits. The module should have a clock input and a reset input. On every rising edge of the clock, if reset is not asserted, the module should compute the checksum and store it in an output register. The module should also have an output signal that indicates when the checksum has been updated.
