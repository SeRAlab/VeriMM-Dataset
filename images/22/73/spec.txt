Design a GPIO controller that allows for reading and writing to a GPIO pin. The controller should have two main control signals: `write_enable` and `read_enable`. The `write_enable` signal allows the user to set the GPIO pin to a certain value when high, while the `read_enable` signal allows the user to read the value of the GPIO pin. The output of the read operation should be available on a separate output signal `gpio_out`. There should also be a clock signal for synchronizing the operations.
