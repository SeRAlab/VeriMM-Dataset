Design a 5-word by 4-bit RAM module that supports read and write operations. The module features two read ports, specified by addr1 and addr2, which output the contents of the selected memory locations as content1 and content2. Data can be written to the memory using the addw address when the enable signal (en) is asserted high on the rising edge of the clock (clk).
module top_module(input clk,en,input[4:0] addr1,addr2,addw, input [3:0]data, output[3:0] content1,content2);
