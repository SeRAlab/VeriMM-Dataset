Declare a register prev_edge to keep track of the previous state of the edge_in signal.
Inside an always block, sensitive to the positive edge of the clk signal and the negative edge of the rst_n signal, implement the logic for edge detection and output generation.
In the reset condition (~rst_n), set the prev_edge register to 0 and set the edge_out output to 0, indicating no edge. Continue the detection process by comparing the current state of edge_in with the previous state. If a rising edge is detected, set edge_out to 1 for one cycle.
