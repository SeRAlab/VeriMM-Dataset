Design a 4-bit Carry Lookahead Adder (CLA) that efficiently calculates the carry-out signals for a 4-bit binary addition. Inputs consist of generate (g) and propagate (p) signals for each bit and a carry input (c). The module outputs the overall propagate (P), generate (G), and the carry outputs (C0 to C3) that indicate the carry generated at each bit position based on the given inputs. This structure enhances performance by allowing faster carry generation compared to ripple-carry adders, making it suitable for high-speed arithmetic operations.
module top_module(
    input[3:0] g,
    input[3:0] p,
    input c,
    output P,
    output G,
    output C3,
    output C2,
    output C1,
    output C0
    );
