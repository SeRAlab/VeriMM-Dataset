Implement a Verilog module based on the following description. Design an 8-bit parallel in serial out (PISO) shift register with a synchronous load signal. When the load signal is high, the data input is loaded into the register; otherwise, the register shifts right by one bit on each positive clock edge.

module piso_shift_register (
	input clk,
	input reset,
	input load,
	input [7:0] data_in,
	output reg data_out
);
