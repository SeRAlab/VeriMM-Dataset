Design an 8-bit SRAM cell with read and write capabilities. The SRAM should have the following specifications:
- 8 data bits (D[7:0])
- 1 write enable signal (WE)
- 1 read enable signal (RE)
- 8 output bits (Q[7:0]) that reflect the stored data when read is enabled
- The SRAM cell should store data when the write enable signal is high and maintain the data when the write enable signal is low. When the read enable signal is high, the stored data should be available on the output.
