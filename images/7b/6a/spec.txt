Implement the Verilog module based on the following description.
Create an 8-bit shift register that shifts left on each clock cycle when the shift signal is high. The register loads a parallel input when the load signal is high. It resets to zero when the reset signal is high.

// Signals are defined as below:
// (1) clk: The clock signal.
// (2) reset: Resets the register to zero. Active high.
// (3) load: Loads parallel input data when high.
// (4) shift: Enables shifting when high.
// (5) data_in: The 8-bit parallel input data.
// (6) q: The 8-bit output of the shift register.
module shift_register(
    input clk,
    input reset,
    input load,
    input shift,
    input [7:0] data_in,
    output reg [7:0] q);
