Design an 8-bit DRAM cell that can store a single byte of data. The DRAM cell should have the following functionality: when a write enable signal (we) is high, the data input (data_in) should be written into the memory cell. When the write enable signal is low, the data output (data_out) should output the stored value in the memory cell. The cell should also have a reset signal (reset) that clears the stored data when asserted.
