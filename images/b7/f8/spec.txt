Design a 4-to-1 multiplexer that selects one of four 4-bit wide inputs (in0, in1, in2, in3) based on the values of two selection signals (sel0 and sel1). The selected input is output as a 4-bit value through the output (out) based on the binary encoding of the selection signals. Specifically, when sel1 and sel0 are both low, in0 is chosen; when sel0 is high and sel1 is low, in1 is selected; when sel1 is low and sel0 is high, in2 is output; and when both selection signals are high, in3 is routed to the output.
module top_module(
  input [3:0] in0,
  input [3:0] in1,
  input [3:0] in2,
  input [3:0] in3,
  input sel0,
  input sel1,
  output reg [3:0] out
);
