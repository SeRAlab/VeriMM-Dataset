The module takes a 16-bit input value and a 16-bit mask value and allows for operations including AND, OR, XOR, left shift, and right shift, determined by a 3-bit operation selector. The output reflects the result of the selected operation between the input and mask values or shifting of the input, with a default behavior of passing the input unchanged if an invalid operation is selected.
module top_module(
    input [15:0] in_value,
    input [15:0] mask_value,
    input [3:0] shift_value,
    input [2:0] op_select,

);
