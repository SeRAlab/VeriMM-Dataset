Design a simple timer circuit that counts up from zero to a specified target value. The timer is activated by a start signal, and it increments its count on each rising edge of a clock, provided that a reset signal is not asserted. When the count reaches the specified target, it outputs a done signal indicating completion. The timer can handle a count width of up to 32 bits and is designed to operate at a clock frequency of 50 MHz.
