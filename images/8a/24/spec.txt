Design a 4-to-1 multiplexer that selects one of four one-bit data inputs (d0, d1, d2, d3) based on two select lines (sel1, sel2). The output 'out' will reflect the value of the selected input based on the combination of the select lines: when sel1 and sel2 are both 0, out equals d0; when sel1 is 0 and sel2 is 1, out equals d1; when sel1 is 1 and sel2 is 0, out equals d2; and when both sel1 and sel2 are 1, out equals d3.
module top_module(
  input sel1,
  input sel2,
  input d0,
  input d1,
  input d2,
  input d3,
  output reg out
);
