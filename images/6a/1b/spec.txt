Design a 4-bit binary counter with synchronous reset and enable controls. On the rising edge of the clock, when the reset signal (rst) is high, the counter resets to zero. If the reset is low and the enable signal (en) is high, the counter increments its value. The current count value is also output to a 4-bit wide register representing LEDs, allowing for visual representation of the count.
module top_module(
    input clk,
    input rst,
    input en,
    output reg [3:0] count,
    output reg [3:0] leds
);
