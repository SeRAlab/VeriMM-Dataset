
Design a 4-bit DRAM cell that can store a single 4-bit value. The cell should have inputs for data (4 bits), a write enable signal (we), and a read enable signal (re). When write enable is high, the data should be stored in the cell. When read enable is high, the stored data should be output. The circuit should also have an asynchronous reset input (reset) that clears the stored data.
