Design a 5-to-1 multiplexer that selects one of five 32-bit input signals based on a 3-bit select signal (S). The module chooses from the inputs Q, EX_MEM, MEM_WB, res_hi, and res_lo, outputting the selected input on the signal Y. When S is 000, it outputs Q; when S is 001, it outputs EX_MEM; when S is 010, it outputs MEM_WB; when S is 100, it outputs res_hi; and when S is 101, it outputs res_lo.
