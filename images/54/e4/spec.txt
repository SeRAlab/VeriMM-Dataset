Design a circuit that performs a conditional XOR operation based on a clock signal and a toggle input. When the reset signal is asserted, the output is set to LOW. On each rising edge of the clock, if the toggle input is HIGH, the circuit computes the XOR of the two input signals (in1 and in2) and updates the output accordingly. If toggle is LOW, the output retains its previous value.
module top_module(
   input clk,
   input reset,
   input toggle,
   input in1,
   input in2,
   output reg out
);
