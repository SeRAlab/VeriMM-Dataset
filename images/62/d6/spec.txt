Design a 4-bit up/down counter that modifies its count based on two control inputs: `updown` and `inc`. When `reset` is asserted, the counter is initialized to zero. If `updown` is high, the counter increments (with the choice of incrementing by either 1 or 2 based on the `inc` signal); if `updown` is low, the counter decrements similarly. This allows for flexible control of the counting direction and step size.
module top_module(
input updown,
input inc,
input clk,
input reset,
output reg [3:0] Q
);
