
Design a 4-bit SRAM cell that can store a 4-bit word. The SRAM cell should have the following inputs and outputs:
- Inputs: 
  - `address` (2-bit): Address input to select one of the four SRAM cells.
  - `data_in` (4-bit): Data input to be written into the selected SRAM cell.
  - `write_enable` (1-bit): Control signal to enable writing to the SRAM cell.
  - `clock` (1-bit): Clock signal for synchronous operation.
- Outputs:
  - `data_out` (4-bit): Data output from the selected SRAM cell.
The SRAM should be able to store and retrieve values based on the address and the write_enable signal.
