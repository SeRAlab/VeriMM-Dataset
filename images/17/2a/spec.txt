
Create a Verilog module that simulates a simple Bluetooth state machine. The Bluetooth module should have the following states: IDLE, CONNECTING, CONNECTED, DISCONNECTING. It should respond to the following inputs: 
- `start` (start connection), 
- `connect` (if the connection is successful), 
- `disconnect` (to disconnect). 
The state transitions should be as follows:
1. IDLE -> CONNECTING on `start`
2. CONNECTING -> CONNECTED on `connect`
3. CONNECTED -> DISCONNECTING on `disconnect`
4. DISCONNECTING -> IDLE
