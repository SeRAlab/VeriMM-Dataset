
Design a 2x2 matrix inversion module in Verilog. The module should take a 2x2 matrix as input and output its inverse. The formula for the inverse of a 2x2 matrix is given by:

If A = | a  b |
        | c  d |

Then, the inverse A^-1 is calculated as:

A^-1 = (1/det(A)) * | d  -b |
                   | -c  a |

where det(A) = ad - bc. If the determinant is zero, the output should indicate that the matrix is not invertible (can use a predefined value such as `0` for all elements in the output).
