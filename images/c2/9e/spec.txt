

You are tasked with designing a module that takes in six inputs and outputs one signal. The module should be named `six_to_one`.

The six inputs are:
- `in0`: a single-bit input signal
- `in1`: a single-bit input signal
- `in2`: a single-bit input signal
- `in3`: a single-bit input signal
- `in4`: a single-bit input signal
- `in5`: a single-bit input signal

The output signal is named `out` and should be a single-bit signal.

The module should implement the following logic:
- If `in0` is 1, `out` should be 1.
- If `in0` is 0 and `in1` is 1, `out` should be 1.
- If `in0` and `in1` are 0 and `in2` is 1, `out` should be 1.
- If `in0`, `in1`, and `in2` are 0 and `in3` is 1, `out` should be 1.
- If `in0`, `in1`, `in2`, and `in3` are 0 and `in4` is 1, `out` should be 1.
- If `in0`, `in1`, `in2`, `in3`, and `in4` are 0 and `in5` is 1, `out` should be 1.
- If all inputs are 0, `out` should be 0.

You should implement this module within 200 lines of verilog code.
