Design an 8-bit DRAM cell that can store a value and can be read from and written to. The DRAM cell should have a write enable signal (WE), a read enable signal (RE), an 8-bit data input (D), an 8-bit data output (Q), and an address input (A) that selects the cell to be accessed. The cell should be able to hold the value written to it until it is read or overwritten.
