Design a data storage module capable of temporarily holding a 32-bit input value. On a rising clock edge, the module updates its stored data with new input when valid, or resets to zero if a reset signal is received. The module outputs the stored value and indicates its validity through the `out_valid` signal, which is asserted when new data is stored and de-asserted when the output is accessed. This design serves as a simple buffer or register for handling data input in synchronous digital systems.
module top_module(
    input clk,
    input reset,
    input [31:0] in_data,
    input in_valid,
    output reg [31:0] out_data,
    output reg out_valid
);
