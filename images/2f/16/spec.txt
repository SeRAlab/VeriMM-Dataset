Design a fan speed control system that has three speed settings: low, medium, and high. The speed setting is controlled by a 2-bit input (00: low, 01: medium, 10: high). The system should also have an enable signal. When the enable signal is high, the system should set the fan speed accordingly; when low, the fan should stop. The output should be a 2-bit representation of the fan speed. When the enable signal is low, the output should be 00 regardless of the speed setting.
