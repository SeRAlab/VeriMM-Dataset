Design a GPIO controller that allows for reading and writing to a set of GPIO pins. The controller should have a 5-bit input for the data to be written to the GPIO pins and a 5-bit output for reading data from the GPIO pins. Additionally, there should be a control signal to trigger the read and write operations. When the write control signal is asserted, the input data should be written to the output. When the read control signal is asserted, the output should reflect the state of the GPIO pins.
