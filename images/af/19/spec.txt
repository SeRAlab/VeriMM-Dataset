Design a 4-to-1 multiplexer using a conditional operator. The module takes a 4-bit input `data_in` and a 2-bit `select` signal to determine which of the four inputs to route to the output. Based on the value of `select`, the corresponding bit from `data_in` (data_in[0] through data_in[3]) is assigned to the output `data_out`.
module top_module(
  input [3:0] data_in,
  input [1:0] select,
  output reg data_out
);
