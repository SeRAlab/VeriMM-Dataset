
Design a Verilog module that implements a simple Support Vector Machine (SVM) classifier with 2D input data. The module should have three inputs: two 8-bit signed integers (representing the 2D data points) and a 1-bit enable signal. The output should be a 1-bit signal indicating the class (0 or 1) of the data point based on a defined hyperplane. The hyperplane can be represented by weights and a bias term. For simplicity, let the weights be fixed values (W1 = 1, W2 = -1) and the bias be 0. The classifier should work as follows: if (W1 * x1 + W2 * x2 + bias) > 0, then output class 1; otherwise, output class 0.
