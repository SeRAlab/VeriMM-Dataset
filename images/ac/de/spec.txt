Implement a binary to Gray code converter for 3-bit wide input. The module takes a 3-bit binary number (BIN) and outputs its equivalent 3-bit Gray code (GRAY). The conversion is done by using XOR operations: the least significant bit of the Gray code is generated by XORing the first two bits of the binary input, the second Gray code bit is the result of XORing the second and third binary bits, and the most significant Gray code bit is taken directly from the most significant binary bit.
module top_module(
    input [2:0] BIN,
    output [2:0] GRAY
);
