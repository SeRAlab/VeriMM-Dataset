Design a Serial-In Serial-Out (SISO) shift register of 5 bits. The shift register should have a serial input 'SI', a clock input 'CLK', and a reset input 'RST'. On each rising edge of the clock, the current value of 'SI' should be shifted into the register, and the output 'SO' should reflect the value of the register from the most significant bit (MSB) to the least significant bit (LSB). When 'RST' is asserted, the register should be cleared to 0.
