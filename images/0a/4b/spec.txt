
Design a 4-channel DMA controller that allows data transfer between memory and four peripheral devices. The controller should have the following inputs:
- start: A signal that initiates the data transfer when high.
- channel_select: A 2-bit signal that selects one of the four channels (00, 01, 10, 11).
- mem_address: A 16-bit address for the memory location.
- peripheral_data: A 16-bit data input from the peripheral device.

The output should be:
- mem_out: A 16-bit data output to the memory.
- done: A signal that indicates when the data transfer is complete.

The controller should transfer data from the selected peripheral device to memory when 'start' is asserted and signal 'done' when finished.
