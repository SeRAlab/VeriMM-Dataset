Design a 4-bit DRAM cell that can store a 4-bit value. The cell should be able to read and write data. It has a write enable signal (we), a read enable signal (re), a 4-bit input (data_in), a 4-bit output (data_out), and a clock signal (clk). On the rising edge of the clock, if write enable (we) is high, the input data (data_in) should be stored in the cell. If read enable (re) is high, the stored data should be sent to the output (data_out).
