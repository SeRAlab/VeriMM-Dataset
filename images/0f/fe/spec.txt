Design a simple SATA controller state machine that manages the IDLE, READ, and WRITE states. The controller should transition between these states based on input signals: a start signal to initiate a READ or WRITE operation, and a done signal to indicate the completion of the operation. The state transitions should be as follows: 
- From IDLE, on start signal, transition to READ if the READ command is issued, or to WRITE if the WRITE command is issued.
- From READ or WRITE, on done signal, transition back to IDLE.
