Design a four-way data selector that determines the output based on the two control signals, scd and sce. The module has a clock input and a single data input. The operation is as follows: when both control signals are LOW, the output is set to LOW (0); when scd is HIGH and sce is LOW, the output follows the data input; when scd is LOW and sce is HIGH, the output is the inverse of the data input; and when both control signals are HIGH, the output is set to HIGH (1). If none of the conditions are met, the output is undefined (1'bx).

    clk,
    data_in,
    scd,
    sce,
