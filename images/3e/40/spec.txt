Design an 8-bit Digital-to-Analog Converter (DAC) that takes an 8-bit binary input and produces a corresponding analog output in the range of 0 to 5 volts. The output voltage should be represented by a 10-bit value, where each step corresponds to (5V / 256) = 0.01953125 volts. The DAC should be combinational logic based, meaning that the output should change immediately in response to the input change without any delays.
