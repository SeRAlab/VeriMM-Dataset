Design a 2-bit binary counter that operates on a clock signal. On a negative edge of the reset signal, both output bits (Q1 and Q0) are initialized to zero. On each positive edge of the clock, the counter toggles the least significant bit (Q0) while the most significant bit (Q1) follows the state of Q0, resulting in a binary counting sequence. This counter outputs the current count value as two separate bits, enabling easier integration into larger digital systems.

    input clk,
    input rst,
    output reg Q1,
