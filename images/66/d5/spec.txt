Design a clock gating module with an enabled D flip-flop that toggles its output based on a clock signal and specific enable conditions. The module controls when the clock signal is passed through depending on the status of the enable (EN) and test enable (TE) signals; both must be active for the gated clock to be generated. When enabled, the flip-flop toggles its output (ENCLK) on each rising edge of the gated clock, effectively reducing power consumption by allowing the clock to be gated off when not needed.
module top_module(
  input CLK,
  input EN,
  input TE,
  output ENCLK
);
