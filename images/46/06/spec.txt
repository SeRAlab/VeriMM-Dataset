Design a counter that increments an 8-bit value on each rising edge of a clock (iCLK) when the control signal (lap) is high. If the lap signal is low, the counter resets the stored value to zero. The current count is reflected in the output (giatri), which is an 8-bit wide output representing the counter's state.
module top_module(input iCLK,input lap,output [7:0] giatri);
