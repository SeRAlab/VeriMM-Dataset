Implement the Verilog module based on the following description.
Given a 4-bit binary counter with a synchronous load and an asynchronous reset:

1. The counter increments on the rising edge of the clock.
2. The counter loads the input data (D) when the load input is high.
3. The counter resets to zero when the asynchronous reset (reset) is high.

Write Verilog implementing this counter.
module binary_counter (
        input clk,
        input load,
        input reset,
        input [3:0] D,
        output reg [3:0] count);
