

You have been assigned the task of designing a 4:1 multiplexer using Verilog. The multiplexer has four input bits (A, B, C, D), one output bit (Y), and two select bits (S0, S1). The output bit Y should be equal to one of the four input bits based on the value of the select bits S0 and S1 as shown in the truth table below:

```
S1  |  S0  ||  Y
-----------------
 0  |  0   ||  A
 0  |  1   ||  B
 1  |  0   ||  C
 1  |  1   ||  D
```

Design a Verilog module that implements this 4:1 multiplexer. The module should be named "mux_4to1" and should have the following ports:

- A: input bit
- B: input bit
- C: input bit
- D: input bit
- S0: select bit
- S1: select bit
- Y: output bit

Your design should be generic and should not use any specific libraries.
