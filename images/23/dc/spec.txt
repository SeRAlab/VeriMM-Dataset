
Design a simple branch predictor using a 2-bit saturating counter for a given address. The counter should predict whether a branch will be taken (1) or not taken (0). Based on the previous outcomes, the counter should be updated accordingly. The state transitions for the 2-bit counter are as follows:
- 00: Strongly not taken
- 01: Weakly not taken
- 10: Weakly taken
- 11: Strongly taken

The input will consist of branch outcomes (1 for taken, 0 for not taken) and the output should show the predicted outcomes based on the current state of the counter.
