Design a register that captures and holds a 32-bit value from the `inALUOut` input. On each rising edge of the clock signal (`clk`), if the `reset` signal is asserted, the register is cleared to zero; otherwise, it updates its stored value with the incoming `inALUOut` data. The output `outALUOut` continuously reflects the current value stored in the register.
module top_module(
	input [31:0] inALUOut,
	input reset, clk,
	output [31:0] outALUOut
    );
