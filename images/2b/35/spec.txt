
Design a 4-bit SRAM cell with read and write operations. The SRAM cell should have the following inputs: a 4-bit data input (D), a 1-bit write enable signal (WE), a 1-bit chip enable signal (CE), and a 1-bit read enable signal (RE). The output should be the 4-bit data output (Q). When WE is high, the data input should be written to the memory cell. When RE is high and WE is low, the data stored in the memory cell should be output on Q. The output Q should only change when CE is high.
