Design a 16-bit DRAM cell that can store data and be read and written to. The DRAM cell should have an input data bus (idata), a write enable signal (we), a read enable signal (re), a clock signal (clk), and a 16-bit output data bus (odata). The DRAM should store the input data when the write enable signal is high during a clock edge, and it should output the stored data when the read enable signal is high.
