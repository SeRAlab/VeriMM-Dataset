

You are tasked with designing a module that takes in 5 input signals, A1, A2, A3, B1, and B2, and outputs a single signal Y. The module should be named "five_input_module". The input signals are all single-bit signals, and the output signal is also a single-bit signal.

The module should implement the following logic:

- If A1 and A2 are both high, Y should be high.
- If A1 and A3 are both high, Y should be high.
- If B1 and B2 are both high, Y should be high.
- If none of the above conditions are met, Y should be low.

You should assume that the input signals are stable and will not change during the execution of the module.
