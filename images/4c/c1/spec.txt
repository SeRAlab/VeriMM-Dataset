Design a forwarding unit for a CPU that determines the necessary data forwarding paths to resolve potential data hazards in a pipeline. The module takes in enable signals and destination registers from both the execution (exe) and memory (mem) stages, as well as source registers from the current instruction. It outputs two 2-bit values, `forward1` and `forward2`, indicating whether to forward data from the memory or execution stage for each source register. If the corresponding source register matches the destination register from either of the preceding stages and the respective enable signals are active, the appropriate forwarding paths are selected, helping to avoid stalls in the pipeline.
