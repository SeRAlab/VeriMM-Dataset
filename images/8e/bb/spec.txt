Design a 32-bit wide, 2-to-1 multiplexer with a clock input. The output will reflect one of the two 32-bit inputs (first or second) based on the value of the select signal at each positive clock edge. When select is 0, the output is assigned to first; when select is 1, the output is assigned to second.
module top_module(input clk, 
						input select, 
						input [31:0] first, 
						input [31:0] second, 
						output reg [31:0] out);
