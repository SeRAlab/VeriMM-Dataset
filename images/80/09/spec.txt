Implement the Verilog module based on the following description.
A digital stopwatch that counts seconds up to 99 seconds and displays the count on a 7-segment display. The stopwatch can be started, stopped, and reset using three control signals: start, stop, and reset. The display should be updated every second.

Variables:
1. clk (input)
2. start (input)
3. stop (input)
4. reset (input)
5. seg0 (output, 7-segment display for units place)
6. seg1 (output, 7-segment display for tens place)

module stopwatch (
    input clk,
    input start,
    input stop,
    input reset,
    output reg [6:0] seg0,
    output reg [6:0] seg1);
