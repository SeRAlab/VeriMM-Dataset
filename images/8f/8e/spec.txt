Design a synchronous 8-bit calculator that performs various arithmetic and logical operations based on a 3-bit operation code (op) input. The calculator takes two 8-bit inputs (a and b) and, on each rising edge of the clock signal (clk), computes the result (res) using the specified operation: addition, subtraction, bitwise AND, bitwise OR, bitwise XOR, NAND, NOR, or XNOR, depending on the value of op. The resulting output is updated accordingly, enabling basic mathematical and logical manipulations in a digital design context.
module top_module(
  input clk,
  input [7:0] a,
  input [7:0] b,
  input [2:0] op,
  output reg [7:0] res
);
