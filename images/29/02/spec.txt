Design a simple Direct Memory Access (DMA) controller that transfers data from a source address to a destination address in memory. The controller should have the following inputs: a clock signal (clk), a reset signal (rst), a start signal (start), a source address (src_addr), a destination address (dest_addr), and the data to be transferred (data_in). Upon receiving the start signal, the DMA should begin the transfer and indicate completion with a done signal. The controller should also support basic status flags: busy and error.
