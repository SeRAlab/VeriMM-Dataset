
Design an interrupt controller that can handle multiple interrupt requests. The controller should have the following features:
1. It should accept up to 4 interrupt requests (IRQ0 to IRQ3).
2. It should have a priority encoder to determine which interrupt has the highest priority and should be serviced.
3. The controller should generate an interrupt acknowledge signal (INT_ACK) when an interrupt is being serviced.
4. It should have a reset signal to clear the current interrupt state.
5. The module should output the index of the highest priority interrupt being serviced.
