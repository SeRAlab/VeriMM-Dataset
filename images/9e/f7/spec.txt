Implement a Verilog module for an 8-bit shift register with parallel load and right shift. The shift register should have a clock input `clk`, a load input `load`, an 8-bit data input `D`, and an 8-bit output `Q`. When `load` is high, `Q` should be set to `D`. Otherwise, `Q` should shift right by one bit on each rising edge of `clk`.

module shift_register(
	input wire clk,
	input wire load,
	input wire [7:0] D,
	output reg [7:0] Q
);
