Design a Verilog module that takes a 5-bit binary input representing a WiFi signal strength (0 to 31) and outputs a 3-bit binary indicator for the signal quality. The output should map the signal strength to the following quality levels: 000 for low quality (0-10), 001 for medium quality (11-20), and 010 for high quality (21-31). If the input is greater than 31, the output should be set to 111 as an error indicator.
