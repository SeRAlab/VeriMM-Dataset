
Design a 5-stage pipelined processor that performs a simple arithmetic operation (e.g., addition) on two 8-bit inputs. The architecture should include the following pipeline stages: Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). The processor should support a simple instruction format and register file. The outputs after the Write Back stage should be the result of the addition operation.
