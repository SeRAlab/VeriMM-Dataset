Implement a Verilog module for a 4-bit barrel shifter with synchronous reset. The shifter should perform circular shifts based on a control signal. If reset is high, the register should reset to zero.
module barrel_shifter(
    input clk,
    input reset,
    input [1:0] shift_amount,  // Shift amount
    input [3:0] data_in,
    output reg [3:0] data_out);
