Design a 4-bit Arithmetic Logic Unit (ALU) that performs various operations based on a 2-bit control signal. The ALU can execute addition, subtraction, bitwise AND, and bitwise OR on two 4-bit inputs, A and B. The result of the selected operation is provided as a 4-bit output, while an additional carry output indicates the carry status for addition and subtraction operations. The operation performed is determined by the control inputs: '00' for addition, '01' for subtraction, '10' for AND, and '11' for OR.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input [1:0] control,
  output reg [3:0] result,  // Changed output to reg type
  output carry_out
);
