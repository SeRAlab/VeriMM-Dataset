Design a 4-to-1 multiplexer that selects one of four input signals based on a 2-bit selection input. The module outputs the selected input signal on the output line `out`. When `sel` is `00`, it outputs `in[0]`; when `01`, it outputs `in[1]`; when `10`, it outputs `in[2]`; and when `11`, it outputs `in[3]`. Additionally, the module includes power and ground pins indicative of a design suitable for integration within larger digital systems.
module top_module(
    input  [3:0] in,
    input  [1:0] sel,
    output reg out,
    input  VPB ,
    input  VPWR,
    input  VGND,
    input  VNB
);
