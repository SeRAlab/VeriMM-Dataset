If u = 1, v = 1, w = 1, x = 0, then trigger = 1.
If u = 0, v = 1, w = 0, x = 1, then trigger = 0.
If u = 1, v = 0, w = 1, x = 0, then trigger = 1.
If u = 0, v = 0, w = 0, x = 1, then trigger = 1.
If u = 1, v = 1, w = 0, x = 1, then trigger = 0.
If u = 0, v = 0, w = 1, x = 1, then trigger = 1.
If u = 1, v = 0, w = 1, x = 1, then trigger = 0.
If u = 0, v = 1, w = 0, x = 0, then trigger = 1.
If u = 1, v = 1, w = 1, x = 1, then trigger = 0.
If u = 0, v = 0, w = 1, x = 0, then trigger = 0.
