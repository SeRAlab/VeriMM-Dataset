
Design a temperature sensor interface that converts a 5-bit binary input representing the temperature in degrees Celsius into a 3-bit binary output representing a specific range:
- 000 for 0-10°C
- 001 for 11-20°C
- 010 for 21-30°C
- 011 for 31-40°C
- 100 for 41-50°C
- 101 for over 50°C
If the input exceeds 50°C, the output should be 101. If the input is invalid (greater than 63), the output should remain unchanged from the previous valid input.
