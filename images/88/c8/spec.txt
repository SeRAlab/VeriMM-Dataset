Design an n-bit wide accumulator circuit. It takes an n-bit input, accumulates the value over clock cycles, and resets to zero when the reset signal is active. The output is a single-bit representation of the accumulated value, which updates on the rising edge of the clock, adding the input value to the current output. This design effectively implements a simple stateful storage element capable of summing input values over time.
module top_module(
  input [n-1:0] in,
  input clk,
  input reset,
  output reg out
);
