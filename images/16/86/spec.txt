Design a JK latch using Verilog. The JK latch should have inputs J, K, and a clock signal CLK. The output should have two states: Q and Q_not. The latch should toggle its state based on the input conditions: if J=1 and K=0, output Q should be set to 1; if J=0 and K=1, output Q should be reset to 0; if J=1 and K=1, output Q should toggle on each clock edge.
