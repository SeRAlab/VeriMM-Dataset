Implement a 32-bit wide barrel shifter capable of left or right shifting based on the input control signal. When the `shift_right` signal is high, the module will perform a right shift of the input `data` using the specified amount in `shift`. Conversely, when `shift_right` is low, it will perform a left shift. The output is the shifted value of the input data, making it suitable for applications such as arithmetic operations or data alignment tasks.
module top_module(
    input [31:0] data,
    input [4:0] shift,
    input shift_right,
    output reg [31:0] shifted_data
);
