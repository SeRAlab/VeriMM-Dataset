

You are tasked with designing a module that takes in four input signals and outputs one signal. The module should be named "signal_converter". The input signals are A1_N, A2_N, B1, and B2. The output signal is X. 

The module should have the following functionality:
- If A1_N and A2_N are both low (0), X should be set to B1.
- If A1_N is low (0) and A2_N is high (1), X should be set to B2.
- If A1_N is high (1) and A2_N is low (0), X should be set to the inverse of B1.
- If A1_N and A2_N are both high (1), X should be set to the inverse of B2.

Assume that the input signals are all 1-bit signals. You can use any gates, primitives, or other modules from the sky130_fd_sc_lp library to implement the module.
