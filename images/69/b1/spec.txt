Design a 4-bit arithmetic and logic unit (ALU) that performs a variety of operations based on a 3-bit operation code (op_code). The ALU is capable of performing addition, subtraction, multiplication, and basic logical operations (AND, OR, XOR). It features a clock input for synchronization and a reset input to initialize the outputs to zero. The carry output indicates overflow conditions for addition and multiplication, while remaining zero for logical operations. This module is intended for integration into larger digital systems requiring arithmetic and logical computations.
module top_module(
  input clk,
  input reset,
  input [3:0] op_code,
  input [3:0] in1,
  input [3:0] in2,
  output reg [3:0] out,
  output reg carry
);
