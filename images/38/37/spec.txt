Design a JK latch in Verilog. The latch should have inputs J, K, and a clock signal, and outputs Q and Qn. The latch should update its state on the rising edge of the clock according to the following truth table:  
If J = 0 and K = 0, Q remains unchanged.  
If J = 0 and K = 1, Q resets to 0.  
If J = 1 and K = 0, Q sets to 1.  
If J = 1 and K = 1, Q toggles.
