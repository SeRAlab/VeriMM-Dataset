
Design a simple OFDM symbol generator in Verilog. The circuit will take a 4-bit input representing a data symbol and generate a corresponding 8-bit output representing the OFDM symbol. The mapping from 4-bit input to 8-bit output will be defined as follows:
- Input: 0000 -> Output: 00000000
- Input: 0001 -> Output: 00000001
- Input: 0010 -> Output: 00000010
- Input: 0011 -> Output: 00000011
- Input: 0100 -> Output: 00000100
- Input: 0101 -> Output: 00000101
- Input: 0110 -> Output: 00000110
- Input: 0111 -> Output: 00000111
- Input: 1000 -> Output: 00001000
- Input: 1001 -> Output: 00001001
- Input: 1010 -> Output: 00001010
- Input: 1011 -> Output: 00001011
- Input: 1100 -> Output: 00001100
- Input: 1101 -> Output: 00001101
- Input: 1110 -> Output: 00001110
- Input: 1111 -> Output: 00001111
The symbol generation should occur on the rising edge of a clock signal.
