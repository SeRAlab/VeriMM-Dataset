
Design a simple 4-bit EEPROM cell that can store a value and be read. The EEPROM cell should have a write enable signal (`we`), an input data bus (`data_in`), an output data bus (`data_out`), and a clock signal (`clk`). When `we` is high, the value on `data_in` should be stored in the cell; when `we` is low, the stored value should be available on `data_out`.
