Design a Verilog module for a Flash memory cell type that can store a single bit of data. The module should have inputs for data (`data_in`), a write enable signal (`we`), and a clock signal (`clk`). On the rising edge of the clock, if `we` is high, the module should store `data_in`. If `we` is low, the stored data should remain unchanged. The module should also provide an output (`data_out`) that reflects the stored value.
