Design a program counter (PC) module that updates its output value based on the clock and control signals. The PC outputs a 16-bit address that can be reset to zero when a reset signal (rst_n) is asserted. It also handles an enabling condition for updating the output—when both the halt (hlt) signal and stall signal are low, it loads the new program counter value from the input (pc_input); otherwise, it retains its current value. This module is essential for managing instruction addresses in a processor.
module top_module(clk, rst_n, hlt, pc_input, pc_output, stall);
