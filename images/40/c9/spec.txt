Design a digital phase shifter that takes a 3-bit input and produces a 3-bit output that represents the phase-shifted value. The phase shift should be defined as follows: if the input value is 0, output 1; if the input value is 1, output 2; if the input value is 2, output 3; if the input value is 3, output 4; if the input value is 4, output 5; if the input value is 5, output 6; if the input value is 6, output 7; if the input value is 7, output 0.
