

You are tasked with designing a module that performs a bitwise AND operation between two 8-bit inputs, `A` and `B`, and outputs the result as an 8-bit value, `Z`. The module should be named `bitwise_and`.

The module should have the following inputs and outputs:
- `input [7:0] A`: the first 8-bit input
- `input [7:0] B`: the second 8-bit input
- `output [7:0] Z`: the 8-bit output

The module should perform the following operations:
- For each bit position, perform a bitwise AND operation between the corresponding bits in `A` and `B`.
- Assign the result to the corresponding bit in `Z`.

You should implement the module within 200 lines of Verilog code.
