
Design a 4-depth FIFO (First-In-First-Out) queue with the following specifications:
- The FIFO has a 4-bit data width.
- It has an input for data (`data_in`), a write enable (`wr_en`), a read enable (`rd_en`), and a full/empty flag.
- The FIFO should have signals to indicate if it is full and if it is empty. 
- Implement the write and read functionalities such that when data is written, it goes into the queue, and when read, the oldest data is removed from the queue.
