Design a 4-to-1 multiplexer that selects one of four input signals (in0, in1, in2, in3), each of width defined by the parameter WIDTH. The selection is controlled by two select lines (sel0 and sel1), where the selected input is forwarded to the output (out) based on the binary combination of these select signals.
module top_module(
    input [WIDTH-1:0] in0,
    input [WIDTH-1:0] in1,
    input [WIDTH-1:0] in2,
    input [WIDTH-1:0] in3,
    input sel0,
    input sel1,
    output reg [WIDTH-1:0] out
);
