Design an SR flip-flop using Verilog. The flip-flop should have two inputs, S (set) and R (reset), and two outputs, Q and Q_bar. The behavior should be defined as follows: 
- When S = 1 and R = 0, Q should be set to 1.
- When S = 0 and R = 1, Q should be reset to 0.
- When S = 0 and R = 0, Q should hold its previous state.
- When S = 1 and R = 1, the state is considered invalid (you can choose to set Q to 0 or 1, but it should maintain its previous state for the sake of this problem).
