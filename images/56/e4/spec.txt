Design a 4-bit up counter that increments on each positive clock edge. The counter resets to zero when the reset signal is activated. Additionally, the module includes a wrap-around output signal that indicates when the counter has reached its maximum value (15 in decimal or F in hexadecimal), allowing a designer to implement functionality dependent on this overflow behavior.
module top_module(
    input wire clk,
    input wire reset,
    output reg [3:0] count,
    output reg wrap_around
);
