

You are tasked with designing a module that implements a D flip-flop with asynchronous reset. The module should have four inputs: `D` for the data input, `CLK` for the clock signal, `RESET` for the asynchronous reset signal, and `EN` for the enable signal. The module should have one output, `Q`, which is the output of the flip-flop.

The flip-flop should be triggered on the rising edge of the clock signal. When the enable signal is high, the flip-flop should store the value of the data input. When the reset signal is asserted, the flip-flop should be reset asynchronously to 0.

Write a verilog code for the module that implements the D flip-flop with asynchronous reset as described above.
