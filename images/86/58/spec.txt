Design a 32-bit comparator circuit that provides three output signals: 'eq' (equal), 'gt' (greater than), and 'lt' (less than) based on the comparison of two 32-bit input values, val1 and val2. The 'eq' output will be high when the inputs are equal, the 'gt' output will indicate if val1 is greater than val2, and the 'lt' output will signal if val1 is less than val2.
module top_module(
  input [31:0] val1,
  input [31:0] val2,
  output eq,
  output gt,
  output lt
);
