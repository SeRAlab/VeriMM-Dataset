Design a 2-to-4 decoder circuit. The module takes two binary inputs, A and B, and produces four outputs (Y0, Y1, Y2, Y3), where each output corresponds to one of the possible combinations of the inputs. Specifically, Y0 is active when both inputs are LOW, Y1 is active when A is LOW and B is HIGH, Y2 is active when A is HIGH and B is LOW, and Y3 is active when both inputs are HIGH.
module top_module(
  input A,
  input B,
  output Y0,
  output Y1,
  output Y2,
  output Y3
);
