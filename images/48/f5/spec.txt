Design a circuit that implements three separate 16-bit wide adder functionalities. For each input signal (a, b, c), the module produces an output by adding the input to a respective register initialized to zero (ra, rb, rc). This allows the outputs a_out, b_out, and c_out to represent the sum of each input with its corresponding register value, facilitating the processing of three independent 16-bit addition operations simultaneously.
module top_module(
    input [15:0] a,
    input [15:0] b,
    input [15:0] c,
    output reg [15:0] a_out,
    output reg [15:0] b_out,
    output reg [15:0] c_out
);
