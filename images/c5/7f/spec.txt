

You are tasked with designing a verilog module to implement a 2:1 multiplexer with an enable signal. The module should have three inputs: `in0`, `in1`, and `en`. When `en` is high, the output of the module should be equal to `in1`. When `en` is low, the output of the module should be equal to `in0`. You are to implement this module using a conditional operator.

Write a verilog module that implements this 2:1 multiplexer with an enable signal using a conditional operator. The module should have the following interface:

```
module mux_2_1_en(
    input in0,
    input in1,
    input en,
    output reg out
);
```

You may assume that the inputs `in0` and `in1` are 1-bit wide and that the input `en` is also 1-bit wide.
