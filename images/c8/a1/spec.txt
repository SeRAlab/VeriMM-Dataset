

You are tasked with designing a verilog module for a 2:1 multiplexer. The module should have two input ports `A` and `B`, one select port `S`, and one output port `Y`. When `S` is 0, `Y` should be equal to `A`. When `S` is 1, `Y` should be equal to `B`.

Please use the following template to design the module:
```
module mux_2_1 (
    // Input ports
    input A,
    input B,
    input S,

    // Output port
    output Y
);

    // Your code here

endmodule
```
