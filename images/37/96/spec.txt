Design a 4-bit SRAM cell that can read and write data. The SRAM should have the following inputs: a 4-bit data input (`data_in`), a write enable signal (`we`), a clock signal (`clk`), and a 2-bit address input (`addr`). The output should be a 4-bit data output (`data_out`) that reflects the content of the SRAM cell at the given address. The SRAM will consist of 4 memory cells, and each cell can store a 4-bit value. When `we` is high, the input data should be written to the specified address on the rising edge of the clock. When `we` is low, the data at the specified address should be outputted on `data_out`.
