Design a read/write memory module that functions as a RAM with configurable depth and width. The module features two read addresses (ra1 and ra2) and one write address (wa), controlled by the write enable signal (we). On the rising clock edge, if we is asserted, the data input (di) is stored in the location specified by wa. Simultaneously, the outputs do1 and do2 provide the stored data from the addresses ra1 and ra2, respectively. This design is suitable for applications requiring flexible memory access in digital systems.
module top_module(
                      clk,
                      we,
                      wa, 
                      ra1, 
                      ra2, 
                      di, 
                      do1, 
                      do2);
