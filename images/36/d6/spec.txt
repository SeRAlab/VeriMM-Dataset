Design a GPIO controller that allows for reading and writing to a set of GPIO pins. The controller should have the following features: a 4-bit input for the GPIO pin number, a 1-bit input for the read/write operation (1 for write, 0 for read), and a 1-bit input for the data to write (only applicable when writing). The output should be a 1-bit data read from the specified GPIO pin when reading. The controller should have a clock input and reset input to synchronize operations. On reset, all GPIO pins should be set to low (0). Implement the functionality to maintain the state of the GPIO pins in an array.
