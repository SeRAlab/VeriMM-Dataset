

You are tasked with designing a verilog module for a pipelined multiplier that takes two 8-bit unsigned numbers as inputs and produces a 16-bit unsigned result. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock signal
- `rst`: a synchronous active-high reset signal
- `a`: an 8-bit unsigned number
- `b`: an 8-bit unsigned number

Outputs:
- `result`: a 16-bit unsigned number

The multiplier should use the standard shift-and-add algorithm, with the following requirements:
- The multiplication should be pipelined, with a latency of one clock cycle
- The module should use unsigned arithmetic
- The module should handle overflow and wraparound correctly
- The module should be designed to be synthesizable and meet timing requirements

Design the verilog module for the pipelined multiplier.
