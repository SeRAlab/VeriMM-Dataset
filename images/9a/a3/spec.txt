Design a combinational logic circuit that outputs a HIGH signal (1) based on certain conditions of its inputs. The output X is set to HIGH if any of the following conditions are met: all four inputs A, B, C, and D are HIGH, or all four inputs E, F, G, and H are HIGH, or both inputs I and J are HIGH. Otherwise, the output X remains LOW (0).
module top_module(
    input A,
    input B,
    input C,
    input D,
    input E,
    input F,
    input G,
    input H,
    input I,
    input J,
    output reg X
);
