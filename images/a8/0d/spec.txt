Design a Pulse Width Modulation (PWM) generator that produces a PWM signal based on a specified duty cycle. The module takes a clock input and an n-bit wide duty cycle value as inputs. It counts clock cycles and sets the output high until the counter reaches the duty cycle value, after which the output will go low. This process repeats, allowing the width of the high output pulse to be adjusted based on the duty cycle input, effectively modulating the power delivered to a load based on the specified duty cycle.
module top_module(
  input clk,
  input [n-1:0] duty_cycle,
  output pwm_out
);
