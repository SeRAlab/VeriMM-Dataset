Design a 32x8-bit Block RAM (BRAM) with synchronous read and write capabilities. The module utilizes a clock signal to synchronize data operations, allowing data to be written into or read from the memory based on the `write_enable` signal. When `write_enable` is high, the data provided on `datain` is stored at the specified `address`. Conversely, when `write_enable` is low, the data from the specified `address` is output on `dataout`. The memory is initialized to zero on startup.
module top_module(input wire sysclock,input wire [4:0] address,input wire [7:0] datain,output reg [7:0] dataout,input wire write_enable);
