
Design a simple matrix factorization module that takes a 2x2 input matrix and outputs two matrices (1x2 and 2x1) such that their product approximates the original matrix. The input matrix is represented as four separate inputs (a, b, c, d) for elements (a, b) and (c, d). The output matrices will be represented as output elements (e1, e2) for the first row and (f1, f2) for the first column.
