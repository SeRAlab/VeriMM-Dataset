Design a resettable D flip-flop with active-low reset functionality. The flip-flop captures the value of the D input on the rising edge of the CLK signal while being held in a reset state when RESET_B is low. When RESET_B is high, the flip-flop operates normally, storing the D input value and providing its output Q and complementary output Q_N. Thus, it ensures that Q outputs a low state when reset and a high state on unreset, with Q_N being the inverse.
module top_module(
    input CLK,
    input D,
    input RESET_B,
    output Q,
    output Q_N
);
