
Design a 4-bit SRAM cell in Verilog. The SRAM cell should have a data input (D), a data output (Q), a write enable (WE), and a read enable (RE). When WE is high, the input data should be written into the SRAM cell. When RE is high, the output should reflect the stored data. If both WE and RE are low, the cell should maintain its current state.
