Design a circuit for handling interrupt requests in a microcontroller system. This module monitors an external interrupt signal (IRQ) and an interrupt enable signal (IEN_d) to determine when to branch to an interrupt service routine. It maintains a return address (return_adr) to store the current program counter (PC) when an interrupt occurs and enables branching to either a fixed interrupt address or back to the return address when returning from the interrupt (using the RTI_d signal). The module outputs a control signal (branch_ISR) to signal when an interrupt should be processed, and it appropriately sets the interrupt service routine address (ISR_adr) based on the interrupt context.
