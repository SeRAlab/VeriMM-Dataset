
Create a Verilog module that performs a basic 3x3 convolution operation on a 2D input image. The input image will be a 3x3 matrix with 8-bit pixel values, and the convolution kernel will also be a 3x3 matrix with 8-bit values. The output should be a single 8-bit value representing the result of the convolution. The convolution operation will sum the products of the overlapping elements of the input and the kernel.
