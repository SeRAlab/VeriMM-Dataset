Design a synchronous two-input AND gate with reset functionality. The module takes two inputs, A and B, and produces an output X that reflects the logical AND of A and B on the rising edge of the clock (clk). If the reset signal is activated, the output X is set to LOW (0). Otherwise, it updates X with the result of A AND B.

    input A,
    input B,
    input clk,
    input reset,
