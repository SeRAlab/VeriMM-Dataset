Design a simple memory allocator with a fixed-size block allocation. The system should allow allocation and deallocation of memory blocks of a predetermined size. It should support a maximum of N blocks, where N is defined as a parameter. The allocator will store the status (allocated or free) of each block and provide the following functionality:
1. `malloc`: Allocate a block of memory if available.
2. `free`: Deallocate a previously allocated block.
3. `status`: Return the status of all blocks.
The memory blocks will be indexed from 0 to N-1. The output of the memory status should show which blocks are allocated and which are free.
