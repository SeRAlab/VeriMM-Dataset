Implement a Verilog module for an 8-bit register with synchronous reset and enable. When reset is asserted, the output q should be 0. The register should store the input d on the rising edge of clk if enable is asserted.
module reg8_en (
    input clk,
    input reset,
    input enable,
    input [7:0] d,
    output reg [7:0] q);
