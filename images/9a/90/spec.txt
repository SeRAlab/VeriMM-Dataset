Design a pipelined register module that captures and propagates input data through a series of stages controlled by clock, reset, enable, and squash signals. The module has configurable width and depth, allowing it to hold multiple registers in a pipeline fashion, where each register can be individually enabled or squashed. On each clock cycle, if not reset and if enabled, the current data is loaded into the first register; otherwise, it takes the data from the previous stage, enabling seamless data flow through the pipeline. When the squash signal is active, the associated register is reset to a predefined value.
