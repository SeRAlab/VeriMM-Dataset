Design a FIFO queue that can store 4 bits of data. The FIFO should have a write enable signal (`wr_en`), a read enable signal (`rd_en`), and a clock signal (`clk`). The queue should store data when `wr_en` is high, and output data on the `rd_en` signal. The system should be able to handle overflow and underflow conditions. The output should indicate when the FIFO is full or empty.
