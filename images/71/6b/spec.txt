Implement the Verilog module based on the following description. Design a finite state machine to control a traffic light system for a single road intersection. The traffic light has three states: Green, Yellow, and Red. The system cycles through these states in the order: Green -> Yellow -> Red -> Green. Each state lasts for a specific duration: Green (5 clock cycles), Yellow (2 clock cycles), and Red (3 clock cycles). Use an asynchronous reset (areset) that sets the light to Red.
