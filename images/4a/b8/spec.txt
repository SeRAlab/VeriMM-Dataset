Design a synchronous accumulator circuit with a configurable bit-width (defaulting to 8 bits). It accumulates the incoming data signal `in` on each rising edge of the clock `clk`, while also allowing for a reset functionality. When the `rst` signal is high, the accumulator resets to zero; otherwise, it continuously adds the input to its stored sum. The output `out` reflects either the accumulated sum or zero, depending on the state of the reset signal.
module top_module(
  input clk,
  input rst,
  input [n-1:0] in,
  output reg [n-1:0] out
);
