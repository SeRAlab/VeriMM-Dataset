Design a Verilog module for an 8-bit wide, 256-word deep RAM with synchronous read and write operations. The RAM reads data on the positive clock edge when read_enable is high and writes data when write_enable is high.
module ram_256x8 (
    input clk,
    input read_enable,
    input write_enable,
    input [7:0] write_data,
    input [7:0] addr,
    output [7:0] read_data );
