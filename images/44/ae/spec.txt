Implement an 8-bit register that holds the value of the `exponent` input. On the positive edge of the `clk`, if the `clear` signal is asserted, the register resets to zero. If the `load` signal is asserted, the register captures and stores the value from the `exponent` input.
module top_module(
    input [7:0]exponent,
    input clk, clear, load,
    output reg [7:0]saved_exp
    );
