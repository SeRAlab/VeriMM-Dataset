Design a 4-to-1 multiplexer that selects one of four 8-bit input data lines (a, b, c, or d) based on the 2-bit selection signal (sel). The output (out) delivers the 8-bit value from the chosen input, where sel=00 selects input a, sel=01 selects input b, sel=10 selects input c, and sel=11 selects input d. The implementation uses a combinational logic block to determine the output based on the value of sel.
module top_module(
  input [7:0] a,
  input [7:0] b,
  input [7:0] c,
  input [7:0] d,
  input [1:0] sel,
  output reg [7:0] out
);
