Create a 4-bit shift register with the following specifications: The shift register should have an input for a 4-bit data, a clock input, and a reset input. On the rising edge of the clock, if the reset is active, the output should reset to '0000'. Otherwise, the input data should be shifted into the register, and the previous data should shift left. The least significant bit (LSB) should be filled with '0'. If no new data is provided, the register should hold its value.
