Design a fan speed controller that adjusts the speed of a fan based on temperature input. The controller will have the following behavior: If the temperature is below 20 degrees Celsius, the fan speed will be set to 0 (OFF). If the temperature is between 20 and 30 degrees, the fan speed will be set to 1 (LOW). If the temperature is between 30 and 40 degrees, the fan speed will be set to 2 (MEDIUM). If the temperature is above 40 degrees, the fan speed will be set to 3 (HIGH). The design should include a clock signal and a reset signal.
