Design a 4-bit synchronous flip-flop with an asynchronous reset. On the rising edge of the CLK signal, if the asynchronous reset (AR) is asserted, the output Q is set to zero (4'b0000). Otherwise, Q takes the value of the input D, effectively capturing and holding the 4-bit data input on each clock cycle.

  input [3:0] D,
  input CLK,
  input AR,
  output reg [3:0] Q
