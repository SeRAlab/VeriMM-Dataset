
Create a Verilog module that implements a simple Dynamic Voltage and Frequency Scaling (DVFS) controller. The module should take an input signal representing the desired performance level (from 0 to 3) and adjust the output voltage and frequency accordingly using a state machine. The frequency and voltage values for each performance level are as follows:
- Level 0: Voltage = 0.5V, Frequency = 100MHz
- Level 1: Voltage = 0.8V, Frequency = 200MHz
- Level 2: Voltage = 1.0V, Frequency = 300MHz
- Level 3: Voltage = 1.2V, Frequency = 400MHz
The module should also have a reset input to return to level 0.
