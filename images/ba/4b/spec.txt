Design a 4x4 register file with the ability to store 16 words of 8 bits each. The module includes capabilities for reset and write operations, controlled by a clock signal. On a negative edge of the reset signal, all registers in the array are cleared to zero. When the write signal is asserted (WR), data is written to the specified address (ADDR_W) in the register array (data) from the input data (DATA_W). The output provides the concatenated contents of all 16 registers, allowing for easy observation of stored data.
module top_module(CLK, RSTn, WR, ADDR_W, DATA_W, data_out);
