It incorporates basic gates such as inverters, AND gates, and an OR gate to facilitate the selection logic for data routing, ensuring that only one input is forwarded to the output at any time. The multiplexer also includes a buffer for signal integrity at the output.

    input [3:0] data, // 4-bit input signals

    output reg out    // 1-bit output signal
