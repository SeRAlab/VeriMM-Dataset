Design a clock divider circuit that takes an input clock signal (CLK) and produces a divided output clock signal (CLK_div). This module uses a 4-bit counter to count clock cycles. On every rising edge of the input clock, if the reset signal is asserted, the counter and output clock are reset to zero. When the counter reaches a value of 4, it resets and toggles the output clock signal, effectively dividing the input clock frequency by 4.
module top_module(
    input CLK,
    input reset,
    output reg CLK_div
);
