Design a 3-to-1 multiplexer that selects one of three 1-bit inputs (in0, in1, in2) based on a 3-bit selection signal (sel). The output (out) is updated on the rising edge of the clock (clk). If the reset signal is asserted, the output is set to LOW. If reset is not asserted, the selected input according to the sel signal is assigned to the output; if sel is not one of the specified values, the output defaults to LOW.
module top_module(
    reset,
    clk,
    sel,
    in0,
    in1,
    in2,
    out);
