Design a Verilog module that performs LU decomposition on a 2x2 matrix. The input will be a 4-bit wide matrix represented as a 4-bit vector (A, B, C, D) where:
```
| A B |
| C D |
```
The output will be two 4-bit vectors representing the lower triangular matrix L and the upper triangular matrix U:
```
L = | 1 0 |
    | x 1 |

U = | y z |
    | 0 w |
```
The values of x, y, z, and w should be computed based on the input matrix. Ensure proper handling of zero or near-zero values in the input to avoid division by zero issues during the computation.
