

You are tasked with designing a Verilog module for a 4-bit binary to Gray code converter. The module should have a 4-bit input (A) and a 4-bit output (G). The output should be the Gray code equivalent of the input binary. 

Gray code is a binary numeral system where two successive values differ in only one bit. For example, the 4-bit binary number 0101 has a Gray code equivalent of 0111. The conversion from binary to Gray code is done by XORing each bit of the binary number with the bit to its right. The leftmost bit of the Gray code is the same as the leftmost bit of the binary number.

Your module should have the following interface:

```
module binary_to_gray(
  input [3:0] A,
  output [3:0] G
);
```

You should only use one module within 200 lines of Verilog code to implement the binary to Gray code converter.
