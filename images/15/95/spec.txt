Write a Verilog module that implements a simple linear regression calculation. The module should take two inputs, `x` and `y`, and output the estimated `y` value based on the linear regression formula: `y_estimated = a * x + b`, where `a` (slope) and `b` (intercept) are constant parameters defined within the module. Use a 16-bit signed representation for `x`, `y`, `a`, and `b`.
