Design a 5-bit Johnson counter. The counter should circulate a pattern of ones and zeros through its bits on each clock cycle. The counter should reset to all zeros when the reset signal is active.

Module name:
    JohnsonCounter
Input ports:
    clk: Clock signal used for synchronous operation.
    reset: Active-high reset signal.

Output ports:
    count: 5-bit output representing the current count value.
