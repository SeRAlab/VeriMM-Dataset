

You are tasked with designing a Verilog module to implement a logic circuit. The circuit should take in 5 inputs: A1, A2, B1, B2, and C1. The circuit should output a single value X. 

The circuit should be implemented within a module named "logic_circuit". You are not allowed to use any pre-defined Verilog modules, and the entire circuit should be implemented within a single module that is no longer than 200 lines of code.

The logic circuit should be implemented as follows:
- The output X should be the result of a logical OR operation between the following:
  - A logical AND operation between B1 and B2
  - A logical AND operation between A1 and A2
  - The input C1

Your task is to implement the "logic_circuit" module in Verilog that satisfies the above requirements. Your module should be able to compile without any errors or warnings.
