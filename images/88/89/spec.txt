Design a one-bit full adder circuit that computes the sum of two binary inputs (Op_A_i and Op_B_i) along with a carry input (C_i). The module outputs the sum (S_o), the carry output (C_o), and the propagate signal (P_o). The propagate signal indicates if either of the inputs can propagate a carry, while the carry output reflects whether a carry has occurred as a result of the operation.
module top_module(
    input wire Op_A_i,
    input wire Op_B_i,
    input wire C_i, 
    output wire S_o, 
    output wire C_o, 
    output wire P_o 
    );
