Design a 3-bit linear feedback shift register (LFSR) random number generator. The circuit produces a pseudo-random output based on the initial seed and feedback logic derived from the output bits. When enabled, the output is updated on every rising edge of the clock, utilizing linear feedback based on a combination of the current output bits and the seed. The output can be reset to zero when the reset signal is asserted.
module top_module(
	output [2:0] out             ,  
	input enable          ,  
	input clk             ,  
	input reset,            
	input [2:0] seed
);
