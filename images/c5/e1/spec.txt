

You are tasked with designing a Verilog module that implements a D-latch with an enable gate. The module should have the following inputs and outputs:

- Input `D`: data input
- Input `GATE`: enable gate input
- Output `Q`: output
- Output `Q_N`: negated output

The module should have the following behavior:

- When `GATE` is high, the output `Q` should follow the input `D`.
- When `GATE` is low, the output `Q` should hold its previous value.
- The output `Q_N` should be the logical negation of `Q`.

You should implement the module using no more than 200 lines of Verilog code.
