Design a Verilog module that implements a 4-bit binary up-down counter. The module should have a clock input, a reset input, an up/down control input, and a 4-bit output. The counter should increment when the up/down control is high and decrement when it is low, and reset to 0 when the reset signal is high.

module counter4bit_ud (
    input clk,
    input rst,
    input up_down,
    output reg [3:0] count
);
