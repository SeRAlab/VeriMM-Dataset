Design a 4-to-1 multiplexer with a single output. The output X selects one of the four inputs (A0, A1, A2, A3) based on the values of the two select lines (S0 and S1). When S1 and S0 are both 1, A3 is output; with S1 as 0 and S0 as 1, A2 is selected; if S1 is 1 and S0 is 0, A1 is chosen; and when both S1 and S0 are 0, A0 is output.
module top_module(
    output X,
    input A0,
    input A1,
    input A2,
    input A3,
    input S0,
    input S1
);
