

You are tasked with designing a clock gate module that takes in a clock signal, an enable signal, and a test enable signal, and outputs a gated clock signal. The module should only allow the clock signal to pass through when both the enable signal and test enable signal are high. 

Design a Verilog module called `clock_gate` that has the following input and output ports:
- `clk`: a single-bit input representing the clock signal
- `en`: a single-bit input representing the enable signal
- `te`: a single-bit input representing the test enable signal
- `en_clk`: a single-bit output representing the gated clock signal

The module should implement the following functionality:
- When `en` and `te` are both high, `en_clk` should output the value of `clk`.
- When either `en` or `te` is low, `en_clk` should output a logic low value.

Ensure that your module only contains combinational logic and no sequential logic.
