Implement a Verilog module for an 8-bit register with enable and synchronous set. The register should have a clock input `clk`, a synchronous set input `set`, an enable input `en`, an 8-bit data input `D`, and an 8-bit output `Q`. When `set` is high, `Q` should be set to all 1s on the next rising edge of `clk`. When `en` is high, `Q` should be set to `D` on the rising edge of `clk`.

module register8(
	input wire clk,
	input wire set,
	input wire en,
	input wire [7:0] D,
	output reg [7:0] Q
);
