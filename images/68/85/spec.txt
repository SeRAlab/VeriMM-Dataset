Design a shift register that operates on an 8-bit parallel input. When the load signal is activated, it loads the entire 8-bit value from data_parallel into the output. In the absence of the load signal, it shifts the current output data to the left by one bit and shifts in a new bit from data_in on each clock cycle.
module top_module(
  input clk,
  input load,
  input data_in,
  input [7:0] data_parallel,
  output reg [7:0] data_out
);
