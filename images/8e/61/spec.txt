Develop a three-to-one multiplexer that selects one of three input signals (a, b, or c) based on the 3-bit select input (sel). When sel is 000, output the value of a; when sel is 001, output b; when sel is 010, output c; and for any other value of sel, output a LOW signal (0).
module top_module(
    input wire a,
    input wire b,
    input wire c,
    output reg out,
    input wire[2:0] sel
);
