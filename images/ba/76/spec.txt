Design a 2-to-1 multiplexer for 32-bit wide data inputs. When the control signal MA is LOW, the output Bus_A is taken from the A_DATA input; when MA is HIGH, the output Bus_A is sourced from the PC_1 input.
module top_module(
    input MA,
    input [31:0] PC_1, A_DATA,
    output [31:0] Bus_A
    );
