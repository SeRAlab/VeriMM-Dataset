

You have been tasked with designing a module that takes two inputs A and B, and outputs their logical AND, X. You are given a code snippet for inspiration, but you must write the complete module from scratch.

Your module should have the following requirements:
- It should be named `my_and2`.
- It should have three ports: two inputs A and B, and one output X.
- It should implement the logical AND operation between A and B to produce X.
- The module should be implemented using only combinational logic, meaning no flip-flops or latches.

Your module must also meet the following additional requirements:
- It must be written in Verilog and be no more than 200 lines long.
- The module must be syntactically and semantically correct, and should not generate any errors or warnings when compiled.
- You must provide a testbench to verify the functionality of your module. The testbench should provide a set of inputs to the module and verify that the output is correct.
