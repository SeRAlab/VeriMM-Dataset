Design a 6-to-1 multiplexer that selects one of six 4-bit input values (in0 to in5) based on a 4-bit selection signal (sel). The output (mux_out) reflects the selected input corresponding to the value of sel, ranging from 0 to 5; if sel exceeds this range, mux_out defaults to 0. This module effectively routes multiple data sources to a single output line based on the selection criteria.
module top_module(
    input [3:0] sel, in0, in1, in2, in3, in4, in5,
    output reg [3:0] mux_out
);
