Design a clock generator that produces a modulated output clock signal (clk_out) based on an input clock signal (clk_in). This module generates a clock signal with a defined period (10 time units) and a duty cycle of 25%. It counts cycles to determine when to output a HIGH signal (for 2.5 time units) followed by a LOW for the remainder of the period, repeating this process until a set cycle count (1024) is reached when clk_out goes LOW and stays LOW.
module top_module(
    input wire clk_in,
    output reg clk_out
);
