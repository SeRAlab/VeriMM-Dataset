Design a D flip-flop with asynchronous reset and set functionality. The flip-flop captures the input data on the rising edge of the clock; however, it can be asynchronously reset to a LOW state when the reset input is LOW or set to a HIGH state when the set input is LOW. The output provides both the stored value (q) and its inverted value (qn).
module top_module(
  input clk,
  input rst,
  input set,
  input d,
  output reg q,   // Change from wire to reg
  output qn
);
