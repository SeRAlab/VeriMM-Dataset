Design a circuit that computes the absolute value of a 4-bit two's complement input. If the most significant bit (sign bit) of the input `a` is 1 (indicating a negative number), the circuit outputs the two's complement of `a` by inverting the bits and adding one. If the sign bit is 0, the output is simply the input value `a`.
module top_module(
    input [3:0] a,
    output reg [3:0] abs_val
);
