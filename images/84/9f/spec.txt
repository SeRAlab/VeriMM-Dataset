Design a circular shift register, specifically a 4-bit ring counter. The counter rotates its state on each positive clock edge, transferring the most significant bit back to the least significant bit position. Upon receiving a reset signal, the counter initializes to zero. The output signals represent each bit of the counter, allowing external circuitry to observe the current state of the ring counter.
module top_module(
    input clk,
    input reset,
    output reg [3:0] bit_0,
    output reg [3:0] bit_1,
    output reg [3:0] bit_2,
    output reg [3:0] bit_3
);
