
Design a 4-bit shift register with synchronous loading capability. The shift register should have an input for loading new data, a clock signal, and a reset signal. When the reset signal is high, the register should clear to 0. On the rising edge of the clock, if the load signal is high, the register should load the input data. If the load signal is low, the register should shift its content to the right, with the leftmost bit being filled with 0.
