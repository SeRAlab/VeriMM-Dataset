
Create a Direct Memory Access (DMA) controller that manages data transfers between memory and peripherals. The DMA controller should be able to initiate a transfer, read data from a source address, and write it to a destination address. The controller should have the following inputs:
- `start`: A signal to initiate the DMA transfer.
- `src_addr`: The source memory address.
- `dest_addr`: The destination memory address.
- `data`: The data to be transferred.
- `clk`: Clock signal.
- `reset`: Asynchronous reset signal.

The outputs should include:
- `busy`: A signal indicating that the DMA controller is active.
- `done`: A signal indicating that the transfer is complete.
- `read_data`: The data read from the source address.
