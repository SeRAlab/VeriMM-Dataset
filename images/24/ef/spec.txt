Design a Verilog module that takes a 16-bit input data representing a TCP segment and outputs a 4-bit segmentation type based on the following criteria: 
- If the input data is less than 512, output "0001" (indicating small segment).
- If the input data is between 512 and 1024 (inclusive), output "0010" (indicating medium segment).
- If the input data is more than 1024, output "0011" (indicating large segment).
