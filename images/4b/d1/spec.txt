Design a 32-bit Arithmetic Logic Unit (ALU) capable of performing various operations based on a 3-bit function select input (F). The ALU supports bitwise AND, OR, addition, AND with the negation of B, addition with the negation of B, subtraction, and comparison for less than. The output (Y) reflects the result of the selected operation on the two 32-bit inputs (A and B), while an additional output (Zero) indicates if the result is zero.
module top_module(	input [31:0] A, B, 
            input [2:0] F, 
				output reg [31:0] Y, output Zero);
