
Design a Verilog module that implements a bilinear interpolation for a 2D image. The module takes four pixel values (A, B, C, D) from the corners of a rectangle and two fractional coordinates (u, v) to compute the interpolated pixel value at coordinates (u, v). The pixel values are 8-bit unsigned integers, and the fractional coordinates are represented as 8-bit unsigned integers as well, with a range of 0-255. The output pixel value should also be an 8-bit unsigned integer.
