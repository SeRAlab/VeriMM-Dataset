Implement a 4-to-1 multiplexer, allowing selection among four 4-bit wide inputs (A, B, C, D) based on a 2-bit selection signal (S). The output (Y) reflects the selected input, with the chosen value being registered on the rising edge of a clock signal. This design enables dynamic input selection in synchronous applications.
module top_module(
    input wire [3:0] A,
    input wire [3:0] B,
    input wire [3:0] C,
    input wire [3:0] D,
    input wire [1:0] S,
    input wire clk, // Added clk input
    output wire [3:0] Y
);
