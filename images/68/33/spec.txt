Design a shift register-based stack memory module that operates on a 16-bit input. The module features a reset function that initializes the stack memory and the output to zero. It has a three-bit stack pointer (sp) that determines which memory location to access. On the rising edge of the clock, it stores the input data (din) to the specified memory location, and on the falling edge of the clock, it outputs the content of that same memory location (dout). This module effectively implements a simple stack memory with read and write capabilities, controlled by the clock signal.
