Implement a Verilog module for a 3-bit ring counter with asynchronous reset. The counter should have a clock input `clk`, a reset input `reset`, and a 3-bit output `Q`. When `reset` is high, `Q` should be set to 3'b001. On each rising edge of `clk`, the counter should shift left by one bit, with the most significant bit wrapping around to the least significant bit.

module ring_counter(
	input wire clk,
	input wire reset,
	output reg [2:0] Q
);
