Design a three-input logic gate that outputs a HIGH signal only when input A_N is HIGH and both inputs B and C are also HIGH. If any of A_N, B, or C are LOW, the output X will be LOW. If A_N is LOW and all others are HIGH, the output will be indeterminate (X = 'x'). The design supports standard power supply and ground connections (VPWR, VGND) as well as additional power and ground terminals (VPB, VNB), making it suitable for integration into a larger circuit.
module top_module(
    input wire A_N,
    input wire B,
    input wire C,
    input wire VPWR,
    input wire VGND,
    input wire VPB,
    input wire VNB,
    output wire X
);
