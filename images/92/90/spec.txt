Design a D flip-flop with asynchronous set and reset functionality. The flip-flop captures the input D on the rising edge of the clock signal CK. If the reset signal RST is asserted, the output Q is set to LOW. If the set signal SET is asserted, the output Q is set to HIGH regardless of CK or D. Under normal operation (when neither RST nor SET is active), the output Q will follow the input D.
module top_module(
  input SET, 
  input RST, 
  input CK, 
  input D, 
  output Q 
);
