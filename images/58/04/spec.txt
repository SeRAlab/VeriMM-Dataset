Implement a toggle flip-flop that changes the output state between HIGH and LOW on the rising edge of the clock signal, controlled by the 'toggle' input. When 'toggle' is asserted, the output 'out' is set to HIGH if it is currently LOW, or set to LOW if it is currently HIGH. The width of the output can be configured with the parameter 'WIDTH', allowing for multi-bit output toggling.
module top_module(
   input clk,
   input toggle,
   output reg [WIDTH-1:0] out
);
