Design a programmable 8-bit up/down counter that increments or decrements its count based on the direction input (DIR) when enabled (EN) and resets to zero upon a negative edge of the reset signal (RST). When EN is low, the counter maintains its current value.
module top_module(
    input CLK,
    input RST,
    input EN,
    input DIR,
    output reg [7:0] CNT
    );
