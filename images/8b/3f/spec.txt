Design a finite state machine (FSM) controller for a digital system that manages three main operations: addition, shifting, and loading of registers. The module transitions between states based on input signals and the clock. Initially, in the idle state, it waits for a start signal, at which point it loads registers and transitions to the addition state. In the addition state, it decrements a parameter and conditionally adds to the registers based on the input signal Q0 before moving to the shifting state. The shifting state performs a shift operation and transitions back to either idle or the addition state depending on input conditions involving Zero and Nothing. The outputs control loading, decrementing, adding, and shifting appropriately, along with a ready signal indicating the controller's status.
