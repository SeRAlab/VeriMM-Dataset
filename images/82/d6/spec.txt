Design a 4-bit ripple carry adder that performs the addition of two 4-bit binary numbers, A and B, along with a carry-in (Cin) on the rising edge of the clock signal. The result is a 4-bit sum output (S) and a carry-out (Cout) that indicates if there is an overflow beyond the 4-bit sum. The module also includes a synchronous reset feature that initializes the sum and carry outputs to zero when the reset signal is asserted low.
module top_module(
    input clk,
    input reset_n,
    input [3:0] A,
    input [3:0] B,
    input Cin,
    output [3:0] S,
    output Cout
);
