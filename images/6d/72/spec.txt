Implement a Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state J (T = 1).
2. state K (T = 0).
3. state L (T = 1).
4. state M (T = 0).

State transitions:
1. From state J: If c = 0, then transition to state K. If c = 1, then transition to state L.
2. From state K: If c = 0, then transition to state M. If c = 1, then transition to state J.
3. From state L: If c = 0, then transition to state M. If c = 1, then transition to state K.
4. From state M: If c = 0, then transition to state L. If c = 1, then transition to state J.

Assume that you want to Implement the FSM using two flip-flops and state codes v[1:0] = 00, 01, 10, 11 for states J, K, L, M, respectively. Implement just the next-state logic for v[1] in Verilog. The output T is v[1].
