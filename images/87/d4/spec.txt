When in state 1, the intensity increases from 0 to 6, then reverses direction until it reaches 1, at which point it resets back to the initial state. The output signal reflects the current intensity value as a 3-bit value, simulating a fading effect akin to a twinkler.

    input clk,
    input rst,
    input step,
