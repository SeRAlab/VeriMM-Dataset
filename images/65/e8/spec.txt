Design a sound control module that manages audio output based on user input from switches. It generates two 24-bit outputs, `writedata_left` and `writedata_right`, by modifying a counter on each clock cycle when `write_ready` is asserted. The output bits are determined by the state of a 4-bit switch input; each switch configuration corresponds to a specific bit of the counter. When the system is reset, the counter initializes to zero, and when `write_ready` is inactive, the writing process halts. The module is intended for applications that require sound generation or modulation based on user interaction.
