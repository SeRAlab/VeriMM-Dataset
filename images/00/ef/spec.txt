Design a 4-bit DRAM cell that allows for reading and writing data. The DRAM cell should have the following inputs: `data_in` (4 bits), `write_enable` (1 bit), `row_address` (2 bits), `column_address` (2 bits), and outputs `data_out` (4 bits). The DRAM should store the written data when `write_enable` is high and should output the stored data when `write_enable` is low. It should be able to handle multiple addresses, allowing storage in a 4x4 memory matrix.
