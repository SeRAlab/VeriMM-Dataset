Design a combinational multiplier that takes two 4-bit inputs, A and B, and produces an 8-bit output P representing their product. The module stores the inputs A and B in internal registers on the rising edge of a clock signal, calculates the product of these registers, and assigns the result to the output P. This design efficiently implements the multiplication operation using a synchronous approach.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input clk,             // Added clk input
    output reg [7:0] P
);
