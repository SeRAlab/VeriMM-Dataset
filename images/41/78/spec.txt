Design a 32-bit signed adder/subtractor circuit. The module takes two signed 32-bit inputs, A and B, and a control input C, which determines the operation mode: when C is 0, it performs addition (A + B); when C is 1, it performs subtraction (A - B). The output S provides the result, and the output V indicates overflow, signaling if the addition/subtraction resulted in an invalid signed representation due to exceeding the range of signed integers.
module top_module(
    input signed [31:0] A,
    input signed [31:0] B,
    input C,
    output signed [31:0] S,
    output V
);
