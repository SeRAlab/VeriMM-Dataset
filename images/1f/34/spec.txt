
Design an 8-bit SRAM cell with the following functionalities:
- The SRAM cell should have a single data input (D), a read enable (RE), a write enable (WE), and an 8-bit data output (Q).
- When WE is high, the value present at D should be stored into the SRAM cell.
- When RE is high, the value stored in the SRAM cell should be outputted on Q.
- Both WE and RE should not be active at the same time.
