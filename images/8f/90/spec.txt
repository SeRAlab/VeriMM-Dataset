The module accepts external inputs to set (load) specific time values and control the counting process. When enabled, the nanosecond counter increments on each clock cycle, and it resets or loads new values upon receiving specified signals. Additionally, when a pulse-per-second (pps) signal is detected, the second counter increments, also responding to loading inputs. A clear input allows for resetting both counters. This functionality supports high-precision timing applications, ensuring accurate time representation in both seconds and nanoseconds.
