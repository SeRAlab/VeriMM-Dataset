Design a 1-bit DRAM cell that can store a single bit of data. The DRAM cell should have the following inputs: a data input (D), a wordline input (WL), and a bitline output (BL). When the wordline is high, data can be written to the cell. When the wordline is low, the data stored in the cell should be available on the bitline. The cell should also have a reset function that sets the stored value to 0 when activated.
