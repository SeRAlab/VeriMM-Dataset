Design an SR latch using D flip-flops. The latch should have two inputs, S (Set) and R (Reset), and one output Q. The output Q should maintain its state until a change is induced by the inputs. Implement the reset and set functionality such that when S is high and R is low, Q should be set to 1. When S is low and R is high, Q should be reset to 0. If both inputs are low, Q should retain its previous value. If both inputs are high, it should be considered an invalid state.
