Design a RAM memory module capable of reading and writing 16-bit data words at addresses ranging from 0 to 4095. The module operates on a positive clock edge, with write enable signals allowing for selective writing of data based on the two-bit `wea` input. The `ena` signal controls the enabling of memory operations. The output `douta` continuously reflects the data read from the specified address, `addra`, making it suitable for applications that require quick access to stored data. The design utilizes a block memory generator configured for synchronous operation within a Virtex-6 FPGA family.
