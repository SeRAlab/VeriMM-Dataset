Design a D flip-flop with asynchronous reset and set inputs. The module features a clock input for triggering state changes, an active-low reset (reset_b) that clears the output (q) when asserted, and an active-low set (set_b) that sets the output to high when asserted. The flip-flop retains its last state between clock cycles unless either reset or set is activated, ensuring controlled logic state behavior in digital circuits. Power (vpwr) and ground (vgnd) connections are also established for operation.
module top_module(
    input        clk,
    input        reset_b,
    input        set_b,
    input        vpwr,
    input        vgnd,
    output reg   q
);
