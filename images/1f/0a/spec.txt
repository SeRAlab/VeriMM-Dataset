Design a Verilog module that computes a simple checksum for a given 8-bit input data. The checksum should be the sum of all bits in the input data, computed modulo 256. The module should take an 8-bit input (data) and output an 8-bit checksum. Additionally, the module should have an enable signal that, when high, allows the checksum computation to occur, otherwise the output should be held at its previous state.
