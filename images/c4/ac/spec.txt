

You are tasked with designing a module for a digital circuit that implements a D flip-flop with asynchronous reset. The module should have the following input and output ports:

- `D`: input port for the data signal
- `R`: input port for the reset signal (active low)
- `CLK`: input port for the clock signal
- `Q`: output port for the output signal

The module should implement the following behavior:

- When the reset signal `R` is asserted (low), the output `Q` should be set to 0, regardless of the value of the data input `D`.
- When the reset signal `R` is de-asserted (high), the output `Q` should follow the input `D` on the rising edge of the clock signal `CLK`.

You should implement this module using only basic logic gates (AND, OR, NOT, etc.) and no pre-built flip-flop components. Assume that the input signals are glitch-free and that the clock signal is a periodic square wave with a 50% duty cycle.
