

You are tasked with designing a verilog module that implements a T flip-flop with asynchronous set and reset inputs. The module should have the following inputs and outputs:

- `T`: input bit for toggling the output
- `S`: asynchronous set input
- `R`: asynchronous reset input
- `CLK`: clock input
- `Q`: output bit
- `QN`: complement output bit

Design the module using behavioral verilog and ensure that it has the following functionality:

- When `S` is asserted, `Q` is set to 1 and `QN` is set to 0, regardless of the value of `T`.
- When `R` is asserted, `Q` is set to 0 and `QN` is set to 1, regardless of the value of `T`.
- When `T` is asserted, the output `Q` should toggle.
