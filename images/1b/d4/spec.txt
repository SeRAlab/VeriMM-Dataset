
Design an I2C controller that can send data to a slave device. The controller should have inputs for the clock signal (clk), reset signal (reset), start signal (start), data input (data_in), and a valid signal (valid). The outputs should indicate whether the controller is busy (busy), whether the data was successfully sent (ack), and the output data (data_out). The controller should follow the I2C protocol for sending data, including generating start conditions, sending bits, and generating stop conditions.
