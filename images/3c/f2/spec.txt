Design an SR Flip-Flop using Verilog. The flip-flop should have inputs S (Set) and R (Reset), and outputs Q and Qn (not Q). The flip-flop should adhere to the following rules: if S=1 and R=0, Q should be set to 1; if S=0 and R=1, Q should be reset to 0; if S=0 and R=0, Q should hold its previous state; if S=1 and R=1, the behavior is undefined (hold previous state).
