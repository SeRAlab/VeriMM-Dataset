Design a circuit that controls the state of a motor based on a control signal. The module monitors a clock and a reset signal; when the reset signal is high, the motor state is set to LOW. On the rising edge of the clock, if the motor control signal is high, the motor state is set to HIGH; otherwise, it is set to LOW. This effectively creates a simple motor controller that toggles the motor state based on the control input.
module top_module(
    input clk,
    input rst,
    input motor_ctrl,
    output reg motor_state
);
