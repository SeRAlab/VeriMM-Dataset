

You are tasked with designing a verilog module that implements a 4-bit binary adder that adds two 4-bit inputs, A and B, and produces a 4-bit output, C. The module should have the following inputs and outputs:

Inputs:
- A (4-bit input)
- B (4-bit input)
- Cin (1-bit input)

Outputs:
- C (4-bit output)
- Cout (1-bit output)

The adder should perform the addition of A and B with the Cin input as the initial carry-in value. The output C should represent the sum of A, B, and Cin, while Cout should represent the carry-out value of the addition.

Your module should be named "four_bit_adder" and should be implemented using only basic logic gates (AND, OR, NOT, XOR, etc.) and D flip-flops.
