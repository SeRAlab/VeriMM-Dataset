

You are designing a verilog module for a simple full adder with carry in and carry out. The module should have the following inputs and outputs:

Inputs:
- A (1-bit)
- B (1-bit)
- Cin (1-bit)

Outputs:
- Sum (1-bit)
- Cout (1-bit)

The module should be named "full_adder" and should have the following behavior:
- The Sum output should be the result of adding A, B, and Cin together (A + B + Cin).
- The Cout output should be 1 if the addition of A, B, and Cin results in a carry out, and 0 otherwise.

Write the verilog code for the "full_adder" module.
