

You are tasked with designing a Verilog module that implements a D flip-flop with reset functionality. The module should have the following ports:

- `clk`: input clock signal
- `reset`: asynchronous reset signal
- `d`: input data signal
- `q`: output data signal

The module should have the following behavior:

- On the rising edge of the `clk` signal, the output `q` should take on the value of the input `d`.
- If the `reset` signal is asserted (i.e. goes from 0 to 1), the output `q` should be forced to 0 regardless of the input `d`.

You may assume that the input signals `clk` and `reset` are synchronous to each other and that the input signal `d` is synchronous to the clock signal `clk`.

Write a Verilog module that implements this behavior.
