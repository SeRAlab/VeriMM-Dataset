

You are tasked with designing a Verilog module that implements a 4-bit adder. The module should have two 4-bit inputs (`A` and `B`) and one 4-bit output (`S`). The module should also have a 1-bit input `Cin` for the carry-in bit and a 1-bit output `Cout` for the carry-out bit. The module should be named `four_bit_adder`.

You should use the following code snippet as a starting point:

```
module four_bit_adder(
  input [3:0] A,
  input [3:0] B,
  input Cin,
  output [3:0] S,
  output Cout
);

// your code here

endmodule
```
