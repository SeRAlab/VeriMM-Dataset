Design a simple Watchdog Timer in Verilog that resets a signal if it doesn't receive an input 'kick' signal within a specified timeout period. If the 'kick' signal is received, the timer should reset and start counting again. The timer can be implemented using a counter that increments on each clock cycle. If the counter reaches a specified limit, it asserts a 'reset' signal. The module should have an active-low reset, a clock input, a kick input, and an output reset signal.
