Design a JK latch using Verilog. The JK latch should have two inputs (J and K) and one output (Q). The latch should toggle its output Q based on the input conditions. If J is high and K is low, Q should set to 1. If J is low and K is high, Q should reset to 0. If both J and K are high, Q should toggle its state. The clock signal should be used to latch the output. Implement this functionality in a Verilog module.
