Design a 4-bit binary counter with reset and load capabilities. The module operates on the rising edge of a clock signal; when the reset input is all ones (4'b1111), the output resets to zero. If the load input is non-zero, the output is set to the value provided by the count input. If neither condition is met, the counter increments the output by one on each clock cycle.
module top_module(
    input wire clk,
    input wire [3:0] reset,
    input wire [3:0] load,
    input wire [3:0] count,
    output reg [3:0] out
);
