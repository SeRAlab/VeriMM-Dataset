Design a synchronous D flip-flop with asynchronous active-low set and reset functionality. On the rising edge of CLK, if RESET_B is asserted (low), the output Q is cleared to 0. If SET_B is asserted (low), Q is set to 1. Otherwise, Q captures the value of input D. Additionally, the output Q_N represents the inverse of Q, updated on each clock edge.
module top_module(
    input D,
    input CLK,
    input SET_B,
    input RESET_B,
    output reg Q,
    output reg Q_N
);
