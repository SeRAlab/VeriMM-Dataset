Design a module that implements fundamental logic gates. The module takes two single-bit inputs, `a` and `b`, and produces five outputs: `and_out` generates the logical AND of `a` and `b`, `or_out` computes the logical OR, `not_out` provides the logical NOT of `a`, `xor_out` performs the logical XOR operation, and `xnor_out` yields the logical XNOR of `a` and `b`. This module can be utilized in various digital circuit designs requiring basic combinatorial logic operations.
module top_module(
  input a,
  input b,
  output and_out,
  output or_out,
  output not_out,
  output xor_out,
  output xnor_out
);
