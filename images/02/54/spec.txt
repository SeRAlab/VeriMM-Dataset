Design an interrupt controller with the following specifications: The controller has 4 interrupt requests (IRQ0-IRQ3), a global interrupt enable (GIE), and a priority encoder. The controller should generate a single interrupt signal (INT) based on the highest priority interrupt that is enabled. The priority order is IRQ0 (highest) to IRQ3 (lowest). If the GIE is low, the INT signal should be low regardless of the IRQ states.
