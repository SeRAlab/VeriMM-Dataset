Module name:  
    up_down_counter               
Input ports:
    rst_n: Reset signal (active low)
    clk: Clock signal
    en: Signal to enable counting
    dir: Direction control signal (1 for up, 0 for down)
Output ports:
    out: 4-bit output representing the current count value

Implementation:
If the reset signal is active (!rst_n), the counter is reset to 0 by assigning the value 4'b0000 to the output register (out). If the en signal is 1, the counter increments if dir is 1, or decrements if dir is 0. The counter wraps around when it reaches the maximum or minimum value (4'b1111 or 4'b0000). If en = 0, the counter will stop, and the output register (out) remains unchanged.
