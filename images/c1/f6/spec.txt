

You are tasked with designing a verilog module that implements a 4-bit binary counter with parallel load. The module should have the following inputs and outputs:

Inputs:
- `clock`: a single bit input representing the clock signal
- `load`: a single bit input representing the load signal
- `data_in`: a 4-bit input representing the data to be loaded into the counter when `load` is high

Outputs:
- `count`: a 4-bit output representing the current count value of the counter

The counter should increment on every rising edge of the `clock` signal, unless the `load` signal is high, in which case the counter should load the value of `data_in`. The counter should wrap around to 0 when it reaches the maximum count value of 15.

Write the verilog code for the counter module.
