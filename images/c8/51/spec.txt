

You have been asked to design a verilog module that takes in two inputs, `a` and `b`, and outputs the result of a bitwise AND operation on them. The module should be named `and_module` and should have the following ports:

- `input a`: a single bit input
- `input b`: a single bit input
- `output out`: a single bit output

You must implement the AND operation using bitwise operators.

Write the `and_module` verilog code that implements these requirements.
