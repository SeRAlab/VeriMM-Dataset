Design a fan speed control system that adjusts the fan speed based on temperature readings. The system should have three fan speeds: LOW, MEDIUM, and HIGH. The temperature sensor provides a 4-bit input representing the temperature. The fan speed is set to LOW if the temperature is below 25°C (0000 to 0110 in binary), MEDIUM if the temperature is between 25°C and 50°C (0111 to 1100), and HIGH if the temperature is above 50°C (1101 to 1111). Use a state machine to control the fan speed.
