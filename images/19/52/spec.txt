Design a simple NVMe controller command decoder. The controller should take a 4-bit command input and output a corresponding 3-bit command type based on the input command as follows: 
- 0000 -> 000
- 0001 -> 001
- 0010 -> 010
- 0011 -> 011
- 0100 -> 100
- 0101 -> 101
- 0110 -> 110
- 0111 -> 111
- For any command above 0111, output should be 111 (indicating an invalid command).
