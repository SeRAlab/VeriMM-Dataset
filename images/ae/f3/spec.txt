Design a 4-to-1 multiplexer that selects between four input signals (A, B, C, and D) based on a 2-bit select input (S). The output (Y) will reflect one of the selected input signals: when S=00, output A; when S=01, output B; when S=10, output C; and when S=11, output D. The implementation includes inverting the select lines, using AND gates to isolate the chosen input based on the select values, and an OR gate to produce the final output.
module top_module(
    input  A,
    input  B,
    input  C,
    input  D,
    input  [1:0] S,
    output Y
);
