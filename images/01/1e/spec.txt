
Design a 4-bit CORDIC processor that computes the sine and cosine of a given angle in radians. The angle will be provided as a 4-bit binary number representing the angle multiplied by a scale factor (e.g., 16) to allow for fractional values. The processor should have a clock and reset input, and the output should be the sine and cosine values as 4-bit binary numbers. The CORDIC iterations should be performed in a sequential manner, updating the sine and cosine values at each clock cycle until a specified number of iterations is reached.
