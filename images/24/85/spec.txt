Implement a 4-bit MD5-like hash function that takes a 4-bit input and produces a 4-bit output. The output is computed by performing a simple XOR operation on the input bits and a fixed constant value. The constant value is 4'b1010. The hash function should have a clock and a reset signal. On each clock cycle, if reset is not asserted, the output should be updated with the XOR of the current input and the constant value.
