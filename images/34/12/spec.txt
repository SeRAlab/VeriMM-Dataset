
Design a 16-bit SRAM cell with read and write capabilities. The SRAM should have the following inputs:
- `data_in`: 16-bit data input for writing to the SRAM.
- `addr`: 4-bit address input to select which cell to read from or write to.
- `we`: write enable signal (1 to write, 0 to read).
- `clk`: clock signal for synchronous operation.
The output should be `data_out`, which is the data read from the selected SRAM cell.
