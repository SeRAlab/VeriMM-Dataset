
You are tasked with designing a module `r_FAULT_STATUS_MASK` that takes in a reset signal, a write enable signal (`wenb`), input data (`in_data`), and a clock signal. The module should output an 8-bit register `reg_0x15`. 

The module should behave as follows:
- When reset is high, `reg_0x15` should be cleared to 0x00.
- When reset is low and `wenb` is low, `reg_0x15` should be updated with the value of `in_data`.
- When reset is low and `wenb` is high, `reg_0x15` should remain unchanged.

Design a Verilog module that implements the above behavior. Your solution should include a module declaration and the necessary Verilog code to implement the functionality described above.
