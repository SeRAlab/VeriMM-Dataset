Design a circuit that generates a parity bit for incoming data, intended for error detection. The module takes a clock signal, a data input, and a reset signal. Upon receiving a reset signal, the parity bit and internal state are initialized to zero. On each clock cycle, if not in reset, the module captures the data input and computes the parity by performing an XOR operation on the data bit, updating the output parity accordingly. The output indicates the evenness or oddness of the captured data input.
module top_module(
  input clk,
  input data,
  input reset,
  output reg parity
);
