

You are tasked with designing a module that takes in a 4-bit input and outputs a 4-bit output. The output should be the same as the input, but with each bit inverted (i.e. 0 becomes 1 and 1 becomes 0). You are only allowed to use one module, and your code should be no more than 200 lines of Verilog.

Create a module called `Inverter` with the following inputs and outputs:
- `input [3:0] input_data`: a 4-bit input
- `output [3:0] output_data`: a 4-bit output

Your module should perform the following operation:
- Invert each bit of the input_data to create the output_data.

You should assume that the input_data will be valid and that the output_data should be updated whenever the input_data changes.
