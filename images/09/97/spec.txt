Design a simplified OFDM modulator in Verilog that takes a stream of binary data and converts it into an OFDM symbol. The OFDM modulator should include the following functionalities: 1) Input binary data of size 8 bits (representing a sub-carrier), 2) A simple IFFT operation to transform the input data into the time domain (this can be simplified), 3) The output should be a 16-bit resultant OFDM symbol. The design should handle the cases of valid and invalid inputs, where valid inputs are in the range of 0-255.
