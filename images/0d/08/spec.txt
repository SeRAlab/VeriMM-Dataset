
Design a 16-bit SRAM cell. The SRAM cell has an input data line (16 bits), a write enable signal (1 bit), and a read enable signal (1 bit). When the write enable signal is high, the input data should be stored in the SRAM cell. When the read enable signal is high, the stored data should be outputted. The SRAM cell should have a reset functionality that clears the stored data when the reset signal is asserted.
