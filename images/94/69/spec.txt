Design a D flip-flop with asynchronous reset and enable functionality. The flip-flop captures the input 'data' on the rising edge of the clock signal when the 'enable' signal is high. If the 'reset' signal is asserted, the output 'out' is immediately set to LOW, irrespective of the clock or enable conditions. This design is useful for synchronizing data in digital circuits while providing flexibility through reset and enable controls.
module top_module(
  input clk,
  input reset,
  input enable,
  input data,
  output reg out
);
