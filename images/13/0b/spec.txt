Design an 8-bit DRAM cell which can store, write, and read data. The cell should have the following inputs: a 3-bit address (addr), an 8-bit data input (data_in), a write enable signal (we), and a read enable signal (re). The output should be an 8-bit data output (data_out). When write enable is high, the data input should be written to the specified address. When read enable is high, the data from the specified address should be output. In the case of both signals being high simultaneously, the priority should be given to writing data over reading it.
