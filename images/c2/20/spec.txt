

You are tasked with designing a Verilog module that implements a 4-to-1 multiplexer using only basic logic gates (AND, OR, NOT). The module should have four 32-bit input ports (A, B, C, D) and a 2-bit select port (S). The output should be the selected input, based on the value of the select port: if S=00, output A; if S=01, output B; if S=10, output C; if S=11, output D.

Your module should be named "mux_4to1" and should not use any pre-existing Verilog libraries or modules. You may use any temporary variables or internal signals that you require.

Ensure that your module is completely self-contained and works correctly for all possible input combinations.
