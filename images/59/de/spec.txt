Design a 32-bit binary counter that increments its value on each rising edge of the clock when enabled (count_en). The counter resets to zero when the reset signal (rst) is asserted. Additionally, it has a maximum counting limit defined by the input count_max; once the counter reaches this limit while counting enabled, it rolls over back to zero.
module top_module(
    input clk,
    input rst,
    input count_en,
    input [31:0] count_max,
    output reg [31:0] count
);
