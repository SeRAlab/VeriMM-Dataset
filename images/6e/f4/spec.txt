Design a 4-bit up counter with a configurable modulus. The counter increments its value on each positive edge of the clock signal, and when the reset signal is asserted, it resets the count to zero. Additionally, when the count reaches the specified modulus value, it wraps around and resets to zero, enabling a counting cycle that can be adjusted based on the modulus input.
module top_module(
  input clk,
  input reset,
  input [3:0] modulus,
  output reg [3:0] count
);
