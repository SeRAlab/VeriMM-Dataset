Implement a Parallel-in Serial-out (PISO) shift register with the following specifications: The PISO register should have a data input (D) of 5 bits, a clock input (CLK), a load input (LOAD), and a serial output (Q). When LOAD is high, the data from D should be loaded into the shift register. On every rising edge of CLK, if LOAD is low, the register should shift to the right, outputting the least significant bit to Q until all bits have been shifted out.
