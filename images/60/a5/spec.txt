Design a 3-bit shift register that can load a single bit input A into all three output bits (Q2, Q1, Q0) when the load signal is high. On the rising edge of the clock, if not loading, the register shifts its contents to the right, with the current input A being placed into the least significant bit (Q0) and the contents of Q1 and Q2 shifting to Q0 and Q1 respectively.
module top_module(
    input A,
    input load,
    input clk,
    output reg Q2,
    output reg Q1,
    output reg Q0
);
