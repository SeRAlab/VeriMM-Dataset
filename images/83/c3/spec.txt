Create a Verilog module called 'shift_register' that implements a 8-bit shift register with parallel load. It should have an input 'clk', an input 'load', an input 'data[7:0]', and an output 'q[7:0]'. When 'load' is high, 'data' is loaded into the register; otherwise, the register shifts to the right by one bit on each clock cycle.
