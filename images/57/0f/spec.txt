Design a 4-to-1 multiplexer that selects one of four 4-bit inputs (in1, in2, in3, in4) based on the values of two select signals (sel1 and sel2). The output (out_always) will reflect the selected 4-bit input according to the combination of the select signals: when sel1 and sel2 are both 0, output in1; when sel1 is 0 and sel2 is 1, output in2; when sel1 is 1 and sel2 is 0, output in3; and when both are 1, output in4.
module top_module(
    input [3:0] in1,
    input [3:0] in2,
    input [3:0] in3,
    input [3:0] in4,
    input sel1,
    input sel2,
    output reg [3:0] out_always
);
