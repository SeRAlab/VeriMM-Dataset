
Design a 4-bit SRAM cell that allows for reading and writing data. The SRAM cell should have the following inputs and outputs:
- Inputs: 
  - clk (clock signal),
  - we (write enable signal),
  - data_in (4-bit input data),
  - addr (2-bit address input to select the SRAM cell).
- Outputs:
  - data_out (4-bit output data).
When `we` is high, the data from `data_in` should be written to the memory location specified by `addr`. When `we` is low, the data from the memory location specified by `addr` should be output on `data_out`.
