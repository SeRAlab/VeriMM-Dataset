Design a fixed-priority arbiter that selects one of the multiple request signals based on a predefined priority. The arbiter should have 4 request inputs (req[3:0]) and one output grant (grant). The highest priority request (req[3] has the highest priority and req[0] has the lowest) should be granted. If multiple requests are high, the one with the highest priority should be granted. If no requests are made, the grant signal should remain low.
