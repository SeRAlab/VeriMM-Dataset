Design a JK flip-flop circuit with asynchronous reset functionality. The flip-flop has inputs for J and K, a clock control (CP), and a reset signal. When the reset signal is active high, it sets the output (y) to low and the inverted output (ybar) to high. On the negative edge of the clock signal, the outputs are updated based on the values of J and K: when J is high and the current state is low, the output is set high; when K is high and the output is high, the output is set low; otherwise, the output retains its previous state.
module top_module(
    input j,k,CP,reset,
    output reg y,ybar
    );
