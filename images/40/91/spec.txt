
Design a simple UART transmitter module. The transmitter should receive an 8-bit data input and a start signal. Once the start signal is asserted, the module should transmit the data serially, starting with a start bit (0), followed by the 8 data bits, and ending with a stop bit (1). The baud rate is determined by a clock signal. The module should also have a ready signal that asserts high when the transmission is complete.
