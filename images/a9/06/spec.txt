Design a circuit that implements a 4-input logical OR gate with active-low inputs for C and D. The output X will be high if at least one of the inputs A or B is high, while the low active signals C_N and D_N must also be considered—when C and D are not asserted (active-low), they will influence the output as well. This module is designed to interface with power and ground connections, suitable for a specific technology library (sky130_fd_sc_ms).
module top_module(
    output X,
    input  A,
    input  B,
    input  C_N,
    input  D_N,
    input  VPWR,
    input  VGND,
    input  VPB,
    input  VNB
);
