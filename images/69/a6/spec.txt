Design an 8-bit Gray code counter that increments its count in Gray code sequence on the rising edge of the clock while being resettable and enabled. The module has inputs for enable, clock, and reset signals. When reset is asserted, the counter initializes to 0 and sets a flag for even/odd parity tracking. Upon enabling, the counter toggles the least significant bit of the Gray code output, ensuring that only one bit changes at any given time, adhering to the Gray code characteristic. The output is provided through the `gray_count` signal.
