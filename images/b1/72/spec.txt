Design a 6-bit shift register with load capability. When the LOAD signal is asserted, the register is initialized with the same value as the input D across all six bits. On each rising edge of the clock signal (CLK), if LOAD is not asserted, the register shifts its current value to the left by one bit, with the least significant bit receiving the value of D. This structure allows for both parallel loading of a constant value and serial data shifting.
module top_module(input D,
     input LOAD,
     input CLK,
     output reg [5:0] Q);
