
Design a current sensor circuit that measures the current flowing through a conductor. The circuit has a 5-bit binary input representing the sensed current value and outputs a 3-bit binary value based on the following conditions:
- If the current is less than or equal to 15, the output should be 3'b000.
- If the current is between 16 and 31, the output should be 3'b001.
- If the current is between 32 and 47, the output should be 3'b010.
- If the current is between 48 and 63, the output should be 3'b011.
- If the current exceeds 63, the output should be 3'b111 (indicating an overload).
