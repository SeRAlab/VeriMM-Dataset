Design a circuit that performs multiplication of two 8-bit numbers, a and b, producing a 16-bit output c. The circuit supports both signed and unsigned multiplication based on the ctrl input signal; if ctrl is high, the multiplication is signed, and if ctrl is low, it is unsigned. The results are stored in a temporary register and outputted on the rising edge of the clock.
module top_module(
    input [7:0] a,
    input [7:0] b,
    input ctrl,
    input clk,             // Added clk input
    output reg [15:0] c
);
