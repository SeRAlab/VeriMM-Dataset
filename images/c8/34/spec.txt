

You are tasked with designing a verilog module for a 4-bit binary counter that counts up on every positive edge of the clock signal. The counter should have a reset signal that sets the counter to all zeros. The module should have four output signals, representing the four bits of the counter. The module should be named "counter" and should have the following ports:

- `output [3:0] out`: the four output signals representing the four bits of the counter
- `input clk`: the clock signal
- `input reset`: the reset signal, active high

Write the verilog code for the "counter" module.
