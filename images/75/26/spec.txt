Design a 4-bit synchronous up/down counter. The counter increments its value on each positive clock edge when the enable signal is high and the control signal is set to 1; it decrements when the control signal is set to 0. The counter is reset to zero when the reset signal is activated.
module top_module(
    input clk,
    input reset,
    input enable,
    input control,
    output reg [3:0] count
);
