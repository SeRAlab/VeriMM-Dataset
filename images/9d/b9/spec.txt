Design a 3-to-8 decoder that decodes a 3-bit input (A, B, C) into one of eight outputs (Y0 to Y7). On each positive clock edge, the module captures the input values and activates exactly one of the outputs based on the binary value represented by the inputs, while all other outputs remain inactive. This functionality allows the module to effectively select one of eight distinct output lines based on the input combination.
module top_module(
    input clk, // Added the clock input declaration
    input A,
    input B,
    input C,
    output reg Y0,
    output reg Y1,
    output reg Y2,
    output reg Y3,
    output reg Y4,
    output reg Y5,
    output reg Y6,
    output reg Y7
);
