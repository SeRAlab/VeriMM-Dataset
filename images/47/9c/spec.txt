Implement a circuit that functions as a set of retiming registers for an n-bit wide input. The module captures the input signals on the rising edge of the clock and retains their values in internal registers. The output reflects the state of these registers, effectively allowing the output to be updated with the input after one clock cycle. This design is useful for improving timing by introducing extra registers in critical paths, thereby reducing propagation delays in high-speed digital circuits.

  input [n-1:0] in,
  output [n-1:0] out
