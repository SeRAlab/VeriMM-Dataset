
Design a 1-bit DRAM cell in Verilog. The DRAM cell should have a data input (D), a write enable (WE), and an output (Q). When WE is high, the input D should be stored in the DRAM cell (Q). When WE is low, Q should retain its last value. Additionally, implement a reset functionality that sets Q to 0 when a reset signal (RST) is high.
