Design a 1-bit DRAM cell with read and write operations. The DRAM cell should have the following inputs: `write_enable` (1 bit), `data_in` (1 bit), `row_address` (1 bit for simplicity), and `read_enable` (1 bit). The outputs should include `data_out` (1 bit) representing the data stored in the DRAM cell. When `write_enable` is high, the `data_in` should be written to the memory location specified by `row_address`. When `read_enable` is high, the `data_out` should reflect the stored data. Ensure that the cell holds its value when neither read nor write is enabled.
