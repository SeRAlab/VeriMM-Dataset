Design a Verilog module that implements a logistic regression function which takes three 8-bit inputs (representing the features) and produces a 1-bit output representing the class prediction (0 or 1). The weights for the logistic regression are fixed as follows: weight1 = 3, weight2 = 2, weight3 = 5. The output should be 1 if the weighted sum of the inputs plus a bias (which is 10) is greater than or equal to 50, otherwise it should be 0.
