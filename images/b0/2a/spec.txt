Design a synchronized memory register that operates on a clock and reset signal. The module includes a write enable (we) input to allow writing data into the memory from the wr input, and an increment (incr) input that, when activated, increments the stored value by one. On reset (rst), the memory is cleared to zero. The output (rd) provides a specified lower-width portion of the stored value, effectively implementing a register file feature with both write and increment functionalities.
