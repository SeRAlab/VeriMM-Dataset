Design a sign extension unit that processes a 16-bit immediate value (`imm`) to produce a 32-bit extended value based on the `EXTOp` control signal. If `EXTOp` is high, the unit performs sign extension by checking the most significant bit of `imm`; if it's set, the upper 16 bits are filled with ones, otherwise, they are filled with zeros. When `EXTOp` is low, the upper 16 bits are always filled with zeros. Additionally, the module calculates a branch address (`ConBA`) by adding the 32-bit `PCplus` with the shifted extended immediate value (shifted left by two bits). The output `immout` is determined based on the `LUOp` signal; if it is high, the lower 16 bits of `immout` are set to the original `imm` with the upper 16 bits as zeros, otherwise, it outputs the extended immediate.
module top_module(imm,PCplus,EXTOp,LUOp,ConBA,immout);
