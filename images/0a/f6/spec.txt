Design a simple 5-stage instruction pipeline for a basic CPU architecture that consists of Fetch (IF), Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). The pipeline should handle hazards such as data hazards and control hazards. Assume a simple instruction set and that each stage can take one clock cycle to complete. Your design should include registers to hold intermediate values between stages and control logic to handle stalls for data hazards.
