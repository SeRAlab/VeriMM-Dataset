1. state X1 (out = ~F).
2. state Y1 (out = F).
3. state Z1 (out = 1).
4. state W1 (out = 0).

1. From state X1: If F = 1, then transition to state Y1. If F = 0, then transition to state Z1.
2. From state Y1: If F = 0, then transition to state Z1. If F = 1, then stay in state Y1.
3. From state Z1: If F = 1, then transition to state W1. If F = 0, then stay in state Z1.
4. From state W1: If F = 0, then transition to state X1. If F = 1, then stay in state W1.

module fsm_4 (
  input F,
  input [3:0] state,
  output reg [3:0] next_state,
  output reg out);
