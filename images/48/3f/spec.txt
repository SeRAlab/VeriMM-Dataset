Implement the Verilog module based on the following description.
You are given a 20-bit input vector bits[19:0]. We want to know some relationships between each bit and its neighbour:
(1) res_and: Each bit of this output vector should indicate whether both the corresponding input bit and its neighbour to the left are '1'. For example, res_and[18] should indicate if bits[18] and bits[19] are both 1. Since bits[19] has no neighbour to the left, the answer is obvious so we don't need to know res_and[19].
(2) res_or: Each bit of this output vector should indicate whether any of the corresponding input bit and its neighbour to the right are '1'. For example, res_or[2] should indicate if either bits[2] or bits[1] are 1. Since bits[0] has no neighbour to the right, the answer is obvious so we don't need to know res_or[0].
(3) res_xor: Each bit of this output vector should indicate whether the corresponding input bit is different from its neighbour to the left. For example, res_xor[18] should indicate if bits[18] is different from bits[19]. For this part, treat the vector as wrapping around, so bits[19]'s neighbour to the left is bits[0].

module neighbor_relation (
	input [19:0] bits,
	output [18:0] res_and,
	output [19:1] res_or,
	output [19:0] res_xor);
