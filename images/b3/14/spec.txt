Design a 16-bit up counter that increments its value on each pulse input while being clocked. The counter resets to zero on a reset signal. The current count is output as a 16-bit value. This design allows for synchronous counting based on clock cycles, with an ability to reset and dynamically update the counter based on a pulse signal.
module top_module(
    input clock, reset,
    input pulse,
    output [15:0] countOut
    );
