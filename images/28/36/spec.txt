Design an SPI controller in Verilog that handles data transmission. The SPI controller should have the following functionality:
1. It should accept a data input and a clock signal.
2. On each rising edge of the clock signal, it should shift the input data out serially.
3. The controller should have a state to indicate when it is busy transmitting.
4. The data should be transmitted bit by bit, with an active high signal indicating that the data is valid for the receiver.
