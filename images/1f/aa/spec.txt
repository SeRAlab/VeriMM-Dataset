Design a combinational circuit that performs matrix inversion for a 2x2 matrix. The input will be a 4-bit representation of each element in the matrix, and the output will be the inverted matrix in the same 4-bit format. The matrix inversion should follow the formula:
If A = [[a, b], [c, d]], then A_inv = (1/det(A)) * [[d, -b], [-c, a]]
where det(A) = ad - bc. Handle the case where the determinant is zero by outputting a predefined value (e.g., all zeroes).
