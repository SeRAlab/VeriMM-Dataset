Design a 4-to-1 multiplexer that selects a 2-bit output from one of four 4-bit wide input signals (a, b, c, d) based on a 2-bit selection input (sel). The output will correspond to the least significant 2 bits of the selected input; when sel=00, output the least significant bits of a; sel=01 outputs from b; sel=10 from c; and sel=11 from d.
module top_module(
  input [1:0] sel,
  input [3:0] a,
  input [3:0] b,
  input [3:0] c,
  input [3:0] d,
  output reg [1:0] out
);
