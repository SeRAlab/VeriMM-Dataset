Design a simple arithmetic calculator that performs basic operations on two 8-bit inputs, `a` and `b`. The module computes the sum, difference, product, and quotient of the inputs, producing four 8-bit outputs named `add_out`, `sub_out`, `mul_out`, and `div_out`, respectively. The operations are executed whenever there is a change in the inputs, thanks to the combinational always block.
module top_module(
  input [7:0] a,
  input [7:0] b,
  output reg [7:0] add_out,
  output reg [7:0] sub_out,
  output reg [7:0] mul_out,
  output reg [7:0] div_out
);
