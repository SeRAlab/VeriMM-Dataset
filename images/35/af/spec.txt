Design a fan speed control system that adjusts the speed of the fan based on temperature readings. The fan has three speed settings: low, medium, and high. The system should take a temperature input and control the fan speed as follows: 
- If the temperature is below 20 degrees, the fan should run at low speed.
- If the temperature is between 20 and 30 degrees, the fan should run at medium speed.
- If the temperature is above 30 degrees, the fan should run at high speed.
The system should use a clock input for synchronization and should have an enable signal to start/stop the fan control logic.
