Design a shift register with an 8-bit wide storage capacity. The register can be cleared to zero on a reset signal, loaded with new data from an 8-bit input when the load signal is active, and can perform a right shift operation while accepting a serial input when the shift signal is asserted. The output provides the current stored value of the register.
module top_module(
    input clk,
    input reset,
    input load,
    input [7:0] data_in,
    input shift,
    input serial_in,
    output reg [7:0] data_out
);
