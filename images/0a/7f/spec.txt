Design an 8-to-3 encoder that takes 8 input lines and encodes the input that is high (1) into a 3-bit binary output. If more than one input is high, the output should reflect the highest priority input (i.e., input[7] has the highest priority and input[0] has the lowest). If no inputs are high, the output should be set to a specific value (e.g., 3'b000).
