
Design a digital phase shifter that takes a 3-bit input phase value and outputs a corresponding 3-bit phase shifted value. The phase shifter should allow for phase shifts of 0, 90, 180, and 270 degrees, represented by the following inputs:
- 000 -> 000 (0 degrees)
- 001 -> 100 (90 degrees)
- 010 -> 010 (180 degrees)
- 011 -> 110 (270 degrees)
- 100 -> 000 (0 degrees) (wrap around)
