Design a 4-bit up/down counter that increments or decrements its count value based on the status of an input signal. The counter operates on the rising edge of a clock signal. It has a reset functionality that initializes the count to zero when activated. Additionally, a load signal keeps the current count unchanged when asserted. If the up_down signal is high, the counter increments; if low, it decrements.
module top_module(
  input clk,
  input reset,
  input load,
  input up_down,
  output reg [3:0] count
);
