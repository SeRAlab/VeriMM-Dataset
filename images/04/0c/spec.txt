
Design an edge-triggered D flip-flop with an active-high clock and asynchronous reset. The flip-flop should have the following characteristics:
1. On the rising edge of the clock, if the reset is not asserted, the output (Q) should take the value of D.
2. If the reset is asserted, the output (Q) should be reset to 0 regardless of the clock.
3. Implement a 1-bit D flip-flop.
