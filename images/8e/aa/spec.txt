Implement a 4-bit magnitude comparator that determines if input A is greater than or equal to input B. The comparator checks the most significant bit (MSB) first; if the MSB of A is high while the MSB of B is low, A is greater. If both MSBs are the same, it further compares the lower 3 bits to confirm equality, ensuring accurate magnitude assessment. The output indicates whether A is greater than or equal to B.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output reg greater_or_equal
);
