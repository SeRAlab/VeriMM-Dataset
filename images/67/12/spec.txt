Design a D flip-flop with asynchronous set and clear capabilities. The output Q is set to HIGH when SET is activated, or to LOW when CLR is activated, regardless of the clock. When neither SET nor CLR is active, the flip-flop captures the value of the input D on the rising edge of the CLK signal, while providing the complementary output Q_bar. This module is useful in sequential logic designs requiring control signals to manage the state of the flip-flop asynchronously.
module top_module(
    input CLK,
    input D,
    input SET,
    input CLR,
    output reg Q,
    output reg Q_bar
);
