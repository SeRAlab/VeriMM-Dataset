

You are tasked with designing a verilog module that implements a simple 3-bit up counter. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock input
- `reset`: a synchronous active-high reset input

Outputs:
- `out`: a 3-bit output representing the current count value

The counter should increment on every rising edge of the `clk` input, and reset to 0 on every rising edge of the `reset` input. The initial value of the counter should be 0.

Write a verilog module that implements this counter.
