Design a 4-bit binary up-counter with asynchronous reset functionality. On the rising edge of the clock, if the reset signal (rst_n) is low, the counter is set to zero. If the reset is not active and the enable signal is high, the counter increments its value by one. If the enable signal is low, the counter retains its current value.
module top_module(
  input clock, rst_n,
  input enable,
  output reg [3:0] count
);
