Design a frequency prescaler that divides an input clock signal into two lower frequency outputs. The module has a 24-bit counter that increments on every rising edge of the input clock. The output `clock_lf` represents a lower frequency derived from the most significant bit of the counter, while `clock_hf` represents a higher frequency derived from the 15th bit of the counter. This design can be utilized in applications requiring multiple clock frequencies generated from a single source.
module top_module(
  input wire  clock_src,    
  output wire clock_lf,     
  output wire clock_hf      
  );
