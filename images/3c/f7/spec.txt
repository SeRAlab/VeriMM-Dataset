
Design a simple Automatic Repeat reQuest (ARQ) error correction system. The system should receive a 5-bit data input and a single bit for acknowledgment (ACK). If the ACK is '1', it indicates the data was received correctly. If the ACK is '0', the system should store the data for retransmission. The output should be the last correctly received data when an ACK is received or the data to be retransmitted when an ACK is not received.
