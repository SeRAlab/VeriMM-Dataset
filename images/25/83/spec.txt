Design an 8-channel DMA controller that manages data transfer requests from multiple sources to a shared memory. The DMA controller has the following inputs: a clock signal, a reset signal, 8 request signals (req[0] to req[7]), and a grant signal. The outputs are the grant signals for the channels (grant[0] to grant[7]) which indicate which channel is currently being granted access to the memory. The controller operates in a round-robin fashion, granting access to the next channel in line when a request is active.
