Implement the Verilog module based on the following description.
Create an 8-bit register file with 2 read ports and 1 write port. The read ports should output the contents of the registers at the specified addresses. The write port should update the register at the specified address when the write enable input is high.
module register_file(
    input clk,
    input we,
    input [2:0] write_addr,
    input [7:0] write_data,
    input [2:0] read_addr1,
    input [2:0] read_addr2,
    output reg [7:0] read_data1,
    output reg [7:0] read_data2);
