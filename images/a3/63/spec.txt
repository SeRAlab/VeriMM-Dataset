The state machine starts in the `DISABLE` state and moves to `DRAW` when enabled, and it can be reset back to `DISABLE` based on the `reset_n` signal. Additionally, it outputs a color value that depends on the `clear` input, indicating whether to display a specific color based on the clear condition.

			input clk, 
			   input reset_n,
			   input enable_unit,

			   output reg reset_datapath, 
			   output [2:0] color);
