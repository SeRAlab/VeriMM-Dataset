Design a 1-to-4 demultiplexer that takes a single data input (I0) and routes it to one of four outputs (y0, y1, y2, y3) based on two select control signals (C0 and C1). When both control signals are LOW (C0=0, C1=0), the input data is directed to output y0; when C0 is HIGH and C1 is LOW, the input is directed to output y1; when C0 is LOW and C1 is HIGH, it is routed to output y2; and when both control signals are HIGH, the input is sent to output y3. Each output is activated after a delay of 3 time units, ensuring synchronized data transmission.
module top_module(
        input I0,
        input C0,
        input C1,
        output y0,
        output y1,
        output y2,
        output y3
    );
