Please act as a professional Verilog designer.

Design an 8-bit ring counter. The counter should circulate a single '1' through its bits on each clock cycle. The counter should reset to a single '1' in the LSB when the reset signal is active.

Module name:
    RingCounter
Input ports:
    clk: Clock signal used for synchronous operation.
    reset: Active-high reset signal.

Output ports:
    count: 8-bit output representing the current count value.
