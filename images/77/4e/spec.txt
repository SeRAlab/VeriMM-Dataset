Implement a D-type flip-flop with asynchronous reset and set functionalities. The output Q reflects the D input upon the rising edge of the CLK signal, while Q_N provides the inverted output. The reset input asynchronously clears the flip-flop output to 0, and the set input asynchronously sets the output to 1. This design is suitable for storing one bit of data while incorporating control signals for reset and set operations.
module top_module(
    input CLK,
    input D,
    input RESET,
    input SET,
    output reg Q,
    output reg Q_N
);
