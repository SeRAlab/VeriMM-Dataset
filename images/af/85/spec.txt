Design a clock gating circuit that generates a gated clock output. When the reset signal is low, the output is set to LOW. When the reset is high, if the gate signal is asserted, the output follows the clock signal; otherwise, the output is set to LOW. This functionality effectively reduces power consumption by disabling the clock when it is not needed.

    input clk,
    input gate,
    input rst,
    output reg gated_clk
