Design a Verilog module that models an 8-bit shift register with synchronous reset and shift enable signals. The module should have an input clock signal (clk), an input shift enable signal (sh_en), an input synchronous reset signal (rst), an 8-bit input data signal (din), and an 8-bit output signal (dout). On the rising edge of the clock, if reset is high, dout should be set to 0. If shift enable is high, dout should shift left by one bit and the least significant bit should be loaded from din[0].
