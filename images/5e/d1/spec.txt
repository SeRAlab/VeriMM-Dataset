Design a binary to decimal converter that takes a 4-bit binary input and outputs the same value as a 4-bit decimal output. On each clock cycle, if the reset signal is active, the output is set to zero and the valid flag is cleared. Otherwise, the converter maintains the valid flag and reflects the binary input directly to the output without any transformation.
module top_module(
    input clk,
    input rst,
    input [3:0] bin_in,
    output [3:0] dec_out,
    output valid_out
);
