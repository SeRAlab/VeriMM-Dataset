Implement the Verilog module based on the following description.
Design a Verilog module for a 4-bit synchronous up-down counter with an up/down control signal. The counter should increment or decrement its value on each positive clock edge based on the state of the up/down control signal. The output of the counter is a 4-bit signal 'q'.

module up_down_counter (
	input clk,
	input up_down,
	output [3:0] q);
