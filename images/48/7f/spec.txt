Implement the Verilog module based on the following description.
Given a 4-bit up/down counter with active-high control signals:

1. The counter increments on the rising edge of the clock if the up signal is high.
2. The counter decrements on the rising edge of the clock if the down signal is high.
3. The counter holds its value if both up and down signals are low.

Write Verilog implementing this up/down counter.
module up_down_counter (
    input clk,
    input up,
    input down,
    output reg [3:0] count);
