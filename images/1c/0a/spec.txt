Design an 8-bit EEPROM cell with read and write capabilities. The EEPROM should have a clock input, a write enable signal, a read enable signal, an 8-bit data input, and an 8-bit data output. When the write enable signal is high, the data from the input should be stored in the EEPROM on the rising edge of the clock. When the read enable signal is high, the stored data should be outputted on the data output lines.
