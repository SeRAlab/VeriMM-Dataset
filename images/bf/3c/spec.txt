Design a gated D latch with a set/reset functionality. The output Q updates based on the input D when the clock signal (nCLK) is low, unless the active-low set/reset signal (nSR) is asserted. In that case, Q is set to a predefined state determined by the SRMODE parameter, overriding the input D. The initialization state of Q is defined by the INIT parameter.
