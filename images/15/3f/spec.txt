
Design a JK flip-flop using Verilog. The flip-flop should have inputs J, K, Clock, and Clear, and outputs Q and Qn. The Clear input should asynchronously reset the outputs. The behavior should be as follows:
- When Clear is high, Q should be reset to 0 regardless of the other inputs.
- On the rising edge of the Clock:
  - If J and K are both 0, Q remains unchanged.
  - If J is 1 and K is 0, Q is set to 1.
  - If J is 0 and K is 1, Q is set to 0.
  - If both J and K are 1, Q toggles.
