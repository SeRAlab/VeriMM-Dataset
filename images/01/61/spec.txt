Design a simple RNN cell that performs one-step inference. The RNN cell takes a single input vector and a hidden state vector as inputs and produces a new hidden state vector as output. The RNN uses a simple activation function and weights that are fixed for this problem. The update rule for the hidden state can be represented as:  
H_new = tanh(W * X + U * H_old + b)  
Where W, U are weight matrices, b is a bias vector, X is the input vector, and H_old is the previous hidden state vector. Implement the RNN cell in Verilog.
