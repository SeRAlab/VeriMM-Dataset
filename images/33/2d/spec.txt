
Design a Run-Length Encoding (RLE) circuit that takes an 8-bit input stream representing binary data and encodes it into a compressed format. The output should be a series of pairs that represent the value and its run length. The circuit should operate on a clock signal and produce valid output when a 'valid' signal is high. The input is considered valid for 8 clock cycles, and the output should be presented in the next clock cycle after the input is processed.
