Implement the Verilog module based on the following description.
Design a Verilog module that implements a 3-bit up/down counter with asynchronous reset. The counter should increment when the up signal is high, and decrement when the down signal is high. When the async reset (areset) is high, the counter should reset to 0. The counter value should be output to the "count" signal.

module up_down_counter
(
    input clk,
    input areset,
    input up,
    input down,
    output reg [2:0] count
);
