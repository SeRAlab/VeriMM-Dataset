
Design a simple NVMe controller command decoder. The decoder takes a 4-bit command input and produces a 3-bit output indicating the command type. The command types are as follows:
- 0000: NOOP (No Operation)
- 0001: READ
- 0010: WRITE
- 0011: FLUSH
- 0100: RESET
- 0101: IDENTIFY
- 0110: SHUTDOWN
- 0111: ERROR
Any other command values should result in an output of 111 (INVALID).
