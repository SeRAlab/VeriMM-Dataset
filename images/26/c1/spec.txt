
Design a FIFO queue that can store up to 8 8-bit data words. The FIFO should have the following signals:
- `clk`: Clock input
- `rst`: Active-high reset
- `wr_en`: Write enable signal
- `rd_en`: Read enable signal
- `data_in`: 8-bit data input
- `data_out`: 8-bit data output
- `full`: Output high if the FIFO is full
- `empty`: Output high if the FIFO is empty
