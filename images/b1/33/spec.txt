Design a 4-bit adder that computes the sum of two 4-bit inputs (a and b) along with an optional carry-in (cin). The module outputs a 4-bit sum (s) and a carry-out (cout). The carry-out is determined by checking if there is an overflow from the addition of the sum's most significant bit, effectively indicating whether the result exceeded the representable range of a 4-bit value.
module top_module(
  input [3:0] a,
  input [3:0] b,
  input cin,
  output [3:0] s,
  output cout
);
