Implement a Verilog module for an 8-bit shift register with parallel load and synchronous reset. The register should shift left when shift is high and load the data input when load is high. If reset is high, the register should reset to 8'b00000000.
module shift_register (
    input clk,
    input reset,
    input shift,
    input load,
    input [7:0] data,
    input serial_in,
    output reg [7:0] q
);
