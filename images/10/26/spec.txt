Design a JK flip-flop in Verilog. The JK flip-flop has inputs J, K, and a clock signal (clk). It should toggle its output Q based on the J and K inputs on the rising edge of the clock. If J and K are both 0, the output should remain unchanged. If J is 1 and K is 0, the output should set to 1. If J is 0 and K is 1, the output should reset to 0. If both J and K are 1, the output should toggle.
