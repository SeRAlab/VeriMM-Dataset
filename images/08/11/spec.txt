
Design a fixed-priority arbiter in Verilog. The arbiter should have 4 request inputs (`req[3:0]`) and a grant output (`grant[3:0]`). The arbiter should grant access based on fixed priorities: `req[0]` has the highest priority and `req[3]` has the lowest. The grant output should be a one-hot encoded signal indicating which request has been granted. Each clock cycle, if a request is active, it should be granted according to its priority.
