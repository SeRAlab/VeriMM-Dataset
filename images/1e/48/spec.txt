Design a Verilog module that performs the convolution operation on a 3x3 kernel and a 5x5 input image. The output should be a single 8-bit value representing the result of the convolution. The module should have the following inputs: a 5x5 input image (as a 25-bit vector), a 3x3 kernel (as a 9-bit vector), and an enable signal. The output should be the convolution result and a valid signal indicating when the output is ready.
