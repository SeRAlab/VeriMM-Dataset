Module name:
    register

Input ports:
    CLK: Clock input
    CLR: Active high clear signal
    LOAD: Signal to load new value
    DATA_IN: 8-bit input data to be loaded into the register

Output ports:
    DATA_OUT: 8-bit output representing the current value of the register

Implementation:
The register module uses an always block to update the value of the register based on the clock signal, clear signal, and load signal. It checks if the clear signal is active and sets the register value (DATA_OUT) to 0. If the load signal is high, it loads the new value from the input data (DATA_IN) into the register. Otherwise, it holds the current value of the register.
