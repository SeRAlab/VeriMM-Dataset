
Design a 7-stage pipelined processor that consists of the following stages: Fetch, Decode, Execute, Memory Access, Write Back, and two additional stages for Instruction Fetch and Instruction Decode. Implement a simple control logic that allows for instruction to be fetched and executed sequentially while maintaining the pipeline. The processor should handle a basic instruction set consisting of ADD, SUB, and MOV operations. Implement the registers and control signals necessary for the pipeline stages.
