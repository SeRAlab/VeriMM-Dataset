Design a read-only memory (ROM) module that outputs 8-bit data based on a 4-bit address input when enabled. The output data is determined by the case statement which maps specific addresses (from 0 to 9) to predefined corresponding 8-bit values. If the address falls outside this range, the output will default to zero. The module is triggered on the rising edge of the clock and functions only when the enable signal is active.
