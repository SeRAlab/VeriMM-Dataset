Design a 32-bit Linear Feedback Shift Register (LFSR) that has a feedback polynomial of x^32 + x^22 + x^17 + x^13 + 1. The LFSR should take a clock input and reset input. When reset is high, the LFSR should be initialized to a specific non-zero value (e.g., 32'h1). On each clock edge, the LFSR should shift and update its value based on the feedback polynomial.
