Design a valid signal monitor that captures the state of an 8-bit input signal `Valid` on a clock edge. The module outputs a 4-bit identifier `FE_ID` corresponding to the position of the least significant bit set to 1 in the `Valid` input. If no bits are set, `FE_ID` defaults to 0. The module also supports asynchronous reset, returning `FE_ID` to 0 when `rst_n` is not asserted.
