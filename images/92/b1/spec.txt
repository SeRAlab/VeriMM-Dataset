Design a circuit that converts a 4-bit binary input into a 2-bit output by selecting the two most significant bits (MSBs) of the input when a reset signal is not active. When the reset signal is triggered, the output is set to a default value of 00. Additionally, it directly passes a single-bit scan input to the scan output without modification.
module top_module(
    input [3:0] binary_in,
    input reset,
    input scan_in,
    output reg [1:0] binary_out,
    output reg scan_out
);
