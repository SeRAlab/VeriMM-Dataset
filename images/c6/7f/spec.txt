

You are tasked with designing a verilog module for a simple combinational circuit that takes in five inputs and produces one output. The module must be named "combinational_circuit" and should have the following ports:

- `input [3:0] A`: a 4-bit input
- `input [1:0] B`: a 2-bit input
- `input C`: a single bit input
- `input D`: a single bit input
- `input E`: a single bit input
- `output X`: a single bit output

The module should implement the following logic:

- If `A` is less than or equal to `5`, and `B` is equal to `2`, then output `1`. Otherwise, output `0`.
- If `C` is `1`, and `D` is `0`, and `E` is `1`, then output `1`. Otherwise, output `0`.

You should use the ternary operator to implement the above logic.
