Design a 4-bit to 7-segment display decoder. This module takes a 4-bit binary input (DATA_IN) and outputs the corresponding 7-bit signal (SEVEN_SEG_OUT) that drives a common cathode 7-segment display. Each unique 4-bit input represents a decimal digit (0-9), and the output will illuminate the appropriate segments of the display to visually represent that digit. If the input value is not in the range of 0-9, the output will default to turn off all segments.
module top_module(
    input [3:0] DATA_IN,
    output reg [6:0] SEVEN_SEG_OUT
);
