Design a 4-bit up/down counter that counts based on the input signal 'up_down'—incrementing when 'up_down' is high and decrementing when low. The counter resets to zero when the 'reset' signal is activated. The current count value is outputted on 'q', and a comparison output 'out' indicates whether the counter's magnitude exceeds a 4-bit input 'data_in', producing a high signal when the count is greater and low otherwise.
module top_module(
    input clk,
    input up_down,
    input reset,
    input [3:0] data_in,
    output reg [3:0] q,  // Change to reg type
    output reg out
);
