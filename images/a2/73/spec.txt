Design a circuit that performs sign extension on a 16-bit input. If the most significant bit (MSB) of the input `a` is 1 (indicating a negative number in two's complement representation), the output `value` will be the negated value of `a`; otherwise, it outputs `a` unchanged. Additionally, the output `z_s` indicates whether the MSB is set, serving as a signal to indicate if the input is negative.
module top_module(
  input [15:0] a,
  output [15:0] value,
output z_s);
