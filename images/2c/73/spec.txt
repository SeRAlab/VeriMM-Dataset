Design a simple SD card interface controller that takes in a 4-bit command input and outputs a 4-bit response based on predefined command-response pairs. The commands and their corresponding responses are as follows: 
- Command 0000 -> Response 1111 
- Command 0001 -> Response 1110 
- Command 0010 -> Response 1101 
- Command 0011 -> Response 1100 
For any command not defined, the response should be 0000.
