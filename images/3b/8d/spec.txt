Design an 8-bit Analog-to-Digital Converter (ADC) that takes an 8-bit binary input representing a voltage level between 0 to 255 and outputs a 3-bit binary number representing the range of the ADC. The output should categorize the input voltage into three ranges as follows:
- 0 to 84 (inclusive) should output 3'b000
- 85 to 169 (inclusive) should output 3'b001
- 170 to 255 (inclusive) should output 3'b010
The design should be purely combinational logic.
