Design a 4-bit binary adder that computes the sum of two 4-bit numbers, A and B, along with a carry-in input (C_in). The module outputs a 4-bit sum (S) and a carry-out (C_out). The carry-out indicates if there is a carry from the most significant bit, which could be utilized in cascading with other adder modules for multi-bit addition.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input C_in,
  output [3:0] S,
  output C_out
);
