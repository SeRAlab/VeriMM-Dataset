Design a 4-bit SRAM cell that can store a 4-bit data input and is controlled by a write enable signal. The SRAM cell should have the following ports: 
- `data_in`: 4-bit input data 
- `data_out`: 4-bit output data 
- `write_enable`: Signal to enable writing data into the SRAM cell 
- `clk`: Clock signal for synchronous operation. 
Implement the necessary logic to control the reading and writing of the data based on the write_enable signal.
