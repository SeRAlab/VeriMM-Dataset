
Design a simple PCIe endpoint controller state machine that operates in three states: IDLE, CONFIG, and DATA. The state machine should respond to two inputs: a CONFIG_REQ signal, which transitions the state to CONFIG when in IDLE, and a DATA_REQ signal, which transitions the state to DATA when in CONFIG. If a DATA_REQ is received while in DATA, the state should remain in DATA. The state machine should return to IDLE when a RESET signal is asserted. The output should indicate the current state of the state machine using a 2-bit output signal, `state_out`, where IDLE = 00, CONFIG = 01, and DATA = 10.
