
Design a simple SATA controller state machine that manages the state transitions based on input signals. The state machine has the following states: IDLE, ACTIVE, and ERROR. It transitions between these states based on the following rules:
- If in IDLE state and receive "start" signal, transition to ACTIVE.
- If in ACTIVE state and receive "stop" signal, transition to IDLE.
- If in ACTIVE state and receive "error" signal, transition to ERROR.
- If in ERROR state and receive "reset" signal, transition to IDLE.
The outputs should indicate the current state of the controller.
