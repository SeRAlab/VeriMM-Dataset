Design a basic Arithmetic Logic Unit (ALU) that performs various arithmetic and logical operations based on a 3-bit control input. The operations include addition, subtraction, incrementing, passing the first operand, bitwise AND, OR, XOR, and bitwise NOT of the first operand. The ALU outputs the result of the selected operation and provides a zero flag that indicates if the result is zero. Additionally, an overflow output is defined but not implemented in the provided code.
module top_module(
    input [7:0] op_A,
    input [7:0] op_B,
    input [2:0] ctrl,
    output reg [7:0] alu_res,
    output zero,
    output ov
    );
