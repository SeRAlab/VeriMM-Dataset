Design a 4-bit adder that computes the sum of two 4-bit inputs, A and B. The module outputs the 4-bit result in the 'sum' variable and also signals a carry-out if the addition results in a value greater than 15 (the maximum representable value for 4 bits). The carry_out output indicates an overflow condition based on the fifth bit of the sum.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output reg [3:0] sum,
    output reg carry_out
);
