Design a 4-bit counter with load and reset functionalities. The counter increments on each positive clock edge, unless it is being reset, in which case it outputs zero. Additionally, when the LOAD signal is asserted, the counter outputs the value from DATA_IN instead of incrementing.
module top_module(
    input [3:0] DATA_IN,
    input LOAD,
    input CLK,
    input RESET,
    output reg [3:0] COUNT
);
