The conversion is performed by comparing the analog input against discrete voltage levels determined by a reference voltage of 5V, allowing the circuit to produce a binary representation of the input voltage. The output will reflect the closest digital value corresponding to the measured analog input.
module top_module(
  input wire [15:0] analog_in,
  output reg [n-1:0] digital_out
);
