Design a Verilog module for a SR flip-flop with asynchronous reset. The flip-flop should have inputs S (set), R (reset), and CLK (clock), and an output Q. The behavior should be such that when S is high, Q should be set to 1, when R is high, Q should be reset to 0. If both S and R are low on the rising edge of CLK, Q should hold its previous value. The reset should be asynchronous, meaning if R is high, Q should be reset immediately regardless of CLK.
