Design a 4x4 bit random access memory (RAM) module that operates on a clock signal. It features a write enable (we) signal to allow data input (din) to be stored at specific addresses (addr) on the rising edge of the clock. The module can address four memory locations, each capable of holding 4 bits of data. When write enable is asserted, the data is written to the specified address; otherwise, the output (dout) provides the data stored at the specified address, enabling read operations at any time.
module top_module(clk, we, addr, din, dout);
