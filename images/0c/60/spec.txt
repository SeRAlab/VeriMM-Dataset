
Design a Verilog module that performs data integrity checking using a simple checksum mechanism. The module should take an 8-bit data input and compute a simple checksum (sum of the bytes modulo 256). The checksum is then output as an 8-bit value. Additionally, the module should have a valid signal that indicates when the data is ready to be processed. The module should also verify the checksum against a provided checksum input to indicate if the data is valid or not.
