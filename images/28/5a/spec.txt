Create a Verilog module that implements a 2-to-1 multiplexer with data forwarding capability. The multiplexer should have two input data lines (A and B), one select line (S), and one output line (Y). If the select line S is '0', the output Y should forward the input A. If S is '1', Y should forward the input B. Additionally, if A is equal to B, the output should be '0' irrespective of the select line.
