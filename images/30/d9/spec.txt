Design a Verilog module that performs binary search on a sorted array of 8-bit numbers. The module should take a 3-bit index input to select one of the 8 entries in the array and output the corresponding 8-bit number. The module should also have a 1-bit input to indicate the operation mode (0 for reading, 1 for writing) and a corresponding 8-bit input for writing new data if in writing mode.
