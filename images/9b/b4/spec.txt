Design a simple calculator that performs basic arithmetic operations: addition, subtraction, multiplication, and division on two 32-bit signed operands. The specific operation is selected using a 2-bit input control signal. The operands are contained within a single 64-bit input, where the lower 32 bits represent the first operand and the upper 32 bits represent the second. The result of the operation is provided as a signed 32-bit output.
module top_module(
    input [1:0] operation,
    input signed [63:0] operands,
    output signed [31:0] result
);
