    shift_register

    clk: Clock signal used for synchronous operations.

Output ports:
    data_out: 4-bit shift register output data.

Implementation:
The module includes a 4-bit register, data_out, to store the shift register contents.

If the reset signal (rstn) is high and the load signal is high, the register (data_out) is loaded with the value of the input data signal (data_in). If the load signal is low, the register (data_out) shifts its contents to the right.
