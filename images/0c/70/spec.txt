Design a 16-bit timer that counts up from 0 to a maximum value (65535) and rolls over to 0 when the maximum value is reached. The timer should have a clock input, a reset input, and a start/stop input. When the start input is activated, the timer should begin counting on each clock pulse. The timer should be reset to 0 when the reset input is activated. The timer should stop counting when the start/stop input is deactivated.
