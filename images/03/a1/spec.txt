Design a GPIO controller that can read and write data to a specified pin. The controller should have the following inputs: a clock signal (clk), a reset signal (rst), a 4-bit data input (data_in), a 3-bit pin number (pin_num), and a control signal (write_enable) to determine if the operation is a write or read. The controller should maintain the state of each pin (up to 8 pins) and allow for reading and writing data to these pins based on the control signal.
