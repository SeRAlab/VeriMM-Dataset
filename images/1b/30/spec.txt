Design a Verilog module that implements a simple WiFi connection state machine. The module should have an input for a reset signal, a clock signal, and an input for a WiFi connection request. The state machine should operate in the following states: IDLE, CONNECTING, CONNECTED, and DISCONNECTED. The state transitions are as follows:  
- From IDLE to CONNECTING on a WiFi request.  
- From CONNECTING to CONNECTED after one clock cycle.  
- From CONNECTED to DISCONNECTED on a disconnect request (assumed to be another input signal not stated but required for a full design).  
- From DISCONNECTED back to IDLE on reset.  
The current state should be output on a 2-bit output signal.
