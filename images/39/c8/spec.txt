Design a 4-channel DMA controller that can transfer data from multiple sources to a single destination. The DMA controller should have the following inputs: `start` (to initiate the transfer), `channel_select` (to select which of the 4 channels to use), `data_in` (the data to be transferred), and `clk` (the clock signal). The outputs should be `data_out` (the transferred data) and `busy` (indicating if the DMA is currently busy transferring data). The controller should be able to handle the transfer for one channel at a time and set the `busy` signal while transferring data.
