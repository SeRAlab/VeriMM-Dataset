Design a simple 8-bit calculator that performs basic arithmetic operations on two inputs, A and B. The module can execute addition, subtraction, multiplication, and division based on a 2-bit operation selector (op). Specifically, it computes the sum and difference of A and B for op values of 00 and 01, respectively; it extracts and outputs the upper byte of the product of A and B for op 10; and it provides the quotient of A and B for op 11. If an unspecified operation code is given, it defaults to outputting zero.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input [1:0] op,
    output reg [7:0] result
);
