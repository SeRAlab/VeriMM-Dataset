
Design a Verilog module that performs LU decomposition for a 2x2 matrix. The module should take a 2x2 matrix as input and output the lower (L) and upper (U) triangular matrices. The input matrix is defined as:
```
A = [a11, a12]
    [a21, a22]
```
The output matrices should be:
```
L = [l11, 0]
    [l21, l22]

U = [u11, u12]
    [0,  u22]
```
The LU decomposition equations for a 2x2 matrix are:
- l11 = 1
- u11 = a11
- u12 = a12
- l21 = a21 / u11
- l22 = a22 - l21 * u12
