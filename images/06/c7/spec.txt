Design a 5-bit EEPROM cell. The EEPROM cell has a data input (`data_in`), a write enable signal (`write_en`), and a data output (`data_out`). When `write_en` is high, the `data_in` value should be stored in the EEPROM cell. When `write_en` is low, the `data_out` should reflect the stored value of the cell.
