Design a Verilog module that implements a 10-bit binary up-counter with both synchronous and asynchronous resets. The counter should increment on the rising edge of the clock. The counter should reset to zero when the synchronous reset (sreset) is high or the asynchronous reset (areset) is high. The counter value should be output to the "count" signal.

module top_module
(
    input clk,
    input sreset,
    input areset,
    output reg [9:0] count
);
