Design a D flip-flop with additional control inputs for reset and set operations. On each clock edge, if the reset signal is active, the output q is set to LOW. If the set signal is active, the output q is set to HIGH. If neither control signal is asserted, q takes the value of the logical AND of a 3-bit input data, effectively outputting HIGH only when all three bits of the data input are HIGH.
module top_module(
    input clk,
    input reset,
    input set,
    input [2:0] data,
    output reg q
);
