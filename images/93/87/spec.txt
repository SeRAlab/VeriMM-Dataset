Create a 4-bit ripple-carry adder that computes the sum of two 4-bit inputs, A and B. The module utilizes a series of registers to hold intermediate carry values and constructs the output sum, S, as a 5-bit vector to accommodate potential overflow. Each bit of the sum is derived by performing a bitwise XOR operation between the corresponding bits of A and B, along with any carry from the previous bit addition. The design is intended to allow for sequential addition while managing carry propagation through registered states.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input CLK,
    output [4:0] S
);
