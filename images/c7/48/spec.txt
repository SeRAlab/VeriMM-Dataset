

You have been tasked with designing a verilog module for a 2-input AND gate. The module should have the following ports:

- `input A`
- `input B`
- `output Y`

Additionally, the module should have the following internal signals:

- `wire w1`
- `wire w2`

You must implement the AND gate using the internal signals `w1` and `w2`, and ensure that the output `Y` is equal to `A AND B`.
