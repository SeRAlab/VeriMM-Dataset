Design a simple hash table that takes a 5-bit input key and provides a 3-bit output index. The index is computed by taking the modulo of the key with a fixed size of the hash table (which we’ll assume is 8). The output should be valid only when the input key is not equal to the reserved value 5 (which indicates an invalid input). If the input key is 5, the output should be 3'bxxx to indicate an invalid state.
