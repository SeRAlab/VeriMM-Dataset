Design a synchronous data memory module that serves a dual purpose of reading and writing 32-bit data. The module utilizes a 32-bit address bus to access a memory array capable of storing 2^32 data words. When the clock signal rises, if the memWrite signal is asserted, data from writeData is stored in the memory at the specified address, and this data is also placed on the readDataMem output. If memRead is asserted without memWrite, the module outputs the data stored at the given address on readDataMem. This design acts as a memory unit for data storage and retrieval in digital systems.
