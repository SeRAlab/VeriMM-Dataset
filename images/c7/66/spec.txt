

Design a verilog module for a 4:1 MUX. The module should have four data inputs (A0, A1, A2, A3) and one output (Y). The module should also have two control inputs (S0, S1) which will select one of the four data inputs to be output to Y according to the following truth table:

| S1 | S0 | Y  |
|----|----|----|
| 0  | 0  | A0 |
| 0  | 1  | A1 |
| 1  | 0  | A2 |
| 1  | 1  | A3 |

You should use the following module definition:

```
module mux4to1 (
    input  A0,
    input  A1,
    input  A2,
    input  A3,
    input  S0,
    input  S1,
    output Y
);
```
