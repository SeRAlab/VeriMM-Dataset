
Design a simple Watchdog Timer in Verilog. The timer should have an input signal `reset` to restart the timer, an input signal `enable` to start the timer, and an output signal `timeout` that goes high if the timer reaches a specified count (for example, 8 counts). The timer should count clock cycles, and if `reset` is asserted, the timer should reset to zero. If `enable` is not asserted, the timer should not count.
