Design a Verilog module for a thermal sensor calibration system that takes a raw temperature reading and calibrates it based on a given offset value. The calibrated temperature should be outputted after a specific number of clock cycles, allowing for a delay in processing. The system should have an enable signal to start the calibration process. The input consists of a 10-bit raw temperature reading and a 6-bit offset value. The output should be a 10-bit calibrated temperature reading.
