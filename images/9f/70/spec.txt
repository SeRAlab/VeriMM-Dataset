Design a Music Sheet Reader module that manages the reading of a score based on musical note inputs. It starts reading when triggered by the Start signal and progresses through a sequence of notes indicated by KeyOutput. The module tracks the current address in the score using CurrentAddress, which is initialized to StartAddress. The reading state can be reset by the Reset signal, and the EndofScore output indicates when the reading is complete. The CurrentAddress increments with each note until a key is no longer pressed, at which point the State resets, allowing the reading cycle to start anew.
