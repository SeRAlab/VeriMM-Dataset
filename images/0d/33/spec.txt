Design an 8-bit Analog-to-Digital Converter (ADC) that takes a 3-bit input representing a voltage level (0 to 7) and produces an 8-bit output. The output should represent the input voltage level scaled to fit within the 8-bit range. For example, if the input is '000', the output should be '00000000', and if the input is '111', the output should be '11111111'. The output is obtained by multiplying the input value by 32.
