Design a module that integrates a 4-bit counter with a 4-bit adder/subtractor functionality. The counter increments its value on the positive edge of a clock signal or resets asynchronously when the RST input is low. The adder/subtractor takes two 4-bit inputs, A and B, and outputs their sum or difference based on the control input `sub`, which allows selection between addition and subtraction. Additionally, the module outputs an overflow signal that indicates if the result exceeds the 4-bit signed range. Finally, it combines the current counter value with the adder/subtractor result to produce a final 4-bit output.
module top_module(
    input [3:0] A,   // 4-bit input for adder/subtractor
    input [3:0] B,   // 4-bit input for adder/subtractor
    input sub,       // Input for adder/subtractor to choose between addition and subtraction
    input RST,       // Asynchronous active-low reset input for counter
    input clk,       // Clock input for the counter
    output [3:0] Q,  // 4-bit output from counter
    output [3:0] sum, // 4-bit output from adder/subtractor
    output overflow,  // Output from adder/subtractor to indicate overflow
    output [3:0] final_output // 4-bit output from functional module
);
