
Design a simple virtual memory management unit (MMU) that translates a virtual address to a physical address using a page table. Assume a fixed page size and a direct mapping from virtual pages to physical pages. The MMU should accept a virtual address and output the corresponding physical address. The page table for the MMU should be stored in a register, and each entry in the page table should represent a mapping from a virtual page number to a physical page number. The input virtual address should be 32 bits, and the output physical address should also be 32 bits.
