Design a digital FIR (Finite Impulse Response) low-pass filter that processes input samples to produce an output based on fixed filter coefficients. The module accepts an input data stream and, on each clock cycle, updates its internal sample memory while applying the filter coefficients to the current input and past samples. The output is calculated as a weighted sum of the current input and the stored samples, allowing for smoothing of the input signal. Upon receiving a reset signal, the internal sample memory is cleared, ensuring the filter starts from a known state.
