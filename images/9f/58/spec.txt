Design a circuit that functions as a conditional output generator based on the values of four input signals (A1, A2, B1, and B2). The module computes a sum of all four inputs and selectively modifies the output, X, based on the state of A1. If A1 is high (1), the output X equals the lower two bits of the sum with B1 and B2 added. If A1 is low (0), the output X simply reflects the total 4-bit sum.
module top_module(
    input A1,
    input A2,
    input B1,
    input B2,
    output X
);
