Design a combinational logic circuit in Verilog that computes the inverse of a 2x2 matrix. Given a 2x2 matrix represented as inputs `a`, `b`, `c`, and `d`, the inverse is calculated using the formula:
```
inverse(A) = (1/det(A)) * | d  -b |
                         | -c   a |
Where det(A) = ad - bc
If the determinant is zero, the output should be an indication that the inverse does not exist (e.g., output NaN or an error signal).
