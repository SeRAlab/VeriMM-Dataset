Design a basic 8-bit calculator that performs four arithmetic operations: addition, subtraction, multiplication, and division. The module takes two 8-bit inputs (a and b) and a 2-bit operation selector (op) to determine the operation to perform. The result of the operation is provided as an 8-bit output. For multiplication and division, the design includes overflow handling, capping the output at 0xFF if the result exceeds the maximum representable value for an 8-bit number. Additionally, the design prevents division by zero by outputting 0xFF when such an attempt is made.
module top_module(
    input [7:0] a,
    input [7:0] b,
    input [1:0] op,
    output reg [7:0] result
);
