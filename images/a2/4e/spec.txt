Design a 5-bit Johnson counter with asynchronous reset and enable control. The counter increments its value by shifting the bits to the left and introducing the inverted value of the most significant bit (MSB) at the least significant bit (LSB) on each clock cycle when enabled. Upon receiving a reset signal, it initializes the count to zero.
module top_module(
  input clk,
  input reset,
  input enable,
  output reg [4:0] count
);
