Design a 1-bit SRAM cell in Verilog, where the cell can store a single bit of data. The SRAM cell should have the following inputs: Data (D), Write Enable (WE), and Read Enable (RE). The output should be the stored data (Q). When WE is high, the data at D should be written into the cell. When RE is high, the stored data should be available at Q. Ensure that both write and read operations are regulated by their respective enable signals.
