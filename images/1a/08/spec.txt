Design an 8-bit ADC (Analog to Digital Converter) that converts an analog signal represented by a 3-bit binary input (0 to 7) into an 8-bit digital output. The conversion logic is as follows: each input value corresponds to a specific output value in a linear fashion, where input '0' maps to '00000000' and input '7' maps to '01111111'. The ADC should have a clock input to synchronize the conversion, and a reset input to reset the output to '00000000'.
