

You have been tasked with designing a module that implements a 2-to-1 multiplexer using Verilog. The module should have two data inputs, one select input, and one output. When the select input is 0, the output should be the same as the first data input. When the select input is 1, the output should be the same as the second data input.

Your module should be named "mux_2to1" and should have the following inputs and outputs:

- input [1:0] data_in: the two data inputs
- input sel: the select input
- output data_out: the output of the multiplexer

You should implement the module using only combinational logic and should not use any built-in Verilog constructs for multiplexers.

Write a Verilog module that meets the above specifications and provide the code for the module.
