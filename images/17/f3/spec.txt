
Design a power gating circuit that controls the power to a device based on a control signal. The circuit should have the following inputs:
- `control`: A 1-bit control signal.
- `power_in`: A 1-bit signal representing the incoming power.
The output should be:
- `power_out`: A 1-bit signal representing the output power to the device. If `control` is 0, `power_out` should be 0 (no power to the device). If `control` is 1, `power_out` should follow `power_in`.
