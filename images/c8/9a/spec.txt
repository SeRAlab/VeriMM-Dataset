

You have been tasked with designing a module that implements a 2-to-1 multiplexer using Verilog. The module should have two input signals, one select signal, and one output signal. If the select signal is 0, then the output should be the same as the first input. If the select signal is 1, then the output should be the same as the second input. 

Design a Verilog module that implements the 2-to-1 multiplexer functionality described above. Use the following module interface:

```
module mux_2_1(input [1:0] in, input sel, output out);
```

You can assume that the input signals are 1-bit wide and the output signal is also 1-bit wide.
