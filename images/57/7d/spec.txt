Implement the Verilog module based on the following description.
We want to create a 4-bit up/down counter that:

// (1) increments on a rising edge of the clock when the 'up' input is high,
// (2) decrements on a rising edge of the clock when the 'up' input is low,
// (3) wraps around when it reaches its maximum/minimum value,
// (4) provides a synchronous reset signal to set the counter to zero.

// The counter value is output on 'counter[3:0]'. The reset signal is active high synchronous.

module top_module(
    input wire clk,
    input wire reset,
    input wire up,
    output reg [3:0] counter
);
