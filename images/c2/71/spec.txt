

You are tasked with designing a module that takes in four inputs and produces one output. The module should be implemented in Verilog and should be no more than 200 lines of code. The module should be named `four_input_one_output` and should have the following inputs and outputs:

Inputs:
- `a` (1-bit)
- `b` (1-bit)
- `c` (1-bit)
- `d` (1-bit)

Outputs:
- `out` (1-bit)

The module should implement the following logic:
- If `a` is 1, `out` should be 1.
- If `a` is 0 and `b` is 1, `out` should be 1.
- If `a` is 0, `b` is 0, and `c` is 1, `out` should be 1.
- If `a` is 0, `b` is 0, `c` is 0, and `d` is 1, `out` should be 1.
- In all other cases, `out` should be 0.

Implement the `four_input_one_output` module in Verilog and test it using a testbench. The testbench should cover all possible input combinations.
