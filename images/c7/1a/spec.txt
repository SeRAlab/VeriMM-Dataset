

You are tasked with designing a module that performs a bitwise AND operation on two input bits and outputs the result. The module should be named "bitwise_and" and should have the following inputs and outputs:

Inputs:
- `a` (1-bit): the first input bit
- `b` (1-bit): the second input bit

Outputs:
- `out` (1-bit): the result of the bitwise AND operation

Your module should be able to handle both rising and falling edge clock signals. Additionally, the module should have a reset input named `reset` that sets the output to 0 when asserted.

Write a Verilog module named "bitwise_and" that meets these requirements. Your solution should be contained within 200 lines of Verilog code.
