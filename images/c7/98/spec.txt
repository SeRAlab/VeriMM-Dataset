

In digital design, a common operation is to add a constant value to an input signal. In this problem, you will implement a module that adds a constant value to a 4-bit input signal. The module should have two inputs: a 4-bit input signal, `in_val`, and a 4-bit constant value, `const_val`. The module should have one output: a 4-bit signal, `out_val`, which should be equal to the sum of `in_val` and `const_val`. If the sum of `in_val` and `const_val` is greater than 7 (i.e., 4'b0111), `out_val` should be set to 4'b0111.

You should implement the module using Verilog. Specifically, you should complete the following module definition:

```
module add_const(input wire[3:0] in_val, input wire[3:0] const_val, output reg[3:0] out_val);
// Your code here
endmodule
```

In your implementation, you should use only combinational logic (i.e., no sequential logic). You should also use the ternary operator (`?:`) to implement the conditional assignment of `out_val` when the sum of `in_val` and `const_val` is greater than 7.
