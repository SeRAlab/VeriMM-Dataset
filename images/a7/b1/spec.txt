Develop a Verilog module for a 12-bit ring counter with enable and asynchronous reset. The ring counter should have the following features:
// (1) enable: Enables the counter. Active high.
// (2) reset: Asynchronous reset of the counter. Active high.
// (3) clk: Clock signal.
// (4) q: 12-bit output of the counter.
module top_module(
	input clk,
	input enable,
	input reset,
	output reg [11:0] q);
