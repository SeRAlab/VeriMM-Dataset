Design a barrel shifter that performs variable left or right shifts on an 8-bit input based on a 3-bit shift amount and a direction control signal. When the direction signal is 0, the circuit left shifts the input; when the direction signal is 1, it right shifts the input. The output reflects the shifted value accordingly.
module top_module(
    input [7:0] in,
    input [2:0] shift_amount,
    input direction,
    output reg [7:0] out
);
