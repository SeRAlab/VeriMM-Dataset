
Design a 5-stage pipelined processor that can perform a simple instruction set consisting of ADD, SUB, AND, OR operations. The processor should have the following stages: Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). Each stage should be implemented as a separate module, and the data should flow through the pipeline correctly. The input to the processor will be a series of instructions, and the output should be the result of the operations performed.
