Design a circuit that performs division of two 4-bit binary numbers. The module takes a 4-bit `dividend` and a 4-bit `divisor` as inputs, producing a 4-bit `quotient` and a 4-bit `remainder` as outputs. If the `divisor` is zero, both the `quotient` and `remainder` are set to zero to handle the division by zero case safely.
module top_module(
    input [3:0] dividend,
    input [3:0] divisor,
    output reg [3:0] quotient,
    output reg [3:0] remainder
);
