Design a dual-edge detector circuit that identifies rising and falling edges of a single input signal. When the clock signal (clk) triggers, the module samples the input 'a' and checks for changes in its state. The output 'rise' is set high when a transition from low to high is detected, while the output 'down' is activated during a transition from high to low. The circuit includes asynchronous reset functionality, which initializes the outputs and internal registers to ensure reliable operation at startup.
module top_module(
  input               clk,
  input               rst_n,
  input               a,
  output reg          rise,
  output reg          down
);
