Design a Verilog module for a 16-bit shift register with synchronous load and shift operations. The shift direction should be controlled by a `shift_right` signal. On the rising edge of the clock, load the input data if the `load` signal is high, shift right if `shift_right` is high, or shift left otherwise.
module shift_register(
    input clk,
    input load,
    input shift_right,
    input [15:0] d,
    output reg [15:0] q);
