Design a packet filtering module that checks if incoming packets match allowed IP addresses. The module should have a 32-bit input for the packet IP address and a 32-bit input for allowed IP addresses. The output should be a single bit indicating whether the packet is allowed (1) or denied (0). The module should support checking against multiple allowed IPs, where the allowed IPs are provided as a 32-bit vector for simplicity, with each 32 bits representing a different allowed IP address.
