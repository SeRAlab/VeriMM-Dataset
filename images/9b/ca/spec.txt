Implement a Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state B (P = 1).
2. state C (P = 0).
3. state D (P = 1).
4. state E (P = 0).

State transitions:
1. From state B: If f = 0, then transition to state C. If f = 1, then transition to state D.
2. From state C: If f = 0, then transition to state E. If f = 1, then transition to state B.
3. From state D: If f = 0, then transition to state E. If f = 1, then transition to state C.
4. From state E: If f = 0, then transition to state D. If f = 1, then transition to state B.

Assume that you want to Implement the FSM using two flip-flops and state codes y[1:0] = 00, 01, 10, 11 for states B, C, D, E, respectively. Implement just the next-state logic for y[1] in Verilog. The output P is y[1].
