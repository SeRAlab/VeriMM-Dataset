When RN is low, the output Q is forced to low and QN to high. When SN is low, Q is set to high and QN to low. If both RN and SN are high, the output toggles between its current state and its complement whenever T is high; otherwise, it retains its value. This module effectively combines the functionalities of a D flip-flop with toggle capabilities and control inputs for asynchronous reset and set operations.

    input D,
    input T,
    input RN,
    input SN,
