Implement a 4-bit barrel shifter that shifts the input data (A) based on a 2-bit control signal (B). The shifter operates as follows: no shift occurs when B is 00, a 1-bit left shift occurs for B equal to 01, a 1-bit right shift happens for B equal to 10, and a 2-bit right shift is performed when B is 11. The output (Y) reflects the result of the shifting operation as per the specified control signal.
module top_module(
    input [3:0] A,
    input [1:0] B,
    output reg [3:0] Y // Change output to reg type
);
