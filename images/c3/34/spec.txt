Please act as a professional verilog designer. Create a module that implements a 2x2 Karnaugh map function f with inputs x[1:4] and outputs y. The Karnaugh map is as follows:

// x[1]x[2] // x[3]x[4]
00 01 11 10
// 00 | 1 | 0 | 0 | 1 |
// 01 | 0 | 0 | 0 | 0 |
// 11 | 1 | 1 | 1 | 0 |
// 10 | 1 | 1 | 0 | 1 |

The module should take 4 input bits and produce a single output bit based on the Karnaugh map. Implement the function using logic gates, and minimize the number of gates used.
