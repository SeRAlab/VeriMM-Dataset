Design a 4-input priority arbiter. The arbiter should grant one of the four request inputs (req0, req1, req2, req3) based on the priority, with req0 having the highest priority and req3 having the lowest. When a request is granted, the output (grant) should indicate which request received the grant (0001 for req0, 0010 for req1, 0100 for req2, and 1000 for req3). If no request is active, output should be 0000.
