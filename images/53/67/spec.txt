Design a 3-bit shift register with selectable shifting direction. Upon each clock pulse, the register can shift the bits either to the right or to the left based on the input `dir`: when `dir` is 0, the bits shift right and the new input is loaded at the least significant position; when `dir` is 1, the bits shift left, with the new input loaded at the most significant position. The output reflects the first or last register value depending on the direction of the shift.
module top_module(
    input clk,
    input dir,
    input [2:0] in,
    output reg [2:0] out
);
