Implement a simple 3x3 morphological dilation operation on a binary image represented as a 3-bit input. The input binary image is a 3x3 matrix where each bit represents a pixel (1 for foreground and 0 for background). The output should be a 3-bit representation of the dilated image. The dilation operation sets a pixel in the output to 1 if any of the corresponding pixels in the input is 1.
