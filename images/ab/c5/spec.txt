Then, it computes the XOR of inputs A and B and the XOR of inputs C and D, which further influences the final output by combining these results with the previous logic using another OR gate. The output Y reflects a mix of AND, OR, and XOR operations applied to the inputs, effectively implementing complex logic determined by the state of the four input signals.
module top_module(
    input A,
    input B,
    input C,
    input D,
    output Y
);
