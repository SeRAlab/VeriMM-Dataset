Design a 32-entry register file with 32-bit wide registers. This module allows reading from two specified registers (RS1 and RS2) and writing to a target register (RD) based on a clock signal (Clk) and a write enable signal (RegWr). On a rising edge of Clk, if RegWr is asserted and RD is not the zero register, the data (WData) is stored in the specified register. Outputs RD1 and RD2 provide the current values of the registers indexed by RS1 and RS2, respectively, returning zero if the corresponding index is zero. Additionally, the zero register is hardwired to always hold the value zero.
