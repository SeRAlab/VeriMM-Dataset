Design an 8-bit shift register with a parallel load feature. The shift register should have the following inputs: an 8-bit data input (D), a shift control input (SH), a load control input (LD), and a clock input (CLK). When LD is high, the register loads the input D. When SH is high, the register shifts its contents to the right. The least significant bit (LSB) should be filled with a 0 during a shift operation. The output of the shift register is an 8-bit output (Q).
