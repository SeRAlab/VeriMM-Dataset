Design a dynamic 8-bit shift register with a parallel load feature. When the load signal is asserted, the register captures and holds the input data. On the rising edge of the shift signal, the data is shifted to the left by one position, with a zero being shifted into the least significant bit. The current state of the shift register is outputted continuously through data_out.
module top_module(
    input [7:0] data_in,
    input shift,
    input load,
    output reg [7:0] data_out
);
