Design a memory interface module with 16KB of storage, where each memory location can hold 1 byte of data (8 bits). The interface is controlled by a clock signal (clka) and supports write operations when the write enable signal (wea) is asserted. It utilizes a 14-bit address input (addra) to access specific memory locations and can output 12 bits of data (douta) from these locations. If the write enable signal is activated, the module writes the lower 8 bits of the input data (dina) into the designated memory location; otherwise, it outputs the contents of that memory location. The module uses a tri-state logic for the output, ensuring that it does not drive douta when a write operation is in progress.
