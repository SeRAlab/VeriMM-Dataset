
Design a Verilog module that implements a simple Network Address Translation (NAT) functionality. The module should have two registers, one representing the internal IP address and the other representing the external IP address. The module should allow the following operations: 
1. Set Internal IP: Set the internal IP address
2. Set External IP: Set the external IP address
3. Translate: When this operation is triggered, it should output the corresponding external IP address based on the current internal IP address.
The module should also have a reset functionality to clear both IP addresses.
