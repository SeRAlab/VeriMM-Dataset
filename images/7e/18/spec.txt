Design a circuit that determines the maximum value among three 8-bit inputs (A, B, and C) and outputs this maximum value (max_val). The circuit first compares inputs A and B to find the greater value, then compares this temporary maximum with input C to produce the final maximum value. Additionally, it ensures that if all three inputs are equal, the output will reflect that common value.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input [7:0] C,
    output [7:0] max_val
);
