
Design a 16-bit digital-to-analog converter (DAC) that takes a 16-bit binary input and outputs a voltage level corresponding to the input value. The output voltage should be directly proportional to the input value, using a 5V reference. The DAC should utilize a simple binary-weighted resistor network to convert the digital input into the corresponding analog voltage. The output should be represented as a 12-bit integer value for simulation purposes, where 0 corresponds to 0V and 65535 corresponds to 5V.
