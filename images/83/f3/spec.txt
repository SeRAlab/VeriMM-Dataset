Design a programmable 8-bit up/down counter that increments or decrements its count based on the input signals. The counter resets to zero when the reset signal (rst) is active. The enable signal (enb) controls whether counting occurs, while the direction signal (dir) determines whether to increment (dir=1) or decrement (dir=0) the count on each rising edge of the clock (clk). If the counter is disabled, it maintains its current value.
module top_module(
    
  input rst,	
  input enb,	
  input dir,	
  input clk,	
  output reg [7:0] count	
    );
