
Design a simple Ethernet MAC controller that implements a transmit state machine. The state machine should have the following states: IDLE, TRANSMITTING, and WAIT_FOR_ACK. The controller should accept a transmit request, send data, and wait for an acknowledgment before returning to the IDLE state. The inputs to the state machine are `start_tx` (to initiate transmission), `ack` (to indicate successful transmission), and `data_in` (the data to be transmitted). The output should be `data_out` (the transmitted data) and `state` (current state of the machine).
