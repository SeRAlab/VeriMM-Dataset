Design a Verilog module for multiplying two 2x2 matrices A and B, producing a resultant matrix C, where A, B, and C are defined as follows:
Matrix A = [[a11, a12], [a21, a22]],
Matrix B = [[b11, b12], [b21, b22]],
Resultant Matrix C = [[c11, c12], [c21, c22]].
The elements of matrix C are calculated as:
c11 = a11*b11 + a12*b21,
c12 = a11*b12 + a12*b22,
c21 = a21*b11 + a22*b21,
c22 = a21*b12 + a22*b22.
