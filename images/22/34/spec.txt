
Create a Verilog module that implements a simple PNG filter, specifically the "None" filter which leaves the pixel values unchanged. The module should take an 8-bit pixel value as input and output the same pixel value. You should also implement a 3-bit control signal that indicates when the pixel is processed (1) or not (0). The output should follow the control signal: if the control signal is 0, the output should be 0; if it is 1, the output should match the input.
