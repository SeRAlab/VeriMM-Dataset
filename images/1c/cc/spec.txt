Design a combinational logic circuit that implements a simple Support Vector Machine (SVM) decision function. The circuit should take three 4-bit inputs (x1, x2, and w) representing two input features and a weight vector, and output a single bit (y) indicating the decision: 1 if the input pattern is classified as positive and 0 if classified as negative. The decision function is formulated as y = sign(x1 * w1 + x2 * w2 + b), where b is a bias term represented as a constant.
