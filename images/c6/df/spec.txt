

You are tasked with designing a verilog module that will take in a 4-bit input and output the same 4-bit value but with each bit inverted. The module should be named "INV4BITS" and should have two ports: "in" and "out". The "in" port should be an input port with a width of 4, and the "out" port should be an output port with a width of 4. 

Your implementation should use the bitwise NOT operator to invert each bit of the input. You should use a continuous assignment statement to assign the inverted value to the "out" port. The module should be synthesizable and should not use any procedural assignments.
