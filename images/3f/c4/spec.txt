Design a 16-bit SRAM cell that supports read and write operations. The SRAM cell should have an address input for selecting one of the 16 memory locations, a data input for writing data, a data output for reading data, a write enable signal (we), and a read enable signal (re). If we is high, the data input should be written to the selected address. If re is high, the data from the selected address should be output on the data output.
