Design a 4-bit binary counter with a finite state machine (FSM) architecture that counts up when the enable signal is active. The counter resets to zero on the reset signal. The FSM progresses through four states, each state allowing the counter to increment, but only when the enable signal is asserted. If the enable signal is deasserted, the counter reverts to the initial state, effectively pausing the counting process.
module top_module(
  input clk,
  input reset,
  input enable,
  output reg [3:0] count
);
