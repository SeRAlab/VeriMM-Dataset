

You have been tasked with designing a module in Verilog that takes in a 4-bit input and outputs a 1-bit output. The module should be named "four_bit_module" and should contain only one always block. The input should be named "input_data" and the output should be named "output_data". 

The module should perform the following operation: if the input is equal to 0b1010, the output should be 1, otherwise the output should be 0. 

Write the Verilog code for the "four_bit_module" module that implements this functionality.
