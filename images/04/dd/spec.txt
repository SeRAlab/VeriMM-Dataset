Design a 5-bit Parallel-in Parallel-out (PIPO) shift register. The register should have inputs for loading data in parallel, a clock signal, an active-high load signal, and an active-high enable signal. When the load signal is high, the register should load the input data on the next rising edge of the clock. When the enable signal is high, the register should output the current value on the output port. If both load and enable are low, the output should remain unchanged.
