
Design a 4-bit SRAM cell with read and write operations. The SRAM cell should consist of four bits, and it should have two inputs: a 4-bit data input (D) and a write enable signal (WE). The output should be a 4-bit data output (Q) that reflects the contents of the SRAM cell when the write enable signal is low. When WE is high, the data input should be written to the SRAM cell.
