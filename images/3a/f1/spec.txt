
Implement a power gating controller in Verilog that manages the power state of a device based on a clock signal and a power control signal. The controller should have an input clock, a power control signal (active high), and an output state signal indicating whether the device is powered on or off. The device should power on when the power control signal is high and the clock edges trigger the state change. If the power control signal goes low, the device should power off on the next clock edge.
