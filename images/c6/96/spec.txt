

You are given a Verilog module `bar` with the following inputs and outputs:

- `clk`: a clock input
- `rst`: a synchronous reset input
- `in`: a 32-bit input 
- `out`: a 32-bit output

The module should perform the following operations:
- On the rising edge of `clk` and when `rst` is high, `out` should be set to the value of `in` multiplied by 2.
- On the rising edge of `clk` and when `rst` is low, `out` should be set to the value of `in` divided by 2.

Write the Verilog code for the `bar` module that performs the above operations.
