Design a simple 8-bit calculator module that performs arithmetic operations based on a 4-bit control signal. The module accepts two 8-bit inputs, `a` and `b`, and produces an 8-bit output `result`. Depending on the value of the control signal, the calculator can perform addition, subtraction, multiplication, and division. Specifically, the operations performed are addition for control code 0000, subtraction for 0001, multiplication for 0010, and division for 0011. If the control code does not match any of these operations, the result defaults to zero.
module top_module(input [7:0] a, b, input [3:0] control, output reg [7:0] result);
