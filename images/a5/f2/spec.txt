Design a 32-bit Arithmetic Logic Unit (ALU) capable of performing several operations based on a 4-bit function code. This module takes two 32-bit inputs, in1 and in2, and based on the lower three bits of the function code (func), it performs bitwise AND, OR, XOR, XNOR, addition with carry, sign extension of the result, and a less-than comparison. Additionally, the most significant bit of the sum is utilized to indicate the sign of the result when required. If the high-order bit of the function is set, the second input can be inverted before the arithmetic operation. The ALU outputs the result in the aluout register.
module top_module(input [31:0] in1, in2, 
            input [3:0] func, 
            output reg [31:0] aluout);
