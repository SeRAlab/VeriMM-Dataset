Design a 4-bit binary counter that counts upward on each clock cycle. The counter is reset asynchronously when the reset signal is asserted, setting the count to zero and the overflow flag to low. Upon reaching the maximum count of 15, it wraps around to zero on the next clock cycle and sets the overflow flag high to indicate that an overflow has occurred.
module top_module(
    input clk,
    input reset,
    output reg [3:0] count,
    output reg overflow
);
