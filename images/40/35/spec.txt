
Design a state-space controller that implements a simple closed-loop system. The controller should manage the system's output based on the state and an input control signal. The state-space representation is defined as follows:
1. The state update equation is: x_next = Ax + Bu
2. The output equation is: y = Cx + Du
Where A, B, C, and D are defined matrices for the state-space system. Assume that A, B, C, and D are 2x2 matrices and 1x2 matrices respectively. The input 'u' is a 1-bit control signal which affects the state transition. The system should have an initial state of x = [0, 0].
