

You are tasked with designing a verilog module for a 2-to-1 multiplexer. The module should have two input signals, `A` and `B`, and one select signal, `S`. If `S` is high, the output should be equal to `A`, and if `S` is low, the output should be equal to `B`. You are not allowed to use the ternary operator in your solution.

Design your module to include the following:
- Declare the module name as `mux_2to1`
- Declare the input and output signals as `input A, B, S` and `output Y` respectively
- Use the `always` block to implement the functionality of the module
- Use `if-else` statements to determine the output based on the value of `S`
- Use `assign` statements to set the value of `Y` based on the output determined in the `always` block
