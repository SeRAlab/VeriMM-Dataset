Design a J-K flip-flop with asynchronous clear functionality. The flip-flop toggles its output Q based on the values of inputs J and K at the rising edge of the CLK signal. When CLR is asserted (low), the output Q is reset to 0 regardless of the J and K inputs. If J is high and K is low, Q is set to 1; if J is low and K is high, Q is reset to 0; if both J and K are high, Q toggles its state.
module top_module(
    input wire J,
    input wire K,
    input wire CLK,
    input wire CLR,
    output reg Q);
