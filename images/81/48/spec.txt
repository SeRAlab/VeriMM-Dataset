Design a circuit that converts a 4-bit signed magnitude representation into its 2's complement form. If the sign bit (the MSB) of the input is 1, indicating a negative number, the module computes the 2's complement by inverting the input bits and adding one. If the sign bit is 0, the output is simply the same as the input.
module top_module(
    input [3:0] signed_mag,
    output reg [3:0] twos_comp
);
