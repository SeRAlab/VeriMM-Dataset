Design a 32-bit barrel shifter. This module takes a 32-bit input 'data' and a 5-bit 'shift_amount' that specifies how many positions to shift. The 'shift_direction' input determines the direction of the shift: if 'shift_direction' is high, it performs a left shift; if low, a right shift. The result is output as 'shifted_data'.
module top_module(
    input [31:0] data,
    input [4:0] shift_amount,
    input shift_direction,
    output [31:0] shifted_data
);
