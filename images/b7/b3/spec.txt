Design a 4-to-1 multiplexer that selects one of four one-bit input signals (in0, in1, in2, in3) based on two select lines (sel0 and sel1). The output is determined as follows: if sel1 and sel0 are both high, output in3; if sel1 is high and sel0 is low, output in2; if sel1 is low and sel0 is high, output in1; and if both select lines are low, output in0.
module top_module(
    in0,
    in1,
    in2,
    in3,
    sel0,
    sel1,
    out
);
