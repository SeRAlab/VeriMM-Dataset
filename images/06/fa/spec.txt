
Design a simplified NVMe controller state machine in Verilog that handles command processing states. The controller should have the following states: IDLE, PROCESS, and DONE. The state transitions are as follows:
- From IDLE to PROCESS on input signal `start`.
- From PROCESS to DONE on input signal `done`.
- From DONE back to IDLE on input signal `reset`.
Implement the state machine that outputs the current state as a 2-bit binary value.
