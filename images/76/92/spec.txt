Design a 4-bit comparator module that evaluates two pairs of 4-bit inputs (A, B) and (C, D). It outputs a signal indicating equality (EQ) when A equals B and C equals D, and a greater-than signal (GT) when either A is greater than B or, if A equals B, when C is greater than D. If neither condition is met, both output signals are set to LOW.
module top_module(
    input [3:0] A, B, C, D,
    output reg EQ, GT
);
