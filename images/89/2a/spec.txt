Design a dual-function 8-bit counter with load capability. The counter increments the lower 4 bits (LSBs) on each positive clock edge, rolling over from 9 to 0 and triggering an increment of the upper 4 bits (MSBs) when the LSBs reach 10. An external signal allows loading a new value into the counter; when the load signal is active, the counter's output is directly set to the specified 8-bit input value.
module top_module(
  input clk, load, 
  input [7:0] in,
  output reg [7:0] out);
