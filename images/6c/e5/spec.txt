Implement a parameterized N-bit Johnson counter. The counter should have a synchronous reset and a single clock input. The width of the counter should be parameterized.

Module name:
    johnson_counter

Input ports:
    clk: Clock signal used to synchronize the Johnson counter.
    rst: Reset signal. Defined as 1 for reset and 0 for reset signal inactive.

Output ports:
    q: N-bit output representing the current state of the Johnson counter.

Parameter:
    N = 4
