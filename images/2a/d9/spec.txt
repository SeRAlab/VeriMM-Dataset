Design a 1-bit SRAM cell in Verilog that can store a single bit of data. The cell should have the following inputs: a write enable (we), a data input (d), an enable signal (en), and an output (q). When the enable signal is high and the write enable is high, the data input should be written to the cell. When the enable signal is high and the write enable is low, the output should reflect the stored data. If the enable signal is low, the output should be high impedance (Z).
