

You are tasked with designing a module that implements a 4-bit adder with carry. The module should have two 4-bit inputs, A and B, and one 4-bit output, S. The output S should be the sum of A and B, modulo 16. In addition, the module should output a carry bit, C, which should be 1 if the sum of A and B is greater than or equal to 16, and 0 otherwise.

You should write a Verilog module that implements this 4-bit adder with carry. Your module should be named "adder4" and should be contained within a file named "adder4.v". Your module should be no longer than 200 lines of code.

Your module should have the following interface:

```verilog
module adder4 (
  input [3:0] A,
  input [3:0] B,
  output [3:0] S,
  output C
);
```

The inputs A and B are the two 4-bit numbers to be added together. The output S is the 4-bit sum of A and B, modulo 16. The output C is the carry bit, which is 1 if the sum of A and B is greater than or equal to 16, and 0 otherwise.

Your module should be fully synthesizable and should be tested using a testbench.
