Create a module that implements a 3-bit binary up/down counter. The counter increments when the up signal is high and decrements when the down signal is high. If both signals are high or low, the counter does not change.

Module name:
    up_down_counter_3bit

Input ports:
    clk: Clock signal for synchronous operation.
    rst: Synchronous reset signal. When high, the counter resets to zero.
    up: Control signal to increment the counter.
    down: Control signal to decrement the counter.

Output ports:
    count: 3-bit output representing the current counter value.

Provide the complete code for this module.
