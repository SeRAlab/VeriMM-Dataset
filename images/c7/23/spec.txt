

Create a verilog module named "U2" that takes two inputs, "A" and "B", and one output, "OUT". The module should perform the following operation: if "A" is greater than or equal to "B", then "OUT" should be set to the value of "A" minus "B". Otherwise, "OUT" should be set to the value of "B" minus "A". 

You should use the "ternary operator" to implement this operation. The ternary operator has the following syntax: 

(condition) ? (value if true) : (value if false)

Your module should have the following ports:

- input [7:0] A
- input [7:0] B
- output [7:0] OUT

You should use the "always @(*)" construct to implement your module.
