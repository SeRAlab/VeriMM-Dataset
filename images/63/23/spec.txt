Design a one-bit wide, 2-to-1 multiplexer. The module takes two inputs, A and B, and a select signal, SEL. When SEL is low (0), the output Y is determined by input A; when SEL is high (1), the output Y is determined by input B. The design uses basic logic gates, including NOT, AND, and OR, to route the selected input to the output based on the state of the select line.
module top_module(
  input A,
  input B,
  input SEL,
  output Y
);
