Design a 1-bit DRAM cell with read and write functionalities. The DRAM cell should have an input data signal (D), a read enable signal (RE), a write enable signal (WE), and a clock signal (CLK). The output should be the stored data (Q). The design should ensure that on a write operation, the data signal D is stored in Q when WE is high, and on a read operation, Q should output the stored data when RE is high.
