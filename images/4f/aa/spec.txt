It uses a 24-bit counter to track time intervals for each light state, toggling green for 15 seconds, yellow for 3 seconds, and red for 12 seconds, all governed by a 50 MHz clock. The module also incorporates an asynchronous reset input that initializes the system, setting the lights to the green state while resetting the counter. This controller ensures proper sequential lighting of traffic signals for safe vehicle and pedestrian movement.
module top_module(
  input clk,
  input rst,
  output reg red,
  output reg yellow,
  output reg green
);
