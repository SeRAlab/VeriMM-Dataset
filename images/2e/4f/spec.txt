Design a simple interrupt controller that can handle multiple interrupt requests. The controller should have three inputs: `IRQ0`, `IRQ1`, and `IRQ2`, representing interrupt requests from different devices. It should have one output `INT`, which signals that an interrupt is being processed. The controller should prioritize the interrupts as follows: `IRQ0` > `IRQ1` > `IRQ2`. When an interrupt is received, the output `INT` should be activated for one clock cycle. The `ack` signal will be used to acknowledge the interrupt and clear the output.
