Design a one-shot pulse generator that produces a single output pulse (ENos) in response to the transition of the input push button (PB). The module samples the PB input on each rising edge of the clock (CLK) and uses flip-flops to create a delayed version of the PB signal. When PB is pressed, the output ENos is activated for one clock cycle, regardless of the PB's continuous state. This provides a clean pulse signal suitable for triggering other circuits without bouncing issues.
module top_module(
    input PB,
    input CLK,
    output ENos
    );
