Design a 4-bit up/down counter that can be either reset to zero or loaded with a given value. The counter increments when the up_down signal is high and decrements when it is low, updating its output on the positive edge of the clock. The counter's current value is output through the count register, allowing bidirectional counting functionality as specified by the control inputs.
module top_module(
    input clk,
    input reset,
    input load,
    input up_down,
    output reg [3:0] count
);
