Design an interrupt controller that manages two types of interrupts: high priority and low priority. The controller should have the following inputs: a clock signal `clk`, a reset signal `reset`, two interrupt requests `int_req_high` and `int_req_low`, and an output signal `int_ack` that acknowledges the highest priority interrupt request. The controller should prioritize `int_req_high` over `int_req_low`. When an interrupt request is asserted, the controller should output an acknowledgment signal `int_ack` for the highest priority interrupt. If both interrupts are requested simultaneously, `int_ack` should indicate the high priority interrupt.
