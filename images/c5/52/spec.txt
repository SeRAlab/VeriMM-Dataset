

You are tasked with designing a Verilog module to implement a 2-input AND gate with an enable input. The module should have the following inputs and outputs:

- `input a`: a single bit input
- `input b`: a single bit input
- `input enable`: a single bit input
- `output out`: a single bit output

The output should be the result of the AND operation between `a` and `b`, but only when `enable` is high. If `enable` is low, the output should be 0.

Your Verilog module should be named `and_enable` and should be contained within a single file that is no more than 200 lines long.
