Design a combinational logic circuit that implements a simple decision tree for classifying based on two binary inputs, A and B. The output Y should be determined as follows:
- If A is 0 and B is 0, then Y = 0
- If A is 0 and B is 1, then Y = 1
- If A is 1 and B is 0, then Y = 1
- If A is 1 and B is 1, then Y = 0
