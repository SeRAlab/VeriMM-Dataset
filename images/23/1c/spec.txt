Design a data forwarding unit that takes two register values (rs1, rs2) and a forwarding control signal (forward_sel). The output is the forwarded register value (forwarded_data). The forwarding control signal determines which of the two input register values should be forwarded based on the following criteria:  
- If forward_sel is 00, output rs1.  
- If forward_sel is 01, output rs2.  
- If forward_sel is 10, output rs1 (indicating rs1 is the latest value).  
- If forward_sel is 11, output rs2 (indicating rs2 is the latest value).  
Ensure the module is designed to handle all possible values of forward_sel.
