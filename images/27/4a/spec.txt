
Create a simple Verilog module that simulates a Flash memory cell behavior. The module should have a write and read functionality. The write operation should store data into the memory cell, and the read operation should retrieve the data. The memory cell should be a 1-bit storage, and the operations should be controlled by a clock signal. The module should have the following inputs and outputs:
- Input: `clk` (clock signal), `write_enable` (to allow writing), `data_in` (1-bit data to be written).
- Output: `data_out` (1-bit data read from the memory).
