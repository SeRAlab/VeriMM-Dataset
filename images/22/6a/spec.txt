
Create a simple PCIe endpoint controller that has the following functionalities:
1. It should accept 8-bit data input along with a 1-bit valid signal.
2. When the valid signal is high, the data should be latched onto a 16-bit output register on the rising edge of a clock.
3. The output should also include a ready signal that indicates when the data has been latched.
4. After latching, the controller should wait for the valid signal to go low before it can accept new data.
