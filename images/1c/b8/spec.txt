Design a checksum generator and verifier in Verilog. The circuit should take an 8-bit data input and generate an 8-bit checksum. The generator should compute the checksum by summing the data bits and then taking the 8 least significant bits of the sum. The verifier should check if the received checksum matches the computed checksum from the received data. If they match, the output should indicate data integrity (valid), otherwise, it should indicate data corruption (invalid).
