Design a 4-to-1 multiplexer that selects one of four 1-bit input signals (A, B, C, D) based on a 2-bit selection input (S). The output (Y) will reflect the selected input; when S selects a specific input combination, that input will be passed to the output, effectively allowing for the routing of one input to a single output line based on the selection criteria.
module top_module(
    input [3:0] A, B, C, D,
    input [1:0] S,
    output Y
);
