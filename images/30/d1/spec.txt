Design a Verilog module that simulates a simple Recurrent Neural Network (RNN) cell. The RNN cell will take an input vector of size 4, a hidden state of size 4, and produce an output vector of size 4. The output is calculated as a weighted sum of the input and the hidden state. The weights for the input and hidden state will be hardcoded in the design. The RNN cell should also have a clock and reset signal. On each rising edge of the clock, when reset is low, the RNN should compute the new hidden state and output vector based on the input and the previous hidden state. If reset is high, the hidden state and output should be reset to zero.
