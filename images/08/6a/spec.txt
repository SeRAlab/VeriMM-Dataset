
Design a 32-bit deserializer that takes an 8-bit input data stream and converts it into a 32-bit output. The deserializer should shift the input data into the output on every clock cycle, such that after 32 clock cycles, the output will be fully populated with the 32 bits of data. The input is provided through an 8-bit input signal, and the output is a 32-bit signal. The deserializer should also have a reset signal to clear the output.
