Implement the Verilog module based on the following description.
We want to create a module that:

// (1) receives two 8-bit binary numbers,
// (2) compares them,
// (3) sets the output 'is_equal' to 1 if the numbers are equal, otherwise 0,
// (4) provides a reset mechanism to reset the output.

// The input binary numbers are available on the input signals 'binary_num1' and 'binary_num2'. The reset signal is active high synchronous.

module compare_numbers_module(
    input wire clk,
    input wire reset,
    input wire [7:0] binary_num1,
    input wire [7:0] binary_num2,
    output reg is_equal
);
