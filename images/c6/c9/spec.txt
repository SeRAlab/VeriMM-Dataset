You should create a module named `mux_2to1` that implements this functionality. The module should have the following input and output ports:

- `input A`: a 1-bit input signal
- `input B`: a 1-bit input signal
- `input SEL`: a 1-bit input signal
- `output Y`: a 1-bit output signal

You should use the `always` block to implement the functionality of the 2-to-1 multiplexer. You are not allowed to use any built-in verilog constructs or modules to implement the functionality of the 2-to-1 multiplexer.
