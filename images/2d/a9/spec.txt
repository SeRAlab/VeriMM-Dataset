
Design a simple portfolio optimization module that takes in the weights of three assets and calculates the total portfolio return based on the returns of each asset. The portfolio return can be calculated as:
Portfolio Return = w1 * r1 + w2 * r2 + w3 * r3
where w1, w2, and w3 are the weights of the assets (given as 4-bit binary values) and r1, r2, and r3 are their respective returns (given as 4-bit binary values). The output should be a 5-bit binary value representing the total return.
