
Design a simple ARQ (Automatic Repeat reQuest) system using Verilog. The system should transmit a 5-bit data word and check for an acknowledgment (ACK) from the receiver. If an ACK is received, the system should move to the next data word; if a NACK (negative acknowledgment) is received, the same data word should be resent. Implement a simple state machine that handles the state transitions based on the acknowledgment.
