

You are designing a verilog module for a simple calculator. The module should be able to perform addition and subtraction of two 4-bit numbers, and output the result in a 4-bit binary format. The module should have the following inputs and outputs:

**Inputs**
- `in1`: A 4-bit binary number
- `in2`: A 4-bit binary number
- `op`: A 1-bit control signal to select the operation to be performed. If `op` is 0, then addition should be performed, and if `op` is 1, then subtraction should be performed.

**Outputs**
- `out`: A 4-bit binary number representing the result of the operation.

Write a verilog module that implements the above functionality. You can assume that the inputs `in1` and `in2` will always be valid 4-bit binary numbers.
