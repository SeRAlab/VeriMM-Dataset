
Design a Verilog module for a Flash memory cell that can store a single bit of data. The cell has a control signal `write`, a data input `d`, a read signal `read`, and an output `q` that provides the stored data. The behavior of the memory cell is as follows:
- When `write` is high, the value of `d` is stored in the memory cell.
- When `read` is high, the output `q` reflects the stored value.
- If neither `write` nor `read` is active, the output `q` should retain the last stored value.
