Design a 4-bit FIFO queue with a depth of 4. The FIFO should have inputs for data, write enable (we), read enable (re), and a clock signal (clk). The outputs should include the data at the front of the queue (out) and the number of items in the queue (count). Implement overflow and underflow conditions. When the FIFO is full and a write is attempted, the FIFO should not accept new data. When the FIFO is empty and a read is attempted, the output should be undefined.
