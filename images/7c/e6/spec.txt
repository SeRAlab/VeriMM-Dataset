Design a simple arithmetic and logic unit (ALU) that facilitates various operations on two 8-bit inputs, A and B, based on a 3-bit operation selector, OP. The ALU supports addition, subtraction, bitwise AND, OR, XOR, left and right shifts, and bitwise NOT operations. Additionally, it includes a reset functionality that sets the output, C, to zero when the RESET_B input signal is triggered.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input [2:0] OP,
    input RESET_B,
    output reg [7:0] C
);
