Design a simple branch predictor using a 2-bit saturating counter. The predictor should take the current state (00, 01, 10, 11) and a branch input (0 for not taken, 1 for taken) to update the state. The states should represent:  
00 - Strongly Not Taken  
01 - Weakly Not Taken  
10 - Weakly Taken  
11 - Strongly Taken  
The state should change based on the input and should output the prediction (0 or 1).
