Design a Verilog module that models a 16-bit register with synchronous reset and enable signals. The module should have an input clock signal (clk), an input enable signal (en), an input synchronous reset signal (rst), and a 16-bit output signal (data). On the rising edge of the clock, if reset is high, data should be set to 0. If enable is high, data should load the value from the 16-bit input signal (din).
