Develop a Verilog module for a combinational logic circuit with four inputs h, i, j, and k, and one output l. The behavior should be defined by the following conditions:

If h = 0, i = 0, j = 1, k = 1, then l = 1.
If h = 1, i = 1, j = 0, k = 0, then l = 0.
If h = 1, i = 0, j = 1, k = 1, then l = 1.
If h = 0, i = 1, j = 0, k = 0, then l = 1.
If h = 1, i = 1, j = 1, k = 1, then l = 1.

module combinational_circuit (
	input h,
	input i,
	input j,
	input k,
	output reg l);
