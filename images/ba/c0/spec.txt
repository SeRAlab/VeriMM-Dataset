Design a circuit that concatenates and processes two inputs, a 4-bit value A and a 2-bit value B, to produce a 3-bit output Z. If the 4-bit input A is greater than 7, output Z will be set to 111. If the 2-bit input B is greater than 3, output Z will be set to 000. Otherwise, output Z will be formed by concatenating the two most significant bits of A, the value of B, and the two least significant bits of A, resulting in a combined 6-bit representation truncated to 3 bits for output.
module top_module(
    input [3:0] A,
    input [1:0] B,
    output reg [2:0] Z
    );
