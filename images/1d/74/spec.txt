
Design a Verilog module for a Flash memory cell that simulates a simple read and write operation. The memory cell should have the following ports:
- `clk`: Clock input
- `write_enable`: A control signal to enable writing data
- `data_in`: 8-bit input data to be written to the memory cell
- `data_out`: 8-bit output data to be read from the memory cell
- `reset`: Active high reset signal to clear the memory cell

The memory cell should retain its value until it is written to, and it should output the stored value when read.
