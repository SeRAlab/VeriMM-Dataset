

You have been tasked with designing a verilog module that takes in two 8-bit inputs, `A` and `B`, and outputs their sum. However, the module should also have a control input `C` which determines whether the output should be the sum of `A` and `B` or the difference between `A` and `B`. If `C` is high, the output should be `A` + `B`. If `C` is low, the output should be `A` - `B`. 

Design a verilog module that meets the above specifications.
