
Design a simple EEPROM cell in Verilog. The EEPROM cell should have the following functionality:
- It has a data input (D), a write enable signal (WE), and a read enable signal (RE). 
- When WE is high, the value on the data input (D) should be stored in a register.
- When RE is high, the value stored in the register should be output on a data output (Q).
- If both WE and RE are low, the output Q should maintain its last value without changing.
