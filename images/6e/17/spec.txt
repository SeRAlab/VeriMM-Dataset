Implement the Verilog module based on the following description.
We want to create a module that:

// (1) receives an 8-bit binary number,
// (2) checks if the number is divisible by 5,
// (3) counts the number of 1s in the binary number,
// (4) outputs a flag if the number is a perfect cube,
// (5) provides a reset mechanism to reset all outputs.

// The input binary number is available on the input signal 'binary_num'. The output 'is_divisible_by_5' should be set to 1 if the number is divisible by 5 and 0 otherwise. The number of 1s in the binary number should be output on 'count_ones[3:0]'. The perfect cube flag should be set on 'is_perfect_cube' if the number is a perfect cube. The reset signal is active high synchronous.

module top_module(
    input wire clk,
    input wire reset,
    input wire [7:0] binary_num,
    output reg is_divisible_by_5,
    output reg [3:0] count_ones,
    output reg is_perfect_cube
);
