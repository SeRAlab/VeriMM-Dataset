
Design a Verilog module that performs matrix factorization for a recommendation system using Singular Value Decomposition (SVD). The module should take in a matrix of size NxM and output two matrices of size NxK and KxM, where K is the rank of the factorization. The rank K should be a configurable parameter. The module should handle the updating of the matrices iteratively based on a learning rate and should have a state to keep track of the current iteration.
