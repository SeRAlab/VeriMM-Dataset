Design a simple 5-stage instruction pipeline in Verilog. The pipeline consists of the following stages: Fetch (IF), Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). Each stage takes one clock cycle, and you need to implement the control logic to handle the instruction flow through the stages. The system should be able to handle a pipeline hazard and stall the pipeline in case of a data hazard.
