Implement the Verilog module based on the following description.
Build a 2-bit binary counter with asynchronous positive edge triggered reset, synchronous enable signal, and synchronous active high clear signal.
(1) reset: Resets counter to zero.
(2) enable: Enables the counter to count up.
(3) clear: Clears the counter to zero.
(4) q: The current value of the counter.

module top_module(
    input clk,
    input reset,
    input enable,
    input clear,
    output reg [1:0] q);
