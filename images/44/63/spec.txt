Design a clock generator that produces a divided output clock signal based on an input clock and a division factor. When the reset signal is active, the output clock and the internal counter are reset. If the clock enable signal is asserted, the module toggles the output clock signal after counting up to the specified division value. If the division factor is set to zero, the module directly passes the input clock to the output.
module top_module(input clk_i,input reset_n_i,input clk_en,input [3:0] clk_div_i,output clk_o);
