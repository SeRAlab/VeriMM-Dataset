Design a digital logic circuit that generates two outputs based on three input signals (x, y, z). The first output, out1, is determined by the condition that either both x and y are true or z is false. The second output, out2, is activated if y is true while x is false, or z is true. This module effectively implements a combinational logic function with specific conditions for each output.
module top_module(
  input x,
  input y,
  input z,
  output reg out1,
  output reg out2
);
