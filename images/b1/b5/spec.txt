Design a basic arithmetic calculator that performs addition, subtraction, multiplication, and division on two 8-bit input values (in1 and in2). The operation to be performed is determined by a 2-bit operation code (op) which selects the corresponding arithmetic function. The module includes a clock input (clk) for synchronous operation, a reset input (rst) to clear the result, and a clear input (clr) to reset the result to zero. The calculated result is then output as an 8-bit value.
module top_module(
    input clk,
    input rst,
    input [1:0] op,
    input [7:0] in1,
    input [7:0] in2,
    input clr,
    output reg [7:0] out
);
