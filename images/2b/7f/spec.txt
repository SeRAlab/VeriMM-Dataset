Design a 16-to-4 priority encoder in Verilog. The encoder should have 16 input lines (I0 to I15) and 4 output lines (Y0 to Y3) that represent the binary value of the highest priority active input. The encoder should also have a valid output (V) that indicates if any input is active. The highest priority is given to I15, followed by I14, and so on down to I0.
