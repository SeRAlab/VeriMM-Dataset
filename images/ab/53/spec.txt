Implement a Verilog module for a 12-bit register with enable and asynchronous set. The register should have a clock input `clk`, an asynchronous set input `set`, an enable input `en`, a 12-bit data input `D`, and a 12-bit output `Q`. When `set` is high, `Q` should be set to all 1s. When `en` is high, `Q` should be set to `D` on the rising edge of `clk`.

module register12(
	input wire clk,
	input wire set,
	input wire en,
	input wire [11:0] D,
	output reg [11:0] Q
);
