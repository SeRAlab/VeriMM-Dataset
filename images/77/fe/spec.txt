Design a simple synchronous memory module with a 32-word (32x32-bit) addressable array. The module supports read and write operations controlled by input signals `mem_read` and `mem_write`, respectively. On a read operation, the data at the specified aligned address is output, while unaligned addresses trigger an error message. Additionally, it initializes the memory with predetermined values upon startup. This design includes basic address decoding to ensure only the specified `BASE_ADDRESS` is accessible, with operations synchronized to the clock signal for writes.
module top_module(clk, mem_read, mem_write, address, data_in, data_out);
