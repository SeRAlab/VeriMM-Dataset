Design an 8-bit DRAM cell that can store a single bit of data. The cell should have the following inputs: an 8-bit data input (`data_in`), a write enable signal (`we`), and a clock signal (`clk`). The output should be an 8-bit data output (`data_out`). When the `we` signal is high, the value of `data_in` should be stored in the DRAM cell on the rising edge of the clock. When `we` is low, the `data_out` should reflect the current stored value in the DRAM cell.
