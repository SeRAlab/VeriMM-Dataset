Design an SR flip-flop using Verilog. The flip-flop should have inputs S (Set), R (Reset), and a clock input CLK. The outputs should be Q and Qn (not Q). The SR flip-flop should follow the typical behavior where:
- If S = 1 and R = 0, Q is set to 1.
- If S = 0 and R = 1, Q is reset to 0.
- If S = 0 and R = 0, Q retains its previous state.
- If S = 1 and R = 1, it is an invalid state and should be treated as no change (retain state).
