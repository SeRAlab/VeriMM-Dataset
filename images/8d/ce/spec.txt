Design a 4-bit digital adder/subtractor that selects between addition and subtraction based on a control signal. When the control signal is high, the module computes the sum of inputs a and b; when the control signal is low, it computes the difference. The results are registered and output accordingly, allowing for sequential operation triggered by the positive edge of the control signal.
module top_module(
    input [3:0] a,
    input [3:0] b,
    input control,
    output reg [3:0] out
);
