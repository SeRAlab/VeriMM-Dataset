

You have been tasked with designing a digital circuit that performs a bitwise AND operation between two 8-bit input vectors, A and B. The result of the operation should be stored in an 8-bit output vector, C. 

Design a Verilog module that implements this circuit. The module should have the following inputs and outputs:
- A: an 8-bit input vector
- B: an 8-bit input vector
- C: an 8-bit output vector

Your design should use the "AND" operator to perform the bitwise AND operation. You may not use any other operators or functions to perform this operation. 

Write a testbench to verify that your design is correct. Your testbench should generate random input vectors A and B, and compare the output vector C produced by your design to the expected output vector.
