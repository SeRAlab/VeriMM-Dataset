Design a DES (Data Encryption Standard) module that implements a simplified version of the DES algorithm. The module should take a 64-bit input plaintext and a 64-bit key, and produce a 64-bit ciphertext. The module should include the following components: initial permutation, key schedule, function f, and final permutation. You may simplify the design by using a reduced number of rounds (for example, 2 rounds) and a simplified f function.
