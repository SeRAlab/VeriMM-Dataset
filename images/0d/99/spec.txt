
Create a LIFO stack module in Verilog that allows for pushing and popping 8-bit data. The stack should have a 4-bit depth, meaning it can hold up to 16 8-bit values. The stack should have the following ports:
- clk: clock signal
- rst: reset signal (active high)
- push: push signal (active high)
- pop: pop signal (active high)
- data_in: 8-bit input data for pushing onto the stack
- data_out: 8-bit output data for popping from the stack
- empty: indicates if the stack is empty (1 if empty, 0 otherwise)
- full: indicates if the stack is full (1 if full, 0 otherwise)
