Design a 4-bit adder/subtractor unit that performs addition or subtraction on two 4-bit input values, A and B, based on a control signal C. When C is low, the module computes the sum of A and B. When C is high, it computes the difference by adding A to the two's complement of B, effectively subtracting B from A. The result is provided at the output S, allowing for flexible arithmetic operations based on the control input.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input C,
  output [3:0] S
);
