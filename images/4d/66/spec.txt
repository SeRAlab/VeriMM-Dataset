Design a memory module that functions as a shadow register array with 1024 entries, each 12 bits wide. On each positive edge of the clock (clka), if the write enable (wea) is asserted, the input data (dina) is stored in the register at the specified address (addra). Regardless of the write operation, the output (douta) presents the value stored at the same address, effectively providing read capabilities alongside conditional writes.
