Design a Verilog module that performs Cholesky decomposition on a 2x2 matrix. The module takes a 2x2 positive definite matrix as input and outputs the lower triangular matrix resulting from the decomposition. The input matrix is represented as four separate 8-bit inputs (a11, a12, a21, a22) and the output matrix consists of three 8-bit outputs (l11, l21, l22), where l21 is the lower triangular part of the matrix. The decomposition should be performed on the rising edge of a clock signal. The module should also have an enable signal to control when the computation occurs.
