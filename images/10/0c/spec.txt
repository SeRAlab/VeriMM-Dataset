Design an 8-bit SRAM cell that can store and retrieve data. The SRAM should have the following ports: an 8-bit data input (`data_in`), an 8-bit data output (`data_out`), a write enable signal (`we`), and a clock signal (`clk`). When the `we` signal is high, the SRAM should store the data on the rising edge of the clock. When `we` is low, the SRAM should output the stored data on `data_out`.
