Design a circuit that implements a cyclic redundancy check (CRC) for error detection in data transmission. The module takes in input data, a generator polynomial, and an optional initial CRC value, allowing for CRC generation and verification through the use of shift registers and polynomial division. When the CRC enable signal is active, the circuit computes the CRC value based on the input data and polynomial, while the check enable signal allows for verification against an input CRC value. The output includes both the calculated CRC appended to the original data and a match signal indicating whether the received CRC value is valid.
module top_module(
  input clk,
  input reset,
  input [data_size-1:0] data_in,
  input [data_size-1:0] poly,
  input [data_size-1:0] crc_in,
  input crc_enable,
  input check_enable,
  output [data_size-1:0] crc_out,
  output match
);
