Design an 8-bit SRAM cell with a read and write capability. The SRAM cell should have the following inputs: `data_in` (8 bits), `address` (3 bits), `we` (write enable), and `clk` (clock). The output should be `data_out` (8 bits), which represents the data read from the SRAM cell. The SRAM cell should store data on the rising edge of the clock when `we` is asserted and should output data on the corresponding address when `we` is deasserted.
