

You are tasked with designing a verilog module that implements a 4-bit binary counter with a synchronous reset functionality. The module should have the following inputs and outputs:

Inputs:
- `clk` (1-bit): the clock signal
- `rst` (1-bit): the synchronous reset signal

Outputs:
- `count` (4-bit): the binary count output

The counter should increment on every rising edge of the clock signal, except when the reset signal is asserted. When the reset signal is asserted, the counter should be reset to zero.

Write a verilog module that implements the above functionality, using the following template:

```
module binary_counter (
    // Inputs
    // Outputs
);

  // Declare internal signals and registers here

  // Implement the counter logic here

endmodule
```
