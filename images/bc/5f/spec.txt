Design a circuit that functions as a 2-to-1 RGB selector. Based on the value of the 'sel' input, it outputs one of the two 24-bit RGB color values (rgb_0 or rgb_1) to rgb_out on each positive edge of the clock signal. When sel is 0, rgb_0 is output; when sel is 1, rgb_1 is output.
module top_module(
    input clk,
    input sel,
    input [23:0] rgb_0,
    input [23:0] rgb_1,
    output reg [23:0] rgb_out
);
