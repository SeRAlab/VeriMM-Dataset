Implement the Verilog module based on the following description.
Design a Verilog module that implements a 16-bit register with synchronous clear. The register should store the input data (d) on the rising edge of the clock. When the synchronous clear (sclr) is high, the register should reset to 0. The stored data should be output to the "q" signal.

module register
(
    input clk,
    input sclr,
    input [15:0] d,
    output reg [15:0] q
);
