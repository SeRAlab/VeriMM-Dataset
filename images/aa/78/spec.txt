Design a 12-bit shift register with load and shift functionalities. The module allows for loading a 12-bit input (dat) into the register when the load signal is high. On each rising edge of the clock, if the reset signal is active, the register clears to zero. If the shift signal is asserted, the contents of the register are shifted right by one bit, with the leftmost bit being set to logic high. The last bit of the register can be accessed through the lastbit output, providing the lowest bit of the current register value.
module top_module(input clk, input load, input shift, input [11:0]dat, input reset,output lastbit);
