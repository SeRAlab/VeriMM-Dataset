Design a hazard detection unit for a pipelined CPU architecture. This module detects data hazards by monitoring the source and destination registers of the instruction in the Instruction Fetch/Decode (IFID) stage against those in the Instruction Decode/Execute (IDEX) stage when a memory-read operation is active. If a hazard is detected—specifically, if the destination register of the instruction being executed matches either of the source registers of the instruction currently being fetched—the unit will disable instruction writing and program counter advancement, while providing a stall signal to ensure correct operation of the pipeline.
