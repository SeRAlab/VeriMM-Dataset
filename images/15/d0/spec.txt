Design a simple Automatic Repeat reQuest (ARQ) protocol using Verilog. The system should consist of a sender that sends a data frame and a receiver that acknowledges the receipt of the frame. If the sender does not receive an acknowledgment within a certain period, it should resend the data frame. The data frame is a 5-bit value, and the acknowledgment is a single bit (0 for no acknowledgment and 1 for acknowledgment).
