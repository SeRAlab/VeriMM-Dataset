Design a 16-bit barrel shifter with a two-stage pipeline. The module accepts a 16-bit input data and a 4-bit shift amount to determine how many positions to shift the input left or right, based on the direction signal. When the direction is high, the data is shifted left; when low, the data is shifted right. The final output, which is the result of the second shift stage, is synchronized with a clock signal on the output q. This pipeline design allows for increased throughput by enabling multiple shifts to be processed in stages.
module top_module(
    input clk,                     // Added clk input
    input [15:0] data,
    input [3:0] shift_amount,
    input direction,
    output reg [15:0] q
);
