

You are tasked to design a verilog module that performs a 4-bit left shift on an input signal. The module should have the following specifications:

- The module should be named "left_shift".
- The module should have two input ports: a 4-bit input signal named "data_in", and a single bit input signal named "shift".
- The module should have one output port: a 4-bit output signal named "data_out".
- When "shift" is high, the module should shift the bits of "data_in" to the left by one position. The leftmost bit should be replaced by a zero, and the rightmost bit should be discarded.
- When "shift" is low, the module should output "data_in" unchanged.

Write the verilog code for the "left_shift" module and test your design using a testbench.
