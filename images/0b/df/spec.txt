
Design an 8-bit comparator in Verilog that compares two 8-bit input values and outputs three signals: 
1. `greater` (1 if the first input is greater than the second),
2. `equal` (1 if both inputs are equal), 
3. `less` (1 if the first input is less than the second). 
The inputs are `A` and `B`, each 8 bits wide.
