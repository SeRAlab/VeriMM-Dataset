
Create a Verilog module that implements a simple Support Vector Machine (SVM) decision function. The module should take three inputs: two 4-bit vectors representing feature values (X1 and X2) and a 1-bit bias (B). The output should be a 1-bit decision indicating whether the data point belongs to the positive class (1) or negative class (0). The decision function is defined as follows: output = 1 if (X1 * W1 + X2 * W2 + B) > 0, else output = 0. You can assume W1 and W2 are fixed weights, for example, W1=2 and W2=-1.
