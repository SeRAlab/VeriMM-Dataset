Design a simple interrupt controller that responds to multiple interrupt requests (IRQs). The controller should have 4 inputs (IRQ0, IRQ1, IRQ2, IRQ3) that represent different interrupt requests and a clock signal. The controller will generate an output signal (IRQ_OUT) that indicates which interrupt request has been acknowledged. It will acknowledge the highest priority interrupt request first. The priority order is IRQ0 > IRQ1 > IRQ2 > IRQ3. The IRQ_OUT will hold the acknowledged interrupt until the next clock cycle when a new interrupt can be acknowledged.
