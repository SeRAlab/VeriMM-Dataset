Implement a Verilog module for a 16-bit register with enable and synchronous clear. The register should have a clock input `clk`, a synchronous clear input `clear`, an enable input `en`, a 16-bit data input `D`, and a 16-bit output `Q`. When `clear` is high, `Q` should be set to 0 on the next rising edge of `clk`. When `en` is high, `Q` should be set to `D` on the rising edge of `clk`.

module register16(
	input wire clk,
	input wire clear,
	input wire en,
	input wire [15:0] D,
	output reg [15:0] Q
);
