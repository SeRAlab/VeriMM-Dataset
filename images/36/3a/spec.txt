Design a fan speed controller that adjusts the speed of a fan based on temperature readings. Given a 3-bit binary input representing temperature (0 to 7), the fan speed will be controlled according to the following rules: 
- If the temperature is 0-2, the fan speed is OFF (00).
- If the temperature is 3-4, the fan speed is LOW (01).
- If the temperature is 5, the fan speed is MEDIUM (10).
- If the temperature is 6-7, the fan speed is HIGH (11).
The system should have a clock and a reset signal. On every rising edge of the clock, if reset is low, the system should read the input temperature and set the fan speed accordingly.
