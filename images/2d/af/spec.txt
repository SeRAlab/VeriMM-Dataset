Create a simple Verilog module that implements the ChaCha20 quarter round function. The module should take four 32-bit inputs and produce four 32-bit outputs. The operation is defined as follows:  
1. Add the first input to the second input and store it in the first output.  
2. Rotate the first output left by 16 bits and then add it to the third input, storing the result in the second output.  
3. Rotate the second output left by 12 bits and then add it to the fourth input, storing the result in the third output.  
4. Rotate the third output left by 8 bits and then add the first input again, storing the result in the fourth output.  
You need to ensure that the values wrap around correctly for 32-bit integers.
