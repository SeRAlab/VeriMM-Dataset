Design a 4-to-1 multiplexer with enable functionality. The module takes four 4-bit input signals and uses a 2-bit select signal to choose one of these inputs for the output. The output is only valid when the enable signal is high; otherwise, the output will be zero regardless of the selected input. This allows the circuit to conditionally pass through one of the inputs based on the selection and enable signals.
module top_module(input [3:0] in0, in1, in2, in3,
                     input [1:0] sel,
                     input en,
                     output reg [3:0] out);
