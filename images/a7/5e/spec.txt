Design a circuit that serves as a 32-bit comparator, capable of comparing two input numbers (num1 and num2) in either signed or unsigned format based on the selection signal (sel). When sel=0, the circuit performs an unsigned comparison, outputting flags for equality (eq), greater than (gt), and less than (lt). When sel=1, it performs a signed comparison with the same flag outputs. This allows for both signed and unsigned number comparisons, facilitating versatility in digital signal processing applications.
module top_module(
  input [31:0] num1,
  input [31:0] num2,
  input sel,
  output eq,
  output gt,
  output lt
);
