

You are tasked with designing a 12-bit wide, 1-to-2 multiplexer in Verilog. The module should be named `Span12Mux_v11` and have an input `I` and an output `O`. The input `I` should be a 12-bit wide vector, and the output `O` should be a single bit. The multiplexer should select between two inputs based on the value of the most significant bit of `I`. If the most significant bit of `I` is 0, the output `O` should be equal to the value of the 11th bit of `I`. If the most significant bit of `I` is 1, the output `O` should be equal to the value of the 10th bit of `I`.

Your solution should be contained in a single module of no more than 200 lines of Verilog code. You should assume that all inputs are valid and that there are no timing constraints.
