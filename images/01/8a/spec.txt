Design a combinational logic circuit that takes a 2x2 matrix as input and outputs its inverse. The output should be valid only if the matrix is invertible (its determinant is non-zero). If the matrix is not invertible, the output should be a predefined error code (e.g., all ones). The input matrix will be represented as four 8-bit values (a, b, c, d) corresponding to the matrix [[a, b], [c, d]].
