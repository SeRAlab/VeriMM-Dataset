

You are tasked with implementing a single-port RAM module in Verilog. The module should have the following ports and parameters:

- `addr`: an input port that specifies the memory address to read from or write to.
- `data`: an input port that specifies the data to write to memory.
- `we`: an input port that specifies whether to write to memory (`we = 1`) or read from memory (`we = 0`).
- `out`: an output port that provides the data read from memory.
- `clock`: an input port that provides the clock signal.

The module should have the following parameters:

- `addr_width`: the number of bits required to represent the memory address.
- `data_width`: the number of bits required to represent the data.
- `mem_depth`: the depth of the memory, calculated as `2^addr_width`.

The module should use a single clock edge to perform both read and write operations. The memory should be initialized to all zeros.

Write a Verilog module that implements the single-port RAM with the above requirements.
