Design a combinational logic circuit that implements a simplified Hough Transform for detecting straight lines in a binary image. The circuit should take a binary image represented by an 8x8 array as input and output the parameters (r, θ) of the detected lines. The parameters should be encoded in a way that r is a 6-bit value and θ is a 4-bit value. Assume the maximum possible value for r is 63 and for θ is 15 (representing angles from 0 to 180 degrees).
