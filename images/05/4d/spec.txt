
Design a PCIe packet handler that processes incoming transactions. The module should have the following inputs: a clock signal (`clk`), a reset signal (`rst`), and a transaction valid signal (`txn_valid`). The module should also have inputs for the transaction type (`txn_type`, 2 bits) and the transaction address (`txn_addr`, 32 bits). If `txn_valid` is high, the module should store the transaction information. If a reset occurs, the module should clear stored data. The output should include a transaction ready signal (`txn_ready`) indicating when the stored data is valid.
