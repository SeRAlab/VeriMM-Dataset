Implement a register file that provides read and write access to 32 registers in a 32-bit architecture. When a write operation is enabled (indicated by RegWr), and the register address RW is not 31, the specified register is updated with the value from BusW at the falling edge of the clock. At the rising edge of the clock, the most significant bit of the register is cleared to zero. The outputs BusA and BusB deliver the contents of the registers identified by addresses RA and RB, respectively, with a propagation delay added to these assignments.
module top_module(BusA, BusB, BusW, RA, RB, RW, RegWr, Clk);
