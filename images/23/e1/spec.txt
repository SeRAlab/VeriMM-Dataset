Design a dynamic range compressor that takes a 4-bit signed input audio signal and produces a compressed output signal based on a simple threshold logic. If the input signal exceeds a threshold, the output should be reduced by a fixed ratio. If not, the output remains the same. The threshold is set at 7 for this problem, and if the input exceeds this, the output is set to the input minus 3 (compression), otherwise, the output should be the same as the input.
