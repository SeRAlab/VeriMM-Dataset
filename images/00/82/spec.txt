Design an NVMe controller command decoder. The decoder will take a 5-bit command input and output a corresponding 3-bit command type. The input commands are as follows:  
- 00000: NOP (No Operation)  
- 00001: READ  
- 00010: WRITE  
- 00011: FLUSH  
- 00100: FORMAT  
For any other input, the output should be 3'b111 (Unknown Command).
