Design a Verilog module that implements a simple dynamic range compressor. The input signal is a 12-bit unsigned value representing audio amplitude, and the output signal should be compressed based on a predefined threshold. If the input exceeds the threshold, the output should scale down the amplitude while maintaining the dynamic range. For simplicity, use a threshold of 2048 (half of the maximum value for 12 bits) and a ratio of 2:1 for compression.
