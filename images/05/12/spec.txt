
Design a Watchdog Timer (WDT) in Verilog. The WDT should have an input 'reset' and a clock 'clk'. It should also have an input 'feed' which, when asserted, resets the timer. The WDT should output 'timeout' when the timer reaches a specified limit (e.g., 5 clock cycles without being fed). If the 'reset' signal is asserted, the timer should reset immediately regardless of the state.
