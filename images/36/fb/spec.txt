
Design a 4-bit SRAM cell with the following characteristics:
- It should have an enable signal (EN) to allow writing to or reading from the cell.
- When EN is high, data can be written to the SRAM cell via a 4-bit input (D).
- When EN is low, the output should reflect the stored data in the SRAM cell on a 4-bit output (Q).
- The SRAM cell should have a clock input (CLK) to control the write operation synchronously.
