Design a clocked buffer circuit that captures and stores 24 bits of input data (ZN), 8 bits of enable signals (ZEN), and a single status signal (ZS) on the rising edge of the clock (CLK). The module outputs the stored values as ZN1, ZEN1, and ZS1, effectively serving as a register to hold these signals for sequential logic applications.
module top_module(
    input [23:0] ZN,
    input [7:0] ZEN,
    input ZS,
	 input CLK,
    output reg [23:0] ZN1,
    output reg [7:0] ZEN1,
    output reg ZS1
    );
