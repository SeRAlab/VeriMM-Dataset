Design a simple state machine for a robot that processes received sensor data to determine its movement direction based on the following states: IDLE, MOVE_FORWARD, TURN_LEFT, TURN_RIGHT. The FSM should transition between these states based on input signals that indicate if the sensor detects an obstacle. The movement commands are as follows: if an obstacle is detected, the robot should turn right; if no obstacle is detected, it should move forward. The system should initialize in the IDLE state.
