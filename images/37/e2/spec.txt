
Design a Verilog module that computes a checksum for an 8-bit input data word. The checksum is computed by summing all the bytes of the input data and then taking the 8 least significant bits of the sum. The module should also provide an output signal indicating when the checksum is valid. The input data will be presented as a series of 8-bit words, and a signal will indicate when the last input word has been received.
