

You are tasked with designing a Verilog module that implements a 2-to-1 multiplexer. The module should have two input signals, `A` and `B`, and a select signal `S` that selects which input should be passed to the output `Y`. The module should be named `mux_2to1`.

Declare the module inputs and outputs as follows:
- `A` and `B` are 1-bit inputs
- `S` is a 1-bit input
- `Y` is a 1-bit output

You should implement the multiplexer using a conditional statement. If `S` is 0, `A` should be passed to `Y`. If `S` is 1, `B` should be passed to `Y`.
