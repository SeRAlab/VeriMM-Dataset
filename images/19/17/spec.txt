Design a 4-bit DRAM cell type. The DRAM cell should be able to store a 4-bit value and allow for reading and writing operations. The input signals are `write_enable`, `address`, and `data_in`, while the output signal is `data_out`. When `write_enable` is high, the data at `data_in` should be stored at the specified `address`. When `write_enable` is low, the current value at the specified `address` should be available at `data_out`.
