Design a thermal sensor calibration system using a Verilog module. The system should allow for a 4-bit sensor value input. The calibration process involves adjusting the output based on a calibration factor stored in a register. The calibration factor can be set through an external input signal. The module should have an enable signal that allows the calibration process to occur. If the enable signal is high, the calibrated output should be the sum of the sensor value and the calibration factor. If the enable signal is low, the output should remain unchanged.
