
Design a Verilog module that performs bilinear interpolation on a 2x2 pixel block. The module should take four pixel intensity values (I00, I01, I10, I11) and two fractional values (x and y) as inputs, and output the interpolated pixel intensity (Ixy). The formula for bilinear interpolation is:
Ixy = (1-x)*(1-y)*I00 + (1-x)*y*I01 + x*(1-y)*I10 + x*y*I11.
Assume that the input pixel values and the output pixel value are all 8-bit unsigned integers, and the fractional values x and y are represented as 8-bit fixed-point numbers where the upper 4 bits are the integer part and the lower 4 bits are the fractional part.
