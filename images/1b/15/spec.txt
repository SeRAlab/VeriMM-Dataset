Design a simple PCIe endpoint controller that has a state machine with three states: IDLE, ACTIVE, and ERROR. The controller transitions between these states based on an input signal 'start' and 'error'. When 'start' is asserted, it transitions from IDLE to ACTIVE. If 'error' is asserted while in ACTIVE, it transitions to ERROR. If 'error' is deasserted while in ERROR, it transitions back to IDLE.
