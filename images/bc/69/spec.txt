Design a 4-to-1 multiplexer that selects one of four 32-bit input ports based on a 2-bit selection signal. The module outputs the selected input (port_in_0 to port_in_3) to the output port_out, where sel_port values of 00, 01, 10, and any other value will correspondingly choose port_in_0, port_in_1, port_in_2, and port_in_3, respectively.
module top_module(
input   [1:0] sel_port,
input   [31:0] port_in_0,
input   [31:0] port_in_1,
input   [31:0] port_in_2,
input   [31:0] port_in_3,
output reg [31:0] port_out 
);
