
Design a finite state machine (FSM) that simulates a simple SLAM process with three states: IDLE, MAP, and NAVIGATE. The FSM should transition based on the following conditions:
- From IDLE to MAP on the input signal `start_map`.
- From MAP to NAVIGATE on the input signal `start_navigate`.
- From NAVIGATE to IDLE on the input signal `reset`.
The output should indicate the current state with a 2-bit binary value, where IDLE = 00, MAP = 01, and NAVIGATE = 10.
