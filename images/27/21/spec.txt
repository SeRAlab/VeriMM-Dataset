
Create a simple Recurrent Neural Network (RNN) inference module in Verilog. The RNN will take a 5-bit input vector and a hidden state of 3 bits. The output will be a 3-bit result, which is computed based on the input and the hidden state. The hidden state is updated based on a simple weight application and activation function (e.g., XOR). The RNN should be designed to process the input in a clock-driven manner.
