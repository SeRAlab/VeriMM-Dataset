
Design a cache replacement policy module that can operate in either LRU (Least Recently Used) or FIFO (First In First Out) mode. The module should take inputs for cache access (address), a control signal to choose the replacement policy, and produce the index of the cache line to be replaced. The cache has 4 lines, indexed from 0 to 3, which can be implemented using a 2-bit index. The LRU mode must track the usage of each line, while the FIFO mode must replace the oldest line.
