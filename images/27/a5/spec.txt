
Design a Verilog module for a simple Decision Tree Inference that takes three inputs: `feature1`, `feature2`, and `feature3`, each 4 bits wide, and produces one output `decision` which is also 2 bits wide. The decision is made based on the following rules:
- If feature1 >= 8, output decision 2'b11.
- If feature1 < 8 and feature2 >= 8, output decision 2'b10.
- If feature1 < 8, feature2 < 8, and feature3 >= 8, output decision 2'b01.
- Otherwise, output decision 2'b00.
