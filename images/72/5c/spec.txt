Design a synchronous 4-bit binary adder that computes the sum of two 4-bit inputs `a` and `b`, along with an additional carry input `cin`. The output consists of a 4-bit `sum` and a carry-out flag `cout`. The circuit features a reset functionality that clears the sum and cout to zero when activated. The arithmetic operation is performed on the rising edge of a clock signal, enabling pipelined processing, while maintaining a valid output until the next clock cycle.
module top_module(
    input clk,
    input reset,
    input [3:0] a,
    input [3:0] b,
    input cin,
    output [3:0] sum,
    output cout
);
