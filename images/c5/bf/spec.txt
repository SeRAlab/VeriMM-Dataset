Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a full adder. 
A full adder is a combinational circuit that is used to add three bits: two inputs and a carry bit. 
The outputs of a full adder are the sum of the three bits and a carry bit that is used to add the next set of bits. 
Your module should have the following inputs and outputs:

Inputs: three input signals (a, b, c_in)
Outputs: two output signals (sum, c_out)

Your module should implement the following functionality:

The circuit should compute the sum of the three input bits (a, b, c_in) and generate a carry bit (c_out) that is used to add the next set of bits.
You should use Verilog code to define the Boolean functions for the sum and carry bits in terms of the input signals. 
You should then use these functions to connect the inputs to the outputs.
