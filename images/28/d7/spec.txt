
Design a LIFO stack module in Verilog. The stack should support the following operations:
1. Push: Insert an item onto the stack.
2. Pop: Remove the item from the top of the stack.
3. Peek: Retrieve the item from the top of the stack without removing it.
4. IsEmpty: Check if the stack is empty.

The stack should have a defined size (e.g., 8 items) and you should include control signals for push and pop operations, along with the data input and output signals.
