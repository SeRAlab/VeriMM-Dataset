

You are tasked with designing a module that implements a 4-bit binary up-counter with synchronous reset functionality. The module should take in a clock signal `CLK`, a synchronous reset signal `RESET_B`, and output a 4-bit value `Q` that represents the current count value. The counter should increment on the rising edge of the clock signal and reset to 0 when the reset signal is asserted.

You should design the module using Verilog and ensure that it adheres to the following specifications:
- The module should be named `up_counter`.
- The module should have the following input and output ports:
  - `input CLK`: the clock signal
  - `input RESET_B`: the synchronous reset signal (active low)
  - `output reg [3:0] Q`: the 4-bit count value
- The module should use synchronous logic to increment the count value on the rising edge of the clock signal.
- The module should reset the count value to 0 when the reset signal is asserted.

You should test your module using a testbench that verifies the counter functionality for multiple clock cycles and reset scenarios.
