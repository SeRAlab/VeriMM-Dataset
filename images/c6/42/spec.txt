

You are tasked with designing a Verilog module that implements a 4-input NOR gate. The module should have the following inputs and outputs:

Inputs:
- IN1: 1-bit input
- IN2: 1-bit input
- IN3: 1-bit input
- IN4: 1-bit input
- VDD: 1-bit input
- VSS: 1-bit input

Outputs:
- QN: 1-bit output

The module should be named NOR4X0 and should be completely self-contained, meaning that it should not rely on any other modules.

Your task is to write a Verilog module that implements the NOR4X0 module. The module should take in four inputs, IN1, IN2, IN3, IN4, and output the NOR of these inputs to QN. The module should also have inputs for VDD and VSS, which are the power and ground connections, respectively.

The NOR4X0 module should implement the following logic:

- QN should be the NOR of IN1, IN2, IN3, and IN4.

You should write a Verilog module that implements the NOR4X0 module within 200 lines of code.
