Design a 4-bit Serial-in Serial-out (SISO) shift register. The shift register should have a serial input (`data_in`), a clock input (`clk`), and a reset input (`rst`). On each rising edge of the clock, if the reset is not asserted, the input data should be shifted into the register. The output (`data_out`) should be the current contents of the shift register. The shift register should also have a `load` input to enable loading new data into the register when asserted.
