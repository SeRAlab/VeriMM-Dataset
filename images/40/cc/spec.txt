Design a Verilog module that simulates a thermal sensor calibrator. The circuit should take input in the form of a 10-bit binary value representing the raw temperature reading from the sensor. The output should be a calibrated 10-bit binary value that adjusts the raw reading based on a predefined calibration factor. The calibration factor is defined as an adjustment that is applied to the raw reading. The calibrated output should be the raw reading plus the calibration factor. The calibration factor is also a 10-bit value, and the output should never exceed the maximum value for a 10-bit number (1023). If the output exceeds 1023, it should be capped at 1023.
