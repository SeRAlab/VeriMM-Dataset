
Design a simple I2C controller with the following specifications:
- The controller has an input to receive a 7-bit I2C address and a 3-bit command (read, write, or stop).
- The controller should generate an acknowledgment (ACK) signal after sending the address.
- The output should indicate the current state of the controller (IDLE, ADDRESS_SENT, DATA_TRANSFER, ACK_RECEIVED).
- The controller should transition states based on the commands received.
