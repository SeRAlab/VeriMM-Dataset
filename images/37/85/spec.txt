
Design an I2C controller module in Verilog that interfaces with an external device using the I2C protocol. The controller should be able to initiate a start condition, send 8 bits of data, and generate a stop condition. The module should have inputs for the clock signal, enable signal, and the data to be sent, and outputs for the SDA (data line) and SCL (clock line). The controller should operate in a simplistic manner, completing one byte transmission per clock cycle when enabled.
