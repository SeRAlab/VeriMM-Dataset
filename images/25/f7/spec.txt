
Design a simple memory allocation and deallocation system using a FIFO queue structure. The system should support two operations: `malloc` to allocate a memory block and `free` to deallocate a memory block. Each memory block will be represented by a unique identifier (ID). The memory pool can store a fixed number of memory blocks. If `malloc` is called when the pool is full, it should signal an allocation failure. If `free` is called with an identifier that is not currently allocated, it should signal an error.
