
Design a 24-bit Digital-to-Analog Converter (DAC) that takes a 24-bit binary input and generates a corresponding output voltage level. The output voltage should be proportional to the input binary value, where the maximum output voltage corresponds to a binary value of `24'hFFFFFF` and the minimum corresponds to `24'h000000`. Assume the reference voltage is 5V. The DAC should also have a simple enable signal that allows the output to be held at the current value or updated based on the input.
