Design a GPIO controller that allows for setting and reading the state of up to 8 GPIO pins. The controller should have the following functionality: 
1. A write enable signal (we), an 8-bit data input (data_in), and an 8-bit data output (data_out) signal. 
2. When we is high, the controller should latch the value from data_in to the internal state (representing the GPIO pins).
3. When we is low, the data_out should reflect the current state of the GPIO pins. 
4. Additionally, there should be a reset signal (rst) that resets the GPIO pins to a low state when asserted.
