Design a negative-edge triggered D Flip-Flop with asynchronous preset (pre) and clear (clr) inputs, as well as an enable (en) control. The flip-flop initially sets its output (q) to LOW. On the negative edge of the clock, if the preset is asserted, the output is set to HIGH; if the clear is asserted, the output is set to LOW. If neither of the asynchronous signals is active, the output takes the value of the data input (d) when the enable signal is HIGH.
