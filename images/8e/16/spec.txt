Implement a Verilog module for a 2-to-4 decoder with enable. The decoder should have a 2-bit input `in`, an enable input `en`, and a 4-bit output `out`. When `en` is high, the output `out` should be one-hot encoded based on the input `in`. When `en` is low, `out` should be set to 0.

module decoder(
	input wire [1:0] in,
	input wire en,
	output reg [3:0] out
);
