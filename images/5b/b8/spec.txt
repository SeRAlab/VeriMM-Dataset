Design a 4-bit register that captures and stores a 4-bit input value (din) on the rising edge of a clock signal (clk). If the reset signal (rst) is activated (low), the register will reset its output to zero; otherwise, it will output the current value being held. The output (dout) reflects the stored value of the register.
module top_module(input clk, input rst, input [3:0] din, output reg [3:0] dout);
