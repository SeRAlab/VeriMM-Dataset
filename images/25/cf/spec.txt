Design a GPIO controller that allows reading and writing to a set of GPIO pins. The GPIO controller should have the following features:
1. A register to hold the state of the GPIO pins (let's assume 8 pins).
2. An input signal to write to the GPIO register.
3. A signal to read the state of the GPIO pins.
4. Control signals to enable writing and reading operations.
5. The state of the GPIO pins should be updated on a rising edge of a clock signal.
