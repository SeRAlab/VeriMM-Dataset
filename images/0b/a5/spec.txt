Design a simple state machine for a SLAM system that tracks robot movement in a grid. The state machine should have the following states: IDLE, MOVE, and MAP. The robot starts in the IDLE state. When a signal `start` is received, the state transitions to MOVE. After moving, the robot transitions to MAP when a signal `map` is received. The robot returns to IDLE after completing mapping. The output should indicate the current state of the robot.
