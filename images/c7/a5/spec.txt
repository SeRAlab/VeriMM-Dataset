

You are tasked with designing a Verilog module that takes in four input signals and outputs one signal. The module should be named `four_to_one` and should be able to handle the following signals:

- `input A` (1-bit)
- `input B` (1-bit)
- `input C` (1-bit)
- `input D` (1-bit)
- `output Y` (1-bit)

The module should output the logical OR of the four input signals. That is, if any of the input signals are high, the output should be high. Otherwise, the output should be low.

You should write the Verilog code for the `four_to_one` module, ensuring that it is self-contained and can be run independently. Your code should not exceed 200 lines.
