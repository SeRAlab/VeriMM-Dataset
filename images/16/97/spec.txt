
Design a JK latch using Verilog. The JK latch should have inputs J, K, and a clock signal (CLK), along with an output Q. When the clock is high, the state of the output Q should change based on the values of J and K: if J=K=0, Q remains the same; if J=1 and K=0, Q should set to 1; if J=0 and K=1, Q should reset to 0; and if J=K=1, Q should toggle.
