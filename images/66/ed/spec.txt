Design a Verilog module for a state machine that represents a simple traffic light controller. The state machine has three states: Green, Yellow, and Red. The controller takes no inputs and produces three outputs representing the current light: green, yellow, and red. The state transitions are as follows:
1. From Green: Transition to Yellow.
2. From Yellow: Transition to Red.
3. From Red: Transition to Green.

Assume the state machine uses one-hot encoding, where state[0] through state[2] correspond to the states Green through Red, respectively. Write Verilog implementing the state transition and output logic. Use `clk` as the clock signal and assume a positive clock edge trigger.
