Implement a 32-bit signed arithmetic and logical unit (ALU) that performs various operations based on a 5-bit operation code (alu_op). The ALU can execute addition, subtraction, bitwise AND, OR, XOR, and NOR operations between two 32-bit signed inputs (alu_a and alu_b). The specific operation selected is determined by the value of alu_op, with each operation corresponding to a distinct case in a combinational logic block. The output of the ALU is produced on the alu_out signal.
module top_module(  
  input  signed	    [31:0]	alu_a,
  input  signed	    [31:0]	alu_b,
  input	             [4:0]	alu_op,
  output    	reg    [31:0]	alu_out
    );
