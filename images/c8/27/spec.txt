

You are tasked with designing a module that implements a 2-to-1 multiplexer using Verilog. The module should have the following inputs and outputs:

Inputs:
- A (1-bit)
- B (1-bit)
- Sel (1-bit)

Outputs:
- Out (1-bit)

If Sel is 0, Out should be equal to A. If Sel is 1, Out should be equal to B.

Write a Verilog module that implements this functionality. Your module should be named "mux_2to1" and should have the same inputs and outputs as described above. You should also include any necessary declarations for power and ground signals.
