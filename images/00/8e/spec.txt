Design a 1-bit SRAM cell that can store a single bit of data. The SRAM cell should have the following inputs: `write_enable`, `data_in`, and `read_enable`. The outputs should be `data_out` which reflects the stored data when `read_enable` is active. If `write_enable` is high, the input data should be written to the cell. If `read_enable` is high, the stored data should be available at the output.
