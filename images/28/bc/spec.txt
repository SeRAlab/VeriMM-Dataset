Design a 2D support vector machine (SVM) decision function in Verilog, which takes two 8-bit inputs representing features x and y, and outputs a 1-bit result indicating the class (0 or 1) based on a linear decision boundary. The decision function can be represented as `w0*x + w1*y + b > 0`. Use weights `w0 = 3`, `w1 = 2`, and bias `b = -5`.
