The output X is high when both A1 and A2 are true, or when A1 is true and A2 is false while A3 is true. If A1 is true and both A2 and A3 are false, X takes the value of B1; otherwise, X outputs low.     output X,
    input  A1,
    input  A2,
    input  A3,

    input  VPWR,

    input  VNB
