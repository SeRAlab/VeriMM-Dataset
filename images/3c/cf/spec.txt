Design a simple finite state machine (FSM) for a robot that moves in a grid during a SLAM process. The FSM should have three states: IDLE, MOVE, and MAP, with the following transitions: 
- From IDLE to MOVE on a 'go' signal.
- From MOVE to MAP after a fixed number of clock cycles (simulate a movement).
- From MAP to IDLE on a 'done' signal.
The FSM should output the current state as a 2-bit binary number.
