Design an Arithmetic Logic Unit (ALU) that performs a variety of arithmetic and bitwise operations on two 32-bit inputs, `first` and `second`, based on a 4-bit control signal. The ALU supports addition, subtraction, AND, OR, NOR, XOR, left shift, arithmetic right shift, and logical right shift. Depending on the value of the control signal, the appropriate operation is executed, and the result is outputted as a 32-bit value. If an invalid control signal is provided, the output is set to zero.
module top_module(
            input [31:0] first,
            input [31:0] second,
            input [3:0] control,
            output reg [31:0] out
            );
