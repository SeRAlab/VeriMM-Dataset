

You are tasked with designing a Verilog module that takes in three inputs, `a`, `b`, and `c`, and outputs a 9-bit value `y`. The module should be named `simple`.

The output `y` should be calculated as follows:
- If `a` is less than `b`, `y` should be equal to `a` shifted left by `c` bits.
- If `a` is greater than `b`, `y` should be equal to `b` shifted left by `c` bits.
- If `a` is equal to `b`, `y` should be equal to `a` bitwise ANDed with `b`.

You should assume that `a`, `b`, and `c` are all unsigned 4-bit values.

Write a Verilog module that implements the above functionality. Your module should be named `simple` and should have the following inputs and outputs:

Inputs:
- `a` (4 bits)
- `b` (4 bits)
- `c` (4 bits)

Outputs:
- `y` (9 bits)

Your module should be contained within a single Verilog file, and should not exceed 200 lines of code.
