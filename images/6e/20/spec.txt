Design a circuit that functions as a protocol converter with memory, which captures a new input value on each clock cycle and maintains a memory block of the last eight inputs. When the reset signal is activated, both the memory and the sum are cleared. In normal operation, the module shifts the stored values in memory to make room for the newest input, and simultaneously computes and outputs the sum of the values in the memory block. This module can be utilized in applications where tracking recent data and computing cumulative totals is required.
module top_module(
    input wire clk,
    input wire reset,
    input wire new_input,
    output wire output_sum
);
