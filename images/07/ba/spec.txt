
Create a simple implementation of the ChaCha20 quarter round function as a Verilog module. The module should take four 32-bit inputs (a, b, c, d) and produce four 32-bit outputs. The function is defined by the following operations:
1. a += b; d ^= a; d rotl 16
2. c += d; b ^= c; b rotl 12
3. a += b; d ^= a; d rotl 8
4. c += d; b ^= c; b rotl 7
