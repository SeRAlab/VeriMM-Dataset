
Design a QAM modulator that takes in a 4-bit input representing a constellation point and generates the corresponding I (In-phase) and Q (Quadrature) outputs. The mapping for the constellation points is as follows:
- 0000 -> (1, 1)
- 0001 -> (1, -1)
- 0010 -> (-1, 1)
- 0011 -> (-1, -1)
- 0100 -> (1, 0)
- 0101 -> (0, 1)
- 0110 -> (0, -1)
- 0111 -> (-1, 0)
- 1000 -> (0, 0)
- 1001 -> (1, 1) (and so on for additional points)
The module should have a clock input and a reset input. Upon each clock cycle, when reset is low, the module should output the corresponding I and Q values for the given 4-bit input.
