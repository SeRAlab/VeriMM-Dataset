Design a circuit for an 8-bit bit reverser. The module takes an 8-bit input D and, on each positive clock edge, shifts the input bits into a shift register while simultaneously reversing the order of those bits. The final output R displays the reversed bits, effectively transforming the input data by reversing the bit order from D to R.
module top_module(
    input [7:0] D,
    input clk,          // Added clk as an input
    output reg [7:0] R
);
