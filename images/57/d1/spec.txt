Design a 3-to-8 binary decoder that takes three input signals (A, B, C) and activates one of the eight output lines (Y) based on the binary value represented by the inputs. Each unique combination of the inputs corresponds to a single output line being set to high (1), while all other outputs remain low (0). The output is a reg type, allowing it to be assigned within an always block that responds to changes in the inputs.
module top_module(
// Inputs
input A,
input B,
input C,
// Outputs
output reg [7:0] Y
);
