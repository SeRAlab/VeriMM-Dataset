
You are tasked to design a verilog module that implements a 4-bit shift register with parallel load. The module should have the following inputs and outputs:
- `clk`: a clock input
- `load`: a synchronous active-high input that loads the input data into the shift register on the rising edge of the clock
- `in`: a 4-bit input that is loaded into the shift register when `load` is high
- `shift`: a synchronous active-high input that shifts the data in the shift register one bit to the left on the rising edge of the clock
- `out`: a 4-bit output that represents the current state of the shift register

You should implement the shift register using a behavioral description.
