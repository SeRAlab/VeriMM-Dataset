

You are tasked with designing a module that performs a binary to gray code conversion. Gray code is a binary numeral system where two successive values differ in only one bit. For example, the binary representation of 3 is 011, while the gray code representation is 010. Your module should take in a 4-bit binary input and output the corresponding 4-bit gray code.

You should implement this module in Verilog, and it should be self-contained within 200 lines of code. Your module should have the following inputs and outputs:

- `input [3:0] bin`: the 4-bit binary input
- `output reg [3:0] gray`: the 4-bit gray code output

You may assume that the input will always be a valid 4-bit binary number.
