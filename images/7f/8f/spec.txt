Design a n-bit wide comparator that evaluates the relationship between two input binary numbers, `in1` and `in2`. The operation is controlled by a 2-bit control signal `ctrl`, where `ctrl=00` checks for equality, `ctrl=01` checks if `in1` is greater than `in2`, `ctrl=10` checks if `in1` is less than `in2`, and the default case outputs LOW. The module outputs a single bit indicating the result of the comparison based on the value of `ctrl`.
module top_module(
  input [n-1:0] in1,
  input [n-1:0] in2,
  input [1:0] ctrl,
  output reg out
);
