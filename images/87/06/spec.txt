Design a finite state machine (FSM) that processes a single-bit input signal based on a clock. This FSM operates in three distinct states (ONE, TWO, and THREE), transitioning between them depending on the input signal `in`. The output `out` is LOW in states ONE and TWO, and HIGH in state THREE. The transitions occur as follows: if in state ONE and `in` is LOW, it moves to state TWO; if in state TWO and `in` is LOW, it transitions to state THREE; while remaining in state THREE as long as `in` is HIGH. The design uses clock edges to update the state and output, making it suitable for synchronous digital circuits.
