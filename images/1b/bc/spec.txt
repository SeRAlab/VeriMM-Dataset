
Create a simple combinational logic circuit that implements a Huffman encoding for three different characters 'A', 'B', and 'C'. The output should be a 2-bit encoded value based on the following encoding scheme: 
- 'A' is encoded as '00'
- 'B' is encoded as '01'
- 'C' is encoded as '10'
For any other input, the output should be '11' indicating an invalid character.
