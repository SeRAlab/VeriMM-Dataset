Design a 4-bit SRAM cell that can store a 4-bit value and has read and write capabilities. The SRAM cell should have the following inputs:
- `data_in`: 4-bit data input for writing to the cell.
- `write_enable`: A control signal to enable writing to the cell.
- `read_enable`: A control signal to enable reading from the cell.
The output should be `data_out`, which provides the stored value when reading.
