Design a GPIO controller that allows reading and writing to a set of GPIO pins. The GPIO controller should have an input register for data to be written to the pins, an output register to capture the state of the pins, and a clock input to trigger updates. The controller should have a simple interface with the following signals: a clock (clk), a write enable (we), a data input (data_in), and a data output (data_out). When write enable (we) is high, the data input should be written to the output register on the rising edge of the clock. The output register should then be reflected in the data_out signal.
