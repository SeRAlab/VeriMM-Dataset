Design a four-input, one-bit wide multiplexer. The module takes four 4-bit input data lines (data_in_0, data_in_1, data_in_2, data_in_3) and utilizes a 2-bit select signal to determine which input to route to the 4-bit output (data_out). Depending on the value of the select signal, one of the four inputs is outputted, enabling dynamic switching between multiple data sources.
module top_module(
    input [3:0] data_in_0,
    input [3:0] data_in_1,
    input [3:0] data_in_2,
    input [3:0] data_in_3,
    input [1:0] select,
    output reg [3:0] data_out
);
