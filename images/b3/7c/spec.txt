Please act as a professional verilog designer.

Design a 32-bit register file with 8 registers, read and write capabilities, and an asynchronous reset. The register file should allow reading from two registers simultaneously and writing to one register on the rising edge of the clock. If the reset signal is active, all registers should be cleared to 0 regardless of the clock edge.

Module name:
    reg_file_32bit

Input ports:
    clk: Clock signal.
    rst: Reset signal.
    read_addr1: 3-bit read address for the first read port.
    read_addr2: 3-bit read address for the second read port.
    write_addr: 3-bit write address for the write port.
    write_data: 32-bit write data.
    write_en: Write enable signal.

Output ports:
    read_data1: 32-bit data from the first read port.
    read_data2: 32-bit data from the second read port.

Implementation:
The module uses an always block triggered by the clock and reset signals. If the reset signal is active, all registers are cleared to 0. If the write enable signal is active, the register specified by the write address is updated with the write data on the rising edge of the clock. The read data is continuously assigned based on the read addresses.

Give me the complete code.

module reg_file_32bit(
    input wire clk,
    input wire rst,
    input wire [2:0] read_addr1,
    input wire [2:0] read_addr2,
    input wire [2:0] write_addr,
    input wire [31:0] write_data,
    input wire write_en,
    output reg [31:0] read_data1,
    output reg [31:0] read_data2
    );
