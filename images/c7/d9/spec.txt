

You have been tasked with designing a Verilog module for a 2-input inverter. The module should have two inputs, A and B, and one output, Y. The output should be the inverse of the input A when B is high (1) and the inverse of the input B when A is high (1). 

You should use the following code snippet as a template for your module:

```
module inverter (
    Y,
    A,
    B
);

    output Y;
    input A, B;

    // Voltage supply signals
    supply1 VPWR;
    supply0 VGND;
    supply1 VPB ;
    supply0 VNB ;

    // Your code here

endmodule
```

Your task is to complete the module by adding the necessary Verilog code to implement the inverter functionality as described above. Your code should be as efficient and concise as possible.
