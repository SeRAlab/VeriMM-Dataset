Design a Verilog module that implements a 3x3 Gaussian blur filter for a grayscale image. The input to the module will be a 3x3 matrix of pixel values (8-bit each) representing the image, and the output will be a single 8-bit pixel value representing the blurred result. The Gaussian blur kernel to be used is:
```
1  2  1
2  4  2
1  2  1
```
The output pixel value should be the weighted sum of the input pixels divided by 16 (the sum of the kernel values).
