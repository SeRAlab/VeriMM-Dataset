

You are tasked with designing a module that takes in two inputs and produces one output. The module should be named "adder" and should have the following ports:

- `input [7:0] a`: an 8-bit input
- `input [7:0] b`: an 8-bit input
- `output [8:0] c`: a 9-bit output

The module should add the two 8-bit inputs `a` and `b` and assign the result to `c`. If the result of the addition is greater than 8 bits, the most significant bit should be truncated.

In addition, the module should have the following internal signals:

- `wire [8:0] sum`: a 9-bit wire that holds the result of the addition
- `wire carry`: a 1-bit wire that holds the carry-out of the addition

You should use the `always` construct to assign the value of `sum` and `carry` based on the inputs `a` and `b`.
