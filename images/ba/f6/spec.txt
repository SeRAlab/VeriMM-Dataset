Design a basic Arithmetic Logic Unit (ALU) that performs various operations based on a 4-bit control signal. Upon the rising edge of the clock, the ALU computes results for addition, subtraction, bitwise AND, bitwise OR, set-on-less-than, and NOR operations using two signed 32-bit inputs. It outputs the result of the operation as a signed 32-bit value and provides a zero flag that indicates whether the result of the subtraction operation is zero. If no recognized operation is selected, the ALU defaults the output to zero and keeps the zero flag low.
