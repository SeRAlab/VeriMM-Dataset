1. state A1 (Z = Y).
2. state B1 (Z = ~Y).

2. From state B1: If Y = 1, then transition to state A1. If Y = 0, then stay in state B1.
3. From state C1: If Y = 0, then transition to state A1. If Y = 1, then stay in state C1.

module fsm_3 (
  input Y,
  input [2:0] state,
  output reg [2:0] next_state,
  output reg Z);
