
Design a LIFO stack module in Verilog that supports push and pop operations. The module should have a maximum size of 8 elements. The stack should include the following inputs: 
- `push` (to push a value onto the stack)
- `pop` (to pop a value from the stack)
- `data_in` (the data to push onto the stack)
- `clk` (clock signal)
- `reset` (to reset the stack)

The outputs should be:
- `data_out` (the value popped from the stack)
- `full` (indicates if the stack is full)
- `empty` (indicates if the stack is empty)
