Implement the Verilog module based on the following description. Create a finite state machine that models a traffic light controller for a four-way intersection. Each direction (North, South, East, West) has a Red, Yellow, and Green light. The system should cycle through the states with the North-South direction being green while East-West is red, then North-South yellow while East-West red, then East-West green while North-South red, and finally East-West yellow while North-South red. Each green and yellow state lasts for 10 and 3 clock cycles respectively. Use an asynchronous reset to initialize all lights to red.
