Design a 16-bit wide arithmetic calculator module capable of performing four basic operations: addition, subtraction, multiplication, and division. The module takes two 16-bit inputs (a and b) and a 2-bit operation selector (op). Depending on the value of op, the module calculates the corresponding result, storing the outcome in the appropriate output register: sum for addition, difference for subtraction, product for multiplication, and quotient for division. Only the output relevant to the specified operation is assigned a value, while the others are set to zero.
module top_module(a, b, op, sum, difference, product, quotient);
