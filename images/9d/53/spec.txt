Design a combinational logic circuit that computes the logical function defined by two AND gates and one OR gate. The circuit takes four input signals (A1, A2, B1, B2) and produces a single output (X). The output X is set to HIGH if either of the AND gates outputs a HIGH signal; specifically, one AND gate outputs HIGH when both A1 and A2 are HIGH, while the other outputs HIGH when both B1 and B2 are HIGH. Thus, the module effectively acts as a logical OR for the results of the two AND operations.
module top_module(
    // module ports
    input A1,
    input A2,
    input B1,
    input B2,
    output reg X
);
