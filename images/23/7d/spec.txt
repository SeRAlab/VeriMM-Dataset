Design a simple LIFO (Last In, First Out) stack using Verilog. The stack should have a push and pop operation, with the following specifications:
- The stack has a depth of 4 elements.
- The push operation adds an element to the top of the stack.
- The pop operation removes the element from the top of the stack and outputs it.
- If the stack is full, the push operation should not change the stack.
- If the stack is empty, the pop operation should return a predefined value (e.g., 8'b00000000).
