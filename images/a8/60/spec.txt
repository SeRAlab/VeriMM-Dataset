Design a register bank with 32 entries, each 32 bits wide. On the rising edge of the clock, if the write enable signal (wren) is asserted, the module writes the input data to the specified write address (wraddress). Regardless of the write operation, it outputs the data stored at the specified read address (rdaddress) on the output 'q'. This module effectively functions as a synchronous memory array for storing and retrieving 32-bit values based on the specified addresses.
module top_module(
    input clk,
    input [31:0] data,
    input [4:0] rdaddress,
    input [4:0] wraddress,
    input wren,
    output reg [31:0] q
);
