Design a programmable counter that can be reset, loaded with an initial value, and incremented by a specified step value. It takes a clock signal for operation, an active-low reset signal to clear the counter, an enable signal to permit counting, a load control signal to set the counter to a specific value, and a configurable step input that determines the increment value. The counter outputs its current value as an N-bit wide signal where N is defined by the parameter 'width', defaulting to 8 bits.
