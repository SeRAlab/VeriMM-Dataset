Design a 4-bit SRAM cell that can perform read and write operations. The SRAM should be controlled by a write enable signal (WE) and a chip enable signal (CE). When CE is low and WE is low, data should be written to the SRAM. When CE is low and WE is high, the data stored in the SRAM should be outputted. The SRAM should also have a reset functionality that sets the stored data to 0 when a reset signal is asserted.
