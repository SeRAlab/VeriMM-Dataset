Design a flip-flop with preset and clear functionalities. On the rising edge of the clock (CLK), if the preset (PRE) signal is asserted, the output (Q) is set to HIGH. If the clear (CLR) signal is asserted, the output (Q) is set to LOW. If neither the preset nor the clear is active, the output (Q) takes the value of the data input (D). The module also outputs the complement of Q (Q_bar). This design serves as a versatile storage element with added control for initializing or resetting the state.
module top_module(
    input CLK,
    input D,
    input PRE,
    input CLR,
    output reg Q,
    output reg Q_bar
);
