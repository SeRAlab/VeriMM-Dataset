
You are tasked with designing a module that takes in a 4-bit binary input and outputs the 2's complement of the input. The output should also be in 4-bit binary format. The 2's complement of a binary number is obtained by inverting all the bits (changing 0 to 1 and 1 to 0) and adding 1 to the result. 

Your module should have the following input and output ports:
- `input [3:0] binary_input`: a 4-bit binary input
- `output reg [3:0] twos_complement_output`: a 4-bit binary output representing the 2's complement of the input

Your module should be named `twos_complement` and should be completely self-contained, meaning you should not include any additional modules.
