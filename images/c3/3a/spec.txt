
You have been tasked with designing a Verilog module for a block memory generator. The module should have the following inputs and outputs:

Inputs:
- `addra`: a 14-bit input representing the memory address
- `clka`: a clock input
- `dina`: a 12-bit input representing the data to be written to memory
- `wea`: a write enable input

Outputs:
- `douta`: a 12-bit output representing the data read from memory at the specified address

You should use the provided code snippet as a starting point to create the module. Your module should be able to synthesize correctly using the `title2_blk_mem_gen_v8_3_5_synth` module.

Your module should be able to store and retrieve data from memory correctly. If `wea` is high, the module should write the data from `dina` to the memory location specified by `addra`. If `wea` is low, the module should read the data from the memory location specified by `addra` and output it on `douta`.

You may assume that the memory is 2^14 words deep and each word is 12 bits wide.

Your module should be no longer than 200 lines of Verilog code.
