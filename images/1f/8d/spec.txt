
Design a 4-to-2 priority encoder. The encoder should have 4 input lines (I3, I2, I1, I0) and 2 output lines (Y1, Y0). The input lines represent priority levels, where I3 has the highest priority and I0 has the lowest. If multiple inputs are active, the encoder should output the binary representation of the highest priority input. If no inputs are active, the output should be '00'.
