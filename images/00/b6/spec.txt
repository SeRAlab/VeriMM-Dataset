
Design a Verilog module for a simple EEPROM cell that can store one bit of data. The module should include the following functionalities:
1. A write operation to set the stored bit to a new value.
2. A read operation to retrieve the stored bit.
3. The module should have an enable signal to control whether the write operation is active.
4. The stored value should retain its state when the write operation is not enabled.
