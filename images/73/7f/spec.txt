Design a 4-bit shift register with loading and shifting capabilities. When the LOAD signal is asserted, the register loads the 4-bit input D into the output Q. On the positive edge of the SHIFT signal, the register shifts its current value to the right by one position, inserting a zero in the most significant bit, effectively discarding the least significant bit. This design allows for sequential data manipulation through either loading new data or shifting the existing data.
module top_module(
    input [3:0] D,
    input LOAD,
    input SHIFT,
    output reg [3:0] Q
);
