
Create a simple IIR filter that calculates the output based on the previous output and current input. The filter will have a feedback coefficient and a feedforward coefficient. You need to implement an IIR filter with the equation: 
Y[n] = (a * X[n]) + (b * Y[n-1])
where Y[n] is the current output, X[n] is the current input, a is the feedforward coefficient, and b is the feedback coefficient.
