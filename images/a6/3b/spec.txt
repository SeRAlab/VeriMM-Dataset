Design a simple arithmetic logic unit (ALU) that performs operations based on specified control inputs. The ALU takes a 3-bit function code (`alufun`), a 32-bit instruction (`inst`), a 2-bit selection signal (`op2sel`), and two 32-bit operands (`rs1` and `rs2`). Depending on the value of `op2sel`, the ALU may either add the operands or perform a left shift on `rs1` by the amount specified in `rs2`. The results are output as a 32-bit value (`result`). The ALU is designed to support basic arithmetic operations using the given function codes.
