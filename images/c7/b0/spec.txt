
You are tasked with designing a verilog module that implements a 4-bit counter with a synchronous reset and an enable input. The counter should increment by 1 on each positive edge of the clock when the enable input is high. When the enable input is low, the counter should not increment and should retain its current value. The counter should reset to 0 when the synchronous reset input is high. Your module should have the following inputs and outputs:

Inputs:
- `clk`: a 50 MHz clock signal
- `rst`: a synchronous reset signal
- `en`: an enable signal

Outputs:
- `count`: a 4-bit output representing the current count value

Your module should be named `counter_module`.
