

You are tasked with designing a sign extension module in Verilog. The module should take a 16-bit input and output a 32-bit output, where the upper 16 bits are the sign bit of the input repeated and the lower 16 bits are the input itself. 

Design a module named `signExt` that takes a 16-bit input named `inst` and outputs a 32-bit output named `data`. 

Instantiate the `signExt` module in the provided code snippet and initialize the `inst` input to the following values:
- `inst` = 16'b0000000011111010
- `inst` = 16'b1111111111111111

Simulate the module and verify that the output is correct for the given inputs.
