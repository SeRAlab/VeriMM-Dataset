Implement the Verilog module based on the following description.
Design a 3-bit binary up/down counter with an enable signal and an asynchronous reset.
(1) reset: Resets counter to zero.
(2) enable: Enables the counter to count.
(3) up_down: Determines the count direction (1 for up, 0 for down).
(4) q: The contents of the counter.

module top_module(
    input clk,
    input reset,
    input enable,
    input up_down,
    output reg [2:0] q);
