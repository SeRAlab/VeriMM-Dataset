Design a 4-bit SRAM cell that can store a 4-bit value. The SRAM cell should have the following inputs and outputs:
- Inputs: `address` (2 bits), `data_in` (4 bits), `write_enable` (1 bit), and `read_enable` (1 bit).
- Outputs: `data_out` (4 bits) which should output the stored value when read, and should be valid only when `read_enable` is high.

The SRAM should be able to store 4 different 4-bit values at different addresses. When `write_enable` is high, the input data should be stored at the specified address. When `read_enable` is high, the data from the specified address should be output.
