Design a packet filtering module for a basic firewall. The module should take a 16-bit input packet and a 4-bit filter mask. The output should indicate whether the packet is allowed (1) or blocked (0). The packet is allowed if the result of the bitwise AND operation between the packet and the mask is equal to a predefined allowed value, which is also a 16-bit value. If the condition is met, the output should be high; otherwise, it should be low.
