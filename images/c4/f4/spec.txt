

You are tasked with designing a verilog module to implement a 4-bit synchronous counter that counts from 0 to 9 and then resets to 0. The counter should have a clock input and a reset input. When the reset input is high, the counter should reset to 0. When the clock input transitions from low to high, the counter should increment by 1. The counter output should be displayed on a 4-bit output port.

Design a verilog module that meets these requirements.
