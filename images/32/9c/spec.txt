
Design an 8-bit DRAM cell that can store a single bit of data (0 or 1) for each of the 8 bits. The DRAM cell should have the following functionalities:
1. A `write` signal to determine when to write data into the cell.
2. An `address` input to select which bit to write to.
3. A `data_in` input to specify the value (0 or 1) to write.
4. A `read` signal to determine when to read data from the cell.
5. An `output` signal that provides the current value stored in the selected bit when reading.
6. The cell should hold its state until a new write occurs.

The 8 bits should be stored in an array, and the read and write operations should be asynchronous.
