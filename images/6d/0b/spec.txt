Design a D flip-flop with asynchronous reset and enable functionality. On the rising edge of the clock (CLK), if the reset (RST) input is asserted, the output (Q) is set to LOW. If the enable (EN) input is asserted and reset is not active, the output Q takes the value of the data input (D). This configuration allows for controlled data capture based on the clock signal while providing functionality to reset and enable data updates.
module top_module(
    input CLK,
    input D,
    input RST,
    input EN,
    output reg Q
);
