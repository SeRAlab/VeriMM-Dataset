
Design a Verilog module that simulates a simple EEPROM cell. The EEPROM cell should have the following functionality:
- Input `data_in` to write data.
- An `enable` signal to control the write operation.
- An `output` signal that reads the stored data.
- The stored data should only change when `enable` is HIGH.
- A reset signal `reset` to clear the stored data.
