Design a synchronous 4-bit up/down counter with load and clear functionalities. The module counts upwards when the mode (M) is set high and counts downwards when it is low. It can be cleared asynchronously through the CLR input or loaded with a new value provided by the inputs D, C, B, and A when the load (LD) signal is asserted. The current count state is reflected across four output bits (Qd, Qc, Qb, Qa), and a carry-out flag (Qcc) indicates whether the counter has wrapped around to 0 or 15. When CLR is activated, the counter resets to 0, while the load operation initializes the count with the specified value.
module top_module(input CP,M,D,C,B,A,LD,CLR,output reg Qd,Qc,Qb,Qa,Qcc);
