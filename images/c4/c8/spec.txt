

You are tasked with designing a Verilog module for a 4-bit binary counter that counts up every rising edge of the input clock. The module should have an asynchronous reset input that resets the counter to 0 when asserted. The module should also have an output that is high when the counter reaches the maximum value (15) and low otherwise. The module should be named "binary_counter" and should have the following inputs and outputs:

Inputs:
- clk (1-bit input): the clock signal
- rst (1-bit input): the asynchronous reset signal

Outputs:
- count (4-bit output): the current count value
- max_reached (1-bit output): high when the counter reaches the maximum value (15), low otherwise

You can assume that the input clock signal has a 50% duty cycle and a frequency of 50 MHz.

Write the Verilog code for the "binary_counter" module.
