Design a Verilog module that implements an OFDM modulator. The module should take an input bit stream, modulate it using a simple QPSK (Quadrature Phase Shift Keying) scheme, and output the real and imaginary components of the signal for each symbol. The input bit stream will be 8 bits wide, and the output should be two 8-bit wide signals representing the real and imaginary parts of the QPSK-modulated symbols. The modulation should be done based on pairs of bits from the input stream (00, 01, 10, 11).
