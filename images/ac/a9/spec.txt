Develop a module that performs simple encryption and decryption of memory data using a bitwise XOR operation with a specified key. The module takes an input address and data of defined widths, applies the XOR operation with the provided key, and outputs the resultant encrypted or decrypted data of the same width. This design serves as a lightweight and efficient mechanism for securing data stored in memory.
module top_module(
  input [mem_width-1:0] mem_addr,
  input [mem_width-1:0] mem_data,
  input [key_width-1:0] key,
  output [mem_width-1:0] enc_data
);
