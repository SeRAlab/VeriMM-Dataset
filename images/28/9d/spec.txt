
Design a 4-channel DMA controller that can handle read/write requests from multiple peripheral devices. The controller should have the following features:
1. Four input request lines (req0, req1, req2, req3) for the peripheral devices.
2. A single output grant line (grant) to indicate which peripheral device is granted access to the bus.
3. A round-robin scheduling mechanism to ensure fair access to the bus.
4. An output done signal (done) to indicate when the transfer is complete.
5. A clock (clk) and reset (rst) signals to control the operation of the controller.
