The provided Verilog code implements a simple GPIO controller with a Wishbone slave interface, enabling communication with an external bus. Its primary function is to manage 14 output LEDs and read an 8-bit switch input, allowing the LEDs to be updated based on external data or switch states. The module supports write operations to set the LED states and provides the current switch value upon request. Additionally, it detects a push button press and generates a non-maskable interrupt (NMI) signal based on this input, utilizing a tick signal to help debounce the button press. The design incorporates state management for the NMI functionality and ensures safe resets of all outputs and internal registers.
