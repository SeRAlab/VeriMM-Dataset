

You are tasked with designing a Verilog module that will perform a simple arithmetic operation on two input numbers. The module should have two input ports, A and B, each of which is 8 bits wide. The module should also have an output port, C, which is 16 bits wide. 

The module should take the two input numbers, add them together, and output the result on port C. If the result of the addition is greater than 16 bits, the module should truncate the result to 16 bits by dropping the least significant bits. 

Write a Verilog module that performs the above operation.
