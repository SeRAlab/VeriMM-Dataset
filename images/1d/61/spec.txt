Design a 2-channel DMA controller that can handle two different data transfer requests. The DMA controller should have the following inputs: `request1`, `request2` (indicating data transfer requests), `clk` (clock signal), `reset` (reset signal), and outputs: `grant1`, `grant2` (grant signals for each channel). The controller should prioritize `request1` over `request2`. When both requests are active, `grant1` should be high, and `grant2` should be low. If `request1` is inactive, `grant2` should follow `request2`. The controller should also handle reset conditions properly.
