
Design a 1-bit SRAM cell in Verilog. The SRAM cell should have the following inputs:
- `data_in`: the data to be stored (1 bit)
- `write_enable`: signal to enable writing to the cell (1 bit)
- `read_enable`: signal to enable reading from the cell (1 bit)

The SRAM cell should output:
- `data_out`: the stored data (1 bit) when `read_enable` is high.
It should retain the stored value when `write_enable` is low.
