Design a circuit that performs bitwise logical operations based on a 2-bit selector input. The module takes two 1-bit inputs, A and B, and uses the SEL input to choose between four operations: AND when SEL is 00, OR when SEL is 01, XOR when SEL is 10, and NOT of A when SEL is 11. The output is a single bit, C, which reflects the result of the selected operation, defaulting to an undefined state for invalid selector values.
module top_module(
  input A,
  input B,
  input [1:0] SEL,
  output C
);
