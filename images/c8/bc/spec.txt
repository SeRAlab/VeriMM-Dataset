
You are tasked with designing a Verilog module for a binary to gray code converter. The module should have a single 8-bit input port `binary` and a single 8-bit output port `gray`. The module should convert the binary input to gray code and output it through the `gray` port. The module should be named `binary_to_gray`.

Gray code is a binary numeral system where two consecutive values differ in only one bit. For example, the binary representation of decimal 3 is 0011, and its corresponding gray code is 0010. The gray code representation of a binary number can be obtained by performing an exclusive OR (XOR) operation between the binary number and its right-shifted version.

You can assume that the input binary number is always valid and within the range of 0 to 255.
