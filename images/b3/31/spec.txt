Design a 16-bit shift register with load and shift capabilities. The module stores data in a 16-bit register that can be loaded with a new value upon a high load signal. On each clock cycle, if the reset signal is asserted, the register is cleared to zero. If the shift signal is active, the contents of the register are shifted left by one bit, inserting a zero into the least significant bit. The current value of the register is always available on the output.
