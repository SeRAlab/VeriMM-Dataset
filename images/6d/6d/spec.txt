Design a 4-to-1 multiplexer that selects one of four input signals (A, B, C, or D) based on two selection bits (S0 and S1). The output X is determined by the combination of the selection inputs: when S0 and S1 both are low, output A is selected; when S0 is low and S1 is high, output B is selected; when S0 is high and S1 is low, output C is selected; and when both S0 and S1 are high, output D is chosen.
module top_module(
    input A, B, C, D,
    input S0, S1,
    output X
);
