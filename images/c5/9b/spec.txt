

In this problem, you are given a module called "Test_Line" which has one input called "address", one input called "clock", and one output called "q". The "address" input is a single bit, the "clock" input is a clock signal, and the "q" output is an 8-bit vector. Your task is to implement the logic for this module such that the output "q" is generated based on the following rules:

1. When the "address" input is 0, the output "q" should be equal to 0.
2. When the "address" input is 1, the output "q" should be equal to the value of "address" shifted left by 7 bits.

You need to implement this logic in a single module without using any other modules.
