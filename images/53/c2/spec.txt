Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state A (output 1).
2. state B (output 0).
3. state C (output 1).
4. state D (output 0).

State transitions:
1. From state A: If x = 1, then transition to state B. If x = 0, then transition to state D.
2. From state B: If x = 1, then transition to state C. If x = 0, then transition to state A.
3. From state C: If x = 1, then transition to state D. If x = 0, then transition to state A.
4. From state D: If x = 1, then transition to state B. If x = 0, then transition to state A.

Assume that a one-hot code is used with the state assignment y[3:0] = 0001(A), 0010(B), 0100(C), 1000(D)

Write a Verilog for the signal Y2, which is the input of state flip-flop y[2], for the signal Y3, which is the input of state flip-flop y[3]. Derive the Verilog by inspection assuming a one-hot encoding.
