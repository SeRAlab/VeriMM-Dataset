Design a Verilog module for a flash memory cell. The flash memory cell should be able to store a single bit of data (0 or 1) and should have the following functionalities:
1. A write operation that takes a data input (1 bit) and a write enable signal.
2. A read operation that provides the stored data output.
The memory cell should retain its state until a new write operation is performed, and it should be initialized to 0 at startup.
