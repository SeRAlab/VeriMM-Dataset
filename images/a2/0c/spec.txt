Design a binary to seven-segment display decoder. The module converts a 4-bit binary input (D) representing values from 0 to 15 into a corresponding 7-bit output (S) that drives a common cathode seven-segment display. Each combination of the 4-bit input selects the appropriate segment configuration to display the hexadecimal digit. The output is inverted to match the common cathode display's active-low nature, ensuring the correct segments light up based on the input value.
