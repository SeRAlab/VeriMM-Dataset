

You are tasked with designing a circuit using Verilog that implements a 2-to-1 multiplexer. The circuit should have two inputs, A and B, and one output, Y. The select input, S, should determine which input is passed to the output. If S is 0, A should be passed to Y. If S is 1, B should be passed to Y.

You should use only one module within 200 lines of Verilog code to implement this circuit. The module should be named "mux2to1" and should have the following inputs and outputs:
- A (1-bit input)
- B (1-bit input)
- S (1-bit input)
- Y (1-bit output)

The module should be synthesizable and should not use any non-synthesizable constructs or system tasks.
