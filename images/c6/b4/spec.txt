

You are tasked with designing a module that takes in three inputs `CLK`, `EN`, and `TE` and outputs a single value `ENCLK`. The module should be named `clock_gate_high` and should be written in Verilog within 200 lines of code.

The `CLK` input is a clock signal that is used to synchronize the module. The `EN` input is a control signal that enables the module. The `TE` input is a control signal that sets the output to a high value.

The output `ENCLK` should be high when both `EN` and `TE` are high and the `CLK` signal is high. Otherwise, `ENCLK` should be low.

You can assume that all inputs and outputs are single-bit signals.

Write a Verilog module `clock_gate_high` that meets the above requirements.
