Implement the Verilog module based on the following description.
Create a module that implements a 16-bit Fibonacci sequence generator. Each rising edge of the clock should generate the next Fibonacci number. The reset input is active high synchronous, and should reset the sequence to the first two Fibonacci numbers (1 and 1).
module fibonacci_generator(
	input clk,
	input reset,
	output reg [15:0] fib1,
	output reg [15:0] fib2);
