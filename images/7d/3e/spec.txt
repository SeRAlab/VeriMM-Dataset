Design a synchronous 8-bit counter with load functionality. When the reset input is asserted, the counter output (q) resets to zero. If the load input is active, the counter sets its output to the value present at data_in. In normal operation, when enable is high, the counter increments its output by one on each rising edge of the clock.
module top_module(
	input clk,
	input reset,
	input enable,
	input load,
	input [7:0] data_in,
	output reg [7:0] q
);
