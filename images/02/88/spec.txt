Design an 8-bit DRAM cell that can perform read and write operations. The DRAM cell should have the following inputs: 
- `data_in`: 8-bit input data to be written to the cell. 
- `addr`: 3-bit address to select one of the 8 cells. 
- `we`: write enable signal (active high).
- `clk`: clock signal for synchronous operation.
The output should be `data_out`, which is the 8-bit data read from the cell when the `we` signal is low.
