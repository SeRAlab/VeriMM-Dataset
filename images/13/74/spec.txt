Create a module that implements an HMAC (Hash-based Message Authentication Code) using a simple hash function (e.g., a XOR operation). The module should take a message and a key as inputs and produce a MAC as output. It should also be able to reset. The module should have the following ports:  
- `input [127:0] key`  
- `input [127:0] message`  
- `input clk`  
- `input rst`  
- `output reg [127:0] mac`  
The MAC is generated by performing a simple XOR between the key and the message. The MAC should be updated on the rising edge of the clock unless reset is high, in which case the MAC should be set to zero.
