Design a Verilog module for an SR latch using NAND gates. The latch should have two inputs (S and R) and two outputs (Q and Qn). The output Q should maintain its state unless S or R is activated, with the following conditions: 
- If S = 1 and R = 0, then Q = 1.
- If S = 0 and R = 1, then Q = 0.
- If S = 0 and R = 0, then Q maintains its previous state.
- If S = 1 and R = 1, the output is invalid (undefined state).
