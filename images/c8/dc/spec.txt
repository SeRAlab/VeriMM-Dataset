

You are given a Verilog code snippet that instantiates a D flip-flop with asynchronous reset and a testbench module that tests the functionality of the D flip-flop. Your task is to implement the D flip-flop module, `dff_async_rst`, such that it meets the following requirements:

- The module should have four inputs: `clk`, `rst`, `d`, and `en`.
- The module should have one output: `q`.
- The module should implement a D flip-flop with asynchronous reset and enable.
- The module should sample the input `d` on the rising edge of the clock `clk` only if `en` is high.
- If `rst` is high, the output `q` should be set to 0 regardless of the value of `d` and `en`.
- If `en` is low, the output `q` should hold its previous value.

Write the Verilog code for the `dff_async_rst` module that meets these requirements.
