Implement a simple RNN cell for inference. The RNN cell should take a 2-dimensional input vector and produce a 2-dimensional output vector. The cell should also maintain a hidden state between time steps. The computation for the next hidden state is defined as:  
h(t) = tanh(W_hh * h(t-1) + W_xh * x(t))  
Where W_hh and W_xh are the weight matrices and x(t) is the input vector at time t. The output is given by:  
y(t) = W_hy * h(t)  
Assume that the weights are predefined and fixed in the design.
