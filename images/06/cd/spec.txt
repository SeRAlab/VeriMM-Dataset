
Design a Verilog module for an EEPROM cell that can write, read, and erase data. The module should have the following inputs:
- `clk`: Clock signal
- `write_enable`: Signal to enable writing to the EEPROM
- `erase_enable`: Signal to enable erasing the EEPROM
- `data_in`: 8-bit data input for writing
- `address`: 4-bit address to specify the location in the EEPROM
The module should have the following output:
- `data_out`: 8-bit data output for reading from the EEPROM
The EEPROM should be implemented with a simple array of registers. Provide appropriate handling for write, read, and erase operations based on the control signals.
