Design a D flip-flop with an asynchronous active-low set input. The flip-flop captures the value of the input D on the rising edge of the clock (CLK) unless the SET signal is asserted low, in which case the output Q is reset to low. Additionally, a notifier signal is generated to indicate when the output Q does not match the input D. The circuit is powered by VPWR and grounded by VGND, ensuring proper operation within the intended voltage range.

    output reg Q,        // Change to 'reg' type for storage
    input D,
    input CLK,
    input SET,
    input NOTIFIER,
    input VPWR,
    input VGND
);
