Implement an 8-bit wide memory module that supports read and write operations, with a size capacity of 128 locations. On a positive clock edge, the module initializes the first five memory locations upon receiving a reset signal. If enabled (en=1) and in write mode (r_w=0), it stores the input data (dbus_in) at the address specified by abus. If enabled and in read mode (r_w=1), it outputs the data stored at the specified address through dbus_out. If not in read or write mode, the data output is high impedance (8'hZZ).
module top_module(input clock, reset, en, r_w, input [7:0] abus, input [7:0] dbus_in, output [7:0] dbus_out);
