Design a simple DVFS controller that adjusts the voltage and frequency of a system based on the input load. The controller has a 3-bit input `load` (0 to 7) that represents the current load on the system, and it outputs a 2-bit `frequency` and a 2-bit `voltage`. The mapping is as follows: 
- For load 0-2: frequency = 00, voltage = 00 (Lowest)
- For load 3-5: frequency = 01, voltage = 01
- For load 6-7: frequency = 10, voltage = 10 (Highest)
