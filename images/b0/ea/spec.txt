Design a 3-bit up/down counter that counts in the direction specified by the input signal, `direction`. On each positive edge of the clock, the counter either increments or decrements its value based on the direction input. The counter resets to zero upon receiving a reset signal. The current count value is output as a 3-bit wide signal.
module top_module(
    input clk,
    input reset,
    input direction,
    output reg [2:0] count
);
