

You have been tasked with designing a module that takes in various inputs and outputs. The module should have the following ports:

- `clk`: input clock
- `reset`: asynchronous reset signal
- `in_data`: input data of 32 bits
- `in_valid`: input valid signal
- `out_data`: output data of 32 bits
- `out_valid`: output valid signal

The module should perform the following operations:

- When `in_valid` is high, the module should store the `in_data` value and set `out_valid` high.
- When `out_valid` is high, the module should output the stored `in_data` value and set `out_valid` low.
- If `reset` is high, the module should reset the stored `in_data` value and set `out_valid` low.

Write a Verilog module that implements the above requirements.
