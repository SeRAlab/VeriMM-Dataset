Design an 8-bit SRAM cell that can read and write data on a rising edge of a clock signal. The SRAM should have the following inputs: a 3-bit address (for addressing 8 locations), a 8-bit data input for writing, a read enable (RE) signal, and a write enable (WE) signal. It should output the 8-bit data stored at the given address when read is enabled. If write is enabled, it should store the input data at the given address.
