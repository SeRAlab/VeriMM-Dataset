
Design an 8-bit Digital-to-Analog Converter (DAC) that takes an 8-bit input and outputs a corresponding voltage level on a 10-bit output. The output voltage levels are determined by the following formula: Voltage = (Input Value / 255) * V_REF, where V_REF is a reference voltage set to 5V. The output should be 10 bits wide to represent the voltage as a digital number from 0 to 1023 (10 bits).
