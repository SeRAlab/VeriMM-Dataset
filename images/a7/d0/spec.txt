Design a D flip-flop with an asynchronous active-low set feature. When the clock signal (CLK) has a positive edge, the output (Q) will be set to high if the active-low set signal (SET_B) is low. Otherwise, the output will follow the input data signal (D). This allows for immediate control over the output state, irrespective of the clock, by using the SET_B signal.
