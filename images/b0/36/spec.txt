Design a four-input, one-bit wide multiplexer with enable functionality. When the enable signal (en) is high, the output (out) selects one of the four inputs (in0, in1, in2, in3) based on the two-bit select signal (sel); each combination of sel corresponds to one of the input lines. If the enable signal is low, the output is forced to LOW.
module top_module(
  input in0,
  input in1,
  input in2,
  input in3,
  input [1:0] sel,
  input en,
  output reg out  // Changed from wire to reg
);
