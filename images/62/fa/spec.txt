Implement a 3-bit binary down counter with synchronous reset and load capability. The counter should count down from 7 to 0 and then wrap around back to 7. The counter should have an enable signal to start counting and a load signal to load a specific count value.

Module name:  
    binary_down_counter   

Input ports:
    clk: Clock signal used for synchronous operation.
    rst: Active-high synchronous reset signal.
    enable: Signal to enable counting.
    load: Signal to load the count value.
    load_val: 3-bit input value to be loaded into the counter.

Output ports:
    count: 3-bit output representing the current count value.

Implementation:
The count register is updated on the positive edge of the clock signal (posedge clk) and reset on the positive edge of the reset signal (posedge rst).
When the enable signal is high, the count register decrements by 1. When the count reaches 0, it wraps around to 7 in the next clock cycle.
When the load signal is high, the count register is loaded with load_val.

Give me the complete code.

module binary_down_counter(
    input                 clk,
    input                 rst,
    input                 enable,
    input                 load,
    input       [2:0]     load_val,
    output   reg [2:0]    count
);
