

You are tasked with implementing a Verilog module that checks for a specific property. The module should be named `property_checker` and should have the following inputs and outputs:

Inputs:
- `clock`: a single bit input representing the clock signal.
- `reset`: a single bit input representing the reset signal.
- `data`: a 4-bit input representing the data to be checked.

Outputs:
- `property_met`: a single bit output representing whether or not the property is met.

The property that needs to be checked is as follows: if the `data` input is equal to `4'b1100` for 3 consecutive clock cycles, then the `property_met` output should be set to 1.

You should assume that the clock signal has a frequency of 10MHz, and that the reset signal is synchronous to the clock signal. The reset signal should reset the module to its initial state, where the `property_met` output is set to 0.

Write a Verilog module that implements the `property_checker` module as described above. Your module should be no longer than 200 lines of code.
