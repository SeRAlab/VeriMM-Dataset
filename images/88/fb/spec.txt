Implement a Verilog module for a 3-bit counter with enable and asynchronous reset. The counter should have a clock input `clk`, an asynchronous reset input `rst`, an enable input `en`, and a 3-bit output `Q`. When `rst` is high, `Q` should be set to 0. When `en` is high, `Q` should increment by 1 on the rising edge of `clk`.

module counter3(
	input wire clk,
	input wire rst,
	input wire en,
	output reg [2:0] Q
);
