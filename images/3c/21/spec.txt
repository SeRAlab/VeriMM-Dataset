
Design a data forwarding unit that takes three input signals: `data1`, `data2`, and `forward_signal`. Based on the `forward_signal`, the output `forwarded_data` should be:
- If `forward_signal` is 00, output should be `data1`.
- If `forward_signal` is 01, output should be `data2`.
- If `forward_signal` is 10, output should be `data1 + data2`.
- If `forward_signal` is 11, output should be 0.
