Design a circuit that performs a bitwise AND operation on two 8-bit inputs, `a` and `b`. The operation occurs on the positive edge of the active-low reset signal, `reset_n`. If `reset_n` is low, the output `out` is reset to zero; otherwise, it outputs the result of the AND operation between `a` and `b`.
module top_module(
    input [7:0] a,
    input [7:0] b,
    input reset_n,
    output reg [7:0] out
);
