

You have been tasked to design a verilog module for a simple binary adder. The module should have two inputs, A and B, and one output, S, which represents the sum of A and B. The module should also have a control input, C, which determines whether the adder should perform addition or subtraction. If C is high, the adder should perform subtraction, otherwise it should perform addition. 

Assume that A, B, and S are all 8-bit unsigned integers. The module should be named "binary_adder".

Please write the verilog code for this module.
