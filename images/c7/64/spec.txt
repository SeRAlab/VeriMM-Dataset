

You are tasked with designing a module that takes in three inputs and produces one output. The module should be named `three_to_one` and should have the following ports:

- `input [1:0] A`
- `input [1:0] B`
- `input [1:0] C`
- `output [2:0] Y`

The output `Y` should be the concatenation of the inputs `A`, `B`, and `C`, in that order. 

You should use the following verilog code snippet as a starting point:

```
module three_to_one (
    // ports here
);

    // your code here

endmodule
```
