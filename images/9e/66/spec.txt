Design a D-type flip-flop with asynchronous reset and set signals. On the rising edge of the clock, the output Q updates to the value of the data input D. If the RESET signal is asserted, Q is set to LOW, overriding the data input. If the SET signal is asserted instead, Q is set to HIGH, also overriding the data input. This design allows for synchronous operation controlled by the clock, as well as asynchronous control to force the output to a known state.
module top_module(
    input D,
    input CLK,
    input RESET,
    input SET,
    output reg Q
);
