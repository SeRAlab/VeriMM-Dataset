
Design a FIFO (First In, First Out) queue with a parameterized depth. The FIFO should support the following operations:
- `enqueue`: Adds an element to the end of the queue.
- `dequeue`: Removes an element from the front of the queue.
- `is_empty`: Checks if the queue is empty.
- `is_full`: Checks if the queue is full.
The FIFO should have a synchronous reset signal that clears the queue.
