Implement a 4-bit binary up-counter with reset functionality. The counter increments its value on each positive edge of the clock, and when it reaches the maximum count of 15, it wraps around to 0. A reset signal sets the count back to 0 and asserts a 'done' signal to indicate the counter has completed a cycle. The 'done' signal is also asserted when the counter is reset or when the count reaches 15, otherwise it remains low during normal counting.

   // Inputs
   clk,
   reset,

   // Outputs
   count,
   done
   );
