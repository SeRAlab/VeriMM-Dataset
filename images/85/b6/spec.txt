Design a clocked D flip-flop with asynchronous reset functionality. The circuit captures the value of the input `din` on the rising edge of the clock signal (`clk`), provided that the reset signal (`reset_n`) is not asserted (active-low). When `reset_n` is low, the output resets to 0. The output of the D flip-flop is given by `dout`, which reflects the stored value. This module effectively serves as a basic memory element in digital systems, suitable for storing binary information in synchronous applications.
module top_module(
    input clk,
    input din,
    input reset_n,
    output dout
);
