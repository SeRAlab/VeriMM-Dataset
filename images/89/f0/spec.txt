Design a 3-bit up/down counter that counts in either ascending or descending order based on the mode input. The counter increments its value when the mode is set to up and decrements when the mode is set to down. It wraps around to 0 after reaching the maximum value of 7 (111 in binary) during increment and wraps around to 7 after reaching 0 during decrement. The counter operations are enabled only when the enable input is high, and it resets to 0 when the reset input is activated.
module top_module(
  input clk,
  input reset,
  input enable,
  input mode,
  output reg [2:0] q
);
