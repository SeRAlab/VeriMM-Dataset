Design a 4-register file with write capabilities and dual read outputs. The module allows data to be written to one of four 8-bit registers (reg0 to reg3) on a rising clock edge, controlled by a write signal and a write select signal. It outputs the contents of two selected registers based on the select signals (select0 and select1). Additionally, the contents of reg0, reg2, and reg3 are continuously available as output for external access, while the registers are initialized to zero on a reset.
module top_module(input clk, reset_n, write, input [7:0] data, input [1:0] select0, select1, wr_select,
				output reg [7:0] selected0, selected1, output reg [7:0] delay, position, register0);
