

You are tasked with designing a module that takes in a 4-bit input and outputs a 2-bit value representing the number of 1's in the input. For example, if the input is 0011, the output should be 01 (since there are two 1's in the input). 

Your module should have the following ports:
- `input [3:0] in`
- `output [1:0] out`

Write the Verilog code for this module.
