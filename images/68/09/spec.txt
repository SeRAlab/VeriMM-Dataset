Design a 32-bit wide synchronous RAM module that supports both read and write operations. The memory has a capacity of 1024 addresses, with each address holding a 32-bit data word. The module provides a reset functionality to initialize all memory locations to zero. On a positive clock edge, if the reset signal is asserted, it clears the RAM. If a write request is made (m_write is high), it stores the input data (m_din) into the specified address (m_addr). If a read request is active (m_read is high), it outputs the data from the specified address to m_dout. The addressed memory locations are derived from the lowest 10 bits of the input address.
module top_module(clk, rst, m_read, m_write, m_addr, m_din,m_dout);
