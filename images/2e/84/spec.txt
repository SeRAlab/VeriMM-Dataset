
Design a simple interrupt controller that can handle two types of interrupts: a hardware interrupt and a software interrupt. The controller should have the following inputs: `hw_interrupt`, `sw_interrupt`, and a clock signal `clk`. The outputs should be `interrupt_active` and `interrupt_type`, where `interrupt_active` indicates if an interrupt is currently being serviced, and `interrupt_type` indicates which type of interrupt is active (0 for hardware, 1 for software). The interrupt should be serviced on the rising edge of the clock, and the controller should ignore new interrupts while one is being serviced.
