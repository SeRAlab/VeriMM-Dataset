Given the following Moore state machine with 1 input (in) and 1 output (out). Unless otherwise stated in the diagram below, assume outputs are 0 and inputs are don't cares.

1. state W (out=0).
2. state X (out=1).
3. state Y (out=1).
4. state Z (out=0).

State transitions:
1. From state W: If in = 0, then remain in state W. If in = 1, then transition to state X.
2. From state X: If in = 0, then transition to state Y. If in = 1, then remain in state X.
3. From state Y: If in = 0, then transition to state Z. If in = 1, then remain in state Y.
4. From state Z: If in = 0, then transition to state W. If in = 1, then transition to state X.

At reset, the state machine starts in state "W". Derive next-state logic equations and output logic equations by inspection assuming the following one-hot encoding is used: (W, X, Y, Z) = (4'b0001, 4'b0010, 4'b0100, 4'b1000)

Write code that generates the following equations:

- W_next -- next-state logic for state W
- X_next
- Y_next
- Z_next
- out -- output logic
