Design a 4-bit shift register with load and shift functionality. When the load signal is asserted, the register stores the input data, `data_in`. If the load signal is not active and the shift signal is asserted, the register shifts the stored data to the left by one position, filling the least significant bit with a zero. The current value of the shift register is continuously output as `data_out`.
module top_module(
    input clk,
    input load,
    input [3:0] data_in,
    input shift,
    output [3:0] data_out
);
