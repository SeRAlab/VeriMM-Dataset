Design a D flip-flop with an asynchronous active-low set input. The circuit captures the input data (D) on the rising edge of the clock signal (CLK) and outputs the captured value at Q, while Q_N provides the inverted output. Additionally, when the asynchronous set input (SET_B) is low, it forces the output Q to high regardless of the clock or data input, effectively resetting the flip-flop. The design includes delayed signals for debouncing and a notifier mechanism to handle changes in the asynchronous set condition.
