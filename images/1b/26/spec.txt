Design a state-space controller in Verilog that takes a 4-bit binary input representing a state and produces a 4-bit binary output representing the next state. The next state should be determined by a predefined state transition table. For simplicity, assume there are 4 states (00, 01, 10, 11) and the following transitions:
- State 00 -> State 01
- State 01 -> State 10
- State 10 -> State 11
- State 11 -> State 00
The input should be clocked and the output should be valid on the rising edge of the clock.
