Design a 2-to-4 decoder that activates one of four output lines based on the 2-bit input `x` when the `enable` signal is high. If `enable` is low, all output lines will be set to LOW. The outputs `y` are assigned as follows: when `x` is 00, 01, 10, or 11, the corresponding output line (0, 1, 2, or 3) is set HIGH while the others remain LOW.
module top_module(
input wire  [1:0] x,
input wire  enable,
output reg  [3:0] y 
);
