Design a 2-bit up-down counter that increments or decrements its output based on a control signal. The counter resets to 0 when the reset signal is activated. If the control signal is high, it counts up from 00 to 11 and wraps around back to 00. If the control signal is low, it counts down from 11 to 00 and wraps around to 11 when it reaches 00.
module top_module(
    input clk,
    input rst,
    input ctrl,
    output reg [1:0] out
);
