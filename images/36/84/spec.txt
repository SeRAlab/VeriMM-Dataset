A simple SD card interface problem that takes a 4-bit command input and outputs a corresponding 3-bit response. The mapping is as follows: command '0000' (0) maps to response '000' (0), '0001' (1) to '001' (1), '0010' (2) to '010' (2), '0011' (3) to '011' (3), and any other input results in '111' (invalid).
