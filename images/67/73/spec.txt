Implement a 4-bit binary to 7-segment display decoder. This module takes a 4-bit binary input, `c`, and generates the corresponding output signals for a standard 7-segment display, `ss_out`, to visually represent the binary value as a decimal digit from 0 to 9. It uses combinational logic to determine which segments of the display should be illuminated based on the input value.
