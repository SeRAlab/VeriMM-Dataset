Design a Verilog module for a 16-bit binary counter with an enable signal. The counter increments its value on the rising edge of the clock when the enable signal is active. The counter should not increment when the enable signal is inactive.

Module name:  
    counter_16bit  

Input ports:
    clk: Chip clock signal.
    en: Enable signal.

Output ports:
    count: Counter output signal with a data width of 16 bits.

Implementation:
Counter operation:
On every positive edge of the clock signal (clk), the counter (count) increments its value if the enable signal (en) is active. If the enable signal is inactive, the counter retains its current value.
