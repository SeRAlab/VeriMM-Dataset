Design a 4-bit binary counter that increments on each positive edge of a clock signal when enabled. The counter resets to zero both synchronously when the reset signal is low and when it reaches its maximum count of 15 (4'b1111). The enable input controls whether the counter is active, allowing for flexible operation in a larger system design.
module top_module(
  input clk, // 10 ns clock
  input rst_n, // synchronous reset (active low)
  input en, // enable input
  output reg [3:0] count // 4-bit output port
);
