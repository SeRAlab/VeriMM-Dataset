Design a 4-bit DRAM cell with read and write operations. The DRAM cell should have the following characteristics: 
- It will have a 4-bit data input (D[3:0]) and a 4-bit data output (Q[3:0]).
- It should have a write enable signal (WE) to control write operations.
- It should have a read enable signal (RE) to control read operations.
- The DRAM cell should retain the data until a write operation is performed.
- The cell should respond to the read operation only when RE is enabled and must output the current stored data.
