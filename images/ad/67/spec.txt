The machine transitions between states according to specified conditions, producing outputs `out1` and `out2`. Initially, upon reset, the state is set to S0, where both outputs are LOW. The machine loops back to S0 when `in2` is HIGH, allowing for continuous operation based on the input signals.
module top_module(
  input in1,
  input in2,
  input clk,
  input reset,
  output reg out1,
  output reg out2
