Design a 32-bit wide XNOR gate that performs a bit-wise XNOR operation between two 32-bit inputs, INA and INB. The output, OP, will also be 32 bits wide and will contain the results of the XNOR operation for each corresponding bit of the input signals, producing a logical true (1) when both bits are equal and a false (0) when they are different.
module top_module(
    input [31:0] INA,
    input [31:0] INB,
    output [31:0] OP
    );
