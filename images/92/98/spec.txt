Design a D flip-flop with asynchronous reset and set capabilities. On each rising edge of the clock, if the reset (rst) signal is active, the output (q) is set to LOW. If the set signal is active instead, the output is set to HIGH. Otherwise, the output follows the data input (d). The module also provides the complementary output (qn) as the inverted value of q.
module top_module(
    input clk,
    input rst,
    input set,
    input d,
    output reg q,    // Changed 'output q' to 'output reg q'
    output qn
);
