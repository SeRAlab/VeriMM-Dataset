Design a 4-bit adder-subtractor circuit. The module takes four 4-bit inputs (A, B, C, and D) and a control signal (S). When S is low (0), the circuit computes the sum of the inputs (A + B + C + D). When S is high (1), it performs the subtraction (A - B - C - D). The result is output as a 4-bit value Q.
module top_module(
    input  [3:0] A,
    input  [3:0] B,
    input  [3:0] C,
    input  [3:0] D,
    input        S,
    output [3:0] Q
);
