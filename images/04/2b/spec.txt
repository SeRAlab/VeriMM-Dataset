
Design a 4-bit SRAM cell with read and write functionality. The SRAM cell should have the following specifications:
- It should take a 4-bit input data and a write enable signal to write data.
- It should take a read enable signal to output the stored data.
- The SRAM cell should have a reset signal to clear the stored data.
- The output should be valid only when the read enable signal is asserted.
