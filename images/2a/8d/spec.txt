
Design a fixed-coefficient Infinite Impulse Response (IIR) filter in Verilog. The filter should take a 16-bit input sample, apply a second-order IIR filter equation, and output a 16-bit filtered result. The filter coefficients should be defined in the code. Implement a synchronous reset and a clock signal. The equation for the IIR filter can be defined as follows:
y[n] = b0 * x[n] + b1 * x[n-1] + b2 * x[n-2] - a1 * y[n-1] - a2 * y[n-2]
Where:
- b0, b1, b2 are the feedforward coefficients
- a1, a2 are the feedback coefficients
