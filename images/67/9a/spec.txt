Create a Verilog module for an 8-bit parallel load register. It should take a clock input (clk), a reset input (rst), a load enable input (load), an 8-bit data input (data_in), and produce an 8-bit output (data_out). The register should load data from data_in to data_out on the positive edge of the clock when load is asserted and hold its value otherwise. It should reset to 0 when rst is asserted.
