Design an IIR filter in Verilog that takes a 16-bit input signal and produces a 16-bit output signal. The filter should implement a simple first-order IIR filter defined by the equation:  
y[n] = a * x[n] + (1 - a) * y[n-1]  
Where 'a' is a fixed coefficient (for example, 0.5). The module should have a clock and a reset signal, and it should be capable of processing incoming data on each clock cycle.
