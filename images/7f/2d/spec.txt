Design a circuit that functions as a memory read controller. When the MemRead signal is asserted (set to 1), the module outputs the 32-bit instruction provided on the ninst input to the inst output. If MemRead is not asserted, the output inst remains unchanged, effectively allowing the output to hold its previous value until a read operation is triggered.
module top_module(input wire MemRead,
					input wire [31:0]ninst,
					output reg [31:0]inst
    );
