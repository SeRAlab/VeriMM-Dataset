Design a 1-bit DRAM cell that allows for storing and retrieving a single bit of data. The cell should have the following inputs: `data` (the bit to be stored), `read` (to read the stored bit), and `write` (to write to the cell). The output should be `q`, which reflects the stored bit when `read` is active. When `write` is active, the `data` should be stored in the cell.
