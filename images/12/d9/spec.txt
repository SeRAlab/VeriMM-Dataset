Design a combinational logic circuit that implements a simple decision tree for classifying a binary input into one of four categories based on two input bits (A and B). The categories can be defined as follows:
- If A = 0 and B = 0, classify as 00
- If A = 0 and B = 1, classify as 01
- If A = 1 and B = 0, classify as 10
- If A = 1 and B = 1, classify as 11
The output will be a two-bit value representing the classified category.
