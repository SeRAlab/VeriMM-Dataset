Design a four-bit up counter with load and carry-out capabilities. The counter is set to zero on a reset signal, loads a new value from the input PI when the load signal (ld) is high, and increments its current value by 1 on the positive edge of the clock (CLK) when the count signal (cnt) is true, depending on the carry-in signal (Ci). Additionally, a carry-out (Co) output is generated whenever the count operation is active, indicating when the counter reaches its maximum value in conjunction with the carry-in.
module top_module(input PI, CLK, reset, ld, cnt, Ci, output reg[3:0] PO, output Co);
