Design a parameterized shift register that can store a specified number of stages, with each stage being 32 bits wide. The module has inputs for clock, asynchronous reset, clear, and enable signals. On each clock cycle, if enabled, the data input D is loaded into the first stage, while subsequent stages pass their previous stage data forward. Both the reset and clear signals can set all stages to zero independently. The output Q reflects the contents of the last stage, providing the resulting shifted data.
