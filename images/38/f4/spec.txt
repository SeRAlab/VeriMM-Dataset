
Design a Direct Memory Access (DMA) controller that can transfer data from a source memory address to a destination memory address in a given number of cycles. The DMA controller should include the following inputs:
- `start`: A signal to initiate the transfer.
- `src_addr`: The source memory address.
- `dest_addr`: The destination memory address.
- `data_in`: The data coming from the source memory.
- `num_transfers`: The number of data transfers to perform.

The outputs should include:
- `data_out`: The data being transferred to the destination.
- `done`: A signal that indicates when the transfer is complete.
