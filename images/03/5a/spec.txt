Design a 4-to-1 multiplexer with data forwarding capability. The multiplexer should have four data inputs (D0, D1, D2, D3), two select lines (S0, S1), and an output (Y). If any of the inputs D0 to D3 are equal to a "forward" signal (which is a separate input signal F), the multiplexer should forward that input instead of selecting based on the select lines.
