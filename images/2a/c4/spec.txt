
Create a simple SPI controller that sends a byte of data on the MOSI line when a chip select (CS) signal is activated. The controller should have a clock input (SCK) and shift out the data bit by bit on the rising edge of the clock. The data register should hold the byte of data to be sent, and the MOSI line should reflect the current bit being sent. When the CS signal is deactivated, the MOSI line should be set to high-impedance (tri-state).
