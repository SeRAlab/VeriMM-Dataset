Implement a 4-bit up-down counter that increments or decrements its output based on the state of the up_down input signal. The counter is clock-driven and resets to zero when the reset signal is activated. When up_down is high, the counter will count up; when it is low, the counter will count down.
module top_module(
    input clk,
    input up_down,
    input reset,
    output reg [3:0] out
);
