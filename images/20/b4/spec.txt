Design a simple Ethernet MAC controller state machine that processes incoming frames. The MAC controller should have the following states: IDLE, RECEIVE, PROCESS, and TRANSMIT. The state transitions occur based on the input signals: `start_receive`, `frame_valid`, and `transmit`. The MAC controller outputs the current state and a signal `data_out` when in the PROCESS state. The design must ensure that it handles state transitions correctly based on the specified inputs.
