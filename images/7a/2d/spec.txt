Design a Verilog module for a 14-bit binary down counter with synchronous reset and enable signals. The module should have an input clock signal (clk), an input enable signal (en), an input synchronous reset signal (rst), and a 14-bit output signal (count). On the rising edge of the clock, if reset is high, count should be set to 14'b11111111111111. If enable is high, count should decrement by 1.
