Design a 4-bit accumulator that stores a value when the S (set) signal is high. On each positive edge of the CLK (clock), if S is asserted, the 4-bit wide input W_DATA is loaded into an internal register. The current value of the register is continuously available on the output R_DATA. If S is low, the accumulator retains its previous value.
