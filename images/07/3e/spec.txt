Design a 1-bit SRAM cell that can store a single bit of data. The SRAM cell should have the following inputs: Write Enable (WE), Data Input (D), and a Read Enable (RE). The output should be the stored data (Q). When WE is high, the input D should be written to the SRAM cell. When RE is high, the output Q should provide the stored value. If both WE and RE are low, the cell retains its value.
