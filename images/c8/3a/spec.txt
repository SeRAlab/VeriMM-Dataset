

You are tasked with designing a verilog module for a 2-to-1 multiplexer. The module should have two input signals, `A` and `B`, and one select signal, `SEL`. The output signal, `Y`, should be equal to `A` when `SEL` is 0, and `B` when `SEL` is 1. Use the following code snippet as a starting point:

```
module mux_2to1 (
    input A,
    input B,
    input SEL,
    output Y
);

    // Your code here

endmodule
```

Ensure that your module uses the following verilog constructs:

- `always` block
- `if-else` statement
- `assign` statement

Additionally, your module should include the following:

- Appropriate voltage supply signals
- Comments to explain the purpose of each signal and block of code
