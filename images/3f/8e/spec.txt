Design a simple NVMe command decoder that takes a 4-bit command input and produces a 2-bit output indicating the type of command. The command types are defined as follows:  
- 0000: NOP (No Operation)  
- 0001: READ  
- 0010: WRITE  
- 0011: FLUSH  
- 0100: RESET  
Any command not defined should output 11 to indicate an invalid command.
