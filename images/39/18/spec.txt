Design a 24-bit ADC (Analog to Digital Converter) which takes a 24-bit input signal and provides a 24-bit output signal. The output should be the input value shifted right by 4 bits (divided by 16). The ADC should also include an enable signal, where if the enable signal is low, the output should be set to 0. The design must handle the input correctly and ensure that the output is valid only when the enable signal is high.
