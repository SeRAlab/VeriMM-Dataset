
Design a simple EEPROM cell in Verilog that can store a single bit of data. The cell should have the following inputs: `data_in` (1-bit input to write data), `write_enable` (1-bit control signal to enable writing), and `read_enable` (1-bit control signal to enable reading). The output should be `data_out`, which reflects the stored data when reading is enabled. The EEPROM cell should hold the data even after the write operation is completed until a new write is performed.
