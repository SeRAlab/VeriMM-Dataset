Design a one-bit wide, 3-to-1 multiplexer. The module selects one of three input signals (inA, inB, inC) to be output based on a 2-bit select signal (sel). When sel is 00, the output is inA; when sel is 01, the output is inB; and when sel is 10, the output is inC. The output is registered and updated whenever there is a change in the inputs or the select signal.
module top_module(out, inA, inB, inC, sel);
