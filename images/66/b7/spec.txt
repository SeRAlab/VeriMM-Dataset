Design a barrel shifter that performs variable bit shifts on an input bus of size 8. The module takes a shift amount, which can be specified up to 7 bits, and a shift direction signal to indicate whether the shift should be to the left or right. Depending on the shift direction, the output bus reflects the input bus shifted by the specified amount, filling the vacated bits with zeros.
module top_module(
  input [bus_size-1:0] input_bus,
  input [shift_amount_size-1:0] shift_amount,
  input shift_direction,
  output [bus_size-1:0] output_bus
);
