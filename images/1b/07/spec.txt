
Design a Verilog module that computes a simple checksum for a 4-bit input data and a 2-bit checksum. The module should take a 4-bit input `data_in` and output a 2-bit checksum `checksum_out`. The checksum is calculated by summing the bits of `data_in` and taking the last two bits of the sum. The system should have a clock input and a reset input to initialize the checksum.
