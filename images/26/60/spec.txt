
Design a 128-bit AES encryption module that takes a 128-bit plaintext input and a 128-bit key input, and produces a 128-bit output ciphertext. The AES module should implement the basic structure of AES, including the key expansion, the initial round, the main rounds, and the final round. The module should have a clock and reset signal to control the operation and a done signal to indicate when the encryption process is complete.
