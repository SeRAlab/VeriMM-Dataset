Design a 3-bit synchronous counter with load functionality. The counter increments on each positive edge of the clock, but can be reset to zero asynchronously when the reset signal is low. When the load signal is high, the counter is loaded with a specified 3-bit value from `data_in`. The output `count_out` represents the current value of the counter.
module top_module(
    input clk,
    input rst,
    input load,
    input [2:0] data_in,
    output reg [2:0] count_out
);
