Implement the Verilog module based on the following description.
Given a T flip-flop with an asynchronous reset:

1. The output toggles on the rising edge of the clock if the toggle enable signal is high.
2. The output holds its value if the toggle enable signal is low.
3. The output resets to 0 when the reset signal is high, independent of the clock.

Write Verilog implementing this T flip-flop with asynchronous reset.
module t_flip_flop_async_reset (
    input clk,
    input reset,
    input t_enable,
    output reg q);
