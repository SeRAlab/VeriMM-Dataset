Design a simple signal routing module that passes input control signals and communication lines through to the outputs. Specifically, it forwards the DTR and RTS control signals to outputs D1 and D2, respectively, and directly connects the receive (rx) and transmit (tx2) signals to the outputs rx2 and tx. This module effectively acts as a pass-through interface for these signals without any modification.
module top_module(input wire dtr,
                 input wire rts,
                 input wire rx,
                 input wire tx2,
                 output wire tx,
                 output wire rx2,
                 output wire D1,
                 output wire D2);
