
Design an SPI master controller that can send and receive data from an SPI slave device. The controller should have the following inputs:
- clk: clock signal
- reset: active high reset signal
- mosi: Master Out Slave In signal
- miso: Master In Slave Out signal
- ss: Slave Select signal
- start: signal to start the transmission
- data_in: 8-bit data to be sent to the slave

The controller should output:
- data_out: 8-bit data received from the slave
- busy: indicates whether the SPI transaction is in progress
