Design a gated D flip-flop that controls data sampling based on an enable signal. The module uses a combination of the clock and enable inputs to generate a gated clock signal that, when asserted, allows the output Q to capture the value of input D. The complementary output Q_N is also updated based on the gated clock signal, providing the inverted state of D. If the enable signal is low, the outputs remain in their last state until the gated clock goes high, effectively enabling the D flip-flop operation only when the enable signal is active.
