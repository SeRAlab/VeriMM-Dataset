Develop a 4-bit barrel shifter that can perform logical shifting operations. The module takes two 4-bit inputs, A and B, where A is the data to be shifted and B specifies the number of positions to shift. It has two control inputs: shift_left and shift_right. When shift_left is active, A is shifted to the left by the number of bits indicated in B; when shift_right is active, A is shifted to the right. If neither shift control is active, the output is simply the value of A. The output is provided as a 4-bit result.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input shift_left,
    input shift_right,
    output reg [3:0] result
);
