
Design a 1-bit DRAM cell that can store a single bit of data. The DRAM cell should have the following inputs and outputs:
- Inputs: 
  - `data_in`: 1-bit input data to be stored.
  - `we`: Write enable signal (1 bit), when high, allows writing to the cell.
  - `clk`: Clock signal (1 bit).
- Outputs:
  - `data_out`: 1-bit output data that reflects the stored value.
The DRAM cell should be able to store the input data when the write enable signal is high and must maintain the stored value otherwise.
