Design a 5-bit cyclic redundancy check (CRC) generator using a linear feedback shift register (LFSR) approach. The module takes an 11-bit input data and a control signal to enable CRC computation, producing a 5-bit CRC output. The LFSR is initialized to all ones on a reset signal, and it updates its state based on the current data input and its previous state on the rising edge of the clock, provided that CRC calculation is enabled. The output CRC is asserted as the bitwise NOT of the LFSR's current state, ensuring the generation of a checksum suitable for error detection in data transmissions.
