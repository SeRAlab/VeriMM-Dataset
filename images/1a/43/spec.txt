
Design a Verilog module that performs linear regression using the least squares method. The module should take in a set of data points (x, y) and output the slope (m) and intercept (b) of the best fit line, given a fixed number of data points (e.g., 5). The equations involved are:
m = (N*Σ(xy) - Σx*Σy) / (N*Σ(x^2) - (Σx)^2)
b = (Σy - m*Σx) / N
Where N is the number of data points.
