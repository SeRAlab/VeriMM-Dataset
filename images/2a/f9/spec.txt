Design a Verilog module that implements a simplified HMAC function. The module should take a 128-bit key and a 128-bit message as inputs and produce a 128-bit output hash. The hashing function can be simulated with a simple XOR operation for this problem. The HMAC computation follows the formula: HMAC(key, message) = Hash((key XOR opad) || Hash((key XOR ipad) || message)). Use fixed values for ipad and opad for simplification.
