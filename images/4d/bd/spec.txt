Design a circuit that functions as a 2-bit input controlled output generator. When the 'enable' signal is LOW, the output is set to a constant LOW (0). When 'enable' is HIGH, the output is determined by the value of the 2-bit input: it outputs a HIGH (1) for inputs '01' and '11', and LOW (0) for inputs '00' and '10'.
module top_module(input [1:0] in, input enable, output reg out);
