

You are tasked with designing a module that takes in two 32-bit inputs, `in1` and `in2`, and outputs the sum of the two inputs, `out`. However, the sum should only be calculated if a control signal, `enable`, is high. If `enable` is low, the output should remain unchanged. 

Design a Verilog module that implements this functionality. The module should have the following inputs and outputs:

- `in1`: a 32-bit input
- `in2`: a 32-bit input
- `enable`: a 1-bit control signal
- `out`: a 32-bit output

If `enable` is high, `out` should be the sum of `in1` and `in2`. If `enable` is low, `out` should be the previous value of `out`.
