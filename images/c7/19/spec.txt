

Write a Verilog module that takes in two 8-bit inputs A and B and outputs a 8-bit result R. The module should perform the following operation on the inputs: R = A + B + 1. 

The module should also include an asynchronous reset input, rst, which when asserted should reset the output R to 0. The module should be synchronous to a positive edge of the clock input, clk. 

Ensure that the module has no latch or inferred memory elements.
