Design a 2-to-1 multiplexer that selects between two inputs: a 32-bit data signal (rs1) and a 20-bit immediate value (upperimm). When the control signal (op1sel) is LOW, the module outputs the value from rs1; when op1sel is HIGH, it outputs the upperimm, effectively extending the 20-bit value to a 32-bit width for compatibility.
module top_module(input wire op1sel, input wire [31:0] rs1, input wire [19:0] upperimm, output reg [31:0] out);
