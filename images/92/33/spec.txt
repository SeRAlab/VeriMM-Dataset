Design a 16-bit shift register that supports parallel loading and serial shifting. When the reset signal (rst) is activated, the output is initialized to zero. If the load enable signal (Lden) is active, the register loads the 16-bit input data (pi). When the shift enable signal (shiftEnable) is active, the register shifts its contents to the left by one bit and inputs a new bit (sir) from the serial input side. The most significant bit of the register is continuously outputted on sol.
module top_module(input [15:0] pi, input sir, clk, rst, shiftEnable, Lden, output reg [15:0] sout, output sol);
