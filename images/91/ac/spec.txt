Design a three-input multiplexer that selects one of the three input signals (x, y, z) based on a 2-bit selection input (sel). When sel is 00, the output will be the value of input x; when sel is 01, the output will be y; when sel is 10, the output will be z. If sel has any other value, the output will be set to an unknown state (1'bx).
module top_module(
  input x,
  input y,
  input z,
  input [1:0] sel,
  output reg out
);
