Design a Verilog module for a 16-QAM modulator. The modulator should take 4 bits of input data and produce two outputs representing the I (In-Phase) and Q (Quadrature) components. The mapping of the 4-bit input to the I and Q signals should be as follows:  
- 0000 -> (1, 1)  
- 0001 -> (1, 3)  
- 0010 -> (3, 1)  
- 0011 -> (3, 3)  
- 0100 -> (1, -1)  
- 0101 -> (1, -3)  
- 0110 -> (3, -1)  
- 0111 -> (3, -3)  
- 1000 -> (-1, 1)  
- 1001 -> (-1, 3)  
- 1010 -> (-3, 1)  
- 1011 -> (-3, 3)  
- 1100 -> (-1, -1)  
- 1101 -> (-1, -3)  
- 1110 -> (-3, -1)  
- 1111 -> (-3, -3)  
The module should also have a clock input to synchronize the output. The I and Q outputs should be signed 4-bit values.
