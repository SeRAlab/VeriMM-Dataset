

You have been tasked with designing a module that implements a 4-bit binary counter. The counter should have a synchronous reset input that sets the counter to all zeros when asserted. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock signal with a frequency of 10 MHz
- `reset`: a synchronous reset input that sets the counter to all zeros when asserted

Outputs:
- `count`: a 4-bit output representing the current count value

Design the module and write the Verilog code for it.
