Design a simple SD card command decoder that takes a 4-bit command input and produces a 2-bit response output based on specific command types. The commands are as follows:  
- Command 0 (0000): Response 00  
- Command 1 (0001): Response 01  
- Command 2 (0010): Response 10  
- Command 3 (0011): Response 11  
For any other command input, the response should be 00. The decoder should maintain its state until a new command is received.
