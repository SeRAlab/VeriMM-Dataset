Implement a 3-to-1 multiplexer with a 2-bit select input. The multiplexer should output one of the three 6-bit input data signals based on the value of the select input.

Module name:
    mux_3to1

Input ports:
	sel: 2-bit select input.
	in0: 6-bit input data 0.
	in1: 6-bit input data 1.
	in2: 6-bit input data 2.

Output ports:
	out: 6-bit output data based on the select input.
