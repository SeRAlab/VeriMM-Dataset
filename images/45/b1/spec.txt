Design a clock gating circuit that controls the propagation of the clock signal based on enable signals. The module takes a main clock input (CLK) and two control inputs (EN for enable and TE for test enable). It utilizes a latch to conditionally generate a gated clock signal (ENCLK) depending on the status of the enable inputs. The output ENCLK allows the clock signal to either be passed through or blocked, effectively managing the power consumption in scenarios where the clock is not needed.
module top_module(
  input CLK,
  input EN,
  input TE,
  output ENCLK
);
