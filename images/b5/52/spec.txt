Design a Verilog module that implements a 4-bit shift register with parallel load. The module should have a 4-bit data input, a shift/load control signal, a clock signal, and a 4-bit data output. The output should be the input value if load is asserted on the rising edge of the clock, otherwise it should shift right.

module shiftreg (
    input [3:0] data_in,
    input shift_load,
    input clk,
    output reg [3:0] data_out
);
