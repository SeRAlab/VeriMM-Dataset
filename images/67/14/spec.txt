Design a 4-bit binary counter that operates in either up-counting or down-counting mode, controlled by the input signals. The counter increments when the mode is set to up (mode = 0) and decrements when the mode is set to down (mode = 1). It wraps around upon reaching its maximum (1111) or minimum (0000) values. The counter is enabled by the input signal 'en' and resets to zero when the 'rst' signal is asserted high.
module top_module(
    input clk,
    input rst,
    input en,
    input mode,
    output reg [3:0] count
);
