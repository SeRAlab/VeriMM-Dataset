Design a synchronous memory module that acts as a data memory for a digital system. It has a 16-bit address space allowing access to 32-bit wide data words. When the clock signal rises and the MemWrite control signal is active, it stores WriteData into the specified Address in memory. The MemData output continuously reflects the current contents of the memory location pointed to by Address. This module facilitates memory operations in systems requiring data storage and retrieval.

            MemData,     
            Address,     
            MemWrite,
