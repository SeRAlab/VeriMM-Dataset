Design a 4-bit binary adder that computes the sum of two 4-bit inputs, A and B. The module produces a 4-bit output, S, which represents the least significant bits of the sum, and a carry-out output, C_out, indicating if there is an overflow beyond the 4-bit result. The carry logic is explicitly defined to facilitate the addition process without using a built-in addition operator.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output [3:0] S,
    output C_out
    );
