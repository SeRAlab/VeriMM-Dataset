Design a virtual memory management unit (MMU) that translates logical addresses to physical addresses using a simple page table. The MMU should handle a fixed number of pages and provide the ability to read from and write to a memory location given a logical address. The page table should be initialized with a set of mappings, and it should support read and write operations based on the logical address and the access type (read/write). The module should also have a status output indicating if the operation was successful or if there was a page fault.
