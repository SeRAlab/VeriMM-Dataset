Design a simple virtual memory management system that uses a page table to map virtual addresses to physical addresses. The system should support reading from and writing to a virtual address, updating the page table when necessary. The page table will have a size of 4 entries, each entry containing a physical address corresponding to a virtual address. The virtual addresses are 2 bits wide, and the physical addresses are also 2 bits wide. The system should also include a signal to indicate whether a read or write operation is being performed.
