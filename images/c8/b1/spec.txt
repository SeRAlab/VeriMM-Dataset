

You have been tasked with implementing a module in Verilog that will test whether an input signal is a "bad" signal. The module should be named "test_if" and should have one input signal named "bad" of size 2. The module should output a single bit signal named "result" that should be set to 1 if the input signal is "bad" and 0 otherwise. 

A signal is considered "bad" if it meets the following criteria:

1. The first bit of the signal is 1.
2. The second bit of the signal is 0.

You are only allowed to use one module and the module should be no more than 200 lines of Verilog code. You are not allowed to use any external libraries or modules.

Write the Verilog code for the "test_if" module that meets the above specifications.
