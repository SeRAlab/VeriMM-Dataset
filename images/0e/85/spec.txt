
Create a Verilog code for a simple GPIO controller that takes a 4-bit input for data and a 2-bit input for control signals. The control signals will determine whether to read or write the data. If the control signal is '00', it will output the data as is. If the control signal is '01', it will output the inverted data. If the control signal is '10', it will output the data shifted left by one. If the control signal is '11', it will output the data shifted right by one.
