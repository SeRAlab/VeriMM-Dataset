
Design a Verilog module that performs bilinear interpolation for a given set of four pixel values in a 2x2 grid and fractional pixel coordinates. The inputs will be the four pixel values (P00, P01, P10, P11) and fractional coordinates (Xfrac, Yfrac) where Xfrac and Yfrac are represented as fixed-point numbers (with 8 bits for the integer part and 8 bits for the fractional part). The output will be the interpolated pixel value.
