
Create a 16-bit timer that counts up from 0 to a specified maximum value. The timer should have the following inputs: a clock signal (`clk`), a reset signal (`rst`), and a control signal (`enable`). When `enable` is high, the timer should increment its value on each clock cycle. If the timer reaches the maximum value, it should wrap around to 0. The timer should also reset to 0 when the `rst` signal is high.
