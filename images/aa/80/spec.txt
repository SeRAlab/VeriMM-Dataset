Implement an 8-bit binary counter with load capability.

Module name:  
    Counter_8_load               
Input ports:
    clk: Clock signal used for synchronous operation.
    rst_n: Active-low reset signal to initialize the counter.
    load: Control signal to load a specific value into the counter.
    load_val: 8-bit value to be loaded into the counter when load is high.
Output port:
    Q: 8-bit register representing the current count value.

Implementation:
On every rising edge of the clock signal (clk) or the falling edge of the reset signal (rst_n), the counter value is updated.
If the reset signal (rst_n) is low, the counter value (Q) is set to 0.
If the load signal is high, the counter value (Q) is loaded with the value specified by load_val.
Otherwise, the counter increments by 1 on each clock cycle.
