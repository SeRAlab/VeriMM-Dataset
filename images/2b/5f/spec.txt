Design a 4-bit SRAM cell that allows for reading and writing operations. It should have the following inputs: `data_in` (4 bits), `write_enable`, `read_enable`, and `clk`. The output should be `data_out` (4 bits). Ensure that the write operation occurs on the rising edge of the clock when `write_enable` is high, and the read operation provides the stored data when `read_enable` is high.
