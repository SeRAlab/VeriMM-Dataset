
Design an 8-bit shift register with both left and right shift capabilities. The shift register should have a parallel load feature. It should be controlled by a clock signal, an enable signal, a load signal, and a direction signal. When the load signal is high, the register should load the input value. When the load signal is low, if the enable signal is high, the register should shift left if the direction signal is high, and shift right if the direction signal is low. The register should maintain its value when neither loading nor shifting is active.
