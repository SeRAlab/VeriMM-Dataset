Develop a seven-segment display controller that increments a decimal digit displayed on the segments with each button press. The module has a reset functionality that initializes the digit to zero and lights up the corresponding segments to display the number 0. Upon each press of the button, the digit increases until it reaches 9, after which it may wrap around based on design. The output consists of a 7-bit signal that drives the seven segments of the display, encoding the values from 0 to 9 for visualization, as specified by the case statement.
module top_module(
    input wire clk, reset, button,
    output reg [6:0] leds
);
