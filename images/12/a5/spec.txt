Design a Verilog module that implements a simplified version of Otsu’s method for binary image thresholding. The module should take an 8-bit grayscale pixel value as input and output a binary value (0 or 1) based on a predefined threshold. Implement the logic such that if the pixel value is greater than or equal to the threshold, the output is 1, otherwise, it's 0. The predefined threshold will be a parameter of the module.
