

You are tasked with designing a verilog module that takes in two 8-bit inputs, A and B, and outputs the maximum value of the two inputs. If both inputs are equal, the output should be the same as the inputs. You should implement this module using only combinational logic.

Create a module named "max_8bit" that takes in two 8-bit inputs named "A" and "B" and outputs an 8-bit value named "max_val". You should use the following interface:

```verilog
module max_8bit (
    input [7:0] A,
    input [7:0] B,
    output reg [7:0] max_val
);
```

Your module should implement the following logic:

1. If A is greater than B, set max_val to A.
2. If B is greater than A, set max_val to B.
3. If A and B are equal, set max_val to A.

You should ensure that your module meets the following requirements:

1. The module should be synthesizable.
2. The module should only use combinational logic.
