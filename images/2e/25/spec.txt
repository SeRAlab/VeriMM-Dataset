Design a power gating circuit that takes a 2-bit control signal `ctrl` and a 4-bit data input `data`. When `ctrl` is 00, the output `gated_output` should be 4'b0000 (power gated off). When `ctrl` is 01, the output should be equal to `data`. When `ctrl` is 10, the output should be equal to `data` as well. When `ctrl` is 11, the output should again be 4'b0000 (power gated off).
