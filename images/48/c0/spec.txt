Design an arithmetic logic unit (ALU) that performs four different operations on two 32-bit inputs, a and b, based on a 2-bit control signal (alu_ctr). The ALU can perform addition, subtraction, bitwise OR, and set-on-less-than comparisons. The output of the selected operation is given as alu_out. Additionally, the module provides a zero output indicating whether the result of the subtraction operation is zero, and an overflow output (upover) that signals an overflow condition during addition. The specific operations are chosen according to the value of alu_ctr, with each operation being executed in parallel using combinational logic.
