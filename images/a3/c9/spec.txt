Design a circuit that performs a 4-bit adder/subtractor based on the control signal C. When C is high (1), the circuit computes the sum of inputs A and B; when C is low (0), it computes the difference, outputting the result on Q. The operation occurs on the rising edge of the clock signal, with separate registers for storing the sum and difference results.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input C,
    input clk,           // Added the clk input
    output reg [3:0] Q
);
