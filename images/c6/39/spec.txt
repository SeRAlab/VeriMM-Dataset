

You are tasked with designing a verilog module that implements a 4-bit up-counter with a synchronous reset input. The counter should increment on the rising edge of the clock signal, and the reset input should reset the counter to 0 when asserted. The module should have the following inputs and outputs:
- `clk`: a 1-bit clock input
- `reset`: a 1-bit synchronous reset input
- `out`: a 4-bit output representing the current count value

Write the verilog module for the up-counter with synchronous reset.
