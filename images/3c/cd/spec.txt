
Design a 4-bit wide FIFO queue with a depth of 8. The FIFO should support the following operations: 
1. Enqueue operation when the input signal `wr_en` is high. The data to be enqueued will be provided on a 4-bit input `data_in`.
2. Dequeue operation when the input signal `rd_en` is high. The output will be the 4-bit data that is dequeued to `data_out`.
3. There should be overflow protection, which prevents enqueueing when the FIFO is full.
4. There should be underflow protection, which prevents dequeueing when the FIFO is empty.
5. An additional output signal `full` to indicate if the FIFO is full and a signal `empty` to indicate if the FIFO is empty.
