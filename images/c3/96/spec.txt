

You are tasked with designing a module that implements a 4-bit adder with carry-in and carry-out functionality. The module should have the following inputs and outputs:

Inputs:
- `a` (4-bit input)
- `b` (4-bit input)
- `cin` (1-bit input)

Outputs:
- `sum` (4-bit output)
- `cout` (1-bit output)

Your module should implement the following functionality:
- The 4-bit adder should add the values of `a` and `b` and output the result in `sum`.
- The carry-in value `cin` should be added to the sum of `a` and `b`.
- The carry-out value `cout` should be set to 1 if the sum of `a`, `b`, and `cin` is greater than 15, otherwise it should be set to 0.

Write the verilog code for the module and test it using a testbench.
