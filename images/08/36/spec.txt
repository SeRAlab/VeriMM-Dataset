
Design an SR flip-flop in Verilog that updates its state based on the S (set) and R (reset) inputs. The flip-flop should have a clock input and adhere to the following behavior:
1. When S = 1 and R = 0, the output Q should be set to 1.
2. When S = 0 and R = 1, the output Q should be reset to 0.
3. When S = 0 and R = 0, the output Q should hold its previous state.
4. When S = 1 and R = 1, the output Q should be undefined (you can choose to hold the previous state or set Q to 0).
Ensure the flip-flop is edge-triggered on the rising edge of the clock.
