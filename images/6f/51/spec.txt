Implement a Verilog module that models a 4-bit synchronous binary counter with a load enable. The counter should load the value from 'data_in' when 'load' is high. The reset is active-high and synchronous.
module loadable_counter (
    input clk,
    input reset,
    input load,
    input [3:0] data_in,
    output [3:0] count);
