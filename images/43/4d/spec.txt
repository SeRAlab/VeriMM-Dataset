Implement the Verilog module based on the following description.
Create a 4-bit synchronous binary counter. The counter resets to zero when the reset signal is high. When the enable signal is high, the counter increments by 1 on each clock cycle. When enable is low, the counter holds its value.

// Signals are defined as below:
// (1) clk: The clock signal.
// (2) reset: Resets the counter to zero. Active high.
// (3) enable: Enables counting when high.
// (4) q: The 4-bit output of the counter.
module binary_counter(
    input clk,
    input reset,
    input enable,
    output reg [3:0] q);
