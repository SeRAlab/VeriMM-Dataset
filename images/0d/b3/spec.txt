Design a Cryptographically Secure Pseudo-Random Number Generator (CSPRNG) using a Linear Feedback Shift Register (LFSR) in Verilog. The LFSR should take a 4-bit seed input and produce a 4-bit output. The feedback polynomial used for the LFSR is x^4 + x^3 + 1. Your task is to implement the LFSR, which will generate a sequence of pseudo-random numbers based on the initial seed, and reset upon reaching a certain condition (e.g., after a set number of cycles).
