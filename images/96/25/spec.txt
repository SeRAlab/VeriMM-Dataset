Design a four-bit multiplexer that selects one of four predetermined output states based on a two-bit selector (S). When S is 00, the output (X) is set to 0000; when S is 01, X becomes 1111. If S is 10, the output is either 0000 if the input (A) is 1111 or retains the value of A otherwise. For S equal to 11, the output is 1111 if A is 0000, or again retains the value of A if it has any other value. This module allows dynamic selection of outputs based on input conditions and specified control signals.
module top_module(
    input [3:0] A,
    input [1:0] S,
    output reg [3:0] X
);
