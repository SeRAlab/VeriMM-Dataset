

You are tasked with designing a verilog module that performs a 4-bit binary addition. The module should have the following inputs and outputs:

Inputs:
- A: a 4-bit binary number
- B: a 4-bit binary number
- Cin: a single bit representing the carry-in value

Outputs:
- S: a 4-bit binary number representing the sum of A and B
- Cout: a single bit representing the carry-out value

Your module should be named "add4".
