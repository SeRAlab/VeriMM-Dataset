
Design a simple Model Predictive Control (MPC) system that adjusts a control signal based on the previous state and an external disturbance input. The system should have the ability to hold the previous control value when no disturbance is detected. The control value should be a 4-bit output. The inputs include a 4-bit previous control signal and a 1-bit disturbance signal. When the disturbance signal is high, the output control signal should increment the previous control signal by 1 (with wrap-around at 15). If the disturbance signal is low, the output should maintain the previous control signal.
