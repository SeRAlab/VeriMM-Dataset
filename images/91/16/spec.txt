Implement a parameterized N-bit shift register with parallel load capability. The shift register should have a synchronous reset, a clock input, and a parallel load input. The width of the shift register should be parameterized.

Module name:
    shift_register

Input ports:
    clk: Clock signal used to synchronize the shift register.
    rst: Reset signal. Defined as 1 for reset and 0 for reset signal inactive.
    load: Parallel load signal. When high, the data input is loaded into the shift register.
    data_in: Parallel data input to be loaded into the shift register.
    shift_in: Serial data input to be shifted into the register.

Output ports:
    data_out: N-bit output representing the current state of the shift register.

Parameter:
    N = 8
