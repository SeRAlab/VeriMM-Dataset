
Design a simple PCIe address decoder. The decoder has a 32-bit address input and generates 4 output signals indicating which of four regions the address falls into. Each region is defined as follows:
- Region 0: 0x00000000 to 0x3FFFFFFF
- Region 1: 0x40000000 to 0x7FFFFFFF
- Region 2: 0x80000000 to 0xBFFFFFFF
- Region 3: 0xC0000000 to 0xFFFFFFFF
The outputs should be one-hot encoded, meaning only one output should be high at any time based on the input address.
