Design a 32-entry register file that supports reading and writing of 32-bit data. The module has two read addresses (`raddr1` and `raddr2`) for outputting data from the specified registers (`rdata1` and `rdata2`), and a write address (`waddr`) for writing data (`wdata`) into a specified register when the write enable signal (`w_en`) is active. On a positive clock edge, if the reset signal (`rst`) is asserted, the first register is set to zero; otherwise, if write enable is active, the data is stored in the specified register. The register file initializes all entries to zero at the start.
module top_module(input wire clk,input wire rst,input wire [4:0] raddr1, raddr2, waddr,input wire [31:0] wdata,input wire w_en,output wire [31:0] rdata1, rdata2);
