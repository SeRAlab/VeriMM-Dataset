Design a 4-bit barrel shifter that allows for either left or right shifting of a 4-bit input data based on a 4-bit shift amount. When the shift_left signal is high, the module performs a left shift on the data by the specified number of positions; otherwise, it performs a right shift. The output provides the shifted result.
module top_module(
    input [3:0] data,
    input [3:0] shift_amount,
    input shift_left,
    output [3:0] result
);
