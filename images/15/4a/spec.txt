
Design a 2-channel Direct Memory Access (DMA) controller that can transfer data between memory and peripherals. The controller should have two channels, each capable of independently initiating a transfer. The controller should have a memory address input and a data input for each channel, and it should output a signal indicating the transfer completion for each channel. The controller must also include a clock input and a reset input. The controller should perform the following operations:
1. When reset is asserted, all outputs should be cleared.
2. Each channel should initiate a transfer on a rising clock edge if its respective start signal is high.
3. Each channel should assert its transfer complete signal after a fixed number of clock cycles (e.g., 4 clock cycles) after starting the transfer.
