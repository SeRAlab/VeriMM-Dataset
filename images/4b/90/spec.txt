Design a 2-to-1 multiplexer using a lookup table (LUT). The module has one control input (`ctrl`) and two data inputs (`D0` and `D1`). When the control signal `ctrl` is asserted, the output `S` will reflect the value of `D1`; otherwise, it will reflect the value of `D0`. The lookup table is configured to select between the two data inputs based on the control signal, effectively choosing one of the inputs to be output.
module top_module(
    input ctrl,
    input D0,
    input D1,
    output S
);
