Design a synchronous D flip-flop with enable and reset functionalities. The flip-flop captures the input D on the rising edge of the clock (CLK) and updates its output (Q) based on the enable (EN) signal. When EN is active, if D is high, the reset (RESET) is deactivated, setting SE to low, allowing normal operation; if D is low, SE is set to high, applying a reset condition. When EN is not active, the state of Q remains unchanged, effectively gating input control based on the enable signal.
