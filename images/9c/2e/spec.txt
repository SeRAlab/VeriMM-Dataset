Design a clock gating module that controls the clock signal based on an enable signal and test enable signal. The module accepts a clock input (CLK) and uses an enable signal (EN) to determine whether to pass the clock through to the output (ENCLK). The presence of a test enable signal (TE) allows for additional control, ensuring the clock remains gated in specific operational modes. This approach helps in power management by preventing unnecessary clocking of downstream logic when not needed.
module top_module(
    input CLK,
    input EN,
    input TE,
    output ENCLK
);
