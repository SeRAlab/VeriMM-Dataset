
Design a LIFO (Last In First Out) stack in Verilog with the following specifications:
- The stack should have a capacity of 4 elements.
- It should have the following inputs: 
  - `push`: a signal to push a data value onto the stack.
  - `pop`: a signal to pop a value from the stack.
  - `data_in`: a 4-bit input data value to be pushed onto the stack.
  - `clk`: a clock signal.
  - `reset`: an active-high reset signal.
- The stack should output the popped value and have a signal `empty` to indicate if the stack is empty.
