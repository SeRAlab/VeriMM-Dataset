Design a basic four-function calculator that performs addition, subtraction, multiplication, and division on two signed 8-bit inputs, `a` and `b`. The operation is controlled by a 2-bit selection signal, `op`. For addition and subtraction, the module implements overflow detection, signaling an error when an overflow occurs. Furthermore, during division, if the divisor `b` is zero, it sets an error flag and the result to zero, ensuring safe operations. The result is provided as an 8-bit output, while a separate output indicates any computation errors.
module top_module(input signed [7:0] a, b, input [1:0] op, output reg [7:0] result, output reg error);
