
Design a simplified Ethernet MAC controller that processes incoming frames. The MAC controller should have the following features:
1. It receives a frame and checks for its validity based on a simple checksum.
2. If the frame is valid, it increments a counter for the number of valid frames received.
3. If the frame is invalid, it increments a counter for the number of invalid frames received.
4. The controller should be able to reset the counters based on an external reset signal.
