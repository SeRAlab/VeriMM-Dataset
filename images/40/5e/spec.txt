
Design a temperature sensor interface that takes a 10-bit binary input representing temperature in Celsius and converts it to a 7-segment display format. The output should represent the temperature in decimal format, where each digit is represented by a 4-bit binary value. The output should be in the format of 4 bits for the tens place and 4 bits for the units place. Additionally, if the temperature exceeds 99°C, output an indication that the value is out of range (for example, set both outputs to 4'b1111).
