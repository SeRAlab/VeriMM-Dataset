Design a dual-port RAM module with a single write port and two read ports. The module allows external devices to write data to one of its 128 entries specified by address `p3_a` when `p3_en` is asserted. Simultaneously, it supports reading data from two independent addresses, `p1_a` and `p2_a`, providing the outputs `p1_d` and `p2_d` respectively. This design is suitable for applications requiring simultaneous read access to shared memory while supporting updates to the memory content.
