Create a 16-bit Linear Feedback Shift Register (LFSR) that generates pseudorandom numbers. The LFSR should use a polynomial of the form x^16 + x^14 + x^13 + x^11 + 1. The output of the LFSR should be available at the output port after the clock signal is applied. It should also have a reset input that initializes the LFSR to a non-zero state.
