
You are tasked with designing a Verilog module that implements a simple 8-bit counter. The counter should have a synchronous reset input and an enable input. Whenever the enable input is high, the counter should increment by 1 on the rising edge of the clock. Whenever the reset input is high, the counter should reset to 0 on the next rising edge of the clock. The counter output should be available on a 8-bit output port. 

Create a Verilog module that implements this counter with the following port definitions:
- `input aclk`: the clock input
- `input reset`: the synchronous reset input
- `input enable`: the enable input
- `output reg [7:0] counter_out`: the 8-bit counter output

Assume a positive-edge triggered clock.
