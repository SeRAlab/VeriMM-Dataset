Design an 8-bit SRAM cell with a write and read operation. The cell should have a data input (D), a data output (Q), a write enable (WE), and a clock signal (CLK). When WE is high, the data on D should be written into the SRAM cell on the rising edge of CLK. When WE is low, the data in the SRAM cell should be output to Q on the rising edge of CLK.
