Design a circuit that performs basic bitwise operations on two n-bit inputs, A and B. The module computes the bitwise AND, OR, XOR, and NOT of the input vectors. The outputs include four n-bit values: and_res for A AND B, or_res for A OR B, xor_res for A XOR B, and not_res for the bitwise NOT of A. The parameter n is configurable, allowing flexibility in the width of the inputs and outputs, defaulting to 4 bits.
module top_module(
  input [n-1:0] A,
  input [n-1:0] B,
  output [n-1:0] and_res,
  output [n-1:0] or_res,
  output [n-1:0] xor_res,
  output [n-1:0] not_res
);
