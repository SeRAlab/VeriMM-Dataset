Design an EEPROM cell type using Verilog. The EEPROM should have a write, read, and erase functionality. The write input will be a 5-bit data, a write enable signal, and a clock signal. The read functionality will output the stored data when the read enable signal is activated. The erase functionality will set the stored data to a predefined value (e.g., 5'b00000) when an erase signal is activated.
