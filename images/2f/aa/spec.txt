Design a UART transmitter module in Verilog that takes an 8-bit data input, a transmit enable signal, and produces a serial output. The UART should support a baud rate of 9600 baud, assuming a 50 MHz clock. The module should begin transmission when the transmit enable signal is asserted high. The output should include a start bit, the 8 data bits, and a stop bit. Additionally, the system should have a way to indicate when the transmission is complete.
