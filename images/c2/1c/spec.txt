

You are tasked with designing a module in Verilog that implements a 4-bit adder-subtractor. The module should have four inputs: two 4-bit numbers (A and B), a control signal (sub), and a clock signal (clk). The module should have two outputs: a 4-bit result (out) and a carry-out bit (cout).

If the sub control signal is 0, the module should add the two input numbers (A and B) and output the result (out) and the carry-out bit (cout). If the sub control signal is 1, the module should subtract B from A and output the result (out) and the carry-out bit (cout).

The module should operate on the rising edge of the clock signal (clk). The module should also include a reset input (rst) that sets the output to 0 and the carry-out bit to 0 when asserted.

You are not allowed to use any built-in Verilog operators or functions to implement the adder-subtractor. You must use only basic gates (AND, OR, NOT, XOR, etc.) and/or other modules that you design.

Implement the adder-subtractor module in Verilog and verify its correctness using a testbench.
