Design an NVMe controller state machine that manages the different states of a command processing operation. The states include IDLE, READ, WRITE, and DONE. The state machine should transition based on the command input and should output the current state on a 2-bit output. The state transitions are defined as follows:  
- From IDLE, it can go to READ or WRITE based on input signals.
- From READ, it goes to DONE.
- From WRITE, it goes to DONE.
- From DONE, it goes back to IDLE on a reset signal.
