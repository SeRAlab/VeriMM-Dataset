Design a digital stack memory module with a depth of N (default 8), capable of loading, pushing, and popping 16-bit data elements. The stack's top element (qtop) is directly accessible, while qnext provides the subsequent element. Upon a reset signal, the stack resets all entries to zero. The load signal allows the loading of data into the top of the stack, while the push operation shifts existing elements downwards, effectively adding a new element at the top. The pop operation, on the other hand, removes the top element and shifts the elements accordingly, ensuring the stack maintains its Last In, First Out (LIFO) behavior.
module top_module(clk, reset, load, push, pop, d, qtop, qnext);
