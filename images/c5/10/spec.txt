

You are tasked with designing a digital circuit that counts the number of rising edges on a clock signal. The circuit should have a single input port for the clock signal and a single output port for the count value. The count value should be reset to zero whenever a reset signal is received.

Design a module in Verilog that implements this circuit. The module should have the following specifications:

1. The module should be named "rising_edge_counter".
2. The module should have two input ports: "clk" and "reset".
3. The module should have one output port: "count".
4. The "clk" input port should be a 1-bit wire.
5. The "reset" input port should be a 1-bit wire.
6. The "count" output port should be a 32-bit wire.
7. The count value should be incremented by 1 on every rising edge of the "clk" signal.
8. The count value should be reset to zero whenever the "reset" signal is high.

Your solution should be contained within a single Verilog module with no more than 200 lines of code.
