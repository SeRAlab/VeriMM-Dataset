Design a 4-bit calculator that performs various arithmetic and logical operations based on a 3-bit selector input (SEL). The operations include addition, subtraction, bitwise AND, OR, XOR, and bitwise NOT for inputs A and B. The result of the selected operation is output as a 4-bit value (OUT). If an invalid selector is provided, the output defaults to zero.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input [2:0] SEL,
    output reg [3:0] OUT
);
