Design a combinational logic circuit that produces a single output, `y`, based on the inputs `a`, `b`, `c`, and `d`. The output is set to HIGH (1) if any of the following conditions are met: both `a` and `b` are HIGH, or if `a` is HIGH while both `c` and `d` are also HIGH, or if all three inputs `b`, `c`, and `d` are HIGH. Additionally, the output is set to LOW (0) only when all inputs `a`, `b`, `c`, and `d` are LOW.
module top_module(
    input a,
    input b,
    input c,
    input d,
    output reg y
);
