Design a 32-entry, 32-bit wide data memory module. This memory allows data to be written into and read from it based on control signals. The input address (A) is used to select which memory location to access, with only the upper bits (A[6:2]) being significant for addressing. When the write enable (WE) signal is high on the rising edge of the clock (clk), the data input (WD) is stored in the specified memory location. The output (RD) continuously reflects the data stored at the selected address.
module top_module(input [31:0] A,input [31:0] WD,input WE,output [31:0] RD,input clk);
