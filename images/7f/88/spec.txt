    reg_file

    we: Write enable signal to allow writing.
    waddr: 3-bit address of the register to write to.

    raddr1: 3-bit address of the first register to read from.
    raddr2: 3-bit address of the second register to read from.
Output ports:
    rdata1: 32-bit data read from the first register.
    rdata2: 32-bit data read from the second register.

Give me the complete code.

module reg_file(
   input                clk,
   input                rst_n,
   input                we,
   input      [2:0]     waddr,
   input      [31:0]    wdata,
   input      [2:0]     raddr1,
   input      [2:0]     raddr2,

   output     [31:0]    rdata1,
   output     [31:0]    rdata2
);
