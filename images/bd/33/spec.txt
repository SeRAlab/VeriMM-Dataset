Design a full adder circuit that computes the sum of three single-bit inputs: A, B, and carry-in (CI). The module outputs the sum (SUM) and the carry-out (COUT_N). The SUM is determined using XOR logic to account for the inputs, while the carry-out is generated using NOR and OR gates to handle the conditions for generating a carry based on the input bits. Note that COUT_N outputs the negative logic of the carry-out signal.
module top_module(
    input A,
    input B,
    input CI,
    output reg SUM,
    output reg COUT_N
);
