Design a module for an 8-bit binary adder with a carry-in feature. The circuit takes two 8-bit inputs, A and B, along with a carry-in input, cin, and produces a 9-bit output sum and a carry-out signal, cout. The sum output represents the result of adding A, B, and cin, while cout indicates if there was an overflow. The module also includes a synchronous reset functionality that sets both the sum and carry-out to zero when activated.
module top_module(
  input [7:0] A,
  input [7:0] B,
  input cin,
  input reset,
  output reg [8:0] sum,
  output reg cout
);
