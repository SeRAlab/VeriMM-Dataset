

You are tasked with designing a verilog module that takes in 4 inputs and produces 1 output. The input signals are named `in1`, `in2`, `in3`, and `in4`, and they are all 1-bit wide. The output signal is named `out` and it is also 1-bit wide. 

The `out` signal should be 1 if and only if the input signals are all 0. Otherwise, the output should be 0.

You should implement this functionality using a `case` statement with non-constant case expressions. The case expressions should be based on the values of the input signals and should not use any constants.

You should name your module `all_zeroes`.
