Design a combinational logic circuit that generates a single output based on multiple input conditions. The output will be HIGH (1) if either of the following conditions is met: the 4-bit input1 is greater than or equal to 6 (0110 in binary) and input2 equals 2 (10 in binary), or if input3 is HIGH while input4 is LOW, or if all of inputs 5 through 8 are HIGH. Otherwise, the output will be LOW (0).
module top_module(
    input [3:0] input1,
    input [1:0] input2,
    input input3,
    input input4,
    input input5,
    input input6,
    input input7,
    input input8,
    output reg output1
);
