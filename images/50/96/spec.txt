    d_ff

Input ports：
    clk: Clock signal.
    rst_n: Reset signal (active low).
    en: Enable signal.
    d: Data input signal.

Output ports：
    q: Output signal.

Implementation:

Declare a register q to store the current output value.
Inside an always block, sensitive to the positive edge of the clk signal and the negative edge of the rst_n signal, implement the logic for storing the input value and resetting.
In the reset condition (~rst_n), set the q register to 0, indicating the flip-flop is reset.
On every rising edge of the clk, if the enable signal en is high, store the value of d in q.

Give me the complete code.

    input clk,
