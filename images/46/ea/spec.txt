Design a combinational logic circuit that processes five inputs: two from group A (A1, A2), one from group B (B1), one from group C (C1), and one from group D (D1), to produce a single output Y. The output Y is determined by evaluating two conditions: if both A1 and A2 are high or both B1 and C1 are high, then Y is set to 1. If this condition is not met, Y will be 0 if D1 is high; otherwise, Y will remain 1.
module top_module(
    input  A1,
    input  A2,
    input  B1,
    input  C1,
    input  D1,
    output Y
);
