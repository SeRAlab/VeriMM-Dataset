Implement a 6-to-1 multiplexer with a 3-bit select input. The multiplexer should output one of the six 12-bit input data signals based on the value of the select input.

Module name:
    mux_6to1

Input ports:
	sel: 3-bit select input.
	in0: 12-bit input data 0.
	in1: 12-bit input data 1.
	in2: 12-bit input data 2.
	in3: 12-bit input data 3.
	in4: 12-bit input data 4.
	in5: 12-bit input data 5.

Output ports:
	out: 12-bit output data based on the select input.
