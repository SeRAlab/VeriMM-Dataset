
Design a 7-stage pipelined processor that supports the following operations:
1. Load (LD)
2. Store (ST)
3. Add (ADD)
4. Subtract (SUB)
5. AND (AND)
6. OR (OR)
7. XOR (XOR)

The processor should have a 5-bit instruction input (representing the opcode) and a 5-bit data input for two operand values. The processor will output the result after processing the instruction in a 7-stage pipeline. The instruction should be processed in the order they are received, and the output should be valid after 7 cycles.
