Design a 4-bit adder circuit with reset and enable functionality. The module takes two 4-bit inputs, A and B, and produces a 5-bit output, S, which represents their sum. When the reset signal (rst) is active, the output S is set to zero. If the enable signal (en) is active, the adder performs the addition of A and B; otherwise, the output remains unchanged.
module top_module(
    // Inputs
    input rst,
    input en,
    input [3:0] A,
    input [3:0] B,
    // Outputs
    output [4:0] S
);
