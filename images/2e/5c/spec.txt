Design a 16-bit SRAM cell with read and write functionalities. The SRAM cell should have the following ports: a 16-bit data input (data_in), a 16-bit data output (data_out), a write enable signal (we), a chip select signal (cs), and a clock signal (clk). When cs is low, the cell should be inactive. When we is high and cs is low, the cell should write data from data_in to the memory. When cs is low and we is low, the cell should output the stored data to data_out on the rising edge of clk.
