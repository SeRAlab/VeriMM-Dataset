Implement the Verilog module based on the following description.
Create a Verilog module for a 4-bit synchronous up/down counter. It has an up signal which when high makes the counter count up, and when low, it counts down. There is an active-low asynchronous reset signal that resets the counter to zero.

module up_down_counter (
	input clk,
	input reset_n,
	input up,
	output [3:0] count);
