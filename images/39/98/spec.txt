
Design a 4-way round-robin arbiter in Verilog. The arbiter should have four request inputs (req0, req1, req2, req3) and one grant output (grant), which indicates which request is granted access. The arbiter should maintain the order of granting based on the last granted request and should wrap around after the last request. The arbiter should have a clock (clk) and a reset (rst) input.
