1. state START (out=0).
2. state PROCESS (out=1).
3. state END (out=0).

State transitions:
1. From state START: If in = 0, then remain in state START. If in = 1, then transition to state PROCESS.
2. From state PROCESS: If in = 0, then transition to state END. If in = 1, then remain in state PROCESS.
3. From state END: If in = 0, then remain in state END. If in = 1, then transition to state PROCESS.

At reset, the state machine starts in state "START". Derive next-state logic equations and output logic equations by inspection assuming the following one-hot encoding is used: (START, PROCESS, END) = (3'b001, 3'b010, 3'b100)

Write code that generates the following equations:

- START_next -- next-state logic for state START
- PROCESS_next
- END_next
- out -- output logic
