Design a byte-swapping circuit that rearranges the order of bytes in a given input data stream based on a specified size. This module accepts an input data vector of width determined by the parameter `g_num_bytes` (defaulted to 4 bytes), and an input `size_i` that specifies how many of those bytes should be swapped. The output provides the reordered bytes, with the ordering reversed for the specified number of bytes; if the size exceeds the parameter, the output is undefined. This functionality is particularly useful in digital communication and processing applications where data byte order must be adjusted for compatibility.
