Design a circuit that controls VGA output colors based on the selected mode. When the mode is low (0), all VGA color outputs (R, G, B) are set to the same value determined by the VColor input. When the mode is high (1), the red, green, and blue outputs are determined by the individual bits of the 3-bit GColor input, allowing for specific color representation.
module top_module(
    input mode,
    input [2:0] GColor,
    input VColor,
    output reg VGA_R,
    output reg VGA_G,
    output reg VGA_B
    );
