Design a Verilog module that performs bilinear interpolation on four input pixel values (Q11, Q12, Q21, Q22) and provides an output pixel value (P) based on the fractional parts (x and y) for interpolation. The formula for bilinear interpolation is:  
P = (1 - x) * (1 - y) * Q11 + (1 - x) * y * Q12 + x * (1 - y) * Q21 + x * y * Q22  
where Q11, Q12, Q21, and Q22 are the input values, and x and y are the fractional parts in the range [0, 1].
