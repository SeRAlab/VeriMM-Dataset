Design a Verilog module that implements a Run-Length Encoding (RLE) encoder. The module should take a stream of binary input data (8 bits) and produce a compressed output that encodes consecutive runs of similar bits. The output should consist of pairs of values: the first value is the run length (number of consecutive identical bits), and the second value is the bit value itself (0 or 1). The encoder should be able to handle input data of variable length, and when it reaches the end of the input, it should output a termination signal.
