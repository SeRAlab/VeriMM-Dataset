Design a four-bit binary adder that computes the sum of two 4-bit inputs, A and B, along with a carry-in bit, C_in. The module produces a 4-bit sum output (S) and a carry-out signal (C_out). The design uses a combination of XOR gates for sum calculations and AND/OR gates to manage the carry propagation, ensuring accurate addition across each bit while also considering any carry from the previous lower bit.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input C_in,
    output [3:0] S,
    output C_out
);
