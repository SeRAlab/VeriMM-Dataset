Implement a Verilog module for a 4-bit parallel load shift register with synchronous reset. If reset is high, the shift register should reset to 4'b0000. Otherwise, it should load a value when load is high.
module parallel_load_shift_register (
    input clk,
    input reset,
    input load,
    input [3:0] load_value,
    output reg [3:0] q
);
