Design a 2-to-1 multiplexer with 8-bit wide inputs. The module takes two 8-bit inputs (in1 and in2) and a single select input (choose). Based on the value of choose, it outputs either in1 when choose is 0 or in2 when choose is 1. If an invalid case occurs (though it is unlikely with a single-bit selector), the output defaults to an 8-bit zero value.
