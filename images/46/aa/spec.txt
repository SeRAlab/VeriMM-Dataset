Design a 2-to-4 decoder that uses a 3-bit select signal (sel) to drive four output lines (w, x, y, z) based on a 4-bit data input. When the select signal matches one of the first four combinations (000 to 011), the corresponding output is set to the respective bit of the data input; otherwise, the output is low. This effectively allows the circuit to select one of the four data bits as an active output based on the select input.
module top_module(
    input [2:0] sel,
    input [3:0] data,
    output w,x,y,z);
