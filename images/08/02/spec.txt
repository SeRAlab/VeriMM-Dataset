Design an 8-bit DRAM cell that can store a single bit of data. The cell should have an input for data (D), a read enable (RE), a write enable (WE), and a clock (CLK) signal. The output should be the stored data (Q). When WE is high, the input data (D) should be written into the cell on the rising edge of CLK. When RE is high, the output Q should present the stored data. If both RE and WE are low, the cell should retain its current state.
