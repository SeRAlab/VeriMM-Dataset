Design a Verilog module that implements an SR latch using NAND gates. The latch should have two inputs (S and R) and two outputs (Q and Qn). The behavior should follow these rules: when S=1 and R=0, Q should be set to 1; when S=0 and R=1, Q should be reset to 0; when S=0 and R=0, Q should hold its previous state; and when S=1 and R=1, the output should be indeterminate.
