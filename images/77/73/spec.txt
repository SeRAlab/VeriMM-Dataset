Design a 5-to-1 multiplexer that selects one of five input signals (d0, d1, d2, d3, d4) based on a 3-bit select input (s). The output (y) will reflect the selected input, with the outputs being prioritized from d0 to d4 according to the value of s. If the select input does not match any defined case (i.e., values outside 0 to 4), the output defaults to a LOW state.
module top_module(input d0, d1, d2, d3, d4,input [2:0] s,output reg y);
