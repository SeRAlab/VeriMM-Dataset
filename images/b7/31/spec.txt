Design a data validation module that synchronously transfers 32-bit input data to output when a valid input signal is asserted. On a positive clock edge, if the reset signal is active (low), the output data is cleared to zero, and the output valid signal is deasserted. When the input valid signal is high, the module captures the input data into the output register and asserts the output valid signal. If the input is not valid, the output valid signal is deasserted, indicating that the current output data should not be considered valid.

  input clk,
  input rst,
  input [31:0] in_data,
  input in_valid,
  output reg [31:0] out_data,
  output reg out_valid
