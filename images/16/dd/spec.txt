
Design a WiFi module state machine that manages the connection status of the WiFi module. The state machine should have the following states: IDLE, CONNECTING, CONNECTED, DISCONNECTING, and DISCONNECTED. The state transitions should be controlled by the following input signals:
- `start`: triggers the transition from IDLE to CONNECTING
- `connect`: confirms the connection and transitions from CONNECTING to CONNECTED
- `disconnect`: triggers the transition from CONNECTED to DISCONNECTING
- `reset`: resets the state machine to IDLE

The output should indicate the current state of the module.
