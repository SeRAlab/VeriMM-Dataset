
You are tasked with designing a verilog module for a 2:1 multiplexer. The module should have two input ports, `A` and `B`, and one output port, `Z`. Additionally, there should be a select port, `S`, which determines which input is passed to the output. When `S` is high, the output should be equal to `A`. When `S` is low, the output should be equal to `B`.
