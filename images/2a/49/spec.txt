
Design a LIFO (Last In First Out) stack in Verilog. The stack should support the following operations:
- `push`: to add an element to the top of the stack.
- `pop`: to remove the top element from the stack.
- `peek`: to view the top element without removing it.
- `is_empty`: to check if the stack is empty.
The stack should have a maximum depth of 8 elements, and the data width should be 8 bits.
