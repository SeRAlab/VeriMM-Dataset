Design a four-bit adder that computes the sum of two four-bit inputs (a and b). The result is stored in a four-bit output (sum). If the computed sum exceeds the maximum value of 15 (which is 4'b1111), the output wraps around to represent only the least significant four bits. The module does not need specific handling for negative sums since four-bit unsigned arithmetic is used; thus, the sum will never be negative.
module top_module(
    input [3:0] a,
    input [3:0] b,
    output reg [3:0] sum
);
