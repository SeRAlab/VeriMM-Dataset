Implement a 3-bit up/down counter. The counter increments or decrements its value based on the up_down input signal with each clock cycle. When up_down is high, the counter increments; when low, it decrements. The counter can be reset to zero using the rst signal. The current count value is outputted on the count signal, which reflects the result of the counting operation based on the selected direction.
module top_module(
    input clk,
    input rst,
    input up_down,
    output reg [2:0] count
);
