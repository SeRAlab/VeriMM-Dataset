
Design a Verilog module for a Flash memory cell. The memory cell should have the capability to store one bit of information and support the following operations: 
1. Write: Store a value (0 or 1) into the memory cell.
2. Read: Output the current stored value from the memory cell.
3. Erase: Reset the memory cell to the default value (0).

The module should have:
- Inputs: `data_in` (1-bit), `write_enable` (1-bit), `erase` (1-bit)
- Output: `data_out` (1-bit)

The `data_out` should present the stored value when read, and should reflect changes whenever `write_enable` is asserted.
