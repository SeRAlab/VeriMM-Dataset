Design a Verilog module that implements a CRC-8 checksum calculator. The module should take an 8-bit data input and a control signal for starting the calculation. Once initiated, the module should compute the CRC-8 using a predefined polynomial (x^8 + x^5 + x^4 + 1) and output the checksum after processing all bits. The module should also have a reset signal to initialize the state.
