
Design a fixed-priority arbiter in Verilog. The arbiter should have four request inputs (request0, request1, request2, request3) and a grant output for each request (grant0, grant1, grant2, grant3). The priorities are fixed as follows: request0 has the highest priority, followed by request1, request2, and request3. If multiple requests are made simultaneously, only the highest priority request should be granted access.
