Implement the Verilog module based on the following description.
Create a Verilog module for a 16-bit shift register with parallel load and terminal count output. It should take a clock signal (clk), a reset signal (rst), a load signal (load), and a 16-bit parallel load input (load_val). The counter should reset to 0 when the reset signal is high. If the load signal is high, the counter should load the value from load_val. The terminal count output (tc) should go high when the most significant bit is 1.
