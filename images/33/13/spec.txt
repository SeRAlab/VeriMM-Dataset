
Design a 4-port round-robin arbiter in Verilog. The arbiter should accept four request inputs (req[3:0]) and grant one of the requests based on the round-robin priority. There should also be a clock input (clk) and a reset input (reset). On each clock cycle, the arbiter will grant the highest priority request that is currently active, with the priority rotating in a round-robin fashion. The output should be a grant signal (gnt[3:0]), where only one bit is high at a time.
