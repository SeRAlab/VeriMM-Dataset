Design a 64-bit temporary register that captures input data D on the rising edge of the clock (CLK) when the enable (en) signal is high. The register also has a reset functionality, which, when activated, sets the output Q to zero, overriding the input D. If reset is not asserted and en is true during the clock's rising edge, the value of D will be stored in Q.
