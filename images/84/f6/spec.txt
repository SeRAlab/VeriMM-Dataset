Design a circuit that implements an 8-way chip select decoder based on a 32-bit input address and an active-low enable signal (cs_). The module generates one active-low output signal (cs0 to cs7) corresponding to specific ranges of the upper bits of the address (bits 31 to 22). When the address is 0, the output cs0 is selected (active low), while subsequent addresses (2, 4, 6, 8, A, C, E) activate the respective outputs cs1 through cs7 in a sequential manner. When the enable signal cs_ is inactive, all outputs are set high. This design is typically used in memory control applications where only one memory chip is selected at any given time based on the address input.
module top_module(addr, cs0, cs1, cs2, cs3, cs4, cs5, cs6, cs7, cs_);
