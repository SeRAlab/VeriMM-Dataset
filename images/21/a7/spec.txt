
Design a 24-bit ADC controller with the following functionality: 
- It takes a 24-bit input data from the ADC.
- It should have a clock signal to sample the input data.
- On every rising edge of the clock, it should store the input data into an internal register.
- The stored data can be read from an output signal.
- Additionally, it should have a reset signal that clears the stored data when activated.
