Module name:  
    up_down_counter

Input ports:
    CLK: Clock input
    RST: Active high reset signal
    EN: Enable signal
    UP_DOWN: Control signal (1 for up, 0 for down)

Output ports:
    COUNT: 3-bit counter output

Implementation:
The up/down counter module uses an always block to increment or decrement the counter value based on the clock signal, reset signal, and control signals.
The always block triggers on the positive edge of the clock signal (posedge CLK). It checks if the reset signal is active (RST) and sets the output (COUNT) to 0. If the reset signal is not active and the enable signal is active (EN), it increments or decrements the counter output (COUNT) based on the control signal (UP_DOWN).
