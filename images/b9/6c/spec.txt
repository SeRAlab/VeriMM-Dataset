Design a multi-bit comparator circuit that compares two n-bit wide inputs, A and B. It outputs three signals: EQ indicates equality of the inputs, LT indicates that A is less than B, and GT indicates that A is greater than B. The comparator uses difference calculation to derive these outputs by determining the sign and magnitude of the result from subtracting B from A. This module supports an 8-bit default width but can be parameterized to handle other bit widths as specified.
module top_module(
  input [n-1:0] A,
  input [n-1:0] B,
  output EQ,
  output LT,
  output GT
);
