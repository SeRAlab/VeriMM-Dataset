Design a virtual memory management unit (MMU) in Verilog that takes a virtual address as input and produces a physical address as output using a simple page table. The page table is defined as a small array in the design where each index represents a page number and the value at that index represents the corresponding physical frame number. The virtual address is divided into a page number and an offset. The design should also check for page faults (i.e., when the page number exceeds the defined range of the page table).
