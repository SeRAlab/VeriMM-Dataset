Design a simple Low Dropout Regulator (LDO) for a given input voltage. The LDO should take an input voltage (Vin) and output a regulated voltage (Vout). The output voltage should be regulated to a specified value (Vref) if the input voltage is higher than Vref, otherwise the output should follow the input voltage. The design should also include an enable signal (en) to control the operation of the LDO. When en is low, the output should be zero regardless of the input voltage.
