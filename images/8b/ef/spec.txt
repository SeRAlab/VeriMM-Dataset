Design a 4-bit ripple carry adder that computes the sum of two 4-bit inputs (A and B) and a carry-in bit (C_in) on the rising edge of a clock signal. The module outputs a 4-bit sum (S) and a carry-out bit (C_out). The carry-out is generated by determining when there is an overflow from the most significant bit during addition.
module top_module(
	input [3:0] A,
	input [3:0] B,
	input C_in,
	input clk,
	output reg [3:0] S,    // Change output to reg
	output reg C_out       // Change output to reg
);
