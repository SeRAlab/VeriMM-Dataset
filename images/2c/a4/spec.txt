
Design a Direct Memory Access (DMA) controller that can read from a source address and write to a destination address in memory. The controller should have the following inputs and outputs:
- clk: Clock signal
- rst: Reset signal
- start: Signal to start the DMA transfer
- src_addr: Source address from where data will be read
- dst_addr: Destination address where data will be written
- data_in: Input data from the source address
- data_out: Output data to the destination address
- done: Signal indicating that the DMA transfer is complete
The controller should move one word of data from src_addr to dst_addr on each clock cycle after start is asserted.
