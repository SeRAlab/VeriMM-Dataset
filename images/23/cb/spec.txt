
Create a 24-bit Digital to Analog Converter (DAC) circuit. The DAC should take a 24-bit input and produce a corresponding analog voltage output represented in a fixed-point format. The output voltage should be calculated based on a reference voltage (V_ref), which is 3.3V. The output voltage can be calculated using the formula: V_out = (Input / 2^24) * V_ref. The circuit should include a mechanism to clamp the output to the valid range of 0V to V_ref.
