Design a 2-to-4 line decoder with an enable signal. When the enable input is high, the decoder activates one of the four outputs (out0 to out3) based on the 2-bit address inputs (address0 and address1). The output corresponding to the binary value represented by the address inputs will be set to high, while the others remain low.
module top_module(
    output out0, out1, out2, out3,
    input address0, address1,
    input enable
);
