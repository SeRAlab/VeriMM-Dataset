Design a 4-bit adder/subtractor circuit. When the Mode input is 0, the circuit performs a 4-bit addition of inputs A and B, along with the carry input Cin. When Mode is set to 1, it effectively computes A minus B by inverting the bits of B prior to addition (using two's complement), resulting in the subtraction operation. The circuit outputs a 4-bit Sum and a carry-out (Cout) from the most significant bit.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    input Mode,
    output [3:0] Sum,
    output Cout
);
