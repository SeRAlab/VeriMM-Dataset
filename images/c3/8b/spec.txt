

You are tasked with designing a module that takes in a 32-bit input and outputs a 16-bit output. The output is the result of performing a bitwise AND operation between the input and a 16-bit mask. The mask is determined by a set of control signals that are input into the module. 

The module should have the following inputs:
- `input [31:0] data_in`: the 32-bit input to be masked
- `input [15:0] mask`: the 16-bit mask to be applied to the input
- `input enable`: a control signal that enables the module to perform the masking operation

The module should have the following output:
- `output [15:0] data_out`: the 16-bit output after applying the mask

If `enable` is low, the module should output all zeros. If `enable` is high, the module should perform the bitwise AND operation between `data_in` and `mask` and output the result as `data_out`.

Write a Verilog module that implements this functionality within 200 lines of code.
