Implement a priority encoder that takes an 8-bit input and outputs a 3-bit binary representation of the highest priority input bit that is set to 1. The module also has a valid signal indicating whether any input bit is set.

Module name:
    priority_encoder_8to3

Input ports:
    data_in: 8-bit input data.

Output ports:
    valid: Output signal indicating whether any input bit is set.
    encoded: 3-bit binary representation of the highest priority input bit that is set to 1.

Implementation:
The valid signal is asserted if any bit in the input data (data_in) is set to 1.
The encoded signal represents the position of the highest priority input bit that is set to 1.
