Design a D flip-flop with asynchronous set and reset controls. The module outputs the current state 'q' and its complement 'qbar'. The flip-flop is triggered on the negative edge of the reset or set signals or the positive edge of the clock. When the reset signal is low, the output is set to 0; when the set signal is low, the output is set to 1; otherwise, the output takes the value of the data input.
