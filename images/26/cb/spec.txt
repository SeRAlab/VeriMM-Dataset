
Create a Verilog module that computes the inverse of a 2x2 matrix. The module should take a 2x2 matrix as input and output its inverse. The matrix inversion formula for a 2x2 matrix is given by:
If A = | a  b |
          | c  d |
Then the inverse A^-1 = (1/det(A)) * |  d  -b |
                                      | -c   a |
where det(A) = ad - bc.
The module should output "undefined" if the determinant is zero (which means the matrix is not invertible).
