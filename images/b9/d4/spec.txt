Design a 4-bit shift register with reset and load capabilities, capable of shifting the data either left or right based on the specified direction. Upon receiving a clock pulse, if the reset signal is asserted, the register clears to zero. If the load signal is active, it captures the input serial value into the register. In normal operation, if the direction signal is high, the data shifts left, moving the most significant bit (MSB) into the least significant bit (LSB) position; if the direction is low, the data shifts right, with the LSB being shifted to the MSB position. The current state of the register is available as an output.
module top_module(input clk, input reset, input load, input direction, input serial_in, output reg [3:0] serial_out);
