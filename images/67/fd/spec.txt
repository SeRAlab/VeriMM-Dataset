Design a synchronous block memory generator that provides read and write capabilities. The module features a specified depth of 256 and width of 64 bits. On the rising edge of the clock, if the write enable signal (we) is asserted, data (wdata) is written to the memory location specified by the address (addr). Regardless of the write operation, the module continuously updates the output (rdata) to reflect the contents of the memory location addressed by addr. This module serves as a basic dual-port memory system suitable for various applications in digital circuits requiring memory storage.
