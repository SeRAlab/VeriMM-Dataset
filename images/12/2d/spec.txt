Design a 1-bit SRAM cell using Verilog. The SRAM cell should have the following inputs: Data (D), Word Line (WL), and Cell Enable (CE). The outputs should be the stored value (Q) and its inverted version (Qn). The cell should store the value of D when WL is high and CE is also high. When WL is low, the output should maintain its stored value. The output should be valid only when CE is high.
