Design a simple 8-bit calculator module capable of performing addition and subtraction operations. The module has two 8-bit inputs, A and B, and a control input OP that selects the operation; when OP is 0, it computes A + B, and when OP is 1, it computes A - B. The module also features a RESET input that, when asserted, initializes the output to zero. The result of the operation is provided as an 8-bit output, OUT.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input OP,
    input RESET,
    output reg [7:0] OUT
);
