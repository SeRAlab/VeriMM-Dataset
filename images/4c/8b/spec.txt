Design a 4-bit adder-subtractor module. When the 'subtract' input is low (0), the module performs the addition of inputs A and B. When 'subtract' is high (1), it computes the subtraction of B from A. The result is provided as a 4-bit output.
module top_module(
	input [3:0] A,
	input [3:0] B,
	input subtract,
	output reg [3:0] result
);
