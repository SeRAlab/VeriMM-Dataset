Design a Verilog module that implements a simple version of the Floyd-Warshall algorithm for finding the shortest paths between all pairs of nodes in a directed graph. The graph can be represented as a 4x4 adjacency matrix where the entry at (i, j) indicates the weight of the edge from node i to node j. If there is no edge, the weight should be represented as infinity (a large number). The output should be the shortest path distance matrix after applying the algorithm.
