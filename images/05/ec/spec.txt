
Design a sliding window protocol for reliable data transfer. The system will have a sender and a receiver. The sender can send a maximum of N packets (the window size). Each packet has an identifier (ID). The sender will send packets with sequential IDs, and the receiver will acknowledge received packets. The code should implement a simple state machine for both sender and receiver. The sender should wait for an acknowledgment before sending the next packet if the window is full. The receiver should acknowledge packets in the order they are received.
