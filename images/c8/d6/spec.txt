
You are tasked with designing a module that calculates the sum of two 4-bit binary numbers. The module should have two 4-bit input ports, A and B, and one 4-bit output port, S. The module should also have a 1-bit input port, CIN, which represents the carry-in bit. The module should output a 1-bit carry-out, COUT. The module should use only combinational logic and should not use any sequential elements such as flip-flops or registers. 

You should write the Verilog code for the module, named adder_4bit, which implements the above requirements.
