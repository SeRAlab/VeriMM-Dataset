Design a 4-bit binary adder that computes the sum of two 4-bit inputs, A and B, along with an optional carry input (C_in). The module outputs a 4-bit sum (S) and a carry-out (C_out) signal, indicating whether there is an overflow beyond the 4-bit result. The carry-out is derived from both the sum and additional logic to ensure accurate overflow detection.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input C_in,
    output [3:0] S,
    output C_out
);
