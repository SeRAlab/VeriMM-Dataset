
Design an interrupt controller that manages up to 4 interrupt requests (IRQ). The controller should have the following functionality:
- It should accept 4 interrupt requests (IRQ0 to IRQ3) as inputs.
- It should have a single output (INT), which goes high when any interrupt request is active.
- The controller should also have a register (INT_ACK) that acknowledges the active interrupt. When INT_ACK is written with the index of the active interrupt, the corresponding interrupt request should be cleared.
- The controller should also include a register (INT_STATUS) to indicate which interrupt is currently active.
