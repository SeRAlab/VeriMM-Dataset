Develop a circuit that compares two 8-bit inputs, in1 and in2, and outputs a HIGH signal if in1 is greater than in2. It achieves this by calculating the difference between the two inputs and checking each bit of the resulting difference to determine if it is positive. If the most significant bit (or any lower significant bits) indicates a positive difference, the output will be asserted HIGH; otherwise, it will be LOW.
module top_module(
  input [7:0] in1,
  input [7:0] in2,
  output out
);
