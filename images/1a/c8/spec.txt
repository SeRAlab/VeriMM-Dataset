Design a 1-bit DRAM cell. The cell should have a data input (D), a data output (Q), a wordline (WL) for enabling the cell, and a bitline (BL) for reading the stored data. When the wordline is high, the data from the input (D) should be stored in the cell. When the wordline is low, the cell should retain its state, and the data can be read out through the bitline. Implement the necessary control logic in Verilog.
