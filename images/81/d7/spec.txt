Design a flip-flop-based register that operates with enable, clear, and preset functionalities. On the rising edge of the clock, if the clear (clrn) signal is low, reset the output (q) to 0. If the preset (prn) signal is low, set the output (q) to 1. If both clear and preset are inactive and the enable (ena) signal is high, update the output (q) with the input data (d). This module effectively serves as a configurable storage element in sequential logic applications.
module top_module(
    input clk,
    input ena,
    input d,
    input clrn,
    input prn,
    output reg q
);
