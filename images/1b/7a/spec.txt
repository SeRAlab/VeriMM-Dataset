Design a 1-bit DRAM cell that can store a single bit of data. The cell should have the following signals: a data input (D), a data output (Q), a word line (WL), and a bit line (BL). The DRAM cell should operate as follows: when the word line (WL) is high, the data from the input (D) should be written to the cell. When the word line is low, the current stored value should be output to Q when the bit line (BL) is high. Ensure that the DRAM cell maintains its state when not being actively written to or read from.
