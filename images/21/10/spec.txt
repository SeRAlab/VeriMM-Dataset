
Design a Verilog module that simulates a flash memory cell's operation. The flash memory cell should have the ability to store a single bit of data (0 or 1), and it should be able to perform the following operations:
1. Write a value (0 or 1) to the memory cell.
2. Read the value stored in the memory cell.
3. Erase the memory cell, which resets its value to 0.

The module should have an input for the data to be written, a control signal for writing, a control signal for reading, a control signal for erasing, and an output for the stored value.
