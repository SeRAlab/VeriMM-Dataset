Design a 4-bit comparator module that compares two 4-bit inputs, `a` and `b`, based on a 2-bit control signal. The output is a single bit that indicates the result of the comparison: `1` for true and `0` for false. The control signal dictates the type of comparison: `00` for greater than, `01` for less than, `10` for equal to, and `11` for not equal. If the control input is invalid, the output defaults to `0`.
module top_module(
  input [3:0] a, // 4-bit input a
  input [3:0] b, // 4-bit input b
  input [1:0] control, // 2-bit control input
  output reg out // Single bit output
);
