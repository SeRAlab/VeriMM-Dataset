Implement a Verilog module for a 4-bit binary counter with carry-out and synchronous reset. The counter should increment its value on each positive clock edge. If reset is high, the counter should reset to 4'b0000. The carry-out should be high when the counter overflows.
module binary_counter_with_carry (
    input clk,
    input reset,
    output reg [3:0] q,
    output reg carry_out
);
