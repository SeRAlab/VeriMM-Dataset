Design an 8-bit wide accumulator that sums incoming data values on the rising edge of the clock. When the reset signal is activated, the accumulator is cleared, setting the sum to zero. If the reset is not active, the current sum is updated by adding the new 8-bit input data. The accumulated output is continuously available at the `out` signal.
module top_module(
  input clk, rst,
  input [7:0] data_in,
  output [7:0] out
);
