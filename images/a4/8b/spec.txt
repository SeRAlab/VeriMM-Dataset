    reg_with_enable

    clk: Clock signal used for synchronous operations.

    data_in: 8-bit input data to be stored in the register.

Output ports:
    data_out: 8-bit output representing the stored value.

Implementation:
On every positive clock edge, if the reset signal (rst_n) is low, the register value (data_out) should be set to 0. If the reset signal is high and the enable signal (en) is high, the register should store the input data (data_in).
