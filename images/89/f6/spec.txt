Design a dual D flip-flop circuit with reset capabilities. Upon receiving a clock signal, the first flip-flop captures the value of the input signal, while the second flip-flop outputs the XOR of its own output and the input, effectively toggling whenever there is a change at the input. The module also incorporates an asynchronous reset feature that initializes both flip-flops to LOW when activated.

  input clk,
  input reset,
  input d_in,
