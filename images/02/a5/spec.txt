
Design a simple PCIe request handler in Verilog. The handler should have an input signal for a request (`req`), a clock signal (`clk`), and an output signal for the acknowledgment (`ack`). On every rising edge of the clock, if a request is received (`req` is high), the output acknowledgment (`ack`) should be set high for one clock cycle and then return to low. The handler should also have a reset signal (`rst`) which, when high, will reset the acknowledgment output to low regardless of the request signal.
