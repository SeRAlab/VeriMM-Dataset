Implement a Binary-Coded Decimal (BCD) to binary converter. The module takes an 8-bit BCD input, splits it into two 4-bit values, a and b, representing the tens and units digits, respectively. If either a or b exceeds the decimal value of 9, the output will be undefined. Otherwise, it produces a 7-bit binary output that combines the values of b (tens) and a (units) into a binary number.
