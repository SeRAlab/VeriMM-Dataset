Design a 4-bit binary adder circuit that adds two 4-bit inputs, A and B, along with an optional carry input, C_in. The module calculates the sum and produces a 4-bit output S. It also generates a carry output C based on the most significant bits of the inputs and carry input. If the carry output, C_out, is asserted, the highest bit of the sum is replaced with the carry from the addition operation. Otherwise, the sum is output directly.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input C_in,
    input C_out,
    output reg [3:0] S,
    output reg C
);
