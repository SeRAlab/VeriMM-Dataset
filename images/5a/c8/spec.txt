Design a 4-to-1 multiplexer that selects one of four input signals (A, B, C, D) based on the values of two selection lines (S0 and S1). The output (Y) reflects the value of the selected input: when S0 and S1 are both LOW, output A is chosen; when S0 is HIGH and S1 is LOW, output B is selected; when S0 is LOW and S1 is HIGH, output C is used; and when both S0 and S1 are HIGH, output D is active. The final output Y is inverted to generate the desired logic level.
module top_module(
    input A,
    input B,
    input C,
    input D,
    input S0,
    input S1,
    output Y
);
