Design a dual-port RAM module that supports simultaneous read and write operations. It has two separate sets of inputs for each port, allowing independent access to the memory: one for writing and reading data (address_a, wrdata_a, wren_a, and rddata_a) and another for a different set of memory transactions (address_b, wrdata_b, wren_b, and rddata_b). The memory structure is defined with input address widths of 7 bits and data widths of 8 bits. The module is clocked, ensuring that read and write actions occur on the rising edge of the clock signal. The parameter INIT_FILE indicates that it can be initialized with data from a specified file.
