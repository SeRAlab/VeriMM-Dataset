Design a fan speed controller that adjusts the speed of a fan based on temperature input. The fan should have three speed settings: LOW, MEDIUM, and HIGH. The speed setting will change based on the temperature range: 
- If the temperature is below 20°C, the fan speed should be LOW (00).
- If the temperature is between 20°C and 30°C, the fan speed should be MEDIUM (01).
- If the temperature is above 30°C, the fan speed should be HIGH (10).
The system should have a clock input to simulate the operation at regular intervals. The temperature input will be provided as an 8-bit binary value.
