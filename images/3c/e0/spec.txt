Design a simple I2C controller that generates the start and stop conditions for an I2C communication protocol. The controller has an input signal `start` to initiate communication and an input signal `stop` to terminate it. The output signals are `SDA` and `SCL` for the data and clock lines respectively. The controller should generate the start condition when `start` is high and hold `SDA` low while toggling `SCL` for clock pulses. It should generate the stop condition when `stop` is high by releasing `SDA` while keeping `SCL` high.
