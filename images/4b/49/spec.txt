Design a dual-port RAM module with a capacity of 512 words, each 16 bits wide. This memory allows for simultaneous reading and writing operations, controlled by external address inputs for read and write operations, and a write enable signal. When the write enable is asserted, data is written to the memory at the specified write address; meanwhile, the data at the read address can be accessed at any time, providing quick data retrieval. The module supports independent control of read and write operations through separate input addresses while utilizing a single clock signal for synchronization.
