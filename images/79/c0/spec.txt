Develop a Verilog module for a Moore state machine with three states: IDLE, START, and STOP. The state should transition from IDLE to START on a high 'start' input, and from START to STOP on a high 'stop' input. Include a synchronous reset to return to the IDLE state.
module moore_fsm(
    input clk,
    input reset,
    input start,
    input stop,
    output reg [1:0] state);
