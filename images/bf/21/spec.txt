Design a simple 4-bit calculator that performs basic arithmetic operations. The module takes two 4-bit operands and a 2-bit operation selector, where the operations available include addition, subtraction, multiplication, and division. It updates the result on the rising edge of the clock, under the control of a reset signal that initializes the result to zero. The output reflects the computed value based on the selected operation.
module top_module(
    input wire clk,
    input wire rst,
    input wire [3:0] operand1,
    input wire [3:0] operand2,
    input wire [1:0] operation,
    output wire [3:0] result
);
