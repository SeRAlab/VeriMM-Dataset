Design a 3-bit wide counter to track the number of entries in a FIFO (First In, First Out) buffer. The module increments the count when the `up_count` signal is high and decrements the count when the `down_count` signal is high, triggered on the positive edge of the clock. The count resets to zero when the `reset` signal is asserted.
module top_module(
    input up_count,
    input down_count,
    input reset,
    input clk,
    output reg [2:0] num_entries
);
