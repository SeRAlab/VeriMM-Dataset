Design a Run-Length Encoding (RLE) module in Verilog. The module takes an 8-bit input `data_in` and generates a run-length encoded output. The encoded data consists of pairs of (value, count) where `value` is the input data and `count` is the number of consecutive occurrences of that value. The output should be valid when `valid_in` is high, and the output should be sent on `data_out` and `count_out` lines. The module should also provide a `done` signal that indicates when the encoding process is complete.
