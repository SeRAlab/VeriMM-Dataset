

You have been tasked with designing a module that will take in a 4-bit binary input and output the binary equivalent of the input plus 5. Your module should have the following ports:

- `input [3:0] in`: the 4-bit binary input
- `output [3:0] out`: the 4-bit binary output

Your module should also be sensitive to the positive edge of the clock signal, `clk`. 

Write a Verilog module that meets these specifications.
