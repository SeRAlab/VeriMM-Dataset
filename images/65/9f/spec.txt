Design a circuit that performs bit shifting on a 32-bit input number based on a specified shift amount and operation selection. The module accepts a 32-bit input (`num`), a 5-bit shift value (`shift`), and a 2-bit operation selector (`op_sel`). Depending on the value of `op_sel`, it can execute a left shift, a logical right shift, or an arithmetic right shift, with a default case that maintains the original number if no shift is performed. The shifted result is output as a 32-bit value.
module top_module(
  input [31:0] num,
  input [4:0] shift,
  input [1:0] op_sel,
  output [31:0] result
);
