
Design a hazard detection circuit for a simple 2-bit ALU that detects and resolves data hazards. The ALU takes two 2-bit inputs A and B, and an operation signal Op that can be 00 (AND), 01 (OR), or 10 (XOR). The hazard detection circuit should output a signal `hazard` which indicates whether a hazard is present (1 if there is a hazard, 0 otherwise). A hazard occurs when the same input is read in consecutive operations without an intervening write operation.
