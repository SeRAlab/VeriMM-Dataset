Design a 16-bit wide, 4-to-1 multiplexer with enable functionality. The module takes a 16-bit input and a 4-bit selector input to choose between four 4-bit segments of the input based on the selected value. An enable signal controls whether the output reflects the selected segment or outputs zero. The module utilizes dual-stage registers to store the input and selector values, updating on the positive edge of the clock.
