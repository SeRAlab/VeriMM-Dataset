Design a 3-bit Gray code counter that increments its output count on each positive edge of the clock signal. The counter resets to 0 when the reset signal is asserted. The counting mechanism utilizes the property of Gray code, where each successive value differs from the previous one by only a single bit, achieved through a bitwise XOR operation with the current count shifted right by one position.
