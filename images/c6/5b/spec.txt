

You are tasked with designing a module that takes in 5 inputs and produces a single output. The module should be named `logic_gate` and should be written in Verilog. The inputs are named `A`, `B`, `C`, `D`, and `E`, and are all single-bit signals. The output is named `Y` and is also a single-bit signal.

The module should implement the following logic: `Y = (A & B) | (!C & D) | E`

Write the Verilog code for the `logic_gate` module that implements this logic.
