Design a Parallel-in Parallel-out (PIPO) shift register with an 8-bit width. The shift register should have an input for loading data, an input clock signal, and a reset signal. When the load signal is asserted, the input data should be loaded into the register. On every rising edge of the clock, when the load signal is not asserted, the current value of the register should be output. The reset signal should clear the register.
