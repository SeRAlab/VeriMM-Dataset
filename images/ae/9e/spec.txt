Design a combinational logic circuit that computes two outputs, F1 and F2, based on four inputs, A, B, C, and D. Output F1 is produced by performing a logical AND operation on the results of two separate AND gates, one fed by inputs A and B, and the other by inputs C and D. Output F2 is generated by a logical OR operation that combines the result of an OR operation on inputs A and B with the result from the second AND gate (C and D). This module effectively combines AND and OR logic to provide the desired outputs.
module top_module(
    input A,
    input B,
    input C,
    input D,
    output F1,
    output F2
);
