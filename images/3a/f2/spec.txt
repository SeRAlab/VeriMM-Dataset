
Design a Verilog module that implements a simplified version of the ChaCha20 stream cipher core. The module should accept a 32-bit input key and a 32-bit nonce value, along with a control signal to initiate the operation. The output should be a 32-bit stream of pseudo-random data derived from the key and nonce. The module should implement the core operations of the ChaCha20 algorithm, such as rotation and addition, but simplified for educational purposes.
