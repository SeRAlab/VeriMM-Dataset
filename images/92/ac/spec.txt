Design a frequency synthesizer that generates a clock signal with a frequency determined by the control input. The module takes a reference clock and a control signal, which specifies a division ratio represented by an n-bit value. It uses a binary counter to toggle the output clock at a rate defined by the maximum count derived from the control input, thus allowing the output clock frequency to vary up to a specified maximum frequency. This design enables adjustable frequency generation suitable for various applications requiring clock signal modulation.

  input clk_ref,
  input [n-1:0] ctrl,
