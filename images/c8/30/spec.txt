

You are working on a digital circuit design project and you need to create a module that takes an input signal and outputs a constant value. Your module should be named `constant_module` and should take two inputs and one output. The first input is a single bit signal named `in_signal` which is the input signal to your module. The second input is a 4-bit signal named `constant_value` which is the constant value you want to output. The output is a 4-bit signal named `out_signal` which is the output signal of your module.

Your task is to implement the `constant_module` module that takes the `in_signal` and `constant_value` signals as inputs, and outputs the `constant_value` signal on the `out_signal` signal whenever the `in_signal` is high. When the `in_signal` is low, the `out_signal` should be zero. You can assume that the `in_signal` will only be high or low, and that the `constant_value` will not change during the operation of the module.

You should write your code in Verilog. Your implementation should be done in one module, without using any other modules.
