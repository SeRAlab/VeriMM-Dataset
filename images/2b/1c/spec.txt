
Design a 5-bit Parallel-In Parallel-Out (PIPO) shift register. The shift register should have the following functionalities:
1. An input data signal of 5 bits (D) to load data parallelly.
2. A clock signal (clk) to shift data.
3. A load signal (load) to enable the loading of input data into the register.
4. An output data signal (Q) that reflects the current data in the register after a clock edge.
5. The register should shift left on every clock edge when not loading new data.
