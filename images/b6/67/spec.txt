Design a one-bit wide, 2-to-1 multiplexer. The module takes two input signals, a_in and b_in, and selects one of them to output based on the value of the select signal s_in. When s_in is 0, the output s_out is equal to a_in; when s_in is 1, the output s_out is equal to b_in. The width of the inputs and output can be parameterized, allowing for adaptable bus widths.
module top_module(a_in, b_in, s_in, s_out);
