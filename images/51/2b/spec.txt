Design a signed four-bit adder that computes the sum of two signed 4-bit inputs, `a` and `b`, along with a carry input `cin`. The module produces a 4-bit `sum` output representing the lower four bits of the result and a `cout` output indicating an overflow or carry out of the most significant bit. This adder can be used for arithmetic operations in larger digital systems requiring binary addition of signed numbers.
module top_module(
    input signed [3:0] a,
    input signed [3:0] b,
    input signed cin,
    output signed [3:0] sum,
    output signed cout
);
