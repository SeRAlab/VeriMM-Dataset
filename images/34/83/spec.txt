
Design a 4-bit SRAM cell with enable (write/read) functionality. The SRAM cell should have the following inputs: 
- `write_enable` (1 bit): when high, allows writing to the cell. 
- `data_in` (4 bits): data to be written to the cell when `write_enable` is high.
- `read_enable` (1 bit): when high, allows reading from the cell.
The outputs should be:
- `data_out` (4 bits): the data stored in the SRAM cell when reading is enabled.
The behavior should be such that if both `write_enable` and `read_enable` are high, priority should be given to writing.
