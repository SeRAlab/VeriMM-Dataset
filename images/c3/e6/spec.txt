

You have been tasked with designing a module that will implement a 2:1 MUX using a 2-input AND gate, a 2-input OR gate, and an inverter. The module should take in two data inputs, a select input, and output the selected input. The module should be named `mux_2to1` and have the following ports:

- `in0`: input data bit 0
- `in1`: input data bit 1
- `sel`: select input bit
- `out`: output data bit

Write the verilog code for this module using only the specified gates.
