Design a dual-modulus prescaler (DMP) for an FPGA that divides the input frequency by either 2 or 3, depending on a control signal. The prescaler should take a clock input and a control signal, and output the divided clock signal. The control signal will select the division factor: if the control signal is '0', the output clock should be divided by 2, and if the control signal is '1', it should be divided by 3. The design should ensure that the output clock edges align correctly with respect to the input clock.
