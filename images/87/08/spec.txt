Design a Verilog module to perform the following operations. Assume positive clock/clk edge triggering unless otherwise specified.
You have a twelve-bit input vector in[11:0]. We want to calculate the following:
// (1) out_and: Each bit of this output vector should indicate the logical AND between the corresponding input bit and its neighbour to the left. For example, out_and[5] should be the AND of in[5] and in[6]. Since in[11] has no neighbour to the left, out_and[11] is not needed.
// (2) out_xor: Each bit of this output vector should indicate the XOR between the corresponding input bit and its neighbour to the right. For example, out_xor[2] should be the XOR of in[2] and in[1]. Since in[0] has no neighbour to the right, out_xor[0] is not needed.
// (3) out_diff_wrap: Each bit of this output vector should indicate whether the corresponding input bit is different from its neighbour to the right. For example, out_diff_wrap[3] should indicate if in[3] is different from in[2]. For this part, treat the vector as wrapping around, so in[0]'s neighbour to the right is in[11].
