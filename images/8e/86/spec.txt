Design a 4-bit adder-subtractor module that performs addition or subtraction based on the value of the SUB control signal. When SUB is low, the module adds the 4-bit inputs A and B, producing a 4-bit output OUT and a carry output COUT. When SUB is high, it subtracts B from A, with OUT reflecting the result of the subtraction. COUT indicates the carry out for addition and also serves as a borrow indicator for subtraction. This design effectively allows for basic arithmetic operations in a single circuit.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input SUB,
    output [3:0] OUT,
    output COUT
);
