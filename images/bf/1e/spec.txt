Create a module that functions as a multi-bit comparator for unsigned or signed numbers. It takes two n-bit wide input signals, in1 and in2, and outputs three signals: 'greater' indicates if in1 is greater than in2, 'less' indicates if in1 is smaller than in2, and 'equal' indicates if the two inputs are equal. The comparison properly handles both unsigned and signed scenarios by checking the most significant bit (sign bit) during comparisons, ensuring accurate evaluation of the inputs' magnitudes.
module top_module(
  input [n-1:0] in1,
  input [n-1:0] in2,
  output reg greater,
  output reg less,
  output reg equal
);
