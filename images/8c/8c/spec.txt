Design a 4-bit binary adder that can handle both addition and subtraction based on the carry input. When the carry input (C) is 0, the module performs standard binary addition of the inputs A and B. When C is 1, the module treats the inputs as negative numbers and computes their difference by using two's complement arithmetic, effectively implementing A - B. The output is a 4-bit result (Z) reflecting the appropriate operation based on the value of C.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input C,
    output [3:0] Z
);
