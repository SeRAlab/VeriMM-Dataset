Design a Verilog module for a current sensor that provides an output based on the current reading. The module should have a clock input and a reset input. On each clock cycle, if the reset is not active, the module should read the current value and compare it against a predefined threshold. If the current exceeds the threshold, an output signal should be set high; otherwise, it should remain low. The current value will be represented as a 10-bit unsigned integer.
