Design a Verilog module that implements a simple Support Vector Machine (SVM) decision function. The module should take two 5-bit inputs (feature vectors) and produce a single output that indicates whether the points belong to class 1 (output = 1) or class 0 (output = 0). The decision function will be a simple linear function: `output = sign(w1*x1 + w2*x2 + b)` where w1, w2 are weights, and b is a bias. For this problem, we can set w1 = 1, w2 = 1, and b = 1 for simplicity.
