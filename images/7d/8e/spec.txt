Design a 2-bit up/down counter that increments or decrements its count based on the control signal `up_down`. When the `reset` signal is HIGH, the counter resets to zero. On each rising edge of the clock (`clk`), if `up_down` is set to HIGH, the counter increases by one; if `up_down` is set to LOW, the counter decreases by one, allowing for counting in both directions.
module top_module(
  input clk,
  input reset,
  input up_down,
  output reg [1:0] count
);
