Design a combinational circuit with two outputs based on a control input. The circuit functions as follows: when input `a` is high (1), `out1` produces the negation of input `b`, while `out2` outputs `b` directly; conversely, when `a` is low (0), `out1` outputs `b` and `out2` provides the negation of `b`. This results in a toggle mechanism controlled by input `a`, effectively allowing the circuit to select between the original and negated states of `b` for both outputs.
module top_module(
  input a, b,
  output out1, out2
);
