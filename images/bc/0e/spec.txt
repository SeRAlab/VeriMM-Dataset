Design a D flip-flop with asynchronous reset and enable functionality. The flip-flop captures the input data (D) on the rising edge of the clock (CLK) when the enable (EN) signal is high. If the enable signal is low, it holds the previous value. The output (Q) can be reset to logic LOW when the reset (RST) signal is asserted. The complementary output (Q_N) provides the inverted value of Q. The module also integrates power and ground connections for chip-level integration.
module top_module(
    input CLK,
    input D,
    input RST,
    input EN,
    input VPWR,
    input VGND,
    output reg Q,
    output Q_N
);
