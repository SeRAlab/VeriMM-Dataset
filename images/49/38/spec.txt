Design a D latch with an active-high reset and enable functionality. When the RESET signal is high, the output Q is set to LOW, and Q_n is set to HIGH. When RESET is not active and the ENABLE (EN) signal is high, the latch captures the value on the D input and outputs it on Q, while Q_n provides the inverse of Q. The output updates occur on the rising edge of the clock signal.
module top_module(
    input clk,
    input D,
    input EN,
    input RESET,
    output reg Q,
    output reg Q_n
);
