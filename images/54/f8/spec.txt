Design a circuit that functions as an edge detector. It has a configurable option to detect either a rising or falling edge of an input signal. When a rising edge is detected, the output is set to HIGH for one clock cycle; when a falling edge is detected, the output is similarly set to HIGH for one clock cycle. The module uses a clock for synchronization and an active-low reset to initialize its state. Additionally, it includes a delay parameter that introduces a specific timing delay for output changes, ensuring controlled signal transitions.
module top_module(
    clk,
    reset_n,
    in, // detector input
    out, // detector output
    edge_detect // specifies whether rising or falling edge it to detect
);
