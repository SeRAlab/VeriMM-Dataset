
You need to design a 1-bit DRAM cell using Verilog. The DRAM cell should have the following specifications:
- It should include a data input (D), a word line (WL), a bit line (BL), and a read/write control signal (RW).
- When RW is high, the DRAM cell should write the value on D to the cell when WL is high.
- When RW is low and WL is high, the DRAM cell should output the stored value to BL.
- The DRAM cell should retain the value until it is updated with a new write operation.
