Design a simple SD card interface controller that manages the read and write operations. The controller should have inputs for a clock signal, a reset signal, a read signal, a write signal, and a data input. It should have outputs for a data output and a busy signal indicating whether the controller is currently processing a read or write operation. The controller should operate as follows: on a read signal, it should wait for the clock to indicate that a read operation is starting, then output the data on the data output line. On a write signal, it should store the incoming data from the data input line and indicate that it is busy while the operation is being performed.
