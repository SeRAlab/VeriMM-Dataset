Design a Verilog module that implements a simple RNN cell. The RNN should take an input vector and maintain a hidden state across time steps. The RNN cell should have a single input, a single output, and one hidden state. The hidden state should be updated based on the input and the previous hidden state using a linear transformation followed by a non-linear activation function (e.g., ReLU). The output of the RNN cell at each time step should be the current hidden state.
