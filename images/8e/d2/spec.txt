Design a module that computes the pairwise XOR of five one-bit inputs (a, b, c, d, e) and produces a 25-bit output. Each bit of the output corresponds to the result of the XOR operation between every pair of inputs, including each input XORed with itself, effectively generating a complete pairwise XOR matrix of the inputs.
module top_module(
  input a,
  input b,
  input c,
  input d,
  input e,
  output [24:0] out
);
