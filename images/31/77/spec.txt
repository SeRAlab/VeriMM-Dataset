
Design an 8-bit SRAM cell. The SRAM cell should have the following inputs: 
- `addr` (3 bits) for selecting one of the 8 memory locations
- `data_in` (8 bits) for writing into the selected memory location
- `we` (1 bit) to enable writing (when `we` is high) or reading (when `we` is low)
- `data_out` (8 bits) for reading the data from the selected memory location

The SRAM cell should have a reset input that initializes the memory to all zeros.
