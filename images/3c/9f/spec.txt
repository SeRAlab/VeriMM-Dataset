Design a combinational logic circuit that implements a simple A* search algorithm heuristic function. The input to the circuit will be three 4-bit binary numbers representing the cost from the start node (g), the cost to the goal node (h), and the total cost (f). The output should be a 4-bit binary number representing the heuristic cost. The heuristic function is defined as h = f - g. Ensure that your design handles possible underflow in the subtraction operation.
