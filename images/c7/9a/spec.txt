

You are tasked with designing a verilog module that takes in a 4-bit input signal and returns a 4-bit output signal. The module should perform a bitwise XOR operation on the input signal and a constant 4-bit value, and then output the result.

The module should be named "xor_module" and should have the following ports:
- A 4-bit input port named "data_in"
- A 4-bit output port named "data_out"

The constant 4-bit value to be XORed with the input signal should be defined as a parameter within the module and named "xor_value". The module should be instantiated with a value of "1010" for "xor_value".

Your task is to write the verilog code for the "xor_module" module that meets the above requirements.
