Design a simple Bluetooth module controller that takes a 4-bit input representing the status of a Bluetooth device (0000 for OFF, 0001 for CONNECTING, 0010 for CONNECTED, 0011 for DISCONNECTED, 0100 for ERROR) and outputs a 3-bit status code based on the input status. The output should be 000 for OFF, 001 for CONNECTING, 010 for CONNECTED, 011 for DISCONNECTED, and 100 for ERROR.
