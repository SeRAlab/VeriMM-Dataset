Design a 4-to-1 multiplexer that takes four 32-bit input signals (in0, in1, in2, in3) and outputs one of these inputs based on a 2-bit selection signal (select). The output will reflect the selected input based on the value of select: when select is 00, output in0; when 01, output in1; when 10, output in2; and when 11, output in3.
module top_module(
    input [31:0]in0,in1,in2,in3,
    input [1:0]select,
    output reg [31:0]out
    );
