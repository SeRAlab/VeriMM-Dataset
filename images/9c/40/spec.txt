Implement a 2-bit comparator that checks for equality between two 2-bit inputs, A and B. On each positive clock edge, it captures the values of A and B into registers. It then compares these stored values; if they are equal, it sets the output 'eq' to HIGH (1), otherwise it sets 'eq' to LOW (0).
module top_module(
    input [1:0] A,
    input [1:0] B,
    input clk,      // Added clk as an input
    output reg eq   // Changed output to reg type for assigning in always block
);
