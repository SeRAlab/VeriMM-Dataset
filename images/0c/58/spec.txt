Design an 8-bit shift register with the following specifications:  
- It should have a clock input (clk), a reset input (rst), and a data input (d).  
- On the rising edge of the clk, if rst is low, the data input d is shifted into the register.  
- If rst is high, the register should be reset to 0.  
- The output should be the current state of the shift register.  
- Implement a left shift operation, meaning the most significant bit (MSB) should be 0 after each shift, and the remaining bits should shift left.
