Design a 4-bit wide bitwise AND circuit with an additional output to signal if the most significant bit of the resulting AND operation is HIGH. The module takes two 4-bit inputs, A and B, stores them in registers on the rising edge of the clock, computes the bitwise AND of these inputs, and outputs the 4-bit result. Additionally, it outputs a single bit, D, which indicates whether the most significant bit (the highest bit in the 4-bit output) is set.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input clk,          // Added clk as an input
    output [3:0] C,
    output D
);
