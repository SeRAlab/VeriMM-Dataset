Design a linear feedback shift register (LFSR) with a configurable mask for generating pseudo-random sequences. The module features a clock input, a reset input, an enable signal, and a strobe signal that controls when the LFSR shifts its state. On each positive clock edge, if the reset or enable conditions are not met, the LFSR resets to a predefined state. When strobe is high, the LFSR shifts left, incorporating a calculated parity bit, derived from the current state masked by the provided input mask. The output provides the least significant bit of the LFSR as the pseudo-random output.
