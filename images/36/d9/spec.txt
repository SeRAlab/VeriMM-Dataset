Design a 2-input Support Vector Machine (SVM) classifier using a simple linear decision boundary. The inputs are 2-bit binary values representing feature vectors (x1, x2), and the output is a single bit representing the class label (0 or 1). The decision boundary is defined by weights w1 and w2, and a bias b. The classifier outputs 1 if w1*x1 + w2*x2 + b > 0, otherwise it outputs 0. Use fixed weights w1 = 1, w2 = 1, and b = -1.
