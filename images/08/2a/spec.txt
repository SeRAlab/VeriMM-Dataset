Design a 4x PLL (Phase Locked Loop) that takes an input clock signal and generates four output clock signals which are phase-shifted by 90 degrees. The PLL should have a control signal that allows for enabling or disabling the output clocks. The four output clocks are to be named clk_out_0, clk_out_1, clk_out_2, and clk_out_3. The module should include an active-low reset signal that resets the internal state of the PLL.
