
Design a 1-bit DRAM cell using Verilog. The cell should have the following inputs and outputs:
- Inputs: `data_in` (1-bit), `word_line` (1-bit), `bit_line` (1-bit)
- Outputs: `data_out` (1-bit)

The DRAM cell should work as follows:
- When `word_line` is high, the `data_in` should be written to the cell (stored).
- When `word_line` is low, the `data_out` should output the stored value.
- If `bit_line` is set high, it should allow the stored value to be read and output on `data_out`.
