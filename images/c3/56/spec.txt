Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a power-on reset (POR) circuit. 
A POR circuit is a type of digital circuit that generates a reset signal when the power supply to the circuit is turned on. 
The reset signal is used to initialize the circuit to a known state, which is important for ensuring proper operation of the circuit. 
Your module should have the following inputs and outputs:

Inputs: a power supply signal (VDD)
Outputs: a reset signal (RST)
The module should also have the following parameters:

t: the time it takes for the power supply to stabilize (i.e., the time it takes for the voltage to reach a steady state)
Your module should implement the following functionality:

When the power supply signal (VDD) is first applied, the reset signal (RST) should be asserted (i.e., set to 1) for a period of time equal to t.
After the reset signal has been asserted for t, it should be de-asserted (i.e., set to 0).
To implement the POR circuit, you should use Verilog code to define the timing of the reset signal as a function of the power supply signal. 
You should then use this function to generate the reset signal when the power supply is first turned on.
