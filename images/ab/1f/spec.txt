Design a hysteresis comparator circuit that compares an input voltage (Vin) against a reference voltage (Vref) with a specified hysteresis margin (hyst). The output (Vout) is driven high when Vin exceeds Vref plus the hysteresis, and driven low when Vin falls below Vref minus the hysteresis. In the event that Vin falls within the hysteresis band, the output retains its previous state, thereby providing noise immunity and stable operation in fluctuating signal conditions. This module effectively prevents rapid toggling of the output in response to small variations in the input voltage.
module top_module(
  input Vin,
  input Vref,
  input hyst,
  output reg Vout
