

You are given a verilog module `counter` with a single input `clk` and a single output `q`. Your task is to implement a counter that counts up to a given value `N` and then resets to 0. The counter should increment on every positive edge of `clk`. 

Write a verilog module `counter` that takes in a clock signal `clk` and a parameter `N` and outputs a counter value `q` that counts up to `N` and then resets to 0. 

Assume that the clock signal has a frequency of 50 MHz.
