Design a D-type flip-flop with enable and reset functionality, incorporating a gated clock. This module has an enable signal (EN) that determines if the clock (CLK) is passed through to the flip-flop. If EN is high, the flip-flop captures the value of the toggle input (TE) on the rising edge of the gated clock. The reset (RESET) signal asynchronously clears the flip-flop's output (Q) to LOW. The output (ENCLK) represents the gated clock signal, which is either the original clock or grounded based on the state of the enable signal.
