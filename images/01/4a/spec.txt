Design a 128-bit AES encryption module with the following specifications: The module should take a 128-bit plaintext input and a 128-bit key input to produce a 128-bit ciphertext output. The design should be able to handle multiple rounds of encryption as defined by the AES algorithm. Implement the key schedule for the given key and integrate it into the encryption process. The module should also include a start signal to initiate the encryption process and a done signal to indicate when the encryption is complete.
