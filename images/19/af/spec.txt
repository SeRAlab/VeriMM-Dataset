
Design a state-space controller that manages a simple system with the state represented by a 3-bit register. The controller has two inputs: a 1-bit enable signal (`enable`) and a 3-bit control signal (`control`). When the enable signal is high, the state should update based on the control signal. If the enable signal is low, the state should hold its value. The system should also have a reset signal that sets the state to zero.
