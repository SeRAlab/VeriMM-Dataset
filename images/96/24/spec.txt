Design a 4-to-1 multiplexer that selects one of four input lines (in0, in1, in2, in3) based on a 2-bit selection signal (sel). An additional enable signal (en) controls the output; when en is high, the output corresponds to the selected input, and when en is low, the output is forced to LOW.
module top_module(
  input in0,
  input in1,
  input in2,
  input in3,
  input sel,
  input en,
  output out
);
