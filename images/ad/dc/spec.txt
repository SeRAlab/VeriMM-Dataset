Design a binary-coded decimal (BCD) adder that adds two 4-bit inputs, A and B, along with a carry-in (Cin), producing a 4-bit sum output (Sum) and a carry-out (Cout). The module computes the preliminary sum of A, B, and Cin in a temporary variable and checks if this sum exceeds 9, the maximum value for a single BCD digit. If it does, it adjusts the Sum by adding 6 to ensure valid BCD representation and sets the carry-out signal. If the sum is within the valid range, it keeps the Sum unchanged and sets the carry-out to zero.
module top_module(output reg [3:0] Sum, output reg Cout, input [3:0] A, B, input Cin);
