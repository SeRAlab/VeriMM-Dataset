Design a 4-to-1 multiplexer that selects one of four input signals (A, B, C, D) based on two selection lines (S0, S1). The output Y will reflect the value of the selected input: when S0 and S1 are both 0, input A is selected; when S0 is 0 and S1 is 1, input B is selected; when S0 is 1 and S1 is 0, input C is selected; and when both S0 and S1 are 1, input D is selected.
module top_module(
    input A,
    input B,
    input C,
    input D,
    input S0,
    input S1,
    output Y
);
