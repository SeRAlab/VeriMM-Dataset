
Design a temperature-based shutdown system that turns off a device if the temperature exceeds a specified threshold. The system should have a clock input and a reset input. When the reset is activated, the system should return to a safe state. The temperature is provided as a 7-bit input representing a value from 0 to 127 degrees. If the temperature exceeds 100 degrees, the shutdown signal should be triggered. The shutdown signal should remain active until the reset signal is asserted.
