Design a 2-to-1 multiplexer with an enable signal. When enable is LOW (0), the output will be set to the value of in1. When enable is HIGH (1), the output will be set to the value of in2. The multiplexer operates on 8-bit wide inputs and output.
module top_module(
  input enable,
  input [7:0] in1,
  input [7:0] in2,
  output reg [7:0] out
);
