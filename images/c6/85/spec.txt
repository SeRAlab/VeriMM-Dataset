

You are tasked with designing a module that implements a buffer in Verilog. The module should have one input and one output port. The input should be a single bit, and the output should be the same bit as the input. The module should be named `my_buff`.

Your module should be implemented within 200 lines of Verilog code. You may use any Verilog version.

Write a Verilog module that implements a buffer using the following code snippet as a starting point:

```
module tkg_buff (output o, input i);
	BUFF I0 (o, i);
endmodule
```

Your module should have the following interface:

```
module my_buff (output reg o, input i);
	// your code goes here
endmodule
```

You may not use any Verilog primitives or built-in modules. You may only use basic Verilog constructs such as gates, registers, and wires.

Your module should be synthesizable and should not contain any combinational loops.
