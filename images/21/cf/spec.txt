
Design a simplified NVMe controller state machine that handles three states: IDLE, READ, and WRITE. The controller should transition between these states based on input signals. The inputs are a clock signal (clk), a reset signal (rst), and two control signals (read_cmd, write_cmd). The state transitions are as follows:
- From IDLE, if read_cmd is asserted, transition to READ.
- From IDLE, if write_cmd is asserted, transition to WRITE.
- From READ, if a read operation is completed, transition back to IDLE.
- From WRITE, if a write operation is completed, transition back to IDLE.
