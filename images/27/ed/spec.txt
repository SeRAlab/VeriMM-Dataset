Design a simple Model Predictive Controller (MPC) in Verilog that adjusts an output value based on input signals. The controller should take a 4-bit input for the current state and a 4-bit input for the desired state. The controller will output a 4-bit control signal that represents the necessary adjustment to reach the desired state. Use a simple proportional control method to compute the output: output = (desired_state - current_state).
