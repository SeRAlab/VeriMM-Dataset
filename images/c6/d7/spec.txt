

Create a Verilog module for a 2-to-1 multiplexer with an enable input. The module should have the following inputs and outputs:
- Two data inputs (A and B), each 8 bits wide
- One enable input (EN)
- One output (Y), 8 bits wide

If EN is high, the output Y should be equal to input A. If EN is low, the output Y should be equal to input B. 

Write a Verilog code for the above-mentioned module.
