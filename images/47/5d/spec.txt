Design a simple 8-bit calculator that performs basic arithmetic operations based on the specific values of two 8-bit inputs, A and B. The module outputs a result Z, which is computed as follows: when the concatenation of A and B equals 0xAB, it performs addition; for 0xAA, it performs subtraction; for 0x50, it executes multiplication; and for 0x32, it conducts division. If none of these values are matched, Z is output as zero.
