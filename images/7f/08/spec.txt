Design a circuit that performs a parallel load and right shift operation on an 8-bit input data. The `data_in` is loaded into the circuit, and on the rising edge of a clock signal, it is shifted left by the number of positions specified by `shift_amount`. The resulting shifted value is then output as `data_out`.
module top_module(
    input clk,                  // Added clk input
    input [7:0] data_in,
    input [2:0] shift_amount,
    output [7:0] data_out
);
