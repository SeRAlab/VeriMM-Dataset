Design a fan speed controller that takes as input two signals: `mode` (1-bit) which determines the mode of operation (0 for low speed, 1 for high speed), and `temperature` (5-bit) which indicates the temperature level (0-31). The fan speed output should change based on the following conditions:
- If the mode is 0 (low speed), the fan speed will be set to 1 if the temperature is above 20, otherwise, it will be set to 0.
- If the mode is 1 (high speed), the fan speed will be set to 1 if the temperature is above 15, otherwise, it will be set to 0.
Additionally, there should be a `reset` signal (1-bit) that resets the fan speed to 0.
