Design a 24-bit ADC output decoder that translates the 24-bit digital input from the ADC into a 3-bit binary output that represents the range of input values. The output should indicate the range in which the ADC value falls: 0 for 0-8388607 (0x000000 to 0x7FFFFF), 1 for 8388608-16777215 (0x800000 to 0xFFFFFF).
