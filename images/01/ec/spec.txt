Design a Verilog module that implements a CRC-8 (Cyclic Redundancy Check) generator. The module should take an 8-bit data input and produce an 8-bit CRC output. The CRC polynomial to be used is x^8 + x^2 + x + 1, which corresponds to the hexadecimal value 0x07. The module should have a clock input and a reset input to initialize the CRC calculation. The CRC should be updated with each new byte of data input.
