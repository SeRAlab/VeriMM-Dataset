Design a circuit that functions as an instruction memory module, which stores predefined 14-bit instructions in a memory array of size 256. This module is controlled by a clock signal and a reset signal. Upon receiving a reset (when rst is low), it initializes the memory with specific instructions. When a specific flag (FFlag3) is asserted, it reads the instruction from the memory based on the provided program counter (PC), taking the modulus of 20 to wrap around for addressing the instruction set. Additionally, it sets the output flag (FFlag1) high after a 20-time unit delay, indicating that an instruction has been fetched.
