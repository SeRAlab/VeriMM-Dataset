Design a Verilog module for an SR-latch. The SR-latch should have two inputs (S and R) and one output (Q). The latch should maintain its state until the inputs change. The output should reflect the current state of the latch based on the S and R inputs: when S is high, Q should be set high; when R is high, Q should be reset low; when both S and R are low, Q should hold its previous state. If both S and R are high, the output is considered invalid.
