Design a 1-bit SRAM cell that can store a single bit of data. The SRAM cell should have the following inputs: `data_in` (the bit to be written), `write_enable` (if high, write `data_in` to the cell), and `read_enable` (if high, output the stored value to `data_out`). Additionally, the SRAM cell should maintain its value when not in write mode.
