Design a 12-to-1 multiplexer that selects one of 12 input signals based on a 4-bit select signal. The output will correspond to the input indicated by the select signal, meaning when S is in the range of 0 to 11, the output O is set to the respective input I, while any other value of S will result in a default output of LOW.
module top_module(
  input [11:0] I,
  input [3:0] S,
  output reg O
);
