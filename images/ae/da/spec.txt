Design a 4-bit asynchronous resettable D flip-flop. Upon the rising edge of the clock, if the reset signal (rst_n) is asserted low, the output state will be reset to zero; otherwise, the output will be updated with the 4-bit input data (din). The current state of the flip-flops is reflected on the output (dout).
module top_module(
    input clk,
    input rst_n,
    input [3:0] din,
    output [3:0] dout
);
