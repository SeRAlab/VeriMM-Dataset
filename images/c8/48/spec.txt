

In digital design, sequential circuits are circuits in which the output depends on the previous state of the circuit as well as the current input. One type of sequential circuit is a register, which is a device that stores data for a certain amount of time. A register can be thought of as a group of flip-flops that store bits of data. In this problem, you will be designing a register in Verilog.

Create a Verilog module called "Register" that has the following inputs and outputs:

Inputs:
- clk: a clock signal
- rst: a reset signal that sets the register to a default value of 0
- data_in: the input data to be stored in the register

Outputs:
- data_out: the output data from the register

The register should store the input data on the rising edge of the clock signal and output the stored data on the falling edge of the clock signal. The register should be able to hold 8 bits of data.

You should write a Verilog module that implements the above requirements within 200 lines of code.
