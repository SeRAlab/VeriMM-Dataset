
Design a simple Flash memory controller in Verilog. The controller should have the following functionalities:
1. A reset signal that clears the memory.
2. An input signal to write data to a memory cell.
3. An output signal to read data from a memory cell.
4. A memory size of 4 bits (4 memory cells).
The memory cells can be addressed by a 2-bit address input. The module should include an enable signal to allow writing or reading operations.
