
Design a simple EEPROM cell in Verilog that can store a single bit of data. The cell should have three inputs: `data_in` (the data to be written), `write_enable` (a signal to control writing), and `read_enable` (a signal to control reading). The output should be `data_out` which reflects the stored data when `read_enable` is high. If `write_enable` is high, the `data_in` should be stored in the cell. If both `write_enable` and `read_enable` are low, the cell should retain its previous state.
