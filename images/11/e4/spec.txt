
Design a 2nd-order Infinite Impulse Response (IIR) filter using Verilog. The filter should have the following specifications:
- Two input samples (x[n] and x[n-1]) and one output sample (y[n]).
- The state variables (for feedback) should be stored in registers.
- Coefficients for the filter (b0, b1, b2, a1, a2) will be provided as parameters.
- The output y[n] should be calculated using the formula:
  y[n] = b0*x[n] + b1*x[n-1] - a1*y[n-1] - a2*y[n-2]
- The circuit should respond to clock and reset signals.
