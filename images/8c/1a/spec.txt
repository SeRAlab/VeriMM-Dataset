Design a 16-bit adder/subtractor circuit that performs addition or subtraction based on the control input `sub`. When `sub` is 0, the circuit outputs the sum of inputs `a` and `b`. When `sub` is 1, it computes the difference by subtracting `b` from `a`. The module also outputs a carry flag `carry_out`, which indicates an overflow in addition, and a borrow flag `borrow_out`, which signifies an underflow during subtraction when `b` is greater than `a`.
module top_module(
    input [15:0] a,
    input [15:0] b,
    input sub,
    output [15:0] result,
    output carry_out,
    output borrow_out
);
