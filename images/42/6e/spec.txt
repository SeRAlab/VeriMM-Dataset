Design a four-bit binary adder that computes the sum of two four-bit inputs, A and B, along with a carry-in input, C_in. The module produces a four-bit sum output, S, and a carry-out output, C_out. It utilizes intermediate carry signals to handle the addition of the carry-in correctly, ensuring that if there is an overflow, it is reflected in the carry-out.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input C_in,
  output [3:0] S,
  output C_out
);
