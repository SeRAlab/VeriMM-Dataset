Implement the Verilog module based on the following description.
Design a Verilog module that implements a 12-bit binary counter with enable and synchronous reset. The counter should increment on the rising edge of the clock when the enable (en) signal is high. When the synchronous reset (sreset) is high, the counter should reset to 0. The counter value should be output to the "count" signal.

module binary_counter
(
    input clk,
    input sreset,
    input en,
    output reg [11:0] count
);
