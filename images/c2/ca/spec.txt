
You are tasked with designing a module that takes in a 4-bit binary input `data_in` and outputs a 4-bit binary output `data_out`. The output should be the inverse of the input, i.e. if the input is `1010`, the output should be `0101`. You should also include a control input `enable` which, when high, enables the module to perform the inversion operation. When `enable` is low, the output should be the same as the input. The module should be named `inv_module` and should be written in Verilog within 200 lines of code.
