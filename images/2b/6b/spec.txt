Design a simple state machine for a robot in a SLAM system that operates in three states: IDLE, NAVIGATING, and MAPPING. The robot can transition between these states based on the input signals. The state transitions are as follows: 
- From IDLE, if the start signal is high, transition to NAVIGATING.
- From NAVIGATING, if the map signal is high, transition to MAPPING.
- From MAPPING, if the stop signal is high, transition back to IDLE.
The current state will be output as a 2-bit value (00 for IDLE, 01 for NAVIGATING, 10 for MAPPING).
