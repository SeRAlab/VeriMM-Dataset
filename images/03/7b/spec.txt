
Design a 3rd-order Butterworth filter using combinational logic. The filter has three input signals (x0, x1, x2) and produces one output signal (y). The output y is calculated as a weighted sum of the input signals. The weights are defined as follows: 
- w0 = 1
- w1 = 2
- w2 = 1

The output equation will be: 
y = (w0 * x0 + w1 * x1 + w2 * x2) / (w0 + w1 + w2)
