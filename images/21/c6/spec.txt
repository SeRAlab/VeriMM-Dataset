
Design a clock-gating enabled flip-flop in Verilog. The flip-flop should have a data input (D), a clock input (CLK), a reset input (RST), and a clock gating control input (CG). When CG is high, the flip-flop should behave normally, capturing the data input D on the rising edge of CLK when RST is low. When CG is low, the flip-flop output should hold its previous state regardless of the CLK input.
