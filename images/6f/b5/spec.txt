Design a register that captures and stores an N-bit wide input signal on the rising edge of a clock. If the clear signal is asserted, the output is reset to zero. If the hold signal is asserted, the output retains its previous value. Otherwise, the register updates its output with the input value.
module top_module(
	input clk,
	input clear,
	input hold,
	input wire [N-1:0] in,
	output reg [N-1:0] out);
