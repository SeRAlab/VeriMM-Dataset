

You are tasked with designing a Verilog module that implements a register with enable, clear, and preset functionalities. The module should have the following input and output ports:

**Input Ports:**
- `clk`: the clock signal
- `ena`: the enable signal
- `d`: the data input
- `clrn`: the clear signal
- `prn`: the preset signal

**Output Ports:**
- `q`: the output data

The module should operate as follows:
- When `ena` is high, the data input `d` should be loaded into the register on the rising edge of the clock signal `clk`.
- When `clrn` is low, the register should be cleared to 0 on the rising edge of the clock signal `clk`.
- When `prn` is low, the register should be preset to 1 on the rising edge of the clock signal `clk`.
- When `ena` is low, the register should hold its current value.

Your task is to implement the Verilog module that meets the above requirements.
