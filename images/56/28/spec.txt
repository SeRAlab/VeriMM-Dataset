Design a circuit that functions as a conditional incrementer for an 8-bit input value. When a clock enable (CE) signal is active and a 9-bit input (process_input) provides a value, if the most significant bit (bit 8) is set (indicating an increment condition), the circuit will increment the lower 8 bits unless the value is 127, in which case it wraps around and outputs 0. If the most significant bit is not set, the output is simply the unchanged lower 8-bit value.
module top_module(input CLK, input CE, input [8:0] process_input, output [7:0] process_output);
