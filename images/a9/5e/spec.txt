Design a positive-edge triggered D flip-flop with asynchronous reset and enable features. When the clock (C) has a rising edge, if the reset (R) signal is high, the output (Q) is immediately set to LOW. If the reset is not asserted and the enable (E) signal is high, the output (Q) is updated to the value of the data input (D). If neither the enable nor reset is active during a clock edge, the output remains unchanged.
