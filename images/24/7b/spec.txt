
Design a 4-bit EEPROM cell with the following specifications: 
- The EEPROM cell has a write enable (WE), a read enable (RE), and a 4-bit data input (D).
- On a positive edge of WE, the data input (D) should be stored in the EEPROM cell.
- On a positive edge of RE, the stored data should be output to a 4-bit output (Q).
- The EEPROM cell should maintain its state until it is written again.
