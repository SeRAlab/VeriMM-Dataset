Design a 4-bit SRAM cell with read and write functionality. The SRAM cell should have inputs for data (4 bits), a write enable signal, a read enable signal, and an output for the stored data (4 bits). When the write enable signal is high, the data should be written to the cell. When the read enable signal is high, the stored data should be output. If both read and write are enabled at the same time, prioritize write functionality.
