Design a 4-bit up/down counter that changes its output value based on a control signal. On a rising clock edge, if the reset signal is asserted, the counter resets to zero. If the control signal is high, the counter increments until it reaches its maximum value (15), at which point it wraps around to zero. Conversely, if the control signal is low, the counter decrements until it reaches zero, after which it wraps around to its maximum value (15).
