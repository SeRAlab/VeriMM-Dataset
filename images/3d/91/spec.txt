
Design a state-space controller for a discrete-time system. The system has two state variables, x1 and x2, and the control input is u. The system dynamics are given by the equations:
x1_next = a11 * x1 + a12 * x2 + b1 * u
x2_next = a21 * x1 + a22 * x2 + b2 * u
where a11, a12, a21, a22, b1, and b2 are constants. Implement a Verilog module that takes the current state (x1, x2) and the control input (u), and outputs the next state (x1_next, x2_next).
