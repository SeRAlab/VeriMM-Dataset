Design a binary counter that increments its value on each positive clock edge when the enable signal is HIGH. The counter resets to zero when the reset signal is asserted. It is parameterized to support a variable bit width, specified by the parameter \( n \), defaulting to 4 bits.
module top_module(
    input clk,
    input reset,
    input enable,
    output reg [n-1:0] count
);
