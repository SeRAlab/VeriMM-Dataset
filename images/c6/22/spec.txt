

You have been tasked with designing a verilog module that implements a 4-input AND gate. The module should have the following inputs and outputs:

Inputs:
- A1 (1-bit)
- A2 (1-bit)
- A3 (1-bit)
- A4 (1-bit)

Outputs:
- X (1-bit)

The module should be named "and_gate" and should be designed using structural verilog. You are only allowed to use basic logic gates (AND, OR, NOT, etc.) and not any pre-existing modules.
