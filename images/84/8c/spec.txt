Design a seven-segment display controller that shows specific outputs based on a 3-bit state input and an active reset signal. When reset is high, the display outputs a default pattern for all states. When reset is low, the display outputs different patterns corresponding to the values of the state input, allowing for the visualization of the state through 8 bits dedicated to driving the segments of the display. The circuit defaults to turning all segments off if the input does not match any defined case.
module top_module(
    input [2:0] state,
    input reset,
    output reg [7:0] display
);
