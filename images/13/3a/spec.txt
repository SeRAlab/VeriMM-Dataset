
Create a Verilog module that implements a simple Dynamic Voltage and Frequency Scaling (DVFS) controller. The controller has a clock input, a reset input, and a voltage level input. Based on the voltage level, the controller should adjust the frequency of an output clock signal. The frequency should be set to one of three levels based on the voltage input: 
- 1.0V → 200MHz 
- 0.9V → 150MHz
- 0.8V → 100MHz
If the reset input is high, the output frequency should default to 200MHz.
