Design a priority encoder for an 8-bit input. The module reads an 8-bit binary input and outputs a 3-bit binary code representing the highest-priority active input bit, with priority given to the higher indices. The output `EN` indicates whether any input bit is active (non-zero). The output code is registered and updated on the rising edge of the clock, allowing for synchronized operation.
