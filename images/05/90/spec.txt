
Design a 16-bit DRAM cell that can store data and provide read and write operations. The DRAM cell should have the following input and output:
- Inputs: 
  - `clk` (clock signal)
  - `we` (write enable signal, active high)
  - `data_in` (16-bit data input)
  - `addr` (4-bit address input, selecting one of 16 memory cells)
- Outputs:
  - `data_out` (16-bit data output)
