

You are tasked with designing a Verilog module that implements a 4-bit counter which counts up on the positive edge of a clock signal. The counter should have a synchronous reset input which sets the counter to 0 when asserted. Additionally, the module should have an enable signal which, when high, allows the counter to increment, and when low, stops the counter from incrementing.

Your module should be named `counter` and should have the following ports:
- `clk` (input): a clock signal
- `reset` (input): a synchronous reset signal
- `en` (input): an enable signal
- `count` (output): a 4-bit output representing the current count value

Assume that the clock signal has a frequency of 50 MHz.
