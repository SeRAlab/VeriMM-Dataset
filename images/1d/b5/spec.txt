Design a second-order IIR filter using Verilog. The filter should take two input signals, x and y, and produce an output signal z. The filter coefficients should be defined as parameters, and the filter should implement the following difference equation: z[n] = a0*x[n] + a1*x[n-1] + a2*x[n-2] - b1*z[n-1] - b2*z[n-2], where a0, a1, a2, b1, and b2 are the filter coefficients.
