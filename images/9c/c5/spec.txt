Design a D flip-flop with asynchronous reset and set functionalities. On the rising edge of the clock, if the reset signal is asserted, the output q is cleared to 0. If the set signal is asserted instead, q is set to 1. If neither control signal is active, the output q takes the value of the data input d, thus capturing its state on the clock edge.
module top_module(
    input clk,
    input rst,
    input set,
    input d,
    output reg q
);
