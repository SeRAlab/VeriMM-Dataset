Design a 2-to-1 multiplexer for two separate data buses. The module selects the output for BUS_A based on the input signal MA: if MA is high, BUS_A outputs the value of PC_M1; if MA is low, BUS_A outputs A_DATA. Similarly, the output for BUS_B is determined by MB: if MB is high, BUS_B outputs SEorZF; if MB is low, BUS_B outputs B_DATA. This module effectively routes different data inputs to the appropriate output buses based on control signals.
module top_module(
	input [31:0] PC_M1,
	input [31:0] A_DATA,
	input [31:0] B_DATA,
	input [31:0] SEorZF,
	input        MA,
	input			 MB,
	output[31:0] BUS_A,
	output[31:0] BUS_B
    );
