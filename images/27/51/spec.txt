Design a Parallel-In Parallel-Out (PIPO) shift register in Verilog. The shift register should be able to load data in parallel, shift data out, and store data on a clock edge. It should have the following ports: 
- `clk` for clock input
- `load` for loading data into the register
- `data_in` for the input data (5 bits)
- `data_out` for the output data (5 bits)
- `reset` for resetting the register.
