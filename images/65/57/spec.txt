Design a decoder module that extracts various components from a 16-bit instruction input. This module outputs a 4-bit opcode, two 4-bit register designations (rs and rt), an additional 4-bit register designation (rd), an 8-bit immediate value, and a 9-bit offset. It also determines control signals for memory write enable (writem_en), register write enable (writer_en), and a halt condition. The outputs are based on specific fields within the instruction, enabling the execution of operations determined by the opcode and handling different conditions based on the instruction format.
module top_module(instruction, opcode, rs, rt, rd, immediate_8bit, 
                offset_9bit, condition, writem_en, writer_en, halt);
