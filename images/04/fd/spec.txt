Design a Verilog module that implements a simple Kalman filter for sensor fusion. The module should take in noisy measurements from two sensors and output a filtered estimate of the true state. The Kalman filter should maintain its state across clock cycles and have the following inputs: 
- Measurement from sensor 1 (input1), 
- Measurement from sensor 2 (input2), 
- Control input (control),
- Clock (clk),
- Reset (reset).

The output should be the estimated state (output_estimate). The filter should also include parameters for the process noise covariance (Q) and measurement noise covariance (R), which can be set as parameters in the module.
