Design a dual-function D flip-flop with active-low reset and set inputs. The module captures the value of the input D on the rising edge of the clock (CLK) unless the reset (RESET) is activated, forcing the output (Q) to LOW, or the set (SET) is activated, forcing the output to HIGH. The output is inverted before being assigned to ensure the final output reflects the desired logic state.
module top_module(
    input D,
    input RESET,
    input SET,
    input CLK,
    output Q
);
