
Design a combinational logic circuit that computes the inverse of a 2x2 matrix. The input will be a 2x2 matrix represented as four 8-bit unsigned integers (a, b, c, d) and the output will be the elements of the inverted matrix, also as four 8-bit unsigned integers (e, f, g, h). The matrix inversion formula for a 2x2 matrix is:
```
| a b |
| c d |
```
Inverted matrix:
```
|  d/(ad-bc)  -b/(ad-bc) |
| -c/(ad-bc)   a/(ad-bc)  |
```
If the determinant (ad-bc) is zero, the inversion should be indicated by outputting zeroes.
