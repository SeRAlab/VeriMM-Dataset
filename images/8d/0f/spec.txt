Design a circuit for edge detection that operates on a 10-bit input signal. It compares the current input data with the previously sampled data, calculates the difference, and produces an output. If the difference exceeds a specified threshold, the output is set to the maximum 10-bit value (10'h3FF); otherwise, it outputs zero. The module is synchronous and resets the previous data and output when the reset signal is activated.
module top_module(
  input wire clk,
  input wire rst,
  input wire [9:0] in_data,
  input wire [3:0] threshold,
  output reg [9:0] out_data
);
