Design a circuit that functions as a combination of a 4-to-2 priority encoder and a 4-bit magnitude comparator. The module takes two 4-bit inputs, A and B, and produces a 2-bit output, Y, representing the highest priority input (based on its value), along with an output V indicating if the highest input is zero. Additionally, it provides signals for equality and comparison (greater). The module also performs bitwise AND and OR operations on the outputs, yielding a final result output that encapsulates the state of Y and the comparison outcomes.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output [1:0] Y,
    output V,
    output equal,
    output greater,
    output result
);
