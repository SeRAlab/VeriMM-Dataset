Design a 4-bit Gray code converter that translates a 4-bit binary input to its corresponding Gray code output when the select input is high. When the select input is low, the output simply reflects the binary input. The Gray code is computed by using bitwise XOR operations between consecutive bits of the binary input. This module allows for dynamic conversion between binary and Gray code representations based on the select signal.
module top_module(
    input [3:0] binary_in,
    input select,
    output reg [3:0] gray_out  // Change from wire to reg
);
