Design an 8-bit Arithmetic Logic Unit (ALU) that performs three fundamental operations: addition, bitwise AND, and a comparison operation. The unit computes the sum of two 8-bit inputs, produces the bitwise AND of the same inputs, and evaluates whether the first input is zero, outputting a binary representation of the comparison result. Specifically, when the first input is zero, it outputs a logic high (1), otherwise, it outputs a logic low (0).
module top_module(
    input [7:0] input_x,
    input [7:0] input_y,
    output [7:0] output_sum,
    output [7:0] output_and,
    output [7:0] output_cmp
    );
