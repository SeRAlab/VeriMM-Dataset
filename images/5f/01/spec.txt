Design a synchronous FIFO (First-In, First-Out) buffer with a configurable width and depth. This module enables data to be written to and read from the buffer using separate control signals for reading (rd) and writing (wr). The output data (output_data) corresponds to the data currently at the front of the queue determined by a read pointer (rd_ptr). The module also includes status signals: 'empty' indicates when there is no data to read, and 'full' signifies that the buffer cannot accept more data. Resetting the module initializes both pointers and clears the output data. The FIFO operates on a clock signal, ensuring data integrity during reads and writes.
