Design a 8-bit shift register with control functionality. The module captures a new bit from the `data_in` input on each positive clock edge, shifting existing bits to the left. If the `reset` signal is activated, the shift register is cleared to all zeros. Alternatively, if the `clear` signal is asserted, the register is set to all ones. The current state of the shift register is continuously outputted through `data_out`.
module top_module(
  input clk,
  input reset,
  input clear,
  input [7:0] data_in,
  output [7:0] data_out
);
