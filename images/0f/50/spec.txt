Design a JK-latch in Verilog. The JK-latch should have inputs J, K, and a clock signal, as well as an output Q. The behavior of the JK-latch should follow the standard operation rules: if J and K are both low, Q remains unchanged; if J is high and K is low, Q is set to high; if J is low and K is high, Q is set to low; if J and K are both high, Q toggles. The output Q should be updated on the positive edge of the clock signal.
