Design a state-space controller for a discrete-time system that takes a 2-bit input representing the current state of the system and produces a 2-bit output representing the next state. The state transition is defined by the following rules:
- If the input state is 00, the next state will be 01.
- If the input state is 01, the next state will be 10.
- If the input state is 10, the next state will be 11.
- If the input state is 11, the next state will be 00.
