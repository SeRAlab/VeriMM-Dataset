Design a 4-bit binary to Gray code converter with an enable signal. When the enable (EN) input is asserted, the module converts the 4-bit binary input (B) into its corresponding Gray code output (G) through a sequential process. The conversion is accomplished in stages, with intermediate results stored in registers. When EN is deasserted, G maintains its last value. Upon each rising edge of the enable signal, the module updates its internal registers to perform the necessary bitwise operations for the conversion.
module top_module(
    input [3:0] B,
    input EN,
    output [3:0] G
);
