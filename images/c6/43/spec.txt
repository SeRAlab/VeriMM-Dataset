

You are tasked with designing a module that takes four inputs: A1, A2, A3, and B1, and produces one output, Y. The module should be named "four_input_module". The output Y is generated based on the following logic:

- If A1, A2, and A3 are all high (1), then Y should be high (1).
- If B1 is high (1), then Y should be low (0).
- If A1, A2, and A3 are not all high (1), and B1 is low (0), then Y should be high (1).

You will need to declare the inputs and output, and use the appropriate logical operators to implement the above logic. You can assume that the inputs A1, A2, A3, and B1 are all single bit signals.
