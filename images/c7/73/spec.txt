

You are hired by a company to design a verilog module that implements a 2-to-1 multiplexer. The module should have two input signals, one select signal, and one output signal. The output signal should be equal to the first input signal if the select signal is 0, and equal to the second input signal if the select signal is 1. 

Design a verilog module that implements this 2-to-1 multiplexer. Your module should be named "mux2to1" and should have the following ports:

- input a (1-bit)
- input b (1-bit)
- input sel (1-bit)
- output y (1-bit)

You should use the "always" block to implement the logic for the output signal.
