
Design a 16-bit DRAM cell that can store a single bit of data. The DRAM cell should have an input signal for data (D), a write enable signal (WE), a read enable signal (RE), and a clock signal (CLK). On the rising edge of the clock, if WE is high, the data (D) should be stored in the DRAM cell. If RE is high, the stored data should be outputted.
