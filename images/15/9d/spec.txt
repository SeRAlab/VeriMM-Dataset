Design a simple UART controller that transmits data serially at a fixed baud rate. The UART should have an input data line (data_in), a clock line (clk), a transmit enable line (tx_en), and a serial output line (tx_serial). The UART controller should transmit the data when tx_en is asserted. The transmitted data should be sent one bit at a time, starting with the least significant bit (LSB), followed by a stop bit. The baud rate should be set such that it allows for a specific number of clock cycles per bit.
