Design a Verilog module that implements a simple 2D Discrete Wavelet Transform (DWT) for a 2x2 input matrix. The output should consist of four coefficients: LL, LH, HL, and HH. The input matrix will be represented as a 4-bit wide signal, where the first two bits correspond to the first row and the last two bits correspond to the second row. The coefficients should be computed using the Haar wavelet transformation.
