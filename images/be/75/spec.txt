Design a circuit that concatenates two 16-bit input signals into a 32-bit output. When the selection signal 'sel' is high, the output will be formed by placing the second input (in2) in the upper 16 bits followed by zeros, and the first input (in1) in the lower 16 bits. When 'sel' is low, the output will contain the first input (in1) in the upper 16 bits, followed by zeros, and the second input (in2) in the lower 16 bits.
module top_module(
    input wire [15:0] in1,
    input wire [15:0] in2,
    input wire sel,
    output wire [31:0] out
);
