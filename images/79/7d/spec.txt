Design a 4-bit shift register that can either load new data or perform a single bit shift based on the shift control signal. When the shift signal is low (0), the register captures the input data_in. When the shift signal is high (1), the register shifts its current value left, with the most significant bit (MSB) determining whether to insert a 0 or retain the MSB on the right end. The shifted or loaded value is provided at the output data_out.
module top_module(
  input [3:0] data_in,
  input shift,
  output [3:0] data_out
);
