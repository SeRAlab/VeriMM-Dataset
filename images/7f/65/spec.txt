Design a comparator module that compares two n-bit signed integers. It generates three output signals: `gt`, which indicates if the first input is greater than the second; `eq`, which signals if both inputs are equal; and `lt`, which shows if the first input is less than the second. The parameter `n` allows for configuring the bit-width of the inputs, which defaults to 4 bits.
module top_module(
  input [n-1:0] a,
  input [n-1:0] b,
  output gt,
  output eq,
  output lt
);
