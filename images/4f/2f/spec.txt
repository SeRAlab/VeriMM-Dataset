Design a clock gating circuit that generates an output clock signal (enclk) based on an input enable signal (en). When the input clock (clk) has a positive edge, if the enable signal is high, the output enclk is set to high; otherwise, it is set to low. This effectively controls the propagation of the clock signal, allowing it to be enabled or disabled based on the status of the enable input.
module top_module(
  input clk,
  input en,
  output reg enclk
);
