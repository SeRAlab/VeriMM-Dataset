
Design a 4-bit SRAM cell that can store and retrieve data. The SRAM cell should have the following functionalities:
- Input data (4 bits) to be written into the cell.
- A write enable signal that, when high, allows data to be written to the cell.
- A read enable signal that, when high, allows data to be read from the cell.
- The output should reflect the stored data when the read enable signal is high.
