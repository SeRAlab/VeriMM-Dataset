Design a 16-bit Linear Feedback Shift Register (LFSR) in Verilog. The LFSR should have an initial seed value loaded with a parallel load signal and should shift on every clock cycle. The feedback polynomial to be used is defined as x^16 + x^14 + x^13 + x^11 + 1. Implement a module that outputs the current value of the LFSR after each clock cycle.
