
Design a Verilog module that implements a simple logistic regression classifier. The module should take three 8-bit inputs representing features (x1, x2, x3) and produce a single-bit output (y) which indicates the class label (0 or 1). The logistic regression model should be defined with weights (w1, w2, w3) initialized to fixed values. The output should be calculated using the sigmoid function as follows: 

y = sigmoid(w1*x1 + w2*x2 + w3*x3)

The weights can be defined as:
- w1 = 0.5
- w2 = -0.5
- w3 = 1.0

The sigmoid function can be approximated using the expression:

sigmoid(z) = 1 / (1 + exp(-z))
