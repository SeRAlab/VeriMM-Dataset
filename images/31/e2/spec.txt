
Design a second-order Infinite Impulse Response (IIR) filter in Verilog. The IIR filter should have a single input and a single output, where the output is computed using the following difference equation:
y[n] = b0 * x[n] + b1 * x[n-1] - a1 * y[n-1] - a2 * y[n-2]
where x[n] is the current input, y[n] is the current output, and b0, b1, a1, a2 are the filter coefficients. The coefficients are fixed values defined within the module. The module should have a clock input to trigger the computation.
