A T-latch is a memory device that operates based on a toggle input. When the T input is high (1), the output toggles between 0 and 1 on every clock pulse. If the T input is low (0), the output remains the same. Create a Verilog model for a T-latch with a clock input and a T input. The output should be stored in a D flip-flop style, where the output changes on the rising edge of the clock based on the T input.
