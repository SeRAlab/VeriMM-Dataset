
Design a 24-bit ADC (Analog-to-Digital Converter) output decoder that takes a 24-bit input and outputs a 4-bit binary value indicating the range of the input signal. The ranges are defined as follows:
- 0-15: Output 0000
- 16-31: Output 0001
- 32-47: Output 0010
- 48-63: Output 0011
- 64-79: Output 0100
- 80-95: Output 0101
- 96-111: Output 0110
- 112-127: Output 0111
- 128-143: Output 1000
- 144-159: Output 1001
- 160-175: Output 1010
- 176-191: Output 1011
- 192-207: Output 1100
- 208-223: Output 1101
- 224-239: Output 1110
- 240-255: Output 1111
For inputs greater than 255, the output should be 1111.
