
Design a 4-bit SRAM cell with the following specifications:
- It should have an input data line (D) and a control line (WE) for writing data.
- It should also have a read enable line (RE) for reading data.
- When WE is low, the data on line D should be written to the SRAM cell.
- When RE is low, the data from the SRAM cell should be output on a data line (Q).
