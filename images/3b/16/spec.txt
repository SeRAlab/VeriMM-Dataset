Design a 1-bit SR flip-flop with asynchronous reset and set. The flip-flop should have inputs S (Set), R (Reset), and a clock signal clk. The outputs should be Q and Qn (not Q). When S is high, Q should be set to 1. When R is high, Q should be reset to 0. If both S and R are low, Q should follow the clock. If the reset and set are both high, the behavior is considered indeterminate.
