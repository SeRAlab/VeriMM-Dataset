
Design a state-space controller in Verilog that implements a simple state feedback control system. The controller should have a state vector of size 2, an input vector of size 1, and an output vector of size 1. The state transition and output equations are as follows:
- x_next = A * x + B * u
- y = C * x + D * u
Where A, B, C, and D are defined as:
A = [[0.5, 0.1], [0, 0.9]]
B = [[1], [0]]
C = [[1, 0]]
D = [[0]]
The module should accept the current state and input, and output the next state and output.
