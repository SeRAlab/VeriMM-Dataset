

You are tasked with designing a module that takes in two 4-bit binary inputs, A and B, and outputs the result of XOR operation of each corresponding bit of A and B. The module should be named "xor4" and should be contained within 200 lines of Verilog code. 

The module should have the following ports:
- A: a 4-bit binary input
- B: a 4-bit binary input
- X: a 4-bit binary output representing the result of the XOR operation of A and B

Your task is to implement this module in Verilog. You may assume that the inputs A and B will always be 4-bit binary numbers.
