
Design a PCIe interface state machine in Verilog that manages three states: IDLE, ACTIVE, and ERROR. The state machine should transition based on two inputs: 'start' and 'error'. The 'start' input moves the state from IDLE to ACTIVE, while the 'error' input moves the state to ERROR. The state should return to IDLE if an error occurs and the 'reset' signal is asserted.
