
Design a Watchdog Timer in Verilog. The timer should have an input for a reset signal, an enable signal, and a clock. If the timer is enabled and the reset signal is not asserted, it counts clock cycles. If the timer reaches a specified limit (for example, 10 clock cycles), it should output a "timeout" signal. If the reset signal is asserted before the timer reaches the limit, the timer should reset to 0.
