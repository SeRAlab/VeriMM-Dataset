Design a 4-bit adder/subtractor that performs either addition or subtraction based on a mode input. When mode is 0, the module computes the sum of two 4-bit inputs, A and B. When mode is 1, it computes the difference A - B by utilizing the two's complement of B. The module outputs a 4-bit result and signals for carry-out (COUT) and borrow-out (BOUT), indicating the operation's overflow or underflow respectively.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input mode,
  output [3:0] Y,
  output COUT,
  output BOUT
);
