Design a simple Ethernet MAC controller that processes incoming frames and checks if the frame is valid based on the frame length. The controller should have a reset signal, a clock signal, an input for frame data, an input for frame length, and an output signal indicating if the frame is valid. The valid frame length should be between 64 and 1518 bytes (inclusive). If the reset signal is high, the output should be low regardless of the frame data or length.
