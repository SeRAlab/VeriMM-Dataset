Design an 8-to-3 priority encoder in Verilog. The encoder should take 8 input lines (from `in[7:0]`) and output a 3-bit binary representation (to `out[2:0]`) of the highest priority input line that is asserted (1). If no input is asserted, the output should be `3'b000`. The priority should be from `in[7]` (highest) to `in[0]` (lowest).
