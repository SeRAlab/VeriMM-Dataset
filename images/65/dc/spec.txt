Design a D flip-flop with asynchronous reset and two control signals. The flip-flop captures the value of input D on the rising edge of the CLK when SCE is high, allowing the output Q to follow D. If SCD is high, the output Q directly receives the value of D. When RESET_B is asserted (high), it asynchronously clears the output Q to low. If SCE is low, the flip-flop holds its current state regardless of D. This design allows versatility in controlling the output based on the input conditions.
