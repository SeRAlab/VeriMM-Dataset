Design a Verilog module that performs matrix inversion for a 2x2 matrix. The input will be a 2x2 matrix represented as four 8-bit inputs (a, b, c, d) and the output will be the inverted matrix represented as four 8-bit outputs (a_inv, b_inv, c_inv, d_inv). The inversion is defined as:
If M = | a b |
         | c d |
Then M^-1 = (1/det(M)) * | d -b |
                           | -c a |
Where det(M) = ad - bc. If the determinant is zero, the output should be set to zero. This module should be combinational logic, meaning the output should depend only on the current inputs.
