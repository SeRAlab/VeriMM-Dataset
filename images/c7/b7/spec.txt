

You are tasked to design a verilog module that acts as a 2-bit comparator. The module should have two 2-bit inputs A and B, and an output signal EQ which is high if the two inputs are equal. The module should have the following interface:

```verilog
module comparator_2bit(
    input [1:0] A,
    input [1:0] B,
    output reg EQ
);
```

You should use the following verilog operators to implement the comparator:
- "==" : equal to operator
- "&" : bitwise and operator
- "~" : bitwise negation operator
