Design a 4-bit adder circuit with overflow detection and an enable signal. When the enable input is high, the module computes the sum of two 4-bit inputs, A and B. If the sum exceeds the maximum value for 4 bits (i.e., 15), it sets the overflow output to high and resets the sum to zero. If the enable input is low, the sum and overflow outputs are both reset to zero.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input enable,
  output reg [3:0] sum,
  output reg overflow
);
