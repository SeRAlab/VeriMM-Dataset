Design a multi-threaded register file that supports simultaneous read and write operations for up to 128 32-bit registers. The module has two read ports and one write port, capable of handling different threads identified by a 2-bit thread input. When reading, it selects output data based on the specified register address and thread, returning data while providing the ability to read from a special zero register when a zero address is specified. On the positive edge of the clock, the module updates the register file with new data from the write port if the write enable signal is asserted, and it accommodates writing to different register banks based on the thread identifier. This design is essential for architectures that require context switching and thread management, such as in modern CPUs or FPGAs.
