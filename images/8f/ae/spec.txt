Implement the Verilog module based on the following description. Create a module that acts as a debouncer for a button input. The module should have a clock input "clk", a button input "button", and an output "debounced". The debounced output should go high only if the button has been held down for 4 consecutive clock cycles.
module debouncer(
    input clk,
    input button,
    output debounced);
