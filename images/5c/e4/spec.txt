Design a 4-bit left shifter that shifts the input value left by a specified number of bits, determined by a 2-bit shift control input. The output reflects the input being shifted left, resulting in zero-padding on the right for each shift. Specifically, if the shift value is 0, the output matches the input; for a shift of 1, the least significant bit is replaced with 0 and the others are shifted left accordingly, and similarly for shifts of 2 and 3.
module top_module(
    input [3:0] in,   // value to be shifted
    input [1:0] shift, // number of bits to shift
    output [3:0] out  // output
);
