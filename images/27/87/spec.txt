
Design a simple branch predictor using a 2-bit saturating counter. The predictor should take a 2-bit input representing the current state of the branch (00: Strongly Not Taken, 01: Weakly Not Taken, 10: Weakly Taken, 11: Strongly Taken) and a single input representing the outcome of the branch (0 for Not Taken, 1 for Taken). Based on the outcome, the state should be updated accordingly.
