Design a basic arithmetic calculator that performs operations on two 8-bit input numbers based on a 2-bit operation code (opcode). The operations include addition, subtraction, multiplication, and division, selectable via the opcode: 00 for addition, 01 for subtraction, 10 for multiplication, and 11 for division. The result of the selected operation is output as an 8-bit number.
module top_module(
    input wire [7:0] num1,
    input wire [7:0] num2,
    input wire [1:0] opcode,
    output reg [7:0] result
);
