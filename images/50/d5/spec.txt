Design a 4-bit barrel shifter that can perform both left and right shifts based on the value of a mode signal. The module takes a 4-bit input (data_in) and a 2-bit shift_amount to determine how many positions to shift. When the mode is set to 0, the input is shifted to the right; when the mode is set to 1, it is shifted to the left. The output (data_out) reflects the result of the shift operation on the rising edge of the mode signal.
module top_module(
    input [3:0] data_in,
    input [1:0] shift_amount,
    input mode,
    output reg [3:0] data_out
);
