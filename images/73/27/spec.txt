Design a synchronous decrementing counter module that operates on a rising clock edge. The counter decrements its value by a predefined constant (DECREMENT_VALUE) when enabled, using a specified input (input_value) as its starting point. If the reset signal is high, the counter is set to zero. The current value of the counter is made available at the output (output_value). The counter is parameterizable for different bit widths, allowing for versatility in its application.
