Design a multiplexing circuit that selects one of six 4-bit input data lines based on a 3-bit selection signal. The selected 4-bit data line is then used to compute a 4-bit output, which consists of the lower 2 bits obtained by subtracting the upper 2 bits of the selected input data from its lower 2 bits, combined with the original upper 2 bits. Additionally, the circuit calculates the parity of this output, indicating whether the total number of ones in the output is even or odd.
module top_module(
  input [2:0] sel,
  input [3:0] data0,
  input [3:0] data1,
  input [3:0] data2,
  input [3:0] data3,
  input [3:0] data4,
  input [3:0] data5,
  output reg [3:0] out,
  output reg parity
);
