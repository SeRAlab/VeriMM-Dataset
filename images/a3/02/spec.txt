Design a circuit that functions as a 4-bit adder/subtractor. This module takes two 4-bit inputs, A and B, and a control signal, sub, to determine the operation: when sub is low, it performs addition (A + B), and when sub is high, it performs subtraction (A - B). The output, Y, holds the result and is updated on the rising edge of the clock, while also allowing for a synchronous clear operation that resets the output to zero when the clr signal is asserted.
module top_module(
    input        clk,
    input        clr,
    input  [3:0] A,
    input  [3:0] B,
    input        sub,
    output [3:0] Y
);
