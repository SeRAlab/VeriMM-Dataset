Design a data memory module that interfaces with a clock and control signals for read and write operations. The module utilizes a 64-byte RAM array to store data, and on a read operation (when nRD is low), it outputs 32 bits of data from a specified address, providing the data in little-endian format. On a negative clock edge, if the write control signal (nWR) is inactive (low), it writes 32 bits of input data (DataIn) to consecutive addresses in the RAM, also in little-endian format. This module effectively acts as a read/write data memory interface for a larger system.
