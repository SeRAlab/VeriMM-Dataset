Design a linear voltage regulator that takes a 5-bit binary input representing a desired voltage level and generates a corresponding output voltage level. The output voltage should be limited to a maximum of 31 (for a 5-bit input), and if the input exceeds this value, the output should remain at 31. The output should also be inverted, meaning if the input is 0, the output should be 31, and if the input is 31, the output should be 0.
