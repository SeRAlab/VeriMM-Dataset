

You are tasked with designing a module that takes in a 32-bit input signal and outputs a 32-bit signal which is the result of XORing the input signal with a constant 32-bit signal. The module should be named `xor_const` and should have the following ports:

- `input [31:0] in` : 32-bit input signal
- `output [31:0] out` : 32-bit output signal

The constant signal to be XORed with the input signal is 0xAAAAAAAA. You should use a parameter to define this constant.

Write the verilog code for the `xor_const` module and ensure that it can be synthesized without any errors.
