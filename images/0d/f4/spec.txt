
You are to design a simple interrupt controller that takes multiple interrupt requests (IRQ) and outputs a single interrupt acknowledge signal (ACK). The controller should prioritize the highest priority interrupt request. The design should include a 4-bit input for the IRQs, where each bit represents a different interrupt request. The highest priority interrupt is represented by the least significant bit (LSB). The output should be a single bit indicating which interrupt has been acknowledged. The controller should reset when a reset signal is received.
