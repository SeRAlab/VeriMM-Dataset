Design a NAND gate with a clear function. The circuit takes two inputs, A and B, and produces a NAND output. However, if the CLR signal is asserted (active), the output Y is forced to LOW, and the output Yn is forced to HIGH. When CLR is not active, Y outputs the NAND result of A and B, while Yn outputs the inverted NAND result.
module top_module(
  input A,
  input B,
  input CLR,
  output Y,
  output Yn
);
