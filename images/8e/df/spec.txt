Design a circuit that functions as a 4-bit adder/subtractor with synchronous reset. It takes two 4-bit inputs, A and B, and a control signal, sub, to determine the operation: when sub=0, it performs addition (A + B), and when sub=1, it performs subtraction (A - B). The output is updated on the rising edge of the clock and reset to zero when the reset signal is low.
module top_module(
  input clk,
  input reset,
  input [3:0] A,
  input [3:0] B,
  input sub,
  output reg [3:0] out
);
