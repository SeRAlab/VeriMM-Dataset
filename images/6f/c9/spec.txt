Implement the Verilog module based on the following description.
We want to create a module that:

// (1) receives a 5-bit binary number,
// (2) checks if the number is less than or equal to 10,
// (3) counts the number of 0s in the binary number,
// (4) outputs a flag if the number is a perfect square,
// (5) provides a reset mechanism to reset all outputs.

// The input binary number is available on the input signal 'binary_num'. The output 'is_lte10' should be set to 1 if the number is less than or equal to 10 and 0 otherwise. The number of 0s in the binary number should be output on 'count_zeros[3:0]'. The perfect square flag should be set on 'is_perfect_square' if the number is a perfect square. The reset signal is active high synchronous.

module top_module(
    input wire clk,
    input wire reset,
    input wire [4:0] binary_num,
    output reg is_lte10,
    output reg [3:0] count_zeros,
    output reg is_perfect_square
);
