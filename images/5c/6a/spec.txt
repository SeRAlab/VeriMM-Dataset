Design a 4-bit wide bitwise calculator that performs various logical operations on two 4-bit inputs, A and B. The operation is determined by a 2-bit control signal, C, and an additional single-bit control signal, D. Specifically, when C is '00', if D is '1', it computes the bitwise NOR of A and B; if D is '0', it computes the bitwise NAND. When C is '01', if D is '1', it performs the bitwise OR; if D is '0', it carries out the bitwise AND operation. The output is a 4-bit result reflecting the chosen operation.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input [1:0] C,
    input D,
    output reg [3:0] out
);
