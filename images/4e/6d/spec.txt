Design a circuit that checks the correctness of a received data packet based on even or odd parity. The module takes an n-bit data input and a parity bit. It computes the parity of the data by XORing all bits and compares it to the provided parity bit. If the calculated parity matches the supplied parity, the output indicates no error; otherwise, it signals an error. This design is useful for error detection in digital communication systems.
