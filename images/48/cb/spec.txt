Design a D flip-flop with active-low preset (PREbar) and clear (CLRbar) inputs. The flip-flop captures the input data on the rising edge of the clock signal. If the PREbar input is low, the output (q) is set to high regardless of the clock or data inputs. Conversely, if the CLRbar input is low, the output is reset to low. If both control signals are high, the flip-flop functions normally, holding the data input value. The module also outputs the inverted state (qbar).
