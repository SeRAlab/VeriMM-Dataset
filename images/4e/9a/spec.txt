Design a 5-entry register file with read and write capabilities, controlled by a clock signal. Each of the five entries allows writing data when its respective enable signal (EN_write_X) is asserted. The module reads from each entry simultaneously, outputting the current value of each register. On each rising edge of the clock, the contents of the register are updated based on the most recent write data allowed by the enable signals, making it suitable for applications that require multiple independent registers with controlled access.
module top_module(
    CLK,
    read_0,
    write_0,
    EN_write_0,
    read_1,
    write_1,
    EN_write_1,
    read_2,
    write_2,
    EN_write_2,
    read_3,
    write_3,
    EN_write_3,
    read_4,

    EN_write_4
);
