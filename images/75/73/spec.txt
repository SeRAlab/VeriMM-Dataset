Design a programmable counter that counts from 0 up to a specified maximum value (max_val) and then rolls over to 0. The counter increments its output (out) on each rising edge of the clock signal (clk). If the reset signal is activated, the counter output resets to 0. When the counter reaches its maximum value, it resets back to 0 on the next clock cycle, allowing for repeated counting within the defined range.
module top_module(
    input clk,
    input [7:0] max_val,
    input reset,
    output reg [7:0] out
);
