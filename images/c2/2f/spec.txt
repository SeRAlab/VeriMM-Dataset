

You are tasked with designing a module that implements a D flip-flop with asynchronous set and reset inputs. The module should have the following inputs and outputs:

- `D`: the data input
- `CLK`: the clock input
- `SET_B`: asynchronous set input (active low)
- `RESET_B`: asynchronous reset input (active low)
- `Q`: the output
- `Q_N`: the complement of the output

The module should follow the following behavior:

- When `SET_B` is low, the output `Q` should be set to high and `Q_N` should be set to low, regardless of the state of the clock or data inputs.
- When `RESET_B` is low, the output `Q` should be set to low and `Q_N` should be set to high, regardless of the state of the clock or data inputs.
- When `SET_B` and `RESET_B` are both high, the output `Q` should follow the data input on the rising edge of the clock, and `Q_N` should be the complement of `Q`.

Design a module that meets the above requirements. You may assume that the inputs are glitch-free and that the clock has a 50% duty cycle.
