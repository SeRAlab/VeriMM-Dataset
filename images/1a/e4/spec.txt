
Design a JK latch using Verilog. The latch should have inputs J and K, a clock signal (clk), and an output Q. The latch should maintain its state when the clock is low and only update on the rising edge of the clock according to the following behavior:
- If J=1 and K=0, set Q to 1.
- If J=0 and K=1, set Q to 0.
- If J=1 and K=1, toggle Q.
- If J=0 and K=0, retain the previous state of Q.
