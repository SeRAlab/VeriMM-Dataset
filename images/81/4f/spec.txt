Design a program counter (PC) that updates its stored value on the rising edge of the clock signal. When the reset signal is activated, the program counter will initialize to a specific value (binary '10000000000000000000000'), and when reset is not active, it will take the value from the input PC_next. The module maintains the current program counter value as a 32-bit wide output, providing the functionality to control instruction flow in a digital system.
module top_module(
	input clock,
	input reset,
	input [31:0] PC_next,
	output[31:0] PC
);
