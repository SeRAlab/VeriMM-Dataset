Design a 32-bit program counter (PC) module that updates its value on the rising edge of the clock signal. Upon a reset signal (active-low), the PC resets to zero; otherwise, it takes the input value (pc_in) and holds it as the current value (pc_out). This module is essential for tracking the instruction address in a processor's execution flow.
module top_module(
input             clk,
input             rst_n,
input   [31:0]    pc_in,
output  [31:0]    pc_out
);
