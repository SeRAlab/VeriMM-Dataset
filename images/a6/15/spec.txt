Design a dual-port memory module capable of storing and retrieving 16-bit data words. This module features an input clock signal to synchronize read and write operations, a 16-bit input for data, an address input for memory access, and a 2-bit byte-enable signal to control which portions of the data are written. On a positive clock edge and when writing is enabled, the module can selectively update either the lower or upper byte of the memory based on the byte-enable signals. The output is the concatenated result of the upper and lower bytes corresponding to the accessed address.
module top_module(
    input clk_i,
    input [15:0] data_i,
    input [SIZE-1:0] address_i,
    input [1:0] be_i,
    input wren_i,
    output reg [15:0] data_o
);
