Design a JK flip-flop with asynchronous reset functionality. The flip-flop outputs two complementary signals, Q and Qbar, based on the state of inputs J and K and the clock signal. On a rising edge of the clock, if the reset (rst) signal is high, Q is reset to 0 and Qbar to 1. If reset is low, the behavior of the flip-flop is determined by the inputs J and K: if both are low, the state remains unchanged; if K is high and J is low, it resets the output (Q=0); if J is high and K is low, it sets the output (Q=1); and if both are high, the output toggles between states.
