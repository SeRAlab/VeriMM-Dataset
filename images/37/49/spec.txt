Design a 2nd-order Infinite Impulse Response (IIR) filter. The filter should take a 16-bit input sample and produce a 16-bit output sample. The filter coefficients (a1, a2, b0, b1, b2) will be provided. The output is calculated using the formula:
output[n] = b0 * input[n] + b1 * input[n-1] + b2 * input[n-2] - a1 * output[n-1] - a2 * output[n-2];

Assume that the filter has two previous input samples and two previous output samples stored in registers. The design should include a clock and reset signal.
