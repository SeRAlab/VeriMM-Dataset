Design a 4-bit storage module that conditionally stores input data. When the input enable signal is active (in_enable = 1), the module captures the 4-bit input (in_data) and holds it in a register (stored_data), while also asserting the output enable signal (out_enable = 1). If the input enable signal is inactive, the stored data remains unchanged, and the output enable signal is deasserted (out_enable = 0). The output data (out_data) reflects the current state of the stored data.

    input [3:0] in_data,
    input in_enable,
    output reg [3:0] out_data,  // Changed to reg type
    output reg out_enable        // Changed to reg type
);
