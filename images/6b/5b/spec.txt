Design a 4-to-1 multiplexer that selects one of four input lines (in0, in1, in2, in3) based on a 2-bit selection signal (sel) to produce a single output (out). The output reflects the value of the selected input, which corresponds to the binary value of sel. If an invalid selection is made, the output defaults to LOW.
module top_module(
    out,
    in0,
    in1,
    in2,
    in3,
    sel
);
