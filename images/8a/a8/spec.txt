Design a circuit that performs a series of operations on five 8-bit input vectors (a, b, c, d, e) to produce an 8-bit output. First, it computes the bitwise AND of inputs a and b to create a temporary result, temp1. Next, it computes the bitwise OR of inputs c and d to produce another temporary result, temp2. The final output is generated by taking the bitwise XOR of temp1 and temp2, followed by adding the value of input e to the XOR result, ultimately producing the combined output as an 8-bit wide result.
module top_module(
    input [7:0] a,
    input [7:0] b,
    input [7:0] c,
    input [7:0] d,
    input [7:0] e,
    output [7:0] out
);
