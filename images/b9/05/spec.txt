Design a 2-to-1 multiplexer for 32-bit wide data inputs. The module takes two 32-bit inputs, data0_i and data1_i, along with a select signal select_i. Based on the value of select_i, it outputs either data0_i (when select_i is 0) or data1_i (when select_i is 1) through the output port data_o.
module top_module(
	input  [32-1:0] data0_i,       
	input  [32-1:0] data1_i,
	input       	select_i,
	output reg [32-1:0] data_o
               );
