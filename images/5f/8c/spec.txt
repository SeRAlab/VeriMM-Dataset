Implement a 4-to-1 multiplexer with an active-high enable signal. The module selects one of the four 8-bit input data signals based on a 2-bit select signal when the enable signal is high. If the enable signal is low, the output should be 8'h00.

Module name:
    mux_4to1

Input ports:
    enable: Active-high enable signal.
    sel: 2-bit select signal.
    data0: 8-bit input data 0.
    data1: 8-bit input data 1.
    data2: 8-bit input data 2.
    data3: 8-bit input data 3.

Output ports:
    data_out: 8-bit output data.

Implementation:
Use conditional assignment to select between data0, data1, data2, and data3 based on the sel signal when enable is high. If enable is low, set data_out to 8'h00.
