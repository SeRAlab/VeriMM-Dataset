

You are tasked with designing a module that takes in two 8-bit inputs, A and B, and outputs their sum in binary, S. The module should also output a carry bit, C, which indicates if there is a carry-out from the most significant bit. The module should be named `adder8` and should be written in Verilog within 200 lines of code.

The inputs A and B are unsigned integers, and the output S should also be an unsigned integer. The module should have the following interface:

```verilog
module adder8 (
    input [7:0] A,
    input [7:0] B,
    output [7:0] S,
    output C
);
```

The module should implement a ripple-carry adder, which adds the two inputs one bit at a time and propagates any carry to the next bit. You may use any additional modules or gates you deem necessary, but the `adder8` module should be self-contained and not rely on any external modules.

Your implementation should be optimized for speed, as the module will be used in a critical path in a larger design.
