
Design a UART (Universal Asynchronous Receiver-Transmitter) controller that can transmit a byte of data serially. The UART should have the following specifications:
- It operates at a fixed baud rate.
- The data format is 8 data bits, 1 stop bit, and no parity.
- The controller should have an input signal `start_tx` to indicate when to begin transmission, and an output signal `tx` for serial data output.
- The clock input `clk` should be used to shift out the data bits sequentially.
- The controller should also have a `reset` signal to initialize the state.
