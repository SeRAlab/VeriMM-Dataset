Design a register module with a lookup table (LUT) functionality. The module captures a 4-bit input parallel data (I) on the rising edge of the clock (CLK) if the enable signal (CE) is asserted, and it clears the output to zero when the clear signal (CLR) is active. Additionally, it incorporates a 2-input LUT that produces an output based on two other inputs (LUT_I0 and LUT_I1) with a preset initialization value. The module outputs the 4-bit register value (O) and the result of the LUT (LUT_O).
module top_module(input CLK,
   input CE,
   input CLR,
   input [3:0] I,
   input LUT_I0,
   input LUT_I1,
   output [3:0] O,
   output LUT_O);
