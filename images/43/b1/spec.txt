Develop a 32-to-1 multiplexer that selects one of the 32 input lines based on a 5-bit selector (`sel`). When the `reset` signal is asserted, the output is set to zero. Upon the rising edge of the `clk`, the output (`out`) is updated with the selected input according to the value of `sel`, which ranges from 0 to 31, corresponding to each respective bit of the 32-bit input (`in`).
module top_module(input clk,input reset,input [4:0]sel,input [31:0]in,output reg out);
