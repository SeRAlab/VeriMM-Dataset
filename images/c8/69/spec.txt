Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a clock gating cell. 
A clock gating cell is used to reduce power consumption in digital circuits by selectively enabling clock signals to certain parts of the circuit only when needed.

Your module should have the following inputs and outputs:

Inputs: a clock signal (clk) and an enable signal (en)
Outputs: a gated clock signal (clk_gated)

To implement the clock gating cell, you should use Verilog code to define the enable signal as a Boolean function of the input signals. 
You should then use this function to connect the clock signal to the gated clock signal through an AND gate.
The output of the AND gate should be the gated clock signal.

Your module should follow the following functionality:

When the enable signal is high, the clock signal should pass through the AND gate to the gated clock signal.
When the enable signal is low, the gated clock signal should be held low.
