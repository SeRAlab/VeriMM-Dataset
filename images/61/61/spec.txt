Design a 2-bit binary adder circuit that takes two 2-bit inputs (a and b) and a carry-in bit (cin) to produce a 2-bit sum output (sum) and a carry-out (cout). The module computes the sum by adding the least significant bits of a and b along with the carry-in to produce the least significant bit of the sum and an intermediate carry. It then adds the most significant bits of a and b, along with the intermediate carry to form the most significant bit of the sum, while the carry-out represents any overflow from this addition.
module top_module(
    // Inputs
    input [1:0] a,
    input [1:0] b,
    input cin,

    // Outputs
    output [1:0] sum,
    output cout
);
