Design a register that stores an 8-bit value. The module has a data input (d) and a synchronous clock input (clk). On the rising edge of the clock, if the reset signal (rst_n) is low, the output (q) is set to zero; otherwise, it takes the value of the input (d). This functionality allows for loading new data into the register while providing a reset capability.
module top_module(
                 output logic [7:0] q,
                 input logic [7:0]  d,
                 input logic        clk, rst_n
                 );
