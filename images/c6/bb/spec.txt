

You have been tasked with designing a verilog module for a 2-to-1 multiplexer (MUX) with an enable input. The module should have the following interface:

Inputs:
- `a`: 1-bit input signal
- `b`: 1-bit input signal
- `en`: 1-bit enable signal

Outputs:
- `y`: 1-bit output signal

The module should output `a` when `en` is 0 and `b` when `en` is 1.

Write a verilog module that implements this 2-to-1 MUX with enable input.
