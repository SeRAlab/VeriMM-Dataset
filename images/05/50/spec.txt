Design a simple EEPROM cell in Verilog that allows for read, write, and erase operations. The EEPROM should have a data input, a data output, a write enable signal, an erase signal, and a clock signal. When the write enable signal is high, the data input should be stored in the cell on the rising edge of the clock. When the erase signal is high, the data should be reset to 0. The data output should reflect the current value of the cell when requested.
