Design a 4-bit binary counter that operates based on a clock signal and a reset input. The counter can increment or decrement the count based on the `count_up` control signal; when `count_up` is high, the counter counts up to a maximum of 15 (4'b1111) and wraps around to 0, while when `count_up` is low, it counts down from 0 to 15 and wraps around to 15 when it goes below 0. The counter resets to 0 when the `reset` input is high.
module top_module(
  input clk,
  input reset,
  input count_up,
  output reg [3:0] count
);
