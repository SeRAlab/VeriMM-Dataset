Create an SR latch using Verilog. The SR latch should have two inputs (S and R) and two outputs (Q and Qn). The latch should maintain its state until it is explicitly reset or set. Implement the functionality so that when S=1 and R=0, Q should become 1; when S=0 and R=1, Q should become 0; and when both S=0 and R=0, Q should retain its previous state. If both inputs are 1, it should be considered an invalid state, and the latch should hold its previous state.
