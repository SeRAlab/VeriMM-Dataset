

You are tasked with designing a Verilog module for a 2:1 multiplexer with registered output. The module should have the following inputs and outputs:

Inputs:
- `I0`: a 1-bit input signal
- `I1`: a 1-bit input signal
- `S`: a 1-bit select signal
- `clk`: a clock signal

Outputs:
- `O`: a 1-bit output signal

The module should be named `mux21_reg` and should use a D flip-flop to register the output signal.

Your Verilog module should have the following behavior:
- When `S` is 0, the output `O` should be equal to `I0`
- When `S` is 1, the output `O` should be equal to `I1`
- The output `O` should be registered on the rising edge of the clock signal `clk`
