Design a three-bit wide, 8-to-1 multiplexer. The module selects one of the eight 1-bit inputs from the input_data based on the value of the select signals. Each combination of the select inputs (from 000 to 111) determines which specific bit from the 8-bit input is routed to the output, thereby allowing for flexible data selection in a digital circuit.
module top_module(
    input [2:0] select,
    input [7:0] input_data,
    output reg output_data
);
