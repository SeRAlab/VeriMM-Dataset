Design a simple I2C interface control module with a reset functionality. Upon asserting the reset signal, the module initializes the write request (wreq) and data request (dreq) signals to LOW and resets a 30-bit counter. On each rising edge of the clock, the counter increments until it reaches a predefined threshold of 30'h100_0000, at which point the data request signal (dreq) is asserted HIGH. This module can be used to control data transactions on an I2C bus by signaling when data should be processed.
