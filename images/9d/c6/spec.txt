Design a 2-to-1 multiplexer with two selection lines (sa and sb) for two 72-bit wide input data signals (a and b). The output, muxed, will be composed of bits from a or b depending on the state of the selection lines: if sa is high, the output will take the value of a; if sb is high, the output will take the value of b. If both selection lines are low, the output will be zero.
module top_module(
   // Outputs
   muxed,
   // Inputs
   sa, sb, a, b
   );
