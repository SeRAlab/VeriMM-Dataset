Design a 4-bit edge-triggered D flip-flop with asynchronous reset. The flip-flop should have a clock input (clk), a data input (d), an active-low asynchronous reset (reset), and a 4-bit output (q). On the rising edge of the clk, if reset is low, the output q should be updated to the value of d. If reset is high, the output q should be reset to 0.
