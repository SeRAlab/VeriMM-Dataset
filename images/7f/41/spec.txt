Design a one-bit wide, 2-to-1 multiplexer that selects between two 32-bit input signals, `data1` and `data2`, based on the value of the `select` signal. When `select` is 0, the output `out` will be assigned the value of `data1`; when `select` is 1, the output will take the value of `data2`.
module top_module(
    input [31:0] data1,
    input [31:0] data2,
    input select,
    output [31:0] out
    );
