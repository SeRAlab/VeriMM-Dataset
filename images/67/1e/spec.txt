Design a 4-bit binary adder capable of computing the sum of two 4-bit inputs A and B, along with a carry-in input Cin. The module also includes a reset input that, when asserted, initializes the sum output S to zero and sets the carry-out output Cout to high. The addition operation is performed on the rising edge of a clock signal, producing an updated sum and carry-out based on the inputs.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    input reset,
    input clk,
    output reg [3:0] S,
    output reg Cout
);
