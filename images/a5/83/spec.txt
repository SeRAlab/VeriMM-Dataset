Design a D flip-flop with asynchronous reset and preset functionality. On the rising edge of the clock, if the reset signal is active, the output q is set to LOW and its complement q_n is set to HIGH. Conversely, if the preset signal is active, q is set to HIGH and q_n is set to LOW. If neither reset nor preset is active, the output q takes the value of the input d, while q_n outputs the inverted value of d. This module operates as a storage element with additional control signals for resetting and presetting the output state.
module top_module(
    input clk,
    input reset,
    input preset,
    input d,
    output reg q,
    output reg q_n
);
