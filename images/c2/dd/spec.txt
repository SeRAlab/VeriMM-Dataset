
You have been tasked to design a verilog module that takes in a 4-bit input signal and outputs a 2-bit signal based on the following conditions:
- If the input signal is less than 4, the output signal should be '00'
- If the input signal is between 4 and 7 (inclusive), the output signal should be '01'
- If the input signal is between 8 and 11 (inclusive), the output signal should be '10'
- If the input signal is greater than 11, the output signal should be '11'

Your module should be named `signal_converter` and should have the following ports:
- `input_signal` : a 4-bit input signal
- `output_signal` : a 2-bit output signal

You may assume that the input signal is always a positive integer.
