Design a module that converts a 4-bit Gray code input into its binary equivalent and can also perform multiplication of two 4-bit unsigned integers. The module outputs an 8-bit result that can either be the binary representation of the Gray code (extended with zeros) or the product of the two inputs A and B, depending on the state of the select signal. A synchronous reset functionality allows all internal registers to be cleared. When select is low, the output is derived from the Gray code conversion; when it is high, the output represents the multiplication result.
module top_module(
    input clk,
    input reset, // Synchronous active-high reset
    input [3:0] G, // 4-bit Gray code input
    input [3:0] A, // 4-bit input for the multiplier
    input [3:0] B, // 4-bit input for the multiplier
    input select, // Select input to choose between Gray code input and multiplier output
    output reg [7:0] product // 8-bit output from the functional module
);
