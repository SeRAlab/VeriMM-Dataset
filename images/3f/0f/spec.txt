Design a simple virtual memory address translation module that converts a given 16-bit virtual address into a 10-bit physical page number and a 6-bit offset. The page size is 64 bytes. The module takes a 16-bit virtual address as input and outputs a 10-bit physical page number and a 6-bit offset. The physical page number is calculated as the upper 10 bits of the virtual address divided by the page size, and the offset is the lower 6 bits of the virtual address.
