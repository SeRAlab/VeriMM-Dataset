
Create a fixed-priority arbiter with 4 request signals (req0, req1, req2, req3) and 4 grant signals (grant0, grant1, grant2, grant3). The arbiter should follow the fixed priority order: req0 > req1 > req2 > req3. Implement the arbiter such that when a request signal is active, it grants the highest priority active request signal. If multiple requests are active, only the highest priority one should be granted.
