

You have been asked to design a verilog module that performs a 16-bit multiplication of two unsigned numbers. The module should take two inputs, each of 16 bits, and output a 32-bit result. You should implement the multiplication using a combinational logic circuit.

Write a verilog module named "unsigned_multiplier" that performs this task. The module should have the following ports:

- input clk: a clock signal
- input [15:0] a: the first input number
- input [15:0] b: the second input number
- output reg [31:0] result: the result of the multiplication

The module should use only combinational logic to calculate the result. You may use any verilog operators or constructs that you find useful.
