
Design a packet filtering logic that checks the incoming packet headers for specific conditions. Each packet header consists of 8 bits for source IP (S_IP), 8 bits for destination IP (D_IP), and 16 bits for the packet type (P_TYPE). The filter should allow packets if:
1. The source IP is 0xAA (binary 10101010).
2. The destination IP is 0x55 (binary 01010101).
3. The packet type is either 0x01 (binary 00000001) or 0x02 (binary 00000010).

If the packet satisfies all these conditions, the output should be 'ALLOW', otherwise 'DENY'.
