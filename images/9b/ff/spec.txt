Design a VGA-based sprite renderer that captures a bitmap image and overlays it on a VGA display. The module takes horizontal and vertical synchronization signals alongside memory values to determine pixel colors, producing RGB output signals for color representation. It calculates sprite positioning based on defined scaling, start, and end coordinates for the image. When the coordinates indicate that the pixel is within the boundaries of the scaled image, the corresponding color value is retrieved from memory; otherwise, it outputs black and sets an "inside_image" flag to indicate if the pixel is part of the sprite.
