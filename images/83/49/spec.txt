Design a 4-to-1 multiplexer with 16-bit wide inputs and output. The module selects one of the four 16-bit input signals (iInput0, iInput1, iInput2, iInput3) based on the 2-bit selection input (iSelect). Each selection value corresponds to a specific input; when iSelect is 00, output the first input; when 01, output the second; when 10, output the third; and when 11, output the fourth input. The output (oOutput) reflects the chosen input based on the selection signal.
module top_module(
  input [15:0] iInput0,
  input [15:0] iInput1,
  input [15:0] iInput2,
  input [15:0] iInput3,
  input [1:0] iSelect,
  output reg [15:0] oOutput
);
