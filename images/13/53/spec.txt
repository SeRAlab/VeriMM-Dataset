Design a simple Cryptographically Secure Pseudo-Random Number Generator (CSPRNG) using a Linear Feedback Shift Register (LFSR). The LFSR should have a 5-bit width and use the polynomial x^5 + x^3 + 1 for feedback. The output of the CSPRNG should be a 5-bit random number that can be used for generating random sequences. The generator should have a clock input, a reset input, and an output port for the random number.
