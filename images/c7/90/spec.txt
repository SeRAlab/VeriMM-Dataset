

You are tasked with designing a verilog module that implements a 2:1 multiplexer with an enable signal. The module should have the following inputs and outputs:

Inputs:
- `input wire  a`: the first input to the multiplexer
- `input wire  b`: the second input to the multiplexer
- `input wire  en`: the enable signal

Outputs:
- `output wire y`: the output of the multiplexer

If `en` is high, the output of the module should be equal to `b`. Otherwise, the output should be equal to `a`.

You should implement the module using behavioral Verilog, and assume that the inputs `a`, `b`, and `en` are stable during the entire clock cycle.
