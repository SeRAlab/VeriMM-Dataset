Design a circuit that performs three logical operations (AND, OR, and XOR) on a 100-bit wide input vector using NOR gates. The module generates three outputs: `out_and`, `out_or`, and `out_xor`. The `out_and` output represents the logical AND operation, the `out_or` output represents the logical OR operation, and the `out_xor` output represents the logical XOR operation, all derived from the original input using inverted NOR gate logic techniques.
module top_module( 
    input [99:0] in,
    output out_and,
    output out_or,
    output out_xor 
);
