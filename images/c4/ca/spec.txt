

You have been tasked with designing a digital circuit that will implement a D flip-flop with reset and asynchronous set functionality. The circuit should be implemented in Verilog and should be contained within a single module of no more than 200 lines of code.

The module should have the following inputs and outputs:

- `CLK`: a clock signal
- `D`: the data input
- `RESET_B`: an active-low reset input
- `SET_B`: an active-low set input
- `Q`: the output of the flip-flop
- `Q_N`: the complement output of the flip-flop

The flip-flop should operate according to the following rules:
- When `RESET_B` is low, both `Q` and `Q_N` should be set to 0.
- When `SET_B` is low, both `Q` and `Q_N` should be set to 1.
- At every positive edge of `CLK`, the output `Q` should reflect the input `D`.
- At every negative edge of `CLK`, the output `Q_N` should reflect the input `D`.

Write a Verilog module that implements this flip-flop.
