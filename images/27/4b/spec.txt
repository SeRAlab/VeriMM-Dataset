
Design a 16-bit Linear Feedback Shift Register (LFSR) that generates pseudo-random sequences based on an initial seed value. The LFSR should use the polynomial x^16 + x^14 + x^13 + x^11 + 1 as its feedback taps. The output should be the current state of the LFSR after each clock cycle, and it should also reset to the initial seed value when a reset signal is asserted.
