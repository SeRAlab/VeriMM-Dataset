Design a basic calculator module that performs arithmetic operations on two 32-bit inputs, `a` and `b`. The operations are selected using a 2-bit input `op`, where `00` corresponds to addition, `01` to subtraction, `10` to multiplication, and `11` to division. The module outputs the result of the selected operation. It also includes a synchronous reset feature that initializes the result to zero when activated. This module is clocked, meaning operations are executed on the rising edge of the clock signal.
module top_module(clk, reset, a, b, op, result);
