Design a D flip-flop with set (S) and reset (R) functionality. On the rising edge of the clock, the output Q is updated to the value of input D, unless the set input S is high, which forces the output to high, or the reset input R is high, which forces the output to low. This module thus enables the synchronous storage of a bit while also allowing for asynchronous control to set or reset the output state.
module top_module(
	input clock_i,
	input D,
	input S,
	input R,
	output Q
);
