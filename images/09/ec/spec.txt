Design a 24-bit Digital-to-Analog Converter (DAC) that takes a 24-bit input and generates a 24-bit output scaled to a maximum value of 255. The output should be the input value divided by a scaling factor of 2^16 (65536), with the output represented as an 8-bit integer. The DAC should produce the output value based on the input value at the rising edge of the clock signal.
