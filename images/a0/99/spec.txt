Design a gated D flip-flop that enables data storage based on a clock signal and an enable signal. The module samples the input data (D) on a rising clock edge when the enable signal (EN) is active. If the enable signal is low, the output (Q) holds an undefined state (1'bx). This design uses a latch that is controlled by both the clock and enable signals to determine when to capture the input data.
module top_module(
  input CLK,
  input EN,
  input [31:0] D,
  output reg [31:0] Q
);
