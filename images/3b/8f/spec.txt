
Design a 24-bit ADC processor that takes a 24-bit input representing an analog value and outputs a 24-bit digital representation. The output should have the following features:
1. If the input is less than 0, output all zeros.
2. If the input is greater than the maximum value of 24 bits (16777215), output all ones.
3. If the input is in the valid range (0 to 16777215), output it as-is.
