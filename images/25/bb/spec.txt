
Design a 16-bit SRAM cell where you can perform the following operations:
1. Write data to the SRAM cell.
2. Read data from the SRAM cell.
3. Enable a write operation only when the write enable signal (WE) is high.
4. Enable a read operation only when the read enable signal (RE) is high.

The SRAM cell should have the following ports:
- `data_in` (16 bits) for input data to be written
- `data_out` (16 bits) for output data to be read
- `we` (1 bit) for write enable
- `re` (1 bit) for read enable
- `clk` (1 bit) for clock signal
