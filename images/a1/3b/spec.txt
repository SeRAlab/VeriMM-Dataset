Design a register that holds various inputs related to an instruction decode stage of a CPU. The module captures signals on the rising edge of the clock, transferring them to output registers unless a reset condition is active, in which case all outputs are initialized to zero. It supports stall and flush conditions: stall keeps the existing output values, while flush resets them to zero as well, effectively resetting the pipeline stage. This functionality allows for synchronized control of data through the pipeline while accommodating exceptions and ensuring correct operation in a pipelined architecture.

	output reg [31:0] id_pc,
