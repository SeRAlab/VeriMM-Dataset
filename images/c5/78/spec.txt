
You are tasked with designing a module in Verilog that can perform a bitwise XOR operation on two input signals `A` and `B`. The output signal `X` should be equal to `1` when `A` and `B` are different, and `0` when they are the same. The module should have the following interface:

```
module bitwise_xor (
    input A,
    input B,
    output X
);
```

You should assume that the input signals `A` and `B` are single-bit signals. The output signal `X` should also be a single-bit signal.

Your implementation should use only combinational logic and should be contained within a single module that is no more than 200 lines of Verilog code. You may use any of the standard Verilog operators (e.g., `&`, `|`, `^`, `~`) as well as any other standard Verilog constructs (e.g., `if`, `case`, `always`, `assign`). However, you should not use any Verilog constructs that rely on sequential logic (e.g., `reg`, `always @(posedge clk)`, etc.).
