
Design a voltage sensor that takes a 3-bit binary input representing a voltage level. The output should indicate if the voltage is in the range of 3V to 5V (inclusive). Use 1 to indicate that the voltage is within range and 0 to indicate that it is out of range. The mapping is as follows: 
- 000 (0V) to 011 (3V) -> 0
- 100 (4V) to 101 (5V) -> 1
- 110 (6V) to 111 (7V) -> 0
