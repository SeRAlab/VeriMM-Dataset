Design a 4-bit adder/subtractor circuit that can perform addition or subtraction on two 4-bit inputs, A and B, with a carry-in input Cin. The operation is determined by the Sel control signal; when Sel is low, it computes the sum of A and B (plus Cin), and when Sel is high, it computes the difference, using the two's complement of B for subtraction. The module also outputs a carry-out signal Cout to indicate when the result exceeds the 4-bit capacity.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    input Sel,
    output [3:0] S,
    output Cout
);
