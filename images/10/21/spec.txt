
Design a simple EEPROM memory cell that can store a single bit of data. The EEPROM cell should have the following inputs and outputs:
- Inputs: 
  - `data_in`: the data to be written (1 bit)
  - `write_enable`: control signal that enables writing to the EEPROM cell (1 bit)
  - `read_enable`: control signal that enables reading from the EEPROM cell (1 bit)
- Outputs:
  - `data_out`: the data read from the EEPROM cell (1 bit)
The EEPROM cell should retain its value until a new value is written, and it should output the stored value when read.
