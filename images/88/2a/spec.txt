Design a basic calculator module that performs addition and subtraction on two 4-bit inputs, A and B. The module produces a 4-bit output for the sum and the difference of the inputs. The output is conditionally modified by a control signal: when the control signal (ctrl) is low, the difference output is set to an undefined state, and when it is high, the sum output is set to an undefined state. This allows selective usage of the calculator's functionality based on the control signal.
module top_module(
   input [3:0] A,
   input [3:0] B,
   input ctrl,
   output reg [3:0] sum,
   output reg [3:0] difference
);
