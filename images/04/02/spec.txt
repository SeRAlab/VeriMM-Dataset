
Design a 4-channel DMA Controller that handles data transfers between memory and peripherals. The DMA controller will select one of the four channels based on a 2-bit select input. Each channel has a request (REQ) and an acknowledge (ACK) signal. The DMA controller will grant the channel access to the bus based on REQ and will acknowledge the completion using ACK. The controller should also have a clock input and a reset input to initialize the state.
