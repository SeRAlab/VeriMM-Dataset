Design a parameterized FIFO queue in Verilog. The FIFO should have a depth parameter defining how many elements it can hold. It should have the following inputs: `clk` (clock), `rst` (reset), `wr_en` (write enable), `rd_en` (read enable), and an `input_data` signal. The outputs should include `output_data` (data read from the FIFO) and `full` (indicating if the FIFO is full) and `empty` (indicating if the FIFO is empty).
