
You are tasked with designing a Verilog module that takes in 3 inputs and produces 1 output. The inputs are A1, A2, and B1_N, and the output is Y. The module should be named "three_to_one". The module should be designed to implement the following logic:
- If A1 and A2 are both high, Y should be high.
- If A1 is high and A2 is low, Y should be low.
- If A1 is low and A2 is high, Y should be low.
- If A1 and A2 are both low, Y should be high if B1_N is low, and low if B1_N is high.
- The module should also have two inputs, VPWR and VGND, which should be connected to the power and ground rails, respectively. 

Your task is to implement the "three_to_one" module in Verilog, ensuring that it satisfies the above requirements. Your Verilog module should be no longer than 200 lines of code.
