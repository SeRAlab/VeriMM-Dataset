Design a binary adder/subtractor that processes an 8-bit binary input. The module converts the binary input to a decimal representation and, based on the most significant bit (MSB), either increments or decrements the decimal value by one, before converting it back to binary for the output. If the MSB is high, it performs a subtraction by one; if low, it performs an addition by one. The final output is an 8-bit signed binary representation of the adjusted decimal value.

  input [7:0] binary_input,
  output reg [7:0] binary_output
);
