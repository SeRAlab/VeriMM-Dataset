Design a 16-bit shift register that supports both left and right shifts. The shift direction is controlled by a single input signal: 'shift_dir'. If 'shift_dir' is high, the register should shift left, and if it is low, it should shift right. The register should have a synchronous reset input, 'reset', which clears the register to 0 when asserted. The shifting occurs on the rising edge of the 'clk' signal.
