
Design a simple RNN cell in Verilog that takes a 4-bit input at each time step and maintains a hidden state of 4 bits. The cell should perform the following operations:
1. The hidden state is updated using the formula: 
   `h_next = h_prev * W_h + x * W_x + b`
   Where `W_h`, `W_x`, and `b` are predefined constants.
2. The RNN should accept an input and a clock signal, and update the hidden state on the rising edge of the clock.
3. The output of the RNN should be the current hidden state after each update.
