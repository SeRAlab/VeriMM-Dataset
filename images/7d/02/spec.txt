Design a circuit that functions as a 4-bit binary adder, capable of adding two 4-bit inputs (A and B) along with a single carry-in input (Cin). The module produces a 4-bit output (Sum) representing the result of the addition, and a carry-out signal (Cout) indicating if there is an overflow beyond the 4-bit limit (greater than 15). The design utilizes combinational logic to compute the sum and determine the carry-out condition.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    output reg [3:0] Sum,
    output reg Cout
);
