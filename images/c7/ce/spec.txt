

Your task is to design a Verilog module that takes in a 32-bit input signal `in_signal` and outputs a 16-bit signal `out_signal`. The output signal should be the result of performing a bitwise AND operation between the input signal and a 16-bit constant value `const_value`.

The module should have the following input and output ports:
- `in_signal`: a 32-bit input signal
- `const_value`: a 16-bit constant value
- `out_signal`: a 16-bit output signal

Your module should be named `and_module` and should be written within 200 lines of Verilog code.
