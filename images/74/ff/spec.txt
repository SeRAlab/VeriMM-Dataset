Design a synchronous D flip-flop with asynchronous set and clear functionality. The module captures the value of the input 'd' on the rising edge of a clock signal 'clk'. It also incorporates reset behavior, where the output 'q' is set to LOW upon a reset signal, and can be independently set to HIGH or cleared to LOW based on the 'set' and 'clear' inputs, respectively. The design effectively integrates both synchronous and asynchronous control signals to manage the state of the flip-flop.
module top_module(
    input clk,
    input reset,
    input set,
    input clear,
    input d,
    output reg q
);
