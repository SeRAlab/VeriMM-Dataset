Design a 4-bit binary adder module that computes the sum of two 4-bit inputs, A and B, along with a carry-in input, cin. The module outputs a 4-bit sum and a carry-out signal, cout. If the result of the addition exceeds 4 bits (i.e., greater than 15), the carry-out is set to 1, and the sum is wrapped around by subtracting 16, effectively simulating 4-bit overflow behavior.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input cin,
  output reg [3:0] sum,  // Changed to output reg
  output reg cout        // Changed to output reg
);
