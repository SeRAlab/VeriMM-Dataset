Design a simple audio level controller that takes a 4-bit audio signal as input and adjusts the volume. The output should be the input signal multiplied by a volume factor, which is a 2-bit value. If the volume factor is 00, the output should be 0. If the volume factor is 01, the output should be equal to the input. If the volume factor is 10, the output should be double the input, and if it is 11, the output should be capped at 15 (the maximum for a 4-bit value).
