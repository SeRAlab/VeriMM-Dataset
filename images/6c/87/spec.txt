Implement a Verilog module based on the following description.
Design a finite state machine with input a. The FSM starts in state START. If a=1, it moves to state END. In state END, if a=0, the FSM sets an output b to 1 in the next clock cycle, otherwise b is 0. The FSM remains in state END if a=1. Use as few states as possible. Assume reset is active high synchronous.
