Design a circuit that functions as a keyboard input receiver. It captures a sequence of 11 bits from the kData input at each falling edge of the kClock signal, utilizing an internal register to store the incoming bits. Once 11 bits are received, the module outputs the 8 most significant bits to the LEDR, effectively translating keyboard scan codes into visual LED representation.
module top_module(
	
	output reg[9:0] LEDR,

	
	input kData, 
	input kClock 
);
