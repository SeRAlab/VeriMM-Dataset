Design a JK latch using Verilog. The latch should have inputs J, K, a clock signal CLK, and an asynchronous reset signal RST. The latch should set its output Q based on the following conditions: when RST is high, Q should be reset to 0. On the rising edge of CLK, if J is high and K is low, Q should be set to 1; if J is low and K is high, Q should be set to 0; if both J and K are high, Q should toggle its current state. If both J and K are low, Q should hold its previous state.
