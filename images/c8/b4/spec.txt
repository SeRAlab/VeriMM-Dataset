

You are tasked with designing a module that implements a 2-to-1 multiplexer using Verilog. The module should have two 8-bit input ports, one select port, and one output port. The select port should be a single bit, and when it is high, the output should be equal to the first input port. When the select port is low, the output should be equal to the second input port.

Your module should be named "mux_2to1" and should be self-contained, meaning it should not rely on any external modules or variables. Your module should also be designed to be synthesizable, meaning it can be implemented on an FPGA.

Write a Verilog module that implements the 2-to-1 multiplexer as described above. Your module should be no longer than 200 lines of code.
