Design a 4-bit adder-subtractor circuit that performs addition or subtraction on two 4-bit inputs A and B based on a mode control signal. When Mode is set to 0, the circuit outputs the sum of A and B, considering a carry-in (Cin) for the addition. When Mode is set to 1, the circuit computes the difference by taking the two's complement of B and adding it to A. The result is provided as a 4-bit output (Sum) along with a carry-out (Cout) for the addition operation.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input Cin,
  output [3:0] Sum,
  output Cout
);
