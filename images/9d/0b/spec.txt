Design a circuit that implements a 4-bit counter along with a control mechanism for a multiplexer output. The circuit increments a 4-bit counter on each clock cycle and toggles a select signal every five counts, resetting after ten counts. The multiplexer output, `mux_out`, outputs a logic high when the select signal is high and a logic low otherwise. The counter value is output as `counter_out`, which is reset to zero when the reset signal is activated.
module top_module(
  input clk,
  input reset,
  output reg [3:0] counter_out,
  output reg mux_out
);
