Design a 2-to-4 decoder that converts a 2-bit binary input into one of four output lines, based on an enable signal. When the enable signal is LOW, the decoder produces a LOW output on all lines, effectively disabling the outputs. For a LOW enable and a specific 2-bit input, only one corresponding output line will be HIGH, representing the binary value of the input.

  input [1:0] in,
  input enable,
  output [3:0] out
