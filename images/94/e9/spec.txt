Design a 4-bit counter that increments on each clock cycle when enabled. The counter resets to zero when the reset signal is asserted. The module outputs the least significant 2 bits of the counter value, providing a 2-bit output that reflects the current state of the counter. This configuration allows for efficient counting while selectively providing a portion of the count value for further logic operations.
module top_module(
    input clk,
    input reset,
    input enable,
    input [3:0] in,
    output reg [1:0] out
);
