Design a finite state machine (FSM) that implements a simple ECC point doubling operation on a defined elliptic curve over a finite field. The FSM should take coordinates of a point (x, y) as input and return the coordinates of the doubled point (2x, 2y) as output, following the elliptic curve formula for point doubling: 2P = (x', y') where x' = (x^2 - y^2) mod p, y' = (2xy) mod p, and p is a prime number defining the field.
