Design a 4-to-1 multiplexer with an enable feature. This module takes four 4-bit wide inputs and a 2-bit select input to choose which of the four inputs is routed to the output. When the enable input is high, the multiplexer will output the selected input; when the enable input is low, the output will be set to zero. The logic incorporates AND and OR gates to appropriately filter inputs based on the select lines and the state of the enable signal.
module top_module(
    input [3:0] in0,
    input [3:0] in1,
    input [3:0] in2,
    input [3:0] in3,
    input [1:0] sel,
    input en,
    output reg [3:0] out
);
