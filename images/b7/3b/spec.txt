Design a one-bit multiplexer with an additional inversion feature. The output is determined by the selector input C: when C=0, the output is equal to input A, and when C=1, the output is equal to input B. Furthermore, if the invert input is high (1), the output is inverted, producing the logical NOT of the selected input.
module top_module(
    input A,
    input B,
    input C,
    input invert,
    output reg out
);
