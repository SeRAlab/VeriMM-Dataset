Design an 8-bit SRAM cell. The SRAM cell should have the following inputs: 8-bit data input (data_in), a write enable signal (we), and a clock signal (clk). The output should be an 8-bit data output (data_out). When write enable is high, on the rising edge of the clock, the data input should be written to the SRAM cell. When write enable is low, the data output should reflect the stored value in the SRAM cell.
