Design a 7-segment display driver that takes a 4-bit binary input (iDIG) representing a decimal digit (0-9) or a hexadecimal character (A-F) and outputs the corresponding 7-segment encoding (oSEG) to illuminate the appropriate segments. The module also sets the decimal point output (oSEG_DP) to always be HIGH, indicating that the decimal point is active. The implemented look-up table provides the necessary segment configurations for visual representation on a 7-segment display.
module top_module(
    output reg [6:0]    oSEG,
    output reg          oSEG_DP,
    input [3:0]         iDIG
);
