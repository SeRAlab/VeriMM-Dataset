
Design a fan speed control system using a 3-bit binary input to control the speed of the fan. The fan speed should be set according to the binary input, where:
- 000: Off
- 001: Low speed
- 010: Medium speed
- 011: High speed
- 100: Full speed
The system should remember the last speed when a new input is provided and only change the speed if the new input is different from the previous input. The output should indicate the current speed setting.
