Design a JK flip-flop with additional set and reset functionalities. The flip-flop has inputs for clock, asynchronous reset, set, and both J and K control signals. On the rising edge of the clock, if the reset is activated, the output Q will reset to LOW and Qbar to HIGH. If the set signal is active, Q will be set to HIGH and Qbar to LOW. When both J and K are HIGH, the output alternates between HIGH and LOW on each clock pulse, while if only J is HIGH, Q is set to HIGH, and if only K is HIGH, Q is set to LOW.
module top_module(
  input clk,
  input rst,
  input set,
  input j,
  input k,
  output reg q,
  output reg qbar
);
