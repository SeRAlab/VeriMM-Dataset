Design a simple 4-bit calculator that performs addition or subtraction based on input control signals. The module takes two 4-bit inputs (num1 and num2) and an operation selector (op). When op is low, the circuit outputs the sum of num1 and num2; when op is high, it outputs their difference. Additionally, a reset signal can clear the output, setting the result to zero.
module top_module(
    input [3:0] num1,
    input [3:0] num2,
    input op,
    input reset,
    output reg [3:0] result
);
