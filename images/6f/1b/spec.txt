Design a simple calculator that performs addition and subtraction on two 8-bit operands. It takes two 8-bit inputs (operand1 and operand2) along with a 2-bit operation selector. When the operation selector is 00, the module outputs the sum of the operands; when the operation selector is 01, it outputs the difference. The results are presented as an 8-bit output.
module top_module(
    input [7:0] operand1,
    input [7:0] operand2,
    input [1:0] operation,
    output [7:0] result
);
