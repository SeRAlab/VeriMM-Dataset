Design a simple Watchdog Timer in Verilog. The Watchdog Timer should have three inputs: a reset signal (reset), a start signal (start), and a clock signal (clk). It should have one output (timeout) that goes high if the timer exceeds a preset time limit (in this case, 4 clock cycles). If the reset signal is high, the timer should reset. If the start signal is high, the timer should start counting clock cycles. The timeout output should go high if the timer reaches 4 clock cycles without being reset.
