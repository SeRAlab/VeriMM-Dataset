Design a synchronous 4-bit counter with load functionality. On the rising edge of the clock, if the reset signal is asserted, the counter resets to zero. If the load signal is active, the counter takes the value from the 4-bit input `data_in`. Otherwise, the counter increments its current value by one.
module top_module(
    input clk,
    input reset,
    input load,
    input [3:0] data_in,
    output reg [3:0] count
);
