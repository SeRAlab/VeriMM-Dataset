Design a 16-bit wide adder unit that computes the sum of two 16-bit inputs, A and B, along with an additional carry-in input, CIN. The module outputs a 16-bit result, S, representing the summed value of A, B, and CIN. The functionality is triggered whenever there is a change in either input or the carry-in signal.
module top_module(
    input [15:0] A,
    input [15:0] B,
    input CIN,
    output reg [15:0] S
);
