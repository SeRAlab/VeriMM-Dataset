Design a pseudo-random number generator (PRNG) that outputs an 8-bit value. The module can be initialized to a specific 8-bit input value when the load signal is asserted. Upon a reset, the output is set to zero. In normal operation, on each clock cycle, the generator shifts the stored value left by one bit, while the new bit inserted into the least significant position is derived from the exclusive OR of the two least significant bits of the current state. The output (outf) consistently reflects the current state of the internal shift register.
