

You are tasked with designing a module that performs an arithmetic half adder operation on two input bits, A and B, and outputs the sum of the two bits and a carry-out bit. The module should be named "half_adder" and should be written in Verilog within 200 lines of code.

The module should have the following inputs and outputs:

Inputs:
- A (1-bit)
- B (1-bit)

Outputs:
- sum (1-bit)
- carry_out (1-bit)

The module should implement the following equation:
- sum = A xor B
- carry_out = A and B

Your task is to write the Verilog code for the "half_adder" module that implements the above equation.
