Implement a cyclic redundancy check (CRC) generator and checker. This module takes an n-bit input data and, on each clock cycle, computes a k-bit CRC using a specified generator polynomial. It appends the CRC to the input data, outputs the original data bits, and provides a flag indicating whether the CRC check passed, which can be used to detect errors in data transmission or storage. The design effectively ensures data integrity by enabling the detection of changes to raw data stored in memory or being transmitted over a network.
module top_module(
  input [n-1:0] in,
  input clk,
  output [m-1:0] out,
  output flag
);
