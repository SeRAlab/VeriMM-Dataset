
Design a Verilog module for an OFDM symbol generator that takes a 4-bit input data word and generates a pseudo-random sequence of symbols. The generator should have a clock and a reset input. On each rising edge of the clock, it should output a new symbol based on the input data. The output symbol should be a 4-bit value derived from the input data using a simple transformation (e.g., XOR with a constant value).
