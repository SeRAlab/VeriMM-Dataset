Design a 4-bit mod-6 counter that increments its count on each clock pulse when enabled. The counter resets to zero when the reset signal is active. It uses two registers to store intermediate values and ensures that the output wraps around after reaching the decimal value 6 (binary 0110), thereby preventing counts from exceeding 5. The output reflects the current count value unless it reaches the limit, in which case it is reset.
module top_module(
    input clk,
    input enable,
    input reset,
    output reg [3:0] q
