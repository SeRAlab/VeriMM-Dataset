
Design an NVMe command processing block that accepts commands for read and write operations. It should have the following inputs: a 2-bit command type (00 for read, 01 for write), a 32-bit address, and a 32-bit data input. The output should be a 32-bit data output for read commands and a status signal that indicates the success of the operation (1 for success, 0 for failure). The status should indicate success if the command is valid and the address is within the range 0 to 255.
