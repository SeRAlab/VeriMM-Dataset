Design a 4-bit Linear Feedback Shift Register (LFSR) that generates a pseudo-random sequence of bits. The LFSR takes a clock signal and a reset signal as inputs. Upon each clock cycle, if the reset is activated, the register clears to zero; otherwise, it shifts the current bit pattern to the right and appends the feedback bit generated from specific taps of the register. The output of the module provides the three least significant bits of the LFSR state, enabling the use of the generated sequence in various applications, including random number generation or simple state machine designs.
