Design a voltage sensor system that takes a 5-bit binary input representing a voltage level (from 0 to 31) and outputs a 3-bit binary code representing the voltage category. The categories are defined as follows: 000 for 0-10mV, 001 for 11-20mV, 010 for 21-30mV, and 011 for 31mV. For inputs above 31, the output should be 111 to indicate an out-of-range condition.
