Please act as a professional Verilog designer.

Design a Verilog module for a 2-to-1 multiplexer with 8-bit wide data inputs. The module should have a select signal to choose between the two inputs.

Module name:
    mux_2to1_8bit

Input ports:
    sel: Select signal.
    in0: 8-bit input 0.
    in1: 8-bit input 1.

Output ports:
    out: 8-bit output.

Implementation:
The output (out) should be equal to in0 if the select signal (sel) is 0, and equal to in1 if the select signal (sel) is 1.
