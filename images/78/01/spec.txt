Design a functionally efficient shift register with a parallel reset capability. This module, configured to hold 8 bits, shifts data on each rising edge of the clock when enabled. When the reset signal is active, both the shift register and the output are cleared to zero. On activation of the shift enable signal, it shifts new data bit into the least significant position and outputs the most significant bit (MSB) of the register.
module top_module(
  input clk,
  input data_in,
  input shift_en,
  input reset,
  output reg data_out
);
