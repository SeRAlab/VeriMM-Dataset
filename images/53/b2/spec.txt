Implement the Verilog module based on the following description.
Build a 3-bit up/down counter with an asynchronous positive edge triggered reset, synchronous enable signal, and synchronous direction control signal.
(1) reset: Resets counter to zero.
(2) enable: Enables the counter to count.
(3) direction: If high, counter counts up; if low, counter counts down.
(4) q: The current count of the counter.

module top_module(
    input clk,
    input reset,
    input enable,
    input direction,
    output reg [2:0] q);
