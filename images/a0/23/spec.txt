Design a D flip-flop with asynchronous reset and set functionality. The module, triggered on the rising edge of the clock, will output a low state when the reset signal is asserted, output a high state when the set signal is asserted, and otherwise capture the value of the input data signal 'd' to update the output 'q'.
module top_module(
    input  wire clk,
    input  wire reset,
    input  wire set,
    input  wire d,
    output reg q
);
