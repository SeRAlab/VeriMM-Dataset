

You are tasked with designing a verilog module for a simple calculator. The calculator should be able to perform basic arithmetic operations such as addition, subtraction, multiplication, and division. The calculator should have two input registers, A and B, and one output register, C. The calculator should also have a control input, op, which determines the operation to be performed.

The operations are as follows:
- op = 2'b00: C = A + B (addition)
- op = 2'b01: C = A - B (subtraction)
- op = 2'b10: C = A * B (multiplication)
- op = 2'b11: C = A / B (division)

You may assume that the input registers A and B are 8-bit unsigned integers and that the output register C is also an 8-bit unsigned integer. You may also assume that division by zero will not occur.

Design the verilog module for the calculator, named `simple_calc`, that takes in the inputs A, B, and op, and outputs the result C.
