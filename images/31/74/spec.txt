
Design a 7-stage pipeline processor where each stage has a specific function and passes data to the next stage. The stages are as follows: 
1. Instruction Fetch (IF)
2. Instruction Decode (ID)
3. Execute (EX)
4. Memory Access (MEM)
5. Write Back (WB)
6. Hazard Detection (HD)
7. Data Forwarding (DF)

The processor should handle basic instructions and ensure proper data flow through the pipeline. Implement a simple control mechanism to manage the pipeline stages and ensure that the data dependencies are respected.
