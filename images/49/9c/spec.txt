Design a 16-bit wide base pointer register that stores a value based on clock signals. On the rising edge of the clock, if the reset signal is asserted, the register is cleared to zero. If the write signal is asserted, the register updates its stored value with the incoming 16-bit writeData. The current value of the register is continuously available at the output data.
