Design a 4-bit adder with carry-in capability and enable control. The module takes two 4-bit inputs, A and B, along with a carry-in input (Cin). When enabled, it calculates the sum of A, B, and Cin, generating a 4-bit output (Sum) and a carry-out (Cout). If the enable signal is low, the output will simply echo the value of A. Additionally, it checks if the resulting sum exceeds the maximum 4-bit value (15) to set the carry-out signal.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    input enable,
    output [3:0] Sum,
    output Cout
);
