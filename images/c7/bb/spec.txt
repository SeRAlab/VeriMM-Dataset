

You have been tasked with designing a verilog module that implements a 2-to-1 multiplexer using the following interface:

```
module mux_2_to_1 (
    output reg Y,
    input A,
    input B,
    input S
);
```

The module should have the following functionality:
- When S is 0, the output Y should be equal to A.
- When S is 1, the output Y should be equal to B.

Write the verilog code for the module and ensure that it synthesizes correctly.
