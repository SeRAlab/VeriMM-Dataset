

You are tasked with designing a verilog module that implements a 4-bit counter with synchronous reset functionality. The counter should be able to count up by 1 on every positive edge of the clock signal. Additionally, the counter should be reset to 0 when the reset input is asserted.

You should use the following inputs and outputs:

- `clk` (input): the clock signal
- `reset` (input): the reset signal
- `count` (output): the current value of the counter

Ensure that your module is synthesizable and that it follows best coding practices.
