Design a D-type flip-flop with asynchronous set and reset functionality. The flip-flop samples the D input on the rising edge of the CLK signal, outputting this value to Q. If the SET_B signal is asserted, Q is set to HIGH regardless of the D input, and if the RESET_B signal is asserted, Q is cleared to LOW. Additionally, the inverted output Q_N is provided, reflecting the current state of Q.
module top_module(
    input D,
    input CLK,
    input SET_B,
    input RESET_B,
    output reg Q,
    output Q_N
);
