Please act as a professional verilog designer.

Create a Verilog module for a 12-bit synchronous up counter with an enable signal, a load signal, and a load value input. The counter increments by 1 on each clock cycle when enabled and loads the given value when the load signal is active.

Module name:  
    up_counter_with_load  

Input ports:
    clk: Chip clock signal.
    rst: Active-high synchronous reset signal. Defined as 1 for chip reset and 0 for reset signal inactive.
    en: Enable signal for the counter.
    load: Load signal for the counter.
    load_value: 12-bit value to be loaded into the counter.

Output ports:
    q: Counter output signal with a data width of 12 bits.

Implementation:
Counter operation:
On every positive edge of the clock signal (clk), the counter register (q) is updated.
If the reset signal (rst) is high, the counter register (q) is set to 0.
If the load signal (load) is active, the counter register (q) is set to the load_value.
If the enable signal (en) is active, the counter increments by 1.
If the enable signal (en) is inactive, the counter remains unchanged.
