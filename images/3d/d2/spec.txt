Design an SR latch using D flip-flops. The SR latch should have two inputs S (set) and R (reset), and two outputs Q and Qn (not Q). The outputs should maintain their state until a change in the inputs occurs. If S is high and R is low, Q should be set to high. If S is low and R is high, Q should be reset to low. If both S and R are low, Q should maintain its previous state. If both S and R are high, it should be considered an invalid state and the outputs should be undefined.
