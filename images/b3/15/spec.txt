1. state S1 (out = 0).
2. state S2 (out = 1).

1. From state S1: If A = 1, then transition to state S2. If A = 0, stay in state S1.
2. From state S2: If A = 0, then transition to state S1. If A = 1, stay in state S2.

  input A,
  input [1:0] state,
  output reg [1:0] next_state,
  output reg out);
