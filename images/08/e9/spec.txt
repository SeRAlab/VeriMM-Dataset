Design an 8-bit SRAM cell that allows reading and writing of data. The SRAM should have the following inputs: `data_in` (8 bits for input data), `read_enable` (1 bit to control read operation), `write_enable` (1 bit to control write operation), and `address` (3 bits to select one of the 8 memory locations). The output should be `data_out` (8 bits for output data) which reflects the data from the addressed memory location when `read_enable` is high.
