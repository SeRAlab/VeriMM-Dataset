Design a priority encoder that determines the presence of active signals from two groups of inputs (A, B) and (C, D). The module outputs two bits, Y0 and Y1. Y0 is set to HIGH if at least one of the inputs from the first group (A or B) is HIGH. Similarly, Y1 is set to HIGH if at least one of the inputs from the second group (C or D) is HIGH. If all inputs in a group are LOW, the corresponding output is LOW.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input [3:0] C,
    input [3:0] D,
    output reg Y0,
    output reg Y1
);
