Design a Verilog module that implements a simplified version of the A* search algorithm. The module should take in a current state, a target state, and the costs associated with moving to adjacent states. It should output the next state to move to. The module should use a finite state machine (FSM) to manage the states and transitions based on the input costs. The A* algorithm should prioritize states based on their cost and heuristic values. Implement this in a way that emphasizes combinational logic for state selection and supports sequential logic for state management.
