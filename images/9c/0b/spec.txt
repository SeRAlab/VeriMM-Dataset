Design a clocked sequential circuit with a hold functionality. This module captures an input signal, `di`, on the rising edge of the clock unless the hold signal, `hld`, is asserted. When `hld` is low, the current input `di` is stored in a temporary register (`q1`), and the output register `q` is updated with the value of `q1`. Upon a reset (`rst`), both output `q` and internal register `q1` are cleared to zero. This design effectively creates a delay element with the ability to temporarily hold the stored value based on the `hld` input.
