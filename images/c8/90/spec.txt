

You are tasked with designing a Verilog module that implements a 2-input AND gate. The module should be named "and_gate" and have the following interface:

```
module and_gate(
    input a,
    input b,
    output y
);
```

The module should implement the following behavior: 

- When both inputs a and b are high (1), the output y should be high (1).
- In all other cases, the output y should be low (0).

Your implementation should be contained within a single module that is no more than 200 lines of Verilog code. You should not use any pre-existing Verilog modules or libraries.
