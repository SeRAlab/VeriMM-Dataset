
Design a simple branch predictor using a 2-bit saturating counter for each entry in the predictor table. The predictor should have a table size of 4 entries. The input should include the branch instruction address and the taken/not taken information. The output should indicate whether the branch is predicted to be taken or not taken based on the history stored in the predictor table. The output should also update the predictor table based on the actual outcome of the branch.
