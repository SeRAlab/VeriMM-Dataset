Design a Verilog module for a simple EEPROM cell that can store a single bit of data. The cell should have inputs for data (D), a write enable (WE), and a clock (CLK). When WE is high on the rising edge of CLK, the cell should store the input data bit. It should have an output (Q) that reflects the stored data. The cell should also have an asynchronous reset (RST) input that, when high, resets the stored data to 0 regardless of WE and CLK.
