Design a seven-segment display driver that converts a 4-bit binary input (value) to its corresponding seven-segment output (s7). The module includes inputs to control the display behavior; if the blank input is high, all segments are turned off. If the minus input is high, the display shows a minus sign. For valid hex digits (0-F), the driver outputs the corresponding segment activation patterns, with outputs inverted to suit common cathode displays.
module top_module(input  wire [3:0] value,
                input  wire       blank,
                input  wire       minus,
                output reg  [6:0] s7);
