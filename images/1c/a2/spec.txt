
Design a 2nd-order Infinite Impulse Response (IIR) filter using Verilog. The filter should be able to take an input sample and produce an output sample based on the IIR filter equation:

y[n] = a1*y[n-1] + a2*y[n-2] + b0*x[n] + b1*x[n-1] + b2*x[n-2]

Where:
- y[n] is the current output sample
- x[n] is the current input sample
- a1, a2, b0, b1, b2 are the filter coefficients (fixed-point).
- The design should include a state register to hold the previous outputs and inputs.
