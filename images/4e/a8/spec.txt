Design a basic calculator module that performs arithmetic operations on two signed 16-bit inputs, A and B, based on a 2-bit selection signal, Sel. The operations include addition (Sel=00), subtraction (Sel=01), multiplication (Sel=10), and division (Sel=11). In the division case, if B is zero, the output is set to a predefined error value (0x8000) to prevent division by zero. The result of the selected operation is output as a signed 16-bit value.
module top_module(
    input signed [15:0] A,
    input signed [15:0] B,
    input [1:0] Sel,
    output reg signed [15:0] Result
);
