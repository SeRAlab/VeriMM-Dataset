
Design a simple SATA controller state machine that manages three states: IDLE, TRANSMIT, and RECEIVE. The state machine should transition based on a clock signal and an input signal. The input signal will be a control signal that determines the next state. The system should start in the IDLE state and transition to TRANSMIT when the control signal is high, then to RECEIVE when another control signal is high. The state machine should return to IDLE when a reset signal is asserted.
