Implement a 4-bit ripple carry adder that combines two 4-bit binary numbers, `a` and `b`, along with an input carry bit (`cin`). The module outputs a 4-bit sum and a carry-out bit (`cout`). It utilizes individual full adder components for each bit position and propagates the carry through the adder chain. The addition operation is synchronized with a clock signal, while a reset signal initializes the carry register. The design is aimed at performing binary addition in a digital circuit reliably.
module top_module(
    input clk,
    input rst,
    input [3:0] a,
    input [3:0] b,
    input cin,
    output reg [3:0] sum,
    output reg cout
);
