Design a circuit that conditionally reverses the bits of an 8-bit input signal. When the enable signal (en) is asserted, the output (y) presents the bits of the input (a) in the reverse order. If the enable signal is not asserted, the output directly mirrors the input without modification.
module top_module(
		input wire [7:0] a,
		input wire en,
		output reg [7:0] y
	);
