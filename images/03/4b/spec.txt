Design a Serial-In Serial-Out (SISO) shift register that can shift in a serial input bit and shift out the oldest bit. The shift register should be 5 bits wide. It should have a clock input, a reset input, a serial input for data, and a serial output for the shifted data. On the rising edge of the clock, if the reset is low, the shift register should shift in the serial input bit and shift out the oldest bit. If reset is high, the output should be zeroed.
