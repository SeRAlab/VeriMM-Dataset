

You have been tasked with designing a module in Verilog that will implement a D-latch with an active-low asynchronous reset and a gated clock. The module should have the following inputs and outputs:

- `D`: input signal that holds the data to be stored in the latch
- `RESET_B`: input signal that resets the latch to a known state when active low
- `GATE`: input signal that enables the latch to store the data when high
- `Q`: output signal that represents the stored data
- `Q_N`: output signal that represents the complement of the stored data

Your module should be named `d_latch` and be contained within 200 lines of Verilog code. You should assume that the voltage supply signals have already been defined in a separate module.
