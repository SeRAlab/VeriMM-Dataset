
Design a 2-bit Up/Down counter in Verilog. The counter should increment or decrement its value based on a control signal (up_down). When the counter reaches its maximum value (3), it should roll over to 0 when counting up. Conversely, when it reaches its minimum value (0), it should roll over to 3 when counting down. The counter should have a reset input to reset its value to 0.
