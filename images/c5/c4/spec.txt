

You are tasked with designing a verilog module that implements a 2-to-1 multiplexer using only NAND gates. The module should have two input ports, `A` and `B`, and one select port, `S`. When `S` is high, the output `Y` should be equal to `A`, and when `S` is low, the output `Y` should be equal to `B`.

Write the verilog code for the 2-to-1 multiplexer module using only NAND gates. Assume that all inputs and outputs are single-bit signals.
