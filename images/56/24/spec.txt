Design a sensor interface module that converts temperature readings from Celsius to Fahrenheit while passing pressure and humidity readings directly to output. The module takes signed 16-bit temperature input and converts it using the formula for conversion to Fahrenheit, and outputs this value as a signed 16-bit value. It also outputs an unchanged 16-bit pressure value and an unchanged 8-bit humidity value.
module top_module(
  input signed [15:0] temperature,
  input [15:0] pressure,
  input [7:0] humidity,
  output signed [15:0] temp_out,
  output [15:0] press_out,
  output [7:0] hum_out
);
