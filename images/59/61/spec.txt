Design a D flip-flop with an asynchronous set feature. On the rising edge of the clock (CP), the output Q is updated to the value of the data input D. However, if the asynchronous set signal (SD) is low, the output Q is immediately set to high regardless of the clock input. This module allows for controlled synchronous data storage with the added capability of overriding the output to a predetermined state.
