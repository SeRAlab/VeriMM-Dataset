Design an 8-bit digital-to-analog converter (DAC) using Verilog. The DAC should take an 8-bit binary input and output a corresponding analog voltage level (simulated as a 10-bit output representing the voltage level). The relationship between the input binary value and the output voltage level can be assumed to be linear, where the maximum binary input value of 255 corresponds to the maximum output voltage level of 1023. The DAC should also include a latch to hold the output value stable until the next input is provided.
