

You are tasked with designing a Verilog module that can perform a specific operation on input signals. The module should be named "opModule" and should have the following inputs and outputs:

Inputs:
- clk (1-bit): the clock signal
- iA (4-bit): the first input signal
- iB (4-bit): the second input signal
- iC (1-bit): a control signal that determines the operation to be performed
    - If iC is 0, the module should output the bitwise AND of iA and iB
    - If iC is 1, the module should output the bitwise OR of iA and iB

Outputs:
- oResult (4-bit): the result of the operation

The module should be designed using behavioral Verilog and should be completely self-contained. You should not use any other modules in your design.
