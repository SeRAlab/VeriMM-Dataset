Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a frequency divider. 
A frequency divider is a digital circuit that takes an input clock signal and produces an output clock signal that has a lower frequency than the input clock signal. 
The output clock signal has a frequency that is a fraction of the input clock signal frequency.

Your module should have the following inputs and outputs:

Inputs: 
- clk_in: the input clock signal
- reset: a reset signal that sets the output clock signal to zero
- divider: a parameter that determines the division ratio of the frequency divider

Output: 
- clk_out: the output clock signal with a frequency that is a fraction of the input clock signal frequency

Your module should implement the following functionality:
- The output clock signal should have a frequency that is a fraction of the input clock signal frequency, determined by the value of the divider parameter.
- The output clock signal should be reset to zero when the reset input is asserted.
- The output clock signal should continue to operate normally after the reset input is de-asserted.

To implement the frequency divider, you should use Verilog code to divide the input clock signal frequency by the value of the divider parameter. 
You should then use this divided clock signal to generate the output clock signal. 
You should also use the reset input to set the output clock signal to zero.
