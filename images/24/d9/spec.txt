Design an 8-bit Digital-to-Analog Converter (DAC) using Verilog. The DAC takes an 8-bit input and converts it to a corresponding analog voltage level represented as a 10-bit output. The relationship is defined as follows: the 8-bit input (0-255) corresponds to the analog output (0-1023). The output is simply the input value scaled by a factor of 4. For example, an input of `00000000` (0 in decimal) results in an output of `0000000000` (0 in decimal), and an input of `11111111` (255 in decimal) results in an output of `1111111111` (1020 in decimal).
