Design a 5-to-32 decoder. The decoder will take a 5-bit binary input and activate one of the 32 outputs corresponding to the binary value of the input. When the input is 5'b00000, the output should be 32'b00000000000000000000000000000001. When the input is 5'b00001, the output should be 32'b00000000000000000000000000000010, and so on up to 5'b11111 which should activate 32'b10000000000000000000000000000000.
