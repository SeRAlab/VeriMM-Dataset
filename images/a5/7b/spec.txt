Design a module that performs bitwise shifting operations on a 32-bit input number. This module outputs three results: the first is the left-shifted value of the input number based on a specified shift amount, the second is the right-shifted result using a logical shift, and the third is the result of an arithmetic right shift, which preserves the sign bit for signed integers. The functionality is essential for operations such as multiplication and division by powers of two.
module top_module(
  input [31:0] input_num,
  input [4:0] shift_amount,
  output [31:0] left_shifted,
  output [31:0] right_shifted,
  output [31:0] arithmetic_shifted
);
