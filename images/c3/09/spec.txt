

You have been tasked with designing a 4-to-1 multiplexer using Verilog. The multiplexer should have 4 data inputs (D0, D1, D2, D3), 2 select inputs (S0, S1), and 1 output (Y). The select inputs determine which data input is sent to the output. If S0 and S1 are both 0, then D0 is sent to the output. If S0 is 0 and S1 is 1, then D1 is sent to the output. If S0 is 1 and S1 is 0, then D2 is sent to the output. If S0 and S1 are both 1, then D3 is sent to the output.

Design a Verilog module that implements this 4-to-1 multiplexer. Your module should be named "mux_4_to_1" and should have the following ports:

- D0, D1, D2, D3 (input): 4 data inputs
- S0, S1 (input): 2 select inputs
- Y (output): 1 output

Your module should use an "always" block to determine which data input is sent to the output based on the select inputs.
