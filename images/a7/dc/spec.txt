Design a shift register circuit with parallel load capabilities. This module receives a clock input, a control signal to determine whether to parallel load a new value or shift the existing data, and a serial input for shifting. When the parallel_load signal is high, it loads the value of serial_in into the register. Otherwise, it shifts the register contents left, inserting the serial_in value at the least significant bit. The output provides both the serial output from the least significant bit and the complete content of the shift register.
