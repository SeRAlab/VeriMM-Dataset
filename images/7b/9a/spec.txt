Design a 4-bit shift register with load and shift capabilities. On the rising edge of the clock, if the reset signal is asserted, the register clears to zero. If the load signal is active, it loads the input data into the register. If the shift signal is active, it shifts the data to the left, inserting a zero in the least significant bit. The current state of the shift register is available at the output.
module top_module(input clk, input load, input [3:0] data_in, input shift, input reset, output reg [3:0] data_out);
