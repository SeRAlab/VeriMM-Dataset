It also detects and outputs overflow conditions for both operations, ensuring correct flags are set when the result exceeds the representable range for signed 16-bit integers.
module top_module(
    input signed [15:0] a,
    input signed [15:0] b,
    input sub,
    output reg signed [15:0] result,
    output reg overflow
);
