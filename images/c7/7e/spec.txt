

You have been tasked with designing a 4-input NAND gate using behavioral Verilog. The gate should have four inputs and one output. The inputs should be named A_N, B_N, C, and D and the output should be named Y. The gate should be named "nand4bb". Additionally, you should include voltage supply signals for VPWR, VGND, VPB, and VNB.

Write the Verilog code for the "nand4bb" module that meets the above requirements.
