Design a hazard detection unit for a pipelined processor. This module checks for read-after-write data hazards by comparing register identifiers from the instruction fetch (IF) stage with those in the execution (EX) stage. If a hazard is detected (i.e., an instruction is trying to read a register while it is being written by a previous instruction that is in a memory read stage), the module asserts a data hazard signal and triggers a flush of the instruction in the IDEX pipeline stage to prevent incorrect execution. The outputs include a data hazard flag and a control signal to flush the pipeline as appropriate.
