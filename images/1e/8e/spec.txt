Design a simple Model Predictive Control (MPC) system that calculates the next state of a system based on the current state and a control input. The system will maintain a state register and update it based on the control input every clock cycle. The control input will be a 4-bit value, and the state will be a 4-bit value that gets updated based on the formula: next_state = current_state + control_input. The state can wrap around when exceeding 15 (4-bit maximum).
