
Create a 2-channel DMA controller that can transfer data from a source address to a destination address. The DMA controller should have the following inputs: a clock signal (clk), a reset signal (rst), a start signal (start), two source addresses (src_addr0, src_addr1), two destination addresses (dest_addr0, dest_addr1), and an enable signal for each channel (enable0, enable1). The DMA controller should output a done signal (done) indicating when the transfer is complete. The controller should switch between the two channels based on the start signal and whether each channel is enabled.
