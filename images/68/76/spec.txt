Design a 4-to-1 multiplexer with synchronous reset functionality. The module accepts a 2-bit select signal to choose one of four 1-bit input signals (sig_in), and outputs that selected signal (sig_out) on the clock's rising edge. If the reset signal is asserted, the output is set to LOW.
module top_module(
    input clk,
    input reset,
    input [1:0] select,
    input [3:0] sig_in,
    output reg sig_out
);
