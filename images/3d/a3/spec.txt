Design a Huffman encoding combinational logic circuit that takes a 4-bit input representing symbols and outputs a 3-bit encoded value according to a predefined Huffman code set. The Huffman codes for the symbols are:  
- Symbol '0' -> Code '000'  
- Symbol '1' -> Code '001'  
- Symbol '2' -> Code '010'  
- Symbol '3' -> Code '011'  
- Symbol '4' -> Code '100'  
- Symbol '5' -> Code '101'  
- Symbol '6' -> Code '110'  
- Symbol '7' -> Code '111'
