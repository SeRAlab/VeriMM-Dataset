
Create an 8-bit ADC (Analog to Digital Converter) model in Verilog. The ADC should take a 4-bit binary input representing an analog voltage level and produce an 8-bit digital output. The output should be the input value scaled to fit in an 8-bit range. If the input is larger than the maximum representable value (15 for 4 bits), the output should be capped at 255 (maximum 8-bit value).
