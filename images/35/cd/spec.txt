
Design a simple decision tree for classifying an input based on three binary features: A, B, and C. The decision tree should classify the input into one of two classes: 0 or 1. The rules for classification are as follows:
- If A is 1 and B is 0, then the output is 1.
- If A is 0 and C is 1, then the output is 1.
- Otherwise, the output is 0.
