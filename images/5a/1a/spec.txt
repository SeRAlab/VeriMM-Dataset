Design a 4-bit shift register with synchronous load and reset capabilities. On the rising edge of the clock, if the reset signal is active, the output is set to zero. If the load signal is high, the input value is loaded into the output. If the shift signal is activated, the register shifts its output bits to the left by one position, introducing a zero at the least significant bit.
module top_module(
    input clk,
    input rst,
    input load,
    input [3:0] in,
    input shift,
    output reg [3:0] out
);
