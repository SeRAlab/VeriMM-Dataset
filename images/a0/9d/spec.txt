Design a circuit that functions as a 6-to-1 multiplexer followed by an 8-bit shift register. The multiplexer selects one of the six 4-bit input data lines based on a 3-bit select signal (sel). The selected output is then shifted into an 8-bit shift register on the negative edge of the clock, with a synchronous reset to initialize the register to zero. The final output is the result of adding the current value of the shift register to the 4-bit multiplexer output, producing an 8-bit output.
module top_module( 
    input clk,
    input reset,            // Synchronous reset
    input [2:0] sel, 
    input [3:0] data0,
    input [3:0] data1,
    input [3:0] data2,
    input [3:0] data3,
    input [3:0] data4,
    input [3:0] data5,
    output [7:0] final_output
);
