Design a low-latency 128-entry FIFO (First-In-First-Out) memory buffer for streaming data. This module allows for the pushing of 32-bit instructions along with an associated error flag, and it generates a ready signal indicating if new instructions can be pushed into the FIFO. It also manages the popping of instructions, signaling when valid data is available and allowing the retrieval of the instruction and its error status. The FIFO supports reset and flush operations to clear its contents while maintaining occupancy tracking to prevent overflows.
