
You are tasked with designing a Verilog module that implements a simple 2-input AND gate. The module should have the following inputs and outputs:

- Two input ports, `a` and `b`, each 1-bit wide.
- One output port, `c`, also 1-bit wide.

The AND gate should implement the following functionality:

- Whenever both `a` and `b` are high (i.e., logic level 1), `c` should be high as well.
- In all other cases, `c` should be low (i.e., logic level 0).

Write the Verilog code for this module, including any necessary declarations, assignments, and logic gates.
