Design a D flip-flop with asynchronous set and reset functionality. The module captures the input D on the rising edge of the clock signal (CLK), while also allowing an asynchronous set (SET) to set the output Q to HIGH, or an asynchronous reset (RESET) to set Q to LOW regardless of the clock signal. When neither SET nor RESET is active, the output Q reflects the value of D at the clock edge.
