Design a 4-bit synchronous counter that increments its value on the rising edge of the clock when the `count` signal is high. If the `rst` signal is asserted, the counter resets to zero. The current counter value is output through the `counter_value` wire. In the absence of a count signal, the counter maintains its existing value.
module top_module(
		input	clk, 
		input	rst, 
		input	count, 
		output [3:0]	counter_value
	);
