Design a flip-flop based stage enable circuit that holds the output signal based on a clock input. The output, `stage_enable_out`, is reset to LOW when the reset signal is asserted. When the reset is deasserted, if the `stage_enable_in` input is HIGH during a clock positive edge, the `stage_enable_out` is set to HIGH; otherwise, it is set to LOW. This module effectively acts as a latch that controls the stage enabling logic based on the clock and an input enable signal.
module top_module(
clk,
reset,
stage_enable_in,
stage_enable_out
);
