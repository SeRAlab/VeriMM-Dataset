Design a one-bit wide, 2-to-1 multiplexer using a LUT (Look-Up Table). The module selects between two inputs, D0 and D1, based on the control signal, ctrl. When ctrl is low (0), the output S takes the value of D0; when ctrl is high (1), S takes the value of D1. The LUT implements the multiplexing functionality by utilizing the specific initialization (INIT) configuration to determine the output based on the given inputs and control signal.
module top_module(
  input ctrl,
  input [0:0] D0,
  input [0:0] D1,
  output [0:0] S
);
