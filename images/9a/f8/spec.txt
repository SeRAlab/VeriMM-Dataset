Design a 3-bit up/down counter that can be loaded with zeros. On each rising edge of the clock, if the load signal is high, the counter resets all internal registers to zero. If the load signal is low, the counter increments (when up_down is high) or decrements (when up_down is low) the value of an internal register (reg3) while shifting values through reg1 and reg2. The output reflects the value of reg1, which is updated in each clock cycle based on the counting direction.
module top_module(
    input clk,
    input load,
    input up_down,
    output reg [2:0] out
);
