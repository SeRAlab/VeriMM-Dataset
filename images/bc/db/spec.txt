Implement a Verilog module for a 10-bit register with enable and synchronous reset. The register should have a clock input `clk`, a synchronous reset input `rst`, an enable input `en`, a 10-bit data input `D`, and a 10-bit output `Q`. When `rst` is high, `Q` should be set to 0 on the next rising edge of `clk`. When `en` is high, `Q` should be set to `D` on the rising edge of `clk`.

module register10(
	input wire clk,
	input wire rst,
	input wire en,
	input wire [9:0] D,
	output reg [9:0] Q
);
