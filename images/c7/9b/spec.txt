

You are tasked with designing a module that takes in two inputs `a` and `b` and generates an output `x` based on the following rules:
- If `a` is greater than `b`, `x` should be set to `a`.
- If `b` is greater than `a`, `x` should be set to `b`.
- If `a` and `b` are equal, `x` should be set to `a`.

You should implement this module using Verilog, and ensure that it is synthesizable.

Declare the following signals in your module:
- `a`: a 4-bit input signal
- `b`: a 4-bit input signal
- `x`: a 4-bit output signal
