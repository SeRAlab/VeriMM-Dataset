

You are tasked with designing a Verilog module for a simple counter. The counter should increment by 1 every clock cycle and reset to 0 when a reset signal is asserted. The counter value should be outputted to a 4-bit register. Additionally, the module should have an enable signal that allows the counter to increment when asserted and freezes the counter when deasserted.

The module should have the following inputs and outputs:
- `clk`: clock signal
- `rst_n`: active low reset signal
- `en`: enable signal
- `out`: 4-bit output register for counter value

You should implement the module using behavioral Verilog.
