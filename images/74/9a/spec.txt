Create a Verilog module for a 4-bit Johnson counter. The counter should cycle through its states on the positive edge of the clock.

Time 0ns: clk = 0, count = 4'b0000.
Time 5ns: clk = 1, count = 4'b0000.
Time 10ns: clk = 0, count = 4'b1000.
Time 15ns: clk = 1, count = 4'b1000.
Time 20ns: clk = 0, count = 4'b1100.
Time 25ns: clk = 1, count = 4'b1100.
Time 30ns: clk = 0, count = 4'b1110.
Time 35ns: clk = 1, count = 4'b1110.
Time 40ns: clk = 0, count = 4'b1111.

module johnson_counter (
	input clk,
	output reg [3:0] count);
