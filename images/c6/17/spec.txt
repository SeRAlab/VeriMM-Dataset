

You have been hired to design a module that takes a 32-bit input and outputs a 16-bit slice of the input. The slice should start from the 10th bit and end at the 25th bit (inclusive). You should implement this module using Verilog.

Your module should have the following input and output ports:
- input: a 32-bit input (named `in`)
- output: a 16-bit slice of the input (named `out`)

Write the Verilog code for this module.
