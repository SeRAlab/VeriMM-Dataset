
Design a 16-bit timer with the following specifications:
1. The timer counts up from 0 to 65535 (maximum value for 16 bits).
2. It has a clock input (clk) and an asynchronous reset input (reset).
3. When reset is high, the timer should reset to 0.
4. On each rising edge of the clock, if reset is low, the timer should increment by 1.
5. When the timer reaches 65535, it should wrap around to 0 on the next increment.
