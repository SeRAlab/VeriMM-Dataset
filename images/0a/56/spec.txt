
Design a 32-bit Linear Feedback Shift Register (LFSR) using Verilog. The LFSR should be capable of generating pseudo-random sequences based on an initial seed value. The feedback polynomial to be used for the LFSR is defined by the taps at positions 32, 22, 18, 17, and 13. The LFSR should shift and generate a new bit on each clock cycle, and it should have a reset functionality that sets the state back to the initial seed.
