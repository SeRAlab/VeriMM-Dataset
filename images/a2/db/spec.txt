Design a D flip-flop with asynchronous reset and enable functionalities. On the rising edge of the clock (CLK), if RESETn is asserted low, the output Q is set to LOW. If RESETn is high and ENn is low, the output Q retains its previous state. When both RESETn and ENn are high, the output Q is updated to the value of the input D. The module also outputs the inverted state of Q as Q_N.
module top_module(
    input CLK,
    input D,
    input RESETn,
    input ENn,
    output reg Q,      // Change output to reg
    output Q_N
);
