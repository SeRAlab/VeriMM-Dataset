

You are tasked with designing a module that performs the logical AND operation on four input bits (A, B, C, and D) and outputs the result to a single output bit (X). The module should be named `my_and4` and should be written in Verilog. 

Your module should have the following interface:
```
module my_and4 (
    input A,
    input B,
    input C,
    input D,
    output reg X
);
```

You are required to implement the AND operation using only basic logic gates (AND, OR, NOT). The output bit X should be high (1'b1) only when all the input bits are high, and low (1'b0) otherwise.

Your implementation should not exceed 200 lines of Verilog code. You should also ensure that your code is properly formatted and commented.
