
Create a Verilog module that implements a simple Dynamic Voltage and Frequency Scaling (DVFS) controller. The module should include an input for the current load (as a binary value), a clock signal, and an output for setting the operating frequency. The frequency will be set based on the load levels. For example, if the load is low, set a low frequency; if the load is high, set a high frequency. Choose three levels of load: low (0-3), medium (4-6), and high (7-15).
