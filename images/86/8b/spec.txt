Design a circuit that functions as a selectable output generator based on an input control signal. It includes a two-input AND gate (receiving inputs A1 and A2) and a two-input OR gate (receiving inputs A3 and A4). The output X is determined by the control input B1; if B1 is high, X reflects the result of the AND gate, while if B1 is low, X reflects the result of the OR gate.
module top_module(
    input  A1,
    input  A2,
    input  A3,
    input  A4,
    input  B1,
    output X
);
