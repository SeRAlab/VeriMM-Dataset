

You have been tasked to design a Verilog module that implements a simple 4-bit adder. The module should have two 4-bit input ports, A and B, and one 4-bit output port, S. The module should also have a single input port, C, that represents the carry-in bit. The output port, S, should represent the sum of A, B, and C. Your task is to write the Verilog code to implement this module.
