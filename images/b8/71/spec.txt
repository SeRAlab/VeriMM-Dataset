Design a D flip-flop with an enable signal that controls its operation. When the enable input is LOW, the output resets to zero. When the enable input transitions to HIGH, the flip-flop captures the value of the data input on the rising edge of the enable signal, storing it in the output. This module effectively acts as a controlled latch, only updating its output when enabled.
