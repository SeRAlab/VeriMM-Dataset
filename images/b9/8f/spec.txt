Design a 16-to-1 multiplexer using Verilog. The multiplexer has a selection signal to choose between sixteen 1-bit input signals.

Module name:  
    mux_16to1  

Input ports:
    a0: Input signal a0.
    a1: Input signal a1.
    a2: Input signal a2.
    a3: Input signal a3.
    a4: Input signal a4.
    a5: Input signal a5.
    a6: Input signal a6.
    a7: Input signal a7.
    a8: Input signal a8.
    a9: Input signal a9.
    a10: Input signal a10.
    a11: Input signal a11.
    a12: Input signal a12.
    a13: Input signal a13.
    a14: Input signal a14.
    a15: Input signal a15.
    sel: 4-bit Selection signal.

Output ports:
    y: Output signal.

Implementation:
Multiplexer operation:
Depending on the value of the 4-bit selection signal (sel), the output (y) is assigned the value of one of the sixteen input signals (a0 to a15).
