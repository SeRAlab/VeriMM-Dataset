Design a dual-input, three-output combinational logic block that implements a specific logic function based on inputs A1, A2, and B1. The output Y is driven high when both A1 and A2 are high. If A1 is high and A2 is low, the output Y follows the value of input B1. If A1 is low and A2 is high, output Y receives the value of the VPWR input (which represents the power supply). In all other cases, Y is set to low. This module effectively behaves like a configurable logic gate with a conditional dependency on multiple inputs.
module top_module(
    output reg Y,  // Change from output to output reg
    input A1,
    input A2,
    input B1,
    input VPWR
);
