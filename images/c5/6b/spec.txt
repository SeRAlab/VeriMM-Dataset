

You have been given the task of designing a verilog module for a 4-bit adder with carry-in and carry-out. The module should have the following inputs and outputs:
- A: a 4-bit input
- B: a 4-bit input
- Cin: a single bit input for carry-in
- Sum: a 4-bit output for the sum of A and B
- Cout: a single bit output for carry-out

You should create a verilog module that implements the 4-bit adder with carry-in and carry-out. You can assume that the inputs A and B are valid and do not need to be checked for correctness. The output Sum should be the 4-bit sum of A and B, and Cout should be the carry-out bit.
