Design a 4-tap Finite Impulse Response (FIR) filter with a fixed set of coefficients. The filter should take 8-bit input samples and produce an 8-bit output. The coefficients for the FIR filter are to be defined as follows: 1, 2, 3, 4. The design should have an input clock and a reset signal, and the output should be valid on the rising edge of the clock after a sample is input.
