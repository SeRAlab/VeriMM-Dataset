Design a 3-to-1 register file with 8 registers, each 8 bits wide, capable of storing and retrieving data based on clock cycles and a reset signal. On a rising clock edge, when the write enable signal is asserted, the data specified by `wrt_data` is written to the register designated by `reg_wrt_dst`. The module also outputs the contents of the registers specified by `reg_src` and `reg_dst` to `reg_src_dat` and `reg_dst_dat`, respectively. Upon activation of the reset input, the registers are initialized with predefined values ranging from 0 to 7.
module top_module(
    input clk,
    input rst,
    input [2:0] reg_src,
    input [2:0] reg_dst,
    input [2:0] reg_wrt_dst,
    input reg_wrt,
    input [7:0] wrt_data,
    output reg [7:0] reg_src_dat,
    output reg [7:0] reg_dst_dat
);
