Design a circuit that implements an 8-bit barrel shifter. This module shifts the input data `d_in` left by a specified number of bits determined by the `shift_amount` input, which can range from 0 to 7. The shifting operation occurs on the rising edge of the clock signal, with zero-padding introduced on the right for each shift operation. The output `d_out` provides the shifted result.
module top_module(
    input [7:0] d_in,
    input [2:0] shift_amount,
    input clk,
    output [7:0] d_out
);
