Design a 4-bit wide multiplexer that selects one of the 16 possible inputs based on a 4-bit selector signal. The multiplexer has an enable input (EN) that controls whether the output is active; when EN is low, the output is set to 0. If EN is high, the output reflects the selected 4 bits from the 64-bit input based on the value of the selector. Each selector value corresponds to a different segment of the input, allowing for flexible data routing in digital circuits.
module top_module(
    input [15:0] in,
    input [3:0] sel,
    input EN,
    output reg [3:0] out
);
