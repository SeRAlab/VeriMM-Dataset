Design a D-type flip-flop with synchronous reset functionality. The module captures the value of the input 'd' on the rising edge of the clock signal 'clk'. If the 'reset' signal is asserted, the output 'q' is set to LOW; otherwise, 'q' takes the value of 'd'. Additionally, the output 'qb' represents the complement of 'q'. This design serves as a fundamental building block for memory storage in sequential logic circuits.
