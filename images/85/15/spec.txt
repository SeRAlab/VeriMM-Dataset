Develop a 32-bit Arithmetic Logic Unit (ALU) that performs various arithmetic and logical operations based on a 3-bit opcode input. This ALU can add, subtract, perform bitwise AND, OR, and XOR operations, as well as execute left and right bitwise shifts on the two 32-bit inputs, A and B. Additionally, the module calculates a carry-out (COUT) based on the operation being performed, accommodating both addition and subtraction operations for proper arithmetic overflow handling. The output of the operation is provided on the Y output.
module top_module(
    input [31:0] A,
    input [31:0] B,
    input [2:0] OPCODE,
    input CIN,
    output reg COUT,
    output reg [31:0] Y
);
