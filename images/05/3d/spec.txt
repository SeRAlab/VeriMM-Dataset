
Design a 16-bit DRAM cell with the following features:
1. The cell should have a data input (16 bits), a read enable signal, a write enable signal, and a clock signal.
2. When the write enable signal is high, the input data should be stored in the cell on the rising edge of the clock.
3. When the read enable signal is high, the stored data should be output on a 16-bit data output line.
4. The cell should maintain its data until it is overwritten by a new write operation.
