Design a comparator circuit for 8-bit inputs that determines the relational status between two inputs, `in1` and `in2`. It generates three output signals: `out_eq`, which indicates equality between `in1` and `in2`; `out_gt`, which signals that `in1` is greater than `in2`; and `out_lt`, which indicates that `in1` is less than `in2`. The outputs are updated continuously based on the values of `in1` and `in2`.
module top_module(
  input [7:0] in1,
  input [7:0] in2,
  output reg out_eq,
  output reg out_gt,
  output reg out_lt
);
