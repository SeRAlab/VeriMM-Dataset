Create a digital phase shifter that takes a 3-bit input representing the phase (0 to 7) and outputs a 3-bit signal that is delayed by the specified phase amount. The output will effectively be the input signal shifted according to the specified phase value, with the phase value determining the number of bits to shift. A phase of 0 means no shift, while a phase of 7 means a shift of 7 bits (wrapping around). The circuit should implement a basic right shift operation based on the input phase.
