Design a synchronous FIFO RAM module with configurable width and depth. It supports write and read operations based on control signals: when the write enable signal (we) is asserted, the module writes the input data (wdata) to the specified write address (waddr) on the rising edge of the clock (clk). Regardless of the write operation, it continuously outputs the data stored at the specified read address (raddr) into the output (rdata). This design allows for a simple and effective way to manage memory storage in a digital system.

   clk,
   we,
   waddr,
   wdata,
   raddr,
   rdata
   );
