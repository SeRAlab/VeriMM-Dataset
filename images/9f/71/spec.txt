Design a circuit that detects both rising and falling edges of an asynchronous input signal. The module uses a clock signal to sample the asynchronous input and produce two output signals: one indicating a rising edge and the other indicating a falling edge. The edge detection is controlled by an enable signal, and both outputs are reset to LOW when a reset signal is activated. This design is suitable for applications requiring accurate timing of signal transitions in digital systems.
module top_module(
    input clk, // clock signal
    input async_sig, // asynchronous signal
    input rst, // reset signal
    input en, // enable signal
    output rise, // rising edge detected
    output fall // falling edge detected
);
