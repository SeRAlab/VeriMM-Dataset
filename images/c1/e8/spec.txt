

You are tasked with designing a module that takes in 5 input signals and outputs a single signal. The five input signals are A1, A2, A3, A4, and B1. The output signal is Y. The module should be named "my_module".

The module should operate as follows:
- If A1, A2, A3, A4, and B1 are all high (1), Y should be high (1).
- If A1, A2, A3, A4, and B1 are all low (0), Y should be low (0).
- If any of A1, A2, A3, or A4 are low (0), regardless of the value of B1, Y should be low (0).

You should write the complete code for the module "my_module" in Verilog.
