
Design a simple PCIe endpoint controller that handles a read request and provides the corresponding data back to the requester. The controller should have a state machine with the following states: IDLE, READ_REQUEST, and DATA_READY. The controller accepts a read request signal and a 5-bit address input. When in the READ_REQUEST state, it must read data from a predefined memory array and transition to the DATA_READY state, where it outputs the data. The controller should return to the IDLE state after sending the data.
