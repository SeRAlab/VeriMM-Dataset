
Create an 8-bit DRAM cell with the following functionality:
- Input: 8-bit data (D), a write enable signal (WE), and a clock signal (CLK).
- On the rising edge of the clock, if WE is high, the 8-bit data (D) is stored in the cell. If WE is low, the stored data remains unchanged.
- The output (Q) should reflect the stored data.
