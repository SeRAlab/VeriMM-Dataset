Design a binary adder module that takes two sets of four 1-bit wide inputs (totaling eight inputs) along with an additional input to compute an XOR operation. The module computes the XOR of the first four inputs with the additional input and the XOR of the last four inputs with the same input. It then sums these two results along with the additional input, producing a 3-bit wide output consisting of the least significant three bits of the sum (x, y, z) and an overflow flag (ovf) indicating whether the sum exceeds 3 bits.
module top_module(
    input [3:0] a,b,c,d,e,f,g,h,i,
    output reg [2:0] x,y,z,
    output reg ovf );
