Design an 8-bit adder with carry-in capability. The module takes two 8-bit inputs, A and B, along with a carry-in signal (CI). It computes the sum of A and B, adding an additional 1 if CI is high. The result is provided as a 9-bit output (SUM), and a carry-out signal (COUT_N) is generated, indicating whether there was a carry from the most significant bit.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input CI,
    output [8:0] SUM,
    output COUT_N
);
