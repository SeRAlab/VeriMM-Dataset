Implement a synchronous read/write RAM module with 256 entries, each 16 bits wide. The module utilizes an address input to access and manipulate memory locations based on a clock signal. It features chip enable functionality (`ram_cen`), and a write enable signal (`ram_wen`) that supports different write modes: full overwrite, upper byte write, and lower byte write. The output (`ram_dout`) provides the stored data at the current address registered during the last clock cycle, ensuring data integrity during read operations.
