Design a one-bit wide, 2-to-1 multiplexer. The module takes two input signals, 'a' and 'b', and a select signal 'sel'. Depending on the value of 'sel', the output 'y' will be equal to 'a' when 'sel' is 0, and equal to 'b' when 'sel' is 1. The design utilizes basic logic gates, including NOT, AND, and OR gates, to achieve the selection functionality.
module top_module(
    input a,
    input b,
    input sel,
    output y
);
