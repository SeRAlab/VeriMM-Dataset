Design a synchronous 8-bit shift register that shifts its content to the left by one position on each rising edge of the clock signal when the shift enable (shen) is asserted. If the reset (rst) signal is active, the shift register initializes to zero. The input data (din) is inserted into the least significant bit position during the shift operation, while the current contents of the shift register are outputted to dout.
module top_module(
  input clk,
  input rst,
  input shen,
  input [7:0] din,
  output reg [7:0] dout
);
