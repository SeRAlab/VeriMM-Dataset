Design a 4-bit DRAM cell that can read and write data. The DRAM cell should have inputs for a 4-bit data input (DIN), a read/write control signal (RW), and a clock signal (CLK). The output should be a 4-bit data output (DOUT) that reflects the data stored in the cell upon a read operation. If RW is high during a clock edge, the data from DIN should be written to the cell. If RW is low, the data from the cell should be outputted to DOUT.
