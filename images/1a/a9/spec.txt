Design a 4-bit DRAM cell with read and write operations. The DRAM cell should have a data input (D), a data output (Q), a write enable (WE), a read enable (RE), and a clock (CLK). When WE is high, the data input should be written into the memory cell on the rising edge of the clock. When RE is high, the data stored in the memory cell should be available at the output Q on the next clock cycle.
