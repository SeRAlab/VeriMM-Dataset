
Design a 2nd-order IIR filter that takes a 16-bit signed input sample and produces a 16-bit signed output sample. The filter coefficients should be defined as parameters, and the filter must maintain state for the previous two input and output samples. The filter equation can be expressed as:
output[n] = b0 * input[n] + b1 * input[n-1] + b2 * input[n-2] - a1 * output[n-1] - a2 * output[n-2]
where b0, b1, b2, a1, a2 are the coefficients.
