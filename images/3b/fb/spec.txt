
Design a 5-stage pipeline processor that can perform a simple instruction such as ADD, SUB, AND, OR. Each stage should be defined as follows:
1. Instruction Fetch (IF)
2. Instruction Decode (ID)
3. Execute (EX)
4. Memory Access (MEM)
5. Write Back (WB)

The processor should have a simple register file to hold values and output the final result after executing the instruction through the pipeline. The instruction format can be simplified as 3 bits for the opcode and 5 bits for the operands.
