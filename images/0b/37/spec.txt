Design an 8-bit DRAM cell that allows for reading and writing data. The DRAM cell should have the following inputs: a clock signal (clk), a read enable signal (read_en), a write enable signal (write_en), an 8-bit data input (data_in), and a 3-bit address input (addr). The output should be an 8-bit data output (data_out) that reflects either the data read from the specified address when read_en is high or the data written to the specified address when write_en is high.
