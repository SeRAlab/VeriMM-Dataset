

Design a 4-bit multiplexer module using Verilog. The module should have 4 input ports, 2 select lines, and 1 output port. The select lines should be used to select which input port should be connected to the output port. The select lines should be active high. If the select lines are both low, the output port should be 0. If the select lines are both high, the output port should be 0 as well. All other combinations of select lines should select the corresponding input port and connect it to the output port.

You should name your module "mux4" and the input ports should be named "in0", "in1", "in2", and "in3". The select lines should be named "sel0" and "sel1". The output port should be named "out".
