
Design a 16-bit shift register with a parallel load capability. The shift register should have an input for a 16-bit data, a clock signal, a load signal, and a shift signal. When the load signal is high, the data should be loaded into the shift register. When the shift signal is high, the contents of the shift register should shift right by one bit on each clock cycle. If both load and shift are low, the register should hold its value. The output of the shift register should be available as a 16-bit output.
