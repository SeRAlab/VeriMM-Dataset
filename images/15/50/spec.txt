
Design an 8-bit EEPROM cell that can store a single byte of data. The cell should have the following functionalities:
1. A write operation that takes an 8-bit data input and a write enable signal (we) to store the data.
2. A read operation that outputs the stored data when a read enable signal (re) is asserted.
3. The output should remain valid as long as re is asserted, otherwise it should hold the last value.
4. The EEPROM cell should have an asynchronous reset (rst) which initializes the stored data to 0 when asserted.
