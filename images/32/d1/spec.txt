Design a power gating circuit that takes a 2-bit control signal and a 4-bit data input. When the control signal is '00', the data output should be '0000'. When the control signal is '01', the data output should equal the data input. When the control signal is '10', the data output should be '0000'. When the control signal is '11', the data output should equal the data input. Implement this using Verilog.
