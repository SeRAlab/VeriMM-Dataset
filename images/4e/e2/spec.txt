Design a combinational logic circuit that takes a 4-bit input and produces three different 3-bit outputs: `out_both`, which indicates when pairs of adjacent bits are both high (AND operation); `out_any`, which indicates when at least one in each pair of adjacent bits is high (OR operation); and `out_different`, which shows when pairs of adjacent bits differ (XOR operation). This design can be used for signal processing or to derive various conditions from a digital state represented by the input.
module top_module( 
    input [3:0] in,
    output [2:0] out_both,
    output [3:1] out_any,
    output [3:0] out_different );
