Design a fan speed controller that takes an input temperature value and adjusts the fan speed accordingly. The fan speed should be set to one of four levels based on the temperature range: 0 (off), 1 (low), 2 (medium), or 3 (high). The temperature input will be a 7-bit value representing temperature in degrees Celsius, where:
- 0-20 degrees: Fan speed 0
- 21-30 degrees: Fan speed 1
- 31-40 degrees: Fan speed 2
- 41 and above: Fan speed 3
The system should have a clock input and a reset input for proper operation.
