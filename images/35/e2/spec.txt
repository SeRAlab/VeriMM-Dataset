Design an 8-bit DRAM cell that can read and write data. The cell should have the following inputs: `write_enable` (1-bit), `address` (3-bits), and `data_in` (8-bits) for writing, and `data_out` (8-bits) for reading. When `write_enable` is high, the data from `data_in` should be written to the address specified. When `write_enable` is low, the data at the specified address should be outputted to `data_out`.
