Design a UART transmitter that takes an 8-bit data input and transmits it serially at a defined baud rate. The UART transmitter should also support a start bit and a stop bit, thus forming a complete frame. The module should have a clock input, a data input, a transmit enable signal, and a serial output. The module should shift out the bits in the following order: start bit (0), data bits (LSB first), and stop bit (1).
