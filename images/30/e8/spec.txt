
Design a Verilog module to calibrate a thermal sensor reading. The temperature reading is a 10-bit binary value, and it needs to be adjusted based on a calibration offset, which is also a 10-bit binary value. Your task is to create a module that outputs the calibrated temperature value. The calibrated value is calculated as: 
calibrated_temp = raw_temp + calibration_offset.
The output should also be a 10-bit binary value, and if the sum exceeds the maximum 10-bit value (1023), it should be clamped to 1023.
