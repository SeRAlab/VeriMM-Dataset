
Design a Verilog module to perform nearest neighbor interpolation on a 2x2 image block. The module should take 4 pixel values as input (each represented by 8 bits) and output 4 interpolated pixel values (also 8 bits each). The output pixels should correspond to the nearest neighbor values for a 2x2 block, effectively enlarging the image by a factor of 2. The input pixels are A, B, C, and D, arranged as follows:
```
A B
C D
```
The output pixels should be:
```
A A B B
A A B B
C C D D
C C D D
```
