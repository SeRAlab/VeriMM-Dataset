Implement a light control module that adjusts the brightness of an output light based on an ambient light sensor input and a set of control signals. If the ambient light level (photo) falls below a specified threshold, the module outputs maximum brightness. Otherwise, it computes the brightness level based on the control signals, scaling the maximum brightness according to the value of these signals, which represent a fractional value dependent on the number of control lines (k).
module top_module(
  input photo,
  input [k-1:0] ctrl,
  output light
);
