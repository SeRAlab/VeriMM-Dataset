Design a Verilog module that implements a simple version of the Rapidly-exploring Random Tree (RRT) algorithm. The module should take a start point and a target point as inputs, and each clock cycle it should randomly generate a point in the space, and then find the nearest point in the tree to this random point. It should then create a new node in the direction of the random point, effectively expanding the tree. The module should output the new node created in each cycle.
