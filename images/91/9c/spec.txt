Design a 100-bit circular shift register that can rotate its contents left or right based on control signals. The module features a 'load' input to initialize the register with a 100-bit data value and a clock input for synchronization. The 'ena' input selectively enables either a left rotation (when ena=01) or a right rotation (when ena=10) on each clock cycle. If ena is set to 00, the register retains its current state. The output is always the current state of the shift register, allowing external access to the shifted data.
module top_module(
    input clk,
    input load,
    input [1:0] ena,
    input [99:0] data,
    output reg [99:0] q);
