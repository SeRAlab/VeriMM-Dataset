Design a 4-to-1 multiplexer with data forwarding capabilities. The multiplexer should take four 4-bit input signals (A, B, C, D) and two select lines (S0, S1) to choose which input to forward to the output (Y). Additionally, implement a data forwarding logic that checks if the selected input is equal to the previous output, and if so, it should forward the output directly without passing through the multiplexer.
