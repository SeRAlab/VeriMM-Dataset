Design a simple SPI master controller that can send and receive data in 8-bit format. The controller should include signals for Chip Select (CS), Serial Clock (SCK), Master Out Slave In (MOSI), and Master In Slave Out (MISO). It should have a control input to initiate the transmission and outputs for the data received from the slave. The controller should handle the clock generation and data shifting properly. The design should include a state machine to manage the SPI transmission process.
