Design a 5-bit EEPROM cell read/write interface. The interface should have the following inputs: a 5-bit data input (`data_in`), a 5-bit address input (`address`), a write enable signal (`we`), and an output for the stored data (`data_out`). When `we` is high, the `data_in` should be stored at the given `address`. When `we` is low, the data stored at the `address` should be output on `data_out`.
