Implement a finite state machine (FSM) that cycles through four states (S0, S1, S2, S3) in response to a clock signal, providing synchronization and functionality. The FSM outputs a 3-bit selection signal (`sel`) and a single-bit signal (`digit`) based on the current state. In state S0, `sel` is set to 000 and `digit` to 1; in S1, `sel` is 001 and `digit` remains 1; in S2, `sel` is 011 and `digit` changes to 0; and in S3, `sel` is set to 100 with `digit` back to 1. The reset input initializes the FSM back to state S0 when active low, ensuring proper startup behavior.
module top_module(input clk_i,input reset_n,output reg [2:0] sel,output reg digit);
