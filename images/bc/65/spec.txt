Design a 3-bit magnitude comparator with the ability to select which bits to compare based on a 2-bit selection input. The module takes two 3-bit inputs, A and B, and outputs a 2-bit result indicating the comparison outcome: '10' if A is greater than B, '01' if A is less than B, '00' if they are equal, and '11' if the comparison is invalid (when both inputs are not selected). The selection logic allows the comparison to be made on one of the three bits of the inputs, or it can be disabled entirely.
module top_module(
  input [2:0] A,
  input [2:0] B,
  input [1:0] sel,
  output reg [1:0] out
);
