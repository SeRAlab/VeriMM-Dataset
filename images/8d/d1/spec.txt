Design a 4-bit barrel shifter that allows for both left and right shifts based on the input control signals. When the enable signal is high, the module shifts the input data left or right by a specified amount, determined by the shift_amt input, with shift_dir indicating the direction of the shift (0 for left, 1 for right). If the enable signal is low, the output retains the original input data unchanged.
module top_module(
    input [3:0] data_in,
    input [1:0] shift_amt,
    input shift_dir,
    input enable,
    output reg [3:0] data_out
);
