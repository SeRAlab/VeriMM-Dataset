
You are tasked with designing a module that performs a logical majority function on three input bits, A, B, and C, and outputs the result as X. The logical majority function is defined as follows: if two or more of the input bits are high (1), then the output is high (1); otherwise, the output is low (0).

Your module should be named `majority` and should have the following interface:
```
module majority (
    input  A,
    input  B,
    input  C,
    output X
);
```
You should use only combinational logic to implement the majority function. Your design should be optimized for area and delay, and should be synthesizable using standard cell libraries.
