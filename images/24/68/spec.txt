Design a JK flip-flop in Verilog. The JK flip-flop should have inputs J, K, and a clock signal CLK. It should also have an output Q that represents the current state of the flip-flop. The flip-flop should toggle its output Q based on the values of J and K at the rising edge of the clock. If both J and K are high, the flip-flop should toggle. If J is high and K is low, the output should be set high. If J is low and K is high, the output should be set low. If both J and K are low, the output should remain unchanged.
