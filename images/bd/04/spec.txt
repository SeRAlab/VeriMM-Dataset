Implement an 8-bit rotating register that can be controlled through various inputs. The module provides functionality to load a value from the switches (SW) into the register, rotate its contents either left or right, and reset the register to zero. The control signals include a clock for synchronization, a load signal to input data, a rotate direction signal to specify the rotation (right or left), and a wrap signal that determines whether the bits should wrap around during the rotation or be lost. The output of the register is displayed on the LEDR, allowing for visual feedback of the current state of the register.
