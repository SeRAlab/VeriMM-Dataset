Design a one-bit wide, 2-to-1 multiplexer. The module takes two input signals (i0 and i1) and a select line. When the select line is low (0), the output (d) reflects the value of i0; when the select line is high (1), the output reflects the value of i1. The output is registered, ensuring it holds the selected input value based on the select signal.
module top_module(
    input  i0,
    input  i1,
    input  select,
    output reg d
    );
