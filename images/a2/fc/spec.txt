Design a one-bit wide, active-low 2-to-1 multiplexer. The circuit selects between two input signals, `a` and `b`, based on the value of the `sel` input. When `sel` is 0, the output reflects the value of `a`, and when `sel` is 1, the output reflects the value of `b`. The final output is inverted, providing an active-low output that is high when neither input is selected.
module top_module(
    input  a,
    input  b,
    input  sel,
    output out
);
