
Design a 4-bit SRAM cell that can store a 4-bit data input. The SRAM cell should have the following functionalities:
1. An input data bus (4 bits) to write data into the cell.
2. A control signal for write (wr) and read (rd) operations.
3. An output data bus (4 bits) to read data from the cell.
4. A clock signal for synchronous operation.
5. When the control signal is high (wr = 1), data should be written to the cell on the positive edge of the clock. When the control signal is low (rd = 1), the data should be read from the cell.
The SRAM cell should be able to handle both write and read operations but not at the same time.
