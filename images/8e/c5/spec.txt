Design a one-bit wide, 2-to-1 multiplexer with an additional logical control mechanism. The module selects the output based on the combination of two select inputs, sel_b1 and sel_b2. When both selects are HIGH, the output is set to input b; otherwise, it outputs input a. The use of combined select signals allows for enhanced control and possible cascading of multiplexing functionalities.
module top_module(
    input a,
    input b,
    input sel_b1,
    input sel_b2,
    output reg out_always
);
