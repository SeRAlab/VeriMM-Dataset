Design a D flip-flop with asynchronous reset functionality. When the reset signal (rst_n) is low, the flip-flop output (q) is set to the initial state (ini_state). On the rising edge of the clock (clk), the output updates to the value of the data input (d), effectively capturing the input value. This design is suitable for synchronous data storage with initialization capability upon reset.
