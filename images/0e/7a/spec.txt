
Design a 4-bit flash memory cell with basic read, write, and erase operations. The memory cell will have an enable signal for write and erase operations, and an output signal for reading the stored data. The operations are defined as follows:
- Write operation: When the enable signal is high, data is written to the memory cell.
- Erase operation: When the enable signal is low, the memory cell is set to zero.
- Read operation: The data stored in the memory cell should be outputted when the read signal is high.
