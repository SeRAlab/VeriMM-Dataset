Design a 2nd order Infinite Impulse Response (IIR) filter in Verilog. The IIR filter should take a 16-bit input sample and produce a 16-bit output. The filter coefficients can be defined as fixed-point values, and the filter should perform the operation using the following difference equation: 

y[n] = b0 * x[n] + b1 * x[n-1] + b2 * x[n-2] - a1 * y[n-1] - a2 * y[n-2] 

where b0, b1, b2 are the feedforward coefficients and a1, a2 are the feedback coefficients. The filter should have two internal states to store the previous output samples. The design should also include a clock and reset functionality.
