

You are tasked with designing a module that implements a 2-to-1 multiplexer using Verilog. The module should have three inputs: two data inputs and one select input. The output of the module should be the value of the selected input.

Your module should be named `mux2to1` and have the following interface:

```
module mux2to1 (
                input data_in_0,
                input data_in_1,
                input select,
                output data_out
                );
```

The input `data_in_0` is a single bit input representing the first data input. The input `data_in_1` is a single bit input representing the second data input. The input `select` is a single bit input representing the select input. The output `data_out` is a single bit output representing the selected input.

If `select` is 0, then `data_out` should be equal to `data_in_0`. If `select` is 1, then `data_out` should be equal to `data_in_1`.

You may assume that the inputs `data_in_0`, `data_in_1`, and `select` are valid and will not change during the execution of the module.
