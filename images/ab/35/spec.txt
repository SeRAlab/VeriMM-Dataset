Design a 4-bit up/down counter with load capability. When reset is asserted, the counter initializes to zero. If the load signal is active, the counter loads the value from the load_data input. Depending on the up_down control signal, the counter increments or decrements its value on each clock cycle.
module top_module(
    input clk,
    input reset,
    input up_down,
    input load,
    input [3:0] load_data,
    output reg [3:0] count
);
