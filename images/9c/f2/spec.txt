Implement a Verilog module for a 3-bit synchronous up/down counter. The counter should increment on every positive clock edge when the up signal is high, and decrement when the down signal is high. If both signals are low, the counter should hold its value. If the reset signal is high, the counter should be reset to 0.

module up_down_counter_3bit (
  input clk,
  input reset,
  input up,
  input down,
  output reg [2:0] count);
