Design a simple arithmetic logic unit (ALU) that performs various operations on a 32-bit input based on a 2-bit operation selector and an enable signal. The ALU supports logical operations (AND, OR, XOR, NOT), arithmetic operations (addition, subtraction, multiplication, and division), and initializes the output to zero on reset. The output is updated on the rising edge of the clock when the enable signal is asserted, allowing for controlled operation based on the specified function.
module top_module(
  input clk,
  input reset_n,
  input [31:0] in_data,
  input [2:0] op_select, // Changed to 3 bits to accommodate all operations
  input enable,
  output reg [31:0] out_data
);
