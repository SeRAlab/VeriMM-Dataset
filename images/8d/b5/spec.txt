Design a bridge module that facilitates communication between a processor and two peripheral devices. It decodes the processor's address input to determine if it relates to either of the two devices and asserts write enable signals for the selected device if the appropriate conditions are met. When the processor reads data, the module will output data from the selected device or a default value if neither device is addressed. It also generates a hardware interrupt signal that indicates the status of both devices. The module effectively multiplexes address and data signals between the processor and devices, maintaining coordination for data transfers and interrupt handling.
