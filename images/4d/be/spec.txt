Design a Verilog module for a 2-to-4 binary decoder with an enable signal. The decoder outputs one-hot encoding of the 2-bit input when the enable signal is active.

Module name:  
    decoder_2to4  

Input ports:
    enable: Enable signal for the decoder.
    binary_in: Binary input data with a data width of 2 bits.

Output ports:
    one_hot_out: One-hot encoded output data with a data width of 4 bits.

Implementation:
Decoder operation:
If the enable signal (enable) is active, the decoder outputs one-hot encoding of the 2-bit input (binary_in). Otherwise, all outputs are zero.
