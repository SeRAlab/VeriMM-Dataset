
Design a JK latch in Verilog that operates based on the following specifications:
- The latch has two inputs: J and K, and one output Q.
- The behavior is as follows:
  - If J = 1 and K = 0, then Q is set to 1 (Set condition).
  - If J = 0 and K = 1, then Q is reset to 0 (Reset condition).
  - If J = 1 and K = 1, then Q toggles its current state (Toggle condition).
  - If J = 0 and K = 0, then Q retains its previous state (Hold condition).
- Implement the JK latch using D flip-flops and combinational logic.
