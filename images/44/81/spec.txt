Implement a dual-function arithmetic module that operates as either a multiplier or an adder based on a 2-bit selection input. When the select input is `00`, the module outputs the lower 4 bits of the product from multiplying two 4-bit operands. For any other select value, it produces the sum of the two operands. This design effectively functions as a 4-bit wide arithmetic logic unit (ALU) with two distinct operations determined by the selection signal.
module top_module(
    input [1:0] select,
    input [3:0] operand1,
    input [3:0] operand2,
    output [3:0] result
);
