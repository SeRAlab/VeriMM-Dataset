
You are tasked with designing a module that takes in a 4-bit input signal `in`, and outputs a 2-bit signal `out` based on the following conditions:
- If the input signal is less than 5, output `00`.
- If the input signal is between 5 and 9 (inclusive), output `01`.
- If the input signal is greater than 9, output `10`.

Write a verilog module `signal_converter` that implements this functionality.
