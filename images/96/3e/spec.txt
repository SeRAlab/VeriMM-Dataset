Please act as a professional verilog designer.

Create a Verilog module for a 10-bit synchronous down counter with an active-high synchronous reset signal and an enable signal. The counter decrements by 1 on each clock cycle when enabled.

Module name:  
    down_counter  

Input ports:
    clk: Chip clock signal.
    rst: Active-high synchronous reset signal. Defined as 1 for chip reset and 0 for reset signal inactive.
    en: Enable signal for the counter.

Output ports:
    q: Counter output signal with a data width of 10 bits.

Implementation:
Counter operation:
On every positive edge of the clock signal (clk), the counter register (q) is updated.
If the reset signal (rst) is high, the counter register (q) is set to 0.
If the enable signal (en) is active, the counter decrements by 1.
If the enable signal (en) is inactive, the counter remains unchanged.
