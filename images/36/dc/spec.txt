Design a Verilog module that performs 3x3 image convolution operation. The module should take a 3x3 matrix as input and a 3-bit binary number as a kernel. The output should be a single 8-bit value representing the convolution result. Assume the input matrix values and kernel values are provided as 8-bit unsigned integers. The kernel should be represented as a 9-bit value, where the MSB is the scaling factor for the output. Implement the logic to multiply corresponding elements and sum them to produce the output.
