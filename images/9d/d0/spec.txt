Design a 16-bit barrel shifter capable of performing both left and right shifting operations based on a control signal. When the control signal is high, the module shifts the input data left by a specified number of bits indicated by the shift_amount input. Conversely, when the control signal is low, it shifts the input data right by the same amount. The result is output as a 16-bit value.
module top_module(
    input [15:0] data_in,
    input [3:0] shift_amount,
    input control,
    output [15:0] data_out
);
