Design a Verilog module that simulates a simple SLAM algorithm, maintaining a position and a map that updates based on sensor inputs. The module should take sensor data (a 4-bit input representing distance measurements) and a control signal to update the position (2-bit input for direction: 00 = North, 01 = East, 10 = South, 11 = West). The output should be the current position represented as a 4-bit value. The module should also have a reset signal to initialize the position to 0.
