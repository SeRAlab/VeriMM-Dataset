
Design a simple Lempel-Ziv-Welch (LZW) decompressor in Verilog. The decompressor should take as input a compressed code stream and output the original uncompressed data. The input will be an 8-bit compressed data stream, and the output will be an 8-bit uncompressed data stream. The decompressor will have a clock input for synchronization and will process one code at a time.
