Design a 4-to-1 multiplexer that selects one of four one-bit inputs (in0, in1, in2, in3) based on two selection inputs (sel0 and sel1). The output 'out' will reflect the chosen input according to the binary value represented by sel0 and sel1, where sel = 00 selects in0, 01 selects in1, 10 selects in2, and 11 selects in3.
module top_module(
  input in0,
  input in1,
  input in2,
  input in3,
  input sel0,
  input sel1,
  output out
);
