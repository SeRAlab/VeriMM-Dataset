Design a D-flip-flop with an asynchronous reset. The flip-flop should have the following ports:
- D: Data input
- CLK: Clock input
- RST: Asynchronous reset input (active high)
- Q: Data output
- Qn: Inverted data output

When RST is high, Q should be reset to 0 regardless of the clock. On the rising edge of CLK, if RST is low, Q should take the value of D.
