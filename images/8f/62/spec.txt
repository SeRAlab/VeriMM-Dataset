Develop a 4-bit up-counter with asynchronous load capability. The counter increments its value on each positive clock edge unless reset, in which case it resets to zero. When the load signal is asserted, the counter loads a specified 4-bit input value instead of incrementing. The design utilizes a dual-register mechanism to manage state transitions and ensure proper counting functionality based on the load and reset control signals.
module top_module(
    input clk,
    input reset,
    input load,
    input [3:0] data,
    output reg [3:0] count
);
