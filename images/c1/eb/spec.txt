

You are tasked with designing a verilog module that implements a 4-bit adder with a carry-in input. The module should have four inputs: `A`, `B`, `Cin`, and `Clk`, and two outputs: `Sum` and `Cout`. The module should use a synchronous design approach where the output is updated on the rising edge of the clock signal. 

In addition, the module should have a reset input, `Rst`, which when asserted, sets the output `Sum` to 0 and the `Cout` to 0. The module should also have an enable input, `En`, which when deasserted, should hold the output `Sum` and `Cout` to their current values.

You are given the following skeleton code to start with:

```
module adder_4bit(Cin, A, B, Clk, En, Rst, Sum, Cout);
  input Cin, A, B, Clk, En, Rst;
  output [3:0] Sum;
  output Cout;

  // Your code here

endmodule
```

Please complete the module and ensure that it meets the requirements specified above.
