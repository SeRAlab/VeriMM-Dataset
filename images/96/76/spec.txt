Design a synchronous 8-bit register adder module. On the rising edge of the clock, if the reset signal is active, it clears the output register Q to zero. If the load signal is asserted, it loads the input data D into the register Q. Otherwise, it adds the value of D to the current value of Q, effectively implementing an accumulator functionality.
module top_module(
    input clk, rst, load,
    input [7:0] D,
    output reg [7:0] Q
);
