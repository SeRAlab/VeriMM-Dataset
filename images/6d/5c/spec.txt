Design a module that displays the two's complement of a 4-bit input on a 7-segment display. The module takes a 4-bit `data_in` input and an enable signal `en` to control which of the four 7-segment outputs (seg_a, seg_b, seg_c, and seg_d) is updated. It computes the two's complement of the input by inverting the bits and adding one. The computed value is then converted into a corresponding 7-segment representation and assigned to the enabled output. The digit selection is managed through an internal 2-bit register, allowing for selective display of the computed value on the appropriate segment.
module top_module(
    input clk,               // Added clk input
    input [3:0] data_in,
    input [3:0] en,
    output reg [6:0] seg_a,
    output reg [6:0] seg_b,
    output reg [6:0] seg_c,
    output reg [6:0] seg_d
);
