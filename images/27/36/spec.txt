
Design a 4-bit SRAM cell that allows for read and write operations. The SRAM cell should include the following signals: `data_in` (4 bits), `data_out` (4 bits), `we` (write enable), `re` (read enable), and `clk` (clock). When `we` is high, the `data_in` should be written to the SRAM cell on the rising edge of `clk`. When `re` is high, the data stored in the SRAM cell should be output to `data_out` on the rising edge of `clk`. If both `we` and `re` are high at the same time, the write operation should take priority over the read operation.
