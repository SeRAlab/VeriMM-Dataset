

You are tasked with designing a verilog module that implements a D flip-flop with a clock enable and a clear input. The module should have the following inputs and outputs:

Inputs:
- `clk`: clock input
- `d`: data input
- `ce`: clock enable input
- `clr`: clear input

Outputs:
- `q`: output

The module should implement the following behavior:
- When the `clr` input is high, the output `q` should be low, regardless of the other inputs.
- When the `ce` input is low, the output `q` should hold its previous value, regardless of the other inputs.
- When the `ce` input is high and the `clr` input is low, the output `q` should follow the input `d` on the rising edge of the clock `clk`.

You can use any necessary intermediate signals.
