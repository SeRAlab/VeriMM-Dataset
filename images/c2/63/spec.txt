

You have been tasked with designing a verilog module that implements a 4-to-1 multiplexer (MUX) with an enable signal. The module should have the following inputs and outputs:

Inputs:
- `in0`, `in1`, `in2`, `in3`: 1-bit data inputs to the MUX
- `en`: 1-bit enable signal

Outputs:
- `out`: 1-bit data output from the MUX

Your module should be named `mux4_en` and should use the `always` block for combinational logic. You should assume that the `en` signal is active high. If `en` is low, the output should be 0.
