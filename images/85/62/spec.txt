Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state W (output 1).
2. state X (output 0).
3. state Y (output 1).
4. state Z (output 0).

State transitions:
1. From state W: If f = 1, then transition to state X. If f = 0, then transition to state Z.
2. From state X: If f = 1, then transition to state Y. If f = 0, then transition to state W.
3. From state Y: If f = 1, then transition to state Z. If f = 0, then transition to state W.
4. From state Z: If f = 1, then transition to state X. If f = 0, then transition to state W.

Assume that a one-hot code is used with the state assignment y[3:0] = 0001(W), 0010(X), 0100(Y), 1000(Z)

Write a Verilog for the signal Y1, which is the input of state flip-flop y[1], for the signal Y2, which is the input of state flip-flop y[2]. Derive the Verilog by inspection assuming a one-hot encoding.
