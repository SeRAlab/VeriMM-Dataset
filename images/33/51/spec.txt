
Design a JK flip-flop in Verilog that implements the behavior of a synchronous JK flip-flop with an enable input (E). The flip-flop should change its state on the rising edge of the clock when the enable input is high. The flip-flop's next state is determined by the J and K inputs as follows:
- If J = K = 0, the output remains the same (no change).
- If J = 1 and K = 0, the output sets to 1.
- If J = 0 and K = 1, the output resets to 0.
- If J = K = 1, the output toggles.
