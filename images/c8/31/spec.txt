Please act as a professional Verilog coder. Create a module that implements a 4-bit binary counter with a synchronous reset input. The counter should increment on the rising edge of the clock input and reset to zero when the reset input is high. The module should have two inputs: a clock input and a reset input, and one output: a 4-bit binary output that represents the current count of the counter.
