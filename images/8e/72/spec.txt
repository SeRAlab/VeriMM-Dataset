Implement the Verilog module based on the following description.
You are given a seven-bit input vector in[6:0]. We want to compute some relationships between the bits and their neighbours: 
// (1) out_sum: Each bit of this output vector should indicate the sum of the corresponding input bit and its neighbour to the left (higher index). For example, out_sum[4] should indicate the sum of in[4] and in[3]. Since in[0] has no neighbour to the left, the answer is obvious so we don't need to know out_sum[0]. 
// (2) out_or: Each bit of this output vector should indicate whether either the corresponding input bit or its neighbour to the right are '1'. For example, out_or[2] should indicate if either in[2] or in[1] are 1. Since in[6] has no neighbour to the right, the answer is obvious so we don't need to know out_or[6]. 
// (3) out_xor: Each bit of this output vector should indicate whether the corresponding input bit is different from its neighbour to the left. For example, out_xor[1] should indicate if in[1] is different from in[0]. For this part, treat the vector as wrapping around, so in[6]'s neighbour to the left is in[5].
