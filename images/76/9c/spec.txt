Design a negative-edge-sensitive D flip-flop with reset and enable functionality. The module samples the input data 'din' on the rising edge of the clock 'clk' when the enable signal 'en' is asserted. If the reset signal 'rst' is active, the output 'q' is set to zero regardless of the enable signal. Otherwise, if 'en' is low, the output retains its previous value, effectively holding the data.
