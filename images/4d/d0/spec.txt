Design a 32-bit up counter that increments on each clock cycle when enabled. The counter resets to zero when the reset signal is active low or when it reaches a specified maximum count, defined by the input max_count. When count_en is high, the counter will continue counting; otherwise, it will hold its value.
module top_module(
    input clk,
    input reset,
    input count_en,
    input [31:0] max_count,
    output reg [31:0] count
);
