
Design a Verilog module that performs matrix inversion for a 2x2 matrix. The module should take a 2x2 matrix as input and output its inverse. The input matrix is represented as four separate inputs (a, b, c, d), with the output being represented as four separate outputs (inv_a, inv_b, inv_c, inv_d). The inversion formula for a 2x2 matrix is as follows:
If the input matrix is:
| a  b |
| c  d |
The inverse is given by:
| inv_a  inv_b |
| inv_c  inv_d |
where:
inv_a = d / (ad - bc)
inv_b = -b / (ad - bc)
inv_c = -c / (ad - bc)
inv_d = a / (ad - bc)
If the determinant (ad - bc) is zero, the matrix is not invertible, and the outputs should be set to zero.
