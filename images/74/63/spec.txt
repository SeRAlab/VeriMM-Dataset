Design a byte splitter circuit that takes a 16-bit input and outputs two 8-bit values. The higher 8 bits of the input (bits 8 to 15) are shifted and assigned to the output `out_hi`, while the lower 8 bits of the input (bits 0 to 7) are directly assigned to the output `out_lo`.
module top_module(
    input wire [15:0] in,
    output wire [7:0] out_hi,
    output wire [7:0] out_lo
);
