Develop a circuit that performs both bitwise and logical XOR operations on two 4-bit input vectors, a and b. The module produces a 4-bit output for the bitwise XOR, which is calculated using logical operations, as well as a separate output for the logical XOR, which directly uses the XOR operator. Additionally, the circuit generates an 8-bit output consisting of the bitwise negations of both input vectors concatenated together. This design serves to illustrate various logical operations and their results on the input data.
module top_module(
    input [3:0] a,
    input [3:0] b,
    output [3:0] out_xor_bitwise,
    output out_xor_logical,
    output [7:0] out_not
);
