Design a 3-level decision tree that takes in three binary inputs (x0, x1, x2) and produces a single binary output (y). The decision tree should follow these rules:
1. If x0 = 0, then y = x1.
2. If x0 = 1 and x1 = 0, then y = 0.
3. If x0 = 1 and x1 = 1, then y = x2.
The output y represents the classification based on the input conditions.
