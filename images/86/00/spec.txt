Design a generic n-bit counter with configurable width. The counter increments or decrements its output value based on control signals. When enabled (EN), if the LOAD signal is active, the counter loads a value from the input D. If LOAD is not active, the counter increments its current value when the DOWN signal is inactive and decrements when DOWN is active. It also features a synchronous reset that sets the counter output (Q) to zero when RESET is asserted.

	CLK,
	RESET,
	D,
	Q,
	EN,
	LOAD,
	DOWN
);
