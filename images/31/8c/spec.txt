
Design a 4-bit DRAM cell that can store a 4-bit value and has a read and write functionality. The cell should be able to hold the value until it is updated with a new value. The inputs should include a 4-bit data input (D), a write enable signal (WE), and a clock signal (CLK). The output should provide the 4-bit stored value (Q) when reading (WE = 0).
