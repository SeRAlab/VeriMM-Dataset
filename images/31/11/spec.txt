Design a 5-stage pipeline for a simple processing unit that performs addition and writes the results to a register. The stages are: Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). Each stage should be able to hold its data until the next clock cycle. The input should be two operands (A and B) to be added together, along with a clock signal and a reset signal.
