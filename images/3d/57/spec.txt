Design a fixed-priority arbiter in Verilog that grants access based on a fixed priority order. The arbiter should have 4 request inputs (req[3:0]), a grant output (grant[3:0]), and a clock input (clk). The arbiter should prioritize requests in the order: req[3] > req[2] > req[1] > req[0]. Only one grant signal should be high at any time, corresponding to the highest priority request that is active.
