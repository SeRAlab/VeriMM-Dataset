
Design a Verilog module that performs bilinear interpolation on a 2x2 pixel block. The module should take four input pixel values (P00, P01, P10, P11) and the fractional coordinates (X_frac, Y_frac) representing the position within the block. The output should be the interpolated pixel value (P_out) calculated using the bilinear interpolation formula.

The bilinear interpolation formula is given as:
P_out = (1 - X_frac) * (1 - Y_frac) * P00 + (X_frac) * (1 - Y_frac) * P01 + (1 - X_frac) * (Y_frac) * P10 + (X_frac) * (Y_frac) * P11
