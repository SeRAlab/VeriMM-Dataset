
Design an 8-bit DRAM cell with the following specifications:
1. The cell should store a single 8-bit value.
2. The cell should have a write enable signal (we) to allow writing new data.
3. The cell should have a read enable signal (re) to allow reading the stored data.
4. The cell should have a reset signal (rst) to clear the stored data.

The output should be the stored value when read enable is high and the write enable is low. If write enable is high, the 8-bit input should be stored in the cell. On reset, the cell should be cleared to 0.
