Design a 32-bit shifter module that performs different types of bit shifts based on a 2-bit operation input. The module accepts a 32-bit input (op1) and a 6-bit shift amount (shamt). Depending on the value of the operation input, it can perform a logical left shift, a logical right shift, or an arithmetic right shift. The result of the shift operation is output as a 32-bit result (res). If the operation input does not match any of the specified cases, the output is set to an undefined state.
module top_module(
        input   wire [31:0]   op1,
        input   wire [5:0]    shamt,
        input   wire [1:0]    operation,
        output  wire [31:0]   res
    );
