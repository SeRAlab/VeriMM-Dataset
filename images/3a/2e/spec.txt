Design a 24-bit digital-to-analog converter (DAC) output unit. The unit takes a 24-bit input representing a digital value and outputs a corresponding analog voltage level. The output should be scaled such that the maximum digital input (24'hFFFFFF) corresponds to a maximum output voltage of 3.3V. Implement the digital scaling logic to convert the digital value into an appropriate analog value using a fixed-point representation where 24 bits represent the integer part.
