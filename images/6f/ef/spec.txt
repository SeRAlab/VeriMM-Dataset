Design a circuit that determines the maximum value between two 8-bit inputs, A and B. The module continuously compares the inputs, and the output, MAX, will be assigned the greater of the two values. If A is greater than or equal to B, MAX outputs A; otherwise, it outputs B.
module top_module(
    input [7:0] A,
    input [7:0] B,
    output reg [7:0] MAX
);
