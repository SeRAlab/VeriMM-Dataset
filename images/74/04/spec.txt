Design a Verilog module for a 4-bit shift register with parallel load. The module should have inputs 'clk,' 'load,' 'data_in,' and 'shift_in,' and a 4-bit output 'data_out.' When 'load' is high, 'data_in' is loaded into the register; otherwise, the register shifts in 'shift_in' on each clock cycle.
module shift_register (
	input clk,
	input load,
	input [3:0] data_in,
	input shift_in,
	output reg [3:0] data_out);
