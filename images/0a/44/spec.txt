Design a 2-bit shift register with parallel load capability. The shift register should have a clock input, a reset input, a parallel load input, and a 2-bit data input. If the reset is asserted, the output should be set to 00. If the parallel load input is asserted, the data input should be loaded into the register. Otherwise, on each clock edge, the data in the register should shift left by one bit, with the least significant bit being filled with '0'. The output of the register should be visible on a 2-bit output signal.
