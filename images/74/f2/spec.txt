Design a 2-bit comparator that evaluates two 2-bit inputs, A and B. It produces two outputs: EQ, which indicates whether the bits of A and B are equal for each bit position, and GT, which signifies whether each bit of A is greater than the corresponding bit of B. The EQ output will have both bits set to 1 if A equals B, while the GT output reflects the comparison results for the individual bits of A and B.
module top_module(
    input [1:0] A,
    input [1:0] B,
    output reg [1:0] EQ,
    output reg [1:0] GT
);
