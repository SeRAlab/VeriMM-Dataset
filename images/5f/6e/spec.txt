Design a simple 8-bit wide synchronous RAM module with a capacity of 256 locations. On each rising edge of the clock, the module writes the value from `wdata` into the memory location specified by `addr`. The output `rdata` continuously reflects the data stored at the given `addr`, allowing for read operations while supporting simultaneous write operations.
module top_module(input clk, input [7:0] addr, wdata, output [7:0] rdata);
