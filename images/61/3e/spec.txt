Design a 4-to-1 multiplexer that selects one of the four 8-bit input signals (in1, in2, in3, in4) based on a 2-bit selection input (sel). When sel is 00, the output (out) will reflect in1; when sel is 01, it will output in2; for sel 10, it will output in3; and for sel 11, it will output in4. If the selection does not match any case, the output defaults to 0.
