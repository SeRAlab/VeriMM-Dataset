Design a control logic module for an Arithmetic Logic Unit (ALU) that outputs a corresponding control signal based on the operation type and function code provided as inputs. The module takes a 6-bit function code (funct_i) and a 2-bit operation code (ALUOp_i) to determine one of the several possible operations: addition, subtraction, bitwise AND, bitwise OR, or multiplication. It produces a 3-bit output (ALUCtrl_o) that specifies the desired ALU operation. If the ALU operation type is R-type, it decodes the function code to select the operation; otherwise, it uses the provided ALU operation code to directly set the output control signal.
