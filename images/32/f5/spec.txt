Design an 8-bit SRAM cell that allows for both read and write operations. The SRAM cell should have an 8-bit data input (D), an 8-bit data output (Q), a write enable signal (WE), and an address input (A). When WE is high, the input data D should be written to the memory location specified by A. When WE is low, the data stored at the memory location A should be output to Q.
