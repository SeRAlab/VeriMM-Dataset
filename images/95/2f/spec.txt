Design a 4-bit adder that computes the sum of four 4-bit inputs, A, B, C, and D. The module outputs a 4-bit sum and a single carry-out flag, which indicates if there is a carry from the addition of the most significant bit.
module top_module(
    input  wire [3:0] A,
    input  wire [3:0] B,
    input  wire [3:0] C,
    input  wire [3:0] D,
    output wire [3:0] SUM,
    output wire       CARRY
);
