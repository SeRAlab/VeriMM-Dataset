Design a one-bit wide, 2-to-1 multiplexer that selects between two input signals, in0 and in1, based on the value of the select line, sel. When sel is 0, the output out receives the value of in0; when sel is 1, out receives the value of in1. The output is implemented using a sequential logic block triggered by changes in the select line.
module top_module(output reg out, input in0, in1, sel);
