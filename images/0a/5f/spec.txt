Design a Verilog module that implements an HMAC (Hash-based Message Authentication Code) using a simple hash function for the purpose of this problem. The module should take a secret key and a message as inputs and produce a hashed output as the HMAC. The secret key and message should be of fixed length (e.g., 128 bits each). The HMAC process involves hashing the combination of the key and the message. You need to create a simple hash function (e.g., a XOR operation for simplicity) for this problem. The module should include a clock and reset signal to handle the sequential logic.
