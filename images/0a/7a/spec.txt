
Design an Infinite Impulse Response (IIR) filter using Verilog. The filter should take a 4-bit input sample and produce a 4-bit output sample. The filter uses the following difference equation:
y[n] = 0.5 * x[n] + 0.25 * y[n-1]
where x[n] is the input, y[n] is the output, and y[n-1] is the previous output sample.
