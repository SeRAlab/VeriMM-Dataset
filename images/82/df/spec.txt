Design a digital calculator module that performs arithmetic operations on two 8-bit inputs, A and B, based on a selected operation specified by a 2-bit control signal, OP. The supported operations include addition, subtraction, multiplication, and division. The module also includes functionality to output the result on an 8-bit output and display it in a 7-segment format. The NEG input signal can modify the output to represent a negative result if necessary. The state machine controls the sequence of operation: performing the calculation, handling potential negative results, setting the output, and updating the 7-segment display. The entire operation is synchronized with a clock signal and can be reset with a RESET input.
module top_module(CLK, RESET, A, B, OP, NEG, OUT, SEG);
