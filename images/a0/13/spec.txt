Design a D flip-flop with asynchronous reset and set capabilities. On the rising edge of the clock, if the reset signal is high, the output q will be set to LOW and qb to HIGH. If the set signal is high, q will be set to HIGH and qb to LOW. If neither reset nor set is activated, the output q follows the input d, while qb is the complement of d. This module provides control over the output states, allowing for precise initialization and operation in synchronous circuits.
module top_module(input clk, input reset, input set, input d, output reg q, output reg qb);
