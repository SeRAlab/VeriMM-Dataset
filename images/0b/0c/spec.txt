
Design a PCIe interface controller that manages the transmission of data packets. The controller should keep track of the current state of the transmission, which can be either IDLE, TRANSMITTING, or COMPLETE. The state transitions are as follows:
- From IDLE to TRANSMITTING on a signal `start`.
- From TRANSMITTING to COMPLETE on a signal `done`.
- From COMPLETE to IDLE on a reset signal `reset`.
The controller should also maintain a data register that holds the current data being transmitted.
