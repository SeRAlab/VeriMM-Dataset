
Design a Verilog module that implements a simplified version of the RRT algorithm. The module should take a start point and a goal point as inputs, and at each clock cycle, it should generate a random point in a 2D space. It will then check if this point is closer to the goal than the previous point stored within the module. If it is, it should update the stored point. The module should also have a signal to indicate when the goal is reached (i.e., when the stored point is within a certain distance of the goal). Use a parameter to define the distance threshold for reaching the goal.
