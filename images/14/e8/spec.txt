Design an interrupt controller that manages up to 4 interrupt requests. The controller should have an input for each interrupt request (irq0, irq1, irq2, irq3) and a clock signal. Each time the clock signal goes high, the controller should check the status of the interrupt requests. If an interrupt request is active, it should set a corresponding output signal (ack0, ack1, ack2, ack3) high and clear the interrupt request after acknowledging the interrupt. Only one interrupt can be acknowledged at a time, with priority given to irq0, followed by irq1, irq2, and irq3.
