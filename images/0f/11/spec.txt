Design an 8-bit DRAM cell that can store a single bit of data. The cell should have inputs for a clock signal, a write enable signal (we), a data input (d), and an address input (addr) which selects the cell to read or write. When the write enable (we) is high, the data (d) should be written to the cell at the given address. When the write enable is low, the data at the given address should be output. The output should be 1-bit wide.
