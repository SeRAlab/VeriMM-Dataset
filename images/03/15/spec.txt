Design a Verilog module for Run-length encoding (RLE). The module should take a binary input stream and output the run-length encoded data. The input will consist of a series of bits (0s and 1s), and the output will be a sequence of pairs indicating the value and its count. For example, the input "000111" should produce the output "0 3 1 3". The module should also include a valid signal to indicate when the output is valid.
