Design a 3-to-8 line decoder. The module takes three input lines (A, B, C) and produces eight output lines (Y0 to Y7), where only one output line is activated (set HIGH) based on the binary value represented by the inputs. On each positive clock edge, the inputs are latched, and the corresponding output line is driven HIGH according to the decoded value of the 3-bit input.
module top_module(
    input A,
    input B,
    input C,
    output reg Y0,
    output reg Y1,
    output reg Y2,
    output reg Y3,
    output reg Y4,
    output reg Y5,
    output reg Y6,
    output reg Y7
);
