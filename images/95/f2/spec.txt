Design a register that responds to a reset signal and produces an output based on a control clock enable signal. When the reset is activated, the output is set to LOW. If the reset is not active, and the clock enable signal is asserted, the output is updated to reflect the logical AND of the four-bit input data. If neither condition is met, the output retains its previous state.
module top_module(input clk, reset,set,
                      input clk_en,
                      input [3:0] data_in, 
                      output reg data_out);
