
Design a combinational logic circuit that implements a simple Huffman encoding for a fixed set of characters. The circuit should take a 3-bit input representing one of the characters (0-7) and output the corresponding Huffman code, which can vary in length from 1 to 3 bits. The mapping is as follows:
- Character '0' -> '0'
- Character '1' -> '10'
- Character '2' -> '110'
- Character '3' -> '1110'
- Character '4' -> '11110'
- Character '5' -> '111110'
- Character '6' -> '1111110'
- Character '7' -> '1111111'
The output should be a variable-length code, so the output should consist of signals to indicate the length and the actual encoded bits.
