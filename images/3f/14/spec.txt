Design a Verilog module that implements a simple Dynamic Voltage and Frequency Scaling (DVFS) controller. The controller takes an input signal that indicates the workload level (0 to 3) and adjusts the output voltage (Vout) and frequency (Fout) accordingly. The mapping is as follows: 
- Workload 0: Vout = 1.0V, Fout = 1.0GHz 
- Workload 1: Vout = 1.2V, Fout = 1.2GHz 
- Workload 2: Vout = 1.5V, Fout = 1.5GHz 
- Workload 3: Vout = 1.8V, Fout = 1.8GHz 
The controller should have a clock signal and a reset signal. On reset, the output voltages and frequencies should be set to the lowest values.
