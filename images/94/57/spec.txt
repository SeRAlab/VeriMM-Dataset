Design a 2-bit binary counter with load and reset capabilities. On the rising edge of the clock, if the RESET signal is active, the output Q is set to zero. If the LOAD signal is active, Q is loaded with the value provided at the DATA input. Otherwise, Q increments by one. This module effectively counts up from 0 to 3, allowing for initialization or overriding the count value as needed.
module top_module(
    input clk,
    input LOAD,
    input RESET,
    input [1:0] DATA,
    output reg [1:0] Q
);
