

You are tasked with designing a Verilog module for a 8-bit adder with carry-in and carry-out signals. The module should have three input signals: `A`, `B`, and `Cin` representing the two 8-bit numbers to be added and the carry-in bit, respectively. The module should also have two output signals: `Sum` representing the sum of the two input numbers and `Cout` representing the carry-out bit.

The Verilog module should be named `adder_8bit` and should be designed to be synthesizable. The module should only use combinational logic and should not use any sequential logic or memory elements. The module should be self-contained and should not rely on any external modules.

You must write the Verilog code for the `adder_8bit` module within 200 lines of code. Your code should be well-commented and easy to read.
