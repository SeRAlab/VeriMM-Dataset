
Design a simple OFDM transmitter that takes a stream of data bits and modulates them using QPSK (Quadrature Phase Shift Keying). The transmitter should have an input for a serial data stream, a clock input, and a reset input. The output should be a parallel data stream where each 2 bits are mapped to a QPSK symbol. The design should also include a state machine that controls the data processing.
