Implement an 8-bit ADC (Analog-to-Digital Converter) that takes an 8-bit input and outputs a binary value based on a simple threshold decision. If the input value is greater than or equal to a threshold value (e.g., 128), the output value should be set to 1; otherwise, it should be set to 0. The ADC should also include a reset functionality that sets the output to 0 on a reset signal.
