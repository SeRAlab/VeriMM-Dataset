Design a clocked D flip-flop with asynchronous set and clear inputs. The module stores the value of input D at the rising edge of CLK, but if the SET input is asserted, it will set the output Q to high, and if the CLR input is asserted, it will reset the output Q to low. The output Q_N is the complement of Q, providing both the normal and inverted output states.
