Design a circuit that implements a combinational logic function based on the inputs A, B, and C. The output F is determined by the Boolean expression F = !B*C + A*!C, which means F is high when either B is low and C is high or A is high and C is low. This can be viewed as a simplified logical operation using an AND-OR structure.
module top_module(
  input wire A, B, C,
  output reg F
);
