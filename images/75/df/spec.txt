Design a 2-to-1 multiplexer with enable functionality. The module selects between two input signals, `i0` and `i1`, based on the `en` (enable) control signal. When the `en` signal is low (0), the output `o` is determined by the logical negation of the OR operation between both inputs, effectively making `o` always high (1). When the `en` signal is high (1), the output `o` reflects the selection between `i0` and `i1`, representing a standard multiplexer behavior.
module top_module(
  input  wire i0,
  input  wire i1,
  input  wire en,
  output wire o
);
