Design a 4-input round-robin arbiter. The arbiter should grant access to one of four requestors (R0, R1, R2, R3) in a rotating manner. The arbiter has a clock input and a reset input. When the reset is activated, the arbiter should start granting access from R0. Each grant should be indicated by a corresponding output signal (G0, G1, G2, G3) that goes high when that requestor is granted access. The arbiter should use a state variable to keep track of the last granted requestor.
