Design a traffic light control system that utilizes a 3-bit command input to manage the states of red, yellow, green, and left turn signals. Upon a reset signal, the system initializes to the red light. Based on the value of the `cmd` input, which can range from 0 to 4, the module transitions between various traffic light states: cmd=0 activates the red light; cmd=1 activates the yellow light; cmd=2 activates the green light; cmd=3 activates the green light alongside a left turn signal; and cmd=4 activates both the green and yellow lights. If the command does not match any cases, the system defaults to the red light state. This module effectively functions as a simple state machine for traffic light control.
