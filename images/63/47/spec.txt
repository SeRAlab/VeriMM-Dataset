Design a circuit that implements an 8-level stack (Last In, First Out - LIFO) memory structure. This stack supports push (write) and pop (read) operations controlled by input signals. When the write signal (wn) is asserted, data from the DATAIN input is pushed onto the stack if it is not full, and when the read signal (rn) is asserted, data is popped from the stack to the DATAOUT output if it is not empty. The stack utilizes a 4-bit stack pointer (sp) to track the current depth of the stack, and includes signals to indicate when the stack is full or empty. Additionally, there is a reset functionality that initializes the stack and outputs to known states.
