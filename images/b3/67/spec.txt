Design a 4-to-1 multiplexer for 8-bit wide inputs. The module selects one of the four 8-bit input lines (in0, in1, in2, in3) based on a 2-bit select signal (sel) and outputs the chosen input on the output line (out). When sel corresponds to a specific binary value, the output reflects the respective input; for example, sel=00 outputs in0, sel=01 outputs in1, sel=10 outputs in2, and sel=11 outputs in3.
module top_module(
  input [7:0] in0,
  input [7:0] in1,
  input [7:0] in2,
  input [7:0] in3,
  input [1:0] sel,
  output reg [7:0] out
);
