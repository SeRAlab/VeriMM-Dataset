Design a two-input, one-bit multiplexer that selects between two data inputs based on a two-bit select signal. When the select signal (s) is 00, the output (y) will be assigned the value of the first input (d[0]), while for any other value of the select signal (specifically s=01), it outputs the second input (d[1]). Note that the implementation supports input data of size four, but only two inputs are utilized in the selection.
module top_module(
    input [3:0] d,
    input [1:0] s,
    output reg y
    );
