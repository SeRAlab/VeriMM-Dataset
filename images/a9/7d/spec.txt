Design a four-to-one multiplexer that selects one of the four input signals (A, B, C, or D) based on the two select lines (S0 and S1). The output (Y) corresponds to the selected input: if S1 and S0 are both low, output A; if S0 is high and S1 is low, output B; if S1 is low and S0 is high, output C; if both select lines are high, output D.
module top_module(
    input A,
    input B,
    input C,
    input D,
    input S0,
    input S1,
    output reg Y
);
