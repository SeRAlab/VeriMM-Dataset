Design a 4-bit Gray code counter, which increments a binary count on each clock cycle when enabled. The counter outputs the corresponding 4-bit Gray code value. The counter is initialized to zero when the Clear input is activated, and it starts counting from a specific non-zero state (1) after clearing. The Gray code is generated by performing bitwise XOR operations between adjacent bits of the binary count.
module top_module(
    input wire Clk,
    input wire Clear_in,
    input wire Enable_in,
    output reg [3:0] GrayCount_out
);
