Design a 16-bit Arithmetic Logic Unit (ALU) that performs the following operations based on a 4-bit operation code (opcode):  
0: Addition  
1: Subtraction  
2: Bitwise AND  
3: Bitwise OR  
4: Bitwise XOR  
5: Logical Shift Left  
6: Logical Shift Right  
7: Set on Less Than (SLT)  
The ALU should take two 16-bit inputs and output a 16-bit result. The ALU should also output a zero flag that indicates if the result is zero.
