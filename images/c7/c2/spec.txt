

You have been tasked with designing a module that takes in five input signals, A1, A2, A3, B1, and B2, and outputs a single signal, X. The module should be named "five_signal_module".

The input signals are all single-bit signals, and the output signal is also single-bit. The input signals are all active-high signals.

The module should have the following functionality:
- If A1, A2, and A3 are all high, X should be high.
- If B1 and B2 are both high, X should be low.
- If neither of the above conditions are met, X should be high.

Write the code for the "five_signal_module" module that implements the above functionality.
