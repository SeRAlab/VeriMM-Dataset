
Design a simple SLAM system that updates its position based on sensor inputs and previous location. The system maintains a 2-bit position state (00, 01, 10, 11) and updates it based on a 1-bit sensor input which indicates whether the sensor detects an obstacle (1) or not (0). If an obstacle is detected, the position state should increment (wrapping around at 11 to 00). If no obstacle is detected, the position state remains unchanged.
