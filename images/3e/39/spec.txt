
Design a fixed-priority arbiter in Verilog that grants access to a shared resource based on the priority of the requests. The arbiter should have three request inputs (req0, req1, req2), each corresponding to a different priority, and one output signal (grant) that indicates which request has been granted access. The priority order is req0 > req1 > req2. If multiple requests are made simultaneously, the highest priority request should be granted access. The output grant should be a 3-bit signal indicating which request is granted (3'b001 for req0, 3'b010 for req1, and 3'b100 for req2). If no requests are made, grant should be 3'b000.
