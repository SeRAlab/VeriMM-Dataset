Design a one-bit wide, 2-to-1 multiplexer. The module selects between two input signals, inA and inB, based on the value of the control signal sel: when sel is high (1), the output out is assigned the value of inA; when sel is low (0), the output out takes the value of inB.
module top_module(
	input wire sel, inA, inB,
	output reg out
);
