Design a simple LIFO (Last In First Out) stack in Verilog. The stack should support the following operations: push, pop, and peek. The stack should have a fixed depth (e.g., 4), and the operations should be controlled by an enable signal. The push operation should add a value to the top of the stack, the pop operation should remove the value from the top of the stack, and the peek operation should return the value at the top of the stack without removing it.
