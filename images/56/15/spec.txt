Design a synchronous 3-bit binary counter with an active-high reset functionality. On each rising edge of the clock signal, the counter increments its value by one, unless the reset input is active, in which case it resets the count to zero. This module effectively tracks a count value, ranging from 0 to 7, that is resettable based on the reset signal.

  input clk,
