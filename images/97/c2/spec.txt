Design a VGA converter module that processes 24-bit color data input and synchronizes it with horizontal and vertical sync signals for display. The module captures and stores the input data on the rising edge of the clock, then outputs 8-bit pixel data for three consecutive clock cycles, effectively multiplexing the higher 24-bit color data into three 8-bit segments, while maintaining the original sync and blanking signals. The outputs include an 8-bit VGA data signal and potentially synchronized horizontal and vertical sync signals to drive a VGA display.
module top_module(
  input [23:0] data,
  input blank,
  input hs,
  input vs,
  input clk,
  output reg [7:0] vga_data,
  output reg blank_out,
  output reg hs_out,
  output reg vs_out
);
