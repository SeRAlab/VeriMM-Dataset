Please act as a professional verilog designer.

Design a Verilog module for a 64-bit shift register with parallel load capability. The shift register can shift left or right and load a 64-bit value on a load signal.

Module name:  
    shift_reg_64bit  

Input ports:
    clk: Chip clock signal.
    rst: Reset signal.
    load: Load enable signal.
    shift_left: Shift left enable signal.
    shift_right: Shift right enable signal.
    load_data: 64-bit data to load.

Output ports:
    q: 64-bit output of the shift register.

Implementation:
Shift register operation:
The shift register loads the 64-bit value from load_data when the load signal is active.
The shift register shifts left or right based on the shift_left and shift_right signals.
