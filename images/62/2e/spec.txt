Design a performance monitoring counter (PMC) module that tracks various events in a digital system. The module counts occurrences of interrupts, cache misses for both instructions and data, cache accesses, and UART communication events. It takes a reset signal and a clock to control the counting process, with outputs available through specific addresses. When the `rst` signal is high, the module resets all counters to zero. It increments the respective count registers based on incoming signals for each monitored event during the negative edge of the clock. The outputs can be read from designated memory addresses, providing insights into system performance.
module top_module(rst, clk, ie, de, iaddr, daddr, drw, din, iout, dout, pmc_int, pmc_cache_miss_I, pmc_cache_miss_D, pmc_cache_access_I, pmc_cache_access_D, pmc_uart_recv, pmc_uart_send);
