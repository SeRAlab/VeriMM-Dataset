Design a Verilog module that implements an SR flip-flop with asynchronous set and reset inputs. The module should have inputs S (Set), R (Reset), and a clock signal clk. The outputs should be Q and Qn (not Q). The flip-flop should operate such that when S is high, Q gets set, when R is high, Q gets reset, and it maintains its state on the rising edge of the clock if both S and R are low. The behavior when both S and R are high should be treated as a forbidden condition.
