Design a bus hold block that captures and holds the value of an n-bit input bus when the enable signal is high. The circuit latches the input data on the rising edge of the enable signal and maintains this value at the output until the enable signal is deactivated, effectively providing a hold function for the input data. This design is essential for retaining data across buffered signals in digital circuits.

  input [n-1:0] in,
