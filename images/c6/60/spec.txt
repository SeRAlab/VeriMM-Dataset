

You are tasked with designing a Verilog module that performs a simple mathematical operation. The module should take in two inputs, `a` and `b`, and output the result of multiplying them together. 

The input `a` is a 14-bit signed integer, while the input `b` is a 16-bit unsigned integer. The output should be a 32-bit signed integer.

Your module should be named `multiplier` and should have the following inputs and outputs:

Inputs:
- `clk`: a 50 MHz clock signal
- `reset`: an asynchronous active low reset signal
- `a`: a 14-bit signed integer
- `b`: a 16-bit unsigned integer

Outputs:
- `result`: a 32-bit signed integer

Your module should use only combinational logic and should be no longer than 200 lines of Verilog code.
