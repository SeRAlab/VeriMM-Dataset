
Design a simple packet filtering firewall in Verilog that checks if incoming packets meet certain criteria. The criteria are:
1. Packet source is allowed if it matches the allowed source (src_allowed).
2. Packet destination is allowed if it matches the allowed destination (dst_allowed).
3. The packet is valid if both source and destination are allowed.

The input will consist of:
- A 5-bit packet source (src)
- A 5-bit packet destination (dst)
- A 5-bit allowed source (src_allowed)
- A 5-bit allowed destination (dst_allowed)

The output will be a single bit indicating whether the packet is valid (valid_packet).
