

In this problem, you are given a Verilog module called `register16`. This module is a 16-bit register that can store an input value and output it on the next clock cycle. The module has four inputs: `clk` (the clock signal), `in` (the input value to be stored), `write` (a control signal that determines whether the input value should be stored), and `reset` (a control signal that resets the register to 0). The module has one output: `out` (the output value of the register).

Your task is to create a new Verilog module called `register16_with_enable` that is similar to `register16`, but with an additional control input called `enable`. When `enable` is 1, the register should behave exactly like `register16`, storing the input value on the next clock cycle if `write` is also 1. However, when `enable` is 0, the register should not store any new input values, and instead should simply output the current stored value on every clock cycle.

Write a Verilog module `register16_with_enable` that takes in the same inputs as `register16`, plus an additional input `enable`, and produces the same output as `register16`.
