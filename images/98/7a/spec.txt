Design a 4-bit shift register with load functionality. The module captures a 4-bit input, D, and shifts its contents to the right on each clock cycle when the load signal (LD) is not asserted. The register is asynchronously reset to zero when the reset signal (RST) is activated. The current state of the shift register is available at the output (OUT). This design serves to store and manipulate 4-bit data by enabling both loading and shifting operations.
module top_module(
    input CLK,
    input RST,
    input LD,
    input [3:0] D,
    output reg [3:0] OUT
);
