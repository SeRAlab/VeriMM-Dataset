Design a 4-bit barrel shifter that shifts the input data (D) left by 0 to 3 positions based on the value of a 2-bit control signal (A). The module processes the input through three stages of shifting, where each stage corresponds to a possible shift defined by the control signal: shifting the bits left fills with zeros for positions 1 to 3, and keeps the input unchanged for a shift of 0. The final output (S) reflects the shifted value after all stages are completed.
module top_module(
    input [3:0] D,
    input [1:0] A,
    output [3:0] S
);
