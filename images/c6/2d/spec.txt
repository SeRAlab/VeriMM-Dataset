

You are tasked with designing a verilog module that implements a 2-to-1 multiplexer using a case statement. The module should have two input ports, `in1` and `in2`, and a single output port, `out`. The module should also have a control input port, `sel`, which specifies which input should be passed to the output. If `sel` is 0, `in1` should be passed to `out`, and if `sel` is 1, `in2` should be passed to `out`. 

Write a verilog module that implements this 2-to-1 multiplexer using a case statement. The module should be named `mux2to1_case` and should have the following port declarations:

```
module mux2to1_case(
  input in1,
  input in2,
  input sel,
  output reg out
);
```
