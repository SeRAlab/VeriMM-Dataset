
Design a 2nd order Infinite Impulse Response (IIR) filter using Verilog. The filter should take a 16-bit signed input sample, apply the IIR filter coefficients, and produce a 16-bit signed output sample. The filter should have the following coefficients:
- b0 = 1
- b1 = 1
- b2 = 1
- a1 = -0.5
- a2 = 0.25
The output should be calculated based on the formula:
output[n] = b0 * input[n] + b1 * input[n-1] + b2 * input[n-2] - a1 * output[n-1] - a2 * output[n-2]
