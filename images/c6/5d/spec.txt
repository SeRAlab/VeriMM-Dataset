

You have been tasked with designing a module that selects a specific output based on an input selection signal. The module should be called `output_select` and should have the following inputs and outputs:

Inputs:
- `sel` (1-bit): selection signal to choose the output
- `out1` (8-bit): first output to choose from
- `out2` (8-bit): second output to choose from

Outputs:
- `out` (8-bit): selected output based on the value of `sel`

The `sel` input will have a value of either 0 or 1. If `sel` is 0, then `out` should be equal to `out1`. If `sel` is 1, then `out` should be equal to `out2`.

Implement the `output_select` module using behavioral Verilog.
