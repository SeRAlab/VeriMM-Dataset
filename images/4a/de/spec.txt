Design a combinational logic circuit that outputs a signal X based on various input conditions. The output X is set to 1 if the 4-bit input A is greater than or equal to 8, or when specific combinations of other inputs (B, C, D, E, F, G, H) fulfill certain criteria. These conditions include scenarios where B equals 1 or 2, C and D are in specific states, or both E and F are high. The module effectively implements multiple logical comparisons and selections, making it a complex decision-making unit suitable for various control applications.
module top_module(
    input [3:0] A,
    input [1:0] B,
    input C,
    input D,
    input E,
    input F,
    input G,
    input H,
    output reg X
);
