Design a control module that functions as a multi-input selector based on a 4-bit input signal (input_1). The module outputs one of the various inputs (input_3 through input_8, as well as a 2-bit selection from input_2) depending on the value of input_1. If input_1 is 0, the output is LOW. For values 1 to 6, it directly selects corresponding input signals. If input_1 equals 7, the output is determined by the value of input_2. Any other value results in a LOW output.
module top_module(
    input_1,
    input_2,
    input_3,
    input_4,
    input_5,
    input_6,
    input_7,
    input_8,
    output_1
);
