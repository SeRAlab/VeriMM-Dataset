Design an arbiter circuit that manages multiple request lines to grant access to resources in a prioritized manner. It receives four request signals and corresponding acknowledge signals, outputting a grant signal that indicates which request is currently being serviced. The module operates on a clock signal and resets to a default state when the reset input is active. The arbiter also provides an encoded output to easily identify the granted request and includes a valid signal to confirm when a request has been successfully acknowledged. The design ensures that only one grant is issued at a time, preventing conflicts among the requestors.
