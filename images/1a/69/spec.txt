
Design a 7-stage pipeline processor where the pipeline registers hold the intermediate values across the stages. Each stage will perform a simple arithmetic operation, and the output of the last stage will be stored in a register. The stages are as follows:
1. Stage 1: Input values
2. Stage 2: Add 1 to the input
3. Stage 3: Multiply by 2
4. Stage 4: Subtract 3
5. Stage 5: Divide by 4
6. Stage 6: Modulus 5
7. Stage 7: Store the output
