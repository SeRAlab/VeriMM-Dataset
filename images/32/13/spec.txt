Create a FIFO queue with a depth of 4. The FIFO should have inputs for data and write enable and an output for read data and a read enable. When write enable is high, the data should be written to the FIFO. When read enable is high, the data should be read from the FIFO. The FIFO should maintain the order of the elements. If the FIFO is full, new writes should be ignored. If the FIFO is empty, reads should return zero.
