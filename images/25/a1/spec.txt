Design a fixed-priority arbiter that selects one of several requests based on fixed priorities. It should support 4 request lines (req0, req1, req2, req3) and provide a grant line (grant) that indicates which request is granted. The priority order is fixed as req0 > req1 > req2 > req3. If multiple requests are active, the arbiter should grant the highest priority request. If no requests are active, the grant should be deasserted.
