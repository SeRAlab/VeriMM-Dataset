Implement a 4-bit Gray code counter controlled by a clock and reset signals. The module transitions through four predefined states in an FSM, generating the corresponding Gray code outputs for each state. Upon reset, the counter initializes to the first state and output. The counter is designed to wrap around to zero after reaching the maximum 4-bit Gray code value, facilitating cyclical counting in Gray code format.
module top_module(
  input clk,
  input reset,
  output reg [3:0] gray_code
);
