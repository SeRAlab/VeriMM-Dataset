Design a 16-bit SRAM cell that can store a 16-bit data word and has a read and write capability controlled by an external signal. The SRAM cell should have the following inputs: `write_enable` (active high), `address` (4-bit), and `data_in` (16-bit). The outputs should include `data_out` (16-bit) and `ready` (active high when the cell is ready to operate). The cell should store data during a write operation and output the stored data during a read operation.
