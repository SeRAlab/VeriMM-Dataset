Design a synchronous 4-bit adder circuit that outputs a 5-bit sum. The module adds two 4-bit inputs, 'a' and 'b', and produces a 5-bit output 'c'. Upon a reset signal, the output is set to zero. The addition occurs on the rising edge of the clock signal, ensuring proper synchronization with the system clock.
module top_module(
  input clk,
  input reset,
  input [3:0] a,
  input [3:0] b,
  output reg [4:0] c
  );
