

You have been tasked with designing a verilog module that implements a 16-bit up counter with a synchronous reset. The counter should increment on the positive edge of the clock signal and reset to zero when the reset signal is asserted. The module should have the following interface:

Inputs:
- `reset` : a synchronous reset signal
- `clk` : the clock signal

Outputs:
- `q` : a 16-bit output representing the current count value

Write the verilog code for the module.
