Design an interrupt controller that can handle up to 4 interrupt requests (IRQ0 to IRQ3). The controller will have a register that keeps track of the current highest priority interrupt. The inputs will be the interrupt requests and the output will be the index of the highest priority interrupt. The priority is fixed, meaning IRQ0 has the highest priority and IRQ3 has the lowest. When multiple interrupts are received, the controller should output the highest priority interrupt index. The controller should also have a clear signal that resets the output to an invalid state when asserted.
