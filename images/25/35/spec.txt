Design an SPI master controller in Verilog that can send and receive data serially. The controller should have the following inputs and outputs:
- Input: clk (clock), rst (reset), mosi (master out slave in), miso (master in slave out), start (to initiate communication), data_in (data to be sent).
- Output: sclk (serial clock), ss (slave select), data_out (received data).
The controller should generate the SPI clock signal and manage the data transmission and reception according to the SPI protocol.
