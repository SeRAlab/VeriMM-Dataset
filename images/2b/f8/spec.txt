
Design a Verilog module that simulates a simple EEPROM (Electrically Erasable Programmable Read-Only Memory) cell. The module should allow for writing a 1-bit value to an address, reading the value from that address, and erasing (resetting) the value at that address. The EEPROM should consist of 8 memory cells. The write operation should set a specified cell to a given value, the read operation should output the value of a specified cell, and the erase operation should reset a specified cell to 0.
