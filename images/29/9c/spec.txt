Design a pulse generator that produces a single pulse of specified width and period based on input control signals. The pulse generator should have the following inputs: 
1. clk (clock signal)
2. start (start signal to initiate the pulse)
3. width (pulse width in clock cycles)
4. period (total period in clock cycles)
The output should be a single pulse signal (pulse) that is high for the specified pulse width and then low, after which it resets and waits for the next start signal.
