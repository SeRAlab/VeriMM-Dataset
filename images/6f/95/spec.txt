Design a 4-to-1 multiplexer with enable functionality. The module takes a 4-bit input and outputs one of those bits based on the selected index derived from the input values when the enable signal (`en`) is high. The selection is determined by recognizing which input bit is high (indicating a valid selection). If none of the bits are high or if the enable signal is low, the output defaults to zero.
module top_module(input [3:0] in, input en, output out);
