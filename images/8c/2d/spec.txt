Design a JK flip-flop with an asynchronous reset. The flip-flop outputs Q, which is determined by the state of the inputs J and K at the rising edge of the clock signal. When Q is 0, the output is set to J, and when Q is 1, it is reset to the inverse of K. Additionally, the module provides Qn, the complement of Q.
module top_module(
    input rstn, clk, J, K,
    output reg Q,
    output Qn
);
