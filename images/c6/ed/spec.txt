

You are tasked with designing a module that takes in four input signals (A, B, C, and D) and outputs the logical OR of these four signals (X). You have been provided with a code snippet for the sky130_fd_sc_hd__or4_1 module, which implements a 4-input OR gate using the SkyWater 130nm process technology. However, you are not allowed to use this module in your design. Instead, you must create your own module that implements the same functionality using only Verilog code. 

Your module should have the following interface:
```
module my_or4_1 (
    input A,
    input B,
    input C,
    input D,
    output X
);
```
Your module should be able to handle any combination of input signals (A, B, C, and D) and output the logical OR of these signals (X). Your module should be designed to work with the SkyWater 130nm process technology.

Your module should be implemented using Verilog code and should be no longer than 200 lines of code.
