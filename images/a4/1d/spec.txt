Design a dual-port RAM module capable of handling two separate read and write operations simultaneously. It features two 8-entry memory banks, each storing 4-bit wide data, with independent enable signals for reading and writing. Upon a reset signal, the memory is initialized to zero. The module outputs a final result that is the bitwise XOR of the two read data values, providing a mechanism for data comparison or synthesis from the two memory banks.
module top_module(
    input clk,
    input rst_n,
    input write_en_1,
    input [2:0] write_addr_1,
    input [3:0] write_data_1,
    input read_en_1,
    input [2:0] read_addr_1,
    output reg [3:0] read_data_1,
    input write_en_2,
    input [2:0] write_addr_2,
    input [3:0] write_data_2,
    input read_en_2,
    input [2:0] read_addr_2,
    output reg [3:0] read_data_2,
    output [3:0] final_output
);
