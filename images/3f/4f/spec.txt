Design a Verilog module that implements a simple JPEG-like compression mechanism. The module should accept an input pixel value (8 bits) and output a compressed version of it (4 bits). The compression mechanism should be as follows: the output should be the upper 4 bits of the input pixel value if the pixel value is greater than or equal to 128, otherwise it should output the lower 4 bits of the input pixel value. The module should operate on a clock signal and should also include a reset signal to initialize the output to zero.
