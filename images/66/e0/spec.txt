Design a 2-to-1 multiplexer (MUX) using NAND gates. The module selects between two input signals, A and B, based on the control signal SEL. When SEL is 0, the output Y will reflect the value of A; when SEL is 1, Y will take the value of B. This design utilizes four NAND gates to achieve the desired multiplexing functionality.
module top_module(
    input  A,
    input  B,
    input  SEL,
    output Y
);
