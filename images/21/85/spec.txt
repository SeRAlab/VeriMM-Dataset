Design an 8-bit ALU that performs the following operations based on a 3-bit function code:
- 000: AND
- 001: OR
- 010: ADD
- 011: SUBTRACT
- 100: XOR
- 101: NOT (only on first input)
- 110: SHIFT LEFT
- 111: SHIFT RIGHT

The ALU should take two 8-bit inputs (A and B) and output an 8-bit result. It should also have a 3-bit control signal to select the operation, and a valid output signal to indicate if the operation was successful.
