Design a watchdog timer circuit that monitors an input signal (I) and regulates an output signal (O) based on the tick of a clock (clk) and an enable signal (en). The circuit increments an 8-bit counter when enabled, and upon reaching a specific threshold (indicated by the most significant bit of the counter), it checks the state of the input signal (I). If a change is detected in the input signal compared to the previous output state (O), the output is updated to match the input, and the counter is reset to a predefined value. This functionality ensures that the output reflects the input signal state only after the timer has sufficiently elapsed, providing a form of debouncing or delay to avoid rapid changes.
