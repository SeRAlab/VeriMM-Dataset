Design a 16-bit ADC (Analog-to-Digital Converter) controller that takes a 16-bit input signal and compares it to a reference voltage. The controller should output a 16-bit digital value representing the quantized output. The quantization process should be done using a simple thresholding technique, where if the input is greater than the reference, the output should be set to the maximum value (16'hFFFF), otherwise it should be set to zero (16'h0000). Implement this in Verilog.
