Implement a 16-entry register file with 32-bit wide registers. This module allows for resetting the registers to default values and writing data to a specified register based on the control signal `rw`. When the reset signal (`rst`) is active, all registers are set to zero, with specific registers initialized to predefined values. The outputs `Fx` and `Fy` provide access to the values of the registers indexed by inputs `X` and `Y`, respectively.
