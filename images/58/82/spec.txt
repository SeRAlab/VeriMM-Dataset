Conversely, if the reset input R is activated while S is low, Q is set to low. If both set and reset are inactive, Q's value is determined by an XOR operation between the toggle input T and the current state of Q, enabling toggle functionality based on the clock signal.

    input C,
    input S,
    input R,
    input T,
    output reg Q
);
