Design a Verilog module that takes a 24-bit RGB pixel value and compresses it using a simple run-length encoding (RLE) scheme. The module should output a compressed format where consecutive pixels of the same color are encoded as a count followed by the color value. For example, an input of three consecutive pixels of the color red (RGB: 255, 0, 0) should be output as `3 255 0 0`. The module should handle up to 8 consecutive pixels and output a maximum of 32 bits for the count and color value.
