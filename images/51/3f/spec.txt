Design a barrel shifter that performs bitwise shifting of an 8-bit input. The module takes an 8-bit input and a 3-bit shift amount to determine how many positions to shift the input either left or right, based on the value of the shift direction control input. When shift_direction is 0, the input is shifted to the right; when it is 1, the input is shifted to the left. The result is output as an 8-bit signal.
module top_module(
    input [7:0] in,
    input [2:0] shift_amount,
    input shift_direction,
    output [7:0] out
);
