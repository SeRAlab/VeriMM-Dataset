
You are tasked with designing a module that takes in a 4-bit binary input and outputs the binary equivalent of the input in Gray code. Gray code is a binary numeral system where two successive values differ in only one bit. For example, the 4-bit Gray code sequence for the binary sequence 0000-1111 is 0000-0001-0011-0010-0110-0111-0101-0100-1100-1101-1111-1110-1010-1011-1001-1000.

Design a Verilog module that takes in a 4-bit binary input (`in`) and outputs the corresponding 4-bit Gray code (`out`). The module should have the following interface:

```verilog
module gray_code(
    input [3:0] in,
    output [3:0] out
);
```

You should implement the module using only combinational logic (no stateful elements such as flip-flops). Your module should be synthesizable and meet the following requirements:
- The module should be able to handle all possible 4-bit binary input values.
- The output should be the corresponding 4-bit Gray code of the input.
- The module should not use any built-in Verilog functions or operators that directly implement Gray code conversion.
