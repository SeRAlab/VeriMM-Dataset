Design a D flip-flop with asynchronous active-low reset and set functionality. The module features an input clock (CLK), data input (D), and two control inputs (RESET_B and SET_B). When RESET_B is low, the output Q is reset to 0, and Q_N is set to 1. When SET_B is low, Q is set to 1, and Q_N is reset to 0. During normal operation, on the rising edge of the clock, the output Q takes the value of D, while Q_N is always the inverse of Q. This design provides synchronous data storage with asynchronous control features.
module top_module(
    input CLK,
    input D,
    input RESET_B,
    input SET_B,
    output reg Q,
    output reg Q_N
);
