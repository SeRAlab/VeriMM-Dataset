

You have been tasked with designing a verilog module that will implement a 4-bit comparator. The module should have two 4-bit inputs, A and B, and three outputs: EQ, GT and LT. EQ should be high if A is equal to B, GT should be high if A is greater than B, and LT should be high if A is less than B. 

Implement the module in such a way that the comparison is done using combinational logic only. The module should be named "four_bit_comparator" and should have the following interface:

Inputs:

- A (4-bit input)
- B (4-bit input)

Outputs:

- EQ (1-bit output)
- GT (1-bit output)
- LT (1-bit output)
