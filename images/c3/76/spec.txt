

You are tasked with designing a verilog module that takes in a 4-bit input `a`, and outputs a 2-bit value `o`. The output `o` is determined by the following rules:
- If the input is less than 5 (i.e. `a < 5`), the output should be the 2 least significant bits of the input.
- If the input is greater than or equal to 5 (i.e. `a >= 5`), the output should be the 2 most significant bits of the input, shifted right by 2 bits.

You should implement this module using only combinational logic. You may use any number of intermediate wires or variables as necessary.

Your module should be named `four_bit_selector` and should have the following interface:
- `input [3:0] a`: a 4-bit input value
- `output reg [1:0] o`: a 2-bit output value
