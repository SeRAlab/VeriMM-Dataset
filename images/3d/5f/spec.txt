Design a simple decision tree for classifying whether a fruit is an apple, orange, or banana based on two features: color and size. Use a 2-bit color input (00: Red, 01: Orange, 10: Yellow) and a 2-bit size input (00: Small, 01: Medium, 10: Large) to determine the fruit type. The output should be a 2-bit code representing the fruit type (00: Apple, 01: Orange, 10: Banana).
