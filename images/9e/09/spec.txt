Design a four-input, one-bit wide multiplexer. The module selects one of the four input lines based on the two-bit select signal (s). When s is 00, it outputs in[0]; when s is 01, it outputs in[1]; when s is 10, it outputs in[2]; and when s is 11, it outputs in[3]. If an invalid selection occurs (though not expected in the given design), it defaults the output to LOW.
