Implement a 2-bit binary adder. The adder should have two 2-bit inputs (a and b) and a 1-bit carry-in input (cin). The output should be a 2-bit sum and a 1-bit carry-out.

Module name:
    binary_adder_2bit
Input ports:
    a: a 2-bit input operand
    b: a 2-bit input operand
    cin: a 1-bit carry-in input
Output ports:
    sum: a 2-bit output representing the sum
    cout: a 1-bit output representing the carry-out

The adder should calculate the sum of the two input operands and the carry-in, and produce the sum and carry-out.
