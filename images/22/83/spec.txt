Design an 8-bit SRAM cell with read and write functionality. The SRAM cell should be able to store an 8-bit value and allow for reading and writing based on control signals. The control signals should be `write_enable` to enable writing to the SRAM and `read_enable` to enable reading from the SRAM. The design should also include an output to indicate the stored data when read. Assume that the data is valid when the read operation is performed.
