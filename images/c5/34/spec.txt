

You are tasked with designing a verilog module that takes in several inputs and outputs a 32-bit sum. The module should be named `Adder` and have the following inputs and outputs:

- `input [31:0] a`: a 32-bit input signal
- `input [31:0] b`: a 32-bit input signal
- `input [1:0] op`: a 2-bit input signal that determines the operation to be performed. If `op` is `2'b00`, the module should output the sum of `a` and `b`. If `op` is `2'b01`, the module should output the difference between `a` and `b`. If `op` is `2'b10`, the module should output the bitwise AND of `a` and `b`. If `op` is `2'b11`, the module should output the bitwise OR of `a` and `b`.
- `output [31:0] out`: a 32-bit output signal that holds the result of the operation

You should implement the `Adder` module using behavioral verilog.
