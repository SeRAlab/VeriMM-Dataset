    load: Signal to load data

Output ports:
    q: 8-bit output representing the current register value

Implementation:
If the reset signal is active (reset), the register is reset to 0 by assigning the value 8'b00000000 to the output register (q). If the shift signal (shift) is high, the register shifts the data to the right on each positive clock edge, with the most significant bit (MSB) being filled with 0. If neither load nor shift signals are high, the register retains its current value.
