
Design a simple Automatic Repeat reQuest (ARQ) error correction system that can send a 5-bit data word and acknowledge the reception of that data word. The system should include a sender and receiver. The sender will send a 5-bit data word, and the receiver will introduce a probability of error in the received data. If the receiver detects an error, it will request the sender to resend the data. The sender will resend the data upon receiving this request. The system should continue until the receiver acknowledges that the correct data has been received.
