Design a combinational logic circuit that implements power gating control for a digital circuit. The circuit should take a 3-bit input `control` which can be 000, 001, 010, ..., 111 representing different states of the power gating (e.g., ON, OFF, STANDBY, etc.). The output `power_gate` should be 1 when the power is ON and 0 when it is OFF for the combinations where `control` indicates ON state (i.e., 000 and 001). For any other state, the output should be 0. Provide a Verilog implementation for this functionality.
