Design a Model Predictive Control (MPC) unit that takes a 4-bit input, which represents the current state of a system, and produces a 4-bit output that represents the control action. The control action is determined by a simple state feedback mechanism. If the current state is greater than a certain threshold (e.g., 8), the output should be set to 4'b1111 (maximum control action), otherwise, it should be set to the current state plus 1.
