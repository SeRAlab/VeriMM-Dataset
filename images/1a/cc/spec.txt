Design a Verilog module that implements a simple feed-forward neural network layer with three inputs, two neurons, and a ReLU activation function. The weights and biases are fixed for this example. The output of each neuron should be computed as follows:
1. Neuron 1: Output1 = ReLU(W11 * Input1 + W12 * Input2 + W13 * Input3 + Bias1)
2. Neuron 2: Output2 = ReLU(W21 * Input1 + W22 * Input2 + W23 * Input3 + Bias2)
Weights (W11, W12, W13) = (2, 3, 1), Bias1 = 1, Weights (W21, W22, W23) = (1, 2, 2), Bias2 = 2.
