
Create a Verilog module that performs Cholesky decomposition on a 2x2 symmetric positive definite matrix. The input to the module will be a 4-bit wide matrix represented as two 4-bit inputs (a and b), and the output will be the lower triangular matrix elements (l11, l21, l22). The decomposition satisfies the equation A = L * L^T where A is the input matrix and L is the output lower triangular matrix.
