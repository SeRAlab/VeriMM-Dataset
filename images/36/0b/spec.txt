Design a 16-bit SRAM cell that allows writing and reading data. The SRAM cell should have the following inputs: a 16-bit data input (data_in), a write enable signal (write_en), a clock signal (clk), and a 16-bit data output (data_out). When the write enable is high, the data input should be latched on the rising edge of the clock. When the write enable is low, the data output should reflect the stored data.
