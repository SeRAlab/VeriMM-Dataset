Design a JK flip-flop in Verilog. The flip-flop should have inputs J, K, Clock, and Reset. The output should be Q. The flip-flop should operate according to the standard JK flip-flop behavior: when Reset is asserted, Q should be 0. On the rising edge of the Clock, if J and K are both 0, Q remains unchanged; if J is 1 and K is 0, Q sets to 1; if J is 0 and K is 1, Q resets to 0; if both J and K are 1, Q toggles.
