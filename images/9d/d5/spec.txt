Develop a synchronized edge-triggered D flip-flop with a reset function (active low) and an inverted output. When the reset signal (sr) is low, the output q is set to low and qn to high. On the rising edge of the clock (clk), if the reset is not active, the output q takes the value of d, and qn outputs the inverse of d. This module can be used in sequential logic circuits where data storage and control via reset are required.
module top_module(
    input clk,
    input d,
    input sr,
    output reg q,
