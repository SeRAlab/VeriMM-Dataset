Design a simple arithmetic calculator capable of performing addition, subtraction, multiplication, and division on two 8-bit inputs, a and b. The operation to be executed is determined by a 2-bit opcode input. The system is synchronous and operates on the rising edge of the clock, with an active reset signal to initialize the result to zero.
module top_module(
    input clk,
    input reset,
    input [7:0] a,
    input [7:0] b,
    input [1:0] opcode,
    output reg [7:0] result
    );
