Design a simple Bluetooth state machine that has three states: IDLE, CONNECTED, and DISCONNECTED. The state transitions occur based on the input signals: 'connect' and 'disconnect'. The state machine should start in the IDLE state and transition to the CONNECTED state when 'connect' is asserted, and transition to the DISCONNECTED state when 'disconnect' is asserted. If in the CONNECTED state, it should return to IDLE state if 'disconnect' is asserted.
