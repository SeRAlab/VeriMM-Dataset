Design a 4-bit asynchronous up counter that increments its count on the rising edge of the clock signal. The counter resets to zero upon receiving a high reset signal. The output 'count' will reflect the current count value, ranging from 0 to 15, with each clock pulse causing the value to increase by one unless a reset is activated.
module top_module(
  input clk,
  input rst,
  output reg [3:0] count
);
