

You are tasked with designing a module that implements a 2-input AND gate with an additional input C1, which acts as an enable signal. The module should be named "and_en" and should take in the following inputs and outputs:
- Inputs: A, B, C1 (1-bit each)
- Output: Y (1-bit)

The AND gate should only output a value when the enable signal C1 is high (1). When C1 is low (0), the output Y should be 0 regardless of the values of inputs A and B.

Write a verilog module "and_en" that implements this functionality. The module should be self-contained and should not rely on any external modules or functions. Your solution should be within 200 lines of verilog code.
