
Design a simple WiFi module controller in Verilog that manages the connection state of a WiFi module. The module should have an input for a reset signal, a connect signal, and a disconnect signal. The module should have an output indicating the current state of the WiFi module: "Disconnected" (0), "Connecting" (1), and "Connected" (2). The state transitions should occur as follows:
- On reset, the state should go to "Disconnected".
- If the connect signal is high while in "Disconnected", it should transition to "Connecting".
- If the connect signal is high while in "Connecting", it should transition to "Connected".
- If the disconnect signal is high while in "Connected", it should transition back to "Disconnected".
