Design a character ROM that outputs a 10-bit wide font representation for a specified character and row number. When the RESET signal is low, the module initializes the font information from a predefined font value. On the falling edge of the clock, if the input character matches a specified character (in this case, 'H'), it outputs the corresponding row's font data based on the ROW_NUM input. If there is no match, the output is set to high impedance, effectively disabling it.
module top_module(CLK, RESET, CHAR_IN, ROW_NUM, DATA_OUT);
