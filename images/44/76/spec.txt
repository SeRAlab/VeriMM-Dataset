Design a circuit that implements four different types of latches: a D latch, JK latch, T latch, and SR latch. Each latch is controlled by a clock signal and has set and reset inputs for asynchronous operation. The D latch captures the input data on a clock edge, while the JK latch toggles its state based on its inputs; the T latch toggles its state when activated, and the SR latch sets or resets based on two control signals. Each latch outputs its current state, enabling the storage of one bit of information with distinct control mechanisms for each latch type.
module top_module(
  input clk,
  input din,
  input set,
  input reset,
  input j,
  input k,
  input t,
  input s,
  input r,
  output dout,
  output jkout,
  output tout,
  output srout
);
