Design a fan speed control system that uses a simple state machine. The system should have an input for temperature and should control the speed of the fan based on predefined temperature thresholds. If the temperature is below 20°C, the fan should be off. If the temperature is between 20°C and 30°C, the fan should run at low speed. If the temperature is between 30°C and 40°C, the fan should run at medium speed. If the temperature is above 40°C, the fan should run at high speed. The system should respond to changes in temperature continuously, and the state of the fan should be updated accordingly.
