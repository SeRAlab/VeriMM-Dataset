Design a Verilog module for a flash memory cell that can perform read, write, and erase operations. The memory cell should have a data input (D), a control input (W for write, R for read, E for erase), and a data output (Q). The memory cell should store one bit of data and should be able to read the stored data when R is high, write new data when W is high, and erase the stored data when E is high. The memory cell should be initialized to 0.
