Design a checksum circuit that computes an 8-bit checksum for an n-bit input data stream. The module takes an n-bit data input, sums the individual bits, and outputs the checksum value as an 8-bit result. Additionally, it checks the validity of the checksum by ensuring that the sum of the computed checksum and the total sum equals 255 (0xFF). The validity is indicated by a separate output signal, which becomes HIGH when the checksum is valid. This design is useful for error detection in digital communication systems.
module top_module(
  input [n-1:0] data_in,
  output reg [7:0] checksum_out,
  output reg valid_out
);
