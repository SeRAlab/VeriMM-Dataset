Design a 4-to-1 multiplexer that selects one of four 1-bit wide input signals based on a 2-bit select signal. The output reflects the value of the selected input; when sel is 00, out corresponds to in[0]; with sel as 01, it corresponds to in[1]; for sel as 10, it outputs in[2]; and when sel is 11, it selects in[3]. In any case where the select input is invalid, the output defaults to 0.
module top_module(
  input [3:0] in,
  input [1:0] sel,
  output reg out  // Changed from wire to reg
);
