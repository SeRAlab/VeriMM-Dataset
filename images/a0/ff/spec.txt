Design a shift register capable of loading an 8-bit value from an input and performing serial shifting on each clock cycle. When the load signal (ld) is asserted, the shift register will be loaded with the value from input d; otherwise, the register will shift its content left by one bit and input d will be shifted into the least significant bit position. The output q reflects the value of the least significant bit of the shift register.
module top_module(
  input clk,
  input ld,
  input d,
  output reg q
);
