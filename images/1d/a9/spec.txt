A 1-bit SRAM cell that can store a bit and allow for read and write operations. The SRAM cell should have the following inputs: `write_enable`, `data_in`, and `read_enable`, and output `data_out`. The behavior should be such that when `write_enable` is high, the `data_in` is stored. When `read_enable` is high, the stored value should be available at `data_out`.
