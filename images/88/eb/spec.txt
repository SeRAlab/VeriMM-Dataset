Implement a Verilog module for a 9-bit shift register with enable and asynchronous reset. The shift register should have a clock input `clk`, an asynchronous reset input `rst`, an enable input `en`, a 9-bit data input `D`, and a 9-bit output `Q`. When `rst` is high, `Q` should be set to 0. When `en` is high, `Q` should shift left by 1 bit on the rising edge of `clk` and the least significant bit of `Q` should be set to the least significant bit of `D`.

module shift_register9(
	input wire clk,
	input wire rst,
	input wire en,
	input wire [8:0] D,
	output reg [8:0] Q
);
