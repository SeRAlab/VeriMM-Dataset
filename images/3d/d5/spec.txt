
Design a 24-bit ADC with a simple 3-to-1 multiplexer. The multiplexer should select one of the three 24-bit input values based on a 2-bit select signal. The output should be the selected 24-bit value. Additionally, implement a mechanism to detect if any of the inputs exceed a defined threshold (e.g., 16,777,216). If any input exceeds the threshold, the output should be set to a predefined error value (e.g., 24'hFFFFFF) instead of the selected input.
