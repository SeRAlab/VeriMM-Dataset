

You are tasked with designing a module in Verilog that implements a 2-input AND gate. The module should have 2 input ports, A and B, and 1 output port, Y. The module should be named "and_gate". The module should be self-contained and should not require any external modules or packages.

The module should adhere to the following specifications:
- The module should be synthesizable and should have a maximum depth of 1.
- The module should implement a 2-input AND gate, where Y = A AND B.
- The module should use the following Verilog constructs: module, input, output, assign.

Write a Verilog module that implements the AND gate described above. Your solution should be within 200 lines of code.
