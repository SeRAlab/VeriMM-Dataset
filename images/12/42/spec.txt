Design a 1-bit SRAM cell with the following behavior: 
- The SRAM cell should have a data input (D), data output (Q), a write enable (WE), and a clock signal (CLK). 
- When WE is high, the value of D should be stored in the SRAM cell on the rising edge of CLK. 
- When WE is low, the value stored in the SRAM cell should be output on Q.
