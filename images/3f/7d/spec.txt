
Design a Verilog module that takes three 5-bit binary numbers as input, representing different investment proportions in a portfolio. The module should calculate the total investment and output a 5-bit binary number that represents the proportion of the total investment for each of the input proportions. The output should be scaled such that all outputs together represent the entire investment as a fixed-point number (for example, if inputs are 5, 10, and 15, the outputs should represent fractions of 30).
