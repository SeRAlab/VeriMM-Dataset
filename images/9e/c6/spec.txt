Design a one-bit wide, 2-to-1 multiplexer using NAND gates. The module takes two inputs, `a` and `b`, selects between them based on the `sel` signal. When `sel` is low, the output is equal to input `a`; when `sel` is high, the output becomes input `b`. The logic is implemented utilizing the properties of NAND gates to perform the selection and output the desired result.
module top_module(
    input a,
    input b,
    input sel,
    output out
);
