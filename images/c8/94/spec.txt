

You have been tasked with designing a Verilog module for a simple 8-bit adder. The module should have two input ports, `A` and `B`, and one output port, `S`. The module should also have a control input port, `C`, which determines whether the output should be the sum of `A` and `B` (`C = 1`) or the difference between `A` and `B` (`C = 0`).

Your task is to write a Verilog module that implements this functionality. The module should be named `addsub_8bit` and should be designed to be synthesizable. You should assume that the input and output ports are all 8 bits wide.
