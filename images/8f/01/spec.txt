Implement the Verilog module based on the following description.
Build an 8-bit shift register with an asynchronous negative edge triggered reset, synchronous load signal, and synchronous enable signal.
(1) reset: Resets shift register to zero.
(2) enable: Enables the shift register to shift left by one bit.
(3) load: Loads the shift register with an 8-bit value from input "data".
(4) data: 8-bit data input to the shift register.
(5) q: The contents of the shift register.

module top_module(
    input clk,
    input reset,
    input enable,
    input load,
    input [7:0] data,
    output reg [7:0] q);
