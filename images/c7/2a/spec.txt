

You are tasked with designing a verilog module that takes in two inputs, A and B, and outputs their sum, C. However, the output should only be valid when a control signal, enable, is high. If enable is low, the output should be held at its previous value. 

You should define the module with the following ports:
- A (1-bit input)
- B (1-bit input)
- C (1-bit output)
- enable (1-bit input)

Your module should be named "add_with_enable".
