Design a 2nd-order IIR filter using Verilog. The filter should take two inputs (current input and previous input) and produce an output based on the IIR filter equation: y[n] = a1 * x[n] + a2 * x[n-1] + b1 * y[n-1] + b2 * y[n-2]; where a1, a2, b1, and b2 are the filter coefficients. The filter should have two previous output states and one previous input state.
