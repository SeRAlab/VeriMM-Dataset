
Design a 4-bit DRAM cell with read and write functionality. The DRAM cell should have the following inputs:
- `clk`: Clock signal
- `wr_en`: Write enable signal (active high)
- `data_in`: 4-bit data input
- `addr`: 2-bit address input

The DRAM cell should have the following outputs:
- `data_out`: 4-bit data output

The design should be able to store data in one of the four memory locations based on the address provided. When `wr_en` is high, the input data should be written to the specified address. When `wr_en` is low, the data at the specified address should be read and available at `data_out`.
