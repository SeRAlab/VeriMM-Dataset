Design a 32-register file with synchronous write capabilities and asynchronous read operations. The module includes a clock and reset signal for initializing and managing the register states. When the reset signal is asserted, all registers are initialized to zero. The registers are addressed by 5-bit input addresses for reading, where Rs_Addr and Rt_Addr provide access to the contents of the designated registers Rs and Rt, respectively, while avoiding access to a zero register that always outputs zero. When the clock goes low and WriteReg is high, the data provided by WriteData is stored in the register indicated by Rd_Addr, allowing for selective updates while retaining existing register values.
