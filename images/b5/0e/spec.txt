Implement a 4-bit Synchronous Counter. The counter counts from 0 to 15 and then rolls over back to 0. It has an enable signal to control counting and a reset signal to reset the counter.

Module name:  
    counter  

Input ports:
    clk: Clock signal used for synchronous operations.
    rst: Reset signal. Defined as 1 for reset and 0 for reset signal inactive.
    en: Enable signal. Defined as 1 to enable counting and 0 to disable counting.

Output ports:
    count: 4-bit output representing the current count value.

Implementation:
The module includes a 4-bit register to store the count value. On the positive edge of the clock signal (clk) or the positive edge of the reset signal (rst), the module updates the count value.
If the reset signal (rst) is high, the count register is set to 0. If the reset signal (rst) is low and the enable signal (en) is high, the count register is incremented. When the count value reaches 15, it rolls over to 0 on the next increment.

Give me the complete code.

    input clk,
    input rst,
    input en,

    output [3:0] count
);
