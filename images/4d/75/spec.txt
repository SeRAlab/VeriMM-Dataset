Implement a synchronous counter with an 8-bit output that supports asynchronous loading of a value, alongside an 8-bit barrel shifter that can perform left and right shifts based on enable inputs. The counter increments on each clock cycle unless reset or loaded with a new value. The module outputs the current counter value, the result of the barrel shift operation, and the final output, which is the sum of the counter and the shifter output. This design integrates counting and shifting functionalities and allows for dynamic data manipulation through specified inputs.
module top_module(
    input clk,
    input reset,      // Active-high synchronous reset
    input load,       // Asynchronous active-high load input
    input [7:0] load_value, // 8-bit load value
    input [1:0] ena, // Left/right enable inputs for the barrel shifter
    input [7:0] data, // Input for the barrel shifter
    output reg [7:0] counter_out, // 8-bit output from the counter
    output reg [7:0] shifter_out, // 8-bit output from the barrel shifter
    output reg [7:0] final_out // Sum of counter and barrel shifter outputs
);
