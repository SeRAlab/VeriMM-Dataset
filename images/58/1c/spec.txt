Design a forwarding unit for a pipelined processor that resolves data hazards by determining the need for data forwarding based on register write signals and destination registers. The module takes as input signals indicating whether the execute/memory and memory/write back stages are writing to registers, along with the relevant register identifiers (source and target). It produces two outputs, ForwardA and ForwardB, each 2 bits wide, to indicate if the values from the execute/memory stage or the memory/write-back stage should be forwarded to the inputs of the subsequent instruction execution stage, thus reducing stalling in the pipeline due to data hazards.
module top_module(EX_MEMRegWrite,MEM_WBRegWrite,EX_MEMRegisterRd,MEM_WBRegisterRd,ID_EXRegisterRs,ID_EXRegisterRt,ForwardA,ForwardB);
