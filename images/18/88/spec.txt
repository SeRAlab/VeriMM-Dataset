Design a Verilog module that implements a basic Quadrature Amplitude Modulation (QAM) transmitter. The module should take in 4 bits of input data representing the symbols and output a 2-bit I (In-phase) and a 2-bit Q (Quadrature) signal based on a predefined mapping for 16-QAM. The mapping is as follows: 
00 -> (1, 1), 01 -> (1, -1), 10 -> (-1, 1), 11 -> (-1, -1). The design should utilize a clock and a reset signal to synchronize the output with the input. The module should also feature an enable signal to allow or disallow the transmission of data.
