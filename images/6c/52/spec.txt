Design a 4-bit ripple counter that increments its output value on every positive edge of the clock signal. When the reset signal is asserted, the counter and all internal pipeline registers are set to zero. The counter utilizes three internal pipeline registers to store the output of the previous stages, creating a staggered counting mechanism. The output is updated to reflect the value of the third pipeline register plus one, effectively creating a delayed increment behavior.

  input clk,
  input reset,
  output reg [3:0] out
