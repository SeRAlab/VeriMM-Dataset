Design a UART (Universal Asynchronous Receiver-Transmitter) transmitter module that serializes an 8-bit data input for transmission. The module operates through four states: IDLE, START, SEND, and STOP. In the IDLE state, the transmitter is inactive and waits for the start signal; upon receiving `tx_start`, it transitions to the START state where it initializes the data to be sent. In the SEND state, each bit of the 8-bit data is transmitted serially on each `s_tick` pulse. After all bits are sent, the module transitions to the STOP state where it outputs a stop bit and signals the completion of the transmission with `tx_done`. The module utilizes a finite state machine (FSM) approach to manage state transitions, ensuring proper timing and order of operations for serial data transmission.
module top_module(input clock,input reset,input s_tick,input tx_start,input [7:0] data_in,output reg tx,output reg tx_done);
