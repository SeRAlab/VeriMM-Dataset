Design a combined 4-bit comparator and barrel shifter. The module compares two 4-bit inputs, A and B, and produces outputs for equality (eq) and greater-than (gt). It also includes a barrel shifter that shifts A left or right based on a control input (C) and the amount specified by another 4-bit input (D). The final output is derived from the logical conjunction of the equality, greater-than condition, and the shifted value of A.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output eq,
    output gt,
    input C,
    input [3:0] D,
    output [3:0] final_output
);
