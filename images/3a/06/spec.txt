Design a JK flip-flop using Verilog. The flip-flop should have inputs J, K, clock, and reset. The output should be Q. The behavior should be as follows: On the rising edge of the clock, if reset is high, Q should be set to 0. If J and K are both high, Q should toggle. If J is high and K is low, Q should be set to 1. If J is low and K is high, Q should be set to 0. If both J and K are low, Q should remain unchanged.
