Design a data exporter module that facilitates data transfer between an input source and an output destination. The module receives a 64-bit input data alongside a valid signal and a last signal, and when the output is ready, it captures this input data into a register along with the last signal while asserting the output valid signal. Conversely, upon receiving a readiness signal for output, it lowers the valid signal and raises the input ready signal, enabling back-and-forth communication. This module effectively acts as a buffering mechanism to manage valid data transfer, ensuring synchronization between the input and output signals.
module top_module(
    input wire[63:0] din_data,
    input wire din_last,
    output wire din_ready,
    input wire din_valid,
    output wire[63:0] dout_data,
    output wire dout_last,
    input wire dout_ready,
    output wire dout_valid
);
