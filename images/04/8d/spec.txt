Create a 5-bit serial-in serial-out (SISO) shift register in Verilog. The shift register should have a serial input, a clock input, and a reset input. On each rising edge of the clock, if reset is not asserted, the input bit should be shifted into the register. The output should be available as a 5-bit parallel output after 5 clock cycles. The register should initialize to 0 when reset is asserted.
