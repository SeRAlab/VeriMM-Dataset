Design an OFDM demodulator that takes in a serial input of modulated data and outputs parallel demodulated data. The demodulator should have a fixed number of subcarriers, for example, 4. The input data will be received at a clock edge and should be stored in a shift register until enough data is available to demodulate the output. The output should be valid when a specified number of clock cycles have elapsed since the first input data was received.
