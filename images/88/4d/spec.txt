Design a 4-bit binary counter with load functionality. On each positive edge of the clock, the counter increments its value by one unless the reset signal is active, in which case it resets to zero. If the load signal is asserted, the counter loads a specified 4-bit value from the input "load_data" instead of incrementing.
module top_module(
    input clk,
    input reset,
    input load,
    input [3:0] load_data,
    output reg [3:0] count
);
