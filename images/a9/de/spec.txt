Design a 4-to-1 multiplexer with an enable signal. When the enable signal (E) is HIGH, the output (Q) will take the value of input A. When the enable signal is LOW, the output will instead take the value of input D. Inputs B and C are designated but not utilized in this design, effectively allowing for selective data routing based on the enable condition.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input [3:0] C,
    input [3:0] D,
    input E,
    output reg [3:0] Q
);
