Design a 4-bit adder circuit that performs the addition of two 4-bit inputs, A and B, along with an optional carry-in (Cin). The addition operation is controlled by an enable signal (en) and can reset to zero with the reset signal (rst). The circuit also includes a carry-out (Cout) output that indicates if there was a carry from the most significant bit during addition or if an additional carry condition is enabled when the output equals 15 (4'hF).
module top_module(
  input clk,
  input rst,
  input en,
  input en_carry,
  input [3:0] A,
  input [3:0] B,
  input Cin,
  output [3:0] S,
  output Cout
);
