

You are tasked with designing a verilog module that implements a 4-bit unsigned comparator. The module should have two input ports, A and B, and three output ports, EQ, GT, and LT. EQ should be high when A is equal to B, GT should be high when A is greater than B, and LT should be high when A is less than B. You should use the following template for the module:

```
module unsigned_comparator (
    input [3:0] A,
    input [3:0] B,
    output EQ,
    output GT,
    output LT
);

// Your code here

endmodule
```
