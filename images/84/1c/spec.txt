Create a Verilog module to implement a D flip-flop with synchronous reset and enable. When the reset signal is asserted (reset = 1), the output q should be set to 0. When the enable signal is asserted (enable = 1), the output q should follow the input d on the next positive clock edge. Otherwise, q should hold its value.

module d_flip_flop
(
    input clk,
    input reset,
    input enable,
    input d,
    output reg q
);
