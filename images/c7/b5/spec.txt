

You are tasked with designing a verilog module that takes in 3 inputs (A, B, C) and produces a single output (Y). The output Y should be 1 if A is greater than or equal to B and C is less than B. Otherwise, Y should be 0. Assume that A, B, and C are 8-bit unsigned integers.

Your module should be named "greater_than" and should have the following ports:

- input [7:0] A
- input [7:0] B
- input [7:0] C
- output Y

Write the verilog code for the "greater_than" module.
