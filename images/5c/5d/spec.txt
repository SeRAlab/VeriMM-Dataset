Implement a clock divider circuit with five independent prescalers that generate multiple output clocks (D1, D2, D3, D4) based on different division factors. Each prescaler counts incoming clock cycles and toggles its respective output signal when the count reaches a predefined threshold. The division factors are defined as powers of two, allowing for simple scaling and easy configuration. The outputs can be used for generating various clock frequencies derived from the input clock (clk_in).
module top_module(
    input clk_in,
    output reg D1,
    output reg D2,
    output reg D3,
    output reg D4
);
