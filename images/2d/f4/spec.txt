Design a Verilog module that implements a simple RNN cell for inference. The RNN should take an input vector of size 5 and a hidden state vector of size 5, and produce an output vector of size 5. The RNN should use a simple activation function (e.g., identity) and maintain the hidden state across clock cycles. The module should have the following ports: clk (clock), rst (reset), input_vector (5-bit input), hidden_state (5-bit input), output_vector (5-bit output).
