Design a circuit that implements an 8-bit D flip-flop with asynchronous reset and enable functionality. On the negative edge of the clock, if reset is asserted low, the output initializes to all ones (8'b11111111). If reset is not active, the flip-flop captures the value from the data input when enable is high. The output reflects the stored data when enable is asserted; otherwise, it outputs all zeros (8'b00000000).
module top_module(
  input clk,
  input reset,
  input enable,
  input [7:0] data_in,
  output reg [7:0] data_out
);
