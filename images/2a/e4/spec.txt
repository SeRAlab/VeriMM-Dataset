
Design a Verilog module to interface with an SD card that reads a 4-bit command input and indicates the readiness of the SD card with a 1-bit output signal. The module should have a clock input and a reset input. On the rising edge of the clock, if the reset is low, the module should set the output ready signal based on the following commands:
- Command 0: Ready (output ready = 1)
- Command 1: Not Ready (output ready = 0)
- Command 2: Initialization (output ready = 1)
- Command 3: Error (output ready = 0)
- Commands 4-15: Reserved (output ready = 0)
The output should hold its value until the next clock cycle.
