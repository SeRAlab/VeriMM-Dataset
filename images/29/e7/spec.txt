
Design a 16-bit Linear Feedback Shift Register (LFSR) Verilog module. The LFSR should use the polynomial x^16 + x^14 + x^13 + x^11 + 1 as the feedback function. The module should have a clock input, a reset input, and a 16-bit output that represents the current LFSR state. The LFSR should shift its state on every clock cycle and if reset is asserted, it should initialize to a non-zero seed value (for example, 16'hACE1).
