Design a dual-port synchronous RAM module that supports independent read and write operations on two different ports (A and B). Each port operates with its own clock signal and can reset its address registers. The module has a data width of 16 bits and an address width of 8 bits, allowing storage for up to 256 16-bit words. Port A and Port B utilize enable signals to control read/write operations, and data is written to or read from the specified addresses on the rising edge of the respective clock signals.
