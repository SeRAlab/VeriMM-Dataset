Design a module that captures input data and provides both the original and its inverted version. On the rising edge of the clock (clk), it outputs the original 8-bit data from `data_in` to `data_out`. Simultaneously, on the falling edge of the clock, it outputs the bitwise negation of `data_in` to `data_out_inv`. This module effectively serves as a dual-purpose data register with both direct and inverted outputs based on clock transitions.
module top_module(
  input clk,
  input [7:0] data_in,
  output reg [7:0] data_out,
  output reg [7:0] data_out_inv
);
