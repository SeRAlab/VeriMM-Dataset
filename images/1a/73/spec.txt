Design a simple NVMe controller register that can handle read and write operations. The controller should have a 32-bit input data bus, a 32-bit output data bus, a read/write control signal, and an enable signal. When the enable signal is high and the write control signal is asserted, the data on the input bus should be written to the register. When the read control signal is asserted, the data from the register should be placed on the output bus.
