Design a simple PCIe packet checker that verifies the integrity of incoming data packets. The checker will take a 32-bit data input and a 4-bit control signal indicating the type of packet. The control signal has the following meanings: 0000 - Data Packet, 0001 - Acknowledgment Packet, 0010 - Error Packet, and the remaining values are reserved. The checker should assert a valid output signal if the packet type is Data or Acknowledgment and the data is not zero. If the packet type is Error or if the data is zero, the valid output should be deasserted.
