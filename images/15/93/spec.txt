Design a 4-bit CRC module that calculates the CRC of a given 4-bit input data using a predefined polynomial. The polynomial used is x^4 + x^3 + x^2 + 1 (binary representation: 11001). The module should have a clock input, a reset input, and a 4-bit data input. The CRC result should be a 4-bit output. The CRC should be updated on the rising edge of the clock when the data input is valid.
