Design a checksum calculator that takes an n-bit wide input data vector and computes its checksum, producing an m-bit wide output. The module sums the values of the input data words and then computes the final checksum by taking the sum modulo \( 2^m \). The parameters n and m can be configured to define the bit width of the input data and the size of the checksum, respectively.

  input [n-1:0] data,
