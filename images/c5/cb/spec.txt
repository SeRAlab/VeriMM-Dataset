
You are tasked with designing a Verilog module that implements a 4-bit binary counter with synchronous reset. The module should have the following inputs and outputs:
- `clk` (1-bit input): clock signal
- `reset` (1-bit input): asynchronous reset signal, active low
- `count` (4-bit output): current count value

The counter should increment on every rising edge of the clock signal, and reset to 0 when the reset signal is asserted. The initial count value should be 0.

Write the Verilog code for the module that implements the 4-bit binary counter with synchronous reset.
