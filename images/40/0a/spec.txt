Implement a Verilog module that performs LU decomposition on a 2x2 matrix. The module takes a 2x2 matrix as input and produces the lower triangular matrix L and the upper triangular matrix U as output. The matrices will be represented as 4-bit wide signals. The LU decomposition of a matrix A is given by A = LU, where L is a lower triangular matrix and U is an upper triangular matrix.
