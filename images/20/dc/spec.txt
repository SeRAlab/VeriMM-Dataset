Design a temperature-based shutdown system that turns off a device when the temperature exceeds a certain threshold (e.g., 75 degrees Celsius). The system should have a clock input and a reset input. When the reset is activated, the system should return to the safe state. The system should have an input for temperature and an output for the shutdown signal. If the temperature exceeds 75 degrees, the shutdown signal should be activated, otherwise it should remain deactivated.
