

You are tasked with designing a verilog module that can calculate the sum of two 8-bit unsigned numbers. The module should have two input ports, `a` and `b`, and one output port, `sum`. The module should also have a control input port, `enable`, which should be high to enable the calculation and low to disable it. When the `enable` input is high, the module should add the values of `a` and `b` and output the result on the `sum` port. When the `enable` input is low, the `sum` output should be zero. You may assume that the input values `a` and `b` are always valid 8-bit unsigned numbers.
