

You are tasked to design a verilog module that performs a binary to gray code conversion. The module should have two inputs: a 4-bit binary number, and a clock signal. The module should have one output: a 4-bit gray code number. The module should operate on the rising edge of the clock signal. The binary input number may change asynchronously, but the gray code output should only change on the rising edge of the clock signal. 

You may assume that the binary input is always valid, and that the clock signal has a 50% duty cycle. You may also assume that the module is part of a larger system, and that the inputs and outputs are connected to other modules.
