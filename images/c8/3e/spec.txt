

You have been tasked to design a verilog module for a 2:1 multiplexer with the following inputs and outputs:

Inputs:
- sel: a single bit input representing the selection signal
- a: a 4-bit input signal
- b: a 4-bit input signal

Outputs:
- out: a 4-bit output signal representing the selected input signal based on the value of sel.

Design a verilog module that implements the 2:1 multiplexer with the given inputs and outputs. The output should be the selected input signal based on the value of the selection signal.
