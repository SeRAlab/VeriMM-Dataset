The output signals indicate which light is active, where red is on for 5 seconds, followed by a red-yellow state for 1.25 seconds, then green for 7.5 seconds, and finally yellow for 1.25 seconds. This module utilizes a counter that decrements over time to facilitate the transitions between states, ensuring safe traffic management at intersections.
module top_module(
  input clk,
  input reset,
  input [1:0] state,
  output reg red,
  output reg green,
  output reg yellow
);
