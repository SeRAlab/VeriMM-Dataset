Design a 1-to-16 demultiplexer that takes an 8-bit input and a 4-bit select signal. Depending on the value of the select signal, the module routes the 8-bit input to one of the 16 output lines (Out0 to Out13). Only the selected output line will hold the value of the input; all other outputs will retain their previous state. This module is useful for distributing a single data source to multiple destinations based on the selector logic.
