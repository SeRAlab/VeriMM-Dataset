Design a circuit that generates a beep signal based on input flags. The module monitors two input signals, `beep_flag1` and `beep_flag2`, and, on each rising edge of the clock signal `CLK`, outputs a LOW signal (active) if either flag is asserted. If neither flag is asserted, it outputs a HIGH signal (inactive). This creates a mechanism to control a buzzer or similar device, turning it on when the flags are low and turning it off when either flag is high.
module top_module(
	 input CLK,
    input beep_flag1,
	 input beep_flag2,
    output beep
    );
