Design a pulse-width modulation (PWM) generator that produces a PWM output signal controlled by a specified duty cycle. The module takes a clock signal and two inputs: a data signal used to enable or disable the PWM signal and a duty cycle value representing the proportion of time the output should be high within a defined number of clock cycles. The PWM output can only be high when the data input is also high, and it modulates based on the duty cycle, toggling between high and low states according to the counter that increments with each clock cycle.
module top_module(
  input clk,
  input [n-1:0] data,
  input [m-1:0] duty_cycle,
  output pwm
);
