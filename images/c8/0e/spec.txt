

You are tasked with designing a module that takes in a 2-bit binary input and outputs a 1-bit binary value. The output should be the inverse of the least significant bit of the input. You are not allowed to use any other modules in your design.

Design a Verilog module that implements the above functionality.

Your module should be named `inv_lsb` and have the following ports:
- `data`: a 2-bit binary input
- `q`: a 1-bit binary output

You should ensure that your module can handle all possible input combinations.
