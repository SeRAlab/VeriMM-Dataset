Design a digital circuit that produces an output X based on a combination of inputs A1, A2, A3, B1, and B2. The output X is set to HIGH (1) when either A1 is true and A2 is false, or when A1 is false and A2 is true. Additionally, if both A1 and A2 are true, X is HIGH when A3 is false and either B1 is true with B2 false or B1 is false with B2 true; otherwise, X is LOW (0) under all other conditions. This circuit effectively acts as a complex combinational logic function with specific conditions for HIGH output based on the state of multiple inputs.
module top_module(
    input A1,
    input A2,
    input A3,
    input B1,
    input B2,
    output X,
    input VPB,
    input VPWR,
    input VGND,
    input VNB
);
