Design a four-bit arithmetic unit that performs either addition or subtraction based on the control input C. When C is 0, the module computes the sum of two four-bit inputs A and B, while it calculates the difference A - B when C is 1. The module includes overflow and underflow detection: if the sum exceeds the maximum representable value (15), an overflow flag is raised, and if the difference drops below the minimum value (0), an underflow flag is triggered. The output Y displays either the sum or the difference, depending on the operation selected, while the overflow flag OVF indicates any arithmetic overflow or underflow conditions.
