Design a D Flip-Flop with asynchronous reset and set functionalities. The module has inputs for clock (CLK), data (D), reset (RESET), and set (SET). When RESET is asserted (active-low), the output Q is set to 0. When SET is asserted (active-low), the output Q is set to 1. In normal operation, on the rising edge of the clock, the output Q takes the value of input D. The complementary output QN is also provided, which is the inverted value of Q.
module top_module(
    input CLK,
    input D,
    input RESET,
    input SET,
    output reg Q,    // Change Q to reg type
    output QN
);
