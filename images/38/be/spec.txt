
Design an 8-bit SRAM cell that allows read and write operations. The SRAM cell should include the following inputs: a write enable signal (we), a read enable signal (re), an 8-bit data input (data_in), an 8-bit data output (data_out), and a 3-bit address (addr). The SRAM cell should be capable of storing data in one of 8 locations (0 to 7) based on the address input.
