Design a WiFi module controller that manages the state of a WiFi connection. The module should have the following states: IDLE, CONNECTING, CONNECTED, and DISCONNECTED. The controller takes a start signal to initiate a connection, a connected signal to indicate successful connection, and a disconnect signal to terminate the connection. The output of the module should indicate the current state. The state transitions are as follows:
- IDLE -> CONNECTING (on start signal)
- CONNECTING -> CONNECTED (on connected signal)
- CONNECTED -> DISCONNECTED (on disconnect signal)
- DISCONNECTED -> IDLE (on start signal to reconnect)
Additionally, implement a reset functionality that brings the state back to IDLE.
