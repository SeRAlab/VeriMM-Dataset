Design a level-sensitive D latch with an active-low clear input. When CLR is asserted, the output Q is reset to 0 regardless of the other inputs. When CLR is not active and G (the gate input) is high, the output Q is updated to the value of D. Thus, Q captures the value of D when G is enabled, effectively storing the state based on the input D while providing a mechanism for asynchronous reset.
