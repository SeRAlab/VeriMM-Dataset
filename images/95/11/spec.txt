Design a 4-bit shift register with a load functionality. When the load signal is asserted, the module will load the provided 4-bit input data into the output register. If the load signal is not asserted, the register will perform a right shift operation, moving its bits to the right and inserting the most significant bit of the input data into the least significant bit position. This allows for both data loading and shifting operations based on the clock signal.
module top_module(
    input clk,
    input load,
    input [3:0] data,
    output reg [3:0] out
);
