Design a 4-bit binary counter that increments on the rising edge of the clock. The counter has an active-high reset input that sets the output to zero when asserted. When enabled, the counter counts up from 0 to 15, and then wraps back to 0 after reaching 15. If the enable signal is low, the counter holds its value steady.

  input clk,
  input rst,
  input enable,
