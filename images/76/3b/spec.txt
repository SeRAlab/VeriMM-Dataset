Develop a Verilog module for a 4-bit synchronous binary counter with a parallel load input. The module should have an input clock signal (clk), an input reset signal (rst), an input load signal (load), an input [3:0] load_value, and a 4-bit output signal (count). On the rising edge of the clock, if reset is high, count should be set to 0. If load is high, count should be set to load_value. Otherwise, it should increment by 1.
