Develop a 16-bit shift register with load and shift capabilities. When the load signal is asserted, the register captures the 16-bit input data (din) on the rising edge of the clock. When the shift signal is active, the register performs a left shift operation, shifting all bits to the left and introducing a zero at the least significant bit position.
module top_module(
  input clk,
  input load,
  input shift,
  input [15:0] din,
  output reg [15:0] dout
);
