
Design a binary min-heap data structure in Verilog. The heap should support the following operations:
1. Insert a value into the heap.
2. Delete the minimum value from the heap.
3. Get the minimum value from the heap.

The heap will have a fixed size of 16 elements. The interface should consist of:
- A 4-bit input for the value to be inserted.
- A control signal to indicate the operation (insert, delete, get).
- An output for the current minimum value.
- An output for the success/failure of the operations.

The min-heap should maintain its properties after each operation.
