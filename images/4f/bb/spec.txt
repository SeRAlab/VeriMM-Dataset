Design a Verilog module for a 6-bit binary counter with both synchronous set and enable signals. The counter increments its value on the rising edge of the clock when the enable signal is active and sets to a specific value when the set signal is active.

Module name:  
    counter_6bit_set  

Input ports:
    clk: Chip clock signal.
    rst: Synchronous reset signal.
    en: Enable signal.
    set: Synchronous set signal.
    set_value: Value to set the counter.

Output ports:
    count: Counter output signal with a data width of 6 bits.

Implementation:
Counter operation:
On every positive edge of the clock signal (clk), the counter (count) is reset if the reset signal (rst) is active. Otherwise, if the set signal is active, the counter is set to the specified set_value. If both reset and set signals are inactive, the counter increments its value if the enable signal (en) is active.
