
Implement a 2nd-order IIR filter with the following transfer function:
H(z) = (b0 + b1*z^(-1) + b2*z^(-2)) / (1 + a1*z^(-1) + a2*z^(-2))
The filter coefficients are:
b0 = 0.2, b1 = 0.3, b2 = 0.5
a1 = -0.4, a2 = 0.1

Your task is to create a Verilog module that simulates this IIR filter. The module should take a 16-bit signed input sample and output a 16-bit signed result. Use fixed-point arithmetic for the filter calculations, and ensure that the output is properly quantized.
