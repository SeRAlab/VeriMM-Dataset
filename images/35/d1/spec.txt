Design an SR flip-flop in Verilog. The flip-flop should have two inputs, S (Set) and R (Reset), and two outputs, Q and Q_not. The flip-flop should operate according to the following behavior: 
- When S = 1 and R = 0, Q should be set to 1.
- When S = 0 and R = 1, Q should be reset to 0.
- When S = 0 and R = 0, Q should retain its previous state.
- When S = 1 and R = 1, it is considered an invalid state.
