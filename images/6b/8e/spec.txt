Design a 3-to-1 multiplexer that selects one of three 32-bit input sources (RD2, E_Forward, or M_Forward) based on a 2-bit select input (selet). When selet is 0, the output (rt_final) is set to RD2; when selet is 1, the output is set to E_Forward; when selet is 2, the output is set to M_Forward; and if selet is any other value, the output defaults to 0.
module top_module(
    input [31:0] RD2,
    input [31:0] E_Forward,
    input [31:0] M_Forward,
    input [1:0] selet,
    output [31:0] rt_final
    );
