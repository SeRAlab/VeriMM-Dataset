Design a combinational circuit that implements a simple Huffman encoding for three symbols with the following frequencies: A (5), B (9), and C (12). The output should provide a 2-bit binary code for each symbol based on the Huffman tree. The output encoding should be as follows: A -> 00, B -> 01, C -> 10. The circuit should have three inputs representing symbols, and the output should show the corresponding Huffman code.
