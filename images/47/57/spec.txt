Design a 4-input NOR gate circuit. The module takes four input signals, A, B, C, and D, and produces a single output Y that represents the logical NOR of all four inputs. The output Y is high (logic 1) when all inputs are low (logic 0) and low otherwise. This is achieved by first computing the NOR of inputs A and B, and C and D separately, and then applying NOR again to the results.
module top_module(
    input A,
    input B,
    input C,
    input D,
    output Y
);
