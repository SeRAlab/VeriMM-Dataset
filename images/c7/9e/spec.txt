

You are tasked with designing a Verilog module that takes in a 16-bit input signal `in` and outputs a 16-bit signal `out` that is the result of performing a bitwise AND operation between `in` and a 16-bit mask signal `mask`. The module should also have a control input `enable` that, when set to 1, enables the AND operation and allows `in` to pass through to `out`. When `enable` is set to 0, the module should output all zeros.

Assume that the input signal `in` and the mask signal `mask` are both valid 16-bit signals, and that the control input `enable` is a valid 1-bit signal.

Your module should be named `bitwise_and` and should have the following inputs and outputs:

Inputs:
- `in` (16-bit signal)
- `mask` (16-bit signal)
- `enable` (1-bit signal)

Outputs:
- `out` (16-bit signal)

Your module should be implemented within 200 lines of Verilog code.
