Design a 4-bit binary counter that increments its value on each positive edge of the clock signal (CLK) when the enable signal (EN) is high. If the reset signal (RST) is active, the counter resets its value to zero. The current count is output as a 4-bit wide signal (Q).
module top_module(
    input  wire        CLK,
    input  wire        RST,
    input  wire        EN,
    output wire [3:0]  Q
);
