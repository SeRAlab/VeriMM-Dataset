Design a 4-bit shift register that operates on the positive edge of the clock. When the reset (rst) signal is high, the output is cleared to zero. If the enable (en) signal is active, the shift register shifts its contents to the left and inserts the least significant bit of the input (in) into the rightmost position. This operation effectively allows for serial input to be shifted into the register while maintaining its shifting capability.
module top_module(
    input clk,
    input rst,
    input en,
    input [3:0] in,
    output reg [3:0] out
);
