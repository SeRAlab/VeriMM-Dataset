

You have been tasked with designing a 4-to-1 multiplexer using Verilog. Write a module called `MUX4X1` that has four inputs, `A`, `B`, `C`, and `D`, and two inputs, `S0` and `S1`. The output of the multiplexer should be `Z`. The multiplexer should follow the truth table below:

| S1 | S0 | Z  |
|----|----|----|
| 0  | 0  | A  |
| 0  | 1  | B  |
| 1  | 0  | C  |
| 1  | 1  | D  |

Your module should have the following interface:
```
module MUX4X1 (A, B, C, D, S0, S1, Z);
input  A ;
input  B ;
input  C ;
input  D ;
input  S0 ;
input  S1 ;
output Z ;
```
You can use any combinational logic gates and Verilog constructs to implement the multiplexer. Ensure that your implementation follows the truth table above.
