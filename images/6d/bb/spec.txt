Develop an 8-bit binary adder that adds two 8-bit inputs, A and B. The module outputs the 8-bit sum of A and B, along with a carry flag indicating if an overflow occurred (i.e., if the sum exceeds the maximum representable value of 255). The carry signal is asserted when the sum exceeds 255, while the sum output always reflects the lower 8 bits of the result.
module top_module(
  input [7:0] A,
  input [7:0] B,
  output reg [7:0] sum,
  output reg carry
);
