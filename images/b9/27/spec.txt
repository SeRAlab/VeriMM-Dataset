Design a circuit that converts a 4-bit hexadecimal input into its equivalent Binary-Coded Decimal (BCD) representation. If the input hex value exceeds 9 (i.e., 4'b1001), the module generates a carry-out signal and adjusts the BCD output by subtracting 10 from the hex value. If the hex value is 9 or less, the BCD output mirrors the hex input without any carry.
module top_module(
    input [3:0] hex, 
    output reg [3:0] bcd, 
	output reg carry 
    );
