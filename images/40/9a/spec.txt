Design an 8-bit Analog to Digital Converter (ADC) circuit that takes a 3-bit binary input representing the voltage range (from 0 to 7 volts) and outputs a corresponding 8-bit digital value. The mapping should be linear such that each input value corresponds to a digital value scaled from 0 to 255, where 0 volts corresponds to 0 and 7 volts corresponds to 255.
