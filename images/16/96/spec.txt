Design a 16-bit SRAM cell with read and write operations. The SRAM cell should consist of an array of 16 individual SRAM cells, each capable of storing 1 bit of data. The inputs should include a 4-bit address bus (for selecting one of the 16 cells), a data input bus (1 bit for writing data), a read enable signal, and a write enable signal. The output should be the 1-bit data stored at the specified address when read is enabled.
