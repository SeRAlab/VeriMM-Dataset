Design a 16-bit Linear Feedback Shift Register (LFSR) that generates a pseudorandom sequence of bits. The feedback polynomial is defined as x^16 + x^14 + x^13 + x^11 + 1, and the LFSR should be initialized with a non-zero seed value. The output of the LFSR should be a 16-bit value that represents the current state of the LFSR.
