On the rising edge of the clock, if the preset (`pre`) input is HIGH, the output is set to HIGH. If the clear (`clr`) input is HIGH, the output resets to LOW. If neither of these controls is active, the output will follow the input `d` if the enable (`en`) signal is HIGH.
