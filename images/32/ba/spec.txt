
Design a 4-bit DRAM cell with read and write operations. The cell should be able to store a 4-bit value and allow reading the stored value. The DRAM cell will have the following inputs:
- `clk`: Clock input
- `we`: Write enable (1 for write, 0 for read)
- `data_in`: 4-bit input data to be written to the cell
- `data_out`: 4-bit output data read from the cell

When `we` is high, the `data_in` should be stored in the cell on the rising edge of `clk`. When `we` is low, the `data_out` should reflect the stored value.
