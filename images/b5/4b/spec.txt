Please act as a professional verilog designer.

Design a Verilog module for an 8-bit register with synchronous clear and load capabilities. The register loads a new value on the rising edge of the clock when the load signal is active. It also clears the value synchronously when the clear signal is active.

Module name:  
    reg_8bit  

Input ports:
    clk: Chip clock signal.
    clr: Synchronous clear signal.
    load: Load signal for the register.
    d: Data input signal with a data width of 8 bits.

Output ports:
    q: Register output signal with a data width of 8 bits.

Implementation:
Register operation:
On every positive edge of the clock signal (clk), the register (q) is updated.
If the clear signal (clr) is active, the register is cleared to 0.
If the load signal (load) is active, the data input (d) is loaded into the register.
