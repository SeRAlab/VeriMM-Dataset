

You are tasked with designing a verilog module for a 2:1 multiplexer. The module should have two inputs, `A` and `B`, and one output, `Y`. The module should also have a select input, `S`, which determines which input is propagated to the output. If `S` is high, `B` should be propagated to `Y`, and if `S` is low, `A` should be propagated to `Y`. Use the following template to create your module:

```
module mux_2to1 (
    Y,
    A,
    B,
    S
);

    output Y;
    input A, B, S;

    // Your code here

endmodule
```
