
Design a simple Automatic Repeat reQuest (ARQ) error correction system that acknowledges received data and requests retransmission if an error is detected. The system will include a data sender and a receiver. The sender will send data in 5-bit words, and the receiver will check for errors using a simple parity bit. If an error is detected, the receiver will signal the sender to retransmit the data. The design should include state management for sending, waiting for acknowledgment, and handling retransmissions.
