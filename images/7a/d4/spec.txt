Write a Verilog module for a combinational circuit with three inputs x, y, and z, and one output w. The output should be defined by these rules:

If x = 1, y = 0, z = 0, then w = 1.
If x = 0, y = 1, z = 1, then w = 0.
If x = 1, y = 1, z = 1, then w = 1.
If x = 0, y = 0, z = 0, then w = 0.
If x = 1, y = 0, z = 1, then w = 1.

module logic_design (
	input x,
	input y,
	input z,
	output reg w);
