
Design a Verilog module that implements a simple decision tree for classifying a binary input based on three criteria. The input is a 3-bit vector (x[2:0]), representing three features. Based on these features, the output will be a 2-bit class label (y[1:0]). The classification rules are as follows:
1. If x[2] is 1, then if x[1] is 1, then y = 00; else y = 01.
2. If x[2] is 0, then if x[0] is 1, then y = 10; else y = 11.
You need to implement this logic in Verilog.
