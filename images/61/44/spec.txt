Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state R (output 0).
2. state S (output 1).
3. state T (output 0).
4. state U (output 1).

State transitions:
1. From state R: If l = 1, then transition to state S. If l = 0, then transition to state T.
2. From state S: If l = 1, then transition to state U. If l = 0, then transition to state R.
3. From state T: If l = 1, then transition to state U. If l = 0, then transition to state R.
4. From state U: If l = 1, then transition to state S. If l = 0, then transition to state R.

Assume that a one-hot code is used with the state assignment n[3:0] = 0001(R), 0010(S), 0100(T), 1000(U)

Write a Verilog for the signal N1, which is the input of state flip-flop n[1], for the signal N2, which is the input of state flip-flop n[2]. Derive the Verilog by inspection assuming a one-hot encoding.

module top_module (
        input [3:0] n,
        input l,
        output reg N1,
        output reg N2);
