
Design a 4-bit SRAM cell that can store a 4-bit value. The SRAM cell should have the following inputs: `data_in` (4 bits), `write_enable` (1 bit), `read_enable` (1 bit), and an output `data_out` (4 bits). When `write_enable` is high, the `data_in` should be stored in the cell. When `read_enable` is high, the stored data should be output to `data_out`.
