
You are tasked with designing a module in Verilog that can perform a specific function. The module should be no longer than 200 lines of code, and should be able to take in an input signal and output a corresponding output signal.

The module should be named `add_subtract` and should have the following inputs and outputs:
- `input [7:0] a`: an 8-bit input signal
- `input [7:0] b`: an 8-bit input signal
- `input sel`: a single-bit input signal that selects between addition and subtraction (0 for addition, 1 for subtraction)
- `output [7:0] result`: an 8-bit output signal that is the result of either adding or subtracting `a` and `b` based on the value of `sel`

The module should perform the following operation:
- If `sel` is 0, the output signal `result` should be the sum of `a` and `b`
- If `sel` is 1, the output signal `result` should be the difference between `a` and `b`

You can assume that the input signals `a` and `b` will always be valid 8-bit values.
