
Design a simple UART receiver controller. The controller receives a data bit stream and outputs the received byte once it has received 8 bits. It should also include a start bit and stop bit. The controller should have the following inputs: `rx` (the received serial data), `clk` (the clock signal), and `rst` (reset signal). The output should be `data_out` (the received byte) and `data_valid` (indicating the valid received data).
