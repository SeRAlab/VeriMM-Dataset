
Design a Verilog module that implements a 16-QAM modulator. The module should take 4 bits of input (representing 16 different symbols) and output the corresponding I (In-Phase) and Q (Quadrature) components. The mapping from input bits to I and Q components can be done as follows:
- For inputs 0000 to 1111, map to I and Q values as follows:
   - 0000 -> (1, 1)
   - 0001 -> (1, 0)
   - 0010 -> (1, -1)
   - 0011 -> (0, 1)
   - 0100 -> (0, 0)
   - 0101 -> (0, -1)
   - 0110 -> (-1, 1)
   - 0111 -> (-1, 0)
   - 1000 -> (-1, -1)
   - 1001 -> (0, -1)
   - 1010 -> (1, -1)
   - 1011 -> (0, 1)
   - 1100 -> (-1, 1)
   - 1101 -> (1, 0)
   - 1110 -> (1, 1)
   - 1111 -> (0, 0)
