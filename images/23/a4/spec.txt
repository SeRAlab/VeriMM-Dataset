Design a Verilog module that implements a simple HMAC (Hash-based Message Authentication Code) function. The HMAC should take a 64-bit key and a 64-bit message as inputs and produce a 64-bit MAC as output. The MAC will be generated by applying a simple XOR operation between the key and the message, followed by an AND operation with a constant value for simplification. Make sure to include a clock and reset signal for the sequential logic.
