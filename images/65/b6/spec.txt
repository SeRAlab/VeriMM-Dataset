Design a 4-to-1 multiplexer with a 4-bit wide output. The module takes four 4-bit input signals and, based on a 2-bit select input (sel), routes one of the input signals to the output (out). Additionally, an enable signal (en) controls the output; when en is low, the output is set to zero regardless of the selected input.
module top_module(
    input [3:0] in0,
    input [3:0] in1,
    input [3:0] in2,
    input [3:0] in3,
    input [1:0] sel,
    input en,
    output reg [3:0] out
);
