Design a 4-to-1 multiplexer; the module takes four 4-bit wide input signals (in_0 to in_3) and uses a 2-bit selection signal (sel) to choose one of the inputs to be output. Depending on the value of sel, the corresponding input signal is routed to the output (out), facilitating efficient data selection in digital circuits.
module top_module(
    input [3:0] in_0,
    input [3:0] in_1,
    input [3:0] in_2,
    input [3:0] in_3,
    input [1:0] sel,
    output reg [3:0] out
);
