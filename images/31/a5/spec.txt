
Design a simple Automatic Repeat reQuest (ARQ) system in Verilog. The system should include a sender and a receiver. The sender sends a data bit along with an acknowledgment (ACK) signal from the receiver. If the receiver detects an error in the received data, it will send a negative acknowledgment (NACK) signal back to the sender. The sender should then resend the last data bit until it receives an ACK signal. Assume that there is a simple error detection mechanism that flips a bit with a 10% probability.
