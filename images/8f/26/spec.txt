Design a basic d-type flip-flop with an enable signal. On each rising edge of the clock, if the enable (EN) is active, the flip-flop captures the input data (D) and drives the output (Q) with that value, while its complementary output (Q_N) is the inverted value of D. If EN is not active, the output remains unchanged. This module serves to temporarily store a single bit of data while allowing controlled updating based on the enable signal and clock transitions.
module top_module(
    input CLK,
    input D,
    input EN,
    output reg Q,
    output reg Q_N
);
