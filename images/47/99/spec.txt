The module takes an n-bit input and a control signal that specifies the number of bit positions to shift. When the control signal is positive, the input is left-shifted by that number of positions; when negative, it is right-shifted, effectively allowing for efficient data manipulation in digital systems. The parameters n and log2_n define the bit width of the input and the control signal size, respectively.

  input [n-1:0] in,
  input [log2_n-1:0] ctrl,
  output [n-1:0] out
);
