Design a simple packet filtering module for a firewall that checks incoming packets based on specific criteria. The criteria are as follows: the packet must have a source IP address not matching a specified blocked IP address and a certain flag (e.g., SYN, ACK). The input consists of a 32-bit source IP, a 32-bit destination IP, and a 1-bit flag indicating whether the packet is a SYN packet (1) or not (0). The output is a single bit indicating whether the packet is allowed (1) or blocked (0).
