

You are tasked with designing a Verilog module that takes in three inputs, A1, A2, and B1, and outputs X. The module should be named "three_input_module".

The module should have the following behavior:
- If A1 and A2 are both 1, X should be 1.
- If B1 is 0, X should be 0.
- If A1 is 0 and A2 is 1, X should be 1.
- If A1 is 1 and A2 is 0, X should be 0.
- If A1 and A2 are both 0, X should be 1.

The module should have the following ports:
- A1 (input): a 1-bit input signal
- A2 (input): a 1-bit input signal
- B1 (input): a 1-bit input signal
- X (output): a 1-bit output signal

Assume that the input signals are stable and valid.

Write a Verilog module that satisfies the above behavior and name it "three_input_module".
