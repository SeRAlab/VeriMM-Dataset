Design a D flip-flop with asynchronous set (S) and reset (R) inputs. On the rising edge of the clock (CLK), if S is high, the output Q is set to high (1). If R is high, the output Q is reset to low (0). If neither S nor R is active, the output Q takes the value of the D input, effectively storing it until the next clock edge.
module top_module(
    input D,
    input S,
    input R,
    input CLK,
    output Q
);
