Implement a 32-bit barrel shifter that allows for left or right bit shifting of the input data. The amount of shifting is specified by a 5-bit input, 'shift_amount', which ranges from 0 to 31. The 'shift_direction' input determines the type of shift: when set to 0, the circuit performs a left shift, effectively multiplying the data by 2 for each bit shifted; when set to 1, it performs a right shift, effectively dividing the data by 2 for each bit shifted. The resulting shifted output is provided as a 32-bit wide output.
module top_module(
    input [31:0] data,
    input [4:0] shift_amount,
    input shift_direction,
    output [31:0] shifted_output
);
