

Write a Verilog module for a 2-to-1 multiplexer that selects between two inputs (A and B) based on a select signal (S). The module should have three inputs and one output. The inputs are A, B, and S, and the output is Y. The output Y should be equal to A when S is 0, and equal to B when S is 1. 

Use the following module definition as a starting point:

```verilog
module mux2to1 (
    input A,
    input B,
    input S,
    output Y
);

// Your code here

endmodule
```
