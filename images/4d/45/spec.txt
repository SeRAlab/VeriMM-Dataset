This module implements a button anti-jitter circuit that stabilizes the input signals from buttons and switches. It utilizes a clock signal to manage a counter that helps filter out any noise or fluctuations in the button and switch signals. When any button or switch is activated, the counter increments until it reaches a threshold, at which point it samples the stable state of the inputs and outputs this state through `button_out` and `SW_OK`. The design effectively eliminates bounce by ensuring that only stable, valid inputs are registered after a defined delay, contributing to reliable input signal processing in digital applications.
