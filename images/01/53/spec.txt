Design a 4-bit SRAM cell with the following specifications: The SRAM cell should support write and read operations. The cell should be able to store a 4-bit value and be controlled by a write enable signal (we) and a chip enable signal (ce). When ce is low, the cell is disabled and should not respond to read or write operations. When we is high, the input data should be written into the SRAM cell. When we is low, the stored data should be available at the output when ce is high.
