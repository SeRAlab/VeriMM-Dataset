Design a 32-depth, 64-bit wide register file with functionality to read from two registers and write to a third. It outputs the contents of registers specified by the 5-bit inputs RA and RB to BusA and BusB, respectively, while ensuring a default output of zero when the register address is 31 (representing an unused or reserved register). On the negative edge of the clock, if the RegWr signal is high and the write register (RW) is not 31, it writes the 64-bit input BusW to the register addressed by RW. If RW is 31, it sets that register to zero. This module acts as a fundamental component for multi-cycle or pipelined CPU designs, supporting register operations in a digital system.
