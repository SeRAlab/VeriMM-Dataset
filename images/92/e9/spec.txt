When the selection signal is high, it outputs the position of the highest set bit (ranging from 0 to 7) as a 3-bit value. When the selection signal is low, it outputs the original 8-bit input. The functionality includes both bit position detection and output multiplexing based on the selection signal.
module top_module(
    input [7:0] in,
    input sel,
    output reg [2:0] pos,
    output reg [7:0] out_always );
