
Design a Verilog module that implements a simplified version of the MD5 hash function. The module should take a 128-bit input message and produce a 128-bit output hash. The module should consist of the following:
1. A block to initialize and store the hash state.
2. A block to process the input message in 512-bit chunks.
3. A block to perform the necessary bitwise operations and transformations according to the MD5 algorithm.
4. A block to output the final hash value after processing the input message.
