Design a D-type flip-flop with asynchronous set and reset capabilities. The flip-flop captures the input data (d) on the rising edge of the clock signal (clk). If the reset signal (rst) is asserted low, the output (q) is cleared to 0. If the set signal (set) is asserted low, the output is set to 1. The complement of the output is also provided (qn). This design allows for flexible state control independent of the clock.
