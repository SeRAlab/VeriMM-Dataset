

You are tasked with designing a module that takes in five inputs and produces one output. The inputs are A1, A2, A3, A4, and B1. The output is Y. The module should be named "five_to_one".

You are given the following specifications:
- If B1 is high, the output Y should be the logical AND of all the inputs (A1 AND A2 AND A3 AND A4).
- If B1 is low, the output Y should be the logical OR of all the inputs (A1 OR A2 OR A3 OR A4).

You are also given the following constraints:
- All inputs and output are single-bit signals.
- The design should be implemented using only basic logic gates (AND, OR, NOT).
- The design should minimize the number of gates used.

Implement the "five_to_one" module and provide its Verilog code.
