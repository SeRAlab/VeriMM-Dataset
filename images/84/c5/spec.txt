Implement a 2-port register file that allows simultaneous read and write operations for two different sets of registers. Each port can access one of eight 16-bit registers based on provided address inputs (as1, as2, bs1, bs2, cs1, cs2). The module supports two write controls (cw1 and cw2) and ensures that writes to the same register are handled correctly to avoid conflicts. On a reset signal, all registers are set to zero. The outputs supply data from the selected registers and indicate potential write operations based on address and control signals.
