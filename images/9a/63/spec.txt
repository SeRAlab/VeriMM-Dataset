Module name:
    up_down_counter

Input ports:
    clk: Clock signal used for synchronous operations.
    rst: Synchronous reset signal. Defined as 1 for reset.
    en: Enable signal. Defined as 1 for enabling the counter.
    dir: Direction signal. Defined as 1 for counting up and 0 for counting down.

Output ports:
    count: 4-bit count value.

Implementation:
The counter increments its value when the direction signal is high, and decrements its value when the direction signal is low, on each clock cycle when the enable signal is high. If the reset signal is high, the counter resets to zero.
