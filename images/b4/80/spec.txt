Design a memory interface module that supports simple read and write operations for a small memory array. The module has a 2-bit address input for selecting one of three memory locations. On the rising edge of the clock, data can be written to the first memory location if reset is not asserted; otherwise, the output readdata is updated to reflect the contents of the second or third memory locations based on the address input. When reset is active, the memory is initialized to zero. This module allows for basic memory access control in a digital system.
module top_module(
  input [1:0] address,
  input clk,
  input [8:0] in_port,
  input reset_n,
  output reg [31:0] readdata
);
