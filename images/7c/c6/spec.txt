Design a Verilog module for a 16-bit binary up/down counter with synchronous reset and up/down control. The counter should count up or down on each positive clock edge based on the up/down control signal. The reset signal should synchronously set the counter to 16'b0000000000000000.

module up_down_counter
(
    input clk,
    input reset,
    input up_down,
    output reg [15:0] count
);
