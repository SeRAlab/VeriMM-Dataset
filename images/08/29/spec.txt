
Design a simplified NVMe (Non-Volatile Memory Express) controller state machine that manages read and write operations. The controller has three states: IDLE, READ, and WRITE. The inputs to the controller are a clock signal (clk), a reset signal (reset), and a control signal (ctrl) which determines the operation mode (0 for READ, 1 for WRITE). The output is a 2-bit state that indicates the current state of the controller.
