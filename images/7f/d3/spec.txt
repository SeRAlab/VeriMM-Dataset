Design a 4-to-1 multiplexer that selects one of the four single-bit inputs (a, b, c, or d) based on the 2-bit selection input (sel). When sel is 00, the output is set to a; when sel is 01, the output is b; when sel is 10, the output is c; and when sel is 11, the output is d. The output is registered, ensuring that it responds to changes in the inputs and selection signal in a synchronous manner.
module top_module(
  input a,
  input b,
  input c,
  input d,
  input [1:0] sel,
  output reg out
);
