

You are tasked with designing a module that generates a 4-bit binary counter. The counter should count from 0 to 15 and then reset back to 0. The module should have the following inputs and outputs:

Inputs:
- clk: a clock signal
- rst: a reset signal

Outputs:
- q: a 4-bit binary output representing the current count

The module should use the given code snippet as a template and should not use any other modules.
