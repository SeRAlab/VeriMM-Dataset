

You are tasked with designing a verilog module that implements a binary latch with synchronous reset. The module should have the following inputs and outputs:

Inputs:
- `CLK`: a clock input
- `RST`: a synchronous reset input
- `D`: a data input

Outputs:
- `Q`: a data output

The module should latch the input `D` on the rising edge of `CLK`, and hold the value until the next rising edge of `CLK`. When `RST` is asserted, the output `Q` should be reset to 0.

Your module should be implemented within 200 lines of verilog code.

Write a verilog module that meets these specifications and provide the code below.
