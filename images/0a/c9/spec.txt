
Design a 4-channel DMA controller that can transfer data between memory and 4 peripheral devices. The controller should have the following inputs and outputs:
- Inputs:
  - `req` (4 bits): Request signals from 4 devices.
  - `ack`: Acknowledge signal from the controller.
  - `clk`: Clock signal.
  - `rst`: Reset signal.
- Outputs:
  - `sel` (2 bits): Channel selection for the active request.
  - `active`: Indicates which channel is currently active (1 bit).
The controller should prioritize requests in the order of Channel 0 to Channel 3.
