Implement a 4th-order IIR filter in Verilog. The filter will have a single input and a single output. The filter coefficients will be predefined. The input data will be processed in a clocked manner, and the output will be the filtered result. The filter will implement the following transfer function: H(z) = (b0 + b1*z^(-1) + b2*z^(-2) + b3*z^(-3) + b4*z^(-4)) / (1 + a1*z^(-1) + a2*z^(-2) + a3*z^(-3) + a4*z^(-4)) where the coefficients are defined in the module.
