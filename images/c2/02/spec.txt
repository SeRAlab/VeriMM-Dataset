

You are tasked with designing a verilog module that implements a 3-bit counter with asynchronous reset and enable signals. The module should have the following inputs and outputs:

Inputs:
- clk: the clock signal
- reset: the asynchronous reset signal (active low)
- enable: the enable signal (active high)

Outputs:
- count: the 3-bit counter output

The counter should increment on the rising edge of the clock signal when the enable signal is high. When the reset signal is low, the counter should be cleared to zero.

Write the verilog code for this module.
