Module name:  
    shift_register
                 
Input ports:
    clk: Clock signal used for synchronous operation.
    rst_n: Active-low reset signal. Defined as 0 for reset and 1 for reset signal inactive.
    serial_in: 1-bit input signal representing the serial data input.

Output ports:
    shift_reg: 8-bit output register representing the current shifted data.

Implementation:
State and Shift Register Operation:
The module includes a register, shift_reg, with a width of 8 bits, which represents the current shifted data.
The shift_reg register is updated in the always block, triggered on the positive edge of the clock signal (posedge clk) or the negative edge of the reset signal (negedge rst_n).
On reset, indicated by ~rst_n, the shift_reg register is cleared to 0.
On each clock cycle, the shift_reg register shifts its data to the left and the LSB is updated with the serial_in data.
