Design a fan speed control system that adjusts the speed of the fan based on temperature readings. The system should have the following specifications:  
1. Input: A 4-bit temperature input (TEMP) representing temperature in degrees Celsius (0-15).  
2. Output: A 3-bit fan speed output (FAN_SPEED) that determines the fan speed. The mapping from temperature to fan speed should be as follows:  
   - TEMP 0 to 3: FAN_SPEED = 000 (OFF)  
   - TEMP 4 to 7: FAN_SPEED = 001 (LOW)  
   - TEMP 8 to 11: FAN_SPEED = 010 (MEDIUM)  
   - TEMP 12 to 15: FAN_SPEED = 011 (HIGH)  
3. The fan speed should only change on the rising edge of a clock signal (CLK) and a reset signal (RST) can be used to set the fan speed to OFF.  
You need to implement this in Verilog.
