Design a 4-bit up/down counter that operates based on a clock input. The counter can count up or down controlled by the UP and DOWN signals; when UP is high, it increments the count, and when DOWN is high, it decrements the count. If both UP and DOWN are low, the counter maintains its current value. Additionally, if the LOAD signal is activated, the counter resets to zero regardless of other conditions.
module top_module(
    input CLK,
    input LOAD,
    input UP,
    input DOWN,
    output reg [3:0] Q
);
