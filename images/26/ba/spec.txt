Design a SR-flip-flop in Verilog that has two inputs: S (Set) and R (Reset), and one output Q. The flip-flop should have the following behavior:  
1. If S=1 and R=0, Q should be set to 1.  
2. If S=0 and R=1, Q should be reset to 0.  
3. If S=0 and R=0, Q should retain its previous state.  
4. If S=1 and R=1, the state is undefined (but for this implementation, we will keep Q unchanged).  
Implement this in Verilog code.
