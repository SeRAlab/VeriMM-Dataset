Design a FIFO (First-In-First-Out) memory buffer that allows for asynchronous data enqueueing and dequeueing. The module takes a clock signal and an active-low reset, alongside control inputs for enqueue (ENQ) and dequeue (DEQ) operations, as well as a clear (CLR) signal. It provides output data (D_OUT) and signals to indicate the buffer's status as empty (EMPTY_N) or full (FULL_N). The FIFO supports a data width of 153 bits and a depth defined by an 8-bit address width, enabling storage for up to 256 entries. Data can be written to the memory on the rising edge of the clock when not full, and read when not empty, with an underlying pointer management system to track read and write positions.
