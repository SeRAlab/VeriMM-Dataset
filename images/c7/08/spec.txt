

You are tasked with designing a module that will take in a binary input and output its one's complement. The module should be named "ones_comp" and should have the following ports:

- `input [7:0] in`: an 8-bit binary input
- `output [7:0] out`: an 8-bit one's complement output

The module should include the following voltage supply signals:

- `supply1 VDD`: a 1V voltage supply
- `supply0 VSS`: a 0V voltage supply

The module should be implemented using only logic gates and should not use any built-in operators or functions. You can use the following gates:

- AND (`&`)
- OR (`|`)
- NOT (`~`)
- XOR (`^`)
- NAND (`~&`)
- NOR (`~|`)
- XNOR (`~^`)

You may use as many of these gates as you need. Your design should be optimized for area and not for speed.
