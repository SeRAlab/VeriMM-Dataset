Develop a timer module that counts up with a configurable threshold and provides interrupt signals. The module features an 8-bit data bus for reading and writing to four registers that hold the current count and threshold values. It has a reset input to initialize the registers and counter to zero. On each clock cycle, when not in write mode, it updates the lower four registers with the least significant bits of the counter while also checking if a read operation is occurring. An interrupt output is generated when the count reaches or exceeds the threshold or resets to zero, signaling a condition based on the state of the registers.
