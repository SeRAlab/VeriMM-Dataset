Create a Verilog module for a simple switching regulator controller that takes an input voltage and outputs a regulated voltage. The regulator has a reference voltage of 2.5V, and the output voltage is adjusted based on the difference between the input voltage and the reference voltage. If the input voltage exceeds the reference voltage, the output should be reduced; otherwise, it should be increased. The module should have two inputs: input_voltage (an 8-bit value) and enable (a 1-bit control signal). The output should be output_voltage (an 8-bit value).
