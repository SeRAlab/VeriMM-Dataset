Design a set-reset flip-flop (DFF) with asynchronous set and reset capabilities. The module captures the value of input D on the rising edge of the clock (CLK) when both the asynchronous SET_B and RESET_B inputs are inactive. If SET_B is active, the flip-flop sets its output Q to HIGH regardless of D, while if RESET_B is active, it sets Q to LOW. The output Q_N provides the complementary output of Q. This design enables flexible control of the flip-flop state in digital circuits, allowing it to be set, reset, or loaded with data as needed.
