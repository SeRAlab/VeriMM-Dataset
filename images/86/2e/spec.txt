Design a timer module with an 8-bit register bank that operates on a clock signal and reset control. The module includes an addressable data bus, control signals for chip select (cs_), output enable (oe_), and write enable (we_). When the chip is selected and output is enabled, the data bus can read from or write to the register specified by the address input. The first four registers can be incremented automatically on each clock cycle if the write enable signal is not asserted. An interrupt signal is generated when the value in one set of registers exceeds the value in another set, allowing for comparisons and timing events to be detected.
