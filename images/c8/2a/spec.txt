

You have been tasked with designing a Verilog module for a simple calculator that can perform addition and subtraction operations. The calculator should take in two 8-bit inputs, A and B, and a 1-bit select signal, sel. If sel is 0, the module should output A + B, and if sel is 1, the module should output A - B. 

Your module should be named "calculator" and should be self-contained, meaning that it should not rely on any external modules. The module should be written in Verilog and should be no more than 200 lines long. 

You may assume that the inputs A and B are valid 8-bit binary numbers, and that the select signal sel will only ever be 0 or 1.
