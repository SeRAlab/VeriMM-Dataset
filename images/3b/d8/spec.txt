Design an 8-bit ADC (Analog to Digital Converter) that converts a 1V input signal to a digital output. The input voltage (Vin) is represented as an 8-bit binary number, where 0V corresponds to 0 and 1V corresponds to 255. The output should be a binary representation of the input voltage scaled according to the 8-bit representation. The ADC should also have an enable signal (enable) that allows it to function only when it is high. If the enable signal is low, the output should be held at the last valid value.
