
Design a simple gradient descent module that updates a variable `x` based on a learning rate and the gradient of a function at that point. The operation performed is:
1. Read the current value of `x`.
2. Calculate the new value of `x` as `x = x - learning_rate * gradient`.
3. Output the updated value of `x`.
The module should have inputs for the current value of `x`, the learning rate, and the gradient, and it should output the new value of `x`.
