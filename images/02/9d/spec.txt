Design a Verilog module that implements Prim's Minimum Spanning Tree (MST) algorithm for a connected, undirected graph represented as an adjacency matrix. The module should output the minimum spanning tree as a list of edges. The graph size will be fixed at 5 vertices for simplicity. The input adjacency matrix will be a 5x5 matrix where the value at position (i,j) represents the weight of the edge between vertex i and vertex j. If there is no edge, the weight should be represented by a special value (e.g., 0 or MAX_WEIGHT).
