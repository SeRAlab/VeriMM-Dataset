Design a simple data acquisition system (DAQ) that captures data from an analog-to-digital converter (ADC) and manages data storage in memory. The system operates with a finite state machine (FSM) that transitions through three main states: an idle state where it can respond to start, read, or write requests, a state for reading data from the ADC, and a state for writing that data to a specified memory address. The module supports reset functionality, allowing it to initialize states and memory addresses, and can read from or write to a 1KB memory. The ADC data is captured from a single input channel, with the possibility of handling memory operations based on external control signals.
module top_module(
    input clk,
    input rst,
    input start,
    input mem_read,
    input mem_write,
    input [7:0] adc_data,
    input [9:0] mem_addr,
    input [7:0] mem_data,
    output reg [7:0] mem_out // Changed from wire to reg
);
