The output will reflect the value of the chosen input according to the binary combination of the selection lines, where sel0 and sel1 determine which of the four inputs is routed to the output. Specifically, sel0 and sel1 will select in0 when both are 0, in1 when sel=01, in2 when sel=10, and in3 when sel=11.
module top_module(
    input in0,
    input in1,
    input in2,
    input in3,
    input sel0,
    input sel1,
    output reg out
);
