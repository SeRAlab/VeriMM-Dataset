Design a 24-bit shift register with a parallel load and a shift functionality. The register can be loaded with a 23-bit input (`pi`) when the `Lden` signal is active, with the most significant bit set to 1. On each rising edge of the clock, if the `shiftEnable` signal is asserted, the register shifts all bits to the right, filling the most significant bit with 0. The register will reset to 0 when the `rst` signal is asserted. If neither loading nor shifting occurs, the output remains unchanged.
module top_module(input [22:0] pi, input clk, rst, shiftEnable, Lden, output reg [23:0] sout);
