Design a 16-bit SRAM cell with read and write functionality. The SRAM should be able to store a 16-bit data word and be accessed through address lines. Implement signals for read (`read_enable`), write (`write_enable`), data input (`data_in`), and data output (`data_out`). The SRAM should only allow writing when `write_enable` is high and reading when `read_enable` is high. The address should be ignored during the operation for this simplified model.
