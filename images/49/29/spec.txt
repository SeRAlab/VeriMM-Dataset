Design a small instruction memory module that stores a set of predefined instructions and outputs the appropriate instruction code based on an input program counter (PC). The module can hold 16 instructions, each 8 bits wide, and has a reset functionality that initializes the instruction memory with specific values when the reset signal is activated. When provided with a valid PC value, it retrieves and outputs the instruction corresponding to that address.
module top_module(
	input [7:0] PC,
	input Reset,
	output [7:0] Instruction_Code
    );
