Implement a 3-bit ring counter. The ring counter cycles through a sequence of 3-bit values, where only one bit is set to 1 at any time. The counter resets to the initial state on reset.

Module name:
    ring_counter_3bit

Input ports:
    clk: Clock signal used for synchronous operation.
    rst_n: Active-low reset signal. Defined as 0 for reset and 1 for reset signal inactive.

Output ports:
    count: 3-bit output representing the current state of the ring counter.

Implementation:
The count register is triggered on the positive edge of the clock signal (posedge clk) or the negative edge of the reset signal (negedge rst_n).
On reset, indicated by !rst_n, the count register is set to the initial state where the first bit is 1 and the others are 0.
On each clock cycle, the count register shifts its value to the left by one bit, with the leftmost bit wrapping around to the rightmost bit.
