Design a 4-bit up/down counter that can be initialized to a specified value. The counter increments the output Q on the rising edge of the Clock when the Enable signal is asserted and Up_Down is high. If Up_Down is low, the counter decrements the output. The counter resets to the value provided by the Initial input when the Reset signal is high.
module top_module(
    input wire Clock,
    input wire Reset,
    input wire Up_Down,
    input wire Enable,
    input wire [3:0] Initial,
    output reg [3:0] Q
);
