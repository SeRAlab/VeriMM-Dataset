

You are tasked with designing a module that implements a D flip-flop with an asynchronous reset input. The module should have the following inputs and outputs:

Inputs:
- D: data input
- RESET: asynchronous reset input
- CLK: clock input

Outputs:
- Q: output of the flip-flop

The module should be named "dff_asynch_reset" and should be written in Verilog. The module should be self-contained and should not include any other modules.

Design the module such that when the RESET input is asserted, the output Q is set to 0 regardless of the value of the data input D. When RESET is deasserted, the module should behave as a normal D flip-flop, such that the output Q follows the input D on the rising edge of the clock CLK.

Write a testbench to verify the functionality of your module. The testbench should apply various input patterns to the module and check that the output Q behaves as expected.
