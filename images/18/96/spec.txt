Design a simplified NVMe controller state machine that handles command processing. The controller should support three states: IDLE, PROCESSING, and DONE. In the IDLE state, the controller waits for a command signal. Upon receiving a command, it transitions to the PROCESSING state, where it remains for a specified number of clock cycles (N). After processing, it transitions to the DONE state, which indicates that the command has been completed. The controller should reset to IDLE upon receiving a reset signal.
