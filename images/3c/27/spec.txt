
Design a 1-bit SRAM cell that allows for writing and reading data. The SRAM cell should have the following inputs: 
- `data_in` (1-bit input for data to be written)
- `write_enable` (1-bit input to enable writing)
- `read_enable` (1-bit input to enable reading)
The outputs should be:
- `data_out` (1-bit output for the data read from the SRAM cell)
The SRAM cell should retain its state until explicitly overwritten.
