
Implement a 4-point FFT processor in Verilog. The FFT processor should take four complex input values and produce four complex output values. Each input is represented as two separate bits for the real and imaginary parts (total of 8 bits per complex number). The FFT should be performed synchronously on a clock signal with a start signal to indicate when the computation should begin. The output should be valid when an output ready signal is asserted.
