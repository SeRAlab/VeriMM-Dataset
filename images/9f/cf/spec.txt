Develop a 4-bit signed comparator that evaluates whether the input A is greater than or equal to input B. The module stores the inputs in registers, and upon each clock cycle, it transitions through two stages: the first stage captures the input values, and the second stage compares the stored values to set the output GTE (Greater Than or Equal) accordingly. The output is asserted high when A is greater than or equal to B, and low otherwise.
module top_module(
    input clk,                       // Added clk input
    input signed [3:0] A,
    input signed [3:0] B,
    output reg GTE
);
