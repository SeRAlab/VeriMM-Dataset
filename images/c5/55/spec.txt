

You are hired by a company to design a verilog module for a 4:1 multiplexer. The module should have 4 inputs, one output, and a select input. The select input should determine which of the 4 inputs will be passed to the output. The select input should be a 2-bit input, and the output should be a single bit. The company requires that you use a case statement in your design.

Design a verilog module that meets the company's requirements.
