Design a simple Verilog module that takes a 16-bit input representing a TCP segment size and outputs a 3-bit value representing the TCP segmentation type based on the following criteria:
- If the segment size is less than or equal to 64 bytes, the segmentation type is 3'b000.
- If the segment size is between 65 and 128 bytes, the segmentation type is 3'b001.
- If the segment size is between 129 and 256 bytes, the segmentation type is 3'b010.
- If the segment size is greater than 256 bytes, the segmentation type is 3'b011.
