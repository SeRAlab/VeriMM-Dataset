Implement the Verilog module based on the following description.

1. The register captures the 4-bit input data (D) on the rising edge of the clock (clk).

Write Verilog implementing this 4-bit register.
module register_4bit (
        input clk,
        input reset,
        input [3:0] D,
        output reg [3:0] Q);
