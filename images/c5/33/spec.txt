

You are tasked with designing a module that takes 5 inputs and produces 1 output. The module should be named `multiplier` and should be implemented in Verilog. The inputs are:

- `a` (8-bit signed integer)
- `b` (8-bit signed integer)
- `sel` (1-bit unsigned integer)
- `reset` (1-bit unsigned integer)
- `clk` (1-bit unsigned integer)

The `reset` signal is active-high and should reset the output to 0 when it is asserted. The `clk` signal should be used to synchronize the module. The `sel` signal should be used to select between two modes of operation: 

- When `sel` is 0, the output should be the product of `a` and `b`.
- When `sel` is 1, the output should be the sum of `a` and `b`.

The module should be designed to minimize the number of logic gates used.
