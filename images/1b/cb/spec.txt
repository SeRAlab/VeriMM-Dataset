
Design a 16-bit SRAM cell with read and write capabilities. The SRAM should have the following inputs:
- `address`: 4-bit address to select one of the 16 memory locations.
- `data_in`: 16-bit input data for writing.
- `write_enable`: signal to enable writing to the selected memory location.
- `read_enable`: signal to enable reading from the selected memory location.

The outputs are:
- `data_out`: 16-bit output data upon reading from the selected memory location.

When `write_enable` is high, the `data_in` should be written to the memory location specified by `address`. When `read_enable` is high, the `data_out` should reflect the data stored at the memory location specified by `address`. Ensure that both read and write operations cannot occur simultaneously.
