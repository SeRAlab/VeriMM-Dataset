Please act as a professional verilog designer.

Create a Verilog module for a 6-bit synchronous Johnson counter with an active-low synchronous reset signal. The counter cycles through a sequence of 6-bit patterns.

Module name:  
    johnson_counter  

Input ports:
    clk: Chip clock signal.
    rst_n: Active-low synchronous reset signal. Defined as 0 for chip reset and 1 for reset signal inactive.

Output ports:
    q: Counter output signal with a data width of 6 bits.

Implementation:
Counter operation:
On every positive edge of the clock signal (clk), the counter register (q) is updated.
If the reset signal (rst_n) is low, the counter register (q) is set to 0.
The counter cycles through a sequence of 6-bit patterns in a Johnson counter manner.
