
Create a Verilog module that performs LU decomposition on a 2x2 matrix. The inputs will be a 2x2 matrix represented as four separate inputs, and the outputs will be the resulting L and U matrices, also represented as separate outputs. The matrix is defined as:
```
A = | a11 a12 |
    | a21 a22 |
```
The output L and U matrices will be:
```
L = | l11  0  |
    | l21 l22 |
    
U = | u11 u12 |
    |  0  u22 |
```
The decomposition should follow the rules:
1. l11 = a11
2. u11 = a11
3. l21 = a21 / u11
4. u12 = a12
5. u22 = a22 - l21 * u12
