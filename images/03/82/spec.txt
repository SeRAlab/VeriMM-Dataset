Design a temperature-based shutdown system, which turns off a device when the temperature exceeds a certain threshold. The system should include a temperature sensor input and a shutdown output signal. The sensor input is a 4-bit binary representation of temperature, and the shutdown signal is asserted (1) when the temperature exceeds 15 degrees Celsius (i.e., when the sensor input is greater than 15). The system should also include a reset signal that, when asserted, resets the shutdown output to 0 regardless of the temperature input.
