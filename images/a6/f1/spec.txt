Design a quadrature encoder that counts pulses based on two input signals, a and b. The module updates a 32-bit count value on the rising edge of the clock, incrementing or decrementing the count based on the direction of the input changes, which are determined by the previous states of a and b. It includes a reset capability that initializes the count to zero and sets the direction to a default state. The count updates only occur when there is a valid change detected in the a and b inputs, effectively allowing the system to track position or movement accurately.
module top_module(input clk, input reset, input a, input b, output reg [31:0] count);
