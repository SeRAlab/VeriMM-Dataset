Design a D flip-flop with asynchronous reset and enable functionality. When the reset signal is LOW, the output q is asynchronously set to 0. When the reset is HIGH, if the enable signal is LOW, the flip-flop captures and outputs the value of input d on the rising edge of the clock. If enable is HIGH, the output remains unchanged.
module top_module(
    input clk,
    input reset,
    input enable,
    input d,
    output reg q
);
