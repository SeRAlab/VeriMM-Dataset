
Design a 3x3 image convolution module in Verilog that takes an 8-bit pixel value and a 3x3 kernel, applies the convolution operation, and outputs a single 8-bit result. The kernel values can be both positive and negative. The input image data is assumed to be provided as a single 8-bit pixel value, while the kernel is provided in a 3x3 format, flattened into a single 9-bit value (for simplicity).
