Design a simple calculator module that performs basic arithmetic operations on two 8-bit inputs, A and B, based on a 2-bit operation code (OP). The operations include addition, subtraction, multiplication, and division, triggered on the rising edge of the clock signal. If the operation selected is division and the divisor B is zero, the result is set to zero to prevent division by zero errors. The resulting 8-bit output is stored in the 'result' register.
module top_module(
    input clk,
    input [7:0] A,
    input [7:0] B,
    input [1:0] OP,
    output reg [7:0] result
);
