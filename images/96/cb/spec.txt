Design a 2-to-1 multiplexer that selects between two 32-bit input signals, MFALUBEO and EXT_E, based on a 2-bit selection input (sel). When sel is 00, the output (datao) will be the value of MFALUBEO; when sel is 01, the output will be the value of EXT_E; for any other value of sel, the output will default to zero.
module top_module(
	input[1:0] sel,
	input[31:0] MFALUBEO,
	input[31:0] EXT_E,
	output[31:0] datao
    );
