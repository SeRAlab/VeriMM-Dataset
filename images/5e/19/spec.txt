Design a circuit that functions as a 2-to-1 multiplexer with dual selection inputs. The module has two data inputs, a and b, and two selection lines, sel_b1 and sel_b2. The output, out_always, will be assigned the value of input a when both selection lines are low (00) or when sel_b1 is high while sel_b2 is low (01). The output will take the value of input b when sel_b2 is high (10 or 11).
module top_module(
    input a,
    input b,
    input sel_b1,
    input sel_b2,
    output reg out_always
);
