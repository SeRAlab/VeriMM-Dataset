Implement a 4-to-16 line decoder. This module takes a 4-bit input address (ADDR) and activates one of the 16 output lines (DEC) based on the binary value of the input. Each output line corresponds to one of the 16 possible combinations of the input, where only the output associated with the selected address value is HIGH, while all other outputs remain LOW.
