Design a 32-bit wide edge-triggered D flip-flop with enable and clear functionalities. When the clock signal (CLK) transitions to a high state, if the clear input (CLR) is asserted high, the output (Q) is reset to zero. If the enable input (E) is asserted high, the current input data (D) is latched to the output (Q). If both the enable and clear signals are inactive, the output retains its previous value.
module top_module(output reg [31:0] Q,
   input wire E,
   input wire [31:0] D,
   input wire CLK,
   input wire CLR);
