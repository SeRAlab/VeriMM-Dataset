Design a D flip-flop with asynchronous reset and enable functionality. The output data_out is reset to LOW when the reset signal is asserted. When the reset is inactive and enable is HIGH, the flip-flop captures the data_in value on the rising edge of the clock, and this value appears at data_out.
module top_module(
  input clk,
  input reset,
  input enable,
  input data_in,
  output reg data_out
);
