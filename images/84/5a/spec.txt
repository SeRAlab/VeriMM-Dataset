Implement a simple dual-port RAM module that allows for simultaneous read and write operations. The module features two address inputs, RA for read and WA for write, and outputs the data stored at the address RA when rd_in is asserted. If reset (rst) is active, the output and internal memory remain unchanged until the reset is released. The memory supports a width of W bits and a depth defined by COLDEPTH, where data can be written to the specified address WA when wr_in is active. This design effectively facilitates data storage and retrieval for systems requiring fast, bit-width-controlled access to memory.
