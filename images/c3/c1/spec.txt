

You are designing a circuit that will take in a 4-bit input `data_in` and output a 3-bit value `data_out`. The circuit will use a lookup table to determine the output value based on the input value. The lookup table will be implemented using a 16x3 ROM.

Design a Verilog module `lookup_table` that takes in a 4-bit input `data_in` and outputs a 3-bit value `data_out`.

The lookup table should be initialized with the following values:
```
data_in | data_out
--------|---------
0000    | 011
0001    | 000
0010    | 101
0011    | 010
0100    | 111
0101    | 001
0110    | 100
0111    | 110
1000    | 010
1001    | 100
1010    | 001
1011    | 111
1100    | 110
1101    | 011
1110    | 000
1111    | 101
```
Use behavioral modeling to implement the `lookup_table` module.
