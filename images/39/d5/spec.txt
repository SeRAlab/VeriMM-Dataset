Design an EEPROM cell that can store a single bit of data. The EEPROM cell should have the following inputs: a data input (`d`), a write enable signal (`we`), and a clock signal (`clk`). When the write enable signal is high, the value of `d` should be stored in the cell on the rising edge of the clock. The output (`q`) should reflect the stored value, and it should remain unchanged when `we` is low.
