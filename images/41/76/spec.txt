Design a 4-to-1 multiplexer that selects one of four input data lines (data_in[0] to data_in[3]) based on a 2-bit selection signal (sel). The output (data_out) reflects the value of the selected input, where sel indicates which input to forward: when sel is 00, output data_in[0]; when sel is 01, output data_in[1]; when sel is 10, output data_in[2]; and when sel is 11, output data_in[3].
module top_module(
    input [3:0] data_in,
    input [1:0] sel,
    output reg data_out
);
