Design a program counter (PC) circuit that updates its value on the rising edge of the clock signal (clk). When a reset signal is asserted, the program counter resets to zero. Otherwise, it loads a new value, specified by the input nPC, into the counter. The output Addr reflects the current value of the program counter, which is a 11-bit wide address used to track the instruction sequence in a computational system.
module top_module(
	input clk, reset, 
	input [31:0] nPC,
	output [10:0] Addr
    );
