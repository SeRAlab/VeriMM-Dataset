

You are tasked with designing a verilog module for a 4-bit adder with carry-in and carry-out signals. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock signal
- `rst`: a reset signal
- `a`: a 4-bit input signal
- `b`: a 4-bit input signal
- `cin`: a carry-in signal

Outputs:
- `sum`: a 4-bit output signal representing the sum of `a` and `b`
- `cout`: a carry-out signal

The module should perform the addition of `a` and `b` with the carry-in signal `cin`, and output the resulting sum in `sum` and the carry-out signal in `cout`. The module should be synchronous, meaning that the addition should only occur on the rising edge of the clock signal. The module should also have an asynchronous reset signal `rst` that sets the output signals to 0 when asserted.
