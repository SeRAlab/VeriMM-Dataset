Implement the Verilog module based on the following description. Create a module that implements an 8-bit parallel-in serial-out shift register. The module should have an 8-bit input "data_in", a clock input "clk", a load signal "load", and a serial output "data_out". When "load" is high, "data_in" should be loaded into the register on the rising edge of "clk". Otherwise, the register should shift right by one bit.
module piso_shift_reg(
    input clk,
    input load,
    input [7:0] data_in,
    output data_out);
