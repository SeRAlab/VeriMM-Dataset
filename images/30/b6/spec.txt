Design a 16-QAM modulator using Verilog that takes in 4 bits of input data (representing the symbol) and produces a pair of output signals (I and Q) representing the in-phase and quadrature components of the modulation. The mapping of the input bits to the I/Q values should be as follows:
- 0000 -> (1, 1)
- 0001 -> (1, 3)
- 0010 -> (3, 1)
- 0011 -> (3, 3)
- 0100 -> (1, -1)
- 0101 -> (1, -3)
- 0110 -> (3, -1)
- 0111 -> (3, -3)
- 1000 -> (-1, 1)
- 1001 -> (-1, 3)
- 1010 -> (-3, 1)
- 1011 -> (-3, 3)
- 1100 -> (-1, -1)
- 1101 -> (-1, -3)
- 1110 -> (-3, -1)
- 1111 -> (-3, -3)
