Design a 4-bit ripple carry adder. This module takes two 4-bit binary numbers (inputs `a` and `b`) and a carry-in bit (`cin`), producing a 4-bit sum output (`sum`) along with a carry-out bit (`cout`). The addition is performed bit by bit, propagating any carry from one bit position to the next, effectively allowing for the addition of larger numbers by chaining multiple 4-bit adders.
module top_module(
  input [3:0] a,
  input [3:0] b,
  input cin,
  output [3:0] sum,
  output cout
);
