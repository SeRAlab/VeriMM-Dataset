Design a synchronized n-bit up-counter with reset functionality. The counter increments its value on each clock cycle when enabled, wrapping back to zero after reaching a specified maximum (n-1). It can be reset asynchronously, setting the output to zero when the reset signal is asserted. Additionally, it provides a carry-out signal (co) that indicates when the counter has reached its maximum value while enabled. This module is parameterized to allow for different counter widths and maximum counts based on the specified values of n and counter_bits.
