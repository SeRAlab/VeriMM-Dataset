

You are tasked with designing a Verilog module that implements a binary counter. The counter should have a 4-bit output and should be able to count from 0 to 15. The counter should have a synchronous reset input that resets the counter to 0 when asserted. The counter should also have a clock input that increments the counter on the rising edge of the clock signal.

Design a Verilog module called "binary_counter" that implements the above specifications. The module should have the following inputs and outputs:

- Inputs:
  - clk (1-bit): clock input
  - rst (1-bit): synchronous reset input
- Outputs:
  - count (4-bit): binary counter output

Assume that the clock signal is a 50 MHz clock and that the reset input is synchronous to the clock signal.
