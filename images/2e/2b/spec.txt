Design a round-robin arbiter that can handle 4 request signals (req0, req1, req2, req3) and grant a single output signal (grant) based on the current priority. The arbiter should cycle through the request signals on each clock cycle, granting the highest priority request that is active. The priority should be in the order of req0 > req1 > req2 > req3. When a request is granted, the arbiter should remember the last granted request and start checking from the next priority on the subsequent clock cycle.
