Design a synchronous 32-bit multiplier circuit that performs multiplication of two 32-bit inputs (din0 and din1) when the clock enable (ce) signal is active. Upon a positive clock edge, if the reset signal is asserted, the output (dout) and the internal result register are cleared to zero. When reset is deactivated, if ce is asserted, the module computes the product of the inputs and updates the output accordingly.
module top_module(
    input clk, reset, ce,
    input [31:0] din0, din1,
    output reg [31:0] dout
);
