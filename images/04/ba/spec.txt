Design a Verilog module that takes a 16-bit TCP segment length and a 16-bit Maximum Segment Size (MSS) as inputs, and outputs the number of segments required to send the data. The output should be a 4-bit value representing the number of segments. If the segment length is less than or equal to the MSS, the output should be 1. If the segment length exceeds the MSS, calculate how many full MSS segments are needed and whether an additional segment is required for any leftover data.
