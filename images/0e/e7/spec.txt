Design a Verilog module that implements a basic SLAM algorithm state machine. The state machine should have three states: IDLE, LOCALIZE, and MAP. The state transitions happen based on the input signals: 'start' to begin localization, 'map' to create a map, and 'reset' to return to IDLE. The output should indicate the current state as a 2-bit binary value, where IDLE = 00, LOCALIZE = 01, MAP = 10.
