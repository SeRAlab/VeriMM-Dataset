Implement a memory module that supports read and write operations. This design features a RAM array of 32 locations, each capable of storing 32-bit wide data. It allows writing data to a specified address when the writeEnabled signal is high and retrieves data from a specified address on the negative edge of the clock when the readEnabled signal is asserted. The addressing mechanism uses only the upper bits to select the appropriate memory location, effectively creating a word-aligned memory structure.
