Design a Watchdog Timer in Verilog. The timer should take an input signal 'reset' that, when asserted, resets the timer. The timer should also take an input signal 'tick' that increments the timer on each clock cycle if 'reset' is not asserted. If the timer reaches a predefined limit (let's say 8), it should output a 'timeout' signal. The timer should be clocked by a 'clk' signal.
