Design a circuit that calculates the absolute difference between two 12-bit inputs, x and y. The module operates synchronously with a clock signal and has a reset feature. When the reset signal is activated, the output (DIFF) is set to zero. On the rising edge of the clock, the module computes the absolute difference by subtracting the smaller input from the larger one and assigns the result to the output.
module top_module(
    CLOCK,
    RESET,
    x,
    y,
    DIFF
);
