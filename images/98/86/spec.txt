Design a loadable 8-bit down counter. The counter is clocked by 'countClock' and can be loaded with an 8-bit value from 'loadvalue' when the 'load' signal is asserted. If 'load' is not asserted, the counter decrements its current value by the amount specified by the 'count' input on each clock cycle. The output 'countout' holds the current state of the counter.
