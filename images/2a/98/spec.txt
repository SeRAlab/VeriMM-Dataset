Design a 16-bit Linear Feedback Shift Register (LFSR) using Verilog. The LFSR should be able to generate pseudo-random numbers based on a given seed value. The LFSR should shift its bits on each clock cycle, and a feedback mechanism should be implemented based on specific taps. The design should include an active high reset signal to initialize the LFSR to the seed value, and it should produce a new pseudo-random value on every clock edge.
