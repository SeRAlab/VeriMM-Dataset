

You are tasked with creating a Verilog module that takes in an 8-bit input signal and outputs an 8-bit signal that is the logical NOT of the input signal. Your module should be parameterized to allow for different input signal widths. 

Your module should be named `not_gate` and should have the following ports:
- `input [WIDTH-1:0] in`: the input signal
- `output [WIDTH-1:0] out`: the output signal

Your module should use generate statements to create the NOT gate for each bit of the input signal.

Write the Verilog code for the `not_gate` module.
