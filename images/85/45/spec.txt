Implement the Verilog module based on the following description.
Create a module that implements an 8-bit up-down counter. The counter increments when the 'up' input is high, and decrements when 'down' input is high. The reset input is active high synchronous, and should set the output to 8'b00000000.
module up_down_counter(
	input clk,
	input reset,
	input up,
	input down,
	output reg [7:0] count);
