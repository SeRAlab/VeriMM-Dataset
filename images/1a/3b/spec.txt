Implement a 16-bit DRAM cell with a read/write mechanism. The DRAM cell should have an input for data, a clock signal, a read/write control signal, and a row address. On a rising edge of the clock, if the write control signal is high, the data should be written to the specified address. If the read control signal is high, the data from the specified address should be output. The DRAM should have 256 addresses (16 bits each).
