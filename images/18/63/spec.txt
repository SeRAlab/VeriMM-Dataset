Design a 16-bit SRAM cell with read and write functionality. The SRAM cell should be able to store a 16-bit value and allow reading the stored value. The SRAM cell should have the following inputs: 
- `write_enable` (1 bit): when high, allows writing to the SRAM cell.
- `data_in` (16 bits): the data to be written when `write_enable` is high.
- `read_enable` (1 bit): when high, allows reading the stored data.
The output should be `data_out`, which is the stored 16-bit value when `read_enable` is high.
