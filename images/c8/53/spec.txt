
Write a Verilog module that takes in two 8-bit inputs and one 16-bit input and outputs a 24-bit signal. The output signal should be the concatenation of the first 8-bit input (i1) and the 16-bit input (i0).

Define a module named "concatenation_module" that takes the following inputs and outputs:
- input [7:0] i1
- input [15:0] i0
- output [23:0] o

The module should assign the output signal (o) to be the concatenation of the first input signal (i1) and the second input signal (i0) in that order.
