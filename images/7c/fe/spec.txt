    up_down_counter

    CLK: Clock input
    RST: Active high reset signal
    DIR: Direction signal (1 for up, 0 for down)

Output ports:

The up_down_counter module uses one always block to update the counter value based on the clock signal, reset signal, and direction signal.

If the direction signal is 0, the counter decrements.
