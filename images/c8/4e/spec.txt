

You are tasked with designing a Verilog module that implements a D flip-flop with asynchronous reset. The module should have the following inputs and outputs:

Inputs:
- `D`: Data input
- `RESET_B`: Asynchronous reset input (active low)
- `CLK`: Clock input

Outputs:
- `Q`: Output of the flip-flop

The module should operate as follows:
- When `RESET_B` is low, `Q` should be set to 0 regardless of the value of `D`.
- When `RESET_B` is high, `Q` should follow the value of `D` on the rising edge of `CLK`.

Your Verilog module should be named `d_ff_async_reset` and should be solvable within 200 lines of code.
