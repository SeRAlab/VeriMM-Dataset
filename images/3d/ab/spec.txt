
Design a Verilog module that simulates a 5-bit Flash memory cell. The module should have inputs for data (5 bits), write enable, and read enable. If the write enable is high, the data should be written to the memory cell. If the read enable is high, the output should show the stored data. If both write enable and read enable are low, the output should remain unchanged. Ensure that the behavior of the Flash memory cell meets these operational requirements.
