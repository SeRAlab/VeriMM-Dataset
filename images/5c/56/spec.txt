Design a circuit that conditionally zeroes the upper bits of a 32-bit output based on a 5-bit input and an enable signal. When the enable signal (en) is high, the output (q) concatenates the 5-bit input (d) with zeroed upper bits (positions 5 to 31) resulting in a 32-bit output where only the least significant 5 bits can contain data, and the rest are guaranteed to be 0. If the enable signal is low, the output will effectively be 0, as the product with en will make the entire output zero regardless of the input.
