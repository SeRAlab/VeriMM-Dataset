
You are tasked with designing a verilog module that implements a 2-to-1 multiplexer. The module should have the following inputs and outputs:

Inputs:
- `a` (1-bit)
- `b` (1-bit)
- `sel` (1-bit)

Outputs:
- `out` (1-bit)

If `sel` is 0, the output `out` should be equal to `a`. If `sel` is 1, the output `out` should be equal to `b`.

Design your module to be as efficient as possible in terms of area and delay.
