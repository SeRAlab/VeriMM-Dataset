

You are tasked with designing a module that implements a D flip-flop with a hold function. The module should have four inputs: `in`, `enable_l`, `clock`, and `reset`. The `in` input is the data input to the flip-flop, `enable_l` is the enable input, `clock` is the clock input, and `reset` is the asynchronous reset input. The output of the module should be `out`, which is the output of the flip-flop.

The module should implement the following functionality:
- When `enable_l` is high, the flip-flop should operate normally, with `out` following the value of `in` on the rising edge of `clock`.
- When `enable_l` is low, the flip-flop should hold its current value, regardless of the value of `in` or `clock`.
- When `reset` is high, the flip-flop should reset to 0, regardless of the value of `in`, `enable_l`, or `clock`.

You should implement this functionality using a single always block and any other necessary logic gates. Your design should be optimized for area and speed.
