Design a 4-bit binary adder with carry-in functionality. The module takes two 4-bit inputs, `a` and `b`, along with a carry-in input `cin`, and outputs a 4-bit sum and a carry-out signal `cout`. The sum is computed as the addition of the two input operands and the carry-in, while the carry-out is generated based on the logic that determines if an overflow occurs from the most significant bit.
module top_module(
    input [3:0] a,
    input [3:0] b,
    input cin,
    output [3:0] sum,
    output cout
);
