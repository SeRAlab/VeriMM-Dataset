Design a Verilog module that implements a 4-bit binary down-counter with enable. The counter should decrement on the rising edge of the clock if the "enable" signal is high. The counter should reset to fifteen (4'b1111) when the synchronous reset (sreset) is high. The counter value should be output to the "count" signal.

module top_module
(
    input clk,
    input sreset,
    input enable,
    output reg [3:0] count
);
