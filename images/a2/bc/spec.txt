Design a Verilog module that implements a 4-bit binary down-counter with both synchronous and asynchronous resets. The counter should decrement on the rising edge of the clock. The counter should reset to '1111' when the synchronous reset (sreset) is high or the asynchronous reset (areset) is high. The counter value should be output to the "count" signal.

module down_counter
(
    input clk,
    input sreset,
    input areset,
    output reg [3:0] count
);
