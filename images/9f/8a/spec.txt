Design a memory-mapped Input/Output (I/O) interface module that operates based on read and write control signals. The module includes a memory array capable of storing 4096 bytes, and it manages data transfer through a 32-bit input and output. When the write signal (io_wr) is active along with the chip select (io_cs), it stores the incoming data (D_in_IO) into a specified address in the memory. Conversely, when the read signal (io_rd) is active along with the chip select, it retrieves 32 bits of data from the specified address and outputs it (D_out_IO). Additionally, the module provides an interrupt signal (intr) which can be set based on the system's requirements, allowing for asynchronous communication with other components.
module top_module( clk, io_cs, io_rd, io_wr, addr, 
						  D_in_IO, D_out_IO, int_ack, intr );
