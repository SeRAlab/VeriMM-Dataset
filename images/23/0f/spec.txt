Design a Verilog module that implements a simple QAM modulator. The modulator takes in two input bits (I and Q) and generates a corresponding output value based on a predefined mapping. The output is a 4-bit value representing the amplitude of the modulated signal. The mapping is as follows: 00 -> 0000, 01 -> 0001, 10 -> 0010, 11 -> 0011. The module should also have a clock input to synchronize the output.
