Create a Verilog module that implements a simple synchronous RAM with a 16-bit address bus and 8-bit data bus. It should have write_enable and read_enable signals. Data is written on the rising edge of the clock when write_enable is high, and read data is available on the output when read_enable is high.
module simple_ram (
	input clk,
	input write_enable,
	input read_enable,
	input [15:0] address,
	input [7:0] data_in,
	output reg [7:0] data_out);
