Design a temperature-based shutdown system that monitors a temperature sensor input and activates a shutdown signal when the temperature exceeds a specified threshold. The system should have a reset input that can clear the shutdown signal. The temperature sensor will provide a 4-bit binary input representing temperature in degrees Celsius, with a threshold set at 12 degrees Celsius (binary 1100). If the temperature exceeds this threshold, the shutdown signal (1-bit output) should be activated, remaining active until the reset signal is triggered.
