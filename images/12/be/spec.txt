
Design an edge-triggered D-flip-flop (DFF) in Verilog. The DFF should have an input `D`, a clock input `clk`, and an output `Q`. The output `Q` should take the value of `D` on the rising edge of the `clk`. Also, include an asynchronous reset input `reset` that, when asserted, sets `Q` to 0 immediately, regardless of the clock.
