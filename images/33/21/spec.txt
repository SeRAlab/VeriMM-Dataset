
Design a 4-bit SRAM cell with a write and read capability. The SRAM cell should have the following inputs:
- `we`: write enable (1 = write, 0 = read)
- `addr`: 2-bit address to select the SRAM cell (00, 01, 10, 11)
- `data_in`: 4-bit data input for writing
- `data_out`: 4-bit data output for reading

The output `data_out` should hold the current value of the selected SRAM cell when in read mode.
