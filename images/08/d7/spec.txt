Design a 4-channel DMA controller that allows data transfer from one memory location to another. Each channel can be enabled or disabled, and when enabled, it transfers a specified amount of data from a source address to a destination address. The controller should have a clock input, a reset input, and enable signals for each of the four channels. It should also have inputs for the source and destination addresses, as well as the data to be transferred. A simple state machine can be used to manage the transfer process.
