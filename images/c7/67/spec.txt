

You are tasked with designing a module that takes in a 4-bit binary input and outputs its 2's complement representation. The module should have the following inputs and outputs:

Inputs:
- `in`: a 4-bit binary value to be converted

Outputs:
- `out`: a 4-bit 2's complement representation of the input value

Your module should use the following Verilog code snippet as a starting point:

```
module twos_complement(
  input [3:0] in,
  output reg [3:0] out
);

// Your code here

endmodule
```

Write the Verilog code that implements the twos_complement module as described above.
