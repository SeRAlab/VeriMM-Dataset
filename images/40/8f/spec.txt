Design a 1-bit DRAM cell that includes a data input (D), a data output (Q), a word line (WL) for writing to the cell, and a bit line (BL) for reading from the cell. The cell should be able to store a bit, output the stored value when the word line is activated, and allow for data overwriting when the word line is high. The cell should also have a reset functionality to clear the stored value.
