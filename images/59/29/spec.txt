Design a 4-to-1 multiplexer that selects one of four 8-bit input signals (in1, in2, in3, in4) based on two selection lines (sel0 and sel1). The output (out) will reflect the selected input, where sel0 and sel1 determine which of the four inputs is passed to the output: when both selects are 0, output in1; when sel0=1 and sel1=0, output in2; when sel0=0 and sel1=1, output in3; and when both selects are 1, output in4.
module top_module(
    input [7:0] in1,
    input [7:0] in2,
    input [7:0] in3,
    input [7:0] in4,
    input sel0,
    input sel1,
    output reg [7:0] out
);
