Design a Verilog module that implements a Dynamic Voltage and Frequency Scaling (DVFS) controller. The controller should take an input `load` (4-bit value) representing the current load on the system. Based on the value of `load`, the controller should output a `voltage` (3-bit value) and a `frequency` (3-bit value). The mapping is as follows:
- If load is 0-3: voltage = 3'b000, frequency = 3'b000
- If load is 4-7: voltage = 3'b001, frequency = 3'b001
- If load is 8-11: voltage = 3'b010, frequency = 3'b010
- If load is 12-15: voltage = 3'b011, frequency = 3'b011
The output voltage and frequency should be updated on the rising edge of the clock.
