Design a 16-bit digital-to-analog converter (DAC) that takes a 16-bit binary input and outputs a corresponding analog voltage level. The output voltage should be linearly scaled based on the input, where a full-scale input (all bits high) corresponds to the maximum voltage output (e.g., 5V), and a zero input corresponds to 0V. The output should be represented in 12 bits (for simplicity) as an integer value between 0 and 4095, where 4095 corresponds to 5V.
