Design a one-bit wide, 4-to-1 multiplexer. The module has a 2-bit select input (sel) that determines which of the four input data lines (din) is routed to the output (dout). When sel is 00, dout will reflect din[0]; for sel=01, dout will show din[1]; for sel=10, dout will output din[2]; and for sel=11, dout will represent din[3].
module top_module(
    input [1:0] sel,
    input [3:0] din,
    output reg dout
);
