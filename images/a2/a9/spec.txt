Design a synchronous edge detection circuit that outputs the value of `data` to `to_pad` based on specific clock signal conditions while supporting test mode. The module operates on the rising edge of the `clk` signal, resetting to high impedance (`z`) under reset or when in test mode. It captures and outputs `data` when a positive edge on `ctl_pad_clk_se` is detected or when a negative edge on `ctl_pad_clk_si` is observed. The retained state of the last clock signals is used to identify transitions, enabling controlled data output depending on the control signals and the current mode of operation.
module top_module(
    input clk,
    input rst_l,
    input testmode_l,
    input ctl_pad_clk_se,
    input ctl_pad_clk_si,
    input data,
    output reg to_pad
);
