Design a circuit that implements a two-bit T flip-flop. The first flip-flop toggles its state based on the input 't' each time the clock signal 'clk' transitions high. The second flip-flop toggles based on the output of the first flip-flop. The two flip-flops together form a binary counter that counts in binary from 0 to 3 (00 to 11). The current state of the flip-flops is reflected in the two-bit output 'out', which mirrors the state of the flip-flops directly.
module top_module(
    input t,
    input clk,
    output reg [1:0] out
);
