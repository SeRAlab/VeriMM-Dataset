
You are tasked with designing a module that takes in 5 inputs and produces a single output. The module should be named `my_module` and should be written in Verilog. The inputs are `a`, `b`, `c`, `d`, and `e`, and they are all single-bit inputs. The output is `f`, which is also a single-bit output.

The output `f` should be 1 if and only if the majority of the inputs are 1. In other words, if three or more of the inputs are 1, then `f` should be 1. If two or fewer of the inputs are 1, then `f` should be 0.

You should use the following template for your `my_module`:
```
module my_module (
    input a,
    input b,
    input c,
    input d,
    input e,
    output f
);

// your code here

endmodule
```
You can assume that the inputs will always be valid, i.e., they will always be either 0 or 1.
