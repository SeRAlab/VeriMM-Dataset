Design a synchronous data transfer module that stores and retrieves 8-bit data based on an input validity signal. The module takes a clock signal and a reset signal as inputs, along with an 8-bit input data and an input validity indicator. On each active clock edge, if the reset is not asserted, the module captures the input data when the input valid signal is high, and sets an output valid signal to indicate that the data has been successfully transferred. Additionally, when not capturing data, the output valid signal becomes low, ensuring clear communication of data validity. Outputs include the 8-bit stored data and a validity flag.
