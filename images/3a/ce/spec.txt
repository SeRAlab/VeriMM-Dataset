Design a 16-bit shift register with parallel load capability. The shift register should have a clock input, a reset input, a load input, and a 16-bit input data bus. When the load input is high, the shift register should load the input data. When the load input is low, on each clock cycle, the contents of the register should shift right by one bit. The most significant bit (MSB) should be filled with 0 during shifting. The shift register should also be reset to 0 when the reset input is high.
