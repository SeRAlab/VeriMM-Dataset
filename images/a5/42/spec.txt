Design a circuit that captures a 4-bit input `data_in` on the rising edge of a clock signal and stores it in a register `data_reg`. The module then continuously evaluates the stored value; if the value is less than or equal to 5, it outputs a HIGH signal (`data_out` = 1); otherwise, it outputs a LOW signal (`data_out` = 0). This module effectively serves as a comparator with a register that enables monitoring of the input against a predefined threshold.
module top_module(
    input clk,
    input [3:0] data_in,
    output reg data_out
);
