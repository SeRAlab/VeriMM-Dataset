Design a 4-to-1 multiplexer that selects one of four input signals (A0, A1, A2, A3) based on two selection inputs (S0 and S1). When S0 and S1 are both 0, A0 is output; when S0 is 0 and S1 is 1, A2 is output; when S0 is 1 and S1 is 0, A1 is output; and when both S0 and S1 are 1, A3 is output. The output, X, reflects the selected input based on the combination of the select signals.
module top_module(
    input A0,
    input A1,
    input A2,
    input A3,
    input S0,
    input S1,
    output reg X
);
