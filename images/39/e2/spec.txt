Design a UART controller that can transmit 8-bit data serially at a specified baud rate. The controller should include a shift register for serial transmission, a state machine to manage the transmission process, and control signals to indicate when data is ready to be sent and when transmission is complete. The shift register should be able to shift out the data starting from the least significant bit and should include start and stop bits in the transmission. It should also have a mechanism to handle transmission enable and disable signals.
