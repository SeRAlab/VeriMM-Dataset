Design a circuit that implements a shift register with a depth of 7 bits. The module takes a 7-bit input data signal and, on each clock cycle when the reset is inactive, shifts the data left by one position, discarding the most significant bit while introducing a zero at the least significant bit. The output continuously represents the value of the least significant bit of the shifted data. Upon activation of the reset signal, the register loads the input data.

input wire clk,
