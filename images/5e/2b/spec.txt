Implement a Verilog module for a 4-bit shift register with a parallel load. The module should have a 4-bit data input, a clock input, a load input, and a 4-bit data output. When load is high, the data input is loaded into the shift register; otherwise, the shift register shifts left by one bit on each clock cycle.
module top_module(
	input [3:0] data,
	input clk,
	input load,
	output reg [3:0] q);
