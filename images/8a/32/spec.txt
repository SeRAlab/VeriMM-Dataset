Design a 4-to-1 multiplexer with a reset functionality. When the reset signal is high, the output will be forced to zero. When reset is low, the output selects one of the four 4-bit input lines (in0, in1, in2, or in3) based on the 2-bit select signal (sel). The selected input is determined as follows: if sel is 00, output in0; if sel is 01, output in1; if sel is 10, output in2; if sel is 11, output in3.
module top_module(
    // Inputs
    input        reset,
    input  [1:0] sel,
    input  [3:0] in0,
    input  [3:0] in1,
    input  [3:0] in2,
    input  [3:0] in3,

    // Outputs
    output [3:0] out
);
