Design a 16-bit SRAM cell that allows for read and write operations. The SRAM cell should have an input for the data to be written, an address input, a read/write control signal, and a clock signal. When the read/write control signal is high, the data should be written to the specified address at the rising edge of the clock. When the read/write control signal is low, the data at the specified address should be outputted on the data output line.
