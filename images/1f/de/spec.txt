
Create a Verilog module that implements a simple packet filtering mechanism for a firewall. The module should filter packets based on a predefined rule: only allow packets with a specific destination port number (e.g., port 80 for HTTP). The input to the module should include the packet's destination port and a control signal to enable filtering. If the packet is allowed, the output should indicate that the packet is accepted; otherwise, it should indicate that the packet is dropped.
