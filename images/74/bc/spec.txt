Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state A (output 0).
2. state B (output 0).
3. state C (output 1).
4. state D (output 1).

State transitions:
1. From state A: If k = 1, then transition to state B. If k = 0, then transition to state D.
2. From state B: If k = 1, then transition to state C. If k = 0, then transition to state A.
3. From state C: If k = 1, then transition to state D. If k = 0, then transition to state A.
4. From state D: If k = 1, then transition to state B. If k = 0, then transition to state A.

Assume that a one-hot code is used with the state assignment m[3:0] = 0001(A), 0010(B), 0100(C), 1000(D)

Write a Verilog for the signal M1, which is the input of state flip-flop m[1], for the signal M2, which is the input of state flip-flop m[2]. Derive the Verilog by inspection assuming a one-hot encoding.

module top_module (
        input [3:0] m,
        input k,
        output reg M1,
        output reg M2);
