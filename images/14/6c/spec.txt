
Design a 2nd-order Infinite Impulse Response (IIR) filter using Verilog. The filter should have 2 input samples and provide 1 output sample. It should use the following difference equation:
y[n] = a1*y[n-1] + a2*y[n-2] + b0*x[n] + b1*x[n-1]
where:
- x[n] is the current input sample
- x[n-1] is the previous input sample
- y[n] is the current output sample
- y[n-1] and y[n-2] are previous output samples
- a1, a2, b0, b1 are filter coefficients (fixed-point representation).
The coefficients will be set at initialization.
