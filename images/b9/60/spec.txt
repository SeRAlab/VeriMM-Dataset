Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state E (output 0).
2. state F (output 1).
3. state G (output 1).
4. state H (output 0).

State transitions:
1. From state E: If d = 1, then transition to state F. If d = 0, then transition to state H.
2. From state F: If d = 1, then transition to state G. If d = 0, then transition to state E.
3. From state G: If d = 1, then transition to state H. If d = 0, then transition to state E.
4. From state H: If d = 1, then transition to state F. If d = 0, then transition to state E.

Assume that a one-hot code is used with the state assignment y[3:0] = 0001(E), 0010(F), 0100(G), 1000(H)

Write a Verilog for the signal Y1, which is the input of state flip-flop y[1], for the signal Y3, which is the input of state flip-flop y[3]. Derive the Verilog by inspection assuming a one-hot encoding.
