Design a Verilog module that takes a 2x2 matrix as input and outputs its inverse. The input matrix is represented as a 4-bit vector (A, B, C, D) corresponding to the matrix:
| A B |
| C D |
The inverse of the matrix is given by the formula:
| A B |^-1 = (1/(A*D - B*C)) * | D -B |
| C D |               | -C A |
If the determinant (A*D - B*C) is zero, the output should indicate that the inverse does not exist.
