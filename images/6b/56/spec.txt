Design a full-adder circuit that computes the sum of two single-bit inputs, A and B, and an additional carry-in input, CIN. The module outputs a single-bit SUM and a carry-out output, COUT, which indicates whether there is a carry from the addition. The SUM output is derived by performing an XOR operation on A, B, and CIN, while the COUT output is determined by evaluating the carry conditions through AND and OR operations on the input signals.
module top_module(
    input A,
    input B,
    input CIN,
    output SUM,
    output COUT
);
