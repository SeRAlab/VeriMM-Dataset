
Design a LIFO (Last In First Out) stack in Verilog. The stack should have the following features:
1. A parameterizable depth (size) for the stack.
2. Two operations: `push` to add an item and `pop` to remove an item.
3. An output to indicate the current top of the stack.
4. An output to indicate whether the stack is empty or full.

The inputs should include:
- `clk`: Clock signal
- `rst`: Reset signal (active high)
- `push`: A control signal to push data onto the stack
- `pop`: A control signal to pop data from the stack
- `data_in`: Data input to be pushed onto the stack

The outputs should include:
- `data_out`: The data popped from the stack
- `is_empty`: A flag indicating if the stack is empty
- `is_full`: A flag indicating if the stack is full
