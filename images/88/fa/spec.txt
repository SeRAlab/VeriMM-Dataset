Implement a forwarding unit for a pipelined processor architecture that prevents data hazards by selecting the correct source of operands based on the register addresses. The module takes register addresses from the execute stage (RA1_EX, RA2_EX) and compares them with those from the memory and write-back stages (RA1_MEM, RA1_WB). It generates two 2-bit output signals (FWD1 and FWD2) that indicate the appropriate forwarding path for the operands. The signals account for conditions such as whether the memory or write-back stage should write a value to the same register being utilized in the execute stage, and whether a special case for register zero (R0) applies.
