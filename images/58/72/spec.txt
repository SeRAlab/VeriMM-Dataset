Design a 4-to-1 multiplexer that selects one of four 1-bit inputs (A[0] to A[3]) based on a 2-bit selector input (S). When S is set to a specific value, the corresponding input from A is output on X. The module is powered by external power (VPWR) and ground (VGND) connections, along with additional power and ground pads (VPB and VNB) for improved performance and integration.
module top_module(
    input [3:0] A,
    input [1:0] S,
    output X,
    input VPWR,
    input VGND,
    input VPB,
    input VNB
);
