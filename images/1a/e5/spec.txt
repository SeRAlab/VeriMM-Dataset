
Design a 1-bit DRAM cell. The DRAM cell should have a single bit input (D), a read enable (RE), a write enable (WE), and a clock (CLK). The output (Q) should behave such that:
- When WE is high, the input D is written to the cell on the rising edge of CLK.
- When RE is high, the output Q should reflect the stored value in the cell on the next rising edge of CLK.
