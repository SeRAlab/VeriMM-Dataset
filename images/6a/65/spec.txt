Implement the Verilog module based on the following description.
Design a Verilog module that implements a 2-to-1 multiplexer. The multiplexer should select between two 8-bit input signals (a and b) based on the value of the select signal (sel). The selected data should be output to the "y" signal.

module multiplexer
(
    input [7:0] a,
    input [7:0] b,
    input sel,
    output reg [7:0] y
);
