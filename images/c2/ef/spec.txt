

You have been tasked with designing a new module for an arithmetic logic unit (ALU) in Verilog. The ALU will take in two 13-bit inputs and a 5-bit operation code (OP) and output a 13-bit result based on the operation specified by the OP. The module you are designing should be able to handle the following operations:

- Addition
- Subtraction
- Bitwise AND
- Bitwise OR
- Bitwise XOR
- Shift left
- Shift right

You should write a Verilog module to implement this ALU. Your module should have the following inputs and outputs:

- Inputs:
  - `a` (13-bit signed integer)
  - `b` (13-bit signed integer)
  - `op` (5-bit operation code)
- Outputs:
  - `result` (13-bit signed integer)

Your module should implement the following operations based on the value of `op`:

- `op` = 00000 (Addition): `result` should be the sum of `a` and `b`.
- `op` = 00001 (Subtraction): `result` should be the difference between `a` and `b`.
- `op` = 00010 (Bitwise AND): `result` should be the bitwise AND of `a` and `b`.
- `op` = 00011 (Bitwise OR): `result` should be the bitwise OR of `a` and `b`.
- `op` = 00100 (Bitwise XOR): `result` should be the bitwise XOR of `a` and `b`.
- `op` = 00101 (Shift left): `result` should be `a` shifted left by the number of bits specified by the 3 least significant bits of `b`.
- `op` = 00110 (Shift right): `result` should be `a` shifted right by the number of bits specified by the 3 least significant bits of `b`.

You should assume that all arithmetic operations should be signed, and that the shift operations should preserve the sign bit.
