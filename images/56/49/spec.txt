Create a Verilog module for an 8-bit shift register. The module should take an 8-bit input and shift it left or right based on the control signal.

Write the Verilog code for the shift register module with the following signals:
- data: 8-bit input
- dir: 1-bit input (direction control: 0 for left, 1 for right)
- clk: 1-bit input (clock)
- q: 8-bit output

module shift_register8bit(
    input [7:0] data,
    input dir,
    input clk,
    output reg [7:0] q
);
