
Design a digital phase shifter that can shift the input signal phase by 0, 90, 180, or 270 degrees based on a 2-bit control input. The phase shifter will take a clock input and a reset input. The output will be a 1-bit signal that represents the phase-shifted version of the input signal. The 2-bit control input will determine the amount of phase shift: 00 for 0 degrees, 01 for 90 degrees, 10 for 180 degrees, and 11 for 270 degrees.
