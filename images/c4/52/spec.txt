

You have been tasked with designing a verilog module for a 4:1 multiplexer (MUX). The module should have four input ports, one output port, and two select lines. The output port should be connected to one of the four input ports based on the values of the select lines. The truth table for the 4:1 MUX is as follows:

| Select Lines | Output |
|--------------|--------|
| 0 0          | Input 0|
| 0 1          | Input 1|
| 1 0          | Input 2|
| 1 1          | Input 3|

Please write the verilog code for the 4:1 MUX module.
