Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a current source and a current sink. 
A current source is a circuit element that provides a constant current to a load, while a current sink is a circuit element that absorbs a constant current from a source. 
Your module should have the following inputs and outputs:

Inputs: a single control signal (ctrl) to enable/disable the current source/sink
Outputs: a single current signal (I) that represents the current provided/absorbed by the current source/sink
The module should also have the following parameters:

I_src: the current provided by the current source (in Amperes)
I_sink: the current absorbed by the current sink (in Amperes)
Your module should implement the following functionality:

When the control signal is high, the current source should provide a constant current I_src to the load.
When the control signal is low, the current source should provide no current (i.e., the current should be zero).
When the control signal is high, the current sink should absorb a constant current I_sink from the source.
When the control signal is low, the current sink should absorb no current (i.e., the current should be zero).
To implement the current source and sink, you should use Verilog code to define the behavior of the module based on the value of the control signal. 
You should then use this behavior to compute the current signal as a function of the control signal and the parameters I_src and I_sink.
