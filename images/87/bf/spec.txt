Design a four-bit binary adder that computes the sum of two 4-bit inputs, A and B, and produces a 5-bit output, SUM, which includes the carry-out. The output reflects the result of the addition, where SUM[4] indicates an overflow if it occurs, while the lower bits (SUM[0] to SUM[3]) represent the actual sum of the bits in A and B. The design employs bitwise XOR and AND operations to handle the addition and the carry propagation between the bits.
module top_module(
  input [3:0] A,
  input [3:0] B,
  output [4:0] SUM
);
