Design a 32-bit wide register that stores a value on the rising edge of the clock. The register has a reset input that clears its output, setting it to zero when activated. If the reset is not active and the enable signal is high, the register will update its output with the value present at the data input signal.
module top_module(
	input wire clk,
	input wire reset,
	input wire enable,
	input wire [31:0]d,
	output reg [31:0]q
);
