
Design a JK latch using Verilog. The JK latch has two inputs J and K, a clock input CLK, and two outputs Q and Qn. The latch should be able to toggle its state based on the J and K inputs when the clock transitions from low to high. If J and K are both low, the latch should maintain its previous state. If J is high and K is low, the output Q should be set high. If J is low and K is high, the output Q should be set low. If both J and K are high, the output Q should toggle.
