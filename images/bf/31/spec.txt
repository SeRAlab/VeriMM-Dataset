The module outputs an additional parity bit that indicates the parity of the selected data, resulting in a total 5-bit output. The parity bit is calculated by performing an XOR operation on the bits of the selected data, allowing the user to verify the integrity of the data being transmitted.

    input [3:0] data1,
    input [3:0] data2,
    input [3:0] data3,
    input [3:0] data4,
    input [3:0] data5,
    output reg [4:0] out
);
