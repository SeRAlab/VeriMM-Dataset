
Design a Stop-and-Wait ARQ (Automatic Repeat reQuest) protocol in Verilog. The sender sends a frame and waits for an acknowledgment (ACK) from the receiver. If the sender does not receive an ACK within a certain time (timeout), it retransmits the frame. The receiver acknowledges the received frame. You should implement a finite state machine (FSM) to handle the sending and receiving of data.
