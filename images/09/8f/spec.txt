Design a 1-bit DRAM cell in Verilog. The DRAM cell should include a data input (`d`), a word line (`wl`), and a bit line (`bl`). When `wl` is high, the data input should be stored in the cell; when `wl` is low, the data stored in the cell should be output on the bit line (`bl`). The cell should also have a reset feature that clears the stored data when a reset signal (`reset`) is high.
