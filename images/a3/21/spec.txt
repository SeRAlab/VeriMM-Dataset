Design a 4-bit shift register with load capability. The module loads a 4-bit input DATA into the shift register when the LOAD signal is asserted. On each positive edge of the CLK signal, if LOAD is not asserted, the register shifts its contents left by one bit and fills the least significant bit (LSB) with a zero. The current value of the register is continuously assigned to the output Q.
module top_module(
    input CLK,
    input LOAD,
    input [3:0] DATA,
    output reg [3:0] Q
);
