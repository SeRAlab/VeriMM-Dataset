Design a Verilog module that implements a basic SD card command response handler. The module should accept a command signal (`cmd`) and a clock signal (`clk`). When a command is received, the module generates a response signal (`resp`) based on the command type. The response should be generated in two clock cycles: the first cycle should assert a 'busy' indication, and the second cycle should provide the actual response. The commands can be simple integers (0 to 3) representing different operations. Make sure to handle commands 0 to 3 with respective responses, e.g., command 0 returns response 0x01, command 1 returns response 0x02, etc.
