Design a 64-bit wide, 8-to-1 multiplexer that selects one of the eight 8-bit segments from the 64-bit input word based on a 3-bit selection signal. The selected 8-bit output will correspond to the segment identified by the value of the selection signal, where a sel value of 0 outputs the least significant byte and a sel value of 7 outputs the most significant byte. If the selection signal is outside the expected range, the output will be an undefined state (x).
