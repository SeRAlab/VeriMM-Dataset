Design a synchronous flip-flop with asynchronous set and clear functionalities. On the rising edge of the clock, if the set signal is asserted, the output q is set to high. If the clear signal is asserted, q is set to low. If neither the set nor the clear is active, the output follows the input data signal d, effectively storing its value.
module top_module(
    input clk,
    input d,
    input set,
    input clr,
    output reg q
);
