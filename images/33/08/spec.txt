Design a 1-bit SRAM cell in Verilog. The SRAM cell should have the following inputs: a data input (D), a word line (WE - write enable), and a bit line (BL). The output should be the stored data (Q). The SRAM cell should be able to store the input data when the word line is high (1), and should maintain the stored value when the word line is low (0). The circuit should be able to output the stored value regardless of the state of the input when read.
