Design a structural 4-to-1 multiplexer that selects one of four input data lines (data_in[0] to data_in[3]) based on a 2-bit select signal. The module utilizes four AND gates to determine which input is active based on the select value, and two OR gates to combine the outputs of the AND gates for each set of inputs, ultimately providing a single output (data_out) that represents the selected data input.
module top_module(
  input [3:0] data_in,
  input [1:0] select,
  output reg data_out
);
