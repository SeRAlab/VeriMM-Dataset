
Design a fan speed control system that takes an input temperature (in degrees Celsius) and adjusts the fan speed accordingly. The fan has three speed levels: low, medium, and high. The fan speed is determined based on the temperature input as follows:
- If the temperature is less than or equal to 20°C, set the fan speed to low (00).
- If the temperature is between 21°C and 25°C, set the fan speed to medium (01).
- If the temperature is greater than 25°C, set the fan speed to high (10).
The system should have a clock signal to synchronize the fan speed updates.
