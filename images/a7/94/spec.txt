Design a circuit that functions as a multiply-accumulate (MAC) unit. On each rising edge of the clock, it multiplies two 32-bit inputs, `a` and `b`, and adds the result to a running total stored in an internal register, `accum`. If the reset signal is asserted, the accumulated value is cleared to zero. The output of the module is the current value of the accumulator.
module top_module(
  input clk,
  input reset,
  input [31:0] a,
  input [31:0] b,
  output [31:0] out
);
