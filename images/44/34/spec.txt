Design a 10-bit programmable counter that increments its value by 50 on every positive edge of the clock signal (CLK) while allowing for active reset functionality. When the reset input is asserted, the counter resets to zero. The counter will also wrap around to zero when it reaches a maximum value of 1000, ensuring that the output remains within a designated range. The current counter value is outputted as a 10-bit vector (cuenta).
module top_module(
		input CLK,								
		input reset,
		output [9:0] cuenta					
    );
