

You are tasked with designing a module that takes in a 32-bit input and performs a specific operation on it. The module should be named `my_module` and have the following ports:

- `input wire [31:0] in`
- `output wire [31:0] out`

The module should perform the following operation:

- If the input is greater than or equal to 100, the output should be set to 100.
- If the input is less than or equal to -100, the output should be set to -100.
- If the input is between -100 and 100 (inclusive), the output should be set to the input value.

You can assume that the input will always be a signed 32-bit integer.
