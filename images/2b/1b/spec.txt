
Design a 32-bit deserializer that takes in a serialized 32-bit input (which is provided as 4 8-bit data inputs) and outputs the corresponding 32-bit parallel output. The deserializer should work with a clock signal and should have a valid input signal that indicates when new data is available. The deserializer should shift in the incoming data on every clock cycle and output the complete 32-bit data after 4 clock cycles.
