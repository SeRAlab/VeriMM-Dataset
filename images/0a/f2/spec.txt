Design a 16-bit SRAM cell with read and write operations. The SRAM should have a data input (D), a data output (Q), a write enable (WE) signal, and an address input (A) that selects which cell to read from or write to. The SRAM should support one read or write operation at a time, with the operation determined by the WE signal. If WE is high, the data on D should be written to the specified address. If WE is low, the data from the specified address should be output on Q.
