Design a sign extension circuit that takes a 26-bit immediate value (Imm26) and produces a 64-bit output (BusImm) based on a control signal (Ctrl). The circuit interprets the control signal to determine how to extend the immediate value: for '00', it extends selecting bits 10 to 21 with zero padding; for '01', it extends using the sign bit of bit 20; for '10', it extends the full 26 bits using the sign bit from bit 25; and for any other value, it extends using the sign bit from bit 23. This sign extender is useful in instruction decoding for various RISC architectures, allowing the appropriate size and sign of immediate values used in arithmetic and logical operations.
