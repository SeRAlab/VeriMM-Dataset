Design a synchronous n-bit binary counter that increments its count on each rising edge of the clock signal. The counter resets to zero when the reset signal is asserted or when it reaches its maximum value (2^n - 1). This counter operates with an n-bit wide output, allowing for flexibility in the bit width defined by the parameter n, defaulting to 4 bits.
module top_module(
  input clk, // clock signal
  input rst, // reset signal
  output reg [n-1:0] count // n-bit binary count
);
