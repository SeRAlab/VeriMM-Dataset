

You are tasked with designing a Verilog module that implements a 4-bit adder with carry. The module should have the following inputs and outputs:

Inputs:
- `A`: a 4-bit binary number
- `B`: a 4-bit binary number
- `Cin`: a binary carry-in value (0 or 1)

Outputs:
- `Sum`: a 4-bit binary number representing the sum of `A` and `B`
- `Cout`: a binary carry-out value (0 or 1)

The module should be named `four_bit_adder` and should be implemented in a single Verilog file with no more than 200 lines of code.

Assume that the input values `A` and `B` are valid 4-bit binary numbers (i.e., they will never exceed the range of 0-15), and that the input value `Cin` is a valid binary number (either 0 or 1).
