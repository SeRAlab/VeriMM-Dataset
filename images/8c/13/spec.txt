Implement the Verilog module based on the following description.
Create a 3-bit synchronous up/down counter. The counter counts up when the up_down signal is high and counts down when it is low. The counter resets to zero when the reset signal is high.

// Signals are defined as below:
// (1) clk: The clock signal.
// (2) reset: Resets the counter to zero. Active high.
// (3) up_down: Determines the counting direction. 1 for up, 0 for down.
// (4) q: The 3-bit output of the counter.
module up_down_counter(
    input clk,
    input reset,
    input up_down,
    output reg [2:0] q);
