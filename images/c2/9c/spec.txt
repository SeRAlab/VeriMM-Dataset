

You are tasked with designing a module that takes in a 32-bit data input `MDR_data`, a memory write enable signal `Mem_write_enable`, and outputs two 32-bit data signals `BusData_out` and `Mdata_out`. The module should be named `MDMux_out`.

The `MDMux_out` module should have the following behavior:
- When `Mem_write_enable` is high, `Mdata_out` should be equal to `MDR_data` and `BusData_out` should be equal to 0.
- When `Mem_write_enable` is low, `BusData_out` should be equal to `MDR_data` and `Mdata_out` should be equal to 0.

You should implement this module in Verilog.
