On the rising edge of the clock, when the enable (CE) signal is asserted, it sets the output Q to low if reset (R) is active, to high if set (S) is active, or captures the value of input D2 otherwise. On the falling edge of the clock, if the enable (CE) is still active, it captures the value of input D1 and updates the output Q accordingly. This module is suitable for scenarios requiring synchronized data capture on both clock edges.
