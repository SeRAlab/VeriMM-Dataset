
Create a Verilog module that implements a simple Network Address Translation (NAT) function. The module should receive an input IP address and a port number, and output a translated IP address and port number based on a predefined mapping table:
1. Input: 32-bit IP address (ip_in) and 16-bit port number (port_in).
2. Output: 32-bit translated IP address (ip_out) and 16-bit translated port number (port_out).
The mapping for NAT is as follows:
- If ip_in = 192.168.1.10 and port_in = 8080, then ip_out = 10.0.0.1 and port_out = 10000.
- If ip_in = 192.168.1.20 and port_in = 8081, then ip_out = 10.0.0.2 and port_out = 10001.
- If ip_in = 192.168.1.30 and port_in = 8082, then ip_out = 10.0.0.3 and port_out = 10002.
- For any other input, ip_out = ip_in and port_out = port_in.
The module should also have a clock and reset signal to control the translation process.
