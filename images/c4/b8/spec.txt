The "four_bit_adder" module should connect the inputs and outputs of the four "full_adder" modules in a way that correctly implements the 4-bit adder with carry-in and carry-out functionality. The module should use only combinational logic, and should not use any behavioral constructs such as "always" or "assign". 

Write the verilog code for the "four_bit_adder" module, as well as the "full_adder" module.
