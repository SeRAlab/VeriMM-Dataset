Design a module that performs simultaneous addition and multiplication operations on three 8-bit input values (a, b, and c) upon the rising edge of a clock signal. The module computes the sum of a, b, and c, storing it in a 16-bit register, and calculates the product of a and b, also storing it in a separate 16-bit register. The outputs are provided as the `sum` and `product`, capturing the results of these arithmetic operations.
module top_module(
  input clk,
  input [7:0] a,
  input [7:0] b,
  input [7:0] c,
  output reg [15:0] sum,
  output reg [15:0] product
);
