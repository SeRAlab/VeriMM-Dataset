
Design a 16-bit Arithmetic Logic Unit (ALU) that can perform the following operations based on a 4-bit control signal:
- 0000: ADD
- 0001: SUBTRACT
- 0010: AND
- 0011: OR
- 0100: XOR
- 0101: NOT (inverts A, B is ignored)
- 0110: SHIFT LEFT
- 0111: SHIFT RIGHT
- 1000: LESS THAN (outputs 1 if A < B, else 0)
- 1001: GREATER THAN (outputs 1 if A > B, else 0)
- 1010: EQUAL (outputs 1 if A == B, else 0)

The ALU should take two 16-bit inputs (A and B) and output a 16-bit result (R).
