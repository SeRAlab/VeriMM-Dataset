Design a packet filtering module that accepts a 16-bit source IP address and a 16-bit destination IP address. The module should output a single-bit signal indicating whether the packet is allowed (1) or blocked (0). A packet is allowed if the source IP is in the range 192.168.1.0 to 192.168.1.255 and the destination IP is in the range 10.0.0.0 to 10.0.0.255.
