Design a 2nd-order Infinite Impulse Response (IIR) filter using Verilog. The filter will take a single input sample and produce a single output sample, utilizing two feedback coefficients, two feedforward coefficients, and a delay mechanism to store past input and output samples. The filter should have a clock input, a reset input, and an enable input. When enabled, the filter will update its output based on the current input and the stored past samples. The coefficients will be fixed-point numbers.
