Design a flip-flop with asynchronous reset and set functionality. On the rising edge of the clock, if the reset signal is high, the output q is set to LOW. If the set signal is high, the output q is set to HIGH. Otherwise, the output q takes the value of the input d, effectively allowing it to store a single bit of data while providing control over its initial state through the reset and set inputs.
module top_module(
    input clk,
    input reset,
    input set,
    input d,
    output reg q
);
