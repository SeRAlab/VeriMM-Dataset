
You are tasked with designing a Verilog module that takes in two 8-bit unsigned numbers and outputs their sum. The module should have the following ports:

Inputs:
- `a`: an 8-bit unsigned number
- `b`: an 8-bit unsigned number

Outputs:
- `sum`: an 8-bit unsigned number representing the sum of `a` and `b`

The module should be named `adder_module` and should use the `assign` statement to calculate the sum of `a` and `b`. The sum should be stored in the output port `sum`.
