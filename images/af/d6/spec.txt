Design a versatile flip-flop module that implements four types of flip-flops: D, JK, T, and SR. The module utilizes control signals such as CLK (clock), CLR (clear), and PR (preset) to manage the state transitions. The D flip-flop stores the input D signal on the rising edge of the clock. The JK flip-flop toggles its output based on the inputs J and K, allowing for versatile counting behavior. The T flip-flop toggles its output when the T input is high, serving as a toggle flip-flop suitable for binary counting. Lastly, the SR flip-flop sets or resets the output based on the S and R inputs. The output Q and its complement Q_not are provided for use in digital circuits. This module is suitable for creating state storage elements in digital systems, enabling a variety of sequential logic designs.
module top_module(
  input D, CLK, CLR, PR,
  output Q, Q_not
);
