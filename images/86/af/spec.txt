Design a 4-bit Linear Feedback Shift Register (LFSR) counter. This module generates a pseudo-random sequence based on an XOR feedback mechanism using a 64-bit shift register. Upon receiving a clock signal, the LFSR shifts its contents, and the new bit is determined by XORing all bits of the register. The upper 4 bits of the shift register are then output as the counter value \(Q\). The counter resets to zero when the active-low reset signal \(rst_n\) is asserted.

  input                clk,
  input                rst_n,
  output reg  [3:0]    Q
);
