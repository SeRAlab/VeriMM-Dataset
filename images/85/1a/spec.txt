Design a 4-bit binary up-counter with load functionality. The counter increments its output by one on each rising clock edge when the enable signal (en) is asserted. If the reset signal (rst) is activated, the output resets to zero. Additionally, if the load signal is asserted, the counter takes a new value from the input load_value instead of incrementing.
module top_module(
    input clk,
    input rst,
    input en,
    input load,
    input [3:0] load_value,
    output reg [3:0] out
);
