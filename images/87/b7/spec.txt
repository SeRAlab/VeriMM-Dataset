Implement a Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state A (W = 1).
2. state B (W = 0).
3. state C (W = 1).
4. state D (W = 0).

State transitions:
1. From state A: If y = 0, then transition to state B. If y = 1, then transition to state C.
2. From state B: If y = 0, then transition to state D. If y = 1, then transition to state A.
3. From state C: If y = 0, then transition to state D. If y = 1, then transition to state B.
4. From state D: If y = 0, then transition to state C. If y = 1, then transition to state A.

Assume that you want to Implement the FSM using two flip-flops and state codes s[1:0] = 00, 01, 10, 11 for states A, B, C, D, respectively. Implement just the next-state logic for s[1] in Verilog. The output W is s[1].
