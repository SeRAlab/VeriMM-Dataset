Design a 16-depth, 4-bit wide synchronous RAM module that allows for read and write operations controlled by a clock signal. It features a write address and write data input that, when the write enable signal is active, stores data into the specified memory location. At every rising edge of the clock, it also outputs the data from a specified read address, enabling simultaneous read and write capabilities.
