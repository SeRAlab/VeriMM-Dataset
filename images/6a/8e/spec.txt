Design a 5-bit wide, 4-to-1 multiplexer. The module takes four 5-bit inputs and utilizes a 2-bit selection signal to output one of these inputs based on the value of the selection. When `select` is 00, `input0` is output; when 01, `input1`; when 10, `input2`; and when 11, `input3`.
module top_module(
	input [4:0] input0,
	input [4:0] input1,
	input [4:0] input2,
	input [4:0] input3,
	input [1:0] select,
	output reg [4:0] mux_out
    );
