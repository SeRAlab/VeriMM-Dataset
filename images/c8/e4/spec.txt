
You are tasked with designing a module that will take in a 4-bit input signal, `data_in`, and output a 4-bit signal, `data_out`. The `data_out` signal should be the result of performing a bitwise XOR operation on the `data_in` signal and a 4-bit constant value, `0xF`. 

Create a Verilog module that implements this functionality. The module should be named `xor_module` and should have the following input and output ports:

- `input [3:0] data_in`: the 4-bit input signal
- `output [3:0] data_out`: the 4-bit output signal

Ensure that the module can be synthesized and simulated correctly.
