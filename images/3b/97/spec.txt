Design a 4-to-2 encoder in Verilog. The encoder should have 4 input lines (I3, I2, I1, I0) and 2 output lines (O1, O0). If multiple inputs are active, the highest-priority input should be encoded. The priority order is I3 > I2 > I1 > I0. The outputs should be valid only if at least one input is active. If no inputs are active, the outputs should be 2'bxx.
