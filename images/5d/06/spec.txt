Design a D-type flip-flop with asynchronous reset and set capabilities. On the rising edge of the clock, if the reset signal is asserted, the output q is cleared to LOW and qn is set to HIGH. If the set signal is asserted, the output q is set to HIGH and qn is cleared to LOW. If neither reset nor set is active, the output q takes the value of the input d, while qn provides the complementary output.
module top_module(
    input wire clk,
    input wire rst,
    input wire set,
    input wire d,
    output reg q,
    output reg qn
);
