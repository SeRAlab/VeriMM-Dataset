Design a one-bit wide, 2-to-1 multiplexer with a configurable bit-width (default 32 bits). The module selects between two input signals, a and b, based on the value of the select line sel. If sel is low, the output y will be assigned the value of input a; if sel is high, y will take the value of input b.
