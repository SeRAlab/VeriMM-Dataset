Design a simple low dropout regulator (LDO) controller that regulates the output voltage based on an input voltage and a control signal. The LDO should have a reference voltage of 1.2V, and the output voltage should follow this reference voltage as long as the input voltage is above 1.2V. If the input voltage drops below 1.2V, the output should be disabled (set to 0V). The control signal will enable or disable the output based on the input voltage status.
