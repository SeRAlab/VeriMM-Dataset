Design a 13-bit wide program counter circuit that supports loading a new address and automatic incrementing. On a positive edge of the clock, if the reset signal (rst) is high, the counter resets to zero. If the load signal is asserted, the counter loads the address from the input (ir_addr). Otherwise, the counter increments its current value by one, allowing for sequential addressing in a processor or memory access context.
