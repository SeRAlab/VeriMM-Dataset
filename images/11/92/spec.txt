Design a simple SD card interface controller that manages the read and write operations on an SD card. The controller should have the following inputs: clk (clock), rst (reset), cmd (command), and data_in (data input). The outputs should include data_out (data output) and ready (indicates when the controller is ready for a new command). The controller should handle two commands: 'read' and 'write'. The output data should reflect the command executed and the data inputted.
