Write a Verilog module to achieve the following. Assume signals are positive clock/clk edge triggered unless otherwise noted.
You have a ten-bit input vector in[9:0]. Calculate the following relationships:
// (1) out_even: Each bit of this output vector should indicate whether the corresponding input bit and its neighbour to the right are both even numbers. For example, out_even[4] should indicate if in[4] and in[3] are both even numbers. Since in[0] has no neighbour to the right, out_even[0] is not needed.
// (2) out_odd: Each bit of this output vector should indicate whether the corresponding input bit and its neighbour to the left are both odd numbers. For example, out_odd[6] should indicate if in[6] and in[7] are both odd numbers. Since in[9] has no neighbour to the left, out_odd[9] is not needed.
// (3) out_flip: Each bit of this output vector should indicate whether the corresponding input bit is the opposite (0 or 1) of its neighbour to the left. For example, out_flip[2] should indicate if in[2] is the opposite of in[3]. For this part, treat the vector as wrapping around, so in[0]'s neighbour to the left is in[9].
