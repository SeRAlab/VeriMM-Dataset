Design a combinational circuit that performs a comparison between two n-bit wide input signals, A and B. The module outputs a 2-bit signal, eq_gt, indicating the result of the comparison: '11' for equality, '10' if A is greater than B, '01' if A is less than B, and handles cases involving unknown states (represented by 'X') by determining appropriate outputs based on the X state conditions. The design purpose is to facilitate digital decision-making in applications that require comparison of binary numbers, considering both valid and unknown inputs.
module top_module(
  input [n-1:0] A,
  input [n-1:0] B,
  output reg [1:0] eq_gt
);
