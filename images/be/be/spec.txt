Design a game control unit that manages the state transitions of a simple game based on input signals. The module has four main states: RESTART, START, PLAY, and DIE. In the START state, it transitions to the PLAY state when any of the specified keys are pressed. In the PLAY state, it checks for collisions with walls or body, leading to the DIE state upon detection. In the DIE state, the unit prepares to restart the game after a brief period controlled by a clock counter. The restart functionality is activated when the unit returns to the RESTART state, allowing the game to reset and begin anew. The outputs include game status, a die flash indicator, and a restart signal.
module top_module(input clk,input rst,input key1_press,input key2_press,input key3_press,input key4_press,output reg [1:0]game_status,input hit_wall,input hit_body,output reg die_flash,output reg restart);
