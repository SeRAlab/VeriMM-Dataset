Design a 3-bit up/down counter that increments or decrements its count based on control signals. The module features a clock input and a load signal that, when activated, resets the count to zero. On each rising edge of the clock, the counter updates its current value; when the `up_down` signal is high, it increments the count, and when low, it decrements it. The output is a 3-bit register reflecting the current count state.
module top_module(
    input clk,
    input up_down,
    input load,
    output reg [2:0] count
);
