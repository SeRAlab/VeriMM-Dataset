Design a simple 64-word memory module with a 32-bit wide data bus. The module features read and write operations controlled by input signals; on the rising edge of the clock, if the write signal (wr) is asserted, the data (wdata) is stored at the specified address (addr) in memory. When the read signal (rd) is active, the module outputs the data from the addressed location; otherwise, it outputs the previously written data (wdata). This design allows for basic memory operations in a digital system.
