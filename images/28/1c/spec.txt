A simple watchdog timer that resets a counter if not updated within a specified time. The timer counts down from a specified timeout value and resets the output if it reaches zero. There are two inputs: `update` (to reset the timer) and `clk` (the clock signal). When the timer reaches zero, the output `reset` is asserted. Otherwise, if `update` is received before the timer reaches zero, the timer is reset to the timeout value.
