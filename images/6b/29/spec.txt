Implement the Verilog module based on the following description.
You are given a nine-bit input vector in[8:0]. We want to compute some relationships between the bits and their neighbours: 
// (1) out_sum: Each bit of this output vector should indicate the sum of the corresponding input bit and its neighbour to the left (higher index). For example, out_sum[5] should indicate the sum of in[5] and in[4]. Since in[0] has no neighbour to the left, the answer is obvious so we don't need to know out_sum[0]. 
// (2) out_or: Each bit of this output vector should indicate whether either the corresponding input bit or its neighbour to the right are '1'. For example, out_or[6] should indicate if either in[6] or in[5] are 1. Since in[8] has no neighbour to the right, the answer is obvious so we don't need to know out_or[8]. 
// (3) out_xor: Each bit of this output vector should indicate whether the corresponding input bit is different from its neighbour to the left. For example, out_xor[4] should indicate if in[4] is different from in[3]. For this part, treat the vector as wrapping around, so in[8]'s neighbour to the left is in[0].
