Design a synchronous D flip-flop with clear and enable functionalities. The output Q is updated on the rising edge of the clock (CLK) based on the input data (D). If the synchronous clear input (SCD) is asserted, the output Q is reset to 0. If the enable input (SCE) is deasserted, the output Q holds its previous state. Otherwise, Q is updated to reflect the value of D. This module also includes power and ground connections for proper functionality in a digital circuit.
