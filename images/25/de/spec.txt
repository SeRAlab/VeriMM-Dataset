
Design a simple Automatic Repeat reQuest (ARQ) system using Verilog. The system should include a sender and receiver with the following specifications:
- The sender transmits a data bit and waits for an acknowledgment (ACK) from the receiver. 
- If an ACK is received, the sender proceeds to transmit the next bit.
- If a NACK (negative acknowledgment) is received or if no ACK is received within a given timeout, the sender retransmits the same bit.
- The receiver should also include a simple mechanism to simulate correct and erroneous reception of data bits.
