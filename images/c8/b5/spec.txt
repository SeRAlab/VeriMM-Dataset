Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a 4-to-1 multiplexer (MUX). 
A MUX is a digital circuit that selects one of four input signals and passes it to the output based on a two-bit select signal. 
Your module should have the following inputs and outputs:

Inputs: a set of four input signals (in0, in1, in2, in3) and a two-bit select signal (sel)
Outputs: a single output signal (out)
The module should implement the following functionality:

If sel is 00, out should be equal to in0
If sel is 01, out should be equal to in1
If sel is 10, out should be equal to in2
If sel is 11, out should be equal to in3
To implement the MUX, you should use Verilog code to create a case statement that selects the appropriate input signal based on the value of sel. 
You should then assign the selected input signal to the output signal.
