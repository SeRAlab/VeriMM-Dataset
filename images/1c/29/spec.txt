Design an 8-bit Analog-to-Digital Converter (ADC) that takes an 8-bit input representing an analog voltage level from 0 to 255 and converts it to a corresponding binary value that indicates which range the voltage level falls into. The ranges are defined as follows:  
- 0 to 63: Output 3'b000  
- 64 to 127: Output 3'b001  
- 128 to 191: Output 3'b010  
- 192 to 255: Output 3'b011  
If the input is out of bounds, the output should be 3'b111.
