Design a delay control circuit that adjusts an internal delay value based on clock and control inputs. The circuit includes a reset functionality to initialize the delay to a default value of 8, and allows for modification of this delay through a write operation using an 8-bit input. Additionally, it enables incremental adjustment of the delay via 'faster' and 'slower' signals, which decrement or increment the delay value, respectively, within a range of 1 to 15. The output is a 4-bit representation of the current delay setting.
module top_module(
    input clk,
    input reset,

    input faster,
    input slower,
    output [3:0] delay,

    input write,
    input [7:0] writedata
);
