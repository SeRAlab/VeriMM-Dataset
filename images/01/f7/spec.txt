
Design a Verilog module that simulates a simplified Flash memory cell. The Flash memory cell should have the following characteristics:
- It should have a data input (D) and an output (Q).
- It should have a write enable (WE) signal. When WE is high, the data input (D) should be written to the output (Q).
- It should have a read enable (RE) signal. When RE is high and WE is low, the output (Q) should reflect the stored value.
- The module should also have a reset signal (RST) which, when high, sets the output (Q) to a default value (0).
