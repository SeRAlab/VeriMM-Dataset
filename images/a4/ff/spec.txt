Design a D-type flip-flop with set and reset functionalities. The flip-flop captures the input D on the rising edge of clock C, while the outputs are influenced by asynchronous active-low reset (R) and set (S) signals. When R is asserted, the output Q is reset to LOW; when S is asserted, Q is set to HIGH. If neither reset nor set is active, Q holds the last captured state.
