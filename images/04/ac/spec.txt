
Create a LIFO stack module in Verilog. The stack should support the following operations:
1. Push: Add a data item to the top of the stack.
2. Pop: Remove the data item from the top of the stack.
3. Peek: Retrieve the data item from the top of the stack without removing it.
4. IsEmpty: Check if the stack is empty.
The stack should have a maximum size of 8. Use a clock signal for state changes, and include an asynchronous reset.
