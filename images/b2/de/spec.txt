Design a 32-bit wide memory-mapped I/O interface module that operates using a Wishbone protocol. This module supports read and write operations based on input signals: it captures data from the input (`wb_dat_i`) into an internal 32-bit register (`internal_reg`) selectively based on the write enable (`wb_we_i`) and byte-select signals (`wb_sel_i`). The state of the internal register can be reset to zero using the reset signal (`wb_rst_i`). The module outputs the current value of the internal register on both the `wb_dat_o` and `port_output` outputs, confirming successful data transactions with an acknowledgment signal (`wb_ack_o`) that is activated when the strobe signal (`wb_stb_i`) is asserted.
