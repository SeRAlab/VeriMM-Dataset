Design a 4-bit comparator that evaluates two 4-bit inputs, A and B. The module outputs three signals: EQ, GT, and LT. When A equals B, EQ is set high, and GT and LT are low. If A is greater than B, GT is set high, while EQ and LT are low. Conversely, if A is less than B, LT is set high, and EQ and GT are low. This circuit serves to determine the equality and relative size of two 4-bit values.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output reg EQ,
    output reg GT,
    output reg LT
);
