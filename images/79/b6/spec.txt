Design a 2-bit up counter that includes synchronous clear, load, and enable functionality. The counter increments its value on each positive clock edge when enabled. If the Clear signal is asserted, the counter resets to zero. If the Load signal is active, the counter is set to a predefined value of 3 (binary 11). Otherwise, it increments the current count value by one when enabled.
module top_module(
    input Clock,
    input Clear,
    input Enable,
    input Load,
    output reg [1:0] Q
);
