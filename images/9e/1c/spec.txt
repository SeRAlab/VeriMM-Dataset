Design a 4-bit binary up counter with asynchronous reset and enable functionality. The counter increments on the rising edge of the clock when enabled; if the reset is active, it returns to zero. The counter wraps around to zero after reaching its maximum value of 15 (1111), and it includes an output signal that indicates when this maximum value is reached. The current count value is continuously updated and made available as a 4-bit output.
module top_module(
    input clk,
    input reset,
    input enable,
    output [3:0] count,
    output max
);
