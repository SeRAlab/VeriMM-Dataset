Design a four-bit barrel shifter that performs a left or right shift based on the direction input (DIR). The module takes two four-bit inputs, A and B, and shifts the bits according to the amount specified by the two-bit AMT input. If DIR is 0, it performs a left shift using A and B; if DIR is 1, it performs a right shift using B and A, effectively combining the shifted values from both inputs. The output S provides the result of the shift operation.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input DIR,
    input [1:0] AMT,
    output reg [3:0] S
);
