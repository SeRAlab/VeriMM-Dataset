Design a basic arithmetic calculator that performs four operations—addition, subtraction, multiplication, and division—on two 8-bit input values, A and B. The module outputs the results: `sum`, `difference`, `product`, and `quotient`. Notably, it ensures that any negative results for the `difference` and `quotient` are clamped to zero, preventing negative outputs. This module effectively serves as a simple ALU (Arithmetic Logic Unit) for 8-bit signed integers.
module top_module(
  input [7:0] A,
  input [7:0] B,
  output reg [7:0] sum,
  output reg [7:0] difference,
  output reg [7:0] product,
  output reg [7:0] quotient
);
