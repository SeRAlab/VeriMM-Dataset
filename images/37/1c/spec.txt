
Design a 1-bit DRAM cell with the following specifications:
- The cell should have a single bit storage.
- It should have an input for writing data (write data - `d_in`), a write enable signal (`we`), and an output for reading data (`d_out`).
- The stored bit can be read when the write enable signal is low.
- On the rising edge of the clock, if `we` is high, the data input `d_in` is stored in the cell.
- On the falling edge of the clock, the data should be available on `d_out` if `we` is low.
