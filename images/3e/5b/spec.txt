Design a Verilog module for a simple Flash memory cell that can store a single bit. The cell should have inputs for data (D), a write enable signal (WE), and a read enable signal (RE). When WE is high, the module should store the value of D. When RE is high, the module should output the stored value. If both WE and RE are low, the output should remain unchanged. Implement the Verilog code for this functionality.
