Design an 8-to-3 priority encoder. The encoder should take an 8-bit input where only one bit can be high (logic 1) at a time, and output a 3-bit binary representation of the highest priority input bit (where input bit 0 has the highest priority and input bit 7 has the lowest priority). The output should be valid when any input is high, and if no input is high, the output should be 3'b000.
