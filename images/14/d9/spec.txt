
Design a 4-bit SRAM cell that can store a 4-bit data word. The SRAM cell should have the following inputs: 
- `data_in`: 4-bit input data to be stored. 
- `write_enable`: signal to control writing to the cell (active high).
- `address`: 2-bit address to select the SRAM cell.
The outputs should be:
- `data_out`: 4-bit output data read from the cell.
When `write_enable` is high, the `data_in` should be written to the selected address. When `write_enable` is low, the output `data_out` should reflect the contents of the selected SRAM cell.
