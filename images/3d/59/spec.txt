
Create a Verilog module for a simple Recurrent Neural Network (RNN) cell. The RNN cell takes a sequential input `x` and a previous hidden state `h_prev`, and outputs a new hidden state `h_out`. The RNN cell uses a simple activation function (e.g., a tanh function approximation). The inputs are 8 bits wide, and the output is also 8 bits wide. Implement the logic such that the new hidden state is calculated using the formula: `h_out = tanh(W_hh * h_prev + W_xh * x)`, where `W_hh` and `W_xh` are constant weights defined in the module.
