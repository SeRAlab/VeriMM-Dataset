Design a 4-bit SRAM cell that can store a single 4-bit value. The cell should have the following inputs: a 4-bit data input (D), a write enable signal (WE), and a read enable signal (RE). The cell should output the stored value (Q) when RE is high and should store the value on the rising edge of the clock when WE is high. If both WE and RE are low, the output Q should retain its last stored value.
