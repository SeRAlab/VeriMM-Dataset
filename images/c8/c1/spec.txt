

You are tasked with designing a module that takes in an input signal and outputs a 36-bit signal. The output signal should be the input signal shifted left by 2 bits, with the two least significant bits set to 0.

Design a Verilog module that takes in a 34-bit input signal `in_signal` and outputs a 36-bit signal `out_signal`. The module should be named `shift_left_2` and should be self-contained (i.e. do not use any other modules). The module should have the following ports:

- `in_signal`: a 34-bit input signal
- `out_signal`: a 36-bit output signal

The module should perform the following operations:

- Shift the `in_signal` left by 2 bits.
- Set the two least significant bits of the resulting signal to 0.
