Please act as a professional Verilog designer. Create a module that implements a 3-bit counter with a synchronous reset. The counter should count up on every positive edge of the clock signal and reset to 0 when the reset signal is high. The module should have three ports: clk, reset, and count. The clk port is an input port that is used to control the clock signal. The reset port is an input port that is used to reset the counter. The count port is a 3-bit output port that outputs the current count value. You can implement this counter with an always block and a ternary operator to check the state of the reset signal.
