Design an 8-bit DRAM cell that supports both read and write operations. The DRAM cell should have the following inputs: a 1-bit write enable (we), an 8-bit data input (data_in), a 1-bit read enable (re), and an output for the 8-bit data output (data_out). When write enable is high, the data input should be written to the cell. When read enable is high, the cell should output the stored data.
