Design a Verilog module that implements a simple NAT function. The module should take an internal IP address and an external IP address as inputs, and output a translated external IP address based on a predefined mapping. The mapping should be: 
- Internal IP: 192.168.1.1 -> External IP: 203.0.113.1
- Internal IP: 192.168.1.2 -> External IP: 203.0.113.2
- Internal IP: 192.168.1.3 -> External IP: 203.0.113.3
If the internal IP is not in the mapping, output should be 0.0.0.0.
