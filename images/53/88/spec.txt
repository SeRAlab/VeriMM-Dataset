Design a 4-bit counter module with load capability. The counter increments its value on each positive clock edge unless the reset signal is high, in which case it resets to zero. Additionally, if the load signal is asserted, the counter loads a new value from the 4-bit input, overriding the incrementing behavior. The current value of the counter is continuously output through the 'out' port.
module top_module(input clk, input reset, input load, input [3:0] in, output reg [3:0] out);
