Design a 16-QAM modulator in Verilog. The modulator takes a 4-bit input representing the symbol to be transmitted and outputs two signals: I (In-phase) and Q (Quadrature). The mapping for the symbols is as follows:  
0000 -> (1, 1),  
0001 -> (1, 3),  
0010 -> (3, 1),  
0011 -> (3, 3),  
0100 -> (1, -1),  
0101 -> (1, -3),  
0110 -> (3, -1),  
0111 -> (3, -3),  
1000 -> (-1, 1),  
1001 -> (-1, 3),  
1010 -> (-3, 1),  
1011 -> (-3, 3),  
1100 -> (-1, -1),  
1101 -> (-1, -3),  
1110 -> (-3, -1),  
1111 -> (-3, -3).  
The module should have a clock input and reset input, and the outputs should be registered. The inputs are valid on the rising edge of the clock. The reset should initialize the outputs to zero.
