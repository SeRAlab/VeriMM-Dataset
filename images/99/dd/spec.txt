Design a 64-bit ripple carry adder that takes two 64-bit inputs, A and B, and computes their sum. The adder produces a 64-bit output SUM and a carry output CARRY that indicates an overflow beyond the 64th bit. The sum for each bit is calculated using the XOR operation, while carry values are derived from the AND and OR operations, propagating the carry sequentially from the least significant bit to the most significant bit.
module top_module(
  input [63:0] A,
  input [63:0] B,
  output [63:0] SUM,
  output CARRY
);
