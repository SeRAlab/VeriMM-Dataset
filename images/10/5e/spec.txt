Design an 8-bit SRAM cell with the following specifications:
- The SRAM cell should have an 8-bit data input (D), an 8-bit data output (Q), a write enable (WE), and a clock (CLK).
- When WE is high, the data input D should be written to the SRAM cell on the rising edge of CLK.
- When WE is low, the data output Q should hold the last written value.
