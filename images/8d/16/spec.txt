Implement the Verilog module based on the following description.
Design a simple elevator controller. The elevator can be in one of three states: moving up, moving down, or stationary. The elevator moves based on requests (up_request and down_request). The elevator should prioritize requests to move down over requests to move up. When reset, the elevator should be stationary.
module top_module (
	input clk,
	input reset,
	input up_request,
	input down_request,
	output reg moving_up,
	output reg moving_down,
	output reg stationary);
