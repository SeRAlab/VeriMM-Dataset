Design a synchronous circuit that implements a one-clock-cycle delay for a 100-bit wide input signal. Upon receiving a rising clock edge, the circuit captures the current input signal and holds it in a temporary register. The output signal then reflects this captured input after one clock cycle. The design resets both the temporary and output signals to zero when the reset signal is activated.
module top_module(
  input clk,
  input reset,
  input [99:0] in,
  output reg [99:0] out
);
