Please act as a professional Verilog designer. Your task is to create a Verilog module that implements an accumulator. 
An accumulator is a digital circuit that sums a sequence of input values over time and stores the result. 
Your module should have the following inputs and outputs:

Inputs: a clock signal (clk) and a data input signal (data_in)
Outputs: an output signal (out) representing the sum of all input values

Your module should implement the following functionality:

On each rising edge of the clock signal, the input value should be added to the accumulator.
The output signal should represent the sum of all input values up to the current clock cycle.
The accumulator should reset to zero when a reset signal (rst) is asserted.

To implement the accumulator, you should use Verilog code to define a register to store the sum of the input values and a combinational circuit to calculate the new sum on each clock cycle. 
You should also use a conditional statement to reset the accumulator to zero when the reset signal is asserted.
