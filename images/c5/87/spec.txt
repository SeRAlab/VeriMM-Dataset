

You are tasked with designing a verilog module that takes in a 4-bit input and outputs a 2-bit output. The output should be the 2 least significant bits of the input multiplied by a constant value of 3. The module should have a single clock input, and the output should be updated on the rising edge of the clock.

Your module should be named "Multiplier" and should have the following ports:
- input clk: a single bit clock input
- input [3:0] in: a 4-bit input
- output reg [1:0] out: a 2-bit output

Ensure that your design meets the following requirements:
- The output should be updated on the rising edge of the clock.
- The output should be the 2 least significant bits of the input multiplied by a constant value of 3.
