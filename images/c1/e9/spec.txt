
You are tasked with designing a module that takes in a 4-bit binary-coded decimal (BCD) input and outputs a 7-bit value that represents the BCD value in 7-segment display format. The 7-bit output should be in the format of "abcdefg", where each bit represents a segment of the 7-segment display. The segments are labeled as follows:

```
  a
f   b
  g
e   c
  d
```

The mapping of BCD values to 7-segment display segments is as follows:

```
BCD    abcdefg
0      1000000
1      1111001
2      0100100
3      0110000
4      0011001
5      0010010
6      0000010
7      1111000
8      0000000
9      0011000
```

Design a module `bcd7seg` that implements this functionality. The module should have the following ports:

- `input [3:0] bcd`: a 4-bit binary-coded decimal input
- `output reg [6:0] seg`: a 7-bit output representing the BCD value in 7-segment display format

Ensure that the module is synthesizable and can be simulated using a testbench.
