Design an NVMe command queue controller that supports up to 8 concurrent command queues. The controller should have a 3-bit input for queue ID (q_id), a 1-bit input for enqueue (enqueue), and a 1-bit input for dequeue (dequeue). The output should indicate the status of each queue, with a 1-bit output for each queue indicating whether it is active (1) or inactive (0). Additionally, the controller should have a 4-bit counter to keep track of the number of commands in the active queue.
