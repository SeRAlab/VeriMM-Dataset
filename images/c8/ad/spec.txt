

You are tasked with designing a module that implements a 2-input XOR gate with an additional input that is ANDed with the XOR output. The module should be named "xor_and" and should have the following inputs and outputs:

Inputs:
- A (1-bit)
- B (1-bit)
- C (1-bit)

Outputs:
- X (1-bit)

The output X should be equal to (A XOR B) AND C.

Your task is to implement the "xor_and" module in Verilog and ensure that it passes the provided testbench.
