Design a 4-bit binary counter that increments its count on each positive clock edge when enabled and resets to zero upon a reset signal. The counter has a maximum value of 9 (1001 in binary), at which point it will reset back to zero and signal that it has reached its maximum count through the 'reached_max' output. When the reset signal is low, the counter and the 'reached_max' output are initialized to zero.
module top_module(
  input clk,
  input reset,
  input enable,
  output reg [3:0] count,
  output reg reached_max
);
