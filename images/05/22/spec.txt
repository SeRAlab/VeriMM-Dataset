
Design a convolutional encoder with a constraint length of 3, which has two outputs (coded bits). The encoder takes a 1-bit input and produces two output bits based on the following polynomial representation:
- Output 1: G1 = 111 (which corresponds to the polynomial x^2 + x + 1)
- Output 2: G2 = 101 (which corresponds to the polynomial x^2 + 1)
The encoder should maintain state information to generate output bits based on the current input and the previous two bits. The design must include appropriate state management to handle the encoding process correctly.
