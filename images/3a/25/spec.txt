Design an SR flip-flop using Verilog. The flip-flop should have two inputs (S and R) and two outputs (Q and Qn). The flip-flop should operate on the positive edge of a clock signal. The behavior of the flip-flop should be as follows: if S = 1 and R = 0, Q should be set to 1; if S = 0 and R = 1, Q should be reset to 0; if S = 0 and R = 0, Q should hold its previous state; and if S = 1 and R = 1, the output should be undefined (we can choose to hold the previous state as well).
