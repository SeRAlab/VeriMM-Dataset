
Design a 1-bit SRAM cell using Verilog. The SRAM cell should have the following inputs: `data_in`, `we` (write enable), and `clk` (clock). The output should be `data_out`. The SRAM cell should allow data to be written to the cell when `we` is high on the rising edge of the clock, and it should hold the data when `we` is low.
