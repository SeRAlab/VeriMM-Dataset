Design a 2-channel DMA controller that can manage two separate data streams. Each channel should be able to start a data transfer independently and signal when the transfer is complete. The controller needs to have the following inputs: `clk`, `reset`, `start_ch1`, `start_ch2`, and outputs: `done_ch1`, `done_ch2`. The DMA controller should also have a counter that increments with each clock cycle while a transfer is in progress for each channel, and it should stop the transfer after a predefined number of clock cycles defined as `transfer_length` for each channel.
