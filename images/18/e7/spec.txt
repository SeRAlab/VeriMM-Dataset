
Design a 16-bit ADC (Analog to Digital Converter) module in Verilog that takes a 16-bit analog input signal and converts it to a 4-bit digital output representing the range of the input in quantized levels. The ADC should implement a simple quantization logic that maps the input range of 0 to 65535 (for 16 bits) to levels from 0 to 15 (for 4 bits). The outputs should be determined by dividing the input value by 4096 (65536/16) and taking the floor of that value.
