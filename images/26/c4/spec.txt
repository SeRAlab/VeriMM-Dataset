Design a LIFO (Last In, First Out) stack in Verilog. The stack should have a parameter for the depth (size of the stack) and include the following operations: push, pop, and a function to check if the stack is empty. The stack should also have an output to show the current top element. The push operation should add an element to the top of the stack, while the pop operation should remove the element from the top. The operation signals should be triggered on the rising edge of a clock signal, and the stack should handle underflow (trying to pop from an empty stack) gracefully by not changing the stack state.
