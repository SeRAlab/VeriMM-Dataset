Design a 4-to-1 multiplexer that selects one of four 5-bit wide input signals (a, b, c, or d) based on a 2-bit selection input (s). The output (r) will reflect the value of the selected input, where s=00 corresponds to a, s=01 to b, s=10 to c, and s=11 to d.
module top_module(
	input [4:0] a,
	input [4:0] b,
	input [4:0] c,
	input [4:0] d,
	input [1:0] s,
	output [4:0] r
    );
