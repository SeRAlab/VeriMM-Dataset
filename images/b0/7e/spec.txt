Design a 32-bit D flip-flop with asynchronous preset and clear functionality. The module captures the input data (D) on the rising edge of the clock (C), replacing the output (Q) with the input value unless the clear (CLRbar) is asserted, which resets the output to zero, or the preset (PREbar) is asserted, which sets the output to all ones. The complemented output (Qbar) is also updated correspondingly. This design serves as a fundamental building block for synchronous circuits requiring state retention with reset and preset capabilities.
