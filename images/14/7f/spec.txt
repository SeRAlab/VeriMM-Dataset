
Design a 24-bit ADC (Analog-to-Digital Converter) output encoder that converts a 24-bit input signal into a 4-bit output representation. The 24-bit input is treated as an unsigned integer. The output should represent the quantized value based on a specific range. For example, if the input value exceeds the maximum representable value (2^24 - 1), the output should saturate at its maximum value (1111 in binary, which is 15 in decimal).
