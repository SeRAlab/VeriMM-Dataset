
Design a Voltage-Controlled Oscillator (VCO) that generates a frequency output based on a control voltage input. The VCO should have the following specifications:
1. The control voltage input is a 4-bit binary number (V_control).
2. The output frequency (F_out) should be calculated based on the formula: F_out = (Frequency_base + V_control) * Multiplier, where Frequency_base is 10 MHz and Multiplier is 1 MHz.
3. The output frequency should be represented as a 16-bit number.
4. The design must include a clock signal to enable frequency updates on each clock cycle.
