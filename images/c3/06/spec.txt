

You are tasked with designing a Verilog module that implements a clock gate. The module should have four inputs:

- `CLK`: a clock signal
- `EN`: an enable signal
- `TE`: a transparent enable signal
- `ENCLK`: an output signal that should be the gated version of the input clock signal

The module should implement a transparent latch that is controlled by the `EN` and `TE` signals. When `EN` is high, the latch should be enabled and the output signal `ENCLK` should follow the input clock signal `CLK`. When `EN` is low and `TE` is high, the latch should be transparent and the output signal `ENCLK` should follow the input signal `TE`. When both `EN` and `TE` are low, the latch should be disabled and the output signal `ENCLK` should be low.

Your module should be named `clock_gate` and should be contained within 200 lines of Verilog code.
