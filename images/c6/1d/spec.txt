
You are tasked with designing a Verilog module for a binary to gray code converter. The module should have the following inputs and outputs:
- Inputs:
  - `clk`: a clock signal
  - `rst`: a reset signal
  - `bin`: a 4-bit binary input
- Outputs:
  - `gray`: a 4-bit gray code output

The module should convert the binary input to its corresponding gray code output. The module should be synchronous, meaning that the output should only change on the positive edge of the clock signal.
