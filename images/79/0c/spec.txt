Design a simple Direct Memory Access (DMA) controller that reads from and writes to a memory array based on input signals. The module features a 16-bit address and data bus, with control signals for reading and writing operations. Upon a read signal, it retrieves data from a specified memory address and sets a read completion flag. Conversely, on a write signal, it stores incoming data at the designated address in the memory array and signals completion for the write operation. Additionally, an asynchronous reset is included, which is currently unimplemented. The module outputs the read data and status flags indicating the success of read and write operations.
