Design a negative-edge triggered D flip-flop with asynchronous active-low reset functionality. The flip-flop captures the value of the input D on the falling edge of the clock signal (CLK) and outputs it as Q. If the reset signal (RST) is low, the output Q is immediately set to low, overriding the normal operation. This design provides a way to control the output state directly through the reset line while still functioning as a standard D flip-flop.
