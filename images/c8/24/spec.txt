

You are tasked with designing a Verilog module for a clock gate that is activated by a positive edge-triggered clock signal and an enable signal. The clock gate should output a clock signal that is enabled only when the enable signal is high.

Your module should be named "clock_gate" and should have the following inputs and outputs:

Inputs:
- clk (1-bit): positive edge-triggered clock signal
- enable (1-bit): enable signal

Outputs:
- clk_out (1-bit): output clock signal that is enabled only when the enable signal is high

Your module should be designed to work with a clock signal of 50 MHz.

Write a Verilog module that implements the clock gate described above. Your module should be no more than 200 lines of code.
