Design an HMAC (Hash-based Message Authentication Code) module in Verilog. The module should take a message and a secret key, both of fixed length, and produce a message authentication code (MAC) using a simple hash function. The HMAC should be computed using the following formula:  
HMAC(key, message) = Hash((key XOR opad) || Hash((key XOR ipad) || message)),  
where `ipad` is the inner padding and `opad` is the outer padding. The hash function can be simplified as a concatenation of inputs for this problem. The key and message lengths will be fixed (e.g., 128 bits). The output should be the resulting MAC. Include reset functionality and ensure the output is valid only after a valid input is processed.
