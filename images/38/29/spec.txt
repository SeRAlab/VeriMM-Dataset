
Design an 8-channel DMA controller with the following specifications:
- The DMA controller should have 8 input channels and 8 output channels.
- Each channel can be enabled or disabled.
- The controller should operate in round-robin fashion among the enabled channels.
- An external signal 'start' will trigger the DMA transfer for one cycle, and a reset signal 'reset' should initialize all channels.
- Each channel has a data width of 8 bits.
