Design a simple SPI (Serial Peripheral Interface) controller that operates in master mode. The SPI controller should have the following specifications:
- It should have an input signal `clk` (clock), `start` (to start transmission), `data_in` (8-bit input data), and an output signal `mosi` (Master Out Slave In).
- The controller should shift out `data_in` on the `mosi` line on the rising edge of `clk`, starting when `start` is high, and it should complete the transmission in 8 clock cycles.
- After completing the transmission, `mosi` should be set to 0 until the next start signal.
