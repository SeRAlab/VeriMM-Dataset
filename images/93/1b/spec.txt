Design a program counter (PC) circuit that updates its output value based on control signals. It operates by setting the output to an external address when reset is asserted. If pcWre (program counter write enable) is asserted, the PC updates to the input program counter value (i_pc). When neither reset nor pcWre is active, the PC retains its current value, effectively allowing it to hold its state. This design is essential for managing program flow in digital systems, especially in implementing instruction sequences in microprocessors.
