Design an 8-bit shift register with parallel load capability. The shift register should have the following inputs: an 8-bit data input (D), a clock input (CLK), a load input (LOAD), and a shift direction input (DIR). When LOAD is high, the shift register should load the input data D. When LOAD is low, if DIR is 0, the shift register should shift the data to the right; if DIR is 1, the data should shift to the left. The output of the shift register should be an 8-bit output (Q).
