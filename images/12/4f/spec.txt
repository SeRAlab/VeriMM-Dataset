Design a 4-channel DMA controller that allows for data transfers from memory to four different peripherals. The controller must have the following inputs: a 4-bit channel selection input (sel), a start signal (start), a clock signal (clk), and a reset signal (reset). The controller should output a 4-bit signal indicating which channel is currently active (active_channel). The transfer should occur on the rising edge of the clock when the start signal is asserted, and the active channel should change according to the channel selection input. When reset is asserted, the active channel should be set to zero.
