

You are tasked with designing a verilog module that implements a 4-bit binary adder. The module should have two 4-bit input ports (A and B) and one 4-bit output port (S) that represents the sum of A and B. The module should also have a single input port (Cin) and a single output port (Cout) that represent the carry-in and carry-out bits, respectively. The module should be synchronous, with a single clock input port (clk) and a single asynchronous reset input port (rst_n).

Design the module and provide the verilog code.
