Given the following Moore state machine with 1 input (in) and 1 output (out). Unless otherwise stated in the diagram below, assume outputs are 0 and inputs are don't cares.

1. state E (out=1).
2. state F (out=1).
3. state G (out=0).

State transitions:
1. From state E: If in = 0, then remain in state E. If in = 1, then transition to state F.
2. From state F: If in = 0, then transition to state G. If in = 1, then transition to state E.
3. From state G: If in = 0, then transition to state F. If in = 1, then remain in state G.

At reset, the state machine starts in state "E". Derive next-state logic equations and output logic equations by inspection assuming the following one-hot encoding is used: (E, F, G) = (3'b001, 3'b010, 3'b100)

Write code that generates the following equations:

- E_next -- next-state logic for state E
- F_next
- G_next
- out -- output logic
