Design a 4-to-1 combinational logic circuit that produces a single output (X) based on the logic levels of two pairs of inputs (A1, A2) and (B1, B2). The output is determined by evaluating the logical conditions of each pair: X will output high if both pairs of A inputs are either low or both pairs of B inputs are high; otherwise, it will be low. This design effectively implements a custom logical function combining AND and OR operations on the two input pairs.
module top_module(
    input A1,
    input A2,
    input B1,
    input B2,
    output X
);
