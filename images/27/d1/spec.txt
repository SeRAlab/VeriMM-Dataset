Design a simple RSA encryption module that takes 2 prime numbers, p and q, and a plaintext message as input. The module will compute the RSA public keys and encrypt the message. The RSA encryption is done using the formula: ciphertext = plaintext^e mod n, where n = p * q and e is a predefined public exponent (usually 65537). The outputs should be the public key (n, e) and the ciphertext.
