Design a circuit for a one-bit wide multiplexer that selects between two 32-bit inputs, PCplus4 and nPC, based on the value of the FlushPC control signal. If FlushPC is high (1), the output F_nPC will be nPC; if FlushPC is low (0), the output will be PCplus4.
module top_module(
	 input  FlushPC,           
	 input  [31:0] PCplus4,    
	 input  [31:0] nPC,        
	 output  [31:0] F_nPC      
	 );
