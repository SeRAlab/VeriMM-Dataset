
Design a Verilog module that simulates a simple gradient descent optimization algorithm. The module should take a 16-bit input representing the current position (x) and a 16-bit input representing the learning rate (alpha). It will output a 16-bit value representing the new position after one step of optimization. The gradient descent update rule is given by: 
new_position = current_position - alpha * gradient.
For simplicity, assume a fixed gradient value of 1.
