Design a 4-bit DRAM cell with read and write operations. The DRAM cell should have a 4-bit data input, a control signal for write (1 for write, 0 for read), and a 4-bit data output. Upon receiving a write command, the data should be stored in the cell. On a read command, the data should be outputted. The cell should hold its value until it's overwritten with a new value.
