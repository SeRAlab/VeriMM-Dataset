
Design an 8-channel DMA (Direct Memory Access) controller that allows for data transfer between peripherals and memory without CPU intervention. The DMA controller should have the following features:
- It should be able to select one of the 8 channels based on a 3-bit channel select input.
- Each channel should be able to initiate a read or write operation based on a control signal.
- The DMA controller should generate a transfer complete signal for each channel after the data transfer is completed.
- Include an enable signal to activate the DMA controller.
