Design a digital phase shifter that takes a 5-bit binary input and produces a 5-bit output that represents the input shifted by a certain phase. The phase shift can be controlled by a 3-bit binary control input that determines the number of positions the input is shifted. The control input can range from 0 to 7, allowing for phase shifts of 0 to 7 bits. If the shift exceeds the input length, it should wrap around.
