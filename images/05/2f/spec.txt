Design a 16-bit Arithmetic Logic Unit (ALU) that can perform the following operations based on a 4-bit operation code (opcode):
0: ADD
1: SUBTRACT
2: AND
3: OR
4: XOR
5: NOT
6: NAND
7: NOR
The ALU should take two 16-bit inputs and output a 16-bit result. The NOT operation should only use the first input, while the rest use both inputs.
