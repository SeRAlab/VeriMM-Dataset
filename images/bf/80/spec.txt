Implement a simple 8-bit shift register with parallel load capability. The shift register should shift data to the right on each positive clock edge when the shift enable signal is high. When the parallel load enable signal is high, the shift register should load the parallel input data.

Module name:
    shift_register

Input ports:
	clk: Clock signal used for synchronous operations.
	shift_en: Shift enable signal. When high, the shift register shifts data to the right.
	load_en: Parallel load enable signal. When high, the shift register loads the parallel input data.
	parallel_in: 8-bit parallel input data.

Output ports:
	serial_out: Serial output data representing the rightmost bit of the shift register.
