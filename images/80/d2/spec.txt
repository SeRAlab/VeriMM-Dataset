Design a 4-bit register with asynchronous reset and enable functionality. On the negative edge of the clock, if the reset signal is active, the register outputs are cleared to zero. If the reset is not active and the enable signal is asserted, the register captures the input data (din) and stores it. The current value of the register is continuously available on the output (dout).
module top_module(
    input clk, rst, en,
    input [3:0] din,
    output [3:0] dout
);
