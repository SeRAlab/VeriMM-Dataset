

You are tasked with designing a verilog module that takes in two 4-bit inputs (A and B) and outputs a 4-bit result (Z). The output should be the result of adding the two inputs together. If the result is greater than 15, the output should be saturated to 15. The module should have the following interface:

Inputs:
- A: 4-bit input
- B: 4-bit input

Outputs:
- Z: 4-bit output

Your module should be named "adder_4bit".

You can assume that the inputs will always be valid 4-bit values (0-15) and that the module will be used in a larger system.
