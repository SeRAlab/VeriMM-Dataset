Design a Parallel-in Parallel-out (PIPO) shift register that allows loading a 5-bit data input in parallel and can shift out the data on demand. The shift register should have a clock input, a load enable input, and a shift enable input. When load enable is high, the data on the input should be loaded into the register. When shift enable is high, the data should be shifted out to an output on the rising edge of the clock.
