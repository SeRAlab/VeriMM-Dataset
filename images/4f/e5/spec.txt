Design a D-type flip-flop with set and reset functionalities. On the rising edge of the clock signal (C), the flip-flop's output (Q) can be set to high (1) when the set signal (S) is asserted, cleared to low (0) when the reset signal (R) is asserted, or updated to the value of the data input (D) when neither S nor R are active. The initial value of Q can be configured using a parameter for initialization.

    output reg Q,
    input D,
    input C,
    input S,
    input R
