Design a divide-by-2 circuit using a register. The circuit should take a single-bit input and output a single-bit result. The output should be the input divided by 2, which means if the input is 0, the output should be 0, and if the input is 1, the output should be 0 on the next clock cycle. The circuit should have a clock and a reset signal. When reset, the output should be set to 0.
