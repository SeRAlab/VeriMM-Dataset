Design a simple EEPROM cell using Verilog. The EEPROM cell should have the following specifications:
- It must be able to store a single bit (0 or 1).
- It should have three control signals: `write`, `read`, and `reset`.
- When `write` is asserted, the data input (D) should be stored in the cell.
- When `read` is asserted, the stored data should be output (Q).
- When `reset` is asserted, the stored data should be set to 0.
