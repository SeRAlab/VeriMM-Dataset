Design a clock divider circuit that generates a lower-frequency clock output (clk_o) from an input clock (clk_i). The output clock toggles its state whenever a specified count, determined by the 16-bit input value (div), is reached. The circuit includes a reset (rst) input to initialize the output clock and the count register to zero. 
module top_module(
	input rst,
	input clk_i,
	input [15:0] div,
	output clk_o
	);
