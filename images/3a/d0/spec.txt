Design a simple hash table with a fixed size of 16 entries. The hash table will support two operations: 
1. Insertion of a key-value pair into the table. 
2. Retrieval of a value by its key. The hash function will compute an index based on the key modulo the size of the hash table. If a collision occurs during insertion, the new value will overwrite the existing one. The keys will be 8 bits wide and the values will be 8 bits wide as well. The design should handle up to 5 key-value pairs.
