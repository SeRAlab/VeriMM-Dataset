Design a distributed RAM module with configurable address and data widths. The module features an 8-bit address space allowing access to 256 memory locations, each capable of storing 8 bits of data. On the positive edge of the clock signal, if the write enable signal is asserted, the input data will be stored at the specified address in memory. The output continuously reflects the data stored at the given address, allowing read operations at any time. The RAM is initialized to zero on startup.
