Design a Read-Only Memory (ROM) module with an 8-bit address input and a 16-bit data output. It outputs specific 16-bit data values based on the address input; for example, when the address is 8'h00, the output is 16'hF104, and for 8'h01, it outputs 16'hF100. For any other address, the output defaults to 16'h0000. This module is useful for storing fixed data that can be read during operation but not modified.
module top_module(
input [7:0] addr,
input CLK,
output reg [15:0] data);
