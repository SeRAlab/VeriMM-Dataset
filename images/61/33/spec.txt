Design a display counter that increments an 18-bit output count on every positive clock edge when both the counting and enable inputs are active. If the reset input is low, the counter is reset to zero. Additionally, if the enable input is deactivated, the count is also reset to zero, effectively halting the counting process.
module top_module(
    input reset,
    input counting,
    input enable,
    input clk,
    output reg [17:0] count
    );
