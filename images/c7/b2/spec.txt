

You have been tasked with designing a Verilog module that implements a gated D latch. The module should have the following inputs and outputs:

Inputs:
- `d`: a single-bit input representing the data to be stored in the latch.
- `clk`: a single-bit input representing the clock signal.
- `en`: a single-bit input representing the enable signal.

Outputs:
- `q`: a single-bit output representing the stored value.

The module should only store a new value when the enable signal is high. Otherwise, the stored value should remain unchanged. The stored value should be updated on the rising edge of the clock signal.

Design a Verilog module that implements the gated D latch as described above. Your module should be self-contained and should not exceed 200 lines of Verilog code.
