

You are tasked with designing a module that takes in two 3-bit inputs, `A` and `B`, and outputs the sum of the two inputs, `S`, and the carry out, `Cout`. The module should be implemented using behavioral Verilog.

Create a module named `adder` with the following ports:
- `input [2:0] A`
- `input [2:0] B`
- `output [2:0] S`
- `output Cout`

Your module should perform the following operation:
- `S = A + B`
- `Cout` should be set to 1 if there is a carry out from the most significant bit of the sum, and 0 otherwise.
