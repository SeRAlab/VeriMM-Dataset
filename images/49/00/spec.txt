Design a 4-to-1 multiplexer that takes four 4-bit inputs (in0, in1, in2, in3) and outputs one of these inputs based on a 2-bit selection signal. The output will be determined by the value of the select signal; if select is 00, the output will be in0; if 01, the output will be in1; if 10, the output will be in2; and if 11, the output will be in3.
module top_module(
    input [3:0] in0,
    input [3:0] in1,
    input [3:0] in2,
    input [3:0] in3,
    input [1:0] select,
    output reg [3:0] out
);
