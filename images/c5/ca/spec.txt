

You are tasked with designing a module that takes in 8 inputs and outputs 1 value. The module should be named "logic_gate". The inputs are as follows:
- A (1-bit)
- B (1-bit)
- C (1-bit)
- D (1-bit)
- E (1-bit)
- F (1-bit)
- G (1-bit)
- H (1-bit)

Your module should implement the following logic gate:
```
X = (A and B) or (not C and D) or (E xor F) or (not G and H)
```
Where "and" denotes logical AND, "or" denotes logical OR, "not" denotes logical NOT, and "xor" denotes logical XOR.

Your module should have the following port declarations:
- input A (1-bit)
- input B (1-bit)
- input C (1-bit)
- input D (1-bit)
- input E (1-bit)
- input F (1-bit)
- input G (1-bit)
- input H (1-bit)
- output X (1-bit)

Write the code for the "logic_gate" module that implements the above logic gate.
