The flip-flop captures the data input (D) on the rising edge of the clock (CLK) while allowing for asynchronous control signals. If the RESET signal is active, the output (Q) is set to LOW, and if the SET signal is active, the output is set to HIGH. This module is useful for circuits requiring specific reset and set functionalities alongside standard data storage.
