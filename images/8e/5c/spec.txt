Design a 4-bit adder-subtractor circuit. It takes two 4-bit inputs, A and B, and a control signal (Sub) that determines the operation: when Sub is low, the module performs addition (A + B), and when Sub is high, it performs subtraction (A - B). The result of the operation is updated on the rising edge of the clock signal.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input Sub,
  input clk,
  output reg [3:0] result  // Change wire to reg for result
);
