
Design a Verilog module that implements a simplified version of an RRT (Rapidly-exploring Random Tree) algorithm. The module should take a start point and a goal point as inputs, along with a random point, and determine if a path can be formed from the start point to the goal point via the random point. The module should use a simple state machine to control the process of checking whether the random point is within a certain distance from the start or goal points. The distance metric can be defined as the Manhattan distance in a 2D space.
