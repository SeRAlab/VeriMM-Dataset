
Design an interrupt controller that manages multiple interrupt requests (IRQ). The controller should have the following features:
1. It should accept multiple interrupt requests as input.
2. It should prioritize interrupts by their order of arrival.
3. It should allow only one interrupt to be processed at a time.
4. When an interrupt is acknowledged, it should generate an output signal indicating the active interrupt.
5. The controller should have a reset signal to clear the acknowledged interrupt and reset the state.
