

You are tasked with designing a Verilog module that implements a 4-bit binary counter with synchronous reset. The module should have the following inputs and outputs:

- `clk`: a clock input with a frequency of 50 MHz
- `rst`: a synchronous reset input that resets the counter to 0 when asserted
- `out`: a 4-bit output representing the current count value

The counter should increment on every rising edge of the clock input. When the reset input is asserted, the counter should immediately reset to 0.

Your module should be named `four_bit_counter` and should be contained within 200 lines of Verilog code.
