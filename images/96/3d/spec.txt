Design a 4-bit barrel shifter that can perform three types of bit shifts based on two control inputs: a 2-bit SHIFT value indicating the shift amount and a MODE input that determines the type of shift operation. The MODE can be set for logical left shift, logical right shift, or arithmetic right shift. The output, Y, will reflect the shifted result of the input vector IN based on the specified shift direction and amount.
module top_module(
    input [3:0] IN,
    input [1:0] SHIFT,
    input MODE,
    output reg [3:0] Y
);
