
Create a Verilog module that performs 2x2 matrix inversion. The input to the module will be a 2x2 matrix represented by four inputs (a, b, c, d) and the output will be the inverted matrix represented by four outputs (a_inv, b_inv, c_inv, d_inv). The matrix inversion formula for a 2x2 matrix is given by:
```
| a  b |
| c  d |
```
The inverse is calculated as:
```
1/(ad - bc) * |  d  -b |
              | -c   a |
```
If the determinant (ad - bc) is zero, output should be undefined or a specific error indicator.
