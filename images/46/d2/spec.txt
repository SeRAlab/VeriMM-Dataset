Design a 4-to-1 multiplexer that selects one of four input signals (in0, in1, in2, in3) based on a 2-bit select input. The selected input is routed to the output, which is a register of configurable BIT_WIDTH (defaulted to 32 bits). If the select input does not match any of the valid cases (0-3), the output will drive high impedance. The multiplexer operates in combinational logic, allowing for rapid signal switching based on the select lines.
module top_module(
input clk, reset,
input [1:0] select,
input [BIT_WIDTH-1:0] in0, in1, in2, in3,
output reg [BIT_WIDTH-1:0] out
);
