

You are tasked with designing a verilog module that implements a 2-to-1 multiplexer. The module should have two input ports, `A` and `B`, and one output port, `Y`. Additionally, the module should have a control input port, `S`, which selects which input is passed through to the output. If `S` is 0, then `A` should be passed through to `Y`. If `S` is 1, then `B` should be passed through to `Y`.

Use the following module declaration as a starting point:

```
module mux_2to1 (
    input A,
    input B,
    input S,
    output reg Y
);
```

Note that the `Y` output port is declared as a `reg`, indicating that it should be assigned a value within the module. You may assume that the `S` input port will always be either 0 or 1.
