Design a 4-bit SRAM cell that can store data and be read and written to. The SRAM cell should have inputs for data (4 bits), a write enable signal (we), a read enable signal (re), and a clock signal (clk). When the write enable signal is high, the data should be stored in the SRAM cell on the rising edge of the clock. When the read enable signal is high, the stored data should be available at the output.
