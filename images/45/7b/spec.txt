Design a 32-bit wide, 4-to-1 multiplexer. The module takes a 2-bit control input to select one of the four 32-bit inputs (a, b, c, or d) to output on the selected line. When control is `00`, output a; when `01`, output b; when `10`, output c; and when `11`, output d.
module top_module(
    input wire [1:0] control,
    input wire [31:0] a,b,c,d,
    output wire [31:0] selected
);
