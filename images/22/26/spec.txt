Design a 1-bit SRAM cell in Verilog. The SRAM cell should have the following functionality: it should be able to store a single bit (1 or 0) and be controlled by a write enable signal (we). When we is high, the data input (d) should be written to the cell. When we is low, the cell should hold its value and the output (q) should reflect the stored value. The cell should also have an asynchronous reset signal (rst) that resets the stored value to 0 when asserted.
