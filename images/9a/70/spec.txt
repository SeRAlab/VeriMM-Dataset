Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs: 
1. state P (output 1).
2. state Q (output 0).
3. state R (output 1).

State transitions:
1. From state P: If p = 0, then transition to state Q. If p = 1, then transition to state R.
2. From state Q: If p = 0, then transition to state P. If p = 1, then transition to state R.
3. From state R: If p = 0, then transition to state Q. If p = 1, then transition to state P.

Resets into state P. For this part, assume that a one-hot code is used with the state assignment l[3:1] = 001, 010, 100 for states P, Q, R, respectively.

Write Verilog for the next-state signals L2 and L3 corresponding to signal l[2] and l[3]. Derive the logic equations by inspection assuming a one-hot encoding.
