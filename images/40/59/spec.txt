Design an 8-bit DRAM cell that can be read from and written to. The DRAM cell should have the following inputs and outputs:  
- `clk`: clock signal  
- `we`: write enable signal  
- `addr`: 3-bit address for selecting one of the 8 bits  
- `din`: 1-bit data input for writing  
- `dout`: 1-bit data output for reading  
The behavior should be such that when `we` is high, the value on `din` is written into the memory cell at the address specified by `addr` on the rising edge of `clk`. When `we` is low, the value at the specified `addr` is output on `dout` on the rising edge of `clk`. The DRAM cell should initially be reset to 0. The output should be valid on the next clock cycle after a write or read operation.
