Design a 5-bit Linear Feedback Shift Register (LFSR) using polynomial x^5 + x^2 + 1. The LFSR should have an active high load input that allows you to set the initial state of the LFSR. The LFSR should also have a clock input and a reset input. On each positive edge of the clock, if reset is low, the LFSR should either shift and feedback based on the polynomial or load a new value if the load input is high.
