
Design a simple Bluetooth module state machine that has the following states: IDLE, CONNECTING, CONNECTED, and DISCONNECTED. The module should transition between these states based on the following conditions:
- From IDLE to CONNECTING: when `start_conn` is high
- From CONNECTING to CONNECTED: when `conn_success` is high
- From CONNECTED to DISCONNECTED: when `disconnect` is high
- From any state to IDLE: when `reset` is high
The state machine should have an output `current_state` which indicates the current state.
