The module outputs the selected 8-bit value from the inputs fila0 to fila7 accordingly to the value of act_add, functioning as an 8-to-1 multiplexer. If act_add is not valid, it defaults the output to an 8-bit zero value.
module top_module(
    input wire [2:0] act_add,
	 input wire [7:0] fila7,
	 input wire [7:0] fila6,
	 input wire [7:0] fila5,
	 input wire [7:0] fila4,
	 input wire [7:0] fila3,
	 input wire [7:0] fila2,
	 input wire [7:0] fila1,
	 input wire [7:0] fila0,
    output reg [7:0] max_in
    );
