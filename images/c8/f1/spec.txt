
You are tasked with designing a verilog module that takes in a 4-bit input and outputs a 2-bit value based on the following conditions:
- If the input is less than 4, output 00
- If the input is between 4 and 7 (inclusive), output 01
- If the input is between 8 and 11 (inclusive), output 10
- If the input is greater than 11, output 11

You should use the following module declaration:
```
module input_to_output (input [3:0] in, output [1:0] out);
   // your code here
endmodule
```
