Design a 4-to-1 multiplexer for 5-bit wide inputs. The module takes four 5-bit inputs (a1, a2, a3, a4) and a 2-bit selection input (choose). Based on the value of the choose inputs, the output (z) will be assigned one of the four input signals. Specifically, if choose is 00, output a1; if 01, output a2; if 10, output a3; and if 11, output a4.
module top_module(
    input [4:0]a1,
    input [4:0]a2,
    input [4:0]a3,
    input [4:0]a4,
    input [1:0]choose,
    output [4:0]z
    );
