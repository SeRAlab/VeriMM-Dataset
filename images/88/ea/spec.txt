Design a program counter (PC) module that tracks the current instruction address in a processor. The PC is updated on the rising edge of the clock; it initializes to the value 0x00003000 upon reset and updates its value to the next program counter (npc) when enabled. Additionally, the module outputs the current program counter value (pc) and the subsequent address (pcplus), which is simply the current value incremented by 4, facilitating sequential instruction fetching.
