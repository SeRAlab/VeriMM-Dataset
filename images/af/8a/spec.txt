Create a Verilog module for a 4-bit binary counter with a loadable value, synchronous reset, and enable. When reset is asserted, the counter should be set to 0. The counter should load a new value when the load signal is high and increment on each rising edge of clk when enable is high.
module binary_counter (
    input clk,
    input reset,
    input en,
    input load,
    input [3:0] load_value,
    output reg [3:0] q);
