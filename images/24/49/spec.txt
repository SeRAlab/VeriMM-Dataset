Design a Verilog module that implements a 3x3 Gaussian blur filter for an 8-bit grayscale image. The input is a 3x3 matrix of pixel values, and the output is a single blurred pixel value. The Gaussian blur filter can be represented with the following coefficients:  
```
1  2  1  
2  4  2  
1  2  1  
```  
The output pixel value should be calculated as the weighted sum of the input pixel values divided by 16 (the sum of the coefficients).
