Design a Verilog module that implements a simple Rapidly-exploring Random Tree (RRT) node. The module should take in a random point and a target point and output the direction to move towards the target point. Assume the inputs are 2D coordinates (x, y) for both the random point and the target point. The output should be a 2-bit direction (00=North, 01=East, 10=South, 11=West) indicating the closest direction to the target point.
