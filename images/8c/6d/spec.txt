Design a 4-bit shift register with asynchronous reset functionality. On the rising edge of the clock, if the reset signal is low, the output is set to zero. If the shift signal is high, the register shifts its content to the left by one bit, inserting the new input bit at the least significant position, effectively allowing serial input to be captured while maintaining the previous bits in order.
module top_module(
    // inputs
    input in,
    input shift,
    input clk,
    input reset,
    // outputs
    output reg [3:0] out
);
