Design a Verilog module for a simple SLAM (Simultaneous Localization and Mapping) state machine. The state machine should have the following states: IDLE, MAPPING, and LOCALIZING. The machine transitions between these states based on a start signal (start) and a done signal (done). When in IDLE state, if 'start' is asserted, it moves to MAPPING state. In MAPPING state, if 'done' is asserted, it transitions to LOCALIZING state. In LOCALIZING state, if 'done' is asserted again, it returns to IDLE state. The output of the module should indicate the current state in binary (2 bits). The states are encoded as follows: IDLE = 00, MAPPING = 01, LOCALIZING = 10.
