
You are tasked with designing a module that implements a full adder using Verilog. The module should have three inputs: A, B, and CI, and two outputs: SUM and COUT. A and B are single bit inputs, CI is the carry in bit, SUM is the sum of the three bits, and COUT is the carry out bit. 

Create a Verilog module that implements a full adder using the following interface:

```
module full_adder (
    input A,
    input B,
    input CI,
    output SUM,
    output COUT
);
```

You may use any gates or other modules available in Verilog to implement the full adder. Your module should be able to handle any combination of inputs and produce the correct output.
