

You are tasked with designing a verilog module for a simple 2-to-1 multiplexer. The module should have two 8-bit input ports, one 1-bit select input port and one 8-bit output port. The select input port should determine which input port is passed to the output port. 

The module should be named "mux_2to1" and should have the following ports:
- input [7:0] in0
- input [7:0] in1
- input sel
- output reg [7:0] out

You should use the ternary operator to implement the functionality of the module.
