

You are tasked with designing a module that takes in six inputs and produces one output. The input signals are A1, A2, B1, B2, C1, VPB, VPWR, VGND, and VNB. The output signal is Y. 

The module should be named "six_input_module". The inputs and outputs should be declared in the module header. The inputs A1, A2, B1, B2, and C1 are data signals, while VPB, VPWR, VGND, and VNB are power signals. The output Y is also a data signal. 

The module should implement the following logic: 
- If A1 and A2 are both 1, and B1 and B2 are both 0, then Y should be 1.
- If A1 and A2 are both 0, and B1 and B2 are both 1, then Y should be 0.
- If C1 is 1, then Y should be 1.
- If none of the above conditions are met, then Y should be 0.

Implement the "six_input_module" and test it using the following test cases:
- A1 = 1, A2 = 1, B1 = 0, B2 = 0, C1 = 0 -> Y = 0
- A1 = 0, A2 = 0, B1 = 1, B2 = 1, C1 = 0 -> Y = 1
- A1 = 0, A2 = 0, B1 = 0, B2 = 0, C1 = 1 -> Y = 1
- A1 = 1, A2 = 0, B1 = 1, B2 = 0, C1 = 0 -> Y = 0
