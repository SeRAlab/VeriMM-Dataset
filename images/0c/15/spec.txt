Design a UART controller that can send data serially at a specified baud rate. The UART controller should have inputs for a data byte, a send enable signal, and a clock signal. When the send enable signal is asserted, the controller should transmit the data byte bit by bit, starting with the least significant bit, followed by a start bit (0), and a stop bit (1) at the end. The controller should have an output for the serial transmitted data.
