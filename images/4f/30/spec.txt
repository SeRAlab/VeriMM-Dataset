Implement an 8-bit shift register with parallel load capability. The module should shift left or right based on a control signal.

Module name:
    shift_register
Input ports:
    clk: clock signal
    rst: reset signal
    load: parallel load enable signal
    data_in: 8-bit input data for parallel loading
    shift_left: direction control signal (0 for right, 1 for left)
Output ports:
    data_out: 8-bit shifted output

Implementation:
The module uses an always block that triggers on the rising edge of the clock or the reset signal. Based on the control signal, it shifts the data left or right.
