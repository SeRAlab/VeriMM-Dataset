

You are tasked with designing a verilog module for a 2-to-1 multiplexer. The module should have two input ports, A and B, and one output port, Y. The module should also have a control input, S, which selects which input is routed to the output. When S is 0, input A should be routed to output Y, and when S is 1, input B should be routed to output Y.

You should implement the module using structural verilog, using only basic logic gates (AND, OR, NOT, XOR, etc.) and no instantiated modules or pre-defined primitives.

Your module should be named "mux_2to1" and should have the following ports:

- A (input): the first input to the multiplexer
- B (input): the second input to the multiplexer
- S (input): the control signal that selects which input to route to the output
- Y (output): the output of the multiplexer
