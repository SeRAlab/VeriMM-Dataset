Design a 4-to-1 multiplexer that selects one of four 1-bit input signals based on a 2-bit selection input. The selected input is output on the 'out' line, where 'sel' determines which input is conveyed: 'sel' = 00 outputs 'in[0]', 'sel' = 01 outputs 'in[1]', 'sel' = 10 outputs 'in[2]', and 'sel' = 11 outputs 'in[3]'.
module top_module(
    input [3:0] in,
    input [1:0] sel,
    output reg out
);
