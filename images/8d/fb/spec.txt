Implement a 32-bit Arithmetic Logic Unit (ALU) that performs a variety of operations based on a 5-bit operation code (op). On each positive clock edge, the ALU executes operations such as addition, subtraction, bitwise AND, OR, XOR, and shift operations, depending on the value of op. Specifically, the ALU can create zero outputs for certain operation codes and perform arithmetic or logical operations between two 32-bit inputs (op1 and op2) for others, returning the result in a 32-bit output (alu_out). The design includes default behavior of returning zero for any undefined operation code.
module top_module(
           input wire clk,
           input wire [31:0] op1,
           input wire [31:0] op2,
           input wire [4:0] op,

           output reg [31:0] alu_out
       );
