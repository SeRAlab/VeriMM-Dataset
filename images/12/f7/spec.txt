
Design a GPIO controller in Verilog that allows for reading and writing to a specified register. The controller should have the following functionalities:
1. A `write_enable` signal that enables writing to the data register.
2. A `read_enable` signal that enables reading from the data register.
3. A 4-bit `data_in` signal for writing data to the register.
4. A 4-bit `data_out` signal for reading data from the register.
5. A clock signal for synchronizing the operations.
6. An asynchronous reset signal that resets the data register to zero.

The data register should hold the last written value and output the current value when read.
