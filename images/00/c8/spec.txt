Design a GPIO controller that can read from input pins and write to output pins. The controller should have the following functionalities:
1. A 4-bit input data register that captures data from GPIO pins.
2. A 4-bit output data register that controls GPIO output.
3. A control signal that specifies whether to read from the input pins or write to the output pins. If the control signal is high, the data from the input pins should be captured. If it is low, the data should be sent to the output pins.
4. There should be a clock and reset signal to manage the operation of the controller.
