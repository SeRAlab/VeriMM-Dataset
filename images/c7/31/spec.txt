
You are tasked with designing a module that implements a 2-to-1 multiplexer using Verilog. The module should have two inputs, A and B, and one output, Y. Additionally, the module should have a select input, SEL, which determines which input is passed through to the output. If SEL is 0, input A should be passed through to the output. If SEL is 1, input B should be passed through to the output.

Your module should be named "mux_2to1" and should have the following interface:
- A and B: two 1-bit inputs
- SEL: one 1-bit input
- Y: one 1-bit output

You may assume that all inputs and outputs are initially set to 0.
