Design a 2-bit Arithmetic Logic Unit (ALU) that performs different operations based on the value of the control input C. The unit can execute a bitwise AND operation when C is 00, a bitwise OR operation when C is 01, addition when C is 10, and subtraction when C is 11. The outputs are determined by the selected operation applied to the two 2-bit input operands, A and B.
module top_module(
    input [1:0] A,
    input [1:0] B,
    input [1:0] C,
    output reg [1:0] out
);
