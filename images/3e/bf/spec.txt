
Design a 24-bit ADC (Analog to Digital Converter) controller that takes a 24-bit input signal and produces a 24-bit output. The output should have the following characteristics:
1. The output should be equal to the input signal when a valid signal is high.
2. When the valid signal is low, the output should latch the last valid input value.
3. The module should have a reset functionality that clears the output to zero.
