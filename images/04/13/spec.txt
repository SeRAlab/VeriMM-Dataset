Design a simple SATA controller signal decoder that takes a 5-bit input representing a command type and outputs a 3-bit signal indicating the command category. The command types are as follows:  
- 00000: No Operation (NOP)  
- 00001 to 00010: Read commands (00)  
- 00011 to 00100: Write commands (01)  
- 00101: Identify Device (10)  
- 00110 to 11111: Reserved commands (11).  
The output should be based on the input command type.
