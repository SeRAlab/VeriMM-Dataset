Design a 3-level decision tree for classifying an input of 3 bits (X[2:0]) into two classes (output Y). The decision tree should be designed as follows:
1. If X[2] is 1, then Y = 1 (class 1).
2. If X[2] is 0 and X[1] is 1, then Y = 0 (class 0).
3. If X[2] is 0, X[1] is 0, and X[0] is 1, then Y = 1 (class 1).
4. If X[2] is 0, X[1] is 0, and X[0] is 0, then Y = 0 (class 0).
