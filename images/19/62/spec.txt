Design a linear voltage regulator controller in Verilog that takes an input voltage and outputs a regulated voltage. The input voltage (Vin) should be compared to a reference voltage (Vref). If Vin is greater than Vref, the output voltage (Vout) should be equal to Vref. If Vin is less than or equal to Vref, Vout should be equal to Vin. Implement this behavior using combinational logic.
