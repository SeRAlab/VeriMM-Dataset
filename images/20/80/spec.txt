Design a 3x3 Gaussian blur filter in Verilog that takes a 3x3 pixel matrix as input and outputs a blurred pixel value. The Gaussian blur is defined by the following kernel:
```
1  2  1
2  4  2
1  2  1
```
The output pixel value is calculated by multiplying each pixel value in the kernel by the corresponding pixel value from the input matrix, summing the results, and then dividing by 16 (the sum of the kernel values).
