Design a Verilog module that implements a simple Recurrent Neural Network (RNN) inference block. The RNN should take a 4-bit input vector `x`, maintain a hidden state `h` of 4 bits, and use weights (also 4 bits) to update the hidden state based on the input. The module should have a clock input to synchronize updates and a reset signal to initialize the hidden state. The output should be the updated hidden state.
