
Design an 8-bit data bus multiplexer that takes in three 8-bit inputs (A, B, and C) and a 2-bit select signal (sel). The output (Y) should be one of the inputs based on the value of sel: if sel is 00, output A; if sel is 01, output B; if sel is 10, output C; and if sel is 11, output 0 (all bits low).
