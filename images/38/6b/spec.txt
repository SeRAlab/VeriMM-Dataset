Design a 1-bit SR flip-flop with asynchronous reset and set inputs. The flip-flop should have inputs S (Set) and R (Reset), and an output Q. When S is high, Q should be set to 1. When R is high, Q should be reset to 0. If both S and R are low, the flip-flop should hold its state. The reset should be asynchronous, meaning it takes effect immediately regardless of the clock.
