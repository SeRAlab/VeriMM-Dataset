Design an 8-bit SRAM cell that can read and write data. The SRAM cell should have the following input and output ports: 
- `data_in` (8 bits): the data to be written to the SRAM cell
- `addr` (3 bits): the address of the SRAM cell
- `we` (1 bit): write enable signal (active high)
- `clk` (1 bit): clock signal
- `data_out` (8 bits): the data read from the SRAM cell

The SRAM cell should store data at the specified address when `we` is high on the rising edge of `clk`. When `we` is low, `data_out` should reflect the data stored at the specified address.
