
Design a 16-bit Digital-to-Analog Converter (DAC) in Verilog. The DAC should take a 16-bit binary input and produce an output that represents the equivalent analog voltage. Assume a reference voltage of 5V, with the output voltage being calculated as (Input / 65535) * 5V. The output should be represented as a 16-bit integer value corresponding to the analog voltage scaled to a 16-bit resolution.
