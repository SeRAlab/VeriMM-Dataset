Design a simple counter-based circuit that operates on a single clock cycle. The module features a 4-bit register (cnt) that increments by one on each negative edge of the clock. Upon receiving a reset signal (active high), the counter resets to zero. The output y indicates when the second bit of the counter is high, while output z signifies when the most significant bit (third bit) is high. This design can be used as a state indicator in sequential circuits.
module top_module(input clk,reset,output y,z);
