Design a module that incorporates a two-input AND gate combined with additional logic to control the output based on specific conditions of its inputs. The module outputs the result of the AND operation between inputs A1 and A2, modified by the states of B1, B2, and C1. Specifically, if both B1 and B2 are high, it outputs the negation of the AND result; if B1 is high and B2 is low, it outputs the AND result conditioned by C1; otherwise, it outputs a logic LOW. This effectively creates a hybrid logic design with an AND gate and conditional control based on multiple input signals.
module top_module(
    output X,
    input A1,
    input A2,
    input B1,
    input B2,
    input C1
);
