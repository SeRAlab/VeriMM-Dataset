Design a 4-bit analog-to-digital converter (ADC) that samples an 8-bit analog input signal. Upon each rising edge of the clock, the module captures the analog input value and quantizes it by shifting the sampled value right to fit within the 4-bit output range. The resulting 4-bit digital output is then made available on the `dout` line, effectively representing the quantized value of the input signal.
module top_module(
  input clk,
  input [7:0] ain,
  output reg [3:0] dout
);
