Design a combinational logic circuit that outputs a signal Y based on the conditions of the inputs A1, A2, B1, C1, and D1. The output Y is determined as follows: if both A1 and A2 are high, Y is set to B1; if only A2 is high, Y is set to C1; if only A1 is high, Y is set to D1; and if neither A1 nor A2 is high, Y outputs a LOW (0).
module top_module(
    input A1,
    input A2,
    input B1,
    input C1,
    input D1,
    output Y
);
