Design a circuit that performs three fundamental logical operations on a 4-bit input. The module takes a 4-bit input vector and produces three outputs: one for the logical AND of all input bits, one for the logical OR of all input bits, and one for the logical XOR of all input bits. The output 'out_and' yields a HIGH only if all bits are HIGH, 'out_or' produces a HIGH if at least one input bit is HIGH, and 'out_xor' gives a HIGH if there is an odd number of HIGH input bits.
module top_module( 
    input [3:0] in,
    output out_and,
    output out_or,
    output out_xor
);
