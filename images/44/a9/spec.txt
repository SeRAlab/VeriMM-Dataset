Design a comparator circuit that evaluates the relationship between two 32-bit inputs, ReadData1 and ReadData2. It outputs two flags: EqualD, which indicates whether the two inputs are equal (1 if they are equal, 0 otherwise), and LtzD, which signifies if ReadData1 is less than ReadData2 (1 if true, indicating a negative result of the subtraction, and 0 otherwise).
module top_module(
	 input  [31:0] ReadData1,          
    input  [31:0] ReadData2,          
    output  EqualD,                   
	 output  LtzD                      
    );
