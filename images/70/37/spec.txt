Design a digital display controller that cycles through four predefined 7-segment display outputs at a specified frequency determined by the input clock (CLK). It includes a counter to manage timing, and it updates the active segment and corresponding display values every N clock cycles, where N is set to 35,000. The output signals, DISP1 and AN1, represent the 8-bit display values for the segments and the 4-bit active segment indicator, respectively. The module enables dynamic display switching, allowing it to show different numerical values across the display's segments in a sequential manner.
module top_module(
    input CLK,
    output [7:0] DISP1,
    output [3:0] AN1
    );
