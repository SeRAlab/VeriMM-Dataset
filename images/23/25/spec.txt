
Design an Automatic Repeat reQuest (ARQ) error correction system using a simple stop-and-wait protocol. The system should include a sender and a receiver. The sender sends a 5-bit data packet and waits for an acknowledgment (ACK) from the receiver. If the receiver detects an error in the received packet (using a parity bit), it sends a negative acknowledgment (NACK) back to the sender, which resends the packet. The receiver will be able to detect errors based on a parity bit check. The design should include state machines for the sender and the receiver.
