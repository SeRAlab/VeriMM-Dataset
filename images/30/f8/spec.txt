Design a simple SPI master controller that can send 8-bit data to a slave device. The controller should have the following inputs: clock (clk), reset (rst), start (start), and a 8-bit data input (data_in). The output should be the SPI clock (sck), the Serial Data Out (mosi), and a data valid signal (data_valid) indicating when the data is being sent. The controller should initiate the SPI transmission when the start signal is asserted, and the transmission should occur on the rising edge of the SPI clock.
