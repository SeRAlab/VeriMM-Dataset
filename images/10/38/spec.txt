
Design a fixed-priority arbiter that can handle 4 request signals (req[0], req[1], req[2], req[3]) and grant one signal (grant) based on fixed priority. The priority order is defined as: req[0] > req[1] > req[2] > req[3]. When a request is granted, the arbiter should maintain the grant until the request goes low. If multiple requests are high, only the highest priority request should be granted.
