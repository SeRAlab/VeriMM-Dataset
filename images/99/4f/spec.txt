Design an Arithmetic Logic Unit (ALU) that performs a variety of operations based on a 4-bit control signal (ALUop). The ALU accepts two 32-bit inputs (OpA and OpB) and produces a 32-bit output (ALUResult) based on the selected operation, which includes addition, subtraction, multiplication, bitwise AND, OR, XOR, and NOR. Additionally, it sets a Zero flag to indicate if the result of the subtraction operation is zero. The logic is implemented using a combinational always block that evaluates the operation based on the provided ALUop input.
module top_module(
input [3:0] ALUop,
input [31:0] OpA, OpB,
output wire [31:0] ALUResult,
output Zero
);
