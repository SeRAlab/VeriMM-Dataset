

You are tasked with designing a module that slices a 18-bit input signal `Din` and outputs a 10-bit signal `Dout`. The module should take the 10 bits from positions 12 to 3 of the input signal and assign them to the output signal.

Design a Verilog module that takes an 18-bit input signal `Din` and outputs a 10-bit signal `Dout`. The module should follow the following specifications:

- The module should be named `slice_module`.
- The module should have two ports: an input port named `Din` and an output port named `Dout`.
- The input port `Din` should be a 18-bit wide signal.
- The output port `Dout` should be a 10-bit wide signal.
- The module should assign bits 12 to 3 of the input signal `Din` to the output signal `Dout`.
- The module should be synthesizable.
