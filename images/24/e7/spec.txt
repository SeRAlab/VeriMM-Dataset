Design a Verilog module that implements a simple decision tree for binary classification. The decision tree has three levels with binary inputs (X1, X2, X3) and outputs a single binary decision (Y). The decision tree logic is as follows:
1. If X1 == 1, go to the left child (return Y = 1 if X2 == 1).
2. If X1 == 0, go to the right child (return Y = 0 if X3 == 0).
3. If X2 == 1 and X1 == 1, return Y = 1.
4. If X1 == 0 and X3 == 1, return Y = 1.
5. Otherwise, return Y = 0.
