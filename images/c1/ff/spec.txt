

You have been tasked with designing a module that takes in two 4-bit binary inputs, A and B, and outputs the 4-bit binary value of A XOR B. Your module should be named "xor_4bit" and should have the following ports:

- A (4-bit input)
- B (4-bit input)
- Y (4-bit output)

Your module should use only basic logic gates (AND, OR, NOT, XOR) and should not use any pre-defined modules or operators. 

Write the verilog code for the "xor_4bit" module.
