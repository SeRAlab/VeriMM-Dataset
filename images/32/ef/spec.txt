
Design a 16-bit shift register that supports both left and right shifting, as well as loading a parallel input. The shift register should have the following inputs: 
- `clk`: Clock signal
- `reset`: Active high reset signal
- `load`: Active high signal to load the parallel input
- `shift_left`: Active high signal to shift left
- `shift_right`: Active high signal to shift right
- `parallel_in`: 16-bit input to load into the shift register

The output should be a 16-bit register output named `data_out`.
