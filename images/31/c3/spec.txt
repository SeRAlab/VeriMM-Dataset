Design a simplified WiFi module that has a state machine responsible for managing the connection state. The states are 'DISCONNECTED', 'CONNECTING', 'CONNECTED', and 'DISCONNECTING'. The module should take a 'connect' input signal to transition from 'DISCONNECTED' to 'CONNECTING', and a 'disconnect' signal to transition from 'CONNECTED' to 'DISCONNECTING'. It should have an output signal 'state' that indicates the current state of the WiFi module.
