Design a 16-bit DRAM cell that can store a 16-bit value and has the following functionality: it should have a write enable signal (we), an address input (addr), a data input (data_in), and a data output (data_out). The DRAM cell should be able to write data on a rising edge of the clock when we is high and should output the stored data when we is low. The address input should select the specific register within the 16-bit cell.
