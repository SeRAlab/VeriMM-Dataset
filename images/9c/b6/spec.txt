Design a register file with configurable parameters for the number of bits and the number of registers. It allows for writing data to a specified register when the write enable signal is active and can read data from a specified register when the read enable signal is active. If reading is not enabled, it outputs zero. This structure supports an n-bit data width and m registers, facilitating storage and retrieval of data in digital systems.
module top_module(
  input [n-1:0] write_data,
  input [m-1:0] reg_addr,
  input read_en,
  input write_en,
  input clk, // Added clk input
  output [n-1:0] read_data
);
