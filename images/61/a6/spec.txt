Please act as a professional verilog designer.

Design a Verilog module for a 6-bit Gray code counter with a synchronous reset. The counter increments its value in Gray code on the rising edge of the clock and resets to zero when the reset signal is active.

Module name:  
    gray_counter_6bit  

Input ports:
    clk: Chip clock signal.
    reset: Synchronous reset signal.

Output ports:
    count: Counter output signal with a data width of 6 bits.

Implementation:
Counter operation:
On every positive edge of the clock signal (clk), the Gray code counter increments its value in Gray code if the reset signal (reset) is not active. If the reset signal is active, the counter resets to zero.
