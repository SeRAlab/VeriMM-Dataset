Design a 16-bit ADC output comparator that compares the ADC output with a reference voltage. The comparator will output a high signal when the ADC output exceeds the reference value, and a low signal otherwise. The reference value will be a 16-bit input to the module. The module should take a 16-bit ADC output and a 16-bit reference value as inputs. The output will be a single bit indicating whether the ADC output is greater than the reference value.
