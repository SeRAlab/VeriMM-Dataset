Design a simple Automatic Repeat reQuest (ARQ) system that can detect and correct a single error in a 5-bit data word. The system should have an input for the 5-bit data, a clock, and a reset signal. If an error is detected in the received data, the system should request for retransmission by setting an output signal high. The error detection can be done using a simple parity bit. If the data is correct, the output should indicate successful reception.
