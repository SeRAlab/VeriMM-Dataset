Design a four-bit binary adder that computes the sum of two 4-bit inputs, A and B, along with a carry-in input (Cin). The module outputs a 4-bit sum (S) and a carry-out (Cout). The adder employs full adder logic to handle each bit of the inputs sequentially, propagating carry bits appropriately to achieve accurate addition, including the ability to handle an overflow indicated by Cout.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    output [3:0] S,
    output Cout
);
