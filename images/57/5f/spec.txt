Design a synchronous RAM-like module that functions as a read-only memory (ROM). On the rising edge of the clock signal, if the reset signal is asserted, the module initializes its data by storing values corresponding to the remainder of each index divided by 256 into its addressable locations. When the chip enable (ce0) input is active, the module outputs the data stored at the specified address (address0); otherwise, the output is driven to low.

    clk,
