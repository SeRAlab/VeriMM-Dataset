Design a synchronous register block that captures and outputs data based on clock and enable signals. When the reset signal is asserted, the outputs o_x, o_y, and o_z are set to zero. If the reset is not active and the enable signal is asserted, the module outputs the values of input signals i_x, i_y, and i_z respectively. This module provides a means to store and forward input values in a digital system, controlling data flow with a clock and enabling mechanism.
module top_module(
	//Inputs
	clock,
	reset,
	enable,
	
   i_x, 
   i_y, 
   i_z, 

	//Outputs
	o_x,
	o_y,
	o_z
	);
