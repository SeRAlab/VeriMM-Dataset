
Design a UART controller receiver that can receive serial data with the following specifications:
1. The UART operates at a fixed baud rate.
2. The receiver should sample the incoming data at the correct times to align with the baud rate.
3. The controller should have a state machine to transition between states: Idle, Start Bit, Data, Stop Bit, and Output.
4. The receiver should output the received byte after receiving 8 data bits.
5. Provide a way to reset the controller.
