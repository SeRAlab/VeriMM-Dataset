Design a 4-bit up/down counter with load functionality. The module counts up or down based on the UD input signal, which determines the counting direction. When RST is asserted, the counter resets to zero. If LD is asserted, the counter loads a specified 4-bit value from load_value instead of incrementing or decrementing. The counter's current value is reflected in the output Q.
module top_module(
    input UD,
    input CLK,
    input RST,
    input LD,
    input [3:0] load_value,
    output reg [3:0] Q
);
