Design a 40x7 bit RAM module that supports read and write operations. It has an asynchronous reset feature that initializes the memory with a predefined set of character data when activated. The module has a clock input for synchronous operation, where memory can be written to at the rising edge of the clock if the write enable signal is asserted. It outputs the stored data at the address specified by the input when accessed.
