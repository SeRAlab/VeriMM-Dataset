Design a power gating controller that takes two inputs: `power_on` (a control signal) and `load_current` (an input signal representing the current load). The circuit should output `gated_power` which is `1` if `power_on` is `1` and `load_current` is below a certain threshold (e.g., 10). Otherwise, it should output `0`. This logic allows power to be gated off when the load exceeds the threshold or when the power_on signal is low.
