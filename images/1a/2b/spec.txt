Design a combinational logic circuit in Verilog that performs matrix multiplication of two 2x2 matrices. The input matrices A and B will be provided as 4-bit vectors, and the output matrix C will also be a 4-bit vector. The resulting matrix C will be organized in a single 16-bit output vector, with the elements of the resulting matrix C ordered as C[0][0], C[0][1], C[1][0], and C[1][1].
