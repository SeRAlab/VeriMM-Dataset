Design an 8-bit DRAM cell with read and write functionalities. The DRAM cell should have inputs for a 8-bit data signal (`data_in`), a write enable signal (`we`), a clock signal (`clk`), and an output for the stored data (`data_out`). When `we` is high, the data from `data_in` should be written into the cell on the rising edge of the clock. When `we` is low, the output `data_out` should provide the stored data from the cell.
