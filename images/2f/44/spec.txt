
Design a simple 8-bit SRAM cell with read and write functionality. The SRAM cell should have a data input (8 bits), a data output (8 bits), a write enable signal (we), and a chip enable signal (ce). When ce is low, the cell should be inactive. When we is high, the data input should be written to the cell. When we is low and ce is high, the output should reflect the stored data.
