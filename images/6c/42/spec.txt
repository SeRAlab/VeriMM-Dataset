Design a Verilog module that implements a D flip-flop with enable and asynchronous reset. The module should have a data input, an enable signal, a clock signal, a reset signal, and a data output. The output should follow the input when enable is asserted and reset is not asserted on the rising edge of the clock.

module dff (
    input d,
    input en,
    input clk,
    input reset,
    output reg q
);
