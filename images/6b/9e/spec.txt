Design a 4-bit binary counter with overflow detection. The counter increments its value on each rising edge of the clock signal. Upon receiving a reset signal, it sets the count to zero and clears the overflow flag. If the count reaches its maximum value of 15 (binary 1111), it resets to zero in the next clock cycle and sets the overflow output high, indicating that an overflow has occurred.
module top_module(
    input clk,
    input reset,
    output reg [3:0] count,
    output reg overflow
);
