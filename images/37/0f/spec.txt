
Design an 8-bit ADC converter that takes a 10-bit binary input and maps it to an 8-bit output. The 10-bit input represents a voltage level from 0V to 5V, and the output should represent the 8-bit equivalent voltage level (0-255). The mapping should be done using integer division, where the 10-bit input is divided by 4 (since 1024/256 = 4).
