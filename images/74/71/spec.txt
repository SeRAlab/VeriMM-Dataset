Design a 16-bit barrel shifter that shifts the input data D left or right based on the value of the shift amount S. If S is positive (or zero), the data is left-shifted by S bits; if S is negative, the data is right-shifted by the absolute value of S bits. The output Q reflects the shifted result.
module top_module(
    input [15:0] D,
    input [3:0] S,
    output [15:0] Q
);
