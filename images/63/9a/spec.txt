Design a 2-to-4 line decoder. It takes a 2-bit input (reg_no) and activates one of the four outputs (register) by shifting a 1-bit representation left by the value of reg_no, producing a binary output that corresponds to the selected register. When reg_no is 00, the output is 0001; when reg_no is 01, the output is 0010; when reg_no is 10, the output is 0100; and when reg_no is 11, the output is 1000, effectively decoding the 2-bit input into a single active output line.
