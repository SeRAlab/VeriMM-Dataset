

You are tasked with designing a module that takes in a 4-bit input `in_data` and outputs a 2-bit value `out_data` based on the following truth table:

| in_data | out_data |
| ------- | -------- |
| 0000    | 00       |
| 0001    | 01       |
| 0010    | 10       |
| 0011    | 11       |
| 0100    | 00       |
| 0101    | 01       |
| 0110    | 10       |
| 0111    | 11       |
| 1000    | 00       |
| 1001    | 01       |
| 1010    | 10       |
| 1011    | 11       |
| 1100    | 00       |
| 1101    | 01       |
| 1110    | 10       |
| 1111    | 11       |

Write a verilog module `truth_table` that implements this truth table.
