Design a read-only memory (ROM) module that has an 8-bit address input and a 16-bit data output. This ROM is initialized with a fixed pattern of 256 8-bit data words, ranging from 0 to 255. When provided an address, the module outputs the corresponding data word stored at that address. The design serves to store a specific set of values that can be accessed but not modified, making it suitable for applications requiring fixed data retrieval.
module top_module(
  input [n-1:0] addr,
  output [m-1:0] data
);
