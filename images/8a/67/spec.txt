Please act as a professional verilog designer.

Implement a D flip-flop with an asynchronous reset. The flip-flop should have a clock input, a data input, a reset input, and a data output. The output should follow the input on the rising edge of the clock unless the reset is asserted.

Module name:
    d_flip_flop
Input ports:
    clk: a 1-bit clock input
    d: a 1-bit data input
    rst: a 1-bit reset input
Output ports:
    q: a 1-bit output representing the stored data value

The flip-flop should store the value of the data input on the rising edge of the clock. If the reset input is high, the output should be reset to zero regardless of the clock or data input.
