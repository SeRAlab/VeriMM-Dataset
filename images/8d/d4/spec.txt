Design a 4-bit counter with load functionality. The module counts up on each clock pulse when enabled (EN) and resets to zero when the RESET signal is high. It can also load a specified 4-bit value from the input D when the LOAD signal is asserted. Additionally, the module outputs the 4-bit complement of the current count value on Q_N.
module top_module(
    input CLK,
    input RESET,
    input EN,
    input LOAD,
    input [3:0] D,
    output reg [3:0] Q,
    output reg [3:0] Q_N
);
