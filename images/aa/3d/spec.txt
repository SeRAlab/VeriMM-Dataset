Design a traffic light controller that manages the operation of a traffic signal with three states: green, yellow, and red. It uses a clock signal for timing and a reset signal for initialization. The controller transitions between states after predefined counts: it remains in the green state for 10 clock cycles, the yellow state for 2 cycles, and the red state for 8 cycles. The output signals indicate the current light state, ensuring that only one light (green, yellow, or red) is active at any given time, enabling efficient and safe traffic management.
module top_module(
  input clk, rst,
  output reg green, yellow, red
);
