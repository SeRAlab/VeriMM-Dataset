
Design a Verilog module that simulates a TCP segmentation mechanism. The input to the module will be a 32-bit data packet and a 16-bit Maximum Segment Size (MSS). The module should output a segmented packet of up to 16 bits, along with a control signal indicating if there are more packets to come. If the input packet is smaller than or equal to the MSS, it should output the entire packet in one cycle; otherwise, it should segment the packet into chunks of MSS size.
