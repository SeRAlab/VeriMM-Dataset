Design a 4-bit ripple carry adder that computes the sum of two 4-bit binary numbers, A and B, along with an input carry (CIN). The adder processes the input values across three stages to handle intermediate carry generation, ensuring accurate addition and carry-out (COUT) detection. The final output is a 4-bit SUM representing the least significant bits of the result, with COUT indicating if an overflow occurred, signaling that the sum exceeds the maximum value representable in 4 bits.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input CIN,
    output reg [3:0] SUM,
    output reg COUT
);
