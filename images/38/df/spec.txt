Design a Voltage-Controlled Oscillator (VCO) in Verilog that generates a square wave output based on a control voltage input. The frequency of the output square wave should be determined by a 4-bit binary value. The VCO should have the following parameters:
- A clock input to synchronize the output generation.
- A control voltage input that will determine the frequency of oscillation (represented as a 4-bit binary).
- An output square wave that toggles based on the control voltage value.
The output frequency should be calculated as (base frequency << control_voltage) where the base frequency is a fixed value.
