Design an 8-bit serializer that converts an 8-bit parallel input into a serial output. The serializer should have a clock input, a reset input, an 8-bit data input, and a serial output. It should output each bit of the input data serially on every rising edge of the clock, starting from the least significant bit (LSB) to the most significant bit (MSB). It should also provide a signal to indicate when the serialization is complete.
