Design a 4-bit down counter that counts down from a preset value to zero. The counter should have a clock input, a reset input, and a load input. When the load input is high, the counter should load the preset value. When the reset input is high, the counter should reset to zero. On each clock edge, if the load input is low and reset is low, the counter should decrement by one. The output of the counter should be a 4-bit value.
