Design a 16-bit ADC output decoder. Given a 16-bit binary input, the output should indicate the corresponding decimal value of the binary input. The output should be a 16-bit binary value that represents the decimal value of the input, where the 16-bit binary input is treated as an unsigned integer. The output should take the highest 4 bits of the input as a control signal to determine if the current value is valid (0-15) or invalid (16-65535). The output should be set to 0 in case of an invalid value.
