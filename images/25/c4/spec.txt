
Design an 8-bit Linear Feedback Shift Register (LFSR) that uses the polynomial x^8 + x^6 + x^5 + x^4 + 1. The LFSR should shift its bits on every clock cycle and produce a pseudo-random sequence of bits. The LFSR should have an active-high reset input that initializes the register to a non-zero state (e.g., 8'b00000001).
