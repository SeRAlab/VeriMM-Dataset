Implement a simple asynchronous single-read, single-write memory module with an 8-bit address bus and a 16-bit data bus. The module allows data to be written to a memory location specified by the 8-bit input address 'a' when the write enable signal 'we' is asserted, and outputs the data stored at the same address during a read operation. The memory consists of 256 locations, each capable of holding 16 bits of data.
module top_module(input clk,input [7:0] a,input we,input [15:0] d,output [15:0] q);
