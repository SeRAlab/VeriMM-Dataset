
Design a Verilog module that determines the TCP segmentation type based on the size of the TCP segment. The module should take an input segment size (in bytes) and output a corresponding segmentation type:
- If the segment size is less than or equal to 536 bytes, output "Small".
- If the segment size is between 537 and 1460 bytes, output "Medium".
- If the segment size is greater than 1460 bytes, output "Large".
