Design a data controller that produces a 4-bit output based on a 2-bit control signal. The output will be 0000 when the control signal is 00, all ones (1111) when the control signal is 01, the same as the 4-bit input data when the control signal is 10, and the bitwise NOT of the input data when the control signal is 11.

    input [3:0] data_in,
    input [1:0] ctrl,
    output [3:0] data_out
);
