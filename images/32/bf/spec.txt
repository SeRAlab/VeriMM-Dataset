
Design an 8-bit DRAM cell that has the following functionality:
- The cell can be written to when the write enable signal (`we`) is high, and the input data is provided on the `data_in` bus.
- The cell can be read when the `we` signal is low, and the output data should be available on the `data_out` bus.
- The cell should have a reset signal (`rst`) that clears the stored data when asserted.
