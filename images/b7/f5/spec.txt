Design a module that captures the state of a 4-bit switch input and provides it as output. On the falling edge of the reset signal, the output is reset to zero. On the rising edge of the clock, the module updates the output to reflect the current state of the switches, transferring the 4-bit switch value to the `data_out` register.
module top_module(
  input clk,
  input reset_n,
  input [3:0] switches,
  output reg [3:0] data_out
);
