Design a simple synchronous RAM module with 512 eight-bit data storage locations. On each positive edge of the clock, if the module is enabled (en), it can either write data (we=1) from the input (di) to the address specified by addr or read data from that address to the output (dout). This functionality allows the module to function as a read/write memory component, suitable for applications that require temporary data storage and retrieval.
module top_module(clk, en, we, addr, di, dout);
