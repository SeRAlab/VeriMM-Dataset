
Design a fixed-priority arbiter in Verilog that controls access to a shared resource for 5 requestors. Each requestor has a fixed priority, with Requestor 0 having the highest priority and Requestor 4 having the lowest. The arbiter should grant access to the highest priority requestor that asserts its request signal. The output will be a grant signal indicating which requestor has been granted access. If no requests are active, the grant signal should be deasserted.
