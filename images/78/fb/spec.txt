Design a 4-bit magnitude comparator that compares two 4-bit inputs A and B. The module outputs three signals: 'gt' indicates if A is greater than B, 'lt' indicates if A is less than B, and 'eq' indicates if A is equal to B. The comparison is performed by calculating the difference between A and B, and interpreting the sign bit along with the result to determine the relational outputs.
module top_module(
    input [3:0] A,
    input [3:0] B,
    output gt,
    output lt,
    output eq
);
