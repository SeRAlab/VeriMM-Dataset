Design a 4-bit adder-subtractor module that can perform both addition and subtraction based on the value of the SUB input, where SUB=0 enables addition of inputs A and B, and SUB=1 enables subtraction of B from A. The module also provides an overflow (OVFL) flag to indicate if the result has overflowed, which is determined by checking the most significant bit of the result for both operations.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input SUB,
    output reg [3:0] result,
    output reg OVFL
    );
