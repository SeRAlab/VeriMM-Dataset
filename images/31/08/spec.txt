Design a Direct Memory Access (DMA) controller that transfers data between a source and a destination memory without CPU intervention. The controller should have the following inputs: `start` (to initiate the transfer), `src_addr` (source address), `dst_addr` (destination address), `data_in` (data to be transferred), and `clk` (clock signal). The output should be `data_out` (data transferred to the destination) and `done` (signal indicating completion of the transfer). The controller should transfer one word of data per clock cycle.
