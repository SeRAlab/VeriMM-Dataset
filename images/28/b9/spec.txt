
Design a Fixed-Priority Arbiter in Verilog that selects one of four requests (req[3:0]) based on a fixed priority scheme. The arbiter should output a grant signal (grant) indicating which request is granted. The priority is fixed as follows: req[0] has the highest priority, followed by req[1], req[2], and req[3] having the lowest priority. If multiple requests are active, the highest priority request should be granted.
