Implement a Booth's multiplier circuit that processes a 4-bit multiplier and a 5-bit multiplicand to produce the next state values of both A and the multiplicand. The module calculates either the sum or the difference of the multiplier and a fixed 4-bit input A based on the least significant bits of the multiplicand. Depending on these bits being "00", "11", "01", or "10", it shifts A and the multiplicand appropriately for the multiplication operation. The outputs provide the updated values of A shifted left and the multiplicand shifted right.
module top_module(

input [3:0] A,
input [3:0] multiplier, 
input [4:0] multiplicand, 
output [3:0] A_left,
output [4:0] q_right
