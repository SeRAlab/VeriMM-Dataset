Design a circuit that toggles a single output bit based on a pulse input signal. The module, which is synchronous to a clock and reset signal, initializes the output to LOW when reset is activated. On each rising edge of the clock, if the reset is not active, the output will toggle its state (from HIGH to LOW or LOW to HIGH) according to the state of the pulse input, effectively acting as a toggle flip-flop that responds to incoming pulse events.
module top_module(
    input      clk,
    input      rst,
    input      pulse,
    output reg toggle
);
