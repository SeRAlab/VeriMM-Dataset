Design a 5-bit down counter that initializes its count based on the input value when the reset signal is activated. On each rising edge of the clock, if the reset is not asserted, the counter decrements its value by one until it reaches zero. Once zero is reached, the counter resets to the specified input value. If the reset signal is active, the counter outputs the initial value, effectively allowing for controlled reset functionality.

    input clk,
    input reset,
    input [4:0] value,
    output reg [4:0] counterOut
    );
