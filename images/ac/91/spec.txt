Design a 3-bit wide cyclic counter that increments on each rising edge of the clock signal (clk) when the enable signal (enn) is low. When enn is high, the counter resets to zero. The counter wraps around from 111 back to 000, allowing it to cycle through values 0 to 7. The current counter value is continuously made available at the output (cycle).
module top_module(
  output reg [2:0] cycle,
  input clk,
  input enn
);
