
Design a simple packet filtering firewall that checks incoming packets based on predefined rules. The firewall has a rule set that consists of a source IP address, destination IP address, and a port number. If the packet's source IP, destination IP, and port match the rule's criteria, the packet is allowed; otherwise, it is dropped.

Inputs:
- clk: Clock signal
- rst: Reset signal
- src_ip: 8-bit source IP address (from 0 to 255)
- dest_ip: 8-bit destination IP address (from 0 to 255)
- port: 8-bit port number (from 0 to 255)
- rule_enable: A signal to enable or disable the rule checking

Outputs:
- packet_allowed: 1-bit signal indicating if the packet is allowed (1) or dropped (0)

The rule is predefined as follows:
- src_ip = 10011000 (152 in decimal)
- dest_ip = 11010101 (213 in decimal)
- port = 00111000 (56 in decimal)
