Design a one-bit full adder module that computes the carry-out signal based on two input bits (A and B) and a carry-in bit (Cin). The carry-out (C) is generated by combining the carry generation (G) and propagation (P) logic, where G represents the logical AND of inputs A and B, and P represents the logical XOR of A and B. The output C is asserted if either A and B both are 1 (indicating carry generation) or if either A or B is 1 while Cin is 1 (indicating carry propagation).
module top_module(
	input  A,
	input  B,
	input Cin,
	output C
    );
