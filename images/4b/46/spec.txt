Implement an 8-to-1 multiplexer with 3-bit wide select input. The multiplexer chooses one of the eight 8-bit input channels (ch_0 to ch_7) based on the value of the select input, outputting the selected channel to data_out. If the select line does not match any of the designated cases, it defaults to outputting ch_0.
module top_module(input wire [2:0] select,input wire [7:0] ch_0,input wire [7:0] ch_1,input wire [7:0] ch_2,input wire [7:0] ch_3,input wire [7:0] ch_4,input wire [7:0] ch_5,input wire [7:0] ch_6,input wire [7:0] ch_7,output reg [7:0] data_out);
