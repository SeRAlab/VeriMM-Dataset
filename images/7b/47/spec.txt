Design a 4-bit shift register with load and shift capabilities. When the LOAD input is high, the register captures the 4-bit input data D on the rising edge of the clock. When the LOAD input is low and the SHIFT input is high, the register shifts its contents to the right, filling the most significant bit with a zero. The current value of the shift register is made available at the output Q.
module top_module(
  input CLK,
  input LOAD,
  input [3:0] D,
  input SHIFT,
  output [3:0] Q
);
