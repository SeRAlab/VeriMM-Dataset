Create a 1-bit SR-latch using Verilog. The latch should have two inputs: S (Set) and R (Reset), and one output Q. The output Q should maintain its state until a change is made by the inputs. If S is high and R is low, Q should be set to 1. If S is low and R is high, Q should be reset to 0. If both S and R are low, Q should retain its previous state. If both S and R are high, the output is considered indeterminate.
