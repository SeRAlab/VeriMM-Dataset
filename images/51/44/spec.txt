Design a one-bit wide, 2-to-1 multiplexer that selects between two 32-bit inputs: `RegData` and `PCplus8`. When the control signal `RegRA` is low (0), the output `raRegData` is assigned the value of `RegData`; when `RegRA` is high (1), it assigns the value of `PCplus8` instead.
module top_module(
	 input  RegRA,               
	 input  [31:0] RegData,      
	 input  [31:0] PCplus8,      
	 output  [31:0] raRegData    
	 );
