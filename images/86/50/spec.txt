Implement a 4-bit binary counter with enable and asynchronous reset. The counter should increment on each positive clock edge when the enable signal is high. When the reset signal is high, the counter should reset to zero regardless of the clock.

Module name:
    binary_counter

Input ports:
	clk: Clock signal used for synchronous operations.
	enable: Enable signal. When high, the counter increments.
	reset: Asynchronous reset signal. When high, the counter resets to zero.

Output ports:
	count: 4-bit output representing the current counter value.
