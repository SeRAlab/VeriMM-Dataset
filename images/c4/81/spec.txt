

You are tasked with designing a D flip-flop with asynchronous reset and synchronous set using Verilog. You have been given a code snippet for a module that implements a D flip-flop with preset and clear capabilities, but you need to modify it to meet the new requirements.

The module takes three inputs and one output:
- D: the data input
- C: the clock input
- Q: the output

The module should have the following behavior:
- When C is high, the flip-flop should capture the value of D and hold it until the next rising edge of C.
- When the asynchronous reset input, labeled R, is high, the output Q should be forced to 0, regardless of the value of D or C.
- When the synchronous set input, labeled S, is high, the output Q should be forced to 1, regardless of the value of D or C.

You should modify the given code snippet to implement the new requirements. Your solution should be a single module that is self-contained and does not require any additional modules.
