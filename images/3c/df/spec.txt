Design an 8-bit SRAM cell with read and write functionality. The SRAM cell should have a data input (D), a data output (Q), a write enable signal (WE), and a clock signal (CLK). When WE is high, the data on input D should be written into the SRAM cell on the rising edge of CLK. When WE is low, the value stored in the SRAM cell should be available on output Q.
