Design a 4-bit binary up/down counter. The counter increments when the `up` input is high and the `en` input is asserted, and it decrements when `up` is low under the same condition. The counter resets to zero when the `rst` input is high. The counting operation occurs on the rising edge of the clock signal, allowing synchronous operation.
module top_module(
    input clk,
    input rst,
    input en,
    input up,
    output reg [3:0] count
);
