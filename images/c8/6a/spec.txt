

You are tasked with designing a module that implements a 4-input AND gate. The module should have 4 input ports (A, B, C, and D) and 1 output port (X). The output of the module should be the logical AND of all 4 input signals. You should use the Verilog hardware description language to implement this module.

Your module should be named `and4` and should be defined in a file named `and4.v`. The module should be defined using the `module` keyword, and should take the following form:

```
module and4 (
    input A,
    input B,
    input C,
    input D,
    output X
);
```

In addition to the input and output ports, your module should include voltage supply signals for power and ground. You should use the following signals:

```
supply1 VPWR;
supply0 VGND;
```

Your module should implement the AND function using logical operators in Verilog. Your implementation should be correct and efficient.
