Design a Verilog module that implements a simple Canny edge detection step. The module should take a 3x3 pixel input matrix representing grayscale pixel values (each pixel value from 0 to 255) and output a single edge strength value. The edge strength is calculated by applying the Sobel operator to the input matrix, which detects edges in both horizontal and vertical directions. The output should be the maximum of the absolute values of the convolution results in both directions, clipped to a maximum value of 255.
