Design a 3-bit shift register that captures a single input bit on the rising edge of a clock signal. The module has an active low reset input to initialize the register state. Upon reset, all internal storage elements are set to zero. On each clock cycle, the input data is shifted through a series of three registers, with each stored bit being transferred to the next register. The output (q) reflects the value held in the third register, effectively indicating the value of the input as it propagates through the shift register across three clock cycles.
module top_module(input clk, input rst, input data, output reg [2:0] q);
