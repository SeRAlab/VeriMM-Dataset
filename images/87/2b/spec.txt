Design a D latch with an asynchronous reset capability. When the reset signal is low, the output q is set to LOW regardless of the values of data and enable. If reset is high, the output q reflects the input data only when the enable signal is also high, allowing the latch to store the data value. This behavior allows for controlled data storage while providing a method to clear the output.
