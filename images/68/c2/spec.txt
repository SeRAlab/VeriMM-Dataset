Design a 40-to-1 multiplexer that selects one of the 40 input data signals based on a 6-bit selection input. The module outputs the selected data signal corresponding to the value of the selection input. When the selection input (in) ranges from 0 to 39, the output will reflect the value of the respective input from the data array.
module top_module(
	input wire [5:0] in,
	input wire [39:0] data,
	output reg out
	);
