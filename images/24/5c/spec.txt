
Design a 2-channel DMA (Direct Memory Access) controller that transfers data between memory and two peripheral devices. The DMA controller should have two channels, each with its own request (REQ) and acknowledge (ACK) signals. The controller should also have a clock input (CLK) and a reset input (RST). When a REQ signal is asserted for a channel, the controller should wait for an ACK signal before completing the transfer. The controller should be able to switch between the two channels based on which REQ signal is active.
