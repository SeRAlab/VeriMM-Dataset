Design a synchronous D latch with an asynchronous set/reset feature. The latch outputs the inverted state of the input D when the clock (nCLK) is low, overriding with an inverted state of the SRMODE when the active low set/reset (nSR) signal is asserted. The initial state of the latch can be set through the parameter INIT. The SRMODE parameter specifies the behavior during the set/reset condition.
