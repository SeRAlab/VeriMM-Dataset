Design a circuit that performs a bitwise shift operation on an 8-bit input number. When the control signal is high (1), the module left-shifts the input number by one position, effectively multiplying the number by 2. Conversely, when the control signal is low (0), the module right-shifts the input number by one position, effectively dividing it by 2. The result is output as an 8-bit value.
module top_module(
    input [7:0] input_num,
    input control_signal,
    output [7:0] shifted_num
);
