Design a signed 8-bit Booth multiplier which computes the product of two signed 8-bit inputs. The module processes the inputs 'a' and 'b', extending their bit-width to 16 bits based on their sign, and performs multiplication to yield a 16-bit signed output 'prod'. The multiplication result is stored and updated on the rising edge of a clock signal, and can be reset to zero when a reset signal is asserted.
module top_module(
    input signed [7:0] a,
    input signed [7:0] b,
    input clk,
    input reset,
    output reg signed [15:0] prod
);
