Design a data latch with enable control. This module captures the input data (D) and stores it in the output (Q) when the enable signal (EN) transitions to a high state. The complementary output (Q_bar) is also provided, which reflects the negation of the stored value in Q. The latch does not change its output when EN is low, thus acting as a transparent latch that holds the last value of D while EN is inactive.
module top_module(
    input D,
    input EN,
    output Q,
    output Q_bar
);
