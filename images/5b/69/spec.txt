Design a 4-bit shift register with edge detection capability. The module shifts in new data on each clock cycle while maintaining the previous data in a registers array. Upon detecting a rising edge, where the most significant bit transitions from low to high, it asserts an edge output signal, indicating that this edge has been detected. The design includes a reset feature to initialize the shift register and the edge detection flag.
module top_module(
    clk,
    reset,
    shift_in,
    shift_out,
    edge_out
);
