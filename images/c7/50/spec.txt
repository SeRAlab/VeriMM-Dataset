

You are tasked with designing a module to implement a counter that accepts a reset signal, a clock signal, and an initial value. The counter should increment by 1 on each positive edge of the clock signal, unless the reset signal is high, in which case the counter should be set to the initial value. 

Design a Verilog module named "counter" that takes the following inputs and outputs:
- `clk`: a 1-bit clock signal
- `reset`: a 1-bit reset signal
- `init_value`: a 4-bit input value that is used to initialize the counter when the reset signal is high
- `count`: a 4-bit output that represents the current count value of the counter

Your module should use a synchronous always block to implement the counter logic.
