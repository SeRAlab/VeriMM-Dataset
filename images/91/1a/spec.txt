Design a 1-to-4 demultiplexer controlled by a 2-bit select signal, sel. On each rising edge of the clock, the input signal, in, is routed to one of the four outputs (outA, outB, outC, outD) based on the value of sel. Specifically, when sel is '00', '01', '10', or '11', the input is directed to outA, outB, outC, or outD respectively, while the other outputs remain unchanged.
module top_module(input wire clk, input wire sel, input wire in, output wire outA, output wire outB, output wire outC, output wire outD);
