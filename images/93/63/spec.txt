Design a 4-bit shift register that allows for both loading new data and shifting existing data. When the load signal is asserted, the shift register captures the input data. Upon the assertion of the shift signal, the contents of the register are shifted left, with the new data being input on the least significant bit (LSB). The current state of the shift register is continuously available at the output.
module top_module(
    input [3:0] data_in,
    input load,
    input shift,
    output [3:0] out
);
