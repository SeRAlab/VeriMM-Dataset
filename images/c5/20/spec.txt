

You are tasked with designing a module that implements a 3-input logic gate. The module should have the following ports:
- `A`, `B`, and `C`: the three input signals
- `Y`: the output signal

The module should implement the following logic function:
```
Y = (A AND B) OR (A AND C) OR (B AND C)
```
where `AND` is the logical AND operator and `OR` is the logical OR operator.

Design a module that implements this logic function and has the specified input and output ports. Your module should only use basic logic gates (AND, OR, NOT), and should not use any other modules or subcircuits.

Your module should be named `three_input_gate` and should be written in Verilog.
