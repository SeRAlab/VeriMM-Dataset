Design a JK flip-flop with asynchronous preset and clear inputs. The flip-flop should have inputs J, K, clock (clk), preset (preset), clear (clear), and an output Q. The behavior of the JK flip-flop is as follows: if clear is asserted, Q is reset to 0. If preset is asserted, Q is set to 1. On the rising edge of the clock, if J and K are both 0, Q remains unchanged; if J is 1 and K is 0, Q is set to 1; if J is 0 and K is 1, Q is set to 0; if both J and K are 1, Q toggles. Provide the Verilog code for this design.
