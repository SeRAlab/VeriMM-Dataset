Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state U (output 0).
2. state V (output 1).
3. state W (output 0).
4. state X (output 1).

State transitions:
1. From state U: If h = 1, then transition to state V. If h = 0, then transition to state W.
2. From state V: If h = 1, then transition to state X. If h = 0, then transition to state U.
3. From state W: If h = 1, then transition to state X. If h = 0, then transition to state U.
4. From state X: If h = 1, then transition to state V. If h = 0, then transition to state U.

Assume that a one-hot code is used with the state assignment z[3:0] = 0001(U), 0010(V), 0100(W), 1000(X)

Write a Verilog for the signal Z1, which is the input of state flip-flop z[1], for the signal Z3, which is the input of state flip-flop z[3]. Derive the Verilog by inspection assuming a one-hot encoding.

module top_module (
        input [3:0] z,
        input h,
        output reg Z1,
        output reg Z3);
