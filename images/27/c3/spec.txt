Design a synchronous FIFO queue with a configurable depth. The FIFO will have the following features: 
- Inputs: `clk` (clock), `rst` (reset), `wr_en` (write enable), `rd_en` (read enable), and `data_in` (data input).
- Output: `data_out` (data output) and a flag `empty` to indicate if the FIFO is empty.
- The FIFO should be able to hold a maximum of 8 data entries. If `wr_en` is high, `data_in` should be pushed to the FIFO. If `rd_en` is high, the output `data_out` should be the data at the front of the FIFO and should be removed from the FIFO. Implement necessary conditions to handle overflow on write and underflow on read.
