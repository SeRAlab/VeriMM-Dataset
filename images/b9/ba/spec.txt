Design a clock-gated circuit where the output clock signal, clk_gated, is generated based on the input enable signal. When the clk input transitions to a positive edge and the enable signal is high, clk_gated will output a logic high; otherwise, it will output a logic low. This design effectively controls the propagation of the clock signal, allowing it to be turned on or off based on the enable condition, thereby reducing power consumption in synchronous digital systems.
module top_module(
    input clk,
    input enable,
    output reg clk_gated
);
