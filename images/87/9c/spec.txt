Design a circuit that functions as a synchronous set/reset flip-flop with an active-low reset. The module captures the input signal `in` on the positive edge of the clock (`clk`), and when the reset signal (`rst_n`) is low, it sets the output (`out`) to LOW. Otherwise, it reflects the value of the input `in`.
module top_module(
    input in,
    input clk,
    input rst_n,
    output reg out
    );
