Design a 4-bit barrel shifter that allows for left shifting of input data based on a 2-bit shift amount. The module takes a 4-bit input and, depending on the shift_amount, performs the equivalent left shift operation, discarding the appropriate number of least significant bits, with the possibility of shifting up to two bits and resulting in the shifted output. If the shift amount is zero, the output equals the input; if it is one, the least significant bit is dropped; if two, the two least significant bits are dropped; and if the shift amount is three, the output will be zero.
module top_module(
    input [3:0] data,
    input [1:0] shift_amount,
    output reg [3:0] result
);
