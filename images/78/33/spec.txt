Implement a Verilog module that performs the bitwise AND operation on two 8-bit inputs. The module should have the following specifications:
- `clk`: The clock signal.
- `reset`: An active-high synchronous reset signal.
- `start`: An active-high signal that starts the operation.
- `data1`: The first 8-bit input data.
- `data2`: The second 8-bit input data.
- `result`: The output which holds the result of the bitwise AND operation.
- `done`: An active-high signal indicating the completion of the operation.
