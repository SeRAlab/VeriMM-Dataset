Design a 1-bit SRAM cell with the following inputs and outputs:
- Inputs: 
  - `data_in`: The data to be written to the SRAM cell.
  - `write_enable`: A control signal that enables writing to the memory cell.
  - `clock`: A clock signal for synchronous operation.
- Outputs:
  - `data_out`: The data read from the SRAM cell.
The SRAM cell should store the value of `data_in` when `write_enable` is high on the rising edge of the clock; otherwise, it retains its previous value.
