

You are tasked with designing a Verilog module for a register with enable and reset capabilities. The module should have the following inputs:
- `clk`: clock input
- `ena`: enable input
- `d`: data input
- `rst`: reset input
The module should have the following outputs:
- `q`: data output

The register should operate as follows:
- When `rst` is asserted, the output `q` should be reset to 0.
- When `ena` is asserted, the register should be enabled.
- When `ena` is deasserted, the register should be disabled and hold its current value.
- On every positive edge of the clock `clk`, if the register is enabled, the output `q` should be updated with the value of `d`.

Your task is to implement the `reg_ena_rst` module in Verilog. The module should be self-contained and have a maximum of 200 lines of code.
