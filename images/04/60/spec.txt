Design a 16-bit shift register with parallel load capability. The shift register should have a clock input, a reset input, a load input, a 16-bit data input, and a 16-bit output. When the reset is asserted, the output should be set to 0. When the load input is asserted, the data input should be loaded into the shift register. On each clock cycle, if the load input is not asserted, the shift register should shift right by one bit, with the least significant bit (LSB) being filled with a zero.
