Implement an 8-bit shift register with parallel load. The module should shift left or right based on a control signal, and it should also support parallel loading of data.

Module name:
    shift_register
Input ports:
    clk: clock signal
    rst: reset signal
    load: parallel load control signal
    left_right: direction control signal (0 for right, 1 for left)
    data_in: 8-bit parallel input data
    data_serial: 1-bit serial input data
Output ports:
    data_out: 8-bit output data

Implementation:
The module uses an always block that triggers on the rising edge of the clock or the reset signal. Depending on the control signals, it performs the appropriate shift or load operation.
