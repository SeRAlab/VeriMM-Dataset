Design a synchronous flip-flop circuit that captures an input signal on the rising edge of the clock while being controlled by an active-low enable signal. The flip-flop can be asynchronously reset to a LOW output or cleared to a HIGH output. Its output is determined by the state of four internal registers, allowing it to exhibit specific output behaviors based on predefined conditions of these registers. The module can thus function as a sequential element in a digital design, capable of holding and controlling states based on both clock and control signals.

    input in,
    input clock,
    input enable_l,
    input reset,
    input clear,
    output reg out
