Write a Verilog module to implement a 4-bit up/down counter with synchronous reset and mode control. The counter should increment when the mode signal is high and decrement when it is low on each positive clock edge. The reset signal should set the counter to 4'b0000.

module up_down_counter
(
    input clk,
    input reset,
    input mode,
    output reg [3:0] count
);
