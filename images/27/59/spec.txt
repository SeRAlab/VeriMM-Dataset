Design a simple state machine that represents a basic robot navigating a 2D grid. The robot can move in four directions: North, East, South, and West. The state machine should output the current direction and update the state based on a 2-bit input representing the command: 00 for North, 01 for East, 10 for South, and 11 for West. The state should also include a reset signal to return to the initial state (North).
