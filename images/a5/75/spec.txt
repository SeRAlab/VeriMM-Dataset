Design a D-type flip-flop with asynchronous set and clear functionalities. On the rising edge of the clock signal (CLK), if the RESET_B signal is low, the output Q is reset to 0, and Q_N is set to 1. If the SCD (Set Control Direct) input is high, Q is set to 1 and Q_N is set to 0. If the SCE (Clear Enable) input is high, Q is reset to 0 and Q_N is set to 1. In all other cases, the flip-flop captures the value of the D input, and Q_N outputs the complement of D.
module top_module(
    input CLK,
    input D,
    input SCD,
    input SCE,
    input RESET_B,
    output reg Q,
    output reg Q_N
);
