Design an 8-bit data bus multiplexer that takes four 8-bit inputs (A, B, C, D) and selects one of them based on a 2-bit select signal (sel). The output (Y) should be the selected 8-bit input based on the value of sel. If sel is '00', Y should be A, if '01', Y should be B, if '10', Y should be C, and if '11', Y should be D.
