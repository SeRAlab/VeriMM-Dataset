
Design a state-machine-based controller that implements a simple traffic light control system. The state machine should have three states: RED, GREEN, and YELLOW. The system will change states based on a clock input and a reset signal. The sequence is as follows: RED for 5 time units, GREEN for 3 time units, and YELLOW for 2 time units. The state transitions should loop continuously. The outputs should indicate the current state of the traffic light.
