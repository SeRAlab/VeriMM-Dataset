Design a circuit that functions as a clocked flip-flop with additional control signals. The circuit samples the input signal D on the rising edge of CLK, storing it in a register, unless SCE (Store Control Enable) is asserted; in that case, it stores the value of SCD instead. The output Q reflects the value stored in the flip-flop, enabling selective data storage based on external control inputs.
module top_module(
    input  D,
    output Q,
    input  SCD,
    input  SCE,
    input  CLK
);
