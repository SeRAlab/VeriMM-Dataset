Design a circuit that functions as an AXI protocol converter, managing the flow of read address commands between a master and slave interface. The module coordinates the timing of read requests and responses using a state machine with four states: IDLE, CMD_EN, CMD_ACCEPTED, and DONE. When a read request is valid and data is ready, it transitions to CMD_EN to enable the command. If the master is ready and there's a pending next command, it accepts the command or completes the transaction, controlling the signals for readiness and pushing data as needed. The design ensures proper synchronization and efficient handling of read transactions in an AXI-based system.
