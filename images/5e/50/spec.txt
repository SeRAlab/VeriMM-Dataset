Design a register module named IFIDReg that captures and holds the program counter value (PCValue) and the fetched instruction (InstructionRead) on the rising edge of the clock (Clk). This module features control signals for flushing and stalling: when the flushcontrol signal is asserted, the output registers are reset to zero; if the stallcontrol signal is asserted, the module retains the previous output values without updating; otherwise, it updates both output registers with the new input values. This design effectively facilitates instruction fetch and execution stages in a pipelined processor architecture while allowing for control over data flow during pipeline stalls and flush scenarios.
