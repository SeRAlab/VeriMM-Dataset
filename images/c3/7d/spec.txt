

You have been tasked with designing a verilog module for a 4-bit binary adder. The module should have two 4-bit inputs, A and B, and a 1-bit input, Cin, representing the carry-in bit. The module should output a 4-bit sum, S, and a 1-bit carry-out bit, Cout. 

In addition, the module should have a 1-bit input, En, representing the enable signal. When En is high, the module should perform the addition and output the result. When En is low, the module should output all zeros.

You should use the following module template:

```
module binary_adder (
    A   ,
    B   ,
    Cin ,
    En  ,
    S   ,
    Cout
);

    input  [3:0] A   ;
    input  [3:0] B   ;
    input        Cin ;
    input        En  ;
    output [3:0] S   ;
    output       Cout;

    // your code here

endmodule
```
