Implement a wide bus selector that takes a 128-bit input bus and outputs one of the eight 8-bit segments based on a 3-bit selector. The selected output corresponds to the segment of the input bus indexed by the selector value, allowing for selective data extraction from the wide input for further processing or routing.
module top_module(input logic [8*16-1:0] wide_input_bus,
   input logic [3:0] selector,
   output logic [7:0] selected_out);
