Design a 4-bit depth-first search (DFS) state machine that traverses a binary tree. The tree has nodes with values 0 to 15. The state machine should take a 4-bit input representing the current node value and an input signal that indicates when to traverse (traverse signal). When the traverse signal is high, the state machine should push the current node onto a stack (represented by a shift register) and move to the left child (current node - 1). If there is no left child (current node = 0), it should pop the top of the stack and move to the right child (current node + 1) if possible. The state machine should output the current node value and the contents of the stack after each traversal step. It should also have a reset signal to initialize the state machine.
