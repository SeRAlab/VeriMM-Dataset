

You have been tasked with designing a verilog module for a 4:1 multiplexer. The module should have one output and four inputs. The output should be connected to one of the four inputs based on the value of two select inputs. If the value of the select inputs is 00, the output should be connected to the first input. If the value of the select inputs is 01, the output should be connected to the second input. If the value of the select inputs is 10, the output should be connected to the third input. And if the value of the select inputs is 11, the output should be connected to the fourth input. The module should have the following ports:

- `output reg Y`: output signal
- `input A, B, C, D`: input signals
- `input [1:0] S`: select signals

To implement this module, you should use the ternary operator.
