Design a Verilog module that simulates a basic EEPROM cell. The EEPROM cell should have inputs for data (D), a write enable signal (WE), and a clock signal (CLK). When WE is high, the data input should be stored in the EEPROM cell on the rising edge of the clock. When WE is low, the stored data should be output on a separate output (Q) on the next clock cycle. The module should also initialize the stored data to zero at reset.
