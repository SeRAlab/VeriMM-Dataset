
You are tasked with designing a module that takes in three inputs A, B, and C and outputs X. The output X should be high only when all three inputs are high, otherwise, it should be low. You are given a code snippet for inspiration that implements an AND gate with three inputs. You should use this code snippet as a starting point to design your module.

Your task is to create a Verilog module that implements the required functionality. The module should be named `and3_gate` and should have the following ports:

- `A`: input bit, representing the first input to the AND gate.
- `B`: input bit, representing the second input to the AND gate.
- `C`: input bit, representing the third input to the AND gate.
- `X`: output bit, representing the output of the AND gate.

You should also ensure that your module is synthesizable, meaning that it can be translated into hardware by a synthesis tool.
