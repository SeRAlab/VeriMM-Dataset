Design a 4-bit barrel shifter that shifts the input signal A either to the left or to the right based on the direction control input `dir` and the number of positions specified by the input B. When `dir` is high, the shifter performs a left shift, effectively moving bits toward the most significant bit (MSB) and wrapping shifted-out bits to the least significant bit (LSB) side. Conversely, when `dir` is low, it performs a right shift. The amount of shift is determined by the 2-bit input B, allowing shifts of 0 to 3 positions. The output S reflects the result of these shifting operations.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input dir,
    output [3:0] S
);
