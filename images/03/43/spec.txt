Design a 1-bit SRAM cell that can store a single bit of data. The SRAM cell should have the following inputs: `write_enable`, `data_in`, and `read_enable`. When `write_enable` is high, the input `data_in` should be written to the memory cell. When `read_enable` is high, the stored bit should be output to `data_out`. Implement necessary logic to ensure that `data_out` reflects the stored data only when `read_enable` is high.
