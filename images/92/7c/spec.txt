Design a circuit that implements a comparator, which evaluates different status flags (Zero, Overflow, Negative) based on a 3-bit selection input (FLAG). The module outputs a signal S that indicates various comparison results according to defined conditions: it outputs Zero when equal, the negation of Zero when not equal, and interprets Negative for less than, along with combinations of conditions for less than or equal to, greater than or equal to, and greater than. If none of the conditions match, it defaults to a predetermined error output.
module top_module(input			Zero,
			input			Overflow,
			input			Negative,
			input	[2:0]	FLAG,
			output			S);
