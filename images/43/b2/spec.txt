Design a 4-bit up/down counter that increments or decrements its count based on the `up_down` input signal. It also includes a `load` functionality, which allows the user to set the counter to a specified 4-bit value from `data_in`. The counter resets to zero when the `reset` signal is activated. The counting operation occurs on the rising edge of the `clk` signal, ensuring synchronous operation.
module top_module(
    input clk,
    input reset,
    input up_down,
    input load,
    input [3:0] data_in,
    output reg [3:0] count
);
