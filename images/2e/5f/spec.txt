
Design an 8-bit SRAM cell with read and write capabilities. The SRAM cell should include a 2-to-1 multiplexer for selecting between read and write modes. The write enable signal (we) should control whether the data is written to the cell or the data is read from it. Implement the SRAM cell such that it can store 8 bits of data, and provide a mechanism to read this data when required.
