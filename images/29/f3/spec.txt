Design a 16-bit SRAM cell that supports read and write operations. The SRAM cell should have the following inputs: a 16-bit data input (data_in), a 16-bit address input (addr), a write enable signal (we), and a clock signal (clk). When the write enable signal is high, the data should be written to the specified address on the rising edge of the clock. When the write enable signal is low, the data at the specified address should be available at the output (data_out) on the next clock cycle.
