

You have been tasked with designing a Verilog module that implements a simple counter. The module should have a 32-bit input port called `clk` for the clock signal and a 32-bit output port called `count` for the counter value. The counter should start at 0 and increment on every rising edge of the clock signal. The module should also have a 1-bit input port called `reset` that resets the counter to 0 on the next rising edge of the clock signal when it is asserted.

Write a Verilog module that implements the counter as described above. Your module should be named `counter` and should be contained within a single Verilog file of no more than 200 lines of code. You may use any Verilog constructs or modules that you wish, but the `counter` module should be self-contained and not rely on any external modules or parameters.
