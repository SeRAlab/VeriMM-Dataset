When FSM_selector_D is high, the value of D is added to the current value in Q_reg; if it is low, Q_reg retains its previous value. Additionally, the module includes an asynchronous reset feature (AR) that sets Q_reg to zero when activated. The output Data_A indicates whether the sum of the least significant 8 bits of Q_reg and D exceeds the maximum value for an 8-bit number (255), providing a flag for overflow.

    input FSM_selector_D,

);
