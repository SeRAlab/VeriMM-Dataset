
Design a simple EEPROM cell model in Verilog that can store a single bit (0 or 1). The EEPROM cell should have the following functionality:
- An input `data_in` to write data.
- A `write_enable` signal to control the writing process.
- An output `data_out` to read the stored value.
- A `read_enable` signal to control the reading process.

When `write_enable` is high, the `data_in` value should be written to the cell. When `read_enable` is high, the stored value should be presented on `data_out`. The cell should retain the value until a new write occurs.
