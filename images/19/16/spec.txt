
Design an I2C master controller in Verilog that can initiate a start condition, send data, and generate a stop condition. The I2C master should have inputs for a clock signal (clk), a reset signal (rst), a data input (data_in), and an acknowledgment input (ack). The outputs should be the data output (data_out), a start signal (start), and a stop signal (stop). The controller should operate in a simple state machine fashion.
