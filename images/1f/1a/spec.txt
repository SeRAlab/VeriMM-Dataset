Design a Verilog module for a simple SD card interface controller. The controller should manage read and write operations to the SD card. It should have an input signal for command (CMD), a clock signal (CLK), and data input/output lines (DATA). The controller should respond to a write command by taking data from the DATA lines and storing it internally, and respond to a read command by placing stored data onto the DATA lines. Assume the commands are simple: a '1' for writing data and a '0' for reading data. The controller should have a reset signal to initialize the internal state.
