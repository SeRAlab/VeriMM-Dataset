

You are tasked with designing a verilog module that takes in five inputs and provides one output. The module should be named `logic_gate` and should implement the following logic:
- If `A1` and `A2` are both high, and `B1` and `B2` are both low, then `X` should be high.
- If `C1` is high, then `X` should be low.
- In all other cases, `X` should be low.

You may use any verilog primitives or gates available to you. Ensure that your module has the correct input and output ports, and that all necessary supply voltage signals are included.
