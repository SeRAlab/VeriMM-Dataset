
Design a Verilog module that implements a linear regression model. The module should take three inputs: two feature values (x1 and x2) and a bias term (b), all as signed 8-bit integers. It should output the predicted value (y) as a signed 16-bit integer. The linear regression equation is: 
y = w1 * x1 + w2 * x2 + b.
Assume constants w1 and w2 are given as signed 8-bit integers.
