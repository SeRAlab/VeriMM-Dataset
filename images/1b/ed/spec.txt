Design a Verilog module that calculates the Internet Protocol (IP) checksum for a given 16-bit data packet. The module should take a 16-bit input and output a 16-bit checksum. The checksum is calculated by summing all 16-bit words of the packet, with carry-over added back into the least significant bit. The final checksum is the one's complement of the sum. The module should be able to handle multiple packets and provide an output checksum for each input.
