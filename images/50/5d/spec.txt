Design a one-bit wide, 2-to-1 multiplexer that selects between input A and a constant value based on the value of input B. When B is 1, the output Y is assigned the value of A; when B is 0, the output Y takes the value of B (which is 0). The design also accounts for circumstances where the input may not meet expected conditions, setting Y to 0 in such cases.
module top_module(
    input A,
    input B,
    output Y
);
