Design a forwarding unit for a pipelined processor to manage data hazards by selecting appropriate data sources for two input registers (rs and rt). The unit outputs two signals, forward_a_sel and forward_b_sel, which indicate whether to forward results from the execution stage (EX) or write-back stage (WB) back into the input registers based on conditions involving register write enable signals and active register values. Specifically, it prevents stale data from being used when newer data is available, thereby ensuring data consistency and improving the performance of the pipeline.
