

You are tasked with designing a verilog module for a digital circuit that takes in multiple input signals and produces a single output signal. The module is called `mux21` and has the following inputs and outputs:

Inputs:
- `A`: a single bit input signal
- `B`: a single bit input signal
- `S`: a single bit input signal representing the select signal

Outputs:
- `MO`: a single bit output signal representing the selected signal

The module should take in the input signals `A` and `B` and output the selected signal based on the value of the select signal `S`. If `S` is 0, the output should be `A`. If `S` is 1, the output should be `B`.

Your task is to write the verilog code for the `mux21` module.
