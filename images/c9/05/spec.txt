Please act as a professional Verilog designer. Create a module that implements a 4-bit synchronous up-counter with enable and reset inputs. The counter should increment by 1 on each positive edge of the clock signal when the enable input is high. When the reset input is high, the counter should be reset to 0. The module should have 3 inputs and 1 output, where the inputs are clk, reset, enable, and the output is count. You should use an always block to define the state transition of count. The port connections of instantiated modules should be shown in the module declaration.
