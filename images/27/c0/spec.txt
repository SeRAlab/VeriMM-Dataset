
Design a combinational logic circuit that implements the merge operation of the merge sort algorithm. The circuit should take two sorted arrays of 4 bits each as input and produce a single sorted output array of 8 bits. The inputs will be `A` and `B`, each represented as 4 bits (A3 A2 A1 A0 and B3 B2 B1 B0). The output `O` will be an 8-bit array (O7 O6 O5 O4 O3 O2 O1 O0).
