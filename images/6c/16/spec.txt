Design a synchronous 64-word data memory module with a 32-bit wide data bus. The module has a write enable signal (we) that allows writing to the specified memory address on the rising edge of the clock. When the write enable is active, the data input (wd) is stored in the memory at the address specified by the upper bits of addr. The output (rd) provides the data stored at the address during read operations, utilizing a simple address decoding mechanism. The memory is organized as 64 memory locations of 32 bits each, with address inputs effectively using the upper bits to index the memory.
module top_module(input clk, we,
                input [31:0] addr, wd,
                output [31:0] rd);
