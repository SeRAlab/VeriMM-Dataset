Design a data memory module with a 32-bit wide data bus, capable of storing and retrieving data in a memory array of 1024 locations. The module takes a 10-bit memory address and control signals for byte enable (be), write enable (we), and clock (clk). On a positive clock edge and if write enable is active, it allows selective writing of data based on the byte enable signal, which determines which bytes of the 32-bit input data are written to the specified address. The module continuously outputs the data stored at the provided address.
module top_module(addr,be,din,we,clk,dout);
