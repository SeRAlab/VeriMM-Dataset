

You are tasked with writing a module that will take in three input values and output their sum. However, there is a catch: the input values are in binary format and the output must also be in binary format. You must write the module in Verilog and ensure that it meets the following requirements:

- The module should be named "binary_adder"
- The module should have three input ports, each with a width of 4 bits
- The module should have one output port with a width of 5 bits
- The output should be the binary sum of the input values, with the least significant bit (LSB) on the right and the most significant bit (MSB) on the left

Write the Verilog code for the "binary_adder" module that meets these requirements.
