
Design a clock-gated D flip-flop module. The module should include a data input (D), a clock input (clk), a clock enable input (ce), and a reset input (rst). When the reset is high, the output (Q) should be forced to 0. When the clock enable (ce) is high, the D input should be sampled on the rising edge of the clock. If the clock enable is low, the output should hold its previous value.
