
Design a simple Stop-and-Wait ARQ (Automatic Repeat reQuest) protocol in Verilog. This protocol includes a sender and a receiver. The sender transmits a data packet and waits for an acknowledgment (ACK) from the receiver before sending the next packet. If the sender does not receive an ACK within a certain time frame, it will resend the packet. Implement a finite state machine (FSM) to handle the sending and receiving of packets and acknowledgments.
