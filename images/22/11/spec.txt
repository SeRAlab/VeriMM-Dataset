
Design a Verilog module for a 1-bit EEPROM cell. The EEPROM cell should have the following functionalities:
1. A write enable signal (`we`), when high, allows writing a new value to the cell.
2. An input data signal (`d_in`) to write data to the EEPROM cell.
3. A read enable signal (`re`), when high, allows reading the value stored in the cell.
4. An output data signal (`d_out`) that provides the current value of the cell.
5. The cell should maintain its state until a write operation occurs.

The module should also handle asynchronous reset (`rst`) that sets the stored value to `0`.
