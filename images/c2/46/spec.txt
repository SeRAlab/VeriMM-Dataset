

You are tasked with designing a verilog module that implements a 4-bit binary counter. The module should have the following inputs and outputs:
- `clk`: a clock input
- `reset`: a reset input
- `enable`: an enable input
- `out`: a 4-bit output representing the count

The counter should increment on every rising edge of the `clk` input when the `enable` input is high. When the `reset` input is high, the counter should reset to 0. The `out` output should represent the current count in binary.

Design the verilog module `binary_counter` that implements the above specifications.
