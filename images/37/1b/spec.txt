
Create a simple SATA controller state machine that has three states: IDLE, ACTIVE, and ERROR. The controller will transition between these states based on a single input signal `start`. When in the IDLE state, if `start` is high, it transitions to the ACTIVE state. From the ACTIVE state, if `start` goes low, it transitions back to IDLE. If an ERROR condition is detected (for simplicity, we can use a signal `error` that goes high), it transitions to the ERROR state. The state machine should also provide the current state as output.
