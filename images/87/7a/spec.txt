Design a 2-to-1 multiplexer that selects between two input data signals based on the `sel` control signal. When `sel` is LOW (0), the output will reflect the value at `data_in_0`, and when `sel` is HIGH (1), the output will adopt the value from `data_in_1`. The module incorporates a combination of logical operations and an instantiated cell to achieve the desired selection functionality.
module top_module(
    input sel,
    input data_in_0,
    input data_in_1,
    output reg data_out
);
