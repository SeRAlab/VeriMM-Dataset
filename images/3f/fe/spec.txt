Design a combinational logic circuit that implements a simple Huffman encoding functionality. The circuit should take a 4-bit input representing a symbol and output the corresponding 3-bit Huffman code based on a predefined Huffman tree. The mapping is as follows: 
Symbol 0 -> 000
Symbol 1 -> 001
Symbol 2 -> 010
Symbol 3 -> 011
Symbol 4 -> 100
Symbol 5 -> 101
Symbol 6 -> 110
Symbol 7 -> 111
If the input symbol is not in the range 0-7, the output should be 111 (indicating an invalid symbol).
