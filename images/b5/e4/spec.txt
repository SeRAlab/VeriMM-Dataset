Design a synchronous RAM module that supports reading and writing operations based on a clock signal. The module has a configurable data width of 36 bits and an address width of 8 bits, allowing for storage of up to 256 words of data. When the write enable signal (wren) is asserted, it writes the input data to the specified write address at the rising edge of the clock. Simultaneously, it continuously reads from the address specified by the read address input and outputs the corresponding data to the output q.
module top_module(data,rdaddress,wraddress,wren, clock,q);
