Design a synchronous JK flip-flop circuit. The module takes inputs J, K, and CLK, where J and K control the state of the flip-flop. On each positive edge of the clock (CLK), the output Q is updated based on the combination of J and K: if J is high and K is low, Q is set to 1; if J is low and K is high, Q is set to 0; if both are high, Q toggles its state. The output Q_B is the complement of Q.
