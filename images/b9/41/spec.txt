Design a circuit that swaps the nibbles (4-bit segments) of a 32-bit input vector. The module takes a 32-bit input and rearranges its segments so that the first 8 bits become the last, the second 8 bits move to the third position, the third 8 bits go to the second position, and the last 8 bits move to the first position. Thus, the output vector outputs the input vector with its nibbles swapped in a specified order.
module top_module(
  input [31:0] in_vector,
  output reg [31:0] out_vector
);
