Design a divide-by-4 circuit that takes a 2-bit binary input and produces a 2-bit binary output. The output should update on the rising edge of a clock signal, effectively dividing the input by 4. If the input is less than 4, the output should represent the quotient of the division. If the input is 4 or more, the output should saturate to the maximum value for 2 bits (i.e., 3).
