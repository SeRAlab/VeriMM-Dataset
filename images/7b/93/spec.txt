It also features a parity register that maintains the running XOR of the adder's output. The parity register is reset synchronously on a high reset signal and updated on each clock cycle. Finally, the module outputs the result of subtracting the adder's output from the current parity value, providing both the addition result and a dynamic parity check in a single design.
