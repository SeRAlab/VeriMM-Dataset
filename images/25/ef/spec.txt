Design a 16-bit Linear Feedback Shift Register (LFSR) in Verilog that generates pseudo-random numbers. The LFSR should use the polynomial \(x^{16} + x^{14} + x^{13} + x^{11} + 1\) and have an active low reset input. The output of the LFSR should be 16 bits and should update with each clock cycle unless reset. Implement a 'next' signal to advance the LFSR state.
