
Design a fan speed control system that adjusts the fan speed based on temperature readings. The fan has three speed levels: low, medium, and high. The system should take a temperature input and adjust the fan speed according to the following criteria:
- If the temperature is below 20 degrees Celsius, set the fan speed to low (00).
- If the temperature is between 20 and 30 degrees Celsius, set the fan speed to medium (01).
- If the temperature is above 30 degrees Celsius, set the fan speed to high (10).
The system should also have a reset functionality to return the fan speed to low when activated.
