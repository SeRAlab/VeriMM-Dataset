
Design an 8-bit ADC (Analog to Digital Converter) module in Verilog that takes an 8-bit binary input representing an analog voltage and converts it into a corresponding digital value. The module should produce an output that represents the voltage level in a range from 0 to 255. Additionally, it should have an enable signal that allows the ADC to process the input only when enabled. When the enable signal is low, the output should be held at the last valid value.
