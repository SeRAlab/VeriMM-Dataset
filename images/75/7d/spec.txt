Design a 4-to-1 multiplexer that selects one of four input signals (A, B, C, D) based on two selection lines (S0 and S1). The output (Y) will reflect the value of the chosen input: if S1 and S0 are both low, Y outputs A; if S1 is low and S0 is high, Y outputs B; if S1 is high and S0 is low, Y outputs C; and if both S1 and S0 are high, Y outputs D.
module top_module(
    input A,
    input B,
    input C,
    input D,
    input S0,
    input S1,
    output Y
);
