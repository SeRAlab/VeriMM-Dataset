
Design a LIFO stack in Verilog. The stack should have the following characteristics:
- A depth of 8 entries.
- It should support `push` and `pop` operations.
- The `push` operation should store a new value into the stack if it is not full.
- The `pop` operation should remove and return the top value from the stack if it is not empty.
- There should be an output signal to indicate if the stack is empty or full.
