
Design a Stop-and-Wait flow control protocol using Verilog. The sender transmits one data packet at a time and waits for an acknowledgment (ACK) from the receiver before sending the next packet. The system should have the following inputs and outputs:
- Inputs: `data_in` (5-bit data input), `send` (1-bit signal to initiate sending data), `ack` (1-bit acknowledgment signal from receiver)
- Outputs: `data_out` (5-bit data output sent to the receiver), `send_done` (1-bit signal indicating that the data has been sent and acknowledged)
