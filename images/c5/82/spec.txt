

You have been tasked with designing a module in Verilog to implement a 2-to-1 multiplexer with an enable signal. The module should take two input signals, A and B, and an enable signal, E, and output either A or B depending on the value of E. If E is high, the output should be A, and if E is low, the output should be B.

You are required to implement this module within 200 lines of Verilog code. You may assume that the input signals A, B, and E are all single-bit signals.

Write a Verilog module named mux_2to1_enable that implements the 2-to-1 multiplexer with an enable signal. The module should have the following inputs and outputs:

- input A: a single-bit input signal
- input B: a single-bit input signal
- input E: a single-bit enable signal
- output Y: a single-bit output signal

Your module should adhere to the following specifications:

- When E is high (1), the output Y should be equal to A.
- When E is low (0), the output Y should be equal to B.
- Your module should be synthesizable and should not contain any procedural assignments or delays.
- Your module should be designed to minimize the number of gates used.
