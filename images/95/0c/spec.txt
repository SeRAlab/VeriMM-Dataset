Design a state machine that controls a note-playing process in a musical application. The module transitions between four states: RESET, NEW_NOTE, WAIT, and NEXT_NOTE. Upon receiving a play signal while in the RESET state, it moves to NEW_NOTE, where it outputs a signal indicating a new note has started. In the WAIT state, it checks if the note is done playing; if so, it transitions to NEXT_NOTE to prepare for the next note, or it remains in WAIT if the note is still active. The state machine returns to RESET if the play signal is not active. This logic facilitates the sequential processing of musical notes based on timing and play control.
