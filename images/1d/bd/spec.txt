
Design a combinational logic circuit in Verilog that implements a simple Logistic Regression model. The circuit should take a 4-bit input vector `X` (features) and a 4-bit weight vector `W`, compute the dot product of `X` and `W`, and then apply the sigmoid function to produce a single output bit `Y`. The sigmoid function can be approximated in this context as `Y = 1 / (1 + exp(-Z))`, where `Z` is the dot product. For simplicity, the sigmoid output will be represented as a single bit, where `Y` is `1` if the output is greater than or equal to `0.5`, and `0` otherwise.
