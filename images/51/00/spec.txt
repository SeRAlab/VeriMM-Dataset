Design a synchronous counter that operates on a clock signal (CLK) and supports an asynchronous reset (RST). The counter is 8 bits wide and increments its value on each positive clock edge, except when the reset is active, in which case it initializes to zero. Specifically, the counter increments in a linear fashion for values 0 to 2 (inclusive) and wraps back to 0 when reaching the maximum value of 255 (0xFF). For any value between 3 and 254, it continues to increment. This design enables counting while providing a reset capability for initializing the count value.
