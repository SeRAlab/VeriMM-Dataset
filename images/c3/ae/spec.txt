

You have been tasked with designing a module that takes in a 4-bit input signal `data_i`, a write enable signal `we_i`, a clock signal `clk_i`, and a reset signal `rst_i`. The module should output a 4-bit signal `data_o` and a flag signal `flag_o`. The `data_o` output should be the input `data_i` shifted left by one bit position on every rising edge of the clock signal, with the least significant bit being replaced by the value of `we_i`. The `flag_o` output should be set to 1 if the output `data_o` is equal to the input `data_i` on any given clock cycle.

Write a verilog module that implements this functionality.
