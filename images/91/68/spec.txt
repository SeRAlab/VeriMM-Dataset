Design a 4-bit adder/subtractor module that performs addition or subtraction on two 4-bit inputs A and B, controlled by the SUB input signal. When SUB is 0, the module computes the sum of A and B, while producing a carry output if there is an overflow. When SUB is 1, it computes the difference A minus B, generating a carry output to indicate a borrow condition if A is less than B.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input SUB,
    output reg [3:0] SUM,
    output reg CARRY
);
