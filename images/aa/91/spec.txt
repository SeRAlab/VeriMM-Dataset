Design a 2-to-4 line decoder. The module takes a 2-bit input and activates one of the four outputs corresponding to the binary value of the input, with only one output high at any given time and all others low. Specifically, when the input is 00, output 0 is activated; when the input is 01, output 1 is activated; for input 10, output 2 is activated; and for input 11, output 3 is activated.
module top_module(
    input [1:0] in,
    output reg [3:0] out
