Design a 2-stage pipeline processor that accepts 8-bit input data. The first stage consists of a register that holds the input data and a combinational logic that performs an addition of 1 to the data. The second stage also has a register which holds the result of the first stage and outputs it as a final result after a clock cycle. The module should have an enable signal to control the loading of data into the registers. When the enable signal is low, the output should remain stable. The module has the following ports: 
- input [7:0] data_in,
- output reg [7:0] data_out,
- input clk,
- input enable.
