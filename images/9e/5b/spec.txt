Design a LED controller that utilizes a clock signal to create a timed sequence for illuminating four sets of LEDs. The module counts clock cycles and, based on the counter value, turns on each LED group (leds_0, leds_1, leds_2, and leds_3) for a specific duration before resetting. The output LEDs turn on and off in a predefined pattern, creating a visual effect with a programmable timing interval. The counter resets when the reset (rst) input is activated, ensuring a controlled start state.
module top_module(
  input clk,
  input rst,
  output reg [3:0] leds_0,
  output reg [3:0] leds_1,
  output reg [3:0] leds_2,
  output reg [3:0] leds_3
);
