Design a Verilog module for an 8-bit loadable counter with enable and synchronous reset. The counter should load the input value on each positive clock edge when the load signal is high, increment when the enable signal is high, and reset to 8'b00000000 when the reset signal is high.

module loadable_counter
(
    input clk,
    input reset,
    input enable,
    input load,
    input [7:0] data_in,
    output reg [7:0] count
);
