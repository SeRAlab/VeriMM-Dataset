
Design an 8-channel DMA (Direct Memory Access) controller that can select one of the 8 channels based on a 3-bit channel select input. The controller should have a clock input, a reset input, and an enable input. When enabled, the DMA controller should output the selected channel number (0 to 7) on a 3-bit output. If reset is active, the output should be set to 0. The controller should also have a busy signal that is high when a channel is in use and goes low when not in use.
