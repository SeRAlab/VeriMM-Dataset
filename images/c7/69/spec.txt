

You have been tasked with designing a verilog module that implements a 4-bit counter with synchronous reset. The module should have the following inputs and outputs:

Inputs:
- `CLK`: a clock signal with a frequency of 50 MHz
- `RST`: a synchronous reset signal that resets the counter to 0 when high

Outputs:
- `Q`: a 4-bit output that represents the current count value

Design the verilog module that implements the 4-bit counter with synchronous reset. Ensure that the module is synthesizable and meets the timing requirements for the given clock frequency.
