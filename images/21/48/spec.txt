
Design a Verilog module for a 1T1C (one-transistor, one-capacitor) Flash memory cell. The module should have the following functionality: 
- It should accept a control signal `write` and a 1-bit `data_in` to write to the memory cell.
- It should accept a control signal `read` and output the stored value as `data_out`.
- The memory cell should retain its value until a new write operation is performed.
