Design a 16-QAM modulator that takes 4 bits of input and outputs the corresponding I and Q components. The input bits are to be mapped as follows:  
0000 -> (0, 0)  
0001 -> (1, 0)  
0010 -> (0, 1)  
0011 -> (1, 1)  
0100 -> (0, -1)  
0101 -> (1, -1)  
0110 -> (-1, 0)  
0111 -> (-1, 1)  
1000 -> (0, 0)  
1001 -> (1, 0)  
1010 -> (0, 1)  
1011 -> (1, 1)  
1100 -> (0, -1)  
1101 -> (1, -1)  
1110 -> (-1, 0)  
1111 -> (-1, 1)
