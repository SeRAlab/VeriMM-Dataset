Design a 1-bit DRAM cell in Verilog. The DRAM cell should have a data input (D), a read enable (RE), a write enable (WE), and an output (Q). When WE is high, the input data D should be written to the cell. When RE is high, the stored data in the cell should be made available at the output Q. If both RE and WE are low, the output Q should maintain its previous state.
