

You are tasked with designing a Verilog module that reads in a 4-bit input `x` and outputs the result of multiplying that input by 3. Implement this module using a combinational logic circuit.

Your module should have the following inputs and outputs:
- `input [3:0] x`: a 4-bit input
- `output [5:0] y`: a 6-bit output representing the result of `x * 3`

To complete this task, you may use any Verilog operators or constructs that you deem necessary. 

Implement your solution within a module called `mult_by_3`.
