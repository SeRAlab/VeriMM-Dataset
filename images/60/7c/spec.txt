Design a 128-byte (16 words of 64 bits each) FIFO (First-In, First-Out) buffer that allows data transfer between a slave and master interface. The module accepts clock and reset signals, along with a valid signal and data input from the slave side. It indicates readiness for slave data input and manages data output validity based on the master’s readiness. The FIFO supports read and write operations, updating internal memory and read/write addresses accordingly. The output data width is 8 bits, extracted from 64-bit memory locations based on the read address. The module also maintains a data count to ensure storage limits are respected, allowing up to 120 bytes to be written into the buffer.
