Implement a 2x2 matrix multiplication module in Verilog. The module should take in two 2x2 matrices as input and produce the resulting 2x2 matrix as output. The inputs and outputs should be 8-bit wide, where each matrix element is 8 bits. The multiplication should be performed as follows:
Result[0][0] = A[0][0] * B[0][0] + A[0][1] * B[1][0]
Result[0][1] = A[0][0] * B[0][1] + A[0][1] * B[1][1]
Result[1][0] = A[1][0] * B[0][0] + A[1][1] * B[1][0]
Result[1][1] = A[1][0] * B[0][1] + A[1][1] * B[1][1]
