
Create a Verilog module that performs a simple 3x3 convolution operation on a 2D input matrix. The input matrix will be a 2x2 pixel image, and the kernel will be a 3x3 matrix. The module should take the input image and the kernel as inputs and output the single pixel result after convolution. The input image pixels will be represented as 8-bit values and the kernel will also be 8-bit values. Assume zero padding is applied such that the output is a single pixel.
