Design a simple memory allocator that manages a fixed-size memory pool. The allocator should support two operations: `malloc` to allocate a block of memory and `free` to deallocate a block of memory. The memory pool can be represented as an array of bytes, and the `malloc` operation should find a contiguous block of free bytes of a specified size. The `free` operation should mark a previously allocated block as free again. The design should also include a status output to indicate success or failure of memory operations.
