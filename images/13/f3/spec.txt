
Create a Verilog module that implements a simple Recurrent Neural Network (RNN) cell. The RNN should take an input `x` and a previous hidden state `h_prev`, then use weights and biases to compute a new hidden state `h`. The update rule for the RNN can be simplified as:
h = tanh(Wxh * x + Whh * h_prev + b)
where Wxh and Whh are weight matrices and b is the bias. Assume Wxh and Whh are fixed for this problem.
