Design a 4-to-1 multiplexer that selects one of four input signals based on a 2-bit select line. The module outputs the chosen input signal, where the selection is defined by the value of the `sel` input: when `sel` is 00, the output is the first input; when 01, the second; when 10, the third; and when 11, the fourth input. The output is registered and updated accordingly in response to changes in either the select line or the input data.
module top_module(
    input [3:0] data_in,
    input [1:0] sel,
    output reg data_out
);
