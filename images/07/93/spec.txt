Implement a JK latch in Verilog. The JK latch should have inputs J and K, a clock signal (CLK), and outputs Q and QN. It should behave such that:  
1. If J and K are both 0, the output state remains the same.  
2. If J is 1 and K is 0, the output Q is set to 1.  
3. If J is 0 and K is 1, the output Q is set to 0.  
4. If J and K are both 1, the output Q toggles its state on each clock edge.  
Make sure to include necessary initial conditions and sensitivity to the clock.
