Design a 16-entry, 48-bit wide read-only memory (ROM) that outputs stored data based on a 4-bit input address. The module initializes specific addresses with predefined 48-bit values, while the remaining addresses are set to a default state of all bits being high (0xFFFF). When the specified address is provided, the corresponding 48-bit data stored in the ROM is output.
module top_module(input [15:0] addr, output [47:0] data);
