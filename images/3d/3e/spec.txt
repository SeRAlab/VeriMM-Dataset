Design a simple PCIe endpoint controller that receives a command signal to read or write data. The controller should have a 4-bit address input, a 32-bit data input/output, a command input (0 for read, 1 for write), and a clock signal. The output data should be driven based on the command signal and the address. If the command is a read, the data from a pre-defined memory should be outputted based on the address. If the command is a write, the data should be stored in the memory.
