Design a 5-stage pipeline processor that implements a simple instruction set: ADD, SUB, AND, OR, and NOT. Each stage of the pipeline should consist of Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). The processor should support 2-input operations for ADD, SUB, AND, and OR, while NOT should work with a single input. The output of the processor should provide the result of the operation based on the inputs and the opcode of the instruction. The processor should handle hazards using a simple stalling mechanism.
