Design a 16-bit Analog to Digital Converter (ADC) that takes a 16-bit input data and produces a 4-bit output which represents the quantized level of the input. The input range is from 0 to 65535 (16-bit unsigned), and the output levels are from 0 to 15 (4-bit unsigned). The output should be calculated as the integer division of the input by 4096 (65536/16).
