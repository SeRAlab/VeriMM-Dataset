Design a synchronous SRAM (Static Random Access Memory) module with a 16-bit data width and a 12-bit address space, allowing for read and write operations. On each rising edge of the clock, if the write enable (wren) signal is active, the module stores the provided data at the specified write address. If the wren signal is inactive, it outputs the data from the memory location indicated by the read address. This module facilitates efficient data storage and retrieval in digital systems, suitable for applications requiring fast access to a small to moderate amount of memory.
