Design a 1-bit SR flip-flop using Verilog. The flip-flop should have two inputs (S and R) and one output (Q). The flip-flop should have the following behavior: when S=1 and R=0, Q should be set to 1; when S=0 and R=1, Q should be reset to 0; when S=0 and R=0, Q should retain its previous value; when S=1 and R=1, the state is considered invalid. The design should use a clock input to enable state changes on the rising edge of the clock.
