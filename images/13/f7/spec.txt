Design a combinational logic circuit that implements a simplified version of the A* search algorithm. The circuit takes as input a 4-bit heuristic value (H) and a 4-bit cost value (C), and outputs a 5-bit evaluation value (E) calculated as E = H + C. The evaluation value should be the sum of the heuristic and cost inputs. The circuit should also include an enable signal (EN) that controls whether the output is valid (1) or not (0).
