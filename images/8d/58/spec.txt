Develop a Verilog module for a 6-bit down counter with a synchronous negative edge triggered reset, an enable signal, and a synchronous active high load signal. The counter should count down by one when enabled.
(1) reset: Resets the counter to all ones.
(2) enable: Enables the counter to count down by one.
(3) load: Loads the counter with a 6-bit value from input "data".
(4) data: 6-bit data input to the counter.
(5) q: The current count of the counter.
