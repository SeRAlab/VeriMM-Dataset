Design a synchronous 4-bit counter that counts upward from 0 to 9. On reaching the count of 9, the counter resets to 0 and sets a 'done' signal high, indicating the count is complete. The counter can be reset asynchronously via the 'rst' input, which sets the count back to 0 and clears the 'done' signal. The 'done' signal is also asserted in a combinational block whenever the count equals 9.
module top_module(
    input clk,
    input rst,
    output reg [3:0] count,
    output reg done
);
