Implement a 32-bit register with enable and synchronous reset. The module should load a 32-bit input when enable is asserted and reset the register synchronously when reset is asserted.

Module name:
    register_32bit
Input ports:
    clk: clock input
    reset: synchronous reset input
    enable: enable input
    data_in: 32-bit input
Output ports:
    q: 32-bit output

Implementation:
The module uses an always block that triggers on the clock's positive edge. It loads the data input when enable is asserted and resets the register when reset is asserted.
