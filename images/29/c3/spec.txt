
Create a Verilog module for a basic EEPROM memory cell. The EEPROM cell should be able to perform the following operations:
1. Write data to the cell when the write enable signal is high.
2. Read data from the cell when the read enable signal is high.
3. The cell should retain its data when neither read nor write operations are performed.
The data width of the EEPROM cell should be 8 bits.
