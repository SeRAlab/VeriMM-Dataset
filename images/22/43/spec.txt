Design a 16-bit SRAM cell that can read and write data. The SRAM cell should have the following inputs: a 16-bit data input (data_in), a read enable signal (read_en), a write enable signal (write_en), a 4-bit address input (addr), and a 16-bit data output (data_out). The SRAM should have a memory array of size 16x16 bits, supporting read and write operations based on the control signals.
