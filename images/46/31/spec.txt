Design a circuit that determines the maximum value between two 8-bit inputs, A and B. The output, max, will hold the greater of the two values; if both values are equal, max will output a fixed value of 0. This functionality effectively serves as a comparator that outputs the larger input or a default when the inputs are equal.

    input [7:0] A,
    input [7:0] B,
    output reg [7:0] max
);
