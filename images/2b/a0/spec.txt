
Design a parameterized FIFO (First-In-First-Out) queue in Verilog. The FIFO should have a configurable depth and be able to support enqueue and dequeue operations. The module should have the following ports:
- `clk`: Clock signal
- `rst`: Reset signal
- `enq`: Enqueue signal
- `deq`: Dequeue signal
- `data_in`: Data input for enqueue
- `data_out`: Data output for dequeue
- `full`: Output signal indicating the FIFO is full
- `empty`: Output signal indicating the FIFO is empty
