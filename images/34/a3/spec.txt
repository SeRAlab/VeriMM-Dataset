Design a simple EEPROM cell with Read and Write operations. The EEPROM cell should have the following inputs: a clock signal (clk), a write enable signal (we), a data input (data_in), and a data output (data_out). When the write enable signal is high, the data input should be stored in the EEPROM cell on the rising edge of the clock. When the write enable signal is low, the stored data should be output as data_out.
