Design a Verilog module that models a 16-bit register with synchronous clear. The module should have an input clock signal (clk), an input clear signal (clr), a 16-bit input data signal (d), and a 16-bit output signal (q). On the rising edge of the clock, if clear is high, q should be set to 0, otherwise q should be set to the value of d.
module register (
  input clk,
  input clr,
  input [15:0] d,
  output reg [15:0] q);
