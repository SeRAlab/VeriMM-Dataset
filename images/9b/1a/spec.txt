Design a 4-bit up/down counter that toggles its counting direction on each clock cycle when enabled. The counter resets to zero when the reset signal is asserted. It counts up from 0 to 15 and down from 15 to 0, with the direction alternated on every count when enabled. The module also outputs the current count and a direction signal that indicates whether the counter is counting up (1) or down (0).
module top_module(
  input clk,
  input rst,
  input en,
  output reg [3:0] count,
  output reg dir
);
