Design a FIFO (First-In, First-Out) buffer with an 8-entry capacity, capable of storing 8-bit wide data. It operates on a clock signal, requiring an active low reset signal. The module takes input data along with a validity signal; when both are asserted and the buffer is not full, it writes new data into the buffer. It outputs the oldest data when requested, indicated by the out_ready signal, along with an output validity signal whenever there is data available to read. The design manages read and write pointers, along with a count of the current number of items in the buffer, ensuring proper data flow control.
module top_module(
  input wire clk,
  input wire nrst,
  input wire [7:0] in_data,
  input wire in_valid,
  output wire in_ready,
  output reg [7:0] out_data,  // Change to reg type
  output wire out_valid,
  input wire out_ready
);
