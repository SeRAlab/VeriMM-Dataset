

You are tasked with implementing a verilog module that takes in two 8-bit inputs and a carry-in bit and outputs their sum along with a carry-out bit. Your module should be called `eight_bit_adder` and have the following interface:

Inputs:
- `a`: an 8-bit input
- `b`: an 8-bit input
- `cin`: a single bit input representing the carry-in

Outputs:
- `s`: an 8-bit output representing the sum of `a`, `b`, and `cin`
- `cout`: a single bit output representing the carry-out

You should use the built-in `+` operator to perform the addition.
