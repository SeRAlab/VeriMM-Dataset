Design a gated D flip-flop with an enable signal that controls whether the flip-flop is allowed to take its input. The module generates an output signal, ENCLK, which is set to the value of the test input TE on the positive edge of the clock (CLK) when the enable signal (EN) is high. If EN is low, the output ENCLK will consistently be driven LOW. This functionality ensures that the flip-flop retains its state unless enabled, making it suitable for selective data storage in synchronous circuits.
