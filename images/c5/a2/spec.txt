

Write a Verilog module that takes in four 1-bit inputs A, B, C, and D and outputs a 2-bit signal Y. The output Y is the sum of the inputs modulo 4. The module should be named `mod4sum` and should have the following interface:

```verilog
module mod4sum(
    input A,
    input B,
    input C,
    input D,
    output reg [1:0] Y
);
```
