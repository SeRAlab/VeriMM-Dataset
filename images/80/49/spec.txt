Design a 4-bit binary counter that counts upwards or downwards based on the control signal `up_down`. The counter increments from 0 to 15 when `up_down` is high and wraps back to 0 upon reaching 15. When `up_down` is low, it decrements from 15 to 0, wrapping back to 15 upon reaching 0. The counter resets to 0 asynchronously when the reset signal `rst` is asserted.
module top_module(
    input clk,
    input rst,
    input up_down,
    output reg [3:0] count
);
