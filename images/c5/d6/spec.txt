

You have been tasked with designing a verilog module to implement a simple 16-bit multiplexer. The module should have two inputs: `a` and `b`, and a select input `sel`. When `sel` is `0`, the output should be `a`, and when `sel` is `1`, the output should be `b`. You should use the following module template:

```
module mux_16bit(
    input [15:0] a,
    input [15:0] b,
    input sel,
    output [15:0] out
);

    // Your code here

endmodule
```

Your task is to implement the logic for the `mux_16bit` module, using verilog. You can assume that all inputs are valid and that there are no timing constraints.
