Please act as a professional Verilog designer.

Design a 4-bit synchronous up/down counter. The counter should increment its value when the up signal is high and decrement its value when the down signal is high. The counter should reset to 0 when the reset signal is active.

Module name:
    UpDownCounter
Input ports:
    clk: Clock signal used for synchronous operation.
    reset: Active-high reset signal.
    up: Signal to increment the counter.
    down: Signal to decrement the counter.

Output ports:
    count: 4-bit output representing the current count value.
