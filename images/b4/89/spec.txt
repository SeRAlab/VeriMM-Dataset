Design a Verilog module that implements a 7-segment display driver for a 4-bit binary input. The 7-segment display should show the hexadecimal value of the input. The input value should be given to the "binary_input" signal, and the 7-segment display segments should be output to the "segments" signal.

module top_module
(
    input [3:0] binary_input,
    output reg [6:0] segments
);
