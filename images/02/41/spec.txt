Design a Verilog module for a Flash memory cell type, which includes a storage element that can be set or reset based on input control signals. The cell should have two control signals: `set` and `reset`, and a data input `d`. The output `q` should reflect the stored value, with `set` taking precedence over `reset`. If both `set` and `reset` are active simultaneously, the output should not change from its previous state. Additionally, there should be a clock input to synchronize the operations.
