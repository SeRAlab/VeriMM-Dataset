

You have been tasked to design a verilog module that implements a 4-to-1 multiplexer. The module should have 4 inputs, 2-bit each, and 2 control inputs, 2-bit each. The output of the module should be the value of the input selected by the control inputs. The module should have the following ports:

* `input [1:0] A, B, C, D`: input values
* `input [1:0] S1, S0`: control inputs
* `output reg [1:0] Y`: output value

Implement the module using behavioral modeling and a `case` statement.
