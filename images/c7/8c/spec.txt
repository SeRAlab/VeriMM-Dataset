

You are tasked with designing a Verilog module for a 4-bit binary counter with a synchronous reset. The counter should increment on every rising edge of the clock signal and reset to 0 when the reset signal is asserted. The module should have the following inputs and outputs:

- `clk`: a clock input
- `reset`: a synchronous reset input
- `count_out`: a 4-bit output that represents the current count value

You should implement the counter using a single always block and the minimum possible number of registers. The Verilog module should be self-contained and should not rely on any external modules or libraries.

Write a Verilog module that implements the 4-bit binary counter with synchronous reset as described above.
