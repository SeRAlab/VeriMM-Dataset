Create a 5-bit wide, 2-to-1 multiplexer for selecting the destination register address in a processor. When the RegDst signal is low (0), the output RegAddr will select the address from Rt; when RegDst is high (1), it will select from Rd.
module top_module(
	 input  RegDst,           
	 input  [4:0] Rt,         
	 input  [4:0] Rd,         
	 output  [4:0] RegAddr    
    );
