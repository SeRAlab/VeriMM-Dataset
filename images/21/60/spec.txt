A Bluetooth module that takes a 4-bit input representing a command and outputs a 3-bit status based on the command. The command to status mapping is as follows: 
Command 0 (0000) -> Status 0 (000)
Command 1 (0001) -> Status 1 (001)
Command 2 (0010) -> Status 2 (010)
Command 3 (0011) -> Status 3 (011)
Command 4 (0100) -> Status 4 (100)
All other commands -> Status 5 (101)
