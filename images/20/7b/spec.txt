Design a 4-channel DMA controller that can read from multiple sources and write to a single destination. The controller should have the following features: 
- It should have 4 request lines (req0, req1, req2, req3) indicating which channel is requesting access.
- It should have a grant line (grant) that shows which channel is granted access to the bus.
- It should have a busy signal (busy) indicating when the DMA is currently transferring data.
- It should have an enable signal (enable) to start the DMA operation.
- The controller should switch between requests on a round-robin basis when multiple requests are active.
