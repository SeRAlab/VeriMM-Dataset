

You have been tasked with designing a verilog module for a 4-bit binary adder with carry. The module should have two 4-bit inputs (A and B) and a 1-bit input (CIN) for carry-in. Create a verilog module that meets the above requirements and name it "binary_adder". Ensure that the module includes the following:
- Inputs: A (4-bit), B (4-bit), CIN (1-bit)
- Outputs: S (4-bit), COUT (1-bit)
- Use behavioral modeling to implement the full-adder logic
- Use appropriate signal names and data types
