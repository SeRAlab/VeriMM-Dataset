Design a theme controller for a VGA display that manages a 4-bit theme value. The module increments the theme value whenever a change signal (chg) is received while cycling through themes from 0 to 2. When the theme value reaches 2, the next increment resets the theme back to 0. The current theme is updated on the rising edge of the clock (clk), and can be reset to 0 with the reset signal (rst).
