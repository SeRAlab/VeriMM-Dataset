Design a register file that supports reading from and writing to an array of registers. This module has parameters for depth and width, allowing it to store 8 registers of 8 bits each. On the rising edge of the clock, when the write enable signal is active, data from the input is written to a specific register identified by the write address. If writing is not enabled, the module reads the data from a register specified by the read address and outputs it.
