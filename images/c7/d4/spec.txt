

You are tasked with designing a module that implements a 2-to-1 multiplexer using Verilog. The module should have the following inputs and outputs:

Inputs:
- `sel`: a single-bit signal that selects which input to pass to the output. If `sel` is 0, then the output should be equal to `in0`. If `sel` is 1, then the output should be equal to `in1`.
- `in0`: a single-bit signal representing one of the inputs to the multiplexer.
- `in1`: a single-bit signal representing the other input to the multiplexer.

Outputs:
- `out`: a single-bit signal representing the output of the multiplexer.

Write a Verilog module that implements this 2-to-1 multiplexer.
