
Design a 4-bit FIFO queue with a depth of 4. The FIFO should have the following features:
- It should accept a data input (4 bits), a write enable (we), and a read enable (re) signal.
- When the write enable is high, the data input should be pushed into the FIFO.
- When the read enable is high, the data at the front of the FIFO should be output.
- The FIFO should indicate when it is empty or full with two output flags: `empty` and `full`.
