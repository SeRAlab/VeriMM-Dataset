Design a Universal Dual Counter that increments or decrements an 8-bit output `data_o` based on the `direction` input, controlled by a `count` signal. When the `reset` signal is active, the output is reset to zero. The counter operates on the rising edge of the clock signal `clk`. When `direction` is high, `data_o` counts down, and when low, it counts up. This module can be used in applications requiring flexible counting operations.
module top_module(
  input wire clk,
  input wire reset,
  input wire count,
  input wire direction,
  output reg [Size-1:0] data_o
);
