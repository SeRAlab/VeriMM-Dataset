Design a 4-depth FIFO queue with the following specifications:
- The FIFO should have 4 entries.
- It should have a `push` input to add data to the queue, a `pop` input to remove data, and a `clk` input for synchronous operation.
- The FIFO should have `data_in` as the input data, `data_out` as the output data, `full` and `empty` flags to indicate the status of the FIFO queue.
- The FIFO should be designed as a circular buffer.
