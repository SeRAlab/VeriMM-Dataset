Implement a Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state M (R = 1).
2. state N (R = 0).
3. state O (R = 1).
4. state P (R = 0).

State transitions:
1. From state M: If a = 0, then transition to state N. If a = 1, then transition to state O.
2. From state N: If a = 0, then transition to state P. If a = 1, then transition to state M.
3. From state O: If a = 0, then transition to state P. If a = 1, then transition to state N.
4. From state P: If a = 0, then transition to state O. If a = 1, then transition to state M.

Assume that you want to Implement the FSM using two flip-flops and state codes u[1:0] = 00, 01, 10, 11 for states M, N, O, P, respectively. Implement just the next-state logic for u[1] in Verilog. The output R is u[1].
