Design a binary-coded decimal (BCD) counter that increments or decrements based on control signals. The module features a clock input (CLK) for synchronization, a load input (LOAD) to set the counter to a specified 4-bit value (D), and an enable input (ENABLE) to control active counting. It counts up when the UP signal is high and down when the UP signal is low. The counter resets to 0 on a clear signal (CLR) or wraps around between 0 and 9 in BCD format, generating a carry-out (CO) signal when the count overflows or underflows in the respective direction.
