Design a Verilog module that performs 2x2 matrix inversion. The matrix is represented as a 4-bit wide input, where the first two bits represent the first row and the last two bits represent the second row. The output should be the inverted matrix in 4 bits. The formula for inverting a 2x2 matrix A = [[a, b], [c, d]] is given by A^(-1) = (1/det(A)) * [[d, -b], [-c, a]], where det(A) = ad - bc. If the determinant is zero, the output should be a fixed value indicating that inversion is not possible. Use a clock signal to control the inversion operation.
