Design a clock-gated data latch. The module outputs the value of `data_in` at the rising edge of `clk` when the enable signal `en` is high; otherwise, it sets `data_out` to LOW. This functionality helps in reducing power consumption by preventing the data from being updated and thus toggling when the enable signal is not asserted.
module top_module(
  input clk,
  input en,
  input data_in,
  output reg data_out
);
