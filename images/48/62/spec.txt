Create a simple calculator module that performs basic arithmetic operations: addition, subtraction, multiplication, and division on two signed 16-bit operands. The module takes a clock signal and a reset signal for synchronous operation, with an operation selector that determines which arithmetic operation to execute. It outputs the result of the computation along with flags indicating overflow and whether the result is zero. The design also handles edge cases, such as division by zero, by setting the appropriate flags.
module top_module(
    input clk,
    input rst,
    input signed [15:0] operand1,
    input signed [15:0] operand2,
    input [1:0] operation,
    output reg signed [15:0] result,
    output reg overflow,
    output reg zero
);
