Design a simple PCIe endpoint controller that responds to a read request from a host. The controller should have an input `read_request` signal that indicates a read operation and an input `address` signal that specifies the address to read from. The output `data_out` should provide the data from the specified address, with a specific delay to simulate response time. The response will occur after a clock cycle when `read_request` is asserted. The controller should also have a reset signal to initialize the state.
