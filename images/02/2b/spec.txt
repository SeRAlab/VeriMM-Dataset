Design a voltage and frequency control circuit that adjusts the operation mode of a system based on temperature and load conditions. The circuit should have three modes: LOW, MEDIUM, and HIGH. The operation mode is determined by two inputs: TEMP and LOAD. TEMP is a 3-bit input representing temperature levels (0-7), and LOAD is a 3-bit input representing load levels (0-7). The output MODE is a 2-bit signal representing the mode of the circuit. The conditions for the modes are as follows:
- LOW: TEMP < 3 and LOAD < 3
- MEDIUM: (TEMP >= 3 and TEMP < 6) or (LOAD >= 3 and LOAD < 6)
- HIGH: TEMP >= 6 or LOAD >= 6
