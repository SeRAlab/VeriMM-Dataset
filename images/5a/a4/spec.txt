Design a 4KB instruction memory module that outputs a 32-bit data word based on a given 10-bit address input. The module is resettable and fetches instructions from an internal memory array, allowing the address range from 0 to 1023 (corresponding to 4KB when each instruction is 32 bits wide). When the `rst` signal is active, it can be used to reset the state of the memory.
