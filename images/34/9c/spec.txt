
Design a Verilog module that implements a TCP Segmentation logic. The module takes a 16-bit input data and a control signal that indicates whether to segment the data or not. If the control signal is high, the module outputs the segmented data as two 8-bit outputs. If the control signal is low, the module passes the original data as a single 16-bit output. The segmentation should be done by splitting the 16-bit input into two 8-bit outputs.
