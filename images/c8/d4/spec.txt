

You are tasked with designing a module that takes in four inputs, A1, A2, B1, and C1, and outputs a single bit X. You are given a code snippet for inspiration, but you should create a new module from scratch.

The module should have the following behavior: if A1 and A2 are both high, or if B1 and C1 are both high, then X should be high. Otherwise, X should be low.

Design a module that implements this behavior and write a Verilog code for it. Make sure to include the module definition, input and output ports, and any necessary local signals. Your Verilog code should be self-contained and should not require any external modules or testbenches.
