Develop a read-only memory (ROM) module that outputs a 16-bit data word based on an 8-bit address input. This design initializes the ROM with predefined binary values for addresses ranging from 0 to 15. The module utilizes an array to store the data and provides the corresponding data output based on the input address, effectively functioning as a look-up table where each address corresponds to a specific stored data value. The ROM can be classified as a mask ROM type due to the nature of its initialization.
module top_module(
  input [n-1:0] addr,
  output [m-1:0] data
);
