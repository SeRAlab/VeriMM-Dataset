Design a circuit that detects edges on a single input signal A. The module generates two outputs: 'rise' indicates a rising edge (transition from low to high) when A changes from 0 to 1, and 'down' indicates a falling edge (transition from high to low) when A changes from 1 to 0. The outputs are synchronized to a clock signal, and both are reset to low when the reset signal is active.
module top_module(
  input               clk,
  input               rst_n,
  input               A,
  output reg          rise,
  output reg          down
);
