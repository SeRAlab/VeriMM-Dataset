Design a Verilog module to implement a JK flip-flop with asynchronous reset. The output q should toggle when both J and K are high, set when J is high and K is low, reset when J is low and K is high, and remain unchanged when both are low. The reset should set q to 0.
module jk_ff(
	input clk,
	input reset,
	input j,
	input k,
	output reg q);
