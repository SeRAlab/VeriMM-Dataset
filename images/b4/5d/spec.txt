Implement a 2-to-4 line decoder with an enable signal. The module generates four outputs (Y3, Y2, Y1, Y0) based on the binary inputs A and B, active when the enable signal (en) is high. For each combination of A and B, one of the outputs will be driven low, while the others will be high, effectively translating the input selection into a unique output line. If the enable signal is low, all outputs will be high, indicating that no selection is active.
