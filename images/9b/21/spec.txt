Design a 4-to-1 multiplexer that selects one of four input signals based on a 2-bit selection line. When sel corresponds to A0 (00), the output y is assigned the value of the first input (a[0]); for A1 (01), it corresponds to the second input (a[1]); for A2 (10), it corresponds to the third input (a[2]); and for A3 (11), it corresponds to the fourth input (a[3]). The output is registered to respond to changes in the selected input based on the input selection.
