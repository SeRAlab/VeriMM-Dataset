
Design a 4-channel DMA controller that can accept requests from four different devices. The controller should have a clock signal, reset signal, and a request input for each channel. When a request is received, the controller should grant access to the corresponding channel in a round-robin fashion. Implement the control logic to manage which channel is currently granted access and ensure that the grant signal is active for one clock cycle. The output should be a 4-bit grant signal indicating which channel is currently granted access.
