Design a simple EEPROM cell in Verilog. The EEPROM cell should have the following functionality: It has a single bit of data input (D), a clock signal (CLK), a write enable signal (WE), and an output signal (Q). When WE is high, the input data should be written to the output on the rising edge of the clock. When WE is low, the output should hold its last value. The output Q represents the stored value of the EEPROM cell.
