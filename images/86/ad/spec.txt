Design a circuit that manages hay stock control based on a 4-bit input. The module outputs a HIGH signal (hay = 1) if the stock input is anything other than four zeros (0000), indicating that hay is available. If the stock input is exactly four zeros, the output becomes LOW (hay = 0), signaling that there is no hay available. The operation is synchronized to the rising edge of the clock signal.
module top_module(
    input clk,
    input [3:0] stock,
    output reg hay          
    );
