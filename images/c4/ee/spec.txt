

You are tasked with designing a verilog module that takes in 8-bit data and outputs the data in little-endian format. The module should have two inputs and one output:

- `input [7:0] data_in`: 8-bit input data
- `input clk`: clock input
- `output reg [7:0] data_out`: 8-bit output data

The module should sample the input data on the rising edge of the clock and output the data in little-endian format. That is, the least significant bit of the input should be the most significant bit of the output, and vice versa.

Write the verilog code for the module that meets these requirements.
