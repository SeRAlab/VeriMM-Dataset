

You are tasked with designing a Verilog module that takes in 5 inputs and outputs a single value. The module should be named `five_to_one` and should have the following inputs and outputs:

- Inputs: `A`, `B`, `C`, `D`, and `E`, all of which are single-bit wires.
- Output: `Y`, a single-bit wire.

The `Y` output should be the result of the following logic:

- If `A` is 1, `Y` should be 1.
- If `B` is 1, `Y` should be 1.
- If `C` is 1, `Y` should be 1.
- If `D` is 1 and `E` is 0, `Y` should be 1.
- If `D` is 0 and `E` is 1, `Y` should be 1.
- If none of the above conditions are met, `Y` should be 0.

You should write a Verilog module that implements this logic. Your module should be contained within 200 lines of code, and should be named `five_to_one`.
