Design a synchronous D flip-flop with additional control functionalities. The module captures the input D on the rising edge of the CLK when the SCE (Set Control Enable) signal is active, allowing for data storage. The SCD (Set Control Direct) signal allows for asynchronous clearing of the output Q to zero on the rising edge of CLK. Further, asynchronous set and reset functionalities are provided through the SET_B and RESET_B inputs, which set Q to high or low, respectively, when asserted. The complementary output Q_N is generated by inverting Q, providing a useful output in certain digital logic applications.
