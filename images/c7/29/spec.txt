

You are tasked with designing a verilog module that generates a sequence of numbers from 1 to 10. The output of this module should be a signal that toggles between 0 and 1 every time a new number is generated. The module should have a single input, a clock signal, and a single output, the toggle signal.

You should use the following code snippet as a starting point:

```
module seq_gen (
   input clk,
   output reg toggle
);

// Your code here

endmodule
```

Your task is to fill in the module with the necessary logic to generate the desired sequence of numbers and toggle the output signal accordingly.
