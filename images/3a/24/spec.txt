Design a data forwarding unit that takes three inputs: `src1`, `src2`, and `dest`, representing the source registers and the destination register respectively. The unit outputs a signal `forward` that determines if data from `src1` should be forwarded to `dest`, if data from `src2` should be forwarded to `dest`, or if no forwarding is necessary. The forwarding logic is as follows: if `src1` equals `dest`, then `forward` should output `1` (forward from `src1`); if `src2` equals `dest`, then `forward` should output `2` (forward from `src2`); otherwise, it should output `0` (no forwarding).
