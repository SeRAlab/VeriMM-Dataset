

You have been hired to design a verilog module that takes in five input signals - A1, A2, A3, B1, and C1 - and generates a single output signal X. You are required to implement this module using the following components:

- An OR gate with three inputs, named or0
- An AND gate with three inputs, named and0
- A buffer, named buf0

The module should be named sky130_fd_sc_ls__o311a and should have the following interface:

- X: a single-bit output
- A1, A2, A3, B1, C1: single-bit inputs

You are also provided with four supply nets: VPWR (supply1), VGND (supply0), VPB (supply1), and VNB (supply0).

Write the verilog code for the sky130_fd_sc_ls__o311a module that meets these requirements.
