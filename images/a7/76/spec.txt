Design a circuit that acts as a binary splitter for a 3-bit input vector. The module outputs the same 3-bit input vector directly while also providing individual outputs for each bit. Specifically, output_2 corresponds to the most significant bit, output_1 to the middle bit, and output_0 to the least significant bit of the input vector.
module top_module(
    input wire [2:0] input_vector,
    output wire [2:0] output_vector,
    output wire output_2,
    output wire output_1,
    output wire output_0
);
