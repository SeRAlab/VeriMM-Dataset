Design a 4-to-1 multiplexer that selects one of four 32-bit input data lines (Data_0, Data_1, Data_2, Data_3) based on a 2-bit selector. The output (Data_out) corresponds to the input line selected by the binary value of the selector: if the selector is 00, output Data_3; if 01, output Data_2; if 10, output Data_1; and if 11, output Data_0.
module top_module(
    input wire    [1:0]     selector,
    input wire    [31:0]    Data_0,
    input wire    [31:0]    Data_1,
    input wire    [31:0]    Data_2,
    input wire    [31:0]    Data_3,
    output wire   [31:0]    Data_out
);
