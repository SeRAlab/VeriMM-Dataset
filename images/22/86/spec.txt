
Design a 16-bit Linear Feedback Shift Register (LFSR) with a polynomial feedback configuration. The LFSR should take a clock input and reset input. The feedback should be based on taps at positions 16, 14, 13, and 11. The output of the LFSR should be a 16-bit value that shifts left and incorporates the feedback bit. The reset input should set the LFSR to a specified non-zero seed value.
