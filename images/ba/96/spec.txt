Design a synchronous read/write RAM module with reset functionality. The module accepts a clock signal, enable, write enable, and reset signals, along with a 10-bit address and a 16-bit data input. When enabled, it allows writing data to the specified address if the write enable is active. If the reset signal is asserted, it clears the output data to zero; otherwise, on each clock cycle, it outputs the data stored at the specified address, thereby functioning as a memory bank with a capacity of 1024 words.
