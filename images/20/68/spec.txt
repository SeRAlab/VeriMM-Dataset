Design a simple 8-bit DRAM cell that can store a single 8-bit value and can be read from and written to. The DRAM cell should have the following inputs: a 3-bit address, a 1-bit write enable, an 8-bit data input, and a 1-bit read enable. The cell should output the stored data when read. The address will determine which of the 8 DRAM cells to access. The initial state of the memory should be undefined (reset condition).
