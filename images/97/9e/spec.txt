Design a one-bit wide, 2-to-1 multiplexer circuit. The multiplexer selects between two input signals, `a` and `b`, based on the value of the select signal `sel_b1`. When `sel_b1` is high (1), the output `out_mux` will reflect the value of input `b`. When `sel_b1` is low (0), the output will reflect the value of input `a`.
module top_module(
    input a,
    input b,
    input sel_b1,
    output reg out_mux
);
