

You are tasked with designing a verilog module that implements a 4-bit binary counter with asynchronous reset. The module should have the following inputs and outputs:

Inputs:
- `clk`: the clock signal
- `reset_n`: asynchronous active-low reset signal

Outputs:
- `count`: a 4-bit binary output representing the current count value

The counter should increment on each rising edge of the clock signal, and reset to 0 when the reset signal is asserted.

Write a verilog module that implements the above functionality.
