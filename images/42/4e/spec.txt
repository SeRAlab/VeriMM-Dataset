Module name:  
    down_counter_12_ld

    rst: Reset signal (active high)

    ld: Load signal
    load_value: 12-bit input value to be loaded when load signal is active
Output ports:
    count: 12-bit output representing the current count value

Implementation:
If the reset signal is active (rst), the counter is reset to 4095 by assigning the value 12'b111111111111 to the output register (count). If the load signal (ld) is active, the counter loads the value from load_value into count. On each positive clock edge, the counter decrements by 1.
