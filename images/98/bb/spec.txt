Design a synchronous 5-bit adder with a reset and enable control. When the reset signal is active, the output is set to zero. When enable is high, on each positive clock edge, the module adds the 5-bit input data to the current output value, effectively accumulating the input data over time.
module top_module(
  input reset,
  input clk,
  input enable,
  input [4:0] data_in,
  output reg [4:0] data_out
);
