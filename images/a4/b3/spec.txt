Design a 4-bit right shift register that operates on a rising clock edge. When the clear signal (clrb) is asserted low, the output (Q) is reset to zero. On each positive edge of the clock, the register shifts its contents to the right by one bit and loads the most significant bit (MSB) with the value from the serial input (SDR), effectively allowing for serial data input while maintaining the shifted values.
module top_module(input clk, input clrb, input SDR, output reg [3:0]Q);
