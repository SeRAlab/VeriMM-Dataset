Design a 1-bit DRAM cell that can store a single bit of information. The DRAM cell should have the following inputs: a data input (D), a write enable (WE), and a read enable (RE). The cell should output the stored value (Q) on the read enable signal. If the write enable is active, the cell should store the input data. If read enable is active, the cell should output the stored value. The cell should retain its value when neither read nor write is active.
