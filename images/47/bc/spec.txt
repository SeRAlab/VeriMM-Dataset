Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs: 
1. state A (output 1).
2. state B (output 0).
3. state C (output 1).

State transitions:
1. From state A: If x = 0, then transition to state B. If x = 1, then transition to state C.
2. From state B: If x = 0, then transition to state A. If x = 1, then transition to state C.
3. From state C: If x = 0, then transition to state B. If x = 1, then transition to state A.

Resets into state A. For this part, assume that a one-hot code is used with the state assignment e[3:1] = 001, 010, 100 for states A, B, C, respectively.

Write Verilog for the next-state signals E2 and E3 corresponding to signal e[2] and e[3]. Derive the logic equations by inspection assuming a one-hot encoding.
