

You are tasked with designing a module that takes in 5 input signals and outputs a single signal. The module is required to have the following functionality:

- The module should be named `my_module`.
- The output signal should be named `out_signal`.
- The input signals should be named `in_signal_1`, `in_signal_2`, `in_signal_3`, `in_signal_4`, and `in_signal_5`.
- The module should have two internal signals named `sig1` and `sig2`.
- `sig1` should be the result of an AND gate between `in_signal_1` and `in_signal_2`.
- `sig2` should be the result of a NOR gate between `in_signal_3`, `in_signal_4`, `in_signal_5`, and `sig1`.
- `out_signal` should be the result of a buffer with input `sig2`.

Design the `my_module` module with the above functionality.
