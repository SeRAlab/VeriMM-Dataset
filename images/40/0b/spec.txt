Design a 32-bit data bus that takes two 32-bit inputs, A and B, and produces a 32-bit output C. The output C should be determined by the following logic: if the least significant bit (LSB) of A is 1, then C should equal A; otherwise, C should equal B. Additionally, the design should include a control signal that toggles between two modes: mode 0 (selects A) and mode 1 (selects B) based on the LSB of A.
