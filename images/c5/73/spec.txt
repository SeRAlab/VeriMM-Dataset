

You are tasked with creating a module that implements a simple 16-bit Arithmetic Logic Unit (ALU) in Verilog. The module should take in three 16-bit inputs: A, B, and C. Additionally, it should take in a 2-bit input op that determines the operation to be performed on the inputs. The module should output a 16-bit value, Z, which is the result of the operation.

The following table shows the possible values of op and their corresponding operations:

| op | Operation |
|----|-----------|
| 00 | A + B     |
| 01 | A - B     |
| 10 | A & B     |
| 11 | A \| B     |

You are required to implement the module using only combinational logic, without using any sequential elements.

Your task is to implement the Verilog module alu_16 to perform the above operations.
