Design a binary counter with configurable bit width (N). The counter increments its value on each positive clock edge when enabled (en) and resets to zero when the reset signal (rst) is asserted. It wraps around to zero once it reaches its maximum value, determined by the parameter N, which specifies the number of bits in the counter. This module is useful for counting events or managing time intervals in digital circuits.
module top_module(
    input clk,
    input rst,
    input en,
    output reg [N-1:0] count
);
