Design a 16-bit SRAM cell with read and write capabilities. The SRAM cell should have a data input (D), a data output (Q), a write enable signal (WE), a read enable signal (RE), and a clock signal (CLK). When WE is high, the input data D should be written into the SRAM cell. When RE is high, the data stored in the SRAM cell should be output to Q on the rising edge of the clock.
