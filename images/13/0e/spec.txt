Design an ARQ (Automatic Repeat reQuest) error correction module that uses a simple Stop-and-Wait protocol. The module should include registers for storing data, acknowledgment (ACK) signals, and a state machine to manage the send and receive operations. The system should handle the sending of data frames and responding to ACKs from the receiver. If an ACK is not received within a specified timeout, the system should retransmit the last sent data frame. The design should include a clock and reset signal, and the output should indicate whether the data was successfully sent or needs retransmission.
