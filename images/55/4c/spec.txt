Design a 4-bit adder-subtractor circuit that can perform addition or subtraction based on a selection input (Sel). When Sel is set to 0, the module computes A + B + Cin, producing a 4-bit sum (S) and a carry-out (Cout). When Sel is set to 1, it computes A - B, providing the 4-bit result (S) and the carry-out as the most significant bit of the result. The module utilizes a combination of addition and subtraction operations to handle arithmetic based on the input selection.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input Cin,
    input Sel,
    output [3:0] S,
    output Cout
);
