Design a D-type flip-flop with asynchronous set and reset capabilities. The flip-flop captures the value of input D on the rising edge of the clock signal (CLK). If the SET input is activated, the output Q is set to HIGH regardless of the clock; if the RESET input is activated, the output Q is set to LOW. The complementary output QN reflects the inverted state of Q. This module effectively allows for normal data storage, along with control over the output state through asynchronous signals.
