Design a 4-bit SRAM cell with read and write functionality. The SRAM cell should have four data inputs (D0, D1, D2, D3), a read enable (RE), a write enable (WE), and a clock signal (CLK). When WE is high and RE is low, the data inputs should be written to the SRAM cell. When RE is high and WE is low, the SRAM cell should output the stored data on the outputs (Q0, Q1, Q2, Q3).
