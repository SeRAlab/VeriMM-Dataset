Design a programmable counter that incorporates features for loading different values based on selection signals. The module outputs the current value of the program counter (`pc_out`) and an ungated version of the counter value (`pc_ungated`). It increments the counter by 2 on each clock cycle when reset is high and the `load_pc` signal is active. Depending on the `pc_sel` input, the counter can be loaded with the incremented value, an external address from `ea`, a value from `bus`, or a fixed value. When enabled, the counter will reflect the current value, while it outputs high impedance when not enabled. If reset is low, the counter initializes to a fixed value of 0x0200.
module top_module(en, clk, reset, bus, ea, pc_sel, load_pc, pc_ungated, pc_out);
