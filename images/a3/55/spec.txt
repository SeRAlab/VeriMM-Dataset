Design a circuit that decodes a 16-bit scancode input to generate control signals for directional movement. Depending on the specific scancode values (e.g., for left, down, right, and up), the module outputs a high signal on the corresponding direction output while ensuring all other direction outputs remain low. This functionality enables the detection of directional commands from an external input, allowing for the control of movements or actions based on user input.
module top_module(
    input [15:0] scancode,
    output reg left,
    output reg down,
    output reg right,
    output reg up  );
