Design a 4-bit by 4-bit multiplier with enable functionality. The circuit takes two 4-bit inputs, a and b, and produces an 8-bit output, prod, representing their product. When the enable signal is high, the multiplier computes the product of the inputs; if low, the output resets to zero. The inputs a and b are registered on the rising edge of the clock, ensuring synchronized operation of the multiplication.
module top_module(
    input clk,            // Add clk input to the module
    input [3:0] a,
    input [3:0] b,
    input enable,
    output reg [7:0] prod
);
