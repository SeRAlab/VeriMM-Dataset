Design a 4-to-1 multiplexer that selects one of four single-bit inputs (in_0, in_1, in_2, in_3) based on two select lines (sel_0 and sel_1). When sel_1 and sel_0 are both LOW (00), the output (out) is set to in_0; with sel_0 HIGH (01), it outputs in_1; with sel_1 LOW and sel_0 HIGH (10), it outputs in_2; and when both select lines are HIGH (11), it outputs in_3.
module top_module(
    input in_0,
    input in_1,
    input in_2,
    input in_3,
    input sel_0,
    input sel_1,
    output reg out
);
