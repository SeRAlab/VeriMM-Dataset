Design a 4-to-1 multiplexer with an enable signal. When the enable (`en`) input is HIGH, the output (`out`) will select one of the four inputs (`in[0]` to `in[3]`) based on a priority scheme, effectively prioritizing `in[0]` through `in[3]`. If the enable signal is LOW, the output will be set to LOW regardless of the input values. Note that the current design will only reflect the first active input due to potential overwriting of the output.
module top_module(
    input [3:0] in,
    input en,
    output out
);
