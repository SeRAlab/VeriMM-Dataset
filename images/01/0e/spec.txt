Design a Verilog module that implements a simple Network Address Translation (NAT) function. The NAT will take a 32-bit private IP address and map it to a 32-bit public IP address based on a predefined mapping. The module should have the following inputs and outputs:
Inputs: 
- private_ip (32-bit): The private IP address to be translated.
Outputs:
- public_ip (32-bit): The corresponding public IP address after translation.
The mapping is predefined as follows:
- 192.168.1.1 -> 203.0.113.1
- 192.168.1.2 -> 203.0.113.2
- 192.168.1.3 -> 203.0.113.3
- 192.168.1.4 -> 203.0.113.4
- 192.168.1.5 -> 203.0.113.5
All other private IPs should output a public IP of 0.0.0.0.
