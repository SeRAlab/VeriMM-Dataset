
Design a 24-bit Digital-to-Analog Converter (DAC) that takes a 24-bit binary input and produces a corresponding voltage output. The output voltage is linearly scaled based on the input value, where the maximum input (24'b111111111111111111111111) corresponds to the maximum output voltage (for example, 5V), and the minimum input (24'b000000000000000000000000) corresponds to 0V. Implement this functionality in Verilog.
