Implement the Verilog module based on the following description.
Build a 4-bit up/down counter with asynchronous positive edge triggered reset, synchronous enable signal, and synchronous active high clear signal.
(1) reset: Resets counter to zero.
(2) enable: Enables the counter to count up or down based on the direction signal.
(3) clear: Clears the counter to zero.
(4) direction: 1 for up-counting, 0 for down-counting.
(5) q: The current value of the counter.

module top_module(
    input clk,
    input reset,
    input enable,
    input clear,
    input direction,
    output reg [3:0] q);
