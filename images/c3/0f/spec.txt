

You are tasked to design a verilog module that takes two inputs `A` and `B` and generates an output `X` based on the following conditions:
- If both `A` and `B` are high, then `X` should be high.
- If both `A` and `B` are low, then `X` should be low.
- If `A` is high and `B` is low, then `X` should be high.
- If `A` is low and `B` is high, then `X` should be low.

You should implement this module using only `and` and `not` gates. You are not allowed to use any other gates or operators.

The module should be named `two_input_logic` and should have the following interface:
- `A` and `B`: input ports of type `logic`
- `X`: output port of type `logic`

You should write the verilog code for the `two_input_logic` module.
