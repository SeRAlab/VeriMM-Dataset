Implement a 4-to-2 priority encoder. The module takes a 4-bit input, d_in, and outputs a 2-bit code, d_out, corresponding to the highest-priority active input bit (the highest bit position that is set to 1). If none of the input bits are active, d_out defaults to zero. The output indicates which of the input lines is the first one to go high, based on mapped priority.
