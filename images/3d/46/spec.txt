Design an I2C controller in Verilog that can send a byte of data to a specified address. The controller should have the following inputs: a clock signal, a reset signal, an 8-bit data input, a 7-bit address input, and a start signal. It should produce the following outputs: a busy signal indicating the controller is sending data, an SDA signal representing the data line, and an SCL signal for the clock line. The controller should implement the I2C start condition, send the address, and send the data byte in 8 clock cycles.
