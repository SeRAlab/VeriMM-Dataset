Implement a Verilog module for a simple UART transmitter. The module should have the following specifications:
- `clk`: The clock signal.
- `reset`: An active-high synchronous reset signal.
- `tx_start`: An active-high signal to start transmission.
- `tx_data`: The 8-bit data to be transmitted.
- `tx_busy`: An active-high signal indicating the transmitter is busy.
- `tx`: The serial output data.
