
Design a 16-bit SRAM cell that can store a 16-bit data input and allow reading and writing operations. The cell should have the following inputs:
- `clk`: clock signal
- `write_enable`: signal to enable writing to the cell
- `data_in`: 16-bit data input
- `address`: address input (in this case, we will use a single address since it is one cell)

The cell should have the following output:
- `data_out`: 16-bit data output that reflects the stored value.

When `write_enable` is high, the `data_in` should be written to the cell on the rising edge of `clk`. When `write_enable` is low, the `data_out` should reflect the stored value.
