Design a 4-bit up/down counter with load capability. The counter outputs a 4-bit value (q) that can be reset to zero, loaded with a value from input (d), incremented when the 'und' signal is asserted, or decremented by default on each clock cycle. The operation is synchronized with the rising edge of the clock signal.

input [3:0]d,
input clk,rst,ld,und,
