Design a Verilog module that implements a simple finite state machine (FSM) for an Elliptic Curve Point Doubling operation. The FSM should have two inputs: `clk` (clock) and `reset` (active high), and it should take in a 2D point represented by `x` and `y` coordinates (each 8 bits) and output the result of the point doubling operation as a new 2D point also represented by `x'` and `y'` coordinates (8 bits each). The FSM should have three states: IDLE, PROCESS, and OUTPUT. In the PROCESS state, the doubling operation should be performed using the following simplified formula:  
x' = (x^2) mod p  
y' = (y^2) mod p  
Assume p = 257 for this problem, which is a prime number.
