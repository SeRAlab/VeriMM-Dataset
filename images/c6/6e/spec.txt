Please act as a professional Verilog designer. Your task is to create a Verilog module that implements a modulo operator. 
A modulo operator is a mathematical operation that returns the remainder of a division operation. 
For example, 5 modulo 3 is 2, because 5 divided by 3 is 1 with a remainder of 2.

Your module should have the following inputs and outputs:

Inputs: 
1. a: the dividend (positive integer)
2. b: the divisor (positive integer)

Outputs: 
1. c: the remainder of a divided by b

Your module should implement the following functionality:

The module should use the modulo operator to compute the remainder of a divided by b.
The remainder should be output to the c output.

To implement the modulo operator, you can use the following formula:

c = a - (b * (a / b))

This formula calculates the remainder of a divided by b by subtracting b times the integer result of a divided by b from a.

Your Verilog module should take the a and b inputs and use this formula to calculate the modulo operation. 
The result should be output to the c output.
