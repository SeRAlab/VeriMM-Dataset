Design a down counter with a load and reset functionality. The module features a 4-bit output representing the count value, which decrements with each clock pulse when enabled. If the Clear input is activated, the count resets to zero. Additionally, if the Enable signal is high and either the Load input is asserted or the counter reaches zero, the count is preloaded with the value 10. The circuit thus functions as a flexible timer that can be reset or initialized while counting down.
