Design a PS/2 keyboard decoder that captures scan codes from a keyboard and indicates when a complete code is ready. It utilizes a state machine controlled by the falling edge of the input clock and a reset signal. As the scanner processes each bit of the scan code over several clock cycles, it stores the received bits in an 8-bit register. Once the code is fully received and validated, an output signal is asserted to indicate that the scan code is ready for use. The module effectively manages state transitions and ensures data integrity by checking the parity of the received code.
module top_module(input reset,input i_clock,input i_data,output scan_ready,output [7:0] scan_code);
