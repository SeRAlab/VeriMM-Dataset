Design a module that drives four 7-segment displays based on a 2-bit input mode. The module outputs specific 7-segment encoding for each display (HEX3, HEX2, HEX1, HEX0) depending on the value of the mode input. For mode `11`, it produces a unique pattern of segments; for mode `00`, it outputs another distinct pattern; and for any other mode, it defaults to a third pattern. This module effectively serves as a visual indicator that translates mode selections into corresponding hexadecimal representations on the displays.
module top_module(
input [1:0] mode,
output reg [6:0] HEX3,HEX2,HEX1,HEX0
);
