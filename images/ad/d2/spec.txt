Design a program counter (PC) module that updates its output based on various control signals. It operates on the rising edge of a clock, resetting the output to zero when the reset signal is high. If a flush signal is asserted, it clears the lower 31 bits of the counter while preserving the most significant bit. When the PCWrite signal is active, the new PC value is determined by the Branch signal and the PCSrc input. Depending on the value of PCSrc, the next PC can either increment by 4, use a jump target, select a value from DataBusA, or be directly set to specific address values. The output remains unchanged if PCWrite is not asserted.
module top_module(input clk, rst, flush,input [31:0] PC_In,input [2:0] PCSrc,input PCWrite,Branch,input [31:0] ConBA,DataBusA,input [25:0] JT,output reg [31:0] PC_Out);
