Design a 16-to-4 encoder in Verilog. The encoder should take 16 input lines (from `in[15:0]`) and produce a 4-bit output (`out[3:0]`) representing the binary encoding of the highest priority input line that is active (1). If no inputs are active, the output should be 4'b0000. The outputs should be in binary form of the input line number. The encoder should be designed in a combinational logic style.
