Design a pixel receiver for an RGB 656 interface that captures pixel data in a synchronized manner. The module takes an 8-bit input data signal (d_i), vertical sync (vsync_i), horizontal reference (href_i), pixel clock (pclk_i), and reset (rst_i) signals. It outputs a 16-bit pixel value (pixel_o) and an indication signal (pixelReady_o) when a complete pixel is ready. The design operates in two phases: on each pixel clock cycle, it captures high byte data during the first half of the pixel input (when odd = 0) and the low byte during the second half (when odd = 1). The pixel output is flagged complete by asserting pixelReady_o, and the initiation of a new frame is indicated by the vsync signal.
