Create a Verilog module that implements a simple Bluetooth module state machine. The module takes two inputs: a control signal and a reset signal. The output should indicate the current state of the Bluetooth module (Idle, Connecting, Connected, Disconnected). The state should transition based on the control signal as follows: 
- From Idle, if control = 1, go to Connecting.
- From Connecting, if control = 1, go to Connected.
- From Connected, if control = 0, go to Disconnected.
- From Disconnected, if control = 0, go back to Idle.
