Design a priority encoder with 'n' input signals. For the given inputs, it will output the binary representation of the highest priority active input. If no inputs are active (all are LOW), the output will be zero. The implementation uses a parameterized approach, allowing the number of input signals to be easily configurable, with the output calculated using the logarithmic base-2 function to determine the active input's position.
module top_module(
  input [n-1:0] in,
  output reg [log2(n)-1:0] out
);
