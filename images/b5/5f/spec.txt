Design a module that functions as a configurable 1-input look-up table (LUT). The module takes a single input (I0) and outputs two signals, O and LO. The output O is determined by the parameter INIT: if both bits of INIT are equal, O is set to the value of INIT[0]; otherwise, O is selected from INIT based on the value of I0. LO simply mirrors the output O, effectively providing an additional signal that reflects the LUT's output behavior.
