Design a 4-bit decade counter that increments its count on each rising edge of the clock signal. The counter resets to zero when the reset input is activated. It counts from 0 to 9 and indicates an overflow condition when it resets after reaching 9. The current count value is output as a 4-bit signal, and a separate overflow signal indicates when the counter has wrapped around.
module top_module(
  input clk,
  input reset,
  output [3:0] count,
  output reg overflow  // Change from wire to reg
);
