
Create a Verilog module that implements a simplified version of the SHA-256 hash function. The module should accept a 512-bit input message and produce a 256-bit output hash. The core operations of the SHA-256 algorithm, such as bitwise operations and modular additions, need to be simplified for this problem. The module should be clocked and able to process one message at a time, producing an output after a specific number of clock cycles.
