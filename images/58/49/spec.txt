Design a signal converter that processes a 4-bit input signal and produces a 3-bit output signal based on specific conditions. If the input signal is less than 4, the output will be the same as the input. If the input signal is between 4 and 7, the output will be the input value decreased by 1. For input values of 8 or higher, the output will be the input value decreased by 2, effectively compressing the range of the input signal into a 3-bit output.
module top_module(
    input [3:0] in_signal,
    output reg [2:0] out_signal
);
