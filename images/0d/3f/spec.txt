Design a Run-Length Encoding (RLE) circuit that takes a stream of binary data (1 bit at a time) and encodes it using RLE. The output should be the encoded value in 8 bits followed by the count in 8 bits. The circuit should output valid data when a special "end" signal is received, indicating that the input stream has finished. The input includes a clock and reset signal. When the reset is activated, the circuit should clear its states.
