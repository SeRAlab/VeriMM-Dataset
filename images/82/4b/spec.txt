Design a circuit that performs basic arithmetic operations on two 4-bit inputs, num_a and num_b, based on a control signal. When the control signal (ctrl) is low, the module outputs the sum of num_a and num_b; when ctrl is high, it outputs the difference (num_a - num_b). The output is updated on the rising edge of the clock signal (clk).
module top_module(
input wire clk,
input wire [3:0] num_a,
input wire [3:0] num_b,
input wire ctrl,
output reg [3:0] out
);
