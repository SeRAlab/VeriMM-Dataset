
Design a 4-bit SRAM cell that can read and write data. The cell should have the following inputs:
- `data_in`: 4-bit input data to be written to the cell.
- `write_enable`: a signal that, when high, allows data to be written into the cell.
- `read_enable`: a signal that, when high, allows data to be read from the cell.
The output should be `data_out`: 4-bit output data read from the cell.
