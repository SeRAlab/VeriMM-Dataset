Design a 4-bit register that can hold a binary value and supports both loading a new value and incrementing the current value. On the rising edge of the clock (Clk), if the Reset signal is low, the output is set to zero. If Reset is high, the register can either load a new value from the input (In) when the Load signal is active or increment the current value by one if the Increment signal is asserted.
