

You are tasked with designing a verilog module for a 4-bit adder with carry input. The module should have the following inputs and outputs:

Inputs:
- `cin`: a single-bit input representing the carry input.
- `a`: a 4-bit input representing the first operand.
- `b`: a 4-bit input representing the second operand.

Outputs:
- `sum`: a 4-bit output representing the sum of the two operands.
- `cout`: a single-bit output representing the carry output.

Write a verilog module that implements the above specifications. Use the following template for your module:

```
module adder4(
    // Inputs
    input cin,
    input [3:0] a,
    input [3:0] b,
    
    // Outputs
    output [3:0] sum,
    output cout
);

// Your code here

endmodule
```
