

You are tasked with designing a module that implements a binary counter. The module should have two inputs, a clock signal (CLK) and a reset signal (RST), and one output, a 4-bit binary value (Q) that represents the current count. The counter should increment on every rising edge of the CLK signal, and reset to 0000 on every rising edge of the RST signal. 

Design a module that meets these specifications. The module should be self-contained and should not rely on any other modules.
