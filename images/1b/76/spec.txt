
Design a combinational circuit that implements a basic gradient descent step. The circuit should take the following inputs:
- `current_position`: a signed 16-bit integer representing the current position on a function.
- `gradient`: a signed 16-bit integer representing the gradient at the current position.
- `learning_rate`: a signed 16-bit integer representing the learning rate.

The output should be the new position calculated by the formula:
```
new_position = current_position - (learning_rate * gradient)
```
Note that the multiplication needs to be handled carefully to fit within the 16-bit signed integer range.
