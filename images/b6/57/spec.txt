Implement a register for instruction storage that captures input from a data bus. The instruction register (ir) loads 8 bits of data from the bus when the load signal (ldir) is high, triggered by the positive edge of the clock signal (t3). This design is intended for use in a synchronous digital system, enabling the transfer of instruction data into the register on each clock cycle when the load condition is met.
