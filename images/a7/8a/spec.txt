Design a 4-bit shift register with load, shift left, and shift right functionality. When the LOAD input is activated, the register is loaded with the value on the D input. The SHL input performs a left shift, moving all bits toward the more significant end while inserting a zero at the least significant bit. Conversely, the SHR input performs a right shift, moving all bits toward the less significant end and inserting a zero at the most significant bit. The output Q reflects the current state of the shift register.
module top_module(
    input [3:0] D,
    input SHL,
    input SHR,
    input LOAD,
    output reg [3:0] Q
);
