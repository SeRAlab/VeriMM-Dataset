Implement the Verilog module based on the following description.
Design a Verilog module that implements an 8-bit shift register with parallel load. The shift register should shift left on the rising edge of the clock. When the parallel load signal (pload) is high, the shift register should load the input data (pdata) into the register. The register value should be output to the "q" signal.

module shift_register
(
    input clk,
    input pload,
    input [7:0] pdata,
    output reg [7:0] q
);
