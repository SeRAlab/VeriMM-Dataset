Design a 4-bit barrel shifter that takes a 4-bit input and a 2-bit shift amount to produce an output. Depending on the value of the shift amount, the module will shift the input data left by 0, 1, or 2 positions, or circularly shift the bits. Specifically, a shift amount of 0 yields the original data, 1 shifts the bits left by one position with the least significant bit wrapping around to the most significant position, 2 shifts by two positions, and a shift amount of 3 yields a three-position shift. If none of these conditions are met, the output is set to zero.
module top_module(
    input [3:0] data_in,
    input [1:0] shift_amount,
    output [3:0] out
);
