Design a JK flip-flop with asynchronous set and reset inputs. The flip-flop should have inputs J, K, clock (clk), asynchronous set (set), and asynchronous reset (reset). The output should be Q, which holds the state of the flip-flop. The output should be updated on the rising edge of the clock. If set is high, Q should be set to 1 regardless of the state of J and K. If reset is high, Q should be set to 0 regardless of the state of J and K. If both set and reset are low, the flip-flop should behave according to the values of J and K on the rising edge of the clock. If J and K are both high, Q should toggle.
