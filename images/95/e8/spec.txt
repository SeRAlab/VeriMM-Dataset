Design a Verilog module that models a 4-bit parallel load register with synchronous enable and clear signals. The module should have an input clock signal (clk), an input load signal (ld), an input clear signal (clr), a 4-bit input data signal (d), and a 4-bit output signal (q). On the rising edge of the clock, if clear is high, q should be set to 0. If load is high, q should be set to the value of d.
module parallel_load_register (
  input clk,
  input ld,
  input clr,
  input [3:0] d,
  output reg [3:0] q);
