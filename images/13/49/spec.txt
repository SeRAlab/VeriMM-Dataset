
Design a 1-bit SR Flip-Flop using Verilog. The flip-flop should have two inputs (S for Set, R for Reset) and one output (Q). The flip-flop should follow the standard behavior where:
- If S=1 and R=0, then Q should be set to 1.
- If S=0 and R=1, then Q should be reset to 0.
- If S=0 and R=0, then Q should retain its previous value.
- If S=1 and R=1, the behavior is typically considered invalid, but for this implementation, Q should remain unchanged.
