

You are tasked with designing a Verilog module for a simple shift register. The module should have the following inputs and outputs:

Inputs:
- `clk`: clock input
- `rst`: asynchronous reset input
- `shift_in`: input data to be shifted in
- `shift`: control signal to initiate shifting

Outputs:
- `shift_out`: output data shifted out

The shift register should be able to shift in 8 bits of data and shift them out in the same order they were shifted in. The shift register should be able to shift the data in on the rising edge of the `shift` signal and shift the data out on the falling edge of the `shift` signal.

You should implement the shift register using a behavioral model.
