Design a 64-bit linear feedback shift register (LFSR) based counter that generates pseudo-random values on each clock cycle. On a low reset signal, the counter and shift register are initialized to zero. During each positive edge of the clock, the LFSR updates its state based on a feedback function involving a specific set of taps, and the current value of the LFSR is assigned to the output Q.
module top_module(
  input                clk,
  input                rst_n,
  output reg  [63:0]   Q
);
