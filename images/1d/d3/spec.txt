
Design a linear voltage regulator in Verilog that takes a 5-bit binary input voltage (0 to 31) and produces a regulated output voltage which is a scaled version of the input. The output should only change on the rising edge of a clock signal and should maintain the last value until the next clock pulse. The scaling factor should be a fixed value, for example, 3 (i.e., output = input * 3). If the output exceeds the maximum value for 5 bits (31), it should be clamped to 31.
