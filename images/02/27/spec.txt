
Design a Verilog module that simulates a basic Flash memory cell. The module should have a data input (D), a control signal (WE) for write enable, a control signal (RE) for read enable, and an output (Q) to indicate the stored data. The memory cell should store the data when WE is high, and it should output the stored data when RE is high. If both WE and RE are low, the module should retain its current state.
