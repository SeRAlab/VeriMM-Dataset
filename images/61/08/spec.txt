Design a Verilog module for a 4-bit up-down counter with synchronous reset. The counter should increment its value on each positive clock edge when the "up" signal is high, decrement when the "down" signal is high, and reset to 4'b0000 when the reset signal is high.

module up_down_counter
(
    input clk,
    input reset,
    input up,
    input down,
    output reg [3:0] count
);
