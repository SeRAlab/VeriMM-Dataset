Design a single-port, 128-word by 1-bit wide RAM module with write capabilities. The module allows data to be written on the rising edge of the clock (WCLK) when the write enable (WE) signal is active. Input data (D) is stored at the address specified by A in the internal memory array, while the output (SPO) reflects the input data and the data output (DPO) provides access to the contents at the address given by DPRA. The RAM is initialized to zero upon reset.
module top_module(WCLK,D,WE,SPO,DPO,A,DPRA);
