
Design a state-space controller for a discrete-time system that takes a 3-bit input representing a state (000 to 111) and a control signal (1-bit), and outputs a 3-bit next state based on the current state and control signal. The controller should have the following behavior:
- If the control signal is 0, the next state remains the same as the current state.
- If the control signal is 1, the next state transitions to the next state cyclically (for example, from 000 to 001, 001 to 010, ..., 111 back to 000).
