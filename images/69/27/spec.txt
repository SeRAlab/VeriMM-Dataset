Design a Verilog module that implements an 8-bit binary up/down-counter with enable and direction control. The counter should increment on the rising edge of the clock if the "enable" signal is high and the "dir" signal is high. The counter should decrement if the "dir" signal is low. The counter should reset to zero when the synchronous reset (sreset) is high. The counter value should be output to the "count" signal.

module top_module
(
    input clk,
    input sreset,
    input enable,
    input dir,
    output reg [7:0] count
);
