Design a 16-bit Arithmetic Logic Unit (ALU) that can perform the following operations based on a 4-bit operation code (opcode):
1. Addition
2. Subtraction
3. Bitwise AND
4. Bitwise OR
5. Bitwise XOR
6. Shift Left
7. Shift Right

The ALU should take two 16-bit input operands and output a 16-bit result. The operation is selected using a 4-bit opcode as follows:
- 0000: Addition
- 0001: Subtraction
- 0010: AND
- 0011: OR
- 0100: XOR
- 0101: Shift Left
- 0110: Shift Right
The ALU should also have a carry output for addition and subtraction operations.
