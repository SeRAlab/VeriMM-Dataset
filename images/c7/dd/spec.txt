

You are tasked with designing a verilog module for a binary counter. The counter should have an input `clock` and an output `q` which is a 4-bit binary value representing the current count. The counter should start at 0 and increment by 1 on each rising edge of the `clock` input. Once the count reaches 15 (1111 in binary), it should reset back to 0. You should use a synchronous design approach and ensure that the counter is glitch-free.

Write a verilog module that implements the binary counter as described above.
