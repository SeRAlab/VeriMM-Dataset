Design a simple EEPROM cell using Verilog. The EEPROM cell should have inputs for data (D), write enable (WE), and a read enable (RE) signal. When WE is high, the data should be written to the EEPROM cell. When RE is high, the stored data should be available on the output (Q). The cell should retain the data until it is overwritten. Ensure appropriate handling of write and read operations.
