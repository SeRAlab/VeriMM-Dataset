Design an 8-bit ADC (Analog to Digital Converter) that takes a 10-bit input value and converts it to an 8-bit output value. The conversion should truncate the 10-bit input to fit into 8 bits by discarding the least significant 2 bits. The module should also have a valid input signal that indicates when the input data is valid. If the valid signal is low, the ADC output should be zero.
