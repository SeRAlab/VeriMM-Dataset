Design a 3-to-1 multiplexer that selects one of three 32-bit input signals (in_a, in_b, in_c) based on a 2-bit select input (sel). The output (out) corresponds to in_a when sel is 00, in_b when sel is 01, and in_c when sel is 10, effectively routing the selected input to the output while ignoring the others. The design utilizes bitwise operations to enable appropriate selection based on the sel input.
module top_module(
	input [31:0] in_a, 
	input [31:0] in_b, 
	input [31:0] in_c, 
	input [1:0] sel,  

	output [31:0] out 
	
);
