Design a JK flip-flop circuit that operates based on the input signals j and k. The circuit transitions between two states, ON and OFF, controlled by the clock and reset signals. The output is HIGH when in the ON state and LOW when in the OFF state. During the clock's positive edge, if reset is active, the state is set to OFF; otherwise, the next state is determined by the current state and the j and k inputs. If j is HIGH while in the OFF state, the flip-flop transitions to the ON state, and if k is HIGH while in the ON state, it transitions back to OFF.
module top_module(
    input clk,
    input reset,    
    input j,
    input k,
    output out);
