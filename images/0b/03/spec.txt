Design a convolutional encoder in Verilog that takes a 1-bit input data stream and generates a 2-bit output according to the specified polynomial encoding equations. The specific encoding equations to implement are:
- Output 1: (Input ⊕ Input_delay)
- Output 2: (Input ⊕ Input_delay ⊕ Input_delay_delay)
The encoder should also have a reset input that initializes the internal state.
