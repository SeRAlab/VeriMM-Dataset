
Design a simple SATA controller state machine that manages the SATA link states. The controller should have the following states: IDLE, ACTIVE, and SLEEP. The state transitions are as follows:
- From IDLE to ACTIVE on receiving a start signal.
- From ACTIVE to SLEEP on receiving a sleep signal.
- From SLEEP to ACTIVE on receiving a wakeup signal.
- From ACTIVE to IDLE on receiving an end signal.
The state machine should output the current state as a 2-bit value (00 for IDLE, 01 for ACTIVE, and 10 for SLEEP).
