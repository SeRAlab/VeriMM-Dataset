Design a signed 16-bit comparator that determines the relationship between two input values (in1 and in2). The module computes the difference between the two inputs and outputs a 2-bit code indicating whether in1 is less than, greater than, or equal to in2. Specifically, the output will be 11 if in1 < in2, 10 if in1 > in2, 01 if in1 = in2, and 00 in an undefined state.
module top_module(
		input signed [15:0] in1, in2,
		output reg [1:0] result
	);
