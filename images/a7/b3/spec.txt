Implement a Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs:
1. state G (S = 1).
2. state H (S = 0).
3. state I (S = 1).
4. state J (S = 0).

State transitions:
1. From state G: If d = 0, then transition to state H. If d = 1, then transition to state I.
2. From state H: If d = 0, then transition to state J. If d = 1, then transition to state G.
3. From state I: If d = 0, then transition to state J. If d = 1, then transition to state H.
4. From state J: If d = 0, then transition to state I. If d = 1, then transition to state G.

Assume that you want to Implement the FSM using two flip-flops and state codes w[1:0] = 00, 01, 10, 11 for states G, H, I, J, respectively. Implement just the next-state logic for w[1] in Verilog. The output S is w[1].
