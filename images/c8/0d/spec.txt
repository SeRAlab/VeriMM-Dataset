

You are tasked with designing a Verilog module that takes in a clock signal, a single-bit input signal `din`, and an active-low reset signal `reset_n`. The module should contain a single D flip-flop that is clocked by the input clock signal. When the reset signal is asserted, the output of the flip-flop should be set to 0. When the reset signal is de-asserted, the output of the flip-flop should be set to the value of the `din` input signal.

Your module should be named `single_dff_reset`.
