

You are tasked with designing a Verilog module for a 4-bit adder that takes two 4-bit inputs (A and B) and produces a 4-bit output (S). The adder should also have a carry-in input (Cin) and a carry-out output (Cout). The adder should be implemented using a ripple carry adder.

Your module should have the following inputs and outputs:

Inputs:
- A: 4-bit input
- B: 4-bit input
- Cin: carry-in input

Outputs:
- S: 4-bit output
- Cout: carry-out output

Your module should be named "ripple_adder" and should use the following Verilog code as a starting point:

```
module ripple_adder (
  input [3:0] A,
  input [3:0] B,
  input Cin,
  output [3:0] S,
  output Cout
);
  // your code here
endmodule
```
