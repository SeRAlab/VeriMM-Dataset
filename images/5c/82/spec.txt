Design a 4-bit shift register-based counter with an adjustable loading feature. The circuit initializes to zero upon reset and can load a 4-bit value when the load input is non-zero. During normal operation, it shifts its bits and computes the next state based on a combination of its current bits and specified logic, updating the output register Q accordingly. This setup allows for sequential counting, with the ability to set a specific initial value dynamically.
module top_module(
  input                clk,
  input                rst_n,
  input  [3:0]         load,
  output reg  [3:0]    Q
);
