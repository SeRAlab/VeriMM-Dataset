
Design a simple virtual page table that can handle virtual addresses and translate them to physical addresses. The virtual address consists of a page number and an offset. The page table maps virtual pages to physical frames. The system should support 4 virtual pages, each of size 16 bytes, where the physical memory can hold 4 frames, each also of size 16 bytes. Additionally, implement a valid bit for each page entry to indicate if the page is currently mapped.
