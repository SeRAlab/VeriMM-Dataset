Design a simple arithmetic module that performs either addition or subtraction of two 8-bit input values, A and B. The operation is controlled by the CTRL signal; when CTRL is 0, the module outputs the sum of A and B, and when CTRL is 1, it outputs the result of A minus B.
module top_module(
   input [7:0] A,
   input [7:0] B,
   input CTRL,
   output reg [7:0] RESULT
);
