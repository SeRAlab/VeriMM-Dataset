- If A1 is low and A2 is high, X should be low
- If A1 and A2 are both high or both low, X should be the same as A3
- If B1 is high, X should be the opposite of whatever the previous logic determined

Write the logic for the sky130_fd_sc_lp__o31a base module using Verilog.
