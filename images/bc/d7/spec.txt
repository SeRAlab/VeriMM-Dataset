Design a circuit that performs the XOR operation on two input signals, `a` and `b`, and generates three outputs. The first output, `out_assign`, provides a combinational result of the XOR directly. The second output, `out_always_comb`, is also a combinational XOR result activated by a sensitivity list that includes both inputs. The third output, `out_always_ff`, captures the XOR result on the rising edge of the clock signal, providing a registered version of the same logic. This module effectively illustrates both combinational and sequential logic interface handling for XOR operations.
