
Design a simple Ethernet MAC controller that includes a 64-bit transmit data register (`tx_data`) and a 64-bit receive data register (`rx_data`). The MAC controller should have inputs for transmit enable (`tx_en`), a clock signal (`clk`), and a reset signal (`reset`). When `tx_en` is asserted, the value on the data input line (`data_in`) should be stored in the `tx_data` register on the rising edge of the clock. When reset is asserted, both `tx_data` and `rx_data` should be cleared to zero. The controller should also provide an output `data_out` which presents the content of the `rx_data` register.
