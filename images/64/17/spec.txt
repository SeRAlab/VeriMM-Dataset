Design a Verilog module for a 10-bit binary counter with load and synchronous reset. The counter should count up on each positive clock edge. The load signal should load a given value into the counter. The reset signal should synchronously set the counter to 10'b0000000000.

module counter_with_load
(
    input clk,
    input reset,
    input load,
    input [9:0] load_value,
    output reg [9:0] count
);
