Design a finite state machine (FSM) that toggles between two states, A and B, based on the input signal 'in' and clock 'clk'. When 'areset' is high, the FSM resets to state B. In state A, if 'in' is high, it remains in state A; if 'in' is low, it transitions to state B. Conversely, in state B, if 'in' is high, it stays in state B, but if 'in' is low, it moves to state A. The output 'out' is set high when the FSM is in state B.
module top_module(
	input clk,
	input in,
	input areset,
	output out
);
