Implement the Verilog module based on the following description.
Design a simple 4-bit parallel load register with asynchronous reset.
(1) reset: Clears the register.
(2) load: Enables parallel loading of data into the register.
(3) data_in: The parallel data input.
(4) q: The contents of the register.

module top_module(
    input clk,
    input reset,
    input load,
    input [3:0] data_in,
    output reg [3:0] q);
