Implement the Verilog module based on the following description.
Consider a state machine with the following states and their corresponding outputs: 
1. state S (output 0).
2. state T (output 1).
3. state U (output 1).

State transitions:
1. From state S: If t = 0, then transition to state T. If t = 1, then transition to state U.
2. From state T: If t = 0, then transition to state S. If t = 1, then transition to state U.
3. From state U: If t = 0, then transition to state T. If t = 1, then transition to state S.

Resets into state S. For this part, assume that a one-hot code is used with the state assignment b[3:1] = 001, 010, 100 for states S, T, U, respectively.

Write Verilog for the next-state signals B2 and B3 corresponding to signal b[2] and b[3]. Derive the logic equations by inspection assuming a one-hot encoding.
