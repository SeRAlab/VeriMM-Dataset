Design a D flip-flop with asynchronous reset functionality. On the rising edge of the clock signal (CK), if the reset signal (RST) is low, the output Q is set to 0 and QN is set to 1. If the reset is not active, the output Q takes the value of the data input (D), while QN outputs the inverse of D. This module can be utilized in digital circuits requiring both storage and reset capabilities.
module top_module(
    input CK,
    input D,
    input RST,
    output reg Q,     // Changed Q to output reg
    output reg QN     // Changed QN to output reg
);
