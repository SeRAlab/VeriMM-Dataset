On the rising edge of the clock (Clk), the flip-flop captures the value of the data input (D) and transfers it to the output (Q). If the clear signal (Clr) is asserted, regardless of the clock, the output (Q) is immediately set to LOW. This functionality is essential for memory elements in digital circuits that require resetting without waiting for a clock pulse.
