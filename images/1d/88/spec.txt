Design a 16-bit DRAM cell with read and write functionality. The DRAM cell should have inputs for a 16-bit data bus, a write enable signal, a read enable signal, and a clock signal. The DRAM cell should store data on a rising clock edge when write enable is high, and it should output the stored data onto the data bus when read enable is high. The DRAM cell should also have a reset functionality that clears the stored data when a reset signal is asserted.
