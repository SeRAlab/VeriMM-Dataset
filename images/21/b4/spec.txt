Design a simple 2-bit branch predictor using a 2-bit saturating counter. The branch predictor should predict taken or not taken based on the previous outcomes of two branches. The predictor state should be updated based on the actual outcome of the branch. The input will be a 2-bit branch identifier and an actual branch outcome (1 for taken and 0 for not taken). The output will indicate the predicted outcome (1 for taken, 0 for not taken).
