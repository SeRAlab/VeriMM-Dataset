

You have been tasked with designing a verilog module for a 4-bit binary up counter with synchronous reset functionality. The counter should increment on the rising edge of the clock signal and reset to 0 on the rising edge of the reset signal. The module should have the following inputs and outputs:

Inputs:
- `CLK`: a clock signal
- `RST`: a synchronous reset signal

Outputs:
- `Q`: a 4-bit output representing the current count value

You should use the following module template:

```
module up_counter_4bit_sync_reset (
  input CLK,
  input RST,
  output reg [3:0] Q
);

  // your code here

endmodule
```

Please write the verilog code for the up_counter_4bit_sync_reset module.
