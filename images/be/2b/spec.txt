Design a module for a one-bit full adder that computes the sum of three input bits: two primary bits (a, b) and a carry-in bit (cin). The module outputs the sum (s) and the carry-out (cout) signals. The sum is calculated using the XOR operation on the inputs, and the carry-out is derived from the OR operation of the carries produced by the input combinations. This design can be utilized in larger arithmetic circuits for binary addition.
module top_module(
  input a,
  input b,
  input cin,
  output s,
  output cout
);
