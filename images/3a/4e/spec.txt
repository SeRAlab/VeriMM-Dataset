
Design a Direct Memory Access (DMA) controller in Verilog that allows a peripheral device to read/write data to/from memory without involving the CPU. The DMA controller should have the following inputs and outputs:
- Inputs: 
  - clk: Clock signal
  - rst: Reset signal
  - start: Signal to start the DMA transfer
  - src_addr: Source address in memory
  - dest_addr: Destination address in memory
  - mem_data: Data from memory
- Outputs:
  - dma_busy: Signal indicating that the DMA is currently busy
  - transfer_complete: Signal indicating that the transfer is complete
  - data_out: Data being transferred to the destination
