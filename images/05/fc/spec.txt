Design a simple interrupt controller that has the following functionality: It takes a 4-bit input for interrupt requests (IRQ[3:0]) and a single-bit input for acknowledge (ACK). The output will be a 4-bit interrupt vector (IV[3:0]). The controller should generate the interrupt vector based on the highest priority interrupt request that is acknowledged. If no interrupt request is acknowledged, the output should be zero. The priority order is IRQ[3] > IRQ[2] > IRQ[1] > IRQ[0].
