Design a combinational logic circuit that produces an output X based on the logical conditions of four input signals (A1, A2, B1, C1). The output X is determined by the following rules: if A1 is true and A2 is false, output B1; if A1 is false and A2 is true, output C1; if both A1 and A2 are true, output a constant high (1); otherwise (if both A1 and A2 are false), output low (0).
module top_module(
    output X,
    input A1,
    input A2,
    input B1,
    input C1
);
