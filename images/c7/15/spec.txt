

You are tasked with designing a module in Verilog that implements a simple counter. The counter should have a synchronous reset input and an enable input. When the enable input is high, the counter should increment on every rising edge of the clock input. When the reset input is high, the counter should be reset to zero.

The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock input
- `rst`: a synchronous reset input
- `en`: an enable input

Outputs:
- `count`: the current count value

The module should be named `simple_counter` and should be no longer than 200 lines of Verilog code.
