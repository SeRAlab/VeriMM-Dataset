Design a streaming data operation module that implements a circular buffer, allowing for the storage and retrieval of 16-bit wide data inputs. The module utilizes a FIFO (First-In-First-Out) mechanism with read and write pointers to manage data flow. When `in_valid` is asserted and the buffer is not full, it stores incoming data into the buffer and updates the write pointer. Conversely, when `out_valid` is asserted and the buffer is not empty, it outputs the data at the read pointer and increments it. The module supports reset functionality to initialize pointers and state flags, ensuring proper operation in a streaming data context.

    input clk,
    input in_valid,

    input out_valid,
