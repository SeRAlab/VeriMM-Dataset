Design an 8-bit right shift register with a parallel load feature. The shift register should have an input to load data in parallel, a clock signal for shifting, and a reset signal to clear the register. When the load signal is high, the register should load the input data. When the load signal is low, the register should shift its contents to the right on each clock cycle, and the least significant bit (LSB) should be filled with a zero. The reset signal should clear the register to 0 on its activation.
