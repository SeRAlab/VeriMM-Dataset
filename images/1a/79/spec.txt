
Design a simple WiFi state machine that can be used to track the connection status of a device. The state machine should have three states: DISCONNECTED, CONNECTING, and CONNECTED. The state transitions are as follows:
- From DISCONNECTED, it transitions to CONNECTING on a 'connect' signal.
- From CONNECTING, it transitions to CONNECTED on a 'connected' signal.
- From CONNECTED, it transitions back to DISCONNECTED on a 'disconnect' signal.
The state machine should have an output that indicates the current state of the WiFi connection.
