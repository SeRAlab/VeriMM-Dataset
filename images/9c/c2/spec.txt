Design a state machine that generates a Gray code sequence in an n-bit format, where n is set to 4 by default. The circuit utilizes a clock signal for state transitions and a reset input to initialize the state to zero. On each clock cycle, if not in reset, the current state is incremented; if the maximum state is reached (2^n), the state wraps around to zero. The output is continuously updated to reflect the corresponding Gray code representation of the current binary state through a dedicated conversion function.
module top_module(
  input clk, // clock signal
  input rst, // reset signal
  output reg [n-1:0] state // Gray code state
);
