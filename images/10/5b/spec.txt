
Create a Verilog module to perform matrix multiplication for two 2x2 matrices. The design should take two 2x2 matrices as inputs and produce a 2x2 matrix as output. The matrices should be defined as follows:
Input matrices A and B:
A = | a11 a12 |
    | a21 a22 |

B = | b11 b12 |
    | b21 b22 |

Output matrix C:
C = | c11 c12 |
    | c21 c22 |

Where:
c11 = a11 * b11 + a12 * b21
c12 = a11 * b12 + a12 * b22
c21 = a21 * b11 + a22 * b21
c22 = a21 * b12 + a22 * b22
