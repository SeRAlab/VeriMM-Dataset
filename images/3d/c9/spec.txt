
Create a Verilog module that simulates a simplified SD card interface. The module should take an 8-bit command input (cmd) and generate a response signal (resp) based on predefined command values. If the command is 8'h01, the response should be 8'hFF; for command 8'h02, the response should be 8'hAA; for command 8'h03, the response should be 8'h55; for any other command, the response should be 8'h00. Additionally, the module should have a valid input signal (valid), which indicates whether the command is valid.
