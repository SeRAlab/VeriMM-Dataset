
Design a simple EEPROM cell model in Verilog that can store a single bit of data. The model should have inputs for `write_enable`, `data_in`, and `read_enable`, and outputs for `data_out`. When `write_enable` is high, the value of `data_in` should be stored. When `read_enable` is high, the stored value should be output on `data_out`. If both `write_enable` and `read_enable` are low, `data_out` should remain unchanged.
