Design a 4-to-1 multiplexer with an enable signal. Four 4-bit wide input vectors (in0, in1, in2, in3) are selected based on a 2-bit selector input (sel). When the enable signal (en) is high, the multiplexer outputs the selected 4-bit input; if the enable signal is low, the output will be forced to zero.
module top_module(
  input [3:0] in0,
  input [3:0] in1,
  input [3:0] in2,
  input [3:0] in3,
  input [1:0] sel,
  input en,
  output [3:0] out
);
