
Design a simple Verilog module that takes a 8-bit input pixel value representing the intensity of a grayscale image and quantizes it to a 2-bit value. The quantization should map the pixel value to one of four levels: 
- 0 for [0, 63],
- 1 for [64, 127],
- 2 for [128, 191],
- 3 for [192, 255].
The module should output the quantized value.
