Create a Verilog module that implements a simple sliding window protocol. The module should manage the sending of packets with a specified window size, handle acknowledgments, and keep track of the sequence numbers. The inputs should include the `send` signal to send a packet, `ack` signal to acknowledge a received packet, `reset` for resetting the protocol state, and `clk` for clock signal. The outputs should include `window_start` and `window_end` representing the current window range for sending packets.
