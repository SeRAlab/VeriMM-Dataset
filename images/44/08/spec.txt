Create a Verilog module for a 4-bit up/down counter with enable and synchronous reset. Assume positive clock/clk edge triggered. The counter should count up when the up_down signal is high and down when it is low. When enable is low, the counter should hold its value. When reset is high, the counter should reset to 0.

module up_down_counter (
  input clk,
  input reset,
  input enable,
  input up_down,
  output reg [3:0] count
);
