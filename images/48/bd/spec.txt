Design a 4-to-1 multiplexer with an enable control. The module selects one of the four 4-bit input lines (in0, in1, in2, in3) based on a 2-bit selection input (sel). If the enable signal (en) is asserted, the output will reflect the selected input; otherwise, the output will be set to zero regardless of the selection. This allows for both multiplexer functionality and controlled signal gating.
module top_module(
    input [3:0] in0,
    input [3:0] in1,
    input [3:0] in2,
    input [3:0] in3,
    input [1:0] sel,
    input en,
    output reg [3:0] out
);
