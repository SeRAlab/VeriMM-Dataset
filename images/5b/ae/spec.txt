Design a 2-bit wide dual-port RAM module that allows for read and write operations. On each positive edge of the clock, the module writes the value from the input data (din) to the addressed location (adr) in RAM while simultaneously outputting the previous value stored at that location (ram[adr]) to the output register (q). This effectively allows for simultaneous data retrieval and storage in a small memory array.
module top_module(input clk,input [1:0] adr,input [1:0] din,output reg [1:0] q);
