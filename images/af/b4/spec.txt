Design a circuit that provides arithmetic and logical operations on two input bits, a and b, along with a carry-in bit cin. The module computes the sum and carry of a half adder, outputting the sum as one output (sum) and the carry as another (cout). Additionally, it implements an XNOR gate using NAND gates; based on the carry output, the final output (out) is determined by selecting between the XNOR result and the half adder sum. When the carry is zero, the output is the XNOR result; otherwise, it outputs the sum.
module top_module( 
    input a, 
    input b, 
    input cin,
    output cout, 
    output sum,
    output out );
