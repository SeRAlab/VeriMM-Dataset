Design a 4-bit barrel shifter that can perform three distinct operations based on the input control signals: shift left, shift right, or rotate right. When the `shift_left` signal is asserted, the data is shifted left by one bit, inserting a zero at the least significant bit. When `shift_right` is asserted, the data is shifted right by one bit, inserting a zero at the most significant bit. If `rotate_right` is activated, the least significant bit is moved to the most significant bit position while shifting the other bits to the right. If none of the control signals are active, the module outputs the original data unchanged.
module top_module(
    input [3:0] data,
    input shift_left,
    input shift_right,
    input rotate_right,
    output reg [3:0] shifted_data
);
