Design a 32-bit data bus multiplexer (MUX) that selects one of four 32-bit input buses based on a 2-bit select signal. The output should be the selected input bus. The input buses and the select signal should be defined as follows: `input [31:0] bus0`, `input [31:0] bus1`, `input [31:0] bus2`, `input [31:0] bus3`, `input [1:0] sel`, `output [31:0] dout`.
