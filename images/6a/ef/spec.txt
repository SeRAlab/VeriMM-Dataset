Implement a parity generator and checker for an n-bit data input, where n is parameterized (defaulting to 8 bits). The module produces a parity bit, p, calculated as the XOR of all input bits, d, which indicates even or odd parity. Additionally, it includes a parity check output, e, that evaluates if the received parity matches the expected parity of the input data, thus enabling error detection in data transmission.
module top_module(
  input [n-1:0] d,
  output p,
  output e
);
