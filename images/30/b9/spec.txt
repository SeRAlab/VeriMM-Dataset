
Design a 16-bit SRAM cell that can store a 16-bit value and supports reading and writing. The SRAM cell should have an input data line (data_in), an output data line (data_out), a write enable signal (we), and a clock signal (clk). When the write enable (we) is high, the data from data_in should be written to the SRAM cell on the rising edge of the clock. When we is low, the data_out should reflect the stored value in the cell.
