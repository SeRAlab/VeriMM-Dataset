Please act as a professional verilog designer.

Design a 2-to-1 multiplexer using Verilog. The multiplexer has a selection signal to choose between two 1-bit input signals.

Module name:  
    mux_2to1  

Input ports:
    a: Input signal a.
    b: Input signal b.
    sel: 1-bit Selection signal.

Output ports:
    y: Output signal.

Implementation:
Multiplexer operation:
If the selection signal (sel) is 0, the output (y) is assigned the value of input a.
If the selection signal (sel) is 1, the output (y) is assigned the value of input b.
