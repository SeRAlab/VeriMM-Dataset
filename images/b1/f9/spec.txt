Design a synchronous 8-bit flip-flop adder. This module captures 8 input data bits (d) on the falling edge of the clock signal, while also incorporating an 8-bit synchronous reset signal (reset) that clears individual bits of the flip-flop register (q_reg) when asserted. The output (q) is the sum of the captured data bits, effectively calculating the total of the 8 bits stored in the flip-flops.
module top_module(
    input clk,
    input [7:0] reset,      // Synchronous reset
    input [7:0] d,
    output [7:0] q
);
