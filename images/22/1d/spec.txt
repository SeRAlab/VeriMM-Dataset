Design a Bluetooth module status signal generator. The module takes two inputs: `power_on` (a 1-bit signal indicating if the Bluetooth module is powered on) and `connected` (a 1-bit signal indicating if the module is connected to a device). The output `status` should be a 2-bit signal that encodes the following states: 00 for 'OFF', 01 for 'READY', and 10 for 'CONNECTED'. If `power_on` is low, the `status` should be 'OFF'. If `power_on` is high and `connected` is low, `status` should be 'READY'. If both `power_on` and `connected` are high, `status` should be 'CONNECTED'.
