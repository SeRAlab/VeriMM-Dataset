Design a 2-to-1 multiplexing circuit that selects between two 32-bit input options (opt1 and opt2) based on a select signal (sel) and an enable signal. When enable is high, the output (muxout) reflects the chosen input: opt1 if sel is high, or opt2 if sel is low. When enable is low, the output retains its previous value, effectively disabling output changes.
module top_module(
input[31:0] opt1, opt2, 
input sel, enable,
output reg[31:0] muxout
);
