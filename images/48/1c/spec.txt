Design a synchronous data memory module that operates with a clock signal. It allows for reading and writing 8-bit wide data to a memory array of 256 locations. When the write enable (`wrEn`) signal is active, data from `wrData` is stored at the specified address; when the read enable (`rdEn`) signal is active, the data from the specified address is outputted to `Data`. The output data is updated on the positive edge of the clock.
module top_module(Clk, rdEn, wrEn, addr, wrData, Data);
