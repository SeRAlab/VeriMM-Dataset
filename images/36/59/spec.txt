Design a fixed-priority arbiter in Verilog that grants access based on a three-level priority scheme. There are four request inputs (req[3:0]) and one output signal (grant[3:0]) that indicates which request has been granted. The arbiter should follow the priority order: req[0] > req[1] > req[2] > req[3]. If multiple requests are made simultaneously, the highest priority request should be granted. The arbiter should remember the last granted request to ensure fairness in request handling.
