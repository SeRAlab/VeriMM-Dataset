Design a synchronous 8-bit adder with reset functionality. The module computes the sum of two 8-bit inputs, a and b, when enabled by the control signal (ctrl) on the rising edge of the clock (clk). If the reset (rst) signal is active, the output (sum) is set to zero. This design is suitable for applications requiring periodic addition of values with the ability to reset the output.
module top_module(
    input clk, rst, ctrl,
    input [7:0] a, b,
    output reg [15:0] sum
);
