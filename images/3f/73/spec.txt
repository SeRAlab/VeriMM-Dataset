Design a simple Direct Memory Access (DMA) controller that transfers data from a source address to a destination address. The controller will have a clock input, a reset input, a start signal, a done signal, a source address input, a destination address input, and a data input. Upon receiving the start signal, the DMA controller will begin the transfer of data from the source address to the destination address. The transfer will take place in a single clock cycle, and the done signal will be asserted when the transfer is complete.
