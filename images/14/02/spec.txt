Design a rising edge detector in Verilog. The edge detector should have a single input signal `signal_in` and a single output signal `edge_detected`. The `edge_detected` signal should be high (1) for one clock cycle when a rising edge is detected on `signal_in`. Assume that the input `signal_in` is synchronized with a clock signal `clk`. The output should remain low (0) when there is no rising edge.
