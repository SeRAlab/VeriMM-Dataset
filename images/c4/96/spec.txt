

You are tasked with designing a Verilog module that will perform a specific set of operations on input signals. The module should be named `Bitwise_Or` and should have the following inputs and outputs:

- `in0`, `in1`: two 32-bit input signals
- `enable`: a single-bit input signal that indicates whether the module should perform the bitwise OR operation on the input signals
- `out`: a 32-bit output signal that contains the result of the bitwise OR operation

The `Bitwise_Or` module should perform the bitwise OR operation on the `in0` and `in1` signals when the `enable` signal is high. When the `enable` signal is low, the `out` signal should be set to all zeros.

You should ensure that the module is designed to be synthesizable and meets the following requirements:

- The module should be designed using only combinational logic
- The module should not use any sequential logic
- The module should not use any other modules or external libraries
