Design a simple cache memory with 4 blocks using the Least Recently Used (LRU) replacement policy. The cache should accept two inputs: a 4-bit address and a read/write signal. The cache should output the data stored at the given address and indicate whether it was a hit or miss. Implement a FIFO replacement policy as well for comparison. Ensure the cache can store 4 different data items, and manage hits and misses appropriately.
