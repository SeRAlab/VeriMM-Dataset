Design a Direct Memory Access (DMA) controller in Verilog. The DMA controller should be able to initiate a transfer from a source address to a destination address when it receives a start signal. It should have the capability to specify the number of bytes to transfer, and a done signal should be asserted once the transfer is complete. The controller should also include a read signal to indicate when data is being read from memory and a write signal to indicate when data is being written to memory.
