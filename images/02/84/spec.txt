Design a convolutional encoder in Verilog that encodes a 1-bit input data stream into a 2-bit output stream. The convolutional encoder should have a constraint length of 3 and generate output based on the following generator polynomials: G1 = 111 (octal 7) and G2 = 101 (octal 5). The encoder should have a valid input signal to indicate when the input data is present and a clock signal to trigger the encoding process. The output should be valid for one clock cycle after the input is valid.
