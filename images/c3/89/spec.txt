

You are tasked with designing a module that implements a rising-edge triggered D flip-flop with asynchronous reset and set. The module should have the following inputs and outputs:

Inputs:
- `clk`: a clock signal.
- `rst`: an asynchronous active-low reset signal.
- `set`: an asynchronous active-low set signal.
- `d`: the data input.

Outputs:
- `q`: the output of the flip-flop.
- `qn`: the complement of the output.

The module should operate as follows:
- When `rst` is asserted, `q` and `qn` should both be reset to 0.
- When `set` is asserted, `q` and `qn` should both be set to 1.
- On the rising edge of `clk`, `q` and `qn` should be updated with the value of `d`.

You should implement the module in Verilog within 200 lines of code.
