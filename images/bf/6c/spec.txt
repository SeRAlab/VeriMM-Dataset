Design a one-bit wide, 2-to-1 multiplexer. The module selects between two inputs, A and B, based on the select signal S. When S is low (0), the output Y reflects the value of A; when S is high (1), it reflects the value of B. The implementation utilizes a standard cell from the sky130 library to perform the multiplexing operation while integrating connections for power and ground.
module top_module(
    input A,
    input B,
    input S,
    output Y
);
