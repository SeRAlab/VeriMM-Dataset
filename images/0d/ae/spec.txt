
Design an interrupt controller that can handle multiple interrupt requests. The controller should have the following features:
- It has 4 interrupt request inputs (`irq0`, `irq1`, `irq2`, `irq3`).
- A single output (`irq_out`) that indicates which interrupt is being serviced.
- A priority mechanism where `irq0` has the highest priority and `irq3` has the lowest.
- It should include an enable signal to allow interrupt servicing.
- The controller should clear the interrupt when the servicing is complete.
