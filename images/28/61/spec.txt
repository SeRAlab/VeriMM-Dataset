
Design a 5-bit linear voltage regulator controller using combinational logic. The circuit should take a 5-bit input voltage (Vin) and output a 5-bit regulated voltage (Vout) based on specified conditions: 
1. If Vin < 16, Vout should be equal to Vin.
2. If 16 <= Vin < 32, Vout should be equal to 16.
3. If 32 <= Vin < 48, Vout should be equal to 32.
4. If Vin >= 48, Vout should be equal to 48.
