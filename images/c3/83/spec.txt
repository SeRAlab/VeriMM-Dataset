

You are tasked with designing a module that implements a 4-bit binary counter with a synchronous reset. The module should have the following inputs and outputs:

Inputs:
- `CLK`: the clock signal
- `RESET`: the synchronous reset signal

Outputs:
- `Q`: a 4-bit binary output representing the current count

The counter should increment on the rising edge of the clock signal and reset to 0 on the rising edge of the reset signal. The counter should count up from 0 to 15 (1111 in binary) and then wrap around to 0.

Design a Verilog module that implements this 4-bit binary counter with a synchronous reset.
