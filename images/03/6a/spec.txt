Design a finite state machine (FSM) that simulates a simple A* search algorithm. The FSM should take the current state, the heuristic cost, and the actual cost as inputs and output the next state based on the A* logic. The states could represent various positions in a grid, and the FSM should transition between these states based on the input costs. The FSM will have three inputs: `current_state`, `heuristic_cost`, `actual_cost`, and one output `next_state`.
