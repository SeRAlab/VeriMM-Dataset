Design a simple 8-bit calculator that performs basic arithmetic operations based on a 2-bit operation selector. The module accepts two 8-bit inputs (A and B) and provides an 8-bit output (result) that can represent the sum, difference, product, or quotient of A and B, depending on the value of the operation code (op). Specifically, op=00 corresponds to addition, op=01 to subtraction, op=10 to multiplication, and op=11 to division, with built-in error handling to prevent division by zero, resulting in a zero output.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input [1:0] op,
    output reg [7:0] result
);
