Design a synchronous shift register with eight stages (flip-flops). This module shifts an input bit through the register on each positive clock edge, effectively moving the input data through the chain of flip-flops. It has an asynchronous reset input, which, when activated, clears all the flip-flops to zero. The output reflects the value in the last flip-flop, allowing for the retrieval of data after it has been shifted through the register.
module top_module(
  input in,
  input clk,
  input rst,
  output out
);
