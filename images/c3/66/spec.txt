

You are tasked with designing a module that takes in a 9-bit control signal `ctrl` and outputs a 4-bit signal `td_mode`. The control signal `ctrl` is used to select one of eight possible values for `td_mode`. The mapping of control signal values to `td_mode` values is as follows:

| Control Signal | td_mode |
| :------------: | :-----: |
|     000        |  0000   |
|     001        |  1000   |
|     010        |  0100   |
|     011        |  1100   |
|     100        |  0010   |
|     101        |  1010   |
|     110        |  0101   |
|     111        |  1111   |

Your module should be named `td_mode_selector` and should take in the following inputs and outputs:

Inputs:
- `clk`: a clock signal
- `rst`: a synchronous reset signal
- `ctrl`: a 9-bit control signal

Outputs:
- `td_mode`: a 4-bit signal representing the selected `td_mode` value

Your module should be implemented using behavioral Verilog and should be no more than 200 lines of code.
