

You have been hired by a hardware design company to implement a new component for a digital circuit. The component is a 2-input AND gate with an additional enable input. The gate should only output a logic high when both inputs are high and the enable input is also high. Otherwise, the output should be a logic low. 

You are provided with a skeleton code for the component, which includes the input and output ports, as well as voltage supply signals. Your task is to complete the implementation of the AND gate component in Verilog.

```
module and_gate (
    input  a,
    input  b,
    input  en,
    output out
);

    // Your code here

endmodule
```

Please complete the implementation of the AND gate component in Verilog, using the input and output ports provided.
