Design a circuit that converts a 4-bit Binary Coded Decimal (BCD) input into a 7-segment display representation. The module takes a 4-bit BCD input and an additional input for the decimal point (dp), and outputs an 8-bit signal where the lower 7 bits represent the appropriate segments to be illuminated for the corresponding BCD digit. The 8th bit is used to control the display of the decimal point.
module top_module(
    input wire [3:0] bcd,
    input wire dp,
    output reg [7:0] seg  
   );
