Develop a clock gating circuit that selectively enables or disables the clock signal based on two input control signals. When the enable (EN) signal is high and the test enable (TE) signal is low, the output (ENCLK) follows the input clock (CLK). In all other cases, the output is driven low, effectively stopping the clock signal. This design is commonly used to reduce power consumption by turning off clock signals to inactive modules within a digital system.
module top_module(
    input CLK,
    input EN,
    input TE,
    output reg ENCLK
);
