Design a 4-to-1 multiplexer that selects one of four 4-bit wide input data lines (A, B, C, D) based on the values of two selection inputs (SEL0 and SEL1). The output (Y) reflects the selected input, where SEL0 and SEL1 determine which input to route to the output: 00 for A, 01 for B, 10 for C, and 11 for D.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input [3:0] C,
    input [3:0] D,
    input SEL0,
    input SEL1,
    output reg [3:0] Y
);
