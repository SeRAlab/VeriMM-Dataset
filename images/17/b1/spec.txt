Design a Verilog module that performs Run-length encoding (RLE) on a binary input stream. The module should take a stream of binary values and output the run-length encoded data, which consists of pairs of counts and values. The input will be a binary sequence and the output will be pairs indicating how many times each binary value appears consecutively. The module should be able to handle sequences of varying lengths. The output should be valid for the clock cycles corresponding to the input data.
