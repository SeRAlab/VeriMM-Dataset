Design a 4-bit SRAM cell that can read and write data. The SRAM cell should have a write enable (WE) signal, an input data signal (D), an output data signal (Q), and a clock signal (CLK). When WE is high, the data on D should be written to Q on the rising edge of CLK. When WE is low, Q should hold its value, and during a read operation, Q should be updated with the current stored data.
