Design a 4-bit ripple carry adder that computes the sum of two 4-bit binary numbers (A and B) along with an incoming carry bit (carry_in). The module outputs a 4-bit sum (S) and a carry-out signal (carry_out). The sum is calculated by adding A, B, and carry_in, while the carry_out indicates whether there is a carry generated from the most significant bit during the addition process.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input carry_in,
    output [3:0] S,
    output carry_out
);
