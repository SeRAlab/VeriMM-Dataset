Design a power gating circuit that controls the power supply to a module based on a control signal. The circuit should have two inputs: a control signal (`ctrl`) and a data signal (`data_in`). When `ctrl` is high, the `data_out` should output the value of `data_in`; when `ctrl` is low, `data_out` should output a fixed value (e.g., `5'b00000`). The circuit must be implemented using combinational logic.
