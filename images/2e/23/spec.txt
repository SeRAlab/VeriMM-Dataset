Create an 8-bit SRAM cell module that supports read and write operations. The module should have inputs for a data input (8 bits), an address (3 bits for 8 addresses), a read enable (1 bit), a write enable (1 bit), and a clock (1 bit). The output should be the data read from the specified address. The module should support storing data in memory when write enable is high and reading data from memory when read enable is high.
