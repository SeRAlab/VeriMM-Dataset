Design a one-bit wide, 2-to-1 multiplexer. The module selects between two inputs, A and B, based on the value of the select signal, SEL. When SEL is 0, the output OUT is assigned the value of A; when SEL is 1, OUT takes the value of B. This functionality allows for the dynamic selection between two signal paths in a circuit.
module top_module(
    input A,
    input B,
    input SEL,
    output reg OUT
);
