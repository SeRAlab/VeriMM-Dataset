Design a 4-bit arithmetic module that performs addition and subtraction operations based on a 2-bit control signal. When the control signal is 00, the module outputs the sum of the input values a and b. When the control signal is 01, it outputs the difference (a - b). For any other control signal values, the output is set to zero, effectively creating a simple arithmetic unit.
module top_module(input [3:0] a, b, input [1:0] control, output reg [3:0] out);
