Design a dual-port memory module functioning as a simple RAM. It allows 32-bit data to be written to and read from addresses that are aligned to 4-byte boundaries. The memory is updated on the rising edge of the clock when the `mem_write` signal is asserted. The module outputs the data at the specified address, enabling both storage and retrieval of data in a clocked manner.
