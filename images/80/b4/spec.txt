Implement the Verilog module based on the following description.
Design a module that acts as an 8-bit binary up/down counter. The counter should increment when the up signal is high and decrement when the down signal is high. Include an active low asynchronous reset to set the counter to zero.

	input reset_n,
	input up,
	input down,
	output reg [7:0] count);
