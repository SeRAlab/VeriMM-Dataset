Design an 8-bit SRAM cell with the ability to write and read data. The SRAM cell should have a 1-bit enable signal for writing (write_enable), an 8-bit data input (data_in), an 8-bit output (data_out), and a 3-bit address input (address). You need to implement the following functionality: when write_enable is high, the data_in should be written to the memory location specified by the address. When write_enable is low, the data_out should reflect the data stored at the memory location specified by the address.
