On the rising edge of the clock, if the reset signal (rst) is asserted, the flip-flop outputs (q) will be set to LOW and its complement (qn) to HIGH. If reset is not asserted, the output (q) will take the value of the data input (d), while (qn) will provide the inverted output of (d).
