
Create a FIFO (First-In-First-Out) queue module in Verilog. The FIFO should have the following specifications:
- It should be parameterizable for depth and width.
- It should have `enqueue` and `dequeue` operations.
- The module should include control signals for `full`, `empty`, and `valid` output.
- The FIFO should support synchronous write and read operations.
