Design a 4-to-1 multiplexer for 32-bit wide data inputs. Depending on the value of the 2-bit select signal (Op), the module outputs one of the four input data lines: In1, In2, In3, or In4, with each input being chosen based on the corresponding Op value (00 for In1, 01 for In2, 10 for In3, and 11 for In4).
module top_module(
	 input [31:0] In1,
	 input [31:0] In2,
	 input [31:0] In3,
	 input [31:0] In4,
	 input [1:0] Op,
	 output [31:0] Out
	 );
