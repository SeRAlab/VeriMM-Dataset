Design a level-sensitive latch that captures an 8-bit input (din) when the gate signal is high. When the gate is asserted (set to 1), the current state of din is transferred to the output (dout), effectively storing that value until the gate is deactivated. If the gate signal is low, the output remains unchanged, retaining the last captured value.
