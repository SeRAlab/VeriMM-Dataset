Design a 16-bit SRAM cell that allows for read and write operations. It should include a write enable signal (WE), an address input (ADDR), a 16-bit data input (DATA_IN), a 16-bit data output (DATA_OUT), and a clock signal (CLK). The SRAM should store data at the address specified by ADDR when WE is asserted. On the rising edge of CLK, if WE is not asserted, the data at the specified address should be output on DATA_OUT.
