Implement the Verilog module based on the following description.
You are given a 24-bit input vector value[23:0]. We want to determine some relationships between each bit and its neighbour:
(1) out_and: Each bit of this output vector should indicate whether the corresponding input bit and its neighbour to the left are both '1'. For example, out_and[22] should indicate if value[22] and value[23] are both 1. Since value[23] has no neighbour to the left, the answer is obvious so we don't need to know out_and[23].
(2) out_or: Each bit of this output vector should indicate whether any of the corresponding input bit and its neighbour to the right are '1'. For example, out_or[4] should indicate if either value[4] or value[3] are 1. Since value[0] has no neighbour to the right, the answer is obvious so we don't need to know out_or[0].
(3) out_xor: Each bit of this output vector should indicate whether the corresponding input bit is different from its neighbour to the left. For example, out_xor[22] should indicate if value[22] is different from value[23]. For this part, treat the vector as wrapping around, so value[23]'s neighbour to the left is value[0].

module bitwise_compare (
	input [23:0] value,
	output [22:0] out_and,
	output [23:1] out_or,
	output [23:0] out_xor);
