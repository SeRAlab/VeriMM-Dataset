Design a 4-to-1 multiplexer with an enable feature. The circuit selects one of the four input data bits (data_in[0] to data_in[3]) based on the 2-bit select signal. When the enable signal is high, the corresponding input is output on 'out', based on the select value. If the enable signal is low, the output is forced to LOW regardless of the select signal.
module top_module(
    input [3:0] data_in,
    input [1:0] select,
    input enable,
    output reg out
);
