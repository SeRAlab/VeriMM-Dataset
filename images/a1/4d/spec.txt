Design a 4-bit ripple carry adder circuit that sums two 4-bit binary numbers, A and B, along with a carry-in input (CIN). The module outputs a 4-bit result (Q) representing the sum and a single-bit carry-out (COUT) indicating if an overflow occurred. The carry-out is determined by evaluating the carry conditions based on the most significant bits of the inputs and the carry-in.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input CIN,
    output reg [3:0] Q,
    output reg COUT // Changed from wire to reg
);
