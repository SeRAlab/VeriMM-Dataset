Design a video output controller module for a 2-bit color depth display system. The module processes pixel data and generates horizontal and vertical sync signals (hr, vr), while controlling the pixel color output (r, g, b) based on a palette indexed by input signals. It utilizes a finite state machine to manage drawing operations, including horizontal and vertical counters to track the current pixel position on the screen. The design includes the ability to handle palette writes and outputs a request signal (drq) for data, along with an interrupt signal (vid_irq) based on vertical synchronization conditions. The overall operation supports dynamic updates to the display based on input video data and synchronization with the display refresh rate.
