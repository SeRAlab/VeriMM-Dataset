Design a combinational logic circuit that functions as a three-input gate, generating an output based on the specified conditions. The output, X, is true if either A1 is true while A2 is false, A1 is false while A2 is true, or if both A1 and A2 are true while B1 is false. This design implements a combination of NOT, AND, NAND, and OR operations to create the desired logic relationship among the three inputs.
module top_module(
    input A1,
    input A2,
    input B1,
    output X
);
