Design a block RAM module that provides a dual-functionality of reading and writing data based on control signals. It supports a memory depth of 2048 addresses and a data width of 10 bits. The module accepts an input clock, write enable, read enable, address, and data input, while generating a 10-bit data output. When the write enable (we) is asserted, the data input (din) is written to the memory at the specified address (addr), and when the read enable (rd_en) is asserted, it outputs the stored data from the addressed location. The module also utilizes a specific RAM primitive to handle memory operations and manages output registration to ensure synchronized read operations.
module top_module(clk, we, addr, din, rd_en, dout);
