Design a configurable N-bit binary counter with reset capability. The counter increments its output value on each positive clock edge when the count enable signal is active. If the reset signal is asserted, the output is set to zero. Additionally, an external signal can force the counter to zero regardless of the count enable signal. The counter width is defined by the parameter DW, allowing it to be easily adjusted for different sizes.
