Design a simple PCIe request-response controller. The circuit should have an input signal `req` (request), a clock signal `clk`, and a reset signal `rst`. When `req` is high, if not already processing a request (indicated by an internal signal `busy`), the controller should set an output signal `ack` (acknowledge) high after one clock cycle. The `ack` signal should go low after another clock cycle. If the request signal is low, the controller should keep the `ack` signal low and not respond until a new request comes in. The `busy` signal should indicate when a request is being processed.
