Implement a single-bit output that selects data from either an 8-bit wide input or a 256-bit wide input based on a conditional compilation directive. When the directive `BUG` is not defined, the output M256 is assigned the bit from the 256-bit input D according to the index specified by the 8-bit input S. Conversely, if `BUG` is defined, the output M256 is instead assigned the value from the 8-bit input S at the index specified by the 256-bit input D. This design allows for flexible behavior based on compilation flags, effectively functioning as a selector for data retrieval.

input [7:0] S,
input [255:0] D,
output M256
);
