Implement a 1-bit SRAM cell in Verilog. The SRAM cell should have a data input (D), a data output (Q), a write enable signal (WE), and a clock signal (CLK). When WE is high, the data on the input D should be written to the output Q on the rising edge of the CLK. If WE is low, the output Q should retain its previous value. The cell should also include a reset signal (RESET) that resets the output Q to 0 when asserted.
