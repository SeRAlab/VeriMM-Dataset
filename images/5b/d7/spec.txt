Design a 4-element register file that supports read and write operations. The module has two input addresses (`raAddress` and `rbAddress`) used to read from the corresponding registers, outputting their values as `regA` and `regB`. On the negative edge of the clock, if the `regWrite` signal is asserted, data from `dataIn` is written to the register specified by `raAddress`. Additionally, the module includes a reset function that clears all registers to zero when activated. This design is suitable for use in digital systems requiring small data storage and retrieval capabilities, like CPU register files.
module top_module(raAddress, rbAddress,
		    regA, regB, regWrite,
		    dataIn, reset, clk);
