Design a finite state machine (FSM) that controls a traffic light system with three states: GREEN, YELLOW, and RED. The FSM transitions from GREEN to YELLOW, then to RED, and back to YELLOW, based on a clock input while allowing for asynchronous reset functionality that initializes the system to the GREEN state. The output `light` is a 3-bit register, which represents the current state of the traffic light, indicating GREEN through `100`, YELLOW through `010`, and RED through `001`.
module top_module(
  input clk,
  input reset,
  output reg [2:0] light
);
