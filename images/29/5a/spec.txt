Design an interrupt controller that can handle up to 4 different types of interrupts. The controller should have the following inputs: a clock signal, a reset signal, and a 4-bit input representing the active interrupts. The output should be a 2-bit vector indicating the highest priority interrupt being handled. The interrupt priorities are defined as follows: Interrupt 0 has the highest priority, and Interrupt 3 has the lowest. The controller should also implement edge-triggered behavior, where it only acknowledges an interrupt on the rising edge of the clock. If multiple interrupts are active, the controller should prioritize based on the defined priorities.
