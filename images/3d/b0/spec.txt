Design a 4-channel DMA controller that allows data to be transferred between memory and peripheral devices. The controller should have the following features:
- Four channels (channel 0, channel 1, channel 2, channel 3).
- Each channel has a request signal (req), an acknowledge signal (ack), and a data bus (data).
- The controller should prioritize requests based on the channel number (lower channel number has higher priority).
- When a channel's request signal is high, it should be granted and the respective acknowledge signal should be activated.
- The data should be transferred from the memory to the peripheral device or vice versa as specified by the channel.
- The controller operates in a clocked fashion, where it checks requests on the rising edge of the clock.
