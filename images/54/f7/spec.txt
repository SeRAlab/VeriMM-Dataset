Design a signed arithmetic module that performs basic operations on two 8-bit signed inputs, A and B. The module computes the sum, difference, product, and quotient of the inputs. It outputs the sum and difference as signed 8-bit values, the product as a signed 16-bit value, and the quotient as a signed 8-bit value, handling division by zero by outputting zero when B is zero. This functionality effectively implements an arithmetic unit capable of handling addition, subtraction, multiplication, and conditional division.
module top_module(
  input signed [7:0] A,
  input signed [7:0] B,
  output reg signed [7:0] sum,
  output reg signed [7:0] diff,
  output reg signed [15:0] product,
  output reg signed [7:0] quotient
);
