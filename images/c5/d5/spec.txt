

You are tasked with designing a module that implements a 2-input AND gate using Verilog HDL. The module should have the following interface:

Inputs:
- A (1-bit input)
- B (1-bit input)

Outputs:
- Y (1-bit output)

You should use the following template for your module:

```verilog
module and_gate (
    // Inputs
    input A,
    input B,
    
    // Outputs
    output Y
);

// Your code here

endmodule
```

Your task is to fill in the code within the module to implement the AND gate functionality. You are not allowed to use any built-in Verilog AND gate primitives (`&`, `&&`, etc.) or any other Verilog operators that perform the AND operation directly. You must implement the AND gate functionality using only basic Verilog operators like `!`, `~`, `|`, `^`, `&`, `&&`, `||`, etc.
