Design a 16-bit barrel shifter capable of performing both left and right shifts based on a 4-bit shift amount. The `shift_direction` input determines the direction of the shift, where a value of 0 indicates a right shift and a value of 1 indicates a left shift. The module processes the input `data_in` and produces the shifted result on `data_out`.
module top_module(
    input [15:0] data_in,
    input [3:0] shift_amount,
    input shift_direction,
    output [15:0] data_out
);
