Implement the Verilog module based on the following description.
Build a 2-bit counter with an asynchronous positive edge triggered reset, synchronous enable signal, and synchronous active high decrement signal.
(1) reset: Resets counter to zero.
(2) enable: Enables the counter to count up by one.
(3) decrement: Decrements the counter by one.
(4) q: The current count of the counter.

module top_module(
    input clk,
    input reset,
    input enable,
    input decrement,
    output reg [1:0] q);
