The operation is determined by a 2-bit control signal: CTRL defines the type of shift (logical left, logical right, arithmetic right, or rotate), while the SHIFT input specifies how many positions to shift or rotate. The output is a modified 16-bit value reflecting the applied shifts or rotations.

    input [15:0] DATA,
    input [3:0] SHIFT,
    input [1:0] CTRL,
    output reg [15:0] out
