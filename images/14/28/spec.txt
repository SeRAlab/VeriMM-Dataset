
Design a GPIO (General Purpose Input Output) controller in Verilog. The controller should have a 4-bit input for data, a 1-bit input for a read/write control signal, and a clock input. When the read signal is high, the controller should output the current state of the data input on a 4-bit output. When the write signal is high, the data input should be stored and should replace the previous state. The controller should also have a reset input that initializes the output to zero.
