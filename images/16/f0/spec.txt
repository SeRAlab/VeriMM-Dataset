
Design a Verilog module that performs a simple portfolio optimization calculation. The module should take in the returns of three assets and calculate the expected return of the portfolio based on given weights. The weights should be represented as 4-bit binary numbers where each weight corresponds to one of the three assets. The calculation of the expected return can be done using the formula:
\[ \text{Expected Return} = (w1 \times r1 + w2 \times r2 + w3 \times r3) \]
where \( w1, w2, w3 \) are the weights (in binary) and \( r1, r2, r3 \) are the asset returns (in 4-bit binary). The outputs should be limited to the upper 8 bits of the result.
