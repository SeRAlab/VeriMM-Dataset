
Design a FIFO (First In First Out) queue with parameters for depth and width. The FIFO should support the following operations: 
1. `push`: to add an element to the queue.
2. `pop`: to remove an element from the queue.
3. `full`: to indicate if the queue is full.
4. `empty`: to indicate if the queue is empty.
The queue should have a synchronous reset input that clears the queue. The queue should also have a clock input to synchronize operations.
