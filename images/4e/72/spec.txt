Design a clock gating circuit that controls the output of a gated clock based on two input signals: an enable signal (en) and a data signal. When both en and data are high on the rising edge of the input clock (clk), the output gated_clk will be set high; otherwise, it will be set low. This design is useful for reducing power consumption in digital systems by selectively enabling the clock signal based on specific conditions.
module top_module(
    input clk,
    input en,
    input data,
    output gated_clk
);
