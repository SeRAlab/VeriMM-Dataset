

You are tasked with designing a verilog module that implements a simple 4-bit adder. The module should have two 4-bit inputs (A and B) and one 4-bit output (C). The module should also have a single input (sel) that determines whether the output should be the sum of A and B (sel=0) or the bitwise AND of A and B (sel=1). 

Implement the adder using behavioral modeling, and ensure that the module has the following interface:

Inputs:
- input [3:0] A: the first 4-bit input
- input [3:0] B: the second 4-bit input
- input sel: a single bit input that determines whether the output should be the sum of A and B (sel=0) or the bitwise AND of A and B (sel=1)

Outputs:
- output [3:0] C: the 4-bit output of the adder

You may assume that the inputs A and B will be valid 4-bit values.
