Develop a circuit that generates a single parity bit for an 8-bit input value. On each rising edge of the clock, the module captures the input and calculates the parity by XOR-ing all bits of the input together. The result, representing even parity, is then outputted as the parity_bit, enabling detection of single-bit errors in data transmission.
module top_module(
  input clk,
  input [7:0] in,
  output reg parity_bit
);
