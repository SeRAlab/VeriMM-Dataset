Design a game clock that generates a one-second pulse for a game, driven by a 25 MHz input clock. The module includes a reset and pause functionality: it resets the pulse when the reset signal is active, and it halts the clock increments while the pause signal is asserted. Upon reaching a count of 25,000,000, the output pulse (game_clk) is activated for one clock cycle, effectively creating a timed signal for game logic operations.
module top_module(
    input wire clk,
    input wire rst,
    input wire pause,
    output reg game_clk
    );
