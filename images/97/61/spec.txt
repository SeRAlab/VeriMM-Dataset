Design a D-type flip-flop with an active-high reset and enable along with a scan functionality. It captures the input `din` on the rising edge of the clock (`clk`) when `en` is asserted. If the `rst` input is high, it resets the output `q` to zero. Additionally, when the scan-enable (`se`) signal is active, it allows for serial testing by loading the output `so` with the scan input (`si`). This design supports both normal operation as a flip-flop and test operation for integrated circuit testing.
