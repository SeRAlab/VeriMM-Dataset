Design an 8-bit DRAM cell with a write and read interface. The DRAM cell should have the following inputs: a 8-bit data input (D), a write enable signal (WE), a read enable signal (RE), and a clock signal (CLK). When WE is high, the data input D should be written to the cell on the rising edge of the clock. When RE is high, the data stored in the cell should be output on a data output (Q) on the rising edge of the clock.
