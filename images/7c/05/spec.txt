Create a 4-bit adder-subtractor circuit that can perform both addition and subtraction based on a control input, C. When C=0, the module computes the sum of inputs A and B, optionally including a carry-in (Cin). When C=1, it calculates the difference by taking the two's complement of B before adding it to A, again considering Cin. The circuit outputs a 4-bit result, R, and a carry-out signal, Cout, indicating whether an overflow occurred in the addition or if there was a borrow in the subtraction.
module top_module(
    input [3:0] A,
    input [3:0] B,
    input C,
    input Cin,
    output [3:0] R,
    output Cout
);
