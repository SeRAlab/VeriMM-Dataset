Design a simple SPI controller that can handle data transmission. The controller should have input signals for clock (SCK), chip select (CS), and data input (MOSI), and an output for the data read (MISO). The controller will latch the incoming data on the rising edge of SCK when CS is low and output the data on MISO on the falling edge of SCK when CS is low. The controller should also have a 4-bit internal register to hold the data.
