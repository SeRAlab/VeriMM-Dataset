Design a Verilog module for a 16-QAM modulator. The module should take in 4 bits of input data (representing the symbols) and output a corresponding 4-bit I (in-phase) and 4-bit Q (quadrature) signal. The mapping for the 16-QAM symbols should be as follows: 
- 0000 -> (I, Q) = (0, 0)
- 0001 -> (I, Q) = (0, 1)
- 0010 -> (I, Q) = (0, -1)
- 0011 -> (I, Q) = (1, 0)
- 0100 -> (I, Q) = (1, 1)
- 0101 -> (I, Q) = (1, -1)
- 0110 -> (I, Q) = (-1, 0)
- 0111 -> (I, Q) = (-1, 1)
- 1000 -> (I, Q) = (-1, -1)
- 1001 -> (I, Q) = (0, 2)
- 1010 -> (I, Q) = (0, -2)
- 1011 -> (I, Q) = (2, 0)
- 1100 -> (I, Q) = (2, 1)
- 1101 -> (I, Q) = (2, -1)
- 1110 -> (I, Q) = (-2, 0)
- 1111 -> (I, Q) = (-2, 1)
