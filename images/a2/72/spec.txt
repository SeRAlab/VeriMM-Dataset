Design a circuit that performs either addition or subtraction based on a control signal. The module takes two 4-bit inputs, A and B, and a single-bit input SUB. When SUB is low (0), the module computes the sum of A and B; when SUB is high (1), it calculates the difference by subtracting B from A. The results are updated synchronously on the rising edge of the clock and output as a 4-bit SUM.
module top_module(
    input clk,  // Added clk as an input
    input [3:0] A,
    input [3:0] B,
    input SUB,
    output [3:0] SUM
);
