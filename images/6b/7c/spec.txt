Design a circuit that performs binary exponentiation of a given base raised to the power of an exponent, where the base is a 9-bit input and the exponent is an 8-bit input. The operation is synchronized with a clock signal, and a reset signal initializes the computation. The result is stored as a 100-bit output. The module counts the number of multiplications performed, updating the result during each clock cycle until the specified exponent is reached. Once the calculation is complete, an output signal indicates that the operation is done.
module top_module(
    input clk,
    input [8:0] base,
    input [7:0] exponent,
    input reset,
    output reg [99:0] result,
    output reg isDone
);
