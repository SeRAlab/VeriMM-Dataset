Implement a 3-bit binary up/down counter with enable and synchronous reset. The counter increments or decrements its value based on a control signal.

Module name:
    up_down_counter_3bit

Input ports:
    clk: Clock signal used for synchronous operation.
    rst: Active-high synchronous reset signal. Defined as 1 for reset and 0 for reset signal inactive.
    en: Enable signal to increment or decrement the counter.
    up_down: Control signal to determine the count direction. 1 for up, 0 for down.

Output ports:
    count: 3-bit output representing the current count value.

Implementation:
The count register is triggered on the positive edge of the clock signal (posedge clk).
If the reset signal is asserted (rst == 1), the count register is cleared to 0 on the next clock cycle.
If the enable signal is asserted (en == 1), the count register increments its value by 1 if up_down is 1, otherwise decrements its value by 1 if up_down is 0.
