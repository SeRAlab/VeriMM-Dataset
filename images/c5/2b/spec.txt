

You are tasked with designing a Verilog module that can generate a PWM signal with a given frequency and duty cycle. The module should have two inputs: a clock signal and a duty cycle value. The clock signal should be used to generate the PWM signal, and the duty cycle value should be used to set the percentage of time that the PWM signal is high.

The module should have one output, which is the PWM signal. The frequency of the PWM signal should be equal to the frequency of the clock signal, and the duty cycle of the PWM signal should be equal to the duty cycle value.

Write a Verilog module that meets the above requirements. You may assume that the duty cycle value will be a 8-bit unsigned integer.
