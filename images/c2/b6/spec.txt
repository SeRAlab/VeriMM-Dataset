

You are tasked with designing a Verilog module that takes in a 4-bit input `A` and outputs the 2's complement of `A`. The module should be named `complement` and should have the following inputs and outputs:

Inputs:
- `A` (4-bit input)

Outputs:
- `C` (4-bit output)

The module should use the following logic to calculate the 2's complement of `A`:
- Invert all bits of `A`
- Add 1 to the result

You can assume that the input `A` will always be a valid 4-bit binary number.

Write the Verilog code for the `complement` module.
