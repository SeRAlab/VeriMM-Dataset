
Design a fixed-priority arbiter in Verilog that can handle up to 4 requests. The arbiter should grant access to the highest priority request among the active requests. The priority order is defined as Request 0 > Request 1 > Request 2 > Request 3. The arbiter should output the grant signal and a corresponding grant signal to indicate which request has been granted access. The output grant should remain valid until the next clock cycle, even if the request is deactivated.
