Design a two-input, one-bit multiplexer that selects between two data inputs based on the control signals A1_N and A2_N. The output Y is determined by the values of the inputs: when both A1_N and A2_N are LOW (0), Y takes the value of B1; when A1_N is LOW and A2_N is HIGH (1), Y takes the value of B2; in cases where A1_N is HIGH, Y will again follow the same logic as previously, selecting B1 when A2_N is LOW and B2 when A2_N is HIGH.
module top_module(
    input A1_N,
    input A2_N,
    input B1,
    input B2,
    output reg Y
);
