Design a hazard detection unit for a pipelined processor. This module monitors the read and write registers, along with the memory operation signal (MemRead), to identify data hazards. If a conflict is detected where the destination register (`rd`) is the same as either of the source registers (`rs1` or `rs2`) while a memory read is occurring, it disables the program counter update (`PCwrite`) and instruction fetch (`IF_IDwrite`), while also asserting control signals (`control_sel`) for hazard management. Conversely, when no hazards are present, it allows normal operation by enabling both the PCwrite and IF_IDwrite signals.
