Design a scratchpad RAM module with a memory depth of 256 addresses and a data width of 10 bits. The module allows data to be written to or read from specific memory locations based on the input address and a write enable signal. On the rising edge of the clock, if the write enable signal (WE) is asserted, data from the DATA_IN input is stored at the location specified by ADDR. The DATA_OUT output continuously reflects the data stored at the given address, allowing for direct read access to the memory contents.
