Design a Verilog module that implements a simple state machine for a basic SD card interface. The state machine should have the following states: IDLE, READ, WRITE, and ERROR. The machine should transition between states based on a 2-bit input signal (state_signal) that indicates the operation: 00 for IDLE, 01 for READ, 10 for WRITE, and 11 for ERROR. The state should be outputted as a 2-bit signal (current_state).
