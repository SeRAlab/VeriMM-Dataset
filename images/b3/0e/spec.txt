Module name:  
    up_down_counter  
                 
Input ports:
    CLK: Clock input
    RST: Active high reset signal
    UpDown: Control signal to determine count direction (1 for up, 0 for down)

Output ports:
    Count: 3-bit output representing the current count value

Implementation:
The up_down_counter module uses an always block to update the count value based on the clock signal, reset signal, and control signal. The always block triggers on the positive edge of the clock signal (posedge CLK) or the positive edge of the reset signal (posedge RST). It checks if the reset signal is active (RST) and sets the count value (Count) to 0. If the control signal (UpDown) is high, it increments the count value by 1. If the control signal is low, it decrements the count value by 1.
