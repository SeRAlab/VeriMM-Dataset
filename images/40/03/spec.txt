Design a Restoring Divider in Verilog that divides two binary numbers. The division process should be implemented using a sequential logic method. The module should take in two inputs: a dividend and a divisor, and output the quotient and the remainder. The divisor should not be zero. If it is zero, the module should output an error signal. The division process should be clocked, and the module should have a ready signal indicating when the division operation is complete.
