Design a synchronous memory module with a configurable RAM size and 32-bit word width. The module features a write enable signal (`we`), allowing data input (`data_in`) to be written to a specified address (`addr`) on the positive edge of the clock (`clk`). If `we` is high, the memory updates the contents at the given address with the new data; regardless of the write operation, it outputs the current data stored at that address through `data_out`. This design is intended for applications requiring a simple read-write memory interface.
module top_module(clk, we, addr, data_in, data_out);
