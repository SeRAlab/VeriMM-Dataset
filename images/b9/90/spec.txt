Design a register bank that functions as a dual-port RAM. It allows for synchronous read and write operations based on the clock signal. When writing is enabled (wren=1), data input is written to the address specified by wraddress. Simultaneously, data can be read from the address specified by rdaddress. The output q reflects the data read from memory under the condition that writing is not occurring. This module effectively facilitates concurrent read/write operations, making it suitable for various applications like CPU register files or data buffers in digital systems.
module top_module(
    input clock,
    input [31:0] data,
    input [4:0] rdaddress,
    input [4:0] wraddress,
    input wren,
    output reg [31:0] q
);
