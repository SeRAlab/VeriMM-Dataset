Design a simple GPIO controller that can read inputs and control outputs based on a control signal. The GPIO controller should have the following specifications: it has 8 input pins and 8 output pins. The controller should read the state of the input pins when the control signal is high and latch the state of the output pins to the current state of the input pins when the control signal is pulsed high (goes from low to high). The output pins should remain unchanged when the control signal is low.
