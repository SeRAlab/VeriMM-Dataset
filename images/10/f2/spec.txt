Design a combinational logic circuit that implements a simple decision tree for a binary classification problem. The decision tree should have the following structure:  
- If feature1 > 5, go to node A  
- If feature1 <= 5, go to node B  
- Node A: If feature2 > 3, classify as Class 1; otherwise, classify as Class 2  
- Node B: If feature3 == 1, classify as Class 3; otherwise, classify as Class 4  
The circuit should return a 2-bit output representing the class. Class 1 = 00, Class 2 = 01, Class 3 = 10, Class 4 = 11.
