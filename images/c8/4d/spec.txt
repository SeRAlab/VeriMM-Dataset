

You are tasked with designing a module that performs a bitwise XOR operation on two 8-bit inputs and outputs the result. The module should be named `xor_module` and should have the following ports:

- `input [7:0] input_a`: the first 8-bit input
- `input [7:0] input_b`: the second 8-bit input
- `output [7:0] output_result`: the result of the bitwise XOR operation

Your module should be implemented using only combinational logic, meaning that it should not contain any flip-flops or other sequential elements.

Write the Verilog code for the `xor_module` module that implements the above functionality. Your code should be synthesizable and should follow good coding practices.
