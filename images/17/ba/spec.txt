Design a Verilog module that implements a simple OFDM symbol mapping. The module should take a 4-bit input representing a data symbol and output a 16-bit binary representation of the mapped OFDM symbol. The mapping is defined as follows: each 4-bit input is converted to a 16-bit output by repeating the input value 4 times. For example, if the input is 4'b1010, the output should be 16'b1010101010101010.
