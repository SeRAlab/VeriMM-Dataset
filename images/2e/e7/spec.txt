
Design a thermal sensor calibration system that adjusts an output temperature value based on an input raw sensor value and a calibration factor. The system should have the following features:
- A 10-bit raw sensor value input (`raw_temp`) that ranges from 0 to 1023.
- A 4-bit calibration factor input (`cal_factor`) ranging from 0 to 15.
- The output temperature value (`calibrated_temp`) should be calculated as: 
  `calibrated_temp = raw_temp + (raw_temp * cal_factor / 16)`.
- The output should be updated on a clock edge.
