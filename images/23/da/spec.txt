
Design a 5-stage pipelined architecture for a simple RISC CPU. The pipeline stages include Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). The CPU should support a simple instruction set that includes ADD, SUB, AND, and OR operations. Each stage should be implemented in a clocked manner, and ensure data forwarding is considered for hazard prevention.
