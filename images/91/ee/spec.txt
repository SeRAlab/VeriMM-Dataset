Design a priority encoder that converts an 8-bit input into a 3-bit output, while considering an enable signal. When the enable signal is low, the output is set to zero. When enabled, the encoder outputs the binary representation of the highest-priority input (from the 7th bit down to the 0th bit) that is high (1), providing a compact representation of the active input line. If no inputs are high, the output remains zero.
