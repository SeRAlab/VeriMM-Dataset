Implement a circuit that converts an n-bit binary input into its equivalent Gray code output. The module takes an n-bit binary number as input and outputs the corresponding n-bit Gray code. The most significant bit of the Gray code is directly assigned from the binary input, while each subsequent bit is generated using the XOR operation between the current binary bit and the previous Gray code bit.
module top_module(
  input [n-1:0] binary_in,
  output [n-1:0] gray_out
);
