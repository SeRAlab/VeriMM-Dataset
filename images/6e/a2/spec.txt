Implement a 16-bit shift register with synchronous reset in Verilog. When reset is active, the shift register is loaded with 16'h1234. Otherwise, it shifts its contents to the right by 1 bit on every clock cycle, and the input is shifted in from the left.

	input clk,
	input reset,
	input shift_in,
	output reg [15:0] q);
