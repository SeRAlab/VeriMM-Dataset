Implement the Verilog module based on the following description.
Create an 8-bit wide, 256-word deep memory with a synchronous write enable. The memory writes data to the specified address when the write enable signal is high on the clock edge. It outputs the data at the specified address.
module memory (
    input clk,
    input write_enable,
    input [7:0] address,
    input [7:0] data_in,
    output [7:0] data_out );
