Design a synchronous data memory module with a width of 32 bits and a depth of 1024 entries. On each positive edge of the clock, if the write enable signal (we) is active, the module writes the input data (datain) to the memory address specified by addr. Regardless of the write enable state, the output data (dataout) is updated to reflect the value stored at the specified address. This module serves as a simple RAM component in a digital system.
module top_module(input 		  clk, we,
						 input [9:0]  addr,
						 input [31:0] datain,
						 output reg [31:0] dataout);
