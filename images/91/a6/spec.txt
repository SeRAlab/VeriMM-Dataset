Implement a Verilog module for a 4-to-1 multiplexer. The module should have a 2-bit select input (sel[1:0]), four 1-bit data inputs (d0, d1, d2, d3), and a 1-bit output (y). The output should be one of the data inputs based on the value of the select input.

module mux_4to1 (
  input [1:0] sel,
  input d0,
  input d1,
  input d2,
  input d3,
  output y);
