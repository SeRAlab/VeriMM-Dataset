Design a FIFO (First-In, First-Out) buffer with asynchronous reset and clock control. This buffer allows for read and write operations on 64-bit wide data and can hold up to two entries. It provides status signals to indicate if the buffer is full, empty, almost full, or almost empty. The buffer toggles between two data entries when writing and reading, ensuring that data is read in the order it was written. The read and write operations can occur simultaneously, with the design ensuring proper handling of data entries and maintaining synchronization through clock signals.
