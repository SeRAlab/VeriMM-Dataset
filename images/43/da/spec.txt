Design a 4-bit barrel shifter that allows for flexible left or right shifting of input data. The module takes a 4-bit input (A) and a 2-bit shift amount, along with a direction flag (shift_dir), which determines the shifting direction. When shift_dir is high, it performs a right shift; when low, it performs a left shift. The output (Y) reflects the shifted result based on the specified amount, enabling efficient data manipulation for various digital signal processing applications.
module top_module(
    input [3:0] A,
    input [1:0] shift_amount,
    input shift_dir,
    output [3:0] Y
);
