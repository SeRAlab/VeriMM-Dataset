Design a Verilog module that implements a 4-point Discrete Cosine Transform (DCT). The module should take a 4-bit input vector and produce a 4-bit output vector. The DCT is defined for a 4-point input as follows:
Output[0] = (Input[0] + Input[1] + Input[2] + Input[3]) / 2
Output[1] = (Input[0] + Input[1] - Input[2] - Input[3]) / 2
Output[2] = (Input[0] - Input[1] + Input[2] - Input[3]) / 2
Output[3] = (Input[0] - Input[1] - Input[2] + Input[3]) / 2
