Implement the Verilog module based on the following description.
You are given an eleven-bit input vector in[10:0]. We want to compute some relationships between the bits and their neighbours: 
// (1) out_both: Each bit of this output vector should indicate whether both the corresponding input bit and its neighbour to the left (higher index) are '1'. For example, out_both[4] should indicate if in[4] and in[5] are both 1. Since in[10] has no neighbour to the left, the answer is obvious so we don't need to know out_both[10]. 
// (2) out_any: Each bit of this output vector should indicate whether any of the corresponding input bit and its neighbour to the right are '1'. For example, out_any[9] should indicate if either in[9] or in[8] are 1. Since in[0] has no neighbour to the right, the answer is obvious so we don't need to know out_any[0]. 
// (3) out_different: Each bit of this output vector should indicate whether the corresponding input bit is different from its neighbour to the left. For example, out_different[2] should indicate if in[2] is different from in[3]. For this part, treat the vector as wrapping around, so in[10]'s neighbour to the left is in[0].
