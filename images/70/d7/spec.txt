Design a 4-to-1 multiplexer that selects one of four input data lines (D0, D1, D2, D3) based on the values of two select lines (S1, S0). The output (Y) will reflect the selected input as follows: when S1 and S0 are both 0, output D0; when S1 is 0 and S0 is 1, output D1; when S1 is 1 and S0 is 0, output D2; and when both S1 and S0 are 1, output D3.
module top_module(
    input S1,
    input S0,
    input D3,
    input D2,
    input D1,
    input D0,
    output reg Y
);
