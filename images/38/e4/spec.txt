
Design a power gating system in Verilog that takes two control signals (enable and power_gating) and three input signals (A, B, C). The output should be produced based on the following conditions:
1. If enable is high and power_gating is low, the output should be the logical AND of A, B, and C.
2. If enable is high and power_gating is high, the output should be zero.
3. If enable is low, the output should be held to the previous output value (assuming an initial value of zero).
