
Design a 4-bit DRAM cell that can store a single bit of data. The DRAM cell shall have the following inputs: a clock signal (`clk`), a write enable signal (`we`), a 4-bit data input (`din`), and a 4-bit data output (`dout`). When the write enable signal is high, the data input should be written to the cell on the rising edge of the clock. When write enable is low, the output should reflect the stored data. Implement the Verilog module for this functionality.
