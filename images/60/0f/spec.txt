Design a simple Analog-to-Digital Converter (ADC) that samples an incoming analog signal and produces an 8-bit digital output. The ADC uses a reference voltage of 5V to determine whether the sampled signal is above or below half of the reference voltage. When the analog input exceeds this threshold, it outputs a digital value representing a high state; otherwise, it outputs a low state. The output is updated on the rising edge of the analog input signal.
module top_module(
  input analog_in,
  output reg [7:0] digital_out
);
