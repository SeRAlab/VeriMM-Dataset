Please act as a professional verilog designer.

Design a Verilog module for a 4-bit up/down counter with synchronous reset capability. The counter increments or decrements its value on the rising edge of the clock based on the up signal. It resets to 0 synchronously when the reset signal is active.

Module name:  
    counter_4bit  

Input ports:
    clk: Chip clock signal.
    rst: Synchronous reset signal.
    up: Up/Down control signal.

Output ports:
    count: Counter output signal with a data width of 4 bits.

Implementation:
Counter operation:
On every positive edge of the clock signal (clk), the counter (count) is updated.
If the reset signal (rst) is active, the counter is reset to 0.
If the up signal (up) is high, the counter increments by 1.
If the up signal (up) is low, the counter decrements by 1.
