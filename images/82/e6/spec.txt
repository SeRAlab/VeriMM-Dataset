Design a synchronous memory module that supports read and write operations. It features an 8-bit wide data memory with 16 addresses, where the write enable signal (wr_en) allows the writing of a value (wr_value) to a specified address (wr_addr) on the positive edge of the clock. Concurrently, the module reads data from a specified address (rd_addr) and outputs the corresponding 8-bit value (rd_value) on every clock cycle.
