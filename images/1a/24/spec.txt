Design an NVMe controller read command state machine that processes read requests. The state machine should have three states: IDLE, READ, and DONE. The controller should transition from IDLE to READ when a read command is received (input signal `read_cmd` is high). It should remain in the READ state while the read operation is in progress (indicated by a signal `busy` being high). Once the read operation is complete, it should transition to the DONE state (indicated by a `done` signal being high) and then back to IDLE when the `read_cmd` signal goes low.
