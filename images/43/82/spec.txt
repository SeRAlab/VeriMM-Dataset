Develop a circuit that converts an n-bit binary number into an m-digit Binary-Coded Decimal (BCD) representation. The module first calculates the decimal equivalent of the binary input and then extracts each decimal digit to represent it in BCD format, where each 4-bit slice corresponds to a decimal digit from the binary number. The output consists of the concatenated BCD digits, effectively mapping the original binary input into a more human-readable decimal format.
module top_module(
  input [n-1:0] bin,
  output [m-1:0] bcd
);
