
Design a Verilog module that implements a simple version of the SHA-256 hash function. Your module should take a 512-bit input message and compute the 256-bit hash output. The module should have an initialization phase where it sets its internal state based on the initial hash values specified by the SHA-256 standard. It should also have a clock input, a reset input, and a start signal to indicate when to begin computation. The output should be available after the computation is complete.
