Implement an 8-bit shift register with a parallel load and shift control. The register will shift left on each clock cycle when the shift signal is high. When the load signal is high, the register loads the parallel input data.

Module name:
    shift_register_8bit

    clk: Clock signal for synchronous operation.

    load: Parallel load control signal. When high, the register loads the parallel input data.
    shift: Shift control signal. When high, the register shifts left.
    data_in: 8-bit parallel input data.

Output ports:
    data_out: 8-bit output representing the current register value.
