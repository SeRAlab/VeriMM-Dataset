Design a one-bit full adder circuit, which computes the sum of three input bits: A, B, and Cin (carry-in). The module outputs a Sum bit representing the least significant bit of the summation and a Cout (carry-out) bit indicating whether a carry has occurred. The circuit uses XOR gates for summation and AND/OR gates to determine the carry output.
module top_module(
    input A,
    input B,
    input Cin,
    output Sum,
    output Cout
);
