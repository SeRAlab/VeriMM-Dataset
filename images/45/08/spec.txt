Design a configurable 8-bit shift register that allows both parallel loading and shifting of data. The module accepts a clock signal for synchronization, a data input for loading, and a control signal to dictate the shifting direction. When the load signal is active, the input data is loaded into the register; otherwise, the register shifts its contents either to the left or right based on the control signal's state. The most significant bit of the shift register is outputted as dout.
module top_module(
  input clk,
  input din,
  input load,
  input ctrl,
  output reg dout
);
