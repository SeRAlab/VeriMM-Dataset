Design a circuit that implements a 2-to-1 multiplexer feeding into a 3-bit shift register. The module takes clock and serial inputs and shifts the selected input (either in1 or in2) into the shift register on each clock cycle. The output of the shift register is a 3-bit value output on shift_out, while the final output also combines the most significant bit of the shift register with the third bit of the shift_out signal using a logical OR operation.
module top_module(
    input clk,
    input serial_in,
    input in1,
    input in2,
    output [2:0] shift_out,
    output out
);
