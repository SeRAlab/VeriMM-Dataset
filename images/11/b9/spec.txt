Implement a Huffman encoding combinational circuit that takes a 4-bit input representing a character and outputs a 3-bit code based on predefined Huffman encoding rules. The encoding rules to be used are as follows:

- 'A' (0000) -> 00
- 'B' (0001) -> 01
- 'C' (0010) -> 10
- 'D' (0011) -> 11
- Any other character should output an invalid code (default to 111)
