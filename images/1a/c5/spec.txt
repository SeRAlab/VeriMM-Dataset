Design a dynamic range compressor circuit that takes a 5-bit signed input and produces a 5-bit signed output. The compression should be such that if the input is greater than a certain threshold, it scales down the input value. The scaling factor can be determined as follows: if the input is greater than 15, output should be input / 2; if the input is between 8 and 15, output should be input - 2; if the input is less than or equal to 8, output should be the same as the input.
