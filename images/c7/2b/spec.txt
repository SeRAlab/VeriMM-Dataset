

You have been hired as a digital design engineer to design a module for a bus driver that can operate in different modes. You need to design a Verilog module that can drive a bus with an output Z and input A. The module should be able to operate in two modes: normal mode and sleep mode. In normal mode, the output Z should be set to the input A when the enable signal TE_B is high. In sleep mode, the output Z should be set to 0, regardless of the input A. The module should have a sleep input signal to switch between the two modes. 

Design a Verilog module that meets the requirements above. The module should be named "bus_driver" and should have the following ports:

- input A: the input signal to the bus driver
- output Z: the output signal from the bus driver
- input TE_B: the enable signal for the bus driver
- input SLEEP: the sleep signal for the bus driver

Assume that all input and output signals are 1-bit wide. You are not allowed to use any other modules in your design.
