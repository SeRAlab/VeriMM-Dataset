Design a simple CSPRNG using a Linear Feedback Shift Register (LFSR). The LFSR should have a width of 8 bits and use polynomial x^8 + x^6 + x^5 + x^4 + 1 for feedback. The output of the LFSR should be taken as the pseudo-random number. The design should also include an enable signal to start the generation of the random numbers.
