Design a clock divider that generates a lower frequency output clock (clk_out) from an input clock (clk_in). The module counts the number of rising edges of clk_in, and when the count exceeds 500,000, it resets the count. When the count is between 250,001 and 500,000, clk_out is set high; otherwise, it is low. This effectively divides the input clock frequency by a factor of 2.
