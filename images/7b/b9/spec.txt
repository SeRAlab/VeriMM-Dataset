Design a four-bit arithmetic and logic unit (ALU) that performs various operations based on a 4-bit control signal. The ALU can execute addition, subtraction, bitwise AND, OR, XOR, NOT, as well as left and right shifts on two 4-bit inputs, `a` and `b`. The output of the chosen operation is provided on a 4-bit output line, and there is a dedicated output to indicate whether the result is zero. Additionally, the ALU checks for overflow specifically during addition and subtraction operations.
module top_module(
    input [3:0] ctl,
    input [3:0] a,
    input [3:0] b,
    output reg [3:0] out,
    output zero
);
