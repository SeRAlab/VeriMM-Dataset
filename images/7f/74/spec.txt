Design a circuit that converts a 5-bit binary input (BIN) into its Binary-Coded Decimal (BCD) representation, producing two separate BCD outputs: BCD0 and BCD1. The BCD0 output corresponds to the lower digit (units), while BCD1 corresponds to the higher digit (tens). The implementation uses conditional logic to decompose the binary value into appropriate BCD values, incrementing each BCD digit based on the original binary input's value.
module top_module(
    input [4:0] BIN,
    output reg [3:0] BCD0,
    output reg [3:0] BCD1
);
