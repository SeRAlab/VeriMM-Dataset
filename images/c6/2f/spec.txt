

You are tasked with designing a verilog module for a simple 2-input AND gate with the following specifications:

- The module should be named "and_gate".
- The module should have two input ports, both of which are single-bit in size and named "a" and "b".
- The module should have one output port, which is also single-bit in size and named "out".
- The module should implement the logical AND operation, such that the output is 1 only if both inputs are 1.

Write the verilog code for the "and_gate" module that meets the above specifications.
