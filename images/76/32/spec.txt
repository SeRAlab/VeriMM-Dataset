Design a 4-bit adder/subtractor module that operates based on a mode selection input. The input signal M determines the operation: when M=0, the module performs addition of inputs A and B; when M=1, it computes A minus B using two's complement representation. The output R reflects the 4-bit result of the computation, while COUT indicates a carry-out for addition and V is the overflow flag, which is activated when there is a sign change, indicating an overflow condition in signed arithmetic.
module top_module(
  input [3:0] A,
  input [3:0] B,
  input M,
  output [3:0] R,
  output COUT,
  output V
);
