Design a 2x2 matrix inversion module. Given a 2x2 matrix, the module outputs the inverse of the matrix if it's invertible. The matrix is represented by four input values: a, b, c, d for the matrix [[a, b], [c, d]]. The inverse is calculated using the formula:  
\[ \text{Inverse} = \frac{1}{ad - bc} \begin{bmatrix} d & -b \\ -c & a \end{bmatrix} \]  
If the determinant \(ad - bc\) is zero, then the matrix is not invertible, and the module should output a predefined error value (e.g., 0 for all outputs).
