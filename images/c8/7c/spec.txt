

You are tasked with creating a module that takes in a 4-bit input `V` and outputs a single bit `z`. The output `z` is determined by the following logic: if the most significant bit of `V` (bit 3) is 1 AND either bit 1 or bit 2 of `V` is 1, `z` should be 1. Otherwise, `z` should be 0.

Create a Verilog module `comparator` that takes in a 4-bit input `V` and outputs a single bit `z` based on the logic described above. Your module should be self-contained and should not require any additional modules or testbenches.
