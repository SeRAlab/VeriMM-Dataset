

You have been tasked with designing a verilog module that implements a 3-input AND gate with an additional input that acts as an enable signal. The module should be named `and_en` and should have the following inputs and outputs:

Inputs:
- `a`, `b`, `c`: 3-bit binary inputs
- `en`: 1-bit binary enable signal

Outputs:
- `y`: 1-bit binary output

The module should only output the AND of `a`, `b`, and `c` if the `en` signal is high. If `en` is low, the output should be set to 0.

Your module should be implemented within 200 lines of Verilog code and should be self-contained, with all necessary components included.
