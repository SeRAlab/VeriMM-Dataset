Design a combinational logic circuit that processes ten input signals to produce a single output. The output, out1, is controlled by a series of conditional statements: if in1 is high, out1 goes high; if in2 is high, out1 is driven low; if in3 is high, out1 toggles its current state; if in4 is high, out1 is assigned the logical AND of in5 and in6; if in7 is high, out1 is the result of the logical OR between in8 and in9; and if in10 is high, out1 is set to the logical XOR of in8 and in9. This module implements a flexible logic function based on priority conditions.
module top_module(
    input in1,
    input in2,
    input in3,
    input in4,
    input in5,
    input in6,
    input in7,
    input in8,
    input in9,
    input in10,
    output reg out1
);
