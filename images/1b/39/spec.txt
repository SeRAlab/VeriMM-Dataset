Design a SR-latch using D flip-flops in Verilog. The SR-latch should have two inputs, Set (S) and Reset (R), and two outputs, Q and Qn. The behavior of the latch should be as follows: When S=1 and R=0, Q should be set to 1. When S=0 and R=1, Q should be reset to 0. If both S and R are 0, Q should retain its previous state. If both S and R are 1, the output is considered an invalid state.
