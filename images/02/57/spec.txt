
Design a Run-Length Encoding (RLE) module that takes an 8-bit input stream and encodes it into a compressed format. The RLE should work as follows: It takes a stream of bits and outputs pairs of (value, count) where 'value' is the bit (0 or 1) and 'count' is how many times it appears consecutively. The output should be a 16-bit output where the first 8 bits represent the value and the next 8 bits represent the count. The module should also have a valid output signal to indicate when the output is valid.
