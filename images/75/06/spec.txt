Design a circuit that functions as a 4-bit binary counter with an asynchronous active-high reset. The counter increments on each positive clock edge and resets to zero when the reset signal is high. Additionally, the circuit counts the number of '1's in the binary representation of the current counter value, outputting this count as a 3-bit signal. The counter value is also made available on a 4-bit output.
module top_module(
    input clk,
    input reset,      // Asynchronous active-high reset
    output [3:0] q,
    output reg [2:0] count_ones
);
