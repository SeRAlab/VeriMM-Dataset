Design an 8-bit arithmetic unit that performs addition or subtraction based on control signals. If the 'add' signal is high, the module outputs the sum of inputs A and B; if the 'sub' signal is high, it outputs the difference of A and B. If neither signal is active, the output defaults to zero. This module effectively acts as a simple ALU for 8-bit operations.
module top_module(
    input [7:0] A,
    input [7:0] B,
    input add,
    input sub,
    output [7:0] Z
);
