Design a simple dual-port Block RAM with write enable functionality. The module can store 64-bit data at a depth defined by the address width (8 bits, allowing for 256 unique addresses). It has two separate read ports (q_a and q_b) that allow simultaneous access to the stored data at different addresses (addr_a and addr_b). When the write enable signal (wr_en) is active, the input data (d) is written to the memory location specified by addr_a on the rising edge of the clock. Regardless of the write state, the module always outputs the current values at addresses addr_a and addr_b through q_a and q_b, respectively.
module top_module(clk, wr_en, d, addr_a, addr_b, q_a, q_b);
