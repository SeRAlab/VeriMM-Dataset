
Design a Verilog module that implements a simple SD card interface controller. The controller should have the following functionality:
1. It should have a clock input, a reset input, and two data inputs (data_in1 and data_in2).
2. On each rising edge of the clock, if the reset is not asserted, the controller should store the latest value of data_in1 and data_in2 into internal registers.
3. Additionally, the controller should toggle an output signal (data_out) every time data_in1 changes.
4. The data_out signal should reflect the value of data_in1 when it changes and should be held for one clock cycle until the next change.
