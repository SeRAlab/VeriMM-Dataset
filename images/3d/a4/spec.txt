
Design a 1-bit SRAM cell using Verilog. The SRAM cell should have the following inputs and outputs:
- Inputs: `data_in` (1-bit), `read_enable` (1-bit), `write_enable` (1-bit), `clk` (1-bit)
- Outputs: `data_out` (1-bit)

The SRAM cell should store a value when `write_enable` is high, and output the stored value when `read_enable` is high. The output should be updated on the rising edge of the clock.
