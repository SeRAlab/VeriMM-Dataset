
Design a 16-bit Digital to Analog Converter (DAC) controller that takes a 4-bit input representing a control signal and generates a corresponding 16-bit output. The 4-bit input signal (ctrl) will select one of the 16 possible voltage levels for the DAC output, where each level corresponds to a specific 16-bit binary value that represents a voltage in the range of 0 to V_ref (where V_ref is a constant reference voltage).
