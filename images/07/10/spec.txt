
Design a combinational logic circuit that implements a simplified version of the A* search algorithm. The circuit should take as input a set of nodes represented as a 5-bit binary number (from 0 to 31), a heuristic value also as a 5-bit binary number, and a goal node represented as a 5-bit binary number. The output should be a 5-bit binary number representing the next node to explore in the search based on the lowest cost (actual cost + heuristic cost).
