

You have been tasked with designing a 3-input NOR gate using the sky130_fd_sc_ms technology library. The module should have three input signals, A, B, and C, and a single output signal, Y. The module should be self-contained and should not rely on any other modules.

Your task is to write the Verilog code for the module. The code should be no longer than 200 lines and should be written in the sky130_fd_sc_ms technology library.

You may assume that all input signals are valid and that the voltage supply signals are already defined in the module.
