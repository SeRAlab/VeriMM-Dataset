Design a Verilog module that implements a basic RRT (Rapidly-exploring Random Tree) step. The module should take a current node position (x, y), a goal position (goal_x, goal_y), and an obstacle map (obstacle_map), which indicates whether a position is free (0) or occupied (1). The module will calculate a new node position (new_x, new_y) by randomly exploring a direction from the current node towards the goal, while avoiding obstacles. The output should indicate whether the new position is valid (not an obstacle) and if it is within a certain distance from the goal. The module should have a clock and reset signal to manage state transitions.
