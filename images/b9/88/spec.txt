Design a Verilog module that implements a 16-bit binary down-counter with both synchronous and asynchronous resets and an enable signal. The counter should decrement on the rising edge of the clock if the enable (en) signal is high. The counter should reset to '1111111111111111' when the synchronous reset (sreset) is high or the asynchronous reset (areset) is high. The counter value should be output to the "count" signal.

module down_counter_with_enable
(
    input clk,
    input en,
    input sreset,
    input areset,
    output reg [15:0] count
);
