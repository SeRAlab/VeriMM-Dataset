
Create a combinational logic circuit that implements a simple decision tree with the following structure:
- Input: 3-bit binary number (X[2:0])
- Decision: 
  - If X[2] == 0 and X[1] == 0, output 0
  - If X[2] == 0 and X[1] == 1, output 1
  - If X[2] == 1 and X[1] == 0, output 2
  - If X[2] == 1 and X[1] == 1, output 3
- The output should be a 2-bit binary number (Y[1:0]).
