Design a 3-bit up/down counter that can be loaded with a specific value D on the rising edge of the CLK signal when the load signal (LD) is high. If LD is low, the counter operates in either up or down mode based on the state of the up/down control signal (UD): if UD is high, the counter decrements its current value, and if UD is low, it increments the current value. The output Q holds the current count.
module top_module(
    input [2:0] D,
    input UD,
    input LD,
    input CLK,
    output reg [2:0] Q
);
