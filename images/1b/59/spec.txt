
Create a Verilog module that implements bilinear interpolation for a 2D grid. The module should take four input pixel values (Q11, Q12, Q21, Q22) and two fractional coordinates (u, v) as inputs. It should output the interpolated pixel value (Q) based on the bilinear interpolation formula:
Q = (1-u)*(1-v)*Q11 + (1-u)*v*Q12 + u*(1-v)*Q21 + u*v*Q22
Where u and v are in fixed-point format (8 bits with 8 fractional bits).
