Design a Fractional-N PLL that takes a reference clock and a fractional feedback divisor to generate a high-frequency output clock. The PLL should be adjustable between two states based on the control input: a locked state and an unlocked state. The output clock should toggle only when in the locked state, and it should remain stable in the unlocked state. The design must include a counter to track the number of cycles and a state machine to manage the PLL states.
