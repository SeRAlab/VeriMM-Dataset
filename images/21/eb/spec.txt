
Design a 1-bit DRAM cell in Verilog that can store a single bit of data. The DRAM cell should have the following inputs:
- `addr`: the address for selecting the cell (1 bit)
- `data_in`: the data to be written to the cell (1 bit)
- `we`: write enable signal (1 bit)
- `clk`: clock signal (1 bit)
The cell should output the stored value when the read operation is enabled. It should have an output `data_out` (1 bit). The read operation occurs when `we` is low.
