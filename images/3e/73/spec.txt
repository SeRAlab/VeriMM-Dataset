Design a 16-bit 2-to-1 multiplexer. The multiplexer will have two 16-bit data inputs (data0 and data1), a select input (sel), and a 16-bit data output (data_out). The output should reflect the selected input based on the value of sel: if sel is 0, data_out should equal data0; if sel is 1, data_out should equal data1.
