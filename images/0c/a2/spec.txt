Design a Verilog module that implements a simple Discrete Wavelet Transform (DWT) for a 1D input signal of size 8. The module should take an 8-bit input vector and produce two 8-bit output vectors: one for the approximation coefficients and one for the detail coefficients. The coefficients are computed using a 1D Haar wavelet transform. The design should use a clock signal for synchronization and a reset signal to initialize the outputs.
