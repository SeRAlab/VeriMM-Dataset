

You have been tasked with designing a module that will take in a 4-bit input and output a 16-bit vector. The output vector should be the input value replicated 4 times, with each replication shifted one bit to the left. For example, if the input is `1010`, the output should be `1010000010100000`.

Write a Verilog module that implements this functionality. The module should have the following interface:

Inputs:
- `in`: 4-bit input value

Outputs:
- `out`: 16-bit output vector

You may assume that the input value will be valid and that the output vector will not overflow.
