
Design a priority arbiter in Verilog that accepts three request signals (req0, req1, req2). The arbiter should grant access based on the priority: req0 has the highest priority, followed by req1, and then req2. The output should be a grant signal (grant) indicating which request has been granted. If multiple requests are active, grant the one with the highest priority. Additionally, if no requests are active, grant should be low.
