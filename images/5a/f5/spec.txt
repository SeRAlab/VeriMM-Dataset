Design a PWM (Pulse Width Modulation) generator that outputs a control signal based on a specified duty cycle of 75%. The module uses a clock input to increment a 32-bit counter when the control input is asserted. The output, `pwm_out`, generates a high pulse for a duration proportional to the duty cycle and maintains a low state otherwise. When the control signal is low, the counter resets and the output remains low, effectively disabling the PWM functionality.
module top_module(
    input clk,
    input ctrl,
    output reg pwm_out
);
