Design a 5-bit wide, 2-to-1 multiplexer. The module selects between two 5-bit inputs, Input0 and Input1, based on the selection signal Sel. When Sel is 0, the output Output_Mux reflects Input0; when Sel is 1, the output reflects Input1. If an unexpected value for Sel is encountered, Output_Mux will be set to an undefined state.
module top_module(Input0, Input1, Sel, Output_Mux );
