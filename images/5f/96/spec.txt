Design a Read-Only Memory (ROM) module that uses an n-bit address input to select one of 2^n possible data words, each m bits wide. The internal memory is initialized with specific values, allowing for the retrieval of predefined data based on the input address. When the address changes, the corresponding data word from memory is output, making it suitable for applications requiring fixed data storage that must not be modified during operation.

  input [n-1:0] addr,
  output reg [m-1:0] out // Change to reg type
