Design an 8-bit SRAM cell with a read and write capability. The cell should have a single write enable signal (WE), a read enable signal (RE), an 8-bit data input (D), an 8-bit data output (Q), and a 3-bit address (A) for selecting one of the 8 SRAM cells. The design should allow writing to the specified cell when WE is high and reading from the specified cell when RE is high. Ensure that the output Q reflects the data of the selected SRAM cell during a read operation.
