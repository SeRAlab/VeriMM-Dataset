Design a 128-bit AES encryption module that takes a 128-bit plaintext input and a 128-bit key input and outputs a 128-bit ciphertext after one round of AES encryption. The module should implement the ShiftRows, SubBytes, and AddRoundKey transformations as part of the AES algorithm, but not the MixColumns transformation for simplicity. The module should also have a clock and reset signal to control the operation.
