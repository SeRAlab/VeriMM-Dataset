Design a Verilog module that implements a 6-bit binary counter with both enable and load signals. The module should have a clock input, a reset input, an enable input, a load input, a 6-bit load value input, and a 6-bit output. The counter should increment on every clock cycle when the enable signal is high, load the load value when the load signal is high, and reset to 0 when the reset signal is high.

module counter6bit_en_load (
    input clk,
    input rst,
    input en,
    input load,
    input [5:0] load_value,
    output reg [5:0] count
);
