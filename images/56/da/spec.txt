Implement a Verilog module based on the following description.
This module is a synchronous 4-bit up/down counter. It should count up when the up signal is high, and count down when the down signal is high. If both signals are low or both are high, the counter should hold its value. The reset should be active high synchronous.
module up_down_counter(
	input clk,
	input reset,
	input up,
	input down,
	output [3:0] count);
