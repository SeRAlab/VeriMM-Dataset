Design a synchronous D flip-flop with enable, set, and clear functionalities. The flip-flop captures the value of input D on the rising edge of the clock (CLK) when the enable (EN) signal is high. If the set (SET) signal is activated, it forces the output Q to HIGH and Qbar to LOW. Conversely, if the clear (CLR) signal is triggered, it sets Q to LOW and Qbar to HIGH. When neither SET nor CLR are active, the output Q reflects the value of D, while Qbar is the complement of Q.
