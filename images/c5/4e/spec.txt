

You are tasked with designing a verilog module that takes in four inputs and produces one output. The module should be named "my_module". The inputs are as follows:

- "clk": a clock input.
- "rst": a reset input.
- "data_in": a 4-bit input.
- "enable": an enable input.

The output of the module is:

- "data_out": a 4-bit output.

The module should operate as follows:

- When "enable" is high, the module should output "data_in" on "data_out".
- When "enable" is low, the module should output the value of "data_out" from the previous clock cycle.

You should use flip-flops to store the output from the previous clock cycle.
