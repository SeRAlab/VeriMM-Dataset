Design a Mealy finite state machine (FSM) that transitions between two states based on the input signal 'a' and the clock. The FSM has a reset functionality and outputs 'y' when it is in state S1 and the input 'a' is asserted (high). When 'a' is low, the state transitions from S0 to S1 or remains in the current state based on the input. This design could be used for pattern detection or conditional signaling applications where the output depends on both the current state and the input.

    input  clock,
