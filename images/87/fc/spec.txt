Design a 4-stage shift register circuit that serves as a delay line for a single input signal A. On the rising edge of the clock (clk), if the reset signal is activated, the output X and the internal delay register are both reset to zero. Otherwise, the latest input A is shifted into the register, and the output X reflects the value of the fourth bit of the register, effectively delaying the input signal by three clock cycles.

    input A,
    input reset,
    output reg X,
    input clk
